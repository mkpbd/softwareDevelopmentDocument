1.3 Variables and Data Type in Python

## **Variable কী?**

Variable হলো এমন একটি নাম, যেখানে আমরা কোনো ডেটা (value) সংরক্ষণ করি।
এটা মূলত কম্পিউটারের মেমোরিতে একটি জায়গার রেফারেন্স।
উদাহরণ:
```python
name = "Mehrab"
age = 28
price = 99.99
```
এখানে
-   name → একটি স্ট্রিং ভ্যালু সংরক্ষণ করছে
-   age → একটি integer ভ্যালু সংরক্ষণ করছে
-   price → একটি floating-point সংখ্যা সংরক্ষণ করছে

### **Python এ Variables এর বৈশিষ্ট্য**

1.  আলাদা করে ডেটা টাইপ ঘোষণা করতে হয় না (Dynamic Typing)।
    ```python
    x = 10     
    x = "Hello"
    ```
2.  একই ভ্যারিয়েবল নতুন ভ্যালু নিয়ে ডেটা টাইপও পরিবর্তন করতে পারে।
3.  সমান চিহ্ন (=) দিয়ে মান অ্যাসাইন করা হয়।
    ```python
    country = "Bangladesh"
    ```
4.  এক লাইনে একাধিক ভ্যারিয়েবলেও মান দেওয়া যায়।
    ```python
    a, b, c = 5, 10, 15
    ```

## **Python এ সাধারণ Data Types**

Python এ অনেক ধরনের Data Types আছে, তবে সবচেয়ে বেশি ব্যবহৃত কিছু হলো:

1.  **Numeric Types**
    -   `int` → পূর্ণসংখ্যা (যেমন 10, -5)
    -   `float` → দশমিক সংখ্যা (যেমন 3.14, -0.5)
2.  **Text Type**
    -   `str` → স্ট্রিং (যেমন "Hello", 'Python')
3.  **Sequence Types**
    -   `list` → পরিবর্তনযোগ্য লিস্ট (যেমন [1, 2, 3])
    -   `tuple` → অপরিবর্তনযোগ্য লিস্ট (যেমন (1, 2, 3))
4.  **Mapping Type**
    -   `dict` → কী-ভ্যালু পেয়ার (যেমন {"name": "Rafi", "age": 25})
5.  **Set Types**
    -   `set` → অনন্য মানের কালেকশন (যেমন {1, 2, 3})
6.  **Boolean Type**
    -   `bool` → True বা False

## **Variables Naming Convention**

Python এ ভ্যারিয়েবল নামকরণ করার কিছু নিয়ম ও ভালো অভ্যাস (convention) আছে:

#### নিয়ম:

1.  নামের শুরুতে অক্ষর বা আন্ডারস্কোর (\_) হতে হবে
2.  সংখ্যা দিয়ে শুরু করা যাবে না
    ```python
    name = "Phitron"   # valid
    _age = 20         # valid
    2nd_number = 50   # invalid
    ```
3.  শুধুমাত্র অক্ষর, সংখ্যা ও আন্ডারস্কোর ব্যবহার করা যায়।
4.  স্পেস বা স্পেশাল ক্যারেক্টার ব্যবহার করা যাবে না।
5.  ভ্যারিয়েবল case-sensitive।
6.  `age`, `Age`, `AGE` — তিনটি আলাদা ভ্যারিয়েবল

1.4 Taking Input in Python

এই মডিউলে আমরা দেখব কিভাবে টার্মিনাল থেকে ডেটা ইনপুট নেয় যায়।

এর জন্য আমরা পাইথনের বিল্ট-ইন **input** মেথড ইউস করতে পারি।

```python

print("Welcome,", name)
```

```
Welcome, Mehrab
```

এ থেকে বোঝা গেল, ইনপুট নেয়া যে কোন ডেটার টাইপ কিন্ত str - ই হবে।

যদিও প্রয়োজন অনুসারে ডেটার টাইপ পরিবর্তন করে নিতে পারব আমরা -

**(Image of code snippet and output)**
```python

```

```
Enter your age: 20
20
<class 'int'>
```

এখানে, age এর ডেটা টাইপ int- এ cast (রুপান্তর) করা হয়েছে।


1.5 Operators in Python

# **Operators in Python**

এই মডিউলে আমরা পাইথনে ব্যবহৃত operators সম্পর্কে জানব।

Python প্রোগ্রামিং ভাষায় অপারেটর হলো এমন কিছু প্রতীক বা চিহ্ন যেগুলো ভ্যারিয়েবল বা মানের উপর নির্দিষ্ট কাজ সম্পাদন করে। উদাহরণ: +, -, *, / ইত্যাদি।

## Arithmetic Operators
এগুলো গাণিতিক হিসাব-নিকাশ করার জন্য ব্যবহার হয়।
উদাহরণ:
x = 10, y = 3
- `x + y` → যোগফল (13)
- `x - y` → বিয়োগফল (7)
- `x * y` → গুণফল (30)
- `x / y` → ভাগফল (3.333...)
- `x % y` → modulus (1)
- `x // y` → পূর্ণসংখ্যা ভাগফল (3)
- `x ** y` → power (10³ = 1000)

## Comparison Operators
দুটি মানের মধ্যে তুলনা করার জন্য ব্যবহৃত হয়। ফলাফল সবসময় True অথবা False হয়।
উদাহরণ:
- `x == y` → সমান কি না
- `x != y` → সমান নয় কি না
- `x > y` → বড় কি না
- `x < y` → ছোট কি না
- `x >= y` → বড় বা সমান কি না
- `x <= y` → ছোট বা সমান কি না

## Assignment Operators
ভ্যারিয়েবলে মান সেট বা আপডেট করার জন্য ব্যবহার হয়।
উদাহরণ:
- `x = 5` → মান সেট করা
- `x += 3` → x = x + 3
- `x -= 2` → x = x - 2
- `x *= 4` → x = x * 4
- `x /= 2` → x = x / 2
- `x %= 3` → x = x % 3
- `x **= 2` → x = x ** 2

## Membership Operators
একটি মান কোনো সিকোয়েন্স (যেমন লিস্ট, টিউপল, স্ট্রিং) এর মধ্যে আছে কি না তা যাচাই করতে ব্যবহৃত হয়।
উদাহরণ:
- `"a" in "apple"` → True
- `"b" not in "apple"` → True

## Identity Operators
দুটি ভ্যারিয়েবল একই অবজেক্টকে নির্দেশ করছে কি না তা যাচাই করতে ব্যবহৃত হয়।
উদাহরণ:
- `x is y`
- `x is not y`

# Logical Operators কী?

Logical operators হলো এমন অপারেটর যা boolean মানের উপর কাজ করে এবং ফলাফল হিসেবে True বা False প্রদান করে।
Python-এ তিনটি logical operators আছে:
-   and
-   or
-   not

## **and Operator**
দুটি বা তার বেশি boolean মানকে যুক্ত করে।
ফলাফল True হবে শুধুমাত্র যদি সব মান True হয়।
উদাহরণ:
-   `True and True` → True
-   `True and False` → False
-   `False and False` → False

## **or Operator**
দুটি বা তার বেশি boolean মানের মধ্যে যেকোনো একটি True হলে ফলাফল True হয়।
উদাহরণ:
-   `True or False` → True
-   `False or False` → False
-   `True or True` → True

## **not Operator**
একটি boolean মানকে উল্টো করে। True হলে False হয়, False হলে True হয়।
উদাহরণ:
-   `not True` → False
-   `not False` → True

## **Operator Precedence Table (Highest to Lowest)**

1.  `()` - parentheses (grouping)
2.  `**` - exponentiation
3.  `+x, -x, ~x` - unary plus, minus, bitwise NOT
4.  `*, /, //, %` - multiplication, division, floor division, modulus
5.  `+, -` - addition, subtraction
6.  `<<, >>` - bitwise shifts
7.  `&` - bitwise AND
8.  `^` - bitwise XOR
9.  `|` - bitwise OR
10. Comparison: `==, !=, >, <, >=, <=`
11. `not` - logical NOT
12. `and` - logical AND
13. `or` - logical OR
14. Assignment: `=, +=, -=, *=, /=, //=, %=, **=`

এবার ধাপে ধাপে প্রবলেম টি সলভ করি -

**ইনপুট নেওয়া**
Python এ বড় সংখ্যা নেওয়া সম্ভব, তাই 10^18 পর্যন্ত সংখ্যা সমস্যা ছাড়াই নেওয়া যায়।
```python
N, M = map(int, input().split())
```
এখানে, `split()` মেথডের সাহায্যে ইনপুট গুলো কে স্পেস দিয়ে আলাদা করা হয়েছে এবং `map()` এর সাহায্যে সবগুলো ইনপুট কে int এ কনভার্ট করা হয়েছে।

**last digit বের করা**
সংখ্যার শেষ অঙ্ক বের করার জন্য modulus `% 10` ব্যবহার করা হয়।
```python
last_digit_N = N % 10
last_digit_M = M % 10
```
**লাস্ট ডিজিট দুইটির যোগফল গণনা**
1.  যোগফল:
    ```python
    result = last_digit_N + last_digit_M
    ```
**ফলাফল প্রিন্ট করা**
2.  Python এর `print()` ব্যবহার করে ফলাফল দেখানো যায়।

## **কোড**
```python
N, M = map(int, input().split())

last_digit_N = N % 10
last_digit_M = M % 10

result = last_digit_N + last_digit_M

print(result)
```
