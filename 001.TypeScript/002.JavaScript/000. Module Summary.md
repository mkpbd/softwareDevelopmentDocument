# 📚 Course Overview: ১০ মডিউলের মহাযাত্রা
আমরা একদম **Basic** থেকে শুরু করে **Advanced** প্রজেক্ট পর্যন্ত বানাবো।
1. **Module 1:** JS Basics (ভিত্তি শক্ত করা)
2. **Module 2:** Functions & Intermediate (লজিক বিল্ড করা)
3. **Module 3:** Arrays & Objects (ডেটা নিয়ে খেলা)
4. **Module 4:** DOM (ওয়েবসাইটকে জীবন্ত করা)
5. **Module 5:** Async JS (সার্ভারের সাথে কথা বলা)
6. **Module 6:** ES6+ (মডার্ন জাভাস্ক্রিপ্ট)
7. **Module 7:** OOP (অ্যাডভান্সড স্ট্রাকচার)
8. **Module 8:** Advanced Topics (প্রো টিপস)
9. **Module 9:** Real Project (হাতে কলমে কাজ)
10. **Module 10:** Final Touch (ডিপলয় ও ফিউচার)
