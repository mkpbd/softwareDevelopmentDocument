### 📖 Lesson 1: JS আসলে কী? (The Brain)

**🎯 Learning Goal:** জাভাস্ক্রিপ্ট ব্রাউজারে কী কাজ করে তা বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
ধরো একটা ওয়েবসাইট একটা **মানুষ**।
- **HTML** হলো মানুষের **কঙ্কাল (Skeleton)**।
- **CSS** হলো মানুষের **চামড়া, জামাকাপড় ও মেকআপ (Style)**।
- **JavaScript (JS)** হলো মানুষের **ব্রেইন বা বুদ্ধি (Logic/Behavior)**।
JS ছাড়া ওয়েবসাইট হলো একটা মূর্তির মতো, নড়াচড়া করতে পারে না। JS দিলে সে হাঁটতে পারে, কথা বলতে পারে।

**🤣 Real-life Analogy:**
বিয়ে বাড়িতে প্যান্ডেল আর লাইটিং হলো HTML/CSS। আর বাবুর্চি যে বিরিয়ানি রান্না করছে, ওয়েটার যে খাবার দিচ্ছে—এই কাজের মানুষগুলো হলো JavaScript। কাজ না থাকলে ডেকোরেশন দিয়ে পেট ভরবে না!

**💻 Code Example:**
ব্রাউজারের কনসোলে (Console) আমরা আমাদের প্রথম কোড লিখবো।
```javascript
// কনসোল হলো আমাদের টেস্ট খাতা
console.log("Hello Bondhu! JS shikhtesi!");
```

**💪 Mini Exercise:**
1. তোমার ব্রাউজারে `Right Click` -> `Inspect` -> `Console` এ যাও।
2. `console.log("Amar nam [Tomar Nam]")` লিখে Enter চাপো।

**⚠️ Common Mistakes:**
- `console.log` এর `c` ছোট হাতের হবে। `Console.log` লিখলে এরর খাবে।

**📝 One-line Summary:**
JS হলো ওয়েবসাইটের প্রাণ, যা দিয়ে ওয়েবসাইটকে ডাইনামিক করা হয়।

**🏢 Real Project Importance:**
বাটন ক্লিক করলে মেনু আসা, ফর্ম ফিলাপ করা—সব JS দিয়েই হয়।

### 📖 Lesson 2: Variables (লেট, কনস্ট - পাত্রের খেলা)

**🎯 Learning Goal:** ডেটা স্টোর করার নিয়ম শেখা (`let` vs `const`)।

**🗣️ সহজ ব্যাখ্যা:**
প্রোগ্রামিংয়ে আমাদের তথ্য (Data) জমা রাখতে হয়। যেখানে জমা রাখি তাকে বলে **Variable**।
- **`const`**: এমন বাক্স যার ভেতরের জিনিস আর পাল্টানো যাবে না।
- **`let`**: এমন বাক্স যার ভেতরের জিনিস পরে বদলানো যাবে।
*(আগে `var` ব্যবহার হতো, এখন আমরা মডার্ন `let/const` ব্যবহার করবো)*।

**🤣 Real-life Analogy:**
- **`const`**: তোমার **বউয়ের নাম**। একবার ঠিক হলে আর বদলানো যাবে না (রিস্ক আছে! 😜)।
- **`let`**: তোমার **পকেটের টাকা**। সকালে ১০০ টাকা ছিল, বিকেলে ১০ টাকা হয়ে যেতে পারে।

**💻 Code Example:**
```javascript
let pocketMoney = 500;
console.log(pocketMoney); // 500

pocketMoney = 200; // মান পরিবর্তন করলাম
console.log(pocketMoney); // 200

const myName = "Rahim";
console.log(myName);

// myName = "Karim"; // ❌ Error দিবে! নাম বদলানো যাবে না।
```

**💪 Mini Exercise:**
1. `let` দিয়ে তোমার `age` ডিক্লেয়ার করো।
2. পরে `age` এর মান বাড়িয়ে প্রিন্ট করো।

**⚠️ Common Mistakes:**
- `const` ভেরিয়েবলের মান পরে পরিবর্তন করার চেষ্টা করা। এটা ক্রাইম!

**📝 One-line Summary:**
ফিক্সড ভ্যালুর জন্য `const`, আর চেঞ্জ হতে পারে এমন ভ্যালুর জন্য `let` ব্যবহার করো।

**🏢 Real Project Importance:**
ইউজারের নাম (const) আর শপিং কার্টের টোটাল প্রাইস (let) রাখার জন্য এগুলো লাগে।

### 📖 Lesson 3: Data Types (কোনটা কী জিনিস?)

**🎯 Learning Goal:** স্ট্রিং, নাম্বার, বুলিয়ান সম্পর্কে জানা।

**🗣️ সহজ ব্যাখ্যা:**
জাভাস্ক্রিপ্টে ডেটা বিভিন্ন টাইপের হয়:
1. **String:** টেক্সট বা লেখা। কোটেশনের `""` বা `''` মধ্যে থাকে।
2. **Number:** সংখ্যা (পূর্ণসংখ্যা বা দশমিক)।
3. **Boolean:** সত্য বা মিথ্যা (`true` / `false`)।
4. **Undefined:** বাটি আছে কিন্তু ভেতরে কিছু নাই।

**🤣 Real-life Analogy:**
- **String:** প্রেমিকার নাম (লেখা)।
- **Number:** মোবাইল নাম্বার (সংখ্যা)।
- **Boolean:** তুমি কি পাস করেছ? (হ্যাঁ/না)।

**💻 Code Example:**
```javascript
let name = "Sokina Begum"; // String
let age = 25;              // Number
let isMarried = false;     // Boolean
let futurePlan;            // Undefined (এখনও ঠিক করি নাই)

console.log(typeof name); // "string"
console.log(typeof age);  // "number"
```

**💪 Mini Exercise:**
1. তোমার নাম, বয়স এবং তুমি স্টুডেন্ট কিনা (true/false)—এই তিনটি ভেরিয়েবল বানাও।

**⚠️ Common Mistakes:**
- নাম্বারকে কোটেশনের মধ্যে লেখা (যেমন `"25"`), তখন সেটা স্ট্রিং হয়ে যায়, যোগ-বিয়োগ করা যায় না।

**📝 One-line Summary:**
কম্পিউটারকে বোঝাতে হয় কোনটা লেখা (String) আর কোনটা হিসাবের সংখ্যা (Number)।

**🏢 Real Project Importance:**
ফর্ম ভ্যালিডেশনে লাগে—ফোন নাম্বারের জায়গায় কেউ নাম লিখল কিনা চেক করতে।

### 📖 Lesson 4: Operators (হিসাব নিকাশ)

**🎯 Learning Goal:** যোগ, বিয়োগ, গুণ, ভাগ এবং তুলনা করা শেখা।

**🗣️ সহজ ব্যাখ্যা:**
ছোটবেলার অংক:
`+` (যোগ), `-` (বিয়োগ), `*` (গুণ), `/` (ভাগ), `%` (ভাগশেষ)।
তুলনা করার জন্য: `==`, `===`, `>`, `<`।

**🤣 Real-life Analogy:**
- `%` (Modulus): ৫টা বিরিয়ানির প্যাকেট ২ জনকে দিলে, কয়টা অবশিষ্ট থাকবে? (১টা)। এই ১ হলো ভাগশেষ।
- `===`: আপন ভাই। `==`: খালাতো ভাই (একটু ছাড় দেয়)।

**💻 Code Example:**
```javascript
let alu = 30;
let peyaj = 50;
let total = alu + peyaj; 
console.log(total); // 80

// ভাগশেষ বা Modulus
let money = 10;
let person = 3;
console.log(money % person); // 1 (অবশিষ্ট)

// তুলনা (Comparison)
console.log(5 > 3); // true
console.log('5' == 5);  // true (টাইপ চেক করে না, শুধু ভ্যালু দেখে)
console.log('5' === 5); // false (টাইপও চেক করে, এটা ব্যবহার করা বেস্ট)
```

**💪 Mini Exercise:**
1. তোমার জন্মসাল থেকে বর্তমান সাল বিয়োগ করে বয়স বের করো।
2. `10 === "10"` ট্রাই করে দেখো কী আসে।

**⚠️ Common Mistakes:**
- `=` (অ্যাসাইনমেন্ট) আর `==` বা `===` (তুলনা) গুলিয়ে ফেলা।

**📝 One-line Summary:**
হিসাবের জন্য ম্যাথ অপারেটর, আর লজিকের জন্য `===` ব্যবহার করবো।

**🏢 Real Project Importance:**
ই-কমার্স সাইটে ডিসকাউন্ট ক্যালকুলেশন বা পাসওয়ার্ড ম্যাচিংয়ে অপারেটর লাগে।

### 📖 Lesson 5: Template Literals (স্মার্ট স্ট্রিং)

**🎯 Learning Goal:** ডাইনামিক স্ট্রিং বা লেখা তৈরি করা (Backticks ব্যবহার করে)।

**🗣️ সহজ ব্যাখ্যা:**
আগে স্ট্রিং যোগ করতে `+` দিয়ে জোড়াতালি দেওয়া লাগতো। এখন আমরা ব্যাকটিক ( `` ` `` ) ব্যবহার করি। এর ভেতরে `${variable}` দিয়ে সরাসরি ভেরিয়েবল বসানো যায়।

**🤣 Real-life Analogy:**
আগে চিঠি লিখতে হতো: "প্রিয় " + নাম + ", আশা করি..." (বিরক্তিকর)।
এখন টেমপ্লেট লিটারেল হলো শূন্যস্থান পূরণ: "প্রিয় ${নাম}, আশা করি..." (সহজ)।

**💻 Code Example:**
```javascript
let hero = "Shakib Khan";
let movie = "Toofan";

// Old Way (Boring)
let messageOld = hero + " acted in " + movie;

// New Way (Smart - ES6)
let messageNew = `${hero} acted in ${movie} recently.`;

console.log(messageNew);
```

**💪 Mini Exercise:**
1. দুটি ভেরিয়েবল নাও: `myName` এবং `myCity`.
2. ব্যাকটিক ব্যবহার করে প্রিন্ট করো: "Amar nam X, ami Y te thaki."

**⚠️ Common Mistakes:**
- ব্যাকটিক (`) এর বদলে সিঙ্গেল কোট (') ব্যবহার করা। ব্যাকটিক সাধারণত Tab কী-এর উপরে থাকে।

**📝 One-line Summary:**
স্ট্রিংয়ের ভেতরে ভেরিয়েবল ঢোকাতে ব্যাকটিক (`` ` ``) আর `${}` ব্যবহার করা সবচেয়ে সহজ।

**🏢 Real Project Importance:**
ইউজারকে ওয়েলকাম মেসেজ দেখাতে: `Welcome back, ${userName}!`

### 📖 Lesson 6: Conditionals (যদি... কিন্তু... অথবা)

**🎯 Learning Goal:** `if`, `else if`, `else` দিয়ে সিদ্ধান্ত নেওয়া।

**🗣️ সহজ ব্যাখ্যা:**
কোডকে বুদ্ধি দেওয়া। "যদি" বৃষ্টি হয়, "তাহলে" ছাতা নাও। "না হলে" সানগ্লাস নাও।

**🤣 Real-life Analogy:**
পকেটে ৫০০ টাকা থাকলে **কাচ্চি** খাবো। ২০০ টাকা থাকলে **বার্গার**। আর টাকা না থাকলে **বাসায় গিয়ে ডাল-ভাত**।

**💻 Code Example:**
```javascript
let pocketMoney = 150;

if (pocketMoney >= 500) {
    console.log("Cholo Kacchi khai!");
} else if (pocketMoney >= 200) {
    console.log("Burger e hobe ajke.");
} else {
    console.log("Mama, ruti kala vuna den (Or basha jao).");
}
```

**💪 Mini Exercise:**
1. একটা ভেরিয়েবল `marks` নাও।
2. যদি `marks >= 33` হয়, প্রিন্ট করো "Pass", না হলে "Fail"।

**⚠️ Common Mistakes:**
- `if (pocketMoney = 500)` লেখা (একটা সমান চিহ্ন)। এটা ভুল! `==` বা `===` দিতে হবে।

**📝 One-line Summary:**
শর্ত সাপেক্ষে কোড রান করতে `if-else` লাগে।

**🏢 Real Project Importance:**
লগইন করা থাকলে প্রোফাইল দেখাবে, না থাকলে লগইন বাটন দেখাবে—এটা `if-else` দিয়েই হয়।

### 📖 Lesson 7: Loops (একই কাজ বারবার)

**🎯 Learning Goal:** `for` লুপ এবং `while` লুপের ব্যবহার।

**🗣️ সহজ ব্যাখ্যা:**
একই কাজ বারবার করার জন্য লুপ ব্যবহার করা হয়। ১০০ বার "Sorry" প্রিন্ট করতে ১০০ লাইন কোড না লিখে ৩ লাইনের লুপ লিখলেই হয়।

**🤣 Real-life Analogy:**
স্কুলে দুষ্টামি করলে টিচার বলতো "আমি আর কথা বলবো না"—১০০ বার লেখ। এটাই লুপ।

**💻 Code Example:**
```javascript
// For Loop: শুরু; শর্ত; ধাপ
for (let i = 1; i <= 5; i++) {
    console.log(`Sorry Babu ${i} bar`);
}

// i++ মানে i এর মান ১ করে বাড়বে
```

**💪 Mini Exercise:**
1. ১ থেকে ১০ পর্যন্ত সংখ্যাগুলো কনসোলে প্রিন্ট করো।

**⚠️ Common Mistakes:**
- লুপ থামানোর শর্ত (condition) ভুল করা, যার ফলে **Infinite Loop** হয়ে পিসি হ্যাং হয়ে যায়।

**📝 One-line Summary:**
রিপিটেটিভ কাজের জন্য কপি-পেস্ট না করে লুপ ব্যবহার করতে হয়।

**🏢 Real Project Importance:**
ফেসবুকের নিউজফিডে হাজার হাজার পোস্ট দেখায়—ওটা আসলে একটা লুপের মাধ্যমে ডেটাগুলো লোড হচ্ছে।

### 📖 Lesson 8: Functions (জুস মেশিন)

**🎯 Learning Goal:** ফাংশন ডিক্লেয়ার করা এবং কল করা।

**🗣️ সহজ ব্যাখ্যা:**
ফাংশন হলো একটা মেশিনের মতো। ইনপুট দিলে আউটপুট দেয়। কোড বারবার না লিখে একটা ফাংশনে রেখে দিলে, দরকার মতো নাম ধরে ডাক দিলেই কাজ করে।

**🤣 Real-life Analogy:**
ব্লেন্ডার মেশিন।
- **ইনপুট:** আম, দুধ, চিনি।
- **প্রসেস:** ঘরররররররর (ব্লেন্ডিং)।
- **আউটপুট:** ম্যাংগো জুস।

**💻 Code Example:**
```javascript
// Function তৈরি করা
function makeJuice(fruit1, fruit2) {
    let juice = `Wow! ${fruit1} and ${fruit2} juice is ready!`;
    return juice; // জুস ফেরত দিলো
}

// Function কল করা (মেশিন চালানো)
let myGlass = makeJuice("Mango", "Orange");
console.log(myGlass); 

let bondhuGlass = makeJuice("Apple", "Grape");
console.log(bondhuGlass);
```

**💪 Mini Exercise:**
1. `addMoney` নামে একটা ফাংশন বানাও যা দুটি সংখ্যা যোগ করে রিটার্ন করবে।

**⚠️ Common Mistakes:**
- ফাংশন বানালেন কিন্তু `return` করলেন না, তখন রেজাল্ট `undefined` আসবে।
- ফাংশন বানালেন কিন্তু কল (Call) করলেন না, তখন কিছুই হবে না।

**📝 One-line Summary:**
ফাংশন হলো রিইউজেবল কোড ব্লক—একবার লিখবো, হাজারবার ব্যবহার করবো।

**🏢 Real Project Importance:**
"Add to Cart" বাটন সব প্রোডাক্টের নিচে থাকে। বাটন টিপলে একই `addToCart()` ফাংশন কল হয়।

### 📖 Lesson 9: Scope (এলাকার মাস্তান)

**🎯 Learning Goal:** Global Scope এবং Block Scope বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
**Scope** মানে এলাকা।
- **Global Scope:** প্রধানমন্ত্রী। সারা দেশে তার ক্ষমতা।
- **Block Scope (Local):** তোমার বাসার চাবি। এটা দিয়ে শুধু তোমার গেট খুলবে, প্রতিবেশীর গেট খুলবে না।

**🤣 Real-life Analogy:**
পাবলিক টয়লেট (Global) সবাই ইউজ করতে পারে। কিন্তু তোমার বেডরুমের টয়লেট (Local) শুধু তুমি ইউজ করো।

**💻 Code Example:**
```javascript
let globalVip = "Ami PM"; // Global Variable

function myArea() {
    let localMastaan = "Ami Elakar Bhai"; // Local Variable
    console.log(globalVip); // কাজ করবে, কারণ PM সব জায়গায় চলে
}

myArea();
// console.log(localMastaan); // ❌ Error! এলাকার মাস্তান এলাকার বাইরে অচল।
```

**💪 Mini Exercise:**
1. `if` ব্লকের ভেতরে একটা `let` ভেরিয়েবল ডিক্লেয়ার করো। ব্লকের বাইরে সেটা প্রিন্ট করার চেষ্টা করো এবং এরর দেখো।

**⚠️ Common Mistakes:**
- ফাংশনের ভেতরের ভেরিয়েবল বাইরে খোঁজা।

**📝 One-line Summary:**
`{}` সেকেন্ড ব্র্যাকেটের ভেতরের জিনিস (`let/const`) বাইরে থেকে দেখা যায় না।

**🏢 Real Project Importance:**
যাতে এক ফাংশনের ভেরিয়েবল অন্য ফাংশনের সাথে মারামারি (conflict) না করে, তাই স্কোপ বোঝা জরুরি।

### 📖 Lesson 10: Module 1 Recap & Mini Logic

**🎯 Learning Goal:** আগের ৯টি লেসন ঝালাই করা এবং ছোট্ট একটা লজিক বিল্ড করা।

**🗣️ সহজ ব্যাখ্যা:**
আমরা এখন পর্যন্ত ভেরিয়েবল, লুপ, কন্ডিশন, ফাংশন শিখেছি। এগুলো হলো রান্নার মশলা। এখন আমরা ছোট একটা রান্না করবো।

**🚀 Project Logic: নামতা (Multiplication Table) জেনারেটর**
আমরা একটা ফাংশন বানাবো, যেখানে কোনো সংখ্যা দিলে তার নামতা প্রিন্ট করে দেবে।

**💻 Code Example:**
```javascript
function namotaLikho(number) {
    console.log(`--- ${number} er Namota ---`);
    
    for (let i = 1; i <= 10; i++) {
        let result = number * i;
        // 5 x 1 = 5
        console.log(`${number} x ${i} = ${result}`);
    }
}

namotaLikho(5); // ৫ এর নামতা
namotaLikho(13); // ১৩ এর নামতা
```

**💪 Mini Exercise:**
1. এই কোডটাই কপি করে এমনভাবে মডিফাই করো যেন শুধু জোড় সংখ্যার গুণফল দেখায় (if ব্যবহার করে)।

**⚠️ Common Mistakes:**
- লজিক সাজাতে ভয় পাওয়া। ছোট ছোট ভাগে ভাগ করে চিন্তা করো।

**📝 One-line Summary:**
প্রোগ্রামিং আসলে কিছুই না, ছোট ছোট লজিক জোড়া দিয়ে বড় সমস্যা সমাধান করা।

**🏢 Real Project Importance:**
এই লজিকটাই ই-কমার্সে `Item Price x Quantity = Total Price` বের করতে ব্যবহার করা হয়।
