### 📦 Module 5: রিকোয়েস্ট আর রেসপন্সের খেলা (Intermediate Express)

এই মডিউলে আমরা শিখবো ফ্রন্টএন্ড বা Postman থেকে ডাটা পাঠালে সার্ভার সেটা কিভাবে রিসিভ করে এবং কিভাবে স্মার্টলি রেসপন্স দেয়।

#### 🎓 Lesson 5.1: The Body Problem - ডাটা কোথায়?

**সহজ বাংলা:**
আমরা যখন GET রিকোয়েস্ট করি, ডাটা থাকে URL-এ। কিন্তু যখন POST রিকোয়েস্ট (লগইন বা সাইনআপ) করি, ডাটা থাকে রিকোয়েস্টের পেটের ভেতর (Body)। কিন্তু ডিফল্টভাবে Express এই পেট দেখতে পায় না।

**🤣 ফানি উদাহরণ:**
ধরো তোমার বন্ধু তোমাকে একটা গিফট বক্স (Request) পাঠিয়েছে। কিন্তু বক্সটা এত শক্ত টেপ দিয়ে মারা যে তুমি খুলতেই পারছো না। তুমি জানোই না ভেতরে কি আছে। Express এর অবস্থা শুরুতে এমনই থাকে।

**💻 কোড (সমস্যাটা দেখো):**
```javascript
app.post('/register', (req, res) => {
    console.log(req.body); // আউটপুট আসবে: undefined (ফাঁকা)
    res.send("ডাটা পাই নাই মামা!");
});
```

---

#### 🎓 Lesson 5.2: Middleware to Rescue - চশমা পরো মামা!

**সহজ বাংলা:**
Express কে `req.body` পড়ার ক্ষমতা দিতে হলে একটা **Middleware** ব্যবহার করতে হয়। এটা হলো `express.json()`। এটা ডাটাকে সুন্দর করে পার্স (Parse) করে দেয়।

**🤣 ফানি উদাহরণ:**
আগের গিফট বক্সটা খোলার জন্য এখন তোমার হাতে একটা **কাটার (Cutter)** আছে। এখন তুমি বক্স কেটে ভেতরের চকলেট বের করতে পারবে। `express.json()` হলো সেই কাটার।

**💻 কোড:**
```javascript
// এই লাইনটা কোডের শুরুতে (app তৈরির পর) দিতেই হবে!
app.use(express.json()); 

app.post('/register', (req, res) => {
    console.log(req.body); // এখন ডাটা দেখা যাবে!
    res.send("ধন্যবাদ! ডাটা পেয়েছি।");
});
```

#### 🎓 Lesson 5.3: POST Request - নতুন কিছু তৈরি করা

**সহজ বাংলা:**
POST মেথড ব্যবহার করা হয় সার্ভারে নতুন ডাটা তৈরি করার জন্য। যেমন: নতুন ইউজার তৈরি, পোস্ট শেয়ার করা ইত্যাদি।

**🤣 ফানি উদাহরণ:**
ব্যাংকে গিয়ে অ্যাকাউন্ট খোলার ফর্ম জমা দেওয়া। তুমি ফর্ম (Data) ফিলাপ করে ম্যানেজারের (Server) কাছে দিলে। ম্যানেজার সেটা নিয়ে সিস্টেমে এন্ট্রি করলো।

**💻 কোড:**
```javascript
app.post('/user', (req, res) => {
    const { name, age } = req.body; // বডি থেকে নাম আর বয়স নিলাম
    res.send(`স্বাগতম ${name}! আপনার বয়স ${age}, বিয়ার বয়স হইছে!`);
});
```

#### 🎓 Lesson 5.4: Postman দিয়ে ডাটা পাঠানো (Testing)

**সহজ বাংলা:**
কোড তো লিখলে, কিন্তু টেস্ট করবে কিভাবে? ব্রাউজার দিয়ে তো আর POST করা যায় না (ফর্ম ছাড়া)। তাই Postman ব্যবহার করবো।

**🤣 ফানি উদাহরণ:**
এটা হলো **ফেসবুক হ্যাক** করার মতো ভাব নেওয়া। তুমি ম্যানুয়ালি ডাটা সার্ভারে পুশ করছো।

**💻 কাজ:**
১. Postman ওপেন করো।
২. Method: `POST` সিলেক্ট করো।
৩. URL: `http://localhost:3000/user`
৪. নিচে `Body` ট্যাবে যাও -> `raw` সিলেক্ট করো -> ডানপাশে `JSON` সিলেক্ট করো।
৫. বক্সে লেখো:
```json
{
    "name": "Abul",
    "age": 25
}
```
৬. Send বাটনে চাপ দাও। ম্যাজিক দেখো!

#### 🎓 Lesson 5.5: HTTP Status Codes - ট্রাফিক সিগন্যাল

**সহজ বাংলা:**
সার্ভার শুধু ডাটা দিলেই হবে না, সাথে একটা স্ট্যাটাস কোড দিতে হয়। যাতে বোঝা যায় রিকোয়েস্ট সফল নাকি ব্যর্থ।
*   **200:** সব ঠিক আছে (OK)।
*   **201:** নতুন কিছু তৈরি হয়েছে (Created)।
*   **400:** তোমার রিকোয়েস্টে ভুল আছে (Bad Request)।
*   **404:** খুঁজে পাওয়া যায় নাই (Not Found)।
*   **500:** সার্ভারের পেটে অসুখ (Internal Server Error)।

**🤣 ফানি উদাহরণ:**
*   **200:** থাম্বস আপ 👍 (কাজ হইছে)।
*   **404:** ভুল দরজায় নক করেছো, এখানে কেউ থাকে না 🏠🚫।
*   **500:** বাবুর্চি রান্নাঘরে আগুন লাগিয়ে দিয়েছে 🔥 (তোমার দোষ না, বাবুর্চির দোষ)।

**💻 কোড:**
```javascript
app.post('/create', (req, res) => {
    res.status(201).send("অ্যাকাউন্ট খোলা হয়েছে!");
});

app.get('/not-found', (req, res) => {
    res.status(404).send("ভাই এই নামে কিছু নাই!");
});
```

#### 🎓 Lesson 5.6: PUT vs PATCH - বাড়ি ভাঙা বনাম রঙ করা

**সহজ বাংলা:**
ডাটা আপডেট করার জন্য এই দুইটা মেথড ব্যবহার হয়। কিন্তু পার্থক্য আছে:
*   **PUT:** পুরো ডাটা রিপ্লেস করে দেয় (পুরানো সব ডিলিট করে নতুন বসায়)।
*   **PATCH:** শুধু যেটুকু চেঞ্জ দরকার, সেটুকু আপডেট করে।

**🤣 ফানি উদাহরণ:**
তোমার শার্টের বোতাম ছিঁড়ে গেছে।
*   **PUT:** তুমি বাজার থেকে নতুন একটা শার্ট কিনে এনে আগেরটা ফেলে দিলে। (পুরো চেঞ্জ)।
*   **PATCH:** তুমি সুঁই-সুতা দিয়ে শুধু বোতামটা লাগিয়ে নিলে। (স্মার্ট চেঞ্জ)।

**💻 কোড:**
```javascript
// PATCH - শুধু নাম চেঞ্জ করবো
app.patch('/update-name/:id', (req, res) => {
    const { name } = req.body;
    res.send(`আইডি ${req.params.id} এর নাম চেঞ্জ করে ${name} করা হলো।`);
});
```

#### 🎓 Lesson 5.7: DELETE Request - ব্রেকআপ লেটার

**সহজ বাংলা:**
সার্ভার থেকে কোনো ডাটা মুছে ফেলার জন্য `DELETE` মেথড ব্যবহার করা হয়।

**🤣 ফানি উদাহরণ:**
সিম্পল! মোবাইলের গ্যালারি থেকে এক্স-গার্লফ্রেন্ড বা বয়ফ্রেন্ডের ছবি ডিলিট করা। একবার ডিলিট করলে আর ফিরে পাওয়া যাবে না (যদি না ব্যাকআপ থাকে)।

**💻 কোড:**
```javascript
app.delete('/user/:id', (req, res) => {
    const id = req.params.id;
    // ডাটাবেস থেকে ডিলিট করার কোড এখানে থাকে
    res.send(`ইউজার ${id}-কে লাত্থি দিয়ে বের করে দেওয়া হয়েছে!`);
});
```

#### 🎓 Lesson 5.8: JSON Response - প্লেটে সাজিয়ে খাবার দেওয়া

**সহজ বাংলা:**
আমরা এতদিন `res.send()` দিয়ে প্লেইন টেক্সট পাঠাচ্ছিলাম। কিন্তু প্রফেশনাল API সবসময় `JSON` ফরম্যাটে ডাটা রিটার্ন করে। এজন্য `res.json()` ব্যবহার করা বেটার।

**🤣 ফানি উদাহরণ:**
মেহমান আসলে কি হাতে করে ভাত-তরকারি দাও? না! প্লেটে (Object) সুন্দর করে সাজিয়ে দাও। `res.json()` হলো সেই প্লেট।

**💻 কোড:**
```javascript
app.get('/me', (req, res) => {
    const user = {
        name: "Jodu Madhu",
        profession: "Coder",
        salary: "Doya korun!"
    };
    res.status(200).json(user); // অটোমেটিক JSON হয়ে যাবে
});
```

#### 🎓 Lesson 5.9: Form Data Handling (urlencoded)

**সহজ বাংলা:**
সবসময় যে JSON আসবে তা না। মাঝে মাঝে সাধারণ HTML ফর্ম থেকেও ডাটা আসতে পারে। সেটার জন্য আরেকটা মিডলওয়্যার লাগে: `express.urlencoded`।

**🤣 ফানি উদাহরণ:**
কিছু মানুষ চামচ দিয়ে খায় (JSON), আবার কিছু মানুষ হাত দিয়ে খায় (Form Data)। রেস্টুরেন্ট মালিক হিসেবে তোমাকে দুই ব্যবস্থাই রাখতে হবে।

**💻 কোড:**
```javascript
// HTML ফর্মের ডাটা পড়ার জন্য
app.use(express.urlencoded({ extended: true })); 
```

#### 🎓 Lesson 5.10: Module 5 Project - মিনি ইউজার ম্যানেজমার

**সহজ বাংলা:**
আমরা একটা ভুয়া ডাটাবেস (Array) বানাবো এবং সেখানে ইউজার অ্যাড, ডিলিট এবং শো করবো।

**💻 কোড:**
```javascript
const express = require('express');
const app = express();

app.use(express.json());

// ভুয়া ডাটাবেস
let users = [
    { id: 1, name: "Sakib", role: "All-rounder" },
    { id: 2, name: "Tamim", role: "Batsman" }
];

// ১. সব ইউজার দেখা
app.get('/users', (req, res) => {
    res.json(users);
});

// ২. নতুন ইউজার অ্যাড করা
app.post('/users', (req, res) => {
    const newUser = req.body;
    users.push(newUser);
    res.status(201).json({ message: "প্লেয়ার অ্যাড করা হয়েছে!", users });
});

// ৩. ইউজার ডিলিট করা
app.delete('/users/:id', (req, res) => {
    const id = parseInt(req.params.id);
    users = users.filter(user => user.id !== id); // ফিল্টার করে বাদ দিলাম
    res.json({ message: "প্লেয়ার বাদ!", users });
});

app.listen(3000, () => console.log("Team Manager Server Running..."));
```
*Postman দিয়ে এই ৩টা রাউট টেস্ট করো। দেখবে কি সুন্দর কাজ করছে!*
