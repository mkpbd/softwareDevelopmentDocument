### 📦 Module 8: সিকিউরিটি ও অথেনটিকেশন (Authentication & JWT)

এই মডিউলে আমরা শিখবো পাসওয়ার্ড হ্যাশিং, লগইন সিস্টেম এবং টোকেন-বেসড অথেনটিকেশন।

#### 🎓 Lesson 8.1: Authentication vs Authorization - পরিচয় বনাম ক্ষমতা

**সহজ বাংলা:**
শব্দ দুইটা শুনতে একরকম মনে হলেও কাজ আলাদা।
*   **Authentication (কে তুমি?):** এটা নিশ্চিত করা যে তুমি আসলে সেই ব্যক্তি কিনা (লগইন করা)।
*   **Authorization (ক্ষমতা আছে?):** লগইন তো করেছো, কিন্তু তোমার কি এডমিন প্যানেলে ঢোকার অনুমতি আছে? (পারমিশন চেক)।

**🤣 ফানি উদাহরণ:**
*   **Authentication:** বিয়াবাড়ির গেটে কার্ড দেখানো। কার্ড থাকলে ভেতরে ঢুকতে দিবে।
*   **Authorization:** ভেতরে ঢুকে তুমি কি স্টেজে উঠে কনের পাশে বসতে পারবে? না! ওটা শুধু জামাইয়ের ক্ষমতা। তুমি শুধু খাওয়ার টেবিলে বসতে পারবে।

**💻 কোড:**
(লজিক বুঝলাম, কোড পরে আসছে)।

#### 🎓 Lesson 8.2: Password Hashing (Bcrypt) - ব্লেন্ডারে জুস বানানো

**সহজ বাংলা:**
ডাটাবেসে পাসওয়ার্ড কখনো প্লেইন টেক্সটে (যেমন: "123456") রাখা যাবে না। ডাটাবেস হ্যাক হলে সবার পাসওয়ার্ড লিক হয়ে যাবে। আমাদের পাসওয়ার্ডকে এমনভাবে খিচুড়ি বানাতে হবে যা দেখে বোঝা অসম্ভব। একে বলে **Hashing**।

**🤣 ফানি উদাহরণ:**
তুমি একটা আপেলকে ব্লেন্ডারে দিয়ে জুস বানিয়ে ফেললে (Hash)। এখন কেউ কি সেই জুস থেকে আবার আপেল ফেরত আনতে পারবে? না! এটা **One Way** প্রসেস। পাসওয়ার্ড হ্যাশ করলে আর ফেরত আনা যায় না, শুধু ম্যাচ করা যায়।

**💻 কাজ:**
টার্মিনালে ইনস্টল করো: `npm install bcryptjs`

**💻 কোড:**
```javascript
const bcrypt = require('bcryptjs');

const password = "mySecretPassword123";

// হ্যাশ তৈরি করা (জুস বানানো)
const hashPassword = async () => {
    // 10 হলো লবণের (Salt) পরিমাণ, যত বেশি তত স্ট্রং
    const hashedPassword = await bcrypt.hash(password, 10);
    console.log("জুস (Hash):", hashedPassword);
    // আউটপুট দেখবে হিজিবিজি: $2a$10$wI...
}
hashPassword();
```

#### 🎓 Lesson 8.3: Registration with Hash - সিকিউর সাইনআপ

**সহজ বাংলা:**
এখন আমরা ইউজার রেজিস্টার করার সময় পাসওয়ার্ডটা হ্যাশ করে তারপর ডাটাবেসে সেভ করবো।

**🤣 ফানি উদাহরণ:**
চোর যদি তোমার ডায়েরি (Database) চুরিও করে, সে দেখবে পাসওয়ার্ডের জায়গায় লেখা "XyZ#99.."। সে ভাববে এটা ভিনগ্রহের ভাষা, পাসওয়ার্ড আর পাবে না।

**💻 কোড:**
*(আগের User মডেল ব্যবহার করছি)*
```javascript
const bcrypt = require('bcryptjs');
const User = require('./models/User');

app.post('/register', async (req, res) => {
    const { name, email, password } = req.body;

    // ১. পাসওয়ার্ড হ্যাশ করা
    const hashedPassword = await bcrypt.hash(password, 10);

    // ২. হ্যাশ করা পাসওয়ার্ড দিয়ে ইউজার তৈরি
    const newUser = new User({ 
        name, 
        email, 
        password: hashedPassword // আসল পাসওয়ার্ড গুম করে দিলাম
    });

    await newUser.save();
    res.json({ message: "ইউজার রেজিস্টার্ড! পাসওয়ার্ড সিকিউরড!" });
});
```

#### 🎓 Lesson 8.4: Login Logic - চাবি মিলানো

**সহজ বাংলা:**
লগইন করার সময় ইউজার যে পাসওয়ার্ড দিবে (প্লেইন), আর ডাটাবেসে যেটা আছে (হ্যাশ)—এই দুইটা মিলাতে হবে। `bcrypt.compare()` এটা করে দেয়।

**🤣 ফানি উদাহরণ:**
তুমি ব্লেন্ড করা জুস (Hash) আর আস্ত আপেল (Input) নিয়ে ল্যাবে গেলে। ল্যাব টেস্ট করে বলবে—"হ্যাঁ, এই জুসটা এই আপেল দিয়েই বানানো হয়েছে।"

**💻 কোড:**
```javascript
app.post('/login', async (req, res) => {
    const { email, password } = req.body;

    // ১. ইউজার আছে কিনা চেক
    const user = await User.findOne({ email });
    if (!user) return res.send("ভুল ইমেইল মামা!");

    // ২. পাসওয়ার্ড মিলানো (Compare)
    const isMatch = await bcrypt.compare(password, user.password);
    
    if (isMatch) {
        res.send("লগইন সাকসেস! ওয়েলকাম!");
    } else {
        res.send("পাসওয়ার্ড ভুল! আবার চেষ্টা করেন।");
    }
});
```

#### 🎓 Lesson 8.5: JWT (JSON Web Token) - ডিজিটাল সিল

**সহজ বাংলা:**
লগইন তো হলো, কিন্তু সার্ভার বুঝবে কিভাবে যে তুমিই লগইন আছো? বারবার পাসওয়ার্ড চাওয়া তো বিরক্তিকর। তাই লগইন সফল হলে সার্ভার তোমাকে একটা **Token** দিবে। এটা হলো তোমার ডিজিটাল পরিচয়পত্র।

**🤣 ফানি উদাহরণ:**
কনসার্টে বা ক্লাবে ঢোকার পর হাতে একটা **সিল (Seal)** বা **ব্যান্ড** পরিয়ে দেয়। এরপর তুমি বাথরুমে যাও আর বাইরে যাও, গার্ড শুধু হাতের সিল দেখেই তোমাকে ঢুকতে দিবে। টিকিট আর দেখবে না। JWT হলো সেই হাতের সিল।

**💻 কনসেপ্ট:**
JWT তে ৩টা অংশ থাকে: Header, Payload (ডাটা), Signature।

#### 🎓 Lesson 8.6: Generating Token - সিল মারা

**সহজ বাংলা:**
লগইন সফল হলে আমরা একটা টোকেন জেনারেট করে ইউজারকে দিবো।

**💻 কাজ:**
টার্মিনালে: `npm install jsonwebtoken`

**💻 কোড:**
```javascript
const jwt = require('jsonwebtoken');
const SECRET_KEY = "amar_gopon_chabi"; // এটা কাউকে বলা যাবে না!

app.post('/login', async (req, res) => {
    // ... আগের কোড (ইউজার খোঁজা ও পাসওয়ার্ড ম্যাচ) ...
    
    if (isMatch) {
        // টোকেন বানানো
        const token = jwt.sign({ id: user._id, email: user.email }, SECRET_KEY, { expiresIn: '1h' });
        
        res.json({ message: "লগইন হইছে!", token: token });
    }
});
```
*এখন লগইন করলে দেখবে একটা লম্বা টোকেন দিচ্ছে।*

#### 🎓 Lesson 8.7: Auth Middleware - গার্ড মামা

**সহজ বাংলা:**
এখন আমরা একটা মিডলওয়্যার বানাবো। কেউ যদি কোনো সিকিউর পেজে (যেমন: `/dashboard`) যেতে চায়, তাকে টোকেন দেখাতে হবে। টোকেন না থাকলে—"গেট আউট!"।

**🤣 ফানি উদাহরণ:**
সেই ক্লাবের গার্ড। গেটে দাঁড়িয়ে সবার হাত চেক করছে। সিল (Token) আছে? যাও। নাই? ভাগো!

**💻 কোড:**
```javascript
const verifyToken = (req, res, next) => {
    const token = req.headers['authorization']; // হেডার থেকে টোকেন নিব
    
    if (!token) return res.status(403).send("টোকেন নাই! পারমিশন নাই!");

    try {
        // টোকেন ভেরিফাই করা (সিল আসল না নকল?)
        const decoded = jwt.verify(token, SECRET_KEY);
        req.user = decoded; // টোকেন থেকে ইউজার আইডি বের করে রাখলাম
        next(); // ভেতরে যান
    } catch (err) {
        res.status(401).send("ভুয়া টোকেন!");
    }
};
```

#### 🎓 Lesson 8.8: Protecting Routes - ভিআইপি জোন

**সহজ বাংলা:**
এখন আমরা আমাদের সিকিউর রাউটগুলোতে `verifyToken` মিডলওয়্যার বসিয়ে দিবো।

**🤣 ফানি উদাহরণ:**
এটা হলো ভিআইপি লাউঞ্জ। সাধারণ পাস দিয়ে ঢোকা যাবে না।

**💻 কোড:**
```javascript
// এই রাউটে ঢুকতে হলে টোকেন লাগবেই
app.get('/dashboard', verifyToken, (req, res) => {
    // req.user এর মধ্যে ইউজারের ইনফো আছে (মিডলওয়্যার থেকে আসছে)
    res.send(`স্বাগতম ড্যাশবোর্ডে! আপনার আইডি: ${req.user.id}`);
});
```

#### 🎓 Lesson 8.9: Environment Variables (dotenv) - গোপন সিন্দুক

**সহজ বাংলা:**
আমরা যে `SECRET_KEY` বা ডাটাবেস পাসওয়ার্ড কোডের মধ্যে লিখছি, এটা খুবই বিপজ্জনক। কোড গিটহাবে আপলোড দিলে সবাই হ্যাক করে ফেলবে। তাই এগুলো রাখতে হয় `.env` ফাইলে।

**🤣 ফানি উদাহরণ:**
টাকা মানিব্যাগে না রেখে প্যান্টের গোপন পকেটে বা সিন্দুকে রাখা। `.env` হলো সেই সিন্দুক।

**💻 কাজ:**
১. `npm install dotenv`
২. প্রজেক্টের মূলে `.env` নামে ফাইল বানাও।
৩. লেখো: `SECRET_KEY=verysecretkey123`
৪. কোডের শুরুতে: `require('dotenv').config();`
৫. ব্যবহার: `process.env.SECRET_KEY`
