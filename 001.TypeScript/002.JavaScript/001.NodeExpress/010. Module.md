### 📦 Module 10: রিয়েল প্রজেক্ট ও ডিপ্লয়মেন্ট (Real Project & Deployment)

এই মডিউলে আমরা শিখবো গিটহাবে কোড রাখা, প্রোডাকশন লেভেল সেটআপ এবং **Vercel** বা **Render** এ ফ্রিতে আমাদের সার্ভার হোস্ট করা।

#### 🎓 Lesson 10.1: `localhost` থেকে `Production` - প্রস্তুতি

**সহজ বাংলা:**
বাসায় লুঙ্গি পরে থাকা আর বিয়ের অনুষ্ঠানে স্যুট পরে যাওয়ার মধ্যে পার্থক্য আছে। কোড লাইভ করার আগে কিছু প্রস্তুতি নিতে হয়।
যেমন: পোর্ট নম্বর ফিক্স করা এবং সিক্রেট চাবিগুলো লুকানো।

**🤣 ফানি উদাহরণ:**
বাসায় রিহার্সাল করার সময় ভুল হলে সমস্যা নাই। কিন্তু স্টেজে (Production) ভুল হলে দর্শক পচা ডিম ছুড়বে। তাই সব চেক করে নিতে হয়।

**💻 কোড:**
`server.js` বা মেইন ফাইলে পোর্ট নম্বরটা এভাবে লিখতে হয়:
```javascript
const PORT = process.env.PORT || 5000; 
// এর মানে: সার্ভার যদি কোনো পোর্ট দেয় সেটা নাও, না হলে ৫০০০ নাও।
app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
```

#### 🎓 Lesson 10.2: Git & GitHub - কোড আকাশে তোলা

**সহজ বাংলা:**
তোমার হার্ডডিস্ক ক্র্যাশ করলে কোড শেষ! তাই কোড রাখতে হবে **GitHub**-এ। তাছাড়া ডিপ্লয় করার জন্য গিটহাব লাগবেই।

**🤣 ফানি উদাহরণ:**
ফোনের ছবি গুগল ফটোসে ব্যাকআপ রাখা। ফোন হারালেও ছবি হারাবে না। গিটহাব হলো কোডারদের গুগল ফটোস।

**💻 কাজ:**
১. `server.js` এর পাশে `.gitignore` নামে একটা ফাইল বানাও।
২. ফাইলের ভেতর লেখো:
   ```
   node_modules
   .env
   ```
   *(এই দুইটা ফোল্ডার আমরা গিটহাবে পাঠাবো না। কারণ `node_modules` অনেক ভারী, আর `.env` তে গোপন পাসওয়ার্ড আছে)*
   
৩. গিটহাবে একটা নতুন রিপোজিটরি খোলো।
৪. টার্মিনালে কমান্ড দাও:
   ```bash
   git init
   git add .
   git commit -m "Final code ready for launch"
   git branch -M main
   git remote add origin <তোমার_রিপো_লিঙ্ক>
   git push -u origin main
   ```

#### 🎓 Lesson 10.3: Vercel বা Render? - বাড়ি ভাড়া নেওয়া

**সহজ বাংলা:**
কোড তো গিটহাবে উঠল। এখন এটা রান করার জন্য একটা কম্পিউটার (Server) লাগবে যা ২৪ ঘণ্টা অন থাকবে।
আগে **Heroku** ফ্রি ছিল, এখন টাকা চায়। তাই আমরা গরিবের বন্ধু **Render.com** অথবা **Vercel** ব্যবহার করবো। আমরা এই কোর্সে **Render** ব্যবহার করবো কারণ এটা Node.js এর জন্য খুব সহজ।

**🤣 ফানি উদাহরণ:**
ঢাকায় বাসা ভাড়া নেওয়া। হিরোকু এখন গুলশানের ফ্ল্যাট (টাকা লাগে)। রেন্ডার হলো মেসে থাকার মতো—ফ্রি, কিন্তু কাজ চলে যায় দারুণ!

#### 🎓 Lesson 10.6: কনফিগারেশন - রান্নার নিয়ম বলে দেওয়া

**সহজ বাংলা:**
সার্ভারকে বলে দিতে হবে কোডটা কিভাবে স্টার্ট করতে হয়।

**🤣 ফানি উদাহরণ:**
নতুন রাঁধুনিকে বলে দেওয়া—"প্রথমে তেল দিবা, তারপর পেঁয়াজ দিবা"।

**💻 সেটিংস:**
*   **Name:** তোমার অ্যাপের একটা সুন্দর নাম দাও (যেমন: `my-api-boss`)।
*   **Region:** Singapore (কাছে হবে) বা ডিফল্ট যা থাকে।
*   **Build Command:** `npm install` (প্যাকেজগুলো ইন্সটল করার জন্য)।
*   **Start Command:** `node server.js` (বা `node index.js` তোমার মেইন ফাইলের নাম)।
*   **Plan:** Free (অবশ্যই!)।

#### 🎓 Lesson 10.7: Environment Variables - গোপন চাবি হস্তান্তর

**সহজ বাংলা:**
মনে আছে `.env` ফাইল গিটহাবে আপলোড করিনি? তাহলে Render পাসওয়ার্ড পাবে কোথায়? Render এর সেটিংসে গিয়ে এগুলো ম্যানুয়ালি বসাতে হবে।

**🤣 ফানি উদাহরণ:**
গার্ডকে কানে কানে গোপন পাসওয়ার্ড বলে দেওয়া। কাগজে লিখে দেওয়া যাবে না।

**💻 কাজ:**
১. Render এর পেজেই নিচে নামলে **"Environment Variables"** অপশন পাবে।
২. **Add Environment Variable** এ ক্লিক করো।
3. Key: `MONGO_URI`, Value: তোমার কানেকশন স্ট্রিং।
4. Key: `SECRET_KEY`, Value: তোমার টোকেন সিক্রেট।
5. সব দেওয়া হলে **Create Web Service** বাটনে চাপ দাও!

#### 🎓 Lesson 10.9: ডিবাগিং - হায় হায়! চলছে না কেন?

**🤣 ফানি উদাহরণ:**
