# ⏳ Module 5: Asynchronous JavaScript

### 📖 Lesson 1: Sync vs Async (লাইন বনাম টোকেন)

**🎯 Learning Goal:** Synchronous এবং Asynchronous কোডের পার্থক্য বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
- **Synchronous (Sync):** একটার পর একটা কাজ। আগেরটা শেষ না হলে পরেরটা শুরু হবে না। (যেমন: ব্যাংকের লাইনে দাঁড়িয়ে থাকা)।
- **Asynchronous (Async):** কাজ দিয়ে অন্য কাজে চলে যাওয়া। আগেরটা শেষ হলে আমাকে জানাবে। (যেমন: রেস্টুরেন্টে অর্ডার দিয়ে টেবিলে বসে গেম খেলা, খাবার রেডি হলে ওয়েটার ডাকবে)।

**🤣 Real-life Analogy:**
- **Sync:** তুমি দোকানে দাঁড়িয়ে আছো, দোকানি ১ ঘণ্টা ধরে জিনিস খুঁজছে, তুমি নড়তে পারছো না।
- **Async:** তুমি অর্ডার দিয়ে বাসায় চলে এসেছো, জিনিস রেডি হলে দোকানি তোমাকে ফোন দেবে।

**💻 Code Example:**
```javascript
// Synchronous (ব্লক করে রাখে)
console.log("1. Customer 1 Order dilo");
console.log("2. Customer 2 Order dilo");
console.log("3. Customer 3 Order dilo");

// Asynchronous (অপেক্ষা করে না)
console.log("1. Pani garam hosshe...");

setTimeout(() => {
    console.log("2. Pani Garam Shesh! (Async kaj)");
}, 2000); // ২ সেকেন্ড পর আসবে

console.log("3. Cha-er cup ready korchi..."); 
// ৩ নম্বর লাইন কিন্তু ২ এর আগেই প্রিন্ট হবে!
```

**💪 Mini Exercise:**
1. কোডটা রান করো এবং দেখো ৩ নম্বর লাইন কেন ২ নম্বরের আগে প্রিন্ট হলো।

**📝 One-line Summary:**
জাভাস্ক্রিপ্ট কারো জন্য অপেক্ষা করে বসে থাকে না, এটাই Async এর শক্তি।

### 📖 Lesson 2: Callback Hell (প্যাঁচানো জিলাপি)

**🎯 Learning Goal:** কলব্যাকের সমস্যা (Callback Hell) দেখা।

**🗣️ সহজ ব্যাখ্যা:**
আমরা মডিউল ২-এ কলব্যাক শিখেছি। কিন্তু একটার ভেতর আরেকটা, তার ভেতর আরেকটা কলব্যাক ঢুকালে কোড দেখতে ভয়ংকর হয়ে যায়। ডান দিকে পিরামিড তৈরি হয়। এটাকে বলে **Callback Hell**।

**🤣 Real-life Analogy:**
বন্ধুকে ফোন দিলে, সে বলল "দোস্ত আমি বাসে, ১০ মিনিট পর ফোন দে"। ১০ মিনিট পর ফোন দিলে বলল "এখন রিকশায়, ৫ মিনিট পর দে"। ৫ মিনিট পর বলল "লিফটে আছি..." — মেজাজ খারাপ হওয়ার অবস্থা!

**💻 Code Example:**
```javascript
// ভয়ংকর দেখতে কোড (Don't memorize, just look)
getMeat(function(meat) {
    cleanMeat(meat, function(cleanedMeat) {
        cookMeat(cleanedMeat, function(cookedMeat) {
            serveMeat(cookedMeat, function(dish) {
                console.log("Finally kacchi ready!");
            });
        });
    });
});
```

**💪 Mini Exercise:**
1. শুধু কোডটা দেখো আর ভাবো, যদি মাঝখানে কোথাও এরর হয়, তবে খুঁজে বের করা কতটা কঠিন হবে!

**📝 One-line Summary:**
নেস্টেড কলব্যাক কোডকে জটিল ও মেইনটেইন অযোগ্য করে তোলে। এর সমাধান নিচে আসছে!

### 📖 Lesson 3: Promises (ওয়াদা বা কসম)

**🎯 Learning Goal:** Promise এর ৩টি অবস্থা (Pending, Resolved, Rejected) বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
কলব্যাক হেল থেকে বাঁচতে এল **Promise**।
জাভাস্ক্রিপ্টকে তুমি একটা কাজ দিলে, সে একটা "ওয়াদা" (Promise) করে।
১. **Pending:** কাজ চলছে... (ওয়াদা ঝুলে আছে)।
২. **Resolved (Fulfilled):** কাজ সফল! (ওয়াদা রেখেছে)।
৩. **Rejected:** কাজ ব্যর্থ! (ওয়াদা ভেঙেছে)।

**🤣 Real-life Analogy:**
বাবা বলল, "রেজাল্ট ভালো করলে বাইক কিনে দেব।"
- রেজাল্ট না দেওয়া পর্যন্ত: **Pending**
- এ প্লাস পেলে: **Resolved** (বাইক পেল)
- ফেল করলে: **Rejected** (ঝাড়ু পেল)

**💻 Code Example:**
```javascript
const willGetBike = new Promise((resolve, reject) => {
    let result = "A+"; // ধরলাম এ প্লাস পেয়েছো

    if (result === "A+") {
        resolve("Bike peyechi! 🏍️"); // কথা রেখেছে
    } else {
        reject("Jharu peyechi... 🧹"); // কথা রাখেনি
    }
});

// ওয়াদার ফলাফল দেখা
willGetBike
    .then(msg => console.log(msg)) // সফল হলে .then
    .catch(err => console.log(err)); // ব্যর্থ হলে .catch
```

**💪 Mini Exercise:**
1. `result` এর মান পরিবর্তন করে "F" করো এবং দেখো `.catch` ব্লক কাজ করে কিনা।

**📝 One-line Summary:**
ভবিষ্যতের কোনো কাজের রেজাল্ট হ্যান্ডেল করতে Promise ব্যবহার করা হয়।

### 📖 Lesson 4: Fetch API (ডেটা আনা)

**🎯 Learning Goal:** সার্ভার থেকে ডেটা লোড করা।

**🗣️ সহজ ব্যাখ্যা:**
আগে ডেটা আনার জন্য অনেক কষ্ট করতে হতো (XHR)। এখন মডার্ন ব্রাউজারে `fetch()` নামের একটা জাদুকরী ফাংশন আছে। এটা একটা Promise রিটার্ন করে।

**🤣 Real-life Analogy:**
অনলাইনে পিৎজা অর্ডার করা। `fetch` মানে ডেলিভারি বয়কে পাঠানো। সে পিৎজা (Data) নিয়ে ফিরে আসবে।

**💻 Code Example:**
(আমরা একটা ডামি সার্ভার `jsonplaceholder` ব্যবহার করবো)
```javascript
fetch('https://jsonplaceholder.typicode.com/todos/1')
    .then(response => response.json()) // প্যাকেট খুললাম (JSON কনভার্ট)
    .then(json => console.log(json))   // ভেতরের মালমশলা দেখলাম
    .catch(error => console.log("Bhool hoyeche!", error));
```

**💪 Mini Exercise:**
1. ব্রাউজারের কনসোলে এই কোডটা পেস্ট করো। দেখো একটা অবজেক্ট প্রিন্ট হয়েছে কিনা।

**⚠️ Common Mistakes:**
- `response.json()` নিজেও একটা প্রমিজ, তাই ওটাকেও `.then` দিয়ে ধরতে হয়। সরাসরি ডেটা পাওয়া যায় না।

**📝 One-line Summary:**
যেকোনো URL থেকে ডেটা আনতে `fetch('url')` ব্যবহার করতে হয়।

**🏢 Real Project Importance:**
ফেসবুকের নিউজফিড, আবহাওয়ার অ্যাপ—সবাই `fetch` দিয়ে ডেটা আনে।

### 📖 Lesson 5: Async / Await (মডার্ন ম্যাজিক)

**🎯 Learning Goal:** প্রমিজ হ্যান্ডেল করার সবচেয়ে সহজ এবং মডার্ন উপায় শেখা।

**🗣️ সহজ ব্যাখ্যা:**
`.then().then()` চেইন করাও মাঝে মাঝে বিরক্তিকর।
তাই এল `async` এবং `await`।
- ফাংশনের আগে `async` লিখলে সেটা বিশেষ ক্ষমতা পায়।
- ভেতরে `await` লিখলে জাভাস্ক্রিপ্ট সেখানে **অপেক্ষা** করে (Sync এর মতো আচরণ করে)।

**🤣 Real-life Analogy:**
ওয়েটারকে খাবার অর্ডার দিয়ে বললাম, "ভাই, খাবার না আসা পর্যন্ত আমি হাত ধোব না (Wait)।" খাবার আসলে তারপর খাবো।

**💻 Code Example:**
```javascript
async function getData() {
    console.log("1. Data anchi...");
    
    // এখানে ২ সেকেন্ড অপেক্ষা করবে, তারপর পরের লাইনে যাবে
    const res = await fetch('https://jsonplaceholder.typicode.com/todos/1');
    const data = await res.json();
    
    console.log("2. Data eshe geche:", data);
}

getData();
console.log("3. Ami kintu agei print hobo!"); 
// কারণ getData ফাংশনটা ব্যাকগ্রাউন্ডে ওয়েট করছে।
```

**💪 Mini Exercise:**
1. `getData` ফাংশনের ভেতরে `console.log(data)` এর পর আরেকটা `console.log("Finished")` দাও। দেখো সেটা কখন প্রিন্ট হয়।

**📝 One-line Summary:**
কোডকে ক্লিন এবং পড়ার উপযোগী করতে `async/await` এখন ইন্ডাস্ট্রি স্টান্ডার্ড।

### 📖 Lesson 6: Error Handling (দুর্ঘটনা বীমা)

**🎯 Learning Goal:** `try...catch` দিয়ে এরর হ্যান্ডেল করা।

**🗣️ সহজ ব্যাখ্যা:**
সার্ভার ডাউন থাকতে পারে, ইন্টারনেট চলে যেতে পারে। তখন `await` কোড ক্র্যাশ করবে।
এজন্য আমরা কোডটাকে একটা `try` ব্লকে রাখি। যদি কোনো সমস্যা হয়, কোড ক্র্যাশ না করে `catch` ব্লকে চলে যাবে।

**🤣 Real-life Analogy:**
বাইক চালানোর সময় হেলমেট পরা।
- **Try:** বাইক চালানো।
- **Accident:** এরর খাওয়া।
- **Catch (Helmet):** মাথা ফাটতে না দিয়ে বাঁচিয়ে দেওয়া।

**💻 Code Example:**
```javascript
async function loadUser() {
    try {
        const res = await fetch('https://vul-url.com/users'); // ভুল URL
        const data = await res.json();
        console.log(data);
    } catch (error) {
        console.log("Mama, jamela hoise:", error.message);
        // এখানে ইউজারকে সুন্দর করে বলতে পারো "Internet Error"
    }
}

loadUser();
```

**💪 Mini Exercise:**
1. উপরের কোডে URL ঠিক করে দাও (`https://jsonplaceholder.typicode.com/users`) এবং দেখো `catch` ব্লক স্কিপ করে কিনা।

**📝 One-line Summary:**
`async` ফাংশনে সবসময় `try...catch` ব্যবহার করা বুদ্ধিমানের কাজ।

### 📖 Lesson 7: Promise.all (একের লাঠি, দশের বোঝা)

**🎯 Learning Goal:** একাধিক কাজ একসাথে (Parallel) করা।

**🗣️ সহজ ব্যাখ্যা:**
ধরো তোমার ৩টা API কল করতে হবে। একটার পর একটা করলে সময় বেশি লাগবে। `Promise.all` দিয়ে তুমি ৩টা রিকোয়েস্ট একসাথে পাঠাতে পারো। যখন ৩টাই শেষ হবে, তখন রেজাল্ট পাবে।

**🤣 Real-life Analogy:**
খিচুড়ি রান্না।
- **Serial:** আগে চাল ধোব, তারপর ডাল ধোব, তারপর সবজি কাটব (দেরি হবে)।
- **Parallel:** আমি চাল ধুই, তুমি ডাল ধোও, মা সবজি কাটুক (দ্রুত হবে)।

**💻 Code Example:**
```javascript
const promise1 = fetch('https://jsonplaceholder.typicode.com/todos/1');
const promise2 = fetch('https://jsonplaceholder.typicode.com/todos/2');

async function loadTogether() {
    const startTime = Date.now();
    
    // দুটো একসাথে শুরু হলো
    const results = await Promise.all([promise1, promise2]);
    
    console.log("Sob kaj shesh!", results);
    console.log(`Somoy laglo: ${Date.now() - startTime} ms`);
}

loadTogether();
```

**💪 Mini Exercise:**
1. `Promise.all` এর অ্যারেতে ৩টা ফেচ রিকোয়েস্ট দাও এবং দেখো কত দ্রুত রেসপন্স আসে।

**📝 One-line Summary:**
সময় বাঁচাতে একাধিক স্বাধীন রিকোয়েস্ট `Promise.all` দিয়ে একসাথে চালাও।

### 📖 Lesson 8: Event Loop (ভিতরের খবর)

**🎯 Learning Goal:** জাভাস্ক্রিপ্ট কীভাবে ব্যাকগ্রাউন্ডে কাজ করে তা সিম্পলভাবে বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
জাভাস্ক্রিপ্ট এক হাতে কাজ করে (Single Threaded)। কিন্তু ব্রাউজারের সাহায্যে সে মাল্টি-টাস্কিংয়ের ভান করে।
১. **Call Stack:** মেইন কাজের টেবিল।
২. **Web API:** ওয়েটিং রুম (টাইমার, ফেচ এখানে অপেক্ষা করে)।
৩. **Queue:** লাইন। ওয়েটিং শেষ হলে এখানে এসে দাঁড়িয়ে থাকে।
স্ট্যাক খালি হলে কিউ থেকে কাজ নিয়ে টেবিলে বসায়। এটাই **Event Loop**।

**🤣 Real-life Analogy:**
ব্যাংকের ক্যাশ কাউন্টার (Stack) একটাই।
ম্যানেজার (Web API) কিছু কাস্টমারকে ফর্ম ফিলাপ করতে সাইডে পাঠালো।
ফর্ম ফিলাপ শেষে তারা লাইনে (Queue) দাঁড়াল।
ক্যাশ অফিসার ফ্রি হলে লাইন থেকে একজনকে ডাকবে।

**💻 Code Example:**
```javascript
console.log("1. Start");

setTimeout(() => {
    console.log("2. Timer (Waiting room theke aslam)");
}, 0); // ০ সেকেন্ড দিলেও এটা শেষে আসবে!

console.log("3. End");

// Output: 1 -> 3 -> 2
// কারণ ২ নম্বরকে লাইন ঘুরে আসতে হয়েছে।
```

**💪 Mini Exercise:**
1. এই কনসেপ্টটা ইন্টারভিউতে খুব জিজ্ঞেস করে। কোডটা চালিয়ে লজিকটা মাথায় গেঁথে নাও।

**📝 One-line Summary:**
Event Loop হলো সেই ট্রাফিক পুলিশ যে ঠিক করে কখন কোন কোড রান করবে।

### 📖 Lesson 9: Practical Async (আসল প্রোজেক্টের স্বাদ)

**🎯 Learning Goal:** ইউজারের ডাটা এনে কার্ড বানিয়ে দেখানো।

**🗣️ সহজ ব্যাখ্যা:**
এতক্ষণ যা শিখলাম তা দিয়ে এখন ছোট একটা ডাইনামিক কাজ করবো। বাটন চাপলে ইউজারের নাম আসবে।

**💻 Code Example:**
HTML: `<button id="loadBtn">Load User</button> <div id="userBox"></div>`

```javascript
document.getElementById("loadBtn").addEventListener("click", async () => {
    const userBox = document.getElementById("userBox");
    userBox.innerText = "Loading..."; // ইউজারকে বুঝালাম কাজ চলছে
    
    try {
        const res = await fetch('https://jsonplaceholder.typicode.com/users/1');
        const user = await res.json();
        
        // DOM ম্যানিপুলেশন (Module 4 এর পড়া)
        userBox.innerHTML = `
            <h3>Name: ${user.name}</h3>
            <p>Email: ${user.email}</p>
        `;
    } catch (error) {
        userBox.innerText = "Error loading data!";
    }
});
```

**💪 Mini Exercise:**
1. এই কোডটা তোমার ফাইলে বসাও। ইন্টারনেট কানেকশন অন রেখে বাটন চেপে দেখো ম্যাজিক!

### 📖 Lesson 10: Module 5 Recap (Sync to Async Journey)

**🎯 Learning Goal:** পুরো মডিউল রিভাইস দেওয়া।

**🗣️ সারমর্ম:**
আমরা শিখলাম:
১. জাভাস্ক্রিপ্ট বাই ডিফল্ট **Synchronous** (একটার পর একটা)।
২. সময়ের কাজ (টাইমার, এপিআই) **Asynchronous**।
৩. কলব্যাক হেল থেকে বাঁচতে **Promise** এবং শেষে **Async/Await**।
৪. এরর হলে বাঁচার জন্য **Try/Catch**।

**🚀 Final Challenge:**
এমন একটা ফাংশন বানাও যেটা:
১. প্রথমে "Searching..." প্রিন্ট করবে।
২. ২ সেকেন্ড অপেক্ষা করবে (setTimeout & Promise দিয়ে বানাবে)।
৩. তারপর "Found!" প্রিন্ট করবে।

**💻 Hint Code:**
```javascript
const wait = (ms) => new Promise(resolve => setTimeout(resolve, ms));

async function search() {
    console.log("Searching...");
    await wait(2000); // নিজের বানানো ওয়েট ফাংশন
    console.log("Found!");
}
search();
```
