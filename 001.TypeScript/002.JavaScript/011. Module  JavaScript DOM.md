### 📖 Lesson 1: DOM আসলে কী? (The Blueprint)

**🎯 Learning Goal:** DOM (Document Object Model) এর কনসেপ্ট ক্লিয়ার করা।

**🗣️ সহজ ব্যাখ্যা:**
তুমি যখন একটা ওয়েবসাইট দেখো, ব্রাউজার তোমার HTML কোডটাকে একটা **গাছ (Tree)** এর মতো স্ট্রাকচার বানিয়ে ফেলে। এই গাছটাকেই বলে **DOM**।
জাভাস্ক্রিপ্ট এই DOM এর মাধ্যমেই HTML এর সাথে কথা বলে। DOM ছাড়া জাভাস্ক্রিপ্ট হলো অন্ধ, সে HTML এর কিছুই দেখতে পায় না।

**🤣 Real-life Analogy:**
- **HTML:** বাড়ির নকশা বা প্ল্যান।
- **Browser:** রাজমিস্ত্রি যে নকশা দেখে বাড়ি বানায়।
- **DOM:** বাড়ির **ইলেকট্রিক সুইচবোর্ড**। তুমি সুইচ টিপলে (JS Code) লাইট জ্বলে (HTML change হয়)। সুইচবোর্ড না থাকলে তুমি তার ছিঁড়ে লাইট জ্বালাতে পারতে না!

**💻 Code Example:**
(ব্রাউজারের কনসোলে এই কোড লিখলে পুরো ওয়েবসাইটটা DOM আকারে দেখা যায়)
```html
<!DOCTYPE html>
<html>
<body>
    <h1>Hello DOM!</h1>
    <script>
        console.log("Entire DOM Tree:", document);
        console.log("Only Body:", document.body);
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. যেকোনো ওয়েবসাইটে যাও (যেমন Facebook/Google)।
2. `Right Click` -> `Inspect` -> `Console` এ যাও।
3. `document.title = "Hacked by [Tomar Nam]"` লিখে Enter দাও। দেখো ট্যাবের নাম পাল্টে গেছে!

**⚠️ Common Mistakes:**
- ভাবা যে DOM আর HTML একই জিনিস। না! HTML হলো ফাইল, আর DOM হলো ব্রাউজারের মেমোরিতে তৈরি হওয়া স্ট্রাকচার।

**📝 One-line Summary:**
DOM হলো জাভাস্ক্রিপ্ট আর HTML এর মাঝখানের সেতু।

**🏢 Why Important:**
ফেসবুকের নোটিফিকেশন আসলে পেজ রিফ্রেশ ছাড়াই লাল বাতি জ্বলে ওঠে—এটা DOM দিয়েই করা হয়।

### 📖 Lesson 2: Selecting Elements (ধরো ব্যাটারে!)

**🎯 Learning Goal:** `getElementById` এবং `querySelector` দিয়ে ট্যাগ খুঁজে বের করা।

**🗣️ সহজ ব্যাখ্যা:**
HTML এর হাজার হাজার লাইনের মধ্যে নির্দিষ্ট একটা ট্যাগকে ধরতে হলে তাকে সিলেক্ট করতে হয়।
- **`getElementById`**: সরাসরি নাম (ID) ধরে ডাকা।
- **`querySelector`**: একটু স্টাইল নিয়ে CSS এর মতো করে ডাকা।

**🤣 Real-life Analogy:**
- **getElementById:** ক্লাসে "রোল নাম্বার ১০" বলে ডাকা (একদম নির্দিষ্ট)।
- **querySelector:** "ঐ লাল শার্ট পরা ছেলেটা" বলে ডাকা (CSS স্টাইল)।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <h1 id="main-title">Old Title</h1>
    <p class="text">This is a paragraph.</p>

    <script>
        // ID দিয়ে ধরা (Fastest)
        const title = document.getElementById('main-title');
        console.log(title);

        // CSS Selector দিয়ে ধরা (Flexible)
        const para = document.querySelector('.text');
        console.log(para);
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. একটা `h2` ট্যাগ বানাও যার id হবে `hero`।
2. JS দিয়ে সেটাকে সিলেক্ট করো এবং কনসোলে প্রিন্ট করো।

**⚠️ Common Mistakes:**
- `getElementById` এর ভেতরে `#` দেওয়া যাবে না (শুধু নাম)।
- `querySelector` এ ক্লাসের আগে `.` এবং আইডির আগে `#` দিতে হবে।

**📝 One-line Summary:**
আইডি দিয়ে ধরতে `getElementById` আর যেকোনো কিছু ধরতে `querySelector` সেরা।

### 📖 Lesson 3: Changing Content & Style (মেকআপ করা)

**🎯 Learning Goal:** লেখার রং, সাইজ এবং টেক্সট পরিবর্তন করা।

**🗣️ সহজ ব্যাখ্যা:**
এলিমেন্ট তো ধরলাম, এবার ওটাকে সাজাবো।
- **`innerText`**: ভেতরের লেখা বদলানো।
- **`style`**: রংচং মাখানো (CSS)।

**🤣 Real-life Analogy:**
পার্লারে গিয়ে মেকআপ করা।
- **innerText:** কপালে টিপ পরানো (কন্টেন্ট চেঞ্জ)।
- **style:** মুখে ফেস পাউডার মাখা (কালার চেঞ্জ)।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <h1 id="magic-text">Hello World</h1>
    <button onclick="changeLook()">Magic!</button>

    <script>
        function changeLook() {
            const heading = document.getElementById('magic-text');
            
            // লেখা বদলে দিলাম
            heading.innerText = "JavaScript is Fun! 🚀";
            
            // স্টাইল বদলে দিলাম
            heading.style.color = "red";
            heading.style.fontSize = "50px";
            heading.style.backgroundColor = "yellow";
        }
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. একটা বাটন বানাও। ক্লিক করলে ব্যাকগ্রাউন্ড কালার কালো এবং টেক্সট কালার সাদা হয়ে যাবে (Dark Mode)।

**⚠️ Common Mistakes:**
- CSS এ `background-color` লিখি, কিন্তু JS এ লিখতে হয় `backgroundColor` (camelCase)। হাইফেন (-) চলে না।

**📝 One-line Summary:**
`element.style.property` দিয়ে যেকোনো CSS চেঞ্জ করা যায়।

**🏢 Why Important:**
ভুল পাসওয়ার্ড দিলে ইনপুট বক্স লাল হয়ে যাওয়া—এই স্টাইল চেঞ্জ দিয়েই হয়।

### 📖 Lesson 4: Attributes & Classes (ইউনিফর্ম পরা)

**🎯 Learning Goal:** `getAttribute`, `setAttribute` এবং `classList` এর ব্যবহার।

**🗣️ সহজ ব্যাখ্যা:**
মাঝে মাঝে আমাদের পুরো স্টাইল ধরে চেঞ্জ করতে হয়, অথবা ছবির লিংক বদলাতে হয়।
- **`setAttribute`**: ট্যাগের পেটের ভেতরের জিনিস (src, href, id) বদলানো।
- **`classList`**: নতুন ক্লাস (CSS Class) যোগ করা বা সরানো।

**🤣 Real-life Analogy:**
- **setAttribute:** নিজের নাম পরিবর্তন করে "শাকিব খান" রাখা।
- **classList:** স্কুলের ইউনিফর্ম পরা (`.add`) বা খুলে ফেলা (`.remove`)। ইউনিফর্ম পরলে অটোমেটিক স্মার্ট লাগে (CSS অ্যাপ্লাই হয়)।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<head>
    <style>
        .highlight {
            border: 5px solid gold;
            padding: 20px;
            color: purple;
        }
    </style>
</head>
<body>
    <img id="myImg" src="old-pic.jpg" alt="Photo" width="100">
    <div id="box">I am a Box</div>
    
    <button onclick="updateBox()">Upgrade Box</button>

    <script>
        function updateBox() {
            const box = document.getElementById('box');
            const img = document.getElementById('myImg');

            // ছবির সোর্স বদলে দিলাম
            img.setAttribute('src', 'https://via.placeholder.com/150');

            // ক্লাস যোগ করলাম (একসাথে অনেক স্টাইল পাবে)
            box.classList.add('highlight');
            
            // টগল (থাকলে রিমুভ, না থাকলে অ্যাড)
            // box.classList.toggle('highlight');
        }
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. একটা প্যারাগ্রাফ নাও। বাটনে ক্লিক করলে `hidden` নামের একটা ক্লাস অ্যাড হবে যা `display: none` করে দেবে (লেখা গায়েব)।

**⚠️ Common Mistakes:**
- `className` ব্যবহার করলে আগের সব ক্লাস মুছে যায়। তাই `classList.add()` ব্যবহার করা সেফ।

**📝 One-line Summary:**
স্টাইল ধরে ধরে চেঞ্জ না করে `classList` দিয়ে ক্লাস অ্যাড/রিমুভ করা স্মার্ট কাজ।

# 🟡 Module 2: DOM Traversing (ফ্যামিলি ট্রি)
**লক্ষ্য:** এক এলিমেন্ট থেকে তার বাবা, মা, ভাই-বোন বা বাচ্চা খুঁজে বের করা এবং নতুন এলিমেন্ট তৈরি করা।

---

### 📖 Lesson 1: Parent, Children & Siblings (আত্মীয়-স্বজন)

**🎯 Learning Goal:** DOM ট্রি ধরে নড়াচড়া করা (`parentNode`, `children`)।

**🗣️ সহজ ব্যাখ্যা:**
তোমার যদি একটা এলিমেন্ট জানা থাকে, তুমি তার আত্মীয়দের খুঁজে বের করতে পারবে।
- `parentNode`: বাবা।
- `children`: ছেলে-মেয়ে।
- `nextElementSibling`: ছোট ভাই।

**🤣 Real-life Analogy:**
বিয়ের অনুষ্ঠানে গিয়ে কাউকে জিজ্ঞেস করা—"আপনার বাবা কে?" (Parent), "আপনার ছেলে কই?" (Children)।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <div id="dad">
        <p>Boro Bhai</p>
        <p id="me">Ami</p>
        <p>Choto Bhai</p>
    </div>

    <script>
        const me = document.getElementById('me');

        // বাবাকে খুঁজছি
        const father = me.parentNode;
        father.style.border = "2px solid blue"; // বাবাকে বর্ডার দিলাম

        // ছোট ভাইকে খুঁজছি
        const littleBro = me.nextElementSibling;
        littleBro.innerText = "Choto Bhai (Selected)";
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. একটা লিস্ট (`ul > li*3`) বানাও। ২য় `li` কে সিলেক্ট করো, তারপর তার মাধ্যমে আগের `li` এর কালার চেঞ্জ করো (`previousElementSibling`)।

**📝 One-line Summary:**
সম্পর্ক ধরে এলিমেন্ট খুঁজতে Traversing মেথডগুলো লাগে।

### 📖 Lesson 2: Creating & Appending Elements (নতুন সদস্য)

**🎯 Learning Goal:** জাভাস্ক্রিপ্ট দিয়ে নতুন HTML ট্যাগ বানিয়ে পেজে বসানো।

**🗣️ সহজ ব্যাখ্যা:**
HTML ফাইলে না লিখেও আমরা JS দিয়ে ট্যাগ বানাতে পারি।
1. **`createElement`**: ট্যাগ বানানো (যেমন `div`, `p`)।
2. **`innerText`**: লেখা দেওয়া।
3. **`appendChild`**: সঠিক জায়গায় বসানো (বাবার কোলে বাচ্চা দেওয়া)।

**🤣 Real-life Analogy:**
১. রুটি বানানো (Create)।
২. ভাজি দিয়ে সাজানো (Content)।
৩. মেহমানের প্লেটে দেওয়া (Append)। প্লেটে না দিলে কেউ খেতে পারবে না!

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <ul id="fruit-list">
        <li>Mango</li>
    </ul>
    <button onclick="addFruit()">Add Apple</button>

    <script>
        function addFruit() {
            // ১. নতুন li বানালাম
            const newLi = document.createElement('li');
            
            // ২. লেখা দিলাম
            newLi.innerText = "Apple 🍎";
            newLi.style.color = "green";

            // ৩. লিস্টের মধ্যে ঢুকালাম
            const ul = document.getElementById('fruit-list');
            ul.appendChild(newLi);
        }
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. ৫টি ফলের নাম একবারে লুপ চালিয়ে লিস্টে অ্যাড করো।

**⚠️ Common Mistakes:**
- `createElement` করলেন কিন্তু `appendChild` করলেন না—তাহলে এলিমেন্ট মেমোরিতে থাকবে, স্ক্রিনে দেখা যাবে না।

**📝 One-line Summary:**
`createElement` দিয়ে জন্ম দাও, `appendChild` দিয়ে ঘরে তোলো।

**🏢 Why Important:**
ফেসবুকে কমেন্ট করলে পেজ রিলোড হয় না, ধুপ করে নিচে কমেন্টটা বসে যায়—এটা `appendChild` এর কাজ।

### 📖 Lesson 3: Removing Elements (ঘাড় ধাক্কা)

**🎯 Learning Goal:** এলিমেন্ট মুছে ফেলা (`remove`, `removeChild`)।

**🗣️ সহজ ব্যাখ্যা:**
অপ্রয়োজনীয় এলিমেন্ট ডিলিট করা।
- `element.remove()`: নিজে নিজেই গায়েব হওয়া।
- `parent.removeChild(child)`: বাবাকে বলে সন্তানকে ত্যাজ্য করা।

**🤣 Real-life Analogy:**
বাসায় পচা আপেল থাকলে ঝুড়ি থেকে ফেলে দেওয়া।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <div id="container">
        <p>Valo Data</p>
        <p id="bad-data">Poca Data 🤮</p>
    </div>
    <button onclick="cleanUp()">Clean</button>

    <script>
        function cleanUp() {
            const bad = document.getElementById('bad-data');
            
            // সরাসরি রিমুভ (Modern Way)
            bad.remove();
            
            // অথবা বাবার মাধ্যমে (Old Way)
            // bad.parentNode.removeChild(bad);
        }
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. একটা লিস্ট বানাও। যেকোনো আইটেমে ক্লিক করলে সেটা রিমুভ হয়ে যাবে।

**📝 One-line Summary:**
জঞ্জাল সাফ করতে `.remove()` মেথড ব্যবহার করো।

# 🔴 Module 3: Events (অ্যাকশন হিরো)
**লক্ষ্য:** ইউজার ক্লিক করলে, মাউস নাড়ালে বা কিবোর্ড চাপলে রেসপন্স করা।

### 📖 Lesson 1: Click Event & Listeners (কলিং বেল)

**🎯 Learning Goal:** `addEventListener` এর ব্যবহার।

**🗣️ সহজ ব্যাখ্যা:**
HTML এর ভেতর `onclick="..."` লেখা এখন ব্যাকডেটেড। আমরা স্মার্ট ওয়েতে `addEventListener` ব্যবহার করবো। এটা একটা দারোয়ানের মতো, সবসময় কান পেতে থাকে কখন ঘটনা ঘটবে।

**🤣 Real-life Analogy:**
দারোয়ানকে বলে রাখা: "ম্যানেজার সাহেব (Event) আসলে গেট খুলে দিবা (Function)।"

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <button id="myBtn">Click Me!</button>

    <script>
        const btn = document.getElementById('myBtn');

        // কান পেতে থাকা (Listener)
        btn.addEventListener('click', function() {
            alert("Ouch! Tumi amake click korle keno? 😢");
            btn.style.backgroundColor = "salmon";
        });
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. একটা ইনপুট ফিল্ড আর একটা বাটন নাও। বাটনে ক্লিক করলে ইনপুটের লেখাটা `alert` এ দেখাবে।

**⚠️ Common Mistakes:**
- ফাংশনের নামের পরে `()` দেওয়া যাবে না। যেমন `btn.addEventListener('click', myFunc())` ❌ ভুল! শুধু `myFunc` ✅।

**📝 One-line Summary:**
ইউজারের কাজের রেসপন্স দিতে `addEventListener` এর বিকল্প নেই।

### 📖 Lesson 2: Event Bubbling (চুগলখোরি)

**🎯 Learning Goal:** ইভেন্ট কীভাবে নিচ থেকে উপরে ছড়ায় তা বোঝা এবং `stopPropagation`।

**🗣️ সহজ ব্যাখ্যা:**
ধরো একটা বাক্সের ভেতর বাটন আছে। তুমি বাটনে ক্লিক করলে আসলে তুমি বাক্সেও ক্লিক করেছো। ইভেন্টটা বাবল (বুদবুদ) এর মতো নিচ থেকে উপরে উঠতে থাকে। এটাকে **Bubbling** বলে।

**🤣 Real-life Analogy:**
ছোট ভাই (Button) মার খেল। সে গিয়ে মাকে (Parent Div) বলল। মা গিয়ে বাবাকে (Body) বলল। পুরো গুষ্টি জেনে গেল!
এটা থামাতে হলে ছোট ভাইয়ের মুখ বন্ধ করতে হবে (`stopPropagation`)।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body id="body">
    <div id="container" style="padding: 20px; background: gray;">
        <button id="btn">Click Me</button>
    </div>

    <script>
        document.getElementById('body').addEventListener('click', () => {
            console.log("Body clicked!");
        });

        document.getElementById('container').addEventListener('click', () => {
            console.log("Container clicked!");
        });

        document.getElementById('btn').addEventListener('click', (event) => {
            console.log("Button clicked!");
            // নিচের লাইনটা কমেন্ট আউট করে দেখো কী হয়
            event.stopPropagation(); // চুগলখোরি বন্ধ!
        });
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. কনসোল ওপেন করে কোডটা রান করো। `stopPropagation` ছাড়া এবং সহ পার্থক্য দেখো।

**📝 One-line Summary:**
ইভেন্ট যাতে ছড়িয়ে না পড়ে, তাই `event.stopPropagation()` ব্যবহার করতে হয়।

### 📖 Lesson 1: Reading Input & Preventing Default (সাবধান!)

**🎯 Learning Goal:** `value` পড়া এবং পেজ রিফ্রেশ আটকানো।

**🗣️ সহজ ব্যাখ্যা:**
ফর্ম সাবমিট করলে ব্রাউজার বাই ডিফল্ট পেজ রিফ্রেশ দেয়। এটা খুব বিরক্তিকর! আমাদের প্রথম কাজ হলো `event.preventDefault()` দিয়ে এই রিফ্রেশ আটকানো। তারপর ইনপুট বক্সের `value` পড়া।

**🤣 Real-life Analogy:**
পরীক্ষার হলে খাতা জমা দেওয়ার সাথে সাথে যদি স্যার খাতা ছিঁড়ে ফেলে (Refresh), কেমন লাগবে? আমরা সেটা হতে দেব না!

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <form id="loginForm">
        <input type="text" id="username" placeholder="Username">
        <button type="submit">Login</button>
    </form>
    <p id="output"></p>

    <script>
        const form = document.getElementById('loginForm');
        const output = document.getElementById('output');

        form.addEventListener('submit', function(event) {
            // ১. রিফ্রেশ আটকানো (মাস্ট!)
            event.preventDefault(); 

            // ২. ভ্যালু পড়া
            const name = document.getElementById('username').value;
            
            // ৩. আউটপুট দেখানো
            output.innerText = "Welcome, " + name;
            console.log("Form Submitted by:", name);
        });
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. কোডটা রান করো। `event.preventDefault()` লাইনটা কমেন্ট করে সাবমিট করো। দেখো পেজ রিফ্রেশ হয়ে কনসোলের লেখা গায়েব হয়ে যায়!

**📝 One-line Summary:**
ফর্ম সাবমিশনে `event.preventDefault()` ফরজ কাজ।

# 📋 Module 5: Working With Lists (ডাইনামিক বাজার ফর্দ)
**লক্ষ্য:** জাভাস্ক্রিপ্ট দিয়ে লিস্ট আইটেম যোগ করা এবং সার্চ করা।

### 📖 Lesson 1: Dynamic List (বাজারের ফর্দ)

**🎯 Learning Goal:** ইনপুট নিয়ে `ul` এর মধ্যে `li` যোগ করা।

**🗣️ সহজ ব্যাখ্যা:**
আমরা আগেই `createElement` শিখেছি। এখন সেটা ইনপুট ফিল্ডের সাথে জুড়ে দেব। যা লিখবো, তাই লিস্টে অ্যাড হবে।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <input type="text" id="itemInput" placeholder="Item name">
    <button onclick="addItem()">Add Item</button>
    <ul id="shoppingList"></ul>

    <script>
        function addItem() {
            const val = document.getElementById('itemInput').value;
            const list = document.getElementById('shoppingList');

            if(val !== "") {
                const li = document.createElement('li');
                li.innerText = val;
                
                // বোনাস: ক্লিক করলে আইটেম ডিলিট
                li.addEventListener('click', function() {
                    li.remove(); 
                });

                list.appendChild(li);
                document.getElementById('itemInput').value = ""; // বক্স খালি করা
            }
        }
    </script>
</body>
</html>
```

**📝 One-line Summary:**
ইউজারের ইনপুট নাও -> এলিমেন্ট বানাও -> অ্যাপেন্ড করো -> ইনপুট খালি করো।

---

### 📖 Lesson 2: Filter/Search (খুঁজে বের করো)

**🎯 Learning Goal:** বড় লিস্ট থেকে নির্দিষ্ট আইটেম খুঁজে বের করা।

**🗣️ সহজ ব্যাখ্যা:**
লুপ চালিয়ে প্রতিটি আইটেমের লেখার সাথে সার্চের লেখার তুলনা করবো (`includes` বা `indexOf` দিয়ে)। মিললে দেখাবো, না মিললে `display: none` করে লুকাবো।

**🤣 Real-life Analogy:**
হাজিরা খাতা থেকে "করিম" নামটা খুঁজে বের করা।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <input type="text" id="searchBox" onkeyup="searchItem()" placeholder="Search...">
    <ul id="names">
        <li>Rahim</li>
        <li>Karim</li>
        <li>Salam</li>
        <li>Jabbar</li>
    </ul>

    <script>
        function searchItem() {
            const text = document.getElementById('searchBox').value.toLowerCase();
            const items = document.querySelectorAll('#names li');

            for (let item of items) {
                const name = item.innerText.toLowerCase();
                if (name.includes(text)) {
                    item.style.display = "block"; // মিললে দেখাও
                } else {
                    item.style.display = "none";  // না মিললে লুকাও
                }
            }
        }
    </script>
</body>
</html>
```

**📝 One-line Summary:**
`keyup` ইভেন্ট আর লুপ চালিয়ে রিয়েল-টাইম সার্চ বানানো হয়।

# 💾 Module 6: DOM + Storage (স্মৃতিশক্তি)

---

### 📖 Lesson 1: LocalStorage Basics (পার্মানেন্ট মার্কার)

**🎯 Learning Goal:** `setItem` এবং `getItem`।

**🗣️ সহজ ব্যাখ্যা:**
রিফ্রেশ দিলে ভেরিয়েবলের মান হারিয়ে যায়। কিন্তু `localStorage` এ রাখলে ব্রাউজার বন্ধ করলেও ডেটা থাকে।

**🤣 Real-life Analogy:**
ব্ল্যাকবোর্ডে লিখলে মুছে যায় (Variable)। কিন্তু দেয়ালে খোদাই করে লিখলে থেকে যায় (LocalStorage)।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <h1>Hello <span id="user">Guest</span></h1>
    <input type="text" id="nameInput" placeholder="Enter Name">
    <button onclick="saveName()">Save Name</button>
    <button onclick="clearName()">Clear</button>

    <script>
        // পেজ লোড হলে চেক করো নাম আছে কিনা
        const savedName = localStorage.getItem('myName');
        if (savedName) {
            document.getElementById('user').innerText = savedName;
        }

        function saveName() {
            const name = document.getElementById('nameInput').value;
            localStorage.setItem('myName', name); // সেভ করলাম
            document.getElementById('user').innerText = name;
        }

        function clearName() {
            localStorage.removeItem('myName'); // ডিলিট করলাম
            location.reload(); // পেজ রিলোড
        }
    </script>
</body>
</html>
```

**📝 One-line Summary:**
ছোটখাটো সেটিংস (যেমন ইউজারনেম, থিম) মনে রাখতে `localStorage` বেস্ট।

# 🌐 Module 7: DOM + API (সার্ভারের সাথে কথা)
**লক্ষ্য:** `fetch` দিয়ে ইন্টারনেট থেকে ডেটা আনা।

---

### 📖 Lesson 1: Fetch API & Display (ওয়েটার মামা)

**🎯 Learning Goal:** JSON ডেটা এনে কার্ড বানানো।

**🗣️ সহজ ব্যাখ্যা:**
আমাদের ওয়েবসাইটে সবসময় স্ট্যাটিক ডেটা থাকে না। আমরা অন্য সার্ভার (API) থেকে ডেটা আনি। `fetch()` হলো সেই ওয়েটার যে কিচেন (Server) থেকে খাবার (Data) নিয়ে আসে।

**💻 Code Example:**
(আমরা `jsonplaceholder` থেকে ফেক ইউজার আনবো)

```html
<!DOCTYPE html>
<html>
<style>
    .user-card { border: 1px solid gray; padding: 10px; margin: 5px; background: #f0f0f0; }
</style>
<body>
    <button onclick="loadUsers()">Load Users</button>
    <div id="user-container"></div>

    <script>
        function loadUsers() {
            fetch('https://jsonplaceholder.typicode.com/users')
                .then(res => res.json()) // প্যাকেট খোলা (JSON)
                .then(data => displayUsers(data)); // ডেটা ডিসপ্লে ফাংশনে পাঠানো
        }

        function displayUsers(users) {
            const container = document.getElementById('user-container');
            
            // লুপ চালিয়ে কার্ড বানাচ্ছি
            for (const user of users) {
                const div = document.createElement('div');
                div.classList.add('user-card');
                div.innerHTML = `
                    <h3>${user.name}</h3>
                    <p>📧 ${user.email}</p>
                `;
                container.appendChild(div);
            }
        }
    </script>
</body>
</html>
```

**💪 Mini Exercise:**
1. কোডটা কপি করে রান করো। দেখো ১০ জন ইউজারের নাম আর ইমেইল চলে এসেছে!

**📝 One-line Summary:**
`fetch -> json -> loop -> append` : এটাই হলো API থেকে ডেটা দেখানোর মন্ত্র।

# 🚀 Module 8: Advanced DOM (প্রো টিপস)
**লক্ষ্য:** পারফরম্যান্স এবং ইভেন্ট ডেলিগেশন।

### 📖 Lesson 1: Event Delegation (টিম লিডার)

**🎯 Learning Goal:** প্যারেন্টের মাধ্যমে চাইল্ডের ইভেন্ট হ্যান্ডেল করা।

**🗣️ সহজ ব্যাখ্যা:**
ধরো তোমার লিস্টে ১০০টা আইটেম আছে। ১০০টা আইটেমে আলাদা আলাদা `addEventListener` লাগানো বোকামি (মেমোরি খাবে)।
আমরা শুধু প্যারেন্ট (`ul`) এর ওপর একটা লিসেনার বসাবো। যে আইটেমেই ক্লিক পড়ুক, প্যারেন্ট সেটা ধরে ফেলবে।

**🤣 Real-life Analogy:**
ক্লাসের সব ছাত্রকে আলাদা করে না বলে, মনিটরকে (Parent) বলে দেওয়া। মনিটর সবাইকে সামলাবে।

**💻 Code Example:**
```html
<!DOCTYPE html>
<html>
<body>
    <ul id="myList">
        <li>Item 1</li>
        <li>Item 2</li>
        <li>Item 3</li>
    </ul>
    
    <script>
        // উল (ul) এর ওপর লিসেনার, কিন্তু কাজ করবে লি (li) এর জন্য
        document.getElementById('myList').addEventListener('click', function(event) {
            // চেক করছি ক্লিকটা li এর ওপর পড়েছে কিনা
            if (event.target.tagName === 'LI') {
                event.target.style.textDecoration = "line-through";
                console.log("Deleted:", event.target.innerText);
            }
        });
    </script>
</body>
</html>
```

**📝 One-line Summary:**
ডাইনামিক আইটেম হ্যান্ডেল করতে Event Delegation এর বিকল্প নেই।

### 📖 Project: Simple Theme Switcher (Dark/Light Mode)

**🗣️ কনসেপ্ট:** একটা বাটন থাকবে, চাপলে ব্যাকগ্রাউন্ড কালো হবে, লেখা সাদা হবে। এবং এটা `localStorage` এ সেভ থাকবে।

**💻 Complete Code:**
```html
<!DOCTYPE html>
<html>
<head>
    <style>
        body { transition: 0.5s; padding: 20px; font-family: sans-serif; }
        .dark-mode { background-color: #333; color: white; }
        button { padding: 10px 20px; cursor: pointer; }
    </style>
</head>
<body>
    <h1>My Website</h1>
    <p>This is a simple theme switcher.</p>
    <button id="themeBtn">Toggle Dark Mode 🌙</button>

    <script>
        const btn = document.getElementById('themeBtn');
        const body = document.body;

        // ১. লোড হওয়ার সময় চেক করো
        if (localStorage.getItem('theme') === 'dark') {
            body.classList.add('dark-mode');
            btn.innerText = "Toggle Light Mode ☀️";
        }

        // ২. বাটন ক্লিক হ্যান্ডলার
        btn.addEventListener('click', () => {
            body.classList.toggle('dark-mode');

            // সেভ করা
            if (body.classList.contains('dark-mode')) {
                localStorage.setItem('theme', 'dark');
                btn.innerText = "Toggle Light Mode ☀️";
            } else {
                localStorage.setItem('theme', 'light');
                btn.innerText = "Toggle Dark Mode 🌙";
            }
        });
    </script>
</body>
</html>
```

**📝 One-line Summary:**
`classList.toggle` আর `localStorage` মিলে জোস একটা ফিচার!

# 🏆 Module 10: Final Project (Github User Finder)
**লক্ষ্য:** একটা কমপ্লিট অ্যাপ যেখানে সার্চ, API কল, এরর হ্যান্ডলিং এবং DOM ম্যানিপুলেশন থাকবে।

**🗣️ প্রজেক্টের বর্ণনা:**
আমরা গিটহাবে ইউজার খুঁজবো। নাম লিখবো, গিটহাব থেকে তার ছবি আর বায়ো (Bio) এনে দেখাবো।

**💻 Full Project Code:**
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Github Finder</title>
    <style>
        body { font-family: sans-serif; text-align: center; background: #f4f4f4; }
        .container { max-width: 400px; margin: 50px auto; background: white; padding: 20px; border-radius: 10px; box-shadow: 0 0 10px rgba(0,0,0,0.1); }
        input { padding: 10px; width: 70%; margin-bottom: 20px; }
        button { padding: 10px; cursor: pointer; background: #333; color: white; border: none; }
        .profile { margin-top: 20px; border: 1px solid #ddd; padding: 10px; border-radius: 5px; }
        img { width: 100px; border-radius: 50%; }
        .error { color: red; }
    </style>
</head>
<body>

<div class="container">
    <h2>Github User Finder 🔍</h2>
    <input type="text" id="searchUser" placeholder="Enter Github Username...">
    <button onclick="getUser()">Search</button>

    <div id="profile"></div>
</div>

<script>
    async function getUser() {
        const username = document.getElementById('searchUser').value;
        const profileDiv = document.getElementById('profile');

        // ইনপুট ভ্যালিডেশন
        if(!username) {
            alert("Please enter a username!");
            return;
        }

        // লোডিং দেখানো
        profileDiv.innerHTML = "<p>Loading...</p>";

        try {
            // API কল (Async/Await দিয়ে)
            const response = await fetch(`https://api.github.com/users/${username}`);
            
            // ইউজার না পাওয়া গেলে
            if (!response.ok) {
                profileDiv.innerHTML = `<p class="error">User not found! ❌</p>`;
                return;
            }

            const data = await response.json();

            // DOM এ ডাটা দেখানো
            profileDiv.innerHTML = `
                <div class="profile">
                    <img src="${data.avatar_url}" alt="Avatar">
                    <h3>${data.name || data.login}</h3>
                    <p>${data.bio || "No bio available"}</p>
                    <p>Followers: ${data.followers} | Following: ${data.following}</p>
                    <a href="${data.html_url}" target="_blank">View Profile</a>
                </div>
            `;

        } catch (error) {
            profileDiv.innerHTML = `<p class="error">Something went wrong! ⚠️</p>`;
            console.error(error);
        }
    }
</script>

</body>
</html>
```
