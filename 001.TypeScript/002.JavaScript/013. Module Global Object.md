### 1️⃣ Promise (ওয়াদা বা কসম) 🤞

**কাজ:** Asynchronous কাজ হ্যান্ডেল করা (দেরিতে হওয়া কাজ)।

**🗣️ সহজ ব্যাখ্যা:**
জাভাস্ক্রিপ্ট সাধারণত এক লাইনের পর আরেক লাইন কোড রান করে। কিন্তু কিছু কাজ করতে সময় লাগে (যেমন সার্ভার থেকে ডেটা আনা)। সেখানে কোড আটকে না রেখে আমরা **Promise** ব্যবহার করি।
Promise এর ৩টি অবস্থা:
1.  **Pending:** কাজ চলছে... (রেজাল্ট আসেনি)।
2.  **Resolved (Fulfilled):** কাজ সফল! (কথা রেখেছে)।
3.  **Rejected:** কাজ ফেইল! (কথা রাখেনি)।

**🤣 Real-life Analogy:**
বাবাকে বললাম, "বাবা, রেজাল্ট ভালো হলে বাইক কিনে দিবা?" বাবা বলল, **"Promise করলাম"**।
- যতক্ষণ রেজাল্ট দেয়নি: **Pending**।
- রেজাল্ট ভালো হলো + বাইক পেলি: **Resolved**।
- ফেল করলি + ঝাড়ু পেলি: **Rejected**।

**💻 Code Example:**
```javascript
const bikePromise = new Promise((resolve, reject) => {
    let result = "Pass"; // ধরলাম পাস করেছো

    if (result === "Pass") {
        resolve("Yeay! Bike peyechi! 🏍️");
    } else {
        reject("Sad life... Jharu peyechi 🧹");
    }
});

// প্রমিজ হ্যান্ডেল করা
bikePromise
    .then(msg => console.log(msg))   // সফল হলে এখানে আসবে
    .catch(err => console.log(err)); // ফেইল হলে এখানে আসবে
```

### 2️⃣ Proxy (সিকিউরিটি গার্ড বা মিডলম্যান) 🛡️

**কাজ:** অবজেক্টের ডিফল্ট আচরণ পরিবর্তন করা বা কাস্টমাইজ করা।

**🗣️ সহজ ব্যাখ্যা:**
তুমি একটা অবজেক্টের প্রপার্টি সরাসরি অ্যাক্সেস না করে মাঝখানে একটা **Proxy** বসিয়ে দিতে পারো। কেউ অবজেক্টের কাছে যাওয়ার আগে প্রোক্সির পারমিশন নিতে হবে। এটা ভ্যালিডেশন বা সিকিউরিটির জন্য দারুণ।

**🤣 Real-life Analogy:**
একজন সেলিব্রেটি (Object)। তুমি সরাসরি তার সাথে কথা বলতে পারো না। মাঝখানে একজন **ম্যানেজার (Proxy)** থাকে।
তুমি: "স্যারের বয়স কত?"
ম্যানেজার: "এটা বলা যাবে না (Access Denied)।"
তুমি: "স্যারকে গিফট দিতে চাই।"
ম্যানেজার: "দাও (Set Value)।"

**💻 Code Example:**
```javascript
const celebrity = {
    name: "Shakib Khan",
    age: 40
};

// প্রোক্সি বা ম্যানেজার তৈরি
const managerHandler = {
    // গেট ট্র্যাপ (কেউ কিছু জানতে চাইলে)
    get: function(target, prop) {
        if (prop === "age") {
            return "Wife chara kauke boli na! 🤫"; // বয়স লুকালাম
        }
        return target[prop]; // বাকি সব ঠিকঠাক দিলাম
    },

    // সেট ট্র্যাপ (কেউ ভ্যালু বদলাতে চাইলে)
    set: function(target, prop, value) {
        if (prop === "age" && value > 50) {
            console.log("Eto buro banano jabe na!");
            return false; // আটকিয়ে দিলাম
        }
        target[prop] = value;
        return true; // অনুমতি দিলাম
    }
};

const secureCelebrity = new Proxy(celebrity, managerHandler);

console.log(secureCelebrity.name); // Shakib Khan
console.log(secureCelebrity.age);  // Wife chara kauke boli na! (আসল বয়স দেখাল না)

secureCelebrity.age = 60; // Output: Eto buro banano jabe na!
```

### 3️⃣ Reflect (আয়না বা অফিসিয়াল অ্যাসিস্ট্যান্ট) 🪞

**কাজ:** অবজেক্টের অপারেশনগুলো স্ট্যান্ডার্ড উপায়ে করা।

**🗣️ সহজ ব্যাখ্যা:**
`Reflect` হলো জাভাস্ক্রিপ্টের এমন এক অবজেক্ট যার ভেতরে `get`, `set`, `deleteProperty` এর মতো মেথড আছে।
তুমি বলতে পারো, **Proxy** যদি হয় "পুলিশ", তবে **Reflect** হলো "আইনের বই"। প্রোক্সি যখন কোনো রিকোয়েস্ট আটকায় বা ছাড়ে, তখন সে কাজটা করার জন্য `Reflect` ব্যবহার করে। এটা পুরানো `Object.something` এর চেয়ে ক্লিনার।

**🤣 Real-life Analogy:**
ম্যানেজার (Proxy) যখন ডিসিশন নেয় যে তোমাকে সেলিব্রেটির সাথে দেখা করতে দেবে, তখন সে অফিশিয়াল প্রসেস (Reflect) ফলো করে দরজাটা খুলে দেয়। নিজে হাতুড়ি দিয়ে দরজা ভাঙে না।

**💻 Code Example (Reflect একাই):**
```javascript
const car = { brand: "Toyota", model: "Corolla" };

// আগে আমরা করতাম:
// console.log(car.brand); 

// Reflect দিয়ে করা (Standard Way):
console.log(Reflect.get(car, "brand")); // Toyota

// প্রপার্টি সেট করা
Reflect.set(car, "color", "Red");
console.log(car.color); // Red
```

### 🚀 Proxy + Reflect (সেরা জুটি)

সাধারণত এই দুটো একসাথেই ব্যবহার করা হয়। `Proxy` রিকোয়েস্ট ধরে, চেক করে, আর `Reflect` আসল কাজটা করে দেয়।

**💻 Combined Example:**
```javascript
const user = { username: "Rahim", balance: 500 };

const handler = {
    get(target, prop) {
        console.log(`Checking ${prop}...`); // লগ রাখছি
        return Reflect.get(target, prop);   // আসল কাজ Reflect দিয়ে করলাম
    },
    
    set(target, prop, value) {
        if (prop === "balance" && value < 0) {
            console.log("Balance negative hote pare na!");
            return false;
        }
        return Reflect.set(target, prop, value);
    }
};

const secureUser = new Proxy(user, handler);

secureUser.balance = -100; // ❌ Balance negative hote pare na!
secureUser.balance = 1000; // ✅ কাজ হবে Reflect এর মাধ্যমে
console.log(secureUser.balance); // 1000
```

---

**এক লাইনে সারমর্ম:**
1.  **Promise:** "কাজটা পরে হবে, হলে জানাবো" (Async).
2.  **Proxy:** "দাঁড়াও! চেক করে দেখি তোমাকে ঢুকতে দেওয়া যায় কিনা" (Interceptor).
3.  **Reflect:** "আচ্ছা, নিয়ম মেনে দরজা খুলে দিচ্ছি" (Standard Operations).

### 1️⃣ Promise এর আরও উদাহরণ (Teamwork & Competition)

#### উদাহরণ ১: `Promise.all` (সব বন্ধু আসলে আড্ডা হবে)
ধরো, বিরিয়ানি রান্না হবে। চাল, মাংস আর মশলা—তিনটা তিন দোকান থেকে আনতে হবে। তিনটা কাজ একসাথে (Parallel) শুরু হবে। সব উপাদান না আসা পর্যন্ত রান্না শুরু হবে না।

```javascript
const getRice = new Promise(resolve => {
    setTimeout(() => resolve("🍚 চাল চলে এসেছে!"), 1000); // ১ সেকেন্ড লাগলো
});

const getMeat = new Promise(resolve => {
    setTimeout(() => resolve("🥩 মাংস চলে এসেছে!"), 2000); // ২ সেকেন্ড লাগলো
});

const getSpices = new Promise(resolve => {
    setTimeout(() => resolve("🌶️ মশলা চলে এসেছে!"), 1500); // ১.৫ সেকেন্ড লাগলো
});

// সব প্রমিজ শেষ হলে তারপর কাজ হবে
Promise.all([getRice, getMeat, getSpices])
    .then(items => {
        console.log(items); 
        console.log("🔥 সব রেডি! এবার বিরিয়ানি রান্না শুরু!");
    })
    .catch(err => console.log("কোনো একটা আইটেম আসেনি, রান্না হবে না!"));
```

#### উদাহরণ ২: `Promise.race` (যে আগে আসবে)
উবার (Uber) আর পাঠাও (Pathao) দুইটাতেই রিকোয়েস্ট দিলাম। যে আগে আসবে, তার বাইকেই উঠবো।

```javascript
const uber = new Promise(resolve => {
    setTimeout(() => resolve("🚗 Uber আগে এসেছে!"), 3000);
});

const pathao = new Promise(resolve => {
    setTimeout(() => resolve("🏍️ Pathao আগে এসেছে!"), 1000);
});

// দৌড় প্রতিযোগিতা (Race)
Promise.race([uber, pathao])
    .then(winner => console.log("Winner is:", winner)); 
    // Output: Pathao আগে এসেছে! (কারণ সে ১ সেকেন্ডে এসেছে)
```

### 2️⃣ Proxy এর আরও উদাহরণ (Magic Tricks) 🎩

#### উদাহরণ ১: Python স্টাইল অ্যারে (Negative Index)
জাভাস্ক্রিপ্ট অ্যারেতে `arr[-1]` লিখলে লাস্ট আইটেম দেয় না (undefined দেয়)। কিন্তু **Proxy** দিয়ে আমরা এই জাদুর ফিচার বানাতে পারি!

```javascript
const fruits = ["Am", "Jam", "Kathal", "Lichu"];

const magicArrayHandler = {
    get(target, prop) {
        let index = Number(prop); // স্ট্রিং থেকে নাম্বারে নিলাম
        
        // যদি ইনডেক্স নেগেটিভ হয় (যেমন -1)
        if (index < 0) {
            index = target.length + index; // 4 + (-1) = 3 (Last item)
        }
        
        return target[index];
    }
};

const smartFruits = new Proxy(fruits, magicArrayHandler);

console.log(smartFruits[-1]); // Lichu (জাদু! 😲)
console.log(smartFruits[-2]); // Kathal
```

#### উদাহরণ ২: Smart Data Entry (Auto Formatting)
ইউজার নাম ছোট হাতের লিখলেও আমরা অটোমেটিক সেটা বড় হাতের করে সেভ করবো।

```javascript
const user = {
    firstName: "rahim",
    lastName: "uddin"
};

const formatHandler = {
    set(target, prop, value) {
        if (typeof value === 'string') {
            // ভ্যালু সেট করার আগেই মডিফাই করে দিচ্ছি
            target[prop] = value.toUpperCase(); 
        } else {
            target[prop] = value;
        }
        return true;
    }
};

const smartUser = new Proxy(user, formatHandler);

smartUser.firstName = "karim"; // ছোট হাতের দিলাম
console.log(smartUser.firstName); // Output: KARIM (হয়ে গেল বড় হাতের!)
```

### 3️⃣ Reflect এর আরও উদাহরণ (The Cleaner) 🧹

#### উদাহরণ ১: অবজেক্ট থেকে প্রপার্টি ডিলিট করা
সাধারণত আমরা `delete obj.prop` ব্যবহার করি। কিন্তু এটা `true` বা `false` রিটার্ন করে না সবসময় সুন্দরভাবে। `Reflect.deleteProperty` ব্যবহার করা বেশি স্ট্যান্ডার্ড।

```javascript
const laptop = {
    brand: "Dell",
    ram: "16GB",
    secretKey: "12345"
};

// সাধারণ ডিলিট
// delete laptop.secretKey;

// Reflect দিয়ে ডিলিট (সাথে প্রোক্সি ট্র্যাপ)
const laptopHandler = {
    deleteProperty(target, prop) {
        if (prop === "brand") {
            console.log("❌ Brand ডিলিট করা যাবে না!");
            return false;
        }
        console.log(`🗑️ Deleting ${prop}...`);
        return Reflect.deleteProperty(target, prop); // আসল কাজটা Reflect করে দিল
    }
};

const secureLaptop = new Proxy(laptop, laptopHandler);

delete secureLaptop.brand;     // ❌ Brand ডিলিট করা যাবে না!
delete secureLaptop.secretKey; // 🗑️ Deleting secretKey...

console.log(laptop); // { brand: 'Dell', ram: '16GB' }
```

#### উদাহরণ ২: প্রপার্টি আছে কিনা চেক করা (`Reflect.has`)
আমরা সাধারণত `in` অপারেটর ব্যবহার করি (`"name" in obj`)। Reflect দিয়ে ফাংশনাল ওয়েতে করা যায়।

```javascript
const mobile = { model: "iPhone 15", price: 120000 };

// Old way
if ("price" in mobile) {
    console.log("দাম দেওয়া আছে।");
}

// Reflect way (Clean looking)
if (Reflect.has(mobile, "model")) {
    console.log("মডেল পাওয়া গেছে!");
}
```

### 🔥 এক কথায় সারমর্ম:

1.  **Promise.all:** সব বন্ধু একসাথে হলে মুভি শুরু হবে।
2.  **Promise.race:** যে বন্ধু আগে টিকিটের লাইনে দাঁড়াবে, তারটাই কেনা হবে।
3.  **Proxy (Negative Index):** বইয়ের শেষ পৃষ্ঠা থেকে পড়া শুরু করা (জাভাস্ক্রিপ্টকে বোকা বানিয়ে নতুন ফিচার দেওয়া)।
4.  **Reflect:** অপারেশনের সময় "অফিশিয়াল সিল" মারা, যাতে কোড ক্লিন আর স্ট্যান্ডার্ড থাকে।
