

### **Tuple কী?**
Tuple হলো একটি **ordered** কিন্তু **immutable** data structure। অর্থাৎ, এটি list-এর মতোই ordered collection হলেও এর মান পরিবর্তন করা যায় না। একবার Tuple তৈরি হলে এর মান, আকার বা গঠন পরিবর্তন করা সম্ভব নয়।

**উদাহরণ:**
```python
t = (1, 2, 3, 4)
print(t)
```
আউটপুট:
```
(1, 2, 3, 4)
```

<br>

### **Tuple কিভাবে তৈরি করা হয়**
Tuple তৈরি করতে সাধারণত **parentheses ( )** ব্যবহার করা হয়।
```python
t1 = (10, 20, 30)
print(type(t1))  # Output: <class 'tuple'>
```
একটি একক (single) মানের Tuple তৈরি করার সময় অবশ্যই শেষে কমা (`,`) দিতে হয়।
```python
t2 = (5,)  # একক Tuple
print(type(t2))  # Output: <class 'tuple'>
```

<br>

### **Tuple Indexing ও Accessing**
Tuple-এর প্রতিটি মানের একটি **index** থাকে যা 0 থেকে শুরু হয়।
```python
numbers = (10, 20, 30, 40)
print(numbers[0])  # Output: 10
print(numbers[-1]) # Output: 40
```
Tuple থেকে **slicing** ব্যবহার করেও নির্দিষ্ট অংশ নেওয়া যায়।
```python
print(numbers[1:3])  # Output: (20, 30)
```

<br>

### **Tuple Immutable হওয়ার মানে কী**
Tuple তৈরি করার পরে এর মান পরিবর্তন করা যায় না। নিচের উদাহরণটি দেখো:
```python
t = (1, 2, 3)
t[0] = 10  # এটি error দেবে
```
**Error:** `TypeError: 'tuple' object does not support item assignment`

<br>

### **Tuple Concatenation এবং Repetition**
Tuple-গুলো একত্রিত করা বা পুনরাবৃত্তি করা যায় `+` এবং `*` অপারেটর ব্যবহার করে।
```python
t1 = (1, 2)
t2 = (3, 4)
print(t1 + t2)   # Output: (1, 2, 3, 4)
print(t1 * 2)    # Output: (1, 2, 1, 2)
```

<br>

### **Tuple Methods**
Tuple-এর জন্য কিছু built-in method আছে যেমন:

| Method | কাজ |
| :--- | :--- |
| `count(x)` | Tuple-এ x কতবার আছে তা গণনা করে |
| `index(x)` | Tuple-এ x-এর প্রথম অবস্থান (index) দেয় |

**উদাহরণ:**
```python
nums = (1, 2, 2, 3)
print(nums.count(2))  # Output: 2
print(nums.index(3))  # Output: 3
```

<br>

### **Tuple এবং List-এর মধ্যে পার্থক্য**

| বৈশিষ্ট্য | List | Tuple |
| :--- | :--- | :--- |
| Mutable | ✅ | ❌ |
| Syntax | [] | () |
| Performance | তুলনামূলক ধীর | তুলনামূলক দ্রুত |
| ব্যবহার | পরিবর্তনযোগ্য ডেটা | স্থির বা অপরিবর্তনীয় ডেটা |

<br>

### **মূল পয়েন্টসমূহ**
*   Tuple হলো immutable ordered collection।
*   একবার Tuple তৈরি হলে এর মান পরিবর্তন করা যায় না।
*   Tuple-এ indexing, slicing, concatenation সম্ভব।
*   Tuple সাধারণত এমন ডেটা সংরক্ষণের জন্য ব্যবহৃত হয় যা পরিবর্তন করা প্রয়োজন নেই।


## Set কী?
Set হলো একটি **unordered** এবং **mutable** data structure, যেখানে **duplicate value রাখা যায় না**। Set সাধারণত unique elements রাখার জন্য ব্যবহৃত হয়।

**উদাহরণ:**
```python
s = {1, 2, 3, 3, 4}
print(s)
```
আউটপুট:
```
{1, 2, 3, 4}
```
(এখানে duplicate মান 3 একবারই থাকবে।)

<br>

### **Set create করা**
Set তৈরি করা যায় `{}` ব্র্যাকেট ব্যবহার করে অথবা `set()` function দিয়ে।
```python
s1 = {10, 20, 30}
s2 = set([1, 2, 3])
print(s1)
print(s2)
```
আউটপুট:
```
{10, 20, 30}
{1, 2, 3}
```
**দ্রষ্টব্য:** `{}` ব্যবহার করলে যদি কোনো মান না দেওয়া হয়, Python সেটিকে **empty dictionary** ধরে নেয়। তাই empty set তৈরি করতে `set()` ব্যবহার করতে হবে।
```python
s = set()
print(type(s))
```
আউটপুট:
```
<class 'set'>
```

<br>

### **Set-এর Elements add ও delete করা**
Set mutable হওয়ায় এতে নতুন elements যোগ বা পুরনো মুছে ফেলা যায়।
```python
numbers = {1, 2, 3}
numbers.add(4)
print(numbers)

numbers.remove(2)
print(numbers)
```
আউটপুট:
```
{1, 2, 3, 4}
{1, 3, 4}
```
`discard()` method ব্যবহার করলে element না থাকলেও error দেয় না।
```python
numbers.discard(10)
```

<br>

### **Set Operations**
Set-এ গণিতের মতো বিভিন্ন operation করা যায়।

| Operation | Symbol | Description |
| :--- | :--- | :--- |
| Union | `\|` | উভয় set-এর সব unique elements দেয় |
| Intersection | `&` | শুধুমাত্র common elements দেয় |
| Difference | `-` | প্রথম set থেকে দ্বিতীয় set-এর element বাদ দেয় |
| Symmetric Difference | `^` | উভয়ের unique elements দেয় |

**উদাহরণ:**
```python
a = {1, 2, 3}
b = {3, 4, 5}
print(a | b)
print(a & b)
print(a - b)
print(a ^ b)
```
**আউটপুট:**
```
{1, 2, 3, 4, 5}
{3}
{1, 2}
{1, 2, 4, 5}
```

<br>

### **Set Iteration**
Set-এর ওপর loop চালানো যায়, কিন্তু যেহেতু এটি unordered, তাই output-এর ক্রম পরিবর্তিত হতে পারে।
```python
for item in {10, 20, 30}:
    print(item)
```
সম্ভাব্য আউটপুট (ক্রম ভিন্ন হতে পারে):
```
10
20
30
```

<br>

### **Membership Checking**
`in` এবং `not in` অপারেটর দিয়ে Set-এর মধ্যে কোনো মান আছে কিনা তা যাচাই করা যায়।
```python
s = {1, 2, 3}
print(2 in s)
print(5 not in s)
```
আউটপুট:
```
True
True
```

<br>

### **Set Comprehension**
Set comprehension list comprehension-এর মতোই, তবে `{}` ব্যবহার করা হয়।
```python
squares = {x*x for x in range(5)}
print(squares)
```
আউটপুট (ক্রম ভিন্ন হতে পারে):
```
{0, 1, 4, 9, 16}
```

### **মূল পয়েন্টসমূহ**
*   Set হলো unordered, mutable এবং unique elements-এর collection।
*   Duplicate element স্বয়ংক্রিয়ভাবে বাদ যায়।
*   Union, intersection, difference ইত্যাদি operation সমর্থন করে।
*   Empty set তৈরি করতে `set()` ব্যবহার করতে হয়।


## **Dictionary কী**
Dictionary হলো একটি **key-value pair ভিত্তিক data structure**, যেখানে প্রতিটি মানের সাথে একটি নির্দিষ্ট key যুক্ত থাকে। এটি **unordered** হলেও Python 3.7 থেকে **insertion ordered** হয়ে গেছে।

**উদাহরণ:**
```python
student = {"name": "Rafi", "age": 20, "grade": "A"}
print(student)
```
আউটপুট:
```
{'name': 'Rafi', 'age': 20, 'grade': 'A'}
```

<br>

### **Create a Dictionary**
Dictionary তৈরি করতে `{}` ব্যবহার করা হয় অথবা `dict()` function দিয়ে তৈরি করা যায়।
```python
info1 = {"name": "Amit", "age": 25}
info2 = dict(city="Dhaka", country="Bangladesh")
print(info1)
print(info2)
```
আউটপুট:
```
{'name': 'Amit', 'age': 25}
{'city': 'Dhaka', 'country': 'Bangladesh'}
```

<br>

### **Access elements in a Dictionary**
Key ব্যবহার করে Value access করা হয়।
```python
person = {"name": "Sara", "age": 22}
print(person["name"])
print(person.get("age"))
```
আউটপুট:
```
Sara
22
```
`get()` method ব্যবহার করলে key না থাকলে error দেয় না।
```python
print(person.get("city", "Not Found"))
```
আউটপুট:
```
Not Found
```

<br>

### **Add or update elements in a Dictionary**
Dictionary mutable, তাই নতুন key-value pair যোগ করা যায় বা পুরনো মান পরিবর্তন করা যায়।
```python
student = {"name": "Mina", "age": 18}
student["grade"] = "A"
student["age"] = 19
print(student)
```
আউটপুট:
```
{'name': 'Mina', 'age': 19, 'grade': 'A'}
```

<br>

### **Delete elements from a Dictionary**
To delete elements, you can use the following methods.
```python
student = {"name": "Ali", "age": 20, "grade": "B"}
student.pop("age")
print(student)
```
আউটপুট:
```
{'name': 'Ali', 'grade': 'B'}
```
Using `clear()` makes the Dictionary empty.
```python
student.clear()
print(student)
```
আউটপুট:
```
{}
```

<br>

### **Dictionary Iteration**
Dictionary-এর key, value বা key-value pair এর ওপর loop চালানো যায়।
```python
person = {"name": "Rafi", "age": 21}

for key in person:
    print(key, ":", person[key])

for value in person.values():
    print(value)

for key, value in person.items():
    print(key, value)
```
Output
```
name : Rafi
age : 21
Rafi
21
name Rafi
age 21
```

<br>

### **Dictionary Methods**

| Method | কাজ |
| :--- | :--- |
| `keys()` | সব key ফেরত দেয় |
| `values()` | সব value ফেরত দেয় |
| `items()` | key-value pair ফেরত দেয় |
| `pop(key)` | নির্দিষ্ট key-value pair মুছে ফেলে |
| `clear()` | পুরো Dictionary খালি করে |
| `update()` | আরেকটি Dictionary-এর ডেটা যোগ করে |

**উদাহরণ:**
```python
a = {"x": 1, "y": 2}
b = {"y": 3, "z": 4}
a.update(b)
print(a)
```
আউটপুট:
```
{'x': 1, 'y': 3, 'z': 4}
```

<br>

### **Nested Dictionary**
Dictionary-এর ভেতরেও Dictionary থাকতে পারে।
```python
students = {
    "101": {"name": "Rafi", "grade": "A"},
    "102": {"name": "Mina", "grade": "B"}
}
print(students["101"]["name"])
```
আউটপুট:
```
Rafi
```

### **মূল পয়েন্টসমূহ**
*   Dictionary হলো key-value pair ভিত্তিক structure।
*   Key অবশ্যই unique এবং immutable হতে হয়।
*   Dictionary mutable, তাই এটি আপডেট করা যায়।
*   `keys()`, `values()`, `items()` দিয়ে সহজে iteration করা যায়।


### Quick Reference: Common Methods

| Category | Method | Purpose |
| :--- | :--- | :--- |
| Read | `get(key, default=None)` | Safe read; key না থাকলে default রিটার্ন করে |
| Read | `keys()` / `values()` / `items()` | Views of keys/values/pairs |
| Create | `fromkeys(iterable, value=None)` | Keys from iterable; same default value |
| Update/Add | `update(mapping_or_iterable)` | Merge/overwrite pairs |
| Update/Add | `setdefault(key, default=None)` | If key missing, set to default and return it |
| Delete | `pop(key[, default])` | Remove key and return its value |
| Delete | `popitem()` | Remove and return last inserted pair (LIFO) |
| Empty | `clear()` | Remove all items |
| Copy | `copy()` | Shallow copy of dictionary |

<br>

### **Read (Access) Methods**
`get()` দিয়ে safe read করা যায়; key না থাকলে error নয়, বরং default রিটার্ন হয়।
```python
user = {"name": "Nadia", "age": 23}
print(user.get("name"))
print(user.get("city"))
print(user.get("city", "Unknown"))
```
আউটপুট:
```
Nadia
None
Unknown
```
`keys()`, `values()`, `items()` view object দেয় যা dynamic—ডিকশনারি বদলালে view-ও reflect করবে।
```python
user = {"name": "Nadia", "age": 23}
print(user.keys())
print(user.values())
print(user.items())
```
আউটপুট (representation ভিন্ন হতে পারে):
```
dict_keys(['name', 'age'])
dict_values(['Nadia', 23])
dict_items([('name', 'Nadia'), ('age', 23)])
```

<br>

### **Create Methods**
`fromkeys()` দিয়ে iterable থেকে keys তৈরি করা যায়, সবগুলোর জন্য same value সেট হয়।
```python
keys = ["id", "name", "age"]
defaults = dict.fromkeys(keys, None)
print(defaults)
```
আউটপুট:
```
{'id': None, 'name': None, 'age': None}
```
> নোট: যদি mutable object (যেমন list) value হিসেবে দাও, সব key একই object share করবে।
```python
fields = dict.fromkeys(["a", "b"], [])
fields["a"].append(1)
print(fields)
```
আউটপুট:
```
{'a': [1], 'b': [1]}
```

<br>

### **Update/Add Methods**
`update()` অন্য mapping বা key-value pair iterable থেকে merge করে। Existing key থাকলে overwrite হয়।
```python
profile = {"name": "Nadia", "age": 23}
profile.update({"age": 24, "city": "Dhaka"})
print(profile)
```
আউটপুট:
```
{'name': 'Nadia', 'age': 24, 'city': 'Dhaka'}
```
`setdefault()` missing key create করতে সুবিধাজনক; key থাকলে সেটির value-ই রিটার্ন করে।
```python
settings = {"theme": "light"}
val = settings.setdefault("lang", "bn")
print(val)
print(settings)
```
আউটপুট:
```
bn
{'theme': 'light', 'lang': 'bn'}
```

<br>

### **Delete Methods**
`pop()` নির্দিষ্ট key remove করে এবং value রিটার্ন করে। Default দিলে missing key হলে default রিটার্ন করে।
```python
stock = {"apple": 5, "banana": 10}
q = stock.pop("apple")
print(q)
print(stock)

missing = stock.pop("orange", 0)
print(missing)
print(stock)
```
আউটপুট:
```
5
{'banana': 10}
0
{'banana': 10}
```
`popitem()` last inserted pair remove করে (Python 3.7+)।
```python
pairs = {"x": 1, "y": 2, "z": 3}
item = pairs.popitem()
print(item)
print(pairs)
```
আউটপুট (LIFO):
```
('z', 3)
{'x': 1, 'y': 2}
```

<br>

### **Empty & Copy**
`clear()` পুরো dictionary empty করে দেয়।
```python
data = {"a": 1, "b": 2}
data.clear()
print(data)
```
আউটপুট:
```
{}
```
`copy()` shallow copy রিটার্ন করে—nested mutable object শেয়ার্ড থাকতে পারে।
```python
orig = {"nums": [1, 2]}
cloned = orig.copy()
cloned["nums"].append(3)
print(orig)
print(cloned)
```
আউটপুট:
```
{'nums': [1, 2, 3]}
{'nums': [1, 2, 3]}
```
> Deep copy দরকার হলে `copy` মডিউলের `deepcopy()` ব্যবহার করো।

### **Performance Notes (সংক্ষিপ্ত)**
*   Most dict ops average O(1) (hash table ভিত্তিক)।
*   `keys()/values()/items()` view অবজেক্ট—iterate করতে O(n)।

### **মূল পয়েন্টসমূহ**
*   Safe read-এর জন্য `get()` এবং create-if-missing-এর জন্য `setdefault()`।
*   Merge/overwrite করতে `update()`।
*   নির্দিষ্ট remove-এর জন্য `pop()`; last-in remove-এর জন্য `popitem()`।
*   সবকিছু empty করতে `clear()`; shallow `copy()` nested mutable share করে।


### **What are dictionary views?**
`keys()`, `values()`, `items()` মেথডগুলো **view object** রিটার্ন করে—এগুলো lightweight এবং ডিকশনারি পরিবর্তিত হলে view-ও সাথে সাথে reflect করে।
```python
user = {"name": "Nadia", "age": 23}
ks = user.keys()
vs = user.values()
its = user.items()
print(ks)
print(vs)
print(its)
```
আউটপুট (representation ভিন্ন হতে পারে):
```
dict_keys(['name', 'age'])
dict_values(['Nadia', 23])
dict_items([('name', 'Nadia'), ('age', 23)])
```

<br>

### **Views are dynamic (live)**
ডিকশনারিতে add/update/delete করলে view সঙ্গে সঙ্গে reflect করে।
```python
user = {"name": "Nadia"}
ks = user.keys()
print(list(ks))

user["age"] = 23  # add
print(list(ks))    # ks আবার নতুন key দেখাবে

user.pop("name")  # delete
print(list(ks))
```
আউটপুট:
```
['name']
['name', 'age']
['age']
```

<br>

### **Iterate and membership with views**
Read/iterate করা ও membership check করা সহজ।
```python
person = {"id": 101, "city": "Dhaka"}
for k in person.keys():
    print(k)
for v in person.values():
    print(v)
for k, v in person.items():
    print(k, v)

print("city" in person.keys())   # membership on keys
print("Khulna" in person.values())
```
সম্ভাব্য আউটপুট:
```
id
city
101
Dhaka
id 101
city Dhaka
True
False
```

<br>

### **Convert views to concrete containers**
কখনো স্থির snapshot দরকার হলে view-কে list/tuple/set-এ convert করা হয় (যেমন sorting/Indexing দরকার হলে)।
```python
data = {"b": 2, "a": 1, "c": 3}
key_list = list(data.keys())
value_tuple = tuple(data.values())
key_set = set(data.keys())
print(key_list)
print(value_tuple)
print(key_set)
```
আউটপুট (ক্রম ভিন্ন হতে পারে):
```
['b', 'a', 'c']
(2, 1, 3)
{'a', 'b', 'c'}
```
> নোট: list/tuple/set বানালে সেটা আর live থাকে না—এটি একটি snapshot।

<br>

### **Set-like operations on views (keys/items)**
`dict_keys` এবং `dict_items` view গুলো set-like—এগুলোতে অন্য set বা keys view-এর সাথে `&` (intersection), `|` (union), `-` (difference) করা যায়।
```python
p = {"id": 1, "name": "Ana", "city": "Dhaka"}
q = {"name": "Ana", "country": "BD"}

common_keys = p.keys() & q.keys()
all_keys = p.keys() | q.keys()
left_only = p.keys() - q.keys()
print(common_keys)
print(all_keys)
print(left_only)

# items()-এর ক্ষেত্রেও
common_items = p.items() & {("name", "Ana"), ("id", 1)}
print(common_items)
```
আউটপুট (ক্রম ভিন্ন হতে পারে):
```
{'name'}
{'id', 'name', 'city', 'country'}
{'city', 'id'}
{('id', 1), ('name', 'Ana')}
```
> নোট: `dict_values` view set-like অপারেশনের জন্য উপযুক্ত নয়; দরকার হলে আগে `set()` নাও (values hashable হলে)।

<br>

### **Sorting or indexing with views**
View নিজে index/sort সাপোর্ট করে না। Indexing/Sorting দরকার হলে list-এ convert করো।
```python
scores = {"Rafi": 88, "Mina": 92, "Ali": 85}

# Top scorer (by value) বের করতে values দিয়ে sort
top = sorted(scores.items(), key=lambda kv: kv[1], reverse=True)[0]
print(top)
```
আউটপুট:
```
('Mina', 92)
```

<br>

### **Performance notes (সংক্ষিপ্ত)**
*   Views memory-efficient এবং তৈরি করা O(1)।
*   Iterate করা O(n)। Snapshot (list/tuple/set) বানালে O(n) কপি খরচ হয়।

<br>

### **মূল পয়েন্টসমূহ**
*   `keys()/values()/items()` view object—live update reflect করে।
*   Membership/iteration/read-এর জন্য views যথেষ্ট; স্থির কপি দরকার হলে list/tuple/set নাও।
*   Keys/items view-এ set-like operations কাজ করে; values-এর ক্ষেত্রে আগে set() লাগতে পারে।

### **Dictionary Comprehension কী**
Dictionary comprehension হলো সংক্ষিপ্ত সিনট্যাক্স ব্যবহার করে নতুন dictionary **create** করার পদ্ধতি। সাধারণ ফর্ম:
```python
{key_expr: value_expr for item in iterable if condition}
```

<br>

### **Create: বেসিক উদাহরণ**
সংখ্যা 1..5 এর square values দিয়ে dict **create** করা:
```python
squares = {x: x*x for x in range(1, 6)}
print(squares)
```
আউটপুট:
```
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

<br>

### **Read/Filter: শর্ত দিয়ে নির্বাচন**
শুধু even key রেখে dict **create** করা (read/select-স্টাইল):
```python
evens = {x: x*x for x in range(1, 8) if x % 2 == 0}
print(evens)
```
আউটপুট:
```
{2: 4, 4: 16, 6: 36}
```
> নোট: `if` শর্তটি `for`-এর পরে দিলে item ফিল্টার হয়; `value`-তে `if-else` দিলে মান পরিবর্তন হয়।

<br>

### **Transform/Update-style: মান পরিবর্তন**
কমপ্রিহেনশন দিয়ে value **transform** করা (যেমন, string normalize):
```python
raw = {"Name": "Rafi", "CITY": "Dhaka"}
normalized = {k.lower(): v.upper() for k, v in raw.items()}
print(normalized)
```
আউটপুট:
```
{'name': 'RAFI', 'city': 'DHAKA'}
```

**Conditional transform (ternary):**
```python
nums = {1: 10, 2: 15, 3: 20}
flagged = {k: ("EVEN" if v % 2 == 0 else "ODD") for k, v in nums.items()}
print(flagged)
```
আউটপুট:
```
{1: 'EVEN', 2: 'ODD', 3: 'EVEN'}
```

<br>

### **তালিকা/টিউপল থেকে dict create**
Tuple list → dict:
```python
pairs = [("a", 1), ("b", 2), ("c", 3)]
D = {k: v for k, v in pairs}
print(D)
```
আউটপুট:
```
{'a': 1, 'b': 2, 'c': 3}
```
দুটি আলাদা list → `zip()` দিয়ে dict:
```python
keys = ["id", "name", "age"]
vals = [101, "Mina", 20]
info = {k: v for k, v in zip(keys, vals)}
print(info)
```
আউটপুট:
```
{'id': 101, 'name': 'Mina', 'age': 20}
```
### Invert: key ↔ value বদলানো
> সতর্কতা: values অবশ্যই hashable হতে হবে এবং **duplicate value হলে শেষটি থাকবে**।
```python
orig = {"x": 1, "y": 2, "z": 1}
inverted = {v: k for k, v in orig.items()}
print(inverted)
```
আউটপুট:
```
{1: 'z', 2: 'y'}
```

<br>

### **Nested Comprehension**
Nested iterable থেকে flat dict **create** করা:
```python
matrix = [[1, 2], [3, 4]]
flat = {idx: val for row in matrix for idx, val in enumerate(row, 1)}
print(flat)
```
আউটপুট:
```
{1: 3, 2: 4}
```
আরও স্পষ্ট উদাহরণ (pair numbering):
```python
pairs = [[("a", 1), ("b", 2)], [("c", 3)]]
flat_pairs = {k: v for sub in pairs for (k, v) in sub}
print(flat_pairs)
```
আউটপুট:
```
{'a': 1, 'b': 2, 'c': 3}
```

<br>

### **Comprehension vs for-loop (equivalent)**
কমপ্রিহেনশনের সমতুল্য লুপ কোড:
```python
# comprehension
squares = {x: x*x for x in range(3)}

# equivalent for-loop
squares2 = {}
for x in range(3):
    squares2[x] = x*x

print(squares)
print(squares2)
```
আউটপুট:
```
{0: 0, 1: 1, 2: 4}
{0: 0, 1: 1, 2: 4}
```

<br>

### **Common Pitfalls**
1.  **Duplicate keys overwrite**: একই key একাধিকবার এলে শেষ মানটি থাকবে।
2.  **Mutable shared value**: যদি একই mutable object রেফারেন্স দাও, সব key তাতে share করবে।
3.  **Complex logic**: অতিরিক্ত nested/complex হলে পড়া কঠিন—লুপ ব্যবহার করো।
4.  **Order**: Python 3.7+ এ dict insertion ordered; comprehension-ও সে অনুসারেই order রাখে।

<br>

### Performance Notes 
*   comprehension সাধারণত সমতুল্য লুপের চেয়ে concise এবং সামান্য দ্রুত।
*   অতিরিক্ত complex condition/নেস্টিং performance/পঠনযোগ্যতা কমাতে পারে।

<br>

### **মূল পয়েন্টসমূহ**
*   `{k: v for ...}` দিয়ে dict দ্রুত **create** করা যায়।
*   `if` দিয়ে **filter** করা যায়; `if-else` দিয়ে **transform** করা যায়।
*   `zip()`/list-of-tuples থেকে dict বানানো সহজ।
*   Duplicate keys হলে শেষ মানটি থাকবে; value hashable না হলে invert সম্ভব নয়।
