### 📦 Module 1: Node.js এর সাথে পরিচয় (Introduction)

এই মডিউলে আমরা জানবো Node.js আসলে কি জিনিস এবং কেন এটা নিয়ে দুনিয়াজুড়ে এত লাফালাফি।

#### 🎓 Lesson 1.1: Node.js আসলে কি? (What is Node.js?)

**সহজ বাংলা:**
Node.js কোনো প্রোগ্রামিং ল্যাঙ্গুয়েজ না (যেমন C++ বা Python), আবার এটা কোনো ফ্রেমওয়ার্কও না। এটা হলো একটা **Runtime Environment**। সোজা কথায়, জাভাস্ক্রিপ্ট আগে শুধু ব্রাউজারে (Google Chrome, Firefox) চলতো। Node.js এর কারণে এখন জাভাস্ক্রিপ্ট তোমার কম্পিউটারে বা সার্ভারেও চলে।

**🤣 ফানি উদাহরণ:**
ধরো, জাভাস্ক্রিপ্ট হলো একটা **ফেরারি গাড়ির ইঞ্জিন**। আগে এই ইঞ্জিনটা শুধু **গাড়ির বডির (Browser)** ভেতরেই ফিট করা যেতো। এখন Node.js হলো এমন এক মেকানিক, যে এই ফেরারি ইঞ্জিনটাকে খুলে এনে একটা **ট্রাক বা রকেটের (Server)** মধ্যে ফিট করে দিছে। এখন ওই ট্রাকও ফেরারির গতিতে চলে!

**💻 কোড:**
(কোনো কোড নাই, জাস্ট কনসেপ্ট। কিন্তু মন চাইলে টার্মিনাল ওপেন করে `node -v` লিখে দেখতে পারো তোমার পিসিতে ইঞ্জিন আছে কিনা।)

#### 🎓 Lesson 1.2: কেন Node.js শিখবো? (Why Node.js?)

**সহজ বাংলা:**
কারণ এটা **Non-blocking I/O** এবং **Single Threaded**। মানে একসাথে অনেক কাজ হ্যান্ডেল করতে পারে আটকানো ছাড়াই।

**🤣 ফানি উদাহরণ:**
ধরো তুমি এক রেস্টুরেন্টে গেছো।
**অন্যান্য ভাষা (PHP/Java old style):** ওয়েটার অর্ডার নিয়ে কিচেনে যায়, রাঁধুনির পাশে দাঁড়িয়ে থাকে, রান্না শেষ হলে খাবার এনে দিয়ে তারপর অন্য কাস্টমারের কাছে যায়। (খুবই স্লো!)
**Node.js ওয়েটার:** অর্ডার নিয়েই কিচেনে স্লিপ ধরিয়ে দিয়ে সাথে সাথে দৌড় দেয় অন্য কাস্টমারের অর্ডার নিতে। রান্না হলে শেফ বেল বাজায়, ওয়েটার খাবার দিয়ে দেয়। মানে ওয়েটার কখনোই বেকার বসে থাকে না।

**💻 কোড:**
কোড পরে আসছে, আগে লজিক বোঝো মামা!

#### 🎓 Lesson 1.3: এনভায়রনমেন্ট সেটআপ (Installation)

**সহজ বাংলা:**
Node.js এর অফিসিয়াল ওয়েবসাইট থেকে `LTS` (Long Term Support) ভার্সন ডাউনলোড করে ইনস্টল করতে হবে। আর কোড লেখার জন্য `VS Code` লাগবে।

**🤣 ফানি উদাহরণ:**
ক্রিকেট খেলার আগে যেমন ব্যাট-বল কিনতে হয়, তেমনি কোডিং করার আগে এই টুলগুলো নামাতে হবে। ব্যাট ছাড়া মাঠে নামলে তো আম্পায়ার বের করে দিবে!

**💻 কাজ:**
১. Node.js ইনস্টল করো।
২. টার্মিনালে লেখো: `node -v` (ভার্সন দেখাবে)।

#### 🎓 Lesson 1.4: Hello World - প্রথম কোড

**সহজ বাংলা:**
আমরা আমাদের প্রথম জাভাস্ক্রিপ্ট কোড রান করবো ব্রাউজার ছাড়া, সরাসরি পিসিতে।

**🤣 ফানি উদাহরণ:**
নতুন প্রেমিকার সাথে প্রথম দেখা হলে যেমন ভয়ে ভয়ে "হাই" বলো, এটাও তাই। কম্পিউটারের সাথে পিরিত করার প্রথম ধাপ।

**💻 কোড:**
একটা ফাইল বানাও `index.js` নামে।
```javascript
console.log("Hello Node.js! Mama ami coding shikhtesi!");
```
টার্মিনালে রান করো: `node index.js`

**মজার ব্যাখ্যা:**
কম্পিউটার তোমার কথা শুনেছে এবং উত্তরে প্রিন্ট করেছে। সে এখন তোমার গোলাম!

#### 🎓 Lesson 1.5: REPL - খেলার মাঠ

**সহজ বাংলা:**
REPL মানে Read-Eval-Print-Loop। টার্মিনালে শুধু `node` লিখলে একটা মোড অন হয়, যেখানে ছোটখাটো কোড টেস্ট করা যায়।

**🤣 ফানি উদাহরণ:**
এটা হলো পরীক্ষার হলের **রাফ খাতা (Rough Khata)**। অংক মেলানোর আগে যেমন রাফ করে নাও, তেমন মেইন কোড লেখার আগে এখানে একটু গুতাগুতি করে দেখা যায় সব ঠিক আছে কিনা।

**💻 কোড:**
টার্মিনালে `node` লেখো। তারপর:
```javascript
> 10 + 20
30
> "Bangla" + "desh"
'Bangladesh'
```
(বের হতে চাইলে `Ctrl + C` দুইবার চাপো)।

#### 🎓 Lesson 1.6: Global Objects (window নাই!)

**সহজ বাংলা:**
ব্রাউজারে যেমন `window` অবজেক্ট থাকে, Node.js এ সেটা নাই। এখানে আছে `global`। আর আছে `__dirname` এবং `__filename`।

**🤣 ফানি উদাহরণ:**
ব্রাউজার হলো তোমার **শ্বশুরবাড়ি**, সেখানে নিয়ম আলাদা। আর Node.js হলো তোমার **মেস বাড়ি**। শ্বশুরবাড়িতে লুঙ্গি পরে ঘুরলে সমস্যা হতে পারে (window error), কিন্তু মেস বাড়িতে যা খুশি তাই (global)। কিন্তু মেস বাড়িতেও কিছু রুলস আছে।

**💻 কোড:**
```javascript
console.log(__dirname); // ফোল্ডারের নাম
console.log(__filename); // ফাইলের নাম
// console.log(window); // এটা দিলে এরর খাবে, কারণ এটা শ্বশুরবাড়ি না!
```

**মজার ব্যাখ্যা:**
`__dirname` তোমাকে বলে দিবে তুমি এখন কোন চিপায় (folder) আছো।

#### 🎓 Lesson 1.7: Modules - কোড ভাগাভাগি (CommonJS)

**সহজ বাংলা:**
সব কোড এক ফাইলে লিখলে জগাখিচুড়ি হয়ে যাবে। তাই আমরা কোড আলাদা ফাইলে রাখি এবং দরকার হলে `require` করি।

**🤣 ফানি উদাহরণ:**
বিয়ে বাড়িতে বিরিয়ানি রান্নার সময় বাবুর্চি কি একা সব করে? না! একজন পেঁয়াজ কাটে, একজন মাংস ধোয়। কোডও তেমন। এক ফাইলে সব না লিখে, আলাদা ফাইলে লিখে মেইন ফাইলে ইম্পোর্ট করা—একে বলে **Module**।

**💻 কোড:**
*math.js*
```javascript
const add = (a, b) => a + b;
module.exports = add;
```
*index.js*
```javascript
const jogKoro = require('./math');
console.log(jogKoro(5, 5)); // 10
```

**মজার ব্যাখ্যা:**
`math.js` থেকে `add` ফাংশনটা ধার করে এনে `index.js` এ ব্যবহার করলাম। প্রতিবেশীর ঘর থেকে চিনি ধার করার মতো।

#### 🎓 Lesson 1.8: Multiple Exports - ভাণ্ডার উজাড় করে দেয়া

**সহজ বাংলা:**
এক ফাইল থেকে একাধিক জিনিস এক্সপোর্ট করতে চাইলে অবজেক্ট আকারে পাঠাতে হয়।

**🤣 ফানি উদাহরণ:**
আগেরবার শুধু চিনি ধার দিয়েছিলে। এবার প্রতিবেশী চিনি, লবণ, আর পেঁয়াজ সবই চায়। তাই একটা বাটিতে (Object) করে সব একসাথে পাঠাতে হবে।

**💻 কোড:**
*utils.js*
```javascript
const name = "Hero Alom";
const add = (a, b) => a + b;

module.exports = { name, add };
```
*index.js*
```javascript
const { name, add } = require('./utils');
console.log(name); // Hero Alom
console.log(add(2, 3)); // 5
```

#### 🎓 Lesson 1.9: NPM - জাদুর বাক্স (Node Package Manager)

**সহজ বাংলা:**
NPM হলো দুনিয়ার সবচেয়ে বড় ওপেন সোর্স লাইব্রেরি। অন্যের লেখা কোড ফ্রিতে ব্যবহার করার জায়গা।

**🤣 ফানি উদাহরণ:**
এটা হলো **ডোরেমনের পকেট**। তোমার যা লাগবে (যেমন তারিখ ফরম্যাট করা, পাসওয়ার্ড এনক্রিপ্ট করা), সব রেডিমেড পাওয়া যায়। কষ্ট করে চাকা আবিষ্কার করার দরকার নাই, বাজার থেকে চাকা কিনে গাড়িতে লাগাও।

**💻 কাজ:**
টার্মিনালে `npm init -y` লেখো। দেখবে একটা `package.json` ফাইল তৈরি হয়েছে।

#### 🎓 Lesson 1.10: package.json - জন্ম নিবন্ধন

**সহজ বাংলা:**
`package.json` হলো তোমার প্রজেক্টের মেইন ফাইল। এখানে প্রজেক্টের নাম, ভার্সন, এবং কি কি লাইব্রেরি ব্যবহার করা হয়েছে তার লিস্ট থাকে।

**🤣 ফানি উদাহরণ:**
এটা তোমার প্রজেক্টের **জাতীয় পরিচয়পত্র (NID)** বা **বায়োডাটা**। পুলিশ (ডেভেলপার) ধরলে আগে এটাই চেক করবে—"তোর নাম কি? বাপের নাম কি? তুই কি কি প্যাকেজ খাস?"

**💻 কোড:**
`package.json` ফাইলটা খুলে দেখো:
```json
{
  "name": "node-course",
  "version": "1.0.0",
  "main": "index.js",
  "dependencies": {
     // এখানে আমরা যা ইনস্টল করবো তার লিস্ট থাকবে
  }
}
```
