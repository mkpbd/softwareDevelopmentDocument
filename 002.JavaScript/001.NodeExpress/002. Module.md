### 📦 Module 2: Node.js এর ভিতরের খবর (Node Fundamentals)

এই মডিউলে আমরা Node.js এর নিজস্ব কিছু সুপারপাওয়ার (Core Modules) নিয়ে খেলবো। এগুলো বাইরে থেকে ইনস্টল করতে হয় না, Node.js এর পেটের ভেতর জন্ম থেকেই আছে।

#### 🎓 Lesson 2.1: Core Modules - বিল্ট-ইন অস্ত্রশস্ত্র

**সহজ বাংলা:**
তুমি যখন একটা নতুন স্মার্টফোন কিনো, তখন কি ক্যামেরা বা ক্যালকুলেটর আলাদা করে ডাউনলোড করতে হয়? না! ওগুলো বিল্ট-ইন থাকে। ঠিক তেমনি, Node.js ইনস্টল করলেই `fs` (File System), `http`, `path`, `os`—এই মডিউলগুলো ফ্রিতে পাওয়া যায়।

**🤣 ফানি উদাহরণ:**
এটা হলো **সুইস আর্মি নাইফ** এর মতো। এক চাকুতেই কাঁচি, স্ক্রু-ড্রাইভার, বোতল খোলার যন্ত্র সব আছে। তোমার শুধু বের করে ব্যবহার করতে হবে।

**💻 কোড:**
```javascript
// জাস্ট ডেকে নিয়ে আসো
const fs = require('fs'); 
const os = require('os');

console.log("সব রেডি বস!");
```

#### 🎓 Lesson 2.2: File System (fs) - প্রেমপত্র লেখা (Write File)

**সহজ বাংলা:**
`fs` মডিউল দিয়ে তুমি পিসিতে ফাইল তৈরি করতে পারো, ডিলিট করতে পারো, আবার ফাইলের ভেতর লিখতেও পারো।

**🤣 ফানি উদাহরণ:**
ছোটবেলায় বেঞ্চে কম্পাস দিয়ে নাম লিখতাম মনে আছে? Node.js দিয়ে আমরা হার্ডডিস্কের উপর নাম লিখবো। ধরো তুমি তোমার ক্রাশের জন্য একটা প্রেমপত্র (file) লিখবে কোড দিয়ে।

**💻 কোড:**
```javascript
const fs = require('fs');

// writeFileSync(ফাইলের নাম, কি লিখবে)
fs.writeFileSync('love-letter.txt', 'I love you Node.js! Tumi amar jaan!');

console.log("চিঠি লেখা শেষ মামা!");
```
*টার্মিনালে রান করো, দেখবে ফোল্ডারে `love-letter.txt` নামে একটা ফাইল তৈরি হয়ে গেছে! যাদু!*

#### 🎓 Lesson 2.3: File System (fs) - প্রেমপত্র পড়া (Read File)

**সহজ বাংলা:**
আগের লেসনে ফাইল বানালাম, এবার সেই ফাইলের ভেতর কি লেখা আছে সেটা কোড দিয়ে পড়বো।

**🤣 ফানি উদাহরণ:**
চিঠি তো লিখলে, এবার যদি রিপ্লাই আসে? সেটা তো পড়তে হবে! কিন্তু খাম না খুলে (মানে ফাইলে ডাবল ক্লিক না করে) কোড দিয়ে পড়বো।

**💻 কোড:**
```javascript
const fs = require('fs');

// readFileSync(ফাইলের নাম, এনকোডিং)
const letter = fs.readFileSync('love-letter.txt', 'utf-8');

console.log("চিঠিতে লেখা আছে: ", letter);
```
**মজার ব্যাখ্যা:**
`utf-8` না দিলে কম্পিউটার তোমাকে হাবিজাবি বাফার (Buffer) কোড দেখাবে, মানুষের ভাষা বুঝবে না। তাই `utf-8` হলো দোভাষী (Translator)।

#### 🎓 Lesson 2.4: Sync vs Async - লাইনে দাঁড়ানো বনাম টোকেন সিস্টেম

**সহজ বাংলা:**
এটা এই কোর্সের **সবচেয়ে গুরুত্বপূর্ণ** কনসেপ্ট।
*   **Sync (Synchronous):** এক কাজ শেষ না হওয়া পর্যন্ত পরের কাজ শুরু হবে না। (ব্লক করে রাখে)।
*   **Async (Asynchronous):** কাজ দিয়ে বলবে "হয়ে গেলে জানাস", আমি অন্য কাজ করি। (ব্লক করে না)।

**🤣 ফানি উদাহরণ:**
*   **Sync:** ব্যাংকের লাইনে দাঁড়িয়ে আছো। ক্যাশিয়ার কাজ শেষ না করা পর্যন্ত তুমি নড়তে পারবে না, পেছনেও কেউ কাজ করতে পারবে না। (বিরক্তিকর!)
*   **Async:** রেস্টুরেন্টে অর্ডার দিয়ে তুমি বসে মোবাইল টিপছো। খাবার রেডি হলে ওয়েটার ডেকে দিবে। তুমি বসে নেই, অন্য কাজ করছো। (স্মার্ট!)

**💻 কোড (Async Way):**
```javascript
const fs = require('fs');

console.log("1. অর্ডার দিলাম");

// readFile হলো Async, এটা সময় নিবে কিন্তু আটকাবে না
fs.readFile('love-letter.txt', 'utf-8', (err, data) => {
    console.log("2. চিঠি পড়া শেষ: " + data);
});

console.log("3. আমি অন্য কাজ করছি...");
```
**আউটপুট দেখবে:** আগে ১, তারপর ৩, শেষে ২ প্রিন্ট হবে। কারণ ৩ নম্বর লাইন অপেক্ষা করেনি!

#### 🎓 Lesson 2.5: Path Module - রাস্তা চিনিয়ে দেয়া

**সহজ বাংলা:**
উইন্ডোজ আর ম্যাক/লিনাক্সে ফোল্ডারের রাস্তা (Path) লেখার নিয়ম একটু আলাদা (স্ল্যাশ `/` বনাম ব্যাকস্ল্যাশ `\`)। `path` মডিউল এই ঝগড়া মিটিয়ে দেয়।

**🤣 ফানি উদাহরণ:**
রিকশাওয়ালাকে যদি বলো "বামে যান", সে বুঝবে। কিন্তু আমেরিকায় গিয়ে "বামে যান" বললে বুঝবে না, বলতে হবে "Turn Left"। `path` মডিউল হলো **Google Maps**, যে অটোমেটিক বুঝে নেয় এখন কোন দেশে (OS) আছে এবং সেই অনুযায়ী রাস্তা দেখায়।

**💻 কোড:**
```javascript
const path = require('path');

const fullPath = path.join(__dirname, "love-letter.txt");
console.log(fullPath); 
// এটা একদম পারফেক্ট লোকেশন দিবে, ভুল হওয়ার চান্স নাই।
```

#### 🎓 Lesson 2.6: OS Module - ডাক্তার চেকআপ

**সহজ বাংলা:**
তোমার কম্পিউটারের র‍্যাম কত, প্রসেসর কি, কতক্ষণ ধরে পিসি অন আছে—এসব জানার জন্য `os` মডিউল।

**🤣 ফানি উদাহরণ:**
এটা হলো পিসির **মেডিকেল রিপোর্ট**। ডাক্তার যেমন নাড়ি ধরে বলে দেয় শরীর কেমন, `os` মডিউল পিসির নাড়ি নক্ষত্র বলে দেয়।

**💻 কোড:**
```javascript
const os = require('os');

console.log("User Info:", os.userInfo());
console.log("Total Memory (RAM):", os.totalmem());
console.log("Free Memory:", os.freemem()); // কতটুকু খালি আছে
```

#### 🎓 Lesson 2.7: Events Module - কারেন্ট গেলে জেনারেটর

**সহজ বাংলা:**
Node.js এর অনেক কিছু **Event Driven**। মানে, "কিছু একটা ঘটলে, কিছু একটা করো"। একে বলে `EventEmitter`।

**🤣 ফানি উদাহরণ:**
তোমার বাসায় একটা **কলিং বেল** আছে।
*   Event: কেউ বেল চাপলো।
*   Listener: তুমি দরজা খুললে।
বেল না চাপলে তুমি দরজা খুলবে না।

**💻 কোড:**
```javascript
const EventEmitter = require('events');
const myEmitter = new EventEmitter();

// ইভেন্ট লিসেনার সেট করা (কান পেতে থাকা)
myEmitter.on('bellRing', () => {
    console.log("দরজা খুলছি মামা! দৌড় দিও না!");
});

// ইভেন্ট ফায়ার করা (বেল চাপ দেওয়া)
myEmitter.emit('bellRing');
```

#### 🎓 Lesson 2.8: HTTP Module - নিজের সার্ভার নিজে বানাই

**সহজ বাংলা:**
এখন আমরা সত্যিকারের একটা ওয়েব সার্ভার বানাবো। ব্রাউজারে `localhost` দিয়ে হিট করলে আমাদের সার্ভার রেসপন্স দিবে।

**🤣 ফানি উদাহরণ:**
এতদিন তুমি ছিলে কাস্টমার (Facebook চালাচ্ছো)। আজ তুমি নিজেই **দোকানদার**। তুমি সার্ভার খুলে বসে আছো, ব্রাউজার তোমার কাছে রিকোয়েস্ট পাঠাবে, তুমি রেসপন্স (মুড়ি-চানাচুর) দিবে।

**💻 কোড:**
```javascript
const http = require('http');

const server = http.createServer((req, res) => {
    if(req.url === '/') {
        res.write('Welcome to My Node Server Mama!');
        res.end();
    } else if (req.url === '/about') {
        res.write('Amra Gorib Coder!');
        res.end();
    } else {
        res.write('Kire bhai? Vul jaygay esechos!');
        res.end();
    }
});

server.listen(5000);
console.log('Server choltase port 5000 e...');
```
*ব্রাউজারে গিয়ে `localhost:5000` লেখো।*

#### 🎓 Lesson 2.9: Nodemon - অটো রিলোডের বস

**সহজ বাংলা:**
কোডে একটু চেঞ্জ করলেই বারবার সার্ভার স্টপ করে আবার `node index.js` লিখতে হয়। বিরক্তিকর না? `nodemon` ইনস্টল করলে সেভ করার সাথে সাথে অটো রিস্টার্ট হবে।

**🤣 ফানি উদাহরণ:**
তোমার একটা পার্সোনাল এসিস্ট্যান্ট আছে। তুমি জাস্ট বলবে "এইটা চেঞ্জ কর", সে দৌড় দিয়ে গিয়ে সার্ভার অফ করে আবার অন করে দিবে। তোমার কিচ্ছু করা লাগবে না। আরাম আর আরাম!

**💻 কাজ:**
১. টার্মিনালে: `npm install -g nodemon` (একবার করলেই হবে)।
২. এখন থেকে রান করবে: `nodemon index.js`।

#### 🎓 Lesson 2.10: Module 2 Project - সিম্পল API

**সহজ বাংলা:**
আমরা এখন টেক্সট না পাঠিয়ে, `JSON` ডাটা পাঠাবো। কারণ প্রফেশনাল লাইফে আমরা ডাটা নিয়েই কাজ করবো।

**🤣 ফানি উদাহরণ:**
রেস্টুরেন্টে গিয়ে কি শুধু ওয়েটারের মুখের কথা শুনলে হবে? মেনু কার্ড দেখতে হবে না? `JSON` হলো সেই মেনু কার্ড, যেখানে সুন্দর করে সব সাজানো থাকে।

**💻 কোড:**
```javascript
const http = require('http');

const server = http.createServer((req, res) => {
    if (req.url === '/courses') {
        const courses = [
            { id: 1, name: 'Node.js er Boss' },
            { id: 2, name: 'React er Ostad' }
        ];
        // ডাটা পাঠানোর নিয়ম
        res.writeHead(200, { 'Content-Type': 'application/json' }); 
        res.end(JSON.stringify(courses));
    } else {
        res.writeHead(404, { 'Content-Type': 'text/plain' });
        res.end("Kisu nai ekhane!");
    }
});

server.listen(5000);
console.log('API Server Running...');
```
*ব্রাউজারে `localhost:5000/courses` এ যাও, দেখবে জাদুর মতো ডাটা দেখাচ্ছে!*
