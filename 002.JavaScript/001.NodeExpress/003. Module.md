### 📦 Module 3: অ্যাসিঙ্ক্রোনাস জগত (Async Programming)

এই মডিউলে আমরা শিখবো কিভাবে কম্পিউটারকে বসিয়ে না রেখে একসাথে অনেক কাজ করানো যায়। Callback, Promise, আর Async/Await—এই তিন যাদুর কাঠি দিয়ে আমরা কোড কন্ট্রোল করবো।

#### 🎓 Lesson 3.1: Blocking vs Non-Blocking (আসল সমস্যাটা কি?)

**সহজ বাংলা:**
জাভাস্ক্রিপ্ট বাই ডিফল্ট **Synchronous**। মানে এক লাইন শেষ না হওয়া পর্যন্ত পরের লাইনে যায় না।
*   **Blocking:** একটা কাজ শেষ না হওয়া পর্যন্ত পুরো পৃথিবী থমকে থাকবে।
*   **Non-Blocking:** ভারী কাজটা ব্যাকগ্রাউন্ডে চলতে থাকবে, মেইন লাইন ক্লিয়ার থাকবে।

**🤣 ফানি উদাহরণ:**
*   **Blocking:** বাসে ওঠার সময় গেটে কেউ যদি বিশাল ব্যাগ নিয়ে আটকে যায়, পেছনের কেউ উঠতে পারে না। সবাই গালি দেয়।
*   **Non-Blocking:** সুপারশপে বিল দেয়ার সময় কারো কার্ড কাজ করছে না? ক্যাশিয়ার তাকে সাইডে অপেক্ষা করতে বলে পরের জনের বিল নেয়। স্মার্ট ক্যাশিয়ার!

**💻 কোড (সমস্যা):**
```javascript
console.log("১. ভাত রান্না বসালাম");
// ধরো এটা একটা বিশাল লুপ যা শেষ হতে ৫ সেকেন্ড লাগে (Blocking)
alert("২. ভাত রান্না হচ্ছে... (সব আটকে আছে)"); 
console.log("৩. খাওয়া শুরু করলাম");
```
*যতক্ষণ `alert` বা লুপ চলবে, ৩ নম্বর লাইন এক্সিকিউট হবে না।*

#### 🎓 Lesson 3.2: Callback Function - কাজের বুয়া সিস্টেম

**সহজ বাংলা:**
Callback মানে হলো একটা ফাংশনকে আরেকটা ফাংশনের ভেতরে প্যারামিটার হিসেবে পাঠানো। সোজা কথায়—"কাজটা শেষ হলে আমাকে এই নম্বরে কল দিও।"

**🤣 ফানি উদাহরণ:**
তুমি দর্জির দোকানে প্যান্ট বানাতে দিয়েছো। তুমি কি দোকানের সামনে ৩ দিন দাঁড়িয়ে থাকবে? না! তুমি দর্জিকে বলবে, **"মামা, প্যান্ট রেডি হলে আমাকে ফোন (Callback) দিয়েন, আমি এসে নিয়ে যাবো।"**

**💻 কোড:**
```javascript
function pantBanao(callback) {
    console.log("১. প্যান্টের মাপ নিচ্ছি...");
    
    // ২ সেকেন্ড সময় লাগবে প্যান্ট বানাতে (Async Simulate)
    setTimeout(() => {
        console.log("২. প্যান্ট রেডি!");
        callback(); // কাজ শেষে কল দিলাম
    }, 2000);
}

function deliveryNibo() {
    console.log("৩. প্যান্ট নিয়ে বাসায় যাচ্ছি!");
}

pantBanao(deliveryNibo);
```
**আউটপুট:** ১ প্রিন্ট হবে, ২ সেকেন্ড পর ২ আর ৩ প্রিন্ট হবে। মাঝের সময়টায় প্রোগ্রাম হ্যাং হয়ে ছিল না!

#### 🎓 Lesson 3.3: Callback Hell - প্যাঁচের মধ্যে প্যাঁচ

**সহজ বাংলা:**
একটা কলব্যাক এর ভেতর আরেকটা, তার ভেতর আরেকটা... এভাবে কোড লিখলে সেটা দেখতে পিরামিডের মতো হয়ে যায়। কোড পড়া অসম্ভব হয়ে পড়ে। একেই বলে **Callback Hell**।

**🤣 ফানি উদাহরণ:**
সরকারি অফিসের ফাইল পাশ করানোর মতো। পিয়ন বলে ক্লার্কের কাছে যান -> ক্লার্ক বলে বড়াবুর কাছে যান -> বড়বাবু বলে বসের কাছে যান। ঘুরতেই আছো, ঘুরতেই আছো!

**💻 কোড (ভয়ঙ্কর):**
```javascript
getUser(1, (user) => {
    getMarks(user.id, (marks) => {
        getGrade(marks, (grade) => {
            console.log(grade); // উফ! কত গভীরে!
        });
    });
});
```
*এটা মেইনটেইন করা আর বাঘের পিঠে চড়া সমান কথা।*

#### 🎓 Lesson 3.4: Promise - আমি কথা দিচ্ছি!

**সহজ বাংলা:**
Callback Hell থেকে বাঁচতে এলো **Promise**। Promise হলো একটা অবজেক্ট যা ভবিষ্যতে কোনো একটা রেজাল্ট দিবে।
এটার ৩টা অবস্থা থাকে:
১. **Pending:** কথা দিয়েছে, কিন্তু কাজ এখনো হয়নি।
২. **Resolved (Fulfilled):** কথা রেখেছে (Success)।
৩. **Rejected:** ছ্যাকা দিয়েছে (Error)।

**🤣 ফানি উদাহরণ:**
বন্ধুর কাছে টাকা ধার চেয়েছো। সে বললো "কালকে দিবো" (Promise)।
*   এখন তুমি আশায় আছো (Pending)।
*   কাল সে টাকা দিল (Resolved) -> তুমি বিরিয়ানি খাবে।
*   সে ফোন বন্ধ করে রাখল (Rejected) -> তুমি গালি দিবে।

**💻 কোড:**
```javascript
const promiseMama = new Promise((resolve, reject) => {
    let takaAse = true; // টাকা আছে কিনা
    
    if (takaAse) {
        resolve("নে দোস্ত টাকা!"); // কথা রেখেছে
    } else {
        reject("সরি দোস্ত, পকেটে ফুটো!"); // ছ্যাকা
    }
});
```

#### 🎓 Lesson 3.5: .then() এবং .catch() - প্রতিদান ও সান্ত্বনা

**সহজ বাংলা:**
Promise তো বানানো হলো, এবার সেটা ব্যবহার করবো কিভাবে?
*   কাজ সফল হলে `.then()` চলে।
*   এরর খেলে `.catch()` চলে।

**🤣 ফানি উদাহরণ:**
প্রেমিকার কাছে প্রপোজ করেছো (Promise)।
*   যদি "হ্যাঁ" বলে (.then) -> ডেটিং-এ যাবে।
*   যদি "না" বলে (.catch) -> দেবদাস হয়ে যাবে।

**💻 কোড:**
```javascript
promiseMama
    .then((result) => {
        console.log(result); // "নে দোস্ত টাকা!"
        console.log("চল বিরিয়ানি খাই!");
    })
    .catch((error) => {
        console.log(error); // "সরি দোস্ত..."
        console.log("ধুর! জীবনটাই বেদনা!");
    });
```

#### 🎓 Lesson 3.6: Async/Await - আধুনিক যাদু (Modern Magic)

**সহজ বাংলা:**
`.then()` `.catch()` চেইনিং করাও মাঝে মাঝে বিরক্তিকর লাগে। তাই ES6 এ এসেছে `Async/Await`। এটা দেখতে একদম Synchronous কোডের মতো, কিন্তু কাজ করে Asynchronous ভাবে।

**🤣 ফানি উদাহরণ:**
এটা হলো **টিভি রিমোটের পজ বাটন**। `await` দেখলে জাভাস্ক্রিপ্ট বলে, "ওকে, এই লাইনটা শেষ না হওয়া পর্যন্ত আমি এখানেই দাঁড়িয়ে থাকবো, তাড়াহুড়ো নাই।" কিন্তু সে মেইন থ্রেড আটকায় না, স্মার্টলি হ্যান্ডেল করে।

**💻 কোড:**
```javascript
async function dharNibo() {
    // await মানে অপেক্ষা করো যতক্ষণ না রেজাল্ট আসে
    const result = await promiseMama; 
    console.log(result);
    console.log("বিরিয়ানি খাওয়া শেষ!");
}

dharNibo();
```
*দেখো, কোনো `.then` নাই, কোড কত ক্লিন!*

#### 🎓 Lesson 3.7: Error Handling (Try/Catch) - সেফটি হেলমেট

**সহজ বাংলা:**
`Async/Await` ব্যবহারে যদি কোনো এরর হয় (Promise Reject হয়), তখন কোড ক্র্যাশ করতে পারে। তাই আমরা `try...catch` ব্লক ব্যবহার করি।

**🤣 ফানি উদাহরণ:**
বাইক চালানোর সময় হেলমেট পরা।
*   `try` ব্লকে তুমি স্বাভাবিকভাবে বাইক চালাচ্ছো।
*   যদি এক্সসিডেন্ট হয় (Error), `catch` ব্লক তোমাকে বাঁচিয়ে দিবে (হেলমেট), মাথা ফাটবে না।

**💻 কোড:**
```javascript
async function dharNiboSafe() {
    try {
        const result = await promiseMama;
        console.log("Success: " + result);
    } catch (error) {
        console.log("Error kheyechi: " + error);
    }
}
```

#### 🎓 Lesson 3.8: Node.js এ Promisify (Callback কে Promise বানানো)

**সহজ বাংলা:**
Node.js এর `fs.readFile` কিন্তু ডিফল্টভাবে কলব্যাক দিয়ে কাজ করে। এটাকে মডার্ন `Async/Await` দিয়ে ব্যবহার করতে চাইলে `util.promisify` বা `fs/promises` ব্যবহার করতে হয়।

**🤣 ফানি উদাহরণ:**
তোমার দাদা বাটন ফোন চালায় (Callback)। তুমি তাকে জোর করে স্মার্টফোন কিনে দিলে (Promisify) যাতে ভিডিও কল করা যায়।

**💻 কোড:**
```javascript
const fs = require('fs').promises; // মডার্ন ভার্সন

async function filePoro() {
    try {
        const data = await fs.readFile('love-letter.txt', 'utf-8');
        console.log("ফাইল পড়া শেষ: ", data);
    } catch (err) {
        console.log("ফাইল পাই নাই মামা!");
    }
}

filePoro();
```

#### 🎓 Lesson 3.9: Event Loop - নোড জেএস এর হার্টবিট

**সহজ বাংলা:**
ইন্টারভিউতে ১০০০% কমন প্রশ্ন। Node.js তো Single Threaded (একলা মানুষ), তাহলে সে হাজার হাজার রিকোয়েস্ট হ্যান্ডেল করে কিভাবে? উত্তর: **Event Loop**।

**🤣 ফানি উদাহরণ:**
**চায়ের দোকান:**
১. মামা (Call Stack) চা বানাচ্ছে।
২. একজন এসে বলল "পুরি ভাজেন"। মামা পুরিটা তেলের কড়াইয়ে দিয়ে দিল (Web API)।
৩. মামা কিন্তু দাঁড়িয়ে থাকলো না, সে আরেকজনকে চা দিচ্ছে।
৪. পুরি ভাজা হলে সহকারী (Callback Queue) বেল বাজিয়ে মামাকে বলল "পুরি রেডি"।
৫. মামা হাতের চা দেওয়া শেষ করে পুরিটা সার্ভ করলো।
এই যে চক্করটা, এটাই **Event Loop**।

**টেকনিক্যাল:** Stack খালি হলে Queue থেকে কাজ নিয়ে Stack এ দেয়।

#### 🎓 Lesson 3.10: Module Project - মাল্টিপল ফাইল রিডার

**সহজ বাংলা:**
আমরা এখন `Async/Await` দিয়ে সিরিয়ালি তিনটা ফাইল পড়বো। একটার পর একটা, সুন্দরভাবে।

**🤣 ফানি উদাহরণ:**
প্রেমিকার ৩টা চিঠি এসেছে। তুমি একটার পর একটা খুব মনোযোগ দিয়ে পড়ছো। ৩টা একসাথে খুললে তো জগাখিচুড়ি হয়ে যাবে!

**💻 কোড:**
প্রথমে ৩টা টেক্সট ফাইল বানাও: `file1.txt`, `file2.txt`, `file3.txt`।

```javascript
const fs = require('fs').promises;

async function readThreeFiles() {
    try {
        console.log("১ম ফাইল পড়ছি...");
        const data1 = await fs.readFile('file1.txt', 'utf-8');
        console.log(data1);

        console.log("২য় ফাইল পড়ছি...");
        const data2 = await fs.readFile('file2.txt', 'utf-8');
        console.log(data2);

        console.log("৩য় ফাইল পড়ছি...");
        const data3 = await fs.readFile('file3.txt', 'utf-8');
        console.log(data3);
        
        console.log("সব পড়া শেষ বস!");

    } catch (err) {
        console.log("কোথাও ঝামেলা হইছে: ", err);
    }
}

readThreeFiles();
```
