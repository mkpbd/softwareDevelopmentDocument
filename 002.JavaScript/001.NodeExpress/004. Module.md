### 📦 Module 4: Express.js এর শুরু (Express.js Basics)

এই মডিউলে আমরা Node.js এর সবচেয়ে জনপ্রিয় ফ্রেমওয়ার্ক **Express** এর সাথে পরিচিত হবো। এটা দিয়ে খুব সহজে এবং দ্রুত সার্ভার বানানো যায়।

#### 🎓 Lesson 4.1: Express.js কি এবং কেন?

**সহজ বাংলা:**
Node.js হলো ইঞ্জিন, আর Express.js হলো সেই ইঞ্জিনের ওপর বানানো সুন্দর একটা **গাড়ির বডি**।
তুমি চাইলে শুধু ইঞ্জিন দিয়েও গাড়ি চালাতে পারো (Raw Node.js), কিন্তু তাতে বসার সিট নাই, এসি নাই, অনেক কষ্ট। Express.js তোমাকে সেই আরামটা দেয়। এটা কোড অনেক কমিয়ে দেয়।

**🤣 ফানি উদাহরণ:**
*   **Raw Node.js:** বাজার থেকে আটা, ময়দা, চিনি, ডিম কিনে এনে নিজে কেক বানানো। (অনেক ঝামেলা)।
*   **Express.js:** দোকান থেকে "Cake Mix" কিনে আনা। জাস্ট পানি মিশিয়ে ওভেনে দিলেই কেক রেডি! (স্মার্ট লাইফ)।

**💻 কোড:**
কোনো কোড নাই, শুধু ফিলিংস নাও। Express হলো Node.js এর মেকআপ বক্স।

#### 🎓 Lesson 4.2: সেটআপ ও ইনস্টলেশন

**সহজ বাংলা:**
Express ব্যবহার করতে হলে এটাকে আমাদের প্রজেক্টে দাওয়াত দিতে হবে (Install করতে হবে)।

**🤣 ফানি উদাহরণ:**
বাসায় বিরিয়ানি রান্না হবে, কিন্তু বাবুর্চি নাই। তাই আমরা প্রফেশনাল বাবুর্চি (Express) ভাড়া করবো।

**💻 কাজ:**
১. একটা ফোল্ডার বানাও, টার্মিনালে `npm init -y` দাও (আগের মতো)।
২. এবার কমান্ড দাও:
```bash
npm install express
```
দেখবে `node_modules` ফোল্ডারে মেলা ফাইল চলে আসছে। ভয় পেও না, ওগুলো বাবুর্চির হাড়ি-পাতিল।

#### 🎓 Lesson 4.3: প্রথম Express সার্ভার (Hello World)

**সহজ বাংলা:**
মনে আছে মডিউল ২-এ সার্ভার বানাতে কত কোড লিখতে হয়েছিল? `if-else` দিয়ে রাউট চেক করতে হতো। এখন দেখো কত সহজে হয়।

**🤣 ফানি উদাহরণ:**
আগে চিঠি লিখতে হতো "বরাবর, প্রধান শিক্ষক..."। এখন জাস্ট হোয়াটসঅ্যাপে মেসেজ: "স্যার, আজ আসবো না"। কাজ শেষ!

**💻 কোড:**
`app.js` নামে ফাইল বানাও:
```javascript
const express = require('express');
const app = express(); // অ্যাপ তৈরি করলাম

// রাউট বা রাস্তা
app.get('/', (req, res) => {
  res.send('Hello World! Express is Joss!');
});

// সার্ভার স্টার্ট
app.listen(3000, () => {
  console.log('সার্ভার ৩০০০ পোর্টে দৌড়াচ্ছে...');
});
```
*টার্মিনালে রান করো `nodemon app.js` এবং ব্রাউজারে যাও `localhost:3000` এ।*

#### 🎓 Lesson 4.4: Routing - রাস্তার দিক নির্দেশনা

**সহজ বাংলা:**
রাউটিং মানে হলো ইউজার কোন লিঙ্কে গেলে কি দেখবে। `/about` এ গেলে এক জিনিস, `/contact` এ গেলে আরেক জিনিস।

**🤣 ফানি উদাহরণ:**
ঢাকায় বাসের হেল্পার যেমন চিল্লায়—"মামা গুলিস্তান!", "মামা ফার্মগেট!"।
প্যাসেঞ্জার যদি বলে "গুলিস্তান যাবো", হেল্পার তাকে গুলিস্তানের বাসে উঠাবে।
আমাদের কোডে `app.get('/location', ...)` হলো সেই হেল্পার।

**💻 কোড:**
```javascript
app.get('/home', (req, res) => {
    res.send("এটা আমার হোম পেজ মামা!");
});

app.get('/about', (req, res) => {
    res.send("আমি একজন জুনিয়র ডেভেলপার, কিন্তু স্বপ্ন বড়!");
});

app.get('*', (req, res) => {
    res.send("ভুল রাস্তায় এসেছিস বন্ধু! (404)");
});
```

#### 🎓 Lesson 4.5: Request (req) এবং Response (res)

**সহজ বাংলা:**
প্রতিটা রাউটে দুইটা জিনিস থাকে:
১. `req` (Request): কাস্টমার কি চায়? (সাথে কি কি ডাটা পাঠিয়েছে)।
২. `res` (Response): দোকানদার কি দিবে? (ডাটা বা পেজ ফেরত পাঠানো)।

**🤣 ফানি উদাহরণ:**
*   **Req:** তুমি দোকানে গিয়ে বললে "মামা, এক প্যাকেট চিপস আর একটা কোক দেন" (তোমার ডিমান্ড)।
*   **Res:** দোকানদার তোমাকে চিপস আর কোক হাতে দিল (তার রিপ্লাই)।

**💻 কোড:**
```javascript
app.get('/shop', (req, res) => {
    console.log("কাস্টমার এসেছে!"); // সার্ভারের কনসোলে দেখাবে
    res.send("নিন আপনার পণ্য!"); // ব্রাউজারে দেখাবে
});
```

#### 🎓 Lesson 4.6: HTTP Methods (GET, POST, PUT, DELETE)

**সহজ বাংলা:**
API এর দুনিয়ায় আমরা মূলত ৪টা কাজ করি (CRUD):
*   **GET:** ডাটা আনা (Create)।
*   **POST:** নতুন ডাটা পাঠানো (Read)।
*   **PUT/PATCH:** ডাটা আপডেট করা (Update)।
*   **DELETE:** ডাটা মুছে ফেলা (Delete)।

**🤣 ফানি উদাহরণ:**
ফেসবুকের কথা ভাবো:
*   **GET:** নিউজফিড দেখা।
*   **POST:** নতুন স্ট্যাটাস দেওয়া।
*   **PUT:** স্ট্যাটাস এডিট করা (বানান ভুল হলে)।
*   **DELETE:** পুরনো ক্রাশের ছবি ডিলিট করা।

**💻 কোড:**
(আপাতত আমরা কোডে শুধু `app.get` আর `app.post` বেশি ব্যবহার করবো)।

#### 🎓 Lesson 4.7: Postman - ডেভেলপারদের বন্ধু

**সহজ বাংলা:**
ব্রাউজারের এড্রেস বারে শুধু **GET** রিকোয়েস্ট পাঠানো যায়। **POST** বা ডাটা পাঠাতে হলে আমাদের একটা টুল লাগবে, তার নাম **Postman** (অথবা VS Code এর Thunder Client)।

**🤣 ফানি উদাহরণ:**
ব্রাউজার হলো শুধু জানালা দিয়ে উঁকি মারা (GET)। কিন্তু ঘরের ভেতর ফার্নিচার ঢুকাতে হলে (POST) দরজা দিয়ে আসতে হবে। Postman হলো সেই দরজা।

**💻 কাজ:**
১. Postman ডাউনলোড করে ইনস্টল করো।
২. সেখানে URL বারে `http://localhost:3000/` লিখে `GET` মেথড সিলেক্ট করে Send বাটন চাপো। দেখবে রেসপন্স আসছে।

#### 🎓 Lesson 4.8: Query Parameters - ছাঁকনি দিয়ে খোঁজা

**সহজ বাংলা:**
অনেক সময় আমরা লিঙ্কের সাথে এক্সট্রা তথ্য পাঠাই `?` চিহ্ন দিয়ে। যেমন: `youtube.com/watch?v=abcd`। এটাকে বলে Query Parameter।

**🤣 ফানি উদাহরণ:**
চায়ের দোকানে গিয়ে শুধু "চা দেন" বললে হবে না। বলতে হবে "চা দেন **?চিনি=কম&লিকার=বেশি**"। এই যে চিনি আর লিকারের কন্ডিশন দিলে, এটাই কুয়েরি।

**💻 কোড:**
```javascript
// URL হতে পারে: localhost:3000/search?name=pen&color=red

app.get('/search', (req, res) => {
    const { name, color } = req.query; // ডাটা ধরলাম
    res.send(`তুমি খুঁজছো: ${color} রঙের ${name}`);
});
```

#### 🎓 Lesson 4.9: Route Parameters - ডাইনামিক রুট

**সহজ বাংলা:**
ফেসবুকে সবার প্রোফাইল লিঙ্ক আলাদা হয়। `facebook.com/rahim`, `facebook.com/karim`। কোডে আমরা সবার জন্য আলাদা রাউট লিখবো না। আমরা একটা ভেরিয়েবল বা `Placeholder` ব্যবহার করবো। একে বলে Params।

**🤣 ফানি উদাহরণ:**
স্কুলে রোল কল করা। স্যার বলেন "রোল ১", "রোল ২"... স্যার কিন্তু ১০০০ জন ছাত্রের নাম মুখস্থ করে আসেন না। রোল নম্বরটা হলো ডাইনামিক।

**💻 কোড:**
```javascript
// :id মানে এখানে যা খুশি বসতে পারে
app.get('/users/:id', (req, res) => {
    const userId = req.params.id; // প্যারামিটার ধরলাম
    res.send(`এটা হলো ইউজার নম্বর: ${userId} এর প্রোফাইল`);
});
```
*ব্রাউজারে `localhost:3000/users/500` লিখে দেখো।*

#### 🎓 Lesson 4.10: Serving Static Files - শোরুম সাজানো

**সহজ বাংলা:**
আমাদের সার্ভারে কিছু ইমেজ, CSS ফাইল বা HTML ফাইল থাকতে পারে যা সবাই দেখতে পাবে। এগুলোকে বলে Static Files।

**🤣 ফানি উদাহরণ:**
দোকানের ভেতরের ক্যাশ বাক্স (Database) সবাই দেখতে পায় না। কিন্তু দোকানের সাইনবোর্ড, ডেকোরেশন, লাইটিং (Images, CSS) সবাই দেখে। এগুলো পাবলিক প্রপার্টি।

**💻 কোড:**
১. একটা ফোল্ডার বানাও `public` নামে। এর ভেতর একটা ছবি রাখো `logo.png`।
২. কোডে এই লাইনটা যোগ করো:
```javascript
app.use(express.static('public'));
```
৩. এখন ব্রাউজারে `localhost:3000/logo.png` দিলেই ছবিটা দেখা যাবে। কোনো রাউট লেখা ছাড়াই!
