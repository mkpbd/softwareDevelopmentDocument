### 📦 Module 6: মিডলওয়্যার - ট্রাফিক পুলিশ (Middleware)

এই মডিউলে আমরা শিখবো রিকোয়েস্ট আসার পর এবং রেসপন্স পাঠানোর আগে মাঝখানের সময়টাতে কিভাবে ছড়ি ঘোরাতে হয়।

#### 🎓 Lesson 6.1: Middleware আসলে কি?

**সহজ বাংলা:**
Middleware হলো এমন একটা ফাংশন, যা ক্লায়েন্ট (Browser) এবং সার্ভারের (Database/Response) ঠিক মাঝখানে বসে থাকে।
রিকোয়েস্ট সার্ভারে ঢোকার আগে মিডলওয়্যার সেটা চেক করে। যদি সব ঠিক থাকে, তবে যেতে দেয়। আর ঠিক না থাকলে ওখানেই আটকে দেয়।

**🤣 ফানি উদাহরণ:**
শপিং মলে ঢোকার সময় **সিকিউরিটি গার্ড** মামার কথা চিন্তা করো।
১. তুমি গেটে আসলে (Request)।
২. গার্ড মামা তোমাকে মেটাল ডিটেক্টর দিয়ে চেক করলো (Middleware Processing)।
৩. যদি পকেটে পিস্তল থাকে, সে বের করে দিবে (Error/Block)।
৪. যদি সব ঠিক থাকে, বলবে "যান স্যার, ভেতরে যান" (Next)।

**💻 কোড:**
কোড পরে, আগে কনসেপ্ট মাথায় ঢুকাও: `Request -> Middleware -> Response`

---

#### 🎓 Lesson 6.2: `next()` ফাংশন - চাবি কার কাছে?

**সহজ বাংলা:**
মিডলওয়্যার ফাংশনে ৩টা জিনিস থাকে: `req`, `res`, এবং `next`।
এই `next()` হলো জাদুর কাঠি। এটা কল না করলে রিকোয়েস্ট আজীবন লোডিং... দেখাবে, সার্ভার হ্যাং হয়ে থাকবে। `next()` মানে হলো: "আমার কাজ শেষ, পরের জনের কাছে যাও।"

**🤣 ফানি উদাহরণ:**
রিলে রেস (Relay Race) এর ব্যাটন বা লাঠি। দৌড়বিদ যদি লাঠি পরের জনকে পাস না করে পকেটে নিয়ে দাঁড়িয়ে থাকে, রেস কি শেষ হবে? হবে না! `next()` হলো সেই লাঠি পাস করা।

**💻 কোড:**
```javascript
const myMiddleware = (req, res, next) => {
    console.log("আমি মাঝখানে দাঁড়িয়ে আছি!");
    next(); // এইটা না দিলে ব্রাউজার ঘুরতেই থাকবে 😵‍💫
}
```

#### 🎓 Lesson 6.3: আমাদের প্রথম মিডলওয়্যার (Logger)

**সহজ বাংলা:**
আমরা এমন একটা মিডলওয়্যার বানাবো যেটা কনসোলে প্রিন্ট করবে কখন কোন লিঙ্কে হিট করা হয়েছে। একে বলে **Logger**।

**🤣 ফানি উদাহরণ:**
সিসি ক্যামেরা (CCTV)। বিল্ডিংয়ে কে কখন ঢুকলো, গার্ড রুমে বসে সেটা মনিটর করা। চোর আসুক আর পুলিশ আসুক, ক্যামেরায় সব রেকর্ড হবে।

**💻 কোড:**
```javascript
const express = require('express');
const app = express();

// মিডলওয়্যার বানালাম
const logger = (req, res, next) => {
    console.log(`${new Date().toLocaleString()} - হিট এসেছে: ${req.url}`);
    next(); // কাজ শেষ, এবার যাও
};

// অ্যাপে সেট করলাম (সবার জন্য প্রযোজ্য)
app.use(logger);

app.get('/', (req, res) => {
    res.send("হোম পেজ");
});

app.listen(3000);
```
*টার্মিনালে তাকাও, দেখবে সময় আর URL প্রিন্ট হচ্ছে।*

#### 🎓 Lesson 6.4: Application Level vs Route Level

**সহজ বাংলা:**
*   **Application Level:** `app.use(middleware)` - এটা দিলে প্রজেক্টের সব রাউটের জন্য এই মিডলওয়্যার কাজ করবে।
*   **Route Level:** নির্দিষ্ট কোনো রাউটের পেটে মিডলওয়্যার ঢুকিয়ে দেওয়া। শুধু ওই রাউটের জন্যই কাজ করবে।

**🤣 ফানি উদাহরণ:**
*   **App Level:** স্কুলের ইউনিফর্ম। সব ছাত্রকে পরতেই হবে।
*   **Route Level:** অ্যাপ্রন। শুধু যারা ল্যাবে ক্লাস করবে, তাদের পরতে হবে। সবাই অ্যাপ্রন পরে মাঠে ফুটবল খেলে না।

**💻 কোড:**
```javascript
const specialGuard = (req, res, next) => {
    console.log("VIP চেকিং চলছে...");
    next();
}

// এটা সবার জন্য
app.use(logger); 

// specialGuard শুধু '/vip' রাউটে কাজ করবে
app.get('/vip', specialGuard, (req, res) => {
    res.send("স্বাগতম ভিআইপি স্যার!");
});

app.get('/general', (req, res) => {
    res.send("আমজনতা!"); // এখানে specialGuard চেক করবে না
});
```

#### 🎓 Lesson 6.5: গরিবের অথেনটিকেশন (Blocking Request)

**সহজ বাংলা:**
আমরা একটা মিডলওয়্যার বানাবো যা চেক করবে ইউজারের কাছে "পাস" আছে কিনা। না থাকলে লাত্থি দিয়ে বের করে দিবে।

**🤣 ফানি উদাহরণ:**
সিনেমার টিকিট চেকার। টিকিট (Token) ছাড়া হলে ঢুকতে দিবে না। "মামা আমি এমপির ভাই" বললেও কাজ হবে না।

**💻 কোড:**
```javascript
const ticketChecker = (req, res, next) => {
    const { ticket } = req.query; // URL এ ?ticket=true খুঁজবো
    
    if (ticket === 'true') {
        next(); // টিকিট আছে, ভেতরে যান
    } else {
        res.status(403).send("টিকিট নাই? ভাগেন এখান থেকে!"); // গেট আউট
    }
};

app.get('/movie', ticketChecker, (req, res) => {
    res.send("🍿 সিনেমা শুরু! এনজয় করেন!");
});
```
*ব্রাউজারে `localhost:3000/movie` দিলে এরর খাবে। কিন্তু `localhost:3000/movie?ticket=true` দিলে ঢুকতে দিবে।*

#### 🎓 Lesson 6.6: Third-Party Middleware (Morgan)

**সহজ বাংলা:**
সব মিডলওয়্যার নিজের হাতে বানাতে হয় না। অন্যের বানানো জোস জোস মিডলওয়্যার আছে। যেমন: **Morgan** (লগিং করার জন্য)।

**🤣 ফানি উদাহরণ:**
বাসায় গার্ড না রেখে "Group 4 Security" এর লোক ভাড়া করা। তারা প্রফেশনাল, ইউনিফর্ম পরা, এবং কাজ ভালো জানে।

**💻 কাজ:**
১. `npm install morgan`
২. কোড:
```javascript
const morgan = require('morgan');
app.use(morgan('dev')); // কালারিং লগ দেখাবে
```
*এখন সার্ভারে হিট দিলে টার্মিনালে সুন্দর রঙিন লগ দেখতে পাবে।*

#### 🎓 Lesson 6.7: Built-in Middlewares (Recap)

**সহজ বাংলা:**
Express এর নিজেরও কিছু মিডলওয়্যার আছে যা আমরা আগেও ব্যবহার করেছি।
১. `express.json()` -> বডি পার্সার।
২. `express.static()` -> স্ট্যাটিক ফাইল সার্ভার।

**🤣 ফানি উদাহরণ:**
গাড়ি কিনলে সাথে টুলবক্স, চাকা খোলার রেঞ্চ ফ্রিতে দেয় না? ওগুলোই হলো Built-in Middleware. আলাদা কেনা লাগে না।

**💻 কোড:**
```javascript
app.use(express.json()); // ডাটা পড়ার চশমা
app.use(express.static('public')); // ফোল্ডার ওপেন করে দেওয়া
```

#### 🎓 Lesson 6.8: Error Handling Middleware - অ্যাম্বুলেন্স সার্ভিস

**সহজ বাংলা:**
কোডে যদি কোথাও এরর হয় বা ক্র্যাশ করে, তখন ডিফল্ট এরর পেজ দেখতে খুব বাজে লাগে। আমরা একটা স্পেশাল মিডলওয়্যার বানাবো যা সব এরর হ্যান্ডেল করবে। এটার ৪টা প্যারামিটার থাকে `(err, req, res, next)`।

**🤣 ফানি উদাহরণ:**
সার্কাসের ট্রাপিজ খেলা। উপরে দড়াবাজি করছে (Route)। যদি হাত ফসকে পড়ে যায়, নিচে জাল (Error Middleware) পাতা আছে। সে মরবে না, জালে আটকাবে।

**💻 কোড:**
(এই কোড সবার শেষে লিখতে হয়)
```javascript
// ইচ্ছা করে এরর খাওয়ালাম
app.get('/error', (req, res) => {
    throw new Error("হায় হায়! সার্ভার ক্র্যাশ!");
});

// এরর হ্যান্ডলার (নিচে জাল পাতা)
app.use((err, req, res, next) => {
    console.error(err.message);
    res.status(500).send("সার্ভারের জ্বর আসছে, একটু পরে আসেন!");
});
```

#### 🎓 Lesson 6.9: Chain of Responsibility - একের পর এক

**সহজ বাংলা:**
একই রাউটে একাধিক মিডলওয়্যার ব্যবহার করা যায়। একে বলে চেইনিং।

**🤣 ফানি উদাহরণ:**
বিমানবন্দরের সিকিউরিটি:
ধাপ ১: পাসপোর্ট চেক (Middleware 1) -> ধাপ ২: ব্যাগের ওজন চেক (Middleware 2) -> ধাপ ৩: বডি স্ক্যান (Middleware 3) -> বিমানে ওঠা (Final Response)। যেকোনো এক ধাপে ফেল করলেই বাড়ি পাঠিয়ে দিবে।

**💻 কোড:**
```javascript
const step1 = (req, res, next) => { console.log("১. পাসপোর্ট চেক"); next(); }
const step2 = (req, res, next) => { console.log("২. ব্যাগ চেক"); next(); }

app.get('/fly', step1, step2, (req, res) => {
    res.send("✈️ আপনি এখন আকাশে!");
});
```

#### 🎓 Lesson 6.10: Module 6 Project - অফিস আওয়ার ট্র্যাকার

**সহজ বাংলা:**
আমরা এমন একটা মিডলওয়্যার বানাবো, যেটা চেক করবে এখন অফিস টাইম (সকাল ১০টা - বিকাল ৫টা) কিনা। অফিস টাইম হলে সাইট ভিজিট করা যাবে, না হলে বলবে "অফিস বন্ধ"।

**🤣 ফানি উদাহরণ:**
সরকারি অফিস। বিকেল ৫টার পর গেলে পিয়ন বলবে—"স্যার চলে গেছে, কালকে আসেন।"

**💻 কোড:**
```javascript
const express = require('express');
const app = express();

const officeHourGuard = (req, res, next) => {
    const date = new Date();
    const hour = date.getHours(); // বর্তমান সময় (ঘন্টা)

    // যদি ১০টা থেকে ৫টার (১৭টা) মধ্যে হয়
    if (hour >= 10 && hour <= 17) {
        next(); // অফিস খোলা
    } else {
        res.send("⛔ অফিস বন্ধ! কাল সকাল ১০টায় আসেন।");
    }
};

app.use(officeHourGuard); // পুরো অ্যাপে তালা মেরে দিলাম

app.get('/', (req, res) => {
    res.send("🏢 ওয়েলকাম টু অফিস! কাজ করেন!");
});

app.listen(3000);
```
*তোমার পিসির টাইম চেঞ্জ করে টেস্ট করে দেখতে পারো!*
