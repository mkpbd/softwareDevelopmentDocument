### 📦 Module 7: ডেটাবেস কানেকশন (MongoDB/Mongoose)

এই মডিউলে আমরা শিখবো ডাটাবেস কি, কেন MongoDB ব্যবহার করবো এবং কিভাবে Node.js এর সাথে এটাকে কানেক্ট করে ডাটা আজীবনের জন্য সেভ করবো।

#### 🎓 Lesson 7.1: RAM vs Database - ভুলে যাওয়া রোগ

**সহজ বাংলা:**
*   **RAM (Temporary):** কোডের ভেরিয়েবল `let users = []` র‍্যামে থাকে। কম্পিউটার বন্ধ করলে র‍্যাম খালি হয়ে যায়।
*   **Database (Permanent):** এটা হার্ডডিস্ক বা ক্লাউডে সেভ থাকে। ১০ বছর পর পিসি অন করলেও ডাটা ওখানেই থাকবে।

**🤣 ফানি উদাহরণ:**
*   **RAM:** ক্লাসের পড়া। স্যার যতক্ষণ ক্লাসে আছেন, ততক্ষণ মনে থাকে। স্যার গেলেই সব ভোঁ দৌড়!
*   **Database:** প্রেমিকার জন্মদিনের তারিখ। ভুললে কপালে শনি আছে, তাই এটা ব্রেইনের পার্মানেন্ট মেমোরিতে সেভ করে রাখতে হয়।

**💻 কোড:**
(কনসেপ্ট লিসেন, কোড নাই)।

#### 🎓 Lesson 7.2: SQL vs NoSQL - এক্সেল শিট বনাম বস্তা

**সহজ বাংলা:**
ডাটাবেস দুই ধরনের হয়:
১. **SQL (MySQL/PostgreSQL):** টেবিল সিস্টেমে ডাটা রাখে। সব নিয়ম মেনে চলতে হয়।
২. **NoSQL (MongoDB):** ডকুমেন্ট সিস্টেমে ডাটা রাখে। একটু এদিক-সেদিক হলে সমস্যা নাই। আমরা শিখবো **MongoDB** (NoSQL)।

**🤣 ফানি উদাহরণ:**
*   **SQL:** ঔষধের দোকান। সব ঔষধ তাকে তাকে সাজানো। নাপা'র বক্সে গ্যাস্ট্রিকের ঔষধ রাখা যাবে না। (কড়াকড়ি)।
*   **NoSQL:** ব্যাচেলর মেসের রুম। এক ড্রয়ারে মোজা, বিস্কুট, আর চার্জার একসাথে রাখা যায়। ফ্লেক্সিবল! JSON ডাটা যেমন, MongoDB দেখতে হুবহু তেমন।

#### 🎓 Lesson 7.3: MongoDB Atlas - আকাশের উপর ডাটাবেস

**সহজ বাংলা:**
MongoDB আমরা পিসিতে ইনস্টল করতে পারি, কিন্তু সেটা ঝামেলার। আমরা ব্যবহার করবো **MongoDB Atlas**। এটা ক্লাউড (ইন্টারনেটে) থাকে। গুগল ড্রাইভের মতো।

**🤣 ফানি উদাহরণ:**
টাকা মাটির ব্যাংকে (Local PC) না রেখে সুইস ব্যাংকে (Cloud) রাখা। চোর ডাকার ভয় নাই, হার্ডডিস্ক নষ্ট হওয়ার ভয় নাই।

**💻 কাজ:**
১. [mongodb.com](https://www.mongodb.com/) এ গিয়ে ফ্রি একাউন্ট খুলো।
২. একটা `Cluster` (ফ্রি) তৈরি করো।
৩. `Database Access` এ গিয়ে ইউজারনেম আর পাসওয়ার্ড সেট করো।
৪. `Network Access` এ গিয়ে `Allow Access from Anywhere` (IP 0.0.0.0/0) করে দাও।
৫. `Connection String` টা কপি করে রাখো (দেখতে এমন: `mongodb+srv://...`).

#### 🎓 Lesson 7.4: Mongoose - ঘটক পাখি ভাই

**সহজ বাংলা:**
Node.js এবং MongoDB এর ভাষা আলাদা। তারা সরাসরি একে অপরের সাথে কথা বলতে পারে না। তাদের মিল করিয়ে দেয় **Mongoose**। একে বলে ODM (Object Data Modeling)।

**🤣 ফানি উদাহরণ:**
Node.js হলো জাপানি, আর MongoDB হলো রাশিয়ান। মাঝখানে **Mongoose** হলো দোভাষী (Translator) বা ঘটক। সে Node.js এর কথা MongoDB কে বুঝিয়ে দেয়।

**💻 ইনস্টল:**
টার্মিনালে লেখো:
```bash
npm install mongoose
```

#### 🎓 Lesson 7.5: কানেকশন স্থাপন - হ্যালো ডাটাবেস!

**সহজ বাংলা:**
এবার আমরা আমাদের Express অ্যাপের সাথে MongoDB কানেক্ট করবো।

**🤣 ফানি উদাহরণ:**
মোবাইল চার্জে দেওয়া। চার্জার প্লাগ (Connection String) সকেটে না ঢুকালে যেমন চার্জ হয় না, কানেক্ট না করলে ডাটা সেভ হবে না।

**💻 কোড:**
`db.js` বা মেইন ফাইলে:
```javascript
const mongoose = require('mongoose');

// তোমার কানেকশন স্ট্রিং (পাসওয়ার্ড সাবধানে বসাবে)
const mongoURI = "mongodb+srv://user:password@cluster0.mongodb.net/myDatabase";

const connectDB = async () => {
    try {
        await mongoose.connect(mongoURI);
        console.log("🎉 ডাটাবেস কানেক্টেড মামা!");
    } catch (err) {
        console.error("❌ কানেকশন ফেইল:", err);
        process.exit(1);
    }
};

connectDB();
```

#### 🎓 Lesson 7.6: Schema & Model - পিঠার ছাঁচ

**সহজ বাংলা:**
MongoDB ফ্লেক্সিবল হলেও আমরা কিছু নিয়ম ঠিক করে দিবো। যেমন: ইউজার এর নাম থাকতেই হবে, ইমেইল থাকতেই হবে। এই নিয়ম বা ম্যাপকে বলে **Schema**। আর এই স্কিমা দিয়ে যা তৈরি হয় তাকে বলে **Model**।

**🤣 ফানি উদাহরণ:**
পিঠা বানানোর ছাঁচ (Saaj)। ছাঁচ যেমন হবে (Schema), পিঠা দেখতে তেমনই হবে (Model)। ছাঁচ গোল হলে পিঠা গোল, ছাঁচ চারকোনা হলে পিঠা চারকোনা।

**💻 কোড:**
`models/User.js` নামে ফাইল বানাও:
```javascript
const mongoose = require('mongoose');

// স্কিমা বা নকশা তৈরি
const userSchema = new mongoose.Schema({
    name: {
        type: String,
        required: true // নাম দিতেই হবে, মাফ নাই
    },
    email: {
        type: String,
        required: true,
        unique: true // এক ইমেইল দুইবার চলবে না
    },
    age: Number,
    isMarried: Boolean
});

// মডেল তৈরি (এটা দিয়েই আমরা ডাটাবেসে কাজ করবো)
const User = mongoose.model('User', userSchema);

module.exports = User;
```

#### 🎓 Lesson 7.7: Create Data - নাম এন্ট্রি করা

**সহজ বাংলা:**
এখন আমরা API এর মাধ্যমে ডাটাবেসে নতুন ইউজার সেভ করবো। `User.create()` বা `.save()` দিয়ে এটা করা যায়।

**🤣 ফানি উদাহরণ:**
জমির দলিলে নাম রেজিস্ট্রি করা। একবার লেখা হয়ে গেলে সেটা পাকা দলিল।

**💻 কোড:**
`index.js` ফাইলে:
```javascript
const User = require('./models/User'); // মডেলটা ইম্পোর্ট করলাম

app.post('/register', async (req, res) => {
    try {
        const { name, email, age } = req.body;

        // নতুন ইউজার বানালাম
        const newUser = new User({ name, email, age, isMarried: false });
        
        // ডাটাবেসে সেভ করলাম (Async কাজ)
        await newUser.save();

        res.status(201).json({ message: "সেভ হয়ে গেছে বস!", newUser });
    } catch (error) {
        res.status(500).json({ error: "সেভ করতে পারলাম না!", details: error.message });
    }
});
```

#### 🎓 Lesson 7.8: Read Data - খুঁজে বের করা

**সহজ বাংলা:**
ডাটাবেস থেকে ডাটা পড়ার জন্য `find` (সবাইকে আনো) অথবা `findOne` (একজনকে আনো) ব্যবহার করা হয়।

**🤣 ফানি উদাহরণ:**
*   `User.find()`: ক্লাসের সব ছাত্রকে ডাক দেওয়া।
*   `User.findOne({name: 'Rahim'})`: ভিড়ের মধ্যে থেকে রহিমকে খুঁজে বের করা।

**💻 কোড:**
```javascript
// সব ইউজার দেখাও
app.get('/users', async (req, res) => {
    const users = await User.find(); // জাদুর মতো সব নিয়ে আসবে
    res.json(users);
});

// নির্দিষ্ট কাউকে খোঁজা
app.get('/user/:email', async (req, res) => {
    const user = await User.findOne({ email: req.params.email });
    if(user) {
        res.json(user);
    } else {
        res.status(404).send("এই লোককে পাওয়া গেল না!");
    }
});
```

#### 🎓 Lesson 7.9: Update & Delete - কাটাকাটি

**সহজ বাংলা:**
*   `findByIdAndUpdate`: আইডি ধরে আপডেট করা।
*   `findByIdAndDelete`: আইডি ধরে ডিলিট করা।

**🤣 ফানি উদাহরণ:**
*   **Update:** প্লাস্টিক সার্জারি করে চেহারা (Data) পাল্টে ফেলা।
*   **Delete:** বাসা থেকে পুরোনো ফার্নিচার ফেলে দেওয়া।

**💻 কোড:**
```javascript
// আপডেট
app.put('/user/:id', async (req, res) => {
    // {new: true} দিলে আপডেটের পরের ডাটা দেখাবে
    const updatedUser = await User.findByIdAndUpdate(req.params.id, req.body, { new: true });
    res.json(updatedUser);
});

// ডিলিট
app.delete('/user/:id', async (req, res) => {
    await User.findByIdAndDelete(req.params.id);
    res.send("ডাটাবেস থেকে ডিলিট করে দিয়েছি!");
});
```
