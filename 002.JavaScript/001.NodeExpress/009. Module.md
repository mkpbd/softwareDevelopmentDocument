### 📦 Module 9: প্রফেশনাল API ডেভেলপমেন্ট (Advanced API Structure)

এই মডিউলে আমরা শিখবো **MVC Pattern** (Model-View-Controller), ফোল্ডার স্ট্রাকচার সাজানো, ইনপুট ভ্যালিডেশন, এবং বড় প্রজেক্ট হ্যান্ডেল করার টেকনিক।

#### 🎓 Lesson 9.1: জগাখিচুড়ি কোড vs MVC আর্কিটেকচার

**সহজ বাংলা:**
এতদিন আমরা সব কোড (Database connection, Route, Logic) একটা ফাইল `index.js` বা `app.js` এ লিখেছি। এটাকে বলে **Spaghetti Code** (নুডলসের মতো প্যাঁচানো)।
প্রফেশনালরা কোড ভাগ করে রাখে ৩ ভাগে: **M-V-C**।
*   **M (Model):** ডাটাবেসের সাথে কথা বলে (Schema)।
*   **V (View):** ইউজার যা দেখে (React/JSON Response)।
*   **C (Controller):** মেইন লজিক বা ব্রেইন।

**🤣 ফানি উদাহরণ:**
রেস্টুরেন্টের কথা ভাবো:
*   **Model:** রান্নাঘর ও স্টোররুম (যেখানে কাঁচামাল/ডাটা থাকে)।
*   **Controller:** ওয়েটার (যে তোমার অর্ডার নিয়ে কিচেনে যায়, আবার খাবার এনে দেয়)।
*   **View:** সুন্দর সাজানো খাবারের প্লেট (যা তুমি টেবিলে পাও)।
সবাই সবার কাজ আলাদা করে করে। ওয়েটার রান্না করে না, রাঁধুনি অর্ডার নেয় না।

#### 🎓 Lesson 9.2: ফোল্ডার স্ট্রাকচার - আলমারি গোছানো

**সহজ বাংলা:**
এখন আমরা প্রজেক্ট ফোল্ডারটা সুন্দর করে সাজাবো।

**🤣 ফানি উদাহরণ:**
বাসায় মেহমান আসলে যেমন ড্রয়িং রুম পরিষ্কার করো, আর ময়লা সব খাটের নিচে ঢুকাও—এখানে আমরা সেটা করবো না! আমরা সব আলাদা ড্রয়ারে (Folder) রাখবো।

**💻 কাজ:**
প্রজেক্ট ফোল্ডারে এই ফোল্ডারগুলো বানাও:
1.  `/config` (ডাটাবেস কানেকশন)
2.  `/models` (ডাটাবেস স্কিমা)
3.  `/controllers` (কাজের লজিক)
4.  `/routes` (রাস্তা বা API URL)
5.  `/middleware` (গার্ড মামা)

#### 🎓 Lesson 9.3: Config & Models - ভিত্তি প্রস্তর

**সহজ বাংলা:**
ডাটাবেস কানেকশন `index.js` থেকে সরিয়ে `config/db.js` এ নিবো। আর মডেল তো আগেই `models` ফোল্ডারে ছিল।

**💻 কোড:**
`config/db.js`:
```javascript
const mongoose = require('mongoose');
const connectDB = async () => {
   // ... আগের কানেকশন কোড ...
   console.log("DB Connected from Config Folder!");
}
module.exports = connectDB;
```
*এখন `index.js` বা `server.js` অনেক ক্লিন হয়ে যাবে!*

#### 🎓 Lesson 9.4: Controllers - বাবুর্চি এবং ম্যানেজার

**সহজ বাংলা:**
এতদিন আমরা রাউটের ভেতরেই ফাংশন লিখতাম: `app.get('/user', (req, res) => {...})`।
এখন ওই `(req, res)` ওয়ালা ফাংশনটা কেটে `controllers` ফোল্ডারে নিয়ে যাবো। রাউট শুধু কন্ট্রোলারকে কল করবে।

**🤣 ফানি উদাহরণ:**
বিয়ের বাড়িতে বাড়ির মালিক (Route) গেটে দাঁড়িয়ে থাকে। মেহমান আসলে সে বলে "ভেতরে যান"। ভেতরে খাওয়ার দায়িত্বে থাকে ক্যাটারিং সার্ভিস (Controller)। মালিক নিজে ভাত বেড়ে দেয় না।

**💻 কোড:**
`controllers/userController.js`:
```javascript
const User = require('../models/User');

// লজিক সব এখানে
const getAllUsers = async (req, res) => {
    try {
        const users = await User.find();
        res.status(200).json(users);
    } catch (error) {
        res.status(500).json({ error: "Server Error" });
    }
};

module.exports = { getAllUsers };
```

#### 🎓 Lesson 9.5: Express Router - ট্রাফিক সাইন

**সহজ বাংলা:**
`app.get`, `app.post`—এগুলো মেইন ফাইলে রাখবো না। `routes` ফোল্ডারে আলাদা ফাইলে রাখবো। এজন্য `express.Router()` ব্যবহার করতে হয়।

**🤣 ফানি উদাহরণ:**
হাসপাতালে গেলে দেখবে—"ENT Department বামে", "Cardiology ডানে"। সব ডাক্তার রিসিপশনে বসে থাকে না। ডিপার্টমেন্ট আলাদা।

**💻 কোড:**
`routes/userRoutes.js`:
```javascript
const express = require('express');
const router = express.Router();
const { getAllUsers } = require('../controllers/userController'); // কন্ট্রোলার ইম্পোর্ট

// রাউট ডিফাইন করা
router.get('/', getAllUsers); // '/users' এর পর '/' মানে মেইন

module.exports = router;
```

**💻 মেইন ফাইল (server.js):**
```javascript
const userRoutes = require('./routes/userRoutes');
app.use('/api/users', userRoutes); // এই লাইনেই সব কানেক্ট হলো
```

#### 🎓 Lesson 9.6: Input Validation (Joi Library) - এয়ারপোর্ট চেকিং

**সহজ বাংলা:**
ইউজার যা খুশি তা ডাটা পাঠাতে পারে। ইমেইলের জায়গায় ফোন নম্বর, বয়সের জায়গায় নাম। ডাটাবেসে ঢোকানোর আগেই এগুলো চেক করতে হবে। আমরা `Joi` লাইব্রেরি ব্যবহার করবো।

**🤣 ফানি উদাহরণ:**
এয়ারপোর্টে ইমিগ্রেশন অফিসার। পাসপোর্টে ভিসা ঠিক আছে? মেয়াদ আছে? চেহারা মিলছে? সব ঠিক থাকলে তবেই বিমানে (Controller) উঠতে দিবে।

**💻 কাজ:**
`npm install joi`

**💻 কোড:**
`middleware/validate.js` (বা কন্ট্রোলারের ভেতরে):
```javascript
const Joi = require('joi');

const registerSchema = Joi.object({
    name: Joi.string().min(3).required(),
    email: Joi.string().email().required(),
    password: Joi.string().min(6).required()
});

// ব্যবহার (কন্ট্রোলারের শুরুতে)
const { error } = registerSchema.validate(req.body);
if (error) return res.status(400).send(error.details[0].message);
```

#### 🎓 Lesson 9.7: Pagination - অল্প অল্প করে খাও

**সহজ বাংলা:**
তোমার ডাটাবেসে ১০,০০০ ইউজার আছে। কেউ `/users` এ হিট করলে তুমি কি ১০,০০০ ডাটাই একসাথে পাঠাবে? সার্ভার ক্র্যাশ করবে! আমরা ১০টা বা ২০টা করে ডাটা পাঠাবো। একে বলে **Pagination**।

**🤣 ফানি উদাহরণ:**
বিয়ে বাড়িতে তোমাকে এক ডেকচি বিরিয়ানি একসাথে দেওয়া হয় না। প্লেটে অল্প অল্প করে দেওয়া হয়। খাওয়া শেষ হলে আবার নাও।

**💻 কোড:**
```javascript
// কন্ট্রোলারের ভেতরে
const getUsers = async (req, res) => {
    const page = parseInt(req.query.page) || 1; // কত নম্বর পৃষ্ঠা
    const limit = parseInt(req.query.limit) || 10; // কয়টা দেখাবে
    const skip = (page - 1) * limit; // কয়টা বাদ দিয়ে শুরু করবে

    const users = await User.find().skip(skip).limit(limit);
    res.json(users);
}
```
*URL হবে: `/users?page=2&limit=5`*

#### 🎓 Lesson 9.8: CORS (Cross-Origin Resource Sharing) - বর্ডার গার্ড

**সহজ বাংলা:**
তোমার ব্যাকএন্ড চলছে `localhost:5000` এ, আর ফ্রন্টএন্ড (React) চলছে `localhost:3000` এ। ব্রাউজার সিকিউরিটির কারণে এক পোর্ট থেকে অন্য পোর্টে ডাটা নিতে দেয় না। একে বলে CORS Error। এটা ফিক্স করতে হবে।

**🤣 ফানি উদাহরণ:**
বাংলাদেশ থেকে ভারতে যেতে হলে ভিসা লাগে। `cors` প্যাকেজ হলো সেই ভিসা, যা বলে দেয়—"হ্যাঁ, ওই ওয়েবসাইটকে আমার ডাটা নিতে দিও।"

**💻 কাজ:**
`npm install cors`

**💻 কোড (server.js):**
```javascript
const cors = require('cors');
app.use(cors()); // সবার জন্য দরজা খোলা (বা নির্দিষ্ট ডোমেইন সেট করা যায়)
```

#### 🎓 Lesson 9.9: Try-Catch সরানো (Async Handler)

**সহজ বাংলা:**
প্রতিটা কন্ট্রোলারে বারবার `try-catch` লিখতে লিখতে হাত ব্যথা হয়ে যায়। আমরা একটা র‍্যাপার ফাংশন (Wrapper Function) ব্যবহার করবো যা অটোমেটিক এরর ধরবে। `express-async-handler` খুব কাজের।

**🤣 ফানি উদাহরণ:**
বৃষ্টির দিনে বারবার ছাতা খোলা আর বন্ধ করা বিরক্তিকর। তার চেয়ে রেইনকোট পরে নাও, ঝামেলা শেষ।

**💻 কাজ:**
`npm install express-async-handler`

**💻 কোড:**
```javascript
const asyncHandler = require('express-async-handler');

const getAllUsers = asyncHandler(async (req, res) => {
    const users = await User.find(); // try-catch লাগবে না
    res.json(users);
});
// এরর হলে সে অটোমেটিক এরর মিডলওয়্যারে পাঠিয়ে দিবে
```
