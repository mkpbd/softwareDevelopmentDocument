# 🚀 Module 2: Functions & Intermediate JS

### 📖 Lesson 1: Arrow Functions (স্মার্ট ফাংশন)

**🎯 Learning Goal:** মডার্ন উপায়ে ছোট করে ফাংশন লেখা শেখা।

**🗣️ সহজ ব্যাখ্যা:**
আগে আমরা `function` কিওয়ার্ড দিয়ে বড় করে ফাংশন লিখতাম। এখন যুগ পাল্টেছে, এখন আমরা "তীর" (Arrow) `=>` মেরে ফাংশন বানাবো। কাজ একই, দেখতে স্মার্ট।

**🤣 Real-life Analogy:**
- **Normal Function:** হাতে চিঠি লেখা (সময় লাগে)।
- **Arrow Function:** হোয়াটসঅ্যাপে ভয়েস মেসেজ পাঠানো (চটজলদি)।

**💻 Code Example:**
```javascript
// Old Way (Backdated)
function addOld(a, b) {
    return a + b;
}

// New Way (Arrow Function)
const addNew = (a, b) => a + b; 
// এক লাইনে হলে return বা {} লাগে না!

console.log(addNew(10, 20)); // 30
```

**💪 Mini Exercise:**
1. একটা Arrow Function বানাও যা ইনপুট হিসেবে একটা সংখ্যা নেবে এবং তার দ্বিগুণ (double) রিটার্ন করবে।

**⚠️ Common Mistakes:**
- এক লাইনের বেশি কোড থাকলে `{}` ব্র্যাকেট এবং `return` দিতে ভুলে যাওয়া।

**📝 One-line Summary:**
ছোটখাটো ফাংশন লেখার জন্য `=>` বা অ্যারো ফাংশন বেস্ট।

**🏢 Real Project Importance:**
React বা আধুনিক সব ফ্রেমওয়ার্ক-এ ৯৯% সময় অ্যারো ফাংশন ব্যবহার করা হয়।

### 📖 Lesson 2: Default Parameters (ব্যাকআপ প্ল্যান)

**🎯 Learning Goal:** ফাংশনে ইনপুট না দিলে কী হবে, তা ঠিক করে রাখা।

**🗣️ সহজ ব্যাখ্যা:**
ধরো ফাংশনে ইনপুট চাওয়ার কথা, কিন্তু ইউজার দিল না। তখন যাতে কোড ক্র্যাশ না করে, তাই আমরা একটা "ডিফল্ট" মান সেট করে রাখি।

**🤣 Real-life Analogy:**
বিয়ে বাড়িতে গেস্ট আসলে বিরিয়ানি দেওয়ার কথা। যদি বিরিয়ানি শেষ হয়ে যায়?
**Backup:** সাদা ভাত আর ডাল রেডি রাখা। কেউ না খেয়ে ফিরবে না!

**💻 Code Example:**
```javascript
function welcomeGuest(name = "Unknown Person") {
    console.log(`Hello, ${name}! Welcome.`);
}

welcomeGuest("Rahim"); // আউটপুট: Hello, Rahim! Welcome.
welcomeGuest();        // আউটপুট: Hello, Unknown Person! Welcome.
```

**💪 Mini Exercise:**
1. `calculateTax` নামে ফাংশন বানাও। যদি ইনপুট না দেয়, তবে ট্যাক্স `0` ধরবে।

**⚠️ Common Mistakes:**
- ডিফল্ট ভ্যালু সেট না করলে রেজাল্ট `undefined` চলে আসে, যা দেখতে খারাপ।

**📝 One-line Summary:**
ফাংশনে `parameter = value` দিয়ে রাখলে ইনপুট মিস হলেও সমস্যা নেই।

**🏢 Real Project Importance:**
ইউজার প্রোফাইল পিকচার আপলোড না করলে একটা ডিফল্ট "ফাঁকা মানুষ" আইকন দেখানোর জন্য এটা লাগে।

### 📖 Lesson 3: Spread Operator (ছড়িয়ে দেওয়া)

**🎯 Learning Goal:** অ্যারে বা অবজেক্টকে ভেঙে ছড়িয়ে দেওয়া (`...`)।

**🗣️ সহজ ব্যাখ্যা:**
একটা বস্তার ভেতর অনেকগুলো আলু আছে। তুমি বস্তাটা উপুড় করে সব আলু মেঝেতে ছড়িয়ে দিলে। এটাই স্প্রেড অপারেটর। ব্র্যাকেট `[]` সরিয়ে এলিমেন্টগুলোকে মুক্ত করে দেয়।

**🤣 Real-life Analogy:**
তোমার প্লেটে ভাত আছে, বন্ধুর প্লেটে মাংস আছে। দুইটা এক প্লেটে মাখানো হলো **Spread Operator**।

**💻 Code Example:**
```javascript
const poorBondhu = ["Dal", "Bhat"];
const richBondhu = ["Kacchi", "Borhani"];

// দুই বন্ধুর খাবার এক করলাম
const partyMenu = [...poorBondhu, ...richBondhu];

console.log(partyMenu); 
// ["Dal", "Bhat", "Kacchi", "Borhani"]
```

**💪 Mini Exercise:**
1. দুটি আলাদা সংখ্যার অ্যারে বানাও, তারপর তৃতীয় একটি অ্যারেতে সেগুলোকে মার্জ (একত্র) করো।

**⚠️ Common Mistakes:**
- `...` (তিনটা ডট) এর বদলে দুইটা বা চারটা ডট দেওয়া।

**📝 One-line Summary:**
তিনটা ডট `...` দিয়ে অ্যারে কপি বা মার্জ করা সবচেয়ে সহজ।

**🏢 Real Project Importance:**
পুরানো ডেটার সাথে নতুন ডেটা যোগ করতে (যেমন: ফেসবুকের লোড মোড পোস্ট) এটা খুব লাগে।

### 📖 Lesson 4: Rest Parameter (সবাইকে এক বস্তায় ভরা)

**🎯 Learning Goal:** অগণিত ইনপুটকে একটা অ্যারেতে নেওয়া।

**🗣️ সহজ ব্যাখ্যা:**
Spread এর উল্টো কাজ। ফাংশনে তুমি জানো না কয়টা ইনপুট আসবে—২টা নাকি ২০টা। `...` দিলে সব ইনপুট একটা অ্যারে হয়ে যাবে।

**🤣 Real-life Analogy:**
লোকাল বাস। ২ জন সিটে বসবে, বাকি যতজন আসবে সব "উইড়া লন" (ছিঁড়ে নেওয়া নয়, গাদাগাদি করে নেওয়া)। সব যাত্রী মিলে একটা গ্রুপ।

**💻 Code Example:**
```javascript
// যত খুশি সংখ্যা দাও, সব যোগ করবে
function jogging(...numbers) {
    let sum = 0;
    for(let num of numbers) {
        sum += num;
    }
    return sum;
}

console.log(jogging(10, 20, 30, 40)); // 100
```

**💪 Mini Exercise:**
1. এমন একটা ফাংশন বানাও যেটা অনেকগুলো বন্ধুর নাম নেবে এবং বলবে "Welcome [সবার নাম]"।

**⚠️ Common Mistakes:**
- Rest parameter ফাংশনের **শেষে** না দিয়ে শুরুতে দেওয়া। এটা সবসময় লাস্টে বসবে।

**📝 One-line Summary:**
ফাংশনে আনলিমিটেড আর্গুমেন্ট হ্যান্ডেল করতে `...args` ব্যবহার করো।

### 📖 Lesson 5: Destructuring (ভেঙে বের করা)

**🎯 Learning Goal:** অবজেক্ট বা অ্যারে থেকে ভ্যালু সহজে বের করে আনা।

**🗣️ সহজ ব্যাখ্যা:**
আগে অবজেক্ট থেকে ভ্যালু বের করতে বারবার `person.name`, `person.age` লিখতে হতো। এখন আমরা প্যাকেট ছিঁড়ে সরাসরি জিনিস বের করে নেবো।

**🤣 Real-life Analogy:**
চিপসের প্যাকেট থেকে একটা একটা করে চিপস না বের করে, প্যাকেট ছিঁড়ে সব বাটিতে ঢেলে নেওয়া। এখন সরাসরি খাওয়া যাবে।

**💻 Code Example:**
```javascript
const user = {
    id: 101,
    name: "Sakib",
    age: 24,
    wife: "Nei"
};

// Old way
// const name = user.name;

// Smart way (Destructuring)
const { name, age } = user; 

console.log(name); // Sakib
console.log(age);  // 24
```

**💪 Mini Exercise:**
1. একটা `address` অবজেক্ট বানাও (village, post, district)। সেখান থেকে `district` বের করে প্রিন্ট করো।

**⚠️ Common Mistakes:**
- অবজেক্টের প্রপার্টির নামের সাথে ভেরিয়েবলের নাম না মেলালে কাজ করবে না।

**📝 One-line Summary:**
`const { x } = object`—এভাবে লিখলে কোড অনেক ক্লিন হয়।

**🏢 Real Project Importance:**
API থেকে আসা বড় ডেটা থেকে শুধু প্রয়োজনীয় তথ্যগুলো বের করে নিতে এটা মাস্ট লাগে।

### 📖 Lesson 6: Callback Functions (কল ব্যাক করো)

**🎯 Learning Goal:** একটা ফাংশনকে অন্য ফাংশনের ভেতরে পাঠানো।

**🗣️ সহজ ব্যাখ্যা:**
জাভাস্ক্রিপ্টে ফাংশন হলো ফার্স্ট ক্লাস সিটিজেন। মানে, ফাংশনকে তুমি নাম্বারের মতোই অন্য ফাংশনে পাঠাতে পারো।
"কাজ শেষ হলে আমাকে জানাবে"—এটাই কলব্যাক।

**🤣 Real-life Analogy:**
মাকে বললাম, "ভাত রান্না হলে আমাকে ডাক দিও"।
এখানে:
- **কাজ:** ভাত রান্না।
- **কলব্যাক:** ডাক দেওয়া।

**💻 Code Example:**
```javascript
function mainKaj(kajerNam, callback) {
    console.log(`${kajerNam} shuru korlam...`);
    
    // কিছুক্ষণ পর...
    console.log(`${kajerNam} shesh!`);
    callback(); // এই যে কলব্যাক কল হলো
}

function poreKiKorbo() {
    console.log("Ebar goon goon kore gaan gai!");
}

mainKaj("Gari dhoya", poreKiKorbo);
```

**💪 Mini Exercise:**
1. `processUser` নামে ফাংশন বানাও, কাজ শেষ হলে `greetUser` নামে আরেকটা ফাংশন কল করবে।

**⚠️ Common Mistakes:**
- কলব্যাক পাস করার সময় ব্র্যাকেট দেওয়া `callback()`। শুধু নাম পাঠাতে হয় `callback`।

**📝 One-line Summary:**
এক কাজের পর আরেক কাজ অটোমেটিক শুরু করতে কলব্যাক লাগে।

**🏢 Real Project Importance:**
বাটন ক্লিক করলে কী হবে, সার্ভার থেকে ডেটা আসলে কী হবে—সব কলব্যাক দিয়ে হয়।

### 📖 Lesson 7: Higher-Order Functions (বস লেভেল)

**🎯 Learning Goal:** হায়ার অর্ডার ফাংশন কী তা বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
যে ফাংশন অন্য ফাংশনকে ইনপুট হিসেবে নেয় অথবা আউটপুট হিসেবে ফাংশন রিটার্ন করে, সে হলো **Higher-Order Function**। মানে ফাংশনদের বস।

**🤣 Real-life Analogy:**
**ম্যানেজার।** ম্যানেজার নিজে কোদাল চালায় না, সে লেবারদের (অন্য ফাংশন) দিয়ে কাজ করায়।

**💻 Code Example:**
```javascript
// এটা একটা Higher-Order Function
function operation(num1, num2, specificFunction) {
    return specificFunction(num1, num2);
}

const jog = (a, b) => a + b;
const biyog = (a, b) => a - b;

console.log(operation(10, 5, jog));   // 15
console.log(operation(10, 5, biyog)); // 5
```

**💪 Mini Exercise:**
1. উপরের উদাহরণের মতো `gun` (গুণ) করার ফাংশন বানিয়ে `operation` দিয়ে কল করো।

**📝 One-line Summary:**
ফাংশন যখন অন্য ফাংশনকে কন্ট্রোল করে, সেটাই হায়ার অর্ডার ফাংশন।

### 📖 Lesson 8: IIFE (গোপন এজেন্ট)

**🎯 Learning Goal:** Immediately Invoked Function Expression বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
এমন ফাংশন যেটা তৈরি হওয়ার সাথে সাথেই নিজেকে কল করে দেয়। একবার কাজ করেই গায়েব হয়ে যায়।

**🤣 Real-life Analogy:**
**নাপা ট্যাবলেটের প্যাকেট।** ছিঁড়লেন (তৈরি করলেন), খেলেন (কল করলেন), প্যাকেট ফেলে দিলেন (গায়েব)।

**💻 Code Example:**
```javascript
(function() {
    console.log("Ami create howar sathe sathei run hoyechi!");
    let secret = "Top Secret Code";
})();

// console.log(secret); // ❌ Error! বাইরে থেকে ধরা যাবে না।
```

**💪 Mini Exercise:**
1. একটা IIFE বানাও যা কনসোলে "Setup Complete" প্রিন্ট করবে।

**📝 One-line Summary:**
কোডকে প্রাইভেট রাখতে এবং গ্লোবাল স্কোপ নোংরা না করতে IIFE ব্যবহার হয়।

### 📖 Lesson 9: Closures (পুরানো স্মৃতি)

**🎯 Learning Goal:** ক্লোজার (Closure) এর কনসেপ্ট ক্লিয়ার করা।

**🗣️ সহজ ব্যাখ্যা:**
একটা ফাংশন যখন আরেকটা ফাংশনের ভেতরে থাকে, ভেতরের ফাংশনটা বাইরের ফাংশনের ভেরিয়েবলগুলো মনে রাখতে পারে। বাইরের ফাংশন মরে গেলেও (কাজ শেষ হলেও) ভেতরেরটা স্মৃতি আগলে রাখে।

**🤣 Real-life Analogy:**
তুমি বিদেশ চলে গেছো (ফাংশন রিটার্ন হয়েছে), কিন্তু মায়ের হাতের রান্নার স্বাদ (ভেরিয়েবল) তোমার মনে আছে। তুমি যেখানেই যাও, এই স্মৃতি (Closure) তোমার সাথে যায়।

**💻 Code Example:**
```javascript
function bankAccount(initialBalance) {
    let balance = initialBalance; // এটা মেমোরিতে থেকে যাবে
    
    return function() {
        balance += 100; // বাইরের balance কে অ্যাক্সেস করছে
        return balance;
    }
}

const myAccount = bankAccount(500);
console.log(myAccount()); // 600
console.log(myAccount()); // 700 (আগের 600 মনে রেখেছে!)
```

**💪 Mini Exercise:**
1. কোডটা কপি করে চালাও এবং বোঝার চেষ্টা করো `balance` কেন রিসেট হচ্ছে না।

**📝 One-line Summary:**
ফাংশন তার জন্মের পরিবেশ (Scope) মনে রাখে, এটাই ক্লোজার।

**🏢 Real Project Importance:**
প্রাইভেট ভেরিয়েবল তৈরি করতে এবং মেমোরি এফিশিয়েন্ট কোড লিখতে ক্লোজার লাগে।

### 📖 Lesson 10: Recursion (আয়নার ভেতরে আয়না)

**🎯 Learning Goal:** রিকারশন বা নিজেকেই কল করা ফাংশন শেখা।

**🗣️ সহজ ব্যাখ্যা:**
ফাংশন যখন নিজেই নিজেকে কল করে, তাকে রিকারশন বলে। তবে থামার জন্য একটা শর্ত (Stop Condition) দিতে হয়, নাহলে অনন্তকাল চলতে থাকবে।

**🤣 Real-life Analogy:**
সেলুনের দোকানে দুই দিকে আয়না থাকলে যেমন নিজের ছবি অসীম পর্যন্ত দেখা যায়।
অথবা, পেঁয়াজের খোসা ছড়ানো—একটার পর একটা খোসা, যতক্ষণ না শেষ হয়।

**💻 Code Example:**
```javascript
// ১ থেকে n পর্যন্ত যোগফল (যেমন: 5+4+3+2+1)
function sumUp(n) {
    if (n === 1) { // Stop Condition (থামার পয়েন্ট)
        return 1;
    }
    return n + sumUp(n - 1); // নিজেকেই আবার কল করছে
}

console.log(sumUp(5)); // 15
```

**💪 Mini Exercise:**
1. রিকারশন ব্যবহার করে ৫ থেকে ১ পর্যন্ত উল্টো করে সংখ্যা প্রিন্ট করো।

**⚠️ Common Mistakes:**
- থামার শর্ত (Base Case) না দিলে ব্রাউজার ক্র্যাশ করবে (Stack Overflow)।

**📝 One-line Summary:**
বড় সমস্যাকে ছোট ছোট একই রকম ভাগে ভাগ করে সমাধান করাই রিকারশন।
