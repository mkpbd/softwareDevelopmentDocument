## 🟢 Module 1: Admin & CRUD Basics (শুরুটা হোক সহজ)

### Lesson 1: Admin Commands (`show dbs`, `use`, `db`)
**আলোচনা:** ডেটাবেস জগতে ঢোকার চাবি। কোন ডেটাবেস দেখব, কোনটা ব্যবহার করব।
**মজার উদাহরণ:** রেস্টুরেন্টে গিয়ে মেনু কার্ড দেখা (`show dbs`), তারপর ওয়েটারকে বলা "মামা, বিরিয়ানিটাই খাব" (`use biryaniDB`)।
**Code:**
```javascript
show dbs
use myShop
db.dropDatabase() // খাবার পচা হলে ফেলে দেওয়া
```

### Lesson 2: Insert One (`insertOne`)
**আলোচনা:** একটা সিঙ্গেল ডেটা বা ডকুমেন্ট এন্ট্রি দেওয়া।
**মজার উদাহরণ:** বাসে একজন যাত্রীকে সিট দেওয়া।
**Code:**
```javascript
db.users.insertOne({ name: "Rahim", age: 25 })
```
**ব্যাখ্যা:** `users` বাসে রহিম নামের একজনকে তুলে নিলাম।

### Lesson 3: Insert Many (`insertMany`)
**আলোচনা:** একসাথে অনেকগুলো ডেটা ঢোকানো।
**মজার উদাহরণ:** ঈদের সময় লোকাল বাসে "ধাক্কায়া" একসাথে ১০ জন যাত্রী তোলা। 🚌
**Code:**
```javascript
db.users.insertMany([{ name: "Karim" }, { name: "Jabbar" }])
```
**ব্যাখ্যা:** করিম আর জব্বারকে একসাথে এন্ট্রি দিলাম।

### Lesson 4: Basic Read (`find`, `findOne`, `pretty`)
**আলোচনা:** ডেটা খুঁজে দেখা। সব দেখব নাকি একটা দেখব?
**মজার উদাহরণ:** ক্লাসের সব ছাত্রকে দাঁড় করানো (`find`), অথবা শুধু ফার্স্ট বয়কে ডাকা (`findOne`)।
**Code:**
```javascript
db.users.find().pretty()
```
**ব্যাখ্যা:** সব ইউজারকে সুন্দর করে (pretty) দেখাও।

### Lesson 5: Counting (`countDocuments`, `estimatedDocumentCount`)
**আলোচনা:** মোট কয়টা ডেটা আছে গণা।
**মজার উদাহরণ:** পকেটে কয় টাকা আছে সেটা গণা। হুবহু গণা (`countDocuments`) vs চোখের আন্দাজে বলা (`estimated...`)। 💵
**Code:**
```javascript
db.users.countDocuments({ age: 25 })
```
**ব্যাখ্যা:** ২৫ বছর বয়সী কয়জন আছে গুণে বলো।

## 🟢 Module 2: Comparison & Logical Operators (খোঁজ দ্য সার্চ)

### Lesson 6: Comparison Operators (`$eq`, `$ne`, `$gt`, `$lt`)
**আলোচনা:** সমান, অসমান, বড়, ছোট দিয়ে খোঁজা।
**মজার উদাহরণ:** বিয়ের জন্য পাত্রী খোঁজা—বয়স ২৫ এর কম (`$lt`) হতে হবে, হাইট ৫ ফিটের বেশি (`$gt`) হতে হবে। 👰
**Code:**
```javascript
db.products.find({ price: { $gt: 500, $lt: 1000 } })
```
**ব্যাখ্যা:** দাম ৫০০-র বেশি কিন্তু ১০০০-এর কম।

### Lesson 7: Range Operators (`$in`, `$nin`)
**আলোচনা:** নির্দিষ্ট কয়েকটা ভ্যালুর মধ্যে মিললে আনা।
**মজার উদাহরণ:** বাজারে গিয়ে বলা—"মামা, রুই, কাতল অথবা ইলিশ—এই তিনটার যেকোনো একটা দেন।" (`$in`)। 🐟
**Code:**
```javascript
db.users.find({ city: { $in: ["Dhaka", "Chittagong"] } })
```
**ব্যাখ্যা:** যারা ঢাকা অথবা চট্টগ্রামে থাকে।

### Lesson 8: Logical Operators (`$and`, `$or`)
**আলোচনা:** একাধিক শর্ত যোগ করা।
**মজার উদাহরণ:**
*   `$and`: ছেলে সরকারি চাকরি করে **এবং** দেখতে সুন্দর (দুইটাই লাগবে)।
*   `$or`: খিচুড়ি রান্না করো **অথবা** বিরিয়ানি আনো (যেকোনো একটা হলেই হবে)।
**Code:**
```javascript
db.users.find({ $or: [{ age: 20 }, { city: "Dhaka" }] })
```

### Lesson 9: Element Operators (`$exists`, `$type`)
**আলোচনা:** কোনো ফিল্ড আদৌ আছে কিনা চেক করা।
**মজার উদাহরণ:** সিভিতে "অভিজ্ঞতা" সেকশন আছে কিনা চেক করা (`$exists`)।
**Code:**
```javascript
db.users.find({ phone: { $exists: true } })
```
**ব্যাখ্যা:** যাদের ফোন নম্বর ফিল্ডটা ডেটাবেসে আছে শুধু তাদের আনো।

### Lesson 10: Evaluation (`$regex`)
**আলোচনা:** প্যাটার্ন দিয়ে খোঁজা (SQL-এর LIKE)।
**মজার উদাহরণ:** ফোনে কন্টাক্ট খোঁজা—"Rah" লিখলেই Rahim, Rahat সব চলে আসে। 🔍
**Code:**
```javascript
db.users.find({ name: { $regex: "Rah", $options: "i" } })
```
**ব্যাখ্যা:** নামের মধ্যে 'Rah' থাকলেই হবে, ছোট/বড় হাতের অক্ষর ম্যাটার না (`i`)।

## 🟢 Module 3: Update Operators (ঘষামাজা)

### Lesson 11: Set & Unset (`$set`, `$unset`)
**আলোচনা:** নতুন তথ্য বসানো বা পুরনো তথ্য মুছে ফেলা।
**মজার উদাহরণ:**
*   `$set`: বউ সাজানো (মেকআপ লাগানো)। 💅
*   `$unset`: মেকআপ তোলা (ফিল্ড ডিলিট করা)।
**Code:**
```javascript
db.users.updateOne({ name: "Rahim" }, { $set: { city: "Sylhet" } })
```

### Lesson 12: Numeric Updates (`$inc`)
**আলোচনা:** মান বাড়ানো বা কমানো।
**মজার উদাহরণ:** ক্রিকেট স্কোরের সাথে ১ রান যোগ করা। অথবা কারো বয়স ১ বছর বাড়ানো। 🏏
**Code:**
```javascript
db.products.updateOne({ name: "Rice" }, { $inc: { stock: -5 } })
```
**ব্যাখ্যা:** ৫ কেজি চাল বিক্রি হয়েছে, তাই স্টক থেকে ৫ কমালাম।

### Lesson 13: Array Push (`$push`, `$addToSet`)
**আলোচনা:** লিস্টের মধ্যে নতুন আইটেম ঢোকানো।
**মজার উদাহরণ:**
*   `$push`: শপিং লিস্টে বারবার "আলু" লেখা (ডুপ্লিকেট হয়)।
*   `$addToSet`: মেম্বার লিস্টে নাম লেখা (একবার লিখলে আর লেখা যাবে না, ডুপ্লিকেট হয় না)। 📝
**Code:**
```javascript
db.posts.updateOne({ id: 1 }, { $addToSet: { tags: "coding" } })
```

### Lesson 14: Array Pull (`$pull`, `$pop`)
**আলোচনা:** লিস্ট থেকে আইটেম বের করে দেওয়া।
**মজার উদাহরণ:** তরকারি থেকে এলাচ বেছে ফেলে দেওয়া (`$pull`)। 🍛
**Code:**
```javascript
db.users.updateOne({ name: "Rahim" }, { $pull: { hobbies: "Sleeping" } })
```
**ব্যাখ্যা:** রহিমের শখ থেকে "ঘুম" বাদ দিলাম (সে এখন সিরিয়াস)।

### Lesson 15: Rename & Current Date (`$rename`, `$currentDate`)
**আলোচনা:** ফিল্ডের নাম পাল্টানো।
**মজার উদাহরণ:** "দোকান বাকি" খাতার নাম পাল্টে "কাস্টমার লোন" রাখা। একটু স্মার্ট ভাব! 😎
**Code:**
```javascript
db.users.updateMany({}, { $rename: { "mobile": "phone" } })
```

## 🟢 Module 4: Delete & Advanced Read (সাফাই অভিযান)

### Lesson 16: Delete (`deleteOne`, `deleteMany`)
**আলোচনা:** ডেটা পার্মানেন্টলি ডিলিট করা।
**মজার উদাহরণ:** মোবাইলের গ্যালারি থেকে আজেবাজে ছবি ডিলিট করা। 🗑️
**Code:**
```javascript
db.spam.deleteMany({})
```
**ব্যাখ্যা:** সব স্প্যাম একসাথে ডিলিট!

### Lesson 17: FindOneAnd... (`findOneAndUpdate`, `findOneAndDelete`)
**আলোচনা:** খুঁজে পাওয়া এবং একই সাথে আপডেট/ডিলিট করা।
**মজার উদাহরণ:** দোকানদার টাকা নেওয়ার সময় একই সাথে ক্যাশবাক্সে টাকা রাখে এবং খাতায় লিখে রাখে। (Atomic Operation)।
**Code:**
```javascript
db.orders.findOneAndDelete({ status: "cancelled" })
```

### Lesson 18: Projection (0 & 1)
**আলোচনা:** সব ফিল্ড না এনে শুধু দরকারিগুলো আনা।
**মজার উদাহরণ:** কলা ছিলে শুধু ভেতরটা খাওয়া, খোসা (`0`) ফেলে দেওয়া। 🍌
**Code:**
```javascript
db.users.find({}, { name: 1, password: 0 })
```
**ব্যাখ্যা:** নাম দেখাও (1), পাসওয়ার্ড দেখিও না (0)।

### Lesson 19: Array Query (`$elemMatch`, `$size`)
**আলোচনা:** অ্যারের ভেতরের অবজেক্ট ফিল্টার করা।
**মজার উদাহরণ:** বিরিয়ানির হাড়ির ভেতর থেকে শুধু "লেগ পিস" ওয়ালা প্লেট খোঁজা (`$elemMatch`)। 🍗
**Code:**
```javascript
db.students.find({ scores: { $elemMatch: { subject: "Math", marks: { $gt: 80 } } } })
```
**ব্যাখ্যা:** ওই ছাত্রকে আনো যে ম্যাথে ৮০-র বেশি পেয়েছে।

### Lesson 20: Slice (`$slice`)
**আলোচনা:** অ্যারের কিছু অংশ দেখা।
**মজার উদাহরণ:** ফেসবুক কমেন্টের শুধু প্রথম ৫টা দেখা।
**Code:**
```javascript
db.posts.find({}, { comments: { $slice: 5 } })
```

## 🟢 Module 5: Aggregation Framework (Level: Pro)

### Lesson 21: Match & Group (`$match`, `$group`)
**আলোচনা:** ডেটা ফিল্টার করে গ্রুপ বানানো।
**মজার উদাহরণ:** প্রথমে বেছে পচা আম বাদ দেওয়া (`$match`), তারপর ভালো আমগুলো ঝুড়িতে সাইজ অনুযায়ী ভাগ করা (`$group`)। 🥭
**Code:**
```javascript
db.sales.aggregate([
  { $match: { status: "sold" } },
  { $group: { _id: "$product", total: { $sum: "$amount" } } }
])
```

### Lesson 22: Project & AddFields (`$project`, `$addFields`)
**আলোচনা:** ফিল্ড সাজানো বা নতুন ফিল্ড টেম্পোরারি যোগ করা।
**মজার উদাহরণ:** পরীক্ষার রেজাল্ট শিটে "Total Marks" নামে নতুন কলাম যোগ করা (`$addFields`)। 📝

### Lesson 23: Unwind (`$unwind`)
**আলোচনা:** অ্যারে ভেঙে আলাদা আলাদা ডকুমেন্ট বানানো।
**মজার উদাহরণ:** তাসের প্যাকেট (`Array`) খুলে ৫২টা তাস টেবিলে ছড়িয়ে দেওয়া (প্রত্যেকটা আলাদা)। 🃏
**Code:**
```javascript
db.orders.aggregate([{ $unwind: "$items" }])
```

### Lesson 24: Lookup (`$lookup`) - The JOIN
**আলোচনা:** অন্য কালেকশন থেকে ডেটা এনে জোড়া লাগানো।
**মজার উদাহরণ:** তোমার রেজাল্ট কার্ডে "বাবার নাম" আছে, কিন্তু বাবার ডিটেইলস জানতে বাবার আইডি কার্ড (`Another Collection`) চেক করা।
**Code:**
```javascript
{
  $lookup: {
    from: "customers",
    localField: "customerId",
    foreignField: "_id",
    as: "customerDetails"
  }
}
```

### Lesson 25: Sort, Limit, Skip (`$sort`, `$limit`)
**আলোচনা:** এগ্রিগেশনের শেষে ডেটা সাজানো।
**মজার উদাহরণ:** মিছিলের সামনে নেতাদের রাখা (`Sort`), আর পেছনের আমজনতাকে বাদ দেওয়া (`Limit`)। 🗣️

## 🟢 Module 6: Advanced Tools & Indexing (ফিনিশিং টাচ)

### Lesson 26: String Operators (`$concat`, `$toUpper`, `$substr`)
**আলোচনা:** লেখা জোড়া লাগানো বা বড় হাতের করা।
**মজার উদাহরণ:** ফার্স্ট নেম "Abul" আর লাস্ট নেম "Mia" জোড়া লাগিয়ে "Abul Mia" বানানো (`$concat`)।

### Lesson 27: Arithmetic Operators (`$multiply`, `$divide`, `$sum`)
**আলোচনা:** যোগ, বিয়োগ, গুণ, ভাগ।
**মজার উদাহরণ:** পণ্যের দাম * কোয়ান্টিটি = মোট দাম বের করা। ✖️
**Code:**
```javascript
{ $project: { totalCost: { $multiply: ["$price", "$quantity"] } } }
```

### Lesson 28: Indexes (`createIndex`, `Single`, `Compound`)
**আলোচনা:** সার্চ ফাস্ট করা।
**মজার উদাহরণ:** বইয়ের পেছনে ইনডেক্স পেজ। "Compound Index" হলো ডিকশনারি—প্রথমে A দিয়ে খোঁজা, তারপর Aa, Ab... এভাবে। 📖
**Code:**
```javascript
db.users.createIndex({ email: 1 }, { unique: true })
```
**ব্যাখ্যা:** ইমেইল ইউনিক হতে হবে, ডুপ্লিকেট চলবে না।

### Lesson 29: TTL & Text Index (Special Indexes)
**আলোচনা:**
*   **TTL:** নির্দিষ্ট সময় পর ডেটা অটো ডিলিট (OTP কোডের মতো)। ⏱️
*   **Text:** গুগলের মতো সার্চ।
**Code:**
```javascript
db.sessions.createIndex({ "createdAt": 1 }, { expireAfterSeconds: 3600 })
```

### Lesson 30: Out & Merge (`$out`, `$merge`)
**আলোচনা:** এগ্রিগেশনের রেজাল্ট নতুন কালেকশনে সেভ করা।
**মজার উদাহরণ:** রান্নাবান্না শেষ করে খাবার হটপটে বেড়ে রাখা (নতুন জায়গায় সেভ করা)। 🍲
**Code:**
```javascript
{ $out: "daily_report" }
```
