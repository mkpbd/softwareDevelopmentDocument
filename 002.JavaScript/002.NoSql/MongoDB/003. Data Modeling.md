## 📘 Lesson 1: ObjectId & Null (পরিচয়পত্র আর ফাঁকা পকেট)

**🗣️ সহজ আলোচনা:**
মামা, দুনিয়ায় যেমন সবার একটা আলাদা চেহারা বা ফিঙ্গারপ্রিন্ট থাকে, MongoDB-তে প্রতিটা ডকুমেন্টের একটা ইউনিক আইডি থাকে। এটাকে বলে `ObjectId`। তুমি যদি আইডি না দাও, মংগো মামা নিজ দায়িত্বে একটা আইডি বসিয়ে দেবে।
আর `null` হলো এমন একটা অবস্থা, যেখানে ফিল্ড আছে কিন্তু ভ্যালু নাই। জিরো (0) আর নাল (null) কিন্তু এক না!

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **ObjectId:** এটা হলো তোমার **NID কার্ড**। সারাদেশ খুঁজলে তোমার নম্বরের সাথে মিলবে এমন দ্বিতীয় কার্ড পাবে না।
*   **Null:** এটা হলো মাসের শেষে তোমার **মানিব্যাগ**। মানিব্যাগটা পকেটে আছে (Field Exists), কিন্তু ভেতরে টাকা নাই (Value is Null)। 💸

**💻 Code Example:**
```javascript
db.users.insertOne({
  _id: ObjectId("507f1f77bcf86cd799439011"), // অটো তৈরি হয়, ম্যানুয়ালিও দেওয়া যায়
  name: "Rahim",
  bonus: null  // বেচারা বোনাস পায় নাই
})
```

**🔍 ব্যাখ্যা:**
এখানে `_id` হলো রহিমের ইউনিক পরিচয়। আর `bonus: null` মানে হলো বোনাসের ঘর আছে, কিন্তু ভেতরে কিছু নাই।

## 📘 Lesson 2: String, Boolean, Int, Double (নাম, কাম, আর দাম)

**🗣️ সহজ আলোচনা:**
ডেটাবেসে আমরা কী কী রাখি? কারো নাম (Text/String), বয়স (Number/Int), বেতন (Decimal/Double), আবার কেউ বিবাহিত কি না (True/False)। এগুলোই হলো বেসিক BSON টাইপ।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **String:** দোকানের সাইনবোর্ড। "মায়ের দোয়া স্টোর" (লেখা)।
*   **Boolean:** বিদ্যুতের সুইচ। হয় **ON** (True), নাহয় **OFF** (False)। অথবা তোমার রিলেশনশিপ স্ট্যাটাস (মিঙ্গেলড? হঁ/না)।
*   **Int (Integer):** তোমার বয়স। ২৬ বছর (পূর্ণ সংখ্যা)। সাড়ে ২৬ বছর কেউ বলে না।
*   **Double:** ব্যাংকের হিসাব। ১০ টাকা ৫০ পয়সা (দশমিক সংখ্যা)। 💰

**💻 Code Example:**
```javascript
db.products.insertOne({
  name: "Alu" (String),
  isAvailable: true (Boolean),
  stock: 50 (Int32),
  price: 15.50 (Double)
})
```

**🔍 ব্যাখ্যা:**
`name` হলো টেক্সট। `isAvailable` হলো সত্য/মিথ্যা। `stock` হলো আস্ত সংখ্যা। আর `price` হলো দশমিক সংখ্যা।

## 📘 Lesson 3: Arrays & Objects (লিস্ট আর পোটলা)

**🗣️ সহজ আলোচনা:**
সব তথ্য কি আর এক লাইনে লেখা যায়? মাঝে মাঝে লিস্টি করতে হয় (Array), আবার মাঝে মাঝে এক তথ্যের ভেতর আরো ডিটেইলস দিতে হয় (Embedded Object)। SQL-এ এটা করতে জান বের হয়ে যেত, MongoDB-তে এটা ডাল-ভাত।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **Array:** এটা হলো তোমার **বাজারের ফর্দ**। `["চাল", "ডাল", "লবণ", "তেল"]`—এক কাগজের মধ্যে অনেক আইটেম।
*   **Object (Sub-document):** এটা হলো স্কুলের ব্যাগের ভেতর **টিফিন বক্স**। ব্যাগের ভেতর আরেকটা বক্স (অবজেক্ট), তার ভেতর স্যান্ডউইচ (ডেটা)। 🎒🍱

**💻 Code Example:**
```javascript
db.students.insertOne({
  name: "Kuddus",
  subjects: ["Bangla", "English", "Math"], // Array (লিস্ট)
  address: {                               // Object (সাব-ডকুমেন্ট)
    city: "Dhaka",
    zip: 1216
  }
})
```

**🔍 ব্যাখ্যা:**
`subjects` হলো একটা অ্যারে বা লিস্ট। আর `address` হলো একটা অবজেক্ট, যার পেটের ভেতর `city` আর `zip` আছে।

## 📘 Lesson 4: Date, Timestamp, Regular Expression (সময় আর প্যাটার্ন)

**🗣️ সহজ আলোচনা:**
তারিখ মনে রাখা খুব জরুরি। MongoDB-তে `Date` অবজেক্ট দিয়ে তারিখ সেভ করা হয়। আর `RegEx` হলো প্যাটার্ন দিয়ে খোঁজার অস্ত্র।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **Date:** ডায়েরিতে লিখে রাখা **অ্যানিভার্সারি ডেট**। ভুললে কিন্তু খবর আছে! 📅
*   **Timestamp:** হোয়াটসঅ্যাপের **"Last Seen"**। তুমি কখন অনলাইনে ছিলে, সিস্টেম অটোমেটিক ট্র্যাক রাখে।
*   **Regular Expression (RegEx):** ভিড়ের মধ্যে **লাল শার্ট** পরা লোক খোঁজা। নাম জানি না, শুধু জানি লাল শার্ট পরেছে (প্যাটার্ন)।

**💻 Code Example:**
```javascript
db.logs.insertOne({
  loginTime: new Date(),  // বর্তমান সময়
  message: "User logged in"
})

// খোঁজার সময় (RegEx)
db.users.find({ name: /Rah/ }) // যাদের নামে 'Rah' আছে
```

**🔍 ব্যাখ্যা:**
`new Date()` দিলে সার্ভারের বর্তমান সময় সেভ হবে। আর `/Rah/` দিয়ে বুঝায়, নামের শুরুতে বা মাঝে 'Rah' থাকলেই তাকে ধরে আনো।

## 📘 Lesson 5: Special Types (Decimal128, Binary, Min/MaxKey)

**🗣️ সহজ আলোচনা:**
এগুলো হলো স্পেশাল অস্ত্র। সব সময় লাগে না, কিন্তু যখন লাগে তখন এগুলো ছাড়া গতি নাই। বিশেষ করে টাকার হিসাব আর ফাইল সেভ করার জন্য।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **Decimal128:** এটা হলো **স্বর্ণকারের দাঁড়িপাল্লা**। টাকার হিসাবে ১ পয়সার গরমিল হলেও চলবে না। `Double` টাইপে মাঝে মাঝে দশমিকের পর ভ্যালু এদিক-সেদিক হয়, কিন্তু `Decimal128`-এ একদম পারফেক্ট থাকে। ⚖️
*   **Binary:** এটা হলো ফাইলের **কাঁচামাল**। ছবি বা পিডিএফ-কে বাইনারি বানিয়ে ডেটাবেসে রাখা (যদিও আমরা সাধারণত লিংক রাখি)।
*   **MinKey/MaxKey:** এটা হলো **অসীম (Infinity)**। সবকিছুর শেষ সীমা।

**💻 Code Example:**
```javascript
db.accounts.insertOne({
  accountHolder: "Rich Man",
  balance: NumberDecimal("99999.99") // টাকার জন্য সেরা টাইপ
})
```

**🔍 ব্যাখ্যা:**
`NumberDecimal` ব্যবহার করলে ব্যাংকিং বা স্যালারি অ্যাপে দশমিকের হিসাব কখনো ভুল হবে না।
