## 📘 Lesson 6: Comparison Operators (তুলনা করে খোঁজা)
**($eq, $ne, $gt, $lt, $gte, $lte)**

**🗣️ সহজ আলোচনা:**
সবসময় কি আমরা নাম দিয়েই খুঁজি? মাঝে মাঝে তো বলি—"যাদের বয়স ১৮ এর বেশি তাদের ডাকো" বা "যাদের বেতন ২০ হাজারের কম তাদের লিস্ট দাও"। এই ছোট-বড় বা সমান-অসমান তুলনা করাই হলো Comparison Operator এর কাজ।

**🤣 মামার রিয়েল লাইফ এনালজি:**
পাত্রী দেখার বিজ্ঞাপন দেখেছ তো?
*   **$eq (Equal):** পাত্রকে সরকারি চাকরিজীবী হতে হবে। (Condition == Govt Job)
*   **$gt (Greater Than):** পাত্রের হাইট ৫ ফিট ১০ ইঞ্চির বেশি হতে হবে। 📏
*   **$lte (Less Than or Equal):** পাত্রীর বয়স ২৫ বা তার কম হতে হবে।

**💻 Code Example:**
```javascript
// দাম ৫০০ টাকার বেশি ($gt)
db.products.find({ price: { $gt: 500 } })

// বয়স ১৮ অথবা তার বেশি ($gte - Greater Than or Equal)
db.users.find({ age: { $gte: 18 } })

// শহর ঢাকা না ($ne - Not Equal)
db.users.find({ city: { $ne: "Dhaka" } })
```

**🔍 ব্যাখ্যা:**
`$gt` মানে বড়, `$lt` মানে ছোট, `$gte` মানে বড় অথবা সমান। একদম ছোটবেলার অংকের মতো মামা!

## 📘 Lesson 7: Logical Operators (লজিকের খেলা)
**($and, $or, $not, $nor)**

**🗣️ সহজ আলোচনা:**
যখন শর্ত একটা না, বরং একাধিক হয়। "এটাও চাই, ওটাও চাই" অথবা "যেকোনো একটা হলেই চলবে"।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$and:** দুপুরের লাঞ্চে বিরিয়ানি **এবং** কোক দুইটাই লাগবে। কোক ছাড়া বিরিয়ানি নামবে না। (সব শর্ত মানতে হবে)।
*   **$or:** ঈদে বাড়ি যাব—বাসে **অথবা** ট্রেনে। যেকোনো একটা টিকেট পেলেই হবে। 🚌/🚂
*   **$nor:** আমি করলাও খাব না, লাউও খাব না। (কোনোটাই না)। 🤢

**💻 Code Example:**
```javascript
// $and (অটোমেটিক হয়, কমা দিলেই হয়)
db.users.find({ age: { $gt: 20 }, city: "Dhaka" })
// বয়স ২০ এর বেশি হতে হবে AND ঢাকায় থাকতে হবে।

// $or (যেকোনো একটা)
db.users.find({
    $or: [
        { city: "Chittagong" },
        { status: "Rich" }
    ]
})
```

**🔍 ব্যাখ্যা:**
`$or` ব্যবহার করলে অ্যারের `[]` ভেতর শর্ত দিতে হয়। চিটাগং-এর পোলা হলেও চলবে **অথবা** বড়লোক হলেও চলবে—যেকোনো একটা হলেই রেজাল্ট আসবে।

## 📘 Lesson 8: Element Check (আদৌ আছে তো?)
**($exists, $type)**

**🗣️ সহজ আলোচনা:**
মাঝে মাঝে আমরা ডেটার ভ্যালু খুঁজি না, বরং খুঁজি ফিল্ডটা আদৌ আছে কি না। অথবা ফিল্ডটা কী টাইপের (Number না String)?

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$exists:** পকেটে হাত দিয়ে চেক করা—মানিব্যাগটা আছে তো? ভেতরে টাকা আছে না নাই সেটা পরের বিষয়, আগে মানিব্যাগ থাকা লাগবে। 👛
*   **$type:** মানিব্যাগে হাত দিয়ে বুঝার চেষ্টা করা—এটা কি টাকার নোট (Paper) নাকি কয়েন (Metal)?

**💻 Code Example:**
```javascript
// যাদের ইমেইল ফিল্ড আছে ($exists: true)
db.users.find({ email: { $exists: true } })

// যাদের ফোন নম্বরটা String হিসেবে সেভ করা আছে (Number না)
db.users.find({ phone: { $type: "string" } })
```

**🔍 ব্যাখ্যা:**
NoSQL-এ সব ডকুমেন্টে সব ফিল্ড থাকে না। তাই `$exists` দিয়ে চেক করে নেওয়া ভালো যে ওই ফিল্ডটা ওই ডকুমেন্টে আদৌ আছে কি না।

## 📘 Lesson 9: Evaluation Operators (গণিত আর প্যাটার্ন)
**($regex, $mod)**

**🗣️ সহজ আলোচনা:**
পুরো শব্দ মনে নেই? শুধু শব্দের অংশ দিয়ে খোঁজা (`$regex`)। আর অংক কষে ভাগশেষ বের করা (`$mod`)।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$regex (Regular Expression):** মোবাইলের কন্টাক্ট লিস্টে "Rah" লিখলে Rahim, Rahat, Rahman সব চলে আসে। এটাকে বলে প্যাটার্ন দিয়ে খোঁজা।
*   **$mod (Modulo):** ছোটবেলায় চকলেট ভাগ করে দেওয়া। ১০টা চকলেট ৩ জনকে দিলে ১টা অবশিষ্ট থাকে। এই ভাগশেষ বের করার নাম মডুলাস।

**💻 Code Example:**
```javascript
// নামের মধ্যে 'Khan' থাকলেই আনো (Case insensitive 'i')
db.users.find({ name: { $regex: "Khan", $options: "i" } })

// জোড় সংখ্যার রোল নম্বর খোঁজা (২ দিয়ে ভাগ করলে ভাগশেষ ০ থাকে)
db.students.find({ roll: { $mod: [2, 0] } })
```

**🔍 ব্যাখ্যা:**
`$regex` হলো গুগলের মতো সার্চ। আর `$mod: [2, 0]` মানে ২ দিয়ে ভাগ দিলে ভাগশেষ ০, অর্থাৎ জোড় সংখ্যা।

## 📘 Lesson 10: Array Querying (লিস্টের ভেতর উঁকি)
**($all, $elemMatch, $size)**

**🗣️ সহজ আলোচনা:**
এতক্ষণ তো সব সাধারণ ফিল্ড খুঁজলাম। কিন্তু যদি অ্যারে বা লিস্টের ভেতর খুঁজতে হয়?

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **`$all: রান্নার রেসিপি। বিরিয়ানি রাঁধতে চাল, মাংস, মসলা—সব (`$all`) উপকরণ লাগবে। একটা মিস হলে হবে না।
*   **$size:** ক্রিকেট টিম। টিমে ঠিক ১১ জন প্লেয়ার আছে কি না চেক করা। 🏏
*   **$elemMatch:** ফলের ঝুড়ি থেকে এমন ফল বের করা যেটা দেখতেও সুন্দর **এবং** খেতেও মিষ্টি (একই আইটেমের ভেতর একাধিক গুণ)।

**💻 Code Example:**
```javascript
// ট্যাগ লিস্টে "Gaming" এবং "Coding" দুইটাই থাকতে হবে
db.users.find({ tags: { $all: ["Gaming", "Coding"] } })

// কমেন্ট অ্যারেতে ঠিক ৩টা কমেন্ট আছে কি না
db.posts.find({ comments: { $size: 3 } })

// রেজাল্ট অ্যারেতে এমন সাবজেক্ট আছে যেখানে স্কোর ৮০+
db.students.find({ 
    results: { $elemMatch: { subject: "Math", score: { $gt: 80 } } } 
})
```

**🔍 ব্যাখ্যা:**
`$elemMatch` খুব পাওয়ারফুল। এটা অ্যারের ভেতর অবজেক্টগুলোর নির্দিষ্ট শর্ত চেক করে।
