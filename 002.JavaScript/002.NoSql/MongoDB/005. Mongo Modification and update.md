## 📘 Lesson 11: Field Updates (ভোল পাল্টানো)
**($set, $unset, $rename, $setOnInsert)**

**🗣️ সহজ আলোচনা:**
সবচেয়ে বেশি ব্যবহৃত কমান্ড। `$set` দিয়ে আমরা ভ্যালু বসাই বা চেঞ্জ করি। `$unset` দিয়ে ফিল্ডটাই গায়েব করে দেই। আর `$rename` দিয়ে ফিল্ডের নাম পাল্টাই।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$set:** মেকআপ করা। চেহারার ওপর নতুন প্রলেপ দেওয়া। অথবা ফেইসবুকে রিলেশনশিপ স্ট্যাটাস "Single" থেকে "Married" করা। 💍
*   **$unset:** ব্রেক-আপের পর মেমোরি কার্ড থেকে ফোল্ডার ডিলিট করা। মানে ফিল্ডটাই নাই! 🗑️
*   **$rename:** ছোটবেলার নাম "বল্টু" পাল্টে সার্টিফিকেটে "বোল্ট" করা। ভ্যালু ঠিক থাকে, শুধু লেভেল বদলায়।

**💻 Code Example:**
```javascript
// ১. আপডেট বা নতুন ফিল্ড সেট করা
db.users.updateOne(
  { name: "Rahim" },
  { $set: { city: "Dhaka", status: "Active" } }
)

// ২. ফিল্ড মুছে ফেলা (ফোন নম্বর গায়েব)
db.users.updateOne(
  { name: "Rahim" },
  { $unset: { phone: "" } } // ভ্যালু যা ইচ্ছা দাও, ফিল্ড উধাও হবেই
)

// ৩. ফিল্ডের নাম পরিবর্তন (mobile -> cell)
db.users.updateMany({}, { $rename: { "mobile": "cell" } })
```

## 📘 Lesson 12: Arithmetic Updates (যোগ-বিয়োগের খেলা)
**($inc, $mul, $min, $max)**

**🗣️ সহজ আলোচনা:**
সংখ্যার সাথে খেলা। `$inc` দিয়ে বাড়ানো/কমানো, `$mul` দিয়ে গুণ করা। আর `$min`/`$max` একটু ট্রিকি—এরা তখনই আপডেট করে যদি নতুন ভ্যালুটা শর্ত পূরণ করে।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$inc (Increment):** ক্রিকেট খেলার স্কোরবোর্ড। ১ রান নিলে ১ যোগ হয় (`$inc: 1`), আউট হলে উইকেট বাড়ে। 🏏
*   **$mul (Multiply):** ডাবল বোনাস! স্যালারি ২ গুণ করে দেওয়া। ✖️
*   **$max (Maximum):** হাই স্কোর। গেম খেলার সময় তোমার বর্তমান স্কোরের চেয়ে বেশি করলেই কেবল হাই স্কোর আপডেট হয়। কম করলে আগেরটাই থাকে।
*   **$min (Minimum):** দৌড় প্রতিযোগিতা। আগের চেয়ে কম সময়ে দৌড়াতে পারলেই রেকর্ড আপডেট হবে। ⏱️

**💻 Code Example:**
```javascript
// চালের বস্তায় ৫ কেজি চাল যোগ করা
db.inventory.updateOne(
  { item: "Rice" },
  { $inc: { quantity: 5 } } // কমানোর জন্য -5 দিলেই হবে
)

// হাই স্কোর আপডেট (যদি বর্তমান স্কোর ৫০০ এর বেশি হয় তবেই আপডেট হবে)
db.games.updateOne(
  { player: "Kuddus" },
  { $max: { highScore: 500 } }
)
```

## 📘 Lesson 13: Array Push (লিস্টে ঠাসাঠাসি)
**($push, $addToSet, $each, $position, $slice)**

**🗣️ সহজ আলোচনা:**
অ্যারে বা লিস্টের মধ্যে নতুন ডেটা ঢোকানো। `$push` অন্ধের মতো ঢোকায়, আর `$addToSet` দেখে যে জিনিসটা আগে থেকেই আছে কি না।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$push:** লোকাল বাস। কন্ডাক্টর মামা যেমন "চাপেন, চাপেন" বলে যাত্রী ঢোকাতেই থাকে (ডুপ্লিকেট হলেও সমস্যা নাই)। 🚌
*   **$addToSet:** বিয়ের দাওয়াত কার্ড। একজনকে একবারই দাওয়াত দেওয়া যায়। মফিজকে একবার কার্ড দিলে, দ্বিতীয়বার আর নাম উঠবে না (No Duplicate)। 📩
*   **$each:** বাসে এক স্টপেজে একসাথে ৫ জন বন্ধু ওঠা। (একসাথে অনেকগুলো পুশ করা)।

**💻 Code Example:**
```javascript
// ট্যাগ লিস্টে "Smart" যোগ করা (আগেই থাকলেও যোগ করবে)
db.users.updateOne(
  { name: "Rahim" },
  { $push: { tags: "Smart" } }
)

// ডুপ্লিকেট আটকাবে
db.users.updateOne(
  { name: "Rahim" },
  { $addToSet: { tags: "Smart" } }
)

// একসাথে অনেকগুলো ঢোকানো ($each)
db.users.updateOne(
  { name: "Rahim" },
  { $push: { tags: { $each: ["Honest", "Brave"] } } }
)
```

## 📘 Lesson 14: Array Pull (বেছে ফেলে দেওয়া)
**($pull, $pullAll, $pop)**

**🗣️ সহজ আলোচনা:**
লিস্ট থেকে ডেটা বের করে দেওয়া। `$pull` দিয়ে বেছে বেছে বের করা হয়, আর `$pop` দিয়ে আগা বা গোড়া থেকে বের করা হয়।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$pull:** বিরিয়ানির প্লেট থেকে এলাচ আর দারুচিনি বেছে বেছে ফেলে দেওয়া। স্পেসিফিক জিনিস রিমুভ। 🍛
*   **$pop:** বাসের গেট থেকে হেল্পারকে ধাক্কা দিয়ে ফেলে দেওয়া (শেষের জন -1)। অথবা ড্রাইভারকে নামিয়ে দেওয়া (প্রথম জন 1)।

**💻 Code Example:**
```javascript
// ট্যাগ লিস্ট থেকে "Lazy" রিমুভ করা
db.users.updateOne(
  { name: "Rahim" },
  { $pull: { tags: "Lazy" } }
)

// লিস্টের শেষ আইটেম ফেলে দেওয়া (Last item out)
db.users.updateOne(
  { name: "Rahim" },
  { $pop: { tags: 1 } } // -1 দিলে প্রথমটা যাবে
)
```

## 📘 Lesson 15: Bitwise & Date Updates (টাইম আর বিট)
**($currentDate, $bit)**

**🗣️ সহজ আলোচনা:**
কখন ডেটা আপডেট হলো সেই টাইমস্ট্যাম্প বসানো এবং বাইনারি (0, 1) লেভেলের অপারেশন।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$currentDate:** অফিসের বায়োমেট্রিক মেশিন। তুমি যখনই আঙ্গুল ছোঁয়াবে, মেশিন ঠিক ওই মুহূর্তের টাইমটা রেকর্ড করবে। ম্যানুয়ালি টাইম বসাতে হয় না। ⏰
*   **$bit:** ইলেকট্রিক সুইচের মতো। অন/অফ লেভেলের টেকনিক্যাল কাজ (সাধারণত খুব কম লাগে, হ্যাকার মামাদের জন্য)।

**💻 Code Example:**
```javascript
// আপডেট হওয়ার সময়টা রেকর্ড করা
db.users.updateOne(
  { name: "Rahim" },
  { 
    $set: { status: "Active" },
    $currentDate: { lastModified: true } // অটো আজকের তারিখ ও সময় বসবে
  }
)
```
