
স্বাগতম মামা! আমরা চলে এসেছি MongoDB-র সবচেয়ে পাওয়ারফুল পার্ট—**Aggregation Framework**-এ।

এটাকে আমি বলি **"ডেটা প্রসেসিং ফ্যাক্টরি"**। 🏭
চিন্তা করো, একটা ফ্যাক্টরির এক দিক দিয়ে কাঁচামাল (Raw Data) ঢোকে, ভেতরে অনেকগুলো মেশিন (Stages) পার হয়ে অন্য দিক দিয়ে প্যাকেটজাত চিপস (Processed Data) হয়ে বের হয়।

এখানে আমরা একটার পর একটা স্টেজ সাজাবো, যেটাকে বলে **Pipeline**। চলো, মেশিনগুলো স্টার্ট করি! ⚙️🚨

# 🟢 Module 4: Aggregation Pipeline Basics (ডেটা প্রসেসিং ফ্যাক্টরি)

---

## 📘 Lesson 16: Pipeline Intro (ছাঁকনি আর জটলা)
**($match, $group, $count)**

**🗣️ সহজ আলোচনা:**
ফ্যাক্টরির প্রথম কাজ হলো পচা মাল বাদ দেওয়া (`$match`)। এরপর ভালো মালগুলোকে ক্যাটাগরি অনুযায়ী আলাদা স্তূপ করা বা গ্রুপ করা (`$group`)।

**🤣 মামার রিয়েল লাইফ এনালজি:**
ধরো তুমি আমের আড়তদার। 🥭
1.  **$match:** প্রথমে পচা আমগুলো বেছে ফেলে দিলে। শুধু "হিমসাগর" আমগুলো রাখলে।
2.  **$group:** এবার আমগুলোকে সাইজ অনুযায়ী আলাদা ঝুড়িতে রাখলে (ছোট, মাঝারি, বড়)।
3.  **$count:** শেষে গুনলে—কোন ঝুড়িতে কয়টা আম আছে।

**💻 Code Example:**
```javascript
db.orders.aggregate([
  // ১. স্টেজ ১: শুধু যারা পেমেন্ট করেছে তাদের নাও
  { $match: { status: "paid" } },

  // ২. স্টেজ ২: কাস্টমার অনুযায়ী গ্রুপ করে মোট টাকার হিসাব করো
  { $group: { _id: "$customerId", totalSpent: { $sum: "$amount" } } }
])
```

**🔍 ব্যাখ্যা:**
প্রথমে ফিল্টার (`$match`), তারপর গ্রুপ (`$group`)। `$sum` দিয়ে সব মিলিয়ে মোট কত টাকা খরচ করেছে সেটা বের করলাম।

## 📘 Lesson 17: Reshaping (সাজগোজ আর মেকআপ)
**($project, $addFields, $unset)**

**🗣️ সহজ আলোচনা:**
কাস্টমারকে কি আমরা ডেটাবেসের সব দেখাব? পাসওয়ার্ড, সিক্রেট কোড? না! আমরা ডেটাকে সুন্দর করে সাজিয়ে (Reshape) আউটপুট দিব।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$project:** কনে দেখতে যাওয়ার সময় শুধু সুন্দর শাড়ি আর গয়না পরা (`1`), ঘরের বাসি কাপড় না দেখানো (`0`)। 👰
*   **$addFields:** কনের হাতে নতুন একটা ঘড়ি পরিয়ে দেওয়া (আগে ছিল না, এখন সৌন্দর্যের জন্য যোগ করলাম)। ⌚
*   **$unset:** জামার প্রাইস ট্যাগ ছিঁড়ে ফেলা (রিমুভ করা), যাতে কেউ দাম না দেখে।

**💻 Code Example:**
```javascript
db.users.aggregate([
  { $project: { name: 1, email: 1, _id: 0 } }, // শুধু নাম আর ইমেইল দেখাও, আইডি বাদ
  { $addFields: { country: "Bangladesh" } }    // নতুন ফিল্ড যোগ করো
])
```

## 📘 Lesson 18: Unwind & Sort (তাস ও লাইন ধরা)
**($unwind, $sort, $limit, $skip)**

**🗣️ সহজ আলোচনা:**
`$unwind` অ্যারে ভেঙে ফেলে। আর `$sort`, `$limit` ডেটাকে সাজায়।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$unwind:** এক প্যাকেট তাস (Array)। প্যাকেট খুলে ৫২টা তাস টেবিলে ছড়িয়ে দিলে যেমন হয়, সেটাই আনওয়াইন্ড। একটা ডকুমেন্ট ভেঙে অনেকগুলো হয়ে যায়। 🃏
*   **$sort:** স্কুলের অ্যাসেম্বলি। হাইট অনুযায়ী ছোট থেকে বড় সাজানো।
*   **$limit & $skip:** গুগলের সার্চ পেজ। প্রথম ১০টা দেখাও (`$limit`), পরের পেজে যেতে চাইলে প্রথম ১০টা বাদ দাও (`$skip`)।

**💻 Code Example:**
```javascript
// ১. ট্যাগ অ্যারে ভেঙে আলাদা আলাদা ডকুমেন্ট বানাও
db.products.aggregate([
  { $unwind: "$tags" },
  // ২. দাম অনুযায়ী বড় থেকে ছোট সাজাও (-1)
  { $sort: { price: -1 } },
  // ৩. মাত্র ৫টা দেখাও
  { $limit: 5 }
])
```

## 📘 Lesson 19: Lookup - The Join (ঘটক পাখি ভাই)
**($lookup)**

**🗣️ সহজ আলোচনা:**
NoSQL-এ তো রিলেশন নাই, তাই বলে কি আমরা অন্যের খোঁজ নিব না? এক কালেকশনের সাথে আরেক কালেকশনের ডেটা জোড়া লাগানোর নাম `$lookup`। এটা SQL-এর `LEFT JOIN`-এর মতো।

**🤣 মামার রিয়েল লাইফ এনালজি:**
ধরো তোমার কাছে শুধু **Roll Number** আছে। তুমি সেটা নিয়ে **"স্টুডেন্ট ইনফো"** রেজিস্টারে গেলে বাবার নাম জানতে।
এটা অনেকটা **ঘটক (Matchmaker)** এর কাজ। পাত্রের বায়োডাটার সাথে পাত্রীর বায়োডাটা পিন মেরে জোড়া লাগিয়ে দেওয়া। 📎

**💻 Code Example:**
```javascript
db.orders.aggregate([
  {
    $lookup: {
      from: "products",       // কোন কালেকশনের সাথে জোড়া দিব?
      localField: "productId",// আমার হাতের চাবি কোনটা?
      foreignField: "_id",    // ওই কালেকশনের তালার চাবি কোনটা?
      as: "productDetails"    // জোড়া লাগানোর পর নাম কী হবে?
    }
  }
])
```

**🔍 ব্যাখ্যা:**
`orders` কালেকশনে শুধু প্রোডাক্ট আইডি ছিল। `$lookup` দিয়ে `products` কালেকশন থেকে ওই আইডির ডিটেইলস এনে `productDetails` নামে বসিয়ে দিলাম।

## 📘 Lesson 20: Advanced Stages (বালতি আর ড্যাশবোর্ড)
**($bucket, $facet, $sortByCount)**

**🗣️ সহজ আলোচনা:**
ডেটাকে রেঞ্জ বা ক্যাটাগরিতে ফেলা এবং মাল্টি-টাস্কিং রিপোর্ট তৈরি করা।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$bucket:** মাছ বাজারে মাছের সাইজ অনুযায়ী ঝুড়িতে ফেলা। ০-১ কেজি "ছোট", ১-৩ কেজি "মাঝারি", ৩+ কেজি "বড়" বালতিতে রাখা। 🐟
*   **$facet:** বিয়ের বাড়ির ম্যানেজার। একই সময়ে সে দেখছে—কয়জন খেল (Count), কয়টা প্লেট ভাঙল (Stats), আর বিরিয়ানি কতটুকু বাকি (Inventory)। এক ক্লিকে মাল্টিপল রিপোর্ট! 📊
*   **$sortByCount:** ভোটে কে কত ভোট পেল, সেটা গুনে আবার যার ভোট বেশি তাকে উপরে রাখা।

**💻 Code Example:**
```javascript
// দাম অনুযায়ী বালতিতে ভাগ করা
db.products.aggregate([
  {
    $bucket: {
      groupBy: "$price",
      boundaries: [0, 100, 500, 1000], // রেঞ্জ: ০-১০০, ১০০-৫০০...
      default: "Expensive", // ১০০০ এর বেশি হলে এখানে যাবে
      output: { count: { $sum: 1 } }
    }
  }
])
```
