# 🟢 Module 5: Aggregation Expressions (লজিক ও গণিত)

## 📘 Lesson 21: Arithmetic Expressions (দোকানদারের হিসাব)
**($add, $multiply, $subtract, $divide)**

**🗣️ সহজ আলোচনা:**
ফিল্ডের ভ্যালু নিয়ে যোগ, বিয়োগ, গুণ, ভাগ করা। ডেটাবেসে হয়তো শুধু "দাম" আর "পরিমাণ" আছে, কিন্তু তোমাকে "মোট দাম" বের করতে হবে।

**🤣 মামার রিয়েল লাইফ এনালজি:**
মুদি দোকানের ক্যাশ মেমো। 📝
*   **$multiply:** ৫ কেজি চাল × ৬০ টাকা = ৩০০ টাকা।
*   **$add:** চাল ৩০০ + ডাল ১০০ = ৪০০ টাকা।
*   **$subtract:** ৪০০ টাকা - ২০ টাকা (ডিসকাউন্ট) = ৩৮০ টাকা।

**💻 Code Example:**
```javascript
db.sales.aggregate([
  {
    $project: {
      item: 1,
      // মোট দাম = দাম × পরিমাণ
      totalCost: { $multiply: ["$price", "$quantity"] },
      // লাভ = বিক্রয় মূল্য - কেনা মূল্য
      profit: { $subtract: ["$sellPrice", "$buyPrice"] }
    }
  }
])
```

## 📘 Lesson 22: String Expressions (দর্জি মামার কাজ)
**($concat, $toUpper, $substr, $split)**

**🗣️ সহজ আলোচনা:**
লেখাকে কাটা-ছেঁড়া বা জোড়া লাগানো। ছোট হাতের লেখাকে বড় করা, বা দুইটা নাম জোড়া লাগানো।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$concat (জোড়া লাগানো):** দর্জি মামা যেমন দুই টুকরো কাপড় জোড়া লাগিয়ে শার্ট বানায়। ফার্স্ট নেম "Abul" আর লাস্ট নেম "Mia" জোড়া লাগিয়ে "Abul Mia"। 👕
*   **$toUpper:** বসের সামনে কথা বলার সময় গলার স্বর উঁচুতে রাখা (সব ক্যাপিটাল লেটার)। "shout" হয়ে যাবে "SHOUT"। 🗣️
*   **$substr (কেটে নেওয়া):** কাপড় কেটে পকেট বানানো। বিশাল বড় প্যারাগ্রাফ থেকে প্রথম ১০ লাইন কেটে নেওয়া।

**💻 Code Example:**
```javascript
db.users.aggregate([
  {
    $project: {
      // নাম জোড়া লাগানো (মাঝখানে স্পেসসহ)
      fullName: { $concat: ["$firstName", " ", "$lastName"] },
      // শহরের নাম বড় হাতের করা
      cityUpper: { $toUpper: "$city" }
    }
  }
])
```

## 📘 Lesson 23: Advanced Array Logic (লুপের কারিশমা)
**($map, $filter, $reduce)**

**🗣️ সহজ আলোচনা:**
অ্যারের ভেতর ঢুকে প্রত্যেকটা আইটেম ধরে ধরে কাজ করা। এটা একটু প্রো লেভেলের কোডিং কনসেপ্ট।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$map (Modify):** মাস্টার মশাই পরীক্ষার খাতা দেখার সময় সবার নম্বরের সাথে ৫ নম্বর বোনাস যোগ করে দিলেন। (সবার ওপর অ্যাকশন অ্যাপ্লাই হলো)। 👨‍🏫
*   **$filter (Select):** ঝুড়ি থেকে বেছে বেছে শুধু পাকা আমগুলো আলাদা করা। কাঁচাগুলো বাদ। 🥭
*   **$reduce (Summarize):** মাটির ব্যাংক ভাঙা। অনেকগুলো কয়েন (Array) মিলে একটাই বড় অ্যামাউন্ট (Total) হয়ে যাওয়া।

**💻 Code Example:**
```javascript
db.students.aggregate([
  {
    $project: {
      // যারা ৮০-র বেশি পেয়েছে শুধু তাদের মার্কস রাখো
      distinctionMarks: {
        $filter: {
          input: "$marks",
          as: "m",
          cond: { $gte: ["$$m", 80] }
        }
      },
      // সবার মার্কসের সাথে ২ যোগ করে দাও
      bonusMarks: {
        $map: {
          input: "$marks",
          as: "m",
          in: { $add: ["$$m", 2] }
        }
      }
    }
  }
])
```

## 📘 Lesson 24: Date Expressions (দিন-তারিখের হিসাব)
**($year, $month, $dayOfMonth, $dateToString)**

**🗣️ সহজ আলোচনা:**
তারিখ থেকে বছর, মাস বা দিন আলাদা করা। অথবা তারিখকে সুন্দর ফরমেটে দেখানো।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$month:** বন্ধুর জন্মদিন কবে? সাল বা বার দিয়ে কাজ নাই, শুধু মাস আর তারিখ জানলেই হবে (কেক কাটার জন্য)। 🎂
*   **$dateToString:** বিদেশিদের স্টাইল (YYYY-MM-DD) থেকে আমাদের দেশি স্টাইল (DD-MM-YYYY) এ তারিখ লেখা।

**💻 Code Example:**
```javascript
db.orders.aggregate([
  {
    $project: {
      // অর্ডার ডেট থেকে শুধু বছর বের করা
      orderYear: { $year: "$orderDate" },
      // সুন্দর ফরমেটে তারিখ দেখানো (12-12-2023)
      formattedDate: { $dateToString: { format: "%d-%m-%Y", date: "$orderDate" } }
    }
  }
])
```

## 📘 Lesson 25: Conditional Logic (যদি... কিন্তু... তবুও)
**($cond, $switch, $ifNull)**

**🗣️ সহজ আলোচনা:**
শর্ত সাপেক্ষে সিদ্ধান্ত নেওয়া। যদি এটা হয়, তবে ওটা করো।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$cond (If-Else):** আকাশ কি মেঘলা? **যদি** হ্যাঁ হয়, তবে ছাতা নাও। **নাহলে** সানগ্লাস নাও। ☔/😎
*   **$ifNull (Fallback):** বন্ধুর কাছে টাকা ধার চাওয়া। যদি তার কাছে টাকা থাকে ভালো, **নাহলে (Null)** বাবার কাছে চাও। (বিকল্প ব্যবস্থা)।
*   **$switch (Multiple Choice):** রেজাল্ট শিট। ৮০+ পেলে A+, ৭০+ পেলে A, ৬০+ পেলে B। অনেকগুলো অপশন।

**💻 Code Example:**
```javascript
db.products.aggregate([
  {
    $project: {
      item: 1,
      // যদি দাম ১০০০ এর বেশি হয়, ১০% ডিসকাউন্ট, নাহলে ০
      discount: {
        $cond: { if: { $gt: ["$price", 1000] }, then: 100, else: 0 }
      },
      // ডেসক্রিপশন না থাকলে "No description" দেখাও
      desc: { $ifNull: ["$description", "No description provided"] }
    }
  }
])
```
