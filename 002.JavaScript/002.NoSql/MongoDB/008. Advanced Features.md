## 📘 Lesson 26: Geospatial Queries (ম্যাপ ও লোকেশন)
**($geoWithin, $near, $nearSphere)**

**🗣️ সহজ আলোচনা:**
উবার বা পাঠাও অ্যাপ কীভাবে বোঝে যে তোমার আশেপাশে কোন বাইকটা আছে? বা ফুডপান্ডা কীভাবে দেখায় তোমার ১ কি.মি. এর মধ্যে কোন রেস্টুরেন্ট আছে? এটাই হলো জিওস্পেশিয়াল কুয়েরির জাদুকরী।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **$near:** তুমি সেন্টারে দাঁড়িয়ে আছো, আর বলছ—"আমার সবচেয়ে কাছের ৫টা ফুচকার দোকান দেখাও।" 📍
*   **$geoWithin:** একটা দাগ কেটে দেওয়া (যেমন—রমনা পার্কের সীমানা)। এই বাউন্ডারির ভেতর কে কে আছে তাদের ধরে আনো।

**💻 Code Example:**
```javascript
// ১. আগে লোকেশন ইনডেক্স বানাতে হয় (2dsphere)
db.places.createIndex({ location: "2dsphere" })

// ২. আমার লোকেশন থেকে ১০০০ মিটার (১ কি.মি.) এর মধ্যে রেস্টুরেন্ট খোঁজা
db.places.find({
  location: {
    $near: {
      $geometry: { type: "Point", coordinates: [90.4125, 23.8103] }, // ঢাকার অক্ষাংশ/দ্রাঘিমাংশ
      $maxDistance: 1000 // মিটার
    }
  }
})
```

## 📘 Lesson 27: Special Indexes (টাইমার ও গুগল সার্চ)
**($text, TTL Index)**

**🗣️ সহজ আলোচনা:**
সাধারণ ইনডেক্স তো আগেই দেখেছি। এখন দেখব স্পেশাল ইনডেক্স। `Text` ইনডেক্স দিয়ে গুগলের মতো সার্চ করা যায়, আর `TTL` (Time To Live) দিয়ে নির্দিষ্ট সময় পর ডেটা অটো ডিলিট করা যায়।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **Text Index:** লাইব্রেরিতে বই খোঁজা। তুমি পুরো নাম জানো না, শুধু জানো বইয়ের নামে "History" শব্দটা আছে। এটাই টেক্সট সার্চ। 📖
*   **TTL Index:** মোবাইলে আসা **OTP কোড**। ৫ মিনিট পর ওটার আর দাম নাই, অটোমেটিক গায়েব হয়ে যায়। অথবা Snapchat এর মেসেজ। ⏳💣

**💻 Code Example:**
```javascript
// ১. Text Index: ডেসক্রিপশনের মধ্যে শব্দ খোঁজার জন্য
db.products.createIndex({ description: "text" })
// সার্চ করা:
db.products.find({ $text: { $search: "Burger" } })

// ২. TTL Index: এই ডেটা ৩৬০০ সেকেন্ড (১ ঘণ্টা) পর অটো ডিলিট হয়ে যাবে
db.sessions.createIndex({ "createdAt": 1 }, { expireAfterSeconds: 3600 })
```

## 📘 Lesson 28: Bulk Write (পাইকারি কারবার)
**(bulkWrite, insertMany)**

**🗣️ সহজ আলোচনা:**
এক হাজার ডেটা ইনসার্ট বা আপডেট করতে গেলে যদি ১০০০ বার সার্ভারে রিকোয়েস্ট পাঠাও, সার্ভার স্লো হয়ে যাবে। তার চেয়ে বরং সবগুলোকে এক বস্তায় ভরে একবার পাঠাও।

**🤣 মামার রিয়েল লাইফ এনালজি:**
ইট ভাটায় ইট আনা। 🧱
একটা একটা করে ইট হাতে করে আনলে সারাদিন লাগবে (Single Write)। তার চেয়ে ট্রাকে করে ৫০০০ ইট একবারে নিয়ে আসা ভালো (Bulk Write)। সময়ও বাঁচে, তেলও বাঁচে।

**💻 Code Example:**
```javascript
db.products.bulkWrite([
  { insertOne: { document: { name: "Pen", price: 10 } } },
  { updateOne: { filter: { name: "Pencil" }, update: { $set: { price: 5 } } } },
  { deleteOne: { filter: { name: "Rubber" } } }
])
```
**ব্যাখ্যা:** একই ট্রাকে করে ইনসার্ট, আপডেট আর ডিলিট—সব প্যাকেট পাঠিয়ে দিলাম।

## 📘 Lesson 29: Change Streams (সিসিটিভি ক্যামেরা)
**(watch)**

**🗣️ সহজ আলোচনা:**
ডেটাবেসে কোনো পরিবর্তন (Insert/Update/Delete) হলেই সাথে সাথে তোমাকে নোটিফিকেশন দেবে। রিয়েল-টাইম অ্যাপ (যেমন চ্যাটিং অ্যাপ বা লাইভ স্কোর) বানাতে এটা লাগে।

**🤣 মামার রিয়েল লাইফ এনালজি:**
পাড়ার মোড়ের **সিসিটিভি ক্যামেরা** বা বারান্দায় বসে থাকা **আন্টি**। 👀
কে মহল্লায় ঢুকলো, কে বের হলো—সব দিকে নজর। কিছু একটা ঘটলেই সাথে সাথে খবর (Notification) চলে যায়।

**💻 Code Example:**
```javascript
// জাভাস্ক্রিপ্ট (Node.js) কোডে এটা বেশি ব্যবহার হয়
const changeStream = db.collection('orders').watch();

changeStream.on('change', (change) => {
  console.log("মামা! নতুন অর্ডার আসছে!", change); 🔔
});
```

## 📘 Lesson 30: Admin & Cleanup (হিসাব নিকাশ ও বিদায়)
**(distinct, drop, show collections)**

**🗣️ সহজ আলোচনা:**
কোর্স শেষের আগে ঘরদোর পরিষ্কার করা। ইউনিক ভ্যালু দেখা, আর দরকার না হলে সব ডিলিট করে দেওয়া।

**🤣 মামার রিয়েল লাইফ এনালজি:**
*   **distinct:** ক্লাসে মোট ৫০ জন ছাত্র, কিন্তু নামগুলো কী কী? (রহিম হয়তো ৫ জন আছে, কিন্তু নাম হিসেবে "রহিম" একটাই)। ইউনিক নাম বের করা।
*   **drop:** পুরোনো বিল্ডিং ভেঙে ফেলা। একদম মাটির সাথে মিশিয়ে দেওয়া। 🏗️
*   **The End:** দোকানের শার্টার নামিয়ে দেওয়া। আজকের মতো বেচাকেনা শেষ!

**💻 Code Example:**
```javascript
// ১. ইউনিক ক্যাটাগরিগুলো বের করো
db.products.distinct("category") // [ "Electronics", "Food", "Clothing" ]

// ২. কালেকশন ডিলিট (সাবধান!)
db.products.drop()

// ৩. ডেটাবেস ডিলিট (মহা বিপদ!)
db.dropDatabase()
```
