# 📦 Module 3: Arrays & Objects (Deep Dive)

### 📖 Lesson 1: Array Methods (Basic কাটাছেঁড়া)

**🎯 Learning Goal:** অ্যারেতে আইটেম যোগ করা ও ডিলিট করা শেখা।

**🗣️ সহজ ব্যাখ্যা:**
অ্যারে হলো ট্রেনের মতো, যেখানে বগি (Data) জোড়া দেওয়া যায় আবার খোলা যায়।
- `push()`: পেছনে বগি লাগানো।
- `pop()`: পেছনের বগি খুলে ফেলা।
- `unshift()`: ইঞ্জিনের সামনে বগি লাগানো (ধাক্কা দিয়ে)।
- `shift()`: সামনের বগি খুলে ফেলা।

**🤣 Real-life Analogy:**
**লোকাল বাস।**
- হেল্পার বলল "পিছনে যান": `push()`
- পেছনের যাত্রী নেমে গেল: `pop()`
- ড্রাইভারের পাশে সিট নিলেন: `unshift()`

**💻 Code Example:**
```javascript
let friends = ["Rahim", "Karim"];

friends.push("Jabbar"); // শেষে যোগ
console.log(friends);   // ["Rahim", "Karim", "Jabbar"]

friends.pop();          // শেষ থেকে ডিলিট
console.log(friends);   // ["Rahim", "Karim"]

friends.unshift("Salam"); // শুরুতে যোগ
console.log(friends);     // ["Salam", "Rahim", "Karim"]
```

**💪 Mini Exercise:**
1. ৫টি ফলের নাম দিয়ে অ্যারে বানাও। `pop` করে শেষ ফলটি সরিয়ে ফেলো, তারপর কনসোলে দেখাও।

**📝 One-line Summary:**
`push/pop` (শেষে) আর `shift/unshift` (শুরুতে) দিয়ে অ্যারে এডিট করা হয়।

### 📖 Lesson 2: map() (ট্রান্সফর্মার)

**🎯 Learning Goal:** অ্যারের প্রতিটি উপাদানকে পরিবর্তন করে নতুন অ্যারে বানানো।

**🗣️ সহজ ব্যাখ্যা:**
লুপ চালিয়ে কাজ করা পুরানো স্টাইল। `map` মেথড অ্যারের সব উপাদানের ওপর দিয়ে যায়, কিছু একটা পরিবর্তন করে, এবং **নতুন একটা অ্যারে** ফেরত দেয়।

**🤣 Real-life Analogy:**
**ফ্যাক্টরির কনভেয়ার বেল্ট।**
কাঁচা আলু (Input Array) -> মেশিনের ভেতর দিয়ে গেল (Map) -> চিপসের প্যাকেট হয়ে বের হলো (Output Array)।

**💻 Code Example:**
```javascript
const numbers = [2, 4, 6, 8];

// প্রতিটি সংখ্যাকে দ্বিগুণ করবো
const doubled = numbers.map(num => num * 2);

console.log(doubled); // [4, 8, 12, 16]
console.log(numbers); // [2, 4, 6, 8] (আসল অ্যারে ঠিক থাকে)
```

**💪 Mini Exercise:**
1. `["babu", "sona", "moyna"]` - এই অ্যারের সব নাম `toUpperCase()` ব্যবহার করে বড় হাতের করে নতুন অ্যারেতে রাখো।

**⚠️ Common Mistakes:**
- `map` ব্যবহার করে `return` না দেওয়া। রিটার্ন না দিলে নতুন অ্যারেতে সব `undefined` আসবে।

**📝 One-line Summary:**
অ্যারের চেহারা পাল্টাতে `map()` ব্যবহার করো, লুপের দরকার নেই।

**🏢 Real Project Importance:**
সার্ভার থেকে ইউজারদের ডেটা আসলে, সেটাকে সুন্দর করে HTML লিস্ট আকারে দেখাতে `map` সবচেয়ে বেশি ব্যবহৃত হয়।

### 📖 Lesson 3: filter() (চালুনি বা ছাঁকনি)

**🎯 Learning Goal:** শর্ত অনুযায়ী বেছে বেছে ডেটা নেওয়া।

**🗣️ সহজ ব্যাখ্যা:**
তোমার কাছে অনেক ডেটা আছে, সেখান থেকে শুধু প্রয়োজনীয়গুলো রাখবে, বাকিগুলো ফেলে দেবে। এটাই ফিল্টার।

**🤣 Real-life Analogy:**
**চায়ের ছাঁকনি।** চা (দরকারি ডেটা) নিচে পড়ে, আর চায়ের পাতা (অপ্রয়োজনীয় ডেটা) ছাঁকনিতে আটকে যায়।
অথবা, ক্লাবের বাউন্সার—শুধু কার্ড যাদের আছে (শর্ত) তাদের ঢুকতে দেবে।

**💻 Code Example:**
```javascript
const prices = [500, 200, 1500, 300, 800];

// বাজেট ১০০০ টাকার নিচে
const budgetFriendly = prices.filter(price => price < 1000);

console.log(budgetFriendly); // [500, 200, 300, 800]
```

**💪 Mini Exercise:**
1. `[12, 5, 20, 8, 30]` - এখান থেকে শুধু ১০-এর চেয়ে বড় সংখ্যাগুলো ফিল্টার করো।

**📝 One-line Summary:**
শর্ত দিয়ে বাছাই করতে `filter()` ব্যবহার করো।

**🏢 Real Project Importance:**
ই-কমার্স সাইটে "Price: Low to High" বা "Category: Mobile" সিলেক্ট করলে এই `filter()` ই কাজ করে।

### 📖 Lesson 4: find() (তোমাকেই খুঁজছি)

**🎯 Learning Goal:** অ্যারে থেকে নির্দিষ্ট একটি আইটেম খুঁজে বের করা।

**🗣️ সহজ ব্যাখ্যা:**
`filter` সবাইকে খুঁজে বের করে, আর `find` শুধু **প্রথম** যাকে পায় তাকেই নিয়ে আসে। ডুপ্লিকেট থাকলেও প্রথমটাকেই দেবে।

**🤣 Real-life Analogy:**
পরীক্ষার রেজাল্ট শিটে নিজের রোল নাম্বার খোঁজা। একবার পেয়ে গেলে আর নিচের দিকে খুঁজি না।

**💻 Code Example:**
```javascript
const products = [
    { id: 1, name: "Xiaomi", price: 15000 },
    { id: 2, name: "Samsung", price: 25000 },
    { id: 3, name: "Iphone", price: 100000 }
];

// আইডি ১ যার তাকে খুঁজো
const myPhone = products.find(p => p.id === 1);

console.log(myPhone); // { id: 1, name: "Xiaomi", price: 15000 }
```

**💪 Mini Exercise:**
1. উপরের কোড থেকে যার প্রাইস `100000` তাকে খুঁজে বের করো।

**⚠️ Common Mistakes:**
- `find` কিন্তু অ্যারে রিটার্ন করে না, সরাসরি অবজেক্ট (আইটেম) রিটার্ন করে।

**📝 One-line Summary:**
অনিকগুলোর মধ্যে নির্দিষ্ট একটাকে ইউনিকভাবে খুঁজতে `find()` লাগে।

### 📖 Lesson 5: reduce() (চাঁদা তোলা)

**🎯 Learning Goal:** সব উপাদান মিলিয়ে একটা রেজাল্ট বের করা (যেমন: যোগফল)।

**🗣️ সহজ ব্যাখ্যা:**
অ্যারের সব সংখ্যাকে "রিডিউস" করে একটা সংখ্যায় আনা।

**🤣 Real-life Analogy:**
**পিকনিকের চাঁদা তোলা।**
রহিম দিল ১০০, করিম দিল ৫০, সখিনা দিল ২০০।
টোটাল = ১০০ + ৫০ + ২০০ = ৩৫০ টাকা।
এখানে `accumulator` হলো সেই টাকার ব্যাগ যেখানে টাকা জমা হচ্ছে।

**💻 Code Example:**
```javascript
const costs = [100, 200, 50, 150];

// total = জমার খাতা, current = বর্তমান টাকা
const totalCost = costs.reduce((total, current) => {
    return total + current;
}, 0); // 0 হলো ব্যাগের শুরুর ব্যালেন্স

console.log(totalCost); // 500
```

**💪 Mini Exercise:**
1. `[1, 2, 3, 4, 5]` - এই অ্যারের সব সংখ্যার গুণফল বের করো `reduce` দিয়ে। (শুরুর ব্যালেন্স 1 দিও, 0 দিলে সব শূন্য হয়ে যাবে!)

**📝 One-line Summary:**
যোগফল, গড় বা টোটাল হিসাব করতে `reduce()` এর জুড়ি নেই।

**🏢 Real Project Importance:**
শপিং কার্টের "Total Price" বের করতে এটা ব্যবহৃত হয়।

### 📖 Lesson 6: Objects Deep Dive (Nested Objects)

**🎯 Learning Goal:** অবজেক্টের ভেতরে অবজেক্ট অ্যাক্সেস করা।

**🗣️ সহজ ব্যাখ্যা:**
সবসময় ডেটা সিম্পল হয় না। অবজেক্টের পেটের ভেতর আরেক অবজেক্ট, তার পেটে অ্যারে... এভাবে থাকতে পারে। এটাকে বলে নেস্টেড অবজেক্ট।

**🤣 Real-life Analogy:**
**মাতৃওশকা পুতুল (Russian Dolls)।** পুতুলের পেটে পুতুল, তার পেটে আরও ছোট পুতুল।

**💻 Code Example:**
```javascript
const user = {
    id: 101,
    name: "Abul",
    address: {
        city: "Dhaka",
        geo: {
            lat: 23.81,
            lng: 90.41
        }
    }
};

// ঢাকার ল্যাটিটিউড বের করবো
console.log(user.address.geo.lat); // 23.81
```

**💪 Mini Exercise:**
1. `user` অবজেক্টে `hobbies` নামে একটা অ্যারে যোগ করো। তারপর সেই অ্যারের ২য় আইটেমটা প্রিন্ট করো।

**⚠️ Common Mistakes:**
- কোনো প্রপার্টি মিসিং থাকলে `Cannot read properties of undefined` এরর খাওয়া।

**📝 One-line Summary:**
ডট (`.`) দিয়ে একটার পর একটা লেভেলে ঢুকতে হয়।

### 📖 Lesson 7: Optional Chaining (সেফটি গিয়ার)

**🎯 Learning Goal:** কোড ক্র্যাশ না করিয়ে নেস্টেড ডেটা চেক করা `?.` দিয়ে।

**🗣️ সহজ ব্যাখ্যা:**
ধরো তুমি `user.address.city` খুঁজছো। কিন্তু কোনো কারণে `address` টাই নাই! তখন কোড ক্র্যাশ করবে। এটা ঠেকাতে `?.` ব্যবহার করা হয়। মানে—"যদি থাকে তো আগাও, না থাকলে থামো"।

**🤣 Real-life Analogy:**
রাস্তায় ব্রিজ আছে কিনা চেক করে পা বাড়ানো। ব্রিজ না থাকলে পা বাড়াবো না (পড়ে মরবো না)।

**💻 Code Example:**
```javascript
const user2 = {
    name: "Babul",
    // address নাই
};

// console.log(user2.address.city); // ❌ Error! Crash!

console.log(user2?.address?.city); // ✅ undefined (No Error)
```

**💪 Mini Exercise:**
1. একটা অবজেক্ট বানাও যেখানে কিছু প্রপার্টি মিসিং, তারপর `?.` দিয়ে চেক করো।

**📝 One-line Summary:**
`?.` হলো লাইফ জ্যাকেট, যেটা ডেটা মিসিং থাকলেও কোড ডুবতে দেয় না।

### 📖 Lesson 8: Object Keys, Values & Entries

**🎯 Learning Goal:** অবজেক্টকে লুপ করা বা অ্যারেতে রূপান্তর করা।

**🗣️ সহজ ব্যাখ্যা:**
অবজেক্টের ওপর সরাসরি লুপ চালানো যায় না। তাই অবজেক্টের চাবি (Keys) বা মালপত্তর (Values) গুলোকে অ্যারে বানিয়ে তারপর লুপ চালাতে হয়।

**🤣 Real-life Analogy:**
একটা আলমারি (Object)।
- **Object.keys():** ড্রয়ারের নামগুলো (শার্টের ড্রয়ার, প্যান্টের ড্রয়ার)।
- **Object.values():** ভেতরের জামাকাপড়গুলো।

**💻 Code Example:**
```javascript
const mobile = {
    brand: "Samsung",
    model: "S24",
    price: 120000
};

console.log(Object.keys(mobile));   // ["brand", "model", "price"]
console.log(Object.values(mobile)); // ["Samsung", "S24", 120000]

// লুপ চালানো
Object.keys(mobile).forEach(key => {
    console.log(`${key}: ${mobile[key]}`);
});
```

**💪 Mini Exercise:**
1. তোমার নিজের ডিটেইলস দিয়ে অবজেক্ট বানাও এবং `Object.values()` দিয়ে শুধু তথ্যগুলো প্রিন্ট করো।

**📝 One-line Summary:**
অবজেক্টকে অ্যারের মতো ট্রিট করতে `keys/values` মেথড লাগে।

### 📖 Lesson 9: JSON (ডেটার প্যাকেট)

**🎯 Learning Goal:** JSON কী এবং এর ব্যবহার (Stringify & Parse)।

**🗣️ সহজ ব্যাখ্যা:**
জাভাস্ক্রিপ্ট অবজেক্ট শুধু ব্রাউজার বোঝে। কিন্তু সার্ভারে পাঠাতে গেলে এটাকে টেক্সট বা স্ট্রিং বানাতে হয়। এই ফরম্যাটই হলো **JSON** (JavaScript Object Notation)।

**🤣 Real-life Analogy:**
ফার্নিচার (Object) শিফট করার সময় খুলে প্যাকেটে ভরো (Stringify)। নতুন বাসায় গিয়ে প্যাকেট খুলে আবার ফিট করো (Parse)।

**💻 Code Example:**
```javascript
const student = { name: "Rohim", age: 10 };

// Object -> JSON String (প্যাকেট করা)
const jsonString = JSON.stringify(student);
console.log(jsonString); 
// Output: '{"name":"Rohim","age":10}'

// JSON String -> Object (প্যাকেট খোলা)
const originalObj = JSON.parse(jsonString);
console.log(originalObj.name); // Rohim
```

**💪 Mini Exercise:**
1. একটা অবজেক্টকে `stringify` করো, তারপর আবার `parse` করে কনসোলে দেখাও।

**⚠️ Common Mistakes:**
- JSON এ সব key অবশ্যই ডাবল কোট `""` এর মধ্যে থাকতে হয়। সিঙ্গেল কোট চলে না।

**📝 One-line Summary:**
ডেটা আদান-প্রদানের আন্তর্জাতিক ভাষা হলো JSON।

**🏢 Real Project Importance:**
API কল করার সময় বা লোকাল স্টোরেজে ডেটা রাখার সময় JSON মাস্ট।

### 📖 Lesson 10: Copying Objects (নকল নাকি আসল?)

**🎯 Learning Goal:** Reference vs Value এবং Spread Operator দিয়ে কপি করা।

**🗣️ সহজ ব্যাখ্যা:**
অবজেক্ট `=` দিয়ে কপি করলে সমস্যা হয়। আসলের সাথে নকলের কানেকশন থেকে যায়। নকলটায় হাত দিলে আসলটাও বদলে যায়! (Reference)।
তাই `...` স্প্রেড অপারেটর দিয়ে নতুন করে কপি বানাতে হয়।

**🤣 Real-life Analogy:**
- **Reference:** বাড়ির চাবি বন্ধুকে দিলে, সে গিয়ে টিভিতে চ্যানেল পাল্টালে তোমার টিভির চ্যানেলও পাল্টে যাবে (কারণ টিভি একটাই)।
- **Spread Copy:** বন্ধুকে নতুন টিভি কিনে দিলে, সে যা খুশি করুক, তোমার টিভিতে প্রভাব পড়বে না।

**💻 Code Example:**
```javascript
const original = { name: "A", food: "Biriyani" };

// ভুল পদ্ধতি (Reference Copy)
const fakeCopy = original;
fakeCopy.food = "Khichuri";
console.log(original.food); // "Khichuri" (হায় হায়! আসলটাও বদলে গেছে!)

// সঠিক পদ্ধতি (Spread Copy)
const realCopy = { ...original };
realCopy.food = "Burger";

console.log(original.food); // "Khichuri" (আগেরটাই আছে, বদলায়নি। সেফ!)
```

**💪 Mini Exercise:**
1. উপরের কোডটা নিজে রান করে প্রমাণ করো যে স্প্রেড অপারেটর সেফ।

**📝 One-line Summary:**
অবজেক্ট বা অ্যারে কপি করতে সবসময় `...` (Spread) ব্যবহার করবে, সরাসরি `=` নয়।
