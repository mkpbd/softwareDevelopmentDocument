# 🖥️ Module 4: DOM & Browser Programming

### 📖 Lesson 1: DOM আসলে কী? (Document Object Model)

**🎯 Learning Goal:** DOM এর কনসেপ্ট বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
তোমার লেখা HTML ফাইলটা ব্রাউজারে লোড হওয়ার পর একটা **গাছ (Tree)** এর মতো স্ট্রাকচার তৈরি করে। এটাই **DOM**।
জাভাস্ক্রিপ্ট এই DOM এর মাধ্যমেই HTML এর সাথে কথা বলে।

**🤣 Real-life Analogy:**
তোমার বাড়ি (Website)।
- **HTML:** ইটের দেয়াল।
- **DOM:** বাড়ির নকশা বা ব্লু-প্রিন্ট, যেটা আর্কিটেক্টের (JS) হাতে থাকে। আর্কিটেক্ট নকশায় দাগ দিলেই মিস্ত্রি দেয়াল ভেঙে ফেলে।

**💻 Code Example:**
(এটা কনসোলে লিখলে পুরো ওয়েবসাইট দেখা যাবে)
```javascript
console.log(document); 
// পুরো HTML ফাইলটা দেখাবে।
console.log(document.body); 
// শুধু বডি ট্যাগ দেখাবে।
```

**💪 Mini Exercise:**
1. যেকোনো ওয়েবসাইটে যাও, `F12` চাপো, Console এ `document.title = "Hacked by Me!"` লেখো। দেখো ট্যাবের নাম পাল্টে গেছে!

**📝 One-line Summary:**
DOM হলো জাভাস্ক্রিপ্ট আর HTML এর মাঝখানের সেতু।

### 📖 Lesson 2: Selecting Elements (ধরো ব্যাটারে!)

**🎯 Learning Goal:** HTML এর এলিমেন্ট খুঁজে বের করা (`getElementById`, `querySelector`)।

**🗣️ সহজ ব্যাখ্যা:**
কোনো কিছু পরিবর্তন করার আগে তাকে তো ধরতে হবে। জাভাস্ক্রিপ্টে আমরা ট্যাগ, আইডি বা ক্লাস দিয়ে এলিমেন্ট ধরতে পারি।

**🤣 Real-life Analogy:**
পুলিশ যেমন হাজার মানুষের ভিড়ে আসামিকে খুঁজে বের করে।
- `getElementById`: আইডি কার্ড দেখে একজনকে ধরা (সবচেয়ে ফাস্ট)।
- `querySelector`: হুলিয়া দেখে ধরা (যেকোনো কিছু দিয়ে খোঁজা যায়)।

**💻 Code Example:**
HTML: `<h1 id="title">Hello World</h1>`

```javascript
// ID দিয়ে ধরা
const myTitle = document.getElementById("title");

// CSS স্টাইলে ধরা
const sameTitle = document.querySelector("#title");
const allHeadings = document.querySelectorAll("h1"); // সব h1 কে ধরবে

console.log(myTitle);
```

**💪 Mini Exercise:**
1. তোমার HTML ফাইলে একটা `<p class="text">Text</p>` বানাও। JS দিয়ে সেটাকে সিলেক্ট করে কনসোলে দেখাও।

**⚠️ Common Mistakes:**
- `getElementById` এর ভেতরে `#` দেওয়া যাবে না, শুধু নাম দিতে হবে।
- `querySelector` এ আইডির আগে `#` আর ক্লাসের আগে `.` দিতেই হবে।

**📝 One-line Summary:**
`getElementById` স্পেসিফিক কিছুর জন্য, আর `querySelector` সব কাজের কাজি।

### 📖 Lesson 3: Changing Content (লেখা বদলানো)

**🎯 Learning Goal:** `innerText` এবং `innerHTML` এর ব্যবহার।

**🗣️ সহজ ব্যাখ্যা:**
এলিমেন্ট তো ধরলাম, এবার সেটার লেখা বদলে দেব।

**🤣 Real-life Analogy:**
দোকানের সাইনবোর্ড মুছে নতুন নাম লেখা।

**💻 Code Example:**
HTML: `<h1 id="msg">Old Text</h1>`

```javascript
const message = document.getElementById("msg");

// শুধু টেক্সট বদলাতে
message.innerText = "New Text Magic!";

// ভেতরে HTML ট্যাগ ঢোকাতে
message.innerHTML = "<span style='color:red'>Red Text</span>";
```

**💪 Mini Exercise:**
1. একটা বাটন বানাও। JS দিয়ে বাটনের লেখা "Click Me" থেকে "Clicked!" করে দাও।

**⚠️ Common Mistakes:**
- `innerHTML` দিয়ে ইউজার ইনপুট শো করানো রিস্কি (হ্যাকাররা স্ক্রিপ্ট ঢুকিয়ে দিতে পারে - XSS Attack)।

**📝 One-line Summary:**
প্লেইন টেক্সটের জন্য `innerText`, আর স্টাইল বা ট্যাগসহ টেক্সটের জন্য `innerHTML`।

### 📖 Lesson 4: Changing Styles (মেকআপ করা)

**🎯 Learning Goal:** জাভাস্ক্রিপ্ট দিয়ে CSS পরিবর্তন করা।

**🗣️ সহজ ব্যাখ্যা:**
CSS দিয়ে তো স্টাইল করাই যায়, কিন্তু JS দিয়ে করলে সেটা ডাইনামিক হয় (ক্লিক করলে রং বদলানো)।

**🤣 Real-life Analogy:**
বিউটি পার্লারে গিয়ে মেকআপ করা। "আপা, আমাকে লাল লিপস্টিক পরিয়ে দিন।"

**💻 Code Example:**
HTML: `<div id="box">Box</div>`

```javascript
const box = document.getElementById("box");

box.style.backgroundColor = "blue"; // background-color হবে না, camelCase হবে
box.style.color = "white";
box.style.fontSize = "50px";
box.style.padding = "20px";
```

**💪 Mini Exercise:**
1. একটা গোল চাকা (div) বানাও। JS দিয়ে সেটার বর্ডার রেডিয়াস ৫০% করে গোল বানিয়ে দাও।

**📝 One-line Summary:**
CSS এর প্রপার্টি `kebab-case` (font-size) কে JS এ `camelCase` (fontSize) হিসেবে লিখতে হয়।

### 📖 Lesson 5: Creating Elements (রাজমিস্ত্রি)

**🎯 Learning Goal:** নতুন HTML এলিমেন্ট তৈরি করা এবং যুক্ত করা (`createElement`, `appendChild`)।

**🗣️ সহজ ব্যাখ্যা:**
শুধু যা আছে তা চেঞ্জ করা না, আমরা শূন্য থেকে নতুন এলিমেন্ট বানিয়ে ওয়েবসাইটে বসাতে পারি।
ধাপ ৩টি:
১. বানাও (`createElement`)
২. সাজাও (`innerText`, `style`)
৩. বসাও (`appendChild`)

**🤣 Real-life Analogy:**
নতুন ঘর তোলা।
১. ইট দিয়ে দেয়াল তোলা।
২. রং করা।
৩. বাড়ির সাথে যুক্ত করা।

**💻 Code Example:**
```javascript
// ১. তৈরি করা
const newBtn = document.createElement("button");

// ২. সাজানো
newBtn.innerText = "Click Me";
newBtn.style.backgroundColor = "green";

// ৩. বডিতে বসানো (Body বা অন্য কোনো div এর পেটে ঢোকানো)
const container = document.getElementById("container"); // যদি থাকে
document.body.appendChild(newBtn); 
```

**💪 Mini Exercise:**
1. JS দিয়ে একটা `<li>` বানাও যাতে লেখা থাকবে "New Item", এবং সেটাকে একটা `<ul>` এর ভেতরে ঢোকাও।

**📝 One-line Summary:**
`createElement` দিয়ে জন্ম দেওয়া, `appendChild` দিয়ে ঘরে তোলা।

### 📖 Lesson 6: Event Listeners (সুইচ টেপা)

**🎯 Learning Goal:** ক্লিক, মাউস মুভ ইত্যাদি ইভেন্ট হ্যান্ডেল করা (`addEventListener`)।

**🗣️ সহজ ব্যাখ্যা:**
এতক্ষণ যা করলাম তা পেজ লোড হওয়ামাত্র হয়ে যাচ্ছিল। এখন আমরা চাই ইউজার যখন কিছু করবে (ক্লিক করবে), তখন কাজ হবে। কান পেতে থাকা—কখন ইউজার ক্লিক করবে।

**🤣 Real-life Analogy:**
**কলিং বেল।** কেউ সুইচে চাপ দিলে (Event), ঘরের ভেতরে শব্দ হবে (Function Execute)।

**💻 Code Example:**
HTML: `<button id="btn">Magic</button>`

```javascript
const btn = document.getElementById("btn");

// কান পেতে থাকলাম (Listen)
btn.addEventListener("click", function() {
    console.log("Button clicked!");
    document.body.style.backgroundColor = "gold";
});
```

**💪 Mini Exercise:**
1. এমন একটা বাটন বানাও, যাতে ক্লিক করলে ব্যাকগ্রাউন্ড কালার র‍্যান্ডমলি চেঞ্জ হয়।

**⚠️ Common Mistakes:**
- `onclick` HTML এ লেখা (পুরানো পদ্ধতি)। `addEventListener` ব্যবহার করা বেস্ট প্র্যাকটিস।

**📝 One-line Summary:**
ওয়েবসাইটকে ইন্টারেক্টিভ করতে `addEventListener` এর বিকল্প নেই।

### 📖 Lesson 7: Getting Input Values (মনের কথা শোনা)

**🎯 Learning Goal:** ইনপুট ফিল্ড থেকে ডেটা নেওয়া।

**🗣️ সহজ ব্যাখ্যা:**
লগইন ফর্ম বা সার্চ বক্সে ইউজার যা লেখে, সেটা আমরা কীভাবে পাবো? `.value` প্রপার্টি দিয়ে।

**🤣 Real-life Analogy:**
সাজেশন বক্সে চিঠি ফেলা। আমি চাবি দিয়ে বক্স খুলে চিঠিটা বের করে পড়লাম।

**💻 Code Example:**
HTML: 
```html
<input type="text" id="username" placeholder="Name">
<button id="submit">Submit</button>
```

JS:
```javascript
document.getElementById("submit").addEventListener("click", function() {
    const inputField = document.getElementById("username");
    const name = inputField.value; // ভ্যালু বের করলাম
    
    console.log("User entered:", name);
    inputField.value = ""; // কাজ শেষে ইনপুট বক্স খালি করে দিলাম
});
```

**💪 Mini Exercise:**
1. দুটি ইনপুট ফিল্ড নাও। বাটনে ক্লিক করলে দুটির যোগফল অ্যালার্টে দেখাও।

**📝 One-line Summary:**
ইনপুট বক্স, ড্রপডাউন বা টেক্সটএরিয়া থেকে ডেটা পেতে `.value` ব্যবহার করো।

### 📖 Lesson 8: Event Bubbling (চুগলখোরি)

**🎯 Learning Goal:** ইভেন্ট বাবলিং এবং `stopPropagation` বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
ধরো একটা বড় বাক্সের ভেতর ছোট বাক্স, তার ভেতর একটা বাটন। তুমি বাটনে ক্লিক করলে আসলে তিনজনেই ক্লিক খায় (নিচ থেকে উপরে)। এটাকে বলে **Bubbling** (বুদবুদ যেমন নিচ থেকে উপরে ওঠে)।

**🤣 Real-life Analogy:**
ছোট ভাই (Button) মার খেল। সে গিয়ে মাকে (Parent Div) বলল। মা গিয়ে বাবাকে (Body) বলল। পুরো পরিবার জেনে গেল!
এটা থামাতে `stopPropagation` লাগে (মানে মাকে বলে দিলাম "কাউকে বলবা না")।

**💻 Code Example:**
HTML: `<div id="parent"><button id="child">Click</button></div>`

```javascript
document.getElementById("parent").addEventListener("click", () => {
    console.log("Parent clicked!");
});

document.getElementById("child").addEventListener("click", (event) => {
    event.stopPropagation(); // বাবাকে জানতে দেবে না
    console.log("Child clicked!");
});
```

**💪 Mini Exercise:**
1. `stopPropagation` ছাড়া কোডটা চালিয়ে দেখো কী হয়, তারপর দিয়ে দেখো।

**📝 One-line Summary:**
ইভেন্ট নিচ থেকে উপরে ছড়ায়, থামাতে `event.stopPropagation()` লাগে।

### 📖 Lesson 9: LocalStorage (ব্রাউজারের পকেট)

**🎯 Learning Goal:** ডেটা ব্রাউজারে পার্মানেন্টলি সেভ করে রাখা।

**🗣️ সহজ ব্যাখ্যা:**
রিফ্রেশ দিলে ভেরিয়েবলের মান হারিয়ে যায়। কিন্তু `localStorage` এ রাখলে ব্রাউজার বন্ধ করে চালু করলেও ডেটা থাকে।

**🤣 Real-life Analogy:**
- **RAM (Variable):** ব্ল্যাকবোর্ডে লেখা (মুছে যায়)।
- **LocalStorage:** ডায়েরিতে লিখে রাখা (থেকে যায়)।

**💻 Code Example:**
```javascript
// ডেটা রাখা (Set)
localStorage.setItem("userName", "Rahim");

// ডেটা আনা (Get)
const storedName = localStorage.getItem("userName");
console.log(storedName);

// ডেটা মুছে ফেলা (Remove)
// localStorage.removeItem("userName");
```
*টিপস: অবজেক্ট বা অ্যারে রাখতে চাইলে আগে `JSON.stringify` করতে হয়।*

**💪 Mini Exercise:**
1. একটা ইনপুট নাও, বাটনে ক্লিক করলে নামটা লোকাল স্টোরেজে সেভ হবে। রিফ্রেশ দেওয়ার পর নামটা কনসোলে প্রিন্ট করো।

**📝 One-line Summary:**
ছোটখাটো ডেটা (যেমন থিম কালার, ইউজার নেম) ব্রাউজারে জমা রাখতে `localStorage` সেরা।

### 📖 Lesson 10: Timers (টাইম বোম)

**🎯 Learning Goal:** `setTimeout` এবং `setInterval` এর ব্যবহার।

**🗣️ সহজ ব্যাখ্যা:**
- **`setTimeout`**: নির্দিষ্ট সময় পর **একবার** কাজ করবে।
- **`setInterval`**: নির্দিষ্ট সময় পরপর **বারবার** কাজ করবে।

**🤣 Real-life Analogy:**
- **Timeout:** ওভেনের টাইমার। ৫ মিনিট পর "টিং" করে বন্ধ হবে।
- **Interval:** হার্টবিট। প্রতি সেকেন্ডে "লুব-ডুব" করতেই থাকবে।

**💻 Code Example:**
```javascript
console.log("1. Khela shuru");

setTimeout(() => {
    console.log("2. Ami 3 second pore aslam!");
}, 3000); // 3000 ms = 3 seconds

console.log("3. Khela shesh");
// আউটপুট অর্ডারে খেয়াল করো: ১ -> ৩ -> ২
```

**💪 Mini Exercise:**
