# ✨ Module 6: ES6+ Modern JavaScript

### 📖 Lesson 1: Var vs Let/Const (শেষ বিবাদ)

**🎯 Learning Goal:** `var` কেন ব্যবহার করবো না এবং `Block Scope` কী তা পুরোপুরি বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
- **Var:** পুরানো আমলের নেতা। তার কোনো বাউন্ডারি জ্ঞান নেই। ঘরের কথা (Block) বাইরে বলে দেয়।
- **Let/Const:** ভদ্রলোক। ঘরের কথা ঘরের ভেতরেই রাখে `{}`।

**🤣 Real-life Analogy:**
- **Var:** পাড়ার বখাটে ছেলে। বাসার ছাদে (Block) উঠে চিল্লালে পুরো এলাকা শোনে (Global Leak)।
- **Let/Const:** তোমার রুমের সাউন্ডপ্রুফ দেয়াল। ভেতরে ডিস্কো ড্যান্স দিলেও বাইরে শব্দ যায় না।

**💻 Code Example:**
```javascript
// Var এর সমস্যা (Lickage)
if (true) {
    var boka = "Ami Baire Jabo";
}
console.log(boka); // "Ami Baire Jabo" (হায় হায়! বাইরে চলে এসেছে!)

// Let এর ভদ্রতা (Block Scope)
if (true) {
    let smart = "Ami Gopon";
    const alsoSmart = "Ami o Gopon";
}
// console.log(smart); // ❌ Error! বাইরে থেকে দেখা যাবে না।
```

**💪 Mini Exercise:**
1. একটা `for` লুপে `var i = 0` দিয়ে লুপ চালাও। লুপের বাইরে `i` প্রিন্ট করো। দেখো কী হয় (সর্বনাশ)!
2. এরপর `let i = 0` দিয়ে করো এবং এরর দেখো (যেটা ভালো)।

**📝 One-line Summary:**
`var` কে মিউজিয়ামে পাঠিয়ে দাও, সবসময় `let` আর `const` ব্যবহার করো।

### 📖 Lesson 2: Classes (ব্লু-প্রিন্ট বা নকশা)

**🎯 Learning Goal:** `class` কিওয়ার্ড দিয়ে অবজেক্ট তৈরির ছাঁচ বানানো।

**🗣️ সহজ ব্যাখ্যা:**
আগে আমরা শুধু অবজেক্ট বানাতাম। কিন্তু একই রকম ১০০টা অবজেক্ট বানাতে গেলে ১০০ বার কোড লেখা লাগত।
**Class** হলো একটা ছাঁচ বা মেশিন। মেশিনে মশলা (Data) ঢালবে, আর ধুপধাপ অবজেক্ট বের হবে।

**🤣 Real-life Analogy:**
**বিস্কুট ফ্যাক্টরি।**
- **Class:** বিস্কুটের ছাঁচ (Mould)।
- **Object:** ছাঁচ থেকে বের হওয়া আসল বিস্কুটগুলো।

**💻 Code Example:**
```javascript
class Hero {
    // Constructor হলো মেশিনের ইনপুট মুখ
    constructor(name, power) {
        this.name = name;
        this.power = power;
    }

    attack() {
        return `${this.name} is attacking with ${this.power}!`;
    }
}

// ছাঁচ থেকে হিরো বানাচ্ছি (Instance)
const sakib = new Hero("Sakib", "Acting");
const batman = new Hero("Batman", "Money");

console.log(sakib.attack()); 
console.log(batman.attack());
```

**💪 Mini Exercise:**
1. `Student` নামে একটা ক্লাস বানাও যেখানে `name` আর `roll` থাকবে। একটা মেথড থাকবে `present()` যা বলবে "Roll X is present!"।

**⚠️ Common Mistakes:**
- ক্লাসের নাম সবসময় **Capital Letter** দিয়ে শুরু করতে হয় (Convention)।

**📝 One-line Summary:**
বারবার একই রকম অবজেক্ট বানাতে `class` ব্যবহার করো।

### 📖 Lesson 3: Inheritance (বাপ কা বেটা)

**🎯 Learning Goal:** `extends` এবং `super` দিয়ে এক ক্লাসের বৈশিষ্ট্য অন্য ক্লাসে আনা।

**🗣️ সহজ ব্যাখ্যা:**
বাবার সব সম্পত্তি যেমন সন্তান পায়, তেমনি এক ক্লাসের সব কোড অন্য ক্লাসে নিয়ে আসা যায় **Inheritance** দিয়ে। কোড কপি-পেস্ট করা লাগে না।

**🤣 Real-life Analogy:**
বাবা (Parent Class) জানে কীভাবে টাকা আয় করতে হয়। ছেলে (Child Class) বাবার সেই বিদ্যা তো পেলই, সাথে সে নিজেও ইউটিউবিং পারে।
বাবার গুণ + নিজের গুণ = সুপার ছেলে।

**💻 Code Example:**
```javascript
// বাবা ক্লাস
class Father {
    asset() {
        return "Barir Dolil";
    }
}

// ছেলে ক্লাস (বাবার সব পাবে)
class Son extends Father {
    skill() {
        return "Web Development";
    }
}

const mySon = new Son();
console.log(mySon.asset()); // Barir Dolil (বাবারটা পেয়েছে!)
console.log(mySon.skill()); // Web Development (নিজেরটা)
```

**💪 Mini Exercise:**
1. `Car` ক্লাস বানাও (চাকা আছে)। `Ferrari` ক্লাস বানাও যেটা `Car` কে এক্সটেন্ড করে এবং এক্সট্রা স্পিড দেখায়।

**📝 One-line Summary:**
`extends` কিওয়ার্ড দিয়ে কোড রিইউজ করা হয়, যাতে একই কোড বারবার লিখতে না হয়।

### 📖 Lesson 4: Modules (Import / Export)

**🎯 Learning Goal:** কোডকে বিভিন্ন ফাইলে ভাগ করে রাখা।

**🗣️ সহজ ব্যাখ্যা:**
হাজার লাইনের কোড এক ফাইলে লিখলে সেটা জগাখিচুড়ি হয়ে যায়। তাই আমরা আলাদা আলাদা ফাইলে কোড রাখি।
- **Export:** দোকান থেকে পণ্য বিদেশে পাঠানো।
- **Import:** বিদেশ থেকে পণ্য দেশে আনা।

**🤣 Real-life Analogy:**
তোমার বাসায় সব কিছু তৈরি হয় না। চাল আসে গ্রাম থেকে (Export), তুমি ঢাকায় বসে রিসিভ করো (Import), তারপর রান্না করো।

**💻 Code Example:**
*File: math.js (দোকান)*
```javascript
export const add = (a, b) => a + b;
export const pi = 3.1416;
```

*File: main.js (বাসা)*
```javascript
import { add, pi } from './math.js';

console.log(add(10, 5)); // 15
console.log(pi);
```
*(নোট: ব্রাউজারে টেস্ট করতে হলে HTML ফাইলে script ট্যাগে `type="module"` দিতে হবে)*

**💪 Mini Exercise:**
1. দুটি ফাইল বানাও। একটায় তোমার নাম `export` করো, অন্যটায় `import` করে কনসোলে দেখাও।

**📝 One-line Summary:**
বড় প্রজেক্ট ম্যানেজ করতে ফাইল ভাগ করে `import/export` করা বাধ্যতামূলক।

### 📖 Lesson 5: Sets (ডুপ্লিকেট নট এলাউড)

**🎯 Learning Goal:** `Set` ব্যবহার করে ইউনিক ডেটা রাখা।

**🗣️ সহজ ব্যাখ্যা:**
অ্যারেতে একই জিনিস বারবার রাখা যায়। কিন্তু `Set` হলো কড়া সিকিউরিটি গার্ড। একই লোক দুইবার ঢুকতে পারবে না। ডুপ্লিকেট ভ্যালু অটোমেটিক ডিলিট হয়ে যায়।

**🤣 Real-life Analogy:**
বিয়ের দাওয়াত। এক কার্ডে একজনই ঢুকবে। ফটোকপি করে আনলে গার্ড ঘাড় ধাক্কা দিয়ে বের করে দেবে।

**💻 Code Example:**
```javascript
const numbers = [1, 2, 2, 3, 4, 4, 5];

// Array থেকে Set বানালাম (Duplicate গায়েব)
const uniqueSet = new Set(numbers);

console.log(uniqueSet); // Set {1, 2, 3, 4, 5}

// আবার Array তে ফেরত আনা
const uniqueArray = [...uniqueSet];
console.log(uniqueArray); // [1, 2, 3, 4, 5]
```

**💪 Mini Exercise:**
1. `["Abul", "Babul", "Abul", "Kabul"]` - এই অ্যারে থেকে ডুপ্লিকেট নামগুলো সরিয়ে ফেলো `Set` দিয়ে।

**📝 One-line Summary:**
ডুপ্লিকেট রিমুভ করার সবচেয়ে সহজ উপায় হলো `new Set()`।

### 📖 Lesson 6: Maps (অ্যাডভান্সড অবজেক্ট)

**🎯 Learning Goal:** `Map` ডেটা স্ট্রাকচার বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
সাধারণ অবজেক্টে `key` সবসময় স্ট্রিং হতে হয়। কিন্তু `Map` এ তুমি যা খুশি তাই `key` বানাতে পারো (সংখ্যা, ফাংশন, বা অন্য অবজেক্ট)। তাছাড়া `Map` অর্গানাইজড থাকে এবং এর সাইজ বের করা সহজ।

**🤣 Real-life Analogy:**
সাধারণ অবজেক্ট হলো বাজারের ফর্দ (শুধু নাম লেখা যায়)।
আর `Map` হলো সুপারশপের ডাটাবেস—বারকোড, ছবি, নাম্বার সব কিছু দিয়ে প্রোডাক্ট খোঁজা যায়।

**💻 Code Example:**
```javascript
const myMap = new Map();

myMap.set('name', 'Rahim'); // String Key
myMap.set(10, 'This is a number key'); // Number Key
myMap.set(true, 'This is boolean'); // Boolean Key

console.log(myMap.get(10)); // 'This is a number key'
console.log(myMap.size);    // 3
```

**💪 Mini Exercise:**
1. একটা ম্যাপ বানাও যেখানে বাংলাদেশের ৩টি জেলার নাম Key এবং তাদের বিখ্যাত খাবারের নাম Value হিসেবে থাকবে।

**📝 One-line Summary:**
যদি কি-ভ্যালু পেয়ার নিয়ে অ্যাডভান্সড কাজ করতে হয়, তবে অবজেক্টের চেয়ে `Map` ভালো।

### 📖 Lesson 7: For...of Loop (মডার্ন লুপ)

**🎯 Learning Goal:** অ্যারে বা স্ট্রিং লুপ করার সহজ উপায়।

**🗣️ সহজ ব্যাখ্যা:**
`for` লুপে `i++` লেখা বোরিং। `forEach` একটু স্লো।
`for...of` হলো সবচেয়ে স্মার্ট লুপ। "এই বস্তার সব আলুর জন্য..."—এভাবে কাজ করে।

**🤣 Real-life Analogy:**
তসবিহ পড়া। একটার পর একটা দানা (Item) গুনতে থাকো যতক্ষণ না শেষ হয়। ইনডেক্স বা নাম্বার গোনার দরকার নেই।

**💻 Code Example:**
```javascript
const fruits = ["Mango", "Jam", "Kathal"];

// Smart Loop
for (const fruit of fruits) {
    console.log(fruit);
}

const name = "Bangladesh";
// স্ট্রিংও লুপ করা যায়!
for (const char of name) {
    console.log(char); // B, a, n...
}
```

**💪 Mini Exercise:**
1. একটা নাম্বারের অ্যারে নাও। `for...of` দিয়ে লুপ চালিয়ে সব সংখ্যার যোগফল বের করো।

**📝 One-line Summary:**
অ্যারের ওপর লুপ চালানোর জন্য `for...of` সবচেয়ে ক্লিন সিনট্যাক্স।

### 📖 Lesson 8: Generators (থামা বা পজ করা ফাংশন)

**🎯 Learning Goal:** `function*` এবং `yield` বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
সাধারণ ফাংশন একবার কল করলে দৌড় দিয়ে শেষ মাথায় গিয়ে থামে। মাঝখানে থামানো যায় না।
**Generator Function** কে বলা যায় "দাঁড়াও", "চলো", "আবার দাঁড়াও"। এটা `yield` দেখলে পজ করে, আবার `next()` বললে চলে।

**🤣 Real-life Analogy:**
**ভিডিও প্লেয়ার।** তুমি প্লে করছো (Start), পজ করছো (Yield), আবার প্লে করছো (Next)।

**💻 Code Example:**
```javascript
// নামের পরে একটা * থাকে
function* simpleGenerator() {
    yield "Prothom Dhap";
    yield "Ditiyo Dhap";
    yield "Shesh Dhap";
}

const gen = simpleGenerator();

console.log(gen.next().value); // "Prothom Dhap"
// এখানে ফাংশন পজ হয়ে আছে...

console.log(gen.next().value); // "Ditiyo Dhap"
console.log(gen.next().value); // "Shesh Dhap"
```

**💪 Mini Exercise:**
1. কোডটা কপি করে চালাও এবং দেখো প্রতিবার `next()` কল করলে কী আসে।

**📝 One-line Summary:**
ফাংশনের ফ্লো নিজের হাতে কন্ট্রোল করতে জেনারেটর লাগে (যদিও রিয়েল লাইফে কম লাগে, কিন্তু জেনে রাখা ভালো)।

### 📖 Lesson 9: Symbols (গোপন সংকেত)

**🎯 Learning Goal:** ইউনিক আইডেন্টিফায়ার তৈরি করা।

**🗣️ সহজ ব্যাখ্যা:**
সিম্বল হলো এমন এক জিনিস যা কখনো অন্যের সাথে মেলে না। তুমি যদি দুইবার একই সিম্বল বানাও, তবুও তারা আলাদা।

**🤣 Real-life Analogy:**
দুইজন মানুষের আঙুলের ছাপ (Fingerprint)। দেখতে একই মনে হতে পারে, কিন্তু আসলে সম্পূর্ণ আলাদা।

**💻 Code Example:**
```javascript
const sym1 = Symbol("Desh");
const sym2 = Symbol("Desh");
```

### 📖 Lesson 10: Nullish Coalescing (??) - নতুন গেস্ট

**🎯 Learning Goal:** `??` এবং `||` এর পার্থক্য বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
আমরা ডিফল্ট ভ্যালু সেট করতে `||` (OR) ব্যবহার করতাম। কিন্তু `||` এর সমস্যা হলো সে `0` বা `false` কেও "নাই" মনে করে।
`??` (Nullish Coalescing) শুধু তখনই কাজ করে যখন ভ্যালু আসলেই `null` বা `undefined` হয়।

**🤣 Real-life Analogy:**
- **`||`**: পকেটে ০ টাকা আছে। `||` বলবে "তোমার টাকা নাই, ঋণ নাও"। (ভুল কথা, ০ টাকাও টাকা)।
- **`??`**: পকেটে ০ টাকা আছে। `??` বলবে "টাকা তো আছেই (০), ঋণের দরকার নাই"।

**💻 Code Example:**
```javascript
let money = 0;

// Old problem
let myBalance = money || 500; 
console.log(myBalance); // 500 (ভুল! আমার তো ০ টাকা আছে, ৫০০ কেন দেখাবে?)

// Modern Solution
let realBalance = money ?? 500;
console.log(realBalance); // 0 (সঠিক! ০ টাকা দেখিয়েছে)
```

**💪 Mini Exercise:**
1. `let speed = 0;` নাও। এবার `??` দিয়ে চেক করো স্পিড সেট করা আছে কিনা।

**📝 One-line Summary:**
সঠিকভাবে ডিফল্ট ভ্যালু সেট করতে `||` এর বদলে `??` ব্যবহার করা বেশি নিরাপদ।
