# 🏗️ Module 7: OOP in JavaScript

### 📖 Lesson 1: OOP আসলে কী? (বস্তু ও জীবন)

**🎯 Learning Goal:** OOP এর মূল ধারণা (Concept) বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
প্রোগ্রামিংকে রিয়েল লাইফের বস্তুর (Object) সাথে তুলনা করা।
একটা গাড়ির কথা ভাবো।
- **Properties (বৈশিষ্ট্য):** রঙ, মডেল, স্পিড।
- **Methods (কাজ):** স্টার্ট হওয়া, ব্রেক করা, হর্ন দেওয়া।
কোডকেও আমরা এভাবে অবজেক্ট আকারে চিন্তা করবো।

**🤣 Real-life Analogy:**
হিউম্যান বডি।
- হাত, পা, চোখ হলো **Properties**।
- হাঁটা, দেখা, খাওয়া হলো **Methods**।

**💻 Code Example:**
(আমরা কোডকে এভাবে অবজেক্টের ভেতরে গুছিয়ে ফেলি)
```javascript
const car = {
    brand: "Toyota",  // Property
    speed: 100,       // Property
    
    start: function() { // Method
        console.log("Gari chola shuru korlo... Vroom Vroom!");
    }
};

car.start();
```

**💪 Mini Exercise:**
1. তোমার নিজেকে নিয়ে একটা অবজেক্ট বানাও। নাম, বয়স (Property) দাও এবং `sleep` নামে একটা মেথড দাও যা প্রিন্ট করবে "Zzzzz..."।

**📝 One-line Summary:**
কোডকে ভেরিয়েবল আর ফাংশনের জগাখিচুড়ি না বানিয়ে অবজেক্ট হিসেবে সাজানোই OOP।

### 📖 Lesson 2: Class & Constructor (ফ্যাক্টরি মেশিন)

**🎯 Learning Goal:** ক্লাস এবং কনস্ট্রাক্টর ফাংশনের গভীর ব্যবহার।

**🗣️ সহজ ব্যাখ্যা:**
মডিউল ৬-এ আমরা ক্লাস দেখেছি। ক্লাস হলো ব্লু-প্রিন্ট। আর `constructor` হলো সেই ফাংশন যেটা ক্লাস থেকে অবজেক্ট তৈরি হওয়ার সময় **প্রথমেই** রান হয় এবং ভেরিয়েবল সেট করে।

**🤣 Real-life Analogy:**
জন্মনিবন্ধন। বাচ্চা জন্মানোর সাথে সাথেই (Constructor) তার নাম আর বাবার নাম রেজিস্টারে লিখে ফেলা হয়। এটা পরে আর সেট করতে হয় না।

**💻 Code Example:**
```javascript
class Player {
    constructor(name, goals) {
        this.name = name;   // এই প্লেয়ারের নাম
        this.goals = goals; // এই প্লেয়ারের গোল
        console.log("Notun Player Toiri Holo!");
    }
}

const messi = new Player("Messi", 800);
const ronaldo = new Player("Ronaldo", 850);

console.log(messi.name); // Messi
```

**💪 Mini Exercise:**
1. `Book` নামে ক্লাস বানাও। কনস্ট্রাক্টরে `title` আর `author` নাও। অবজেক্ট বানানোর সময় কনসোলে প্রিন্ট হবে "Book Created!"

**⚠️ Common Mistakes:**
- `constructor` এর বানান ভুল করা (খুবই কমন)।
- `this.name = name` না লিখলে ভ্যালু সেভ হবে না।

**📝 One-line Summary:**
অবজেক্ট তৈরির সময় প্রাথমিক ডেটা সেট করতে `constructor` ব্যবহৃত হয়।

### 📖 Lesson 3: Encapsulation (গোপন সিন্দুক)

**🎯 Learning Goal:** প্রাইভেট ফিল্ড (`#variable`) ব্যবহার করে ডেটা প্রটেক্ট করা।

**🗣️ সহজ ব্যাখ্যা:**
সব ডেটা সবার দেখার জন্য না। ব্যাংকের ব্যালেন্স বা পাসওয়ার্ড বাইরে থেকে চেঞ্জ করা উচিত না।
জাভাস্ক্রিপ্টে ভেরিয়েবলের আগে `#` (হ্যাশ) দিলে সেটা **Private** হয়ে যায়। ক্লাসের বাইরে থেকে সেটা ছোঁয়াও যায় না।

**🤣 Real-life Analogy:**
এটিএম মেশিনের ভেতরের টাকা। তুমি মেশিনের বাইরের বাটন টিপতে পারো (Public Method), কিন্তু ভেতরের টাকার বক্সে হাত ঢোকাতে পারো না (Private Property)।

**💻 Code Example:**
```javascript
class BankAccount {
    #balance; // প্রাইভেট ভেরিয়েবল (সামনে # আছে)

    constructor(initialBalance) {
        this.#balance = initialBalance;
    }

    getBalance() {
        return `Tomar balance: ${this.#balance}`;
    }
}

const myAccount = new BankAccount(5000);

console.log(myAccount.getBalance()); // Tomar balance: 5000
// console.log(myAccount.#balance); // ❌ Error! বাইরে থেকে ধরা নিষেধ!
```

**💪 Mini Exercise:**
1. `#salary` নামে একটা প্রাইভেট ফিল্ড বানাও এবং চেষ্টা করো বাইরে থেকে সেটা প্রিন্ট করতে। দেখো এরর দেয় কিনা।

**📝 One-line Summary:**
নিরাপদ রাখতে সেনসিটিভ ডেটার আগে `#` বসিয়ে প্রাইভেট করে দাও।

### 📖 Lesson 4: Getters & Setters (দারোয়ান)

**🎯 Learning Goal:** `get` এবং `set` দিয়ে ভ্যালু কন্ট্রোল করা।

**🗣️ সহজ ব্যাখ্যা:**
সরাসরি ভেরিয়েবলে হাত দিতে দেব না। ভ্যালু নেওয়ার সময় `get` আর সেট করার সময় `set` মেথডের মাধ্যমে আসতে হবে। এখানে আমরা শর্ত জুড়ে দিতে পারি (যেমন: নেগেটিভ ব্যালেন্স সেট করা যাবে না)।

**🤣 Real-life Analogy:**
ক্লাবে ঢোকার সময় বাউন্সার (Setter)। চেক করবে বয়স ১৮+ কিনা। ১৮ এর কম হলে ঢুকতে দেবে না।

**💻 Code Example:**
```javascript
class User {
    constructor(name) {
        this._name = name;
    }

    // ভ্যালু আনার দারোয়ান
    get name() {
        return this._name.toUpperCase(); // নাম সবসময় বড় হাতের দেখাবে
    }

    // ভ্যালু সেট করার দারোয়ান
    set name(newName) {
        if (newName.length < 3) {
            console.log("Name too short!");
            return;
        }
        this._name = newName;
    }
}

const user1 = new User("Rahim");
user1.name = "Al"; // ❌ Name too short!
console.log(user1.name); // RAHIM
```

**💪 Mini Exercise:**
1. এমন একটা সেটার (Setter) বানাও যেটা পাসওয়ার্ড সেট করার সময় চেক করবে পাসওয়ার্ড ৬ অক্ষরের বেশি কিনা।

**📝 One-line Summary:**
ডেটা এক্সেস এবং মডিফাই করার সময় লজিক বসাতে Getters/Setters লাগে।

### 📖 Lesson 5: Static Methods (সবার সম্পত্তি)

**🎯 Learning Goal:** `static` কিওয়ার্ডের ব্যবহার।

**🗣️ সহজ ব্যাখ্যা:**
কিছু মেথড কোনো নির্দিষ্ট অবজেক্টের জন্য না, বরং পুরো ক্লাসের জন্য। এগুলোকে অবজেক্ট তৈরি না করেই কল করা যায়।

**🤣 Real-life Analogy:**
পার্কের বেঞ্চ। এটা রহিম বা করিমের ব্যক্তিগত না, এটা সবার।
অথবা, `Date.now()`—এটা ব্যবহার করতে আমাদের `new Date()` বানানো লাগে না।

**💻 Code Example:**
```javascript
class Calculator {
    static add(a, b) {
        return a + b;
    }
}

// const calc = new Calculator(); // এসবের দরকার নাই
console.log(Calculator.add(10, 20)); // সরাসরি ক্লাসের নাম ধরে কল
```

**💪 Mini Exercise:**
1. `Config` নামে একটা ক্লাস বানাও, যেখানে `static appName = "My App"` থাকবে। অবজেক্ট না বানিয়ে প্রিন্ট করো।

**📝 One-line Summary:**
ইউটিলিটি ফাংশন বানাতে `static` ব্যবহার হয়, যা অবজেক্ট ছাড়াই কল করা যায়।

### 📖 Lesson 6: Inheritance Deep Dive (উত্তরাধিকার)

**🎯 Learning Goal:** `super()` এর ব্যবহার বোঝা।

**🗣️ সহজ ব্যাখ্যা:**
বাবা ক্লাসের কনস্ট্রাক্টর যদি স্পেশাল কিছু করে, তবে সন্তান ক্লাসে `super()` কল করে বাবাকে আগে জানাতে হয়—"বাবা, তোমার কাজটা আগে করো, তারপর আমি আমারটা করবো।"

**🤣 Real-life Analogy:**
বিয়ে বাড়িতে বাবা আগে স্টেজে ওঠে, তারপর ছেলে ওঠে। `super()` মানে বাবাকে আগে কল করা।

**💻 Code Example:**
```javascript
class Animal {
    constructor(name) {
        this.name = name;
    }
    speak() {
        console.log(`${this.name} sounds...`);
    }
}

class Dog extends Animal {
    constructor(name, breed) {
        super(name); // বাবার কনস্ট্রাক্টর কল করলাম (নাম সেট করার জন্য)
        this.breed = breed; // নিজের এক্সট্রা প্রপার্টি
    }
    
    bark() {
        console.log("Woof! Woof!");
    }
}

const tommy = new Dog("Tommy", "German Shepherd");
console.log(tommy.name); // Tommy
```

**💪 Mini Exercise:**
1. `Employee` ক্লাস থেকে `Manager` ক্লাস এক্সটেন্ড করো। ম্যানেজারের এক্সট্রা প্রপার্টি দাও `department`।

**⚠️ Common Mistakes:**
- `extends` করা ক্লাসে `constructor` লিখলে অবশ্যই প্রথমে `super()` কল করতে হবে, নাহলে এরর খাবে।

**📝 One-line Summary:**
চাইল্ড ক্লাসে কনস্ট্রাক্টর ব্যবহারের সময় `super()` কল করা বাধ্যতামূলক।

### 📖 Lesson 7: Polymorphism (বহুরূপী)

**🎯 Learning Goal:** একই মেথড কিন্তু ভিন্ন আচরণ (Method Overriding)।

**🗣️ সহজ ব্যাখ্যা:**
প্যারেন্ট ক্লাসে একটা মেথড আছে, চাইল্ড ক্লাসে একই নামের মেথড আছে কিন্তু কাজ আলাদা। চাইল্ড ক্লাস বাবার মেথডকে ওভাররাইড (বাতিল করে নিজেরটা চালানো) করে। একে বলে **পলিমরফিজম** (Many Forms)।

**🤣 Real-life Analogy:**
**"বিয়ে করো"** আদেশ।
- বাবার আমল: দেখেশুনে অ্যারেঞ্জ ম্যারেজ।
- ছেলের আমল: পালিয়ে গিয়ে লাভ ম্যারেজ।
আদেশ একটাই "বিয়ে করো", কিন্তু বাস্তবায়ন পদ্ধতি আলাদা।

**💻 Code Example:**
```javascript
class Father {
    dream() {
        console.log("Amar chele Doctor hobe!");
    }
}

class Son extends Father {
    // বাবার স্বপ্ন ওভাররাইড করে দিলাম
    dream() {
        console.log("Na baba, ami YouTuber hobo!");
    }
}

const boy = new Son();
boy.dream(); // Output: Na baba, ami YouTuber hobo!
```

**💪 Mini Exercise:**
1. `Shape` ক্লাসে `draw()` মেথড আছে। `Circle` এবং `Square` ক্লাসে সেই `draw()` মেথডকে আলাদা আলাদা ভাবে ইমপ্লিমেন্ট করো।

**📝 One-line Summary:**
একই নামের ফাংশন পরিস্থিতি ভেদে ভিন্ন কাজ করাই হলো পলিমরফিজম।

### 📖 Lesson 8: Prototypes (অবজেক্টের আত্মা)

**🎯 Learning Goal:** জাভাস্ক্রিপ্ট ক্লাস আসলে কীভাবে কাজ করে (Prototype)।

**🗣️ সহজ ব্যাখ্যা:**
জাভাস্ক্রিপ্টে `class` বলে আসলে কিছু নেই! এটা একটা মেকআপ। ভেতরে ভেতরে সব কাজ হয় **Prototype** দিয়ে। প্রত্যেকটা অবজেক্টের একটা গোপন লিংক থাকে তার প্যারেন্টের সাথে।

**🤣 Real-life Analogy:**
ডিএনএ (DNA)। তুমি দেখতে তোমার বাবার মতো, কারণ তোমার ডিএনএ (Prototype) তে বাবার তথ্য আছে।

**💻 Code Example:**
```javascript
function Person(name) {
    this.name = name;
}

// প্রোটোটাইপে মেথড ঢোকালাম
Person.prototype.hello = function() {
    console.log(`Hello, I am ${this.name}`);
};

const user = new Person("Karim");
user.hello(); // Hello, I am Karim

// চেক করো
console.log(user.__proto__ === Person.prototype); // true
```

**💪 Mini Exercise:**
1. `console.dir(user)` দিয়ে ব্রাউজারে দেখো `[[Prototype]]` নামে কিছু পাও কিনা।

**📝 One-line Summary:**
জাভাস্ক্রিপ্ট হলো প্রোটোটাইপ-বেসড ল্যাঙ্গুয়েজ, ক্লাস শুধু সিনট্যাকটিক সুগার (দেখতে সুন্দর)।

### 📖 Lesson 9: Prototype Chain (বংশলতিকা)

**🎯 Learning Goal:** প্রোটোটাইপ চেইন কীভাবে কাজ করে।

**🗣️ সহজ ব্যাখ্যা:**
তুমি যখন অবজেক্টের কাছে কিছু চাও (যেমন `user.toString()`), সে প্রথমে নিজের পকেটে খোঁজে। না পেলে বাবার পকেটে (Prototype), সেখানে না পেলে দাদার পকেটে (Object Prototype)... এভাবে খুঁজতে খুঁজতে একদম `null` পর্যন্ত যায়। এই চেইনই হলো **Prototype Chain**।

**🤣 Real-life Analogy:**
দাদাবাড়িতে পুরনো দলিল খোঁজা।
নিজের ড্রয়ার -> বাবার ড্রয়ার -> দাদার সিন্দুক -> না পেলে "নাই"।

**💻 Code Example:**
```javascript
const grandFather = { money: 5000 };
const father = Object.create(grandFather); // বাবার বাবা হলো grandFather
const son = Object.create(father);         // ছেলের বাবা হলো father

console.log(son.money); 
// 5000 (ছেলে বাবার কাছে পায়নি, দাদার কাছে পেয়েছে!)
```

**💪 Mini Exercise:**
1. উপরের চেইনে `father` এর মধ্যে `money: 200` সেট করো। এবার দেখো `son.money` কত আসে (৫০০০ নাকি ২০০?)।

**📝 One-line Summary:**
জাভাস্ক্রিপ্ট প্রপার্টি খুঁজতে খুঁজতে চেইন ধরে উপরে উঠতে থাকে যতক্ষণ না পায়।

### 📖 Lesson 10: OOP Mini Project (ব্যাংক একাউন্ট)

**🎯 Learning Goal:** OOP ব্যবহার করে একটা ছোট লজিক দাঁড় করানো।

**🗣️ সহজ ব্যাখ্যা:**
আমরা একটা ব্যাংক সিস্টেম বানাবো যেখানে একাউন্ট খোলা যাবে, টাকা জমা দেওয়া যাবে এবং তোলা যাবে।

**💻 Code Example:**
```javascript
class BankAccount {
    #balance; // প্রাইভেট টাকা

    constructor(owner, balance) {
        this.owner = owner;
        this.#balance = balance;
    }

    deposit(amount) {
        this.#balance += amount;
        console.log(`${amount} taka joma holo. New Balance: ${this.#balance}`);
    }

    withdraw(amount) {
        if (amount > this.#balance) {
            console.log("Taka nai mama! Gorib naki?");
        } else {
            this.#balance -= amount;
            console.log(`${amount} taka tola holo. New Balance: ${this.#balance}`);
        }
    }
}

// প্রোজেক্ট টেস্ট
const myAcc = new BankAccount("Hasin", 1000);
myAcc.deposit(500);  // 1500
myAcc.withdraw(200); // 1300
myAcc.withdraw(5000); // Taka nai mama!
```

**💪 Mini Exercise:**
1. এই ক্লাসে একটা মেথড যোগ করো `transfer(amount, anotherAccount)` যা নিজের একাউন্ট থেকে টাকা কমিয়ে অন্য একাউন্টে (আরেকটা অবজেক্টে) টাকা বাড়িয়ে দেবে।
