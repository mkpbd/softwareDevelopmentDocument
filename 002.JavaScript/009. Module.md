### 📖 Lesson 5: Add Task Function (লজিক শুরু)

**🎯 Learning Goal:** ইনপুট থেকে লেখা নিয়ে অ্যারেতে রাখা।

**🗣️ সহজ ব্যাখ্যা:**
আমরা সরাসরি HTML এ আইটেম ঢোকাবো না। আমরা আগে `tasks` অ্যারেতে ডেটা রাখবো, তারপর সেই অ্যারে থেকে HTML বানাবো। এটাকে বলে **State Management** (React এ এভাবেই কাজ হয়)।

**💻 Code Example (script.js):**
```javascript
function addTask() {
    const text = taskInput.value;
    
    // খালি বাটন চাপলে কিছু হবে না
    if (text === "") {
        alert("Kichu ekta likhen bhai!");
        return;
    }

    // টাস্ক অবজেক্ট
    const task = {
        id: Date.now(), // ইউনিক আইডি
        text: text,
        isCompleted: false
    };

    tasks.push(task); // অ্যারেতে ঢুকালাম
    taskInput.value = ""; // ইনপুট খালি করলাম
    
    console.log(tasks); // কনসোলে দেখো অ্যারে বাড়ছে
    renderTasks(); // এই ফাংশনটা আমরা পরের লেসনে বানাবো
}

// বাটনে ক্লিক করলে ফাংশন কল হবে
addBtn.addEventListener("click", addTask);
```

**📝 One-line Summary:**
ইনপুট -> অবজেক্ট -> অ্যারে। এই ফ্লো মনে রাখবে।

### 📖 Lesson 6: Render Function (দৃশ্যমান করা)

**🎯 Learning Goal:** অ্যারের ডেটা থেকে HTML লিস্ট তৈরি করা।

**🗣️ সহজ ব্যাখ্যা:**
অ্যারেতে ডেটা আছে, কিন্তু স্ক্রিনে দেখা যাচ্ছে না। `renderTasks` ফাংশন অ্যারের প্রতিটি আইটেমের জন্য একটা করে `<li>` বানাবে এবং `<ul>` এর ভেতর ঢুকিয়ে দেবে।

**🤣 Real-life Analogy:**
মেমোরি কার্ডে গান আছে (Array), কিন্তু শুনতে হলে স্পিকারে (DOM) বাজাতে হবে।

**💻 Code Example (script.js):**
```javascript
function renderTasks() {
    // আগের লিস্ট ক্লিয়ার করি, নাহলে ডুপ্লিকেট হবে
    taskList.innerHTML = "";

    tasks.forEach(task => {
        const li = document.createElement("li");
        
        // কাজ শেষ হলে স্টাইল বদলাবে
        if (task.isCompleted) {
            li.classList.add("completed");
        }

        li.innerHTML = `
            <span onclick="toggleTask(${task.id})">${task.text}</span>
            <button onclick="deleteTask(${task.id})">❌</button>
        `;
        
        taskList.appendChild(li);
    });
}
```

**⚠️ Common Mistakes:**
- `taskList.innerHTML = ""` না দিলে প্রতিবার নতুনের সাথে পুরানোগুলোও আবার প্রিন্ট হবে।

**📝 One-line Summary:**
`Data` পরিবর্তন হলে `Render` কল করতে হয়, তাহলে স্ক্রিন আপডেট হয়ে যায়।

### 📖 Lesson 7: Delete Function (মুছে ফেলা)

**🎯 Learning Goal:** আইডি দিয়ে খুঁজে অ্যারে থেকে রিমুভ করা।

**🗣️ সহজ ব্যাখ্যা:**
ডিলিট বাটনে ক্লিক করলে আমরা টাস্কের `id` পাঠাচ্ছি। আমাদের কাজ হলো ওই আইডি ছাড়া বাকি সব টাস্ক রাখা। `filter` মেথড এখানে সেরা।

**💻 Code Example (script.js):**
```javascript
// window তে অ্যাসাইন করছি যাতে HTML থেকে কল করা যায়
window.deleteTask = function(id) {
    // ফিল্টার করে ওই আইডি বাদ দিলাম
    tasks = tasks.filter(task => task.id !== id);
    
    renderTasks(); // আবার লিস্ট আপডেট করো
};
```

**💪 Mini Exercise:**
1. ২-৩টা টাস্ক অ্যাড করো। এরপর লাল ক্রস বাটনে ক্লিক করে দেখো গায়েব হয় কিনা।

**📝 One-line Summary:**
রিমুভ মানেই `filter` করে বাদ দেওয়া এবং আবার রেন্ডার করা।

### 📖 Lesson 8: Toggle Complete (টিক মার্ক)

**🎯 Learning Goal:** কাজ শেষ হলে মার্ক করা।

**🗣️ সহজ ব্যাখ্যা:**
লেখার ওপর ক্লিক করলে আমরা `isCompleted` কে `true` বা `false` বানাবো (টগল)।

**💻 Code Example (script.js):**
```javascript
window.toggleTask = function(id) {
    // আইডি দিয়ে টাস্ক খুঁজছি
    const task = tasks.find(t => t.id === id);
    
    if (task) {
        task.isCompleted = !task.isCompleted; // উল্টে দিলাম (True <-> False)
    }
    
    renderTasks(); // স্টাইল চেঞ্জ হবে
};
```

**📝 One-line Summary:**
অবজেক্টের প্রপার্টি আপডেট করো -> রেন্ডার করো -> কালার চেঞ্জ অটো হবে।

### 📖 Lesson 9: LocalStorage (অমরত্ব দান)

**🎯 Learning Goal:** রিফ্রেশ দিলেও যাতে ডেটা না হারায়।

**🗣️ সহজ ব্যাখ্যা:**
এখন রিফ্রেশ দিলে সব গায়েব হয়ে যায়। আমরা প্রতিবার চেঞ্জ হওয়ার সাথে সাথে `tasks` অ্যারেকে LocalStorage এ সেভ করবো। আর পেজ লোড হলে সেখান থেকে নামাবো।

**💻 Code Example (script.js):**
```javascript
function saveToLocal() {
    localStorage.setItem("myTasks", JSON.stringify(tasks));
}

// renderTasks এর শেষে এটা কল করে দেব
// renderTasks ফাংশনের শেষ লাইনে: saveToLocal(); যোগ করো।
```

**আপডেট `renderTasks` ফাংশন:**
```javascript
function renderTasks() {
    taskList.innerHTML = "";
    tasks.forEach(task => {
        // ... (আগের কোড) ...
    });
    saveToLocal(); // সেভ হয়ে গেল
}
```

**📝 One-line Summary:**
যখনি অ্যারেতে হাত দেবে (Add/Delete), তখনি `localStorage` আপডেট করবে।

### 📖 Lesson 10: Initialize & Wrap Up (ফিনিশিং টাচ)

**🎯 Learning Goal:** অ্যাপ লোড হওয়ার সময় স্টোরেজ থেকে ডেটা আনা।

**🗣️ সহজ ব্যাখ্যা:**
অ্যাপ যখন প্রথম ওপেন হবে, তখন লোকাল স্টোরেজ চেক করবে। যদি আগে কোনো টাস্ক থাকে, সেটা `tasks` অ্যারেতে লোড করবে এবং দেখাবে।

**💻 Code Example (script.js - একদম শেষে):**
```javascript
// অ্যাপ লোড হলে এই কোড চলবে
function loadFromLocal() {
    const savedData = localStorage.getItem("myTasks");
    
    if (savedData) {
        tasks = JSON.parse(savedData); // স্ট্রিং থেকে অ্যারে বানালাম
        renderTasks(); // স্ক্রিনে দেখালাম
    }
}

loadFromLocal(); // কল করলাম
```

**🎉 Full Workflow:**
1. পেজ লোড -> `loadFromLocal()` -> পুরনো ডেটা শো।
2. Add Task -> অ্যারেতে পুশ -> `renderTasks()` -> `saveToLocal()`।
3. Delete -> অ্যারে ফিল্টার -> `renderTasks()` -> `saveToLocal()`।
