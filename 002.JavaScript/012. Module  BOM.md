আজ আমরা শিখবো **BOM**। না না, বোমা 💣 না! এটা হলো **Browser Object Model**।

আমরা এতদিন **DOM** (Document Object Model) নিয়ে নাচানাচি করেছি। DOM হলো তোমার ঘরের ভেতরের আসবাবপত্র (HTML ট্যাগস)। আর **BOM** হলো তোমার পুরো **বাড়ি এবং তার পরিবেশ** (Browser Window)।

ব্রাউজারের ট্যাবের নাম কী হবে, হিস্ট্রি কী, লোকেশন কোথায়, স্ক্রিন কত বড়—এসব কন্ট্রোল করে এই BOM। সোজা কথায়, **DOM হলো বাড়ির ভেতর, আর BOM হলো বাড়ির বাইরে কিন্তু বাউন্ডারির ভেতর।**

চলো, একদম জিরো থেকে হিরো হয়ে যাই! 🚀

# 🟢 Module 1: The Big Boss (Window Object)

### Lesson 1: Window আসলে কে?

**🗣️ সহজ ব্যাখ্যা:**
জাভাস্ক্রিপ্টে ব্রাউজারের দুনিয়ায় **`window`** হলো চৌধুরী সাহেব বা গডফাদার। সব কিছু এর আন্ডারে। আমরা যে `document` বা `console.log` লিখি, এগুলো সব আসলে `window` এর সম্পত্তি।

**🤣 Real-life Analogy:**
ধরো একটা বড় ফাইভ স্টার হোটেল।
*   **Window:** পুরো হোটেলটা।
*   **Document (DOM):** হোটেলের রুমগুলো।
*   **Functions/Variables:** হোটেলের স্টাফ।
সবাই হোটেলের (Window) আন্ডারেই কাজ করে।

**💻 Code Example:**
```javascript
// আমরা সাধারণত লিখি
console.log("Hello Bondhu!");

// কিন্তু আসলে ব্যাকগ্রাউন্ডে এটা হয়:
window.console.log("Hello Bondhu!");

// গ্লোবাল ভেরিয়েবলও উইন্ডোর পেটে থাকে
var myName = "Rahim";
console.log(window.myName); // Output: Rahim
```

**🎯 Output:** ব্রাউজার কনসোলে `Rahim` দেখাবে।

# 🟡 Module 2: User Interaction (কথাবার্তা)

### Lesson 2: Alert, Prompt, Confirm

**🗣️ সহজ ব্যাখ্যা:**
ইউজারকে ধুপ করে কোনো মেসেজ দেওয়া বা কিছু জিজ্ঞেস করার জন্য উইন্ডোর ৩টা মেথড আছে।

1.  **`alert()`**: শুধু তথ্য দেওয়া।
2.  **`confirm()`**: হ্যাঁ/না জিজ্ঞেস করা।
3.  **`prompt()`**: কিছু লিখে নেওয়া।

**🤣 Real-life Analogy:**
1.  **Alert:** পাড়ার মাইক 📢। শুধু বলে যায়, তুমি কিছু বলতে পারো না। শুধু "OK" বলে মেনে নিতে হয়।
2.  **Confirm:** বিয়ের কাজি 👳‍♂️। "কবুল?" (OK = True, Cancel = False)।
3.  **Prompt:** চাঁদাবাজ বা ভিক্ষুক 💰। "ভাই কিছু দেন" (ইনপুট বক্স)।

**💻 Code Example:**
```javascript
// 1. Alert (মাইকিং)
window.alert("Sabdhan! Virus paise! 🦠 (Just kidding)");

// 2. Confirm (বিয়ের কাজি)
let isMarried = window.confirm("Tumi ki biye korte raji?");
if (isMarried) {
    console.log("Mubarak ho! 🎉");
} else {
    console.log("Sad life... 😢");
}

// 3. Prompt (চাঁদা তোলা)
let name = window.prompt("Tomar nam ki?", "Guest");
console.log("Welcome " + name);
```

**⚠️ প্রো টিপ:** মডার্ন ওয়েবসাইটেরা এগুলো কম ব্যবহার করে কারণ এগুলো পেজকে ব্লক করে রাখে। নিজেরা কাস্টম মডাল বানায়।

# 🟠 Module 3: GPS & Rickshaw (Location Object)

### Lesson 3: URL নিয়ে খেলাধুলা

**🗣️ সহজ ব্যাখ্যা:**
`window.location` হলো তোমার ব্রাউজারের জিপিএস। তুমি এখন কোন লিংকে আছো, অন্য লিংকে যাবে কীভাবে—সব এখান থেকে কন্ট্রোল হয়।

**🤣 Real-life Analogy:**
রিকশাওয়ালা মামা। 🚲
*   **`href`**: মামা, এখন কোথায় আছি? (পুরো ঠিকানা)।
*   **`assign()`**: মামা, নিউ মার্কেট চলো (নতুন লিংকে যাওয়া)।
*   **`reload()`**: মামা, চাকাটা একটু ঘুরান তো (পেজ রিফ্রেশ)।

**💻 Code Example:**
```javascript
// ১. বর্তমান ঠিকানা দেখা
console.log("Full URL: ", window.location.href);
console.log("Pathname: ", window.location.pathname); // যেমন: /home

// ২. অন্য লিংকে পাঠিয়ে দেওয়া (Redirect)
// ৫ সেকেন্ড পর গুগলে পাঠিয়ে দেবে
setTimeout(() => {
    // window.location.href = "https://google.com"; // রিকশা স্টার্ট দিল
    // অথবা
    // window.location.assign("https://google.com");
}, 5000);

// ৩. পেজ রিফ্রেশ দেওয়া (সাবধান! লুপে পড়ে গেলে পিসি হ্যাং করবে)
// window.location.reload(); 
```

**🎯 Use Case:** লগইন সফল হওয়ার পর ইউজারকে ড্যাশবোর্ডে পাঠাতে `window.location.href` ব্যবহার করা হয়।

# 🔵 Module 4: Time Machine (History Object)

### Lesson 4: আগে পিছে যাওয়া

**🗣️ সহজ ব্যাখ্যা:**
ব্রাউজারের বাম কোণায় যে Back (⬅️) এবং Forward (➡️) বাটন থাকে, সেটা কন্ট্রোল করে `window.history`।

**🤣 Real-life Analogy:**
এটা হলো তোমার **প্রাক্তন (Ex)** এর স্মৃতি।
*   **`back()`**: পুরনো স্মৃতির কাছে ফিরে যাওয়া।
*   **`forward()`**: মুভ অন করা (যদি ফিউচার থাকে)।

**💻 Code Example:**
```javascript
// ১ ধাপ পেছনে যাওয়া (Back Button)
// window.history.back();

// ১ ধাপ সামনে যাওয়া (Forward Button)
// window.history.forward();

// ২ ধাপ পেছনে যাওয়া
// window.history.go(-2);
```

**🎯 Use Case:** অনেক সময় আমরা কাস্টম "Go Back" বাটন বানাই, সেখানে এটা লাগে।

# 🟣 Module 5: Detective (Navigator & Screen)

### Lesson 5: গোয়েন্দাগিরি করা

**🗣️ সহজ ব্যাখ্যা:**
*   **`navigator`**: ইউজারের ব্রাউজার এবং অপারেটিং সিস্টেম সম্পর্কে তথ্য দেয়। সে কি ক্রোম চালাচ্ছে নাকি ফায়ারফক্স? তার নেট আছে তো?
*   **`screen`**: ইউজারের মনিটর কত বড় সেটা বলে দেয়।

**🤣 Real-life Analogy:**
*   **Navigator:** সিআইডি অফিসার। "স্যার, দয়া দরজা তোড় দো" (সব তথ্য বের করে ফেলে)।
*   **Screen:** দর্জি। তোমার সাইজ মাপে।

**💻 Code Example:**
```javascript
// Navigator (গোয়েন্দা)
console.log("Browser Name:", window.navigator.appName);
console.log("User Agent:", window.navigator.userAgent); // সব গোপন তথ্য
console.log("Internet ache?", window.navigator.onLine); // True/False

if (window.navigator.onLine) {
    console.log("YouTube e video dekho! 🎬");
} else {
    console.log("Game over! Net nai. 🦖");
}

// Screen (দর্জি)
console.log("Screen Width:", window.screen.width);
console.log("Screen Height:", window.screen.height);
```

**🎯 Use Case:** ইন্টারনেট কানেকশন চেক করতে এবং মোবাইল না ডেস্কটপ—সেটা বুঝতে এগুলো লাগে।

# 🔴 Module 6: Time Bomb (Timing Events)

### Lesson 6: SetTimeout & SetInterval

**🗣️ সহজ ব্যাখ্যা:**
জাভাস্ক্রিপ্টকে ঘড়ি ধরে কাজ করানোর জন্য এই দুই বসকে লাগে।
1.  **`setTimeout`**: একবার কাজ করবে, কিন্তু দেরি করে। (Time Bomb 💣)
2.  **`setInterval`**: নির্দিষ্ট সময় পর পর কাজ করতেই থাকবে। (Alarm Clock ⏰)

**🤣 Real-life Analogy:**
*   **setTimeout:** প্রেসার কুকার। ১০ মিনিট পর একটা শিস দিয়ে থেমে যাবে।
*   **setInterval:** কানের কাছে মশা। প্যান প্যান করতেই থাকবে যতক্ষণ না থাপ্পড় (clearInterval) মারছো।

**💻 Code Example:**
```javascript
// ১. SetTimeout (বোমা ফাটবে ৩ সেকেন্ড পর)
console.log("Bomb set kora holo...");

setTimeout(() => {
    console.log("BOOM! 💥 (3 second shesh)");
}, 3000); // 3000 ms = 3 seconds


// ২. SetInterval (প্রতি ১ সেকেন্ডে ঘড়ি)
let count = 0;
let alarm = setInterval(() => {
    count++;
    console.log("Tick Tock... " + count);

    // ৫ বার বাজার পর বন্ধ করে দেব (থাপ্পড় মারা)
    if (count === 5) {
        clearInterval(alarm);
        console.log("Alarm bondho! 😴");
    }
}, 1000);
```

**🎯 Use Case:** ওটিপি (OTP) টাইমার, স্লাইডার এনিমেশন, বা ডিজিটাল ঘড়ি বানাতে এগুলো লাগে।

# 🚀 Module 7: Advanced BOM (Real World Project)

### Lesson 7: BOM দিয়ে "স্মার্ট ওয়েলকাম বট" বানানো

এখন আমরা সব মিলিয়ে একটা ছোট প্রজেক্ট বানাবো।
**আইডিয়া:** সাইটে ঢুকলে বট নাম জিজ্ঞেস করবে, ইন্টারনেট চেক করবে, আর ৫ সেকেন্ড পর অফার পেজে নিয়ে যাবে।

**💻 Full Project Code:**

```html
<!DOCTYPE html>
<html>
<body>
    <h1>BOM Master Project 🚀</h1>
    <h2 id="status">Checking Status...</h2>
    <p id="timer"></p>

    <script>
        // ১. নাম নেওয়া (Prompt)
        let user = window.prompt("Tomar nam ki bondhu?", "Stranger");
        
        if(user) {
            // ২. ইন্টারনেট চেক (Navigator)
            if (window.navigator.onLine) {
                document.getElementById('status').innerText = `Welcome ${user}! You are Online 🟢`;
                
                // ৩. টাইমার সেট করা (SetInterval)
                let timeLeft = 5;
                let countdown = setInterval(() => {
                    document.getElementById('timer').innerText = `Redirecting in ${timeLeft} seconds...`;
                    timeLeft--;

                    if (timeLeft < 0) {
                        clearInterval(countdown);
                        // ৪. অন্য পেজে পাঠানো (Location)
                        // window.location.href = "https://github.com"; 
                        document.getElementById('timer').innerText = "Redirected! (Example)";
                    }
                }, 1000);

            } else {
                window.alert("Net nai mama! Age net on koro!");
                document.getElementById('status').innerText = "You are Offline 🔴";
            }
        }
    </script>
</body>
</html>
```
