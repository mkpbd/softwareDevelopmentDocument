## 🟢 Module 1: MongoDB Basics (ভিত্তি গড়া)

### Lesson 1: What is NoSQL? (NoSQL কী?)
**আলোচনা:** আগেকার দিনে ডেটাবেস ছিল "সরকারি অফিসের রেজিস্টার খাতার" মতো (SQL)। সব কিছু ছক বা টেবিল করে রাখতে হতো। কিন্তু NoSQL হলো তোমার "পার্সোনাল ডায়েরি" বা "বাজারের ফর্দ"। যেখানে যখন যা ইচ্ছা লেখা যায়, কোনো ধরাবাঁধা নিয়ম নেই।
**মজার উদাহরণ:** SQL হলো অ্যারেঞ্জ ম্যারেজ (সব নিয়ম ফিক্সড), আর NoSQL হলো লাভ ম্যারেজ (ফ্লেক্সিবল, যখন যা মন চায় এডজাস্ট করা যায়)। 💍
**Code:** (No Code, just concept)

### Lesson 2: MongoDB Overview (MongoDB কেন সেরা?)
**আলোচনা:** MongoDB হলো NoSQL জগতের বস। এখানে ডেটা টেবিল বা রো-তে থাকে না, থাকে "ডকুমেন্ট" আকারে। এটা সুপার ফাস্ট এবং স্কেলেবল।
**মজার উদাহরণ:** একটা ড্রয়ারে মোজা, গেঞ্জি, প্যান্ট সব আলাদা ভাজ করে রাখা হলো SQL। আর একটা বড় বস্তায় সব জামাকাপড় ধপাস করে ফেলে রাখা (কিন্তু দরকারের সময় জাদুর মতো খুঁজে পাওয়া) হলো MongoDB। 🎒
**Code:** `db.version()` -> ভার্সন চেক করা।

### Lesson 3: BSON, JSON, Documents (ডেটা দেখতে কেমন?)
**আলোচনা:** MongoDB কথা বলে JSON (JavaScript Object Notation) স্টাইলে। দেখতে অনেকটা অবজেক্টের মতো। কিন্তু সেভ করার সময় সে এটাকে BSON (Binary JSON) বানিয়ে ফেলে যাতে স্পেস কম লাগে।
**মজার উদাহরণ:** JSON হলো "কাচ্চি বিরিয়ানি" (দেখতে সুন্দর, খেতে মজা), আর BSON হলো পেটে যাওয়ার পর যা হয় (মেশিন ল্যাঙ্গুয়েজ, যেটা কম্পিউটার বোঝে)। 🍛
**Code:**
```json
{
  "name": "Rahim",
  "age": 25,
  "isMarried": false
}
```
**ব্যাখ্যা:** `name` হলো key, আর `Rahim` হলো value। সেকেন্ড ব্র্যাকেট `{}` মানে একটা ডকুমেন্ট।

### Lesson 4: Collections (কালেকশন কী?)
**আলোচনা:** SQL-এ যা Table, MongoDB-তে তাই Collection। অনেকগুলো ডকুমেন্ট মিলে একটা কালেকশন হয়।
**মজার উদাহরণ:** তোমার মানিব্যাগটা হলো একটা ডেটাবেস। আর টাকার খোপ, কয়েনের খোপ, আর ভিজিটিং কার্ডের খোপ—এগুলো একেকটা Collection। 👛
**Code:** `db.createCollection("users")`
**ব্যাখ্যা:** `users` নামে একটা নতুন খোপ (Collection) বানালাম।

### Lesson 5: Database + Collections Design (ডিজাইন কেমন হবে?)
**আলোচনা:** ডেটাবেস বানানোর আগে ভাবতে হবে কী কী লাগবে। সব কিছু এক জায়গায় রাখব নাকি আলাদা করব?
**মজার উদাহরণ:** ব্যাচেলর বাসায় এক রুমেই রান্না, খাওয়া, শোয়া (Single Collection)। আর ফ্যামিলি বাসায় ড্রইং, ডাইনিং, বেডরুম আলাদা (Multiple Collections)। 🏠
**Code:** `use myShopDB`
**ব্যাখ্যা:** `myShopDB` নামে একটা ডেটাবেস সিলেক্ট করলাম বা বানালাম।

### Lesson 6: Mongo Shell commands basics (কমান্ডের হাতেখড়ি)
**আলোচনা:** মাউস দিয়ে ক্লিক না করে, লিখে লিখে কমান্ড দেওয়া। হ্যাকার ভাব নেওয়া আরকি! 😎
**মজার উদাহরণ:** ওয়েটারকে ইশারা না করে মুখে "এই মামা, এক কাপ চা দে!" বলে অর্ডার দেওয়া।
**Code:** `show dbs`
**ব্যাখ্যা:** সব ডেটাবেসের লিস্ট দেখাও মামা!

## 🟢 Module 2: CRUD Operations (ডেটা নিয়ে খেলা)

### Lesson 7: Insert (ডেটা ঢুকানো)
**আলোচনা:** কালেকশনে নতুন তথ্য রাখা। একটাও রাখা যায়, আবার পুরো গুষ্টিশুদ্ধ (Array) রাখা যায়।
**মজার উদাহরণ:** মাটির ব্যাংকে ১ টাকা রাখা (`insertOne`), অথবা ঈদের সালামির বান্ডিল একসাথে রাখা (`insertMany`)। 💰
**Code:**
```javascript
db.users.insertOne({ name: "Abul", age: 22 })
```
**ব্যাখ্যা:** `users` কালেকশনে আবুলকে ঢোকানো হলো।

### Lesson 8: Find (খুঁজে বের করা)
**আলোচনা:** ডেটাবেস থেকে তথ্য খুঁজে বের করা। ফিল্টারও করা যায়।
**মজার উদাহরণ:** ভিড়ের মধ্যে বন্ধুকে খোঁজা। অথবা ফেইসবুকে ক্রাশের নাম লিখে সার্চ দেওয়া। 🔍
**Code:**
```javascript
db.users.find({ name: "Abul" })
```
**ব্যাখ্যা:** যার নাম আবুল, তাকে ধরে নিয়ে আসো।

### Lesson 9: Update operators (তথ্য বদলানো)
**আলোচনা:** ভুল তথ্য ঠিক করা বা নতুন কিছু যোগ করা। `$set`, `$inc` এগুলো ব্যবহার হয়।
**মজার উদাহরণ:** বসের ঝাড়ি খেয়ে প্রেজেন্টেশন স্লাইড এডিট করা। অথবা চালের বস্তায় আরও ২ কেজি চাল যোগ করা (`$inc`)। ✏️
**Code:**
```javascript
db.users.updateOne({ name: "Abul" }, { $set: { age: 23 } })
```
**ব্যাখ্যা:** আবুলের বয়স ২২ থেকে ২৩ করে দিলাম (বার্থডে চলে গেছে)।

### Lesson 10: Delete operations (মুছে ফেলা)
**আলোচনা:** অপ্রয়োজনীয় ডেটা ডিলিট করা। সাবধান! একবার গেলে আর ফিরে আসবে না।
**মজার উদাহরণ:** ব্রেক-আপের পর এক্স-এর সব ছবি ডিলিট করা। 💔
**Code:**
```javascript
db.users.deleteOne({ name: "Abul" })
```
**ব্যাখ্যা:** আবুলকে সিস্টেম থেকে ভ্যানিশ করে দিলাম।

### Lesson 11: Projection (বেছে নেওয়া)
**আলোচনা:** সব ডেটা না এনে শুধু প্রয়োজনীয় ফিল্ডগুলো দেখা।
**মজার উদাহরণ:** কনে দেখতে গিয়ে শুধু "চেহারা আর হাইট" দেখা, তার দাদাবাড়ি কোথায় সেটা ইগনোর করা। 👰
**Code:**
```javascript
db.users.find({}, { name: 1, _id: 0 })
```
**ব্যাখ্যা:** শুধু নাম দেখাও, আইডি বা অন্য কিছু দেখানোর দরকার নাই।

### Lesson 12: Sort, Limit, Pagination (সাজানো ও পেজ নম্বর)
**আলোচনা:** ডেটা সুন্দর করে সাজানো, কয়টা দেখব সেটা ঠিক করা।
**মজার উদাহরণ:** পরীক্ষার রেজাল্ট শিট—ফার্স্ট বয় সবার উপরে (`Sort`)। আর ইউটিউবে ভিডিও দেখার সময় "Next Page" এ যাওয়া (`Skip` & `Limit`)। 📜
**Code:**
```javascript
db.users.find().sort({ age: 1 }).limit(5)
```
**ব্যাখ্যা:** বয়সের ছোট থেকে বড় সাজাও এবং মাত্র ৫ জনকে দেখাও।

## 🟢 Module 3: Schema Design Basics (ঘর সাজানো)

### Lesson 13: Embedding vs Referencing (একসাথে নাকি আলাদা?)
**আলোচনা:** ডেটা কি এক ডকুমেন্টের পেটের ভেতর ঢুকিয়ে রাখব (Embedding), নাকি অন্য জায়গায় রেখে লিংক করব (Referencing)?
**মজার উদাহরণ:** পকেটে টাকা রাখা (Embedding - ফাস্ট এক্সেস)। আর ব্যাংকে টাকা রেখে চেকবই পকেটে রাখা (Referencing - সেইফ কিন্তু স্লো)। 🏦

### Lesson 14: Relations in MongoDB (সম্পর্ক)
**আলোচনা:** এক ডেটার সাথে আরেক ডেটার সম্পর্ক কেমন হবে।
**মজার উদাহরণ:** তোমার সাথে তোমার বউয়ের সম্পর্ক (স্ট্রং কানেকশন)। তোমার সাথে রিকশাওয়ালার সম্পর্ক (টেম্পোরারি কানেকশন)। 👫

### Lesson 15: One-to-One, One-to-Many, Many-to-Many
**আলোচনা:** রিলেশনশিপের ধরন।
**মজার উদাহরণ:**
*   **1-to-1:** তুমি আর তোমার NID কার্ড।
*   **1-to-Many:** একজন বাবা আর তার ৫ ছেলেমেয়ে।
*   **Many-to-Many:** স্টুডেন্ট আর টিচার (এক স্টুডেন্টের অনেক টিচার, এক টিচারের অনেক স্টুডেন্ট)। 👨‍🏫

### Lesson 16: Normalization vs Denormalization
**আলোচনা:** ডেটা ভেঙে টুকরো করা (Norm) নাকি ডুপ্লিকেট করে ফাস্ট করা (Denorm)।
**মজার উদাহরণ:**
*   **Norm:** রান্নার সব মসলা আলাদা আলাদা কৌটায় রাখা।
*   **Denorm:** "রাঁধুনি মিক্স মসলা" (সব এক প্যাকেটে, তাড়াতাড়ি রান্না হয়)। 🍲

### Lesson 17: Best schema practices (ভালো ডিজাইনের টিপস)
**আলোচনা:** স্কিমা ডিজাইনের সময় কী কী মাথায় রাখতে হবে।
**মজার উদাহরণ:** বাড়ি বানানোর সময় পিলারের জোর চেক করা। অযথা ১০ তলা ফাউন্ডেশন দিয়ে ১ তলা বাড়ি না বানানো। 🏗️
**Code:** (Concept: Limit Array size, avoid unbound arrays).

## 🟢 Module 4: Indexing & Performance (গতি বাড়ানো)

### Lesson 18: Index basics (ইনডেক্স কী?)
**আলোচনা:** ইনডেক্স ছাড়া সার্চ করা মানে পুরো বইয়ের প্রতিটা পাতা উল্টে খোঁজা। ইনডেক্স থাকলে সূচিপত্র দেখে খোঁজা।
**মজার উদাহরণ:** লাইব্রেরিতে বই খোঁজা vs. নিজের অগোছালো রুমে কলম খোঁজা। 📚
**Code:**
```javascript
db.users.createIndex({ name: 1 })
```
**ব্যাখ্যা:** নামের ওপর ইনডেক্স বসালাম, এখন নাম দিয়ে খুঁজলে রকেটের গতিতে রেজাল্ট আসবে।

### Lesson 19: Compound index (একের অধিক ইনডেক্স)
**আলোচনা:** একাধিক শর্ত দিয়ে খোঁজা।
**মজার উদাহরণ:** পাত্রী চাই—শর্ত ১: সুন্দরী, শর্ত ২: সরকারি চাকরিজীবী। দুইটা মিলে ফিল্টার। 👰‍♀️💼
**Code:**
```javascript
db.users.createIndex({ age: 1, city: 1 })
```

### Lesson 20: Text index (লেখা খোঁজা)
**আলোচনা:** বড় প্যারাগ্রাফের ভেতর শব্দ খোঁজা।
**মজার উদাহরণ:** গুগলে সার্চ দেওয়া। "Best Burger in Dhaka" লিখলে সে পুরো ইন্টারনেট ঘেঁটে বের করে। 🍔
**Code:**
```javascript
db.products.createIndex({ description: "text" })
```

### Lesson 21: Performance optimization (মাইলেজ বাড়ানো)
**আলোচনা:** কোয়েরি কত ফাস্ট চলছে সেটা চেক করা (`explain()`)।
**মজার উদাহরণ:** বাইক সার্ভিসিং সেন্টারে নিয়ে গিয়ে চেক করা ইঞ্জিন ঠিক আছে কিনা। 🏍️
**Code:** `db.users.find({name: "Abul"}).explain("executionStats")`

## 🟢 Module 5: Aggregation Framework (এডভান্সড ফিল্টারিং)

### Lesson 22: Pipeline concept (পাইপলাইন কী?)
**আলোচনা:** এক দিক দিয়ে কাঁচামাল ঢুকবে, মেশিনের ভেতর প্রসেস হয়ে অন্য দিক দিয়ে প্যাকেট হয়ে বের হবে।
**মজার উদাহরণ:** জুস ফ্যাক্টরি। আম ঢোকে -> খোসা ছাড়ানো হয় -> জুস হয় -> বোতলে ভরা হয়। 🥭🥤
**Code:** `db.orders.aggregate([ ... ])`

### Lesson 23: Match, Group (বাছাই ও গ্রুপ করা)
**আলোচনা:** প্রথমে ফিল্টার করা (`$match`), তারপর দলবদ্ধ করা (`$group`)।
**মজার উদাহরণ:** ক্লাসের সব ছাত্র থেকে প্রথমে "যারা চশমা পরে" তাদের আলাদা করা। তারপর "লাল চশমা" আর "কালো চশমা" ওয়ালাদের দুই গ্রুপে ভাগ করা। 👓
**Code:**
```javascript
{ $match: { status: "A" } },
{ $group: { _id: "$cust_id", total: { $sum: "$amount" } } }
```

### Lesson 24: Project, Sort (সাজগোজ)
**আলোচনা:** আউটপুট সুন্দর করা।
**মজার উদাহরণ:** বিউটি পার্লারে গিয়ে মেকআপ করে ফাইনাল লুক দেওয়া। 💅

### Lesson 25: Lookup (Join করা)
**আলোচনা:** এক কালেকশনের সাথে আরেক কালেকশনের ডেটা জোড়া লাগানো। SQL এর JOIN এর মতো।
**মজার উদাহরণ:** পরীক্ষার হলে পাশের বন্ধুর খাতা দেখে লেখা (অন্য সোর্স থেকে ডেটা আনা)। 📝
**Code:**
```javascript
{
  $lookup: {
    from: "inventory",
    localField: "item",
    foreignField: "sku",
    as: "inventory_docs"
  }
}
```

### Lesson 26: Real analytics examples (বাস্তব রিপোর্ট)
**আলোচনা:** প্রতিদিনের বিক্রির হিসাব বের করা।
**মজার উদাহরণ:** দিন শেষে দোকানদার যখন ক্যাশ মেলায়—কত লাভ হলো, কত বাকি পড়ল। 🧾

## 🟢 Module 6: Advanced MongoDB (এক্সপার্ট লেভেল)

### Lesson 27: Transactions (লেনদেন)
**আলোচনা:** একাধিক কাজ একসাথে হতে হবে, নাহলে কোনোটাই হবে না।
**মজার উদাহরণ:** বিকাশে টাকা পাঠানো। তোমার ব্যালেন্স কমবে আর বন্ধুর ব্যালেন্স বাড়বে। যদি মাঝপথে নেট চলে যায়, তবে টাকা তোমার কাছেই ফেরত আসবে, হাওয়ায় ভাসবে না। 💸

### Lesson 28: MongoDB Atlas (ক্লাউড ডেটাবেস)
**আলোচনা:** নিজের পিসিতে সেটআপ না দিয়ে অনলাইনে ডেটাবেস ব্যবহার করা।
**মজার উদাহরণ:** নিজের ল্যাপটপে মুভি ডাউনলোড না করে Netflix এ দেখা। প্যারা নাই, চিল। 🍿

### Lesson 29: Security + User roles (নিরাপত্তা)
**আলোচনা:** কে ডেটাবেসে ঢুকতে পারবে, কে পারবে না।
**মজার উদাহরণ:** বাড়ির দারোয়ান। সবাইকে গেট দিয়ে ঢুকতে দেয় না, শুধু আই কার্ড থাকলে ঢুকতে দেয়। 👮‍♂️
**Code:** `db.createUser({ user: "admin", pwd: "123", roles: ["root"] })`

### Lesson 30: Backup, Restore, Deployment (বিপদ আপদ)
**আলোচনা:** ডেটা হারিয়ে গেলে ফেরত আনা।
**মজার উদাহরণ:** মোবাইল হারিয়ে গেলে গুগল ড্রাইভ থেকে কন্টাক্ট নম্বর রিস্টোর করা। অথবা ফটোকপি করে রাখা। 💾
**Code:** `mongodump`, `mongorestore`
