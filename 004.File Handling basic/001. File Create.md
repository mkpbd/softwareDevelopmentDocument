
অবশ্যই, এখানে প্রদত্ত HTML বিষয়বস্তুটি একটি সুগঠিত মার্কডাউন ফরম্যাটে তুলে ধরা হলো।

### **7.1 — File Handling Basics**

#### **File Handling কী (What is File Handling?)**
File Handling হলো এমন একটি প্রক্রিয়া যার মাধ্যমে আমরা Python প্রোগ্রাম থেকে ফাইল **read, write, এবং modify** করতে পারি। এটি ডেটা স্থায়ীভাবে সংরক্ষণের জন্য একটি গুরুত্বপূর্ণ বিষয়।

**উদাহরণ:**
```python
# একটি ফাইল খুলে তাতে কিছু লেখা
f = open('data.txt', 'w')
f.write('Hello Python!')
f.close()
```
**ফলাফল:**
আপনার প্রোগ্রাম যে ফোল্ডারে আছে, সেখানে `data.txt` নামে একটি ফাইল তৈরি হবে এবং তার ভেতরে "Hello Python!" লেখাটি সংরক্ষিত থাকবে।

---

#### **File তৈরি ও খোলা (Creating and Opening a File)**
Python-এ ফাইল খোলার জন্য `open()` ফাংশন ব্যবহার করা হয়।

```python
file = open(filename, mode, encoding)
```
**Parameters:**
*   **`filename`**: ফাইলের নাম বা পাথ (path)।
*   **`mode`**: কী মোডে ফাইলটি খুলতে চান (যেমন: read, write, append)।
*   **`encoding`**: টেক্সট ফাইলের জন্য Character Encoding, সাধারণত `'utf-8'` ব্যবহার করা হয়, বিশেষ করে বাংলা লেখার জন্য।

**উদাহরণ:**
```python
# 'notes.txt' ফাইলটি read মোডে খোলা হচ্ছে
f = open('notes.txt', 'r', encoding='utf-8')
```

---

#### **File Opening Modes**
ফাইল খোলার জন্য বিভিন্ন মোড রয়েছে:

| Mode  | Description                                        |
| :---- | :------------------------------------------------- |
| `'r'` | **Read mode** — ফাইলটি শুধুমাত্র পড়ার জন্য খোলে। ফাইল না থাকলে `FileNotFoundError` দেয়। |
| `'w'` | **Write mode** — ফাইলটি লেখার জন্য খোলে। ফাইল আগে থেকে থাকলে তার পুরনো সব কন্টেন্ট মুছে ফেলে নতুন করে লেখে। ফাইল না থাকলে নতুন তৈরি করে। |
| `'a'` | **Append mode** — ফাইলের শেষে নতুন ডেটা যোগ করে। পুরনো কন্টেন্ট অক্ষত থাকে। ফাইল না থাকলে নতুন তৈরি করে। |
| `'x'` | **Create mode** — একটি নতুন ফাইল তৈরি করে। যদি ফাইল আগে থেকেই থাকে, তাহলে `FileExistsError` দেয়। |
| `'b'` | **Binary mode** — বাইনারি ফাইল (যেমন ছবি, অডিও) নিয়ে কাজ করার জন্য। এটি অন্য মোডের সাথে যুক্ত হয় (যেমন `'rb'`, `'wb'`)। |
| `'t'` | **Text mode** — টেক্সট ফাইল নিয়ে কাজ করার জন্য (এটি ডিফল্ট মোড)। |
| `'+'` | **Update mode** — ফাইল পড়া এবং লেখা উভয় কাজ একসাথে করার জন্য (যেমন `'r+'`, `'w+'`)। |

**উদাহরণ:**
```python
# 'log.txt' ফাইলটি append মোডে খোলা হচ্ছে
f = open('log.txt', 'a', encoding='utf-8')
```

---

#### **Empty File তৈরি করা (Creating an Empty File)**

`'w'` মোডে একটি ফাইল খুলে কোনো কিছু না লিখে বন্ধ করে দিলেই একটি খালি ফাইল তৈরি হয়ে যায়।

```python
f = open('empty.txt', 'w')
f.close()
```
তবে এর চেয়ে ভালো উপায় হলো `with` স্টেটমেন্ট ব্যবহার করা, কারণ এটি কাজ শেষে ফাইলটি স্বয়ংক্রিয়ভাবে বন্ধ করে দেয়।
```python
with open('empty.txt', 'w') as f:
    pass
```

---

#### **File-এ লেখা (Writing to a File)**
`'w'` (write) বা `'a'` (append) মোডে ফাইল খুলে `.write()` মেথড ব্যবহার করে ফাইলে ডেটা লেখা যায়।

```python
with open('test.txt', 'w', encoding='utf-8') as f:
    f.write('Python File Handling Basics')
```
**ফলাফল:** `test.txt` ফাইলে "Python File Handling Basics" লেখাটি সংরক্ষিত হবে।

`'a'` (append) মোড ব্যবহার করলে পুরনো টেক্সটের শেষে নতুন টেক্সট যুক্ত হয়।
```python
with open('test.txt', 'a', encoding='utf-8') as f:
    f.write('\nনতুন লাইন যোগ করা হলো')
```

---

#### **File পড়া (Reading from a File)**
ফাইল পড়ার জন্য `'r'` মোড ব্যবহার করা হয়। `.read()` মেথড পুরো ফাইলের কন্টেন্ট একটি স্ট্রিং হিসেবে রিটার্ন করে।

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    data = f.read()
print(data)
```

**Line by Line পড়া:**
বড় ফাইলের ক্ষেত্রে একবারে পুরোটা না পড়ে, লাইন বাই লাইন পড়া সুবিধাজনক।
```python
with open('story.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line.strip()) # .strip() দিয়ে লাইনের শুরু ও শেষের whitespace বাদ দেওয়া হয়
```

---

#### **File বন্ধ করা (Closing a File)**
ফাইল নিয়ে কাজ শেষ হলে মেমরি মুক্ত করতে এবং ডেটা loss এড়াতে ফাইলটি বন্ধ করা জরুরি। এর জন্য `.close()` মেথড ব্যবহার করা হয়।
```python
f = open('data.txt', 'r')
# ...ফাইল নিয়ে কাজ... 
f.close()

```
তবে সবচেয়ে ভালো এবং নিরাপদ উপায় হলো **with স্টেটমেন্ট** ব্যবহার করা। এটি try...finally ব্লকের মতো কাজ করে এবং ব্লক থেকে বের হওয়ার সময় স্বয়ংক্রিয়ভাবে ফাইলটি বন্ধ করে দেয়, এমনকি যদি কোনো error-ও ঘটে।

```python
with open('data.txt', 'r') as f:
    content = f.read()
# with ব্লকের বাইরে ফাইলটি অটোমেটিক বন্ধ হয়ে গেছে
```
#### **Common Errors**

|   |   |
|---|---|
|Error|কারণ|
|FileNotFoundError|'r' মোডে ফাইল খোলার চেষ্টা করা হলে কিন্তু ফাইলটি উপস্থিত না থাকলে।|
|PermissionError|কোনো ফাইলে read বা write করার অনুমতি না থাকলে।|
|UnicodeDecodeError|ভুল encoding ব্যবহার করে ফাইল পড়ার চেষ্টা করলে।|

**Error Handling উদাহরণ:**

```python
try:
    with open('missing.txt', 'r', encoding='utf-8') as f:
        print(f.read())
except FileNotFoundError:
    print('ফাইল পাওয়া যায়নি!')
```
#### **File Path (Absolute এবং Relative)**

- **Absolute Path:** ফাইলের সম্পূর্ণ ঠিকানা, যা root ফোল্ডার থেকে শুরু হয় (যেমন C:\Users\User\data.txt বা /home/user/data.txt)।
    
- **Relative Path:** বর্তমান ফোল্ডারের সাপেক্ষে ফাইলের ঠিকানা (যেমন ./data.txt বা ../folder/file.txt)।
    

Python-এর pathlib মডিউল ব্যবহার করলে পাথ নিয়ে কাজ করা সহজ হয় এবং কোড cross-platform (Windows, Mac, Linux সব জায়গায় কাজ করে) হয়।

```python
from pathlib import Path

# folder/file.txt পাথ তৈরি করা
p = Path('folder') / 'file.txt'

with p.open('w', encoding='utf-8') as f:
    f.write('Pathlib দিয়ে ফাইল তৈরি')
```
#### **মূল পয়েন্টসমূহ (Key Points)**

- File Handling ডেটা স্থায়ীভাবে সংরক্ষণের জন্য ব্যবহৃত হয়।
    
- open() দিয়ে ফাইল খোলা হয় এবং mode নির্ধারণ করা হয়।
    
- বাংলা বা অন্যান্য ভাষার জন্য 'utf-8' encoding ব্যবহার করা উচিত।
    
- with স্টেটমেন্ট ফাইল স্বয়ংক্রিয়ভাবে বন্ধ করে, যা সবচেয়ে নিরাপদ পদ্ধতি।
    
- সাধারণত ব্যবহৃত মোড: 'r', 'w', 'a', 'x', 'b', 't', '+'।

### **7.2 — File Read**

#### **File Read কী (What is File Read?)**

File read হলো একটি প্রক্রিয়া যার মাধ্যমে আমরা Python প্রোগ্রামে কোনো ফাইলের ভেতরের ডেটা পড়তে পারি। সাধারণত এটি `open()` ফাংশন ব্যবহার করে `'r'` (read) মোডে করা হয়।

**উদাহরণ:**
```python
f = open('sample.txt', 'r', encoding='utf-8')
data = f.read()
print(data)
f.close()
```
**আউটপুট:**
 `sample.txt` ফাইলে যা লেখা আছে, তা টার্মিনালে প্রিন্ট হবে।

---

#### **ফাইল পড়ার বিভিন্ন পদ্ধতি (Different Ways to Read a File)**
Python ফাইল পড়ার জন্য কয়েকটি আলাদা মেথড প্রদান করে।

##### **1. `read()`**
এই মেথডটি ফাইলের **সম্পূর্ণ কন্টেন্ট** একবারে পড়ে এবং একটি স্ট্রিং হিসেবে রিটার্ন করে। বড় ফাইলের ক্ষেত্রে এটি বেশি মেমরি ব্যবহার করতে পারে।
```python
with open('data.txt', 'r', encoding='utf-8') as f:
    text = f.read()
print(text)
```

##### **2. `readline()`**
এই মেথডটি প্রতিবার কল করার সময় ফাইল থেকে **একটি করে লাইন** পড়ে।
```python
with open('story.txt', 'r', encoding='utf-8') as f:
    line1 = f.readline()
    line2 = f.readline()
print(line1)
print(line2)
```

##### **3. `readlines()`**
এই মেথডটি ফাইলের **সবগুলো লাইন** পড়ে এবং প্রতিটি লাইনকে উপাদান হিসেবে একটি **লিস্ট** আকারে রিটার্ন করে।
```python
with open('story.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()
print(lines)
```

##### **4. `for` Loop ব্যবহার করে পড়া**
বড় ফাইল পড়ার জন্য এটি সবচেয়ে memory-efficient পদ্ধতি, কারণ এটি একবারে একটি মাত্র লাইন মেমরিতে লোড করে।
```python
with open('story.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line.strip()) # .strip() দিয়ে অতিরিক্ত স্পেস ও newline character সরানো হয়
```

---

#### **File Pointer or Cursor**
ফাইল থেকে ডেটা পড়ার সময় Python একটি কার্সর বা পয়েন্টার ব্যবহার করে। প্রতিবার `read()` বা `readline()` কল করার পর পয়েন্টারটি पुढे সরে যায়। একবার পুরো ফাইল পড়া হয়ে গেলে পয়েন্টারটি ফাইলের শেষে চলে যায়, তাই আবার `read()` কল করলে খালি স্ট্রিং পাওয়া যায়। পয়েন্টারটিকে আবার শুরুতে আনার জন্য `seek(0)` ব্যবহার করতে হয়।

```python
f = open('data.txt', 'r', encoding='utf-8')

print(f.read(5))   # প্রথম ৫ অক্ষর পড়বে
print(f.read())    # বাকি অংশ পড়বে

f.seek(0)          # কার্সর আবার ফাইলের শুরুতে আনা হলো
print(f.read(10))  # আবার শুরু থেকে প্রথম ১০ অক্ষর পড়া হলো

f.close()
```

---

#### **নির্দিষ্ট অংশ পড়া (Read some specific parts)**
`read(n)` ব্যবহার করে ফাইল থেকে নির্দিষ্ট সংখ্যক ক্যারেক্টার (n) পড়া যায়।
```python
with open('story.txt', 'r', encoding='utf-8') as f:
    # ফাইলের প্রথম ২০টি ক্যারেক্টার পড়া হচ্ছে
    part = f.read(20)
print(part)
```

#### **Exception Handling সহ File Read**
ফাইলটি যদি নির্দিষ্ট পাথে না থাকে বা পড়ার অনুমতি না থাকে, তাহলে প্রোগ্রাম ক্র্যাশ করতে পারে। `try...except` ব্লক ব্যবহার করে এই ধরনের error সামালানো যায়।
```python
try:
    with open('missing.txt', 'r', encoding='utf-8') as f:
        print(f.read())
except FileNotFoundError:
    print('ফাইল পাওয়া যায়নি!')
```

#### **Binary Mode-এ ফাইল পড়া**
যখন টেক্সট ফাইলের বদলে বাইনারি ফাইল (যেমন: ইমেজ, অডিও, পিডিএফ) পড়তে হয়, তখন `'rb'` (read binary) মোড ব্যবহার করতে হয়।
```python
try:
    with open('photo.jpg', 'rb') as f:
        data = f.read()
    print(len(data), 'bytes পড়া হয়েছে')
except FileNotFoundError:
    print("ছবিটি পাওয়া যায়নি।")
```

---

#### **মূল পয়েন্টসমূহ (Key Points)**
*   `'r'` মোড ফাইল পড়ার জন্য ব্যবহৃত হয়।
*   `read()` পুরো ফাইল একসাথে পড়ে, যা বড় ফাইলের জন্য উপযুক্ত নয়।
*   `readline()` প্রতিবার একটি করে লাইন পড়ে।
*   `readlines()` সব লাইনকে একটি লিস্ট আকারে রিটার্ন করে।
*   বড় ফাইলের জন্য `for` loop ব্যবহার করা সবচেয়ে memory-efficient।
*   বাইনারি ফাইল পড়ার জন্য `'rb'` মোড ব্যবহার করতে হয়।

### **7.3 — File Write and Append**

#### **File Write and Append কী? (What are File Write and Append?)**
File Write and Append হলো Python প্রোগ্রামে কোনো ফাইলে নতুন ডেটা লেখা (`write`) বা বিদ্যমান ফাইলে নতুন ডেটা যোগ (`append`) করার প্রক্রিয়া। এটি `open()` ফাংশন ব্যবহার করে `'w'` (write) বা `'a'` (append) মোডে করা হয়।

**উদাহরণ:**
```python
# Write mode ব্যবহার করে ফাইল তৈরি ও লেখা
# যদি sample.txt আগে থেকেই থাকে, তবে তার সব কন্টেন্ট মুছে যাবে
with open('sample.txt', 'w', encoding='utf-8') as f:
    f.write('This is new data.')

# Append mode ব্যবহার করে ফাইলে নতুন ডেটা যোগ করা
with open('sample.txt', 'a', encoding='utf-8') as f:
    f.write('\nThis line is appended.')
```
**ফলাফল:**
প্রথমে `sample.txt` ফাইলে "This is new data." লেখাটি সংরক্ষিত হবে। এরপর দ্বিতীয় কোডটি চালালে, ফাইলের শেষে নতুন একটি লাইনে "This line is appended." লেখাটি যুক্ত হবে।

---

#### **ফাইল লেখা ও যোগ করার বিভিন্ন পদ্ধতি (Different Ways to Write and Append a File)**

##### **1. `write()`**
এই মেথডটি একটি মাত্র স্ট্রিং (string) ফাইলে লেখে।
```python
with open('data.txt', 'w', encoding='utf-8') as f:
    f.write('Hello from write mode.')
```

##### **2. `writelines()`**
এই মেথডটি একটি লিস্ট বা টাপল-এর সবগুলো স্ট্রিংকে একসাথে ফাইলে লেখে। নতুন লাইন (`\n`) নিজে থেকে যোগ হয় না, তাই প্রতিটি লাইনের শেষে `\n` যোগ করে দিতে হয়।
```python
lines = ['Line 1\n', 'Line 2\n', 'Line 3\n']
with open('multi.txt', 'w', encoding='utf-8') as f:
    f.writelines(lines)
```

##### **3. Append Mode (`'a'`) ব্যবহার করা**
যদি ফাইলের পুরনো ডেটা না মুছে শেষে নতুন ডেটা যোগ করতে চান, তাহলে `'a'` মোড ব্যবহার করতে হবে।
```python
with open('log.txt', 'a', encoding='utf-8') as f:
    f.write('New log entry added.\n')
```

---

#### **Overwrite বনাম Append (Overwrite vs. Append)**

*   `'w'` (Write) মোড: ফাইলটি খোলার সাথে সাথে এর পুরনো সব ডেটা মুছে ফেলে এবং নতুন করে লেখা শুরু করে।
*   `'a'` (Append) মোড: ফাইলের পুরনো ডেটা অক্ষত রেখে কার্সরটিকে ফাইলের শেষে নিয়ে যায় এবং সেখান থেকে নতুন লেখা শুরু করে।

**উদাহরণ:**
```python
# Overwrite: demo.txt ফাইলে শুধু "First line only." থাকবে।
with open('demo.txt', 'w', encoding='utf-8') as f:
    f.write('First line only.')

# Append: আগের লেখার পর নতুন লাইন যোগ হবে।
with open('demo.txt', 'a', encoding='utf-8') as f:
    f.write('\nSecond line added.')
```
**`demo.txt` ফাইলের চূড়ান্ত অবস্থা:**
```
First line only.
Second line added.
```
---

#### **ফাইলে নতুন লাইন লেখা (Writing New Lines in a File)**
ফাইলে নতুন লাইন তৈরি করতে নিউলাইন ক্যারেক্টার (`\n`) ব্যবহার করা হয়।
```python
with open('tasks.txt', 'a', encoding='utf-8') as f:
    f.write('Task 1 completed\n')
    f.write('Task 2 completed\n')
```

---

#### **Encoding এবং বাংলা লেখা (Encoding and Writing Bengali)**
বাংলা বা যেকোনো Unicode টেক্সট ফাইলে লেখার সময় অবশ্যই `encoding='utf-8'` ব্যবহার করতে হয়, নাহলে `UnicodeEncodeError` হতে পারে।
```python
with open('bangla.txt', 'w', encoding='utf-8') as f:
    f.write('হ্যালো পাইথন!\nবাংলা লেখা এখন খুব সহজ।')
```

---

#### **Exception Handling সহ File Write**
ফাইল লেখার সময় বিভিন্ন কারণে error হতে পারে, যেমন: ফাইলের পাথ ভুল হলে বা write করার অনুমতি না থাকলে। `try...except` ব্লক ব্যবহার করে এসব error সামালানো যায়।
```python
try:
    with open('restricted_folder/data.txt', 'w', encoding='utf-8') as f:
        f.write('Testing permission error.')
except PermissionError:
    print('ফাইল write করার অনুমতি নেই!')
except FileNotFoundError:
    print('ফোল্ডারটি খুঁজে পাওয়া যায়নি!')
```

#### **Binary Mode-এ ফাইল লেখা (Writing a File in Binary Mode)**
বাইনারি ডেটা (যেমন ইমেজ, অডিও) ফাইলে লেখার জন্য `'wb'` (write binary) মোড ব্যবহার করতে হয় এবং ডেটাকে বাইট স্ট্রিং (`b'...'`) হিসেবে পাস করতে হয়।
```python
# একটি jpg ফাইলের প্রথম কয়েকটি বাইট লেখা হচ্ছে
with open('image_copy.jpg', 'wb') as f:
    f.write(b'\xff\xd8\xff\xe0')
```

---

#### **মূল পয়েন্টসমূহ (Key Points)**
*   `'w'` মোড ফাইল নতুন করে তৈরি করে এবং পুরনো কন্টেন্ট মুছে দেয়।
*   `'a'` মোড পুরনো কন্টেন্ট রেখে শেষে নতুন ডেটা যোগ করে।
*   `write()` একটি স্ট্রিং এবং `writelines()` একটি লিস্ট অফ স্ট্রিংস লেখার জন্য ব্যবহৃত হয়।
*   বাংলা লেখার জন্য `encoding='utf-8'` ব্যবহার করা জরুরি।
*   বাইনারি ফাইল লেখার জন্য `'wb'` মোড ব্যবহার করতে হয়।

### **7.4 — File Pointer**

#### **File Pointer কী (What is a File Pointer?)**
File Pointer (বা File Cursor) হলো ফাইলের ভেতরে একটি অদৃশ্য নির্দেশক, যা Python-কে জানায় কোন অবস্থান থেকে **read করা** বা **write করা** শুরু করতে হবে। যখন একটি ফাইল খোলা হয়, কার্সরটি সাধারণত ফাইলের শুরুতে (position 0) থাকে। প্রতিবার read বা write অপারেশনের পর কার্সরটি সামনে এগিয়ে যায়।

**উদাহরণ:**
```python
# data.txt ফাইলে "Hello Python" লেখা আছে ধরে নেওয়া হলো
with open('data.txt', 'r', encoding='utf-8') as f:
    # প্রথম ৫টি অক্ষর পড়া হলো
    content = f.read(5)
    print('প্রথম ৫ অক্ষর:', content)
    
    # কার্সরের বর্তমান অবস্থান জানা
    position = f.tell()
    print('বর্তমান cursor position:', position)
```
**আউটপুট:**
```
প্রথম ৫ অক্ষর: Hello
বর্তমান cursor position: 5
```

---

#### **File Pointer Movement (`tell()` এবং `seek()`)**
Python-এ দুটি মেথড ব্যবহার করে File Pointer-এর অবস্থান জানা এবং নিয়ন্ত্রণ করা যায়।

##### **1. `tell()`**
`tell()` মেথডটি কার্সরের বর্তমান অবস্থান (শুরু থেকে কত বাইট দূরে আছে) একটি ইন্টিজার হিসেবে রিটার্ন করে।
```python
with open('info.txt', 'r', encoding='utf--8') as f:
    # প্রথম ১০টি অক্ষর পড়া হলো
    f.read(10)
    # কার্সরের অবস্থান প্রিন্ট করা
    print('Cursor position:', f.tell()) # আউটপুট: 10
```

##### **2. `seek(offset, whence)`**
`seek()` মেথড ব্যবহার করে কার্সরকে ফাইলের যেকোনো নির্দিষ্ট অবস্থানে সরানো যায়।

*   **`offset`**: কত বাইট সরাতে হবে।
*   **`whence`**: কোন রেফারেন্স পয়েন্ট থেকে সরাতে হবে (ডিফল্ট মান 0)।

| `whence` মান | অর্থ                | বর্ণনা                                     |
| :----------- | :------------------ | :----------------------------------------- |
| `0`          | ফাইলের শুরু থেকে   | ফাইলের শুরু থেকে `offset` বাইট সামনে যায়।   |
| `1`          | বর্তমান অবস্থান থেকে | বর্তমান অবস্থান থেকে `offset` বাইট সামনে বা পেছনে যায়। (Text মোডে শুধু `offset=0` কাজ করে)|
| `2`          | ফাইলের শেষ থেকে   | ফাইলের শেষ থেকে `offset` বাইট পেছনে আসে। (Text মোডে কাজ করে না) |

**উদাহরণ:**
```python
# example.txt ফাইলে "Python is fun" লেখা আছে
with open('example.txt', 'r', encoding='utf-8') as f:
    # ফাইলের শুরু থেকে পড়া
    print('Start:', f.read(6)) # "Python"
    
    # কার্সর আবার শুরুতে নেওয়া
    f.seek(0)
    
    # আবার পড়া
    print('Back to start:', f.read(6)) # "Python"
```
**আউটপুট:**
```
Start: Python
Back to start: Python
```

---

#### **Example of Cursor Movement**
`seek()` এবং `tell()` একসাথে ব্যবহার করে ফাইলের বিভিন্ন অংশ পড়া যায়।
```python
# story.txt ফাইলে "Python Is Awesome" লেখা আছে
with open('story.txt', 'w', encoding='utf-8') as f:
    f.write("Python Is Awesome")

with open('story.txt', 'r', encoding='utf-8') as f:
    print(f.read(4))      # প্রথম ৪ অক্ষর পড়া হয় ("Pyth")
    print('Position:', f.tell()) # আউটপুট: 4
    
    f.seek(0)             # কার্সর আবার শুরুতে
    print(f.read(8))      # আবার প্রথম ৮ অক্ষর পড়া হয় ("Python I")
```

---

#### **File Pointer in Write and Append Mode**
*   **Write Mode (`'w'`)**: ফাইল খুললে কার্সর শুরুতে (0) থাকে এবং ফাইলের পুরনো সব কন্টেন্ট মুছে যায় (truncate)।
*   **Append Mode (`'a'`)**: ফাইল খুললে কার্সর সবসময় ফাইলের শেষে থাকে, যাতে নতুন লেখা পুরনো লেখার পরে যুক্ত হয়।

**উদাহরণ:**
```python
# Write Mode
with open('sample.txt', 'w', encoding='utf-8') as a:
    a.write('ABC')
    print("Write mode position:", a.tell())  # আউটপুট: 3

# Append Mode
with open('sample.txt', 'a', encoding='utf-8') as b:
    # খোলার সাথে সাথেই কার্সর ফাইলের শেষে চলে যায়
    print("Append mode position:", b.tell())  # আউটপুট: 3
    b.write('\nDEF')
```

#### **Random Access Using `seek()`**
`seek()` ব্যবহার করে ফাইলের যেকোনো অংশে সরাসরি গিয়ে ডেটা পড়া বা লেখা যায় (`'r+'` মোডে)। একে Random Access বলা হয়।
```python
# data.txt ফাইলে "Learning Python is great" লেখা আছে
with open('data.txt', 'r', encoding='utf-8') as f:
    # কার্সরকে ৭ম বাইটে নেওয়া হলো
    f.seek(7)
    # ৭ম বাইট থেকে পরবর্তী ৫টি অক্ষর পড়া
    part = f.read(5)
    print('Selected part:', part) # আউটপুট: "Python"
```

#### **Binary Mode Pointer Example**
বাইনারি ফাইলেও (`'rb'`, `'wb'`) পয়েন্টার একইভাবে কাজ করে, তবে এটি character-এর বদলে বাইট (byte) গণনা করে।
```python
with open('image.jpg', 'rb') as f:
    # কার্সরকে ১০০ বাইট সামনে সরানো হলো
    f.seek(100)
    # পরবর্তী ২০ বাইট ডেটা পড়া হলো
    data = f.read(20)
    print('Read bytes:', len(data)) # আউটপুট: 20
```

---

#### **মূল পয়েন্টসমূহ (Key Points)**
*   File Pointer ফাইলের ভেতরে read বা write করার অবস্থান নির্দেশ করে।
*   `tell()` পয়েন্টারের বর্তমান অবস্থান (বাইট সংখ্যা) জানায়।
*   `seek()` পয়েন্টারকে নির্দিষ্ট অবস্থানে নিয়ে যায়।
*   `'w'` মোডে পয়েন্টার শুরুতে থাকে এবং পুরনো ডেটা মুছে দেয়।
*   `'a'` মোডে পয়েন্টার সবসময় ফাইলের শেষে থাকে।
*   `'r+'` মোড এবং `seek()` ব্যবহার করে Random Access করা যায়।

### **7.6 — Exceptions and Why Handling Them**

#### **What is an Exception?**
Exception হলো প্রোগ্রাম চলার সময় ঘটে যাওয়া একটি **runtime error**, যা প্রোগ্রামের স্বাভাবিক প্রবাহ বন্ধ করে দেয়। অর্থাৎ, কোডের সিনট্যাক্স ঠিক থাকলেও যখন কোনো অপ্রত্যাশিত পরিস্থিতির কারণে প্রোগ্রাম আর চলতে পারে না, তখন একটি Exception ঘটে।

উদাহরণস্বরূপ, যদি আমরা এমন কোনো ফাইল খুলতে চেষ্টা করি যার অস্তিত্ব নেই, তাহলে Python একটি `FileNotFoundError` exception তৈরি করে এবং প্রোগ্রামটি বন্ধ হয়ে যায়।

**উদাহরণ (Exception ছাড়া কোড):**
```python
# 'nofile.txt' নামে কোনো ফাইল নেই
f = open('nofile.txt', 'r', encoding='utf-8')
print(f.read())
```
**আউটপুট (Error):**
```
Traceback (most recent call last):
  ...
FileNotFoundError: [Errno 2] No such file or directory: 'nofile.txt'
```
এই error-এর কারণে প্রোগ্রামের পরবর্তী কোনো লাইন আর এক্সিকিউট হবে না।

---

#### **Why Handle Exceptions?**
Exception handle না করলে প্রোগ্রাম অপ্রত্যাশিতভাবে **crash করে যায়**, যা ব্যবহারকারীর জন্য একটি বাজে অভিজ্ঞতা তৈরি করে। Exception handling-এর মাধ্যমে আমরা এই ধরনের error গুলিকে সুন্দরভাবে সামাল দিতে পারি এবং প্রোগ্রামকে ক্র্যাশ করার পরিবর্তে একটি বিকল্প পথ দেখাতে পারি। এতে প্রোগ্রামটি আরও **robust** (নির্ভরযোগ্য) ও **user-friendly** হয়।

**উদাহরণ (Exception Handling সহ কোড):**
```python
try:
    # যে কোডে error হতে পারে, তা try ব্লকে রাখা হয়
    f = open('nofile.txt', 'r', encoding='utf-8')
    data = f.read()
    print(data)
except FileNotFoundError:
    # যদি FileNotFoundError ঘটে, তবে এই ব্লকটি কাজ করবে
    print('File not found! Please check the file name.')

print("Program continues...") # এই লাইনটি এখন এক্সিকিউট হবে
```
**আউটপুট:**
```
File not found! Please check the file name.
Program continues...
```
এখানে `FileNotFoundError` ঘটলেও প্রোগ্রামটি বন্ধ হয়নি, বরং `except` ব্লকের কোডটি রান করেছে এবং প্রোগ্রামের বাকি অংশ স্বাভাবিকভাবে চলেছে।

---

#### **Common Exceptions in File Handling**
ফাইল নিয়ে কাজ করার সময় সাধারণত যে Exception গুলো ঘটে:

| Exception                | কারণ                                                      |
| :----------------------- | :-------------------------------------------------------- |
| `FileNotFoundError`      | যখন `'r'` মোডে ফাইলটি খুঁজে পাওয়া যায় না।                     |
| `PermissionError`        | যখন কোনো ফাইলে পড়া বা লেখার অনুমতি (permission) থাকে না।     |
| `IsADirectoryError`      | যখন ফাইলের নামের জায়গায় একটি ডিরেক্টরির নাম ব্যবহার করা হয়। |
| `UnicodeDecodeError`     | ভুল `encoding` (যেমন `utf-8`-এর বদলে অন্য কিছু) ব্যবহার করে ফাইল পড়লে। |
| `UnicodeEncodeError`     | ভুল `encoding` দিয়ে ফাইল লেখার চেষ্টা করলে।                   |

---

#### **Using the `try-except` Block**
Python-এ exception handle করার জন্য `try-except` স্টেটমেন্ট ব্যবহার করা হয়।
*   **`try` block:** এখানে সেই কোড রাখা হয় যেখানে error ঘটতে পারে।
*   **`except` block:** যদি `try` ব্লকে কোনো নির্দিষ্ট error ঘটে, তাহলে এই ব্লকটি এক্সিকিউট হয়।

```python
try:
    f = open('data.txt', 'r', encoding='utf-8')
    print(f.read())
except FileNotFoundError:
    print('File does not exist!')
except PermissionError:
    print('You do not have permission to read this file.')
```

---

#### **Using the `else` Block**
`try-except` এর সাথে `else` ব্লকও ব্যবহার করা যায়। `else` ব্লকটি তখনই এক্সিকিউট হয় যখন `try` ব্লকে কোনো exception ঘটে **না**।
```python
try:
    f = open('data.txt', 'r', encoding='utf-8')
except FileNotFoundError:
    print('File not found!')
else:
    # এই ব্লকটি কেবল তখনই চলবে যখন ফাইল সফলভাবে খোলা যাবে
    print('File opened successfully!')
    print(f.read())
    f.close()
```

---

#### **Using the `finally` Block**
`finally` ব্লকটি **সবসময়** এক্সিকিউট হয়—`try` ব্লকে error ঘটুক বা না ঘটুক। সাধারণত রিসোর্স (যেমন: ফাইল, নেটওয়ার্ক কানেকশন) বন্ধ করার মতো ক্লিন-আপ কোড এখানে রাখা হয়।

```python
f = None # ভেরিয়েবলটি আগে ডিক্লেয়ার করা
try:
    f = open('data.txt', 'r', encoding='utf-8')
    print(f.read())
except FileNotFoundError:
    print('File not found!')
finally:
    # এই ব্লকটি সবসময় রান হবে
    if f:
        f.close()
    print('File handling process finished.')
```

#### **Raising Custom Exceptions**
কখনও কখনও আমাদের নিজেদের শর্ত অনুযায়ী error তৈরি করার প্রয়োজন হয়। এর জন্য `raise` কিওয়ার্ড ব্যবহার করা হয়।
```python
filename = ''
if not filename:
    raise ValueError('Filename cannot be empty!')
```
**আউটপুট:**
```
Traceback (most recent call last):
  ...
ValueError: Filename cannot be empty!
```

---

#### **মূল পয়েন্টসমূহ (Key Points)**
*   Exception হলো runtime error যা প্রোগ্রামের স্বাভাবিক প্রবাহকে বাধা দেয়।
*   `try-except` ব্লক ব্যবহার করে প্রোগ্রাম crash হওয়া থেকে রক্ষা করা যায়।
*   `else` ব্লকটি কেবল তখনই চলে যখন `try` ব্লকে কোনো error ঘটে না।
*   `finally` ব্লক error ঘটুক বা না ঘটুক, সবসময় এক্সিকিউট হয়।
*   `raise` কিওয়ার্ড ব্যবহার করে নিজস্ব বা বিল্ট-ইন exception তৈরি করা যায়।

2.  ফাইলটি সফলভাবে খোলা হোক বা না হোক, `finally` ব্লকে “Program ended” মেসেজটি প্রিন্ট করবে।
3.  যদি ব্যবহারকারী কোনো ফাইলের নাম না দিয়ে Enter চাপে, তাহলে একটি `ValueError` তৈরি করুন এবং সেটি handle করুন।

```python
try:
    filename = input('Enter file name: ')
    if not filename:
        raise ValueError('Filename cannot be empty!')

    with open(filename, 'r', encoding='utf-8') as f:
        print("--- File Content ---")

except FileNotFoundError:

except ValueError as e:
    print(f"Error: {e}")
except Exception as e:
    print(f"An unexpected error occurred: {e}")

    print("\nProgram ended.")
```

### **7.7 — Try, Except, Else, and Finally**

#### **What These Blocks Do**
`try`, `except`, `else`, এবং `finally`—এই চারটি ব্লক ব্যবহার করে Python প্রোগ্রামে **exception handling** করা হয়। এর মূল লক্ষ্য হলো, প্রোগ্রামে কোনো error ঘটলে সেটি যেন ক্র্যাশ না করে একটি সুন্দর সমাধান (gracefully behave) দেয় এবং ব্যবহৃত রিসোর্স (যেমন ফাইল) যেন সবসময় সঠিকভাবে বন্ধ হয়।

**সংক্ষিপ্ত ব্যাখ্যা:**
*   **`try`**: এই ব্লকের মধ্যে সেই কোড রাখা হয় যেখানে exception বা error ঘটার সম্ভাবনা থাকে।
*   **`except`**: যদি `try` ব্লকে কোনো exception ঘটে, তাহলে নির্দিষ্ট `except` ব্লকটি সেই error ধরে এবং তার ভেতরের কোড এক্সিকিউট করে।
*   **`else`**: যদি `try` ব্লকে কোনো exception **না ঘটে**, তবেই `else` ব্লকের কোডটি চলে।
*   **`finally`**: এই ব্লকের কোড **সবসময়** চলে—`try` ব্লকে exception ঘটুক বা না ঘটুক। সাধারণত ক্লিন-আপ কোড (যেমন ফাইল বন্ধ করা) এখানে রাখা হয়।

---

#### **Basic Syntax**
```python
try:
    # যে কোডে error হতে পারে
    risky_operation()
except SomeError:
    # error ঘটলে যা করতে হবে
    handle_error()
else:
    # কোনো error না ঘটলে যা করতে হবে
    run_if_no_error()
finally:
    # error ঘটুক বা না ঘটুক, এই কোড সবসময় চলবে
    clean_up_always()
```

---

#### **Control Flow (প্রবাহ চিত্র)**
1.  প্রথমে `try` ব্লকের কোড চালানো হয়।
2.  **যদি exception ঘটে:**
    *   প্রোগ্রামটি `try` ব্লক থেকে বেরিয়ে যায় এবং মিলে যাওয়া `except` ব্লকটি খুঁজে বের করে।
    *   `except` ব্লকের কোড চালানো হয়।
    *   সবশেষে `finally` ব্লকের কোড চালানো হয়।
3.  **যদি exception না ঘটে:**
    *   `try` ব্লকের কোড সফলভাবে শেষ হয়।
    *   এরপর `else` ব্লকের কোড চালানো হয়।
    *   সবশেষে `finally` ব্লকের কোড চালানো হয়।

---

#### **File Handling Example**
```python
try:
    f = open('data.txt', 'r', encoding='utf-8')  # ফাইল পড়ার চেষ্টা
    text = f.read()
except FileNotFoundError:
    print('File not found!') # ফাইল না পেলে এই বার্তা দেখাবে
else:
    print('File content length:', len(text)) # ফাইল পাওয়া গেলে তার দৈর্ঘ্য দেখাবে
finally:
    # ফাইল খোলা হলে তা বন্ধ করা হবে
    try:
        f.close()
        print("File closed.")
    except NameError:
        # ফাইল খোলা না গেলে f ভেরিয়েবল তৈরি হবে না, তাই NameError হতে পারে
        print("File was never opened.")
```
**ব্যাখ্যা:** ফাইলটি পাওয়া গেলে `else` ব্লক কাজ করবে। ফাইল না পাওয়া গেলে `except` ব্লক কাজ করবে। উভয় ক্ষেত্রেই, `finally` ব্লক রান হবে এবং ফাইল খোলা থাকলে তা বন্ধ করার চেষ্টা করবে।

---

#### **Using `with` Statement vs. `finally`**
ফাইল হ্যান্ডলিং-এর জন্য `with open(...)` ব্যবহার করা সবচেয়ে ভালো অভ্যাস। এটি `try...finally`-এর কাজ স্বয়ংক্রিয়ভাবে করে দেয়। `with` ব্লক শেষ হলেই ফাইলটি নিজে থেকেই বন্ধ হয়ে যায়, তাই আলাদা করে `finally` ব্লকে `.close()` লেখার প্রয়োজন হয় না।

```python
try:
    with open('notes.txt', 'r', encoding='utf-8') as f:
        print(f.readline())
except FileNotFoundError:
    print('Missing file')
# এখানে finally ব্লকের প্রয়োজন নেই, with নিজেই ফাইল বন্ধ করে দেবে
```

---

#### **Handling Multiple Specific Exceptions**
ভিন্ন ভিন্ন ধরনের error-এর জন্য আলাদা আলাদা `except` ব্লক ব্যবহার করা যায়।

```python
try:
    with open('conf.txt', 'r', encoding='utf-8') as f:
        value = int(f.read().strip())
except FileNotFoundError:
    print('Configuration file missing')
except ValueError:
    print('Configuration must be an integer')
```

#### **Catching Multiple Exceptions Together**
একাধিক exception-কে একটি `except` ব্লকে tuple আকারেও ধরা যায়।
```python
try:
    connect_and_fetch()
except (TimeoutError, ConnectionError) as e:
    print('Network issue:', e)
```

---

#### **Generic `except` and Exception Object**
শুধুমাত্র `except:` বা `except Exception:` লিখলে এটি প্রায় সব ধরনের error ধরে ফেলে। তবে এটি একটি বাজে অভ্যাস, কারণ এটি আপনার প্রোগ্রামের অপ্রত্যাশিত error গুলিকেও লুকিয়ে ফেলে। যদি ব্যবহার করতেই হয়, তবে error অবজেক্টটি (`as e`) প্রিন্ট করে ডিবাগ করা উচিত।

```python
try:
    do_work()
except Exception as e:  # generic, সতর্কতার সাথে ব্যবহার করুন
    print('Unexpected error:', type(e).__name__, e)
```

#### **Best Practices and Common Mistakes**

##### **Best Practices**
*   **নির্দিষ্ট exception ধরুন:** `except Exception` বা খালি `except:` এড়িয়ে চলুন।
*   **Error গোপন করবেন না:** `except` ব্লকে `pass` ব্যবহার না করে অন্তত error-টি লগ করুন বা একটি অর্থপূর্ণ বার্তা দিন।
*   **`with` স্টেটমেন্ট ব্যবহার করুন:** ফাইল বা অন্যান্য রিসোর্সের জন্য `with` ব্যবহার করলে ক্লিন-আপ নিয়ে চিন্তা করতে হয় না।
*   **`else` ব্লক ব্যবহার করুন:** যে কোডটি কেবল `try` ব্লক সফল হলেই চালানো দরকার, সেটি `else`-এ রাখুন। এতে কোড পরিচ্ছন্ন থাকে।
*   **`finally`-কে ক্লিন রাখুন:** `finally` ব্লক শুধুমাত্র রিসোর্স ক্লিন-আপের জন্য ব্যবহার করুন।

##### **Common Mistakes**
*   খালি `except:` ব্যবহার করে সব error লুকিয়ে ফেলা (swallowing exceptions)।
*   `try` ব্লকের মধ্যে প্রয়োজনের চেয়ে বেশি কোড রাখা। শুধুমাত্র যে লাইনে error হতে পারে, সেটুকুই `try` ব্লকে রাখুন।
*   `finally` ব্লকে এমন কোড লেখা যা নিজেই একটি নতুন exception তৈরি করতে পারে।

1.  ব্যবহারকারীর কাছ থেকে একটি ফাইলের নাম ইনপুট নিন। ফাইলটি পড়া সম্ভব হলে প্রথম লাইনটি প্রিন্ট করুন; না হলে একটি অর্থপূর্ণ error দেখান। `else` এবং `finally` ব্লক ব্যবহার করুন।

3.  `try/except/else/finally` ব্যবহার করে একটি temporary ফাইল তৈরি করুন, তাতে কিছু লিখুন, এবং শেষে ফাইলটি ডিলিট করুন।

**Exercise 2-এর সমাধান:**
```python
try:
    a = float(input('Enter the numerator (A): '))
    b = float(input('Enter the denominator (B): '))
    result = a / b
except ValueError:
    print('Invalid input. Please enter valid numbers.')

    print('Error: Division by zero is not allowed.')
else:
    print('Result =', result)
finally:
    print('Calculation finished.')
```
