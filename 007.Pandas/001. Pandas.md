# Pandas কী এবং কেন এটি গুরুত্বপূর্ণ?

আমরা যখন ডেটা সায়েন্স বা মেশিন লার্নিং নিয়ে কাজ করি, তখন আমাদের সবচেয়ে গুরুত্বপূর্ণ জিনিস হচ্ছে — **ডেটা (Data)**।

এই ডেটা কখনও সঠিক ফরম্যাটে থাকে না — কখনও মিসিং ভ্যালু, কখনও ভুল কলাম, কখনও অপ্রয়োজনীয় ইনফরমেশন থাকে।

এই অবস্থায় ডেটাকে সাজানো, পরিষ্কার করা, এবং বিশ্লেষণের উপযুক্ত করে তোলা — এটিই হলো **ডেটা প্রিপ্রসেসিং (Data Preprocessing)**।

আর এই কাজটি করতে যে লাইব্রেরি আমাদের সবচেয়ে বেশি সাহায্য করে, সেটি হলো **Pandas**।

## Pandas কী?

**Pandas** হলো Python এর একটি শক্তিশালী ওপেন-সোর্স লাইব্রেরি যা মূলত **ডেটা বিশ্লেষণ (Data Analysis)** এবং **ডেটা ম্যানিপুলেশন (Data Manipulation)** এর জন্য ব্যবহৃত হয়।

এর নাম এসেছে "**Panel Data**" থেকে — যার মানে হলো বহু-মাত্রিক (multidimensional) ডেটা সেট।

### কেন Pandas দরকার?

#### ১. ডেটা ক্লিনিং (Data Cleaning)

Pandas দিয়ে খুব সহজেই আমরা —

- মিসিং ভ্যালু (Missing Values) হ্যান্ডেল করতে পারি
- ডুপ্লিকেট ডেটা রিমুভ করতে পারি
- ডেটার ফরম্যাট ঠিক করতে পারি

#### ২. ডেটা প্রিপ্রসেসিং (Data Preprocessing)

মেশিন লার্নিং মডেল ট্রেন করার আগে ডেটাকে প্রস্তুত করতে হয়। Pandas দিয়ে আমরা সহজেই:

- কলাম যোগ/বাদ দিতে পারি
- ডেটা স্কেল বা নর্মালাইজ করতে পারি
- কেটেগোরিকাল ডেটাকে নিউমেরিক্যাল এ রূপান্তর করতে পারি (যেমন get_dummies() ব্যবহার করে)

#### ৩. ডেটা অ্যানালাইসিস (Data Analysis)

Pandas দিয়ে আমরা ডেটার বিভিন্ন দিক বিশ্লেষণ করতে পারি:

- গড় (mean), মিডিয়ান (median), সর্বাধিক মান (max/min)
- গ্রুপ-বাই (groupby) করে বিভিন্ন সাবসেট বিশ্লেষণ
- ডেটার উপর ফিল্টার ও কন্ডিশন প্রয়োগ

#### ৪. ডেটা ভিজুয়ালাইজেশন (Data Visualization)

যদিও Pandas মূলত ডেটা হ্যান্ডলিং লাইব্রেরি, তবুও এটি **Matplotlib** বা **Seaborn** এর সাথে যুক্ত হয়ে সুন্দর গ্রাফ তৈরি করতে পারে।

#### ৫. মেশিন লার্নিং এ Pandas এর ভূমিকা

Pandas মেশিন লার্নিং এর প্রথম ধাপেই সবচেয়ে গুরুত্বপূর্ণ:

1. ডেটা লোড করা (pd.read_csv(), pd.read_excel())
2. ডেটা ক্লিন করা (মিসিং ভ্যালু, আউটলায়ার হ্যান্ডল)
3. ফিচার তৈরি করা (Feature Engineering)
4. মডেলে ইনপুট দেওয়ার আগে ডেটাকে প্রস্তুত করা

বলা যায়, **"No Clean Data, No Good Model"** — আর সেই ক্লিনিং এর মূল হাতিয়ার হলো **Pandas**।


# Pandas DataFrame and Series

## ভূমিকা

Pandas মূলত দুটি গুরুত্বপূর্ণ ডেটা স্ট্রাকচার ব্যবহার করে কাজ করে —

1. **Series**
2. **DataFrame**

এই দুইটি ডেটা স্ট্রাকচার একে অপরের সাথে সম্পর্কিত এবং প্রায় সব ধরনের ডেটা বিশ্লেষণ বা প্রিপ্রসেসিং এ ব্যবহার হয়। চলো আগে একটু বুঝে নিই এরা কী।

### 1. Pandas Series কী?

**Series** হচ্ছে একটি এক-মাত্রিক (1D) ডেটা স্ট্রাকচার, যেখানে একটি নির্দিষ্ট ইনডেক্স সহ ডেটার লিস্ট রাখা হয়। তুমি একে Python-এর **list** বা **array** এর মতো ভাবতে পারো, তবে এর একটি **label (index)** থাকে যা ডেটা আইটেমগুলোকে সনাক্ত করে।

উদাহরণ:
```pathon
import pandas as pd

numbers = pd.Series([10, 20, 30, 40, 50])
print(numbers)
print(type(numbers))
```

**আউটপুট:**
```
0    10
1    20
2    30
3    40
4    50
dtype: int64
<class 'pandas.core.series.Series'>
```
**ব্যাখ্যা:**

- বামপাশে 0, 1, 2, 3, 4 হলো **index**
- ডানপাশে 10, 20, 30, 40, 50 হলো **values**
- Pandas স্বয়ংক্রিয়ভাবে index তৈরি করে, তবে চাইলে আমরা নিজের index সেট করতে পারি।
python

````python
marks = pd.Series([85, 90, 78], index=['Alif', 'Fatima', 'Imran'])
print(marks)
```

**আউটপুট:**
```
Alif      85
Fatima    90
Imran     78
dtype: int64
````

## 2. Pandas DataFrame কী?

**DataFrame** হলো একটি দুই-মাত্রিক (2D) ডেটা স্ট্রাকচার। এক কথায় — এটি হচ্ছে টেবিল ফরম্যাটে ডেটা রাখার ব্যবস্থা, যেখানে প্রতিটি কলাম আসলে একটি **Series**।

অর্থাৎ, একটি DataFrame হলো **Series-এর সংগ্রহ (collection of Series)**।

তুমি এটি Excel sheet বা SQL table-এর মতো কল্পনা করতে পারো।

### উদাহরণ: CSV ফাইল থেকে DataFrame তৈরি
python

````python
import pandas as pd

df = pd.read_csv('student_data.csv')
print(df)
print(type(df))
```

**আউটপুট (সংক্ষেপে):**
```
   StudentID          FullName  ...  Instructor    Location
0     PH1001       Alif Rahman  ...   Mr. Karim       Dhaka
1     PH1002     Fatima Akhter  ...   Ms. Salma  Chattogram
2     PH1003     Imran Hossain  ...   Mr. Karim       Dhaka
...
19    PH1020        Nasir Khan  ...   Ms. Salma       Dhaka

[20 rows x 9 columns]
<class 'pandas.core.frame.DataFrame'>
````
**ব্যাখ্যা:**

- df একটি DataFrame, অর্থাৎ দুই-মাত্রিক টেবিল।
- প্রতিটি কলাম হলো একটি Series।
- এখানে মোট ২০টি row এবং ৯টি column আছে।
- type(df) দিলে দেখা যায় এটি pandas.core.frame.DataFrame।

## 3. DataFrame থেকে Series অ্যাক্সেস করা

যেহেতু প্রতিটি কলামই এক একটি Series, তাই আমরা সহজেই সেগুলো আলাদা করে ব্যবহার করতে পারি।

python

````python
names = df['FullName']
print(names)
print(type(names))

**আউটপুট:**

0          Alif Rahman
1        Fatima Akhter
2        Imran Hossain
...
19          Nasir Khan
Name: FullName, dtype: object
<class 'pandas.core.series.Series'>
````
**ব্যাখ্যা:**

এখানে df['FullName'] একটি Series। অর্থাৎ, DataFrame এর প্রতিটি কলাম আলাদা করে এক-মাত্রিক Series হিসেবে ব্যবহৃত হয়।

## 4. DataFrame তৈরি করা (ম্যানুয়ালি)

চাইলে DataFrame নিজে তৈরি করাও যায়, dictionary ব্যবহার করে।

python

````python
data = {
    'StudentID': ['PH1001', 'PH1002', 'PH1003'],
    'Name': ['Alif', 'Fatima', 'Imran'],
    'Marks': [85, 90, 78]
}

df2 = pd.DataFrame(data)
print(df2)


**আউটপুট:**

  StudentID    Name  Marks
0    PH1001    Alif     85
1    PH1002  Fatima     90
2    PH1003   Imran     78
````
## 5. DataFrame এর কিছু সাধারণ অ্যাট্রিবিউট

|Method/Attribute|বর্ণনা|
|---|---|
|df.shape|রো এবং কলামের সংখ্যা দেখায়|
|df.columns|সব কলামের নাম দেখায়|
|df.head()|প্রথম কয়েকটি রো দেখায়|
|df.tail()|শেষ কয়েকটি রো দেখায়|
|df.info()|ডেটা টাইপ এবং নাল ভ্যালু সম্পর্কে তথ্য দেয়|
|df.describe()|সংখ্যাগত কলামগুলির পরিসংখ্যান দেখায়|

python

```python
print(df.shape)
```
