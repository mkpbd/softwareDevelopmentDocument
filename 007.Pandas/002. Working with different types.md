
12.3 Working with Different file types in Pandas

ভূমিকা

ডেটা সায়েন্স বা মেশিন লার্নিং প্রজেক্টে ডেটা বিভিন্ন ফরম্যাটে সংরক্ষণ করা হয়। যেমন:
1. .csv (Comma-Separated Values)
2. .xlsx (Excel)
3. .parquet (Compressed Binary Format)
4. .json (JavaScript Object Notation)

এই সব ফাইল থেকেই আমরা Pandas DataFrame তৈরি করতে পারি এবং সহজেই বিশ্লেষণ বা প্রক্রিয়াজাত করতে পারি।
এই মডিউলে আমরা দেখব কীভাবে Pandas দিয়ে বিভিন্ন ফাইল টাইপ লোড করা যায়।

1. CSV ফাইল লোড করা

CSV (Comma-Separated Values) হলো সবচেয়ে জনপ্রিয় এবং সাধারণ ডেটা ফরম্যাট।
Pandas দিয়ে CSV ফাইল পড়া যায় pd.read_csv() ফাংশন ব্যবহার করে।

```python
import pandas as pd

# csv file
csv_data = pd.read_csv('student_data.csv')

print(csv_data)
print(type(csv_data))
```

আউটপুট (সংক্ষেপে):
```
   StudentID          FullName  ...  Instructor    Location
0     PH1001       Alif Rahman  ...   Mr. Karim       Dhaka
1     PH1002     Fatima Akhter  ...   Ms. Salma  Chattogram
2     PH1003     Imran Hossain  ...   Mr. Karim       Dhaka
...
19    PH1020        Nasir Khan  ...   Ms. Salma       Dhaka

[20 rows x 9 columns]
<class 'pandas.core.frame.DataFrame'>
```

ব্যাখ্যা:
1. pd.read_csv() ফাংশন CSV ফাইল থেকে ডেটা পড়ে এনে DataFrame তৈরি করে।
2. ফাইলের প্রতিটি কলাম আলাদা Series হিসেবে সংরক্ষণ হয়।
3. type(csv_data) দিলে বোঝা যায় এটি একটি DataFrame।

4. Excel ফাইল লোড করা

Excel ফাইল সাধারণত .xlsx এক্সটেনশনে থাকে।
এটি পড়তে pd.read_excel() ব্যবহার করা হয়।

```python
# excel file
excel_file = pd.read_excel('phitron_student_marks.xlsx')

print(excel_file)
print(type(excel_file))
```

আউটপুট:
```
   StudentID          FullName  ...  Instructor    Location
0     PH1001       Alif Rahman  ...   Mr. Karim       Dhaka
1     PH1002     Fatima Akhter  ...   Ms. Salma  Chattogram
...
19    PH1020        Nasir Khan  ...   Ms. Salma       Dhaka

[20 rows x 9 columns]
<class 'pandas.core.frame.DataFrame'>
```

ব্যাখ্যা:
1. Excel ফাইল পড়ার জন্য সিস্টেমে openpyxl বা xlrd লাইব্রেরি ইন্সটল থাকতে হয়।
2. pd.read_excel() স্বয়ংক্রিয়ভাবে প্রথম শীট পড়ে নেয়।
3. যদি ফাইলে একাধিক শীট থাকে, তবে sheet_name প্যারামিটার ব্যবহার করা যায়।
4. উদাহরণ:

```python
pd.read_excel('file.xlsx', sheet_name='Sheet2')
```

3. Parquet ফাইল লোড করা

Parquet হলো একটি binary, columnar storage format, যা বড় ডেটাসেট সংরক্ষণের জন্য ব্যবহৃত হয়।
এটি .parquet এক্সটেনশন ব্যবহার করে।
Pandas-এ এটি পড়া যায় pd.read_parquet() ফাংশন দিয়ে।

```python
# parquet file
parquet_file = pd.read_parquet('students.parquet')

print(parquet_file)
print(type(parquet_file))
```

আউটপুট:
```
   StudentID          FullName  ...  Instructor    Location
0     PH1001       Alif Rahman  ...   Mr. Karim       Dhaka
1     PH1002     Fatima Akhter  ...   Ms. Salma  Chattogram
...
19    PH1020        Nasir Khan  ...   Ms. Salma       Dhaka

[20 rows x 9 columns]
<class 'pandas.core.frame.DataFrame'>
```

ব্যাখ্যা:
1. Parquet ফাইল সাধারণত Hadoop বা Spark এর মতো বিগ ডেটা সিস্টেমে ব্যবহৃত হয়।
2. এই ফরম্যাটে ডেটা কমপ্রেসড অবস্থায় থাকে, তাই এটি দ্রুত লোড হয় এবং মেমরি বাঁচায়।
3. এটি পড়তে হলে pyarrow বা fastparquet প্যাকেজ ইনস্টল থাকা প্রয়োজন।

4. JSON ফাইল লোড করা

JSON ফাইল মূলত key-value pair আকারে ডেটা রাখে।
এটি পড়তে pd.read_json() ফাংশন ব্যবহার করা হয়।

```python
# json file
json_file = pd.read_json('data.json')

print(json_file)
print(type(json_file))
```

আউটপুট:
```
  StudentID          FullName  ...  Algorithm Marks  Python Marks
0    PH1001       Alif Rahman  ...               85            88
1    PH1002     Fatima Akhter  ...               92            90
2    PH1004  Jannatul Ferdous  ...               78            82

[3 rows x 5 columns]
<class 'pandas.core.frame.DataFrame'>
```

ব্যাখ্যা:
1. JSON ফাইল সাধারণত nested বা structured data সংরক্ষণের জন্য ব্যবহৃত হয়।
2. pd.read_json() JSON কে DataFrame-এ রূপান্তর করে।
3. চাইলে DataFrame থেকে JSON ফাইল তৈরি করাও যায়:

```python
df.to_json('output.json')
```
