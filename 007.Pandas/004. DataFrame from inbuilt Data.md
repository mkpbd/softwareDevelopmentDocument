
### 12.5 Dataframe from Inbuilt Data with Column and Indexes

সব সময় আমাদের ডেটা কোনো CSV বা Excel ফাইলে থাকে না।
অনেক সময় ডেটা প্রোগ্রামের ভেতরেই থাকে — যেমন **list**, **tuple**, বা **dictionary** আকারে।
Pandas সহজেই এই ডেটাগুলো থেকে একটি **DataFrame** তৈরি করতে পারে।

## 1. লিস্ট (List) থেকে DataFrame তৈরি

List হলো একটি সাধারণ Python ডেটা স্ট্রাকচার, যেখানে একাধিক মান রাখা যায়।
একটি nested list (লিস্টের ভেতরে লিস্ট) থেকে DataFrame বানানো যায়।

```python
import pandas as pd

my_list = [['Alice', 25], ['Bob', 30], ['Charlie', 28]]

list_df = pd.DataFrame(my_list, columns=['Name', 'Age'], index=[1, 2, 3])

print(type(list_df))
list_df
```

আউটপুট:

```
<class 'pandas.core.frame.DataFrame'>
      Name   Age
1    Alice   25
2      Bob   30
3  Charlie   28
```

ব্যাখ্যা:
1.  my\_list হলো একটি লিস্টের ভেতরে লিস্ট।
2.  columns দিয়ে কলামের নাম দেওয়া হয়েছে।
3.  index দিয়ে সারির ইনডেক্স নির্ধারণ করা হয়েছে।
4.  ফলাফল একটি পূর্ণাঙ্গ DataFrame।

## 2. টাপল (Tuple) থেকে DataFrame তৈরি

Tuple লিস্টের মতোই, তবে এর মান পরিবর্তন করা যায় না।
Tuple থেকেও DataFrame তৈরি করা সম্ভব।

```python
my_tuple = (('Alice', 25), ('Bob', 30), ('Charlie', 28))

tuple_df = pd.DataFrame(my_tuple, columns=['Name', 'Age'])
tuple_df
```

আউটপুট:

```
      Name   Age
0    Alice   25
1      Bob   30
2  Charlie   28
```

ব্যাখ্যা:
এখানে ইনডেক্স না দিলে Pandas স্বয়ংক্রিয়ভাবে 0, 1, 2 ইনডেক্স সেট করে।

## 3. ডিকশনারি (Dictionary) থেকে DataFrame তৈরি

Dictionary হলো key-value জোড়ার ডেটা স্ট্রাকচার।
এটি DataFrame তৈরির সবচেয়ে প্রচলিত উপায়।

```python
my_dict = {
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 29, 28]
}

dict_df = pd.DataFrame(my_dict)
dict_df
```

আউটপুট:

```
      Name   Age
0    Alice   25
1      Bob   29
2  Charlie   28
```

ব্যাখ্যা:
1.  Dictionary-এর key (যেমন 'Name', 'Age') হয় DataFrame-এর কলামের নাম।
2.  আর এর value (যা লিস্ট আকারে থাকে) হয় সেই কলামের মান।

## 4. ডিকশনারির লিস্ট (List of Dictionaries) থেকে DataFrame তৈরি

একাধিক অবজেক্ট (যেমন ছাত্রদের তথ্য) আলাদা আলাদা dictionary-তে থাকলে
সেগুলো একটি লিস্টে রেখে DataFrame বানানো যায়।

```python
my_data = [
    {'Name': 'Alice', 'Age': 25, 'City': 'New York'},
    {'Name': 'Bob', 'Age': 30, 'City': 'Paris'},
    {'Name': 'Charlie', 'Age': 28}
]

data_df = pd.DataFrame(my_data)
data_df
```

আউটপুট:

```
      Name   Age      City
0    Alice   25  New York
1      Bob   30      Paris
2  Charlie   28       NaN
```

ব্যাখ্যা:
1.  প্রতিটি dictionary একটি করে রো হিসেবে যুক্ত হয়।
2.  যেখানে কোনো মান অনুপস্থিত (যেমন Charlie-এর City), সেখানে Pandas স্বয়ংক্রিয়ভাবে NaN বসায়।
3.  NaN মানে “Not a Number” বা Missing Value

## 5. DataFrame থেকে Series আলাদা করা

যখন কোনো নির্দিষ্ট কলাম নেওয়া হয়, সেটি Series আকারে পাওয়া যায়।

```python
print(type(data_df['Name']))
```

আউটপুট:

```
<class 'pandas.core.series.Series'>
```

ব্যাখ্যা:
1.  DataFrame হলো পুরো টেবিলের মতো।
2.  Series হলো একক কলাম — একমাত্রিক ডেটা।
