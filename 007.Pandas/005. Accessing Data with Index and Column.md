
### 12.6 Accessing Data with Index and Column

DataFrame তৈরি করার পর সবচেয়ে গুরুত্বপূর্ণ কাজ হলো তার ভেতরের **ডেটা দেখা ও নির্দিষ্ট অংশে অ্যাক্সেস করা**।
Pandas-এ DataFrame থেকে ডেটা বের করার জন্য দুটি প্রধান উপায় রয়েছে —

1.  **কলামের নাম ব্যবহার করে**
2.  **ইনডেক্স ও কলামের সমন্বয়ে (loc/iloc) ব্যবহার করে**

### **1. পুরো DataFrame দেখা**

```python
df
```

এভাবে শুধু df লিখলে পুরো DataFrame টেবিল আকারে দেখা যায়।

### **2. একটি নির্দিষ্ট কলাম অ্যাক্সেস করা**

একটি কলাম নেওয়ার জন্য কলামের নাম [] এর মধ্যে দিতে হয়।

```python
# একটি কলাম অ্যাক্সেস করা
df['FullName']
```

আউটপুট:

```
0        Alice
1          Bob
2      Charlie
3         David
...
```

কলামের ডেটা সবসময় **Series** আকারে ফেরত দেয়।

```python
type(df['FullName'])
```

আউটপুট:
```
pandas.core.series.Series
```

### **3. .loc[] ব্যবহার করে সারি (Row) অ্যাক্সেস করা**

.loc[] হলো label-based accessor — অর্থাৎ, ইনডেক্স নাম বা লেবেল দিয়ে ডেটা পাওয়া যায়।

```python
# নির্দিষ্ট একটি সারি অ্যাক্সেস
df.loc[0]
```

আউটপুট:
```
FullName              Alice
Python Marks             88
Algorithm Marks          90
CompletionStatus    Completed
Name: 0, dtype: object
```

একটি সারি অ্যাক্সেস করলে সেটিও **Series** আকারে ফেরত দেয়।

```python
type(df.loc[0])
```

আউটপুট:
```
pandas.core.series.Series
```

### **4. একাধিক সারি অ্যাক্সেস করা**

#### a. নির্দিষ্ট ইনডেক্স লিস্ট ব্যবহার করে

```python
# একাধিক নির্দিষ্ট সারি
df.loc[[2, 3, 19]]
```

আউটপুট:
```
   FullName  Python Marks  Algorithm Marks CompletionStatus
2   Charlie          85.0               78         Completed
3     David          82.0               88      In Progress
19    Sarah          89.0               84         Completed
```

#### b. রেঞ্জ ব্যবহার করে

```python
# ইনডেক্স রেঞ্জ দিয়ে সারি নির্বাচন
df.loc[3:7]
```

এইভাবে 3 থেকে 7 পর্যন্ত সারি পাওয়া যাবে (শেষ ইনডেক্সসহ)।

### **5. নির্দিষ্ট কলাম অ্যাক্সেস করা (loc ব্যবহার করে)**

#### একক কলাম:

```python
df.loc[:, 'Python Marks']
```

আউটপুট:
```
0     88.0
1      NaN
2     85.0
3     82.0
...
19    89.0
Name: Python Marks, dtype: float64
```

#### একাধিক কলাম:

```python
df.loc[:, ['Python Marks', 'Algorithm Marks']]
```

আউটপুট:
```
    Python Marks  Algorithm Marks
0           88.0               90
1            NaN               80
2           85.0               78
3           82.0               88
...

type(df.loc[:, ['Python Marks', 'Algorithm Marks']])
```

আউটপুট:
```
pandas.core.frame.DataFrame
```

ব্যাখ্যা:
একাধিক কলাম নিলে ফলাফল DataFrame আকারে পাওয়া যায়।

### **6. নির্দিষ্ট সারি ও কলাম একসাথে নির্বাচন**

.loc[] ব্যবহার করে নির্দিষ্ট সারি ও নির্দিষ্ট কলাম একসাথে সিলেক্ট করা যায়।

```python
df.loc[3:7, 'CompletionStatus']
```

আউটপুট:
```
3      Completed
4    In Progress
5      Completed
6    In Progress
7      Completed
Name: CompletionStatus, dtype: object
```

ব্যাখ্যা:
এখানে ৩ থেকে ৭ নম্বর সারির জন্য শুধুমাত্র CompletionStatus কলাম নেওয়া হয়েছে।
