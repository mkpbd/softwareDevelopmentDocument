### 12.9 Sorting a DF

`sort_values()` ফাংশন ব্যবহার করে DataFrame-কে নির্দিষ্ট কলাম বা একাধিক কলামের মান অনুযায়ী সাজানো যায়।
এটি ascending (ছোট থেকে বড়) বা descending (বড় থেকে ছোট) ক্রমে sort করতে পারে।

---

### Example 1: DataFrame প্রদর্শন

```python
df
```
*(এই কোডটি মূল DataFrame প্রদর্শন করে।)*
![[Pasted image 20251102072032.png]]
---

### Example 2: এক কলাম অনুযায়ী sort করা

```python
copy = df.sort_values('Data Structure Marks')
```
এখানে 'Data Structure Marks' কলামের মান অনুযায়ী ছোট থেকে বড় ক্রমে sort হয়েছে।

---

### Example 3: Descending (বড় থেকে ছোট) ক্রমে sort করা

```python
copy = df.sort_values(['Data Structure Marks'], ascending=False)
```
এখানে DataFrame বড় থেকে ছোট মান অনুযায়ী সাজানো হয়েছে।

---

### Example 4: একাধিক কলাম অনুযায়ী sort করা

```python
copy = df.sort_values(['Data Structure Marks', 'Python Marks'], ascending=False)
```
প্রথমে 'Data Structure Marks' কলাম অনুযায়ী sort হবে।
যদি কোনো সারিতে ওই কলামের মান সমান হয়, তবে 'Python Marks' কলামের মান অনুযায়ী সাজানো হবে।

---

### Example 5: একাধিক কলামে ভিন্ন ভিন্ন ক্রমে sort করা

```python
copy = df.sort_values(['Data Structure Marks', 'Python Marks'], ascending=[0, 1])
```
এখানে 'Data Structure Marks' কলামটি descending (বড় থেকে ছোট) এবং 'Python Marks' কলামটি ascending (ছোট থেকে বড়) ক্রমে সাজানো হয়েছে।


### 12.10 Filtering Data based on condition

DataFrame থেকে নির্দিষ্ট শর্ত অনুযায়ী সারি (rows) বেছে নেওয়া হয় **filtering** বা **conditional selection** দ্বারা।
এর জন্য সাধারণত `loc[]` ফাংশনের ভিতরে শর্ত (condition) ব্যবহার করা হয়।

---

### Example 1: DataFrame প্রদর্শন

```python
df
```
*(এই কোডটি মূল DataFrame প্রদর্শন করে।)*

---
![[Pasted image 20251102072224.png]]
### Example 2: নির্দিষ্ট শর্তে ডেটা ফিল্টার করা

```python
not_started = df.loc[df['CompletionStatus'] == 'Not Started']
```
এখানে 'CompletionStatus' কলামে যেসব সারিতে মান "Not Started" আছে, শুধুমাত্র সেগুলোই `not_started` DataFrame-এ সংরক্ষিত হয়েছে।

---

### Example 3: অন্য শর্তে ফিল্টার করা

```python
completed = df.loc[df['CompletionStatus'] == 'Completed']
```
এখানে 'CompletionStatus' কলামের মান "Completed" থাকা সব সারি দেখানো হয়েছে।

---

### Example 4: একাধিক শর্ত একসাথে ব্যবহার করা

```python
completed_ds90 = df.loc[
    (df['CompletionStatus'] == 'Completed') & 
    (df['Data Structure Marks'] >= 90)
]
```
এই উদাহরণে দুটি শর্ত একসাথে প্রযোজ্য হয়েছে —
1. 'CompletionStatus' হলো "Completed"
2. 'Data Structure Marks' ≥ 90

দুটি শর্তই True হলে কেবল সেই সারিগুলোই ফিল্টার হয়ে `completed_ds90` তে থাকবে।
