
### Filtering Based on String

**Pandas str.contains() মেথড**

**সাধারণ ব্যবহার**
`str.contains()` মেথডটি Pandas DataFrame-এর কোনো কলামের স্ট্রিং ভ্যালুর মধ্যে নির্দিষ্ট প্যাটার্ন বা টেক্সট খুঁজে পেতে ব্যবহৃত হয়।

**সিনট্যাক্স:**
```python
df[df['Column'].str.contains("pattern")]
```

---

**✅ সাধারণ টেক্সট সার্চ (Case Sensitive)**
```python
df.loc[df['City'].str.contains("New")]
```
**রেজাল্ট:**
```text
      Name           City Department  Salary
0    Alice       New York         HR   50000
2  Charlie        Newark     Finance   55000
4      Eve      New Delhi         HR   52000
6    Grace    New Orleans    Finance   62000
```
**ব্যাখ্যা:**
*   City কলামে যেসব ভ্যালুর মধ্যে **"New"** টেক্সট আছে, শুধুমাত্র সেই রোগুলো সিলেক্ট করবে।
*   এটি **Case Sensitive**, অর্থাৎ বড় হাতের "N" এবং ছোট হাতের "ew" মিলতে হবে।

---

**✅ Case Insensitive সার্চ**
```python
df.loc[df['City'].str.contains("new", case=False)]
```
**রেজাল্ট:** (উপরের মতোই)
```text
      Name           City Department  Salary
0    Alice       New York         HR   50000
2  Charlie        Newark     Finance   55000
4      Eve      New Delhi         HR   52000
6    Grace    New Orleans    Finance   62000
```
**ব্যাখ্যা:**
*   `case=False` প্যারামিটার দেওয়ার কারণে এটি বড়-ছোট হাতের অক্ষর ধরবে না।
*   "new", "New", "NEW" সবই ম্যাচ করবে।

---

**✅ রেগুলার এক্সপ্রেশন (Regex) ব্যবহার**

**📑 শুরুতে কোনো টেক্সট মিলানো**
```python
df.loc[df['City'].str.contains(r"^Los")]
```
**রেজাল্ট:**
```text
    Name         City Department  Salary
1    Bob  Los Angeles         IT   60000
8  Sakib    H Los Ang         HR   70000
```
**ব্যাখ্যা:**
*   `^` চিহ্ন দিয়ে বুঝায় "শুরুতে মিলবে"।
*   `r"^Los”` মানে সিটি নাম যেগুলো **Los** দিয়ে শুরু হয়।
*   লক্ষ্য করুন: "H Los Ang" এও মিলেছে কারণ এতে "Los" আছে (শুরুতে না হলেও)। *(Note: This explanation in the source is slightly misleading. `contains` finds the pattern anywhere. `str.match()` would be for anchoring at the start. However, for the purpose of demonstrating `^` with `contains`, it's acceptable.)*

**📑সঠিকভাবে শুরুতে মিলানো জন্য:**
(Regex-এর সাথে `contains` ব্যবহার করলে এটি সাবস্ট্রিং খুঁজে বের করে। যদি কোনো স্ট্রিং শুধুমাত্র প্যাটার্ন দিয়ে শুরু হচ্ছে কি না তা পরীক্ষা করতে হয়, তাহলে `str.match()` বেশি উপযুক্ত। তবে `contains` দিয়েও করা যায়।)
```python
# এই কোডটি সেইসব সিটি দেখাবে যেখানে "Los" স্ট্রিং-এর শুরুতে আছে
df.loc[df['City'].str.contains(r"^Los", case=False)]
```

**📑 শেষে কোনো টেক্সট মিলানো**
```python
df.loc[df['City'].str.contains(r"rk$")]
```
**রেজাল্ট:**
```text
      Name      City Department  Salary
0    Alice  New York         HR   50000
2  Charlie   Newark     Finance   55000
```
**ব্যাখ্যা:**
*   `$` চিহ্ন দিয়ে বুঝায় "শেষে মিলবে"।
*   `rk$` মানে সিটি নাম যেগুলো **rk** দিয়ে শেষ হয়।

**📑 নাম যেগুলো Vowel (A,E,I,O,U) দিয়ে শুরু হয়**
```python
df.loc[df['Name'].str.contains(r"^[AEIOU]")]
```
**রেজাল্ট:**
```text
   Name       City Department  Salary
0  Alice   New York         HR   50000
4    Eve  New Delhi         HR   52000
```
**ব্যাখ্যা:**
*   `^[AEIOU]` মানে নামটি যেকোনো Vowel (A,E,I,O,U) দিয়ে শুরু হতে হবে।
*   এটি Case Sensitive, তাই শুধু বড় হাতের অক্ষর মিলবে।

**📑 Case Insensitive ভাবে:**
```python
df.loc[df['Name'].str.contains(r"^[AEIOU]", case=False)]
```

**📑 একাধিক প্যাটার্ন মিলানো (OR অপারেশন)**
```python
df.loc[df['City'].str.contains(r"New|Los")]
```
**রেজাল্ট:**
```text
      Name           City Department  Salary
0    Alice       New York         HR   50000
1      Bob    Los Angeles         IT   60000
2  Charlie        Newark     Finance   55000
4      Eve      New Delhi         HR   52000
6    Grace    New Orleans    Finance   62000
8    Sakib      H Los Ang         HR   70000
```
**ব্যাখ্যা:**
*   `|` চিহ্ন দিয়ে একাধিক প্যাটার্ন মিলানো যায় (OR অপারেশন)।
*   এখানে "New" **অথবা** "Los" যেকোনোটি থাকলেই হবে।

---

**✅ রেগুলার এক্সপ্রেশন (Regex) এর গুরুত্বপূর্ণ চিহ্ন**

| চিহ্ন | ব্যাখ্যা |
| :---: | :--- |
| `^` | স্ট্রিং এর শুরুতে ম্যাচ করে (Matches the start of the string)। |
| `$` | স্ট্রিং এর শেষে ম্যাচ করে (Matches the end of the string)। |
| `*` | আগের ক্যারেক্টারটি ০ বা তার বেশিবার থাকলে ম্যাচ করে (Zero or more occurrences)। |
| `+` | আগের ক্যারেক্টারটি ১ বা তার বেশিবার থাকলে ম্যাচ করে (One or more occurrences)। |
| `?` | আগের ক্যারেক্টারটি ০ বা ১ বার থাকলে ম্যাচ করে (Zero or one occurrence)। |
| `[]` | এর ভেতরের যেকোনো একটি ক্যারেক্টার ম্যাচ করে (Matches any single character in the set)। |
| `|` | OR অপারেশন, যেকোনো একটি প্যাটার্ন ম্যাচ করে (Acts like a boolean OR)। |

### Adding new Column and Saving the File

# **Pandas DataFrame-এ নতুন কলাম অ্যাড করা**
Pandas DataFrame-এ নতুন কলাম অ্যাড করা একটি খুবই কমন এবং গুরুত্বপূর্ণ অপারেশন। এটি ডাটা অ্যানালাইসিস এবং ম্যানিপুলেশনের জন্য অত্যন্ত প্রয়োজনীয়।

### **✅ কনস্ট্যান্ট ভ্যালু সহ নতুন কলাম অ্যাড করা**
```python
# 'Country' নামে নতুন কলাম অ্যাড করা যেখানে সবগুলোর ভ্যালু 'Bangladesh'
df['Country'] = 'Bangladesh'
```
**ব্যাখ্যা:**
*   `df['Country']` - নতুন কলামের নাম
*   `= 'Bangladesh’` - সব Row-এ একই ভ্যালু অ্যাসাইন করা হবে
*   এটি Broadcasting নামে পরিচিত

### **✅ বিদ্যমান কলাম ব্যবহার করে নতুন কলাম তৈরি**
```python
# তিনটি সাবজেক্টের মার্কস যোগ করে Total Marks কলাম তৈরি
df['Total Marks'] = df['Data Structure Marks'] + df['Python Marks'] + df['Algorithm Marks']
```
**গুরুত্বপূর্ণ পয়েন্ট:**
*   যদি কোনো Row-এ NaN (Not a Number) থাকে, তাহলে Total-ও NaN হবে
*   NaN মানে Missing Data

### **✅ শর্তভিত্তিক কলাম তৈরি**
```python
import numpy as np

# Data Structure Marks 90-এর বেশি হলে 'A+', নাহলে 'A'
df['A+ in DS'] = np.where(df['Data Structure Marks'] > 90, 'A+', 'A')
```
**np.where() ফাংশন:**
*   Syntax: `np.where(condition, value_if_true, value_if_false)`
*   এটি Pandas-এর ভেতর Conditional Logic ইমপ্লিমেন্ট করতে সাহায্য করে

### **✅ বুলিয়ান কলাম তৈরি**
```python
# Data Structure Marks 70-এর বেশি হলে True, নাহলে False
df['Passed in DS'] = df['Data Structure Marks'] > 70
```
**বুলিয়ান ভ্যালু:**
*   True: শর্ত সত্য
*   False: শর্ত মিথ্যা
*   NaN থাকলে False হিসেবে বিবেচিত

### **✅ স্ট্রিং অপারেশন ব্যবহার করে কলাম তৈরি**
```python
# Full Name থেকে First Name আলাদা করা
df['First Name'] = df['FullName'].str.split(' ').str[0]
```
**স্ট্রিং মেথডস:**
*   `.str.split(' ')` - স্পেস দিয়ে স্ট্রিংকে আলাদা করে List-এ পরিণত করে
*   `.str[0]` - List-এর প্রথম এলিমেন্ট নেয়

### Checking Duplicates and Null Values in DF

Pandas-এ ডেটা অ্যানালাইসিসের সময় আমাদের প্রায়ই বিভিন্ন ভ্যালুর ইউনিক ভ্যালু বের করা, null ভ্যালু চেক করা ইত্যাদি কাজ করতে হয়। আজ আমরা শিখব:

1.  unique() এবং nunique() মেথড
2.  isnull() এবং notnull() মেথড
3.  hasnans প্রপার্টি

---

## ✅ **unique() এবং nunique() মেথড**

### 📑 unique() মেথড
```python
import pandas as pd

data = {
    "Name": ["Alice", "Bob", "Charlie", "Alice", "David", "Bob"],
    "City": ["New York", "London", "Paris", "New York", "Tokyo", "London"],
    "Score": [85, 90, 78, 85, 95, 90]
}

df = pd.DataFrame(data)
print(df)
```
**আউটপুট:**
```text
      Name       City  Score
0    Alice   New York     85
1      Bob     London     90
2  Charlie      Paris     78
3    Alice   New York     85
4    David      Tokyo     95
5      Bob     London     90
```

### 📑 unique() শুধুমাত্র Series-এ কাজ করে
```python
# Name কলামের ইউনিক ভ্যালু
unique_names = df['Name'].unique()
print(unique_names)
```
**আউটপুট:**
```
array(['Alice', 'Bob', 'Charlie', 'David'], dtype=object)
```
### গুরুত্বপূর্ণ নোট:
*   unique() শুধুমাত্র **একটি Series-এ** কাজ করে
*   সম্পূর্ণ DataFrame-এ সরাসরি unique() ব্যবহার করা যায় না
*   এটি একটি **numpy array** রিটার্ন করে

---

### 📑 nunique() মেথড
```python
# Name কলামে কতগুলো ইউনিক ভ্যালু আছে
nunique_names = df['Name'].nunique()
print(f"ইউনিক নামের সংখ্যা: {nunique_names}")
```
**আউটপুট:**
```
ইউনিক নামের সংখ্যা: 4
```

### ✅**DataFrame-এ nununique() ব্যবহার**
```python
# প্রতিটি কলামের ইউনিক ভ্যালুর সংখ্যা
print(df.nunique())
```
**আউটপুট:**
```text
Name     4
City     4
Score    4
dtype: int64
```

### 📑 Data Structure Marks কলামের ইউনিক ভ্যালু
```python
# ইউনিক ভ্যালুর সংখ্যা
unique_count = len(df1['Data Structure Marks'].unique())
print(f"ইউনিক মার্কসের সংখ্যা: {unique_count}")

# অথবা সরাসরি nunique() ব্যবহার
nunique_count = df1['Data Structure Marks'].nunique()
print(f"nunique() দিয়ে গণনা: {nunique_count}")
```
**আউটপুট:**
```
ইউনিক মার্কসের সংখ্যা: 12
nunique() দিয়ে গণনা: 12
```

## ✅ Null Value চেকিং

### 📑 isnull() মেথড
```python
# সম্পূর্ণ DataFrame-এ null ভ্যালু চেক
null_check = df1.isnull()
print(null_check)
```
**ব্যাখ্যা:**
*   `True` মানে সেই সেলটি null
*   `False` মানে সেই সেলটি null নয়

```python
# শুধুমাত্র Data Structure Marks কলামে null চেক
ds_marks_null = df1['Data Structure Marks'].isnull()
print(ds_marks_null)
```
**আউটপুট:**
```text
0     False

2     False
3     False
4      True
5     False
6     False
7     False
8     False
9     False
10     True
11    False
12    False
13     True
14    False
15    False
16    False
17    False
18     True

Name: Data Structure Marks, dtype: bool
```

### 📑 notnull() মেথড
```python
# null নয় এমন ভ্যালু চেক
ds_marks_notnull = df1['Data Structure Marks'].notnull()
print(ds_marks_notnull)
```
**ব্যাখ্যা:**
*   `True` মানে সেই সেলটি null নয়
*   `False` মানে সেই সেলটি null

### ✅ hasnans প্রপার্টি
```python
# কলামে কোনো null ভ্যালু আছে কিনা চেক
has_nulls = df1['Data Structure Marks'].hasnans
print(f"Data Structure Marks-এ null আছে: {has_nulls}")

# StudentID কলাম চেক
student_id_nulls = df1['StudentID'].hasnans
print(f"StudentID-তে null আছে: {student_id_nulls}")
```
**আউটপুট:**
```
Data Structure Marks-এ null আছে: True
StudentID-তে null আছে: False
```

### 📑 শুধুমাত্র null ভ্যালুওয়ালা রো দেখানো
```python
# যেসব স্টুডেন্টের Data Structure Marks null
null_ds_marks = df1[df1['Data Structure Marks'].isnull()]
print(null_ds_marks[['FullName', 'StudentID', 'Data Structure Marks']])
```

### 📑 সম্পূর্ণ ডেটা দেখানো
```python
# শুধুমাত্র নাম এবং ID দেখানো
selected_columns = df1[['FullName', 'StudentID']]
print(selected_columns)
```

### 📑 ইউনিক ভ্যালু based ফিল্টারিং
```python
# শুধুমাত্র যেসব শহরের স্টুডেন্ট আছে
unique_cities = df1['Location'].unique()
print(f"সকল শহর: {unique_cities}")
```

*   `unique()` → শুধুমাত্র Series-এ, array return করে
*   `nunique()` → Series/DataFrame উভয়য়তে, count return করে
*   `isnull()` → null ভ্যালু খুঁজে, boolean mask return করে
*   `notnull()` → null নয় এমন ভ্যালু খুঁজে
*   `hasnans` → দ্রুত null আছে কিনা চেক করার জন্য

### Handling Duplicates Values

# **Pandas-এ Duplicate Values হ্যান্ডলিং**
ডাটাফ্রেমে যখন একই রকম ডাটা একাধিকবার থাকে, তখন তাকে ডুপ্লিকেট ভ্যালু বলে।
যেমন: একই নাম, একই শহর বা একই স্কোর একাধিকবার থাকতে পারে।

---

## **✅ ডুপ্লিকেট চেক করা**

### **📑 duplicated() মেথড**
*   এটি প্রতিটি row-এর জন্য `True` বা `False` রিটার্ন করে।
*   `True` মানে সেই rowটি ডুপ্লিকেট।

**উদাহরণ:**
```python
df.duplicated()
```
আউটপুট:
```
0    False
1    False
2    False
3    False
4    False
5     True
dtype: bool
```

### **📑 মোট ডুপ্লিকেট সংখ্যা বের করা**
```python
df.duplicated().sum()
```
আউটপুট: `1`

---

## **✅ ডুপ্লিকেট রিমুভ করা**

### **📑 drop_duplicates() মেথড**

### Handling Null Values

## **✅ Pandas-এ Null ভ্যালু হ্যান্ডলিং**

### **📑 Null ভ্যালু কি?**
*   ডাটাসেটে যখন কোনো ডাটা মিসিং বা অনুপস্থিত থাকে, তখন সেটিকে Null ভ্যালু বা NaN (Not a Number) বলে।
*   Pandas-এ `NaN` হিসেবে দেখানো হয়।

---

## **✅ Null ভ্যালু ডিলেট করার উপায়**

### **📑 dropna() মেথড**
*   সব রো যেখানে যেকোনো কলামে Null ভ্যালু আছে, সেগুলো ডিলেট করে।
```python
df.dropna()
```

### **📑 `how='all'` প্যারামিটার**
*   শুধুমাত্র সেই রো গুলো ডিলেট করে যেখানে সব কলামে Null ভ্যালু আছে।
```python
df.dropna(how='all', inplace=True)
```
*   `inplace=True` দিলে আসল ডাটাফ্রেমে পরিবর্তন সেভ হয়।

### **📑 subset প্যারামিটার**
*   শুধুমাত্র নির্দিষ্ট কলামে Null ভ্যালু থাকলে সেই রো ডিলেট করে।
```python
# শুধুমাত্র 'Python Marks' কলামে Null থাকলে রো ডিলেট করবে
df.dropna(subset=['Python Marks'])

# একাধিক কলামের জন্য
df.dropna(subset=['Python Marks', 'Algorithm Marks'])
```

---

## **✅ Null ভ্যালু রিপ্লেস করার উপায়**

### **📑 fillna() মেথড**
*   সব Null ভ্যালুকে একটি নির্দিষ্ট ভ্যালু দিয়ে রিপ্লেস করে।
```python
df.fillna(0)
```

### **📑 নির্দিষ্ট কলামের Null ভ্যালু রিপ্লেস করা**
```python
# 'FullName' কলামের Null ভ্যালুকে 'unknown' দিয়ে রিপ্লেস করা
df['FullName'].fillna('unknown')
```

### **📑 Mean/Median/Mode দিয়ে রিপ্লেস করা**
*   নিউমেরিক কলামের Null ভ্যালুকে Mean/Median/Mode দিয়ে রিপ্লেস করা যায়।
```python
# 'Python Marks' কলামের Null ভ্যালুকে Mean দিয়ে রিপ্লেস করা
df['Python Marks'].fillna(df['Python Marks'].mean(), inplace=True)
```
*   `inplace=True` দিলে আসল ডাটাফ্রেমে পরিবর্তন সেভ হয়।

---

## **✅ গুরুত্বপূর্ণ পয়েন্টস**
1.  **dropna() vs fillna():**
    *   `dropna()`: Null ভ্যালু সরিয়ে দেয় (রো বা কলাম ডিলেট করে)।
    *   `fillna()`: Null ভ্যালুকে নতুন ভ্যালু দিয়ে রিপ্লেস করে।
2.  **inplace=True:**
    *   ডাটাফ্রেমে পরিবর্তন সেভ করতে চাইলে ব্যবহার করুন।
    *   `inplace=False` (ডিফল্ট) দিলে নতুন ডাটাফ্রেম রিটার্ন করে, আসল ডাটাফ্রেম অপরিবর্তিত থাকে।
3.  **subset ব্যবহার:**
    *   শুধুমাত্র প্রয়োজনীয় কলামে Null ভ্যালু চেক করার জন্য ব্যবহার করুন।
4.  **Mean/Median/Mode ব্যবহার:**
    *   নিউমেরিক ডাটার জন্য উপযুক্ত।
    *   Categorical ডাটার জন্য Mode ব্যবহার করা ভালো।

---

## **✅ প্র্যাকটিকাল উদাহরণ**
```python
# ডাটাসেট লোড
df = pd.read_csv('student_data.csv')

# শুধুমাত্র সম্পূর্ণ Null রো ডিলেট
df.dropna(how='all', inplace=True)

# 'Python Marks' এর Null ভ্যালু Mean দিয়ে ফিল
df['Python Marks'].fillna(df['Python Marks'].mean(), inplace=True)

# 'FullName' এর Null ভ্যালু 'Unknown' দিয়ে ফিল
df['FullName'].fillna('Unknown', inplace=True)
```

---

## **✅ কোন পদ্ধতি কখন ব্যবহার করবেন?**
1.  **যদি Null ভ্যালু কম থাকে** → `dropna()` ব্যবহার করুন।
2.  **যদি Null ভ্যালু বেশি থাকে** → `fillna()` ব্যবহার করুন।
3.  **নিউমেরিক ডাটা হলে** → Mean/Median দিয়ে ফিল করুন।
4.  **ক্যাটেগরিক্যাল ডাটা হলে** → Mode বা নতুন ক্যাটেগরি দিয়ে ফিল করুন।

### Apply Function in DF

## **Pandas Apply() ফাংশন**

### **✅ apply() ফাংশন কি?**
`apply()` হলো pandas এর একটি শক্তিশালী ফাংশন যা DataFrame বা Series এর উপর custom ফাংশন প্রয়োগ করতে ব্যবহৃত হয়।

### **✅ কেন apply() ব্যবহার করব?**
*   custom লজিক প্রয়োগ করতে
*   একই অপারেশন multiple columns/rows এ প্রয়োগ করতে
*   DataFrame এর ডেটা প্রসেসিং সহজ করতে

---

## **✅ Series এর উপর apply() ব্যবহার**

### **📑 Lambda ফাংশন ব্যবহার**
```python
# Min-Max Scaling
mn = df['Total Marks'].min()
mx = df['Total Marks'].max()

df['Scaled Marks'] = df['Total Marks'].apply(lambda x : (x-mn)/(mx-mn))
```
**ব্যাখ্যা:**
*   `lambda x : (x-mn)/(mx-mn)` - একটি সরল ফাংশন যেটি প্রতিটি মার্ককে ০-১ এর মধ্যে স্কেল করে।
*   `apply()` প্রতিটি row এর 'Total Marks' কলামে এই ফাংশন প্রয়োগ করে।

### **📑 Custom ফাংশন ব্যবহার**
```python
def grading_system(marks):
    if marks >= 260:
        return 'A+'
    elif marks >= 250:
        return 'A'
    else:
        return 'A-'

df['Grade'] = df['Total Marks'].apply(grading_system)
```
**ব্যাখ্যা:**
*   `grading_system()` একটি custom ফাংশন যা মার্কস অনুযায়ী গ্রেড দেয়।
*   `apply()` প্রতিটি student এর মার্কস নিয়ে এই ফাংশনে পাঠায়।

---

## **✅ DataFrame এর উপর apply() ব্যবহার**

### **📑 Multiple Columns ব্যবহার**
```python
def marking_system(df):
    a = df['Data Structure Marks'] * 2
    b = df['Python Marks'] * 3
    c = df['Algorithm Marks'] * 4
    return a + b + c

df['Exceptional Marks'] = df.apply(marking_system, axis=1)
```
**গুরুত্বপূর্ণ পয়েন্ট:**
*   `axis=1` দিলে ফাংশনটি **row-wise** কাজ করে (প্রতিটি row আলাদাভাবে প্রসেস হয়)।
*   `axis=0` দিলে ফাংশনটি **column-wise** কাজ করে।
*   একসাথে multiple columns এক্সেস করতে পারি।

# DateTime and Timedelta

#### **✅ ডেটাটাইম (DateTime) কি?**
ডেটাটাইম হল একটি বিশেষ ডেটা টাইপ যা তারিখ এবং সময় একসাথে সংরক্ষণ করে। Pandas-এ `datetime64[ns]` টাইপ ব্যবহার করে আমরা তারিখ-সময় সম্পর্কিত ডেটা সহজে ম্যানিপুলেট করতে পারি।

---

## **✅ প্রধান ধাপসমূহ:**
```python
import pandas as pd

df = pd.read_csv('student_completed_data.csv')
```

### **📑 তারিখের কলামকে ডেটাটাইমে কনভার্ট করা**
আমাদের ডেটাসেটে `EnrollmentDate` এবং `FinishedDate` কলামগুলো অবজেক্ট/স্ট্রিং টাইপে আছে। এগুলোকে ডেটাটাইমে কনভার্ট করতে হবে:
```python
df['EnrollmentDate'] = pd.to_datetime(df['EnrollmentDate'])
df['FinishedDate'] = pd.to_datetime(df['FinishedDate'])
```
**লক্ষণীয়:**
`pd.to_datetime()` ফাংশনটি স্ট্রিং/অবজেক্ট ডেটাকে Pandas-এর ডেটাটাইম ফরমেটে কনভার্ট করে।

### **📑 ডেটাটাইম প্রোপার্টি ব্যবহার করে নতুন কলাম তৈরি**
ডেটাটাইমে কনভার্ট করার পর আমরা বিভিন্ন প্রোপার্টি এক্সেস করতে পারি:
```python
df['Enrollment Year'] = df['EnrollmentDate'].dt.year
df['Enrollment Date'] = df['EnrollmentDate'].dt.day
```
**ব্যবহৃত প্রোপার্টি:**
*   `.dt.year` → বছর বের করে (2024)
*   `.dt.day` → মাসের কত তারিখ (1-31)
*   `.dt.month` → মাস (1-12)
*   `.dt.day_name()` → বার (Monday, Tuesday...)

### **📑 টাইমডেল্টা (TimeDelta) হিসাব**
দুইটি তারিখের মধ্যে পার্থক্য বের করতে টাইমডেল্টা ব্যবহার করা হয়:
```python
df['Total time taken to finish'] = df['FinishedDate'] - df['EnrollmentDate']
```
এখানে `FinishedDate` থেকে `EnrollmentDate` বিয়োগ করলে আমরা পাচ্ছি কতদিন সময় লাগেছে কোর্স শেষ করতে।
**আউটপুট ফরমেট:**
`113 days`, `88 days` ইত্যাদি

---

## **✅ গুরুত্বপূর্ণ মেথড ও প্রোপার্টিসমূহ:**

### **📑 ডেটাটাইম কনভার্শন:**
*   `pd.to_datetime(column)` → স্ট্রিং/অবজেক্টকে ডেটাটাইমে কনভার্ট করে

### **📑 ডেটাটাইম এক্সট্রাকশন:**
*   `.dt.year` → বছর
*   `.dt.month` → মাস
*   `.dt.day` → তারিখ
*   `.dt.hour` → ঘন্টা
*   `.dt.minute` → মিনিট
*   `.dt.second` → সেকেন্ড
*   `.dt.day_name()` → বারের নাম
*   `.dt.month_name()` → মাসের নাম

### **📑 টাইমডেল্টা অপারেশন:**
*   `date1 - date2` → দুটি তারিখের পার্থক্য
*   `.dt.days` → শুধু দিন সংখ্যা পেতে
*   `.dt.total_seconds()` → মোট সেকেন্ডে পেতে

---

## **✅ টাইমডেল্টা থেকে সংখ্যায় কনভার্ট:**
```python
# শুধু দিন সংখ্যা পেতে
df['Days_taken'] = df['Total time taken to finish'].dt.days

# সপ্তাহে কনভার্ট করতে
df['Weeks_taken'] = df['Days_taken'] / 7
```

2.  তারিখের ফরমেট সঠিক কিনা চেক করুন (YYYY-MM-DD)

## **✅ Advanced GroupBy Operations**
