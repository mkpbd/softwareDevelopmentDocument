### 🎭 বিষয়: MCP Server কি? (দি "ঘটক" থিওরি)

চিন্তা করুন **AI (যেমন Claude বা ChatGPT)** হলো একজন **মহা পন্ডিত ব্যক্তি** (ধরি তার নাম "প্রফেসর বল্টু")। সে পৃথিবীর সব ইতিহাস, বিজ্ঞান, অংক জানে। কিন্তু সমস্যা হলো, প্রফেসর বল্টুকে একটা **বন্ধ ঘরে** আটকে রাখা হয়েছে। তার কাছে ইন্টারনেট বা বাইরের জগতের কোনো রিয়েল-টাইম খবর নেই।

এখন, আপনার কাছে একটা **PostgreSQL Database** আছে (যেখানে আপনার কোম্পানির সিক্রেট ডাটা আছে)। প্রফেসর বল্টু ওই ডাটা দেখতে পায় না।

**MCP Server** হলো সেই **"চালাক পিয়ন" (Messenger)** বা **"ঘটক"**, যার কাছে ওই ডাটাবেজের চাবি আছে।

1.  **AI (প্রফেসর বল্টু):** "ভাই, আজকে কত টাকার সেল হলো একটু বলো তো?"
2.  **MCP Server (পিয়ন):** "দাঁড়ান স্যার, আমি গোডাউন (PostgreSQL) থেকে দেখে আসছি।" (সে দৌড়ে গিয়ে SQL কুয়েরি চালিয়ে রেজাল্ট নিয়ে আসে)।
3.  **Result:** পিয়ন এসে কানে কানে বলে, "স্যার, ১০,০০০ টাকা।"

### 💻 Technical Analogy: SQL Server, Postgres & Angular এর ভাষায়

প্রথাগত ডেভেলপমেন্টে আমরা যেভাবে চিন্তা করি, MCP একটু আলাদা। চলুন কোডের মতো করে দেখি:

#### ১. Traditional Web App (Angular + .NET API + SQL)
এখানে মানুষ (User) বোতাম চাপে, API কল হয়।
```typescript
// Angular Component (User)
buttonClick() {
  http.get('/api/users').subscribe(data => show(data));
}
// সোজা বাংলা: ইউজার বাটন চাপল -> ডাটা দেখল।
```

#### ২. MCP Server World (AI + MCP + SQL)
এখানে **AI** নিজেই সিদ্ধান্ত নেয় তার কী দরকার। সে আপনার কোড বা ডাটাবেজের সাথে চ্যাট করতে চায়।

**MCP Server** হলো একটা **Universal Adapter** বা **USB-C Type Cable**।
*   **AI (Client):** ল্যাপটপ।
*   **Postgres/Local File:** হার্ড ড্রাইভ।
*   **MCP Server:** ওই কানেক্টিং ক্যাবল।

### 🧑‍💻 Funny Code Example (Bangla Style)

চলুন দেখি MCP সার্ভার আসলে ভেতরে ভেতরে কী করে। নিচে একটা কাল্পনিক কোড দেওয়া হলো:

```javascript
// MCP Server: "The Middleman" (ঘটক)

class McpServer {
  
  // ১. নিজের পরিচয় দেওয়া (Capability)
  sayHello() {
    return "হ্যালো AI ভাই! আমি 'Database MCP'। আমি SQL চালাতে পারি, ফোল্ডার চেক করতে পারি। তোমার কী লাগবে বলো?";
  }

  // ২. টুলস বা কাজের তালিকা (Tools)
  listTools() {
    return [
      {
        name: "get_customer_data",
        description: "Postgres থেকে কাস্টমারের নাম আর ফোন নম্বর এনে দেয়।",
        input_schema: { clientId: "string" }
      },
      {
        name: "check_server_health",
        description: "সার্ভার কি মরে গেছে নাকি বেঁচে আছে চেক করে।"
      }
    ];
  }

  // ৩. আসল কাজ করা (Execution)
  async callTool(toolName, args) {
    if (toolName === "get_customer_data") {
      
      // AI কিন্তু SQL জানে না, সে শুধু বলেছে "ডাটা দাও"
      // MCP সার্ভার আসল কুয়েরি চালাচ্ছে (যেমন SQL Server বা Postgres এ)
      
      const result = await postgresDB.query(`SELECT * FROM users WHERE id = ${args.clientId}`);
      
      return `বস, ডাটা পেয়েছি! এই নিন: ${JSON.stringify(result)}`;
    }
  }
}
```

### 💻 কোডিং (আসল জাদু)

এখন আমরা `index.ts` ফোল্ডারে আমাদের **MCP Server** কোড লিখব। এটা `child_process` ব্যবহার করে আপনার পিসিতে `ng` কমান্ড চালাবে।

**ফাইল:** `src/index.ts`

```typescript
#!/usr/bin/env node
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { CallToolRequestSchema, ListToolsRequestSchema } from "@modelcontextprotocol/sdk/types.js";
import { z } from "zod";
import { exec } from "child_process"; // এটা দিয়ে আমরা টার্মিনাল কমান্ড চালাব

// ১. সার্ভার তৈরি (আমাদের ভুতুড়ে এসিস্ট্যান্ট)
const server = new Server(
  {
    name: "angular-helper",
    version: "1.0.0",
  },
  {
    capabilities: {
      tools: {},
    },
  }
);

// ২. টুলস এর লিস্ট (মেনু কার্ড)
server.setRequestHandler(ListToolsRequestSchema, async () => {
  return {
    tools: [
      {
        name: "create_angular_component",
        description: "Angular প্রোজেক্টে নতুন কম্পোনেন্ট তৈরি করে (ng generate component)।",
        inputSchema: {
          type: "object",
          properties: {
            componentName: {
              type: "string",
              description: "কম্পোনেন্টের নাম (যেমন: header, footer, user-list)",
            },
            path: {
              type: "string",
              description: "যে ফোল্ডারে প্রোজেক্ট আছে তার পাথ (অপশনাল, ডিফল্ট হলো বর্তমান ফোল্ডার)",
            }
          },
          required: ["componentName"],
        },
      },
    ],
  };
});

// ৩. টুল চালানো (আসল কাজ)
server.setRequestHandler(CallToolRequestSchema, async (request) => {
  if (request.params.name === "create_angular_component") {
    
    // ডাটা বের করে নিচ্ছি
    const args = request.params.arguments as { componentName: string; path?: string };
    const compName = args.componentName;
    const projectPath = args.path || process.cwd(); // পাথ না দিলে যেখানে আছি সেখানেই

    return new Promise((resolve) => {
      // 🚀 এখানে জাদু হচ্ছে! আমরা পিসির টার্মিনালে কমান্ড চালাচ্ছি
      const command = `ng generate component ${compName}`;
      
      console.error(`Executing: ${command} in ${projectPath}`); // লগের জন্য

      exec(command, { cwd: projectPath }, (error, stdout, stderr) => {
        if (error) {
          resolve({
            content: [{ type: "text", text: `❌ ওরে বাবা! এরর খেয়েছি: ${error.message}` }],
            isError: true,
          });
          return;
        }

        resolve({
          content: [
            {
              type: "text",
              text: `✅ বস কাজ হয়ে গেছে!\n\nটার্মিনাল আউটপুট:\n${stdout}`,
            },
          ],
        });
      });
    });
  }

  throw new Error("এই টুল আমি চিনি না ভাই!");
});

// ৪. কানেকশন শুরু
const transport = new StdioServerTransport();
await server.connect(transport);
```

### 🎭 এনালজি: "রেস্টুরেন্ট কিচেন" (Restaurant Kitchen)

Angular অ্যাপ হলো একটা রেস্টুরেন্ট।
1.  **Model (রেসিপি কার্ড):** এটা বলে দেয় খাবারটা দেখতে কেমন হবে। (যেমন: `User` এর `id` থাকবে, `name` থাকবে)।
2.  **Service (ওয়েটার/সাপ্লায়ার):** যে কিচেন (Frontend) আর বাজারের (Backend/API) মধ্যে দৌড়াদৌড়ি করে ডাটা (সবজি/মাছ) নিয়ে আসে।
3.  **HTTP (ট্রাক/বাহন):** যার মাধ্যমে ডাটা আনা-নেওয়া হয়।

আমরা এখন **MCP Server**-কে বানাবো **"ম্যানেজার"**, যাকে শুধু বলবেন— *"ম্যানেজার, ফিশ কারির রেসিপি আর সাপ্লাই চেইন রেডি করো"*—সে সব লিখে ফাইল রেডি করে দেবে।

### 🛠️ কোডিং প্ল্যান (The Code Logic)

আমরা দুটি টুল বানাবো:
1.  **`create_model`**: যেটা ইন্টারফেস (`interface`) বানাবে।
2.  **`create_http_service`**: যেটা `HttpClient` দিয়ে একদম ফুল `CRUD` মেথডসহ সার্ভিস বানিয়ে দেবে।

**Dependencies (আগের মতোই):**
ফোল্ডারে `fs` (File System) ব্যবহার করব ফাইল রাইট করার জন্য।

**ফাইল:** `src/angular-service-mcp.ts`

```typescript
#!/usr/bin/env node
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { CallToolRequestSchema, ListToolsRequestSchema } from "@modelcontextprotocol/sdk/types.js";
import { z } from "zod";
import * as fs from 'fs';
import * as path from 'path';

// সার্ভার কনফিগারেশন
const server = new Server(
  {
    name: "angular-architecture-bot",
    version: "1.0.0",
  },
  { capabilities: { tools: {} } }
);

// হেল্পার ফাংশন: ফোল্ডার না থাকলে বানিয়ে নেওয়া
const ensureDirectory = (dirPath: string) => {
  if (!fs.existsSync(dirPath)) {
    fs.mkdirSync(dirPath, { recursive: true });
  }
};

// 📜 টুলসের তালিকা (Menu Card)
server.setRequestHandler(ListToolsRequestSchema, async () => {
  return {
    tools: [
      {
        name: "create_model",
        description: "Angular Interface বা Model তৈরি করে।",
        inputSchema: {
          type: "object",
          properties: {
            modelName: { type: "string", description: "মডেলের নাম (যেমন: Product)" },
            properties: { type: "string", description: "প্রপার্টিগুলো (যেমন: id: number; name: string;)" }
          },
          required: ["modelName", "properties"]
        }
      },
      {
        name: "create_http_service",
        description: "HttpClient সহ রেডিমেড সার্ভিস তৈরি করে (CRUD মেথড সহ)।",
        inputSchema: {
          type: "object",
          properties: {
            serviceName: { type: "string", description: "সার্ভিসের নাম (যেমন: ProductService)" },
            modelName: { type: "string", description: "কোন মডেলের জন্য সার্ভিস হবে? (যেমন: Product)" },
            apiUrl: { type: "string", description: "API এন্ডপয়েন্ট (যেমন: /api/products)" }
          },
          required: ["serviceName", "modelName"]
        }
      }
    ]
  };
});

// 🚀 টুল চালানো (Execution)
server.setRequestHandler(CallToolRequestSchema, async (request) => {
  const currentDir = process.cwd();

  // ১. মডেল তৈরি করা (Creating the Recipe)
  if (request.params.name === "create_model") {
    const args = request.params.arguments as any;
    const fileName = `${args.modelName.toLowerCase()}.model.ts`;
    const folderPath = path.join(currentDir, 'src/app/models');
    
    ensureDirectory(folderPath);

    const fileContent = `
export interface ${args.modelName} {
  ${args.properties}
}
`;
    fs.writeFileSync(path.join(folderPath, fileName), fileContent);

    return {
      content: [{ type: "text", text: `✅ মডেল তৈরি হয়ে গেছে বস! \n📍 পাথ: src/app/models/${fileName}` }]
    };
  }

  // ২. সার্ভিস তৈরি করা (Creating the Waiter with HTTP)
  if (request.params.name === "create_http_service") {
    const args = request.params.arguments as any;
    const modelName = args.modelName;
    const serviceName = args.serviceName; // e.g., ProductService
    const apiUrl = args.apiUrl || 'api/items';
    
    const fileName = `${serviceName.toLowerCase().replace('service', '')}.service.ts`;
    const folderPath = path.join(currentDir, 'src/app/services');
    ensureDirectory(folderPath);

    // অটোমেটিক কোড জেনারেশন (Code Injection)
    const fileContent = `
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';
import { ${modelName} } from '../models/${modelName.toLowerCase()}.model';

@Injectable({
  providedIn: 'root'
})
export class ${serviceName} {

  private apiUrl = '${apiUrl}';

  constructor(private http: HttpClient) { }

  // সব ডাটা আনা (GET)
  getAll(): Observable<${modelName}[]> {
    return this.http.get<${modelName}[]>(this.apiUrl);
  }

  // একটা ডাটা আনা (GET by ID)
  getById(id: number): Observable<${modelName}> {
    return this.http.get<${modelName}>(\`\${this.apiUrl}/\${id}\`);
  }

  // নতুন ডাটা তৈরি (POST)
  create(item: ${modelName}): Observable<${modelName}> {
    return this.http.post<${modelName}>(this.apiUrl, item);
  }

  // আপডেট করা (PUT)
  update(id: number, item: ${modelName}): Observable<${modelName}> {
    return this.http.put<${modelName}>(\`\${this.apiUrl}/\${id}\`, item);
  }

  // ডিলিট করা (DELETE)
  delete(id: number): Observable<void> {
    return this.http.delete<void>(\`\${this.apiUrl}/\${id}\`);
  }
}
`;
    fs.writeFileSync(path.join(folderPath, fileName), fileContent);

    return {
      content: [{ type: "text", text: `🔥 সার্ভিস রেডি! HTTP কোড সহ। \n📍 পাথ: src/app/services/${fileName}` }]
    };
  }

  throw new Error("অচেনা টুল!");
});

const transport = new StdioServerTransport();
await server.connect(transport);
```

### 🎬 সিনারিও: এটা কীভাবে ব্যবহার করবেন?

ধরুন আপনি একটা ই-কমার্স সাইট বানাচ্ছেন। আপনি Claude-কে শুধু এই প্রম্পট দেবেন:

**User (আপনি):**
> "ভাই, আমার একটা `Product` মডেল দরকার যেখানে `id`, `name`, `price` থাকবে। আর এটার জন্য একটা `ProductService` বানিয়ে দাও যেটা `/api/products` এ হিট করবে।"

**Claude + MCP (অ্যাকশন):**
Claude বুঝবে তার দুইটা কাজ করতে হবে।

1.  প্রথমে সে **`create_model`** কল করবে।
    *   *Result:* `src/app/models/product.model.ts` ফাইল তৈরি হবে।
2.  তারপর সে **`create_http_service`** কল করবে।
    *   *Result:* `src/app/services/product.service.ts` ফাইল তৈরি হবে।

এবং জাদুর বিষয় হলো, সার্ভিস ফাইলে সে অটোমেটিক `HttpClient` ইম্পোর্ট করে, `getAll`, `post`, `delete` মেথডগুলো লিখে দেবে।
