## Matplotlib Markers Module in Python

The Matplotlib.markers module provides functions to handle markers in [Matplotlib](https://www.geeksforgeeks.org/python/matplotlib-tutorial/). Each marker has a specific character or symbol associated with it that represents how the data point will appear on the graph. This flexibility allows users to customize their plots according to their preferences or requirements

Below is the table defining most commonly used markers in Matplotlib:

| Marker | Symbol | Description   |
| ------ | ------ | ------------- |
| "."    | •      | point         |
| "o"    | ⬤      | circle        |
| "v"    | ▼      | triangle_down |
| "^"    | ▲      | triangle_up   |
| "s"    | ■      | square        |
| "p"    | ⬟      | pentagon      |
| "*"    | ★      | star          |
| "8"    | ⬢      | octagon       |

## Using fmt Parameter in Matplotlib

The syntax for using the fmt parameter in Matplotlib is actually a combination of marker, line style, and color, where the format string follows this structure:

> ****Syntax:**** fmt = 'marker|line|color'
> 
> - ****Marker****: Specifies the style of the points, e.g., `'o'` for circles, `'s'` for squares, etc.
> - ****Line****: Specifies the style of the line, e.g., `'-'` for a solid line, `':'` for a dotted line, etc.
> - ****Color****: Specifies the color of the plot elements, e.g., `'r'` for red, `'b'` for blue, etc.

```python
import matplotlib.pyplot as plt

x = [4,1,7,5,8]
plt.plot(x,'o-r')  # Red circles with a solid line

plt.title('Plot with fmt')
plt.xlabel('X-axis')

plt.show()
```

শুরু করার আগে, আমরা প্রয়োজনীয় লাইব্রেরিগুলো ইম্পোর্ট করে নেব:
```python
import matplotlib.pyplot as plt
import numpy as np
```

### **১. Basic (মৌলিক প্লট)**

এই প্লটগুলো ডেটা ভিজ্যুয়ালাইজেশনের জন্য সবচেয়ে বেশি ব্যবহৃত হয়।

#### **ক) `plot()` - লাইন প্লট**
*   **কখন ব্যবহার করা হয়?** সময়ের সাথে ডেটার পরিবর্তন বা দুটি ভ্যারিয়েবলের মধ্যে ধারাবাহিক সম্পর্ক দেখানোর জন্য। যেমন: শেয়ার বাজারের দাম, মাসিক তাপমাত্রা ইত্যাদি।
*   **মূল ধারণা:** এটি ডেটা পয়েন্টগুলোকে সরলরেখা দিয়ে সংযুক্ত করে একটি ধারাবাহিক লাইন তৈরি করে।
*   **কোড উদাহরণ:**
    ```python
    x = np.array([1, 2, 3, 4, 5])
    y = np.array([2, 3, 5, 7, 11]) # প্রাইম নাম্বার

    plt.figure(figsize=(8, 4))
    plt.plot(x, y, marker='o', linestyle='--', color='g', label='প্রাইম নাম্বার')
    plt.title("একটি সাধারণ লাইন প্লট")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.legend()
    plt.grid(True)
    plt.show()
    ```

#### **খ) `scatter()` - স্ক্যাটার প্লট**
*   **কখন ব্যবহার করা হয়?** দুটি সংখ্যাসূচক ভ্যারিয়েবলের মধ্যে সম্পর্ক বা কোরিলেশন খুঁজে বের করার জন্য। যেমন: উচ্চতা ও ওজনের সম্পর্ক।
*   **মূল ধারণা:** প্রতিটি ডেটা জোড়কে (x, y) একটি বিন্দু হিসেবে প্লটে দেখানো হয়।
*   **কোড উদাহরণ:**
    ```python
    x = np.random.rand(50) * 10
    y = x * 2 + np.random.randn(50) * 3

    plt.figure(figsize=(8, 5))
    plt.scatter(x, y, color='red', label='ডেটা পয়েন্ট')
    plt.title("স্ক্যাটার প্লট")
    plt.xlabel("ভ্যারিয়েবল ১")
    plt.ylabel("ভ্যারিয়েবল ২")
    plt.legend()
    plt.show()
    ```

#### **গ) `bar()` - ভার্টিক্যাল বার চার্ট**
*   **কখন ব্যবহার করা হয়?** বিভিন্ন ক্যাটাগরির মধ্যে মান তুলনা করার জন্য। যেমন: বিভিন্ন পণ্যের বিক্রয় সংখ্যা।
*   **মূল ধারণা:** প্রতিটি ক্যাটাগরির জন্য একটি উল্লম্ব দণ্ড (vertical bar) আঁকা হয়, যার উচ্চতা ওই ক্যাটাগরির মান নির্দেশ করে।
*   **কোড উদাহরণ:**
    ```python
    categories = ['পণ্য ক', 'পণ্য খ', 'পণ্য গ', 'পণ্য ঘ']
    values = [25, 40, 30, 50]

    plt.figure(figsize=(8, 5))
    plt.bar(categories, values, color='skyblue')
    plt.title("বিভিন্ন পণ্যের বিক্রয়")
    plt.xlabel("পণ্যের নাম")
    plt.ylabel("বিক্রয় সংখ্যা")
    plt.show()
    ```

#### **ঘ) `barh()` - হরাইজন্টাল বার চার্ট**
*   **কখন ব্যবহার করা হয়?** `bar()`-এর মতোই, তবে যখন ক্যাটাগরির নামগুলো অনেক লম্বা হয়, তখন এটি বেশি সুবিধাজনক।
*   **মূল ধারণা:** বারগুলো উল্লম্বের পরিবর্তে অনুভূমিকভাবে (horizontally) আঁকা হয়।
*   **কোড উদাহরণ:**
    ```python
    categories = ['বাংলাদেশ', 'ভারত', 'পাকিস্তান', 'শ্রীলঙ্কা']
    population = [16.4, 138.0, 22.0, 2.1]

    plt.figure(figsize=(8, 5))
    plt.barh(categories, population, color='salmon')
    plt.title("বিভিন্ন দেশের জনসংখ্যা (কোটিতে)")
    plt.xlabel("জনসংখ্যা (কোটি)")
    plt.ylabel("দেশ")
    plt.show()
    ```

### **২. Statistical (পরিসংখ্যানিক প্লট)**

এই প্লটগুলো ডেটার বন্টন (distribution) এবং পরিসংখ্যানিক বৈশিষ্ট্য বুঝতে সাহায্য করে।

#### **ক) `hist()` - হিস্টোগ্রাম**
*   **কখন ব্যবহার করা হয়?** একটি একক সংখ্যাসূচক ভ্যারিয়েবলের ডেটা বন্টন বা ফ্রিকোয়েন্সি দেখতে। যেমন: একটি ক্লাসের ছাত্রদের পরীক্ষার নম্বর কীভাবে বন্টিত আছে।
*   **মূল ধারণা:** ডেটাকে কয়েকটি সমান ব্যবধানে (bins) ভাগ করে প্রতিটি ব্যবধানে কতগুলো ডেটা পয়েন্ট আছে, তা বার আকারে দেখানো হয়।
*   **কোড উদাহরণ:**
    ```python
    data = np.random.normal(loc=100, scale=15, size=1000) # গড় ১০০, বিচ্যুতি ১৫

    plt.figure(figsize=(8, 5))
    plt.hist(data, bins=30, color='lightblue', edgecolor='black')
    plt.title("ডেটা বন্টনের হিস্টোগ্রাম")
    plt.xlabel("মান")
    plt.ylabel("ফ্রিকোয়েন্সি")
    plt.show()
    ```

#### **খ) `boxplot()` - বক্স প্লট**
*   **কখন ব্যবহার করা হয়?** ডেটার পরিসংখ্যানিক সারসংক্ষেপ (মধ্যমা, কোয়ার্টাইল, আউটলায়ার) দেখতে এবং বিভিন্ন গ্রুপের মধ্যে ডেটার বন্টন তুলনা করতে।
*   **মূল ধারণা:** এটি ডেটাকে চারটি ভাগে ভাগ করে দেখায়। বক্সটি মাঝের ৫০% ডেটাকে ধারণ করে।
*   **কোড উদাহরণ:**
    ```python
    data1 = np.random.normal(100, 10, 200)
    data2 = np.random.normal(80, 30, 200)
    data_to_plot = [data1, data2]

    plt.figure(figsize=(8, 5))
    plt.boxplot(data_to_plot, labels=['গ্রুপ A', 'গ্রুপ B'])
    plt.title("দুটি গ্রুপের ডেটার বক্স প্লট")
    plt.ylabel("মান")
    plt.show()
    ```

#### **গ) `violinplot()` - ভায়োলিন প্লট**
*   **কখন ব্যবহার করা হয়?** এটি বক্স প্লটের একটি উন্নত সংস্করণ, যা ডেটার ঘনত্বও (density) দেখায়।
*   **মূল ধারণা:** এটি বক্স প্লটের সাথে একটি কার্নেল ডেনসিটি প্লট (KDE) যুক্ত করে, যা ডেটার বন্টনের আকৃতি সম্পর্কে আরও ভালো ধারণা দেয়।
*   **কোড উদাহরণ:**
    ```python
    data1 = np.random.normal(100, 10, 200)
    data2 = np.random.normal(80, 30, 200)
    data_to_plot = [data1, data2]

    plt.figure(figsize=(8, 5))
    plt.violinplot(data_to_plot)
    plt.xticks([1, 2], ['গ্রুপ A', 'গ্রুপ B'])
    plt.title("দুটি গ্রুপের ডেটার ভায়োলিন প্লট")
    plt.ylabel("মান")
    plt.show()
    ```

### **৩. Matrix (ম্যাট্রিক্স প্লট)**

এই প্লটগুলো 2D অ্যারে বা ম্যাট্রিক্স ডেটা ভিজ্যুয়ালাইজ করতে ব্যবহৃত হয়।

#### **ক) `imshow()` - ইমেজ শো**
*   **কখন ব্যবহার করা হয়?** 2D ডেটা অ্যারে বা ম্যাট্রিক্সকে একটি ছবি হিসেবে দেখাতে। প্রতিটি সেলের মান একটি নির্দিষ্ট রঙ দ্বারা প্রকাশ করা হয়। এটি ইমেজ প্রসেসিং এবং হিটম্যাপের জন্য ব্যবহৃত হয়।
*   **কোড উদাহরণ:**
    ```python
    matrix_data = np.random.rand(10, 10) # 10x10 একটি ম্যাট্রিক্স

    plt.figure(figsize=(6, 6))
    plt.imshow(matrix_data, cmap='viridis')
    plt.colorbar(label='মান')
    plt.title("imshow() ব্যবহার করে হিটম্যাপ")
    plt.show()
    ```

#### **খ) `pcolor()` - স্যুডো কালার প্লট**
*   **কখন ব্যবহার করা হয়?** `imshow()` এর মতোই, তবে এটি নন-রেক্ট্যাঙ্গুলার গ্রিডের জন্যও কাজ করতে পারে।
*   **মূল ধারণা:** এটি একটি 2D গ্রিডের প্রতিটি চতুর্ভুজকে (quadrilateral) একটি নির্দিষ্ট রঙ দেয় যা ওই সেলের মান নির্দেশ করে।
*   **কোড উদাহরণ:**
    ```python
    x = np.arange(0, 10)
    y = np.arange(0, 10)
    X, Y = np.meshgrid(x, y)
    Z = np.sin(X) * np.cos(Y)

    plt.figure(figsize=(8, 6))
    plt.pcolor(X, Y, Z, cmap='plasma')
    plt.colorbar(label='Z মান')
    plt.title("pcolor() প্লট")
    plt.show()
    ```

#### **গ) `contour()` - কন্ট্যুর প্লট**
*   **কখন ব্যবহার করা হয়?** 3D পৃষ্ঠকে 2D প্লেনে দেখানোর জন্য। এটি সমান মানের বিন্দুগুলোকে সংযোগকারী রেখা (কন্ট্যুর লাইন) আঁকে, যা ভূ-সংস্থানিক মানচিত্রের (topographical map) মতো।
*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(-3.0, 3.0, 100)
    y = np.linspace(-3.0, 3.0, 100)
    X, Y = np.meshgrid(x, y)
    Z = np.exp(-(X**2 + Y**2))

    plt.figure(figsize=(7, 6))
    contour = plt.contour(X, Y, Z, cmap='viridis')
    plt.colorbar(contour, label='উচ্চতা')
    plt.title("কন্ট্যুর প্লট")
    plt.show()
    ```

### **৪. Polar / Special (পোলার এবং বিশেষ প্লট)**

#### **ক) `pie()` - পাই চার্ট**
*   **কখন ব্যবহার করা হয়?** একটি সমগ্রের অংশগুলো বা শতাংশ দেখানোর জন্য।
*   **মূল ধারণা:** একটি বৃত্তকে বিভিন্ন অংশে ভাগ করা হয়, যেখানে প্রতিটি অংশের আকার তার মানের সমানুপাতিক।
*   **কোড উদাহরণ:**
    ```python
    sizes = [15, 30, 45, 10]
    labels = ['A', 'B', 'C', 'D']
    
    plt.figure(figsize=(6, 6))
    plt.pie(sizes, labels=labels, autopct='%1.1f%%', startangle=90)
    plt.title("পাই চার্ট")
    plt.axis('equal') # বৃত্তটিকে সঠিক গোলক দেখানোর জন্য
    plt.show()
    ```

#### **খ) `polar()` - পোলার প্লট**
*   **কখন ব্যবহার করা হয়?** ডেটা যখন চক্রাকার বা দিকনির্ভর হয়। যেমন: কোনো অ্যান্টেনার সিগন্যাল প্যাটার্ন।
*   **মূল ধারণা:** এটি কার্টেসিয়ান (x, y) কো-অর্ডিনেটের পরিবর্তে পোলার (কোণ এবং ব্যাসার্ধ) কো-অর্ডিনেট ব্যবহার করে।
*   **কোড উদাহরণ:**
    ```python
    theta = np.linspace(0, 2 * np.pi, 100)
    r = np.abs(np.sin(5 * theta)) # একটি ফুলের মতো আকৃতি

    fig, ax = plt.subplots(subplot_kw={'projection': 'polar'})
    ax.plot(theta, r)
    ax.set_title("পোলার প্লট")
    plt.show()
    ```

#### **গ) `hexbin()` - হেক্সাবিন প্লট**
*   **কখন ব্যবহার করা হয়?** যখন স্ক্যাটার প্লটে অনেক বেশি ডেটা পয়েন্ট থাকে এবং সেগুলো একে অপরের উপর চলে আসে (overplotting)। এটি 2D হিস্টোগ্রামের মতো কাজ করে।
*   **মূল ধারণা:** প্লটটিকে ষড়ভুজাকৃতির (hexagonal) বিনে ভাগ করা হয় এবং প্রতিটি বিনে কতগুলো ডেটা পয়েন্ট আছে, তার উপর ভিত্তি করে রঙ করা হয়।
*   **কোড উদাহরণ:**
    ```python
    x = np.random.randn(10000)
    y = np.random.randn(10000)

    plt.figure(figsize=(8, 6))
    plt.hexbin(x, y, gridsize=30, cmap='inferno')
    plt.colorbar(label='পয়েন্টের সংখ্যা')
    plt.title("হেক্সাবিন প্লট")
    plt.show()
    ```

### **৫. 3D (ত্রিমাত্রিক প্লট)**

3D প্লট তৈরির জন্য `mpl_toolkits.mplot3d` থেকে `Axes3D` ইম্পোর্ট করতে হয়।

#### **ক) `plot3D()` - 3D লাইন প্লট**

    ```python
    fig = plt.figure()
    ```

    ```python
    fig = plt.figure()
    ```

#### **গ) `surface()` - 3D সারফেস প্লট**
*   **কখন ব্যবহার করা হয়?** একটি ফাংশন z = f(x, y) এর পৃষ্ঠকে ত্রিমাত্রিকভাবে দেখানোর জন্য।

    ```python
    fig = plt.figure()

    ax.plot_surface(X, Y, Z, cmap='viridis')
    ```

### **৬. Utility (ইউটিলিটি ফাংশন)**

এগুলো সরাসরি প্লট তৈরি করে না, কিন্তু প্লট তৈরি এবং পরিচালনা করার জন্য অপরিহার্য।

*   **`figure()`:** একটি নতুন প্লটের জন্য ক্যানভাস বা উইন্ডো তৈরি করে। এর মাধ্যমে প্লটের আকার (`figsize`), রেজোলিউশন (`dpi`) ইত্যাদি নির্ধারণ করা যায়।
*   **`subplots()`:** এটি একটি Figure এবং এক বা একাধিক Axes (সাবপ্লট) একসাথে তৈরি করার সবচেয়ে সহজ উপায়। এটি `fig` এবং `ax` অবজেক্ট রিটার্ন করে, যা অবজেক্ট-ভিত্তিক পদ্ধতিতে প্লট করার জন্য খুব দরকারি।
*   **`show()`:** তৈরি করা সমস্ত প্লট স্ক্রিনে প্রদর্শন করে।
*   **`savefig()`:** বর্তমান Figure-টিকে একটি ফাইল হিসেবে (যেমন: PNG, PDF, SVG) সেভ করে।

### **১. `plt.plot()` - লাইন প্লট**

*   **কখন ব্যবহার করা হয়?** এটি Matplotlib-এর সবচেয়ে মৌলিক এবং বহুল ব্যবহৃত প্লট। দুটি ভ্যারিয়েবলের মধ্যে ধারাবাহিক সম্পর্ক বা সময়ের সাথে ডেটার পরিবর্তন দেখানোর জন্য এটি আদর্শ। যেমন: এক বছরের তাপমাত্রা, স্টকের দাম, বা কোনো গাণিতিক ফাংশনের গ্রাফ।

*   **মূল ধারণা:** এটি x এবং y অক্ষের ডেটা পয়েন্টগুলোকে পর্যায়ক্রমে সরলরেখা দিয়ে সংযুক্ত করে।

*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(0, 10, 100) # 0 থেকে 10 পর্যন্ত 100টি বিন্দু
    y = np.sin(x) # প্রতিটি x বিন্দুর জন্য সাইন মান

    plt.figure(figsize=(8, 5))
    plt.plot(x, y, label='sin(x)', color='blue', linestyle='-')
    plt.title("লাইন প্লট - Sine Wave")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.legend()
    plt.grid(True)
    plt.show()
    ```

### **২. `plt.scatter()` - স্ক্যাটার প্লট**

*   **কখন ব্যবহার করা হয়?** দুটি সংখ্যাসূচক ভ্যারিয়েবলের মধ্যে সম্পর্ক, প্যাটার্ন বা কোরিলেশন খুঁজে বের করতে। এখানে ডেটা পয়েন্টগুলো লাইন দিয়ে যুক্ত থাকে না। যেমন: ছাত্রের পড়ার সময় এবং পরীক্ষার নম্বরের মধ্যে সম্পর্ক।

*   **মূল ধারণা:** প্রতিটি (x, y) ডেটা জোড়কে একটি স্বতন্ত্র বিন্দু বা মার্কার হিসেবে প্লটে দেখানো হয়।

*   **কোড উদাহরণ:**
    ```python
    # 100 জন ছাত্রের ডেটা
    study_hours = np.random.uniform(1, 10, 100)
    exam_scores = 50 + (study_hours * 5) + np.random.normal(0, 5, 100)

    plt.figure(figsize=(8, 5))
    plt.scatter(study_hours, exam_scores, color='green', alpha=0.6)
    plt.title("স্ক্যাটার প্লট - পড়ার সময় বনাম পরীক্ষার স্কোর")
    plt.xlabel("পড়ার সময় (ঘণ্টা)")
    plt.ylabel("পরীক্ষার স্কোর")
    plt.grid(True)
    plt.show()
    ```

### **৩. `plt.bar()` - ভার্টিক্যাল বার চার্ট**

*   **কখন ব্যবহার করা হয়?** বিভিন্ন স্বতন্ত্র ক্যাটাগরির মধ্যে সংখ্যাসূচক মান তুলনা করার জন্য। যেমন: বিভিন্ন মাসে একটি দোকানের বিক্রয়।

*   **মূল ধারণা:** প্রতিটি ক্যাটাগরির জন্য একটি উল্লম্ব দণ্ড (vertical bar) আঁকা হয়, যার উচ্চতা ওই ক্যাটাগরির মান নির্দেশ করে।

*   **কোড উদাহরণ:**

    ```python
    months = ['জানুয়ারি', 'ফেব্রুয়ারি', 'মার্চ', 'এপ্রিল']
    ```

### **৪. `plt.barh()` - হরাইজন্টাল বার চার্ট**

*   **মূল ধারণা:** বারগুলো উল্লম্বের পরিবর্তে অনুভূমিকভাবে (horizontally) আঁকা হয়, যেখানে বারের দৈর্ঘ্য মান নির্দেশ করে।

    ```python
    products = ['স্মার্টফোন', 'ল্যাপটপ', 'হেডফোন', 'স্মার্টওয়াচ']
    units_sold = [500, 350, 800, 450]

    plt.figure(figsize=(8, 5))
    ```

### **৫. `plt.stem()` - স্টেম প্লট**

*   **কখন ব্যবহার করা হয়?** ডিসক্রিট বা স্যাম্পল করা ডেটা দেখানোর জন্য, বিশেষ করে ডিজিটাল সিগন্যাল প্রসেসিং বা টাইম সিরিজ অ্যানালাইসিসে। এটি প্রতিটি ডেটা পয়েন্টের মানকে স্পষ্টভাবে তুলে ধরে।

*   **মূল ধারণা:** প্রতিটি ডেটা পয়েন্টের জন্য বেসলাইন (সাধারণত y=0) থেকে একটি উল্লম্ব রেখা (stem) আঁকা হয় এবং রেখার শীর্ষে একটি মার্কার থাকে।

*   **কোড উদাহরণ:**
    ```python
    x = np.arange(0, 10)
    y = np.sin(x)

    plt.figure(figsize=(8, 5))
    plt.stem(x, y, linefmt='grey', markerfmt='D', basefmt='r-') # linefmt, markerfmt, basefmt দিয়ে স্টাইল করা যায়
    plt.title("স্টেম প্লট")
    plt.xlabel("ডিসক্রিট সময়")
    plt.ylabel("সিগন্যালের মান")
    plt.show()
    ```

### **৬. `plt.step()` - স্টেপ প্লট**

*   **কখন ব্যবহার করা হয়?** যখন ডেটার মান একটি নির্দিষ্ট সময় পর্যন্ত স্থির থাকে এবং হঠাৎ করে পরিবর্তিত হয়। যেমন: ব্যাংক সুদের হার, ইনভেনটরি লেভেল বা ডিজিটাল সিগন্যাল।

*   **মূল ধারণা:** এটি ডেটা পয়েন্টগুলোকে অনুভূমিক এবং উল্লম্ব রেখা দিয়ে সংযুক্ত করে একটি সিঁড়ির মতো আকৃতি তৈরি করে।

*   **কোড উদাহরণ:**
    ```python
    x = [1, 2, 3, 4, 5]
    y = [10, 12, 12, 15, 14]

    plt.figure(figsize=(8, 5))
    plt.step(x, y, where='mid', label='where="mid"')
    plt.plot(x, y, 'o--', color='grey', alpha=0.3) # আসল পয়েন্টগুলো দেখানোর জন্য
    plt.title("স্টেপ প্লট")
    plt.xlabel("সময়")
    plt.ylabel("মান")
    plt.grid(True)
    plt.legend()
    plt.show()
    ```

### **৭. `plt.fill_between()` - ফিল বিটুইন**

*   **কখন ব্যবহার করা হয়?** দুটি বক্ররেখার মধ্যবর্তী এলাকাকে রঙ দিয়ে ভরাট করার জন্য। এটি দুটি ডেটা সিরিজের মধ্যে পার্থক্য, অনিশ্চয়তার সীমা (confidence interval) বা কোনো রেঞ্জের ডেটা দেখানোর জন্য চমৎকার।

*   **মূল ধারণা:** এটি একটি সাধারণ x-অক্ষের জন্য দুটি y-মানের সিরিজের (`y1`, `y2`) মধ্যবর্তী স্থানকে রঙ করে।

*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(0, 10, 100)
    y1 = np.sin(x)
    y2 = np.cos(x)

    plt.figure(figsize=(8, 5))
    plt.plot(x, y1, label='sin(x)')
    plt.plot(x, y2, label='cos(x)')
    # sin(x) এবং cos(x) এর মধ্যবর্তী এলাকা ভরাট করা
    plt.fill_between(x, y1, y2, color='skyblue', alpha=0.4, where=(y1 > y2), label='sin(x) > cos(x)')
    plt.fill_between(x, y1, y2, color='salmon', alpha=0.4, where=(y1 <= y2), label='sin(x) <= cos(x)')
    plt.title("Fill Between - sin(x) এবং cos(x) এর মধ্যে")
    plt.legend()
    plt.show()
    ```

### **৮. `plt.errorbar()` - এররবার প্লট**

*   **কখন ব্যবহার করা হয়?** যখন প্রতিটি ডেটা পয়েন্টের সাথে একটি অনিশ্চয়তা (uncertainty) বা ত্রুটি (error) যুক্ত থাকে। এটি বৈজ্ঞানিক পরীক্ষা-নিরীক্ষার ফলাফল দেখানোর জন্য অপরিহার্য।

*   **মূল ধারণা:** এটি একটি লাইন বা স্ক্যাটার প্লটের মতোই, কিন্তু প্রতিটি ডেটা পয়েন্টের সাথে উল্লম্ব এবং/অথবা অনুভূমিক দণ্ড (error bars) যুক্ত থাকে, যা ডেটার অনিশ্চয়তার সীমা নির্দেশ করে।

*   **কোড উদাহরণ:**
    ```python
    x = np.arange(0, 5, 0.5)
    y = x**2 + np.random.normal(0, 1, len(x))
    y_error = np.random.uniform(1, 2, len(x)) # প্রতিটি পয়েন্টের জন্য এরর

    plt.figure(figsize=(8, 5))
    plt.errorbar(x, y, yerr=y_error, fmt='o', color='purple', ecolor='lightgray', elinewidth=3, capsize=5, label='পরিমাপ')
    plt.title("এররবার প্লট")
    plt.xlabel("পরিমাপের ক্রম")
    plt.ylabel("মান (এররসহ)")
    plt.legend()
    plt.grid(True)
    plt.show()
    ```

### **১. `plt.hist()` - হিস্টোগ্রাম**

*   **কখন ব্যবহার করা হয়?** একটি একক সংখ্যাসূচক ভ্যারিয়েবলের ডেটা কীভাবে বন্টিত (distributed) আছে বা এর ফ্রিকোয়েন্সি কেমন, তা বোঝার জন্য হিস্টোগ্রাম ব্যবহার করা হয়। যেমন: একটি ক্লাসের ছাত্রদের পরীক্ষার নম্বর, মানুষের বয়স বা উচ্চতার বন্টন ইত্যাদি।

*   **মূল ধারণা:** এটি ডেটার সম্পূর্ণ পরিসরকে কয়েকটি সমান ব্যবধানে (যাকে "বিন" বা `bins` বলা হয়) ভাগ করে। এরপর প্রতিটি বিনে কতগুলো ডেটা পয়েন্ট পড়েছে, তা গণনা করে একটি বার চার্টের মতো দেখায়।

*   **কোড উদাহরণ:**
    ```python
    # পরীক্ষার নম্বরের নমুনা ডেটা (গড় ৭০, বিচ্যুতি ১০)
    exam_scores = np.random.normal(loc=70, scale=10, size=500)

    plt.figure(figsize=(8, 5))
    plt.hist(exam_scores, bins=20, color='skyblue', edgecolor='black')
    plt.title("ছাত্রদের পরীক্ষার নম্বরের বন্টন (হিস্টোগ্রাম)")
    plt.xlabel("নম্বর")
    plt.ylabel("ছাত্রের সংখ্যা (ফ্রিকোয়েন্সি)")
    plt.axvline(exam_scores.mean(), color='red', linestyle='dashed', linewidth=2, label=f'গড় নম্বর: {exam_scores.mean():.2f}')
    plt.legend()
    plt.show()
    ```

### **২. `plt.boxplot()` - বক্স-এন্ড-হুইস্কার প্লট**

*   **কখন ব্যবহার করা হয়?** ডেটার পরিসংখ্যানিক সারসংক্ষেপ (যেমন: মধ্যমা, কোয়ার্টাইল, সর্বনিম্ন ও সর্বোচ্চ মান) দ্রুত বোঝার জন্য এবং আউটলায়ার (outliers) বা চরম মান খুঁজে বের করার জন্য এটি চমৎকার। এটি বিভিন্ন গ্রুপের মধ্যে ডেটার বন্টন তুলনা করতেও খুব কার্যকর।

*   **মূল ধারণা:**
    *   **বক্স:** ডেটার মাঝের ৫০% অংশকে ধারণ করে (Q1 থেকে Q3 পর্যন্ত, যা Interquartile Range বা IQR নামে পরিচিত)।
    *   **বক্সের ভেতরের রেখা:** মধ্যমা (Median বা Q2)।
    *   **হুইস্কার (Whiskers):** বক্সের বাইরে থাকা রেখাগুলো, যা ডেটার স্বাভাবিক পরিসর দেখায় (সাধারণত Q1 - 1.5*IQR থেকে Q3 + 1.5*IQR পর্যন্ত)।
    *   **বিন্দু:** হুইস্কারের বাইরে থাকা ডেটা পয়েন্টগুলো আউটলায়ার হিসেবে বিবেচিত হয়।

*   **কোড উদাহরণ:**
    ```python
    # দুটি ভিন্ন সেকশনের পরীক্ষার নম্বরের ডেটা
    section_a_scores = np.random.normal(75, 8, 100)
    section_b_scores = np.random.normal(70, 12, 100)
    data_to_plot = [section_a_scores, section_b_scores]

    plt.figure(figsize=(8, 6))
    plt.boxplot(data_to_plot, labels=['সেকশন A', 'সেকশন B'], patch_artist=True)
    plt.title("দুটি সেকশনের পরীক্ষার নম্বরের তুলনা (বক্স প্লট)")
    plt.ylabel("নম্বর")
    plt.grid(True, axis='y')
    plt.show()
    ```

### **৩. `plt.violinplot()` - ভায়োলিন প্লট**

*   **কখন ব্যবহার করা হয়?** এটি বক্স প্লটের একটি উন্নত সংস্করণ। এটি ডেটার বন্টনের ঘনত্ব (probability density) দেখায়। বক্স প্লট যেখানে শুধু সারসংক্ষেপ দেখায়, ভায়োলিন প্লট সেখানে ডেটার সম্পূর্ণ আকৃতি (যেমন, ডেটা কি এক জায়গায় কেন্দ্রীভূত নাকি দুটি ভিন্ন স্থানে) বুঝতে সাহায্য করে।

*   **মূল ধারণা:** এটি একটি বক্স প্লট এবং একটি কার্নেল ডেনসিটি এস্টিমেট (KDE) প্লটের সমন্বয়। ভায়োলিনের প্রশস্ততা নির্দেশ করে ওই মানে ডেটার ঘনত্ব কত বেশি।

*   **কোড উদাহরণ:**
    ```python
    # বক্স প্লটের উদাহরণ থেকে একই ডেটা ব্যবহার করা হচ্ছে
    section_a_scores = np.random.normal(75, 8, 100)
    section_b_scores = np.random.normal(70, 12, 100)
    data_to_plot = [section_a_scores, section_b_scores]

    plt.figure(figsize=(8, 6))
    plt.violinplot(data_to_plot)
    plt.xticks([1, 2], ['সেকশন A', 'সেকশন B'])
    plt.title("দুটি সেকশনের পরীক্ষার নম্বরের বন্টন (ভায়োলিন প্লট)")
    plt.ylabel("নম্বর")
    plt.grid(True, axis='y')
    plt.show()
    ```

### **৪. `plt.pie()` - পাই চার্ট**

*   **কখন ব্যবহার করা হয়?** একটি সমগ্রের বিভিন্ন অংশ বা শতাংশ দেখানোর জন্য পাই চার্ট ব্যবহার করা হয়। যেমন: একটি কোম্পানির বিভিন্ন পণ্যের মার্কেট শেয়ার বা একটি পরিবারের মাসিক খরচের খাত। এটি অল্প কয়েকটি ক্যাটাগরি (সাধারণত ৫-৬ টির কম) দেখানোর জন্য সবচেয়ে ভালো।

*   **মূল ধারণা:** একটি সম্পূর্ণ বৃত্তকে (১০০%) বিভিন্ন অংশে বা স্লাইসে ভাগ করা হয়, যেখানে প্রতিটি স্লাইসের আকার তার মানের সমানুপাতিক।

*   **কোড উদাহরণ:**
    ```python
    # একটি পরিবারের মাসিক খরচের খাত
    expense_labels = ['খাবার', 'বাড়ি ভাড়া', 'শিক্ষা', 'যাতায়াত', 'অন্যান্য']
    expense_values = [45, 25, 15, 10, 5]
    
    plt.figure(figsize=(7, 7))
    plt.pie(expense_values, labels=expense_labels, autopct='%1.1f%%', startangle=140,
            explode=(0.05, 0, 0, 0, 0)) # 'খাবার' অংশটি সামান্য আলাদা করে দেখানো
    plt.title("মাসিক পারিবারিক খরচের বন্টন")
    plt.axis('equal')  # পাই চার্টকে বৃত্তাকার রাখার জন্য
    plt.show()
    ```

### **৫. `plt.bar_label()` - বার লেবেল**

*   **কখন ব্যবহার করা হয়?** এটি নিজে কোনো প্লট নয়, বরং একটি সহায়ক ফাংশন। এটি বার চার্টের প্রতিটি বারের উপরে বা পাশে তার সঠিক মান দেখানোর জন্য ব্যবহৃত হয়। এতে চার্টটি পড়া এবং বোঝা অনেক সহজ হয়ে যায়।

*   **মূল ধারণা:** এটি `plt.bar()` বা `plt.barh()` দ্বারা তৈরি করা বারগুলোর একটি কন্টেইনার অবজেক্ট নেয় এবং প্রতিটি বারের জন্য স্বয়ংক্রিয়ভাবে লেবেল যুক্ত করে।

*   **কোড উদাহরণ:**
    ```python
    countries = ['বাংলাদেশ', 'ভারত', 'নেপাল']
    gdp_per_capita = [2821, 2612, 1336]

    plt.figure(figsize=(8, 5))
    bars = plt.bar(countries, gdp_per_capita, color=['green', 'orange', 'red'])
    
    # বারগুলোর উপরে লেবেল যোগ করা
    plt.bar_label(bars, fmt='$%d') # ফরম্যাট: ডলার চিহ্নসহ পূর্ণসংখ্যা

    plt.title("কিছু দক্ষিণ এশীয় দেশের মাথাপিছু জিডিপি (ডলারে)")
    plt.ylabel("মাথাপিছু জিডিপি (USD)")
    plt.show()
    ```

### **৬. `plt.ecdf()` - এম্পিরিকাল কিউমুলেটিভ ডিস্ট্রিবিউশন ফাংশন**

*   **কখন ব্যবহার করা হয়?** এটি একটি ডেটাসেটের ক্রমবর্ধমান বন্টন দেখায়। এটি "একটি নির্দিষ্ট মানের চেয়ে কম বা সমান কত শতাংশ ডেটা পয়েন্ট আছে?"—এই প্রশ্নের উত্তর দেয়। দুটি ভিন্ন ডেটাসেটের বন্টন তুলনা করার জন্য এটি খুব শক্তিশালী একটি টুল। এটি Matplotlib-এর নতুন সংস্করণগুলোতে যুক্ত হয়েছে।

*   **মূল ধারণা:** X-অক্ষে ডেটার মান এবং Y-অক্ষে ০ থেকে ১ পর্যন্ত ক্রমবর্ধমান অনুপাত (cumulative proportion) দেখানো হয়। গ্রাফটি একটি সিঁড়ির মতো ধাপে ধাপে উপরে ওঠে।

*   **কোড উদাহরণ:**
    ```python
    # দুটি ভিন্ন গ্রুপের ওজন ডেটা
    group_A_weights = np.random.normal(loc=65, scale=5, size=100)
    group_B_weights = np.random.normal(loc=70, scale=8, size=100)

    plt.figure(figsize=(8, 5))
    plt.ecdf(group_A_weights, label='গ্রুপ A')
    plt.ecdf(group_B_weights, label='গ্রুপ B')

    plt.title("দুটি গ্রুপের ওজনের ECDF প্লট")
    plt.xlabel("ওজন (কেজি)")
    plt.ylabel("ক্রমবর্ধমান অনুপাত")
    plt.grid(True)
    plt.legend()
    plt.show()
    ```
    এই প্লট থেকে দেখা যায়, গ্রুপ A-এর ওজন সামগ্রিকভাবে গ্রুপ B-এর চেয়ে কম, কারণ এর রেখাটি বাম দিকে বেশি ঝুঁকে আছে।

### **১. `plt.stackplot()` - স্ট্যাকড এরিয়া প্লট**

*   **কখন ব্যবহার করা হয়?** সময়ের সাথে সাথে একাধিক গ্রুপের সমষ্টিগত পরিবর্তন এবং প্রতিটি গ্রুপের আনুপাতিক অবদান দেখানোর জন্য এটি ব্যবহার করা হয়। যেমন: একটি প্রকল্পে বিভিন্ন দলের দৈনিক কাজের পরিমাণ, বিভিন্ন উৎস থেকে আসা ওয়েব ট্র্যাফিকের পরিবর্তন, বা একটি দেশের বিভিন্ন খাতে জিডিপির অবদান।

*   **মূল ধারণা:** এটি একটি লাইন প্লটের মতো, কিন্তু প্রতিটি লাইনের নিচের এলাকা রঙ দিয়ে ভরাট করা হয় এবং পরবর্তী গ্রুপের এলাকা আগেরটির উপরে স্ট্যাক বা স্থাপন করা হয়। প্লটের যেকোনো বিন্দুতে মোট উচ্চতা হলো সেই বিন্দু পর্যন্ত সমস্ত গ্রুপের মানের যোগফল।

*   **কোড উদাহরণ:**
    ```python
    # সপ্তাহের ৭ দিনের ডেটা
    days = [1, 2, 3, 4, 5, 6, 7]

    # তিনজন ডেভেলপারের দৈনিক কোড কন্ট্রিবিউশন (লাইনের সংখ্যা)
    dev1_commits = [80, 120, 100, 130, 90, 110, 140]
    dev2_commits = [90, 100, 110, 80, 120, 130, 100]
    dev3_commits = [100, 90, 120, 110, 100, 100, 90]

    labels = ['ডেভেলপার ১', 'ডেভেলপার ২', 'ডেভেলপার ৩']

    plt.figure(figsize=(10, 6))
    plt.stackplot(days, dev1_commits, dev2_commits, dev3_commits, labels=labels)

    plt.title("সাপ্তাহিক কোড কন্ট্রিবিউশন (স্ট্যাকড এরিয়া প্লট)")
    plt.xlabel("দিন")
    plt.ylabel("মোট কোডের লাইন")
    plt.legend(loc='upper left')
    plt.show()
    ```
    এই প্লটটি থেকে সহজেই বোঝা যায় মোট কন্ট্রিবিউশন প্রতিদিন কেমন ছিল এবং তাতে কোন ডেভেলপারের অবদান কতটুকু।

### **২. `plt.fill()` - ফিল্ড পলিগন প্লট**

*   **কখন ব্যবহার করা হয়?** এটি যেকোনো বহুভুজ (polygon) বা বদ্ধ আকৃতিকে রঙ দিয়ে ভরাট করার জন্য ব্যবহৃত হয়। এটি `fill_between()` এর চেয়ে বেশি সাধারণ, কারণ এটি শুধুমাত্র দুটি রেখার মধ্যবর্তী স্থান নয়, বরং যেকোনো আকারের কাস্টম শেইপ তৈরি করতে পারে। এটি কোনো নির্দিষ্ট এলাকা হাইলাইট করতে বা কাস্টম ভিজ্যুয়াল তৈরি করতে কাজে লাগে।

*   **মূল ধারণা:** আপনাকে বহুভুজের প্রতিটি কোণার (vertex) x এবং y স্থানাঙ্ক (coordinates) সরবরাহ করতে হবে। Matplotlib সেই বিন্দুগুলোকে পর্যায়ক্রমে সংযুক্ত করে একটি বদ্ধ আকৃতি তৈরি করবে এবং সেটিকে রঙ দিয়ে ভরাট করবে।

*   **কোড উদাহরণ:**
    ```python
    # একটি পঞ্চভুজের (pentagon) স্থানাঙ্ক
    x = [1, 2, 3, 2.5, 1.5]
    y = [1, 0.5, 1.5, 2.5, 2]

    plt.figure(figsize=(6, 6))
    plt.fill(x, y, color='cyan', alpha=0.7, edgecolor='blue', linewidth=2)
    
    plt.title("ফিল্ড পলিগন প্লট")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.grid(True)
    plt.show()
    ```

### **৩. `plt.eventplot()` - ইভেন্ট প্লট**

*   **কখন ব্যবহার করা হয়?** এটি ডিসক্রিট বা বিচ্ছিন্ন ঘটনা বা ডেটা পয়েন্টের ক্রম দেখানোর জন্য ব্যবহৃত হয়। যখন আপনার কাছে শুধুমাত্র ঘটনার সময় বা অবস্থান থাকে (কিন্তু কোনো নির্দিষ্ট y-মান থাকে না), তখন এটি খুবই কার্যকর। যেমন: নিউরনের ফায়ারিং প্যাটার্ন, সার্ভারে আসা রিকোয়েস্টের সময়, বা কোনো যন্ত্রের ত্রুটির সময় রেকর্ড করা।

*   **মূল ধারণা:** এটি একটি অক্ষ বরাবর প্রতিটি ঘটনাকে একটি ছোট উল্লম্ব বা অনুভূমিক রেখা হিসেবে দেখায়। একাধিক ঘটনার ক্রম তুলনা করার জন্য সেগুলোকে ভিন্ন ভিন্ন সারিতে দেখানো যায়।

*   **কোড উদাহরণ:**
    ```python
    # তিনটি ভিন্ন সার্ভারে আসা রিকোয়েস্টের সময় (সেকেন্ডে)
    server1_requests = np.random.uniform(0, 60, 20)
    server2_requests = np.random.uniform(0, 60, 30)
    server3_requests = np.random.uniform(0, 60, 15)

    all_requests = [server1_requests, server2_requests, server3_requests]

    plt.figure(figsize=(10, 4))
    # lineoffsets প্রতিটি সারির অবস্থান এবং linelengths রেখার উচ্চতা নির্ধারণ করে
    plt.eventplot(all_requests, colors=['red', 'blue', 'green'], lineoffsets=[1, 2, 3], linelengths=0.8)
    
    plt.yticks([1, 2, 3], ['সার্ভার ১', 'সার্ভার ২', 'সার্ভার ৩'])
    plt.title("এক মিনিটে সার্ভার রিকোয়েস্টের ইভেন্ট প্লট")
    plt.xlabel("সময় (সেকেন্ড)")
    plt.show()
    ```

### **৪. `plt.broken_barh()` - ব্রোকেন হরাইজন্টাল বার চার্ট**

*   **কখন ব্যবহার করা হয়?** এটি একটি টাইমলাইন বা সময়সূচী দেখানোর জন্য আদর্শ, যেখানে বিভিন্ন কাজ বা অবস্থা একটি নির্দিষ্ট সময় শুরু হয়ে একটি নির্দিষ্ট সময় পর্যন্ত চলে। এটি গ্যান্ট চার্ট (Gantt chart) তৈরির জন্য খুবই জনপ্রিয়, যা প্রজেক্ট ম্যানেজমেন্টে ব্যবহৃত হয়।

*   **মূল ধারণা:** `barh()` এর মতো একটি সম্পূর্ণ বার না এঁকে, `broken_barh()` আপনাকে প্রতিটি বারের জন্য একটি শুরুর বিন্দু (`start`) এবং একটি সময়কাল (`duration`) নির্দিষ্ট করতে দেয়। এতে আপনি একই সারিতে একাধিক খণ্ডিত বার তৈরি করতে পারেন।

*   **কোড উদাহরণ:**
    ```python
    fig, ax = plt.subplots(figsize=(10, 5))

    # টাস্ক এবং তাদের সময়কাল (শুরুর সময়, সময়কাল)
    task1_schedule = [(0, 10), (15, 5)]  # টাস্ক ১, ০ থেকে ১০ পর্যন্ত এবং ১৫ থেকে ২০ পর্যন্ত চলে
    task2_schedule = [(5, 8)]             # টাস্ক ২, ৫ থেকে ১৩ পর্যন্ত চলে
    task3_schedule = [(18, 10)]           # টাস্ক ৩, ১৮ থেকে ২৮ পর্যন্ত চলে

    # টাস্কগুলো প্লট করা
    ax.broken_barh(task1_schedule, (10, 9), facecolors='tab:blue')
    ax.broken_barh(task2_schedule, (20, 9), facecolors='tab:orange')
    ax.broken_barh(task3_schedule, (30, 9), facecolors='tab:green')

    ax.set_ylim(5, 45)
    ax.set_xlim(0, 30)
    ax.set_xlabel('সময় (দিন)')
    ax.set_yticks([15, 25, 35], labels=['টাস্ক ১', 'টাস্ক ২', 'টাস্ক ৩'])
    ax.set_title('প্রজেক্টের গ্যান্ট চার্ট')
    plt.grid(True, axis='x')
    plt.show()
    ```

### **৫. `plt.boxplot()` - একাধিক ডিস্ট্রিবিউশন তুলনা**

*   **কখন ব্যবহার করা হয়?** যখন আপনাকে দুই বা ততোধিক গ্রুপের ডেটার বন্টন পাশাপাশি রেখে তুলনা করতে হয়, তখন বক্স প্লট একটি অত্যন্ত শক্তিশালী টুল। এটি প্রতিটি গ্রুপের মধ্যমা (median), বিস্তার (spread/variance), এবং আউটলায়ারগুলোকে (outliers) এক নজরে তুলনা করতে সাহায্য করে। যেমন: বিভিন্ন স্কুলের ছাত্রদের পরীক্ষার ফলাফল, বিভিন্ন ওষুধের কার্যকারিতা, বা বিভিন্ন মডেলের গাড়ির মাইলেজ তুলনা করা।

*   **মূল ধারণা:** প্রতিটি গ্রুপের জন্য একটি করে বক্স প্লট আঁকা হয়। পাশাপাশি রেখে এই বক্সগুলোর অবস্থান, আকার এবং হুইস্কারের দৈর্ঘ্য দেখে গ্রুপগুলোর মধ্যে পার্থক্য খুব সহজে বোঝা যায়।

*   **কোড উদাহরণ:**
    ```python
    # তিনটি ভিন্ন মডেলের গাড়ির মাইলেজের ডেটা
    model_A_mileage = np.random.normal(loc=25, scale=2, size=100)
    model_B_mileage = np.random.normal(loc=22, scale=3, size=100)
    model_C_mileage = np.random.normal(loc=28, scale=1.5, size=100)

    data_to_compare = [model_A_mileage, model_B_mileage, model_C_mileage]
    labels = ['মডেল A', 'মডেল B', 'মডেল C']

    plt.figure(figsize=(8, 6))
    plt.boxplot(data_to_compare, labels=labels, patch_artist=True)
    
    plt.title("বিভিন্ন গাড়ির মডেলের মাইলেজ তুলনা")
    plt.ylabel("মাইলেজ (কিমি/লিটার)")
    plt.grid(True, axis='y')
    plt.show()
    ```
    এই প্লট থেকে দেখা যায় যে, মডেল C-এর গড় মাইলেজ সবচেয়ে বেশি এবং এর মানের বিস্তার (spread) সবচেয়ে কম, যা এটিকে সবচেয়ে স্থিতিশীল (consistent) পারফর্মার হিসেবে নির্দেশ করে।

### **১. `plt.imshow()` - ইমেজ শো**

*   **কখন ব্যবহার করা হয়?** এটি একটি 2D ডেটা অ্যারে, ম্যাট্রিক্স বা ছবিকে একটি ইমেজ হিসেবে দেখানোর জন্য ব্যবহৃত হয়। প্রতিটি সেলের মান একটি নির্দিষ্ট রঙ দ্বারা প্রকাশ করা হয়। এটি হিটম্যাপ (Heatmap), কোরিলেশন ম্যাট্রিক্স এবং ইমেজ প্রসেসিং-এর জন্য অত্যন্ত জনপ্রিয়।

*   **মূল ধারণা:** ডেটা ম্যাট্রিক্সের প্রতিটি সেলকে একটি পিক্সেল বা রঙিন বর্গ হিসেবে দেখানো হয়। সেলের সংখ্যাসূচক মানের উপর ভিত্তি করে একটি কালারম্যাপ (`cmap`) থেকে রঙ নির্বাচন করা হয়।

*   **কোড উদাহরণ:**
    ```python
    # একটি 10x10 র্যান্ডম ম্যাট্রিক্স তৈরি করা
    data = np.random.rand(10, 10)

    plt.figure(figsize=(6, 5))
    im = plt.imshow(data, cmap='viridis')
    
    plt.colorbar(im, label='মানের তীব্রতা')
    plt.title("imshow() ব্যবহার করে হিটম্যাপ")
    plt.show()
    ```

### **২. `plt.matshow()` - ম্যাট্রিক্স শো**

*   **কখন ব্যবহার করা হয়?** এটি `imshow()`-এর একটি বিশেষায়িত সংস্করণ, যা বিশেষভাবে ম্যাট্রিক্স ভিজ্যুয়ালাইজেশনের জন্য তৈরি। এটি ডিফল্টভাবে কিছু সুবিধাজনক সেটিং ব্যবহার করে, যা ম্যাট্রিক্সকে আরও সহজে পড়তে সাহায্য করে।

*   **মূল ধারণা:** `imshow()`-এর সাথে মূল পার্থক্য হলো:
    1.  এটি ডিফল্টভাবে `aspect='equal'` ব্যবহার করে, তাই প্রতিটি সেল বর্গাকার হয়।
    2.  X-অক্ষের টিক এবং লেবেলগুলো নিচে না দেখিয়ে উপরে দেখায়, যা গণিতে ম্যাট্রিক্স উপস্থাপনের সাথে সামঞ্জস্যপূর্ণ।

*   **কোড উদাহরণ:**
    ```python
    # একটি কোরিলেশন ম্যাট্রিক্সের মতো ডেটা
    data = np.array([[1.0, 0.7, -0.2],
                     [0.7, 1.0, 0.9],
                     [-0.2, 0.9, 1.0]])

    plt.figure(figsize=(5, 4))
    plt.matshow(data, cmap='coolwarm', fignum=1) # fignum=1 ব্যবহার করে এটিকে বর্তমান ফিগারে আঁকা হচ্ছে
    
    plt.colorbar(label='কোরিলেশন')
    plt.title("matshow() ব্যবহার করে ম্যাট্রিক্স")
    plt.show()
    ```

### **৩. `plt.pcolor()` - স্যুডোকালার প্লট**

*   **কখন ব্যবহার করা হয়?** এটিও একটি 2D অ্যারে থেকে হিটম্যাপের মতো প্লট তৈরি করে। তবে এটি নন-ইউনিফর্ম বা অনিয়মিত গ্রিডের জন্যও কাজ করতে পারে, যেখানে প্রতিটি সেলের আকার ভিন্ন হতে পারে।

*   **মূল ধারণা:** `pcolor()` একটি স্থানাঙ্ক (coordinate) গ্রিডের উপর কাজ করে। যদি আপনার ডেটা `Z` একটি `M x N` অ্যারে হয়, তবে স্থানাঙ্ক `X` এবং `Y` অ্যারেগুলো `(M+1) x (N+1)` আকারের হতে পারে, যা প্রতিটি রঙিন চতুর্ভুজের কোণাগুলো নির্ধারণ করে। এটি `imshow` এর চেয়ে বেশি নমনীয় কিন্তু সাধারণত ধীরগতির।

*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(0, 2 * np.pi, 10)
    y = np.linspace(0, 2 * np.pi, 10)
    X, Y = np.meshgrid(x, y)
    Z = np.sin(X) * np.cos(Y)

    plt.figure(figsize=(7, 6))
    plt.pcolor(X, Y, Z, cmap='plasma', shading='auto')
    
    plt.colorbar(label='Z মান')
    plt.title("pcolor() প্লট")
    plt.show()
    ```

### **৪. `plt.pcolormesh()` - ফাস্ট স্যুডোকালার মেশ প্লট**

*   **কখন ব্যবহার করা হয়?** এটি `pcolor()`-এর একটি দ্রুততর এবং আরও কার্যকর সংস্করণ। বড় ডেটাসেটের জন্য `pcolor()` অনেক সময় নিতে পারে, সেক্ষেত্রে `pcolormesh()` ব্যবহার করা উচিত। এটি `pcolor()`-এর প্রায় সমস্ত কার্যকারিতা প্রদান করে কিন্তু অনেক দ্রুত রেন্ডার করে।

*   **মূল ধারণা:** `pcolor()` প্রতিটি সেলের জন্য আলাদা আলাদা পলিগন তৈরি করে, যা সময়সাপেক্ষ। অন্যদিকে, `pcolormesh()` একটি সম্পূর্ণ "মেশ" তৈরি করে, যা গ্রাফিক্স হার্ডওয়্যার দ্বারা অনেক দ্রুত প্রসেস করা যায়। বড় ডেটাসেটের জন্য এটিই সেরা পছন্দ।

*   **কোড উদাহরণ:** (কোডটি `pcolor()`-এর মতোই)
    ```python
    x = np.linspace(0, 2 * np.pi, 50) # ডেটাসেট বড় করা হলো গতি পরীক্ষা করার জন্য
    y = np.linspace(0, 2 * np.pi, 50)
    X, Y = np.meshgrid(x, y)
    Z = np.sin(X) * np.cos(Y)

    plt.figure(figsize=(7, 6))
    plt.pcolormesh(X, Y, Z, cmap='inferno', shading='auto')
    
    plt.colorbar(label='Z মান')
    plt.title("pcolormesh() (দ্রুততর) প্লট")
    plt.show()
    ```

### **৫. `plt.contour()` - কন্ট্যুর লাইন প্লট**

*   **কখন ব্যবহার করা হয়?** একটি 3D পৃষ্ঠকে 2D প্লেনে দেখানোর জন্য এটি ব্যবহৃত হয়। এটি সমান মানের বিন্দুগুলোকে সংযোগকারী রেখা (কন্ট্যুর লাইন) আঁকে। এটি ভূ-সংস্থানিক মানচিত্র (topographical map), আবহাওয়ার চাপ বা তাপমাত্রার মানচিত্র এবং গাণিতিক ফাংশন ভিজ্যুয়ালাইজ করতে ব্যবহৃত হয়।

*   **মূল ধারণা:** 2D গ্রিডের উপর তৃতীয় মাত্রার (Z) মানগুলোর উপর ভিত্তি করে, এটি একই মানের ("isolevels") অঞ্চলগুলোকে রেখা দিয়ে চিহ্নিত করে।

*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(-2, 2, 100)
    y = np.linspace(-2, 2, 100)
    X, Y = np.meshgrid(x, y)
    Z = np.exp(-(X**2 + Y**2)) # একটি 2D Gaussian ফাংশন

    plt.figure(figsize=(7, 6))
    contours = plt.contour(X, Y, Z, cmap='viridis')
    
    # কন্ট্যুর লাইনের উপর মানগুলো লেবেল করা
    plt.clabel(contours, inline=True, fontsize=8)
    
    plt.title("কন্ট্যুর লাইন প্লট")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.show()
    ```

### **৬. `plt.contourf()` - ফিল্ড কন্ট্যুর প্লট**

*   **কখন ব্যবহার করা হয়?** এটি `contour()`-এর মতোই, কিন্তু এটি শুধু রেখা না এঁকে, কন্ট্যুর রেখাগুলোর মধ্যবর্তী এলাকাগুলো রঙ দিয়ে ভরাট (`fill`) করে দেয়। এটি `imshow` বা `pcolormesh` এর মতো একটি রঙিন প্লট তৈরি করে, তবে মানগুলো মসৃণভাবে পরিবর্তিত হয় এবং নির্দিষ্ট লেভেলে বিভক্ত থাকে।

*   **মূল ধারণা:** `f` অক্ষরটি "filled" বোঝায়। এটি কন্ট্যুর লেভেলগুলোর মধ্যে থাকা অঞ্চলগুলোকে ভিন্ন ভিন্ন রঙ দেয়, যা একটি রঙিন মানচিত্র তৈরি করে।

*   **কোড উদাহরণ:** (ডেটা `contour()`-এর উদাহরণ থেকে নেওয়া)
    ```python
    x = np.linspace(-2, 2, 100)
    y = np.linspace(-2, 2, 100)
    X, Y = np.meshgrid(x, y)
    Z = np.exp(-(X**2 + Y**2))

    plt.figure(figsize=(7, 6))
    plt.contourf(X, Y, Z, levels=15, cmap='plasma') # levels দিয়ে কন্ট্যুরের সংখ্যা নির্ধারণ করা যায়
    
    plt.colorbar(label='ফাংশনের মান')
    plt.title("ফিল্ড কন্ট্যুর প্লট")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.show()
    ```

### **১. `plt.pie()` - পাই চার্ট**

*   **কখন ব্যবহার করা হয়?** একটি সমগ্রের বিভিন্ন অংশ বা শতাংশ দেখানোর জন্য পাই চার্ট ব্যবহার করা হয়। যেমন: একটি কোম্পানির মার্কেট শেয়ার, একটি নির্বাচনের ভোটের বন্টন, বা একটি পরিবারের মাসিক খরচের খাত। এটি অল্প কয়েকটি ক্যাটাগরির জন্য সবচেয়ে কার্যকর।

*   **মূল ধারণা:** একটি সম্পূর্ণ বৃত্তকে (১০০%) বিভিন্ন অংশে বা স্লাইসে ভাগ করা হয়, যেখানে প্রতিটি স্লাইসের ক্ষেত্রফল তার মানের সমানুপাতিক।

*   **কোড উদাহরণ:**
    ```python
    # একটি টেক কোম্পানির বিভিন্ন পণ্যের মার্কেট শেয়ার
    labels = ['স্মার্টফোন', 'ল্যাপটপ', 'ট্যাবলেট', 'অন্যান্য']
    market_share = [45, 30, 15, 10]
    explode = (0.1, 0, 0, 0)  # প্রথম স্লাইসটিকে সামান্য আলাদা করে দেখানো

    plt.figure(figsize=(7, 7))
    plt.pie(market_share, explode=explode, labels=labels, autopct='%1.1f%%',
            shadow=True, startangle=90)
    plt.axis('equal')  # পাই চার্টকে বৃত্তাকার রাখার জন্য
    plt.title("টেক পণ্যের মার্কেট শেয়ার")
    plt.show()
    ```

### **২. `plt.polar()` - পোলার কো-অর্ডিনেট প্লট**

*   **কখন ব্যবহার করা হয়?** ডেটা যখন চক্রাকার বা দিকনির্ভর হয়, তখন এটি ব্যবহার করা হয়। যেমন: কোনো অ্যান্টেনার রেডিয়েশন প্যাটার্ন, একটি মাইক্রোফোনের বিভিন্ন দিক থেকে শব্দ গ্রহণের ক্ষমতা, বা কোনো ফুলের পাপড়ির আকৃতি।

*   **মূল ধারণা:** এটি কার্টেসিয়ান (x, y) কো-অর্ডিনেট সিস্টেমের পরিবর্তে পোলার (কোণ `theta` এবং ব্যাসার্ধ `r`) কো-অর্ডিনেট ব্যবহার করে। কেন্দ্র থেকে দূরত্ব (ব্যাসার্ধ) এবং কোণ দ্বারা প্রতিটি বিন্দুর অবস্থান নির্ধারণ করা হয়।

*   **কোড উদাহরণ:**
    ```python
    # একটি পোলার প্লটের জন্য ডেটা তৈরি
    theta = np.linspace(0, 2 * np.pi, 200) # 0 থেকে 360 ডিগ্রী পর্যন্ত কোণ
    r = 2 * (1 - np.cos(theta)) # কার্ডিওয়েড (Cardioid) আকৃতির জন্য সমীকরণ

    # একটি পোলার প্রজেকশনসহ সাবপ্লট তৈরি করা
    fig, ax = plt.subplots(subplot_kw={'projection': 'polar'})
    ax.plot(theta, r, color='purple')
    
    ax.set_title("পোলার কো-অর্ডিনেট প্লট (কার্ডিওয়েড)", va='bottom')
    plt.show()
    ```

### **৩. `ax.barpolar()` - পোলার বার চার্ট**

*   **কখন ব্যবহার করা হয়?** এটি একটি বার চার্টের মতোই, কিন্তু বারগুলো একটি বৃত্তের চারপাশে সাজানো থাকে। এটি দিকনির্ভর ডেটার ফ্রিকোয়েন্সি দেখানোর জন্য চমৎকার, যেমন: "উইন্ড রোজ" (wind rose) যা বিভিন্ন দিক থেকে বাতাসের গতি বা তীব্রতা দেখায়।

*   **মূল ধারণা:** এখানে প্রতিটি বারের অবস্থান একটি কোণ দ্বারা এবং বারের উচ্চতা বা দৈর্ঘ্য একটি ব্যাসার্ধ দ্বারা নির্ধারিত হয়। এটি `plt` এর সরাসরি ফাংশন নয়, বরং একটি `Axes` অবজেক্টের মেথড।

*   **কোড উদাহরণ (উইন্ড রোজ):**
    ```python
    # ৮টি দিকের জন্য বাতাসের গড় গতি (কিমি/ঘণ্টা)
    directions = np.array(['N', 'NE', 'E', 'SE', 'S', 'SW', 'W', 'NW'])
    wind_speed = np.array([15, 12, 8, 10, 18, 14, 11, 16])

    # কোণ তৈরি করা (প্রতি ৪৫ ডিগ্রী পর পর)
    theta = np.linspace(0, 2 * np.pi, len(directions), endpoint=False)
    
    fig, ax = plt.subplots(subplot_kw={'projection': 'polar'})
    ax.bar(theta, wind_speed, width=0.4, alpha=0.7) # width বারের প্রস্থ নির্ধারণ করে
    
    # লেবেলগুলো ঠিকমতো বসানো
    ax.set_xticks(theta)
    ax.set_xticklabels(directions)
    ax.set_theta_zero_location('N') # 'N' (উত্তর) দিককে ০ ডিগ্রীতে সেট করা
    ax.set_theta_direction(-1) # ঘড়ির কাঁটার দিকে দিকনির্দেশনা
    
    plt.title("উইন্ড রোজ - দিক অনুযায়ী বাতাসের গতি")
    plt.show()
    ```

### **৪. `plt.quiver()` - ভেক্টর ফিল্ড প্লট**

*   **কখন ব্যবহার করা হয়?** একটি ভেক্টর ফিল্ড (যেমন: চৌম্বক ক্ষেত্র, তড়িৎ ক্ষেত্র, বা তরলের প্রবাহ) ভিজ্যুয়ালাইজ করার জন্য। এটি একটি গ্রিডের বিভিন্ন বিন্দুতে ভেক্টরের দিক এবং মান (magnitude) দেখায়।

*   **মূল ধারণা:** একটি 2D গ্রিডের প্রতিটি (x, y) বিন্দুতে একটি করে তীর আঁকা হয়। তীরের দিক ভেক্টরের দিক নির্দেশ করে এবং তীরের দৈর্ঘ্য বা রঙ ভেক্টরের মান নির্দেশ করে।

*   **কোড উদাহরণ:**
    ```python
    x = np.arange(-2, 2.2, 0.2)
    y = np.arange(-2, 2.2, 0.2)
    X, Y = np.meshgrid(x, y)

    # ভেক্টর ফিল্ডের কম্পোনেন্ট (U, V)
    U = -Y # x-কম্পোনেন্ট
    V = X  # y-কম্পোনেন্ট (এটি একটি ঘূর্ণায়মান ফিল্ড তৈরি করে)

    plt.figure(figsize=(7, 7))
    plt.quiver(X, Y, U, V)
    
    plt.title("ভেক্টর ফিল্ডের কুইভার প্লট")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.show()
    ```

### **৫. `plt.streamplot()` - স্ট্রিমলাইন প্লট**

*   **কখন ব্যবহার করা হয়?** এটিও ভেক্টর ফিল্ড ভিজ্যুয়ালাইজ করার জন্য ব্যবহৃত হয়, তবে এটি প্রবাহের গতিপথ বা "স্ট্রিমলাইন" দেখানোর উপর বেশি জোর দেয়। এটি তরল বা বায়ুর প্রবাহ বোঝার জন্য `quiver` প্লটের চেয়ে বেশি কার্যকর।

*   **মূল ধারণা:** এটি ভেক্টর ফিল্ডের মধ্য দিয়ে কাল্পনিক কণার চলার পথ আঁকে। রেখাগুলো এমনভাবে আঁকা হয় যেন প্রতিটি বিন্দুতে ভেক্টর ফিল্ডের সাথে স্পর্শক (tangent) থাকে।

*   **কোড উদাহরণ:** (ডেটা `quiver`-এর উদাহরণ থেকে নেওয়া)
    ```python
    x = np.arange(-2, 2.2, 0.1)
    y = np.arange(-2, 2.2, 0.1)
    X, Y = np.meshgrid(x, y)
    U = -Y
    V = X

    plt.figure(figsize=(7, 7))
    plt.streamplot(X, Y, U, V, color=np.sqrt(U**2 + V**2), cmap='viridis') # রঙ প্রবাহের গতি নির্দেশ করে
    
    plt.title("ভেক্টর ফিল্ডের স্ট্রিমলাইন প্লট")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.show()
    ```

### **৬. `plt.hexbin()` - হেক্সাগোনাল বিনড স্ক্যাটার প্লট**

*   **কখন ব্যবহার করা হয়?** যখন স্ক্যাটার প্লটে অনেক বেশি ডেটা পয়েন্ট থাকে এবং সেগুলো একে অপরের উপর চলে আসে (overplotting), তখন ডেটার ঘনত্ব বোঝা কঠিন হয়ে যায়। `hexbin` প্লট এই সমস্যার সমাধান করে। এটি একটি 2D হিস্টোগ্রামের মতো কাজ করে।

*   **মূল ধারণা:** প্লট এলাকাটিকে ষড়ভুজাকৃতির (hexagonal) বিনে ভাগ করা হয়। প্রতিটি বিনে কতগুলো ডেটা পয়েন্ট পড়েছে, তা গণনা করা হয়। এরপর বিনের রঙ তার ভেতরের ডেটা পয়েন্টের সংখ্যার উপর ভিত্তি করে নির্ধারণ করা হয়। যেখানে ডেটা বেশি, সেখানকার রঙ গাঢ় হয়।

*   **কোড উদাহরণ:**
    ```python
    # অনেকগুলো র্যান্ডম ডেটা পয়েন্ট তৈরি করা
    x = np.random.randn(5000)
    y = 0.5 * x + np.random.randn(5000) / 2

    plt.figure(figsize=(8, 6))
    plt.hexbin(x, y, gridsize=30, cmap='inferno')
    
    cb = plt.colorbar(label='পয়েন্টের সংখ্যা')
    plt.title("হেক্সাগোনাল বিনড প্লট")
    plt.xlabel("ভ্যারিয়েবল ১")
    plt.ylabel("ভ্যারিয়েবল ২")
    plt.show()
    ```

```python
import matplotlib.pyplot as plt
import numpy as np

# 3D প্লটিং টুলকিট ইম্পোর্ট করা (পুরানো Matplotlib ভার্সনের জন্য আবশ্যক ছিল)
from mpl_toolkits.mplot3d import Axes3D
```

### **১. `ax.plot3D()` - ত্রিমাত্রিক লাইন প্লট**

*   **কখন ব্যবহার করা হয়?** ত্রিমাত্রিক (3D) স্থানে একটি পথ, রেখা বা বক্ররেখা দেখানোর জন্য। যেমন: একটি কণার গতিপথ, একটি হেলিক্সের আকৃতি, বা তিনটি ভ্যারিয়েবলের ধারাবাহিক সম্পর্ক।

*   **মূল ধারণা:** এটি তিনটি 1D অ্যারে (`x`, `y`, `z`) নেয় এবং প্রতিটি (`x[i]`, `y[i]`, `z[i]`) বিন্দুকে পর্যায়ক্রমে সরলরেখা দিয়ে সংযুক্ত করে।

*   **কোড উদাহরণ (একটি হেলিক্স):**
    ```python
    fig = plt.figure(figsize=(8, 6))
    ax = fig.add_subplot(111, projection='3d')

    # ডেটা তৈরি করা
    z = np.linspace(0, 15, 1000)
    x = np.sin(z)
    y = np.cos(z)

    ax.plot3D(x, y, z, 'blue')
    ax.set_title("ত্রিমাত্রিক লাইন প্লট (হেলিক্স)")
    ax.set_xlabel("X-অক্ষ")
    ax.set_ylabel("Y-অক্ষ")
    ax.set_zlabel("Z-অক্ষ")
    plt.show()
    ```

### **২. `ax.scatter3D()` - ত্রিমাত্রিক স্ক্যাটার প্লট**

*   **কখন ব্যবহার করা হয়?** তিনটি সংখ্যাসূচক ভ্যারিয়েবলের মধ্যে সম্পর্ক বা ডেটার বন্টন দেখানোর জন্য। যেমন: একটি ঘরে বিভিন্ন স্থানে তাপমাত্রা, চাপ এবং আর্দ্রতার মান।

*   **মূল ধারণা:** এটি তিনটি 1D অ্যারে (`x`, `y`, `z`) নেয় এবং প্রতিটি (`x[i]`, `y[i]`, `z[i]`) স্থানাঙ্কে একটি করে মার্কার বা বিন্দু স্থাপন করে। চতুর্থ একটি ভ্যারিয়েবল ব্যবহার করে বিন্দুর রঙ বা আকারও পরিবর্তন করা যায়।

*   **কোড উদাহরণ:**
    ```python
    fig = plt.figure(figsize=(8, 6))
    ax = fig.add_subplot(111, projection='3d')

    # র্যান্ডম ডেটা তৈরি করা
    n = 100
    x = np.random.rand(n)
    y = np.random.rand(n)
    z = np.random.rand(n)
    colors = z # z-মানের উপর ভিত্তি করে রঙ

    ax.scatter3D(x, y, z, c=colors, cmap='viridis')
    ax.set_title("ত্রিমাত্রিক স্ক্যাটার প্লট")
    ax.set_xlabel("X")
    ax.set_ylabel("Y")
    ax.set_zlabel("Z")
    plt.show()
    ```

### **৩. `ax.plot_surface()` - ত্রিমাত্রিক সারফেস প্লট**

*   **কখন ব্যবহার করা হয়?** একটি ফাংশন `z = f(x, y)` দ্বারা সংজ্ঞায়িত একটি পৃষ্ঠতল (surface) ভিজ্যুয়ালাইজ করার জন্য। যেমন: একটি পাহাড়ের ভূসংস্থান, গাণিতিক ফাংশনের গ্রাফ, বা মেশিন লার্নিং মডেলের রেসপন্স সারফেস।

*   **মূল ধারণা:** এটি তিনটি 2D অ্যারে (`X`, `Y`, `Z`) নেয়, যা একটি গ্রিড তৈরি করে। `X` এবং `Y` হলো গ্রিডের স্থানাঙ্ক (সাধারণত `np.meshgrid` দিয়ে তৈরি) এবং `Z` হলো প্রতিটি (`X`, `Y`) বিন্দুতে পৃষ্ঠের উচ্চতা। এটি এই গ্রিড বিন্দুগুলোকে রঙিন বহুভুজ দিয়ে সংযুক্ত করে একটি মসৃণ পৃষ্ঠ তৈরি করে।

*   **কোড উদাহরণ:**
    ```python
    fig = plt.figure(figsize=(9, 7))
    ax = fig.add_subplot(111, projection='3d')

    x = np.arange(-5, 5, 0.25)
    y = np.arange(-5, 5, 0.25)
    X, Y = np.meshgrid(x, y)
    Z = np.sin(np.sqrt(X**2 + Y**2))

    ax.plot_surface(X, Y, Z, cmap='plasma')
    ax.set_title("ত্রিমাত্রিক সারফেস প্লট")
    plt.show()
    ```

### **৪. `ax.plot_wireframe()` - ত্রিমাত্রিক ওয়্যারফ্রেম প্লট**

*   **কখন ব্যবহার করা হয়?** এটি `plot_surface()`-এর মতোই, কিন্তু এটি পৃষ্ঠতলকে ভরাট না করে শুধুমাত্র গ্রিডের রেখাগুলো (তারের কাঠামো) দেখায়। এটি পৃষ্ঠের গঠন বুঝতে সাহায্য করে এবং পৃষ্ঠের পেছনের অংশ দেখতে দেয়।

*   **মূল ধারণা:** এটি সারফেস প্লটের মতো রঙিন বহুভুজ না এঁকে, গ্রিড বিন্দুগুলোকে সংযোগকারী রেখাগুলো আঁকে।

*   **কোড উদাহরণ:** (ডেটা `plot_surface()`-এর উদাহরণ থেকে নেওয়া)
    ```python
    fig = plt.figure(figsize=(9, 7))
    ax = fig.add_subplot(111, projection='3d')

    x = np.arange(-5, 5, 0.25)
    y = np.arange(-5, 5, 0.25)
    X, Y = np.meshgrid(x, y)
    Z = np.sin(np.sqrt(X**2 + Y**2))

    ax.plot_wireframe(X, Y, Z, color='green')
    ax.set_title("ত্রিমাত্রিক ওয়্যারফ্রেম প্লট")
    plt.show()
    ```

### **৫. `ax.contour3D()` - ত্রিমাত্রিক কন্ট্যুর প্লট**

*   **কখন ব্যবহার করা হয়?** এটি একটি 3D পৃষ্ঠকে 2D কন্ট্যুর লাইনের মাধ্যমে 3D স্পেসে দেখায়। প্রতিটি কন্ট্যুর লাইন একটি নির্দিষ্ট উচ্চতায় (Z-মান) থাকে।

*   **মূল ধারণা:** এটি 2D `contour()` প্লটের মতোই, কিন্তু লাইনগুলো তাদের নিজ নিজ Z-উচ্চতায় আঁকা হয়, যা একটি "স্তুপীকৃত" কন্ট্যুর ম্যাপের মতো দেখায়।

*   **কোড উদাহরণ:** (ডেটা `plot_surface()`-এর উদাহরণ থেকে নেওয়া)
    ```python
    fig = plt.figure(figsize=(9, 7))
    ax = fig.add_subplot(111, projection='3d')

    x = np.arange(-5, 5, 0.25)
    y = np.arange(-5, 5, 0.25)
    X, Y = np.meshgrid(x, y)
    Z = np.sin(np.sqrt(X**2 + Y**2))

    ax.contour3D(X, Y, Z, 50, cmap='viridis') # 50 হলো কন্ট্যুর লাইনের সংখ্যা
    ax.set_title("ত্রিমাত্রিক কন্ট্যুর প্লট")
    plt.show()
    ```

### **৬. `ax.bar3d()` - ত্রিমাত্রিক বার চার্ট**

*   **কখন ব্যবহার করা হয়?** দুটি ক্যাটাগরিক্যাল ভ্যারিয়েবলের উপর ভিত্তি করে একটি সংখ্যাসূচক মান দেখানোর জন্য। এটি একটি 2D বার চার্টের ত্রিমাত্রিক সংস্করণ। তবে এটি পড়া কঠিন হতে পারে, কারণ পেছনের বারগুলো সামনের বার দ্বারা ঢাকা পড়ে যেতে পারে।

*   **মূল ধারণা:** প্রতিটি বারের অবস্থান (`x`, `y`, `z`) এবং আকার (`dx`, `dy`, `dz`) নির্দিষ্ট করতে হয়। `x`, `y` বারের অবস্থান, `z` বারের ভিত্তি, এবং `dz` বারের উচ্চতা নির্দেশ করে।

*   **কোড উদাহরণ:**
    ```python
    fig = plt.figure(figsize=(9, 7))
    ax = fig.add_subplot(111, projection='3d')

    xpos = [1, 2, 3, 4]
    ypos = [1, 2, 3, 4]
    zpos = np.zeros(4)
    dx = np.ones(4) * 0.5
    dy = np.ones(4) * 0.5
    dz = [5, 3, 8, 6] # বারের উচ্চতা

    ax.bar3d(xpos, ypos, zpos, dx, dy, dz, color=['r', 'g', 'b', 'y'])
    ax.set_title("ত্রিমাত্রিক বার চার্ট")
    plt.show()
    ```

### **৭. `ax.text3D()` - ত্রিমাত্রিক টেক্সট অ্যানোটেশন**

*   **কখন ব্যবহার করা হয়?** 3D প্লটের মধ্যে কোনো নির্দিষ্ট বিন্দু বা এলাকাকে চিহ্নিত করার জন্য টেক্সট বা লেবেল যোগ করতে।

*   **মূল ধারণা:** এটি `ax.text()`-এর 3D সংস্করণ। আপনাকে টেক্সটের জন্য একটি (`x`, `y`, `z`) স্থানাঙ্ক এবং টেক্সট স্ট্রিংটি সরবরাহ করতে হবে।

*   **কোড উদাহরণ:**
    ```python
    fig = plt.figure(figsize=(8, 6))
    ax = fig.add_subplot(111, projection='3d')

    ax.scatter3D([1], [1], [1], s=100, color='red') # একটি বিন্দু প্লট করা
    
    # বিন্দুটির পাশে একটি লেবেল যোগ করা
    ax.text3D(1.1, 1.1, 1.1, "গুরুত্বপূর্ণ বিন্দু", color='red')

    ax.set_title("ত্রিমাত্রিক টেক্সট অ্যানোটেশন")
    ax.set_xlim(0, 2)
    ax.set_ylim(0, 2)
    ax.set_zlim(0, 2)
    plt.show()
    ```

### **১. `plt.imshow()` - ইমেজ বা 2D অ্যারে প্রদর্শন**

*   **কখন ব্যবহার করা হয়?** এটি একটি 2D ডেটা অ্যারে, ম্যাট্রিক্স বা ছবিকে একটি ইমেজ হিসেবে দেখানোর জন্য ব্যবহৃত হয়। প্রতিটি সেলের মান একটি নির্দিষ্ট রঙ দ্বারা প্রকাশ করা হয়। এটি হিটম্যাপ, কোরিলেশন ম্যাট্রিক্স এবং ইমেজ প্রসেসিং-এর জন্য অত্যন্ত জনপ্রিয়।

*   **মূল ধারণা:** ডেটা ম্যাট্রিক্সের প্রতিটি সেলকে একটি পিক্সেল বা রঙিন বর্গ হিসেবে দেখানো হয়। সেলের সংখ্যাসূচক মানের উপর ভিত্তি করে একটি কালারম্যাপ (`cmap`) থেকে রঙ নির্বাচন করা হয়।

*   **কোড উদাহরণ:**
    ```python
    # একটি 5x5 র্যান্ডম ম্যাট্রিক্স তৈরি করা
    data = np.random.rand(5, 5)

    plt.figure(figsize=(6, 5))
    plt.imshow(data, cmap='hot') # 'hot' কালারম্যাপ ব্যবহার করা হচ্ছে
    
    plt.colorbar(label='মানের তীব্রতা') # কালারবার যোগ করা
    plt.title("imshow() ব্যবহার করে হিটম্যাপ")
    plt.show()
    ```

### **২. `plt.text()` - টেক্সট যোগ করা**

*   **কখন ব্যবহার করা হয়?** প্লটের যেকোনো স্থানে (arbitrary position) কোনো টেক্সট বা লেখা যোগ করার জন্য এটি ব্যবহার করা হয়। এটি কোনো নির্দিষ্ট ডেটা পয়েন্টকে লেবেল করতে বা প্লটের মধ্যে অতিরিক্ত তথ্য যোগ করতে কাজে লাগে।

*   **মূল ধারণা:** আপনাকে টেক্সটের জন্য একটি `(x, y)` স্থানাঙ্ক এবং টেক্সট স্ট্রিংটি সরবরাহ করতে হবে। স্থানাঙ্কগুলো ডেটা অক্ষের সাপেক্ষে নির্ধারিত হয়।

*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(0, 10, 100)
    y = np.sin(x)

    plt.figure(figsize=(8, 5))
    plt.plot(x, y)
    
    # প্লটের (5, 0.5) অবস্থানে একটি টেক্সট যোগ করা
    plt.text(5, 0.5, 'এটি একটি গুরুত্বপূর্ণ এলাকা', fontsize=12, color='red')
    
    plt.title("text() ফাংশনের ব্যবহার")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.grid(True)
    plt.show()
    ```

### **৩. `plt.annotate()` - তীরসহ অ্যানোটেশন যোগ করা**

*   **কখন ব্যবহার করা হয়?** যখন আপনি প্লটের কোনো নির্দিষ্ট বিন্দুকে বিশেষভাবে চিহ্নিত করতে চান এবং সে সম্পর্কে কোনো লেখা যোগ করতে চান, তখন `annotate()` ব্যবহার করা হয়। এর সবচেয়ে বড় সুবিধা হলো এটি লেখা থেকে নির্দিষ্ট বিন্দু পর্যন্ত একটি তীর আঁকতে পারে।

*   **মূল ধারণা:** এর দুটি প্রধান প্যারামিটার হলো:
    *   `xy`: যে বিন্দুটিকে নির্দেশ করা হবে তার স্থানাঙ্ক।
    *   `xytext`: টেক্সটটি যেখানে থাকবে তার স্থানাঙ্ক।
    *   `arrowprops`: তীরের স্টাইল নির্ধারণ করার জন্য একটি ডিকশনারি।

*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(0, 2 * np.pi, 100)
    y = np.sin(x)

    plt.figure(figsize=(8, 5))
    plt.plot(x, y)
    
    # সাইন ওয়েভের সর্বোচ্চ বিন্দুটিকে অ্যানোটেট করা
    peak_x = np.pi / 2
    peak_y = np.sin(peak_x)
    
    plt.annotate('সর্বোচ্চ বিন্দু',
                 xy=(peak_x, peak_y),            # তীরের মাথা যেখানে থাকবে
                 xytext=(peak_x + 1, peak_y + 0.3), # টেক্সট যেখানে থাকবে
                 arrowprops=dict(facecolor='black', shrink=0.05))
    
    plt.title("annotate() ফাংশনের ব্যবহার")
    plt.show()
    ```

### **৪. `plt.title()` - প্লটের টাইটেল সেট করা**

*   **কখন ব্যবহার করা হয়?** প্লটটি কী সম্পর্কে, তা বোঝানোর জন্য একটি শিরোনাম বা টাইটেল যোগ করতে এটি ব্যবহার করা হয়। একটি ভালো টাইটেল প্লটকে স্বয়ংসম্পূর্ণ করে তোলে।

*   **মূল ধারণা:** এটি প্লটের উপরের অংশে একটি টেক্সট স্ট্রিং যোগ করে। `fontsize`, `fontweight`, `color` ইত্যাদি প্যারামিটার দিয়ে টাইটেলের স্টাইল পরিবর্তন করা যায়।

*   **কোড উদাহরণ:**
    ```python
    x = [1, 2, 3, 4]
    y = [10, 20, 15, 25]

    plt.figure(figsize=(8, 5))
    plt.bar(x, y)
    
    plt.title("মাসিক ডেটার বার চার্ট", fontsize=16, fontweight='bold', color='navy')
    plt.show()
    ```

### **৫. `plt.xlabel()` / `plt.ylabel()` - অক্ষের লেবেল যোগ করা**

*   **কখন ব্যবহার করা হয়?** X-অক্ষ এবং Y-অক্ষ কী ডেটা উপস্থাপন করছে, তা বোঝানোর জন্য লেবেল যোগ করতে এই ফাংশন দুটি ব্যবহার করা হয়। লেবেল ছাড়া একটি প্লট প্রায়শই অর্থহীন।

*   **মূল ধারণা:** `plt.xlabel()` X-অক্ষের জন্য এবং `plt.ylabel()` Y-অক্ষের জন্য লেবেল সেট করে।

*   **কোড উদাহরণ:**

    ```python
    x = np.linspace(0, 100, 50)

    plt.title("একটি রৈখিক সম্পর্ক")
    
    plt.xlabel("সময় (সেকেন্ড)", fontsize=12)
    plt.ylabel("দূরত্ব (মিটার)", fontsize=12)
    plt.show()
    ```

### **৬. `plt.legend()` - লিজেন্ড যোগ করা**

*   **কখন ব্যবহার করা হয়?** যখন একটি প্লটে একাধিক ডেটা সিরিজ (যেমন: একাধিক লাইন, বার গ্রুপ, বা স্ক্যাটার গ্রুপ) থাকে, তখন কোনটি কী নির্দেশ করছে তা দেখানোর জন্য একটি লিজেন্ড বক্স যোগ করা হয়।

*   **মূল ধারণা:** প্লটিং ফাংশনগুলোতে (`plot`, `bar` ইত্যাদি) `label` প্যারামিটার ব্যবহার করে প্রতিটি ডেটা সিরিজের জন্য একটি নাম দিতে হয়। এরপর `plt.legend()` কল করলে Matplotlib স্বয়ংক্রিয়ভাবে সেই লেবেলগুলো দিয়ে একটি লিজেন্ড বক্স তৈরি করে।

*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(0, 2 * np.pi, 100)
    y1 = np.sin(x)
    y2 = np.cos(x)

    plt.figure(figsize=(8, 5))
    plt.plot(x, y1, label='Sine')
    plt.plot(x, y2, label='Cosine')
    
    plt.title("Sine এবং Cosine ওয়েভ")
    plt.xlabel("রেডিয়ান")
    plt.ylabel("মান")
    plt.legend(loc='upper right') # লিজেন্ডের অবস্থান নির্ধারণ
    plt.grid(True)
    plt.show()
    ```

### **৭. `plt.colorbar()` - কালার স্কেল বার যোগ করা**

*   **কখন ব্যবহার করা হয়?** যখন প্লটে রঙ ব্যবহার করে কোনো তৃতীয় মাত্রার ডেটা দেখানো হয় (যেমন: হিটম্যাপ, কন্ট্যুর প্লট, বা স্ক্যাটার প্লট যেখানে বিন্দুর রঙ তার মান নির্দেশ করে), তখন কোন রঙ কী মান নির্দেশ করছে তা দেখানোর জন্য একটি কালারবার যোগ করা হয়।

*   **মূল ধারণা:** এটি একটি স্কেল তৈরি করে যা রঙ এবং সংখ্যাসূচক মানের মধ্যে ম্যাপিং দেখায়। এটি সাধারণত `imshow`, `scatter`, `contourf` এর মতো ফাংশনের রিটার্ন করা অবজেক্টকে ইনপুট হিসেবে নেয়।

*   **কোড উদাহরণ:**
    ```python
    x = np.random.rand(100)
    y = np.random.rand(100)
    colors = np.random.rand(100) # প্রতিটি বিন্দুর জন্য একটি র্যান্ডম মান
    sizes = 1000 * np.random.rand(100)

    plt.figure(figsize=(8, 6))
    scatter_plot = plt.scatter(x, y, c=colors, s=sizes, alpha=0.7, cmap='viridis')
    
    # স্ক্যাটার প্লট থেকে কালারবার তৈরি করা
    plt.colorbar(scatter_plot, label='মানের তীব্রতা')
    
    plt.title("রঙ এবং আকারসহ স্ক্যাটার প্লট")
    plt.show()
    ```

8. Figure and Subplot Management

|Function|Description|
|---|---|
|`plt.figure()`|Create a new figure|
|`plt.subplot()`|Create a single subplot|
|`plt.subplots()`|Create figure + multiple subplots|
|`plt.tight_layout()`|Adjust spacing automatically|
|`plt.subplots_adjust()`|Manually adjust layout spacing|
|`plt.savefig()`|Save the figure as an image/PDF|
|`plt.show()`|Display the plot window|
অবশ্যই! আপনার দেওয়া টেবিল অনুযায়ী Matplotlib-এর এই ইউটিলিটি ফাংশনগুলোর বিস্তারিত আলোচনা নিচে কোডসহ দেওয়া হলো। এই ফাংশনগুলো সরাসরি কোনো ডেটা প্লট করে না, কিন্তু প্লট তৈরি, বিন্যাস এবং প্রদর্শন ও সংরক্ষণের জন্য অপরিহার্য।

```python
import matplotlib.pyplot as plt
```

### **১. `plt.figure()` - নতুন ফিগার তৈরি করা**

*   **কখন ব্যবহার করা হয়?** যখন আপনি একটি নতুন প্লটিং উইন্ডো বা ক্যানভাস তৈরি করতে চান, তখন `plt.figure()` ব্যবহার করা হয়। প্রতিটি ফিগার একাধিক প্লট (Axes) ধারণ করতে পারে। আপনি এর মাধ্যমে প্লটের আকার, রেজোলিউশন (dpi) এবং অন্যান্য বৈশিষ্ট্য নিয়ন্ত্রণ করতে পারেন।

*   **মূল ধারণা:** এটি একটি `Figure` অবজেক্ট তৈরি করে, যা সব প্লট উপাদানের জন্য একটি ধারক হিসেবে কাজ করে। যদিও `plt.plot()`-এর মতো ফাংশনগুলো প্রয়োজন হলে স্বয়ংক্রিয়ভাবে একটি ফিগার তৈরি করে, তবে কাস্টমাইজেশনের জন্য এটি নিজে থেকে তৈরি করা ভালো অভ্যাস।

*   **কোড উদাহরণ:**
    ```python
    # 10 ইঞ্চি চওড়া এবং 4 ইঞ্চি লম্বা একটি ফিগার তৈরি করা
    fig = plt.figure(figsize=(10, 4))
    
    # এই ফিগারের মধ্যে একটি প্লট তৈরি করা
    x = [1, 2, 3]
    y = [4, 5, 6]
    plt.plot(x, y)
    
    plt.title("একটি কাস্টম আকারের ফিগার")
    plt.show()
    ```

### **২. `plt.subplot()` - একটি একক সাবপ্লট তৈরি করা**

*   **কখন ব্যবহার করা হয়?** এটি একটি ফিগারের মধ্যে একটি গ্রিড কল্পনা করে এবং সেই গ্রিডের একটি নির্দিষ্ট স্থানে একটি সাবপ্লট (Axes) তৈরি এবং সক্রিয় করে। এটি একাধিক প্লট পাশাপাশি দেখানোর জন্য ব্যবহৃত হয়। এটি একটি পুরানো এবং "স্টেট-ফুল" পদ্ধতি।

*   **মূল ধারণা:** `plt.subplot(rows, cols, index)`—এই ফাংশনটি তিনটি আর্গুমেন্ট নেয়।
    *   `rows`: গ্রিডে মোট সারির সংখ্যা।
    *   `cols`: গ্রিডে মোট কলামের সংখ্যা।
    *   `index`: আপনি কোন সাবপ্লটটি সক্রিয় করতে চান (১ থেকে শুরু হয়)।

*   **কোড উদাহরণ:**
    ```python
    plt.figure(figsize=(10, 4))

    # 1x2 গ্রিডের প্রথম সাবপ্লট
    plt.subplot(1, 2, 1)
    plt.plot([1, 2, 3], [1, 4, 9], 'r-')
    plt.title("প্রথম সাবপ্লট")

    # 1x2 গ্রিডের দ্বিতীয় সাবপ্লট
    plt.subplot(1, 2, 2)
    plt.plot([1, 2, 3], [9, 4, 1], 'g--')
    plt.title("দ্বিতীয় সাবপ্লট")

    plt.show()
    ```

### **৩. `plt.subplots()` - ফিগার এবং একাধিক সাবপ্লট তৈরি করা**

*   **কখন ব্যবহার করা হয়?** এটি `plt.subplot()`-এর একটি আধুনিক, শক্তিশালী এবং বহুল ব্যবহৃত বিকল্প। এটি একবারে একটি `Figure` এবং প্রয়োজনীয় সংখ্যক `Axes` (সাবপ্লট) অবজেক্ট তৈরি করে দেয়। এটি অবজেক্ট-ওরিয়েন্টেড পদ্ধতিতে কাজ করার জন্য আদর্শ।

*   **মূল ধারণা:** `fig, ax = plt.subplots(rows, cols)`—এই ফাংশনটি দুটি জিনিস রিটার্ন করে:
    *   `fig`: সম্পূর্ণ `Figure` অবজেক্ট।
    *   `ax` বা `axs`: একটি বা একাধিক `Axes` অবজেক্ট। যদি একটি সাবপ্লট থাকে, তবে `ax` একটি একক অবজেক্ট হয়। একাধিক সাবপ্লট থাকলে, `axs` একটি NumPy অ্যারে হয়, যা থেকে আপনি প্রতিটি সাবপ্লটকে অ্যাক্সেস করতে পারেন (`axs[0, 1]`)।

*   **কোড উদাহরণ:**
    ```python
    # 2x2 গ্রিডসহ একটি ফিগার ও সাবপ্লট তৈরি
    fig, axs = plt.subplots(2, 2, figsize=(8, 8))

    # প্রথম সাবপ্লটে প্লট করা
    axs[0, 0].plot([1, 2], [1, 2], 'blue')
    axs[0, 0].set_title('উপর-বাম')

    # দ্বিতীয় সাবপ্লটে প্লট করা
    axs[0, 1].scatter([1, 2], [2, 1], color='red')
    axs[0, 1].set_title('উপর-ডান')

    # তৃতীয় সাবপ্লটে প্লট করা
    axs[1, 0].bar(['A', 'B'], [10, 15])
    axs[1, 0].set_title('নিচ-বাম')

    # চতুর্থ সাবপ্লটটি খালি রাখা
    axs[1, 1].text(0.5, 0.5, 'খালি', ha='center', va='center')
    axs[1, 1].set_title('নিচ-ডান')

    plt.show()
    ```

### **৪. `plt.tight_layout()` - স্বয়ংক্রিয়ভাবে স্পেসিং ঠিক করা**

*   **কখন ব্যবহার করা হয়?** যখন সাবপ্লটগুলোর টাইটেল, লেবেল বা অন্যান্য উপাদান একে অপরের উপর চলে আসে (overlap), তখন এই ফাংশনটি স্বয়ংক্রিয়ভাবে সাবপ্লটগুলোর মধ্যেকার ফাঁকা জায়গা এমনভাবে সামঞ্জস্য করে যাতে সবকিছু সুন্দরভাবে ফিট হয়ে যায়।

*   **মূল ধারণা:** এটি একটি "ম্যাজিক" ফাংশনের মতো কাজ করে যা লেআউটকে পরিচ্ছন্ন করার চেষ্টা করে। সাধারণত প্লট প্রদর্শনের (`plt.show()`) ঠিক আগে এটি কল করা হয়।

*   **কোড উদাহরণ:**
    ```python
    fig, axs = plt.subplots(2, 1)

    axs[0].plot(np.random.rand(10))
    axs[0].set_title("একটি লম্বা টাইটেল যা প্রায় লেবেলের উপর চলে যায়")
    axs[0].set_ylabel("প্রথম প্লটের Y-লেবেল")

    axs[1].plot(np.random.rand(10))
    axs[1].set_xlabel("দ্বিতীয় প্লটের X-লেবেল")

    # এই লাইনটি ছাড়া টাইটেল এবং লেবেল ওভারল্যাপ করতে পারে
    plt.tight_layout()
    plt.show()
    ```

### **৫. `plt.subplots_adjust()` - ম্যানুয়ালি লেআউট স্পেসিং ঠিক করা**

*   **কখন ব্যবহার করা হয়?** যখন `plt.tight_layout()` আপনার প্রয়োজন অনুযায়ী কাজ করে না এবং আপনার সাবপ্লটগুলোর মধ্যেকার ফাঁকা জায়গার উপর সূক্ষ্ম নিয়ন্ত্রণ প্রয়োজন হয়, তখন এটি ব্যবহার করা হয়।

*   **মূল ধারণা:** এটি আপনাকে `left`, `right`, `bottom`, `top`, `wspace` (width space), এবং `hspace` (height space) এর মতো প্যারামিটার ব্যবহার করে সাবপ্লটগুলোর মধ্যে এবং ফিগারের মার্জিনের সাথে দূরত্ব নির্ধারণ করতে দেয়।

*   **কোড উদাহরণ:**
    ```python
    fig, axs = plt.subplots(2, 2, figsize=(6, 6))

    for ax in axs.flat:
        ax.text(0.5, 0.5, 'সাবপ্লট', ha='center', va='center')
        ax.set_xticks([])
        ax.set_yticks([])

    # সাবপ্লটগুলোর মধ্যে অনুভূমিক এবং উল্লম্ব ফাঁকা জায়গা বাড়ানো
    plt.subplots_adjust(hspace=0.5, wspace=0.5)

    plt.suptitle("ম্যানুয়ালি সামঞ্জস্য করা লেআউট")
    plt.show()
    ```

### **৬. `plt.savefig()` - ফিগার সেভ করা**

*   **কখন ব্যবহার করা হয়?** আপনার তৈরি করা প্লটটিকে একটি ইমেজ ফাইল (যেমন: PNG, JPG) বা ভেক্টর ফাইল (যেমন: PDF, SVG) হিসেবে সংরক্ষণ করার জন্য।

*   **মূল ধারণা:** প্রথম আর্গুমেন্ট হিসেবে ফাইলের নাম এবং এক্সটেনশন দিতে হয়। `dpi` (dots per inch) প্যারামিটার দিয়ে ইমেজের রেজোলিউশন নিয়ন্ত্রণ করা যায়। `plt.show()` কল করার *আগে* এটি ব্যবহার করা ভালো অভ্যাস, কারণ `show()` অনেক সময় ফিগারটিকে রিসেট করে দেয়।

*   **কোড উদাহরণ:**
    ```python
    x = [1, 2, 3]
    y = [1, 4, 9]

    plt.plot(x, y)
    plt.title("আমার সুন্দর প্লট")

    # প্লটটিকে 'my_plot.png' নামে সেভ করা
    plt.savefig('my_plot.png', dpi=300, bbox_inches='tight')

    # এরপর প্লটটি দেখানো
    plt.show()
    ```

### **৭. `plt.show()` - প্লট প্রদর্শন করা**

*   **কখন ব্যবহার করা হয়?** এটি চূড়ান্ত ধাপ। যখন আপনার প্লট তৈরি, লেবেল করা এবং কাস্টমাইজ করা শেষ, তখন `plt.show()` কল করলে Matplotlib একটি গ্রাফিকাল উইন্ডোতে প্লটটি প্রদর্শন করে।

*   **মূল ধারণা:** এটি Matplotlib-এর GUI ইভেন্ট লুপ শুরু করে এবং আপনার তৈরি করা সমস্ত ফিগার উইন্ডো দেখায়। একটি স্ক্রিপ্টে, এই ফাংশনটি কল করার পর স্ক্রিপ্টটি সাময়িকভাবে থেমে যায় যতক্ষণ না আপনি প্লট উইন্ডোটি বন্ধ করেন। Jupyter Notebook-এ এটি সাধারণত সেলের আউটপুটে প্লটটি রেন্ডার করে।

*   **কোড উদাহরণ:**
    ```python
    x = np.linspace(0, 10, 100)
    y = np.cos(x)

    plt.plot(x, y)
    plt.title("Cosine Wave")

    # সমস্ত সেটিংস শেষ হলে প্লটটি দেখাও
    plt.show()
    ```
