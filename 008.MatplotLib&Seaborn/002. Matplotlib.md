### **Matplotlib পরিচিতি (Introduction to Matplotlib)**

Matplotlib হলো Python প্রোগ্রামিং ল্যাঙ্গুয়েজের জন্য একটি অত্যন্ত শক্তিশালী এবং জনপ্রিয় ডেটা ভিজ্যুয়ালাইজেশন (Data Visualization) লাইব্রেরি। এর সাহায্যে ডেটাগুলোকে বিভিন্ন ধরনের গ্রাফ, চার্ট, এবং প্লটের মাধ্যমে সুন্দরভাবে উপস্থাপন করা যায়। এটিকে ডেটার জন্য একটি ডিজিটাল ক্যানভাস বা অঙ্কন বোর্ড হিসেবে ভাবতে পারেন, যেখানে আপনি আপনার প্রয়োজন মতো যেকোনো চিত্র তৈরি করতে পারেন।

এর মূল উদ্দেশ্য হলো ডেটার মধ্যে থাকা প্যাটার্ন, ট্রেন্ড এবং সম্পর্কগুলোকে সহজে বোঝার জন্য ভিজ্যুয়াল রূপ দেওয়া।

### **Matplotlib-এর মূল গঠন (Anatomy of a Matplotlib Plot)**

Matplotlib কিভাবে কাজ করে তা বুঝতে হলে এর মূল উপাদানগুলো সম্পর্কে জানা জরুরি। একটি Matplotlib প্লট কয়েকটি স্তরে বিভক্ত।

1.  **Figure (ফিগার):**
    *   এটি হলো সম্পূর্ণ উইন্ডো বা ক্যানভাস যেখানে সবকিছু আঁকা হয়। একটি Figure-এর মধ্যে এক বা একাধিক প্লট (Axes) থাকতে পারে। এটিকে আপনি একটি ছবির ফ্রেমের মতো ভাবতে পারেন।

2.  **Axes (অ্যাক্সেস):**
    *   এটি হলো Figure-এর ভেতরের আসল প্লট এরিয়া, যেখানে ডেটা পয়েন্টগুলো প্লট করা হয়। একটি Figure-এ একটি Axes থাকতে পারে (সাধারণ প্লটের ক্ষেত্রে) অথবা একাধিক Axes থাকতে পারে (Subplots-এর ক্ষেত্রে)। প্রতিটি Axes-এর নিজস্ব X-অক্ষ (X-axis) এবং Y-অক্ষ (Y-axis) থাকে। এটিকে ফ্রেমের ভেতরের ছবি হিসেবে ভাবতে পারেন।

3.  **Axis (অ্যাক্সিস):**
    *   এগুলো হলো X-অক্ষ এবং Y-অক্ষ, যা প্লটের স্কেল বা সীমা নির্ধারণ করে। এগুলোর ওপর সংখ্যা বা লেবেল থাকে, যেগুলোকে "ticks" বলা হয়।

4.  **Artist (আর্টিস্ট):**
    *   Matplotlib-এ যা কিছু আপনি দেখেন (যেমন - Figure, Axes, লেখা, লাইন ইত্যাদি), তার সবকিছুই একটি Artist অবজেক্ট। যখন `plt.show()` কল করা হয়, তখন এই সমস্ত Artist অবজেক্টগুলো ক্যানভাসে আঁকা হয়।

### **Matplotlib ব্যবহারের দুটি প্রধান উপায়**

Matplotlib ব্যবহার করার দুটি প্রধান পদ্ধতি আছে, এবং এটি জানা খুব গুরুত্বপূর্ণ।

#### **১. Pyplot Interface (State-based Interface)**

এটি Matplotlib ব্যবহারের সবচেয়ে সহজ এবং দ্রুত পদ্ধতি। যারা MATLAB ব্যবহার করেছেন, তাদের জন্য এটি খুবই পরিচিত মনে হবে। এই পদ্ধতিতে, Matplotlib নিজে থেকেই Figure এবং Axes তৈরি ও পরিচালনা করে।

*   **কিভাবে কাজ করে:** আপনি `plt` মডিউল ব্যবহার করে সরাসরি কমান্ড দেন (যেমন `plt.plot()`, `plt.title()`)। Matplotlib "মনে রাখে" আপনি কোন Figure এবং Axes-এ কাজ করছেন এবং সেই অনুযায়ী পরিবর্তন করে। ছোট এবং দ্রুত প্লট তৈরির জন্য এটি খুবই কার্যকরী।

*   **উদাহরণ:**
    ```python
    import matplotlib.pyplot as plt

    # ডেটা তৈরি
    x = [1, 2, 3, 4]
    y = [10, 20, 25, 30]

    # প্লট তৈরি
    plt.plot(x, y)
    plt.title("একটি সাধারণ প্লট")
    plt.xlabel("X-অক্ষ")
    plt.ylabel("Y-অক্ষ")
    plt.show() # প্লটটি দেখাও
    ```

#### **২. Object-Oriented (OO) Interface**

এটি আরও শক্তিশালী এবং নিয়ন্ত্রিত পদ্ধতি। জটিল প্লট, একাধিক সাব-প্লট অথবা প্লটের প্রতিটি উপাদানের ওপর সূক্ষ্ম নিয়ন্ত্রণ রাখার জন্য এই পদ্ধতি ব্যবহার করা হয়।

*   **কিভাবে কাজ করে:** এই পদ্ধতিতে, আপনি প্রথমে `Figure` এবং `Axes` অবজেক্ট তৈরি করেন। তারপর সেই অবজেক্টগুলোর মেথড (method) কল করে প্লট তৈরি ও কাস্টমাইজ করেন। যেমন `ax.plot()` বা `ax.set_title()`।

*   **উদাহরণ:**
    ```python
    import matplotlib.pyplot as plt

    # ডেটা তৈরি
    x = [1, 2, 3, 4]
    y = [10, 20, 25, 30]

    # Figure এবং Axes অবজেক্ট তৈরি
    fig, ax = plt.subplots()

    # Axes অবজেক্টের উপর প্লট তৈরি
    ax.plot(x, y)
    ax.set_title("অবজেক্ট-ভিত্তিক প্লট")
    ax.set_xlabel("X-অক্ষ")
    ax.set_ylabel("Y-অক্ষ")
    plt.show() # প্লটটি দেখাও
    ```
**পার্থক্য:** Pyplot ইন্টারফেসে `plt.` দিয়ে ফাংশন কল করা হয়, আর OO ইন্টারফেসে `ax.` (Axes অবজেক্ট) দিয়ে মেথড কল করা হয়। বড় এবং জটিল প্রজেক্টের জন্য Object-Oriented পদ্ধতিটি বেশি পছন্দের।

### **একটি প্লট তৈরির সাধারণ ধাপ (Steps to Create a Plot)**

যেকোনো ধরনের প্লট তৈরি করতে সাধারণত নিচের ধাপগুলো অনুসরণ করা হয়:

1.  **লাইব্রেরি ইম্পোর্ট:** প্রথমে Matplotlib-এর `pyplot` মডিউলটি ইম্পোর্ট করা হয়। সাধারণত `plt` নামে এটিকে ইম্পোর্ট করা হয়।
    ```python
    import matplotlib.pyplot as plt
    import numpy as np # সাধারণত ডেটা তৈরির জন্য NumPy ব্যবহার করা হয়
    ```

2.  **ডেটা তৈরি/প্রস্তুত:** যে ডেটা দিয়ে প্লট তৈরি করতে চান, তা প্রস্তুত করুন। এটি লিস্ট, NumPy array বা Pandas DataFrame হতে পারে।
    ```python
    x = np.linspace(0, 10, 100)
    y = np.sin(x)
    ```

3.  **প্লট তৈরি (Figure ও Axes):** `plt.figure()` অথবা `plt.subplots()` ব্যবহার করে প্লটের ক্যানভাস তৈরি করুন।
    ```python
    fig, ax = plt.subplots()
    ```

4.  **ডেটা প্লট করা:** `plot`, `scatter`, `bar` ইত্যাদি ফাংশন ব্যবহার করে Axes-এর উপর ডেটা আঁকুন।
    ```python
    ax.plot(x, y)
    ```

5.  **প্লট কাস্টমাইজ করা:** প্লটটিকে আরও তথ্যবহুল করার জন্য টাইটেল, লেবেল, লিজেন্ড, রঙ ইত্যাদি যোগ করুন।
    ```python
    ax.set_title("Sine Wave")
    ax.set_xlabel("X-axis")
    ax.set_ylabel("Y-axis")
    ax.grid(True) # গ্রিড যোগ করা
    ```

6.  **প্লট প্রদর্শন:** সবশেষে, `plt.show()` ফাংশন কল করে প্লটটি স্ক্রিনে প্রদর্শন করুন।

7.  **প্লট সেভ করা (ঐচ্ছিক):** `plt.savefig()` ব্যবহার করে প্লটটিকে ছবি হিসেবে (যেমন PNG, JPG, PDF) সেভ করতে পারেন।
    ```python
    plt.savefig("sine_wave.png")
    ```

### **বিভিন্ন ধরণের প্লট এবং তাদের ব্যবহার**

Matplotlib দিয়ে অনেক ধরণের প্লট তৈরি করা যায়। নিচে কিছু জনপ্রিয় প্লটের উদাহরণ দেওয়া হলো:

#### **১. Line Plot (রৈখিক প্লট)**
সময়ের সাথে সাথে ডেটার পরিবর্তন দেখানোর জন্য এটি খুব কার্যকর।
```python
x = [2018, 2019, 2020, 2021, 2022]
y = [100, 120, 90, 150, 180]
plt.plot(x, y, marker='o', linestyle='--', color='b')
plt.title("বছরের ভিত্তিতে বিক্রয়")
plt.show()
```

#### **২. Bar Chart (বার চার্ট)**
বিভিন্ন ক্যাটাগরির মধ্যে তুলনা করার জন্য ব্যবহৃত হয়।
```python
categories = ['A', 'B', 'C', 'D']
values = [23, 45, 55, 12]
plt.bar(categories, values, color='skyblue')
plt.title("বিভিন্ন ক্যাটাগরির তুলনা")
plt.show()
```

#### **৩. Scatter Plot (স্ক্যাটার প্লট)**
দুটি ভ্যারিয়েবলের মধ্যে সম্পর্ক খুঁজে বের করার জন্য এটি ব্যবহৃত হয়।
```python
x = np.random.rand(50) * 10
y = x * 2 + np.random.randn(50) * 2 # y = 2x + noise
plt.scatter(x, y)
plt.title("দুটি ভ্যারিয়েবলের সম্পর্ক")
plt.show()
```

#### **৪. Histogram (হিস্টোগ্রাম)**
একটি ডেটাসেটের ডেটা বন্টন (distribution) বা ফ্রিকোয়েন্সি দেখানোর জন্য ব্যবহৃত হয়।
```python
data = np.random.randn(1000)
plt.hist(data, bins=30, color='green', alpha=0.7)
plt.title("ডেটা বন্টন")
plt.show()
```

#### **৫. Pie Chart (পাই চার্ট)**
একটি সমগ্রের অংশগুলো দেখানোর জন্য ব্যবহৃত হয়।
```python
labels = ['A', 'B', 'C', 'D']
sizes = [15, 30, 45, 10]
plt.pie(sizes, labels=labels, autopct='%1.1f%%')
plt.title("অংশের তুলনা")
plt.show()
```

### **অন্যান্য লাইব্রেরির সাথে Matplotlib-এর সম্পর্ক**

*   **NumPy:** Matplotlib সাধারণত NumPy অ্যারে (array) নিয়ে কাজ করে। ডেটা তৈরি এবং গাণিতিক অপারেশনের জন্য NumPy অপরিহার্য।
*   **Pandas:** Pandas DataFrame থেকে সরাসরি প্লট তৈরি করার জন্য `.plot()` মেথড ব্যবহার করা যায়, যা ব্যাকএন্ডে Matplotlib ব্যবহার করে।
    ```python
    import pandas as pd
    df = pd.DataFrame({'x': [1,2,3], 'y': [4,5,6]})
    df.plot(x='x', y='y')
    plt.show()
    ```
*   **Seaborn:** Seaborn হলো Matplotlib-এর উপর ভিত্তি করে তৈরি একটি উচ্চ-স্তরের (high-level) লাইব্রেরি। এটি আরও সুন্দর এবং আকর্ষণীয় স্ট্যাটিস্টিক্যাল প্লট তৈরি করতে সাহায্য করে এবং কোড লেখা সহজ করে তোলে।

### **সারসংক্ষেপ (Conclusion)**

Matplotlib একটি অত্যন্ত নমনীয় এবং শক্তিশালী লাইব্রেরি। এর কার্যকারিতা বোঝার মূল চাবিকাঠি হলো **Figure**, **Axes** এবং **Artist**-এর ধারণা বোঝা। আপনি সহজ প্লটের জন্য **Pyplot interface** এবং জটিল ও নিয়ন্ত্রিত প্লটের জন্য **Object-Oriented interface** ব্যবহার করতে পারেন। ডেটা সায়েন্স এবং অ্যানালাইসিসের জগতে ডেটাকে কার্যকরভাবে উপস্থাপন করার জন্য Matplotlib একটি অপরিহার্য টুল।

### **উদাহরণ ১: ব্যবসায়িক বিক্রয় ডেটা বিশ্লেষণ (Business Sales Data Analysis)**

**উদ্দেশ্য:** একটি কোম্পানির মাসিক বিক্রয় এবং বিভিন্ন পণ্যের বিক্রয়ের তুলনা করা। এটি কোম্পানির পারফরম্যান্স বুঝতে এবং সঠিক ব্যবসায়িক সিদ্ধান্ত নিতে সাহায্য করে।

#### **ক) মাসিক বিক্রয়ের ট্রেন্ড (Line Plot)**
একটি লাইন প্লট ব্যবহার করে সময়ের সাথে সাথে বিক্রয়ের পরিবর্তন দেখা যায়, যা থেকে বোঝা যায় ব্যবসা বাড়ছে নাকি কমছে।

```python
import matplotlib.pyplot as plt
import pandas as pd

# বাস্তবসম্মত ডেটা তৈরির জন্য একটি DataFrame ব্যবহার করা হচ্ছে
data = {
    'মাস': ['জানুয়ারি', 'ফেব্রুয়ারি', 'মার্চ', 'এপ্রিল', 'মে', 'জুন'],
    'মোট_বিক্রয় (লাখ)': [50, 55, 65, 60, 75, 80],
    'পণ্য_A_বিক্রয় (লাখ)': [20, 22, 28, 25, 30, 35],
    'পণ্য_B_বিক্রয় (লাখ)': [30, 33, 37, 35, 45, 45]
}
df = pd.DataFrame(data)

# Figure এবং Axes তৈরি
fig, ax = plt.subplots(figsize=(10, 6))

# লাইন প্লট তৈরি
ax.plot(df['মাস'], df['মোট_বিক্রয় (লাখ)'], marker='o', linestyle='-', color='purple', label='মোট বিক্রয়')

# প্লট কাস্টমাইজেশন
ax.set_title('মাসিক বিক্রয়ের ট্রেন্ড (২০২৩)', fontsize=16)
ax.set_xlabel('মাস', fontsize=12)
ax.set_ylabel('বিক্রয় (লাখ টাকায়)', fontsize=12)
ax.grid(True, linestyle='--', alpha=0.6)
ax.legend()

# X-অক্ষের লেবেলগুলো সুন্দরভাবে দেখানোর জন্য
plt.xticks(rotation=45)
plt.tight_layout() # লেবেলগুলো যেন কেটে না যায়

# প্লট প্রদর্শন
plt.show()
```
**বাস্তব জীবনে ব্যবহার:** এই প্লট থেকে ম্যানেজমেন্ট সহজেই বুঝতে পারে কোন মাসে বিক্রয় বেড়েছে বা কমেছে এবং সেই অনুযায়ী তাদের মার্কেটিং বা সেলস স্ট্র্যাটেজি পরিবর্তন করতে পারে।

### **উদাহরণ ২: গ্রাহকদের বয়স ভিত্তিক বন্টন (Customer Age Distribution)**

**উদ্দেশ্য:** একটি পণ্যের গ্রাহকরা কোন বয়সী গ্রুপে সবচেয়ে বেশি, তা বের করা। এটি টার্গেট মার্কেটিং-এর জন্য অত্যন্ত গুরুত্বপূর্ণ।

#### **খ) গ্রাহকদের বয়সের হিস্টোগ্রাম (Histogram)**
হিস্টোগ্রাম ব্যবহার করে ডেটার বন্টন দেখা যায়। এখানে আমরা গ্রাহকদের বয়সের বন্টন দেখব।

```python
import matplotlib.pyplot as plt
import numpy as np

# নমুনা হিসেবে গ্রাহকদের বয়সের ডেটা তৈরি (বাস্তব ডেটা এমন হতে পারে)
np.random.seed(42)
customer_ages = np.random.normal(loc=35, scale=10, size=500) # গড় বয়স ৩৫, কিছুটা বিচ্যুতিসহ
customer_ages = np.clip(customer_ages, 15, 70) # বয়স ১৫ থেকে ৭০ এর মধ্যে সীমাবদ্ধ রাখা

# Figure এবং Axes তৈরি
fig, ax = plt.subplots(figsize=(10, 6))

# হিস্টোগ্রাম তৈরি
ax.hist(customer_ages, bins=15, color='skyblue', edgecolor='black')

# প্লট কাস্টমাইজেশন
ax.set_title('গ্রাহকদের বয়স ভিত্তিক বন্টন', fontsize=16)
ax.set_xlabel('বয়স', fontsize=12)
ax.set_ylabel('গ্রাহকের সংখ্যা', fontsize=12)
ax.axvline(customer_ages.mean(), color='red', linestyle='dashed', linewidth=2, label=f'গড় বয়স: {customer_ages.mean():.1f}')
ax.legend()

# প্লট প্রদর্শন
plt.show()
```
**বাস্তব জীবনে ব্যবহার:** এই চার্টটি দেখে মার্কেটিং টিম বুঝতে পারবে যে তাদের পণ্যের মূল গ্রাহক হলো তরুণরা (যেমন, ২৫-৪০ বছর বয়সী)। ফলে তারা ফেসবুক বা ইনস্টাগ্রামে বিজ্ঞাপন দিতে পারে, যেখানে এই বয়সী গ্রাহকরা বেশি সক্রিয়।

### **উদাহরণ ৩: আবহাওয়ার ডেটা বিশ্লেষণ (Weather Data Analysis)**

**উদ্দেশ্য:** দুটি শহরের মাসিক গড় তাপমাত্রার তুলনা করা। এটি কৃষি, পর্যটন বা জলবায়ু গবেষণার জন্য দরকারি।

#### **গ) দুটি শহরের তাপমাত্রা তুলনা (Multiple Line Plot)**
একই প্লটে একাধিক লাইন এঁকে দুটি বা তার বেশি ডেটাসেটের মধ্যে তুলনা করা যায়।

```python
import matplotlib.pyplot as plt

# ডেটা
months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec']
dhaka_temp = [19, 22, 27, 29, 29, 28, 28, 29, 28, 27, 24, 20]
sylhet_temp = [18, 21, 25, 27, 27, 28, 28, 28, 27, 26, 23, 19]

# Figure এবং Axes তৈরি
fig, ax = plt.subplots(figsize=(12, 6))

# দুটি শহরের জন্য লাইন প্লট
ax.plot(months, dhaka_temp, marker='s', label='ঢাকা')
ax.plot(months, sylhet_temp, marker='^', label='সিলেট')

# প্লট কাস্টমাইজেশন
ax.set_title('ঢাকা ও সিলেটের মাসিক গড় তাপমাত্রার তুলনা', fontsize=16)
ax.set_xlabel('মাস', fontsize=12)
ax.set_ylabel('গড় তাপমাত্রা (°C)', fontsize=12)
ax.legend()
ax.grid(True)

# প্লট প্রদর্শন
plt.show()
```
**বাস্তব জীবনে ব্যবহার:** পর্যটকরা এই ডেটা দেখে ভ্রমণের সেরা সময় বেছে নিতে পারেন। কৃষকরা ফসলের জন্য উপযুক্ত সময় নির্ধারণ করতে পারেন। গবেষকরা জলবায়ু পরিবর্তনের প্রভাব বিশ্লেষণ করতে পারেন।

### **উদাহরণ ৪: পরীক্ষার ফলাফলের বিশ্লেষণ (Exam Score Analysis)**

**উদ্দেশ্য:** ছাত্রছাত্রীদের গণিত এবং বিজ্ঞান বিষয়ের স্কোরের মধ্যে কোনো সম্পর্ক আছে কিনা তা খুঁজে বের করা।

#### **ঘ) স্কোরের মধ্যে সম্পর্ক (Scatter Plot)**
দুটি ভ্যারিয়েবলের মধ্যে সম্পর্ক বা Correlation বোঝার জন্য স্ক্যাটার প্লট সবচেয়ে ভালো উপায়।

```python
import matplotlib.pyplot as plt
import numpy as np

# নমুনা ডেটা
np.random.seed(0)
math_scores = np.random.randint(50, 100, size=50)
science_scores = math_scores + np.random.randint(-10, 15, size=50) # বিজ্ঞানের স্কোর গণিতের সাথে সম্পর্কিত

# Figure এবং Axes তৈরি
fig, ax = plt.subplots(figsize=(10, 6))

# স্ক্যাটার প্লট তৈরি
scatter = ax.scatter(math_scores, science_scores, c=science_scores, cmap='viridis', alpha=0.8)

# প্লট কাস্টমাইজেশন
ax.set_title('গণিত ও বিজ্ঞানের স্কোরের মধ্যে সম্পর্ক', fontsize=16)
ax.set_xlabel('গণিতের স্কোর', fontsize=12)
ax.set_ylabel('বিজ্ঞানের স্কোর', fontsize=12)
ax.grid(True)

# একটি কালারবার যোগ করা
cbar = fig.colorbar(scatter)
cbar.set_label('বিজ্ঞানের স্কোর')

# প্লট প্রদর্শন
plt.show()
```
**বাস্তব জীবনে ব্যবহার:** শিক্ষকরা এই প্লট দেখে বুঝতে পারেন যে, যারা গণিতে ভালো করে, তারা সাধারণত বিজ্ঞানেও ভালো করে (Positive Correlation)। যদি কোনো ছাত্র গণিতে ভালো কিন্তু বিজ্ঞানে খারাপ করে, তবে তার জন্য বিশেষ ব্যবস্থা নেওয়া যেতে পারে।

এই উদাহরণগুলো দেখায় যে Matplotlib শুধু একটি প্রোগ্রামিং টুল নয়, এটি ডেটা থেকে অর্থপূর্ণ তথ্য বের করে সিদ্ধান্ত গ্রহণে সাহায্য করার একটি শক্তিশালী মাধ্যম।
