
### শেখার উদ্দেশ্য

*   **Lineplot** সম্পর্কে ধারণা নেওয়া
*   Seaborn ব্যবহার করে **Axes-level** ও **Figure-level** লাইনপ্লট তৈরি করা

## Scatter Plot কী?

Scatter plot ব্যবহার করা হয় **দুইটি সংখ্যামূলক ভেরিয়েবলের সম্পর্ক** বোঝার জন্য।

উদাহরণ: একজন ছাত্র যত ঘন্টা পড়েছে সেই অনুযায়ী তার test score বেড়েছে কিনা।

## বেসিক Scatter Plot

```python

plt.show()
```

এখানে study\_hours এবং test\_score এর মধ্যে সম্পর্ক চিত্রিত হবে।

size → পয়েন্টের আকার পরিবর্তন করবে (Tshirt\_size অনুযায়ী)

## Histogram কী?

Histogram হল একটি গ্রাফ যেখানে কোন numerical ডেটা কীভাবে বিভিন্ন range বা bin এ ছড়িয়ে আছে, তা দেখায়।

এর মাধ্যমে আমরা বুঝতে পারি:

*   কোন value range এ বেশি ডেটা আছে
*   data distribution symmetric, skewed বা multimodal কিনা
*   dataset এর spread, peak, density

এটি মূলত frequency distribution দেখায়।

KDE (Kernel Density Estimation) হলো একটি **continuous distribution curve**, যা কোনো numeric data-এর **probability density** দেখায়।

Histogarm-এর মতো এটা ডেটার distribution বোঝায়, কিন্তু বার চার্টের পরিবর্তে smooth curve দেখায়।

KDE plot useful কারণ:

*   ডেটার shape (normal / skewed / multimodal) বোঝা যায়
*   ডেটার peak কোথায় বেশি সেটা স্পষ্ট দেখা যায়
*   continuous metric data visualization-এ খুব ব্যবহৃত হয়

## Axes-Level KDE plot

#### Example 1

```python
sns.kdeplot(data = student , x ='attendance_rate')
```

![KDE plot of attendance rate](https://phi.sgp1.digitaloceanspaces.com/website-prod-images/public/files/1762332276274.png)

*   sns.kdeplot() → axes-level function (একটি fixed axis-এ plot করে)
*   data = student → DataFrame
*   x = 'attendance\_rate' → এই কলামের continuous values এর KDE curve আঁকবে

এখানে শুধু curve থাকবে, কোন fill নেই। যদি attendance\_rate ডেটা centered হয়, curve bell-shape হতে পারে।

#### Example 2

```python
sns.kdeplot(data = tips_data, x ='tip', hue='sex', fill=True)
```

![KDE plot of tip amount by sex](https://phi.sgp1.digitaloceanspaces.com/website-prod-images/public/files/1762332276281.png)

*   x = 'tip' → tip amount-এর distribution
*   hue='sex' → male এবং female-এর আলাদা curve
*   fill=True → curve এর নিচের অংশ shaded হবে

## Regplot (Regression Plot)

Regression plot মূলত দুইটি numeric ভেরিয়েবলের মধ্যে relationship বুঝতে সাহায্য করে এবং সাথে trendline (regression line) দেখায়।

এটি correlation এবং direction (positive/negative relation) বুঝতে ভালো।

### Example 1 — regplot() (Axes-level plot)

```python
sns.regplot(data = student , x ='study_hours' , y = 'test_score')
```

![Regression plot of study hours vs test score](https://phi.sgp1.digitaloceanspaces.com/website-prod-images/public/files/1762334494690.png)

*   x = study\_hours → শিক্ষার্থী কত ঘণ্টা পড়েছে
*   y = test\_score → পরীক্ষায় কত স্কোর করেছে
*   এই plot scatter points দেখায়
*   সাথে একটি straight regression line fit করে

**কাজ:**

এটি দেখায় পড়ার সময় বাড়লে test score কি বাড়ছে?

যদি points upward direction follow করে → positive relationship

**Axes-level** meaning:

*   এটি সরাসরি current axes-এর উপর plot করে
*   subplot এর সাথে সহজে ব্যবহার করা যায়

## LMPlot (Linear Model Plot)

lmplot() ও regression line+scatter দেখায়

কিন্তু এটি **figure-level** plot, অর্থাৎ পুরো figure layout control করে।

### Example 2 — lmplot() figure-level

```python
sns.lmplot(data = student , x ='study_hours' , y = 'test_score',hue='gender')
```

![Linear model plot of study hours vs test score by gender](https://phi.sgp1.digitaloceanspaces.com/website-prod-images/public/files/1762334494701.png)

*   hue='gender' → পুরুষ ও নারী আলাদা রঙে দেখায়
*   প্রতিটি gender-এর জন্য আলাদা regression line আঁকে
*   plot আরও customizable (facet grid support করে)

**Figure-level** meaning:

*   new figure create করে
*   FacetGrid structure use করে
*   খুব সহজে col, row দিয়ে multiple plots বানানো যায়

উদাহরণ:

যদি আপনি চাইতেন gender অনুযায়ী plot split করতে:

```python
sns.lmplot(data = student , x='study_hours', y='test_score', col='gender')
```

lmplot এ ধরনের splitting support করে — regplot পারে না।

## Summary

| | **regplot** | **lmplot** |
| :--- | :--- | :--- |
| **Level** | Axes-level | Figure-level |
| **Faceting (col/row)** | না | হ্যাঁ |
| **hue support** | limited | fully supports hue |
| **Use case** | Simple regression | Grouped / Multiple regression plots |

## Practical insight

Regplot simple analysis এর জন্য ভালো

*   Relationship দেখতে
*   Trendline বুঝতে

Lmplot advanced visualization এর জন্য ভালো

*   Categorywise regression compare করা
*   Multiple panels তৈরি করা

## Scatter Plot কী?

Scatter plot দুইটি numeric variable-এর মধ্যে relationship দেখায়।

Plotly এর scatter plot interactive হয়, অর্থাৎ:

*   mouse hover করলে value দেখা যায়
*   zoom, pan, select করা যায়

এটি Seaborn-এর scatterplot-এর advanced version।

### Step 1 — Dataset preview

```python
student
```

![Student Dataframe](https://phi.sgp1.digitaloceanspaces.com/website-prod-images/public/files/1762335377279.png)

এখানে student dataset আছে, যেখানে কলামগুলো:

*   time\_study (numeric)
*   Marks (numeric)
*   gender (categorical)
*   Tshirt\_size (numeric)
*   hostel (categorical)

### Step 2 — Plotly Scatter plot

```python
import plotly.express as px

fig = px.scatter(
    student,
    x='time_study',
    y='Marks',
    color='gender',
    size='Tshirt_size',
    hover_data=['hostel']
)

fig.show()
```

![Plotly Scatter Plot](https://phi.sgp1.digitaloceanspaces.com/website-prod-images/public/files/1762335377293.png)

*   `px.scatter()` → Plotly Express scatter plot function
*   `x='time_study'` → X-axis numeric variable
*   `y='Marks'` → Y-axis numeric variable
*   `color='gender'` → male/female ভিন্ন রঙে দেখাবে
*   `size='Tshirt_size'` → dot size proportional হবে Tshirt\_size অনুযায়ী
*   `hover_data=['hostel']` → mouse hover করলে student এর hostel status দেখাবে

**fig.show()** → interactive plot display করবে

### Interactive Features

*   Mouse hover করলে value দেখাবে
*   Zoom-in / zoom-out, pan, box-select / lasso select
*   Easily shareable & dynamic visualization

## Practical Insight

*   Seaborn scatter plot static, Plotly interactive
*   Large dataset বা presentation এ Plotly scatter plot বেশি useful
*   color, size, hover\_data দিয়ে multiple dimension এক plot এ দেখানো যায়
