### **Seaborn কি?**

Seaborn হলো Python-এর একটি ডেটা ভিজ্যুয়ালাইজেশন লাইব্রেরি, যা Matplotlib-এর উপর ভিত্তি করে তৈরি। এর মূল উদ্দেশ্য হলো আরও আকর্ষণীয় এবং তথ্যবহুল পরিসংখ্যানিক গ্রাফ (statistical graphics) তৈরি করাকে সহজ করে তোলা।

**Matplotlib-এর সাথে Seaborn-এর মূল পার্থক্য:**
*   **সহজ সিনট্যাক্স:** জটিল প্লটগুলো Seaborn-এ অনেক কম কোড লিখে তৈরি করা যায়।
*   **সুন্দর ডিজাইন:** Seaborn-এর ডিফল্ট ডিজাইন এবং কালার প্যালেটগুলো Matplotlib-এর চেয়ে অনেক বেশি সুন্দর এবং আধুনিক।
*   **পরিসংখ্যানিক প্লট:** এটি সরাসরি অনেক জটিল পরিসংখ্যানিক প্লট যেমন- violin plot, box plot, heatmap ইত্যাদি তৈরির জন্য বিল্ট-ইন ফাংশন সরবরাহ করে।
*   **Pandas DataFrame-এর সাথে সামঞ্জস্যপূর্ণ:** Seaborn সরাসরি Pandas DataFrame নিয়ে খুব সহজে কাজ করতে পারে।

### **ধাপে ধাপে Seaborn ব্যবহারের উদাহরণ**

চলুন, একটি বাস্তব উদাহরণ দিয়ে ধাপে ধাপে দেখি কিভাবে Seaborn ব্যবহার করে একটি সুন্দর প্লট তৈরি করা যায়। আমরা Seaborn-এর বিল্ট-ইন "tips" ডেটাসেট ব্যবহার করব, যেখানে একটি রেস্টুরেন্টের বিল, টিপস এবং অন্যান্য তথ্য রয়েছে।

#### **ধাপ ১: Seaborn ইনস্টল করা**

আপনার সিস্টেমে Seaborn ইনস্টল করা না থাকলে, টার্মিনাল বা কমান্ড প্রম্পটে নিচের কমান্ডটি চালান:
```bash
pip install seaborn
```

#### **ধাপ ২: প্রয়োজনীয় লাইব্রেরি ইম্পোর্ট করা**

প্রথমে আমাদের Seaborn এবং Matplotlib লাইব্রেরি ইম্পোর্ট করতে হবে।
```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np
```
*   `sns` হলো Seaborn-এর প্রচলিত সংক্ষিপ্ত নাম (alias)।
*   প্লট প্রদর্শন এবং কাস্টমাইজ করার জন্য `matplotlib.pyplot` কে `plt` হিসেবে ইম্পোর্ট করা হয়।

#### **ধাপ ৩: ডেটা লোড করা**

Seaborn-এ কিছু বিল্ট-ইন ডেটাসেট আছে, যা শেখার জন্য খুব সুবিধাজনক। আমরা "tips" ডেটাসেটটি লোড করব।
```python
# Seaborn থেকে "tips" ডেটাসেট লোড করা
tips_df = sns.load_dataset('tips')

# ডেটাসেটের প্রথম কয়েকটি সারি দেখা যাক
print(tips_df.head())
```
এই ডেটাসেটে `total_bill`, `tip`, `sex`, `smoker`, `day`, `time`, এবং `size` কলাম রয়েছে।

#### **ধাপ ৪: প্লট তৈরি করা (Scatter Plot)**

এখন আমরা `total_bill` এবং `tip`-এর মধ্যে সম্পর্ক দেখার জন্য একটি স্ক্যাটার প্লট (scatter plot) তৈরি করব। আমরা দেখব বিল বাড়ার সাথে সাথে টিপস বাড়ে কিনা।

```python
# একটি scatter plot তৈরি করা হচ্ছে
# x-অক্ষে মোট বিল এবং y-অক্ষে টিপস
sns.scatterplot(data=tips_df, x='total_bill', y='tip')

# প্লট প্রদর্শন
plt.show()
```
এই কোডটি একটি সাধারণ স্ক্যাটার প্লট তৈরি করবে। কিন্তু Seaborn-এর আসল শক্তি হলো ডেটার বিভিন্ন ক্যাটাগরি অনুযায়ী প্লটকে আরও তথ্যবহুল করে তোলা।

#### **ধাপ ৫: প্লটকে আরও তথ্যবহুল করা (`hue` ব্যবহার করে)**

আমরা যদি দেখতে চাই যে ধূমপায়ী (smoker) এবং অধূমপায়ী (non-smoker) গ্রাহকদের মধ্যে টিপস দেওয়ার ধরনে কোনো পার্থক্য আছে কিনা, তাহলে আমরা `hue` প্যারামিটার ব্যবহার করতে পারি।

```python
# Figure-এর সাইজ নির্ধারণ
plt.figure(figsize=(10, 6))

# hue ব্যবহার করে scatter plot তৈরি
# 'smoker' কলামের উপর ভিত্তি করে পয়েন্টগুলোকে ভিন্ন রঙ দেওয়া হবে
sns.scatterplot(data=tips_df, x='total_bill', y='tip', hue='smoker', style='time')

# টাইটেল এবং লেবেল যোগ করা
plt.title('মোট বিল এবং টিপসের মধ্যে সম্পর্ক', fontsize=16)
plt.xlabel('মোট বিল (ডলার)', fontsize=12)
plt.ylabel('টিপস (ডলার)', fontsize=12)

# প্লট প্রদর্শন
plt.show()
```
**ব্যাখ্যা:**
*   `hue='smoker'`: এই অংশটি Seaborn-কে বলছে `smoker` কলামের মানের (`Yes` বা `No`) উপর ভিত্তি করে ডেটা পয়েন্টগুলোকে দুটি ভিন্ন রঙে দেখাতে।
*   `style='time'`: এটি `time` কলামের (`Lunch` বা `Dinner`) উপর ভিত্তি করে পয়েন্টগুলোর স্টাইল (যেমন, বৃত্ত বা ক্রস) পরিবর্তন করবে।

### **সম্পূর্ণ কোড একসাথে**

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 1. ডেটা লোড করা
tips_df = sns.load_dataset('tips')

# 2. প্লটের সাইজ নির্ধারণ
plt.figure(figsize=(10, 6))

# 3. Seaborn ব্যবহার করে তথ্যবহুল Scatter Plot তৈরি
sns.scatterplot(
    data=tips_df,      # কোন ডেটাফ্রেম ব্যবহার হবে
    x='total_bill',    # x-অক্ষের জন্য কলাম
    y='tip',           # y-অক্ষের জন্য কলাম
    hue='smoker',      # রঙের জন্য কলাম (ধূমপায়ী/অধূমপায়ী)
    style='time'       # চিহ্নের স্টাইলের জন্য কলাম (লাঞ্চ/ডিনার)
)

# 4. প্লট কাস্টমাইজ করা (Matplotlib ব্যবহার করে)
plt.title('মোট বিল এবং টিপসের মধ্যে সম্পর্ক', fontsize=16)
plt.xlabel('মোট বিল (ডলার)', fontsize=12)
plt.ylabel('টিপস (ডলার)', fontsize=12)

# 5. প্লট প্রদর্শন করা
plt.show()
```

### **আরও একটি উদাহরণ (Bar Plot)**

কোন দিনে রেস্টুরেন্টে গড় বিল সবচেয়ে বেশি ছিল, তা দেখানোর জন্য একটি বার প্লট তৈরি করা যাক।
```python
plt.figure(figsize=(10, 6))

# Seaborn ব্যবহার করে বার প্লট তৈরি
# এটি স্বয়ংক্রিয়ভাবে প্রতিটি দিনের জন্য গড় 'total_bill' গণনা করবে
sns.barplot(data=tips_df, x='day', y='total_bill')

# টাইটেল ও লেবেল যোগ করা
plt.title('দিন অনুযায়ী গড় মোট বিল', fontsize=16)
plt.xlabel('সপ্তাহের দিন', fontsize=12)
plt.ylabel('গড় মোট বিল (ডলার)', fontsize=12)

plt.show()
```
এই উদাহরণটি দেখায় যে Seaborn কিভাবে স্বয়ংক্রিয়ভাবে ডেটা একত্রিত (aggregate) করে প্লট তৈরি করতে পারে, যা Matplotlib-এ করতে হলে অতিরিক্ত কোড লিখতে হতো।

এই হলো Seaborn ব্যবহারের একটি প্রাথমিক ধারণা। এটি ডেটা অ্যানালাইসিস এবং ভিজ্যুয়ালাইজেশনের কাজকে অনেক সহজ এবং সুন্দর করে তোলে।

### **Seaborn পরিচিতি**

Seaborn হলো Matplotlib-এর উপর ভিত্তি করে তৈরি একটি উন্নত ডেটা ভিজ্যুয়ালাইজেশন লাইব্রেরি। এর মূল লক্ষ্য হলো পরিসংখ্যানিক গ্রাফ তৈরি করাকে আরও সহজ এবং আকর্ষণীয় করে তোলা।

আমরা শুরু করার আগে প্রয়োজনীয় লাইব্রেরিগুলো ইম্পোর্ট করে নেব এবং Seaborn-এর বিল্ট-ইন ডেটাসেট (`tips`) লোড করব।
```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

# ডেটাসেট লোড করা
tips = sns.load_dataset('tips')
titanic = sns.load_dataset('titanic')
flights = sns.load_dataset('flights')
```

Seaborn-এর প্লটগুলোকে প্রধানত কয়েকটি ভাগে ভাগ করা যায়:

1.  **Relational Plots (সম্পর্ক দেখানোর প্লট)**
2.  **Distribution Plots (বন্টন দেখানোর প্লট)**
3.  **Categorical Plots (শ্রেণীবিভাগীয় ডেটার প্লট)**
4.  **Regression Plots (রিগ্রেশন মডেল দেখানোর প্লট)**
5.  **Matrix Plots (ম্যাট্রিক্স ডেটার প্লট)**

---

### **১. Relational Plots (সম্পর্ক দেখানোর প্লট)**

এই প্লটগুলো দুটি সংখ্যাসূচক ভ্যারিয়েবলের (numerical variables) মধ্যে সম্পর্ক দেখাতে ব্যবহৃত হয়।

#### **ক) স্ক্যাটার প্লট (Scatter Plot)**

*   **কখন ব্যবহার করা হয়?** দুটি ভ্যারিয়েবলের মধ্যে সম্পর্ক, প্যাটার্ন বা কোরিলেশন খুঁজে বের করতে। যেমন: বিল বাড়লে কি টিপস বাড়ে?
*   **মূল ধারণা:** প্রতিটি ডেটা পয়েন্টকে x এবং y অক্ষের মান অনুযায়ী একটি বিন্দু হিসেবে দেখানো হয়।
*   **কোড উদাহরণ:**
    ```python
    plt.figure(figsize=(10, 6))
    sns.scatterplot(data=tips, x='total_bill', y='tip', hue='smoker', style='time', size='size')
    plt.title('মোট বিল এবং টিপসের মধ্যে সম্পর্ক')
    plt.xlabel('মোট বিল (ডলার)')
    plt.ylabel('টিপস (ডলার)')
    plt.show()
    ```
    এখানে `hue`, `style`, এবং `size` ব্যবহার করে আরও কয়েকটি ভ্যারিয়েবলের তথ্য একই প্লটে যোগ করা হয়েছে।

#### **খ) লাইন প্লট (Line Plot)**

*   **কখন ব্যবহার করা হয়?** সময়ের সাথে বা কোনো ধারাবাহিক ভ্যারিয়েবলের সাথে ডেটার পরিবর্তন দেখাতে। যেমন: বছরের বিভিন্ন মাসে বিমানের যাত্রী সংখ্যা কেমন ছিল?
*   **মূল ধারণা:** ডেটা পয়েন্টগুলোকে একটি লাইন দিয়ে সংযুক্ত করা হয়।
*   **কোড উদাহরণ:**
    ```python
    # flights ডেটাসেটটি line plot-এর জন্য উপযুক্ত
    flights_wide = flights.pivot(index='year', columns='month', values='passengers')

    plt.figure(figsize=(12, 6))
    sns.lineplot(data=flights, x='year', y='passengers', hue='month')
    plt.title('বছরের ভিত্তিতে মাসিক যাত্রী সংখ্যা')
    plt.xlabel('বছর')
    plt.ylabel('যাত্রী সংখ্যা')
    plt.show()
    ```

### **২. Distribution Plots (বন্টন দেখানোর প্লট)**

এই প্লটগুলো একটি ভ্যারিয়েবলের ডেটা কীভাবে বন্টিত (distributed) আছে, তা বুঝতে সাহায্য করে।

#### **ক) হিস্টোগ্রাম (Histogram)**

*   **কখন ব্যবহার করা হয়?** একটি ভ্যারিয়েবলের ফ্রিকোয়েন্সি বা ডেটার ঘনত্ব দেখতে। যেমন: রেস্টুরেন্টে বেশিরভাগ বিলের পরিমাণ কত?
*   **মূল ধারণা:** ডেটাকে কয়েকটি গ্রুপে (bins) ভাগ করে প্রতিটি গ্রুপে কতগুলো ডেটা পয়েন্ট আছে, তা বার আকারে দেখানো হয়।
*   **কোড উদাহরণ:**
    ```python
    sns.histplot(data=tips, x='total_bill', bins=20, kde=True) # kde=True একটি Density Curve যোগ করে
    plt.title('মোট বিলের বন্টন (Distribution)')
    plt.xlabel('মোট বিল')
    plt.ylabel('ফ্রিকোয়েন্সি')
    plt.show()
    ```

#### **খ) কার্নেল ডেনসিটি এস্টিমেট (KDE Plot)**

*   **কখন ব্যবহার করা হয়?** হিস্টোগ্রামের একটি মসৃণ (smooth) সংস্করণ। এটি ডেটার সম্ভাব্য বন্টন দেখায়।
*   **মূল ধারণা:** এটি একটি বক্ররেখা যা ডেটার ঘনত্ব নির্দেশ করে। যেখানে রেখাটি উঁচু, সেখানে ডেটার ঘনত্ব বেশি।
*   **কোড উদাহরণ:**
    ```python
    sns.kdeplot(data=tips, x='tip', fill=True) # fill=True দিলে নিচের অংশ রঙ দিয়ে ভরে যায়
    plt.title('টিপসের ডেনসিটি প্লট')
    plt.xlabel('টিপস (ডলার)')
    plt.ylabel('ডেনসিটি')
    plt.show()
    ```

### **৩. Categorical Plots (শ্রেণীবিভাগীয় ডেটার প্লট)**

এই প্লটগুলো একটি সংখ্যাসূচক এবং এক বা একাধিক শ্রেণীবিভাগীয় (categorical) ভ্যারিয়েবলের মধ্যে সম্পর্ক দেখায়।

#### **ক) বার প্লট (Bar Plot)**

*   **কখন ব্যবহার করা হয়?** বিভিন্ন ক্যাটাগরির মধ্যে একটি সংখ্যাসূচক মানের গড় (mean) বা অন্য কোনো পরিমাপ তুলনা করতে। যেমন: সপ্তাহের কোন দিনে গড় বিল সবচেয়ে বেশি?
*   **মূল ধারণা:** প্রতিটি ক্যাটাগরির জন্য একটি বার আঁকা হয়, যার উচ্চতা ওই ক্যাটাগরির গড় মান নির্দেশ করে।
*   **কোড উদাহরণ:**
    ```python
    sns.barplot(data=tips, x='day', y='total_bill', hue='sex')
    plt.title('দিন অনুযায়ী লিঙ্গভেদে গড় বিল')
    plt.xlabel('সপ্তাহের দিন')
    plt.ylabel('গড় মোট বিল (ডলার)')
    plt.show()
    ```

#### **খ) কাউন্ট প্লট (Count Plot)**

*   **কখন ব্যবহার করা হয়?** একটি ক্যাটাগরি কতবার এসেছে তা গণনা করে দেখাতে। এটি হিস্টোগ্রামের মতো, কিন্তু ক্যাটাগরিক্যাল ডেটার জন্য।
*   **মূল ধারণা:** প্রতিটি ক্যাটাগরির জন্য একটি বার আঁকা হয়, যার উচ্চতা ওই ক্যাটাগরির সংখ্যা নির্দেশ করে।
*   **কোড উদাহরণ:**
    ```python
    sns.countplot(data=titanic, x='class', hue='who')
    plt.title('টাইটানিকের বিভিন্ন ক্লাসে যাত্রীর সংখ্যা')
    plt.xlabel('ক্লাস')
    plt.ylabel('যাত্রীর সংখ্যা')
    plt.show()
    ```

#### **গ) বক্স প্লট (Box Plot)**

*   **কখন ব্যবহার করা হয়?** ক্যাটাগরি অনুযায়ী ডেটার বন্টন, মধ্যমা (median), কোয়ার্টাইল (quartiles) এবং আউটলায়ার (outliers) দেখতে।
*   **মূল ধারণা:** এটি ডেটাকে চারটি ভাগে ভাগ করে দেখায়। বক্সটি মাঝের ৫০% ডেটাকে ধারণ করে।
*   **কোড উদাহরণ:**
    ```python
    sns.boxplot(data=tips, x='day', y='total_bill', hue='smoker')
    plt.title('দিন অনুযায়ী মোট বিলের বন্টন (Box Plot)')
    plt.xlabel('সপ্তাহের দিন')
    plt.ylabel('মোট বিল (ডলার)')
    plt.show()
    ```

#### **ঘ) ভায়োলিন প্লট (Violin Plot)**

*   **কখন ব্যবহার করা হয়?** এটি বক্স প্লট এবং KDE প্লটের সমন্বয়। এটি ডেটার বন্টন আরও বিস্তারিতভাবে দেখায়।
*   **মূল ধারণা:** এটি বক্স প্লটের মতো ডেটার সারসংক্ষেপ দেখায় এবং এর পাশাপাশি প্রতিটি দিকে ডেটার ঘনত্বও (KDE) দেখায়।
*   **কোড উদাহরণ:**
    ```python
    sns.violinplot(data=tips, x='day', y='total_bill', hue='sex', split=True) # split=True দিলে দুটি ক্যাটাগরি একই ভায়োলিনে দেখায়
    plt.title('দিন অনুযায়ী মোট বিলের বন্টন (Violin Plot)')
    plt.xlabel('সপ্তাহের দিন')
    plt.ylabel('মোট বিল (ডলার)')
    plt.show()
    ```

### **৪. Regression Plots (রিগ্রেশন প্লট)**

*   **কখন ব্যবহার করা হয়?** দুটি ভ্যারিয়েবলের মধ্যে রৈখিক (linear) সম্পর্ক খুঁজে বের করতে এবং একটি রিগ্রেশন মডেল লাইন আঁকতে।
*   **মূল ধারণা:** এটি একটি স্ক্যাটার প্লটের উপর একটি রিগ্রেশন লাইন যুক্ত করে, যা ডেটার ট্রেন্ড দেখায়।
*   **কোড উদাহরণ (`regplot`):**
    ```python
    sns.regplot(data=tips, x='total_bill', y='tip')
    plt.title('মোট বিল এবং টিপসের মধ্যে রিগ্রেশন প্লট')
    plt.xlabel('মোট বিল')
    plt.ylabel('টিপস')
    plt.show()
    ```

*   **`lmplot` (আরও শক্তিশালী সংস্করণ):** `lmplot` ব্যবহার করে বিভিন্ন ক্যাটাগরির জন্য আলাদা আলাদা রিগ্রেশন লাইন আঁকা যায়।
    ```python
    sns.lmplot(data=tips, x='total_bill', y='tip', hue='smoker', col='day', col_wrap=2) # col='day' দিয়ে প্রতিটি দিনের জন্য আলাদা প্লট তৈরি হবে
    plt.show()
    ```

### **৫. Matrix Plots (ম্যাট্রিক্স প্লট)**

এই প্লটগুলো গ্রিড আকারে ডেটা দেখানোর জন্য ব্যবহৃত হয়, যেখানে সেলের রঙ মান নির্দেশ করে।

#### **ক) হিটম্যাপ (Heatmap)**

*   **কখন ব্যবহার করা হয়?** একটি ম্যাট্রিক্সের মানগুলোকে রঙ হিসেবে দেখাতে। এটি কোরিলেশন ম্যাট্রিক্স বা গ্রিড ডেটা ভিজ্যুয়ালাইজ করার জন্য খুবই জনপ্রিয়।
*   **মূল ধারণা:** ডেটা ম্যাট্রিক্সের প্রতিটি সেলের মান অনুযায়ী একটি রঙ দেওয়া হয়। বেশি মানের জন্য এক ধরনের রঙ এবং কম মানের জন্য অন্য ধরনের রঙ।
*   **কোড উদাহরণ:**
    ```python
    # flights ডেটাসেটকে pivot করে ম্যাট্রিক্স বানানো হচ্ছে
    flights_pivot = flights.pivot(index='month', columns='year', values='passengers')

    plt.figure(figsize=(12, 8))
    sns.heatmap(flights_pivot, annot=True, fmt='d', cmap='YlGnBu') # annot=True মানগুলো দেখায়, fmt='d' পূর্ণসংখ্যা ফরম্যাট
    plt.title('মাসিক যাত্রী সংখ্যার হিটম্যাপ')
    plt.show()
    ```

#### **খ) ক্লাস্টারম্যাপ (Clustermap)**

*   **কখন ব্যবহার করা হয়?** এটি হিটম্যাপের মতোই, কিন্তু এটি সারি (rows) এবং কলাম (columns) গুলোকে তাদের সাদৃশ্যের উপর ভিত্তি করে পুনরায় সাজায় (cluster)।
*   **মূল ধারণা:** এটি ডেটার মধ্যে থাকা গ্রুপ বা ক্লাস্টার খুঁজে বের করতে সাহায্য করে।
*   **কোড উদাহরণ:**
    ```python
    sns.clustermap(flights_pivot, cmap='coolwarm', standard_scale=1)
    plt.show()
    ```
    এই প্লটটি একই ধরনের মাস এবং বছরগুলোকে একসাথে দেখাবে।

এই হলো Seaborn-এর সবচেয়ে বেশি ব্যবহৃত চার্টগুলোর বিস্তারিত আলোচনা। প্রতিটি প্লটের নিজস্ব ব্যবহার এবং সুবিধা রয়েছে এবং সঠিক প্লট নির্বাচন করা ডেটা থেকে সঠিক তথ্য বের করার জন্য অত্যন্ত গুরুত্বপূর্ণ।


1. Relational Plots

|Function|Type|Description|
|---|---|---|
|`sns.scatterplot()`|Axes-level|Scatter plot for numeric variables|
|`sns.lineplot()`|Axes-level|Line plot for trends over time or categories|
|`sns.relplot()`|**Figure-level**|Combines scatter and line plots with faceting support (`kind="scatter"` or `"line"`)|
2. Categorical Plots

|Function|Type|Description|
|---|---|---|
|`sns.barplot()`|Axes-level|Show mean and confidence interval of a numeric variable|
|`sns.countplot()`|Axes-level|Show count of observations for each category|
|`sns.boxplot()`|Axes-level|Show distribution through quartiles and outliers|
|`sns.violinplot()`|Axes-level|Combination of boxplot and KDE (density)|
|`sns.stripplot()`|Axes-level|Scatter plot for categorical data|
|`sns.swarmplot()`|Axes-level|Adjusted stripplot with no overlaps|
|`sns.pointplot()`|Axes-level|Show mean values with lines connecting categories|
|`sns.catplot()`|**Figure-level**|Combines all above categorical plots with `kind=` option (`"bar"`, `"box"`, `"violin"`, `"strip"`, etc.)|

**3. Distribution Plots**

| Function         | Type             | Description                                                         |
| ---------------- | ---------------- | ------------------------------------------------------------------- |
| `sns.histplot()` | Axes-level       | Histogram with optional KDE overlay                                 |
| `sns.kdeplot()`  | Axes-level       | Kernel Density Estimate curve                                       |
| `sns.ecdfplot()` | Axes-level       | Empirical Cumulative Distribution Function                          |
| `sns.rugplot()`  | Axes-level       | Marks data points along an axis                                     |
| `sns.displot()`  | **Figure-level** | Combines `histplot`, `kdeplot`, or `ecdfplot` with faceting support |
4. Regression Plots

|Function|Type|Description|
|---|---|---|
|`sns.regplot()`|Axes-level|Scatter plot with linear regression line|
|`sns.residplot()`|Axes-level|Plot residuals of a linear regression|
|`sns.lmplot()`|**Figure-level**|Combines regression plots with faceting (`kind="reg"` or `"resid"`)|
5. Matrix Plots

|Function|Type|Description|
|---|---|---|
|`sns.heatmap()`|Axes-level|Visualize data or correlation matrix as a heatmap|
|`sns.clustermap()`|**Figure-level**|Clustered heatmap with dendrograms|
6. Multivariate Plots

|Function|Type|Description|
|---|---|---|
|`sns.pairplot()`|**Figure-level**|Pairwise relationships across numeric columns|
|`sns.jointplot()`|**Figure-level**|Bivariate plot with marginal distributions|
|`sns.pairplot()`|Figure-level|Multiple pairwise plots automatically|
|`sns.PairGrid()`|**Figure-level (class)**|Fully customizable grid of pairwise plots|
|`sns.JointGrid()`|**Figure-level (class)**|Fully customizable grid for joint distributions|
7. Thematic / Utility Functions

|Function|Description|
|---|---|
|`sns.set_theme()`|Set overall aesthetic style and color palette|
|`sns.set_style()`|Change background style (`white`, `dark`, etc.)|
|`sns.set_palette()`|Set color palette globally|
|`sns.color_palette()`|Return list of colors for plotting|

|Regression|`lmplot()`|`regplot()`, `residplot()`|
