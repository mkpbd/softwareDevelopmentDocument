### পর্ব ১: Redis আসলে কী? (The Funny Analogy 🤣)

ধরো, তুমি একটা **মুদি দোকান (Grocery Shop)** চালাও।

১. **তোমার Database (SQL Server/Postgres):** এটা হলো তোমার দোকানের পেছনের **বড় গোডাউন**। এখানে হাজার হাজার মাল আছে। কিন্তু এখান থেকে কিছু আনতে হলে তোমাকে উঠে যেতে হয়, ধুলোবালি সরাতে হয়, মই বেয়ে উঠতে হয়। এতে **সময় বেশি লাগে**।

২. **Redis (In-Memory Database):** এটা হলো তোমার দোকানের সামনের **কাউন্টারের র‍্যাক**। যেই জিনিসগুলো কাস্টমাররা সবচেয়ে বেশি চায় (যেমন: চিপস, বিস্কুট), সেগুলো তুমি গোডাউনে রাখো না, হাতের কাছেই রাখো। কাস্টমার চাইলো, আর তুমি **চোখের পলকে (Microsecond)** দিয়ে দিলে।

**Redis** হলো সেই সুপার-ফাস্ট কাউন্টার, যেটা **RAM (Memory)** তে ডেটা রাখে, তাই এটা রকেটের গতিতে কাজ করে।

### পর্ব ৪: বেসিক - ক্যাশ করা (Cache-Aside Pattern) 🧠

সবচেয়ে কমন ব্যবহার।
**লজিক:** কাস্টমার কিছু চাইলে আগে কাউন্টারে (Redis) খুঁজব। না পেলে গোডাউন (Database) থেকে এনে কাস্টমারকে দেব এবং পরে ব্যবহারের জন্য কাউন্টারেও সাজিয়ে রাখব।

```csharp
app.MapGet("/product/{id}", async (string id, IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    
    // ১. আগে Redis এ চেক করি (কাউন্টার চেক)
    string? cachedProduct = await db.StringGetAsync($"product:{id}");
    
    if (!string.IsNullOrEmpty(cachedProduct))
    {
        return Results.Ok($"Redis থেকে পেয়েছি: {cachedProduct}"); // সুপার ফাস্ট! ⚡
    }

    // ২. Redis এ নেই? তাহলে Database (Simulated) থেকে আনি
    await Task.Delay(2000); // ২ সেকেন্ড দেরি (DB স্লো বোঝাতে)
    var productFromDb = $"iPhone 16 Pro (ID: {id})";

    // ৩. পরেরবারের জন্য Redis এ সেভ করে রাখি (TTL: ১০ সেকেন্ড)
    // ১০ সেকেন্ড পর এটা অটোমেটিক ডিলিট হয়ে যাবে (Expiring Cache)
    await db.StringSetAsync(
        $"product:{id}", 
        productFromDb, 
        TimeSpan.FromSeconds(10)
    );

    return Results.Ok($"Database থেকে এনেছি: {productFromDb}"); // একটু স্লো
});
```

**মজাটা দেখো:** প্রথমবার হিট করলে ২ সেকেন্ড লাগবে। পরের ১০ সেকেন্ডের মধ্যে যতবার হিট করবে, চোখের পলকে রেসপন্স পাবে!

### পর্ব ৫: ইন্টারমিডিয়েট - শুধু স্ট্রিং না, আরো অনেক কিছু! 🧰

Redis শুধু টেক্সট রাখে না, ও অনেক স্মার্ট।

#### ১. Lists (Timeline বা Queue এর জন্য)
মনে করো ফেসবুকে তোমার নিউজফিড। নতুন পোস্ট উপরে আসে, পুরানগুলো নিচে যায়।
```csharp
app.MapPost("/add-post", async (string post, IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    // বাম পাশ থেকে লিস্টে ডেটা ঢোকানো (LPUSH)
    await db.ListLeftPushAsync("timeline:user1", post);
    return Results.Ok("পোস্ট টাইমলাইনে যোগ হয়েছে!");
});

app.MapGet("/get-timeline", async (IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    // প্রথম ৫টা পোস্ট নিয়ে আসো (LRANGE)
    var posts = await db.ListRangeAsync("timeline:user1", 0, 4);
    return Results.Ok(posts.ToStringArray());
});
```

#### ২. Hash (অবজেক্ট রাখার জন্য)
স্ট্রিং হিসেবে পুরো JSON রাখার চেয়ে Hash এ রাখা ভালো, যদি তুমি স্পেসিফিক ফিল্ড আপডেট করতে চাও।
```csharp
// "user:101" আইডিতে নাম আর বয়স সেট করা
await db.HashSetAsync("user:101", new HashEntry[] {
    new HashEntry("name", "Rahim"),
    new HashEntry("age", 25)
});
```

### পর্ব ৬: অ্যাডভান্সড - Pub/Sub (মাইকিং করা 📢)

মনে করো পাড়ায় মেম্বার ইলেকশন। একজন মাইকিং করছে (Publisher), আর বাকিরা কান পেতে শুনছে (Subscribers)।

এটা রিয়েল-টাইম চ্যাট বা নোটিফিকেশনের জন্য বস!

**Subscriber (যে শুনবে - Background Service হতে পারে):**
```csharp
// এটা অ্যাপ স্টার্ট হওয়ার সময় রান করবে
var sub = redisConn.GetSubscriber();
await sub.SubscribeAsync("news_channel", (channel, message) => {
    Console.WriteLine($"ব্রেকিং নিউজ পেয়েছি: {message}");
});
```

**Publisher (যে খবর পাঠাবে - API Endpoint):**
```csharp
app.MapPost("/send-news", async (string news, IConnectionMultiplexer redis) =>
{
    var sub = redis.GetSubscriber();
    await sub.PublishAsync("news_channel", news);
    return Results.Ok("খবর সবাইকে পাঠানো হয়েছে!");
});
```
তুমি `/send-news` এ হিট করলেই কনসোলে মেসেজ ভেসে উঠবে। কোনো রিলোড ছাড়াই!

### পর্ব ৭: এক্সপার্ট - Distributed Lock (টয়লেটের চাবি 🔑)

**অ্যানালজি:** ধরো একটা পাবলিক টয়লেট আছে, কিন্তু চাবি একটাই। যে চাবি পাবে, সেই ঢুকবে। বাকিরা বাইরে ওয়েট করবে। কাজ শেষ হলে চাবি ফেরত দেবে।

ডিস্ট্রিবিউটেড সিস্টেমে যখন একাধিক সার্ভার একই ডেটা আপডেট করতে চায়, তখন **Lock** লাগে।

```csharp
app.MapPost("/buy-ticket", async (IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    string lockKey = "ticket_counter_lock";
    string token = Guid.NewGuid().ToString();

    // লক নেওয়ার চেষ্টা (১০ সেকেন্ডের জন্য)
    if (await db.LockTakeAsync(lockKey, token, TimeSpan.FromSeconds(10)))
    {
        try
        {
            // ক্রিটিক্যাল কাজ: টিকিটের সংখ্যা কমানো
            Console.WriteLine("টিকেট প্রসেস করছি...");
            await Task.Delay(1000); 
            return Results.Ok("টিকেট কেনা সফল!");
        }
        finally
        {
            // কাজ শেষে লক রিলিজ করা (চাবি ফেরত)
            await db.LockReleaseAsync(lockKey, token);
        }
    }
    else
    {
        return Results.StatusCode(429); // "ভাই লাইন বিজি, পরে আসেন"
    }
});
```

### শেষ কথা (Pro Tips) 💡

১. **TTL (Time To Live):** Redis এ কখনো আজীবনের জন্য ডেটা রাখবে না (যদি না স্পেশাল কেস হয়)। সব সময় `Expiry Time` সেট করবে। না হলে RAM ভরে যাবে, সার্ভার ক্রাশ খাবে।
২. **Key Naming:** নাম দেয়ার সময় সাবধান। `user:101:profile` - এভাবে কোলন (`:`) দিয়ে নাম দিলে অর্গানাইজ করতে সুবিধা হয়।
৩. **Monitoring:** প্রোডাকশনে `RedisInsight` টুলটা ব্যবহার করবে, ভিজুয়ালি সব ডেটা দেখার জন্য।

কেমন লাগলো ব্রাদার? Redis এখন পানির মতো সহজ লাগছে না? কোডগুলো কপি করে প্র্যাকটিস শুরু করে দাও! কোনো প্যারা লাগলে আমি তো আছিই! 😎🔥

### ১. Caching (String) - ফাস্ট লোডিং 🚀
**আলোচনা:** ডাটাবেস থেকে ডাটা এনে আমরা `String` হিসেবে সেভ করব। C#-এ আমরা অবজেক্টকে `JSON` এ কনভার্ট করে রাখি।

**C# Code:**
```csharp
using System.Text.Json;

// ১. ডাটা সেট করা (Set)
var product = new { Id = 1, Name = "Laptop", Price = 50000 };
string jsonString = JsonSerializer.Serialize(product);

// রেডিসে রাখা (StringSet)
db.StringSet("product:1", jsonString);

// ২. ডাটা পাওয়া (Get)
string cachedData = db.StringGet("product:1");

if (!string.IsNullOrEmpty(cachedData))
{
    var data = JsonSerializer.Deserialize<dynamic>(cachedData);
    Console.WriteLine($"Cache Hit: {data.GetProperty("Name")}"); // Output: Laptop
}
```

### ২. Messaging/Queue (List) - কাজের লাইন 🚶🚶
**আলোচনা:** ব্যাকগ্রাউন্ড জবের জন্য কিউ (Queue)। `ListRightPush` দিয়ে ঢোকাবো, `ListLeftPop` দিয়ে বের করব।

**C# Code:**
```csharp
// Producer: কাজের লাইনে কাজ জমা দিচ্ছে (ডান দিক দিয়ে - RightPush)
db.ListRightPush("email_queue", "user1@gmail.com");
db.ListRightPush("email_queue", "user2@gmail.com");

// Consumer: কাজ প্রসেস করছে (বাম দিক দিয়ে - LeftPop)
string emailToProcess = db.ListLeftPop("email_queue");

if (!string.IsNullOrEmpty(emailToProcess))
{
    Console.WriteLine($"Sending email to: {emailToProcess}");
    // ইমেইল পাঠানোর কোড...
}
else
{
    Console.WriteLine("No emails in queue");
}
```

### ৩. Unique Visitors (Set) - ডুপ্লিকেট চলবে না 🚫
**আলোচনা:** `Set` ব্যবহার করলে রেডিস অটোমেটিক চেক করে দেখবে আইপি আগে আছে কি না। `SetAdd` রিটার্ন করবে `true` (নতুন হলে) অথবা `false` (আগেই থাকলে)।

**C# Code:**
```csharp
string todayKey = "visitors:2023-10-25";

// আইপি যোগ করা
db.SetAdd(todayKey, "192.168.1.1");
db.SetAdd(todayKey, "192.168.1.2");
bool isNew = db.SetAdd(todayKey, "192.168.1.1"); // এটা false রিটার্ন করবে

// মোট কতজন ইউনিক ভিজিটর? (SetLength)
long count = db.SetLength(todayKey);
Console.WriteLine($"Total Unique Visitors: {count}"); // Output: 2
```

### ৪. Leaderboard (Sorted Set) - র‍্যাঙ্কিং 🏆
**আলোচনা:** `SortedSet` এ আমরা মেম্বার এবং তার `Score` রাখি। রেডিস স্কোরের ভিত্তিতে ডাটা সাজিয়ে রাখে।

**C# Code:**
```csharp
// প্লেয়ারদের স্কোর সেট করা
db.SortedSetAdd("game_rank", "PlayerA", 100);
db.SortedSetAdd("game_rank", "PlayerB", 500);
db.SortedSetAdd("game_rank", "PlayerC", 350);

// টপ ৩ জন প্লেয়ার বের করা (বড় থেকে ছোট - Order.Descending)
var topPlayers = db.SortedSetRangeByRankWithScores("game_rank", 0, 2, Order.Descending);

foreach (var player in topPlayers)
{
    Console.WriteLine($"{player.Element}: {player.Score}");
}
/* Output:
   PlayerB: 500
   PlayerC: 350
   PlayerA: 100
*/
```

### ৫. User Profile (Hash) - অবজেক্ট স্টোরেজ 👤
**আলোচনা:** C# এ `HashEntry[]` ব্যবহার করে আমরা অবজেক্টের ফিল্ডগুলো সেভ করতে পারি। এটি মেমোরি সাশ্রয়ী।

**C# Code:**
```csharp
// প্রোফাইল তৈরি করা
var userFields = new HashEntry[] {
    new HashEntry("name", "Rahim"),
    new HashEntry("email", "rahim@test.com"),
    new HashEntry("age", 25)
};

db.HashSet("user:101", userFields);

// শুধু বয়স জানা দরকার?
string age = db.HashGet("user:101", "age");
Console.WriteLine($"Age is: {age}");

// পুরো প্রোফাইল আনা
HashEntry[] allData = db.HashGetAll("user:101");
foreach(var field in allData)
{
    Console.WriteLine($"{field.Name}: {field.Value}");
}
```

### ৬. OTP/Session (Expire) - অটো ডিলিট ⏳
**আলোচনা:** ডাটা সেভ করার সময়ই `TimeSpan` দিয়ে বলে দেওয়া যায় এটা কতক্ষণ থাকবে।

**C# Code:**
```csharp
string otpCode = "8899";
string key = "otp:user:123";

// OTP সেট করলাম এবং বললাম এটা ৬০ সেকেন্ড পর এক্সপায়ার হবে
db.StringSet(key, otpCode, TimeSpan.FromSeconds(60));

Console.WriteLine("OTP saved. Valid for 60 seconds.");

// চেক করা
string savedOtp = db.StringGet(key);

if (!string.IsNullOrEmpty(savedOtp))
{
    Console.WriteLine("OTP Valid!");
}
else
{
    // ৬০ সেকেন্ড পর রান করলে এটা দেখাবে
    Console.WriteLine("OTP Expired!");
}
```

### প্রজেক্ট ১: স্মার্ট শপিং কার্ট (The Shopping Cart) 🛒

**সমস্যা:**
ভাবো তুমি দারাজ বা অ্যামাজনে কেনাকাটা করছো। তুমি ১০টা আইটেম কার্টে যোগ করলে। এই ১০ বার যদি আমরা ডাটাবেস (SQL) এ হিট করি আর ডাটা সেভ করি, তাহলে সার্ভারের ওপর অনেক প্রেশার পড়বে। তাছাড়া ইউজার যদি লগইন না-ও করে, তাও তো কার্ট দেখাতে হবে!

**Redis সমাধান:**
আমরা কার্টের ডাটা সাময়িকভাবে Redis এ রাখব। যখন ইউজার ফাইনালি "Order Now" বাটনে চাপ দিবে, তখন সব ডাটা একসাথে SQL ডাটাবেসে পার্মানেন্টলি সেভ করব।

**অ্যানালজি:**
সুপারশপে ট্রলিতে (Redis) মাল তোলার সময় কি কেউ লেজারে (Database) লিখে রাখে? না! ট্রলিতে সব জমা হয়, শেষে ক্যাশ কাউন্টারে গিয়ে একবারেই হিসাব হয়।

**কোড (.NET 10 Web API):**

```csharp
using System.Text.Json;
using StackExchange.Redis;

var builder = WebApplication.CreateBuilder(args);
var redisConn = ConnectionMultiplexer.Connect("localhost:6379");
builder.Services.AddSingleton<IConnectionMultiplexer>(redisConn);
var app = builder.Build();

// কার্ট আইটেমের মডেল
record CartItem(int ProductId, string Name, int Quantity, decimal Price);

// ১. কার্টে আইটেম যোগ করা (Add to Cart)
app.MapPost("/cart/add/{userId}", async (string userId, CartItem item, IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    string cartKey = $"cart:{userId}";

    // আগে দেখি কার্টে কিছু আছে কিনা
    var existingCart = await db.StringGetAsync(cartKey);
    List<CartItem> cartList;

    if (existingCart.IsNullOrEmpty)
    {
        cartList = new List<CartItem>();
    }
    else
    {
        // Redis এর স্ট্রিং থেকে লিস্টে কনভার্ট করছি
        cartList = JsonSerializer.Deserialize<List<CartItem>>(existingCart!) ?? new List<CartItem>();
    }

    // নতুন আইটেম যোগ
    cartList.Add(item);

    // আবার স্ট্রিং বানিয়ে Redis এ সেভ (১ দিনের জন্য ভ্যালিড)
    await db.StringSetAsync(
        cartKey, 
        JsonSerializer.Serialize(cartList), 
        TimeSpan.FromDays(1)
    );

    return Results.Ok("আইটেম ট্রলিতে (Redis) যোগ হয়েছে!");
});

// ২. কার্ট দেখা (View Cart)
app.MapGet("/cart/{userId}", async (string userId, IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    string cartKey = $"cart:{userId}";
    
    var cartData = await db.StringGetAsync(cartKey);

    if (cartData.IsNullOrEmpty)
        return Results.Ok(new List<CartItem>()); // খালি কার্ট

    var items = JsonSerializer.Deserialize<List<CartItem>>(cartData!);
    return Results.Ok(items);
});

app.Run();
```

### প্রজেক্ট ২: API রেট লিমিটার (The Bouncer/Darwan) 🛑✋

**সমস্যা:**
ধরো তোমার এপিআই খুব জনপ্রিয়। কিন্তু কিছু দুষ্টু হ্যাকার বা বট স্ক্রিপ্ট চালিয়ে সেকেন্ডে ১০০০ বার রিকোয়েস্ট পাঠাচ্ছে। এতে তোমার সার্ভার ডাউন হয়ে যাবে।

**Redis সমাধান:**
আমরা Redis দিয়ে গুনব একজন ইউজার ১০ সেকেন্ডে কয়বার নক করেছে। যদি ৫ বারের বেশি হয়, তাকে ব্লক করে দেব।

**অ্যানালজি:**
বাড়ির দারোয়ান। সে গুনছে তুমি কতবার গেট দিয়ে ঢুকছো। নিয়ম হলো: ১ মিনিটে ৫ বারের বেশি ঢোকা যাবে না। ৬ বার হলেই দারোয়ান বলবে, "ভাই বাইরে দাঁড়ান, টাইম আউট!"

**কোড:**

```csharp
app.MapGet("/expensive-api", async (HttpContext context, IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    
    // ইউজারের আইপি এড্রেস বা টোকেন দিয়ে তাকে চিনব
    string userIp = context.Connection.RemoteIpAddress?.ToString() ?? "unknown";
    string limitKey = $"rate_limit:{userIp}";

    // ১. কাউন্টার ১ বাড়াই (Atomic Increment)
    // যদি key না থাকে, Redis অটোমেটিক ০ থেকে ১ বানাবে
    long requestCount = await db.StringIncrementAsync(limitKey);

    // ২. একদম প্রথম রিকোয়েস্ট হলে এক্সপায়ার টাইম সেট করি (১০ সেকেন্ড)
    if (requestCount == 1)
    {
        await db.KeyExpireAsync(limitKey, TimeSpan.FromSeconds(10));
    }

    // ৩. চেকিং: ৫ বারের বেশি হলে কিক আউট!
    if (requestCount > 5)
    {
        return Results.Problem(
            statusCode: 429, 
            title: "Too Many Requests",
            detail: "ভাই একটু থামেন! ১০ সেকেন্ডে ৫ বারের বেশি রিকোয়েস্ট করা যাবে না।"
        );
    }

    return Results.Ok($"স্বাগতম! আপনি ১০ সেকেন্ডে {requestCount} বার রিকোয়েস্ট করেছেন।");
});
```

### বোনাস: লিডারবোর্ড বা র‍্যাঙ্কিং (Gaming Leaderboard) 🏆

**কেন এটা স্পেশাল?**
ডাটাবেসে (SQL) লাখ লাখ ইউজারের মধ্যে `ORDER BY score DESC` কুয়েরি চালানো খুবই স্লো। Redis এর **Sorted Set (ZSET)** ডাটা স্ট্রাকচার এই কাজের জন্যই জন্ম নিয়েছে। এটা অটোমেটিক ডাটা সর্ট করে রাখে।

```csharp
// ১. স্কোর আপডেট করা
app.MapPost("/game/update-score", async (string player, double score, IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    // ZADD কমান্ড: প্লেয়ারের নাম আর স্কোর সেভ করবে এবং অটো সর্ট করবে
    await db.SortedSetAddAsync("game:leaderboard", player, score);
    return Results.Ok($"{player} এর স্কোর আপডেট হয়েছে!");
});

// ২. টপ ৩ প্লেয়ার দেখা
app.MapGet("/game/top-players", async (IConnectionMultiplexer redis) =>
{
    var db = redis.GetDatabase();
    
    // হাইয়েস্ট স্কোর থেকে লোয়েস্ট (Descending Order)
    var topPlayers = await db.SortedSetRangeByRankWithScoresAsync(
        "game:leaderboard", 
        stop: 0, 
        start: 2, // ০ থেকে ২ মানে টপ ৩ জন
        order: Order.Descending
    );

    // সুন্দর করে ফরম্যাট করে দেখানো
    var result = topPlayers.Select(x => new { Player = x.Element.ToString(), Score = x.Score });
    return Results.Ok(result);
});
```
