### **১. চলাফেরা ও ফাইল নাড়াচাড়া (Navigation & File Management)**
লিনাক্স টার্মিনাল হলো একটা অন্ধকার ঘর। কমান্ড দিয়ে দিয়ে লাইট জ্বালাতে হয়।

#### **`pwd` (Print Working Directory)**
*   **কাজ:** আমি এখন দুনিয়ার কোথায় (কোন ফোল্ডারে) আছি?
*   **কখন লাগবে:** হারিয়ে গেলে বা লোকেশন জানতে।
*   **Example:**
    ```bash
    pwd
    # Output: /home/user/projects
    ```

#### **`ls` (List)**
*   **কাজ:** এই ফোল্ডারে কী কী আছে দেখাও (লাইট জ্বালানো)।
*   **কখন লাগবে:** ফাইলের নাম দেখতে।
*   **Example:**
    ```bash
    ls      # শুধু নাম দেখাবে
    ls -la  # সব ডিটেইলস (লুকানো ফাইলসহ) দেখাবে
    ```

#### **`cd` (Change Directory)**
*   **কাজ:** এক রুম থেকে আরেক রুমে যাওয়া।
*   **কখন লাগবে:** ফোল্ডার পাল্টাতে।
*   **Example:**
    ```bash
    cd /var/www   # www ফোল্ডারে ঢুকলাম
    cd ..         # এক ধাপ পেছনে (আগের ফোল্ডারে) আসলাম
    cd ~          # নিজের বাড়ি (Home) চলে আসলাম
    ```

#### **`mkdir` (Make Directory)**
*   **কাজ:** নতুন ফোল্ডার বানানো।
*   **Example:**
    ```bash
    mkdir my-project
    ```

#### **`rm` (Remove)** ⚠️ *Dangerous*
*   **কাজ:** ফাইল বা ফোল্ডার ডিলিট করা। লিনাক্সে রিসাইকেল বিন নাই, একবার গেলে আর ফেরে না!
*   **কখন লাগবে:** জঞ্জাল সাফ করতে।
*   **Example:**
    ```bash
    rm file.txt       # একটা ফাইল ডিলিট
    rm -rf my-folder  # পুরো ফোল্ডার জোর করে ডিলিট (সাবধান!)
    ```

#### **`cp` (Copy) & `mv` (Move)**
*   **কাজ:** `cp` মানে কপি-পেস্ট, `mv` মানে কাট-পেস্ট (বা রিনেম করা)।
*   **Example:**
    ```bash
    cp file1.txt file2.txt   # কপি হলো
    mv oldname.txt newname.txt # নাম পাল্টে গেল (Rename)
    ```

### **২. ফাইলের ভেতর উঁকি দেওয়া (Viewing Files)**
নোটপ্যাড ওপেন না করেই টার্মিনালে ফাইলের লেখা পড়া।

#### **`cat` (Concatenate)**
*   **কাজ:** পুরো ফাইলের লেখা ধুপ করে স্ক্রিনে প্রিন্ট করা।
*   **কখন লাগবে:** ছোট ফাইলের কন্টেন্ট দেখতে।
*   **Example:**
    ```bash
    cat requirements.txt
    ```

#### **`less`**
*   **কাজ:** বড় ফাইল হলে `cat` করলে মাথা খারাপ হয়ে যাবে। `less` দিয়ে আস্তে আস্তে স্ক্রল করে পড়া যায়।
*   **Example:**
    ```bash
    less big-log-file.log
    # বের হতে চাইলে 'q' চাপবে
    ```

#### **`tail` (লেজ)** 🔥 *Very Important for Docker*
*   **কাজ:** ফাইলের শেষের কয়েক লাইন দেখা।
*   **কখন লাগবে:** সার্ভারের লগ চেক করতে। লেটেস্ট এররগুলো নিচেই থাকে।
*   **Example:**
    ```bash
    tail -f app.log
    # -f (follow) দিলে লাইভ লগ দেখা যাবে (ফেসবুক লাইভের মতো)
    ```

#### **`grep` (Global Regular Expression Print)** 🕵️‍♂️
*   **কাজ:** খড়ের গাদায় সুঁই খোঁজা। ফাইলের ভেতর নির্দিষ্ট শব্দ খোঁজা।
*   **কখন লাগবে:** এরর লগ বা নির্দিষ্ট কোড খুঁজতে।
*   **Example:**
    ```bash
    cat app.log | grep "Error"
    # app.log এর ভেতর শুধু যেই লাইনে "Error" লেখা আছে, সেগুলো দেখাবে।
    ```

### **৩. ক্ষমতা ও পারমিশন (Permissions & Power)**
লিনাক্স সিকিউরিটি নিয়ে খুব কড়া।

#### **`sudo` (SuperUser DO)**
*   **কাজ:** এডমিনিস্ট্রেটর পাওয়ার নিয়ে কমান্ড চালানো।
*   **কখন লাগবে:** সফটওয়্যার ইন্সটল করতে বা সিস্টেম ফাইল এডিট করতে।
*   **Example:**
    ```bash
    sudo apt update
    # পাসওয়ার্ড চাইবে
    ```

#### **`chmod` (Change Mode)**
*   **কাজ:** ফাইলের পারমিশন বদলানো (কে পড়তে পারবে, কে লিখতে পারবে)।
*   **কখন লাগবে:** কোনো স্ক্রিপ্ট রান হচ্ছে না? পারমিশন দিতে হবে।
*   **Example:**
    ```bash
    chmod +x script.sh  # ফাইলটাকে এক্সিকিউটেবল (Run করার যোগ্য) বানালাম
    chmod 777 file.txt  # সবাইকে সব পারমিশন (বাজে প্র্যাকটিস, কিন্তু কাজের)
    ```

#### **`chown` (Change Owner)**
*   **কাজ:** ফাইলের মালিকানা পরিবর্তন করা।
*   **Example:**
    ```bash
    sudo chown user:group file.txt
    ```

### **৪. প্রসেস মনিটরিং (Doctor's Checkup)**
পিসি স্লো কেন? কে র‍্যাম খাচ্ছে?

#### **`top` বা `htop`**
*   **কাজ:** টাস্ক ম্যানেজার। লাইভ CPU এবং RAM ইউসেজ দেখা।
*   **Example:**
    ```bash
    top
    # বের হতে 'q'
    ```

#### **`ps` (Process Status)**
*   **কাজ:** বর্তমানে কী কী প্রোগ্রাম চলছে তার স্ন্যাপশট।
*   **Example:**
    ```bash
    ps aux
    ps aux | grep dotnet  # শুধু ডটনেট অ্যাপগুলো খোঁজো
    ```

#### **`kill`**
*   **কাজ:** হ্যাং হওয়া বা বেয়াদব প্রোগ্রাম বন্ধ করা।
*   **Example:**
    ```bash
    kill 1234      # 1234 হলো Process ID (PID)
    kill -9 1234   # জোর করে ঘাড় ধাক্কা দিয়ে বের করা (Force Kill)
    ```

### **৫. নেটওয়ার্কিং (The Postman)**
ইন্টারনেট আছে তো? এপিআই কাজ করে তো?

#### **`ping`**
*   **কাজ:** সার্ভার জ্যান্ত আছে কিনা চেক করা।
*   **Example:**
    ```bash
    ping google.com
    ```

#### **`curl` (Client URL)** 🌐 *Developer's Best Friend*
*   **কাজ:** কমান্ড লাইন ব্রাউজার। এপিআই টেস্ট করা।
*   **কখন লাগবে:** ডকার কন্টেইনারের ভেতর থেকে বাইরের জগত বা অন্য এপিআই চেক করতে।
*   **Example:**
    ```bash
    curl http://localhost:8080/api/users
    # রেসপন্স দেখাবে
    ```

#### **`ip a` (IP Address)**
*   **কাজ:** নিজের আইপি এড্রেস দেখা।
*   **Example:**
    ```bash
    ip a
    ```

### **৬. কেনাকাটা (Package Management)**
উইন্ডোজের মতো লিনাক্সে exe ফাইল নামিয়ে নেক্সট-নেক্সট করতে হয় না। কমান্ড দিলেই ইন্সটল হয়।
*(উবুন্টু/ডেবিয়ান এর জন্য)*

#### **`apt` (Advanced Package Tool)**
*   **কাজ:** অ্যাপ ইন্সটল, আপডেট বা ডিলিট করা।
*   **Example:**
    ```bash
    sudo apt update        # অ্যাপ স্টোর রিফ্রেশ করা
    sudo apt install vim   # Vim এডিটর ইন্সটল করা
    sudo apt remove vim    # ডিলিট করা
    ```

### **রিয়েল লাইফ সিনারিও (ডকার ইঞ্জিনিয়ার হিসেবে)**

ধরো তোমার ডকার কন্টেইনার স্টার্ট হচ্ছে না। তুমি কী করবে?

১. `docker logs my-app` দিয়ে লগ দেখলে, কিন্তু বুঝলে না।
২. `docker exec -it my-app bash` দিয়ে কন্টেইনারের **ভেতরে ঢুকলে**।
৩. `ls -la` দিয়ে দেখলে ফাইলগুলো ঠিক জায়গায় আছে কিনা।
৪. `cat config.json` দিয়ে কনফিগারেশন চেক করলে।
৫. `curl localhost:5000` দিয়ে দেখলে অ্যাপ রেসপন্স করছে কিনা।
৬. `top` দিয়ে দেখলে প্রসেসর ১০০% হয়ে আছে কিনা।
৭. কাজ শেষ হলে `exit` দিয়ে বের হয়ে আসলে।
