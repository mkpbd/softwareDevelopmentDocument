

ওস্তাদ! লিনাক্সে (Linux) ডকার চালানো মানেই হলো "আসল হিরোগিরি"। কারণ পৃথিবীর ৯৯% সার্ভার লিনাক্সে চলে এবং সেখানে ডকারই রাজত্ব করে।

উইন্ডোজের সাথে লিনাক্সে ডকার চালানোর কিছু **পার্থক্য** আছে। লিনাক্সে তোমাকে কমান্ড দিয়ে ডকারের **ইঞ্জিন (Daemon)** কন্ট্রোল করতে হয়।

চলো, লিনাক্স স্পেশাল ডকার কমান্ডগুলো দেখে নিই।

---

### **১. ইন্সটলেশন (যদি করা না থাকে)**
উইন্ডোজে যেমন `exe` ফাইল নামাও, লিনাক্সে (যেমন Ubuntu) কমান্ড দিয়ে নামাতে হয়।

```bash
# ১. আগে লিনাক্স আপডেট করে নাও
sudo apt update

# ২. ডকার নামাও
sudo apt install docker.io -y

# ৩. ডকার ঠিকমতো নামল কিনা চেক করো
docker --version
```

---

### **২. সুডো (Sudo) প্যারা থেকে মুক্তি! 🔓**
লিনাক্সে ডকার চালাতে গেলে প্রতিবার কমান্ডের আগে `sudo` লিখতে হয়। যেমন: `sudo docker ps`। এটা খুবই বিরক্তিকর! 😤
একজন স্মার্ট ইঞ্জিনিয়ার হিসেবে আমরা এটাকে ফিক্স করব।

**কমান্ড:**
```bash
# ১. তোমার ইউজারকে 'docker' গ্রুপে অ্যাড করো
sudo usermod -aG docker $USER

# ২. পিসি বা সেশন লগ-আউট করে আবার লগ-ইন করো (অথবা নিচের কমান্ড দাও)
newgrp docker
```
**ম্যাজিক:** এখন থেকে আর `sudo` লিখতে হবে না। শুধু `docker ps` দিলেই কাজ করবে! 😎

### **৩. ইঞ্জিন স্টার্ট/স্টপ (Service Management) ⚙️**
উইন্ডোজে ডকার ডেস্কটপ অ্যাপ ওপেন করলেই ডকার চালু হয়। কিন্তু লিনাক্স সার্ভারে কোনো গ্রাফিক্স নাই। তাই `systemctl` দিয়ে ইঞ্জিন স্টার্ট দিতে হয়।

#### **`sudo systemctl start docker`**
*   **কাজ:** ডকার ইঞ্জিন চালু করা।
*   **কখন লাগবে:** পিসি অন করার পর যদি দেখো `Cannot connect to the Docker daemon` এরর দিচ্ছে।

#### **`sudo systemctl enable docker`**
*   **কাজ:** অটো-স্টার্ট চালু করা।
*   **কেন:** সার্ভার রিস্টার্ট নিলেও ডকার একা একাই চালু হয়ে যাবে।

#### **`sudo systemctl status docker`**
*   **কাজ:** ডকার ইঞ্জিন জ্যান্ত আছে নাকি মরে গেছে চেক করা।
*   **Example Output:** `Active: active (running)` (সবুজ বাতি জ্বলবে)।

### **৪. ফাইল পাথ (Path) এর পার্থক্য 📂**
এটা কমান্ড না, কিন্তু লিনাক্সে ডকার চালানোর **সবচেয়ে গুরুত্বপূর্ণ কনসেপ্ট**।

*   **Windows:** পাথ হয় `C:\Users\Project` (ব্যাকস্ল্যাশ `\`)
*   **Linux:** পাথ হয় `/home/user/project` (ফরওয়ার্ড স্ল্যাশ `/`)

**ভলিউম মাউন্ট করার সময় উদাহরণ:**

```bash
# Windows Style (ভুল লিনাক্সে কাজ করবে না) ❌
docker run -v C:\MyData:/data nginx

# Linux Style (সঠিক) ✅
docker run -v /home/user/mydata:/data nginx

# অথবা শর্টকাট (যে ফোল্ডারে আছ সেটা বোঝাতে $(pwd) ব্যবহার করো)
docker run -v $(pwd)/mydata:/data nginx
```
*(এখানে `$(pwd)` মানে বর্তমান ফোল্ডারের লোকেশনটা অটো বসিয়ে দিবে)*

### **৫. ক্লিন-আপ (Disk Space Saver) 🧹**
লিনাক্স সার্ভারে স্পেস খুব দামি। ডকার অনেক আবর্জনা জমায়।

#### **`docker system df`**
*   **কাজ:** ডকার মোট কতটুকু ডিস্ক জায়গা খাচ্ছে তা দেখা।
*   **কেন:** সার্ভার স্লো হলে চেক করার জন্য।

#### **`docker system prune -a`**
*   **কাজ:** সব বন্ধ কন্টেইনার, অব্যবহৃত ইমেজ এবং নেটওয়ার্ক এক ক্লিকে ডিলিট!
*   **সতর্কতা:** এটা চালানোর আগে "বিসমিল্লাহ" বলে নিবে, কারণ সব ক্যাশ ফাইল উড়ে যাবে।

### **৬. নেটওয়ার্কিং কমান্ড (Linux Special)**
কখনো কখনো কন্টেইনারের আইপি নিয়ে ঝামেলা হয়।

#### **`ip a | grep docker`**
*   **কাজ:** লিনাক্সের নেটওয়ার্ক লিস্টে ডকারের ইন্টারফেস (docker0) চেক করা।

### **কমপ্লিট প্র্যাকটিস (রিয়েল লাইফ সিনারিও)**

ধরো তুমি একটা লিনাক্স সার্ভারে ঢুকেছ। এখন তোমার কাজ হলো একটা **Nginx** সার্ভার চালু করা এবং চেক করা।

**স্টেপ ১: ইঞ্জিন চেক**
```bash
sudo systemctl status docker
# যদি বন্ধ থাকে: sudo systemctl start docker
```

**স্টেপ ২: কন্টেইনার রান (Linux Path সহ)**
```bash
# প্রথমে একটা html ফাইল বানাই
mkdir my-site
echo "<h1>Hello form Linux Docker</h1>" > my-site/index.html

# এবার ডকার চালাই (PWD ব্যবহার করে)
docker run -d -p 8080:80 \
  -v $(pwd)/my-site:/usr/share/nginx/html \
  --name linux-web nginx
```

**স্টেপ ৩: টেস্ট**
```bash
# লিনাক্সে ব্রাউজার নাই, তাই curl দিয়ে চেক করো
curl localhost:8080
# আউটপুট আসবে: <h1>Hello form Linux Docker</h1>
```

**স্টেপ ৪: প্রসেস দেখা (Linux Style)**
```bash
# সাধারণ ডকার কমান্ড
docker ps 

# লিনাক্স স্টাইল (CPU/RAM প্রসেস দেখা)
top | grep docker
```
