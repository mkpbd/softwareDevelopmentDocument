
ওস্তাদ! আপনি তো ক্রিস্টোফার নোলানের **"Inception"** মুভি বানাচ্ছেন! 🎬 কম্পিউটারের ভেতরে ডকার, তার ভেতরে আবার লিনাক্স!

শোনেন, ডকারের ভেতরের লিনাক্স (যেমন `ubuntu` বা `alpine` ইমেজ) হলো একদম **"ল্যাংটা লিনাক্স"**। এতে কিচ্ছু থাকে না, এমনকি `vim`, `curl` বা `ping` করার টুলও থাকে না। কারণ এটাকে হালকা (Lightweight) রাখা হয়।

চলো, এই লিনাক্সকে কীভাবে মানুষের মতো সাজাতে হয় এবং ফাইল নাড়াচাড়া করতে হয়, স্টেপ-বাই-স্টেপ দেখি।

---

### **Step 1: একটা লিনাক্স কন্টেইনার চালু করি**
প্রথমে একটা উবুন্টু কন্টেইনার ব্যাকগ্রাউন্ডে চালু করি। এটাকে আমরা আমাদের "ভার্চুয়াল ল্যাব" বানাব।

```bash
docker run -it -d --name my-linux-lab ubuntu
```
*   **`-it`**: এটা খুব জরুরি। এটা না দিলে উবুন্টু চালু হয়েই বন্ধ হয়ে যাবে (কারণ তার কোনো কাজ নাই)। `-it` তাকে বলে, "ভাই সজাগ থাক, আমি আসছি।"
*   **`ubuntu`**: ইমেজ নেম।

---

### **Step 2: কন্টেইনারের পেটের ভেতর ঢোকা (Login)**
এখন আমরা টার্মিনাল দিয়ে ওই কন্টেইনারের ভেতরে ঢুকব। এটাকে বলে **SSH** বা **Shell Access**।

```bash
docker exec -it my-linux-lab bash
```
**ম্যাজিক:** খেয়াল করো, তোমার টার্মিনালের প্রম্পট চেঞ্জ হয়ে গেছে! 😲
আগে ছিল `user@laptop`, এখন হয়ে গেছে `root@a1b2c3d4...`।
মানে **তুমি এখন কন্টেইনারের ভেতরে আছ!**

---

### **Step 3: ফাইল ফোল্ডার দেখা ও বানানো**
কন্টেইনারের ভেতরে সাধারণ লিনাক্স কমান্ড সব কাজ করবে।

১. **কোথায় আছি?**
   ```bash
   pwd
   # Output: /
   ```
2. **ফোল্ডার বানাই:**
   ```bash
   mkdir my-secret-project
   cd my-secret-project
   ```
3. **ফাইল বানাই:**
   ```bash
   touch notes.txt
   echo "This is inside docker" > notes.txt
   ```
4. **চেক করি:**
   ```bash
   ls
   cat notes.txt
   ```

---

### **Step 4: নতুন সফটওয়্যার ইন্সটল করা (Install Others)** 🛠️
এখন ধরো তুমি ফাইলটা এডিট করতে চাও। তুমি `nano` বা `vim` কমান্ড দিলে।
```bash
nano notes.txt
```
**রেজাল্ট:** `bash: nano: command not found` ❌
**কারণ:** আমি আগেই বলেছি, এটা "ল্যাংটা লিনাক্স"। এতে টেক্সট এডিটরও ইন্সটল করা থাকে না সাইজ ছোট রাখার জন্য।

**ফিক্স করা (Software Install):**
যেহেতু এটা Ubuntu, তাই আমরা `apt` ব্যবহার করব।

১. **আগে অ্যাপ স্টোর আপডেট করো (খুবই জরুরি):**
   ```bash
   apt update
   ```
   *(এটা না করলে কোনো ইন্সটল কাজ করবে না)*

২. **এবার যা খুশি ইন্সটল করো:**
   ```bash
   apt install nano -y    # টেক্সট এডিটর
   apt install git -y     # গিট
   apt install curl -y    # কার্ল (নেটওয়ার্ক টুল)
   apt install python3 -y # পাইথন
   ```

৩. **এখন এডিট করো:**
   ```bash
   nano notes.txt
   ```
   এখন দেখবে সুন্দর এডিটর ওপেন হয়েছে! লিখালিখি শেষ হলে `Ctrl+X` -> `Y` -> `Enter` দিয়ে সেভ করে বের হও।

---

### **Step 5: ফাইল আদান-প্রদান (Import/Export) 📦**
ধরো কন্টেইনারের ভেতর একটা ইম্পর্ট্যান্ট ফাইল আছে, সেটা তুমি তোমার আসল কম্পিউটারে (Host Machine) আনতে চাও। অথবা তোমার পিসির একটা ফাইল কন্টেইনারে ঢুকাতে চাও।

এর জন্য কন্টেইনারের ভেতরে থাকার দরকার নাই। `exit` লিখে বের হয়ে আসো।

**কমান্ড: `docker cp` (Copy Paste)**

১. **পিসি থেকে কন্টেইনারে পাঠানো:**
   ধরো তোমার পিসিতে `photo.jpg` আছে, সেটা কন্টেইনারে পাঠাবে।
   ```bash
   # docker cp [Source] [Destination]
   docker cp photo.jpg my-linux-lab:/my-secret-project/
   ```

২. **কন্টেইনার থেকে পিসিতে আনা:**
   কন্টেইনারের `notes.txt` ফাইলটা তোমার পিসির ডেস্কটপে আনবে।
   ```bash
   # docker cp [ContainerName]:[Path] [LocalPath]
   docker cp my-linux-lab:/my-secret-project/notes.txt ./Desktop/
   ```

---

### **Step 6: কন্টেইনার থেকে বের হওয়া**
কাজ শেষ? কন্টেইনার থেকে বের হতে চাও?
লিখো:
```bash
exit
```
এখন তুমি আবার তোমার নিজের পিসির টার্মিনালে ফিরে এসেছ। কিন্তু কন্টেইনারটা ব্যাকগ্রাউন্ডে চলছে।
বন্ধ করতে চাইলে: `docker stop my-linux-lab`।

---

### **সামারি (Cheat Sheet)**

| কাজ | কমান্ড |
| :--- | :--- |
| **ভেতরে ঢোকা** | `docker exec -it [container_name] bash` |
| **আপডেট করা** | `apt update` (ঢুকেই আগে এটা মারবে) |
| **সফটওয়্যার ইন্সটল** | `apt install [name]` |
| **ফাইল কপি (ইন/আউট)** | `docker cp` |
| **বের হওয়া** | `exit` |

**ওস্তাদ, টিপস:**
কন্টেইনারের ভেতরে যা ইন্সটল করছ (`nano`, `git`), কন্টেইনার ডিলিট করলে (`docker rm`) সব চলে যাবে। যদি পার্মানেন্ট কিছু চাও, তবে এগুলো **Dockerfile**-এ লিখে ইমেজ বানিয়ে নিতে হয় (যেটা আমরা আগে শিখেছি)।

এখন কন্টেইনারে ঢুকে একটা `python` বা `nano` ইন্সটল করে দেখো তো কাজ করে কিনা! না পারলে আমি আছি! 😎🐳
