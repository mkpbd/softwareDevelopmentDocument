### **১. ইমেজ সংক্রান্ত কমান্ড (The Recipe Management)**
রান্নার আগে রেসিপি (Image) ম্যানেজ করা শিখতে হবে।

#### **`docker pull`**
*   **কাজ:** ইন্টারনেট (Docker Hub) থেকে ইমেজ নামানো।
*   **কেন:** তোমার পিসিতে রেসিপি না থাকলে তো ডাউনলোড করতেই হবে।
*   **Example:**
    ```bash
    docker pull nginx
    # nginx এর লেটেস্ট ইমেজ নামাবে
    ```

#### **`docker images` (বা `docker image ls`)**
*   **কাজ:** তোমার পিসিতে বর্তমানে কী কী ইমেজ (রেসিপি) আছে তার লিস্ট দেখা।
*   **কেন:** স্টক চেক করার জন্য।
*   **Example:**
    ```bash
    docker images
    ```

#### **`docker build`**
*   **কাজ:** Dockerfile থেকে নিজের ইমেজ বানানো।
*   **কেন:** নিজের কোডকে ডকার ইমেজে কনভার্ট করতে।
*   **Example:**
    ```bash
    docker build -t my-app:v1 .
    # -t মানে ট্যাগ বা নাম দেওয়া, শেষের ডট (.) মানে বর্তমান ফোল্ডার
    ```

#### **`docker rmi`**
*   **কাজ:** ইমেজ ডিলিট করা (Remove Image)।
*   **কেন:** ডিস্ক স্পেস খালি করতে। পচা বা পুরান রেসিপি ফেলে দেওয়া।
*   **Example:**
    ```bash
    docker rmi my-app:v1
    # যদি এরর দেয় (বলছে ইমেজটা ইউজ হচ্ছে), তবে -f (force) লাগাতে পারো
    ```

### **২. কন্টেইনার চালানো ও বন্ধ করা (Running the Show)**
সবচেয়ে বেশি এই কমান্ডগুলোই ব্যবহার হবে।

#### **`docker run`**
*   **কাজ:** ইমেজ থেকে কন্টেইনার তৈরি এবং চালু করা।
*   **কেন:** অ্যাপ লাইভ করার জন্য।
*   **Example:**
    ```bash
    docker run -d -p 80:80 --name my-webserver nginx
    ```
    *   `-d`: ব্যাকগ্রাউন্ডে চলবে (Detached)।
    *   `-p`: পোর্ট কানেক্ট করা (External:Internal)।
    *   `--name`: কন্টেইনারের নাম দেওয়া।

#### **`docker ps`**
*   **কাজ:** বর্তমানে কোন কন্টেইনারগুলো **চলছে** (Running) তা দেখা।
*   **কেন:** হাজিরা খাতা দেখার মতো—কে কে ডিউটিতে আছে।
*   **Example:**
    ```bash
    docker ps
    # বন্ধ হয়ে যাওয়া কন্টেইনারসহ সব দেখতে চাইলে:
    docker ps -a
    ```

#### **`docker stop`**
*   **কাজ:** চলমান কন্টেইনার থামানো (Destroy করে না, শুধু Stop করে)।
*   **কেন:** গাড়ি পার্ক করার মতো, কাজ শেষ তাই থামালাম।
*   **Example:**
    ```bash
    docker stop my-webserver
    # নাম অথবা Container ID ব্যবহার করতে পারো
    ```

#### **`docker start`**
*   **কাজ:** থামানো কন্টেইনার আবার চালু করা।
*   **কেন:** পার্ক করা গাড়ি স্টার্ট দেওয়া।
*   **Example:**
    ```bash
    docker start my-webserver
    ```

#### **`docker rm`**
*   **কাজ:** কন্টেইনার একেবারে ডিলিট করে দেওয়া।
*   **কেন:** প্লেট ধুয়ে ফেলার মতো। কন্টেইনার আর দরকার নাই।
*   **Example:**
    ```bash
    docker rm my-webserver
    # যদি কন্টেইনার চলতে থাকে, তবে -f দিয়ে জোর করে ডিলিট করা যায়
    docker rm -f my-webserver
    ```

### **৩. ডিবাগিং এবং পোস্টমর্টেম (Doctor & Detective Tools)**
অ্যাপ চলছে না? এরর দিচ্ছে? তখন এইগুলো কাজে লাগবে।

#### **`docker logs`**
*   **কাজ:** কন্টেইনারের ভেতরের কনসোল আউটপুট বা এরর দেখা।
*   **কেন:** কেন অ্যাপ ক্র্যাশ করল সেটা বুঝতে। এটা ডেভেলপারদের বেস্ট ফ্রেন্ড।
*   **Example:**
    ```bash
    docker logs my-webserver
    # লাইভ লগ দেখতে চাইলে -f (follow) লাগাও
    docker logs -f my-webserver
    ```

#### **`docker exec`**
*   **কাজ:** চলমান কন্টেইনারের **ভেতরে** ঢুকে কমান্ড চালানো।
*   **কেন:** মনে করো কন্টেইনার একটা বন্ধ ঘর, তুমি ম্যাজিক করে ভেতরে ঢুকে ফাইল চেক করতে চাও।
*   **Example:**
    ```bash
    docker exec -it my-webserver bash
    # -it মানে interactive terminal. এখন তুমি কন্টেইনারের লিনাক্স টার্মিনালে আছ।
    ```

#### **`docker inspect`**
*   **কাজ:** কন্টেইনারের নাড়ি-নক্ষত্র (IP Address, Environment Variables, Paths) বের করা।
*   **কেন:** টেকনিক্যাল ডিটেইলস বা "DNA Test" করার জন্য।
*   **Example:**
    ```bash
    docker inspect my-webserver
    ```

### **৪. পরিষ্কার-পরিচ্ছন্নতা (Housekeeping)**
কাজ করতে করতে অনেক জঞ্জাল জমে যায়, সেগুলো সাফ করতে হয়।

#### **`docker system prune`**
*   **কাজ:** অব্যবহৃত সব কন্টেইনার, নেটওয়ার্ক এবং ঝুলে থাকা ইমেজ ডিলিট করে দেয়।
*   **কেন:** এক ক্লিকে পিসি ক্লিন করতে। (সাবধানে ব্যবহার করবে!)
*   **Example:**
    ```bash
    docker system prune
    # সব ভলিউমসহ ডিলিট করতে চাইলে:
    docker system prune -a --volumes
    ```

### **৫. Docker Compose (The Manager)**
যখন `docker-compose.yml` ফাইল ব্যবহার করবে।

#### **`docker-compose up`**
*   **কাজ:** কম্পোজ ফাইলে থাকা সব সার্ভিস একসাথে তৈরি এবং চালু করা।
*   **কেন:** এক কমান্ডে ফুল প্রজেক্ট রান করতে।
*   **Example:**
    ```bash
    docker-compose up -d
    # -d দিলে ব্যাকগ্রাউন্ডে চলবে
    ```

#### **`docker-compose down`**
*   **কাজ:** সব সার্ভিস বন্ধ করা এবং রিমুভ করা।
*   **কেন:** দোকান বন্ধ করে বাড়ি যাওয়ার সময়।
*   **Example:**
    ```bash
    docker-compose down
    ```

### **বোনাস চিটশিট (Cheat Sheet)**

| কমান্ড | কাজ (সহজ বাংলায়) |
| :--- | :--- |
| `docker version` | ডকার ঠিকঠাক ইন্সটল আছে কিনা দেখা |
| `docker stats` | কন্টেইনার কতটুকু RAM/CPU খাচ্ছে দেখা (Task Manager এর মতো) |
| `docker volume ls` | পিসিতে কয়টা ভলিউম (স্টোরেজ) আছে দেখা |
| `docker network ls` | নেটওয়ার্ক লিস্ট দেখা |
