### **১. Dockerfile (রান্নার রেসিপি)** 📜

ডটনেটের জন্য Dockerfile একটু স্পেশাল হয়। এখানে আমরা **Multi-stage build** ব্যবহার করব।
*কেন?* কারণ রান্নাঘরে (SDK) অনেক ময়লা (Source code, tools) থাকে, কিন্তু খাওয়ার টেবিলে (Runtime) আমরা শুধু পরিষ্কার খাবার (DLL files) চাই। এতে ইমেজের সাইজ ছোট হয়।

**Project Root Folder-এ একটা ফাইল বানাও `Dockerfile` নামে:**

```dockerfile
# Stage 1: Build (রান্নাঘর)
# আমরা Microsoft এর SDK ইমেজ নিচ্ছি, যেখানে সব টুলস আছে
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src

# আগে শুধু প্রোজেক্ট ফাইল কপি করি (Layer Caching এর সুবিধার জন্য)
COPY ["MyDotnetApp.csproj", "./"]
# প্রয়োজনীয় প্যাকেজ নামাই (Restore)
RUN dotnet restore

# এবার বাকি সব কোড কপি করি
COPY . .
# রান্না শুরু (Build & Publish) - রিলিজ মুডে
RUN dotnet publish -c Release -o /app/publish

# Stage 2: Runtime (খাবার টেবিল)
# এটা খুব হালকা ইমেজ, শুধু অ্যাপ চালানোর ক্ষমতা আছে
FROM mcr.microsoft.com/dotnet/aspnet:8.0
WORKDIR /app

# রান্নাঘর (build stage) থেকে তৈরি খাবার (DLLs) টেবিলে নিয়ে আসলাম
COPY --from=build /app/publish .

# অ্যাপ রান করার কমান্ড
ENTRYPOINT ["dotnet", "MyDotnetApp.dll"]
```

**কি হলো এখানে?**
*   আমরা প্রথমে `sdk` ইমেজ দিয়ে কোড কম্পাইল করলাম।
*   তারপর `aspnet` (runtime) ইমেজে শুধু `dll` গুলো কপি করে আনলাম। ফলে ইমেজের সাইজ ৫০০MB থেকে কমে ১০০MB হয়ে গেল!

### **২. Image (প্যাকেটজাত খাবার)** 📦

রেসিপি রেডি। এবার ওভেনে দিয়ে প্যাকেট বানাবো।

টার্মিনাল ওপেন করো (যেখানে Dockerfile আছে) এবং কমান্ড দাও:

```bash
docker build -t my-dotnet-api:v1 .
```

*   **`docker build`**: রান্না শুরু করো।
*   **`-t my-dotnet-api:v1`**: খাবারের প্যাকেটের নাম দিলাম "my-dotnet-api" এবং ভার্সন ১।
*   **`.`**: রেসিপি (Dockerfile) এখানেই আছে।

কম্পিউটার কিছুক্ষণ ঘটর-ঘটর করে একটা ইমেজ বানিয়ে ফেলবে। চেক করতে চাইলে: `docker images` কমান্ড দাও।

### **৩. Container (খাবার প্লেটে দেওয়া - Running App)** 🍲

প্যাকেট রেডি, এবার ছিঁড়ে খাওয়া শুরু (Run)।

```bash
docker run -d -p 8080:8080 --name my-running-api my-dotnet-api:v1
```

**ব্যাখ্যা:**
*   **`-d`**: Detached mode (ব্যাকগ্রাউন্ডে চলবে, টার্মিনাল আটকে রাখবে না)।
*   **`-p 8080:8080`**: তোমার পিসির ৮০৮০ পোর্টে রিকোয়েস্ট করলে কন্টেইনারের ৮০৮০ পোর্টে যাবে। (তোমার কোডে `app.Run()` এ পোর্ট কনফিগারেশন অনুযায়ী এটা বদলাতে পারে)।
*   **`--name`**: কন্টেইনারের একটা সুন্দর নাম দিলাম।

এখন ব্রাউজারে গিয়ে `http://localhost:8080/weatherforecast` (ডিফল্ট কন্ট্রোলার) হিট করো। ডাটা দেখতে পাচ্ছ? তার মানে কন্টেইনার জ্যান্ত!

### **৪. Volume (প্লেট - Data Persistence)** 💾

ধরো, তোমার ডটনেট অ্যাপ একটা `app.log` ফাইলে লগ লিখে রাখে। বা SQLite ডাটাবেস ব্যবহার করে। কন্টেইনার রিস্টার্ট দিলে এই ফাইল গায়েব হয়ে যাবে। সেটা আটকাবো কীভাবে?

আমরা আমার পিসির একটা ফোল্ডারকে কন্টেইনারের ফোল্ডারের সাথে "আঠা" দিয়ে লাগিয়ে দিব।

```bash
docker run -d -p 8080:8080 \
  -v D:\MyLogs:/app/logs \
  my-dotnet-api:v1
```

**ব্যাখ্যা:**
*   **`-v D:\MyLogs:/app/logs`**: আমার পিসির `D:\MyLogs` ফোল্ডার আর কন্টেইনারের `/app/logs` ফোল্ডার এখন যমজ ভাই।
*   অ্যাপ যখন কন্টেইনারের ভেতরে `/app/logs`-এ কিছু লিখবে, সেটা ম্যাজিকের মতো তোমার পিসির `D:\MyLogs`-এ সেভ হয়ে যাবে। কন্টেইনার ডিলিট করলেও লগ ফাইল থেকে যাবে।

### **৫. Docker Compose (ফুল কোর্সের ডিনার সেট)** 🍱

রিয়েল লাইফে শুধু অ্যাপ দিয়ে হয় না, সাথে **SQL Server** (Database) লাগে।
আলাদা আলাদা কমান্ড না দিয়ে, আমরা একটা `docker-compose.yml` ফাইল বানাবো। এখানে একটা .NET API এবং একটা SQL Server একসাথে রান করবে।

**ফাইল: `docker-compose.yml`**

```yaml
version: '3.4'

services:
  # সার্ভিস ১: আমাদের ডটনেট অ্যাপ
  webapi:
    image: my-dotnet-api:v1
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "8080:8080"
    environment:
      # কানেকশন স্ট্রিং-এ খেয়াল করো, Server=db (সার্ভিস নেম)
      - ConnectionStrings__DefaultConnection=Server=db;Database=MasterDB;User=sa;Password=Your_Strong_Password123;TrustServerCertificate=True;
    depends_on:
      - db

  # সার্ভিস ২: SQL Server
  db:
    image: mcr.microsoft.com/mssql/server:2022-latest
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=Your_Strong_Password123
    ports:
      - "1433:1433"
    volumes:
      - sql-data:/var/opt/mssql

# ডাটাবেসের ডাটা সেফ রাখার জন্য ভলিউম
volumes:
  sql-data:
```

**মজার বিষয়:**
১. **Networking:** ডটনেট অ্যাপ ডাটাবেসকে চিনে `Server=db` নামে। আইপি এড্রেস মুখস্থ করার প্যারা নাই!
২. **Password:** SQL Server-এ স্ট্রং পাসওয়ার্ড দিতে হয় (বড় হাতের, ছোট হাতের অক্ষর, সংখ্যা), নাহলে কন্টেইনার চালু হয়েই বন্ধ হয়ে যাবে।

**ফাইনাল অ্যাকশন:**
টার্মিনালে লিখো:
```bash
docker-compose up -d
```
বুম! 💥 তোমার অ্যাপ এবং ডাটাবেস একসাথে চালু হয়ে গেল। এখন তোমার অ্যাপ ডাটাবেসে কানেক্ট করে কাজ করতে পারবে।
