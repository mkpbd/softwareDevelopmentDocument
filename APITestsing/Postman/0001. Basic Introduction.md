শুরু করার আগে একটা ওয়ার্নিং: **ক্লাস বোরিং হলে পয়সা ফেরত! (যদিও আপনি পয়সা দিচ্ছেন না 😜)**

চলুন, বিসমিল্লাহ বলে শুরু করি।

### **পর্ব-১: Postman কী এবং কেন? (Introduction)**

**Postman কী?**
নাম শুনেই মনে হচ্ছে সেই আগের যুগের "চিঠির পিয়ন", তাই না? যে সাইকেল চালিয়ে প্রেমিকার চিঠি নিয়ে আসত?
ব্যাপারটা কিছুটা তেমনই! তবে ডিজিটাল যুগে।

সহজ বাংলায়:
ধরুন আপনি রেস্টুরেন্টে গেলেন। আপনি টেবিলে বসে আছেন (Client), আর রান্নাঘর (Server) আছে ভেতরে। আপনি কি নিজে রান্নাঘরে গিয়ে বলবেন—"এই বাবুর্চি, এক প্লেট কাচ্চি দাও?" না!
আপনি ডাকবেন **ওয়েটারকে (API)**।

এখন এই ওয়েটার ঠিকঠাক কাজ করছে কি না, সে কি কাচ্চির বদলে খিচুড়ি নিয়ে আসছে কি না—এটা চেক করার জন্য যেই টুলসটা আমরা ব্যবহার করি, সেটাই হলো **Postman**।

**কেন শিখব?**
কারণ ডেভেলপাররা যখন কোড লেখে, তখন তাদের বানানো API (Application Programming Interface) ঠিকমতো কাজ করছে কি না তা টেস্ট করতে হয়। Postman দিয়ে কোড না লিখেই আমরা এই টেস্টিং করতে পারি।

### **পর্ব-২: পিসি-তে Postman ঢুকানো (Installation)**

Postman ইন্সটল করা "ফেসবুক একাউন্ট" খোলার চেয়েও সহজ। ফলো করুন:

১. **Google মামাকে ডাকুন:** ব্রাউজারে গিয়ে লিখুন `Download Postman`.
২. **অফিসিয়াল সাইট:** `postman.com/downloads` এ যান।
৩. **Download:** উইন্ডোজ, ম্যাক বা লিনাক্স—আপনার পিসি যা খায়, সেই ভার্সন নামিয়ে ফেলুন।
৪. **Install:** সেটআপ ফাইলে ডাবল ক্লিক। নেক্সট-নেক্সট-ফিনিশ। ব্যাস!
৫. **Sign Up:** ইন্সটল হলে বলবে সাইন-আপ করতে। গুগল একাউন্ট দিয়ে করে ফেলুন। না করলেও সমস্যা নেই, কিন্তু করলে আপনার কাজগুলো ক্লাউডে সেভ থাকবে (পিসি ক্র্যাশ করলেও হারাবে না)।

### **পর্ব-৩: জীবনের প্রথম API Request (GET Request)**

এখন আমরা আসল খেলায় নামব। আমরা একটা **Fake API** ব্যবহার করব। কারণ আসল সার্ভার হ্যাক করলে পুলিশ ধরবে! 🚓

আমরা ব্যবহার করব: `reqres.in` (এটা একটা ফ্রি টেস্টিং সাইট)।

**Step-by-Step গাইড:**

১. **Postman ওপেন করুন:** সুন্দর একটা কমলা রঙের লোগোওয়ালা অ্যাপ আসবে।
২. **Workspace:** উপরে দেখবেন `Workspaces` লেখা। ওখানে ক্লিক করে `My Workspace` এ যান। এটা হলো আপনার কাজের টেবিল।
৩. **New Request:** বাম পাশে `+` বা `New` বাটনে ক্লিক করুন। একটা নতুন ট্যাব খুলবে (ব্রাউজারের মতো)।
৪. **Method সিলেক্ট করুন:** ড্রপডাউন মেনুতে দেখবেন `GET` লেখা আছে।
   * *GET মানে কী?* দোকানদারকে বলা, "ভাই, মেনুটা **দেন** (Give/Get)"। মানে সার্ভার থেকে তথ্য আনা।
৫. **URL বসান:** যেখানে `Enter request URL` লেখা আছে, সেখানে এই লিংকটা কপি-পেস্ট করুন:
   👉 `https://reqres.in/api/users?page=2`
৬. **Send বাটন চাপুন:** ডানপাশে নীল রঙের `Send` বাটনে জোরে একটা চাপ দিন! (মাউস ভাঙবেন না কিন্তু)।

**কী ঘটল? (Result Analysis)**

নিচে দেখবেন `Body` সেকশনে কিছু লেখা এসেছে। দেখতে অনেকটা এমন:

```json
{
    "page": 2,
    "per_page": 6,
    "total": 12,
    "data": [
        {
            "id": 7,
            "email": "michael.lawson@reqres.in",
            "first_name": "Michael",
            "last_name": "Lawson"
            ...
        }
    ]
}
```

**মজার ব্যাপারগুলো খেয়াল করুন:**
১. **Status Code:** ডানপাশে কোণায় সবুজ রঙে লেখা `200 OK`।
   * *এটার মানে:* "মিশন সাকসেসফুল বস! ডাটা পাইছি।" (সবুজ বাতি মানেই দিল খুশ!)
   * যদি `404 Not Found` আসত, তার মানে—"ভাই, যেই লিন্ক দিছেন, ওই নামে দুনিয়ায় কিছু নাই।"
   * যদি `500 Server Error` আসত, তার মানে—"রান্নাঘরে আগুন লাগছে (সার্ভার নষ্ট)।"

২. **Response Body:** যেই আজব লেখাগুলো দেখছেন (সেকেন্ড ব্র্যাকেট `{}` দিয়ে ঘেরা), একে বলে **JSON** (JavaScript Object Notation)। এটাকে "ডাটার টিফিন বক্স" ভাবতে পারেন। এর ভেতরেই সব ইনফরমেশন থাকে।
