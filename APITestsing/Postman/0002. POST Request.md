আজকের ক্লাসে আমরা শিখব কীভাবে **ডাটা পাঠাতে হয়**। এতদিন তো শুধু চেয়ে চেয়ে নিলেন (GET), আজ কিছু দেওয়ার পালা!

### **পর্ব-৪: POST Request (সার্ভারে তথ্য পাঠানো)**

**POST Request কী?**
সহজ বাংলায়: ফেসবুকে যখন স্ট্যাটাস দেন—"Feeling hungry with 69 others"—তখন আপনি সার্ভারে তথ্য পাঠাচ্ছেন। এটাই হলো **POST Request**।

আগের ক্লাসে আমরা রেস্টুরেন্টের মেনু দেখেছিলাম (GET)। আজ আমরা **অর্ডার প্লেস** করব। মানে কিচেনে স্লিপ পাঠাব যে—"বাবুর্চি, আমার জন্য কাচ্চি বানাও।"

**Step-by-Step গাইড (Create a User):**

১. **New Tab:** Postman-এ আগের মতো `+` আইকনে ক্লিক করে নতুন ট্যাব খুলুন।
২. **Method:** ড্রপডাউন থেকে `GET` বদলে `POST` সিলেক্ট করুন। (রঙ দেখবেন হলুদ হয়ে গেছে)।
৩. **URL:** এই লিংকটা বসান: `https://reqres.in/api/users`
৪. **Body (আসল কাজ):** GET রিকোয়েস্টে বডি লাগত না, কিন্তু POST-এ তো সার্ভারকে ডাটা দিতে হবে।
   * `Body` ট্যাবে ক্লিক করুন (URL বারের ঠিক নিচে)।
   * `raw` সিলেক্ট করুন।
   * ডানপাশে `Text` লেখা ড্রপডাউন থেকে `JSON` সিলেক্ট করুন।

৫. **JSON লেখা:** নিচের সাদা বক্সে এই কোডটুকু লিখুন (নাম চাইলে আপনার নিজেরটা দিতে পারেন, আমি "মফিজ" দিলাম):

```json
{
    "name": "Mofiz",
    "job": "Leader"
}
```
*(সাবধান: সেকেন্ড ব্র্যাকেট `{}` আর ডাবল কোটেশন `""` মিস করবেন না। JSON খুব সেন্সিটিভ, একটু ভুল হলেই এরর খাবেন!)*

৬. **Send:** নীল বাটনে চাপ দিন।

**ফলাফল (Result Analysis):**
নিচে রেসপন্স বডিতে দেখবেন সার্ভার রিপ্লাই দিয়েছে:
```json
{
    "name": "Mofiz",
    "job": "Leader",
    "id": "486",
    "createdAt": "2024-05-XX..."
}
```
এর মানে সার্ভার বলছে: "ওকে বস! মফিজ নামের লিডারকে আমি ডাটাবেসে এন্ট্রি করে নিয়েছি। তার রোল নম্বর (ID) হলো 486।"

**Status Code খেয়াল করুন:**
এবার কিন্তু `200 OK` আসবে না। আসবে **`201 Created`**।
*   `201` মানে: "মুবারক হো! নতুন কিছু তৈরি হয়েছে।"

### **পর্ব-৫: ঘরদোর গুছানো (Collections)**

আপনি যদি এলোমেলোভাবে রিকোয়েস্ট পাঠাতে থাকেন, কয়দিন পর Postman হয়ে যাবে ব্যাচেলরের রুমের মতো। মোজা কোথায় আর প্যান্ট কোথায়—কিছুই খুঁজে পাবেন না।

তাই আমাদের বানাতে হবে **Collection**। এটা হলো ফোল্ডার বা ফাইলের মতো।

**কিভাবে করবেন?**
১. বাম পাশে `Collections` ট্যাবে ক্লিক করুন।
২. `+` বা `Create new Collection` এ চাপ দিন।
৩. নাম দিন: **"My First API Course"**।
৪. এখন, আজকের `POST` রিকোয়েস্টটা সেভ (Save) বাটনে ক্লিক করুন।
৫. নাম দিন: **"Create User"**।
৬. ফোল্ডার হিসেবে `My First API Course` সিলেক্ট করে সেভ করুন।

ব্যাস! এখন সব রিকোয়েস্ট সুন্দর করে ফোল্ডারে থাকবে।
