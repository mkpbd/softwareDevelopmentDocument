### **পর্ব-১০: Tests Script (অটোমেটিক খাতা দেখা)**

**Test Script কী?**
এটা হলো Postman-এর কাছে একটা ছোট চিরকুট লিখে দেওয়া:
*"ভাই Postman, রিকোয়েস্ট পাঠানোর পর তুমি চেক করবা স্ট্যাটাস কোড ২০০ কি না। যদি ২০০ হয়, তাইলে বলবা PASS, আর না হলে বলবা FAIL।"*

Postman এই কাজটা করে **JavaScript** ব্যবহার করে। ভয় পাবেন না, কোড মুখস্থ করা লাগবে না! Postman আমাদের জন্য **Copy-Paste** ব্যবস্থা করে রেখেছে।

**Step-by-Step গাইড:**

১. **GET Request ওপেন করুন:** আপনার `Get Single User` রিকোয়েস্টটা ওপেন করুন।
২. **Tests ট্যাবে যান:** URL বারের নিচে `Params`, `Auth` এর পরেই দেখবেন **`Tests`** নামের একটা ট্যাব আছে। ওখানে ক্লিক করুন।
   *(এখানে আমরা কোড লিখব)*।
3. **Snippets এর জাদু:** ডানপাশে তাকিয়ে দেখুন **"Snippets"** নামে একটা লিস্ট আছে।
   *   খুঁজে বের করুন: `Status code: Code is 200`
   *   ওটার ওপর একটা ক্লিক করুন।

দেখবেন বাম পাশের সাদা বক্সে ম্যাজিকের মতো একটা কোড চলে এসেছে:

```javascript
pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});
```

**কোড বুঝুন (সহজ ভাষায়):**
*   `pm.test(...)`: Postman-কে বলা হচ্ছে, "একটা টেস্ট শুরু করো"।
*   `"Status code is 200"`: এটা পরীক্ষার নাম।
*   `pm.response.to.have.status(200)`: এটা আসল চেকিং। যদি ২০০ আসে, পাস। অন্য কিছু আসলে ফেইল।

৪. **Send করুন:** এবার নীল `Send` বাটনে চাপ দিন।
৫. **Test Results:** নিচে রেসপন্স বডির পাশে **`Test Results`** ট্যাবে ক্লিক করুন (সাধারণত `Body` ট্যাবের পাশেই থাকে)।
   *   দেখবেন সবুজ রঙে লেখা: **PASS** Status code is 200 (1/1)।

### **পর্ব-১১: ডাটা চেক করা (ভিতরের খবর বের করা)**

শুধু স্ট্যাটাস চেক করলেই হবে না। ধরুন আপনি বিরিয়ানি অর্ডার করলেন (Status 200 OK), কিন্তু প্যাকেটের ভেতর দিল পান্তা ভাত! তখন?
তাই আমাদের ডাটাও চেক করতে হবে।

চলুন চেক করি, রেসপন্সে যেই ডাটা আসছে, সেখানে `first_name` কি আসলেই "Janet" কি না (অথবা যেই আইডি দিয়েছেন সেই অনুযায়ী নাম)।

**Step-by-Step:**
১. আবার `Tests` ট্যাবে যান।
২. আগের কোডের নিচে এন্টার দিয়ে নতুন লাইন নিন।
৩. ডানপাশের Snippets থেকে খুঁজুন: `Response body: JSON value check`। ক্লিক করুন।
৪. কোডটা দেখতে এমন হবে:
```javascript
pm.test("Your test name", function () {
    var jsonData = pm.response.json();
    pm.expect(jsonData.value).to.eql(100);
});
```
৫. **কোড এডিট করা:** আমরা এটা একটু মডিফাই করব আমাদের ডাটা অনুযায়ী।
   *   `Your test name` কেটে লিখুন `"Check First Name"`।
   *   `jsonData.value` কেটে লিখুন `jsonData.data.first_name` (কারণ আমাদের ডাটা `data` অবজেক্টের ভিতরে আছে)।
   *   `100` কেটে লিখুন `"Janet"` (বা আপনার রেসপন্সে যেই নাম আসছে)।

   **ফাইনাল কোড:**
   ```javascript
   pm.test("Check First Name", function () {
       var jsonData = pm.response.json();
       pm.expect(jsonData.data.first_name).to.eql("Janet");
   });
   ```

৬. **Send করুন:** আবার সেন্ড দিন এবং `Test Results` দেখুন।
   *   যদি নাম মিলে যায়, তবে **PASS** (সবুজ)। 🟢
   *   যদি নাম ভুল দেন (যেমন "Mofiz"), তবে **FAIL** (লাল)। 🔴

### **পর্ব-১২: Collection Runner (এক ক্লিকে সব খালাস)**

**Collection Runner কী?**
ধরুন আপনার ফোল্ডারে ১০টা API রিকোয়েস্ট আছে। আপনি কি ১০ বার গিয়ে `Send` বাটনে চাপ দিবেন? না!
আপনি রানারকে বলবেন—"এই নাও লিস্ট, সব চেক করে আমাকে ফাইনাল রিপোর্ট দাও।"

এটা অনেকটা মেশিগানের মতো—টপাটপ রিকোয়েস্ট পাঠাবে! 🔫

**Step-by-Step গাইড:**

১. **Collection সিলেক্ট করুন:**
   বাম পাশের প্যানেল থেকে আপনার কালেকশন **"My First API Course"** এর ওপর মাউস নিন।

২. **Run অপশন খুঁজুন:**
   *   কালেকশনের নামের পাশে `...` (তিনটা ডট) আছে, ওটায় ক্লিক করে `Run collection` এ চাপ দিন।
   *   অথবা, কালেকশনের নামের ওপর ক্লিক করলে ডানপাশে `Run` নামের একটা বাটন পাবেন।

৩. **সেটিং ঠিক করা (Runner Tab):**
   একটা নতুন পেজ আসবে। এখানে কিছু অপশন দেখবেন:
   *   **Run order:** আপনার রিকোয়েস্টগুলো কোনটার পর কোনটা রান হবে। (চাইলে ড্র্যাগ করে আগে-পিছে করতে পারেন)।
   *   **Iterations:** কতবার লুপ চালাবেন? (আপাতত `1` থাকুক)।
   *   **Delay:** একটা রিকোয়েস্টের পর কতক্ষণ জিরোবে? (এখানে `1000ms` বা ১ সেকেন্ড দিন, যাতে সার্ভার হ্যাং না করে)।

৪. **ফায়ার করুন (Run Button):**
   নিচে বড় নীল বাটন **"Run My First API Course"** এ চাপ দিন।

**কী ঘটল? (Result Analysis)** 📊

স্ক্রিনে দেখবেন ম্যাট্রিক্স সিনেমার মতো সব রিকোয়েস্ট রান হচ্ছে।
*   **Green:** যেই টেস্টগুলো পাস করেছে (Pass)।
*   **Red:** যেই টেস্টগুলো ফেল করেছে (Fail)।

শেষে একটা সামারি দেখাবে:
*   Total Requests: ৪ (বা আপনার যতগুলো ছিল)
*   Passed: ৪
*   Failed: ০ (যদি আপনি ভালো ছাত্র হন!)

### **পর্ব-১৩: Export & Import (বন্ধুকে কোড দেওয়া)**

এখন ধরুন, আপনি এই যে এত কষ্ট করে কালেকশন বানালেন, এটা আপনার বন্ধু "বল্টু"কে দিতে চান। কীভাবে দেবেন? পেনড্রাইভে করে?
না! আমরা JSON ফাইল হিসেবে এক্সপোর্ট করব।

**Export করা (নেওয়া):**
১. কালেকশনের নামের পাশে `...` (তিনটা ডট) এ ক্লিক করুন।
২. নিচে `Export` এ ক্লিক করুন।
৩. `JSON` ফরম্যাট সিলেক্ট করে `Export` বাটনে চাপ দিন।
৪. আপনার পিসিতে একটা `.json` ফাইল ডাউনলোড হবে। এটাই আপনার কষ্টের ফসল!

**Import করা (দেওয়া):**
১. Postman-এর একদম উপরে বামে `Import` বাটনে ক্লিক করুন।
२. ওই `.json` ফাইলটা ড্র্যাগ করে ছেড়ে দিন।
৩. ব্যস! আপনার বন্ধুর পিসিতেও হুবহু আপনার কালেকশন চলে আসবে।
