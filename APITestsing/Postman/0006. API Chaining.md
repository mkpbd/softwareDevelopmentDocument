কি খবর ভাতিজা! রেডি তো? 🚀

আজকের ক্লাসটা হলো **"বড়দের ক্লাস"**। এতদিন আমরা খুচরা কাজ করেছি, আজ আমরা এক রিকোয়েস্টের ডাটা আরেক রিকোয়েস্টে পাস করব।

একে বলে **API Chaining**।

---

### **পর্ব-১৪: API Chaining (একটার মাল অন্যটায়)** 🔗

**জিনিসটা কী?**
ধরুন, আপনি বাসের টিকেট কাটলেন (Request A)। কাউন্টার থেকে আপনাকে একটা **টিকেট নম্বর** দিল। এরপর বাসে ওঠার সময় হেল্পারকে ওই **টিকেট নম্বরটাই** দেখাতে হবে (Request B)।
আপনি তো আর আন্দাজে একটা নম্বর বানিয়ে দিলে হেল্পার আপনাকে বাসে উঠতে দিবে না!

API-তেও তাই।
১. আমরা প্রথমে **User Create** করব (POST)।
২. সার্ভার আমাদের একটা **ID** দিবে।
৩. আমরা ওই **ID** টা খপ করে ধরে ফেলব।
৪. তারপর সেই ID দিয়ে ওই ইউজারকে **Delete** বা **Update** করব।

হাতে লিখে আইডি কপি-পেস্ট করা গরিবের কাজ। আমরা করব **অটোমেশন**! 😎

---

### **হাতে-কলমে শিক্ষা (Step-by-Step)**

আমরা চাই: **Create User (POST)** এর পর যেই `id` আসবে, সেটা অটোমেটিক **Delete User** এর URL-এ বসে যাবে।

**ধাপ ১: আইডি চুরি করা (Capturing Data)** 🕵️‍♂️

১. আপনার **Create User** (POST) রিকোয়েস্টটা ওপেন করুন।
২. `Tests` ট্যাবে যান।
৩. নিচের কোডটুকু লিখুন (এটা রেসপন্স থেকে আইডি বের করে ভেরিয়েবলে সেভ করবে):

```javascript
// ১. সার্ভারের রিপ্লাই (JSON) টা ধরলাম
var jsonData = pm.response.json();

// ২. রিপ্লাই থেকে 'id' টা নিলাম এবং এনভায়রনমেন্টে 'my_user_id' নামে সেভ করলাম
pm.environment.set("my_user_id", jsonData.id);

// ৩. কনসোলে প্রিন্ট করে দেখলাম (অপশনাল)
console.log("New User ID is: " + jsonData.id);
```

৪. **Send** বাটনে চাপ দিন।
৫. **জাদু চেক করুন:** উপরে ডানপাশে চোখের আইকনে (👁️) ক্লিক করুন। দেখুন `my_user_id` নামে একটা ভেরিয়েবল তৈরি হয়েছে কি না এবং পাশে একটা ভ্যালু (যেমন `id: 850` বা কিছু একটা) আছে কি না।

যদি থাকে, তাইলে কেল্লাফতে! 🎉

---

**ধাপ ২: চোরাই মাল ব্যবহার করা (Using the Variable)** 🛠️

এখন আমরা এই `my_user_id` টা ব্যবহার করব ইউজার ডিলিট করার জন্য।

১. আপনার **Delete User** রিকোয়েস্টে যান।
২. URL টা খেয়াল করুন। আগে হয়তো ছিল: `{{base_url}}/api/users/2`
৩. এখন ওই `2` (হার্ডকোড করা আইডি) মুছে দিন।
৪. ওখানে আমাদের ভেরিয়েবলটা বসান: `{{my_user_id}}`

   👉 নতুন URL দেখতে হবে: `{{base_url}}/api/users/{{my_user_id}}`

৫. **Save** করুন এবং **Send** করুন।

**ফলাফল:**
Postman অটোমেটিক আগের রিকোয়েস্ট থেকে পাওয়া আইডিটা এখানে বসিয়ে রিকোয়েস্ট পাঠাবে। আপনি `204 No Content` পাবেন।

### **পর্ব-১৫: Workflow টেস্ট করা**

এখন আপনার ফ্লো টা কেমন হলো জানেন?
**Create User** (আইডি জেনারেট হলো) ➡️ **Delete User** (ওই আইডি ডিলিট হলো)।

আপনি যদি এখন **Collection Runner** দিয়ে পুরো কালেকশন রান করেন, তাহলে দেখবেন প্রতিবার নতুন ইউজার তৈরি হচ্ছে এবং ঠিক সেই ইউজারটাই ডিলিট হচ্ছে। কারোর বাপের সাধ্য নাই আটকায়ে রাখে!

**Mini-Project ৭ (The Circle of Life):** 🦁
একটা নতুন ফোল্ডার বানান "Life Cycle"।
সেখানে নিচের সিরিয়ালে রিকোয়েস্ট সাজান:
1. **Create User** (POST) -> আইডি সেভ করুন ভেরিয়েবলে।
2. **Get User** (GET) -> URL এ ভেরিয়েবল ব্যবহার করে চেক করুন ডাটা ঠিক আছে কি না।
3. **Update User** (PUT) -> ওই একই আইডি দিয়ে নাম চেঞ্জ করুন।
4. **Delete User** (DELETE) -> সবশেষে ওই আইডি ডিলিট করে দিন।

Run Collection দিয়ে একশবার রান করলেও কোনো এরর আসবে না! এটাই অটোমেশনের শান্তি। 😌
