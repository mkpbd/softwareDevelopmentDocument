### **পর্ব-১৬: Newman (Postman এর ছোট ভাই)**

**Newman কী?**
Postman হলো একটা গ্রাফিক্যাল অ্যাপ (যেটা আপনি চোখে দেখছেন)। আর Newman হলো Postman-এর **ইঞ্জিন** যেটা কমান্ড লাইনে (CMD/Terminal) চলে।

**কেন শিখব?**
আপনার বস যখন বলবে—"প্রতিদিন রাত ১২টায় অটোমেটিক টেস্ট রান হতে হবে"—তখন কি আপনি রাত ১২টায় উঠে `Send` বাটনে চাপ দিবেন?
না! তখন আমরা সার্ভারে Newman সেট করে দেব। সে একাই সব কাজ করে রিপোর্ট পাঠিয়ে দিবে।

একে বলে **CLI (Command Line Interface)** টেস্টিং।

---

### **পর্ব-১৭: সেটআপ ও ইন্সটলেশন (Setup)** ⚙️

Newman চালানোর জন্য আমাদের পিসিতে **Node.js** লাগবে। (এটা হলো ইঞ্জিনের তেল)।

**ধাপ ১: Node.js আছে কি না চেক করা**
১. আপনার পিসির `CMD` (Command Prompt) বা `Terminal` ওপেন করুন।
   *(Start মেনুতে গিয়ে cmd লিখলেই আসবে কালো বাক্স)*।
২. লিখুন: `node -v` এবং Enter দিন।
   *   যদি `v18.x.x` বা কোনো ভার্সন দেখায়, তাহলে আপনি সেফ।
   *   যদি বলে "node is not recognized", তাহলে [nodejs.org](https://nodejs.org) থেকে `LTS` ভার্সন ডাউনলোড করে ইন্সটল করুন।

**ধাপ ২: Newman ইন্সটল করা**
CMD-তে এই কমান্ডটা লিখুন এবং Enter দিন (ইন্টারনেট অন রাখবেন):

👉 `npm install -g newman`

*(একটু সময় নিবে। ইন্সটল হলে `newman -v` দিয়ে চেক করুন ভার্সন দেখায় কি না)*।

### **পর্ব-১৮: কমান্ড দিয়ে টেস্ট রান করা (The Matrix Mode)** 🕶️

এখন আমরা আমাদের কালেকশনটা কালো স্ক্রিনে রান করব।

**প্রস্তুতি (Export Files):**
Newman তো আর আপনার Postman একাউন্ট চিনে না। তাই ফাইলগুলো তার হাতে দিতে হবে।
১. আপনার **"Life Cycle"** বা **"My First API Course"** কালেকশনটা `.json` আকারে **Export** করুন (আগের ক্লাসে শিখিয়েছি)।
2. আপনার Environment (**"Reqres Test Env"**) টাও **Export** করুন।
   *(Environment এর পাশে `Run` এর আইকনের কাছে বা Settings আইকনে ক্লিক করলে Export অপশন পাবেন)*।
৩. দুইটা ফাইলকে ডেক্সটপে একটা ফোল্ডারে রাখুন। নাম দিন `test-folder`।

**রান করা (Action):**
১. CMD ওপেন করে ওই ফোল্ডারে যান। (কমান্ড: `cd Desktop/test-folder`)
২. এবার জাদুকরী মন্ত্র (কমান্ড) লিখুন:

👉 `newman run <CollectionName.json> -e <EnvironmentName.json>`

*উদাহরণ:*
`newman run MyCollection.json -e MyEnv.json`

৩. **Enter চাপুন!**

**ফলাফল:**
দেখবেন হ্যাকারদের মুভির মতো ঝরঝর করে টেক্সট নামছে!
*   কোন রিকোয়েস্ট পাস হলো, কোনটা ফেল হলো—সব টেবিল আকারে দেখাবে।
*   শেষে সামারি দেখাবে: `Total Run: 1, Failed: 0`।

### **পর্ব-১৯: সুন্দর রিপোর্ট বানানো (HTML Report)** 📊

CMD-এর সাদা-কালো লেখা তো আর বসকে দেখানো যাবে না। বস চায় কালারফুল চার্ট।
চলুন একটা HTML রিপোর্ট বানাই।

১. **রিপোর্টার ইন্সটল করুন:**
   CMD-তে লিখুন: `npm install -g newman-reporter-htmlextra`

২. **রিপোর্টসহ রান করুন:**
   আগের কমান্ডের শেষে শুধু `-r htmlextra` যোগ করে দিন।

   👉 `newman run MyCollection.json -e MyEnv.json -r htmlextra`

৩. **ফাইল চেক করুন:**
   CMD-তে কিছু দেখাবে না। কিন্তু আপনার ফোল্ডারে গিয়ে দেখুন `newman` নামে একটা নতুন ফোল্ডার তৈরি হয়েছে। ওটার ভেতর একটা `.html` ফাইল আছে।
   
৪. **ওপেন করুন:**
   ফাইলটা ডাবল ক্লিক করে ব্রাউজারে ওপেন করুন।
   **ওয়াও!** 😍 লাল-নীল ড্যাশবোর্ড, পাই চার্ট, গ্রাফ—একদম প্রফেশনাল রিপোর্ট!

### **পর্ব-২০: Data Driven Testing (এক ক্লিকে ১০০ ডাটা)**

**জিনিসটা কী?**
ধরুন, আপনার বস বলল: "এই নাও ১০০ জন নতুন এমপ্লয়ির লিস্ট (Excel Sheet)। এদের সবাইকে সিস্টেমের ভেতর রেজিস্টার করে দাও।"

আপনি কি ১০০ বার নাম-ধাম টাইপ করে `Send` বাটন চাপবেন? তাহলে তো বুড়ো হয়ে যাবেন! 👴
আমরা Postman-কে বলব: "এই নাও এক্সেল শিট, তুমি একেকটা লাইন পড়ো আর রিকোয়েস্ট পাঠাও।"

একে বলে **Data Driven Testing**।

### **হাতে-কলমে শিক্ষা (Step-by-Step)**

আমরা `reqres.in` এর **Create User** (POST) রিকোয়েস্টটা ৩ জন ভিন্ন ভিন্ন মানুষের জন্য রান করব।

**ধাপ ১: বুলেটের বাক্স বানানো (Create Data File)** 📝

১. আপনার পিসিতে **Notepad** বা **Excel** ওপেন করুন।
২. নিচের লেখাগুলো হুবহু কপি করে পেস্ট করুন:

```csv
name,job
Abul,Manager
Kabul,Driver
Sokhina,Cook
```
*(প্রথম লাইনটা হলো হেডলাইন বা ভেরিয়েবল নাম। পরেরগুলো ডাটা)*

৩. ফাইলটা সেভ করুন নাম দিয়ে: **`users.csv`** (খেয়াল রাখবেন নামের শেষে যেন `.csv` থাকে, `.txt` না)।

**ধাপ ২: বন্দুক রেডি করা (Prepare Request)** 🛠️

১. Postman-এ আপনার **Create User** (POST) রিকোয়েস্টে যান।
২. `Body` ট্যাবে যান।
৩. আগে যেখানে নাম ফিক্সড ছিল, সেখানে CSV ফাইলের হেডলাইন বসান।
   *(হেডলাইন ছিল `name` আর `job`)*

   **JSON দেখতে এমন হবে:**
   ```json
   {
       "name": "{{name}}",
       "job": "{{job}}"
   }
   ```
   *(সাবধান: ডাবল কার্লি ব্রেস `{{ }}` এর ভেতরের বানান যেন CSV ফাইলের হেডলাইনের সাথে হুবহু মিলে!)*

৪. **Save** করুন। (এখন মাউস ধরলে `Unresolved Variable` বা লাল দেখাবে, ভয় পাবেন না। রান করার সময় ভ্যালু পাবে)।

**ধাপ ৩: ব্রাশফায়ার (Collection Runner)** 🔥

১. বাম পাশ থেকে আপনার কালেকশনের নামের পাশে `...` এ ক্লিক করে **Run collection** এ যান।
২. **Data** সেকশনটা খুঁজুন (ডানপাশে বা নিচে থাকে)।
   *   `Select File` বাটনে ক্লিক করে আপনার বানানো **`users.csv`** ফাইলটা আপলোড দিন।
3. **Preview বাটনে চাপ দিন:**
   *   দেখুন তো Postman ডাটাগুলো ঠিকঠাক চিনতে পারছে কি না? (Abul, Kabul সব দেখা যাচ্ছে?)
   *   **Iterations** অটোমেটিক `3` হয়ে যাওয়ার কথা (কারণ ফাইলে ৩ জন মানুষ আছে)।

৪. **Run** বাটনে চাপ দিন!

**ফলাফল (Result):**
*   Postman ৩ বার রিকোয়েস্ট পাঠাবে।
*   প্রথমবার Abul কে পাঠাবে।
*   দ্বিতীয়বার Kabul কে।
*   তৃতীয়বার Sokhina কে।
*   সবগুলো `201 Created` বা সবুজ দেখাবে।

### **পর্ব-২১: ডাটা চেক করা (Tests with Data)**

শুধু পাঠালেই হবে না, চেক করতে হবে যে আবুল গেলে রেসপন্সে আবুলই আসছে কি না (নাকি ভুলে বাবুল চলে এল!)।

১. **Tests** ট্যাবে যান।
২. নিচের কোডটুকু লিখুন:

```javascript
// ১. ফাইলে যে ডাটা আছে সেটা ধরলাম (data.name)
var expectedName = pm.iterationData.get("name");

// ২. সার্ভার যে রিপ্লাই দিল সেটা ধরলাম (json.name)
var jsonData = pm.response.json();
var actualName = jsonData.name;

// ৩. দুইটা মিলালাম
pm.test("Check Name is " + expectedName, function () {
    pm.expect(actualName).to.eql(expectedName);
});
```

*   `pm.iterationData.get("name")` -> এটা CSV ফাইল থেকে নাম নেয়।
*   এবার আবার **Collection Runner** দিয়ে রান করুন। দেখবেন ৩ বার ৩টা ভিন্ন নামের জন্য টেস্ট পাস করছে!
