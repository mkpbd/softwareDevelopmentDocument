
স্বাগতম ভাতিজা! 🎭

আজকের ক্লাসটা হলো **"অভিনয় শেখার ক্লাস"**।
ধরুন, আপনি ফ্রন্টএন্ড ডেভেলপার। আপনি ডিজাইন রেডি করে বসে আছেন, কিন্তু ব্যাকএন্ড ডেভেলপার (যে সার্ভার বানায়) বলছে—"ভাই, সার্ভার রেডি করতে আরও ৩ দিন লাগবে।"

আপনি কি ৩ দিন হাত গুটিয়ে বসে থাকবেন? না!
আমরা একটা **"নকল সার্ভার" (Mock Server)** বানাব। এটা দেখতে হুবহু আসলের মতো, কিন্তু এর কোনো বুদ্ধি নাই। আপনি যা শিখিয়ে দেবেন, টিয়া পাখির মতো সেটাই বলবে।

আজকের টপিক: **Mock Server**।

---

### **পর্ব-২২: Mock Server কী এবং কেন?**

**জিনিসটা কী?**
মার্কেটে মোবাইলে দোকানে দেখেছেন না? আসল ফোনের পাশে একটা প্লাস্টিকের ফোন রাখা থাকে (Dummy Phone)। দেখতে আসলের মতো, ওজনও এক, কিন্তু কল যায় না।
Mock Server হলো সেই **ডামি ফোন**।

**কেন লাগে?**
১. **সময় বাঁচাতে:** আসল সার্ভার রেডি হওয়ার আগেই কাজ শুরু করা যায়।
২. **টেস্টিং:** ধরুন সার্ভার ডাউন, তখন মক সার্ভার দিয়ে চেক করবেন আপনার কোড ঠিক আছে কি না।

### **পর্ব-২৩: মক সার্ভার তৈরি (Step-by-Step)** 🛠️

আমরা একটা নকল API বানাব যেটা কল করলেই বলবে: "আজকে বিরিয়ানি রান্না হয়েছে!"

**ধাপ ১: রিকোয়েস্ট সাজানো**
১. একটা নতুন কালেকশন বানান। নাম দিন: **"My Mock Server"**।
২. এর ভেতরে একটা `GET` রিকোয়েস্ট নিন।
3. URL এ লিখুন: `{{mock_url}}/menu` (এই ভেরিয়েবল পরে আসবে, এখন যেমন আছে লিখুন)।
৪. রিকোয়েস্টটা সেভ করুন নাম দিয়ে: **"Get Lunch Menu"**।

**ধাপ ২: টিয়া পাখিকে বুলি শেখানো (Add Example)** 🦜
মক সার্ভার তো বোকা, তাকে বলে দিতে হবে কী উত্তর দিতে হবে।

১. আপনার রিকোয়েস্টের ডান পাশে উপরে কোণায় **`Examples`** লেখা একটা ড্রপডাউন আছে, অথবা `Save` বাটনের পাশে `...` মেনুতে `Add Example` অপশন পাবেন।
২. `Add Example` এ ক্লিক করুন।
৩. একটা নতুন পেজ আসবে। এখানে আমরা **"উত্তর"** সেট করব।
   *   **Status Code:** `200 OK` দিন।
   *   **Response Body:** নিচের JSON লিখুন:
   * 
     ```json
     {
         "item": "Kacchi Biryani",
         "price": "250 Taka",
         "mood": "Happy"
     }
     ```
৪. উপরে ডানপাশে `Save` বাটনে ক্লিক করুন। (ব্যাস, পাখি বুলি শিখে গেল!)

**ধাপ ৩: সার্ভার চালু করা (Create Mock Server)** 🚀
১. বাম পাশে আপনার কালেকশন **"My Mock Server"** এর নামের পাশে `...` (তিন ডট) এ ক্লিক করুন।
২. `Mock collection` অপশন সিলেক্ট করুন।
৩. **Mock Server Name:** নাম দিন (যেমন: `Biryani Server`)।
৪. **Create Mock Server** বাটনে চাপ দিন।

**ফলাফল:**
Postman আপনাকে একটা লম্বা URL দিবে। দেখতে অনেকটা এমন:
👉 `https://123456-abcdef-7890.mock.pstmn.io`

এই লিংকটা **Copy** করুন।

### **পর্ব-২৪: মক সার্ভার টেস্ট করা** 🧪

এখন আমরা দেখব আমাদের নকল সার্ভার কাজ করে কি না।

১. Environment এ গিয়ে `mock_url` নামে একটা ভেরিয়েবল বানান এবং ভ্যালু হিসেবে ওই কপি করা লিংকটা বসান। (অথবা সরাসরি রিকোয়েস্টের URL এ বসাতে পারেন)।
২. আপনার **"Get Lunch Menu"** রিকোয়েস্টে ফিরে যান।
৩. URL টা যেন এমন হয়: `https://[আপনার-মক-লিংক]/menu`
৪. **Send** বাটনে চাপ দিন।

**কী ঘটল?**
নিচে রেসপন্সে দেখবেন হুবহু ওই কাচ্চি বিরিয়ানির JSON চলে এসেছে!
Postman সার্ভার না হয়েও সার্ভারের মতো আচরণ করছে।

### **আজকের হোমওয়ার্ক (Homework)** 📝

আজ আপনি নিজেকে জাদুকর মনে করতে পারেন। শূন্য থেকে সার্ভার বানিয়ে ফেলেছেন!

**কাজ:**
১. ওই একই কালেকশনে একটা `POST` রিকোয়েস্ট বানান। নাম: **"Order Food"**। URL: `/order`।

স্বাগতম ভাতিজা! 🌙

আজকের ক্লাসটা হলো **"পাহারাদার বসানোর ক্লাস"**।
ধরুন, আপনার একটা ওয়েবসাইট আছে। রাত ৩টার সময় সার্ভার ক্র্যাশ করল। আপনি তো তখন লেপ মুড়ি দিয়ে ঘুমাচ্ছেন 😴। সকালে উঠে দেখলেন কাস্টমাররা গালাগালি করছে।

কেমন হতো যদি এমন কেউ থাকত, যে সারারাত জেগে প্রতি ঘণ্টায় চেক করত—"সার্ভার ঠিক আছে তো?" এবং সমস্যা হলেই আপনাকে ইমেইল করে জাগিয়ে দিত?

Postman-এ এই পাহারাদারের নাম **Monitor**।

---

### **পর্ব-২৫: Monitors (আপনার ডিজিটাল দারোয়ান)** 👮‍♂️

**Monitor কী?**
এটা Postman-এর ক্লাউড সার্ভার থেকে আপনার API-কে নির্দিষ্ট সময় পর পর (যেমন: প্রতি ঘণ্টায় বা প্রতিদিন) অটোমেটিক হিট করে এবং রিপোর্ট রাখে।

**কেন লাগে?**
১. **Downtime চেক:** সার্ভার কখন ডাউন হলো তা জানার জন্য।
২. **Performance:** সকালে সার্ভার ফাস্ট থাকে, নাকি রাতে স্লো হয়ে যায়—সেটা গ্রাফ আকারে দেখার জন্য।

---

### **পর্ব-২৬: পাহারাদার নিয়োগ দেওয়া (Setup Monitor)** 🛠️

চলুন, আমাদের `reqres.in` বা `Life Cycle` কালেকশনের জন্য একটা মনিটর সেট করি।

**Step-by-Step গাইড:**

১. **Monitors ট্যাবে যান:**
   Postman-এর বাম পাশের প্যানেলে `Collections`, `Environments` এর নিচেই **`Monitors`** লেখা আছে (আইকনটা হার্টবিটের মতো 💓)। ওটায় ক্লিক করুন।

২. **Create a Monitor:**
   `+` বা `Create a Monitor` বাটনে চাপ দিন।

৩. **ফর্ম ফিলাপ করুন:**
   *   **Monitor Name:** একটা সুন্দর নাম দিন (যেমন: **"My API Watchman"**)।
   *   **Collection:** ড্রপডাউন থেকে আপনার `Life Cycle` বা `My First API Course` কালেকশনটা সিলেক্ট করুন।
   *   **Environment (খুবই জরুরি):** ড্রপডাউন থেকে `Reqres Test Env` সিলেক্ট করুন। (এটা না দিলে ভেরিয়েবল কাজ করবে না, সব লাল বাতি জ্বলবে!)।
   *   **Data File:** (যদি CSV ফাইল লাগে, তবে আপলোড করতে পারেন। আপাতত লাগবে না)।
   *   **Run this monitor:** এখানে টাইমার সেট করুন।
     *   `Hour timer` -> `Every hour` (প্রতি ঘণ্টায় চেক করবে)।
   *   **Regions:** অটোমেটিক সিলেক্ট করা থাকে, হাত দেওয়ার দরকার নাই।

৪. **Create Monitor:** একদম নিচে কমলা রঙের বাটনে চাপ দিন।

**ব্যাস! নিয়োগ সম্পন্ন।** 🤝

---

### **পর্ব-২৭: রিপোর্ট দেখা (The Health Check)** 📈

মনিটর তৈরি করার পর একটা ড্যাশবোর্ড আসবে।

১. **Manually Run:** যেহেতু ১ ঘণ্টা বসে থাকা বোরিং, তাই ডানপাশে উপরে **`Run`** বাটনে চাপ দিন। এখনই একবার চেক করে নিবে।
২. **গ্রাফ দেখুন:**
   *   নিচে একটা গ্রাফ তৈরি হবে।
   *   **সবুজ বার (Green Bar):** মানে সব টেস্ট পাস। সার্ভার সুস্থ আছে। ✅
   *   **লাল বার (Red Bar):** মানে কোনো টেস্ট ফেল করেছে বা সার্ভার ডাউন। ❌
   *   **Response Time:** পাশের গ্রাফে দেখাবে সার্ভার রেসপন্স দিতে কত সময় নিয়েছে (যেমন: ১০০ms)।

৩. **ইমেইল নোটিফিকেশন:**
   যদি টেস্ট ফেল করে, Postman সাথে সাথে আপনার ইমেইলে একটা মেইল পাঠিয়ে দিবে—"বস! সর্বনাশ হয়েছে! সার্ভার কাজ করছে না।"

  .catch(error => console.log('error', error));
```

৩. এই কোডটা কপি করে ব্রাউজারের কনসোল (Console) এ পেস্ট করে এন্টার দিন। দেখবেন ব্রাউজার থেকেই API কল হয়ে গেছে!

            // আপনার Postman থেকে কপি করা JavaScript Fetch কোড এখানে পেস্ট করুন
            // উদাহরণ:
            fetch("https://reqres.in/api/users/2")
                .then(response => response.json())
                .then(data => {
                    document.getElementById("demo").innerText = "User Name: " + data.data.first_name;
                });
        }
    </script>
</body>
</html>
```
৩. ফাইলটা সেভ করে ডাবল ক্লিক করে ওপেন করুন।
৪. **"Call API"** বাটনে চাপ দিন। দেখুন তো নামটা স্ক্রিনে ভেসে ওঠে কি না?

---
**ওস্তাদের টিপস:**
*Postman যে কোড দেয় সেটা ৯০% পারফেক্ট। কিন্তু মাঝে মাঝে হেডার বা অথেন্টিকেশন টোকেন কোডের মধ্যে হার্ডকোড করে দেয়। আসল প্রজেক্টে ব্যবহার করার সময় ওগুলো ভেরিয়েবলে নিয়ে নিবেন। অন্ধ বিশ্বাস ভালো না!* 🧐



স্বাগতম ভাতিজা! 🚀

আজকের ক্লাসটা একটু **"ভিআইপি"**। এতদিন আমরা আম-জনতার মতো **REST API** ব্যবহার করেছি।
REST API হলো রেস্টুরেন্টের "সেট মেনু"র মতো। আপনি বার্গার চাইলে সাথে জোর করে ফ্রাই আর কোক গছিয়ে দিবে। আপনি না চাইলেও দিবে।

কিন্তু আজ আমরা শিখব **GraphQL**। এটা হলো **Facebook**-এর আবিষ্কার।
এটা হলো "Buffet" খাওয়ার মতো। আপনি যা চাইবেন, প্লেটে ঠিক ততটুকুই দিবে। এক দানা বেশিও না, কমও না।

আজকের টপিক: **GraphQL in Postman**।

### **পর্ব-৩৫: GraphQL কী? (Set Menu vs Buffet)** 🍔

সহজ উদাহরণ:
ধরুন আপনি সার্ভারের কাছে জানতে চাইলেন: "বাংলাদেশের ডিটেইলস দাও।"

*   **REST API:** সে আপনাকে বাংলাদেশের নাম, রাজধানী, জনসংখ্যা, আবহাওয়া, প্রধানমন্ত্রীর নাম, ক্রিকেট দলের লিস্ট—সব দিয়ে দিবে। আপনার দরকার ছিল শুধু "রাজধানী", কিন্তু সে ১ কেজি ডাটা দিয়ে আপনার ইন্টারনেট শেষ করে দিবে। (Over-fetching).
*   **GraphQL:** আপনি বলবেন—"ভাই, শুধু বাংলাদেশের নাম আর রাজধানীর নাম দাও।" সে ঠিক এই দুইটা লাইনই আপনাকে দিবে। (Perfect fetching).

**মজার বিষয়:** GraphQL এ মেথড একটাই— **POST**। এখানে GET, PUT, DELETE এর আলাদা ঝামেলা নাই। ডাটা আনতেও POST, পাঠাতেও POST!

### **পর্ব-৩৬: প্রথম GraphQL রিকোয়েস্ট (Step-by-Step)** 🛠️

আমরা একটা পাবলিক API ব্যবহার করব যেখানে পৃথিবীর সব দেশের তথ্য আছে।
URL: `https://countries.trevorblades.com/`

**ধাপ ১: রিকোয়েস্ট রেডি করা**
১. Postman-এ নতুন ট্যাব খুলুন (`+`)।
২. **Method:** অবশ্যই **`POST`** সিলেক্ট করুন। (ভুল করেও GET দিবেন না)।
৩. **URL:** `https://countries.trevorblades.com/` বসান।

**ধাপ ২: বডি সাজানো (আসল খেলা)**
১. **Body** ট্যাবে ক্লিক করুন।
২. আগে আমরা `raw` -> `JSON` নিতাম। কিন্তু এখন দেখুন **`GraphQL`** নামে আলাদা একটা অপশন আছে। ওটায় ক্লিক করুন।
   *(Postman এখন অনেক স্মার্ট, সে GraphQL চিনে!)*

**ধাপ ৩: কুয়েরি লেখা (Query)**
বাম পাশের বক্সে (Query box) নিচের কোডটুকু লিখুন:

```graphql
query {
  country(code: "BD") {
    name
    capital
    currency
    emoji
  }
}
```

**মানে কী?**
*   `query`: আমি ডাটা পড়তে চাই।
*   `country(code: "BD")`: আমাকে "BD" (বাংলাদেশ) এর তথ্য দাও।
*   ভেতরের লাইনগুলো: আমাকে শুধু নাম, রাজধানী, মুদ্রা আর পতাকার ইমোজি দাও।

**ধাপ ৪: সেন্ড করা**
নীল **Send** বাটনে চাপ দিন।

**ফলাফল (Response):**
ডানপাশে রেসপন্স দেখুন:
```json
{
    "data": {
        "country": {
            "name": "Bangladesh",
            "capital": "Dhaka",
            "currency": "BDT",
            "emoji": "🇧🇩"
        }
    }
}
```
দেখেছেন? যা চেয়েছেন, ঠিক তাই দিয়েছে! কোনো ফালতু ডাটা নাই।

---

### **পর্ব-৩৭: GraphQL Variables (স্মার্ট হওয়ার উপায়)** 🧠

এখন যদি আপনি বাংলাদেশের বদলে ইন্ডিয়া ("IN") বা আমেরিকা ("US") এর ডাটা চান, বারবার কোড এডিট করা বিরক্তিকর। আমরা ভেরিয়েবল ব্যবহার করব।

**ধাপ ১: কুয়েরি আপডেট করা**
Query বক্সে কোডটা এভাবে পাল্টে দিন:

```graphql
query getCountry($myCode: ID!) {
  country(code: $myCode) {
    name
    capital
  }
}
```
*(এখানে `$myCode` হলো ভেরিয়েবল)*।

**ধাপ ২: ভেরিয়েবল সেট করা**
Query বক্সের ঠিক নিচেই দেখবেন **`GraphQL Variables`** নামে একটা ছোট সেকশন আছে। ওখানে এই JSON টা লিখুন:

```json
{
  "myCode": "US"
}
```

**ধাপ ৩: সেন্ড করা**
এখন Send দিলে দেখবেন আমেরিকার ডাটা আসছে। নিচের ভেরিয়েবল বক্সে `US` কেটে `IN` করে দিন, ইন্ডিয়ার ডাটা আসবে। কোডে হাত দেওয়াই লাগল না!

### **পর্ব-৩৮: Team Workspace (ডিজিটাল অফিস রুম)** 🏢

**জিনিসটা কী?**
এতদিন আমরা `My Workspace` এ কাজ করেছি। এটা হলো আপনার **শোবার ঘর**। এখানে লুঙ্গি পরে কাজ করলেও কেউ দেখবে না।
কিন্তু **Team Workspace** হলো **কনফারেন্স রুম**। এখানে সবাই কোট-টাই পরে আসে (মানে গুছিয়ে কাজ করে)। আপনি যা করবেন, টিমের সবাই তা দেখবে।

**কীভাবে বানাবেন?**
১. Postman-এর উপরে বামে `Workspaces` এ ক্লিক করুন।
২. **Create Workspace** বাটনে চাপ দিন।
৩. **Name:** দিন **"Office Project Alpha"**।
৪. **Visibility:** `Team` সিলেক্ট করুন।
৫. **Create Workspace** এ চাপ দিন।

**মেম্বার ইনভাইট করা:**
এখন আপনি একা। বন্ধু বা কলিগদের ডাকুন।
১. উপরে `Invite` বাটনে ক্লিক করুন।
২. আপনার বন্ধুর ইমেইল অ্যাড্রেস লিখুন (বা নিজের অন্য একটা মেইল দিন)।
৩. `Send Invite` দিন।
সে মেইল পাবে, ক্লিক করলেই এই ওয়ার্কস্পেসে ঢুকে পড়বে।

### **পর্ব-৩৯: Fork & Merge (ফটোস্ট্যাট করে কাজ করা)** 📑

টিম ওয়ার্কস্পেসে সরাসরি মেইন কালেকশনে এডিট করা **কবিরা গুনাহ**! 🚫
কারণ আপনি ভুল করলে সবার কোড নষ্ট হবে।

আমরা ব্যবহার করব **Forking** সিস্টেম।
*   **Fork:** মেইন কপি থেকে একটা ফটোকপি (Duplicate) নিজের জন্য তৈরি করা।
*   **Merge:** নিজের কপিতে কাজ শেষ করে আবার মেইন কপিতে জোড়া লাগানো।

**স্টেপ-বাই-স্টেপ:**

১. **Fork করা (আলাদা হওয়া):**
   *   কালেকশনের নামের পাশে `...` এ ক্লিক করুন।
   *   **Create a fork** সিলেক্ট করুন।
   *   একটা লেভেল দিন (যেমন: `my-feature-work`)।
   *   `Fork Collection` বাটনে চাপ দিন।
   *   দেখবেন কালেকশনের একটা ডুপ্লিকেট কপি তৈরি হয়েছে। এখন এখানে যা খুশি তাই করুন, মেইন ফাইলে কোনো আঁচড় লাগবে না!

২. **কাজ করা:**
   *   আপনার ফোর্ক করা কালেকশনে নতুন একটা রিকোয়েস্ট যোগ করুন বা কিছু এডিট করুন।

৩. **Pull Request (বসের কাছে জমা দেওয়া):**
   *   কাজ শেষ? এবার কালেকশনের নামের পাশে `...` এ ক্লিক করে **Create pull request** এ যান।
   *   Title দিন: "Added new login API"।
   *   Description: "বস, লগিন এর কাজ শেষ। একটু চেক করেন।"
   *   **Create Pull Request** বাটনে চাপ দিন।

৪. **Merge (অ্যাপ্রুভ করা):**
   *   আপনার বস (বা আপনি নিজেই) দেখবেন একটা নোটিফিকেশন এসেছে।
   *   সেখানে `Approve` এবং **Merge** বাটনে ক্লিক করলে আপনার কাজটা মেইন কালেকশনে ঢুকে যাবে।

### **পর্ব-৪০: Comments (অফিসের আড্ডা)** 💬

৩. কালেকশনটাকে **Fork** করুন।
৪. ফোর্ক করা কপিতে একটা নতুন ফোল্ডার বানান এবং সেখানে একটা টেস্ট লিখুন।
৫. একটা **Pull Request** তৈরি করুন।
৬. এবং শেষে নিজেই বসের ভাব নিয়ে সেটা **Merge** করুন।
