### 🟢 Level 1: নরমাল Angular বা CSR (Client Side Rendering) কী?
**(বিয়ে বাড়ির বাফে সিস্টেম - কিন্তু বাবুর্চি নাই!)**

মামা, ধরেন আপনি একটা বিয়ে বাড়িতে (Website) গেছেন। খুব ক্ষিদা (User request)। কিন্তু গিয়ে দেখলেন টেবিলে খাবার নাই! ওয়েটার আপনার হাতে **চাল, ডাল, কাঁচা মুরগি আর মশলার প্যাকেট** ধরাইয়া দিয়ে বলল—

> *"ভাই, ওই কোণায় চুলা আছে। কষ্ট করে রান্না করে (Render) তারপর খান।"*

মেজাজটা কেমন লাগে কন তো? 😡

এটাই হলো **CSR (Client Side Rendering)**।
1.  **Browser (Client):** আপনি (ক্ষুধার্ত মেহমান)।
2.  **Server:** ওয়েটার (সে শুধু কাঁচা বাজার বা `index.html` আর `bundle.js` ফাইল দেয়)।
3.  **সমস্যা:** আপনার ব্রাউজারকে ডাউনলোড করে, কোড রান করে, তারপর পেজ বানাতে হয়।
    *   **Loading Spinner:** ওই যে রান্না হচ্ছে... ঘুরছে তো ঘুরছেই।
    *   **SEO (Google Mama):** গুগল মামা এসে দেখে প্লেট খালি (Blank HTML)। সে তো রাগ করে চলে যায়, আপনার সাইট র‍্যাঙ্কিং পায় না।

### 🟡 Level 2: SSR (Server Side Rendering) কী?
**(কাচ্চি ভাই এর পার্সেল সার্ভিস 🍲)**

Angular 21 এর **SSR** হলো একদম ভিআইপি ট্রিটমেন্ট।
আপনি সার্ভারকে রিকোয়েস্ট করলেন: *"মামা, হোমপেজ দেন।"*

সার্ভার (কিচেন) বলল: *"বস, ২ সেকেন্ড ওয়েট করেন, প্যাকেট করছি।"*
সার্ভার নিজেই চাল-ডাল-মুরগি মিশিয়ে রান্না করে (HTML জেনারেট করে) একদম **গরম গরম বিরিয়ানির প্যাকেট** (Full HTML Page) আপনার ব্রাউজারে পাঠিয়ে দিল।

*   **মজার পার্ট:** প্যাকেট খুললেই খাবার রেডি! ব্রাউজারে পেজ আসার সাথে সাথেই ইউজার সব লেখা আর ছবি দেখতে পায়।
*   **সুবিধা:**
    *   **FCP (First Contentful Paint):** মাশরাফির বলের গতির মতো ফাস্ট!
    *   **SEO:** গুগল মামা এসে দেখে টেবিল ভরা খাবার। খুশি হয়ে র‍্যাঙ্কিং বাড়িয়ে দেয়।
*   **প্যারা:** সার্ভারের ওপর একটু প্রেসার পড়ে। ১০০০ জন কাস্টমার আসলে ১০০০ বার রান্না করা লাগে।

### 🔵 Level 3: SSG (Static Site Generation) কী?
**(বিয়ে বাড়ির দাওয়াত কার্ড 💌)**

বস, এবার ভাবেন আপনার বিয়ে। ১০০০ মেহমান আসবে। এখন মেহমান যখন গেটে আসবে, আপনি কি তখন বসে বসে **হাতে চিঠি লিখবেন**?

*"প্রিয় রহিম ভাই, আমার বিয়েতে আসবেন..."* — এত টাইম আছে? 🙅‍♂️

আপনি কী করেন? প্রেসে গিয়ে ১০০০ টা কার্ড **আগেই প্রিন্ট (Build Time)** করে ড্রয়ারে রেখে দেন।
রহিম ভাই আসলো? ধপাস করে ড্রয়ার থেকে একটা কার্ড বের করে দিয়ে দিলেন। করিম ভাই আসলো? ওরেও সেম কার্ড দিলেন।

এটাই **SSG**।
ডেভেলপার যখন `ng build` দেয়, Angular তখনই সব পেজ রান্না করে (HTML বানিয়ে) সার্ভারে বা CDN-এ সাজিয়ে রাখে।
*   ইউজার রিকোয়েস্ট করে -> সার্ভার রেডিমেড ফাইল ছুড়ে মারে।
*   **গতি:** উসাইন বোল্টও ফেল! কারণ রান্না-বান্নার টাইমই লাগে না, সব ফ্রোজেন ফুড!

### 🔴 Level 4: Advanced - Hydration & Partial Hydration
**(ঘুমন্ত দারোয়ান থিওরি 👮‍♂️💤)**

এখন শুনেন **Angular 21** এর আসল ম্যাজিক।

SSR বা SSG তে সার্ভার যখন পেজ (HTML) পাঠায়, সেটা দেখতে সুন্দর কিন্তু **"মৃত"**। মানে বাটন আছে কিন্তু ক্লিক করলে কাজ করে না (কারণ JavaScript তখনো লোড হয়নি)।

আগে (Angular 16 এর নিচে) ব্রাউজার পুরো পেজটা আবার নতুন করে লোড করত (Replay)। এটাকে বলত **Destructive Hydration**। মানে বিরিয়ানি দিয়ে আবার কেড়ে নেওয়া!

**Angular 21 এর Hydration (The Smart Mama):**
Angular 21 পেজটাকে পাঠায়, কিন্তু পেজের ভেতরের JavaScript বাটনগুলো **ঘুমিয়ে থাকে** (Sleeping Security Guard)।

একে বলে **Partial Hydration (Zoneless + Signals):**
*   ধরেন আপনার পেজে একটা "Buy Now" বাটন আছে, আর ফুটার (Footer) আছে।
*   ইউজার পেজ দেখছে, কিন্তু মাউস দিয়ে কিচ্ছু করছে না। সব কোড ঘুমিয়ে আছে (Memory কম খাচ্ছে)।
*   হঠাৎ ইউজার **"Buy Now"** বাটনে মাউস নিল।
*   Angular বলল: *"এই! শুধু বাই বাটনটা ওঠ! ডিউটি কর!"*
*   বাকি ফুটার, মেনু—সব নাক ডেকে ঘুমাচ্ছে।

মানে দারোয়ান ঘুমাচ্ছে, চোর (Interaction) আসলে শুধু তখনই চোখ খুলবে, বাকি সময় রেস্ট! এতে সাইট একদম মাখনের মতো চলে, ব্যাটারিও কম খায়। **Para nai, just chill!**

### 🥘 Step 2: বিরিয়ানি রান্না (The Component Code)

এখন আমরা একটা কম্পোনেন্ট বানাবো যেটা সার্ভার থেকে ডাটা আনবে। আমরা **Signals** ব্যবহার করব কারণ Angular 21 এ `RxJS` এর চেয়ে `Signal` বেশি চলে।

**File:** `src/app/app.component.ts`

```typescript
import { Component, signal, inject, OnInit, PLATFORM_ID } from '@angular/core';
import { CommonModule, isPlatformServer } from '@angular/common';
import { HttpClient } from '@angular/common/http';
import { RouterOutlet } from '@angular/router';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [CommonModule, RouterOutlet],
  template: `
    <div style="text-align: center; padding: 20px;">
      <h1>🌭 Welcome to {{ title() }}</h1>
      
      <!-- Loading State: যতক্ষণ রান্না হচ্ছে -->
      @if (loading()) {
        <h3>⏳ মামা, বিরিয়ানি দমে আছে (Loading)...</h3>
      } @else {
        <!-- Data Show: খানা রেডি -->
        <div class="menu-card">
          <h2>আজকের মেনু: {{ biryaniData()?.name }}</h2>
          <p>দাম: {{ biryaniData()?.price }} টাকা</p>
          <p>স্বাদ: {{ biryaniData()?.rating }}/10 (অস্থির মামা!)</p>
        </div>
      }

      <!-- Hydration Test Button -->
      <button (click)="orderMore()">আরো এক প্লেট দেন (Click Me)</button>
      <p>অর্ডার সংখ্যা: {{ orderCount() }}</p>
    </div>
  `
})
export class AppComponent implements OnInit {
  // মামা, এগুলা হলো Signal (Variables 2.0)
  title = signal('Sultan\'s Angular Kitchen');
  biryaniData = signal<any>(null);
  loading = signal(true);
  orderCount = signal(0);

  // টুলস নিচ্ছি
  private http = inject(HttpClient);
  private platformId = inject(PLATFORM_ID); // এটা দিয়ে চেক করব সার্ভারে আছি নাকি ব্রাউজারে

  ngOnInit() {
    // এই লগটা টার্মিনালে (Server) দেখালে বুঝবেন SSR কাজ করছে!
    if (isPlatformServer(this.platformId)) {
      console.log('👨‍🍳 সার্ভার: মামা, আমি এখন কিচেনে রান্না করছি (Server Rendering)...');
    }

    // ফেক ডাটা কল (API Call)
    this.http.get('https://jsonplaceholder.typicode.com/users/1') // ডামি API
      .subscribe((data: any) => {
        // ডাটা মডিফাই করছি (মশলা মাখাচ্ছি)
        this.biryaniData.set({
          name: 'Angular Special Kacchi',
          price: 450,
          rating: 10
        });
        this.loading.set(false);
      });
  }

  // বাটন ক্লিক ফাংশন (Hydration চেক করার জন্য)
  orderMore() {
    this.orderCount.update(val => val + 1);
    alert('মামা, অর্ডার নিছি! প্যারা নাই।');
  }
}
```

### 📦 Step 4: SSR vs SSG কনফিগারেশন (The Decision)

এখন আপনি ঠিক করবেন এটা **পার্সেল (SSR)** হবে নাকি **বিয়ের কার্ড (SSG)**। এটা `angular.json` এ ঠিক করা হয়।

**File:** `angular.json` (build অপশনের ভেতরে খুঁজেন)

#### Option A: SSR (Server Side Rendering - ডিফল্ট থাকে)
যদি `prerender: false` থাকে, তাহলে এটা SSR। প্রতিবার রিকোয়েস্টে রান্না হবে।

```json
"architect": {
  "build": {
    "options": {
      "ssr": {
        "entry": "server.ts"
      },
      "prerender": false 
    }
  }
}
```

#### Option B: SSG (Static Site Generation - বিয়ের কার্ড)
যদি চান আগেই সব রান্না করে রাখবেন, তাহলে `prerender: true` করে দেন।

```json

  "build": {
    "options": {
      "ssr": {
        "entry": "server.ts"
      },
      "prerender": true  // 👈 এইটা অন করলেই খেলা ঘুরে যাবে মামা!
    }
  }
}
```

### 🛠️ Step 1: সার্ভিস বানানো (The Cheat Book)
প্রথমে ডাটাগুলো এক জায়গায় সাজাই।

**File:** `src/app/services/cheat.service.ts`

```typescript
import { Injectable, signal } from '@angular/core';
import { of } from 'rxjs';

@Injectable({ providedIn: 'root' })
export class CheatService {
  // মামা, এই হলো আমাদের নকলের ভান্ডার
  private cheats = [
    { 
      slug: 'git', 
      title: 'Git Cheats', 
      content: ['git status - চেক করা', 'git commit -m "msg" - সেভ করা', 'git push - ধাক্কা মারা'] 
    },
    { 
      slug: 'linux', 
      title: 'Linux Commands', 
      content: ['ls - সব দেখা', 'cd - ফোল্ডারে ঢুকা', 'sudo rm -rf / - পিসি ধ্বংস করা (Don\'t do it!)'] 
    }
  ];

  // সব টপিক পাওয়ার জন্য (SSG এর জন্য লাগবে)
  getAllTopics() {
    return this.cheats.map(c => c.slug);
  }

  // স্পেসিফিক টপিক পাওয়ার জন্য
  getCheatBySlug(slug: string) {
    const cheat = this.cheats.find(c => c.slug === slug);
    return of(cheat); // Observable রিটার্ন করলাম ভাব নেওয়ার জন্য
  }
}
```

#### 2. Detail Page (The Actual Cheat)
**File:** `src/app/cheat-detail/cheat-detail.component.ts`

```typescript
import { Component, inject, OnInit, signal } from '@angular/core';
import { ActivatedRoute, RouterLink } from '@angular/router';
import { CheatService } from '../services/cheat.service';
import { Meta, Title } from '@angular/platform-browser'; // SEO এর জন্য

@Component({
  selector: 'app-cheat-detail',
  standalone: true,
  imports: [RouterLink],
  template: `
    @if (cheatData()) {
      <div class="paper-slip">
        <h2>🤫 বিষয়: {{ cheatData().title }}</h2>
        <ul>
          @for (cmd of cheatData().content; track cmd) {
            <li class="code-block">{{ cmd }}</li>
          }
        </ul>
        <a routerLink="/">🔙 পালান (Home)</a>
      </div>
    } @else {
      <p>⚠️ মামা, এই সাবজেক্টের নকল এখনো প্রিন্ট হয় নাই!</p>
    }
  `,
  styles: [`
    .paper-slip { background: #fffacd; padding: 20px; border: 1px dashed black; }
    .code-block { font-family: monospace; background: #eee; padding: 5px; margin: 5px 0; }
  `]
})
export class CheatDetailComponent implements OnInit {
  route = inject(ActivatedRoute);
  cheatService = inject(CheatService);
  meta = inject(Meta);
  title = inject(Title);
  
  cheatData = signal<any>(null);

  ngOnInit() {
    // URL থেকে id (git/linux) নিচ্ছি
    const slug = this.route.snapshot.paramMap.get('id');
    
    if (slug) {
      this.cheatService.getCheatBySlug(slug).subscribe(data => {
        this.cheatData.set(data);
        
        // SEO: গুগল মামাকে বলছি এটা কিসের পেজ (SSR/SSG এর সুবিধা)
        this.title.setTitle(`Cheat for ${data.title}`);
        this.meta.updateTag({ name: 'description', content: `Free cheat sheet for ${data.title}` });
      });
    }
  }
}
```
