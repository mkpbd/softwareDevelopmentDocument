চলুন, সিগন্যালস-এর ময়নাতদন্ত করি।

### **১. আগে কী সমস্যা ছিল? (The Zone.js Drama)** 🕵️‍♂️

Angular-এর আগের ভার্সনগুলোতে একটা "গোয়েন্দা" ছিল, যার নাম **Zone.js**।
তার কাজ ছিল সারাদিন নজরদারি করা।
ধরুন, আপনি ব্রাউজারে একটা মাছিও মারলেন (Click করলেন)। Zone.js সাথে সাথে চিৎকার করে উঠত:
📢 *"অ্যাই সবাই শোন! কিছু একটা হয়েছে! তোরা সবাই চেক কর তোদের ডাটা চেঞ্জ হয়েছে কিনা!"*

হয়তো চেঞ্জ হয়েছে শুধু একটা ছোট টেক্সট, কিন্তু সে **পুরো অ্যাপের** আগাগোড়া চেক করত। এটা অনেকটা মশা মারতে কামান দাগার মতো। এতে অ্যাপ স্লো হয়ে যেত।

### **২. Signals কী? (The Smart Notification)** 🔔

**Signals** হলো স্মার্ট নোটিফিকেশন সিস্টেম।
এটা Zone.js এর মতো হইচই করে না।

সিগন্যাল হলো একটা **"জাদুর বাক্স"**। 📦
1.  এই বাক্সের ভেতর আপনি একটা ভ্যালু (যেমন: নাম, বয়স, সংখ্যা) রাখেন।
2.  যখনই বাক্সের ভেতরের ভ্যালু চেঞ্জ হয়, সে **শুধু তাকেই** খবর দেয়, যার এই ভ্যালুটা দরকার।

**উদাহরণ:**
আপনি ইউটিউবে একটা চ্যানেল সাবস্ক্রাইব করে বেল আইকন 🔔 বাজিয়ে রাখলেন।
এখন ওই চ্যানেল ভিডিও ছাড়লে **শুধু আপনার কাছেই** নোটিফিকেশন আসবে। পুরো দুনিয়ার মানুষের কাছে যাবে না।
Angular Signals ঠিক এভাবেই কাজ করে। একে বলে **Fine-grained Reactivity**।

### **৩. সাধারণ ভেরিয়েবল vs Signals** 🥊

চলুন পার্থক্যটা দেখি:

*   **Normal Variable:** `count = 0;`
    *   এটা একটা সাধারণ সংখ্যা। এটা চেঞ্জ হলে Angular সহজে টের পায় না, পুরো ঘর খুঁজতে হয়।
*   **Signal:** `count = signal(0);`
    *   এটা একটা রিয়েক্টিভ বাক্স। এটা চেঞ্জ হলে সে নিজেই Angular-কে বলে দেয়— *"মামা, আমি আপডেট হয়েছি! শুধু এই জায়গাটুকু রং করে দাও।"*

### **৪. চলো সিগন্যাল বানাই! (Coding Time)** 💻

আমরা আমাদের আগের `user-profile` কম্পোনেন্টে সিগন্যাল ব্যবহার করব।

#### **ধাপ ১: ইমপোর্ট করা**
প্রথমে `signal` কে ইমপোর্ট করতে হবে। `user-profile.ts` ফাইলে যান:

```typescript
import { Component, signal } from '@angular/core'; // ১. signal ইমপোর্ট করলাম

@Component({
  ...
})
export class UserProfile{
  // ২. সাধারণ ভেরিয়েবল (আগের নিয়ম)
  // name = "কুদ্দুছ বয়াতী";

  // ৩. নতুন সিগন্যাল স্টাইল (New Angular 21 Style) 🚀
  firstName = signal('কুদ্দুছ');   // স্ট্রিং সিগন্যাল
  lastName = signal('বয়াতী');    // স্ট্রিং সিগন্যাল
  coin = signal(50);            // নাম্বার সিগন্যাল
}
```

দেখছেন? ভেরিয়েবলের মানের আগে শুধু `signal(...)` দিয়ে মুড়িয়ে দিয়েছি। মানে ডাটা এখন বাক্সবন্দী।

### **৫. সিগন্যাল পড়ার নিয়ম (The Getter Function)** 📖

এখন HTML ফাইলে বা টেমপ্লেটে এই ডাটা দেখাবেন কীভাবে?
এখানেই আসল টুইস্ট! 🌪️

সাধারণ ভেরিয়েবল হলে আমরা লিখতাম: `{{ firstName }}`
কিন্তু সিগন্যাল তো একটা **বাক্স**। মানটা পেতে হলে বাক্সটা খুলতে হবে।
বাক্স খোলার চাবি হলো **প্যারেন্থেসিস বা প্রথম বন্ধনী `()`**।

`user-profile.component.html` ফাইলে যান এবং এভাবে লিখুন:

```html
<div class="card">
  <!-- সিগন্যাল কল করার নিয়ম: শেষে অবশ্যই () দিতে হবে -->
  <h2> {{ firstName() }} {{ lastName() }} </h2>
  
  <p>ওয়ালেটে আছে: {{ coin() }} টাকা</p>
</div>
```

**⚠️ সতর্কবার্তা:**
আপনি যদি ভুল করে `()` না দেন (যেমন `{{ firstName }}`), তাহলে ব্রাউজারে অদ্ভুত কিছু লেখা দেখবেন (যেমন `[Signal: function]`)। তাই সিগন্যাল পড়লে ব্র্যাকেট মাস্ট!

### **৬. কেন সিগন্যাল সেরা? (Why Best?)** 🏆

1.  **সুপার ফাস্ট:** Angular কে পুরো অ্যাপ চেক করতে হয় না। লেজার ফোকাস আপডেট হয়।
2.  **Zone-less Future:** ভবিষ্যতে Angular অ্যাপে Zone.js আর থাকবেই না। অ্যাপ হবে পালকের মতো হালকা।
3.  **ক্লিন কোড:** ডাটা ফ্লো বোঝা সহজ হয়।

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **Signals** হলো রিয়েক্টিভ ভ্যালু রাখার আধুনিক পদ্ধতি।
2.  এটা ব্যবহার করতে `signal(initialValue)` লিখতে হয়।
3.  সিগন্যালের মান পড়ার জন্য একে ফাংশনের মতো কল করতে হয়: `mySignal()`।
4.  এটা অ্যাপের পারফরম্যান্স অনেক বাড়িয়ে দেয়।

### **🎯 আগামী ক্লাসের প্রস্তুতি:**
আমরা সিগন্যাল বানালাম এবং পড়লাম। কিন্তু সিগন্যালের মান **পরিবর্তন (Change)** করব কীভাবে?
কুদ্দুছ বয়াতীর নাম বদলে যদি "Justin Bieber" করতে চাই বা কয়েন বাড়াতে চাই?

সেটার জন্য আমাদের সিগন্যাল বাক্সের ভেতরে হাত ঢোকাতে হবে। আগামী ক্লাসে আমরা শিখব **Writable Signals** এবং এর জাদুকরী মেথড `set` ও `update`।

**Lesson 12: Writable Signals (মান পরিবর্তন)** - খেলা হবে! 👋

++++++++++++++++++++++++++++++++++++++
==============================================================
-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+
স্বাগতম **"Angular মাস্তানি"** সিরিজের ১২তম পর্বে! 🛠️

গত ক্লাসে আমরা শিখেছি কীভাবে **Signal** বানাতে হয় এবং সেটা বাক্সের ভেতর থেকে বের করে (Read) দেখাতে হয়।
কিন্তু জীবন তো আর স্থিরচিত্র না। নাম পাল্টাতে পারে, ব্যাংকের টাকা বাড়তে পারে বা কমতে পারে।

আজ আমরা শিখব সিগন্যাল বাক্সের ভেতরের মালমসলা কীভাবে **পরিবর্তন (Change/Write)** করতে হয়।
টাইটেল দেখেই বুঝছেন—আজকের টপিক **Writable Signals**।

### **১. সিগন্যাল পাল্টানোর অস্ত্রশস্ত্র ⚔️**

সাধারণ ভেরিয়েবল পাল্টানো খুব সহজ ছিল:
`this.name = "নতুন নাম";`

কিন্তু সিগন্যাল যেহেতু একটা স্পেশাল বাক্স, তাই একে পাল্টানোর নিয়মটাও একটু স্পেশাল। এর জন্য Angular আমাদের হাতে দুটো চাবি দিয়েছে:
1.  **`set()`** - পুরান সব ভুলে যাও, নতুন করে শুরু করো।
2.  **`update()`** - অতীতের ওপর ভিত্তি করে বর্তমানকে গড়ো।

চলুন বিস্তারিত দেখি।

---

### **২. `set()` মেথড (একদম নতুন করে)** 🆕

যখন আপনি আগের ভ্যালু নিয়ে মাথা ঘামাতে চান না, ডাইরেক্ট নতুন ভ্যালু বসিয়ে দিতে চান, তখন `set` ব্যবহার করবেন।

**উদাহরণ:**
কুদ্দুছ বয়াতী নাম চেঞ্জ করে আপনি "হিরো আলম" করতে চান। আগের নাম কী ছিল সেটা আপনার জানার দরকার নেই।

**কোড (TS ফাইলে):**
```typescript
changeName() {
  // ভুল পদ্ধতি ❌
  // this.firstName = signal('হিরো'); // এটা নতুন সিগন্যাল বানিয়ে ফেলবে!

  // সঠিক পদ্ধতি ✅
  this.firstName.set('হিরো');
  this.lastName.set('আলম');
}
```

---

### **৩. `update()` মেথড (হিসাব নিকাশ করে)** ➕

যখন নতুন ভ্যালু সেট করার জন্য আগের ভ্যালুটা জানা জরুরি, তখন `update` ব্যবহার করবেন।

**উদাহরণ:**
আপনার কয়েন আছে ৫০টা। আপনি ১০টা কয়েন যোগ করতে চান।
এখন মোট কত হবে? (৫০ + ১০ = ৬০)।
এখানে আগের "৫০" সংখ্যাটা জানা জরুরি ছিল।

**কোড (TS ফাইলে):**
```typescript
addMoney() {
  // update মেথড আমাদের আগের ভ্যালুটা (currentValue) প্যারামিটার হিসেবে দেয়
  this.coin.update(currentValue => currentValue + 10);
  
  // অথবা শর্টকাট (Arrow function):
  // this.coin.update(n => n + 10);
}
```

### **৪. হাতে-কলমে প্রজেক্ট (Action Mode) 🎬**

চলুন আমাদের `UserProfile এ বাটন লাগিয়ে এই মেথডগুলোর পরীক্ষা করি।

#### **ধাপ ১: লজিক লেখা (TS File)**
`user-profile.ts` ফাইলে ক্লাসের ভেতর এই ফাংশনগুলো যোগ করুন:

```typescript
export class UserProfile{
  // আমাদের সিগন্যালগুলো
  firstName = signal('কুদ্দুছ');
  lastName = signal('বয়াতী');
  coin = signal(50);

  // নাম পাল্টানোর ফাংশন (set ব্যবহার করে)
  changeToHero() {
    this.firstName.set('হিরো');
    this.lastName.set('আলম');
  }

  // টাকা বাড়ানোর ফাংশন (update ব্যবহার করে)
  addCoin() {
    this.coin.update(prev => prev + 100);
  }
}
```

#### **ধাপ ২: বাটন যোগ করা (HTML File)**
এবার `user-profile.html` ফাইলে বাটন যোগ করি এবং ফাংশনগুলো কানেক্ট করে দিই।
*(বাটনে ক্লিক ইভেন্ট নিয়ে বিস্তারিত পরে জানব, আপাতত শুধু কপি-পেস্ট করুন)*

```html
<div class="card">
  <h2> {{ firstName() }} {{ lastName() }} </h2>
  <p>ওয়ালেটে আছে: {{ coin() }} টাকা</p>

  <!-- বাটনসমূহ -->
  <button (click)="changeToHero()">নাম বদলাও 🎭</button>
  <br><br>
  <button (click)="addCoin()">টাকা বাড়াও 💰</button>
</div>
```

### **৫. আউটপুট (The Magic) ✨**

ব্রাউজারে যান।
1.  **"নাম বদলাও"** বাটনে ক্লিক করুন।
    *   ধুম করে নাম চেঞ্জ হয়ে "হিরো আলম" হয়ে যাবে। কোনো রিফ্রেশ ছাড়াই!
2.  **"টাকা বাড়াও"** বাটনে ক্লিক করতে থাকুন।
    *   ৫০ -> ১৫০ -> ২৫০... এভাবে বাড়তেই থাকবে।

Angular এর সিগন্যাল সিস্টেম এতটাই ফাস্ট যে, চোখের পলক ফেলার আগেই ব্রাউজারের ওই নির্দিষ্ট টেক্সটটুকু আপডেট হয়ে যায়।

---

### **৬. `set` বনাম `update` - কখন কোনটা? 🤔**

| পরিস্থিতি | কোন মেথড? | উদাহরণ |
| :--- | :--- | :--- |
| ডাইরেক্ট নতুন ডাটা বসাতে হবে | `set()` | লাইট অন/অফ করা, নাম রিসেট করা। |
| আগের ডাটার সাথে যোগ/বিয়োগ করতে হবে | `update()` | শপিং কার্টে আইটেম যোগ করা, স্কোর বাড়ানো। |
| অ্যারে বা অবজেক্ট মডিফাই করতে হবে | `update()` | লিস্টে নতুন নাম ঢোকানো। |

---

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  সিগন্যাল ভ্যালু চেঞ্জ করার জন্য **WritableSignal** দরকার হয়।
2.  **`set(value)`**: পুরান ভ্যালু ফেলে দিয়ে নতুন ভ্যালু বসায়।
3.  **`update(prev => prev + new)`**: আগের ভ্যালুর ওপর ভিত্তি করে নতুন ভ্যালু সেট করে।
4.  HTML থেকে `(click)` এর মাধ্যমে আমরা এই মেথডগুলো কল করতে পারি।

ভাবুন তো, এক্সেল (Excel) শিটের কথা।
আপনি `A1` ঘরে পণ্যের দাম লিখলেন, আর `B1` ঘরে ভ্যাট অটোমেটিক চলে আসল। আপনাকে কিন্তু ভ্যাট ক্যালকুলেটরে টিপে বের করতে হয়নি।
Angular 21-এ এই এক্সেল ফর্মুলার নামই হলো **Computed Signals**।

আজ আমরা শিখব কীভাবে এক সিগন্যালের ওপর ভর করে আরেক সিগন্যাল অটোমেটিক তৈরি হয়।

---

### **১. Computed Signal কী? (The Auto-Pilot)** ✈️

সহজ কথায়: **Computed Signal** হলো এমন এক সিগন্যাল, যার নিজস্ব কোনো ভ্যালু নেই। সে অন্য সিগন্যালের ওপর পরগাছার মতো বেঁচে থাকে।

*   **Writable Signal (`signal`)**: আপনি নিজে ভ্যালু `set` বা `update` করেন।
*   **Computed Signal (`computed`)**: আপনি একে টাচ করতে পারবেন না। সে অন্য সিগন্যালগুলোর দিকে তাকিয়ে থাকে। যখনই "বাবা সিগন্যাল" চেঞ্জ হয়, "ছেলে সিগন্যাল" (Computed) অটোমেটিক আপডেট হয়ে যায়।

একে বলা হয় **Derived State** (অন্য জায়গা থেকে পাওয়া অবস্থা)।

### **২. কেন এটা দরকার? (Why Use It?)** 🤷‍♂️

ধরুন, আপনার `firstName` আছে "হিরো" আর `lastName` আছে "আলম"।
এখন `fullName` দেখানোর জন্য আপনি কী করবেন?
1.  প্রতিবার নাম চেঞ্জ হলে ম্যানুয়ালি `fullName` আপডেট করবেন? (বোরিং কাজ!)
2.  নাকি এমন একটা ফর্মুলা সেট করবেন, যাতে `firstName` বা `lastName` বদলালেই `fullName` একা একাই রেডি হয়ে যায়? (স্মার্ট কাজ! 😎)

অবশ্যই দ্বিতীয়টা!

### **৩. সিনট্যাক্স ও নিয়ম (The Rules) 📜**

প্রথমে `computed` কে ইমপোর্ট করতে হবে।

```typescript
import { Component, signal, computed } from '@angular/core';
```

লেখার নিয়ম:
```typescript
// ১. মেইন সিগন্যাল
price = signal(100);
quantity = signal(2);

// ২. অটোমেটিক সিগন্যাল (Computed)
totalPrice = computed(() => this.price() * this.quantity());
```
*খেয়াল করুন:* `computed` এর ভেতর আমরা অ্যারো ফাংশন `() => ...` ব্যবহার করেছি এবং সিগন্যালগুলোর ভ্যালু পড়ার জন্য `()` কল করেছি।

### **৪. প্রোজেক্টে প্রয়োগ (Action Time) 🎬**

চলুন আমাদের `UserProfileComponent`-এ ফিরে যাই।
আমরা একটা লজিক বানাব:
*   যদি কয়েন ১০০ টাকার কম থাকে, দেখাবে: **"স্ট্যাটাস: গরিব 😢"**
*   যদি কয়েন ১০০ বা তার বেশি হয়, দেখাবে: **"স্ট্যাটাস: বড়লোক 😎"**

#### **ধাপ ১: TS ফাইলে কোড**
`user-profile.component.ts`-এ যান:

```typescript
import { Component, signal, computed } from '@angular/core'; // computed ইমপোর্ট করতে ভুলবেন না

export class UserProfileComponent {
  // আমাদের মেইন সিগন্যাল
  coin = signal(50);

  // আমাদের অটোমেটিক সিগন্যাল
  userStatus = computed(() => {
    if (this.coin() >= 100) {
      return "বড়লোক 😎";
    } else {
      return "গরিব 😢";
    }
  });

  // টাকা বাড়ানোর মেথড
  addCoin() {
    this.coin.update(tk => tk + 20); // ২০ টাকা করে বাড়ালাম
  }
}
```

#### **ধাপ ২: HTML এ দেখানো**
`user-profile.component.html`-এ যান:

```html
<div class="card">
  <h2>আমার ব্যাংক ব্যালেন্স</h2>
  <p>টাকা: {{ coin() }}</p>
  
  <!-- Computed Signal দেখাচ্ছি -->
  <h3> {{ userStatus() }} </h3>

  <button (click)="addCoin()">ভিক্ষা দিন / ইনকাম করুন 💰</button>
</div>
```

### **৫. আউটপুট ও মজা (The Magic) ✨**

ব্রাউজারে যান।
1.  শুরুতে দেখবেন টাকা ৫০, আর স্ট্যাটাস **"গরিব 😢"**।
2.  বাটনে ক্লিক করতে থাকুন... ৭০... ৯০...
3.  যেই ১১০ হবে, সাথে সাথে ম্যাজিকের মতো স্ট্যাটাস বদলে হয়ে যাবে **"বড়লোক 😎"**।

আমরা কিন্তু `addCoin()` ফাংশনের ভেতর `userStatus` নিয়ে কোনো কাজই করিনি। সে `coin` এর দিকে তাকিয়ে ছিল। `coin` বদলেছে, তাই সেও বদলে গেছে।

### **৬. সাবধান! এটা Read-Only! ⚠️**

Computed Signal-এর একটা বড় বৈশিষ্ট্য হলো, আপনি বাইরে থেকে জোর করে এর মান বদলাতে পারবেন না।

যদি আপনি লেখেন:
```typescript
this.userStatus.set("মিডল ক্লাস"); // ❌ Error খাবেন!
```
Angular বলবে: *"ভাই, এটা তো ফর্মুলা দিয়ে তৈরি। তুমি বাইরে থেকে মান বসাচ্ছ কেন? যদি মান বদলাতে চাও, তবে `coin` বদলাও।"*

### **৭. Performance Boost (Memoization) 🚀**

Computed Signal খুব কিপটে। সে প্রয়োজন ছাড়া কাজ করে না।
ধরুন, আপনার কয়েন ১০০ থেকে বেড়ে ২০০ হলো। স্ট্যাটাস কিন্তু আগেই "বড়লোক" ছিল, এখনো "বড়লোক"ই আছে।
রেজাল্ট যদি সেম থাকে, Computed Signal তখন HTML কে বা অন্য কাউকে ডিস্টার্ব করে না। সে চুপচাপ বসে থাকে। এটাকে বলে **Memoization**। এতে অ্যাপ সুপার ফাস্ট হয়।

2.  এটি **Read-only**। একে `set()` বা `update()` করা যায় না।

আমরা সিগন্যাল পাল্টালাম, অটোমেটিক মানও বের করলাম।
কিন্তু ধরুন, সিগন্যাল চেঞ্জ হওয়ার সাথে সাথে আপনি কনসোলে কিছু প্রিন্ট করতে চান, বা ডাটাবেসে লগ রাখতে চান, বা লোকাল স্টোরেজে ডাটা সেভ করতে চান।

মানে স্ক্রিনে কিছু দেখাবেন না, কিন্তু "পেছনের দরজা" দিয়ে কিছু কাজ করবেন।
একে বলা হয় **Side Effects**।

স্বাগতম **"Angular মাস্তানি"** সিরিজের ১৪তম পর্বে! 🧪

আমরা সিগন্যাল বানিয়েছি, সিগন্যাল দিয়ে অংক কষেছি (Computed)।
কিন্তু মাঝে মাঝে আমাদের এমন কিছু কাজ করতে হয়, যা স্ক্রিনে দেখানোর জন্য নয়, বরং **"পর্দার আড়ালে"** বা **"ব্যাকগ্রাউন্ডে"** করার জন্য।

যেমন:
*   ডাটা চেঞ্জ হলে কনসোলে প্রিন্ট করা।
*   ইউজার ডার্ক মোড অন করলে সেটা ব্রাউজারের মেমোরিতে (LocalStorage) সেভ করে রাখা।
*   ডাটা চেঞ্জ হলে সার্ভারে একটা পিং পাঠানো।

এই কাজগুলোকে প্রোগ্রামিংয়ের ভাষায় বলা হয় **Side Effects**। আর Angular-এ এর জন্য আমাদের অস্ত্র হলো **`effect()`**।

---

### **১. Effect আসলে কী? (The CCTV Camera)** 📹

সহজ কথায়, **Effect** হলো একটা সিসিটিভি ক্যামেরা বা গোয়েন্দা।
সে নির্দিষ্ট কিছু সিগন্যালের দিকে তাকিয়ে থাকে।
যখনই ওই সিগন্যালের ভ্যালু চেঞ্জ হয়, সে সাথে সাথে হেডকোয়ার্টারে খবর পাঠায় বা কোনো একটা অ্যাকশন নেয়।

**Computed vs Effect:**
*   **Computed:** ইনপুট নেয় ➡️ প্রসেস করে ➡️ আউটপুট (নতুন ভ্যালু) দেয়। (যেমন: চাল ➡️ ভাত)।
*   **Effect:** ইনপুট নেয় ➡️ প্রসেস করে ➡️ কিন্তু **কোনো ভ্যালু রিটার্ন করে না**। বরং অন্য কোথাও কিছু একটা ঘটায়। (যেমন: ভাত রান্না হলো ➡️ সুগন্ধে খিদে পেয়ে গেল। এই "খিদে পাওয়া" হলো এফেক্ট)।

---

### **২. সিনট্যাক্স ও নিয়ম (Where to put it?)** 🏗️

`effect` সাধারণত কম্পোনেন্টের **Constructor**-এর ভেতর লিখতে হয়।
কেন? কারণ `effect` চালু করার জন্য Angular-এর একটা বিশেষ পারমিশন (Injection Context) লাগে, যা কনস্ট্রাক্টরের ভেতর পাওয়া যায়।

```typescript
import { Component, signal, effect } from '@angular/core';

export class UserProfile {
  count = signal(0);

  constructor() {
    // এফেক্ট লেখার নিয়ম
    effect(() => {
      // সিগন্যালকে কল করলেই সে বুঝবে কার দিকে তাকাতে হবে
      console.log(`বর্তমান কাউন্ট হলো: ${this.count()}`);
    });
  }
}
```

### **৩. রিয়েল লাইফ প্রজেক্ট: "অটো-সেভ থিম" 🌓**

চলুন একটা কাজের কাজ করি। আমরা একটা **"ডার্ক মোড / লাইট মোড"** বাটন বানাব।
ইউজার যখনই মোড চেঞ্জ করবে, আমরা সেটা `localStorage`-এ সেভ করে রাখব। যাতে পেজ রিফ্রেশ দিলেও সেটিংটা থেকে যায়।

#### **ধাপ ১: সেটআপ (TS File)**
`user-profile.ts`-এ যান:

```typescript
import { Component, signal, effect } from '@angular/core';

@Component({
  selector: 'app-user-profile',
  standalone: true,
  templateUrl: './user-profile.html',
  styleUrl: './user-profile.css'
})
export class UserProfile {
  // ১. থিম সিগন্যাল (ডিফল্ট 'light')
  theme = signal('light');

  constructor() {
    // ২. এফেক্ট: যখনই theme বদলাবে, লোকাল স্টোরেজে সেভ হবে
    effect(() => {
      const currentTheme = this.theme();
      console.log(`থিম চেঞ্জ হয়েছে: ${currentTheme} মোডে`);
      
      // ব্রাউজারের মেমোরিতে সেভ করা (Side Effect)
      localStorage.setItem('user-theme', currentTheme);
      
      // বডি-র ব্যাকগ্রাউন্ড কালার চেঞ্জ করা (DOM Manipulation)
      document.body.style.backgroundColor = currentTheme === 'dark' ? '#333' : '#fff';
      document.body.style.color = currentTheme === 'dark' ? '#fff' : '#000';
    });
  }

  // ৩. বাটন টিপলে থিম পাল্টানোর লজিক
  toggleTheme() {
    this.theme.update(t => t === 'light' ? 'dark' : 'light');
  }
}
```

#### **ধাপ ২: বাটন (HTML File)**
`user-profile.component.html`-এ লিখুন:

```html
<div class="card">
  <h2>বর্তমান থিম: {{ theme() }}</h2>
  
  <button (click)="toggleTheme()">
    থিম পরিবর্তন করুন 🌗
  </button>
</div>
```

### **৫. সাবধান! এফেক্ট নিয়ে ছিনিমিনি নয়! ⚠️**

`effect` ব্যবহার করার সময় একটা মারাত্মক ভুল হতে পারে— **Infinite Loop** (অসীম লুপ)।

ধরুন আপনি লিখলেন:
```typescript
effect(() => {
  // সিগন্যাল পড়ছি
  console.log(this.count());
  
  // আবার ওই সিগন্যালকেই আপডেট করছি! 😱
  this.count.set(this.count() + 1); 
});
```

ঘটনা কী ঘটবে?
1.  এফেক্ট রান হবে।
2.  `count` চেঞ্জ হবে।
3.  `count` চেঞ্জ হয়েছে দেখে এফেক্ট আবার রান হবে।
4.  আবার `count` চেঞ্জ হবে...
5.  ...এভাবে চলতে চলতে ব্রাউজার হ্যাং হয়ে যাবে! 😵

**নিয়ম:** `effect`-এর ভেতর পারতপক্ষে সিগন্যাল **set/update** করবেন না। এটা শুধু **বাইরের জগত** (API, Console, DOM) এর সাথে কথা বলার জন্য ব্যবহার করুন।

আজকের টপিক **Event Binding**। সোজা বাংলায়—ইউজারের অ্যাকশন ধরা এবং পাল্টা অ্যাকশন নেওয়া। নিউটনের ৩য় সূত্রের মতো: *"প্রত্যেক ক্রিয়ারই (Event) একটি সমান ও বিপরীত প্রতিক্রিয়া (Function Call) আছে।"*

### **১. সিনট্যাক্স: গোল ব্র্যাকেট `( )` 🎯**

Angular-এ ইভেন্ট বাইন্ডিং চেনার উপায় হলো **Parentheses** বা **প্রথম বন্ধনী `( )`**।

মনে রাখবেন:
*   `[]` থার্ড ব্র্যাকেট = **Input** (ডাটা আসে)।
*   `()` ফার্স্ট ব্র্যাকেট = **Output/Event** (সিগন্যাল বের হয় বা অ্যাকশন হয়)।

লেখার নিয়ম:
```html
<button (ইভেন্টের_নাম)="ফাংশনের_নাম()">ক্লিক করো</button>
```
মানে, যখন এই **ইভেন্ট** ঘটবে, তখন ওই **ফাংশনটা** চালাও।

### **২. Click Event `(click)` - সবচেয়ে জনপ্রিয় 🌟**

এটা আমরা আগেও ব্যবহার করেছি, কিন্তু আজ বুঝব। এটা ইলেকট্রিক সুইচের মতো। টিপ দেবেন, ফ্যান ঘুরবে।

**উদাহরণ:** একটা লাইক বাটন।

**TS ফাইল:**
```typescript
likes = signal(0);

increaseLike() {
  this.likes.update(n => n + 1);
  console.log('লাইক দেওয়া হয়েছে! 👍');
}
```

**HTML ফাইল:**
```html
<button (click)="increaseLike()">
  Like 👍 ({{ likes() }})
</button>
```
এখানে `(click)` হলো সুইচ, আর `increaseLike()` হলো ফ্যান।

### **৩. Mouse Events (মাউসের নড়াচড়া) 🐭**

শুধু ক্লিক নয়, মাউস আনলে বা সরালে কী হবে, সেটাও আমরা কন্ট্রোল করতে পারি।

*   `mouseenter`: মাউস এলিমেন্টের ওপর আনলে।
*   `mouseleave`: মাউস সরালে।
*   `mousemove`: মাউস নড়াচড়া করলে।

**উদাহরণ: চোর ধরা প্রজেক্ট 🕵️‍♂️**
আমরা একটা বক্স বানাব। মাউস নিলেই সে বলবে "চোর ধরা পড়েছে!", আর সরালে বলবে "নিরাপদ"।

**TS ফাইল:**
```typescript
message = signal('নিরাপদ এলাকা 🛡️');

catchThief() {
  this.message.set('চোর ধরা পড়েছে! 🚨');
}

relax() {
  this.message.set('নিরাপদ এলাকা 🛡️');
}
```

**HTML ফাইল:**
```html
<div class="security-box" 
     (mouseenter)="catchThief()" 
     (mouseleave)="relax()">
  
  <h2>{{ message() }}</h2>

</div>
```
*(CSS দিয়ে বক্সটাকে একটু রং করে দেবেন যাতে বোঝা যায়)*

### **৪. Keyboard Events (টাইপিং ধরা) ⌨️**

ইনপুট বক্সে ইউজার কী লিখছে, সেটা ধরার জন্য কিবোর্ড ইভেন্ট লাগে।

*   `keydown`: বাটন চাপ দেওয়ার সাথে সাথে।
*   `keyup`: বাটন চেপে ছেড়ে দেওয়ার পর।

**ম্যাজিক ভেরিয়েবল `$event` 🎁**
যখন কোনো ইভেন্ট ঘটে, Angular একটা গোপন প্যাকেট পাঠায় যার নাম **`$event`**। এর ভেতরে ইভেন্টের সব খবর থাকে (কোন বাটন চাপা হয়েছে, ইনপুট বক্সে কী লেখা আছে ইত্যাদি)।

**উদাহরণ: লাইভ টাইপিং**

**TS ফাইল:**
```typescript
inputText = signal('');

handleInput(event: any) {
  // ইনপুট বক্সের ভ্যালু বের করা
  const value = event.target.value; 
  this.inputText.set(value);
}
```

**HTML ফাইল:**
```html
<input type="text" (keyup)="handleInput($event)" placeholder="এখানে লিখুন...">

<p>আপনি লিখছেন: {{ inputText() }}</p>
```

**ব্যাখ্যা:**
`$event` হলো পিয়ন। সে খবর নিয়ে `handleInput` ফাংশনের কাছে যায়। আমরা পিয়নের ঝুলি (`event.target.value`) থেকে চিঠিটা বের করে সিগন্যাল আপডেট করি।

### **৫. Key Filtering (ফিল্টারিং) ⚡**

ধরুন, আপনি চান ইউজার কিছু একটা লিখে যখন **Enter** চাপবে, তখনই কাজ হবে। অন্য কোনো কি (Key) চাপলে কাজ হবে না।

আগে জাভাস্ক্রিপ্টে লিখতে হতো: `if (event.key === 'Enter') ...`
Angular এ এটা একদম পানিভাত!

```html
<!-- শুধু Enter চাপলে কাজ হবে -->
<input type="text" (keyup.enter)="saveData()">

<!-- শুধু Space চাপলে কাজ হবে -->
<input type="text" (keyup.space)="pauseVideo()">
```

`keyup` এর পর ডট `.` দিয়ে কী-এর নাম লিখে দিলেই কেল্লাফতে!

### **৬. হাতে-কলমে প্র্যাকটিস (Task Manager Demo) 📝**

চলুন সব মিলিয়ে একটা ছোট টাস্ক ইনপুট বানাই।

**TS Code:**
```typescript
export class UserProfileComponent {
  tasks: string[] = []; // সাধারণ অ্যারে

  addTask(event: any) {
    const newTask = event.target.value;
    this.tasks.push(newTask); // অ্যারেতে যোগ করা
    event.target.value = ''; // বক্স খালি করা
  }
}
```

**HTML Code:**
```html
<h3>আপনার টাস্ক লিস্ট</h3>

<input type="text" 
       placeholder="কাজ লিখুন এবং Enter দিন" 
       (keyup.enter)="addTask($event)">

<ul>
  @for (task of tasks; track $index) {
    <li>{{ task }}</li>
  }
</ul>
```

**আউটপুট:**
বক্সে লিখুন "বাজার করা" এবং Enter দিন। দেখবেন নিচে লিস্টে যোগ হয়ে গেছে এবং বক্স খালি হয়ে গেছে। একদম প্রফেশনাল!

2.  ক্লিকের জন্য `(click)`, মাউসের জন্য `(mouseenter)`, কিবোর্ডের জন্য `(keyup)`।
3.  **`$event`** হলো ইভেন্টের ডাটা বহনকারী অবজেক্ট।
4.  Angular এ `(keyup.enter)` এর মতো ফিল্টার ব্যবহার করে জীবন সহজ করা যায়।

গত ক্লাসে আমরা শিখেছি কীভাবে ইউজার ব্রাউজারে "গুঁতা" (Click/Event) দিলে কোড রেসপন্স করে।
আজ আমরা শিখব উল্টোটা। কোড (TypeScript) কীভাবে ব্রাউজারের এলিমেন্টগুলোকে "নিয়ন্ত্রণ" করে।

আজকের টপিক **Property Binding**। এর প্রতীক হলো **থার্ড ব্র্যাকেট `[ ]`**।
আমি এটাকে বলি **"রিমোট কন্ট্রোল"**। কেন? কারণ আপনি সোফায় বসে (TS ফাইলে) রিমোট টিপবেন, আর টিভির চ্যানেল (HTML এর প্রপার্টি) বদলে যাবে।

---

### **১. `[ ]` আসলে কী? (The Controller)** 📺

HTML ট্যাগের কিছু বৈশিষ্ট্য বা Property থাকে। যেমন:
*   `<img>` ট্যাগের `src` (ছবির লিংক)।
*   `<button>` ট্যাগের `disabled` (বন্ধ থাকা)।
*   `<input>` ট্যাগের `value` (লেখা)।

সাধারণত আমরা এগুলো ফিক্সড করে দিই:
```html
<img src="cat.jpg"> <!-- ফিক্সড বিড়াল -->
```

কিন্তু আমরা চাই, আমাদের TS ফাইলে যদি বলি "কুকুর", তাহলে ছবিটা কুকুরের হয়ে যাবে। এটাই **Property Binding**।
```html
<img [src]="myImage"> <!-- ডাইনামিক ছবি -->
```
এখানে `myImage` হলো TS ফাইলের একটা ভেরিয়েবল বা সিগন্যাল।

---

### **২. Interpolation `{{ }}` বনাম Property Binding `[ ]` 🥊**

আপনারা বলতে পারেন, *"ভাই, ইন্টারপোলেশন `src={{ myImage }}` দিয়েও তো কাজ হয়! তাহলে `[ ]` কেন শিখব?"*

দারুণ প্রশ্ন! পার্থক্যটা এখানেই:

1.  **Interpolation `{{ }}`:** সব কিছুকে **String (টেক্সট)** বানিয়ে ফেলে।
2.  **Property Binding `[ ]`:** ডাটার আসল টাইপ (Boolean, Number, Object) বজায় রাখে।

**উদাহরণ (সবচেয়ে গুরুত্বপূর্ণ):**
ধরুন, আপনি একটা বাটন ডিজেবল (Disabled) করতে চান।

*   ❌ **ভুল:** `<button disabled="{{ false }}">Click</button>`
    *   HTML ভাববে "false" একটা টেক্সট। আর টেক্সট থাকা মানেই সত্য (Truthy)। তাই বাটন **Disabled-ই থেকে যাবে!**
*   ✅ **সঠিক:** `<button [disabled]="false">Click</button>`
    *   এখানে Angular বোঝে যে `false` মানে বুলিয়ান মিথ্যা। তাই বাটন **Enable (সচল)** হয়ে যাবে।

তাই লজিক্যাল কাজের জন্য সবসময় `[ ]` সেরা।

---

### **৩. হাতে-কলমে প্রজেক্ট: "মিসাইল লঞ্চার" 🚀**

চলুন একটা মজার প্র্যাকটিস করি। আমরা একটা "Launch Missile" বাটন বানাব। কিন্তু এটা শুরুতে অকেজো (Disabled) থাকবে। যতক্ষণ না ইউজার "I Agree" তে টিক দেবে, ততক্ষণ মিসাইল মারা যাবে না।

#### **ধাপ ১: লজিক সেটআপ (TS File)**
`user-profile.component.ts` এ যান:

```typescript
import { Component, signal } from '@angular/core';

@Component({
  ...
})
export class UserProfileComponent {
  // ১. ইমেজের লিংক
  imageUrl = signal('https://i.pravatar.cc/150?img=12');

  // ২. বাটন ডিজেবল থাকবে কিনা? (শুরুতে true মানে ডিজেবল)
  isButtonDisabled = signal(true);

  // ৩. চেক বক্স বাটন টিপলে এটা উল্টে যাবে
  togglePermission() {
    this.isButtonDisabled.update(val => !val);
  }

  launchMissile() {
    alert("🚀 মিসাইল উৎক্ষেপণ সফল হয়েছে!");
  }
}
```

#### **ধাপ ২: কন্ট্রোল বসানো (HTML File)**
`user-profile.component.html` এ লিখুন:

```html
<div class="card">
  <!-- ১. ইমেজের সোর্স বাইন্ডিং -->
  <img [src]="imageUrl()" alt="User" class="profile-img">
  
  <h3>সিকিউরিটি প্যানেল</h3>

  <!-- চেকবক্স -->
  <label>
    <input type="checkbox" (change)="togglePermission()">
    আমি পারমিশন দিচ্ছি
  </label>
  
  <br><br>

  <!-- ২. বাটন ডিজেবল বাইন্ডিং -->
  <!-- [disabled] যখন true, বাটন কাজ করবে না -->
  <button 
    [disabled]="isButtonDisabled()" 
    (click)="launchMissile()">
    🚀 Launch Missile
  </button>
  
  <p>স্ট্যাটাস: {{ isButtonDisabled() ? 'লক করা 🔒' : 'রেডি ফায়ার 🔥' }}</p>

</div>
```

### **৪. আউটপুট ও ম্যাজিক ✨**

ব্রাউজারে যান।
1.  শুরুতে দেখবেন "Launch Missile" বাটনটি ধূসর (Gray/Disabled)। ক্লিক করলে কাজ হচ্ছে না।
2.  চেকবক্সে টিক দিন।
3.  সাথে সাথে বাটনটি **জীবন্ত (Enabled)** হয়ে যাবে।
4.  এবার বাটনে ক্লিক করলে অ্যালার্ট আসবে।

এখানে `[disabled]="isButtonDisabled()"` লাইনটাই আসল ম্যাজিক। TS ফাইলের সিগন্যাল `true` হলে বাটন অফ, `false` হলে বাটন অন।

### **৫. আরো কিছু উদাহরণ (Common Properties)** 🛠️

শুধু `src` বা `disabled` না, আরো অনেক কিছু কন্ট্রোল করা যায়:

**ক. ইনপুট ভ্যালু `[value]`**
```html
<input type="text" [value]="'হ্যালো ডিফল্ট টেক্সট'">
```
*(ইনপুট বক্স লোড হওয়ার সাথে সাথে এই লেখাটা দেখাবে)*

**খ. হিডেন `[hidden]`**
```html
<p [hidden]="true">আমি লুকিয়ে আছি 🙈</p>
```
*(কোনো কিছু কন্ডিশনালি লুকাতে চাইলে)*

**গ. স্টাইল `[style.color]`**
```html
<h1 [style.color]="'red'">লাল শিরোনাম</h1>
```
*(যদিও এটা আমরা কম ব্যবহার করি, ক্লাস বাইন্ডিং বেশি ভালো)*

---

### **৬. মনে রাখার সহজ টেকনিক (Recap Mnemonic)** 🧠

*   **`[]` (বক্স):** ডাটা **ঢোকে** (Input / Property Binding)। TS ➡️ HTML।
*   **`()` (ব্যানানা/ব্র্যাকেট):** ডাটা **বের হয়** (Output / Event Binding)। HTML ➡️ TS।

Angular কমিউনিটিতে একে বলা হয় **"Banana in a Box" `[()]`** (যখন দুইটা একসাথে ব্যবহার হয়, যেটা আমরা পরে শিখব)।

---

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **Property Binding `[ ]`** দিয়ে HTML অ্যাট্রিবিউট ডাইনামিকালি কন্ট্রোল করা হয়।
2.  ইন্টারপোলেশন `{{ }}` শুধু টেক্সটের জন্য ভালো, কিন্তু বুলিয়ান (সত্য/মিথ্যা) লজিকের জন্য `[ ]` ব্যবহার করতেই হবে।
3.  `[disabled]`, `[src]`, `[value]`—এগুলো সবচেয়ে বেশি ব্যবহৃত প্রপার্টি।
