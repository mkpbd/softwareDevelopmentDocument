স্বাগতম **"Angular মাস্তানি"** সিরিজের ১৭তম পর্বে! 🚦

জীবনে আমাদের প্রতিনিয়ত সিদ্ধান্ত নিতে হয়।
*   পকেটে ৫০০ টাকা থাকলে 👉 **কাচ্চি বিরিয়ানি** খাব।
*   না থাকলে 👉 **সিঙ্গারা** খাব।

প্রোগ্রামিংয়ের ভাষায় একে বলে **Conditional Rendering**।
Angular-এর আগের জমানায় (v16 এর আগে) আমরা `*ngIf` ব্যবহার করতাম। ওটা ছিল একটু "ঘেঁটে ঘ" টাইপের (মডিউল ইমপোর্ট করো, স্ট্রাকচারাল ডিরেক্টিভ বোঝো... উফ!)।

কিন্তু Angular 21-এ এসেছে ঝকঝকে নতুন সিনট্যাক্স **`@if`, `@else`**। এটা দেখতে একদম জাভাস্ক্রিপ্ট বা সাধারণ ইংলিশের মতো। কোনো ইমপোর্ট লাগে না, ডাইরেক্ট অ্যাকশন!

আজ আমরা অ্যাপকে বুদ্ধি শেখাব—কখন কী দেখাতে হবে। 🧠

### **১. সিনট্যাক্স: নতুন বনাম পুরাতন 🥊**

পুরানো দিনের স্মৃতি (ভুলে যান, শুধু চিনে রাখুন):
```html
<!-- আগে এমন ছিল (Old School) -->
<div *ngIf="isLoggedIn; else loginBlock">ওয়েলকাম!</div>
<ng-template #loginBlock>লগইন করুন</ng-template>
```

**নতুন জমানা (Angular 21 - Modern Way):**
```html
@if (isLoggedIn()) {
  <div>ওয়েলকাম বস! 😎</div>
} @else {
  <button>লগইন করুন 🔒</button>
}
```
দেখুন কতটা ক্লিন! `{ }` ব্র্যাকেটের ভেতর যা লিখবেন, কন্ডিশন সত্য হলে সেটাই দেখাবে।

### **২. প্রজেক্ট: "সিক্রেট এজেন্ট ড্যাশবোর্ড" 🕵️‍♂️**

আমরা এমন একটা সিস্টেম বানাব যেখানে:
*   ইউজার লগইন করা না থাকলে শুধু **"লগইন বাটন"** দেখবে।
*   লগইন করলে **"সিক্রেট ফাইল"** দেখতে পাবে।
*   আবার লগআউট করলে সব গায়েব হয়ে যাবে।

#### **ধাপ ১: লজিক সেটআপ (TS File)**
`user-profile.component.ts` এ যান এবং একটা সিগন্যাল নিন:

```typescript
import { Component, signal } from '@angular/core';

@Component({
  ...
})
export class UserProfileComponent {
  // ১. ইউজার লগইন আছে কিনা? (শুরুতে false)
  isLoggedIn = signal(false);

  // ২. লগইন/লগআউট করার সুইচ
  toggleLogin() {
    this.isLoggedIn.update(status => !status);
  }
}
```

#### **ধাপ ২: কন্ডিশন বসানো (HTML File)**
`user-profile.component.html` এ লিখুন:

```html
<div class="card">
  
  <!-- কন্ডিশন চেক শুরু -->
  @if (isLoggedIn()) {
    <!-- যদি সত্য হয় -->
    <h2 style="color: green;">✅ স্বাগতম এজেন্ট 007!</h2>
    <p>সিক্রেট কোড: <strong>XYZ-999</strong></p>
    <button (click)="toggleLogin()">লগআউট করুন 🚪</button>
  } 
  @else {
    <!-- যদি মিথ্যা হয় -->
    <h2 style="color: red;">⛔ প্রবেশ নিষেধ!</h2>
    <p>দয়া করে পরিচয় দিন।</p>
    <button (click)="toggleLogin()">লগইন করুন 🔑</button>
  }

</div>
```

#### **ধাপ ৩: ম্যাজিক দেখুন ✨**
ব্রাউজারে যান।
1.  শুরুতে দেখবেন লাল রঙের **"প্রবেশ নিষেধ!"**। সিক্রেট কোড দেখা যাচ্ছে না।
2.  **"লগইন করুন"** বাটনে ক্লিক করুন।
3.  বুম! 💥 স্ক্রিন চেঞ্জ হয়ে সবুজ রঙের **"স্বাগতম এজেন্ট 007"** চলে আসবে।
4.  পুরো HTML ব্লকটা রিপ্লেস হয়ে গেছে।

### **৩. একাধিক অপশন (`@else if`) 🤹‍♂️**

জীবন সবসময় "হ্যাঁ" বা "না" হয় না। মাঝে মাঝে "হয়তো" থাকে।
ধরুন, সার্ভার থেকে ডাটা আসছে। তখন ৩টা অবস্থা হতে পারে:
1.  **Loading...** (ডাটা আসছে)
2.  **Error** (নেট নেই)
3.  **Data** (সব ঠিক আছে)

এক্ষেত্রে আমরা `@else if` ব্যবহার করি।

**উদাহরণ:**

```typescript
// TS ফাইলে
status = signal('loading'); // মান হতে পারে: 'loading', 'success', 'error'
```

```html
<!-- HTML ফাইলে -->
@if (status() === 'loading') {
  <p>⏳ ডাটা লোড হচ্ছে... ঘুরছে চাকা...</p>
} 
@else if (status() === 'error') {
  <p>❌ সার্ভার ডাউন! ইন্টারনেট বিল দিয়েছেন?</p>
} 
@else {
  <p>✅ ডাটা চলে এসেছে! পার্টি হবে! 🎉</p>
}
```

---

### **৪. কেন নতুন সিনট্যাক্স সেরা? (Why Cool?)** 😎

1.  **No Imports:** আগে `CommonModule` বা `NgIf` ইমপোর্ট করতে হতো। এখন কিচ্ছু লাগে না। এটা Angular-এর বিল্ট-ইন ল্যাঙ্গুয়েজ।
2.  **Better Performance:** এটা আগের `*ngIf` এর চেয়ে অনেক দ্রুত কাজ করে।
3.  **Readable:** কোড পড়লেই বোঝা যায় কী হচ্ছে। কোনো `<ng-template>` এর জটিলতা নেই।

---

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **`@if (condition) { ... }`**: শর্ত সত্য হলে এই ব্লক দেখাবে।
2.  **`@else { ... }`**: শর্ত মিথ্যা হলে এই ব্লক দেখাবে।
3.  **`@else if (condition) { ... }`**: একাধিক শর্ত চেক করার জন্য।
4.  এটি **Control Flow** এর নতুন সিনট্যাক্স, যা Angular 17+ (এবং 21) এ ডিফল্ট।

সবই লুপের খেলা। Angular 21-এ লুপ লেখার স্টাইল এখন আগের চেয়ে অনেক ফাস্ট এবং স্মার্ট। এর নাম **`@for` Block**।

### **১. সিনট্যাক্স: `@for` এর গঠন 🏗️**

আগে আমরা `*ngFor` ব্যবহার করতাম। সেটা ছিল একটু স্লো।
এখন নতুন নিয়মে লিখতে হয় এভাবে:

```html
@for (item of items; track item.id) {
  <p>{{ item.name }}</p>
}
```

এখানে ৩টা জিনিস গুরুত্বপূর্ণ:
1.  **`item`**: এক একটা সিঙ্গেল ডাটা (যেমন: একটি প্রোডাক্ট)।
2.  **`items`**: পুরো লিস্ট বা অ্যারে।
3.  **`track`**: এটা **বাধ্যতামূলক**! Angular কে বলে দিতে হয় ডাটাগুলোর "ইউনিক আইডি" বা "রোল নাম্বার" কোনটা। এতে Angular সুপার ফাস্ট রেন্ডার করতে পারে।

### **২. প্রজেক্ট: "ডিজিটাল শপিং লিস্ট" 🛒**

চলুন আমরা একটা ফলের দোকানের লিস্ট বানাই।

#### **ধাপ ১: ডাটা তৈরি (TS File)**
`user-profile.component.ts` ফাইলে একটা সিগন্যাল অ্যারে তৈরি করি।

```typescript
import { Component, signal } from '@angular/core';

@Component({
  ...
})
export class UserProfileComponent {
  // ফলের তালিকা (Object Array)
  fruits = signal([
    { id: 1, name: 'আম 🥭', price: 100 },
    { id: 2, name: 'কাঁঠাল 🍈', price: 300 },
    { id: 3, name: 'লিচু 🍒', price: 50 },
    { id: 4, name: 'তরমুজ 🍉', price: 200 }
  ]);

  // নতুন ফল যোগ করার ফাংশন
  addFruit() {
    this.fruits.update(list => [
      ...list, 
      { id: Date.now(), name: 'আপেল 🍎', price: 150 }
    ]);
  }
}
```

#### **ধাপ ২: লুপ চালানো (HTML File)**
`user-profile.component.html` এ যান। আমরা একটা লিস্ট তৈরি করব।

```html
<div class="card">
  <h3>ফলের বাজার 🍎</h3>

  <ul>
    <!-- লুপ শুরু -->
    @for (fruit of fruits(); track fruit.id) {
      <li>
        <strong>{{ fruit.name }}</strong> - {{ fruit.price }} টাকা
      </li>
    }
  </ul>

  <button (click)="addFruit()">আপেল যোগ করুন ➕</button>
</div>
```

### **৩. লুপের গোপন ভেরিয়েবল (Implicit Variables) 🕵️‍♂️**

লুপের ভেতর Angular আমাদের কিছু ফ্রি গিফট দেয়। এগুলো দিয়ে আমরা স্টাইলিং করতে পারি।
*   **`$index`**: সিরিয়াল নাম্বার (0, 1, 2...)।
*   **`$first`**: এটা কি প্রথম আইটেম? (true/false)।
*   **`$last`**: এটা কি শেষ আইটেম? (true/false)।
*   **`$even` / `$odd`**: জোড় না বিজোড়? (জেব্রা ক্রসিং স্টাইল করার জন্য)।

**উদাহরণ:**
চলুন সিরিয়াল নাম্বার দেখাই এবং জোড় সংখ্যার ফলের ব্যাকগ্রাউন্ড কালার করি।

```html
<ul>
  @for (fruit of fruits(); track fruit.id; let i = $index; let e = $even) {
    <li [style.background-color]="e ? '#f0f0f0' : 'white'">
      
      <!-- i এর মান ০ থেকে শুরু হয়, তাই ১ যোগ করলাম -->
      <span>{{ i + 1 }}. </span> 
      
      {{ fruit.name }}
      
      @if ($first) { <span style="color:red">(স্পেশাল অফার!)</span> }

    </li>
  }
</ul>
```
*   `let i = $index`: ইনডেক্সটাকে `i` নামে সেভ করলাম।
*   `let e = $even`: ইভেন চেক করার ভেরিয়েবল।
*   `[style...]`: যদি ইভেন হয় (e), তবে ধূসর রং, নাহলে সাদা।

### **৪. `@empty` ব্লক (লিস্ট যখন খালি) 📭**

আগে লিস্ট খালি থাকলে আমাদের আলাদা করে `@if` দিয়ে চেক করতে হতো।
এখন Angular 21-এ `@for` এর নিচেই `@empty` জোড়া লাগিয়ে দেওয়া যায়।

যদি কোনো কারণে আপনার অ্যারেতে কোনো ডাটা না থাকে, তবে `@empty` ব্লকটা দেখাবে।

```html
<ul>
  @for (fruit of fruits(); track fruit.id) {
    <li>{{ fruit.name }}</li>
  } 
  @empty {
    <!-- যদি ঝুড়িতে ফল না থাকে -->
    <li style="color: red;">দুঃখিত! ফলের দোকান খালি। 😢</li>
  }
</ul>
```

**টেস্ট করার উপায়:** TS ফাইলে `fruits = signal([])` (ফাঁকা অ্যারে) করে দিন। দেখবেন ব্রাউজারে লাল রঙের মেসেজ দেখাচ্ছে।

### **৫. `track` কেন এত জরুরি? (Performance Booster) 🚀**

Angular 21-এ `track` ছাড়া কোড লিখলে এরর খেতে পারেন বা ওয়ার্নিং দেবে।
কারণ:
ধরুন আপনার লিস্টে ১০০টা আইটেম আছে। আপনি ১টা আইটেম ডিলিট করলেন।
*   `track` না থাকলে: Angular পুরো ১০০টা আইটেম মুছে আবার নতুন করে রেন্ডার করত। (ধীরগতি)।
*   `track` থাকলে: Angular আইডির সাহায্যে বুঝবে যে শুধু "আইডি ৫" ডিলিট হয়েছে। সে শুধু ওই একটা লাইন মুছে দেবে। বাকি ৯৯টায় হাতও দেবে না। (সুপার ফাস্ট)।

**টিপস:** যদি ডাটার কোনো `id` না থাকে, তবে আপাতত `track $index` ব্যবহার করতে পারেন।

---

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **`@for`** হলো মডার্ন লুপ সিনট্যাক্স।
2.  **`track`** ব্যবহার করা বাধ্যতামূলক (পারফরম্যান্সের জন্য)।
3.  **`$index`, `$even`, `$odd`** দিয়ে লিস্টের সিরিয়াল ও স্টাইল কন্ট্রোল করা যায়।
4.  **`@empty`** ব্লক অটোমেটিক হ্যান্ডেল করে যদি লিস্ট ফাঁকা থাকে।

### **🎯 আগামী ক্লাসের প্রস্তুতি:**
`if-else` শিখলাম, `for` লুপ শিখলাম।
কিন্তু ধরুন আপনার অনেকগুলো অপশন আছে। যেমন: সপ্তাহের ৭ দিনের নাম।
*   শনি হলে 👉 খিচুড়ি।
*   রবি হলে 👉 পোলাও।
*   সোম হলে 👉 সবজি।

এতগুলো `else if` লেখা বিরক্তিকর। এর জন্য আছে **Switch Case**।
আগামী ক্লাসে আমরা শিখব **`@switch`** সিনট্যাক্স।

যেমন, একটা স্টুডেন্টের রেজাল্ট শিট:
*   A+ পেলে 👉 "মিষ্টি খাওয়াও!"

এই সমস্যার স্মার্ট সমাধান হলো **`@switch`**। এটাকে আপনারা ইলেকট্রিক সুইচবোর্ডের সাথে তুলনা করতে পারেন। যে সুইচ টিপবেন, শুধু সেই লাইটটাই জ্বলবে।

### **১. সিনট্যাক্স: `@switch` এর গঠন 🏗️**

Angular 21-এ এর সিনট্যাক্স একদম ঝকঝকে।

```html
@switch (condition) {
  @case ('মান ১') {
    <!-- কাজ ১ -->
  }
  @case ('মান ২') {
    <!-- কাজ ২ -->
  }
  @default {
    <!-- যদি কোনোটার সাথেই না মেলে -->
  }
}
```

### **২. প্রজেক্ট: "ব্যাচেলর মেস-এর মিল সিস্টেম" 🍛**

ব্যাচেলর লাইফে একেক দিন একেক মেনু থাকে। চলুন আমরা একটা অ্যাপ বানাই যেখানে বারের নাম সিলেক্ট করলে মেনু দেখাবে।

#### **ধাপ ১: ডাটা সেটআপ (TS File)**
`user-profile.component.ts` ফাইলে যান।

```typescript
import { Component, signal } from '@angular/core';

@Component({
  ...
})
export class UserProfileComponent {
  // আজ কি বার? (শুরুতে রবিবার)
  day = signal('Sunday');

  // দিন পাল্টানোর ফাংশন
  changeDay(newDay: string) {
    this.day.set(newDay);
  }
}
```

#### **ধাপ ২: সুইচ বসানো (HTML File)**
`user-profile.component.html` ফাইলে লিখুন:

```html
<div class="card">
  <h3>আজকের মেনু (বার: {{ day() }})</h3>

  <!-- বাটন দিয়ে দিন চেঞ্জ করুন -->
  <div class="buttons">
    <button (click)="changeDay('Friday')">শুক্রবার</button>
    <button (click)="changeDay('Saturday')">শনিবার</button>
    <button (click)="changeDay('Sunday')">রবিবার</button>
    <button (click)="changeDay('Monday')">সোমবার</button>
  </div>

  <hr>

  <!-- আসল ম্যাজিক: সুইচ কেস -->
  @switch (day()) {
    
    @case ('Friday') {
      <h1 style="color: gold;">বিরিয়ানি ও বোরহানি 🍗🥤</h1>
      <p>আজ জুম্মাবার, নো ডায়েট!</p>
    }

    @case ('Saturday') {
      <h1 style="color: brown;">খিচুড়ি ও ডিম ভাজি 🍛</h1>
      <p>বৃষ্টির দিনের ফিল!</p>
    }

    @case ('Sunday') {
      <h1 style="color: orange;">সাদা ভাত ও মুরগি 🐔</h1>
      <p>অফিস শুরু, ভালো খেতে হবে।</p>
    }

    @default {
      <!-- বাকি সব বারের জন্য এই খাবার -->
      <h1 style="color: grey;">আলু ভর্তা ও ডাল 🥔</h1>
      <p>মাস শেষ, বাজেট নাই!</p>
    }

  }
</div>
```

### **৩. `@default` ব্লক কেন জরুরি? 🛡️mm,6**

ধরুন, ইউজার এমন একটা বার সিলেক্ট করল (যেমন: মঙ্গলবার), যার জন্য আমরা কোনো `@case` লিখিনি।
তখন অ্যাপ কী দেখাবে? ফাঁকা স্ক্রিন?
না! তখন **`@default`** ব্লক কাজ করবে। এটা হলো "গরিবের বন্ধু"। কোনো কেস না মিললে এটাই দেখাবে।

আমাদের উদাহরণে: শুক্রবার, শনিবার আর রবিবার ছাড়া বাকি সব দিন (সোম, মঙ্গল, বুধ, বৃহস্পতি) ইউজারকে "আলু ভর্তা ও ডাল" খেতে হবে। 😂

### **৪. `@if` বনাম `@switch` - কখন কোনটা? 🤔**

| পরিস্থিতি | কোনটা ব্যবহার করবেন? |
| :--- | :--- |
| **সত্য/মিথ্যা (True/False)** | `@if` (যেমন: লগইন আছে কি নেই?) |
| **কম্পারিজন (>, <)** | `@if` (যেমন: বয়স ১৮ এর বেশি কিনা?) |
| **নির্দিষ্ট কিছু ফিক্সড মান** | `@switch` (যেমন: স্ট্যাটাস - Pending, Active, Rejected) |
| **অনেকগুলো অপশন (৩+)** | `@switch` (কোড ক্লিন থাকে) |

### **৫. পারফরম্যান্স টিপস 🚀**

Angular এর কম্পাইলার `@switch` কে খুব দক্ষতার সাথে হ্যান্ডেল করে। আপনি যদি ১০টা `else if` লেখেন, কম্পিউটারকে ওপর থেকে নিচ পর্যন্ত চেক করে আসতে হয়।
কিন্তু `@switch` সরাসরি জাম্প করে সঠিক কেস-এ চলে যেতে পারে (হ্যাশ ম্যাপ স্টাইলে)। তাই অপশন বেশি হলে `@switch` একটু ফাস্ট কাজ করে।

### **১. `ngStyle` (দর্জি বা টেইলার) ✂️**

`ngStyle` ব্যবহার করা হয় তখন, যখন স্টাইলের **মান (Value)** ফিক্সড না। মানে, এটা কম-বেশি হতে পারে।
যেমন: প্রোগ্রেস বার, ফন্ট সাইজ, বা ডাইনামিক কালার কোড।

**সিনট্যাক্স:**
```html
<div [ngStyle]="{'property': 'value'}">...</div>
```

**উদাহরণ: ডাইনামিক ফন্ট সাইজ**
চলুন এমন একটা টেক্সট বানাই, স্লাইডার বাড়ালে যার সাইজ বাড়বে।

**TS ফাইল:**
```typescript
fontSize = signal(20); // ডিফল্ট সাইজ ২০
```

**HTML ফাইল:**
```html
<label>সাইজ বাড়ান:</label>
<input type="range" min="10" max="100" 
       [value]="fontSize()" 
       (input)="fontSize.set($event.target.valueAsNumber)">

<!-- ngStyle ম্যাজিক -->
<p [ngStyle]="{ 'font-size.px': fontSize(), 'color': 'blue' }">
  আমি ছোট-বড় হতে পারি! 🎈
</p>
```
*খেয়াল করুন:* `'font-size.px'` দিয়ে আমরা পিক্সেল ইউনিট বলে দিয়েছি। আপনি স্লাইডার টানবেন, লেখা বড় হবে। CSS ফাইলে গিয়ে বারবার কোড লিখতে হবে না!

### **২. `ngClass` (আলমারির কালেকশন) 👔**

`ngStyle` দিয়ে তো স্পেসিফিক ভ্যালু বদলানো যায়। কিন্তু যদি আপনি পুরো **লুক** চেঞ্জ করতে চান?
যেমন: ডার্ক মোড, সাকসেস মেসেজ, এরর অ্যালার্ট।
তখন আমরা আগে CSS ফাইলে ক্লাস বানিয়ে রাখি, আর `ngClass` দিয়ে কন্ডিশন অনুযায়ী সেই ক্লাসগুলো অন/অফ করি।

**সিনট্যাক্স:**
```html
<div [ngClass]="{'class-name': condition}">...</div>
```
*   `class-name`: আপনার CSS ক্লাসের নাম।
*   `condition`: সত্য হলে ক্লাস বসবে, মিথ্যা হলে উঠে যাবে।

### **৩. প্রজেক্ট: "ব্যাটারি ইনডিকেটর" 🔋**

আমরা একটা ব্যাটারি বানাব।
*   চার্জ ২০% এর নিচে হলে 👉 **লাল (Critical)**
*   চার্জ ৫০% এর নিচে হলে 👉 **হলুদ (Warning)**
*   চার্জ বেশি থাকলে 👉 **সবুজ (Good)**
*   আর ব্যাটারির ভেতরের বারটা `ngStyle` দিয়ে কমবে- বাড়বে।

#### **ধাপ ১: স্টাইল তৈরি (CSS File)**
`user-profile.component.css` এ যান:

```css
/* ব্যাটারির বডি */
.battery-shell {
  border: 3px solid #333;
  width: 300px;
  height: 50px;
  border-radius: 10px;
  padding: 5px;
  background: #eee;
}

/* ব্যাটারির ভেতরের বার */
.battery-level {
  height: 100%;
  border-radius: 5px;
  transition: all 0.5s ease; /* স্মুথ অ্যানিমেশন */
}

/* বিভিন্ন কালার ক্লাস */
.good { background-color: #4caf50; }   /* সবুজ */
.warning { background-color: #ffc107; } /* হলুদ */
.critical { background-color: #f44336; } /* লাল */
```

#### **ধাপ ২: লজিক সেটআপ (TS File)**
`user-profile.component.ts` এ যান:

```typescript
import { Component, signal } from '@angular/core';

export class UserProfileComponent {
  charge = signal(100); // শুরুতে ১০০% চার্জ

  // চার্জ কমানোর মেথড
  drainBattery() {
    this.charge.update(c => c > 0 ? c - 10 : 0);
  }

  // চার্জ দেওয়ার মেথড
  chargeBattery() {
    this.charge.update(c => c < 100 ? c + 10 : 100);
  }
}
```

#### **ধাপ ৩: কানেকশন দেওয়া (HTML File)**
এখানেই আসল খেলা! `ngStyle` দিয়ে **প্রস্থ (Width)** কন্ট্রোল করব আর `ngClass` দিয়ে **রং (Color)**।

```html
<div class="card">
  <h3>আমার ফোনের চার্জ: {{ charge() }}%</h3>

  <div class="battery-shell">
    <div class="battery-level"
      
      [ngStyle]="{ 'width': charge() + '%' }"

      [ngClass]="{
        'good': charge() > 50,
        'warning': charge() <= 50 && charge() > 20,
        'critical': charge() <= 20
      }">
      
    </div>
  </div>

  <br>
  <button (click)="drainBattery()">গেম খেলুন 🎮 (চার্জ কমান)</button>
  <button (click)="chargeBattery()">চার্জে দিন 🔌 (চার্জ বাড়ান)</button>
</div>
```

### **৪. আউটপুট ও মজা ✨**

ব্রাউজারে যান।
1.  শুরুতে চার্জ ১০০%, বারটা পুরো ভরা এবং **সবুজ**।
2.  "গেম খেলুন" বাটনে ক্লিক করতে থাকুন। চার্জ কমবে, বারের সাইজ ছোট হবে (ngStyle এর কাজ)।
3.  যখনই ৫০% এ আসবে, রং হয়ে যাবে **হলুদ** (ngClass এর কাজ)।
4.  ২০% এ আসলে হয়ে যাবে **লাল**।

কি দারুণ, তাই না? লজিক দিয়ে আমরা ডিজাইন নাচাতে পারছি! 💃

### **৫. `ngStyle` vs `ngClass` - কোনটা কখন? 🤔**

| বৈশিষ্ট্য | `ngStyle` | `ngClass` |
| :--- | :--- | :--- |
| **কাজ** | সরাসরি CSS প্রপার্টি বসায় | CSS ক্লাস অ্যাড বা রিমুভ করে |
| **ব্যবহার** | যখন ভ্যালু ডাইনামিক হয় (যেমন: %, px, color code) | যখন পুরো থিম বা ডিজাইন সেট বদলাতে হয় |
| **উদাহরণ** | প্রোগ্রেস বার, পজিশনিং | অ্যাক্টিভ বাটন, এরর মেসেজ, ডার্ক মোড |
| **পছন্দ** | কম ব্যবহার করাই ভালো | **বেস্ট প্র্যাকটিস** ✅ (কোড ক্লিন থাকে) |

---

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **`[ngStyle]`** দিয়ে আমরা HTML এলিমেন্টের ইনলাইন স্টাইল (width, height, font-size) ডাইনামিকালি চেঞ্জ করি।
2.  **`[ngClass]`** দিয়ে আমরা কন্ডিশন অনুযায়ী CSS ক্লাস যোগ বা বিয়োগ করি।
3.  দুইটা একসাথেও ব্যবহার করা যায় (যেমন আমাদের ব্যাটারি প্রজেক্টে)।

### **🎯 আগামী ক্লাসের প্রস্তুতি:**
আমরা Angular এর দেওয়া `ngStyle`, `ngClass`, `ngIf` ব্যবহার করলাম। এগুলোকে বলে **Built-in Directives**।
কিন্তু ভাবুন তো, যদি আমরা **নিজেদের মতো** একটা ডিরেক্টিভ বানাতে পারতাম?
যেমন: কোনো টেক্সটের ওপর মাউস নিলেই সেটা রংধনু হয়ে যাবে—নাম দেব `appRainbow`।

হ্যাঁ! Angular-এ নিজের রুলস বা ডিরেক্টিভ বানানো যায়।
আগামী ক্লাসে আমরা শিখব **Custom Directives**।

স্বাগতম **"Angular মাস্তানি"** সিরিজের ২১তম পর্বে! 🧪

আমরা এতদিন Angular-এর বানানো জিনিস (`ngClass`, `ngStyle`) ব্যবহার করেছি। এগুলো অনেকটা রেডিমেড জামা কেনার মতো। ফিটিং হলে ভালো, না হলে কিছু করার নেই।

কিন্তু আজ আমরা **টেইলার (Tailor)** হব। আমরা নিজেদের পছন্দমতো রুলস বা ডিরেক্টিভ বানাব।

আজকের টপিক: **Custom Directives (নিজের নিয়ম, নিজের রাজত্ব)।**

### **১. Directive আসলে কী? (The Magic Sticker)** 🏷️

ডিরেক্টিভ হলো একটা **জাদুর স্টিকার**।
আপনি যেই HTML ট্যাগের গায়ে এই স্টিকার লাগিয়ে দেবেন, সেই ট্যাগ জ্যান্ত হয়ে যাবে এবং আপনার কথামতো আচরণ করবে।

Angular-এ ডিরেক্টিভ ৩ প্রকার:
1.  **Component:** (আমরা জানি, টেমপ্লেট সহ ডিরেক্টিভ)।
2.  **Structural:** (DOM চেঞ্জ করে, যেমন `@if`, `@for`)।
3.  **Attribute:** (আজকের টপিক—চেহারা বা আচরণ চেঞ্জ করে)।

### **৩. লজিক বসানো (Coding Time) 💻**

এখন `highlight.directive.ts` ফাইলটি ওপেন করুন।
আমাদের লক্ষ্য: যেই এলিমেন্টে এই ডিরেক্টিভ বসবে, তার ব্যাকগ্রাউন্ড কালার চেঞ্জ করা।

এর জন্য আমাদের দুটো হাতিয়ার লাগবে:
1.  **`ElementRef`**: এটা দিয়ে আমরা ওই HTML ট্যাগটাকে ধরব (DOM Access)।
2.  **`HostListener`**: এটা দিয়ে আমরা মাউসের নড়াচড়া (Event) শুনব।

**কোড:**

```typescript
import { Directive, ElementRef, HostListener } from '@angular/core';

@Directive({
  selector: '[appHighlight]', // <--- এটাই আমাদের স্টিকারের নাম
  standalone: true
})
export class HighlightDirective {

  // ১. ElementRef দিয়ে আমরা ট্যাগটাকে ধরলাম
  constructor(private el: ElementRef) { }

  // ২. মাউস যখন এলিমেন্টের ওপর আসবে (MouseEnter)
  @HostListener('mouseenter') onMouseEnter() {
    this.highlight('yellow'); // হলুদ করো
  }

  // ৩. মাউস যখন সরে যাবে (MouseLeave)
  @HostListener('mouseleave') onMouseLeave() {
    this.highlight(''); // রং তুলে নাও
  }

  // ৪. রং করার প্রাইভেট ফাংশন
  private highlight(color: string) {
    this.el.nativeElement.style.backgroundColor = color;
    this.el.nativeElement.style.transition = '0.3s'; // একটু স্মুথ ভাব
  }

}
```

### **৪. ব্যবহার বিধি (Applying the Magic) ✨**

এখন আমাদের এই ডিরেক্টিভটা `user-profile` বা যেকোনো কম্পোনেন্টে ব্যবহার করতে হবে।

**মনে রাখবেন:** যেহেতু এটা Standalone, তাই ব্যবহার করার আগে **Import** করতে হবে।

#### **ধাপ ১: ইমপোর্ট করা**
`user-profile.component.ts` এ যান:

@Component({

  standalone: true,
  imports: [HighlightDirective], // ২. লিস্টে নাম তোলা

  styleUrl: './user-profile.component.css'

export class UserProfileComponent { ... }

`user-profile.component.html` এ যান এবং যেকোনো ট্যাগে `appHighlight` লিখে দিন।

*   মাউস সরান। রং চলে যাবে।
*   বাটনের ওপর মাউস নিন। সেটাও হলুদ হয়ে যাবে।

মানে আমরা একবার কোড লিখেছি, আর এখন যেকোনো জায়গায় `appHighlight` লিখে দিলেই সেই এলিমেন্ট স্মার্ট হয়ে যাচ্ছে! একেই বলে **Code Reusability**।

### **৬. বোনাস: ডাইনামিক কালার (Custom Color) 🌈**

সবসময় হলুদ ভালো নাও লাগতে পারে। আমরা যদি চাই ইউজার বলে দেবে কোন রং হবে?
যেমন: `<p appHighlight="cyan">` বা `<p appHighlight="red">`।

এর জন্য ডিরেক্টিভে **Input** নিতে হবে।

**`highlight.directive.ts` আপডেট করুন:**

```typescript
import { Directive, ElementRef, HostListener, Input } from '@angular/core';

@Directive({ selector: '[appHighlight]', standalone: true })
export class HighlightDirective {
  
  // ইনপুট নিচ্ছি (বাইরে থেকে রং আসবে)
  @Input() appHighlight = ''; 

  constructor(private el: ElementRef) {}

  @HostListener('mouseenter') onMouseEnter() {
    // ইনপুট কালার থাকলে সেটা দাও, না থাকলে হলুদ (Default)
    this.highlight(this.appHighlight || 'yellow');
  }

  @HostListener('mouseleave') onMouseLeave() {
    this.highlight('');
  }

  private highlight(color: string) {
    this.el.nativeElement.style.backgroundColor = color;
  }
}
```

**HTML এ ব্যবহার:**
```html
<p appHighlight="pink">আমি গোলাপি হবো!</p>
<p appHighlight="lime">আমি কচি পাতা হবো!</p>
<p appHighlight>আমি ডিফল্ট হলুদ হবো!</p>
```

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **Custom Directive** দিয়ে আমরা HTML এলিমেন্টের বিহেভিয়ার বদলাতে পারি।
2.  `ng g d name` দিয়ে ডিরেক্টিভ বানাতে হয়।
3.  **`ElementRef`** দিয়ে এলিমেন্ট ধরতে হয়।
4.  **`HostListener`** দিয়ে মাউস বা কিবোর্ড ইভেন্ট শুনতে হয়।
5.  এটি ব্যবহার করতে হলে কম্পোনেন্টের `imports` অ্যারেতে যুক্ত করতে হয়।
