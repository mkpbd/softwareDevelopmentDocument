
### **মডিউল ৮: ফর্মস (বায়োডাটা কালেকশন)**
*ইউজারের কাছ থেকে ডাটা নেওয়া।*
+++++++++++++++++++++++++++++++++++++++
===============================================================
-+-+-+-+-+-+-+-+-+-+-+-+-+_+-=-+-+_+-+-=-+-+-=-+-+_=-+-+_=-+-+_=-+-+-=-+-=_=-+-+=+=+
স্বাগতম **"Angular মাস্তানি"** সিরিজের ৩৪তম পর্বে! 📝

আজ আমরা **মডিউল ৮: ফর্মস (Forms)** শুরু করছি।
একটা ওয়েবসাইট মানেই ডাটা আদান-প্রদান। ইউজার লগইন করবে, রেজিস্ট্রেশন করবে, বা আপনাকে গালি দিয়ে (অথবা প্রশংসা করে) মেসেজ পাঠাবে। এই সবকিছুর জন্য আমাদের দরকার **Forms**।

Angular-এ ফর্ম বানানোর দুটি রাস্তা আছে:
1.  **Template Driven Forms:** সহজ রাস্তা। যারা খুব বেশি কোড লিখতে চান না, সব কাজ HTML-এই সেরে ফেলতে চান।
2.  **Reactive Forms:** কঠিন কিন্তু পাওয়ারফুল রাস্তা। যারা লজিক কন্ট্রোল করতে পছন্দ করেন (এটা আমরা পরে শিখব)।

আজকের টপিক: **Template Driven Forms** (গরিবের বন্ধু / সহজ উপায়)।

---

### **১. সেটআপ: `FormsModule` ইমপোর্ট করা 📦**

Template Driven Form ব্যবহার করার জন্য আমাদের একটা টুলবক্স লাগবে, যার নাম **`FormsModule`**। যেহেতু আমরা Standalone Component ব্যবহার করছি, তাই এটা সরাসরি কম্পোনেন্টে ইমপোর্ট করতে হবে।

`login.ts` (বা যেকোনো কম্পোনেন্ট) এ যান:

```typescript
import { Component } from '@angular/core';
import { FormsModule } from '@angular/forms'; // ১. এইটা ইমপোর্ট করা মাস্ট!
import { JsonPipe } from '@angular/common'; // ডিবাগিংয়ের জন্য

@Component({
  selector: 'app-login',
  standalone: true,
  imports: [FormsModule, JsonPipe], // ২. লিস্টে নাম তুলুন
  templateUrl: './login.html',
  styleUrl: './login.css'
})
export class Login {
  // ৩. ফর্মের ডাটা রাখার জন্য একটা অবজেক্ট
  userObj = {
    email: '',
    password: ''
  };

  onSubmit() {
    console.log('ফর্ম সাবমিট হয়েছে!', this.userObj);
    alert('লগইন সফল! ✅');
  }
}
```

---

### **২. জাদুর কাঠি: `[(ngModel)]` 🪄**

মনে আছে আমরা লেসন ২৪-এ **Two-way Binding** বা **Banana in a Box `[()]`** শিখেছিলাম?
Template Driven Form-এ এটাই আসল হিরো।

আমরা ইনপুট বক্সের সাথে আমাদের `userObj` এর প্রপার্টিগুলোকে বেঁধে দেব।
*   বক্সে লিখলে 👉 `userObj` আপডেট হবে।
*   `userObj` চেঞ্জ করলে 👉 বক্সে আপডেট হবে।

---

### **৩. ফর্ম ডিজাইন (HTML) 🎨**

`login.html` এ যান।
এখানে কিছু নিয়ম মানতে হবে:
1.  প্রতিটা ইনপুট ফিল্ডে **`name`** অ্যাট্রিবিউট দিতেই হবে (না হলে Angular চিনতে পারবে না)।
2.  পুরো ফর্মটাকে **`<form>`** ট্যাগের ভেতর রাখতে হবে।

```html
<div class="card">
  <h2>লগইন ফর্ম</h2>

  <!-- ১. ফর্ম ট্যাগ -->
  <!-- #loginForm="ngForm" দিয়ে পুরো ফর্মের অবস্থা ট্র্যাক করছি -->
  <!-- (ngSubmit) মানে বাটন চাপলে কী হবে -->
  <form #loginForm="ngForm" (ngSubmit)="onSubmit()">

    <!-- ইমেইল ফিল্ড -->
    <div class="form-group">
      <label>ইমেইল:</label>
      <input 
        type="email" 
        name="email" 
        [(ngModel)]="userObj.email" 
        placeholder="আপনার ইমেইল দিন"
        required> 
        <!-- required মানে এটা খালি রাখা যাবে না -->
    </div>

    <!-- পাসওয়ার্ড ফিল্ড -->
    <div class="form-group">
      <label>পাসওয়ার্ড:</label>
      <input 
        type="password" 
        name="password" 
        [(ngModel)]="userObj.password" 
        placeholder="গোপন পিন দিন"
        required 
        minlength="6">
        <!-- minlength="6" মানে অন্তত ৬ অক্ষর হতে হবে -->
    </div>

    <br>

    <!-- বাটন -->
    <!-- [disabled]="!loginForm.valid" 
         মানে: ফর্ম ঠিকঠাক না হলে বাটন অকেজো থাকবে -->
    <button type="submit" [disabled]="loginForm.invalid">
      লগইন করুন 🚀
    </button>

  </form>

  <hr>
  
  <!-- ডিবাগিং: লাইভ ডাটা দেখার জন্য -->
  <p>লাইভ ডাটা: {{ userObj | json }}</p>
  <p>ফর্ম ভ্যালিড? : {{ loginForm.valid ? 'হ্যাঁ ✅' : 'না ❌' }}</p>

</div>
```

### **৪. আউটপুট ও টেস্ট 🧪**

ব্রাউজারে যান।

**টেস্ট ১ (ভ্যালিডেশন):**
*   শুরুতে কিছুই লিখবেন না। দেখুন "লগইন করুন" বাটনটি **ধূসর (Disabled)** হয়ে আছে।
*   কারণ আমরা `required` দিয়েছি এবং ফর্ম এখন `invalid`।

**টেস্ট ২ (লাইভ আপডেট):**
*   ইমেইল বক্সে টাইপ করুন। নিচে "লাইভ ডাটা" অংশে দেখবেন সাথে সাথে লেখাগুলো আপডেট হচ্ছে। `ngModel` এর ম্যাজিক!

**টেস্ট ৩ (সাবমিট):**
*   ইমেইল এবং ৬ অক্ষরের পাসওয়ার্ড দিন।
*   এখন বাটন **সজীব (Enabled)** হবে।
*   ক্লিক করলে কনসোলে অবজেক্ট প্রিন্ট হবে এবং অ্যালার্ট দেখাবে।

### **৫. কেন এটাকে "Template Driven" বলে? 🤔**

খেয়াল করেছেন? আমরা TS ফাইলে প্রায় কোনো কোডই লিখিনি।
*   কোনটা `required`? 👉 HTML-এ লিখেছি।
*   কোনটা `minlength`? 👉 HTML-এ লিখেছি।
*   বাটন কখন ডিজেবল হবে? 👉 HTML-এ লিখেছি (`loginForm.invalid`)।

সব লজিক যেহেতু **Template (HTML)** চালাচ্ছে, তাই এর নাম **Template Driven Forms**।

### **৬. কখন এটা ব্যবহার করবেন?**

✅ **ভালো:**

### **১. Reactive Forms আসলে কী? (The Master Plan) 🗺️**

Template Driven ফর্মে লজিক থাকত HTML-এ।
আর **Reactive Forms**-এ লজিক থাকে **TypeScript (TS)** ফাইলে।

আমরা প্রথমে TS ফাইলে ফর্মের একটা **নকশা (Blueprint)** তৈরি করি। তারপর সেই নকশাটা HTML-এর সাথে জুড়ে দিই।
*   **সুবিধা ১:** পুরো নিয়ন্ত্রণ আপনার হাতে।
*   **সুবিধা ২:** ফর্মের ভ্যালু চেঞ্জ হলে আমরা লাইভ ট্র্যাক করতে পারি (RxJS দিয়ে)।
*   **সুবিধা ৩:** ডাইনামিক ফিল্ড যোগ করা যায় (যেমন: বাটন চাপলে নতুন ইনপুট আসবে)।

### **২. সেটআপ: `ReactiveFormsModule` 🧰**

প্রথমে আমাদের টুলবক্স বদলাতে হবে। আগের `FormsModule` বাদ, এখন লাগবে **`ReactiveFormsModule`**।

`user-profile.component.ts` ফাইলে যান:

```typescript
import { Component } from '@angular/core';
import { ReactiveFormsModule, FormControl } from '@angular/forms'; // ১. ইমপোর্ট করুন

@Component({
  selector: 'app-user-profile',
  standalone: true,
  imports: [ReactiveFormsModule], // ২. লিস্টে নাম তুলুন
  templateUrl: './user-profile.component.html',
  styleUrl: './user-profile.component.css'
})
export class UserProfileComponent {
  // ৩. ফর্ম কন্ট্রোল তৈরি (আমাদের নকশা)
  // 'FormControl' মানে একটা সিঙ্গেল ইনপুট ফিল্ড
  emailControl = new FormControl('test@example.com'); 
  
  // এখানে ডিফল্ট ভ্যালু 'test@example.com' দিয়েছি
}
```

### **৩. HTML এর সাথে কানেকশন 🔌**

এবার `user-profile.component.html` ফাইলে যান।
এখানে আর `[(ngModel)]` বা `name="..."` লাগবে না।
এখানে আমরা ব্যবহার করব **`[formControl]`**।

```html
<div class="card">
  <h2>রিয়েক্টিভ ফর্ম ডেমো</h2>

  <label>আপনার ইমেইল:</label>
  
  <!-- নকশার সাথে কানেক্ট করছি -->
  <input type="text" [formControl]="emailControl">

  <hr>

  <!-- ভ্যালু দেখার উপায় -->
  <p>লাইভ ভ্যালু: <strong>{{ emailControl.value }}</strong></p>
  
  <!-- কোড দিয়ে ভ্যালু চেঞ্জ করার বাটন -->
  <button (click)="updateEmail()">মেইল রিসেট করুন</button>

</div>
```

### **৪. কোড থেকে নিয়ন্ত্রণ (TS Power) 💪**

এখন আমরা দেখব কীভাবে TS ফাইল থেকে ইনপুট বক্স কন্ট্রোল করা যায়।
`user-profile.component.ts` এ মেথড যোগ করুন:

```typescript
export class UserProfileComponent {
  emailControl = new FormControl('');

  updateEmail() {
    // কোড দিয়ে ইনপুট বক্সে লেখা বসাচ্ছি
    this.emailControl.setValue('admin@angular.com');
  }

  // ফর্মের স্ট্যাটাস চেক করা
  checkStatus() {
    console.log('ভ্যালু:', this.emailControl.value);
    console.log('বক্সে কি হাত দেওয়া হয়েছে? (Dirty):', this.emailControl.dirty);
    console.log('ভ্যালিড কিনা?:', this.emailControl.valid);
  }
}
```

**আউটপুট:**
ব্রাউজারে যান। বাটনে ক্লিক করলেই দেখবেন ইনপুট বক্সে লেখা চলে এসেছে। আমরা কিন্তু HTML-এ হাত দিইনি, সব TS থেকে করেছি।

### **৫. সিগন্যাল থাকতে `FormControl` কেন? 🤔**

অনেকে প্রশ্ন করতে পারেন, "ভাই, সিগন্যাল দিয়েই তো ডাটা বাইন্ডিং করা যায়, তাহলে `FormControl` কেন?"

কারণ `FormControl` শুধু ডাটা রাখে না, সে আরও অনেক কিছু জানে:
1.  **Validation:** ইউজার কি সঠিক ইমেইল দিয়েছে?
2.  **Status:** ইউজার কি বক্সটা টাচ করেছে (Touched)? নাকি কিছু লিখে আবার মুছে ফেলেছে (Dirty)?
3.  **Streams:** রিয়েক্টিভ ফর্মের সবচেয়ে বড় পাওয়ার হলো `valueChanges`।

**উদাহরণ: লাইভ ট্র্যাকিং (CCTV Mode)**
কনস্ট্রাক্টরের ভেতর এটা লিখলে বোঝা যায়:

```typescript
constructor() {
  // যখনই ইউজার কিছু টাইপ করবে, সাথে সাথে কনসোলে দেখাবে
  this.emailControl.valueChanges.subscribe(val => {
    console.log('ইউজার টাইপ করছে:', val);
    
    if(val === 'badword') {
      alert('গালি দেবেন না ভাই! 🤐');
      this.emailControl.setValue(''); // বক্স খালি করে দিলাম
    }
  });
}
```
এই যে প্রতিটা অক্ষর ট্র্যাক করা এবং সাথে সাথে অ্যাকশন নেওয়া—এটা Template Driven ফর্মে করা বেশ কঠিন, কিন্তু এখানে একদম পানিভাত!

### **৬. Template vs Reactive - চূড়ান্ত লড়াই 🥊**

| বৈশিষ্ট্য | Template Driven (আগেরটা) | Reactive Forms (আজকেরটা) |
| :--- | :--- | :--- |
| **লজিক কোথায়?** | HTML ফাইলে (Template) | TS ফাইলে (Class) |
| **সেটআপ** | সহজ (`FormsModule`) | একটু সেটআপ লাগে (`ReactiveFormsModule`) |
| **ডাটা মডেল** | Unstructured (সাধারন অবজেক্ট) | Structured (`FormControl`, `FormGroup`) |
| **স্কেলেবিলিটি** | ছোট ফর্মের জন্য ভালো | বড় এবং জটিল ফর্মের জন্য সেরা |
| **টেস্টিং** | কঠিন | খুব সহজ |

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **Reactive Forms**-এ আমরা TS ফাইলে ফর্মের ব্লু-প্রিন্ট বানাই।
2.  **`ReactiveFormsModule`** ইমপোর্ট করতে হয়।
3.  **`FormControl`** হলো ফর্মের একক ইউনিট (একটা ইনপুট বক্স)।
4.  **`[formControl]`** দিয়ে HTML-এর সাথে কানেক্ট করতে হয়।
5.  **`valueChanges`** দিয়ে লাইভ টাইপিং ট্র্যাক করা যায়।

### **🎯 আগামী ক্লাসের প্রস্তুতি:**
আজ আমরা একটা মাত্র ইনপুট ফিল্ড (`FormControl`) নিয়ে খেলেছি।
কিন্তু বাস্তবে ফর্মে নাম, বয়স, ইমেইল, ঠিকানা—অনেক কিছু থাকে।
এই ১০-১২টা `FormControl` কি আমরা আলাদা আলাদা ভেরিয়েবলে রাখব? না!

আমরা এগুলোকে একটা বস্তায় ভরে ফেলব। সেই বস্তার নাম **`FormGroup`**।
আগামী ক্লাসে আমরা শিখব কীভাবে ফর্ম গ্রুপিং করতে হয়।

স্বাগতম **"Angular মাস্তানি"** সিরিজের ৩৬তম পর্বে! 👨‍👩‍👧‍👦

গত ক্লাসে আমরা **`FormControl`** দিয়ে একটা সিঙ্গেল ইনপুট ফিল্ড (যেমন: ইমেইল) হ্যান্ডেল করেছি।
কিন্তু বাস্তবে একটা ফর্মে কি শুধু ইমেইল থাকে? নাম, ফোন নাম্বার, ঠিকানা, পাসওয়ার্ড—অনেক কিছু থাকে।

এখন ১০টা ইনপুটের জন্য কি আমরা ১০টা আলাদা `FormControl` ভেরিয়েবল বানাব?
*   `nameControl`
*   `ageControl`
*   `addressControl`...

উফ! কোড তো জগাখিচুড়ি হয়ে যাবে। 😫
এর সমাধান হলো **`FormGroup`**। এটা হলো একটা **"বাজারের ব্যাগ"**। আপনি সব ইনপুট (আলু, পটল, পেঁয়াজ) এই ব্যাগের ভেতর ঢুকিয়ে রাখবেন। হ্যান্ডেল করার সময় শুধু ব্যাগটা ধরলেই হবে।

আজকের টপিক: **FormControl-গুলোকে গ্রুপ করা (Grouping)।**

### **১. FormGroup আসলে কী? (The Container) 🧺**

*   **FormControl:** একজন সৈন্য (Single Input)।
*   **FormGroup:** পুরো প্লাটুন বা দল (Collection of Inputs)।

যখন আপনি `FormGroup` ব্যবহার করবেন, তখন পুরো ফর্মের ডাটা একটা সুন্দর **Object (JSON)** হিসেবে পাবেন।
যেমন:
```json
{
  "firstName": "করিম",
  "lastName": "চৌধুরী",
  "email": "karim@boss.com"
}
```

### **২. ব্লু-প্রিন্ট তৈরি (TS File) 📝**

চলুন একটা রেজিস্ট্রেশন ফর্ম বানাই।
`user-profile.component.ts` ফাইলে যান।

```typescript
import { Component } from '@angular/core';
import { ReactiveFormsModule, FormGroup, FormControl } from '@angular/forms'; // ১. FormGroup ইমপোর্ট করুন

@Component({
  selector: 'app-user-profile',
  standalone: true,
  imports: [ReactiveFormsModule], // ইমপোর্ট লিস্টে এটা থাকতেই হবে
  templateUrl: './user-profile.component.html',
  styleUrl: './user-profile.component.css'
})
export class UserProfileComponent {

  // ২. পুরো ফর্মের একটা গ্রুপ বানালাম
  profileForm = new FormGroup({
    
    // এর পেটের ভেতর সব কন্ট্রোল
    firstName: new FormControl(''),
    lastName: new FormControl(''),
    email: new FormControl('test@gmail.com'), // ডিফল্ট ভ্যালু
  });

  // ৩. সাবমিট করলে কী হবে
  handleFormSubmit() {
    console.log('পুরো ফর্মের ডাটা:', this.profileForm.value);
    // আউটপুট: { firstName: '', lastName: '', email: 'test@gmail.com' }
  }
}
```

### **৩. HTML কানেকশন (Binding) 🔗**

এখন `user-profile.component.html` ফাইলে এই গ্রুপটা কানেক্ট করতে হবে।
এখানে দুটো নতুন ডিরেক্টিভ লাগবে:
1.  **`[formGroup]`**: এটা বসবে `<form>` ট্যাগে। (পুরো ব্যাগের জন্য)
2.  **`formControlName`**: এটা বসবে `<input>` ট্যাগে। (ব্যাগের ভেতরের জিনিসের নাম)

```html
<div class="card">
  <h2>রেজিস্ট্রেশন ফর্ম</h2>

  <!-- ১. পুরো গ্রুপ কানেক্ট করা -->
  <form [formGroup]="profileForm" (ngSubmit)="handleFormSubmit()">

    <label>নামের প্রথম অংশ:</label>
    <!-- ২. কন্ট্রোলের নাম স্ট্রিং আকারে দিতে হবে -->
    <input type="text" formControlName="firstName">
    
    <br><br>

    <label>নামের শেষ অংশ:</label>
    <input type="text" formControlName="lastName">

    <br><br>

    <label>ইমেইল:</label>
    <input type="email" formControlName="email">

    <hr>
    
    <!-- ফর্ম ভ্যালিড না হলে বাটন ডিজেবল রাখার লজিক -->
    <button type="submit" [disabled]="!profileForm.valid">
      সেভ করুন 💾
    </button>

  </form>

  <h3>লাইভ প্রিভিউ:</h3>
  <pre>{{ profileForm.value | json }}</pre>

</div>
```

**⚠️ সাবধান:**
সিঙ্গেল কন্ট্রোলে আমরা লিখতাম `[formControl]="name"`.
কিন্তু গ্রুপের ভেতরে লিখব **`formControlName="name"`** (কোনো থার্ড ব্র্যাকেট `[]` ছাড়া, শুধু স্ট্রিং নাম)।

### **৪. `setValue` vs `patchValue` (ডাটা বসানো) 🛠️**

ধরুন, আপনি সার্ভার থেকে ইউজারের ডাটা এনে ফর্মে বসাতে চান। Angular এর `FormGroup`-এ ডাটা বসানোর দুইটা মেথড আছে। এবং ইন্টারভিউতে এটা খুব ধরে!

**১. `setValue()` - কড়া মাস্টার 👮‍♂️**
এটা ব্যবহার করলে আপনাকে **সবগুলো** ফিল্ডের মান দিতেই হবে। যদি একটাও বাদ দেন, সে এরর দেবে।
```typescript
fillData() {
  this.profileForm.setValue({
    firstName: 'রকি',
    lastName: 'ভাই',
    email: 'rocky@kgf.com' 
    // সব ফিল্ড থাকতে হবে, একটাও মিস করা যাবে না!
  });
}
```

**২. `patchValue()` - দয়ালু মাস্টার 😇**
এটা ব্যবহার করলে আপনি শুধু যেই ফিল্ড ইচ্ছা আপডেট করতে পারেন। বাকিগুলো যেমন ছিল তেমনই থাকবে।
```typescript
updateEmailOnly() {
  this.profileForm.patchValue({
    email: 'new@email.com'
    // নাম আর লাস্ট নেম দেওয়ার দরকার নেই
  });
}
```

**টিপস:** ৯০% সময় আমরা `patchValue` ব্যবহার করি কারণ এটা সেফ।

### **৫. Nested FormGroup (গ্রুপের ভেতর গ্রুপ) 📦**

ফর্ম অনেক বড় হলে আমরা গ্রুপের ভেতর গ্রুপ করতে পারি।
যেমন: **ঠিকানা (Address)** এর ভেতর আবার `city`, `street`, `zip` থাকে।

**TS:**
```typescript
profileForm = new FormGroup({
  name: new FormControl(''),
  
  // নেস্টেড গ্রুপ
  address: new FormGroup({
    city: new FormControl('Dhaka'),
    zip: new FormControl('1200')
  })
});
```

**HTML:**
```html
<form [formGroup]="profileForm">
  <input formControlName="name">
  
  <!-- নেস্টেড গ্রুপের জন্য div -->
  <div formGroupName="address">
    <input formControlName="city">
    <input formControlName="zip">
  </div>
</form>
```

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **`FormGroup`** হলো অনেকগুলো `FormControl` এর সমষ্টি বা কন্টেইনার।
2.  HTML-এ `<form [formGroup]="myForm">` দিয়ে কানেক্ট করতে হয়।
3.  ইনপুট ফিল্ডে **`formControlName="fieldName"`** ব্যবহার করতে হয়।
4.  পুরো ফর্মের ডাটা পেতে `this.myForm.value` ব্যবহার করি।
5.  ডাটা সেট করতে **`patchValue`** (আংশিক) বা **`setValue`** (পুরোটা) ব্যবহার করা হয়।

### **১. পুলিশ নিয়োগ (Adding Validators) 👮‍♂️**

Reactive Forms-এ ভ্যালিডেশন সেট করা খুব সহজ। `FormControl` বানানোর সময় দ্বিতীয় প্যারামিটারে রুলস বা নিয়মগুলো বলে দিতে হয়।

প্রথমে `Validators` ইমপোর্ট করতে হবে।

`user-profile.component.ts`:
```typescript
import { Component } from '@angular/core';
import { ReactiveFormsModule, FormGroup, FormControl, Validators } from '@angular/forms'; // ১. Validators ইমপোর্ট

@Component({
  ...
  imports: [ReactiveFormsModule]
})
export class UserProfileComponent {

  loginForm = new FormGroup({
    
    // ইমেইল: খালি রাখা যাবে না এবং ইমেইলের মতো দেখতে হতে হবে
    email: new FormControl('', [
      Validators.required, 
      Validators.email
    ]),

    // পাসওয়ার্ড: খালি রাখা যাবে না এবং অন্তত ৬ অক্ষরের হতে হবে
    password: new FormControl('', [
      Validators.required, 
      Validators.minLength(6)
    ])
  });

  onSubmit() {
    if (this.loginForm.valid) {
      alert('সব ঠিক আছে! ফর্ম সাবমিট হচ্ছে... ✅');
    } else {
      alert('ফর্মে ভুল আছে! দয়া করে চেক করুন। ❌');
    }
  }
}
```

**কমন কিছু ভ্যালিডেটর:**
*   `Validators.required`: অবশ্যই লিখতে হবে।
*   `Validators.minLength(n)`: কমপক্ষে n অক্ষর।
*   `Validators.maxLength(n)`: সর্বোচ্চ n অক্ষর।
*   `Validators.email`: সঠিক ইমেইল ফরম্যাট (যেমন @ থাকা)।
*   `Validators.pattern('...')`:Regex দিয়ে কাস্টম রুলস।

### **২. ভুল ধরে ওয়ার্নিং দেখানো (HTML Logic) ⚠️**

এখন আমাদের চ্যালেঞ্জ হলো HTML-এ ইউজারকে বলা যে সে কী ভুল করেছে।
আমরা কখন লাল মেসেজ দেখাব?
১. যদি ফিল্ডটি **Invalid** হয় (ভুল থাকে)।
২. **এবং** যদি ইউজার ফিল্ডটি **Touched** করে (ছুঁয়ে দেখে) বা **Dirty** করে (কিছু লিখে মুছে ফেলে)।

*(কারণ ইউজার ফর্মে ঢোকার সাথে সাথেই লাল দাগ দেখালে সে ভয় পেয়ে যাবে! তাই টাচ করার পর ভুল দেখাব।)*

`user-profile.component.html`:

```html
<div class="card">
  <h2>লগইন (সিকিউরড) 🔐</h2>

  <form [formGroup]="loginForm" (ngSubmit)="onSubmit()">

    <!-- ইমেইল ফিল্ড -->
    <div class="form-group">
      <label>ইমেইল:</label>
      <input type="text" formControlName="email">
      
      <!-- ভুল ধরার লজিক (নতুন @if সিনট্যাক্স) -->
      @if (loginForm.get('email')?.invalid && loginForm.get('email')?.touched) {
        
        <div class="error-msg">
          <!-- নির্দিষ্ট ভুল চেক করা -->
          @if (loginForm.get('email')?.errors?.['required']) {
            <small>ভাই, ইমেইল না দিলে হবে না! 😱</small>
          }
          @if (loginForm.get('email')?.errors?.['email']) {
            <small>এটা কোনো ইমেইল হলো? ঠিকমতো লিখুন! 📧</small>
          }
        </div>

      }
    </div>

    <br>

    <!-- পাসওয়ার্ড ফিল্ড -->
    <div class="form-group">
      <label>পাসওয়ার্ড:</label>
      <input type="password" formControlName="password">
      
      @if (loginForm.get('password')?.invalid && loginForm.get('password')?.touched) {
        <div class="error-msg">
          @if (loginForm.get('password')?.errors?.['required']) {
            <small>পাসওয়ার্ড দিন!</small>
          }
          @if (loginForm.get('password')?.errors?.['minlength']) {
            <small>অন্তত ৬ সংখ্যার পাসওয়ার্ড লাগবে।</small>
          }
        </div>
      }
    </div>

    <br>

    <!-- বাটন ডিজেবল রাখা (বোনাস) -->
    <button type="submit" [disabled]="loginForm.invalid">
      লগইন
    </button>

  </form>
</div>
```

### **৪. শর্টকাট টিপস (Getters) 🚀**

```typescript
}

get password() {

}
```

**এখন HTML-এ লিখুন:**
```html
@if (email?.invalid && email?.touched) { ... }
```

দেখুন কোড কত ক্লিন হয়ে গেল!

### **১. কাস্টম ভ্যালিডেটর আসলে কী? (The Logic) 🧠**

ভয় পাবেন না! কাস্টম ভ্যালিডেটর হলো নিছক একটা **জাভাস্ক্রিপ্ট ফাংশন**।
এই ফাংশনটা একটা ইনপুট বক্স (Control) হাতে নেয় এবং চেক করে দেখে।

এর রিটার্ন পলিসি একটু অদ্ভুত:
*   ✅ যদি সব ঠিক থাকে (Valid) 👉 রিটার্ন করবে **`null`** (মানে কোনো অভিযোগ নেই)।
*   ❌ যদি ভুল থাকে (Invalid) 👉 রিটার্ন করবে একটা **অবজেক্ট** `{ errorName: true }` (মানে অভিযোগ আছে)।

### **২. মিশন: "No Space Allowed" 🚫**

আমরা এমন একটা ভ্যালিডেটর বানাব, যেটা ইউজারনেমে কোনো ফাঁকা জায়গা (Space) দিতে দেবে না।

#### **ধাপ ১: আইন তৈরি করা (TS File)**

আপনি চাইলে আলাদা ফাইলে ভ্যালিডেটর রাখতে পারেন। তবে শেখার সুবিধার্থে আমরা `user-profile.component.ts` ফাইলের ভেতরেই (ক্লাসের বাইরে) ফাংশনটা লিখব।

```typescript
import { Component } from '@angular/core';
import { ReactiveFormsModule, FormGroup, FormControl, Validators, AbstractControl, ValidationErrors } from '@angular/forms'; 
// AbstractControl আর ValidationErrors টাইপ হিসেবে লাগে

// --- আমাদের কাস্টম ভ্যালিডেটর ফাংশন ---
// এই ফাংশনটি ইনপুট কন্ট্রোল রিসিভ করে
function noSpaceAllowed(control: AbstractControl): ValidationErrors | null {
  
  // ১. ইনপুটের ভ্যালু নিলাম
  const value = control.value as string;

  // ২. চেক করলাম স্পেস আছে কিনা
  if (value && value.includes(' ')) {
    // ❌ ভুল পেয়েছি! অভিযোগ দায়ের করলাম
    return { noSpace: true }; 
  }

  // ✅ সব ঠিক আছে
  return null;
}

@Component({
  selector: 'app-user-profile',
  standalone: true,
  imports: [ReactiveFormsModule],
  templateUrl: './user-profile.component.html',
  styleUrl: './user-profile.component.css'
})
export class UserProfileComponent {

  profileForm = new FormGroup({
    
    // ৩. ভ্যালিডেটর অ্যাপ্লাই করলাম
    username: new FormControl('', [
      Validators.required, 
      noSpaceAllowed // <--- আমাদের কাস্টম পুলিশ
    ])
    
  });
}
```

### **৫. প্যারামিটার সহ ভ্যালিডেটর (Advanced) 🚀**

ধরুন আপনি চান, ইউজারনেমে একটা নির্দিষ্ট শব্দ থাকতে হবে। কিন্তু শব্দটা ফিক্সড না, আমরা প্যারামিটার হিসেবে পাঠাব।
তখন ফাংশনটা একটু অন্যভাবে লিখতে হয় (Factory Function)।

**কোড (TS):**
```typescript
// শব্দ চেক করার ভ্যালিডেটর ফ্যাক্টরি
function containsWord(word: string) {
  return (control: AbstractControl): ValidationErrors | null => {
    if (control.value && !control.value.includes(word)) {
      return { requiredWord: true }; // এরর কি (Key)
    }
    return null;
  };
}

// ব্যবহার:
password: new FormControl('', [
  containsWord('Angular') // পাসওয়ার্ডে 'Angular' থাকতেই হবে
])
```

**HTML:**
```html
@if (form.get('password')?.errors?.['requiredWord']) {
  <small>পাসওয়ার্ডে অবশ্যই 'Angular' শব্দটি থাকতে হবে।</small>
}
```

### **৬. সার্ভার সাইড ভ্যালিডেশন (Async Validator) ⏳**

কাস্টম ভ্যালিডেটর দুই ধরনের হয়:
1.  **Sync (তাৎক্ষণিক):** যেমন স্পেস চেক করা। ব্রাউজারেই হয়ে যায়।
2.  **Async (দেরিতে):** যেমন "এই ইউজারনেমটি আগে কেউ নিয়েছে কিনা?"।
    *   এটার জন্য সার্ভারে কল করতে হয়।
    *   এটা `FormControl` এর **তৃতীয় প্যারামিটারে** দিতে হয়। (এটা আমরা পরে API ক্লাসে দেখব)।
