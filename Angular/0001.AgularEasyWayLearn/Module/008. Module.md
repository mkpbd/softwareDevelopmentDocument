
### **মডিউল ৯: API & HTTP (ইন্টারনেটের সাথে কথা বলা)**
*ডাটা তো আর আকাশ থেকে পড়বে না, সার্ভার থেকে আসবে।*

===============================================================
-+-+-+-+-+-+-+-+-+-+-+-+-+_+-=-+-+_+-+-=-+-+-=-+-+_=-+-+_=-+-+_=-+-+-=-+-=_=-+-+=+=+
স্বাগতম **"Angular মাস্তানি"** সিরিজের ৩৯তম পর্বে! 📨

এতদিন আমরা আমাদের অ্যাপের ভেতরেই খেলেছি। ডাটা বানিয়েছি, ফর্ম ফিলাপ করেছি, কিন্তু সেই ডাটা আমাদের পিসিতেই আটকে ছিল।
কিন্তু একটা রিয়েল অ্যাপে ডাটা আসে **সার্ভার (Server)** বা **ডাটাবেস** থেকে। আর আমাদের অ্যাপ থেকে ডাটা সার্ভারে পাঠাতে হয়।

Angular অ্যাপ এবং সার্ভারের (Backend) মাঝখানের এই যোগাযোগকারীর নামই হলো **`HttpClient`**।
সহজ বাংলায়, এটা হলো আমাদের ডিজিটাল **ডাকপিয়ন (Postman)**। 📮

আজ আমরা শিখব কীভাবে অ্যাপে এই ডাকপিয়নকে নিয়োগ দিতে হয়।

### **১. HttpClient আসলে কী? (The Bridge)  সেতু 🌉**

ধরুন, আপনি ফেসবুকে লগইন করলেন।
১. আপনি ইউজারনেম আর পাসওয়ার্ড দিলেন।
২. Angular এই ডাটা প্যাক করে **HttpClient**-এর হাতে দিল।
৩. HttpClient সেটা ইন্টারনেটের মাধ্যমে ফেসবুকের সার্ভারে নিয়ে গেল (Request)।
৪. সার্ভার চেক করে বলল "সব ঠিক আছে"।
৫. HttpClient সেই খবর (Response) নিয়ে আবার আপনার কাছে ফিরে এল।

এই পুরো আসা-যাওয়ার কাজটা করে `HttpClient`। সে **HTTP Protocol** (ইন্টারনেটের নিয়ম) মেনে চলে।

### **২. সেটআপ: পারমিশন দেওয়া (The Configuration) ⚙️**

Angular 21-এ `HttpClient` বাই-ডিফল্ট চালু থাকে না। অ্যাপকে হালকা রাখার জন্য এটা বন্ধ থাকে। আমাদের `app.config.ts` ফাইলে গিয়ে এটা অন করতে হবে।

*(আগে `app.module.ts`-এ `HttpClientModule` ইমপোর্ট করতে হতো। ওটা এখন জাদুঘরে।)*

**ধাপ ১:** আপনার প্রজেক্টের `src/app/app.config.ts` ফাইলটি ওপেন করুন।

**ধাপ ২:** `provideHttpClient` ফাংশনটা ব্যবহার করুন।

```typescript
import { ApplicationConfig } from '@angular/core';
import { provideRouter } from '@angular/router';
import { routes } from './app.routes';

// ১. ইমপোর্ট করুন
import { provideHttpClient, withFetch } from '@angular/common/http'; 

export const appConfig: ApplicationConfig = {
  providers: [
    provideRouter(routes),
    
    // ২. ডাকপিয়নকে নিয়োগ দিলাম
    provideHttpClient(
      withFetch() // এটা দিলে অ্যাপ আরও ফাস্ট হয় (Modern Fetch API ব্যবহার করে)
    ) 
  ]
};
```

**`withFetch()` কী?**
এটা Angular-এর নতুন ফিচার। আগে `XMLHttpRequest` ব্যবহার হতো (পুরনো আমলের গরুর গাড়ি)। `withFetch` ব্যবহার করলে ব্রাউজারের মডার্ন `fetch` API ব্যবহার হয়, যা অনেক দ্রুত এবং সার্ভার সাইড রেন্ডারিং (SSR) এর জন্য ভালো।

### **৩. সার্ভিসে ডাকপিয়ন ডাকা (Injecting) 💉**

আমরা জানি, ডাটা আনার কাজ **কম্পোনেন্ট** করে না, করে **সার্ভিস**। তাই আমরা আমাদের `UserService`-এ `HttpClient` কে ইনজেক্ট করব।

`user.service.ts` ফাইলে যান:

```typescript
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http'; // ১. ইমপোর্ট

@Injectable({
  providedIn: 'root'
})
export class UserService {
  
  // ২. ডাকপিয়নকে সার্ভিসের ভেতরে নিয়ে আসলাম
  private http = inject(HttpClient); 

  constructor() { 
    // এখন আমরা 'this.http' ব্যবহার করে ইন্টারনেটের সাথে কথা বলতে পারব
  }
}
```

### **৪. ডাকপিয়নের ৪টি অস্ত্র (HTTP Methods) ⚔️**

`HttpClient` মূলত ৪ ধরনের কাজ করে। একে সংক্ষেপে **CRUD** অপারেশন বলে:

1.  **GET (আনা):** সার্ভার থেকে ডাটা পড়ে নিয়ে আসা।
    *   *উদাহরণ:* নিউজফিড লোড করা।
2.  **POST (পাঠানো):** সার্ভারে নতুন ডাটা পাঠানো।
    *   *উদাহরণ:* রেজিস্ট্রেশন করা বা স্ট্যাটাস দেওয়া।
3.  **PUT / PATCH (আপডেট):** পুরনো ডাটা এডিট করা।
    *   *উদাহরণ:* প্রোফাইল পিকচার বদলানো।
4.  **DELETE (মুছে ফেলা):** ডাটা ডিলিট করা।
    *   *উদাহরণ:* পোস্ট ডিলিট করা।

আমরা `this.http.get(...)` বা `this.http.post(...)` লিখে এই কাজগুলো করব।

### **৫. JSONPlaceholder (আমাদের নকল সার্ভার) 🌐**

যেহেতু আমাদের নিজস্ব কোনো ব্যাকএন্ড বা সার্ভার নেই, তাই আমরা প্র্যাকটিসের জন্য একটা ফ্রি ফেইক এপিআই (Fake API) ব্যবহার করব।
তার নাম: **JSONPlaceholder** (jsonplaceholder.typicode.com)।

এরা আমাদের ফ্রিতে ডামি ডাটা দেয়।
*   লিংক: `https://jsonplaceholder.typicode.com/users`
*   এখানে গেলেই ১০টা ডামি ইউজারের ডাটা পাওয়া যায়।

### **১. ডাটার চেহারা চেনা (Interface) 🆔**

ডাটা আনার আগে আমাদের জানতে হবে ডাটা দেখতে কেমন?
আপনি যদি বাজারে যান "কিছু একটা" কিনতে, আর দোকানদার আপনাকে "ইট" ধরিয়ে দেয়, হবে? না!
TypeScript-কে বলে দিতে হবে আমরা কী ধরনের ডাটা আশা করছি।

আমরা একটা **Interface** বানাব।
`src/app/models/user.interface.ts` নামে একটা ফাইল বানান (অথবা কম্পোনেন্টের উপরেই লিখতে পারেন)।

```typescript
export interface User {
  id: number;
  name: string;
  email: string;
  website: string;
}
```
*এর মানে:* আমরা সার্ভার থেকে যা পাব, তাতে এই ৪টা জিনিস থাকতেই হবে।

### **২. সার্ভিসে রিকোয়েস্ট পাঠানো (The Chef's Job) 👨‍🍳**

এখন `user.service.ts` ফাইলে যান। এখানে আমরা `http.get` ব্যবহার করব।

```typescript
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { User } from '../models/user.interface'; // ১. ইন্টারফেস ইমপোর্ট

@Injectable({ providedIn: 'root' })
export class UserService {
  private http = inject(HttpClient);
  
  // আমাদের টার্গেট URL
  private apiUrl = 'https://jsonplaceholder.typicode.com/users';

  // ২. ডাটা আনার মেথড
  getAllUsers() {
    // এখানে <User[]> মানে আমরা বলছি: "অনেকগুলো ইউজারের একটা লিস্ট আসবে"
    return this.http.get<User[]>(this.apiUrl);
  }
}
```

**Observable কী?** 🌊
খেয়াল করবেন, `get()` মেথড কিন্তু সাথে সাথে ডাটা দেয় না। সে একটা **Observable** রিটার্ন করে।
Observable হলো পানির পাইপের মতো। পাইপ ফিট করলেন, কিন্তু কল (Subscribe) না ছাড়লে পানি পড়বে না।

### **৩. কম্পোনেন্টে ডাটা ধরা (The Waiter's Job) 🏃**

এখন `user-profile.component.ts` ফাইলে যান।
আমরা সার্ভিস থেকে ডাটা এনে একটা **Signal**-এ রাখব।

```typescript
import { Component, inject, OnInit, signal } from '@angular/core';
import { UserService } from '../services/user.service';
import { User } from '../models/user.interface';

@Component({
  selector: 'app-user-profile',
  standalone: true,
  templateUrl: './user-profile.component.html',
  styleUrl: './user-profile.component.css'
})
export class UserProfileComponent implements OnInit {
  
  userService = inject(UserService);
  
  // ১. ডাটা রাখার জন্য ফাঁকা সিগন্যাল (শুরুতে খালি অ্যারে)
  userList = signal<User[]>([]);

  // ২. লোডিং স্ট্যাটাস দেখানোর জন্য
  isLoading = signal(true);

  // ৩. পেজ লোড হওয়ার সাথে সাথে ডাটা আনব
  ngOnInit() {
    this.userService.getAllUsers().subscribe({
      
      // ক. যদি সফলভাবে ডাটা আসে (Success)
      next: (data) => {
        this.userList.set(data); // সিগন্যাল আপডেট করলাম
        this.isLoading.set(false); // লোডিং বন্ধ
        console.log('ডাটা পেয়েছি বস!', data);
      },
      
      // খ. যদি এরর হয় (Error)
      error: (err) => {
        console.error('সর্বনাশ! ডাটা আসেনি', err);
        this.isLoading.set(false);
      }
    });
  }
}
```

**`.subscribe()` কেন?**
মনে আছে পাইপের উদাহরণ? `subscribe()` কল করার আগ পর্যন্ত `HttpClient` সার্ভারে কোনো রিকোয়েস্ট পাঠায় না। সাবস্ক্রাইব করা মানেই হলো— *"মামা, আমি রেডি, ডাটা পাঠানো শুরু করো।"*

### **৪. স্ক্রিনে দেখানো (The Display) 🖥️**

এখন `user-profile.component.html`-এ লুপ চালিয়ে সুন্দর করে ডাটা দেখাব।

```html
<div class="container">
  <h2>আমাদের ইউজার ফ্যামিলি 👨‍👩‍👧‍👦</h2>

  <!-- যদি লোডিং হয় -->
  @if (isLoading()) {
    <p class="loading">⏳ ডাটা লোড হচ্ছে... অপেক্ষা করুন...</p>
  } 
  
  @else {
    <!-- ডাটা চলে আসলে লুপ চলবে -->
    <div class="grid">
      @for (user of userList(); track user.id) {
        
        <div class="user-card">
          <h3>{{ user.name }}</h3>
          <p>📧 {{ user.email }}</p>
          <p>🌐 <a [href]="'http://' + user.website" target="_blank">ভিজিট করুন</a></p>
          <small>ID: {{ user.id }}</small>
        </div>

      }
    </div>
  }
</div>
```

### **১. লজিক বুঝুন (The Concept) 🧠**

*   **POST:** নতুন চিঠি লিখে ডাকবাক্সে ফেলা। (সার্ভারে নতুন ডাটা তৈরি হবে)।
*   **PUT:** চিঠি পাঠানোর পর মনে হলো বানান ভুল হয়েছে, তাই গিয়ে ঠিক করে আসা। (সার্ভারের পুরনো ডাটা আপডেট হবে)।
*   **DELETE:** রাগের মাথায় চিঠি ছিঁড়ে ফেলা। (সার্ভার থেকে ডাটা মুছে যাবে)।

*(বিঃদ্রঃ আমরা যেহেতু ফেইক সার্ভার JSONPlaceholder ব্যবহার করছি, এরা ডাটা সেভ করে রাখে না, শুধু অভিনয় করে। তাই রিফ্রেশ দিলে সব আগের মতো হয়ে যাবে।)*

### **২. সার্ভিসে অস্ত্র যোগ করা (Service Update) 🛠️**

আমাদের `user.service.ts` ফাইলে যান। আগে শুধু `get()` ছিল, এখন বাকিগুলো যোগ করব।

```typescript
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { User } from '../models/user.interface';

@Injectable({ providedIn: 'root' })
export class UserService {
  private http = inject(HttpClient);
  private apiUrl = 'https://jsonplaceholder.typicode.com/users';

  // ১. GET: সব আনো
  getAllUsers() {
    return this.http.get<User[]>(this.apiUrl);
  }

  // ২. POST: নতুন তৈরি করো (Body লাগে)
  createUser(newUser: User) {
    return this.http.post<User>(this.apiUrl, newUser);
  }

  // ৩. PUT: আপডেট করো (ID এবং নতুন Body লাগে)
  updateUser(user: User) {
    // কোন ইউজার আপডেট হবে? তার আইডি URL-এর শেষে দিতে হয়
    const url = `${this.apiUrl}/${user.id}`; 
    return this.http.put<User>(url, user);
  }

  // ৪. DELETE: মুছে ফেলো (শুধু ID লাগে)
  deleteUser(id: number) {
    const url = `${this.apiUrl}/${id}`;
    return this.http.delete(url);
  }
}
```

### **৩. কম্পোনেন্টে অ্যাকশন (Component Logic) 🎮**

এখন `user-profile.component.ts`-এ এই ফাংশনগুলো কল করব এবং লোকাল সিগন্যাল আপডেট করব যাতে স্ক্রিনে চেঞ্জ দেখা যায়।

```typescript
import { Component, inject, OnInit, signal } from '@angular/core';
import { UserService } from '../services/user.service';
import { User } from '../models/user.interface';

@Component({ ... })
export class UserProfileComponent implements OnInit {
  userService = inject(UserService);
  userList = signal<User[]>([]);

  // ... ngOnInit আগের মতোই (GET Request)

  // ১. নতুন ইউজার তৈরি (Create)
  createNew() {
    const newUser: User = {
      id: 0, // সার্ভার অটো আইডি দেবে
      name: 'নতুন হিরো',
      email: 'hero@angular.com',
      website: 'hero.com'
    };

    this.userService.createUser(newUser).subscribe({
      next: (savedUser) => {
        // সার্ভার সফল বললে আমরা লোকাল লিস্টেও যোগ করব
        this.userList.update(list => [savedUser, ...list]); // লিস্টের শুরুতে বসালাম
        alert('সফলভাবে তৈরি হয়েছে! 🎉');
      }
    });
  }

  // ২. ইউজার আপডেট (Update)
  onEdit(user: User) {
    // আমরা নামটা একটু চেঞ্জ করে দিচ্ছি
    const updatedUser = { ...user, name: user.name + ' (Updated)' };

    this.userService.updateUser(updatedUser).subscribe({
      next: () => {
        // লোকাল লিস্ট আপডেট করা (যাতে রিফ্রেশ না লাগে)
        this.userList.update(list => 
          list.map(u => u.id === user.id ? updatedUser : u)
        );
        alert('নাম আপডেট হয়েছে! ✏️');
      }
    });
  }

  // ৩. ইউজার ডিলিট (Delete)
  onDelete(id: number) {
    const confirmDelete = confirm('সত্যিই কি ডিলিট করবেন? 😢');
    
    if (confirmDelete) {
      this.userService.deleteUser(id).subscribe({
        next: () => {
          // লোকাল লিস্ট থেকে বাদ দেওয়া (Filter)
          this.userList.update(list => list.filter(u => u.id !== id));
          alert('বিদায় পৃথিবী! 🗑️');
        }
      });
    }
  }
}
```

Angular-এ এই পুলিশের নাম **Http Interceptor**।

### **১. Interceptor আসলে কী? (The Toll Plaza) 🛂**

Interceptor হলো এমন একটা ফাংশন যা:
১. **রিকোয়েস্ট যাওয়ার সময়:** রিকোয়েস্টটাকে ধরে মডিফাই করে (হেডার বসায়, লগ করে)।
২. **রেসপন্স আসার সময়:** সার্ভার থেকে উত্তর আসার পর সেটা চেক করে (এরর হ্যান্ডলিং)।

এটা অনেকটা টোল প্লাজার মতো। গাড়ি (Request) গেলেই স্টিকার (Token) লাগিয়ে দেয়।

### **২. ইন্টারসেপ্টর তৈরি (Functional Interceptor) 🛠️**

Angular 21-এ আমরা **Functional Interceptor** ব্যবহার করি। এটা ক্লাস-বেসড ইন্টারসেপ্টরের চেয়ে অনেক সহজ।

**ধাপ ১:** একটা ফাইল তৈরি করুন `src/app/core/auth.interceptor.ts` (ম্যানুয়ালি বা CLI দিয়ে)।

**ধাপ ২:** কোড লিখুন:

```typescript
import { HttpInterceptorFn } from '@angular/common/http';

export const authInterceptor: HttpInterceptorFn = (req, next) => {
  
  // ১. ধরুন আমাদের টোকেন এটা (বাস্তবে এটা লোকাল স্টোরেজ থেকে আসবে)
  const myToken = 'super-secret-token-123';

  console.log(`🚧 রিকোয়েস্ট যাচ্ছে: ${req.url}-এ। টোকেন বসাচ্ছি...`);

  // ২. রিকোয়েস্ট ক্লোন (Clone) করা (মাস্ট!)
  // নিয়ম: অরিজিনাল রিকোয়েস্ট এডিট করা যায় না (Immutable)। তাই কপি করতে হয়।
  const cloneReq = req.clone({
    setHeaders: {
      Authorization: `Bearer ${myToken}`,
      'Custom-Header': 'Angular-Mastani'
    }
  });

  // ৩. মডিফাই করা রিকোয়েস্ট ছেড়ে দেওয়া (Go ahead)
  return next(cloneReq);
};
```

### **৩. কনফিগারেশন (The Registration) ⚙️**

পুলিশ বানালাম, কিন্তু তাকে রাস্তায় ডিউটি দিতে হবে তো!
`app.config.ts` ফাইলে যান।

এখানে `provideHttpClient` এর পেটের ভেতর `withInterceptors` দিয়ে আমাদের ইন্টারসেপ্টরকে রেজিস্টার করতে হবে।

```typescript
import { ApplicationConfig } from '@angular/core';
import { provideHttpClient, withInterceptors, withFetch } from '@angular/common/http';
import { authInterceptor } from './core/auth.interceptor'; // ১. ইমপোর্ট

export const appConfig: ApplicationConfig = {
  providers: [
    // ২. ইন্টারসেপ্টর যুক্ত করা
    provideHttpClient(
      withFetch(),
      withInterceptors([authInterceptor]) // <--- এই যে আমাদের পুলিশ
    )
  ]
};
```

ব্যাস! সেটআপ শেষ। এখন পুরো অ্যাপের যেকোনো জায়গা থেকে API কল করলেই এই ইন্টারসেপ্টর কাজ করবে।

### **৫. একাধিক কাজ (More Power) 💪**

ইন্টারসেপ্টর দিয়ে আরও অনেক কিছু করা যায়। যেমন: **লোডিং স্পিনার** দেখানো।

**উদাহরণ:**
রিকোয়েস্ট শুরু হলে স্পিনার ঘুরবে, শেষ হলে বন্ধ হবে।

```typescript
// loading.interceptor.ts
import { inject } from '@angular/core';
import { HttpInterceptorFn } from '@angular/common/http';
import { finalize } from 'rxjs';
import { LoaderService } from '../services/loader.service'; // ধরুন এমন একটা সার্ভিস আছে

export const loadingInterceptor: HttpInterceptorFn = (req, next) => {
  const loaderService = inject(LoaderService);

  // ১. স্পিনার চালু
  loaderService.show();

  return next(req).pipe(
    // ২. কাজ শেষ হলে (সফল বা ব্যর্থ), স্পিনার বন্ধ
    finalize(() => loaderService.hide())
  );
};
```
*(এরপর এটাকেও `app.config.ts`-এ অ্যাড করে দেবেন: `withInterceptors([authInterceptor, loadingInterceptor])`)*

### **৬. সাবধানতা (Warning) ⚠️**

*   **Immutable Request:** মনে রাখবেন, `req.clone()` না করে সরাসরি `req.headers.set(...)` করলে কাজ হবে না। কারণ রিকোয়েস্ট অবজেক্ট রিড-অনলি থাকে।
*   **Infinite Loop:** ইন্টারসেপ্টরের ভেতর থেকে আবার HTTP কল করার সময় সাবধান! নাহলে লুপে পড়ে যেতে পারে।

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **Interceptor** সব HTTP রিকোয়েস্ট এবং রেসপন্সকে মাঝপথে থামিয়ে মডিফাই করতে পারে।
2.  Angular 21-এ **`HttpInterceptorFn`** ব্যবহার করা হয়।
3.  **`req.clone()`** দিয়ে রিকোয়েস্ট কপি করে হেডার বা টোকেন বসাতে হয়।
4.  `app.config.ts`-এ **`withInterceptors([])`** দিয়ে এটি চালু করতে হয়।

### **১. লজিকটা কী? (The Ambulance Logic) 🏥**

৩. চেক করবে এররটা কোন ধরনের (404, 500, নাকি 0)?
৪. সেই অনুযায়ী ইউজারকে মেসেজ দেবে।

### **২. এরর ইন্টারসেপ্টর তৈরি (Coding Time) 🛠️**

একটা নতুন ফাইল বানান: `src/app/core/error.interceptor.ts`।

এখানে আমাদের RxJS-এর কিছু অপারেটর লাগবে:
*   **`catchError`**: ভুল ধরবে।
*   **`throwError`**: ভুলটা প্রসেস করার পর কম্পোনেন্টের কাছে ছুঁড়ে দেবে (যাতে লোডিং স্পিনার বন্ধ হয়)।

**কোড:**

```typescript
import { HttpErrorResponse, HttpInterceptorFn } from '@angular/common/http';
import { inject } from '@angular/core';
import { Router } from '@angular/router';
import { catchError, throwError } from 'rxjs';

export const errorInterceptor: HttpInterceptorFn = (req, next) => {
  const router = inject(Router); // ঘাড় ধাক্কা দেওয়ার জন্য (যদি লগইন লাগে)

  return next(req).pipe(
    // এই পাইপের ভেতর আমরা এরর ধরব
    catchError((error: HttpErrorResponse) => {
      
      let errorMessage = 'অজানা কোনো সমস্যা হয়েছে! 😵';

      if (error.error instanceof ErrorEvent) {
        // ১. ক্লায়েন্ট সাইড এরর (নেট নেই, বা কোডে ভুল)
        errorMessage = `নেটওয়ার্ক সমস্যা: ${error.error.message}`;
      } else {
        // ২. সার্ভার সাইড এরর (Backend Error)
        switch (error.status) {
          case 401:
            errorMessage = '⛔ আপনি লগইন করা নেই! দয়া করে লগইন করুন।';
            // টোকেন এক্সপায়ার হলে লগইন পেজে পাঠিয়ে দিচ্ছি
            router.navigate(['/login']); 
            break;
            
          case 403:
            errorMessage = '🚫 আপনার এখানে ঢোকার পারমিশন নেই!';
            break;
            
          case 404:
            errorMessage = '🔍 ডাটা খুঁজে পাওয়া যাচ্ছে না (Not Found)।';
            break;
            
          case 500:
            errorMessage = '🔥 সার্ভারে আগুন লেগেছে! (Internal Server Error)';
            break;
            
          default:
            errorMessage = `⚠️ এরর কোড: ${error.status}\nমেসেজ: ${error.message}`;
        }
      }

      // ৩. ইউজারকে দেখানো (এখানে আমরা অ্যালার্ট দিচ্ছি, প্রজেক্টে 'Toastr' ব্যবহার করবেন)
      alert(errorMessage);
      console.error('Ambulance Report:', error);

      // ৪. কম্পোনেন্টকেও জানিয়ে দেওয়া যে এরর হয়েছে
      return throwError(() => error);
    })
  );
};
```

### **৫. কম্পোনেন্ট ক্লিনআপ (Code Cleaning) 🧹**

এখন আমাদের কম্পোনেন্টের কোড কত সুন্দর হয়ে যাবে দেখুন!

```typescript
// ❌ আগের স্টাইল (কম্পোনেন্টে জঞ্জাল)
this.userService.getAllUsers().subscribe({
  next: (data) => { ... },
  error: (err) => { 
    if(err.status === 404) alert('Not found');
    else if(err.status === 500) alert('Server error');
    // ... আরও অনেক কোড
  }
});
```

এখন আমরা লিখব:

```typescript
// ✅ নতুন স্টাইল (ক্লিন)
this.userService.getAllUsers().subscribe({
  next: (data) => { ... },

    // এখানে শুধু লোডিং স্পিনার বন্ধ করব
    this.isLoading.set(false);
    // আর কিচ্ছু করার দরকার নেই! বাকিটা অ্যাম্বুলেন্স (Interceptor) দেখবে।
  }
});
```
