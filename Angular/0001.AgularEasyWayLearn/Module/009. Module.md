স্বাগতম **"Angular মাস্তানি"** সিরিজের ৪৪তম পর্বে! 💅

আমরা সার্ভার থেকে ডাটা এনেছি। কিন্তু সমস্যা হলো, সার্ভার আমাদের সাথে খুব "নিরামিষ" আচরণ করে।
সে ডাটা দেয় একদম কাঁচা (Raw)।
*   নাম দেয়: `kuddus mia` (ছোট হাতের)।
*   তারিখ দেয়: `2025-12-04T10:00:00.000Z` (দেখলে মনে হয় ওয়াইফাইয়ের পাসওয়ার্ড)। 😵
*   টাকা দেয়: `50000` (কোনো কমা বা টাকার চিহ্ন নেই)।

এই কাঁচা ডাটাকে ইউজারের সামনে সুন্দর করে সাজিয়ে পরিবেশন করার নামই হলো **Pipes**।
Pipe হলো Angular-এর **বিউটি পার্লার**। এখানে অসুন্দর ডাটা ঢুকবে, আর সুন্দর হয়ে বের হবে। 💄

---

### **১. Pipe চেনার উপায় (`|`) 💈**

কিবোর্ডের এন্টার বাটনের ওপরে যে খাড়া দাগটা `|` আছে, ওটাই হলো পাইপ সাইন।
**সিনট্যাক্স:**
```html
{{ ডাটা | পাইপের_নাম }}
```

---

### **২. Angular-এর রেডিমেড মেকআপ বক্স (Built-in Pipes) 🧰**

Angular আমাদের জন্য দারুণ কিছু পাইপ আগে থেকেই বানিয়ে রেখেছে। চলুন দেখি কোনটা দিয়ে কী হয়।

#### **ক. টেক্সট সাজানো (String Pipes)** 🅰️

ধরুন আপনার ডাটা: `name = 'aRiF aHmeD';`

1.  **`uppercase`**: সব বড় হাতের করবে।
    *   `{{ name | uppercase }}` 👉 **ARIF AHMED**
2.  **`lowercase`**: সব ছোট হাতের করবে।
    *   `{{ name | lowercase }}` 👉 **arif ahmed**
3.  **`titlecase`**: প্রতি শব্দের প্রথম অক্ষর বড় হাতের করবে (খুবই কাজের!)।
    *   `{{ name | titlecase }}` 👉 **Arif Ahmed**

#### **খ. টাকা সাজানো (Currency Pipe) 💰**

ধরুন আপনার বেতন: `salary = 50500.5;`

1.  **ডিফল্ট (Dollar):**
    *   `{{ salary | currency }}` 👉 **$50,500.50**
2.  **টাকা (BDT):**
    *   `{{ salary | currency:'BDT' }}` 👉 **BDT50,500.50**
3.  **কাস্টম সিম্বল (৳):**
    *   `{{ salary | currency:'BDT':'symbol' }}` 👉 **৳50,500.50**
4.  **দশমিক ছাড়া:**
    *   `{{ salary | currency:'BDT':'symbol':'1.0-0' }}` 👉 **৳50,501**

*(প্যারামিটারগুলো কোলন `:` দিয়ে আলাদা করতে হয়)*

#### **গ. তারিখ সাজানো (Date Pipe) 📅**

ধরুন আজকের তারিখ: `today = new Date();` (যা দেখতে খুবই জঘন্য)।

1.  **`short`**: `{{ today | date:'short' }}` 👉 **12/4/25, 2:30 PM**
2.  **`medium`**: `{{ today | date:'medium' }}` 👉 **Dec 4, 2025, 2:30:45 PM**
3.  **কাস্টম ফরম্যাট:** `{{ today | date:'dd-MM-yyyy' }}` 👉 **04-12-2025**
4.  **বার ও মাস সহ:** `{{ today | date:'EEEE, d MMMM, y' }}` 👉 **Thursday, 4 December, 2025**

#### **ঘ. ডিবাগিং হিরো (Json Pipe) 🕵️‍♂️**

এটা ডেভেলপারদের সেরা বন্ধু। আপনি যদি কোনো অবজেক্ট সরাসরি প্রিন্ট করেন `{{ user }}`, স্ক্রিনে দেখাবে `[object Object]`। কিছুই বোঝা যায় না।

*   **`json`**: `{{ user | json }}` 👉 পুরো অবজেক্টটা সুন্দর করে দেখাবে।

### **৩. হাতে-কলমে প্র্যাকটিস (Practical) 💻**

চলুন একটা কমপ্লিট প্রোফাইল কার্ড বানাই।

**TS ফাইল (`user-profile.component.ts`):**
```typescript
import { Component, signal } from '@angular/core';
import { CommonModule } from '@angular/common'; // Standalone-এ পাইপ ব্যবহারের জন্য এটা লাগে

@Component({
  selector: 'app-user-profile',
  standalone: true,
  imports: [CommonModule], // ১. CommonModule ইমপোর্ট করতে ভুলবেন না!
  templateUrl: './user-profile.component.html'
})
export class UserProfileComponent {
  user = signal({
    name: 'kuDDus boYaTi',
    salary: 45000,
    joinDate: new Date(),
    rating: 4.56789,
    description: 'খুবই ভালো গান গায় কিন্তু লিরিক্স ভুলে যায়।'
  });
}
```

**HTML ফাইল (`user-profile.component.html`):**
```html
<div class="card" style="padding: 20px; border: 1px solid #ccc;">
  
  <!-- ১. TitleCase -->
  <h2>নাম: {{ user().name | titlecase }}</h2>
  
  <!-- ২. Date with Format -->
  <p>জয়েন করেছেন: {{ user().joinDate | date:'fullDate' }}</p>

  <!-- ৩. Currency BDT -->
  <p>বেতন: {{ user().salary | currency:'BDT':'symbol' }}</p>

  <!-- ৪. Number (দশমিক কন্ট্রোল) -->
  <!-- '1.1-2' মানে: পূর্ণসংখ্যা অন্তত ১টা, দশমিকের পর ১ থেকে ২ ঘর -->
  <p>রেটিং: {{ user().rating | number:'1.1-2' }} ⭐</p>

  <!-- ৫. Slice (লেখা কেটে ছোট করা) -->
  <p>বর্ণনা: {{ user().description | slice:0:15 }}...</p>

  <hr>
  
  <!-- ৬. Chaining (একের অধিক পাইপ একসাথে) -->
  <p>জয়েনিং (বড় হাতের): {{ user().joinDate | date:'mediumDate' | uppercase }}</p>

</div>
```

### **৪. Chaining Pipes (কম্বো প্যাক) 🍔🍟**

আপনি চাইলে একাধিক পাইপ এক লাইনে ব্যবহার করতে পারেন।
যেমন, তারিখ ফরম্যাট করবেন আবার সেটাকে বড় হাতেরও করবেন।

```html
{{ today | date:'fullDate' | uppercase }}
```
**আউটপুট:** THURSDAY, DECEMBER 4, 2025

*(এখানে প্রথমে তারিখ ফরম্যাট হয়েছে, তারপর সেই রেজাল্ট আপারকেস হয়েছে। সিরিয়াল ইম্পর্ট্যান্ট!)*

### **৫. ইম্পর্ট্যান্ট নোট (মনে রাখুন) 🧠**

*   **View Only:** পাইপ কিন্তু আপনার আসল ডাটা (`user().name`) চেঞ্জ করে না। শুধু স্ক্রিনে দেখানোর সময় মেকআপ করে দেখায়। আসল ডাটা যেমন ছিল তেমনই থাকে।
*   **CommonModule:** Standalone Component-এ পাইপ কাজ না করলে চেক করুন `imports: [CommonModule]` অথবা নির্দিষ্ট পাইপ (যেমন `DatePipe`) ইমপোর্ট করা আছে কিনা।

এটা লম্বা লেখাকে ছোট করে ফেলবে এবং শেষে "..." জুড়ে দেবে। (যেমন: "Read More" ফিচারে লাগে)।

### **১. পাইপ তৈরির মেশিন (Generating Pipe) ⚙️**

আমরা CLI ব্যবহার করে পাইপ বানাব। `pipes` ফোল্ডারে রাখলে ঘর গোছানো থাকবে।

টার্মিনালে লিখুন:
```bash

```
বা সংক্ষেপে:
```bash
ng g p pipes/shorten
```

Angular দুটো ফাইল বানাবে:
1.  `shorten.pipe.ts` (লজিক ফাইল)
2.  `shorten.pipe.spec.ts` (টেস্ট ফাইল)

### **২. পাইপের অপারেশন থিয়েটার 🏥**

`shorten.pipe.ts` ফাইলটি ওপেন করুন। এখানে একটা ক্লাস পাবেন যেটা `PipeTransform` ইমপ্লিমেন্ট করে।
আসল কাজ হয় **`transform`** মেথডের ভেতর।

**কোড আপডেট করুন:**

```typescript
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({
  name: 'shorten', // <--- HTML-এ ডাকার নাম
  standalone: true // Angular 21-এ এটা অটোমেটিক থাকে
})
export class ShortenPipe implements PipeTransform {

  // transform মেথড: এটাই ইনপুট নেয় আর আউটপুট দেয়
  // value: যেই লেখার ওপর পাইপ বসাব
  // limit: কত অক্ষরে কাটব (প্যারামিটার)
  
  transform(value: string, limit: number = 50): string {
    
    // ১. যদি কোনো লেখা না থাকে, ফেরত যাও
    if (!value) return '';

    // ২. যদি লেখাটা লিমিটের চেয়ে ছোট হয়, যা আছে তাই দেখাও
    if (value.length <= limit) {
      return value;
    }

    // ৩. যদি বড় হয়, তবে কেটে সাইজ করো এবং '...' জোড়া দাও
    return value.substring(0, limit) + '...';
  }

}
```

দেখলেন? লজিকটা কিন্তু খুব সিম্পল জাভাস্ক্রিপ্ট। ইনপুট নাও 👉 প্রসেস করো 👉 রিটার্ন করো।

### **৩. ফ্যাক্টরি থেকে মার্কেটে (Usage) 🛒**

এখন এই পাইপটা আমরা `UserProfileComponent`-এ ব্যবহার করব।
যেহেতু এটা Standalone Pipe, তাই ব্যবহার করার আগে **Import** করতে হবে।

**ধাপ ১: ইমপোর্ট করা (TS File)**
`user-profile.component.ts`:
```typescript
import { Component } from '@angular/core';
import { ShortenPipe } from '../../pipes/shorten.pipe'; // ১. ইমপোর্ট

@Component({
  selector: 'app-user-profile',
  standalone: true,
  imports: [ShortenPipe], // ২. লিস্টে নাম তুলুন
  templateUrl: './user-profile.component.html'
})
export class UserProfileComponent {
  // একটা বিশাল বড় প্যারাগ্রাফ
  description = 'জামাল সাহেব খুব ভালো লোক কিন্তু তিনি কথা বললে আর থামতে চান না। গতকাল তিনি বাজারে গিয়ে মাছের দাম নিয়ে ১ ঘণ্টা ভাষণ দিয়েছেন। সেই ভাষণ শুনে মাছওয়ালা অজ্ঞান হয়ে গিয়েছিল।';
}
```

**ধাপ ২: HTML-এ ব্যবহার (Template)**
`user-profile.component.html`:

```html
<div class="card">
  <h2>জামাল সাহেবের গল্প</h2>

  <!-- ১. কোনো লিমিট ছাড়া (ডিফল্ট ৫০ অক্ষর) -->
  <p>{{ description | shorten }}</p>

  <hr>

  <!-- ২. লিমিট সহ (২০ অক্ষর) -->
  <p>
    <strong>সংক্ষেপে:</strong> 
    {{ description | shorten:20 }}
  </p>
  
</div>
```

### **৫. একাধিক আর্গুমেন্ট (Multiple Arguments) 🤹‍♂️**

ধরুন, আপনি চান ইউজার ঠিক করবে শেষে "..." বসবে নাকি " (Read More)" বসবে।

**Pipe লজিক আপডেট:**
```typescript
transform(value: string, limit: number, symbol: string = '...'): string {
   // ... আগের লজিক
   return value.substring(0, limit) + symbol;
}
```

**HTML ব্যবহার:**
```html
<!-- কোলন দিয়ে একটার পর একটা ভ্যালু পাঠান -->
{{ description | shorten : 20 : ' (আরও পড়ুন)' }}
```

### **৬. Pure vs Impure Pipe (গভীর আলোচনা) 🧠**

পাইপ ডেকোরেটরে একটা অপশন থাকে `pure: true` (ডিফল্ট) অথবা `false`।

*   **Pure Pipe (ভালো ছেলে):** এরা খুব ফাস্ট। ইনপুট ডাটা (String/Number) চেঞ্জ না হলে এরা নড়াচড়া করে না। আমরা সবসময় এটাই বানাই।
*   **Impure Pipe (দুষ্টু ছেলে):** এরা প্রতিটা মাউস ক্লিকে বা ডিটেকশন সাইকেলে রান হয়। অ্যাপ স্লো করে দেয়। ফিল্টারিং বা সার্চিংয়ের জন্য অনেকে এটা ব্যবহার করে, কিন্তু এটা **Bad Practice**।

### **১. Observable আসলে কী? (The Water Tank) 🚰**

ধরুন, আপনার ছাদের ওপর একটা পানির ট্যাংক আছে।
এই ট্যাংক থেকে একটা পাইপ আপনার বাথরুম পর্যন্ত এসেছে।

এখানে:
*   **Observable:** হলো ওই পানির ট্যাংক। সে পানি (Data) সাপ্লাই দিতে পারে।
*   **Stream:** পাইপের ভেতর দিয়ে যে পানিটা আসছে, সেটা হলো ডাটা স্ট্রিম।
*   **Subscriber:** আপনি যখন কল (Tap) ছাড়েন, তখন আপনি হলেন সাবস্ক্রাইবার।

**মজার ব্যাপার:**
ট্যাংকে হাজার লিটার পানি থাকলেও, আপনি যতক্ষণ না কল ছাড়বেন (Subscribe করবেন), ততক্ষণ এক ফোঁটা পানিও পড়বে না।
RxJS-এর প্রধান মন্ত্র: **"No Subscribe, No Data."**

### **২. Observable-এর ৩টি অবস্থা (The 3 States) 🚦**

যখন আপনি কল ছাড়েন (Subscribe করেন), তখন ৩টি ঘটনা ঘটতে পারে:

1.  **Next (পানি পড়ছে):** পানি বা ডাটা অনবরত আসতেই থাকে। (যেমন: ১ লিটার, ২ লিটার...)।
2.  **Error (পাইপ ফেটেছে):** হঠাৎ কোনো সমস্যা হলো, পানি আসা বন্ধ। (যেমন: সার্ভার ক্রাশ)।
3.  **Complete (ট্যাংক খালি):** পানি শেষ। আর কোনোদিন পানি আসবে না। কাজ খতম।

### **৩. ল্যাবরেটরি: হাতে-কলমে Observable তৈরি 🧪**

চলুন আমরা একটা কৃত্রিম পানির ট্যাংক (Observable) বানাই, যেটা প্রতি ১ সেকেন্ড পর পর ১টা করে ডাটা পাঠাবে।

`user-profile.component.ts` ফাইলে যান:

```typescript
import { Component, OnInit } from '@angular/core';
import { Observable } from 'rxjs'; // RxJS থেকে ইমপোর্ট

@Component({ ... })
export class UserProfileComponent implements OnInit {

  ngOnInit() {
    
    // ১. ট্যাংক তৈরি (Observable Create)
    // এই observer হলো সেই ব্যক্তি যে ডাটা পাঠাচ্ছে
    const myObservable = new Observable((observer) => {
      
      console.log('ট্যাংক রেডি! পানি ছাড়া শুরু...');

      observer.next('১ মগ পানি 💧'); // ১ম ডাটা
      observer.next('২ মগ পানি 💧'); // ২য় ডাটা
      
      // একটু দেরি করে পাঠাই (Synchronous না, Asynchronous বোঝানোর জন্য)
      setTimeout(() => {
        observer.next('৩ মগ পানি (দেরিতে এল) 💧');
        
        // observer.error('ওহ নো! পাইপ ফেটেছে! 💥'); // এটা দিলে আর নিচে নামবে না
        
        observer.complete(); // সব শেষ, টা টা! 👋
      }, 2000);

    });


    // ২. কল ছাড়া (Subscribe)
    // সাবস্ক্রাইব না করলে ওপরের কোড রানই হবে না!
    myObservable.subscribe({
      
      // ক. ডাটা আসলে (Next)
      next: (data) => {
        console.log('পেয়েছি:', data);
      },
      
      // খ. সমস্যা হলে (Error)
      error: (err) => {
        console.error('সমস্যা:', err);
      },
      
      // গ. সব শেষ হলে (Complete)
      complete: () => {
        console.log('ট্যাংক খালি! আর ডাটা আসবে না। ✅');
      }
      
    });

  }
}
```

**আউটপুট (Console):**
1.  পেয়েছি: ১ মগ পানি 💧
2.  পেয়েছি: ২ মগ পানি 💧
3.  *(২ সেকেন্ড পর)* পেয়েছি: ৩ মগ পানি (দেরিতে এল) 💧
4.  ট্যাংক খালি! আর ডাটা আসবে না। ✅

### **৪. Promise vs Observable (ভাইভা প্রশ্ন) 🎤**

ইন্টারভিউতে আপনাকে ১০০% জিজ্ঞেস করবে: *"Promise আর Observable-এর পার্থক্য কী?"*

| বৈশিষ্ট্য          | Promise (পিৎজা ডেলিভারি) 🍕           | Observable (নেটফ্লিক্স সিনেমা) 🎬                 |
| :----------------- | :------------------------------------ | :------------------------------------------------ |
| **ডাটা সংখ্যা**    | মাত্র **১টি** ডাটা দেয় (Pizza)।       | **একাধিক** ডাটা দিতে পারে (পুরো সিনেমার ফ্রেম)।   |
| **সময়**            | একবার দিলেই কাজ শেষ (Complete)।       | চলতেই থাকতে পারে (যেমন চ্যাট মেসেজ)।              |
| **বাতিল (Cancel)** | অর্ডার করলে আর ক্যানসেল করা যায় না।   | চাইলে মাঝপথে **Unsubscribe** (টিভি বন্ধ) করা যায়। |
| **Lazy/Eager**     | ডিক্লেয়ার করলেই কাজ শুরু করে (Eager)। | সাবস্ক্রাইব না করা পর্যন্ত কাজ করে না (Lazy)।     |

Angular-এ `HttpClient` বা `Forms` সবই Observable ব্যবহার করে কারণ এতে পাওয়ার বেশি।

### **৫. মেমোরি লিক ও Unsubscribe (সাবধান!) ⚠️**

ধরুন, আপনি বাথরুমের কল ছেড়ে দিয়ে অফিসে চলে গেলেন। কী হবে?
বাসা ভেসে যাবে! 🌊

RxJS-এ আপনি যদি `subscribe()` করেন কিন্তু কাজ শেষে `unsubscribe()` না করেন, তবে ব্যাকগ্রাউন্ডে ডাটা আসতেই থাকবে এবং অ্যাপ স্লো হয়ে যাবে (Memory Leak)।

**সমাধান ১: ম্যানুয়ালি বন্ধ করা**
```typescript
import { Subscription } from 'rxjs';

export class UserProfileComponent {
  private sub: Subscription; // সাবস্ক্রিপশন রসিদ

  ngOnInit() {
    this.sub = myObservable.subscribe(...);
  }

  // কম্পোনেন্ট ধ্বংস হওয়ার সময়
  ngOnDestroy() {
    this.sub.unsubscribe(); // কল বন্ধ করলাম
  }
}
```

**সমাধান ২: Async Pipe (সেরা উপায়) ⭐**
যদি আপনি HTML-এ ডাটা দেখাতে চান, তবে TS ফাইলে সাবস্ক্রাইব করার দরকার নেই। Angular-এর `async` পাইপ নিজেই কল ছাড়ে এবং কাজ শেষে কল বন্ধ করে দেয়।

```html
<p>ডাটা: {{ myObservable$ | async }}</p>
```
*(Observable ভেরিয়েবলের শেষে `$` চিহ্ন দেওয়া একটা কনভেনশন বা ভদ্রতা, যাতে বোঝা যায় এটা একটা স্ট্রিম)*

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **Observable** হলো ডাটার সোর্স (পানির ট্যাংক)।
2.  **Observer/Subscriber** হলো গ্রহীতা (আপনি)।

### **১. পার্থক্যটা কোথায়? (State vs Event) 🥊**

সহজ একটা উপমা দিই:

*   **Signals (ডিজিটাল ঘড়ি):**
    *   আপনি যখনই তাকাবেন, ঘড়ি আপনাকে **বর্তমান সময়** (Current Value) দেখাবে।
    *   আগে কী বেজেছিল, সেটা সে মনে রাখে না।
    *   **কাজ:** অ্যাপের **State** (নাম, বয়স, কাউন্টার, লিস্ট) রাখার জন্য সিগন্যাল সেরা।

*   **RxJS (কনভেয়ার বেল্ট / পানির পাইপ):**
    *   এটা একটা **প্রবাহ**। একটার পর একটা জিনিস আসতেই থাকে।
    *   আপনি চাইলে ডাটাকে মাঝপথে আটকাতে পারেন (Debounce), ফিল্টার করতে পারেন, বা মডিফাই করতে পারেন।
    *   **কাজ:** অ্যাপের **Events** (ক্লিক, টাইপিং, API Call) হ্যান্ডেল করার জন্য RxJS সেরা।

**গোল্ডেন রুল:**
> **"State (অবস্থা) এর জন্য Signals, আর Events (ঘটনা) এর জন্য RxJS ব্যবহার করুন।"**

### **২. RxJS থেকে Signal-এ রূপান্তর (`toSignal`) 🔄**

ধরুন, আপনার কাছে একটা Observable আছে (যেমন: `HttpClient` এর ডাটা)।
আপনি সেটাকে HTML-এ দেখাতে চান।
*   **আগে:** আমাদের `| async` পাইপ ব্যবহার করতে হতো বা `.subscribe()` করতে হতো।
*   **এখন:** আমরা Observable-কে সোজা সিগন্যাল বানিয়ে ফেলব।

এর জন্য লাগবে **`toSignal`** ফাংশন।

**কোড (TS):**
```typescript
import { Component, inject } from '@angular/core';
import { toSignal } from '@angular/core/rxjs-interop'; // ১. স্পেশাল ইমপোর্ট
import { UserService } from '../services/user.service';

@Component({ ... })
export class UserProfileComponent {
  userService = inject(UserService);

  // ২. Observable (API Call)
  userObserver$ = this.userService.getAllUsers(); 

  // ৩. কনভারশন (Observable -> Signal)
  // initialValue দিয়েছি যাতে ডাটা আসার আগে এরর না দেয়
  userList = toSignal(this.userObserver$, { initialValue: [] });

}
```

**কোড (HTML):**
```html
<!-- এখন আর | async বা subscribe কিচ্ছু লাগবে না! -->
<!-- জাস্ট সিগন্যালের মতো কল করুন () -->

<ul>
  @for (user of userList(); track user.id) {
    <li>{{ user.name }}</li>
  }
</ul>
```
**লাভ:** কোড অনেক ক্লিন হয়ে গেল এবং সিগন্যালের স্পিড পাওয়া গেল!

### **৩. Signal থেকে RxJS-এ রূপান্তর (`toObservable`) 🔄**

এবার উল্টোটা। ধরুন আপনার কাছে একটা সিগন্যাল আছে (যেমন: সার্চ বক্সের ইনপুট)।
আপনি চান ইউজার টাইপ করা বন্ধ করার **৩০০ মিলি সেকেন্ড** পর সার্চ হোক (**Debounce**)।

সিগন্যাল দিয়ে "অপেক্ষা করা" বা Debounce করা খুব কঠিন। কিন্তু RxJS-এ এটা এক লাইনের কাজ।
তাই আমরা সিগন্যালকে Observable বানিয়ে RxJS-এর পাওয়ার ব্যবহার করব।

এর জন্য লাগবে **`toObservable`** ফাংশন।

**কোড (TS):**
```typescript
import { Component, signal, effect, inject } from '@angular/core';
import { toObservable } from '@angular/core/rxjs-interop'; // স্পেশাল ইমপোর্ট
import { debounceTime, distinctUntilChanged } from 'rxjs';

@Component({ ... })
export class SearchComponent {
  
  // ১. আমাদের সার্চ ইনপুট (সিগন্যাল)
  searchQuery = signal('');

  // ২. সিগন্যালকে Observable বানালাম
  query$ = toObservable(this.searchQuery);

  constructor() {
    // ৩. এখন আমরা RxJS-এর পাইপলাইন ব্যবহার করতে পারব
    this.query$
      .pipe(
        debounceTime(500), // ৫০০ms অপেক্ষা করো
        distinctUntilChanged() // একই লেখা বারবার লিখলে সার্চ দিও না
      )
      .subscribe(val => {
        console.log('সার্চ করছি:', val);
        // এখানে API কল হবে...
      });
  }

  // ইনপুট হ্যান্ডলার
  onType(e: any) {
    this.searchQuery.set(e.target.value);
  }
}
```

**লাভ:** আমরা সিগন্যালের সহজ সিনট্যাক্সও পেলাম, আবার RxJS-এর পাওয়ারফুল অপারেটরও ব্যবহার করতে পারলাম।

### **৪. সারাংশ: কে কোথায় বস? 😎**

| পরিস্থিতি | বস কে? | কেন? |
| :--- | :--- | :--- |
| **টেমপ্লেটে ডাটা দেখানো** | **Signal** | `changeDetection` দরকার হয় না, সুপার ফাস্ট। |
| **HTTP Request (API)** | **RxJS** | কারণ এটা নিজে থেকেই Observable রিটার্ন করে। |
| **API ডাটা রিসিভ করে রাখা** | **Signal** | `toSignal` দিয়ে কনভার্ট করে রাখলে দেখানো সহজ। |
| **Debounce / Delay** | **RxJS** | সময়ের কাজ RxJS ভালো পারে। |
| **Complex Logic (Race/Merge)** | **RxJS** | একাধিক স্ট্রিম মেশানোর জন্য RxJS অপ্রতিদ্বন্দ্বী। |

---

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  RxJS এবং Signals একে অপরের পরিপূরক।
2.  **`toSignal`**: Observable থেকে সিগন্যাল বানায় (View-তে ডাটা দেখানোর জন্য সেরা)।
3.  **`toObservable`**: সিগন্যাল থেকে Observable বানায় (RxJS অপারেটর ব্যবহারের জন্য)।
4.  ইমপোর্ট করতে হয়: **`@angular/core/rxjs-interop`** থেকে।

### **১. কেন দরকার? (The Problem) 😫**

ধরুন, আপনি একটা সুন্দর **`CardComponent`** বানিয়েছেন।
*   এক জায়গায় কার্ডের ভেতর শুধু **টেক্সট** দেখাতে হবে।
*   আরেক জায়গায় কার্ডের ভেতর একটা **ছবি** দেখাতে হবে।
*   অন্য জায়গায় একটা **ভিডিও প্লেয়ার** দেখাতে হবে।

আপনি যদি `@Input()` দিয়ে ডাটা পাঠান, তবে টেক্সট পাঠানো সহজ। কিন্তু ইনপুট দিয়ে কি `<img>` ট্যাগ বা `<video>` ট্যাগ পাঠানো যায়? গেলে সেটা জগাখিচুড়ি হবে।

সমাধান: আমরা কার্ডের মাঝখানে একটা **জানালা** কেটে রাখব। সেই জানালার নাম **`<ng-content>`**।

### **২. সিঙ্গেল স্লট প্রোজেকশন (Single Slot) 🕳️**

চলুন একটা `AppCard` বানাই যার মাঝখানে যা ইচ্ছা রাখা যাবে।

**ধাপ ১: চাইল্ড কম্পোনেন্ট (`card.component.ts`)**
```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-card',
  standalone: true,
  template: `
    <div class="card-box">
      <h3>কার্ডের শিরোনাম (ফিক্সড)</h3>
      <hr>
      
      <!-- এই সেই জাদুর জানালা -->
      <ng-content></ng-content>
      
      <hr>
      <small>কার্ডের ফুটার (ফিক্সড)</small>
    </div>
  `,
  styles: [`
    .card-box { border: 2px solid #333; padding: 20px; width: 300px; border-radius: 10px; margin: 10px; }
  `]
})
export class CardComponent {}
```

**ধাপ ২: প্যারেন্টে ব্যবহার (Parent Usage)**
এখন `user-profile.component.html` এ এই কার্ড ব্যবহার করব।

```html
<!-- ১. টেক্সট দিয়ে -->
<app-card>
  <p>আমি সাধারণ টেক্সট! 👋</p>
</app-card>

<!-- ২. ছবি দিয়ে -->
<app-card>
  <img src="https://i.pravatar.cc/150" alt="Avatar">
  <button>লাইক দিন 👍</button>
</app-card>
```

**আউটপুট:**
দেখবেন দুটি কার্ডের বর্ডার, হেডার, ফুটার সেম। কিন্তু পেটের ভেতরের জিনিস আলাদা।
`app-card` ট্যাগের মাঝখানে যা লিখেছেন, Angular সেটা কপি করে `<ng-content>` এর জায়গায় বসিয়ে দিয়েছে।

### **৩. মাল্টি স্লট প্রোজেকশন (Multiple Slots) 🗂️**

এখন ধরুন, আপনি চান হেডার আর ফুটারও বাইরে থেকে আসবে। কিন্তু এলোমেলোভাবে না।
*   হেডার যাবে উপরে।
*   বডি যাবে মাঝখানে।
*   ফুটার যাবে নিচে।

এর জন্য আমাদের `<ng-content>` কে নাম দিতে হবে। একে বলে **`select`** অ্যাট্রিবিউট।

**ধাপ ১: চাইল্ড আপডেট (`card.component.ts`)**
```typescript
@Component({
  selector: 'app-smart-card',
  standalone: true,
  template: `
    <div class="card-box">
      
      <!-- ১. হেডার স্লট (যাদের গায়ে 'header' অ্যাট্রিবিউট আছে) -->
      <div class="header-style">
        <ng-content select="[card-header]"></ng-content>
      </div>

      <hr>

      <!-- ২. বডি স্লট (যাদের গায়ে কোনো ট্যাগ নেই, বা 'body') -->
      <div class="body-style">
        <ng-content></ng-content> <!-- ডিফল্ট স্লট -->
      </div>

      <hr>

      <!-- ৩. ফুটার স্লট (যাদের গায়ে 'footer' অ্যাট্রিবিউট আছে) -->
      <div class="footer-style">
        <ng-content select="[card-footer]"></ng-content>
      </div>

    </div>
  `
})
export class SmartCardComponent {}
```
*এখানে `select="[card-header]"` মানে হলো—বাইরে থেকে যার গায়ে `card-header` লেখা থাকবে, তাকে চুম্বকের মতো টেনে এখানে বসাবে।*

**ধাপ ২: প্যারেন্টে ব্যবহার (Parent Usage)**

```html
<app-smart-card>
  
  <!-- ফুটার (আমি যেখানেই লিখি, সে নিচে গিয়েই বসবে) -->
  <button card-footer>Save Changes 💾</button>

  <!-- হেডার -->
  <h2 card-header>স্পেশাল অফার! 🎉</h2>

  <!-- বডি (কিছু না লিখলে ডিফল্ট স্লটে যাবে) -->
  <p>এই অফারটি সীমিত সময়ের জন্য প্রযোজ্য। তাড়াতাড়ি করুন!</p>

</app-smart-card>
```

**ম্যাজিক:**
আমি কোডে ফুটার আগে লিখেছি, হেডার পরে। কিন্তু আউটপুট দেখবেন—হেডার ওপরেই আছে, ফুটার নিচেই আছে। কারণ `select` দিয়ে তাদের সিট বুকিং করা ছিল।

### **৪. কেন `@Input` ব্যবহার করব না? 🤔**

অনেকে বলতে পারেন, "ভাই, টাইটেল তো ইনপুট স্ট্রিং হিসেবেই পাঠানো যেত!"
হ্যাঁ যেত। কিন্তু যদি টাইটেলটা এমন হয়?
```html
<h2 card-header>
  স্বাগতম <span style="color: red">বন্ধু!</span>
  <icon-star></icon-star>
</h2>
```
এত স্টাইল আর আইকনসহ HTML স্ট্রিং ইনপুট দিয়ে পাঠানো খুবই কষ্টের। তাই **Content Projection** এখানে সেরা।

### **৫. বাস্তব উদাহরণ: Modal / Popup 🪟**

সবচেয়ে বেশি এটা লাগে **মডাল** বা **পপ-আপ** বানাতে।
মডালের ফ্রেম (সাদা বক্স, ক্লোজ বাটন, ব্যাকগ্রাউন্ড) ফিক্সড থাকে। কিন্তু ভেতরের মেসেজ বা ফর্ম একেক পেজে একেক রকম হয়।
তখন আমরা `<app-modal>` বানাই এবং `<ng-content>` দিয়ে ভেতরের মালমসলা ঢোকাই।

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **Content Projection** হলো কম্পোনেন্টের ভেতর বাইরের কন্টেন্ট ইনজেক্ট করার উপায়।
2.  **`<ng-content>`** ট্যাগটি প্লেসহোল্ডার হিসেবে কাজ করে।
3.  **`select="[selector]"`** ব্যবহার করে নির্দিষ্ট জায়গায় নির্দিষ্ট কন্টেন্ট বসানো যায় (Multi-slot)।
4.  এটা `@Input` এর চেয়ে ফ্লেক্সিবল কারণ এতে HTML/Component পাস করা যায়।

স্বাগতম **"Angular মাস্তানি"** সিরিজের ৪৯তম পর্বে! 🚀

আজকের পর্বটা একটু "ইঞ্জিনিয়ারিং" লেভেলের। এতদিন আমরা যা বানিয়েছি, তা ইউজারের ব্রাউজারে সুন্দরভাবে চলে। কিন্তু Google বা Facebook-এর বটের কাছে আমাদের অ্যাপটা কেমন দেখায় জানেন?
একদম **সাদা খাতা**! 📝

আজ আমরা শিখব কীভাবে অ্যাপকে **SEO Friendly** এবং **সুপার ফাস্ট** করা যায়।
আজকের টপিক: **SSR (Server-Side Rendering)** এবং **Hydration (প্রাণ প্রতিষ্ঠা)**।

### **১. সমস্যা: CSR (Client-Side Rendering) 🐢**

Angular বাই-ডিফল্ট **CSR** ব্যবহার করে।
ধরুন, আপনি রেস্টুরেন্টে গিয়ে বিরিয়ানি অর্ডার করলেন।
*   **CSR স্টাইল:** ওয়েটার আপনাকে চাল, ডাল, মাংস, মশলা আর একটা চুলা দিয়ে গেল। বলল— *"স্যার, আপনি রান্না করে খেয়ে নিন।"*
*   **বাস্তবে:** ব্রাউজার সার্ভার থেকে একটা খালি `index.html` আর বিশাল `JS` ফাইল নামায়। তারপর ব্রাউজার নিজে সেই কোড রান করে পেজ বানায়।

**সমস্যা:**
১. **লোডিং টাইম:** ইউজারের মোবাইল স্লো হলে পেজ আসতে দেরি হয় (সাদা স্ক্রিন থাকে)।
২. **SEO:** গুগল বট এসে দেখে পেজে কোনো লেখা নেই, শুধু `<app-root></app-root>`। সে রেগে গিয়ে আপনার সাইট র‍্যাঙ্ক করে না।

---

### **২. সমাধান: SSR (Server-Side Rendering) 🚄**

**SSR স্টাইল:** ওয়েটার কিচেন থেকে ধোঁয়া ওঠা গরম বিরিয়ানি এনে টেবিলে দিল। আপনি সাথে সাথে খাওয়া শুরু করলেন।

Angular-এ SSR অন করলে:
১. সার্ভার নিজেই HTML জেনারেট করে ব্রাউজারে পাঠায়।
২. ইউজার চোখের পলকে (মিলি সেকেন্ডে) পেজের কন্টেন্ট দেখতে পায়।
৩. গুগল বট খুশি হয় কারণ সে পূর্ণাঙ্গ HTML পায়।

---

### **৩. Hydration: মরা শরীরে প্রাণ দেওয়া 🧟‍♂️➡️dh🤵**

SSR-এ সার্ভার থেকে যে HTML আসে, সেটা কিন্তু **"মৃত" (Static)**।
আপনি বাটনে ক্লিক করলে কাজ হবে না, কারণ জাভাস্ক্রিপ্ট তখনো লোড হয়নি।

এরপর ব্রাউজারে Angular-এর জাভাস্ক্রিপ্ট ফাইল লোড হয়। সে এসে ওই স্ট্যাটিক HTML-এর ওপর ভর করে এবং সেটাকে **জীবন্ত (Interactive)** করে তোলে।
এই প্রক্রিয়াকে বলা হয় **Hydration**।

**Angular 21-এর ম্যাজিক:**
আগে Angular পুরো পেজ ডিলিট করে নতুন করে বানাত (Destructive Hydration)। এতে স্ক্রিন একবার কেঁপে উঠত (Flicker)।
কিন্তু Angular 21-এ **Non-Destructive Hydration** ব্যবহার হয়। মানে সে আলতো করে HTML-এর গায়ে ইভেন্ট লিসেনার লাগিয়ে দেয়। ইউজার টেরই পায় না কখন পেজ জীবন্ত হয়ে গেল!

### **৪. প্রোজেক্টে SSR চালু করা ⚙️**

Angular 21-এ নতুন প্রোজেক্ট বানানোর সময় `ng new` কমান্ডেই SSR অন করার অপশন থাকে।
যদি আগে না করে থাকেন, তবে ভয়ের কিছু নেই। এক কমান্ডেই এটা অন করা যায়।

টার্মিনালে লিখুন:
```bash
ng add @angular/ssr
```
ব্যাস! Angular অটোমেটিক সার্ভার ফোল্ডার (`server.ts`) বানাবে এবং সব কনফিগার করে দেবে।

---

### **৫. কনফিগারেশন চেক (app.config.ts) 🧐**

`src/app/app.config.ts` ফাইলে গিয়ে দেখুন `provideClientHydration()` আছে কিনা।

```typescript
import { ApplicationConfig } from '@angular/core';
import { provideRouter } from '@angular/router';
import { provideClientHydration } from '@angular/platform-browser'; // ১. ইমপোর্ট

export const appConfig: ApplicationConfig = {
  providers: [
    provideRouter(routes),
    
    // ২. হাইড্রেশন চালু করা
    provideClientHydration() 
  ]
};
```
এই এক লাইন কোডই আপনার অ্যাপকে মডার্ন করে তোলে!

### **৬. সাবধান! ডেভেলপারদের কমন ভুল ⚠️**

SSR ব্যবহার করলে একটা বিষয়ে খুব সতর্ক থাকতে হয়।
সার্ভারে (Node.js) কিন্তু **ব্রাউজার নেই**। তাই সেখানে `window`, `document`, `localStorage`—এসব জিনিস নেই।

যদি আপনি কম্পোনেন্টে লেখেন:
```typescript
constructor() {
  // ❌ এটা সার্ভারে রান হলে অ্যাপ ক্রাশ করবে!
  console.log(window.innerWidth); 
}
```

**সমাধান ১: `afterNextRender` (Angular 21)**
এই ফাংশনের ভেতর যা লিখবেন, তা শুধু ব্রাউজারে রান হবে, সার্ভারে নয়।

```typescript
import { Component, afterNextRender } from '@angular/core';

@Component({...})
export class UserProfileComponent {
  constructor() {
    // ✅ এটা নিরাপদ
    afterNextRender(() => {
      console.log('উইন্ডো সাইজ:', window.innerWidth);
      localStorage.setItem('visited', 'true');
    });
  }
}
```

**সমাধান ২: Platform Check (পুরাতন পদ্ধতি)**
```typescript
import { PLATFORM_ID, Inject } from '@angular/core';
import { isPlatformBrowser } from '@angular/common';

constructor(@Inject(PLATFORM_ID) private platformId: Object) {
  if (isPlatformBrowser(this.platformId)) {
    // শুধু ব্রাউজারে রান হবে
    alert('হ্যালো ব্রাউজার!');
  }
}
```

### **৭. SSR এর সুবিধা এক নজরে ✅**

1.  **FCP (First Contentful Paint):** পেজ লোড হওয়ার স্পিড অনেক বেড়ে যায়।
2.  **SEO (Search Engine Optimization):** গুগল, বিং আপনার সাইট পড়তে পারে।
3.  **Social Sharing:** ফেসবুকে বা টুইটারে লিংক শেয়ার করলে সুন্দর প্রিভিউ (ছবি, টাইটেল) আসে।

### **📝 আজকের সারসংক্ষেপ (Recap):**

1.  **SSR**-এ সার্ভার রেডিমেড HTML পাঠায়, ফলে পেজ দ্রুত লোড হয়।
2.  **Hydration** হলো সেই প্রক্রিয়া যার মাধ্যমে স্ট্যাটিক HTML জীবন্ত হয়।

### **১. কোড গোছানো (The Build Process) 📦**

আমাদের কোড আছে TypeScript-এ। কিন্তু ব্রাউজার বোঝে JavaScript।
তাছাড়া আমাদের কোডে অনেক স্পেস, কমেন্ট আর হাবিজাবি আছে। লাইভ করার আগে এগুলোকে কম্প্রেস করে ছোট করতে হবে। একে বলে **Build** করা।

**টার্মিনালে লিখুন:**
```bash
ng build
```

**কী ঘটবে?**
Angular আপনার পুরো প্রজেক্টকে মিনিফাই করে একটা ফোল্ডারে প্যাক করবে।
আপনার প্রজেক্ট ফোল্ডারে গিয়ে দেখুন **`dist`** নামে নতুন একটা ফোল্ডার তৈরি হয়েছে।
এর ভেতর `your-project-name` ফোল্ডার আছে। আর তার ভেতর `browser` ফোল্ডারে `index.html` সহ কিছু ফাইল আছে।
👉 **এই `browser` ফোল্ডারটাই হলো আমাদের আসল সম্পদ।** এটাই আমরা সার্ভারে আপলোড করব।

### **৩. ড্রাগ অ্যান্ড ড্রপ পদ্ধতি (সবচেয়ে সহজ) 🖱️**

কোনো কমান্ড লাইন বা গিটহাবের ঝামেলা ছাড়া যদি লাইভ করতে চান:

1.  আপনার পিসির ফাইল এক্সপ্লোরারে **`dist/your-project-name/browser`** ফোল্ডারটা খুঁজে বের করুন। (যেখানে `index.html` আছে)।
2.  ব্রাউজারে গিয়ে [app.netlify.com/drop](https://app.netlify.com/drop) লিংকে যান।
3.  সেখানে একটা বক্স দেখবেন: **"Drag and drop your site output folder here"**।
4.  আপনার ওই **`browser`** ফোল্ডারটা টেনে এনে ওই বক্সে ছেড়ে দিন।

**ম্যাজিক! ✨**
৫-১০ সেকেন্ডের মধ্যে Netlify আপনাকে একটা লিংক দেবে (যেমন: `random-name.netlify.app`)। লিংকে ক্লিক করুন।
আপনার অ্যাপ এখন ইন্টারনেটে লাইভ! 🌍

### **৫. রাউটিং সমস্যা ও সমাধান (404 Error Fix) 🚑**

লাইভ তো করলেন, কিন্তু একটা **মারাত্মক সমস্যা** হতে পারে।
অ্যাপের হোম পেজ ঠিকই আসবে। কিন্তু আপনি যদি `/about` পেজে গিয়ে **Refresh** দেন, দেখবেন **"404 Not Found"** দেখাচ্ছে।

**কেন?**
কারণ Angular হলো SPA (Single Page Application)। সার্ভারে তো `about.html` বলতে কিছু নেই, আছে শুধু `index.html`। রিফ্রেশ দিলে সার্ভার কনফিউজড হয়ে যায়।

**সমাধান (Netlify-এর জন্য):**
আমাদের `src` ফোল্ডারের ভেতর (অথবা `public` ফোল্ডারে) একটা ফাইল বানাতে হবে যার নাম **`_redirects`** (কোনো এক্সটেনশন নেই)।

ফাইলের ভেতর লিখুন:
```text
/*  /index.html  200
```
*(মানে: ইউজার যেই লিংকেই যাক না কেন, তাকে `index.html` ধরিয়ে দাও, বাকিটা Angular বুঝে নেবে।)*

**Angular Config আপডেট:**
`angular.json` ফাইলে যান। `assets` অ্যারেতে এই ফাইলটা চিনিয়ে দিন যাতে বিল্ড ফোল্ডারে এটা কপি হয়।

```json
"assets": [
  "src/favicon.ico",
  "src/assets",
  "src/_redirects" // <--- এটা যোগ করুন
],
```
এরপর আবার `ng build` দিয়ে রি-ডিপ্লয় করুন। সমস্যা সমাধান! ✅
