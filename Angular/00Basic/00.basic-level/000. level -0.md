### 🥣 **Part 1: The Modern JavaScript (ES6+) Ingredients**
তোমার কিচেনের টুলসগুলো এখন আপগ্রেড হয়েছে। পুরনো জং ধরা ছুরি (Old JS) বাদ দিয়ে আমরা লেজার নাইফ (Modern JS) ব্যবহার করব।

#### 1. Constants (`const`) & Variables (`let`)
*   **এনালজি:**
    *   `const`: প্রেসার কুকার। একবার ঢাকনা লাগালে আর খোলা যায় না (মান বদলানো যায় না)।
    *   `let`: সাধারণ কড়াই। যখন ইচ্ছা ঢাকনা খোলো, মশলা দাও, নাড়াচাড়া করো (মান বদলানো যায়)।
*   **Code:**
    ```javascript
    const restaurantName = "Bhai Bhai Biryani"; // এটা বদলাবে না
    let totalCustomer = 10; // এটা বাড়তে বা কমতে পারে
    ```

#### 2. `Arrow Functions (`=>`)
*   **এনালজি:** আগে শেফকে রেসিপি লিখতে হলে পুরো চিঠি লিখতে হতো। এখন সে ইশারায় (Arrow) কাজ সারে। শর্টকাট!
*   **Code:**
    ```javascript
    // Old way
    function cook(food) { return "Cooking " + food; }

    // Smart Way (Arrow Function)
    const cook = (food) => `Cooking ${food}`;
    ```

#### 3. Template Literals (Backticks `` ` ``)
*   **এনালজি:** "শূণ্যস্থান পূরণ" করার মতো। আগে স্ট্রিং জোড়া দিতে `+` চিহ্ন দিয়ে আঠা লাগাতে হতো। এখন ব্যাকটিক (`` ` ``) দিয়ে সহজেই সব বসিয়ে দেওয়া যায়।
*   **Code:**
    ```javascript
    const dish = "Burger";
    // Old: "I want a " + dish + " please."
    // New: `I want a ${dish} please.`  <-- কত ক্লিন!
    ```

#### 4. Destructuring Assignment
*   **এনালজি:** একটা বার্গার থেকে শুধু চিজ আর মাংসটা বের করে নেওয়া। পুরো বার্গার খাওয়ার দরকার নেই। অবজেক্ট বা অ্যারে থেকে স্পেসিফিক জিনিস বের করে আনা।
*   **Code:**
    ```javascript
    const order = { id: 1, food: "Pizza", price: 500 };
    // Destructuring
    const { food, price } = order;
    console.log(food); // Pizza
    ```

#### 5. Default Parameters
*   **এনালজি:** কাস্টমার যদি বলে "জুস দিন", কিন্তু কোন জুস তা না বলে, তবে ওয়েটার ডিফল্ট হিসেবে "অরেঞ্জ জুস" নিয়ে আসবে।
*   **Code:**
    ```javascript
    function serveJuice(type = "Orange") {
        console.log(`Here is your ${type} juice`);
    }
    serveJuice(); // Here is your Orange juice
    ```

#### 6. Rest Operator (`...`)
*   **এনালজি:** "আর বাকি সব"। পিকনিকে যাওয়ার সময় টিফিন বক্সে স্যান্ডউইচ নিলে, আর **বাকি সব** (চিপস, কোক, চকলেট) একটা বড় ব্যাগে (`...bag`) ভরে নিলে।
*   **Code:**
    ```javascript
    function packBag(sandwich, ...snacks) {
        console.log(snacks); // বাকি সব স্ন্যাকস এখানে অ্যারে হিসেবে থাকবে
    }
    ```

#### 7. Modules (Import/Export)
*   **এনালজি:** তোমার কিচেনে চিনি শেষ। তুমি পাশের দোকান (অন্য ফাইল) থেকে চিনি `Import` করে আনলে। আর তোমার বানানো বিরিয়ানি অন্যকে `Export` করলে।
*   **Code:**
    ```javascript
    // file: secretSauce.js
    export const sauce = "Spicy Mayo";

    // file: main.js
    import { sauce } from './secretSauce';
    ```

#### 8. Promises & Async/Await
*   **এনালজি:** রেস্টুরেন্টে অর্ডার দেওয়ার পর ওয়েটার তোমাকে একটা **টোকেন (Promise)** দেয়। তুমি টেবিলে বসে অপেক্ষা করো। যখন খাবার রেডি হয়, তখন টোকেনটা **Resolve** হয় (খাবার পাও)। আর যদি খাবার পুড়ে যায়, তবে **Reject** হয় (সরি বলে)।
*   **Code:**
    ```javascript
    async function getOrder() {
        const food = await waiterBringFood(); // অপেক্ষা করো যতক্ষণ না খাবার আসে
        console.log("Yummy!", food);
    }
    ```

#### 9. Map & Set
*   **Set:** এমন এক ঝুড়ি যেখানে একই ফল দুবার রাখা যাবে না। (Unique items only)।
*   **Map:** এমন এক মেনু কার্ড যেখানে খাবারের নামের সাথে দাম লেখা থাকে (Key-Value pair)।

### 🛡️ **Part 2: TypeScript - The Safety Inspector**
JavaScript হলো একটু বেপরোয়া শেফ, যে লবণের বদলে চিনি দিয়ে দিলেও এরর দেয় না। **TypeScript** হলো কড়া হেড শেফ বা ইন্সপেক্টর, যে রান্না শুরুর আগেই ভুল ধরে দেয়।

#### 1. Static Types (Type Safety)
*   **এনালজি:** মশলার বয়ামে "লেবেল" মারা। 'Sugar' বয়ামে ভুল করে 'Salt' রাখার কোনো সুযোগ নেই।
*   **Code:**
    ```typescript
    let price: number = 100;
    // price = "Hello"; // ❌ Error! টাইপস্ক্রিপ্ট সাথে সাথে লাল দাগ দেবে।
    ```

#### 2. Interfaces
*   **এনালজি:** এটা হলো **"রেসিপি কার্ড"** বা চুক্তিপত্র। একটা পিৎজা হতে হলে তাতে 'Dough' এবং 'Cheese' থাকতেই হবে, নাহলে ওটা পিৎজা না। অবজেক্টের শেপ (Shape) ডিফাইন করা।
*   **Code:**
    ```typescript
    interface Pizza {
        name: string;
        slices: number;
        hasCheese: boolean;
    }

    const myDinner: Pizza = {
        name: "Pepperoni",
        slices: 4,
        hasCheese: true // এটা মিস করলে এরর খাবে!
    };
    ```

#### 3. Enums
*   **এনালজি:** ফিক্সড অপশন। পিৎজার সাইজ যেমন— Small, Medium, Large এর বাইরে কিছু হয় না। ভুল এড়াতে এটা ব্যবহার হয়।
*   **Code:**
    ```typescript
    enum Size { Small, Medium, Large }
    let mySize = Size.Medium;
    ```

#### 4. Classes (with Access Modifiers)
*   **এনালজি:** পুরো রেস্টুরেন্টের ব্লু-প্রিন্ট।
    *   `public`: কাস্টমার বসার জায়গা (সবাই যেতে পারে)।
    *   `private`: ক্যাশ বাক্স (শুধু মালিক এক্সেস করতে পারে)।
    *   `readonly`: রেস্টুরেন্টের সাইনবোর্ড (কেউ মুছতে বা বদলাতে পারবে না)।

#### 5. Decorators (`@`)
*   **এনালজি:** অ্যাঙ্গুলারে এটা খুব দেখবে (যেমন `@Component`, `@Input`)। এটা হলো একটা **"স্টিকার"** যা কোনো সাধারণ ক্লাস বা প্রপার্টির গায়ে লাগালে সেটার ক্ষমতা বেড়ে যায়।
    *   যেমন: সাধারণ একটা ক্লাসের গায়ে `@Component` স্টিকার লাগালে সেটা অ্যাঙ্গুলার কম্পোনেন্ট হয়ে যায়।

#### 6. Union Types (`|`)
*   **এনালজি:** হাইব্রিড গাড়ি। এটা তেলেও চলে, আবার ব্যাটারিতেও চলে। ভেরিয়েবল `string` হতে পারে অথবা `number` ও হতে পারে।
*   **Code:**
    ```typescript
    let id: string | number;
    id = 101;   // OK
    id = "A-1"; // OK
    ```
