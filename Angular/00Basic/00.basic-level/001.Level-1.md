স্বাগতম **Level 1**-এ! 🏗️

লেভেল ০-তে আমরা মশলা (JS/TS) চিনেছি। এখন আমরা **Angular 21** দিয়ে আমাদের স্বপ্নের **"স্মার্ট রেস্টুরেন্ট" (App)** তৈরি শুরু করব।

ভুলে যাও পুরনো জটিলতা (Modules, hefty configs)। Angular 21 এখন অনেক স্লিম এবং স্মার্ট। চলো ভিত্তিপ্রস্তর স্থাপন করি!

### 🏭 **Part 1: The Construction Tools (Setup)**

রান্নাঘর বানাতে হলে আগে জমি আর যন্ত্রপাতি লাগবে।

#### 1. Node.js & NPM
*   **এনালজি:**
    *   **Node.js:** এটা হলো রেস্টুরেন্টের **"গ্যাস এবং ইলেকট্রিসিটি লাইন"**। এটা ছাড়া কিচেন চলবে না।
    *   **NPM (Node Package Manager):** এটা হলো **"সাপ্লাই চেইন বা গোডাউন"**। তোমার কিচেনে যা যা টুলস লাগবে (যেমন অ্যাঙ্গুলার নিজেই), সব এখান থেকে অর্ডার দিয়ে আনা হয়।

#### 2. Angular CLI (Command Line Interface)
*   **এনালজি:** এটা তোমার **"রোবট মিস্ত্রি"** 🤖। তুমি শুধু হুকুম দেবে, সে সব বানিয়ে দেবে।
*   **কমান্ড:**
    *   `npm install -g @angular/cli` -> রোবটকে ভাড়া করা হলো।
    *   `ng new my-smart-kitchen` -> রোবটকে বলা হলো, "একটা নতুন রেস্টুরেন্ট বানিয়ে দাও।"

### 🏠 **Part 2: The Structure (Standalone Components)**

Angular 21-এ আমরা **"Standalone"** আর্কিটেকচার ব্যবহার করি।

#### 1. What is a Component?
*   **সহজ কথা:** অ্যাঙ্গুলার অ্যাপ হলো অনেকগুলো **LEGO** ব্লকের সমষ্টি। প্রতিটি ব্লক হলো এক একটি কম্পোনেন্ট।
*   **এনালজি:** রেস্টুরেন্টের একেকটা সেকশন।
    *   `HeaderComponent`: সাইনবোর্ড।
    *   `SidebarComponent`: মেনু কার্ড।
    *   `FooterComponent`: ঠিকানা লেখা নিচের অংশ।

#### 2. Anatomy of a Component
একটা কম্পোনেন্টের ৩টি পার্ট থাকে (থ্রি-ইন-ওয়ান কফি মিক্সের মতো):
1.  **HTML (Template):** চেহারাসুরত (কাস্টমার যা দেখে)।
2.  **CSS (Styles):** সাজসজ্জা (রং, ডিজাইন)।
3.  **TypeScript (Class):** ব্রেন বা লজিক (কিভাবে কাজ করবে)।

#### 3. Standalone Component (The Modern Hero)
আগে কম্পোনেন্টদের একটা বড় গ্রুপে (NgModule) রেজিস্ট্রি করতে হতো। এখন আর লাগে না।
*   **এনালজি:** আগে শেফদের একটা ইউনিয়নের সদস্য হতে হতো কাজ করার জন্য। এখন **Standalone** মানে হলো "ফ্রিল্যান্সার শেফ"। সে একাই সব পারে, কারো পারমিশন লাগে না।

**Code Example:**
```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-root', // কাস্টম HTML ট্যাগ নাম
  standalone: true,     // 🔥 জাদু এখানে! আমি স্বাধীন!
  imports: [],          // আমার যা সাহায্য লাগবে এখানে ইম্পোর্ট করব
  template: `<h1>স্বাগতম আমাদের কিচেনে!</h1>`,
  styleUrl: './app.component.css'
})
export class AppComponent {
  title = 'My Smart Kitchen';
}
```

#### 4. Bootstrapping
*   **এনালজি:** রেস্টুরেন্টের **মেইন সুইচ অন করা**। `main.ts` ফাইলটি অ্যাপকে জাগিয়ে তোলে।

### 📡 **Part 3: Signals (The Building Blocks of State)**

Angular 21-এর সবচেয়ে বড় চমক হলো **Signals**। এটা ডেটা ম্যানেজ করার নতুন এবং সুপার ফাস্ট উপায়।

#### 1. What is a Signal?
*   **এনালজি:** সাধারণ ভেরিয়েবল হলো **"চকবোর্ডে লেখা মেনু"**। দাম বাড়লে মুছে আবার লিখতে হয়।
    **Signal** হলো **"ডিজিটাল ডিসপ্লে বোর্ড"** 📟। কিচেন থেকে দাম বদলানোর সাথে সাথে ডিসপ্লেতে অটোমেটিক আপডেট হয়ে যায়, কাউকে গিয়ে বলতে হয় না।
*   **সহজ কথা:** এটা এমন একটা ভেরিয়েবল যা ভ্যালু বদলালে সবাইকে নোটিফিকেশন পাঠায়।

#### 2. Creating & Reading Signals
সিগনাল ব্যবহার করতে হলে `()` ব্র্যাকেট দিয়ে ডাকতে হয়।

*   **Code:**
    ```typescript
    import { signal } from '@angular/core';

    export class KitchenComponent {
      // ১. সিগনাল তৈরি (Create)
      burgerCount = signal(0); // শুরুতে ০ টা বার্গার

      constructor() {
        // ২. সিগনাল পড়া (Read) - ব্র্যাকেট দিতেই হবে!
        console.log("Total Burgers: " + this.burgerCount());
      }
    }
    ```

#### 3. Writing (Updating) Signals
সিগনালের ভ্যালু বদলানোর নিয়ম আছে।
*   **এনালজি:** ডিজিটাল বোর্ডে রিমোট দিয়ে সংখ্যা বাড়ানো।

*   **Code:**
    ```typescript
    // ডাইরেক্ট ভ্যালু সেট করা
    this.burgerCount.set(5); 

    // আগের ভ্যালুর সাথে যোগ-বিয়োগ করা (Update)
    this.burgerCount.update(oldValue => oldValue + 1);
    ```

#### 4. Computed Signals (Magic!) 🪄
*   **এনালজি:** ধরো, ১টা বার্গারের দাম ১০০ টাকা। তুমি শুধু বার্গারের সংখ্যা (Quantity) বাড়াবে, মোট দাম (Total Price) অটোমেটিক ক্যালকুলেট হয়ে যাবে। তোমাকে গুণ করতে হবে না।
*   **Code:**
    ```typescript
    import { signal, computed } from '@angular/core';

    quantity = signal(2);
    pricePerItem = 100;

    // Computed Signal: এটা quantity() বদলালে নিজে নিজেই বদলে যাবে
    totalPrice = computed(() => this.quantity() * this.pricePerItem);

    // quantity ২ হলে, totalPrice অটোমেটিক ২০০ হবে।
    ```

### 🛠️ **Level 1 অ্যাকশন প্ল্যান (Hands-on):**

এখন শুধু থিওরি না, হাত নোংরা (কোড) করতে হবে!

1.  **Create App:** টার্মিনালে লেখো: `ng new learning-angular`।
2.  **Run App:** ফোল্ডারে ঢুকে লেখো: `ng serve`। ব্রাউজারে `http://localhost:4200` এ যাও।
3.  **Make a Counter:**
    *   `app.component.ts` ফাইলে যাও।
    *   একটা `count` সিগনাল বানাও: `count = signal(0)`।
    *   একটা মেথড বানাও `increment()` যা `count.update(v => v + 1)` করবে।
4.  **Display:** টেমপ্লেটে (HTML) দেখাও: `<h1>Count: {{ count() }}</h1>` (Level 2 তে এটা আমরা বিস্তারিত দেখব, আপাতত জাস্ট কপি করো)।
