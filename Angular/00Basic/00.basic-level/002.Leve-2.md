স্বাগতম **Level 2**-তে! 🎨

লেভেল ১-এ আমরা কিচেন সেটআপ করেছি (Component & Signals)। কিন্তু কাস্টমার (User) তো আর কিচেনের ভেতরে ঢুকে হাঁড়িপাতিল দেখবে না। তাদের জন্য সুন্দর করে **ডাইনিং এরিয়া** সাজাতে হবে।

Angular-এ এই ডাইনিং এরিয়া বা কাস্টমার যা দেখে, তাকেই বলে **Template (HTML)**। আর এই টেমপ্লেটকে ডাইনামিক করার জাদুর কাঠিগুলো হলো **Directives & Binding**।

চলো আমাদের স্মার্ট রেস্টুরেন্ট সাজাই! 🍽️

### 📺 **Part 1: Interpolation `{{ }}` (Show me the data)**
শেফ (TypeScript) যা রান্না করবে, তা কাস্টমারকে (HTML) দেখানোর উপায়।

*   **এনালজি:** ডিজিটাল মেনু বোর্ড। কিচেন থেকে ম্যানেজারের কম্পিউটারে নাম বা দাম পাল্টালে, দেয়ালে ঝোলানো স্ক্রিনে তা ভেসে ওঠে।
*   **সিনট্যাক্স:** ডাবল কার্লি ব্রেস বা "গোঁফ" `{{ }}`।
*   **Code:**
    ```typescript
    // kitchen.component.ts
    restaurantName = "Angular Eats";
    price = signal(150);
    ```
    ```html
    <!-- kitchen.component.html -->
    <h1> স্বাগতম {{ restaurantName }} এ! </h1>
    <p> বার্গারের দাম: {{ price() }} টাকা </p>
    ```
    *(নোট: সিগনাল হলে `()` দিতে ভুলবে না!)*

### 🎮 **Part 2: Binding (Remote Control)**
HTML এর সাথে TypeScript এর যোগাযোগ করানোর উপায়। এটা দুই ধরণের হয়:

#### ১. Property Binding `[ ]` (Control the Element)
*   **এনালজি:** টিভির রিমোট।
    *   তুমি রিমোট দিয়ে ভলিউম বা চ্যানেল কন্ট্রোল করছো।
    *   এখানে `HTML Element` হলো টিভি, আর `[property]` হলো রিসিভার। তুমি কোড দিয়ে বলছো বাটনটা এখন কাজ করবে কি করবে না।
*   **মনে রাখার উপায়:** `[]` স্কয়ার ব্র্যাকেট দেখতে বাক্সের মতো। ভ্যালুটা বাক্সের ভেতর ঢুকছে।
*   **Code:**
    ```html
    <!-- isClosed একটা সিগনাল বা ভেরিয়েবল যা true/false দেয় -->
    <button [disabled]="isClosed()"> অর্ডার করুন </button>
    ```
    *(যদি `isClosed` সত্য হয়, বাটনটা ধূসর/অকেজো হয়ে যাবে)*

#### ২. Event Binding `( )` (React to User)
*   **এনালজি:** কলিং বেল বা ওয়েটার। 🔔
    *   কাস্টমার যখন বাটনে চাপ দেয় (Click), কিচেনে একটা ঘণ্টা বাজে এবং শেফ কাজ শুরু করে।
*   **মনে রাখার উপায়:** `()` প্যারেন্থেসিস দেখতে কানের মতো 👂। বাটনটি "শুনছে" ইউজার কখন ক্লিক করবে।
*   **Code:**
    ```html
    <button (click)="placeOrder()"> অর্ডার দিন </button>
    ```
    *(ক্লিক করলেই `placeOrder` ফাংশন কল হবে)*

### 🚦 **Part 3: Control Flow (The Manager's Rules)**
আগে অ্যাঙ্গুলারে `*ngIf` বা `*ngFor` লাগত। Angular 21 এ (v17 থেকে শুরু) একদম জাভাস্ক্রিপ্টের মতোই সহজ সিনট্যাক্স এসেছে। একে বলে **Built-in Control Flow**।

#### ১. @if, @else (শর্ত প্রযোজ্য)
*   **এনালজি:** রেস্টুরেন্টের গেট।
    *   **যদি (@if)** দোকান খোলা থাকে, গেট খোলো।
    *   **নাহলে (@else)** "বন্ধ" সাইনবোর্ড দেখাও।
*   **Code:**
    ```html
    @if (isOpen()) {
       <div> আসুন বসুন! কি খাবেন? </div>
    } @else {
       <div> দুঃখিত, আমরা এখন ঘুমাচ্ছি। 😴 </div>
    }
    ```

#### ২. @for (লুপ বা পুনরাবৃত্তি)
*   **এনালজি:** বুফে টেবিল।
    *   তোমার কাছে ১০ পদের খাবারের লিস্ট আছে। তুমি এক এক করে সব টেবিলের ওপর সাজাবে।
    *   `track` হলো টোকেন নাম্বার, যাতে অ্যাঙ্গুলার গুলিয়ে না ফেলে কোন প্লেটটা কার।
*   **Code:**
    ```typescript
    menuItems = [
      { id: 1, name: 'Burger', price: 150 },
      { id: 2, name: 'Pizza', price: 500 },
      { id: 3, name: 'Coke', price: 30 }
    ];
    ```
    ```html
    <ul>
      @for (item of menuItems; track item.id) {
        <li> {{ item.name }} - {{ item.price }} টাকা </li>
      }
    </ul>
    ```

### 💅 **Part 4: Pipes `|` (The Garnish/Filter)**
ডেটা যেমন আছে, ঠিক তেমন না দেখিয়ে একটু মেকআপ করে দেখানো।

*   **এনালজি:** ইনস্টাগ্রাম ফিল্টার বা খাবারের গার্নিশ। 🥗
    *   আলুর চপ একই আছে, কিন্তু তার ওপর সস আর শসা দিয়ে সুন্দর করে সাজানো হলো।
    *   কোডে ডেটা ঠিক থাকে, শুধু দেখার সময় চেঞ্জ হয়।
*   **Code:**
    ```html
    <!-- ডেট দেখতে বিদঘুটে লাগে, তাই পাইপ দিয়ে সুন্দর করলাম -->
    <p> আজকের তারিখ: {{ today | date:'medium' }} </p>

    <!-- টাকাকে কারেন্সি স্টাইলে দেখানো -->
    <p> দাম: {{ price() | currency:'BDT' }} </p>
    ```
*   **গুরুত্বপূর্ণ:** Standalone কম্পোনেন্টে পাইপ ব্যবহার করতে হলে `imports` অ্যারেতে তাদের নাম দিতে হয় (যেমন `DatePipe`, `CurrencyPipe`) অথবা পুরো `CommonModule` ইম্পোর্ট করতে হয়।

### 🛠️ **Level 2 অ্যাকশন প্ল্যান (Hands-on):**

এখন আমরা আমাদের অ্যাপটাকে ইন্টারেক্টিভ করব।

1.  **Open Code:** তোমার আগের প্রজেক্টের `app.component.ts` এ যাও।
2.  **Add Logic (TS):**
    *   `imports: [CommonModule]` যোগ করো (উপরে `import` করতে ভুলবে না)।
    *   একটা মেনু লিস্ট বানাও (Array of objects)।
    *   একটা `cartCount` সিগনাল বানাও।
    *   `addToCart()` মেথড বানাও যা `cartCount` বাড়াবে।
3.  **Update Template (HTML):**
    *   `@for` লুপ ব্যবহার করে মেনু দেখাও।
    *   প্রতিটি আইটেমের পাশে একটা `<button (click)="addToCart()">Add</button>` দাও।
    *   উপরে দেখাও: `Total Items: {{ cartCount() }}`.
    *   `@if` দিয়ে একটা মেসেজ দেখাও: যদি cartCount > 0 হয়, তবে দেখাবে "অর্ডার কনফার্ম করুন", নাহলে দেখাবে "কার্ট খালি"।
