স্বাগতম **Level 3**-তে! 👨‍🍳

লেভেল ১ ও ২-এ আমরা কম্পোনেন্ট বানিয়েছি এবং সেটাকে সাজিয়েছি। কিন্তু সমস্যা হলো, সব রান্নার কাজ (Logic) যদি ওয়েটার (Component) নিজেই করে, তবে সে কাস্টমার সামলাবে কখন?

একটা প্রফেশনাল রেস্টুরেন্টে ওয়েটার শুধু খাবার সার্ভ করে, আর রান্নার কাজ করে **হেড শেফ (Service)**।
আজ আমরা শিখব কিভাবে কাজ ভাগ করে দিতে হয় এবং একজন আরেকজনের সাথে যোগাযোগ করে।

---

### 🧠 **Part 1: Services (The Head Chef)**
কম্পোনেন্ট হলো শুধু **"ভিউ" (যা দেখা যায়)**। কিন্তু আসল ডেটা, ক্যালকুলেশন বা লজিক যেখানে থাকে, তাকে বলে **Service**।

*   **এনালজি:**
    *   **Component:** ওয়েটার। সে সেজেগুজে দাঁড়িয়ে থাকে, অর্ডার নেয় আর খাবার দেয়।
    *   **Service:** হেড শেফ। সে কিচেনের ভেতরে থাকে, স্টক চেক করে, রান্না করে। ওয়েটার তার কাছে চাইলেই সে খাবার রেডি করে দেয়।
*   **কেন দরকার?**
    *   একই লজিক (যেমন: ভ্যাট ক্যালকুলেশন) অনেকগুলো কম্পোনেন্টে লাগতে পারে। বারবার কোড না লিখে এক জায়গায় (Service-এ) লেখা ভালো।

*   **Code:**
    টার্মিনালে লেখো: `ng generate service food`
    ```typescript
    import { Injectable, signal } from '@angular/core';

    // @Injectable মানে এই শেফকে যেকোনো কম্পোনেন্ট ডাক দিলেই পাবে
    @Injectable({
      providedIn: 'root' // 'root' মানে পুরো রেস্টুরেন্টে এই শেফ একজনই (Singleton)
    })
    export class FoodService {
      // ডেটা বা সিগনাল এখানে থাকবে
      private burgerStock = signal(10);

      getStock() {
        return this.burgerStock;
      }

      sellBurger() {
        this.burgerStock.update(n => n - 1);
      }
    }
    ```

### 💉 **Part 2: Dependency Injection (DI) - (Magic Supply)**
তুমি সার্ভিস বানালে, কিন্তু কম্পোনেন্ট সেটা ব্যবহার করবে কিভাবে? `new FoodService()` লিখে? **না!** অ্যাঙ্গুলারে আমরা নিজেরা অবজেক্ট বানাই না। আমরা অ্যাঙ্গুলারের কাছে **চাই (Inject)**।

*   **এনালজি:**
    *   তুমি যখন কফি চাও, তুমি কি কফি মেশিন বানাতে বসো? না! তুমি শুধু মেশিনকে বলো "কফি দাও"।
    *   **Dependency Injection (DI)** হলো সেই সিস্টেম যা অটোমেটিক্যালি তোমার কম্পোনেন্টে সার্ভিস পৌঁছে দেয়।

*   **Modern Way (using `inject` function):**
    Angular 21 এ কনস্ট্রাক্টর এর বদলে `inject()` ফাংশন বেশি জনপ্রিয়।

    ```typescript
    import { Component, inject } from '@angular/core';
    import { FoodService } from './food.service';

    @Component({ ... })
    export class KitchenComponent {
      // শেফকে ডেকে নিলাম (DI)
      private foodService = inject(FoodService);

      // সার্ভিসের সিগনাল ব্যবহার করছি
      stock = this.foodService.getStock();

      sell() {
        this.foodService.sellBurger(); // শেফকে বললাম একটা বার্গার কমাতে
      }
    }
    ```

### 🗣️ **Part 3: Component Communication (Parent vs Child)**
সব কাজ এক কম্পোনেন্টে না করে আমরা ছোট ছোট কম্পোনেন্টে ভাগ করি।
যেমন: `App` (Parent) -> `Card` (Child)। এদের মধ্যে কথা বলার উপায় হলো **Inputs** এবং **Outputs**।

#### ১. Signal Inputs (Parent to Child ⬇️)
বাবা (Parent) সন্তানকে (Child) কিছু দিলে সেটা **Input**।
*   **এনালজি:** ম্যানেজার (Parent) বাবুর্চিকে (Child) **অর্ডারের স্লিপ** ধরিয়ে দিল। বাবুর্চি স্লিপ দেখে রান্না করবে।
*   **Code (Child Component - `CardComponent`):**
    ```typescript
    import { Component, input } from '@angular/core';

    @Component({
      selector: 'app-card',
      template: `<div>Item: {{ itemName() }}</div>`
    })
    export class CardComponent {
      // আগে ছিল @Input(), এখন মডার্ন input() সিগনাল
      itemName = input.required<string>(); // এটা দিতেই হবে (Required)
    }
    ```
*   **Code (Parent Template):**
    ```html
    <!-- Parent ডেটা পাঠিয়ে দিচ্ছে -->
    <app-card [itemName]=" 'Spicy Burger' "></app-card>
    ```

#### ২. Outputs (Child to Parent ⬆️)
সন্তান (Child) বাবাকে (Parent) কিছু জানালে সেটা **Output**।
*   **এনালজি:** রান্না শেষ হলে বাবুর্চি (Child) **ঘণ্টা (Bell)** বাজায় 🛎️। ম্যানেজার (Parent) সেই শব্দ শুনে খাবার নিয়ে যায়।
*   **Code (Child Component):**
    ```typescript
    import { Component, output } from '@angular/core';

    @Component({ ... })
    export class CardComponent {
      // ইভেন্ট বা ঘণ্টা তৈরি করা
      onAdd = output<string>();

      addToCart() {
        // ঘণ্টা বাজানো হলো (Emit)
        this.onAdd.emit("Burger added!"); 
      }
    }
    ```
*   **Code (Parent Template):**
    ```html
    <!-- Parent ইভেন্ট শুনছে (Listen) -->
    <app-card (onAdd)="handleAddition($event)"></app-card>
    ```

### 🛠️ **Level 3 অ্যাকশন প্ল্যান (Hands-on):**

আজকের কাজটা একটু সিরিয়াস, কিন্তু করলে অনেক কনফিডেন্স পাবে।

1.  **Service:**
    *   `CartService` নামে একটা সার্ভিস বানাও (`ng g s cart`)।
    *   ভেতরে একটা সিগনাল রাখো: `items = signal([])`।
    *   একটা মেথড বানাও `addItem(item: string)`।

2.  **Child Component:**
    *   `ProductComponent` নামে একটা কম্পোনেন্ট বানাও (`ng g c product`)।
    *   এতে একটা `input()` নাও পণ্যের নামের জন্য।
    *   একটা বাটন রাখো "Buy Now"। বাটনে ক্লিক করলে `output()` দিয়ে প্যারেন্টকে জানাও।

3.  **Parent Component (App):**
    *   `CartService` কে `inject` করো।
    *   `ProductComponent` কে কল করো এবং পণ্যের নাম পাঠাও (`[productName]=" 'Laptop' "`)।
    *   `output` রিসিভ করো এবং সার্ভিসের `addItem` কল করো।
    *   স্ক্রিনে দেখাও: `Total Cart Items: {{ cartService.items().length }}`.
