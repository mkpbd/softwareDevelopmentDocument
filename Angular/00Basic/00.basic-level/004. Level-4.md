
স্বাগতম **Level 4**-এ! 🛵

লেভেল ৩ পর্যন্ত আমাদের রেস্টুরেন্ট (App) খুব ভালোই চলছে, কিন্তু সব খাবার (Data) আমরা কিচেনের ভেতরেই (Code-এ) হার্ডকোড করে রেখেছিলাম।
বাস্তব জীবনে কিচেনে তো আলু-পেঁয়াজ জন্মায় না, বাজার থেকে কিনে আনতে হয়।
অ্যাঙ্গুলার অ্যাপেও ডেটা আসে বাইরের **সার্ভার বা API** (Backend) থেকে।

আজ আমরা শিখব কিভাবে বাইরের জগত থেকে ডেটা আমদানি করতে হয়।

---

### 📦 **Part 1: HttpClient (The Delivery Service)**
অ্যাঙ্গুলারের নিজস্ব একটা রাইডার বা কুরিয়ার সার্ভিস আছে, যার নাম `HttpClient`।

*   **এনালজি:** **Foodpanda/UberEats রাইডার।**
    *   তুমি কিচেন থেকে ফোন করলে (Request): "ভাই, ১০ কেজি আলু লাগবে।"
    *   রাইডার বাজারে (Server) গেল।
    *   আলু নিয়ে ফিরে এল (Response)।
*   **Method Types:**
    *   `GET`: বাজার থেকে কিছু আনা (Fetch data)।
    *   `POST`: কাস্টমারের অর্ডার সার্ভারে পাঠানো (Send data)।
    *   `PUT/DELETE`: ডেটা আপডেট বা ডিলিট করা।

#### ⚙️ **Setup (Contract Signing)**
রাইডারকে কিচেনে ঢোকার পারমিশন দিতে হবে। Angular 21-এ (Standalone App) এটা `app.config.ts` ফাইলে করতে হয়।

*   **Code (`app.config.ts`):**
    ```typescript
    import { provideHttpClient } from '@angular/common/http';

    export const appConfig: ApplicationConfig = {
      providers: [
        provideRouter(routes),
        provideHttpClient() // 👈 এই পারমিশনটা দিতে হবে
      ]
    };
    ```

### 🌊 **Part 2: RxJS & Observables (The Pipe)**
এখানেই অনেকে ভয় পায়! `HttpClient` ডেটা সরাসরি দেয় না, সে দেয় একটা **Observable**।

*   **এনালজি:**
    *   **Promise:** পিৎজা ডেলিভারি। একবার বক্স হাতে পেলেন, কাজ শেষ।
    *   **Observable (RxJS):** পানির পাইপ। 🚰 ট্যাপ খুললে পানি (ডেটা) আসতেই থাকে। ইন্টারনেটের স্পিড অনুযায়ী ডেটা একটু একটু করে আসতে পারে।
    *   **Subscribe:** বালতি পাতা। পাইপের নিচে বালতি না পাতলে পানি পড়ে নষ্ট হবে। কোডে `.subscribe()` না করলে `HttpClient` কলই হবে না।

কিন্তু... Angular 21 এ আমরা এই "পাইপ" নিয়ে সরাসরি কাজ না করে এটাকে **সিগনাল (Signal)** এ কনভার্ট করে ফেলি। কেন? কারণ সিগনাল হ্যান্ডেল করা পানির বালতির মতোই সহজ!

---

### 🌉 **Part 3: RxJS to Signals (The Smart Bridge)**
আমরা `RxJS` এর জটিলতা এড়াতে `toSignal` ব্যবহার করব। এটা পাইপ থেকে আসা ডেটাকে ধরে একটা সিগনালে রেখে দেয়।

*   **এনালজি:** পাইপের (Observable) নিচে একটা অটোমেটিক রিজার্ভ ট্যাংকি (Signal) লাগিয়ে দেওয়া। ট্যাপ দিয়ে পানি (ডেটা) আসলে ট্যাংকি ভরে যাবে, আর তুমি ট্যাংকি থেকে আরামসে ব্যবহার করবে।

#### **Code Example (Real World Pattern):**

**Step 1: The Service (রাইডারকে অর্ডার দেওয়া)**
```typescript
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';

interface User {
  id: number;
  name: string;
  email: string;
}

@Injectable({ providedIn: 'root' })
export class UserService {
  private http = inject(HttpClient); // রাইডার ইনজেক্ট করলাম

  getUsers() {
    // API থেকে ডেটা আনার পাইপ রেডি করলাম
    return this.http.get<User[]>('https://jsonplaceholder.typicode.com/users');
  }
}
```

**Step 2: The Component (পাইপকে সিগনালে রূপান্তর)**
```typescript
import { Component, inject } from '@angular/core';
import { toSignal } from '@angular/core/rxjs-interop'; // 🔥 জাদুর কাঠি
import { UserService } from './user.service';

@Component({
  selector: 'app-users',
  template: `
    <h2>কাস্টমার লিস্ট (Server Data)</h2>
    
    @if (users()) {
      <ul>
        @for (user of users(); track user.id) {
          <li>{{ user.name }} - {{ user.email }}</li>
        }
      </ul>
    } @else {
      <p>লোডিং হচ্ছে... ⏳</p>
    }
  `
})
export class UserComponent {
  private userService = inject(UserService);

  // Observable কে Signal এ কনভার্ট করলাম
  // initialValue দিয়েছি যাতে ডেটা আসার আগে অ্যাপ ক্রাশ না করে (খালি অ্যারে)
  users = toSignal(this.userService.getUsers(), { initialValue: [] });
}
```

---

### 🧠 **কেন এই পদ্ধতি সেরা?**
1.  **No Subscribe/Unsubscribe:** আগে ম্যানুয়ালি `subscribe` করতে হতো এবং কাজ শেষে `unsubscribe` করতে হতো (মেমোরি লিক এড়াতে)। `toSignal` এটা অটোমেটিক করে।
2.  **Declarative:** কোড দেখে মনে হয়— "এই ভেরিয়েবলটা ওই API এর ডেটা", ব্যাস। কোনো জটিল লজিক নেই।

আজ আমরা ইন্টারনেটের সাথে কানেক্ট হব! 🌐

1.  **Config:** `app.config.ts` ফাইলে `provideHttpClient()` যোগ করো।
2.  **Service:** `UserService` নামে একটা সার্ভিস বানাও।

    *   `getUsers()` মেথড বানাও।
3.  **Component:**
    *   `toSignal` ইম্পোর্ট করো।
    *   সার্ভিস থেকে ডেটা এনে সিগনালে রাখো।
    *   HTML এ `@for` লুপ চালিয়ে নামগুলো প্রিন্ট করো।
    *   **বোনাস:** `@if` ব্যবহার করে একটা লোডিং টেক্সট দেখাও যতক্ষণ না ডেটা আসে (initialValue `null` বা `[]` দিয়ে চেক করতে পারো)।
