### 🛣️ **Part 1: The Router (The Map & Signboards)**

অ্যাঙ্গুলারে এক পেজ থেকে অন্য পেজে যাওয়ার জন্য পেজ রিফ্রেশ হয় না (Single Page Application)। শুধু কন্টেন্ট বদলে যায়।

*   **এনালজি:**
    *   **URL (`/menu`, `/contact`):** রুম নাম্বার বা সাইনবোর্ড।
    *   **Router Outlet:** একটা জাদুর ফ্রেম বা স্টেজ 🖼️। ফ্রেম একটাই থাকে, কিন্তু ইউজার যখন `/menu` তে যায়, ফ্রেমে মেনু ভেসে ওঠে। যখন `/contact` এ যায়, তখন কন্টাক্ট ফর্ম ভেসে ওঠে।
    *   **Router Link:** দরজার হাতল বা বাটন। ক্লিক করলেই সিন চেঞ্জ।

#### **Setup Routes (`app.routes.ts`)**
অ্যাঙ্গুলার প্রজেক্ট তৈরির সময় `routes` ফাইল অটোমেটিক তৈরি হয়।

```typescript
import { Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { AboutComponent } from './about/about.component';

export class routes: Routes = [
    // ডিফল্ট রাউট (কেউ কিছু না লিখলে Home এ যাবে)
    { path: '', redirectTo: 'home', pathMatch: 'full' },
    
    // রুমের নাম এবং কোন কম্পোনেন্ট দেখাবে
    { path: 'home', component: HomeComponent },
    { path: 'about', component: AboutComponent },
];
```

#### **Display (`app.component.html`)**
```html
<nav>
  <!-- সাধারণ href ব্যবহার করবে না, routerLink ব্যবহার করবে -->
  <a routerLink="/home">🏠 Home</a> | 
  <a routerLink="/about">ℹ️ About</a>
</nav>

<!-- এই জাদুর ফ্রেমে কম্পোনেন্ট লোড হবে -->
<router-outlet></router-outlet>
```

### 🚀 **Part 2: Lazy Loading (The Smart Electricity)**
তোমার রেস্টুরেন্টে একটা বিশাল "পার্টি হল" আছে, যা মাসে একবার ভাড়া হয়। এখন ওই হলের এসি কি সবসময় চালিয়ে রাখবে? না! যখন গেস্ট আসবে, তখনই এসি চালাবে।

কোডিং-এ এটাকে বলে **Lazy Loading**। সব কোড শুরুতে লোড না করে, ইউজার যখন ওই পেজে যাবে, তখনই শুধু ওই কোডটুকু ডাউনলোড হবে। এতে অ্যাপ সুপার ফাস্ট হয়।

*   **Code Change:**
    ```typescript
    { 
      path: 'party-hall', 
      // component: PartyHallComponent <-- এটা Bad Practice (সব লোড করে ফেলে)
      
      // ✅ Good Practice (Lazy Load)
      loadComponent: () => import('./party-hall/party-hall.component').then(m => m.PartyHallComponent)
    }
    ```

### 📝 **Part 3: Forms (The Order Slip)**
কাস্টমারের কাছ থেকে ডেটা নেওয়ার উপায়। অ্যাঙ্গুলারে দুই ধরণের ফর্ম আছে, কিন্তু আমরা শিখব **Reactive Forms** (কারণ এটাই প্রফেশনাল এবং স্মার্ট)।

*   **এনালজি:** একটা স্মার্ট ডিজিটাল ফর্ম।
    *   তুমি নাম না লিখলে বক্স লাল হয়ে যাবে।
    *   ইমেইল ভুল লিখলে সাথে সাথে ওয়ার্নিং দেবে।
    *   **FormControl:** ফর্মের এক একটা ইনপুট ফিল্ড (যেমন: নাম, বয়স)।
    *   **FormGroup:** পুরো ফর্মটা (সব ফিল্ডের সমষ্টি)।

#### **Step 1: Setup Logic (TS)**
কম্পোনেন্টে `ReactiveFormsModule` ইম্পোর্ট করতে হবে।

```typescript
import { Component, inject } from '@angular/core';
import { ReactiveFormsModule, FormBuilder, Validators } from '@angular/forms';

@Component({
  standalone: true,
  imports: [ReactiveFormsModule], // 👈 এটা মাস্ট!
  templateUrl: './contact.component.html'
})
export class ContactComponent {
  private fb = inject(FormBuilder); // ফর্ম বানানোর মিস্ত্রি

  // ফর্মের ছাঁচ তৈরি
  contactForm = this.fb.group({
    name: ['', Validators.required], // নাম খালি রাখা যাবে না
    email: ['', [Validators.required, Validators.email]], // ইমেইল হতে হবে
    message: [''] // এটা অপশনাল
  });

  sendMessage() {
    if (this.contactForm.valid) {
      console.log("Customer Says:", this.contactForm.value);
    } else {
      console.log("ফর্ম ঠিকমতো পূরণ করুন!");
    }
  }
}
```

#### **Step 2: The Template (HTML)**
টিভি রিমোটের মতো কোডের ফর্মের সাথে HTML এর কানেকশন করতে হবে।

```html
<form [formGroup]="contactForm" (ngSubmit)="sendMessage()">
  
  <!-- নামের ইনপুট -->
  <label>Name:</label>
  <input type="text" formControlName="name">
  
  <!-- ভ্যালিডেশন মেসেজ -->
  @if (contactForm.get('name')?.invalid && contactForm.get('name')?.touched) {
    <span style="color: red;">নাম লিখুন ভাই! 😡</span>
  }

  <!-- ইমেইল ইনপুট -->
  <label>Email:</label>
  <input type="email" formControlName="email">

  <button type="submit" [disabled]="contactForm.invalid">Send</button>

</form>
```

### 🛠️ **Level 5 অ্যাকশন প্ল্যান (Hands-on):**

চলো অ্যাপটাকে মাল্টি-পেজ বানাই।

1.  **Create Components:** দুটি কম্পোনেন্ট বানাও: `Home` এবং `Login` (`ng g c home`, `ng g c login`)।
2.  **Setup Router:** `app.routes.ts` ফাইলে পাথ সেট করো (`path: 'login', component: LoginComponent`...)।
3.  **Navigation:** `app.component.html` এ `router-outlet` এবং মেনু বার (`routerLink`) বসাও।
4.  **Create Form:**
    *   `LoginComponent` এ একটা ফর্ম বানাও।
    *   ফিল্ড: `username` এবং `password`।
    *   শর্ত: দুটোই `Validators.required`।
    *   বাটন: ফর্ম ভ্যালিড না হলে বাটন `disabled` থাকবে।
