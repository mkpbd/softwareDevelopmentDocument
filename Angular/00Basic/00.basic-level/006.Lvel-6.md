### 📦 **Part 1: Deferrable Views (`@defer`)**
অ্যাপের যেসব অংশ ভারী (Heavy), সেগুলো শুরুতেই লোড না করে, যখন দরকার তখন লোড করা।

*   **এনালজি:** বিয়েবাড়ির গেটে সব খাবার নিয়ে দাঁড়িয়ে থাকার দরকার নেই। মেহমান যখন টেবিলে বসবে (Viewport-এ আসবে), তখনই শুধু খাবার (Component) সার্ভ করো। এতে লোড কমবে।
*   **Keywords:**
    *   `@defer`: পরে লোড করো।
    *   `@placeholder`: লোড হওয়ার আগে কী দেখাবে (যেমন: খালি প্লেট)।
    *   `@loading`: লোড চলাকালীন কী দেখাবে (যেমন: ওয়েটার আসছে...)।
    *   `on viewport`: যখন স্ক্রিনে দেখা যাবে, তখন লোড শুরু হবে।

#### **Code Example:**
```html
<!-- ইউজার স্ক্রল করে নিচে নামলে তবেই HeavyComponent লোড হবে -->
@defer (on viewport) {
  <app-heavy-chart></app-heavy-chart>
} 
@loading (minimum 1s) {
  <p>Loading Chart... ⏳</p>
} 
@placeholder {
  <p>Chart will appear here 📉</p>
}
@error {
  <p>Failed to load chart ❌</p>
}
```

### 🔗 **Part 2: Linked Signals (`linkedSignal`)**
Angular 21-এর নতুন ফিচার (Experimental/New)। যখন একটা সিগনাল বদলালে অন্য একটা সিগনালকে **Reset** বা **Update** করতে হয়, কিন্তু ইউজার চাইলে সেটা ম্যানুয়ালি চেঞ্জও করতে পারে।

*   **এনালজি:** "ডিফল্ট সাইড ডিশ"।
    *   তুমি যদি "Burger" অর্ডার করো, সাথে ডিফল্ট "Coke" সিলেক্ট হয়ে যাবে।
    *   তুমি যদি "Pizza" অর্ডার করো, সাথে ডিফল্ট "Pepsi" হয়ে যাবে।
    *   কিন্তু কাস্টমার চাইলে পেপসি পাল্টে পানিও নিতে পারে (Writable)। `computed` সিগনাল হলে কাস্টমার পাল্টাতে পারতো না, কিন্তু `linkedSignal` এ পারে।

#### **Code Example:**
```typescript
import { Component, signal, linkedSignal } from '@angular/core';

@Component({ ... })
export class OrderComponent {
  // ১. মেইন সিগনাল
  selectedFood = signal('Burger');

  // ২. লিংক করা সিগনাল (খাবার পাল্টালে ড্রিংকসও অটো পাল্টে যাবে)
  drink = linkedSignal(() => {
    if (this.selectedFood() === 'Burger') return 'Coke';
    if (this.selectedFood() === 'Pizza') return 'Pepsi';
    return 'Water';
  });

  changeFood() {
    this.selectedFood.set('Pizza'); 
    // drink অটোমেটিক 'Pepsi' হয়ে যাবে
  }

  manualDrinkChange() {
    this.drink.set('Juice'); 
    // এটা কাজ করবে! (Computed হলে কাজ করত না)
  }
}
```

### ⚡ **Part 3: Zoneless Change Detection (Experimental)**
অ্যাঙ্গুলারের স্পিড বুস্টার। `Zone.js` নামক লাইব্রেরি বাদ দিয়ে অ্যাপ চালানো।

*   **এনালজি:**
    *   **With Zone.js:** রেস্টুরেন্টের ম্যানেজার প্রতি ৫ সেকেন্ড পর পর চিৎকার করে— "সবাই কাজ করছো তো? চেক করো! চেক করো!" (একটু ভারী এবং বিরক্তিকর)।
    *   **Zoneless:** স্মার্ট সেন্সর সিস্টেম। শুধুমাত্র যখন কোনো অর্ডারে পরিবর্তন আসে, ঠিক তখনই সিস্টেম আপডেট হয়। কোনো অহেতুক চেকিং নেই।

#### **Code Example (`app.config.ts`):**
```typescript
import { provideExperimentalZonelessChangeDetection } from '@angular/core';

export const appConfig: ApplicationConfig = {
  providers: [
    // ম্যানেজারকে ছাঁটাই করে স্মার্ট সেন্সর লাগানো হলো
    provideExperimentalZonelessChangeDetection() 
  ]
};
```
*(নোট: এটা ব্যবহার করলে অ্যাপ সুপার ফাস্ট হয় এবং `OnPush` স্ট্র্যাটেজি অটোমেটিক কাজ করে)*
