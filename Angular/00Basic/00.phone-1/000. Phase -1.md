### **১. `let` vs `const` (Variable Declaration)**
JavaScript এ আগে `var` ছিল, ওটা এখন ডাস্টবিনে ফেলে দাও। এখন শুধু `let` আর `const`।

*   **Analogy (মজার উদাহরণ):**
    *   **`const`**: এটা হলো তোমার **বউ**। একবার কবুল বলার পর (Assign করার পর) আর চেঞ্জ করা যাবে না। চেঞ্জ করতে গেলেই `Error` খাবে (সংসারে আগুন লাগবে)।
    *   **`let`**: এটা হলো তোমার **গার্লফ্রেন্ড**। আজকে রিলেশন আছে, কালকে ব্রেকআপ করে ভ্যালু চেঞ্জ করা যাবে।

*   **Code Example:**
    ```typescript
    const wife = "Sakina";
    // wife = "Jorina"; // ❌ Error! সংসার শেষ।

    let girlfriend = "Rita";
    girlfriend = "Mita"; // ✅ OK! ভ্যালু চেঞ্জ করা যাবে।
    ```

### **২. Arrow Functions `() => {}`**
ফাংশন লিখতে এখন আর `function` কিওয়ার্ড লেখার সময় নাই। আমরা এখন স্মার্ট এবং অলস।

*   **Analogy:**
    *   **Normal Function:** "আমি এখন ভাত খাইতেছি" (সাধু ভাষা)।
    *   **Arrow Function:** "ভাত খাইতেছি" (মুরাদ টাকলা বা চ্যাটিং ভাষা - শর্টকাট)।

*   **Code Example:**
    ```typescript
    // Old Style
    function doublePrice(price) {
        return price * 2;
    }

    // New Style (Arrow Function)
    const doublePrice = (price) => price * 2; 
    // এক লাইনে কাজ শেষ! return ও লিখা লাগে না।
    ```

### **৩. Destructuring (ভেতরের মালসামানা বের করা)**
অবজেক্ট থেকে ভ্যালু বের করার মডার্ন উপায়।

*   **Analogy:**
    বিয়ে বাড়িতে বিরিয়ানির প্লেট (Object) থেকে শুধু **লেগপিসটা** (Property) টুপ করে তুলে নেওয়া। পুরা প্লেট হাতানোর দরকার নাই।

*   **Code Example:**
    ```typescript
    const product = {
        id: 1,
        title: "Iphone 16 Pro Max (Kidney Version)",
        price: 150000,
        color: "Titanium"
    };

    // Old way (বোরিং)
    const title = product.title;
    const price = product.price;

    // Destructuring way (স্মার্ট)
    const { title, price } = product; 
    console.log(title); // Iphone 16 Pro Max...
    ```

### **৪. TypeScript এর `Type` এবং `Interface` (The Police)**
JavaScript হলো বেয়াদব পোলাপানের মতো, যা খুশি তাই করে। নাম্বারের সাথে স্ট্রিং যোগ করে দেয়। TypeScript হলো **ট্রাফিক পুলিশ**। নিয়ম না মানলে মামলা (Error) দিবে।

আমাদের দোকানের প্রোডাক্টের একটা ব্লু-প্রিন্ট বা নকশা লাগবে। এটাকে বলে **Interface**।

*   **Analogy:**
    বিয়ের বায়োডাটা। পাত্রের কী কী থাকতে হবে?
    *   নাম (String)
    *   বয়স (Number)
    *   বেতন (Number)
    *   গাড়ি আছে কি না (Boolean)
    এগুলোর একটা মিস হলে বা ভুল ভাল দিলে বিয়ে ক্যান্সেল (Code Error)।

*   **Code Example (Jhut-Jhamela Store এর প্রোডাক্ট):**
    ```typescript
    // ১. ইন্টারফেস বা ব্লু-প্রিন্ট বানানো
    interface Product {
        id: number;
        name: string;
        price: number;
        inStock: boolean;
        description?: string; // '?' মানে এটা অপশনাল, দিলেও হবে না দিলেও হবে।
    }

    // ২. সেই ব্লু-প্রিন্ট অনুযায়ী প্রোডাক্ট বানানো
    const myPhone: Product = {
        id: 101,
        name: "Nokia 1100 (Hammer Edition)",
        price: 1500,
        inStock: true
        // description না দিলেও এরর দিবে না কারণ ওটা অপশনাল (?)
    };

    // ❌ ভুল করলে লাল দাগ দিবে
    // const wrongPhone: Product = {
    //    id: "One", // ❌ Error: id হতে হবে number, তুমি দিছো string!
    //    name: "Samsung"
    // }
    ```

```typescript
// Step 1: Interface
interface Product {
  id: number;
  title: string;
  price: number;
  isAvailable: boolean;
}

// Step 2: Array of Products
const shopProducts: Product[] = [
  {
    id: 1,
    title: "Second Hand Toothbrush",
    price: 50,
    isAvailable: true
  },
  {
    id: 2,
    title: "Broken Heart (Not for sale)",
    price: 0,
    isAvailable: false
  },
  {
    id: 3,
    title: "Invisible Cloak (Harry Potter)",
    price: 9999,
    isAvailable: true
  }

// Step 3: Arrow function দিয়ে ফিল্টার করা (যাদের দাম ১০০ টাকার বেশি)
const expensiveProducts = shopProducts.filter(p => p.price > 100);

console.log(expensiveProducts);
```

### **ধাপ ৪: ডাটা দেখানো (Interpolation `{{ }}`)**
এখন আমরা প্রোডাক্ট কার্ডে কিছু ডাটা দেখাব।

১. **Typescript (Logic):** `product-card.component.ts` ফাইলে যাও। ক্লাসের ভেতরে একটা ভেরিয়েবল নাও।
```typescript
export class ProductCardComponent {
  // এখানে ভেরিয়েবল নিব
  productName = "Iphone 15 (China Copy)";
  price = 500;
}
```

২. **HTML (View):** `product-card.component.html` ফাইলে যাও।
```html
<div class="card">
  <h3>{{ productName }}</h3>  <!-- এটাকে বলে Interpolation -->
  <p>Price: {{ price }} Taka</p>
  <button>Add to Cart</button>
</div>
```
*   **Analogy:** `{{ }}` হলো জানলা। ঘরের ভেতরের (TS ফাইল) জিনিস বাইরের মানুষ (Browser) এই জানলা দিয়ে দেখতে পায়।

৩. **Styling (CSS):** `product-card.component.css` ফাইলে একটু মেকআপ দাও।
```css
.card {
  border: 1px solid red;
  padding: 10px;
  margin: 10px;
  border-radius: 8px;
  background-color: #f9f9f9;
}
```

### **ধাপ ৬: লেটেস্ট ফিচার - `@for` লুপ এবং `Signal Input`**
সব কার্ডে তো একই আইফোন দেখাচ্ছে। এটা তো সমস্যা। আমরা ডাইনামিক ডাটা চাই।

**১. `input()` Signal ব্যবহার (Latest v17/18+ Feature):**
`product-card.component.ts` আপডেট করো। আমরা প্যারেন্ট থেকে ডাটা রিসিভ করব।
```typescript
import { Component, input } from '@angular/core'; // input import করো

@Component({ ... })
export class ProductCardComponent {
  // আগের ভেরিয়েবল মুছে ফেলো।
  // input.required মানে ডাটা দিতেই হবে, না দিলে এরর।
  item = input.required<any>(); 
}
```
`product-card.component.html` আপডেট করো (সিগন্যাল ভ্যালু পড়তে `()` লাগে):
```html
<div class="card">
  <h3>{{ item().name }}</h3>
  <p>Price: {{ item().price }} Taka</p>
</div>
```

**২. App Component এ ডাটা লিস্ট:**
`app.component.ts` এ একটা লিস্ট বানাও।
```typescript
export class AppComponent {
  products = [
    { id: 1, name: "Second Hand Toothbrush", price: 50 },
    { id: 2, name: "Leaked Question Paper", price: 500 },
    { id: 3, name: "Hawa Mithai (Air only)", price: 10 }
  ];
}
```

**৩. HTML এ `@for` লুপ (Modern Syntax):**
`app.component.html` এ লুপ চালাও।
```html
<h1>Jhut-Jhamela Store 🏪</h1>

<div class="product-container">
  <!-- @for লুপ। track ব্যবহার করা বাধ্যতামূলক যাতে অ্যাঙ্গুলার ফাস্ট কাজ করে -->
  @for (p of products; track p.id) {
    <app-product-card [item]="p" />
  }
</div>
```

### **Phase 2 সামারি ও হোমওয়ার্ক**
আমরা কী শিখলাম?
1.  `ng new` দিয়ে প্রজেক্ট বানানো।
2.  `ng g c` দিয়ে কম্পোনেন্ট বানানো।
3.  `{{ }}` দিয়ে ডাটা দেখানো।
4.  `input()` সিগন্যাল দিয়ে ডাটা রিসিভ করা।
5.  `@for` লুপ দিয়ে লিস্ট প্রিন্ট করা।

**তোমার হোমওয়ার্ক:**
*   `products` অ্যারেতে নতুন একটা প্রপার্টি যোগ করো `isSoldOut: boolean`।
*   HTML এ **`@if`** ব্যবহার করো। যদি `isSoldOut` সত্য হয়, তবে লাল রঙে লেখা দেখাও "Stock Out!", আর না হলে "Buy Now" বাটন দেখাও।

Hint:
```html
@if (item().isSoldOut) {
  <p style="color: red">Stock Out!</p>
} @else {
  <button>Buy Now</button>
}
```

Phase 2 শেষ করো, কোড রান করে স্ক্রিনশট মনে মনে তোলো, তারপর **Phase 3** এর জন্য রেডি হও! 🚀

**Target Chapters:** 9, 12, 28 (সবচেয়ে গুরুত্বপূর্ণ পার্ট)

Phase 2-তে আমাদের দোকান দেখতে সুন্দর হয়েছে, কিন্তু কাজ করে না। "Add to Cart" বাটনে চাপ দিলে কিছুই হয় না। মরা লাশের মতো।
এই ফেজে আমরা অ্যাপের ভেতরে **"সিগন্যাল (Signal)"** বসাবো।

Angular v16+ (এবং ফিউচার v21) এর মেইন পাওয়ার হলো **Signals**। আগে `Zone.js` দিয়ে চেক করা হতো কোথায় ডাটা চেঞ্জ হয়েছে, যা ছিল স্লো। Signals হলো সুপার ফাস্ট!

### **১. সিগন্যাল কী? (What is a Signal?)**
সিগন্যাল হলো একটা **"স্বচ্ছ কাঁচের বাক্স"** যার ভেতরে একটা ভ্যালু থাকে।
*   যখনই বাক্সের ভেতরের ভ্যালু বদলায়, যারা যারা এই বাক্সের দিকে তাকিয়ে আছে (Template/View), তারা সাথে সাথে খবর পেয়ে যায়।

*   **Analogy:**
    *   **Normal Variable:** ক্লাসের পেছনের বেঞ্চের ছাত্র। স্যার কিছু পড়ালে সে ঘুমাচ্ছে, খবর পায় না।
    *   **Signal:** ক্লাসের ফার্স্ট বয়। স্যার বোর্ডে একটা অক্ষর লিখলেই সে সাথে সাথে নোট খাতায় (UI) তুলে ফেলে।

### **ধাপ ১: কার্ট কাউন্টার বানানো (Creating a Signal)**
আমরা `AppComponent` এ একটা ঝুড়ি (Cart) রাখব। কয়টা আইটেম কিনলাম তা গুনব।

`app.component.ts` এ যাও:

```typescript
import { Component, signal } from '@angular/core'; // 1. signal ইমপোর্ট করো
// ... imports ...

export class AppComponent {
  // 2. সাধারণ ভেরিয়েবল না, সিগন্যাল বানাও
  // cartCount = 0; // আগে এভাবে লিখতাম (Old School)
  cartCount = signal(0); // এখন এভাবে (New Cool)

  products = [ ... ]; // আগের প্রোডাক্ট লিস্ট
}
```

`app.component.html` এ ডিসপ্লে করো:
```html
<header style="padding: 20px; background: #eee;">
  <h1>Jhut-Jhamela Store 🏪</h1>
  <!-- 3. সিগন্যাল পড়ার জন্য () ব্র্যাকেট দিতে হয়। এটা একটা ফাংশনের মতো কাজ করে -->
  <h3>🛒 Cart: {{ cartCount() }} items</h3>
</header>

<!-- বাকি প্রোডাক্ট লিস্ট নিচে থাকবে -->
```

### **ধাপ ২: সিগন্যাল আপডেট করা (Writing Signals)**
সিগন্যাল আপডেট করার দুইটা নিয়ম:
1.  **set(value):** ডাইরেক্ট ভ্যালু বসিয়ে দেওয়া। (যেমন: স্কোর ০ করে দেওয়া)।
2.  **update(fn):** আগের ভ্যালুর সাথে যোগ-বিয়োগ করা। (যেমন: আগের স্কোরের সাথে ১ যোগ করা)।

আমরা চাই `ProductCard` থেকে বাটনে চাপ দিলে প্যারেন্ট (`AppComponent`) এর সিগন্যাল বাড়বে। এর জন্য চাইল্ড থেকে প্যারেন্টে খবর পাঠাতে হবে। এটাকে বলে **`output()`** (আগে `@Output` ছিল)।

**A. Child Component (`product-card.component.ts`):**
```typescript
import { Component, input, output } from '@angular/core'; // output ইমপোর্ট করো

export class ProductCardComponent {
  item = input.required<any>();
  
  // 1. একটা ইভেন্ট বা খবর পাঠানোর চ্যানেল বানাও
  addToCart = output<void>(); 

  // 2. বাটন ক্লিক করলে এই ফাংশন কল হবে
  handleAddToCart() {
    this.addToCart.emit(); // খবর পাঠিয়ে দিলাম!
  }
}
```

**B. Child HTML (`product-card.component.html`):**
```html
<div class="card">
  <h3>{{ item().name }}</h3>
  <p>Price: {{ item().price }}</p>
  <!-- বাটনে ক্লিক ইভেন্ট -->
  <button (click)="handleAddToCart()">Add to Cart</button>
</div>
```

**C. Parent Component (`app.component.ts`):**
এখন প্যারেন্ট ওই খবর রিসিভ করবে এবং সিগন্যাল আপডেট করবে।

```typescript
export class AppComponent {
  cartCount = signal(0);
  // ... products ...

  // এই ফাংশন কল হলে ১ বাড়বে
  updateCart() {
    this.cartCount.update(prevValue => prevValue + 1);
    // Analogy: update হলো আগের গার্লফ্রেন্ড (prevValue) এর সাথে 
    // নতুন মেকআপ (+ 1) যোগ করা।
  }
}
```

**D. Parent HTML (`app.component.html`):**
```html
<!-- কানেকশন লাগিয়ে দাও -->
@for (p of products; track p.id) {
  <app-product-card 
      [item]="p" 
      (addToCart)="updateCart()" /> 
      <!-- (addToCart) ইভেন্ট ফায়ার হলে updateCart() কল হবে -->
}
```
এখন ব্রাউজারে গিয়ে "Add to Cart" চাপো। দেখবে ম্যাজিকের মতো কার্ট সংখ্যা বাড়ছে! 🚀

### **ধাপ ৩: Computed Signals (অটোমেটিক ক্যালকুলেটর)**
ধরি, প্রতিটা প্রোডাক্টের ডেলিভারি চার্জ ৫০ টাকা। ইউজার যতগুলো আইটেম কার্টে নিবে, টোটাল ডেলিভারি চার্জ তত বাড়বে। এটা আমাদের ম্যানুয়ালি হিসাব করার দরকার নাই।

*   **Concept:** `computed()` হলো এমন একটা সিগন্যাল যা অন্য সিগন্যালের উপর নির্ভর করে। মেইন সিগন্যাল বদলালে এটাও একা একাই বদলে যায়।

`app.component.ts` এ যোগ করো:
```typescript
import { Component, signal, computed } from '@angular/core';

export class AppComponent {
  cartCount = signal(0);

  // অটোমেটিক হিসাব হবে
  totalDeliveryCharge = computed(() => {
    return this.cartCount() * 50;
  });

  // ... বাকি কোড ...
}
```

`app.component.html` এ দেখাও:
```html
<p>Total Delivery Charge: {{ totalDeliveryCharge() }} Taka</p>
```
এখন কার্ট বাড়ালেই ডেলিভারি চার্জও বাড়বে!

### **ধাপ ৪: Effects (গোয়েন্দাগিরি)**
কখনো কখনো আমাদের সিগন্যাল পরিবর্তন হলে কনসোলে লগ করতে হয় বা ডাটা সেভ করতে হয়। এটাকে বলে **Effect**।

*   **Analogy:** যখনই তোমার আম্মু (Signal) তোমার ঘরে আসে, তুমি পড়ার অভিনয় শুরু করো (Effect)।

`app.component.ts` এর `constructor` এর ভেতরে লিখতে হয়:
```typescript
import { effect } from '@angular/core';

export class AppComponent {
  cartCount = signal(0);

  constructor() {
    // এই ইফেক্ট অটোমেটিক কল হবে যখনই cartCount বদলাবে
    effect(() => {
      console.log(`User bought ${this.cartCount()} items. তারা বড়লোক!`);
      
      // এখানে আমরা লোকাল স্টোরেজে ডাটা সেভ করতে পারি
      // localStorage.setItem('count', this.cartCount().toString());
    });
  }
}
```
ব্রাউজারের কনসোল (F12) ওপেন করে বাটনে চাপ দাও। দেখবে ম্যাসেজ প্রিন্ট হচ্ছে।

### **Phase 3 সামারি ও হোমওয়ার্ক**
আমরা শিখলাম:
1.  `signal()` দিয়ে স্টেট বা ডাটা রাখা।
2.  `update()` দিয়ে সিগন্যাল ভ্যালু বদলানো।
3.  `output()` দিয়ে চাইল্ড থেকে প্যারেন্টে সিগন্যাল পাঠানো।
4.  `computed()` দিয়ে অটোমেটিক ক্যালকুলেশন।
5.  `effect()` দিয়ে সাইড ইফেক্ট হ্যান্ডেল করা।

**তোমার হোমওয়ার্ক (খুবই ইন্টারেস্টিং):**
১. `app.component.ts` এ `totalPrice` নামে একটা `computed` সিগন্যাল বানাও।
২. লজিক হবে: ধরে নাও সব প্রোডাক্টের গড় দাম ৫০০ টাকা। তাহলে `totalPrice = cartCount * 500`।
৩. HTML এ দেখাও: "Total Bill: ____ Taka"।
৪. বোনাস: একটা "Reset Cart" বাটন বানাও যা `cartCount.set(0)` করে দিবে।

এটা করে ফেললে তুমি অ্যাঙ্গুলারের **"Brain"** বুঝে গেছো! 🧠
**Phase 4** এ আমরা ফেক ডাটা দিয়ে আসল ই-কমার্স সাইটের মতো পেজ বানাবো (HTTP & Routing)। রেডি? 🚦

**Target Chapters:** 15, 18, 19, 28

আমাদের দোকান (App) এখন দেখতে সুন্দর, সিগন্যাল দিয়ে বাটনও কাজ করে। কিন্তু সমস্যা হলো:
১. সব প্রোডাক্টের ডাটা আমরা হাতে লিখেছি (Hardcoded)। আসল দোকানে ডাটা আসবে সার্ভার বা গোডাউন থেকে।

এই ফেজে আমরা **"গোডাউন থেকে মাল আনবো (HTTP)"** এবং **"এক রুম থেকে অন্য রুমে যাওয়ার দরজা বানাবো (Router)"**।

### **ধাপ ১: সেটআপ (HTTP ক্লায়েন্ট চালু করা)**
Angular এর নতুন ভার্সনে `app.module.ts` নাই। তাই আমাদের কনফিগারেশন ফাইলে `HttpClient` চালু করতে হবে।

`src/app/app.config.ts` ফাইলে যাও:
```typescript
import { ApplicationConfig } from '@angular/core';
import { provideRouter } from '@angular/router';
import { routes } from './app.routes';
import { provideHttpClient } from '@angular/common/http'; // 1. এটা ইমপোর্ট করো

export const appConfig: ApplicationConfig = {
  providers: [
    provideRouter(routes),
    provideHttpClient() // 2. এটা যোগ করো (ইন্টারনেটের লাইন সংযোগ দেওয়া হলো)
  ]
};
```

### **ধাপ ২: সার্ভিস এবং ডিপেন্ডেন্সি ইনজেকশন (The Waiter)**
কম্পোনেন্ট হলো **কাস্টমার** (সে শুধু খেতে চায়)। সে রান্নাঘরে গিয়ে খুঁজবে না। তার জন্য **ওয়েটার** (Service) দরকার যে খাবার (Data) এনে দিবে।

টার্মিনালে লিখো:
```bash
ng g s api
```
*(ng generate service api)*

এখন `src/app/api.service.ts` এ কোড লিখো:

```typescript
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';

@Injectable({
  providedIn: 'root' // মানে এই সার্ভিস পুরো অ্যাপে এভেইলেবল (Global Waiter)
})
export class ApiService {
  // আগের মতো constructor এ inject না করে এখন মডার্ন inject() ফাংশন ব্যবহার হয়
  http = inject(HttpClient); 

  getProducts() {
    // FakeStoreAPI থেকে ডাটা আনছি। এটা একটা ফ্রি অনলাইন ফেক ডাটাবেস।
    return this.http.get<any[]>('https://fakestoreapi.com/products');
  }
}
```
*   **Analogy:** `http.get` হলো অনলাইনে অর্ডার দেওয়া। এটা সাথে সাথে ডাটা দেয় না, একটু সময় নেয় (Asynchronous)।

### **ধাপ ৩: RxJS থেকে Signal এ রূপান্তর (Modern Data Fetching)**
আমরা Phase 3 তে শিখেছি **Signal** কত জোস। কিন্তু HTTP আমাদের দেয় **Observable** (RxJS)।
Angular v17+ এ একটা ম্যাজিক টুল আছে `toSignal` যা Observable কে Signal বানিয়ে দেয়।

`app.component.ts` আপডেট করো:

```typescript
import { Component, inject } from '@angular/core';
import { toSignal } from '@angular/core/rxjs-interop'; // ম্যাজিক টুল
import { ApiService } from './api.service';
import { ProductCardComponent } from './product-card/product-card.component';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [ProductCardComponent], // RouterOutlet পরে যোগ করছি
  templateUrl: './app.component.html',
  styleUrl: './app.component.css'
})
export class AppComponent {
  apiService = inject(ApiService); // সার্ভিসকে ডাক দিলাম

  // ডাটা লোড করে সিগন্যাল বানিয়ে ফেললাম
  // initialValue: [] মানে ডাটা আসার আগ পর্যন্ত লিস্ট খালি থাকবে
  products = toSignal(this.apiService.getProducts(), { initialValue: [] }); 
}
```

এখন `app.component.html` এ আগের `@for` লুপটাই কাজ করবে! কিন্তু এবার ডাটা আসছে ইন্টারনেট থেকে! ব্রাউজার রিফ্রেশ দিলে দেখবে সত্যি সত্যি ২০টা প্রোডাক্ট লোড হয়েছে। 🪄

### **ধাপ ৪: রাউটিং (এক পেজ থেকে অন্য পেজে যাওয়া)**
এখন আমরা চাই হোম পেজে প্রোডাক্ট থাকবে, আর "Cart" বাটনে চাপলে অন্য পেজে যাবে।

**১. নতুন কম্পোনেন্ট বানাও:**
আমরা `AppComponent` কে খালি করব এবং সব প্রোডাক্ট `HomeComponent` এ নিব।
```bash
ng g c home
ng g c cart
```

**২. রাউট কনফিগার করা (`app.routes.ts`):**
এটা হলো ট্রাফিক পুলিশ। কে কোন রাস্তায় যাবে তা বলে দিবে।

```typescript
import { Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { CartComponent } from './cart/cart.component';

export const routes: Routes = [
  { path: '', component: HomeComponent }, // খালি রাস্তায় হোম দেখাও
  { path: 'cart', component: CartComponent }, // /cart এ গেলে কার্ট দেখাও
  { path: '**', redirectTo: '' } // ভুল ভাল রাস্তায় গেলে হোমে পাঠিয়ে দাও
];
```

**৩. কোড স্থানান্তর (Refactoring):**
*   `app.component.ts` থেকে ডাটা লোডিং এর কোডগুলো `home.component.ts` এ নিয়ে যাও।
*   `app.component.html` এর `for` লুপ কেটে `home.component.html` এ বসাও।

**৪. মেইন লেআউট (`app.component.html`):**
এখন `AppComponent` শুধু ফ্রেম হিসেবে থাকবে।

```html
<nav>
  <h1>Jhut-Jhamela Store 🏪</h1>
  <!-- সাধারণ href ব্যবহার করবে না, routerLink ব্যবহার করবে -->
  <a routerLink="/">Home</a> | 
  <a routerLink="/cart">Cart 🛒</a>
</nav>

<hr>

<!-- এই জায়গায় পেজ লোড হবে -->
<router-outlet></router-outlet>
```
*   **Analogy:** `<router-outlet>` হলো টিভির স্ক্রিন। রিমোট টিপলে (Link Click) চ্যানেল বদলায় (Component), কিন্তু টিভি (App) একটাই থাকে।

### **ধাপ ৫: রাউটার সেটআপ আপডেট (`app.component.ts`)**
`AppComponent` এখন রাউটার চিনতে হবে।

```typescript
import { Component } from '@angular/core';
import { RouterOutlet, RouterLink } from '@angular/router'; // ইমপোর্ট করো

@Component({
  selector: 'app-root',

  templateUrl: './app.component.html',
  styleUrl: './app.component.css'
})
export class AppComponent {}
```

### **Phase 4 সামারি ও হোমওয়ার্ক**
আমরা এখন একটা **Single Page Application (SPA)** বানিয়ে ফেলেছি!

**যা যা করলাম:**
১. `provideHttpClient` দিয়ে ইন্টারনেটের রাস্তা খুললাম।
২. `ApiService` দিয়ে `fakestoreapi` থেকে ডাটা আনলাম।
৩. `toSignal` ব্যবহার করে সেই ডাটা সহজে দেখালাম।
৪. `app.routes.ts` দিয়ে পেজ ভাগ করলাম।
৫. `routerLink` দিয়ে নেভিগেশন বানালাম।

**তোমার হোমওয়ার্ক:**
১. **Cart Service:** একটা `CartService` বানাও (Singleton Service)।
    *   এতে একটা সিগন্যাল থাকবে: `cartItems = signal([])`।
    *   `HomeComponent` থেকে "Add to Cart" দিলে এই সার্ভিসের সিগন্যালে আইটেম যোগ হবে।
    *   `CartComponent` এ গিয়ে এই সার্ভিসের সিগন্যাল থেকে ডাটা দেখাবে।
    *   *Result:* হোম পেজে এড করলে কার্ট পেজে গিয়ে সেটা দেখা যাবে।

২. **CSS:** `routerLinkActive` ব্যবহার করে মেনুর লিংকে স্টাইল দাও (যে পেজে আছো সেটা হাইলাইট হবে)।

Hints:
```html
<a routerLink="/cart" routerLinkActive="active-link">Cart</a>
```

### **ধাপ ১: চেকআউট ফর্ম (Forms - The Cash Counter)**
অ্যাঙ্গুলারে ফর্ম বানানোর দুইটা উপায়:
1.  **Template-driven:** সহজ, কম কোড। ছোট ফর্মের জন্য সেরা।
2.  **Reactive:** একটু কঠিন, কিন্তু অনেক পাওয়ারফুল।

আমরা সহজটা (Template-driven) দিয়ে শুরু করব।

**১. সেটআপ:**
`cart.component.ts` ফাইলে `FormsModule` ইমপোর্ট করতে হবে। এটা ছাড়া ফর্ম কাজ করবে না।

```typescript
import { Component, inject } from '@angular/core';
import { FormsModule } from '@angular/forms'; // 1. ইমপোর্ট করো

@Component({
  selector: 'app-cart',
  standalone: true,
  imports: [FormsModule], // 2. এখানে ঢুকাও
  templateUrl: './cart.component.html',
  styleUrl: './cart.component.css'
})
export class CartComponent {
  // ফর্মের ডাটা রাখার জন্য অবজেক্ট
  userData = {
    name: '',
    address: '',
    phone: ''
  };

  placeOrder() {
    alert(`অর্ডার কনফার্ম! ${this.userData.name}, আপনার বাসায় পুলিশ পাঠানো হচ্ছে... মানে ডেলিভারি ম্যান! 🚚`);
    console.log(this.userData);
  }
}
```

**২. HTML এ ফর্ম বানানো (`[(ngModel)]` - Two-way binding):**
`[(ngModel)]` হলো **বুমেরাং** এর মতো। আপনি ইনপুটে লিখলে ভেরিয়েবলে আপডেট হবে, আবার ভেরিয়েবল পাল্টালে ইনপুটে আপডেট হবে।

`cart.component.html` এ লিখো:
```html
<div class="checkout-box">
  <h2>Cash Counter 💰</h2>
  
  <form (ngSubmit)="placeOrder()" #orderForm="ngForm">
    
    <!-- নাম -->
    <div>
      <label>Your Name:</label>
      <input type="text" name="name" 
             [(ngModel)]="userData.name" 
             required 
             #nameField="ngModel">
      
      <!-- ভ্যালিডেশন এরর -->
      @if (nameField.invalid && nameField.touched) {
        <small style="color: red;">নাম না বললে প্রোডাক্ট দিবো কাকে? 😡</small>
      }
    </div>

    <!-- ফোন নম্বর -->
    <div>
      <label>Phone:</label>
      <input type="text" name="phone" 
             [(ngModel)]="userData.phone" 
             required minlength="11">
    </div>

    <!-- বাটন: ফর্ম ভ্যালিড না হলে বাটন ডিজেবল থাকবে -->
    <button type="submit" [disabled]="orderForm.invalid">
      Confirm Order
    </button>

  </form>
</div>
```

*   **Analogy:** `[disabled]="orderForm.invalid"` হলো কড়া দারোয়ান। আইডি কার্ড (সঠিক তথ্য) না দেখালে গেট খুলবে না (বাটন কাজ করবে না)।

### **ধাপ ২: Deferrable Views (লেজি মানুষ ফিচার - @defer)**
তোমার সাইটের নিচে হয়তো বিশাল এক ম্যাপ বা ভারী রিভিউ সেকশন আছে। ইউজার সেখানে না যাওয়া পর্যন্ত সেটা লোড করে লাভ কী? ডাটা খরচ!

Angular v17+ এ এসেছে **`@defer`**। এটা ম্যাজিক।

`home.component.html` এর একদম নিচে এটা যোগ করো:

```html
<!-- উপরের সব প্রোডাক্ট লিস্ট... -->

<hr>

<!-- @defer ব্লক -->
@defer (on viewport) {
  <!-- এই অংশটা ইউজার স্ক্রল করে নিচে আসার আগে লোড হবে না -->
  <app-heavy-reviews-section /> 
} @placeholder {
  <!-- লোড হওয়ার আগে এটা দেখাবে -->
  <p>রিভিউ লোড হতে সময় লাগবে... নিচে নামেন...</p>
} @loading (minimum 1s) {
  <!-- লোডিং এর সময় এটা দেখাবে -->
  <p>Loading... ⏳</p>
} @error {
  <p>লোড হলো না! ইন্টারনেট বিল দিছেন? ❌</p>
}
```

*   **Analogy:** রেস্টুরেন্টে গিয়েই ডেজার্ট অর্ডার দেয় না। আগে বিরিয়ানি খায় (Main content), পেটে জায়গা থাকলে তারপর ওয়েটারকে বলে "ভাই ফিরনি আনেন" (`on viewport` বা `on interaction`)।

### **ধাপ ৩: ফাইনাল বিল্ড (Packing the Luggage)**
ডেভেলপ করার সময় আমরা `ng serve` দেই। কিন্তু ইন্টারনেটে (Vercel/Netlify/Firebase) তোলার জন্য আমাদের **Production Build** দিতে হবে। এটা কোডকে মিনিফাই করে ছোট করে ফেলে।

টার্মিনালে কমান্ড দাও:
```bash
ng build
```

কিছুক্ষণ সময় নিবে। তারপর দেখবে তোমার প্রজেক্ট ফোল্ডারে `dist/jhut-jhamela-store` নামে একটা ফোল্ডার তৈরি হয়েছে।
এই ফোল্ডারের ভেতরের ফাইলগুলোই (index.html, styles.css, main.js) আসল ওয়েবসাইট। এগুলো যেকোনো সার্ভারে আপলোড দিলেই সাইট লাইভ! 🚀

### **ধাপ ৪: পারফরমেন্স টিপস (Bonus Knowledge)**
Angular v21 (ফিউচার) বা মডার্ন অ্যাঙ্গুলারে অ্যাপ ফাস্ট রাখার ৩টি মন্ত্র:
1.  **`track` in loop:** সব সময় `@for` লুপে `track` ব্যবহার করবে (যেমন `track product.id`)। না হলে অ্যাঙ্গুলার কনফিউজড হয়ে যায়।
2.  **Lazy Loading Images:** ইমেজে `ngSrc` ব্যবহার করা (Angular এর ইমেজ অপটিমাইজেশন টুল)।
    *   `imports: [NgOptimizedImage]`
    *   `<img [ngSrc]="product.image" width="200" height="200">`
3.  **Signals:** `Zone.js` বাদ দিয়ে সিগন্যাল ব্যবহার করা (যা আমরা অলরেডি করেছি)।
