স্বাগতম **Lesson 6**-এ! 👋

আমরা এতদিন `new Observable` লিখে অনেক কষ্ট করে স্ট্রিম বানিয়েছি। কিন্তু ভাবো তো, তোমার কাছে যদি আগে থেকেই একটা Array থাকে `[১, ২, ৩, ৪]`, সেটাকে Observable বানাতে এত কোড লেখার দরকার আছে?

না! RxJS আমাদের জন্য কিছু **"রেডিমেড জাদুর কাঠি"** রেখেছে। এদের বলা হয় **Creation Operators**। আজ আমরা দুইটা সুপারস্টার অপারেটর শিখব: **`of`** এবং **`from`**।

---

### **১. `of` Operator - পকেট থেকে চকোলেট বের করা 🍬**

`of` অপারেটর খুব সহজ। তুমি এর ভেতরে যা যা দিবে, সে এক এক করে সেগুলো বের করে দিবে (Emit করবে) এবং সাথে সাথে `complete` হয়ে যাবে।

**উদাহরণ:**
মনে করো তোমার পকেটে ৩টা চকোলেট আছে। তুমি বন্ধুর হাতে একে একে ৩টা চকোলেট দিলে এবং বললে "আর নাই"।

**Code:**
```javascript
import { of } from 'rxjs';

// পকেটের মালপত্র
const pocket$ = of('KitKat', 'Snickers', 'Dairy Milk');

console.log('--- of শুরু ---');
pocket$.subscribe({
  next: (item) => console.log(`খেলাম: ${item}`),
  complete: () => console.log('পকেট খালি! 🤷‍♂️')
});
console.log('--- of শেষ ---');
```

**আউটপুট:**
```
খেলাম: KitKat
খেলাম: Snickers
খেলাম: Dairy Milk
পকেট খালি!
```
*খেয়াল করো:* `of` এর ভেতর তুমি কমা (`,`) দিয়ে যা খুশি দিতে পারো (String, Number, Object, Array)। সে সেগুলোকে **আলাদা আলাদা ভ্যালু** হিসেবে বের করে দিবে।

---

### **২. `from` Operator - জাদুর বাক্স খোলা 📦**

`from` একটু বেশি স্মার্ট। তুমি যদি একে কোনো একটা **Array** বা **Promise** বা **Iterable** কিছু দাও, সে সেটার ভেতরের জিনিসগুলোকে খুলে এক এক করে বের করে দিবে।

**পার্থক্য (`of` vs `from`):**

*   `of([1, 2, 3])`: এটা পুরো অ্যারেটাকে **একবারে** ১টা ভ্যালু হিসেবে দিবে। `[1, 2, 3]`।
*   `from([1, 2, 3])`: এটা অ্যারেকে ভেঙে **৩টা আলাদা** ভ্যালু হিসেবে দিবে। `1`, তারপর `2`, তারপর `3`।

**Code Example:**
```javascript
import { from } from 'rxjs';

const fruits = ['Mango 🥭', 'Banana 🍌', 'Apple 🍎'];

// Array কে Observable বানাচ্ছি
const fruitBasket$ = from(fruits);

console.log('--- from শুরু ---');
fruitBasket$.subscribe({
  next: (fruit) => console.log(`পেলাম: ${fruit}`),
  complete: () => console.log('ঝুড়ি শেষ!')
});
console.log('--- from শেষ ---');
```

**আউটপুট:**
```
পেলাম: Mango 🥭
পেলাম: Banana 🍌
পেলাম: Apple 🍎
ঝুড়ি শেষ!
```

---

### **বোনাস: Promise কে Observable বানানো! 😲**

`from` এর আরেকটা জাদুকরী ক্ষমতা হলো, সে `Promise` কেও Observable বানিয়ে ফেলতে পারে।

```javascript
// একটা প্রমিজ (ধরো API কল)
const pizzaPromise = new Promise(resolve => resolve('Super Cheese Pizza 🍕'));

// প্রমিজকে Observable বানিয়ে ফেললাম!
const order$ = from(pizzaPromise);

order$.subscribe(val => console.log(val)); 
// আউটপুট: Super Cheese Pizza 🍕
```

এতে সুবিধা কী? এখন তুমি এই প্রমিজের উপর RxJS এর হাজারো অপারেটর (filter, map) চালাতে পারবে, যেটা সাধারণ প্রমিজে করা কঠিন।

---

### **কুইজ: কোনটা ব্যবহার করব? 🤔**

১. তোমার কাছে ৫টা আলাদা ভেরিয়েবল আছে (`'A', 'B', 'C'`) -> **Use `of('A', 'B', 'C')`**
২. তোমার কাছে একটা অ্যারে আছে (`['A', 'B', 'C']`) এবং তুমি চাও অ্যারের ভেতরের উপাদানগুলো আলাদাভাবে আসুক -> **Use `from(['A', 'B', 'C'])`**

---

### **আজকের সারাংশ (Takeaway)**

*   **`of`**: যা দিবে তাই বের করবে। কমা দিয়ে ভ্যালু দাও।
*   **`from`**: জিনিসটাকে ভেঙে (Flatten) ভেতরের মালমসলা বের করবে। অ্যারে বা প্রমিজের জন্য সেরা।

স্বাগতম **Lesson 7**-এ! 👋

গত ক্লাসে আমরা `of` আর `from` দিয়ে ডাটার স্ট্রিম বানিয়েছি। এখন ধরো, তোমার পাইপ দিয়ে পানি আসছে, কিন্তু পানিটা ময়লা। তুমি কি সেই ময়লা পানি সরাসরি খাবে? না! তুমি পাইপের মাঝখানে একটা **ফিল্টার** লাগাবে।

RxJS এ এই কাজটাই করে **`.pipe()`**।

আজকের টপিক: **Pipe - পানির লাইনের মিস্ত্রি (Pipeable Operators)** 🔧

---

### **Pipe আসলে কী?**

`pipe` হলো একটা চ্যানেল বা সুরঙ্গ, যার এক পাশ দিয়ে ডাটা ঢোকে, মাঝখানে অনেক কাটাকুটি-মডিফিকেশন হয়, আর অন্য পাশ দিয়ে ফ্রেশ ডাটা বের হয়।

তুমি যখন `observable.subscribe()` করো, তার ঠিক আগেই `.pipe()` বসাতে হয়।

**বাস্তব উদাহরণ:**
1.  **নদীর পানি (Source Observable)**
2.  **Pipe এর ভেতর:**
    *   ধাপ ১: ছাঁকনি দিয়ে ময়লা ফেলা (Filter Operator)
    *   ধাপ ২: পানি ফোটানো (Map Operator)
    *   ধাপ ৩: বোতলে ভরা (Another Operator)
3.  **বিশুদ্ধ পানি (Subscribed Data)**

---

### **Pipe ছাড়া জীবন যেমন (Boring Code) 😩**

ধরো আমাদের একটা স্ট্রিম আছে যা ১ থেকে ৫ পর্যন্ত সংখ্যা দেয়। আমরা চাই শুধু জোড় সংখ্যাগুলোকে দ্বিগুণ করতে।

RxJS এর অপারেটর ছাড়া এটা করতে গেলে `subscribe` এর ভেতরে লজিক লিখতে হতো:

```javascript
import { of } from 'rxjs';

const numbers$ = of(1, 2, 3, 4, 5);

numbers$.subscribe(n => {
  if (n % 2 === 0) { // ফিল্টার লজিক
    const result = n * 2; // ম্যাপ লজিক
    console.log(result);
  }
});
// এটা কাজ করে, কিন্তু RxJS এর স্টাইল হলো লজিক আলাদা রাখা।
```

---

### **Pipe দিয়ে জীবন যেমন (Smart Code) 😎**

এখন আমরা `pipe` ব্যবহার করব। এর জন্য আমাদের দুটি অপারেটর লাগবে (এগুলো আমরা পরের ক্লাসে বিস্তারিত শিখব, এখন জাস্ট সিনট্যাক্স দেখো):
1.  `filter`: যেটা শর্ত চেক করে।
2.  `map`: যেটা ডাটা চেঞ্জ করে।

```javascript
import { of } from 'rxjs';
import { map, filter } from 'rxjs/operators'; // অপারেটর ইমপোর্ট করতে হয়

const numbers$ = of(1, 2, 3, 4, 5);

// পাইপ লাইনের কাজ শুরু
const processedNumbers$ = numbers$.pipe(
  filter(n => n % 2 === 0), // ১. শুধু জোড় সংখ্যা পাস করো (2, 4)
  map(n => n * 2),          // ২. যা এসেছে তাকে দ্বিগুণ করো (4, 8)
  map(n => n + ' টাকা')      // ৩. শেষে 'টাকা' স্ট্রিং যোগ করো
);

// এখন সাবস্ক্রাইব করো
processedNumbers$.subscribe(val => console.log(val));
```

**আউটপুট:**
```
4 টাকা
8 টাকা
```

---

### **Pipe কেন ব্যবহার করব?**

১. **Clean Code:** তোমার বিজনেস লজিক `subscribe` এর ভেতর খিচুড়ি না পাকিয়ে আলাদা থাকে।
২. **Reusability:** তুমি এই পাইপলাইনটা চাইলে অন্য জায়গায় কপি-পেস্ট করতে পারো।
৩. **Chaining:** তুমি একটার পর একটা যত খুশি অপারেটর লাগাতে পারো (LEGO গেমের মতো)।

---

### **Pipe এর ভিজ্যুয়াল ডায়াগ্রাম**

```
Source Data: 1, 2, 3, 4, 5
      |
      V
[ PIPE শুরু ]
      |
   filter(জোড় সংখ্যা?) -> 1 বাদ, 3 বাদ, 5 বাদ। পাস হলো: 2, 4
      |
   map(দ্বিগুণ করো) -> 2 হয়ে গেল 4, 4 হয়ে গেল 8
      |
[ PIPE শেষ ]
      |
      V
Subscriber পায়: 4, 8
```

---

### **আজকের সারাংশ (Takeaway)**

*   Observable থেকে ডাটা বের হয়ে `subscribe` এ পৌঁছানোর আগে মাঝপথে কিছু করতে চাইলে `.pipe()` ব্যবহার করতে হয়।
*   `pipe` এর ভেতরে আমরা কমা (`,`) দিয়ে একটার পর একটা অপারেটর বসাই।
*   ডাটা উপর থেকে নিচে প্রসেস হয়ে নামে।

স্বাগতম **Lesson 8**-এ! 👋

গত ক্লাসে আমরা পাইপলাইন বসিয়েছি। আজ আমরা পাইপের প্রথম এবং সবচেয়ে জনপ্রিয় যন্ত্রটা চালাব—সেটা হলো **`map` Operator**।

আজকের টপিক: **Map Operator - কাঁচা আম থেকে আচার** 🥭➡️🏺

---

### **Map আসলে কী করে?**

জাভাস্ক্রিপ্ট এর Array `map` মেথডটা মনে আছে?
*   ইনপুট নেয় একটা অ্যারে `[1, 2, 3]`
*   প্রত্যেককে ১০ দিয়ে গুণ করে `[10, 20, 30]` রিটার্ন করে।

RxJS এর `map` অপারেটর ঠিক একই কাজ করে, কিন্তু **Stream** এর জন্য।
স্ট্রিম দিয়ে যা আসবে, `map` সেটাকে মডিফাই করে বা রূপান্তর করে ছেড়ে দিবে।

**সহজ উদাহরণ:**
*   ইনপুট: **"মুরগি"** 🐔 -> Map(ফ্রাই করো) -> আউটপুট: **"চিকেন ফ্রাই"** 🍗
*   ইনপুট: **"গম"** 🌾 -> Map(মেশিনে দাও) -> আউটপুট: **"আটা"** 🍚

---

### **কোড করি: কাঁচা আম থেকে আচার**

ধরো সার্ভার থেকে বা ইউজারের কাছ থেকে ডাটা আসছে। কিন্তু ডাটাটা র (Raw) ফরম্যাটে আছে। সেটাকে সুন্দর করে সাজানো দরকার।

```javascript
import { of } from 'rxjs';
import { map } from 'rxjs/operators';

// সোর্স: কাঁচা নামের লিস্ট
const names$ = of('rahim', 'karim', 'jobbar');

names$.pipe(
  // ১. নামের প্রথম অক্ষর বড় হাতের করা (Capitalize)
  map(name => {
    // "rahim" -> "R" + "ahim" -> "Rahim"
    return name.charAt(0).toUpperCase() + name.slice(1);
  }),
  
  // ২. নামের আগে "Mr." যোগ করা
  map(capitalizedName => `Mr. ${capitalizedName}`)
)
.subscribe(val => console.log(val));
```

**আউটপুট:**
```
Mr. Rahim
Mr. Karim
Mr. Jobbar
```

### **রিয়েল লাইফ সিনারিও: API Data Formating 🌐**

ধরো তুমি একটা API কল করেছ। API তোমাকে আজাইরা অনেক ডাটা দিয়েছে, কিন্তু তোমার শুধু `name` আর `age` দরকার।

**API Response (যা আসছে):**
```json
{
  "id": 101,
  "name": "Shakib Al Hasan",
  "profession": "Cricketer",
  "age": 35,
  "country": "BD"
}
```

**আমাদের দরকার:** শুধু নাম আর বয়স।

```javascript
import { from } from 'rxjs'; // of দিলে অবজেক্টটা পুরোটা আসতো, from দিলে যদি অ্যারে থাকতো...
// এখানে আমরা of ব্যবহার করব কারণ এটা একটা সিঙ্গেল অবজেক্ট রেসপন্স
import { of } from 'rxjs';
import { map } from 'rxjs/operators';

const apiResponse = {
  id: 101,
  name: "Shakib Al Hasan",
  profession: "Cricketer",
  age: 35,
  country: "BD"
};

const user$ = of(apiResponse).pipe(
  // পুরো অবজেক্ট থেকে শুধু দরকারি অংশ নেওয়া
  map(data => {
    return {
      userName: data.name,
      userAge: data.age,
      message: `${data.name} is a Legend!`
    };
  })
);

user$.subscribe(user => console.log(user));
```

**আউটপুট (Subscriber যা পাবে):**
```javascript
{
  userName: "Shakib Al Hasan",
  userAge: 35,
  message: "Shakib Al Hasan is a Legend!"
}
```

                    |
               map( x => x * 10 )

### **কুইজ টাইম 🧠**

যদি ইনপুট হয় `of(new Date())` অর্থাৎ বর্তমান সময়, আর তুমি চাও ইউজারকে শুধু "ঘণ্টা" (Hour) দেখাতে। `map` এ কী লিখবে?

```javascript
map(date => date.getHours())
```
সিম্পল! যা আসবে, সেটাকে প্রসেস করে যা রিটার্ন করবে, পরের জন সেটাই পাবে।

### **আজকের সারাংশ (Takeaway)**

*   **`map`** হলো ট্রান্সফরমার। ইনপুট একরকম, আউটপুট অন্যরকম।
*   ডাটাকে প্রসেস করার জন্য, ক্যালকুলেশন করার জন্য বা অবজেক্টের শেপ চেঞ্জ করার জন্য `map` ব্যবহার করা হয়।
*   এটা সোর্স স্ট্রিমের ডাটা সংখ্যা কমায় না (৩টা ইনপুট আসলে ৩টাই আউটপুট হবে), শুধু ডাটার চেহারা পাল্টে দেয়।

স্বাগতম **Lesson 9**-এ! 👋

গত ক্লাসে আমরা `map` দিয়ে ডাটাকে সাজিয়েছি। কিন্তু সবসময় সব ডাটা আমাদের দরকার হয় না। যেমন চায়ের পাতা আমরা খাই না, শুধু লিকারটা খাই। তাই আমাদের একটা ছাঁকনি দরকার।

আজকের টপিক: **Filter Operator - ছাঁকনি দিয়ে চা ছাঁকা** ☕

---

### **Filter আসলে কী করে?**

`filter` অপারেটর হলো একটা দারোয়ান (Guard)। সে প্রত্যেকটা ডাটাকে চেক করে।
*   যদি কন্ডিশন `true` হয় -> গেট খুলে দেয় (পাস)। ✅
*   যদি কন্ডিশন `false` হয় -> লাথি মেরে বের করে দেয় (ব্লক)। ❌

**সহজ উদাহরণ:**
*   ইনপুট: **[ভালো আপেল, পচা আপেল, ভালো আপেল]**
*   Filter Condition: **আপেল কি ভালো?**
*   আউটপুট: **[ভালো আপেল, ভালো আপেল]** (পচাটা ভ্যানিশ!)

---

### **কোড করি: শুধু জোড় সংখ্যা চাই**

আমাদের স্ট্রিম থেকে ১, ২, ৩, ৪, ৫ আসছে। আমরা বেজোড় সংখ্যাগুলোকে গেটে আটকে দিব।

```javascript
import { of } from 'rxjs';
import { filter } from 'rxjs/operators';

const numbers$ = of(1, 2, 3, 4, 5, 6);

numbers$.pipe(
  // শর্ত: সংখ্যাটি কি ২ দিয়ে ভাগ করলে ভাগশেষ ০ থাকে?
  filter(n => n % 2 === 0)
)
.subscribe(val => console.log(`পেলাম: ${val}`));
```

**আউটপুট:**
```
পেলাম: 2
পেলাম: 4
পেলাম: 6
```
*(১, ৩, ৫ গুম হয়ে গেছে!)*

---

### **রিয়েল লাইফ সিনারিও: ১৮+ কন্টেন্ট 🔞**

ধরো তোমার সাইটে ইউজাররা লগইন করছে। তুমি শুধু তাদেরকেই ওয়েলকাম জানাবে যাদের বয়স ১৮ বা তার বেশি।

```javascript
import { from } from 'rxjs';
import { filter, map } from 'rxjs/operators';

const users = [
  { name: 'Raju', age: 12 },
  { name: 'Mina', age: 25 },
  { name: 'Mithu', age: 16 },
  { name: 'Boss', age: 30 }
];

const adultUsers$ = from(users).pipe(
  // ১. দারোয়ান চেক করছে বয়স ১৮+ কিনা
  filter(user => user.age >= 18),
  
  // ২. ম্যাপ দিয়ে ওয়েলকাম মেসেজ বানাচ্ছি
  map(user => `${user.name} ভাই, ওয়েলকাম!`)
);

adultUsers$.subscribe(msg => console.log(msg));
```

**আউটপুট:**
```
Mina ভাই, ওয়েলকাম!
Boss ভাই, ওয়েলকাম!
```
*(রাজু আর মিঠু পিচ্চি বলে বাদ পড়ে গেছে)* 😂

---

### **Filter vs Map (পার্থক্য বুঝো)**

*   **Map:** ডাটার **চেহারা** চেঞ্জ করে। ইনপুট ৫টা হলে আউটপুটও ৫টাই হবে (যদি না এরর হয়)।
*   **Filter:** ডাটার **সংখ্যা** কমায়। ইনপুট ৫টা হলে আউটপুট ০ থেকে ৫ এর মধ্যে যেকোনো কিছু হতে পারে। কিন্তু ডাটার চেহারা চেঞ্জ করে না।

---

### **Visualizing Filter** 👁️

```
Source Stream:  --- 1 --- 2 --- 3 --- 4 --->
                    |
               filter( x > 2 )  (২ এর চেয়ে বড় যারা)
                    |
Output Stream:  --- . --- . --- 3 --- 4 --->
```

---

### **কুইজ টাইম 🧠**

যদি ইনপুট হয় `of(null, 'Hello', undefined, 'World', '')` এবং তুমি চাও শুধু ভ্যালিড টেক্সট আসুক। `filter` এ কী লিখবে?

```javascript
filter(val => val) // Truthy value চেক করবে
```
এটা `null`, `undefined`, `empty string` সব বাদ দিয়ে দিবে। আউটপুট হবে শুধু `'Hello'` এবং `'World'`।

---

### **আজকের সারাংশ (Takeaway)**

*   **`filter`** অপারেটর বুলিয়ান (true/false) রিটার্ন আশা করে।
*   `true` হলে ডাটা পাস হবে, `false` হলে ডাটা হারিয়ে যাবে।
*   অপ্রয়োজনীয় ডাটা বা গার্বেজ ক্লিন করতে এটা বেস্ট।

স্বাগতম **Lesson 10**-এ! 👋

আমরা `map` দিয়ে ডাটা চেঞ্জ করেছি, `filter` দিয়ে ডাটা আটকেছি। কিন্তু মাঝে মাঝে আমাদের ডাটা চেঞ্জ করার দরকার নেই, শুধু দেখতে হয় **"আসলে পাইপের ভেতর দিয়ে কী যাচ্ছে?"** অথবা কোনো সাইড এফেক্ট (Side Effect) ঘটাতে হয়।

আজকের টপিক: **Tap Operator - গোয়েন্দাগিরি (Side Effects)** 🕵️‍♂️

---

### **Tap আসলে কী?**

`tap` হলো এমন এক অপারেটর যে স্ট্রিমের ডাটা **স্পর্শ করে না, শুধু দেখে**।
মনে করো পাইপলাইন দিয়ে পানি যাচ্ছে। `map` পানিকে জুস বানাচ্ছে, `filter` ময়লা পানি ফেলে দিচ্ছে। আর `tap` হলো পাইপের কাঁচের জানাল দিয়ে তাকিয়ে থাকা।

সে ডাটা মডিফাই করে না, আটকাও দেয় না। সে শুধু ইনপুট নেয়, কিছু একটা করে (যেমন লগ করা), আর সেইম ইনপুটটাকেই আউটপুট হিসেবে পাস করে দেয়।

**কাজ:**
১. ডিবাগিং করা (`console.log`)।
২. বাইরের কোনো ভেরিয়েবল চেঞ্জ করা।
৩. DOM আপডেট বা এলার্ট দেওয়া।

---

### **কোড করি: গোয়েন্দা গিরি 🕵️‍♂️**

ধরো আমরা ম্যাপ এবং ফিল্টার ব্যবহার করছি, কিন্তু মাঝখানে কনফিউজড হয়ে গেছি—আসলে ফিল্টার হওয়ার পর কী থাকছে?

```javascript
import { of } from 'rxjs';
import { map, filter, tap } from 'rxjs/operators';

of(1, 2, 3, 4, 5).pipe(
  
  // ১. শুরুতেই দেখব কী কী ঢুকছে
  tap(n => console.log(`শুরুতে ছিল: ${n}`)),

  // ২. ফিল্টার করলাম (বিজোড় সংখ্যা বাদ)
  filter(n => n % 2 === 0),

  // ৩. ফিল্টার হওয়ার পর কে কে টিকে থাকল? গোয়েন্দা লাগাও!
  tap(n => console.log(`ফিল্টারের পর টিকে আছে: ${n}`)),

  // ৪. ম্যাপ করলাম (দ্বিগুণ)
  map(n => n * 2),

  // ৫. ম্যাপের পর অবস্থা কী?
  tap(n => console.log(`ম্যাপের পর সাইজ: ${n}`))

).subscribe(finalVal => console.log(`ফাইনাল আউটপুট: ${finalVal}`));
```

**আউটপুট (Console):**
```
শুরুতে ছিল: 1
শুরুতে ছিল: 2
ফিল্টারের পর টিকে আছে: 2
ম্যাপের পর সাইজ: 4
ফাইনাল আউটপুট: 4

শুরুতে ছিল: 3
... (৩ বাদ যাবে)

শুরুতে ছিল: 4
ফিল্টারের পর টিকে আছে: 4
ম্যাপের পর সাইজ: 8
ফাইনাল আউটপুট: 8
...
```

### **রিয়েল লাইফ সিনারিও: লোডিং স্পিনার ⏳**

UI ডিজাইনার হিসেবে এটা তোমার খুব লাগবে। API কল করার সময় লোডিং দেখাবে, ডাটা আসলে লোডিং বন্ধ করবে।

```javascript
// ফেক লোডিং ফাংশন
const showSpinner = () => console.log('Spinner: ON 🌀');
const hideSpinner = () => console.log('Spinner: OFF ✅');

import { of } from 'rxjs';
import { delay, tap } from 'rxjs/operators';

// API কল সিমুলেশন
const apiCall$ = of('User Data').pipe(
  delay(2000) // ২ সেকেন্ড দেরি হবে (নেটওয়ার্ক ল্যাগ)
);

// স্ট্রিম সেটআপ
const dataStream$ = apiCall$.pipe(
  // ১. সাবস্ক্রাইব করার সাথে সাথেই স্পিনার অন
  // নোট: tap এখানে কাজ করবে না কারণ ডাটা আসার আগেই অন করতে হবে।
  // সাধারণত আমরা ম্যানুয়ালি অন করি সাবস্ক্রাইব এর আগে, অথবা 'defer' ইউজ করি।
  // কিন্তু ডাটা আসার ঠিক আগ মুহূর্ত বা পরে কিছু করতে tap সেরা।
  
  tap(() => console.log('ডাটা এসে গেছে! প্রসেসিং শুরু...')),
  
  // ডাটা আসার পর স্পিনার অফ করার জন্য tap পারফেক্ট
  tap(() => hideSpinner()) 
);

// মেইন ফ্লো
showSpinner(); // ম্যানুয়ালি অন করলাম
dataStream$.subscribe(val => console.log('UI Update:', val));
```

*(নোট: `finalize` অপারেটর স্পিনার বন্ধ করার জন্য আরও ভালো, কিন্তু `tap` দিয়েও করা যায় যখন ডাটা সাকসেসফুলি আসে)*

---

### **ভুল ধারণা (Common Mistake)**

অনেকে `tap` এর ভেতর রিটার্ন করে ডাটা চেঞ্জ করতে চায়।

```javascript
// ভুল! ❌
tap(n => {
   return n * 10; // লাভ নাই! tap রিটার্ন ভ্যালু ইগনোর করে।
})

// সঠিক ✅
map(n => n * 10)
```

---

### **আজকের সারাংশ (Takeaway)**

*   **`tap`** ডাটা প্রবাহে কোনো বাধা দেয় না বা পরিবর্তন করে না।
*   ডিবাগিং এর জন্য `console.log` করার সেরা জায়গা হলো `tap`।
*   একে **Side Effect** অপারেটর বলা হয় (যেমন: ডাটা আসলে একটা সাউন্ড প্লে করা)।
