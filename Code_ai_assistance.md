### 🧰 Open-Source AI Coding Agents

1. **[Cline](https://cline.bot/?utm_source=chatgpt.com)**  
    An open-source AI coding agent designed for terminal environments. It offers transparent resource usage, executes commands, reads outputs, and debugs errors directly in your terminal. Cline runs entirely on your machine, ensuring data privacy and compliance with enterprise security standards. [Cline](https://cline.bot/?utm_source=chatgpt.com)
    
2. **[Gemini CLI](https://blog.google/technology/developers/introducing-gemini-cli-open-source-ai-agent/?utm_source=chatgpt.com)**  
    Developed by Google, Gemini CLI integrates the Gemini 2.5 Pro model into your terminal. It supports tasks like coding, problem-solving, content creation, and task management using natural language prompts. The tool is free for individual developers with generous usage limits. [blog.google](https://blog.google/technology/developers/introducing-gemini-cli-open-source-ai-agent/?utm_source=chatgpt.com)
    
3. **[OpenCode](https://opencode.ai/?utm_source=chatgpt.com)**  
    A terminal-based AI agent that assists in writing and running code directly from the terminal. It features a responsive, native, themeable terminal UI and supports multiple sessions, enabling parallel agent operations on the same project. [OpenCode](https://opencode.ai/?utm_source=chatgpt.com)
    
4. **[Goose](https://github.com/block/goose?utm_source=chatgpt.com)**  
    An extensible AI agent capable of automating complex development tasks, including building entire projects, writing and executing code, debugging failures, and orchestrating workflows. Goose operates on your machine, providing full control over your development environment. [GitHub](https://github.com/block/goose?utm_source=chatgpt.com)
    
5. **[Agent S](https://github.com/simular-ai/Agent-S?utm_source=chatgpt.com)**  
    An open-source framework designed to enable autonomous interaction with computers through an Agent-Computer Interface. It aims to build intelligent GUI agents that can learn from past experiences and perform complex tasks autonomously. [GitHub](https://github.com/simular-ai/Agent-S?utm_source=chatgpt.com)
