
**21.1 Gradient Boosting - Introduction**

**Gradient Boosting কী?**

Gradient Boosting একটি **ensemble learning technique**, যেখানে একাধিক **weak learner** (সাধারণত shallow decision tree) ধাপে ধাপে যুক্ত হয়ে একটি শক্তিশালী model তৈরি করে। এখানে মূল ধারণাটি হলো—

> **প্রতিটি নতুন model আগের model-এর করা ভুল (error) থেকে শেখে।**

অর্থাৎ model একবারে perfect হওয়ার চেষ্টা করে না, বরং **step by step improvement** করে।

**Ensemble ধারণার সাথে তুলনা**

*   **Random Forest**
*   প্রতিটি tree আলাদা ভাবে train হয়। এক tree অন্য tree-এর ভুল থেকে শেখে না।
*   **AdaBoost**
*   ভুল prediction করা data point-কে বেশি গুরুত্ব (weight) দেয়।
*   **Gradient Boosting**
*   ভুল prediction গুলোকে **numerically measure** করে এবং সেই error কমানোর জন্য পরবর্তী model তৈরি করে।

এখানে error কে একটি **loss function** দিয়ে পরিমাপ করা হয়।

**Core Intuition**

Gradient Boosting-এর মূল intuition খুব সহজ:

1.  প্রথমে একটি খুব simple model দিয়ে prediction করা হয়
2.  prediction কতটা ভুল হয়েছে তা হিসাব করা হয়
3.  সেই ভুল ঠিক করার জন্য একটি নতুন model শেখানো হয়
4.  আগের model-এর সাথে নতুন model যুক্ত করা হয়
5.  এই process বারবার repeat হয়

প্রতিটি ধাপে prediction একটু একটু করে improve হয়।

**Step-by-Step Improvement ধারণা**

Gradient Boosting কখনোই এক ধাপে বড় correction করে না।

*   ছোট correction
*   controlled update
*   learning rate দিয়ে নিয়ন্ত্রণ

এই কারণেই Gradient Boosting খুব powerful কিন্তু একই সাথে sensitive হতে পারে।
