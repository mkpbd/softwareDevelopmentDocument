### **ভূমিকা**

ডেটা বিশ্লেষণ বা মেশিন লার্নিং মডেল তৈরি করার সময় অনেক সময় দেখা যায় — বিভিন্ন ফিচারের মান (value) একে অপরের তুলনায় অনেক বেশি বা কম।

যেমন: কারও উচ্চতা সেন্টিমিটারে (১৫০–১৯০), আবার কারও ওজন কিলোগ্রামে (৫০–৯০)।

এই পার্থক্যের কারণে মডেলটি কোনো ফিচারকে অতিরিক্ত গুরুত্ব দিতে পারে।

এই সমস্যার সমাধানই হলো **Scaling** — অর্থাৎ, সব মানকে একটি নির্দিষ্ট পরিসরে নিয়ে আসা।

## **Standardization (Z-score Scaling)**

**Standardization** এমন একটি স্কেলিং পদ্ধতি যেখানে প্রতিটি মানকে এমনভাবে পরিবর্তন করা হয় যেন পুরো ডেটার গড় (mean) হয় **০**, এবং স্ট্যান্ডার্ড ডেভিয়েশন (standard deviation) হয় **১**।

**Formula:**
```
z = (x − mean) / standard deviation
```

অর্থাৎ, প্রতিটি ডেটা পয়েন্ট (x) থেকে গড়কে বাদ দেওয়া হয়, তারপর সেটিকে স্ট্যান্ডার্ড ডেভিয়েশন দ্বারা ভাগ করা হয়।

এর ফলে আমরা জানতে পারি, একটি মান গড় থেকে কত **standard deviation** দূরে অবস্থান করছে।

### **বৈশিষ্ট্য**

*   ডেটাকে **শূন্যে কেন্দ্রিত (centered at zero)** করে।
*   ফিচারগুলোর ভ্যারিয়েন্স একরকম করে দেয়।
*   বেশিরভাগ মেশিন লার্নিং অ্যালগরিদম (যেমনঃ Logistic Regression, KNN, PCA) এইভাবে স্কেল করা ডেটায় ভালো কাজ করে।

### **উদাহরণ: Z-score Scaling প্রয়োগ**

ধরা যাক, নিচের ডেটা রয়েছে—

| ব্যাক্তি | উচ্চতা (cm) | ওজন (kg) |
| :--- | :--- | :--- |
| A | 150 | 50 |
| B | 160 | 60 |
| C | 170 | 70 |
| D | 180 | 80 |
| E | 190 | 90 |

এখন, যদি আমরা উচ্চতার জন্য **mean (গড়)** = 170 এবং **standard deviation (σ)** = 15 ধরি,
তাহলে **Z-score** হবে:

```
z = (x − μ) / σ
```

| ব্যাক্তি | উচ্চতা (cm) | Z-score (উচ্চতা) |
| :--- | :--- | :--- |
| A | 150 | (150−170)/15 = -1.33 |
| B | 160 | (160−170)/15 = -0.67 |
| C | 170 | (170−170)/15 = 0 |
| D | 180 | (180−170)/15 = 0.67 |
| E | 190 | (190−170)/15 = 1.33 |

এভাবেই প্রতিটি মানকে স্ট্যান্ডার্ড স্কেলে রূপান্তর করা যায়।

### **কখন কোনটি ব্যবহার করবেন**

| Scaling Method | কখন ব্যবহার করবেন | অসুবিধা |
| :--- | :--- | :--- |
| Standardization | ডেটা যদি Gaussian বা Normal Distribution হয় | স্কেলের কোনো নির্দিষ্ট সীমা থাকে না |
| Min–Max Scaling | নির্দিষ্ট রেঞ্জে মান রাখার প্রয়োজন হলে (যেমন নিউরাল নেটওয়ার্ক) | Outlier থাকলে ফল বিকৃত হতে পারে |

### **সারসংক্ষেপ**

*   **Standardization:** ডেটাকে কেন্দ্র করে ০ mean ও ১ standard deviation-এ আনা।
*   **Min–Max Scaling:** ডেটাকে ০–১ রেঞ্জে সীমাবদ্ধ করা।
*   স্কেলিং করার মূল উদ্দেশ্য হলো — **সব ফিচারকে সমান গুরুত্ব দেওয়া** যাতে মডেলটি সঠিকভাবে কাজ করে।

### **প্রয়োজনীয় লাইব্রেরি**

*   **numpy:** গাণিতিক গণনার জন্য।
*   **matplotlib:** গ্রাফ আঁকার জন্য।

### **ডেটাসেট তৈরি করা**

আমরা একটি ছোট DataFrame তৈরি করব যেখানে দুটি ফিচার থাকবে — **height (h)** এবং **weight (w)**।

```python
df = pd.DataFrame({
    'h': [150, 160, 170, 185, 190],
    'w': [50, 58, 70, 80, 90]
})
df
```

এতে আমাদের একটি টেবিল তৈরি হবে:

### **গড় (Mean) ও স্ট্যান্ডার্ড ডেভিয়েশন (Standard Deviation) নির্ণয়**

এখন আমরা প্রতিটি কলামের গড় ও স্ট্যান্ডার্ড ডেভিয়েশন বের করব।

```python
m = df.mean()
s = df.std()

print("Mean values:\n", m)
print("\nStandard Deviation:\n", s)
```

এগুলো পরবর্তী ধাপে Z-score বের করার জন্য ব্যবহার করা হবে।

### **Z-score (Standardization) গণনা**

**সূত্র:**
```
z = (x − mean) / standard deviation
```

Python এ এটি খুব সহজভাবে করা যায়:

```python
z = (df - m) / s
z.round(2)
```

এখানে প্রতিটি মান গড় থেকে কত স্ট্যান্ডার্ড ডেভিয়েশন দূরে অবস্থান করছে তা বোঝায়।
`round(2)` ব্যবহার করা হয়েছে মানগুলোকে দুই দশমিক পর্যন্ত দেখানোর জন্য।
ফলাফল হবে একটি নতুন টেবিল, যেখানে স্কেল করা (standardized) মানগুলো থাকবে।

### **ফলাফল ভিজুয়ালাইজেশন (Bar Plot)**

এখন আমরা স্ট্যান্ডার্ডাইজড মানগুলোকে বার চার্ট আকারে দেখাবো।

```python
z.plot(kind='bar')
plt.title("Z scaling Features")
plt.xlabel("Index")
plt.ylabel("Z value")
plt.show()
```

এই গ্রাফে প্রতিটি রো বা ইনডেক্সের জন্য Z-score দেখানো হবে, যা ডেটার মানগুলোর পার্থক্যকে স্পষ্ট করে তুলবে।

### **সারসংক্ষেপ**

*   **Standardization** ডেটাকে mean = 0 এবং standard deviation = 1 এ রূপান্তর করে।
*   Python-এ এটি **pandas** দিয়েই সহজে করা যায় — কোনো বিশেষ লাইব্রেরির প্রয়োজন হয় না।
*   **Visualization** আমাদের বুঝতে সাহায্য করে কোন মানগুলো গড়ের উপরে বা নিচে অবস্থান করছে।

### **১. ভূমিকা**

ডেটা স্কেলিংয়ের আরেকটি বহুল ব্যবহৃত পদ্ধতি হলো **Min–Max Scaling**।

এটি এমন একটি প্রক্রিয়া, যেখানে ডেটার সর্বনিম্ন মান (minimum) এবং সর্বোচ্চ মান (maximum) ব্যবহার করে সকল মানকে একটি নির্দিষ্ট সীমার মধ্যে, সাধারণত **[0, 1]**, নিয়ে আসা হয়।

এই পদ্ধতিকে **Rescaling** নামেও ডাকা হয়।

### **২. সূত্র (Formula)**

```
x' = (x − min) / (max − min)
```

এখানে,

*   **x** = মূল মান (original value)
*   **min** = ডেটার সর্বনিম্ন মান
*   **max** = ডেটার সর্বোচ্চ মান
*   **x'** = স্কেল করা নতুন মান

এই সূত্র অনুযায়ী, **সর্বনিম্ন মান হবে 0**, আর **সর্বোচ্চ মান হবে 1**।

### **৩. বৈশিষ্ট্য**

*   সব মানকে **[0, 1]** রেঞ্জে সীমাবদ্ধ করে।
*   **bounded input** (যেমন, ইমেজ পিক্সেল ভ্যালু 0–255) এর ক্ষেত্রে খুবই কার্যকর।
*   **Outlier** বা অস্বাভাবিক বড় বা ছোট মানের কারণে ফলাফল বিকৃত হতে পারে, তাই প্রয়োগের সময় সতর্ক থাকতে হয়।

### **৪. উদাহরণ: ওজন স্কেলিং**

ধরা যাক, আমাদের কাছে ৫ জন মানুষের ওজন (Weight) রয়েছে: 50, 60, 70, 80, 90।

এখানে,
**min = 50**
**max = 90**

এখন আমরা প্রতিটি ওজনের জন্য `x' = (x − 50) / (90 − 50)` সূত্র প্রয়োগ করব।

| ব্যক্তি | ওজন (Kg) (x) | স্কেল করা মান (x') |
| :--- | :--- | :--- |
| A | 50 | (50−50)/(90−50) = 0.00 |
| B | 60 | (60−50)/(90−50) = 0.25 |
| C | 70 | (70−50)/(90−50) = 0.50 |
| D | 80 | (80−50)/(90−50) = 0.75 |
| E | 90 | (90−50)/(90−50) = 1.00 |

অর্থাৎ, ওজনগুলো এখন **0 থেকে 1** রেঞ্জে পুনঃস্কেল করা হয়েছে।

### **৫. সারসংক্ষেপ**

*   **Min–Max Scaling** মানে হলো ডেটাকে একটি নির্দিষ্ট রেঞ্জে আনা, সাধারণত **[0, 1]**।
*   এটি **bounded inputs** এর ক্ষেত্রে ভালো কাজ করে, যেমন নিউরাল নেটওয়ার্কে ইনপুট মানগুলো নরমালাইজ করা।
*   তবে ডেটায় যদি **outlier** থাকে, তাহলে স্কেলিংয়ের মান অনেকটা বিকৃত হতে পারে।

### **۱. ভূমিকা**

পূর্বের মডিউলে আমরা শিখেছি **Min–Max Scaling** এর ধারণা এবং কীভাবে এটি একটি মানকে **[0, 1]** রেঞ্জে নিয়ে আসে।

এখন আমরা Python ব্যবহার করে বাস্তবে এটি প্রয়োগ করব, ধাপে ধাপে পুরো প্রক্রিয়াটি দেখব এবং শেষে এর ফলাফল একটি গ্রাফের মাধ্যমে ভিজুয়ালাইজ করব।

### **৫. ধাপ–২: মানগুলোকে শূন্য থেকে শুরু করা (Shift to Zero)**

এখন প্রতিটি মান থেকে তার **minimum** মানটি বাদ দেব। এর ফলে সব মান ০ থেকে শুরু করবে।

*   **Python** এ শুধুমাত্র কয়েকটি লাইন কোডের মাধ্যমেই এই প্রক্রিয়া সম্পন্ন করা যায়।
*   ভিজুয়ালাইজেশনের মাধ্যমে আমরা সহজে স্কেলিংয়ের প্রভাব পর্যবেক্ষণ করতে পারি।

# Robust Scaling

Robust Scaling হলো এমন একটি স্কেলিং পদ্ধতি যা **outliers (অস্বাভাবিক বা অতিরিক্ত বড়/ছোট মান)** এর প্রভাব কমিয়ে ডেটাকে স্বাভাবিকভাবে স্কেল করতে ব্যবহৃত হয়।

এই পদ্ধতিতে mean (গড়) এবং standard deviation এর পরিবর্তে **median (মধ্য মান)** এবং **IQR (Interquartile Range)** ব্যবহার করা হয়।

#### **সূত্র (Formula)**

x′ = (x − median) / IQR

যেখানে,
**IQR = Q3 − Q1**

*   **Q1 (1st Quartile):** ডেটার নিচের ২৫% অংশের মান পর্যন্ত
*   **Q3 (3rd Quartile):** ডেটার উপরের ২৫% অংশের মান পর্যন্ত

অর্থাৎ IQR আমাদের বলে দেয় ডেটার মূল অংশটি কতটা বিস্তৃত (spread)।

#### **কেন Robust Scaling ব্যবহার করা হয়**

Min–Max বা Standard Scaling পদ্ধতিতে যদি ডেটায় কোনো outlier থাকে, তাহলে সেটি পুরো ডেটার স্কেল নষ্ট করে দেয়।

কিন্তু Robust Scaling এ যেহেতু median ও IQR ব্যবহার করা হয়, তাই outlier এর প্রভাব অনেক কম পড়ে।

**উদাহরণ:**
ধরা যাক, আমরা নিচের ডেটা ব্যবহার করছি:
```
Person      Height(cm)      Weight(Kg)(x)
A             150               50
B             160               60
C             170               70
D             180               80
E             300               200
```

### **ধাপে ধাপে Robust Scaling গণনা**

#### **Step 1: Median নির্ণয়**
Weight কলামের মানগুলো: [50, 60, 70, 80, 200]
এখানে **Median = 70**

#### **Step 2: Q1 এবং Q3 নির্ণয়**
*   Q1 (25% পজিশন) = 60
*   Q3 (75% পজিশন) = 80

#### **Step 3: IQR নির্ণয়**
IQR = Q3 − Q1 = 80 − 60 = 20

#### **Step 4: প্রতিটি মানের Robust Scaled মান নির্ণয়**

| Person | Weight (x) | Median | IQR | Scaled (x′ = (x − median) / IQR) |
| :--- | :--- | :--- | :--- | :--- |
| A | 50 | 70 | 20 | (50 − 70)/20 = −1.0 |
| B | 60 | 70 | 20 | (60 − 70)/20 = −0.5 |
| C | 70 | 70 | 20 | (70 − 70)/20 = 0 |
| D | 80 | 70 | 20 | (80 − 70)/20 = +0.5 |
| E | 200 | 70 | 20 | (200 − 70)/20 = +6.5 |

#### **Step 5: বিশ্লেষণ**
*   দেখা যাচ্ছে, যদিও **E ব্যক্তির ওজন অনেক বেশি (200)**,
*   কিন্তু Robust Scaling এর ফলে অন্য মানগুলো খুব বেশি প্রভাবিত হয়নি।
*   Standard বা Min–Max Scaling ব্যবহার করলে 200 মানটি স্কেলকে অনেক বিকৃত করত,
*   কিন্তু এখানে median এবং IQR ব্যবহারের কারণে **মূল ডেটার ভারসাম্য বজায় থাকে**।

## **Nominal vs Ordinal**

**Nominal (কোনো ক্রম নেই):**
যেমন — City, Color, Species
এই বৈশিষ্ট্যগুলোর মধ্যে কোনো “বড়–ছোট” সম্পর্ক নেই।

**Ordinal (ক্রমযুক্ত):**
যেমন — Small → Medium → Large, Rating (Low → Medium → High)
এখানে মানগুলোর মধ্যে একটি নির্দিষ্ট ক্রম (Order) রয়েছে।

## **Encoding: One‐Hot বনাম Ordinal**

**One‐Hot Encoding:**
যখন বৈশিষ্ট্যের কোনো ক্রম নেই (Nominal data), তখন প্রতিটি মানের জন্য আলাদা কলাম তৈরি করা হয়।
উদাহরণ:
Color → Red, Blue, Green →
```
Red   Blue    Green
1     0       0
0     1       0
0     0       1
```

**Ordinal Encoding:**
যখন বৈশিষ্ট্যের ক্রম আছে (Ordinal data), তখন প্রতিটি মানকে একটি ক্রমিক সংখ্যা দেওয়া হয়।
উদাহরণ:
Size → Small=1, Medium=2, Large=3

### **সারাংশ**
*   **Robust Scaling** outlier প্রতিরোধী এবং skewed ডেটার জন্য উপযুক্ত।
*   এটি median ও IQR ব্যবহার করে স্কেল নির্ধারণ করে।
*   Nominal ও Ordinal ডেটার মধ্যে পার্থক্য বোঝা জরুরি, যাতে সঠিক encoding technique (One-Hot বা Ordinal) নির্বাচন করা যায়।

### **۱. ভূমিকা**

পূর্বের মডিউলে আমরা শিখেছি **Robust Scaling** কিভাবে কাজ করে।

এবার আমরা Python ব্যবহার করে বাস্তবে দেখব কিভাবে এটি প্রয়োগ করা যায়।

Robust Scaling ডেটার outlier এর প্রভাব কমিয়ে স্কেল নির্ধারণ করে।

### **২. লাইব্রেরি ইমপোর্ট ও ডেটাসেট তৈরি**


### **৩. ধাপ ১: Median, Quartiles, IQR নির্ণয়**

```python
md = df.median()
q1 = df.quantile(0.25)

print("\nIQR:\n", iqr)
```

প্রতিটি মান থেকে median বাদ দিয়ে ডেটা কেন্দ্রিত করা হয়:

### **৭. অন্যান্য স্কেলিং এর তুলনা (Optional)**

Python এ আমরা একসাথে Standardization (Z-score) এবং Min-Max Scaling করতে পারি:

```python
# Standardization / Z-score
m = df.mean()
s = df.std()
z = (df - m) / s

mn = df.min()

mm = (df - mn) / (mx - mn)
```

*   **Min-Max Scaling:** 0 থেকে 1 রেঞ্জে মান স্কেল করা
*   **Robust Scaling:** outlier প্রতিরোধী স্কেলিং

*   প্রতিটি category একটি আলাদা কলামে 0 বা 1 দ্বারা প্রকাশ করা হয়।

```python
d_color = pd.get_dummies(df["color"], prefix="C", dtype=int)
```

```python
df_encoded = pd.concat([df, d_color], axis=1)
```

### **১. ভূমিকা**

Ordinal Encoding হলো এমন একটি পদ্ধতি যেখানে **ordered বা ক্রমিক (ranked) ক্যাটেগরিকাল ভেরিয়েবল** কে numerical মানে রূপান্তর করা হয়।

*   প্রতিটি category কে একটি নির্দিষ্ট সংখ্যা দেওয়া হয়।
*   এটি **Ordinal features** যেমন Size, Rating ইত্যাদির জন্য ব্যবহারযোগ্য।

### **২. উদাহরণ**

```
id    color     size      price
1     red       Small     10
2     blue      Medium    12
3     green     Large     15
4     red       Medium    11
```

*   এখানে **size** একটি Ordinal variable।
*   **color** একটি Nominal variable।
*   **price** একটি numerical feature।

### **৩. Step 1: Order নির্ধারণ করা**

Ordinal feature - size এর জন্য আমরা নির্ধারণ করি ক্রম:

```
Small → 1
Medium → 2
Large → 3
```

### **৪. Step 2: Transformed Table**
```
id    color     size      price    Size_encode
1     red       Small     10       1
2     blue      Medium    12       2
3     green     Large     15       3
4     red       Medium    11       2
```
*   প্রতিটি size মান একটি নির্দিষ্ট integer দ্বারা প্রকাশ করা হলো।
*   এখন size numerical representation হিসেবে মডেলে ব্যবহার করা যাবে।

### **৫. Python Implementation**

```python
import pandas as pd

# Step 1: ডেটাসেট তৈরি
df = pd.DataFrame({
    "id": [1, 2, 3, 4],
    "color": ["red", "blue", "green", "red"],
    "size": ["Small", "Medium", "Large", "Medium"],
    "price": [10, 12, 15, 11]
})
df
```
ডেটা:
```
   id  color    size  price
0   1    red   Small     10
1   2   blue  Medium     12
2   3  green   Large     15
3   4    red  Medium     11
```

### **Step 2: Ordinal Order ঘোষণা করা**
```python
order = {"Small": 1, "Medium": 2, "Large": 3}
```

**ব্যাখ্যা:**
*   একটি dictionary তৈরি করা হলো যা size এর প্রতিটি মানকে integer হিসেবে মানায়।
*   Small=1, Medium=2, Large=3

### **Step 3: Mapping করা ও Column পরিবর্তন করা**
```python
df["size"] = df["size"].map(order).astype(int)
df
```

**ব্যাখ্যা:**
*   `map(order)` ফাংশন ব্যবহার করে প্রতিটি size মানকে dictionary অনুযায়ী রূপান্তর করা হলো।
*   `.astype(int)` ব্যবহার করে নিশ্চিত করা হলো যে column এর dtype integer হবে।

ফলাফল:
```
   id  color  size  price
0   1    red     1     10
1   2   blue     2     12
2   3  green     3     15
3   4    red     2     11
```

### **৬. সারসংক্ষেপ**
*   **Ordinal Encoding** Ordered categorical variable কে numerical মানে রূপান্তর করে।
*   প্রতিটি category কে integer মান দেওয়া হয় যা ক্রম (order) নির্দেশ করে।
*   Python এ `map()` ব্যবহার করে সহজেই রূপান্তর করা যায়।
*   মডেলিংয়ের সময় Ordinal feature এর ক্রমগত মান সংরক্ষিত থাকে।

### **১. ভূমিকা**

Machine learning এবং data analysis-এ **vectors** গুরুত্বপূর্ণ ভূমিকা রাখে।

*   একটি vector হলো magnitude (দৈর্ঘ্য) এবং direction সহ একটি array।
*   Vectors-এর উপর বিভিন্ন operations যেমন **addition, subtraction, dot product, norms** ব্যবহার করা হয়।

### **২. Vectors তৈরি করা**

```python
import numpy as np

# দুইটি 3D vector
a = np.array([2, 1, 3])
b = np.array([1, 3, 3])

print(a)
print(b)
```

ফলাফল:

```
[2 1 3]
[1 3 3]
```

**ব্যাখ্যা:**

*   a এবং b হলো ৩ মাত্রার vectors।
*   এগুলো Python-এর numpy array হিসাবে তৈরি করা হলো।

### **৩. Vector Operations (Addition এবং Subtraction)**

```python
add_ab = a + b
sub_ab = a - b

print(add_ab)
print(sub_ab)
```

ফলাফল:

```
[3 4 6]
[ 1 -2  0]
```

**ব্যাখ্যা:**

*   **Addition:** প্রতিটি coordinate যোগ করা হয়: [2+1, 1+3, 3+3] = [3,4,6]
*   **Subtraction:** প্রতিটি coordinate বিয়োগ করা হয়: [2-1, 1-3, 3-3] = [1,-2,0]

### **৪. Dot Product (Similarity of Direction)**

```python
# Manual dot product: pairwise multiplication sum
dot = a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

# Using numpy
dot_np = a @ b  # অথবা np.dot(a,b)

print(dot)
print(dot_np)
```

ফলাফল:

```
14
14
```

**ব্যাখ্যা:**

*   Dot product হলো vector-দ্বয়ের মধ্যে **similarity measure**।
*   সূত্র: a·b = Σ(ai * bi) = 2*1 + 1*3 + 3*3 = 14
*   যদি dot product ধনাত্মক হয়, vectors প্রায় একই দিকে; ঋণাত্মক হলে বিপরীত দিকে।

### **৫. Norms (Vector-এর দৈর্ঘ্য বা magnitude)**

```python
# L2 norm (Euclidean length)
l2_a = np.linalg.norm(a)
print(l2_a)

# L1 norm (Manhattan distance)
l1_a = np.linalg.norm(a, ord=1)
print(l1_a)
```

ফলাফল:

```
3.7416573867739413
6.0
```

**ব্যাখ্যা:**

*   **L2 norm (Euclidean):** √(Σ ai²) = √(2²+1²+3²) = √14 ≈ 3.7416
*   **L1 norm (Manhattan):** Σ |ai| = 2+1+3 = 6
*   Norm vector-এর দৈর্ঘ্য বা magnitude প্রকাশ করে।

### **৬. Normalizing a Vector (Unit Vector)**

```python
unit_a = a / np.linalg.norm(a)
len_unit_a = np.linalg.norm(unit_a)

print(unit_a)
print(len_unit_a)
```

ফলাফল:

```
[0.53452248 0.26726124 0.80178373]
1.0
```

**ব্যাখ্যা:**

*   Unit vector হলো সেই vector যার দৈর্ঘ্য 1 কিন্তু direction একই থাকে।
*   Normalization: vector ÷ norm(vector)
*   এটি data scaling এবং similarity calculations-এ খুব গুরুত্বপূর্ণ।

### **৭. সারসংক্ষেপ**

*   **Vectors:** Magnitude ও direction সহ arrays
*   **Addition/Subtraction:** Coordinate-wise operations
*   **Dot Product:** Vectors-এর similarity measure
*   **Norms:** L2 norm (Euclidean), L1 norm (Manhattan)
*   **Unit Vector:** Normalized vector যার length = 1

### **১. ভূমিকা**

*   Scaling এবং Encoding করার পর প্রতিটি row numerical **vector** হিসেবে থাকে।
*   Vectors-এর মধ্যে **distance** মাপলে তাদের similarity বা closeness বোঝা যায়।

**Distance-এর গুরুত্ব:**

*   Euclidean: geometric straight-line distance
*   Manhattan: grid-style path distance
*   Scale করার আগে distance measure করলে magnitude বেশি প্রভাব ফেলে।

### **৩. উদাহরণ Dataset**

```
S1 = [70, 80]
S2 = [60, 90]
S3 = [85, 60]
S4 = [78, 76]
S5 = [62, 65]

q = [75, 70]  # Query point
```

**S1 vs q:**

*   Diffs: (70−75)=−5, (80−70)=10
*   Euclidean: √(25+100) = √125 ≈ 11.180
*   Manhattan: |−5|+|10| = 5+10 = 15

### **৪. Python Implementation**

```python
import numpy as np

# Dataset as matrix
X = np.array([
    [70, 80],  # S1
    [60, 90],  # S2
    [85, 60],  # S3
    [78, 76],  # S4
    [62, 65],  # S5
], dtype=float)

# Query point
q = np.array([75, 70], dtype=float)

print("X shape:", X.shape)
print("q:", q.tolist())
```

**ব্যাখ্যা:**

*   X হলো ৫টি ২-মাত্রার vector এর matrix
*   q হলো query point
*   `.shape` দিয়ে X-এর dimensions দেখা যায়

### **Step 1: Euclidean Distance (L2)**

```python
eu = np.linalg.norm(X - q, axis=1)
print("Euclidean:", np.round(eu, 3).tolist())
```

**ব্যাখ্যা:**

*   `X - q` করে প্রতিটি row থেকে query point বাদ দেওয়া হলো
*   `np.linalg.norm(..., axis=1)` করে প্রতিটি row-এর L2 norm (Euclidean distance) বের করা হলো
*   `np.round(..., 3)` করে ৩ দশমিক পর্যন্ত দেখানো হলো

ফলাফল:
```
Euclidean: [11.18, 25.0, 14.142, 6.708, 13.928]
```

### **Step 2: Manhattan Distance (L1)**

```python
ma = np.linalg.norm(X - q, ord=1, axis=1)
print("Manhattan:", ma.tolist())
```

**ব্যাখ্যা:**

*   `ord=1` দিয়ে L1 norm বা Manhattan distance মাপা হলো
*   প্রতিটি row-এর absolute differences যোগ করা হলো

ফলাফল:
```
Manhattan: [15.0, 25.0, 20.0, 9.0, 18.0]
```

### **৫. সারসংক্ষেপ**

*   **Euclidean distance:** সরাসরি straight-line distance
*   **Manhattan distance:** grid-style distance, L1 norm
*   **X - q:** প্রতিটি vector থেকে query point বিয়োগ করা
*   **axis=1:** প্রতিটি row-এ norm প্রয়োগ করা
*   **Scale করার পর distance ব্যবহার করা ভালো**, না হলে বড় magnitude ও features বেশি প্রভাব ফেলে
