*   Module 06–এ ঠিক কী কী skills অর্জন করবেন এবং প্রতিটি section কী নিয়ে কাজ করবে তার একটি স্পষ্ট roadmap পাবেন।

## Step-by-Step Explanation

Exploratory Data Analysis (EDA) হলো Machine Learning project–এর foundational step। এই ধাপ ছাড়া modeling শুরু করাটা অনেকটা অন্ধভাবে ভবিষ্যদ্বাণী করার মতো। কারণ EDA–র মূল লক্ষ্য হলো — data–কে বোঝা, এর pattern–গুলো খুঁজে বের করা, সমস্যা শনাক্ত করা এবং model–এর আগে dataset–কে এমনভাবে প্রস্তুত করা যাতে model কার্যকরভাবে শিখতে পারে।

EDA করার সময় একজন Data Scientist সাধারণত dataset–এর নিচের বিষয়গুলো পর্যবেক্ষণ করেন —

*   Dataset–এ total কতটি row ও column আছে (shape)।
*   প্রতিটি feature কী ধরনের data ধারণ করে (data types)।
*   Missing values কোন কোন column–এ আছে এবং সেগুলোর পরিমাণ কত।
*   Numerical feature–গুলোর distribution symmetric নাকি skewed।
*   Categorical feature–গুলোতে imbalance আছে কি না।
*   Target variable-এর সাথে কোন feature-এর logical বা statistical সম্পর্ক থাকতে পারে।

EDA–র মূল উদ্দেশ্য হলো data–কে readable, understandable এবং usable করে তোলা। এর মাধ্যমে আপনি data–র hidden structure, pattern এবং সমস্যাগুলোর একটি clear ছবি পান।

### ⭐ কেন EDA এত গুরুত্বপূর্ণ?

Machine Learning model তখনই ভালো perform করে যখন dataset সঠিকভাবে clean, formatted এবং balanced থাকে। Raw data–তে সাধারণত কিছু সমস্যা থাকেই —

*   Outliers model-এর prediction–এ noise তৈরি করে।
*   Missing values model–কে ভুল pattern শিখায়।
*   Skewed distribution model–কে biased করে তোলে।
*   Unnecessary বা irrelevant feature model–এর complexity বাড়ায় কিন্তু performance কমায়।

EDA–র মাধ্যমে আপনি —

*   Outlier detection করতে পারেন।
*   Missing value–এর ধরন অনুযায়ী Imputation technique পরিকল্পনা করতে পারেন।
*   Distribution দেখে transformation (log/sqrt) দরকার কি না ঠিক করতে পারেন।
*   Feature selection এবং engineering–এর শুরুটা শক্তভাবে করতে পারেন।

EDA data understanding–এর সেতুবন্ধ তৈরি করে, যা ছাড়া model-building পুরোপুরি incomplete থেকে যায়।
