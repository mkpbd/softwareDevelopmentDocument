### BP risk and Oldpeak stress categories (domain-driven rules)

```python
# Domain-driven risk categories for RestingBP and Oldpeak

def bp_risk(bp):
  if bp < 120:
    return "Normal"
  elif bp < 140:
    return "Elevated"
  else:
    return "High"

def oldpeak_risk(op):
  if op == 0:
    return "No Stress"
  elif op < 2:
    return "Moderate Stress"
  else:
    return "High Stress"

# Apply to dataframe

df_heart_encoded["BP_Risk"] = df_heart_encoded["RestingBP"].apply(bp_risk)
df_heart_encoded["Oldpeak_Risk"] = df_heart_encoded["Oldpeak"].apply(oldpeak_risk)

df_heart_encoded[["RestingBP", "BP_Risk", "Oldpeak", "Oldpeak_Risk"]]
```

*(run the code to get output)*

**Explanation:**
`bp_risk` এবং `oldpeak_risk` functions-গুলি domain knowledge (medical thresholds) ব্যবহার করে simplicity-ভিত্তিক categorical labels তৈরি করে। `apply()` করে নতুন কলামগুলো যোগ করা হয়েছে। Model-এ এই ধরনের interpretable features রাখতে পারলে clinical insights ও prediction দুটোই সহজে ব্যাখ্যা করা যায়।

**Note on Encoding these new features**
*   BP_Risk ও Oldpeak_Risk categorical হওয়ায় এগুলোর জন্য পরবর্তী ধাপে `OneHotEncoder` বা `Ordinal Encoding` বিবেচনা করতে হবে (depend on model)।
*   যদি খুব বেশি distinct categories না থাকে, `OneHotEncoder(drop='first')` সাধারণত নিরাপদ অপশন।

**Short recommendation**
Domain-driven features অনেক সময় কিছু numerical transformation-এর চেয়েও বেশি value রাখে, বিশেষত যখন domain expertise এবং interpretable predictions দরকার হয়।

**9.7 — Putting It All Together in a Preprocessing Pipeline**

**Learning Objectives**
*   Pipeline ও ColumnTransformer দিয়ে reproducible preprocessing workflow তৈরি করা।
*   Numeric ও categorical transformers আলাদা করে combine করা।
*   Full pipeline-এ model attach করে sanity-check চালানোর প্রস্তুতি নেওয়া।

**Overview**
এই সেকশনে আমরা numeric ও categorical features এর জন্য আলাদা transformers তৈরি করে `ColumnTransformer`-এ combine করব, তারপর একটি পূর্ণ `Pipeline` বানিয়ে সহজ একটি model (LogisticRegression) attach করব।

**Define pipelines and combine**

```python
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler, OneHotEncoder

# Define numeric and categorical columns for the pipeline
num_features = ["Age", "RestingBP", "Cholesterol", "MaxHR", "Oldpeak"]
cat_features = ["Sex", "ExerciseAngina", "ChestPainType", "RestingECG", "ST_Slope"]

# Numeric pipeline
num_pipeline = Pipeline([
    ("scaler", StandardScaler())
])

# Categorical pipeline
cat_pipeline = Pipeline([
    ("ohe", OneHotEncoder(drop="first"))
])

# Combine both
preprocess = ColumnTransformer([
    ("num", num_pipeline, num_features),
    ("cat", cat_pipeline, cat_features)
])

# Full pipeline with a simple model
clf = Pipeline([
   ("prep", preprocess),
   ("model", LogisticRegression(max_iter=1000))
])
```

*(run the code to get output)*

**Explanation:**
`num_pipeline`-এ প্রথমে numeric features-এর scaling করা হচ্ছে; `cat_pipeline`-এ categorical এ OneHotEncoder ব্যবহার করা হচ্ছে (drop='first' দিয়ে dummy trap এড়ানো)। `ColumnTransformer` উভয় pipeline-কে দুইটি column group-এ প্রয়োগ করে এবং শেষে একটি `Pipeline`-এ preprocessing ও model attach করে যেন পুরো chain reproducible হয়।

**Notes**
*   Pipeline-এ custom transformers বা imputer যোগ করা যেতে পারে যদি notebook-এ তা উপস্থাপিত থাকে।
*   Pipeline fitting করার সময় `clf.fit(X_train, y_train)` করলে preprocessing steps training set-এ fit হয়ে পরে test set-এ transform হওয়া নিরাপদ হয় (no leakage)।
