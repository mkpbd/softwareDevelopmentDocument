## **what  does Regression Mean**

## Core Idea 

 Regression is a type of  machine learning that predicts  Continuous  numerical outputs. unlike classification  which picks  categories , regression gives you actual numbers  .

Think of it as drawing  a line through data  points to  capture the underlying pattern then using that line to make predictions 

| Task Type      | Output   | Example               |
| -------------- | -------- | --------------------- |
| Regression     | Number   | 325000                |

## The line Equation : Y = mx + c 

Y = mx + c 

Every  straight line can be  described by this simple equation. Let's break down  what each part means. 

 > M (slope)
 >  How steep the line is how much  Y change  for each unit  increase in x
  
> c (intercept)
>  where the line crosses the y-axis the value of when x = 0 
>

Function and Gradient Descent 

How the model finds  the best line 

let's  discover how machine learning algorithms automatically find  the perfect  fit for you data 


## Quick  Recap : Linear Regression 

Remember our simple Equation 

y = mx + c

where m is the  slope  c is the  y  intercept 

we  used this to predict  exam marks based on study hours 

#### The big  Question  : how  do we automatically  find the best values for  m and c ?  that's where cost functions and gradient descent come in 



## Understanding prediction and Error

every prediction has an error  which is the difference  between what we predicted and the actual value 

| study Hours | True Makrs | predicted | Error |
| ----------- | ---------- | --------- | ----- |
| 2           | 45         | 40        | +5    |
| 5           | 75         | 70        | +5    |
| 8           | 85         | 95        | -10   |
why we can't Just Add Up Errors 

 > The Cancellation problem
 > Positive and negative errors cancel each  other out hiding the true error size.
 


 > Example 
 > Error A = +5
 > Error B = -5
 > sum = 0 
 > but both Predictions were off by 5!
 
 This is  why we need a smart  approach  to measuring total error

##  Mean Squared Error   (MSE)
MSE is our cost function . it tells us how Wrong our line is 

f(m,c ) =   1  / n   n sum i =1  (yi - yj) 2

Calculate Each Error 

Find the difference Between true and predicted Values 

Square Each Error 
	This  makes all Errors positive and Penalizes big mistakes more 
Average Them All
	Sum the squared errors and divide by the number of points 

> Key insight : Lower Cost = better line . our goal is  to minimize the number 

##  Visualize the cost function 
when we plot cost against different slope values (keeping intercept fixed ), we get a U-shaped curve 

the bottom or the cures  reparents the best slope value the one that minimizes error .
 Gradient decent is our strategy to reach that Sweet  spot 


## the Hill climbing analogy 

your are on a hill in the dark 
you can not  see the bottom  but you can feel which  way slopes downward 

Take  small steps  downhill
Move in the direction that goes down most steeply 

Repeat until you  reach the valley 

Keep stepping down until you can not go any lower 

That's exactly how gradient descent finds the best line following  the slope of  the cost function downward 



## what  we are  actually updating 

Think of m (slope ) and c (intercept ) as two knobs we are  constantly adjusting to improve our line


## initial Random line  
starting point : m = 2, c = 10 
high Cost 


## Arter gradient Descent

Optimized : m = 5.2, c = 35  low cost 



##  Learning Rate  : Finding the Right Speed 

the learning rate controls how big our steps are when  updating  m and c 


####  Too Small 
 tiny  steps take for every to reach  the minimum .  Training is painfully slow 

### Tool  Large 
	we overshoot and bounce  around , never setting at he minimum 
### Just Right 

Balanced  steps  that  converge  efficiently to the optimal solution 


##  The complete process in six simple steps 

 1.  Initialize Parameters 
	 > Start with random values for  M and  C 
 2.  Compute Prediction 
	 > Use current  m and  c to predict  all y values 
3.  Calculate Cost 
	 > use MSE  formula to measure total Eroro 
	 
4.  compute Gradients
	> Find the direction of steepets descent 

5.  Update Parameters 
	 > Adjust m and c by taking a step downhill 
	 
6. Repeat  Until Convergence 
	 > Keep iterating until  cost stops decreasing
