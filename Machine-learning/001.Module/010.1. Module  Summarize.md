============================ Regression ============================
## **what  does Regression Mean**

## Core Idea 

 Regression is a type of  machine learning that predicts  Continuous  numerical outputs. unlike classification  which picks  categories , regression gives you actual numbers  .

Think of it as drawing  a line through data  points to  capture the underlying pattern then using that line to make predictions 

| Task Type      | Output   | Example               |
| -------------- | -------- | --------------------- |
| Regression     | Number   | 325000                |
| Classification | Category | "Spam " or "Not Spam" |
|                |          |                       |

## The line Equation : Y = mx + c 

Y = mx + c 

Every  straight line can be  described by this simple equation. Let's break down  what each part means. 

 > M (slope)
 >  How steep the line is how much  Y change  for each unit  increase in x
  
> c (intercept)
>  where the line crosses the y-axis the value of when x = 0 
>

## Example of  Calculation 
 if  our line is y = 10x +  10  and a student studies for 7 hours

	 y = 80  marks

## Real life example : car price  prediction 

use car data 

| Mileage(km) | Price ($) |
| ----------- | --------- |
| 10000       | 28000     |
| 30000       | 24000     |
| 50000       | 20000     |
| 70000       | 16000     |
| 90000       | 12000     |
|             |           |
|             |           |
> notice the negative relationship : as mileages increases price  decreases.  the best fit line helps dealers and buyers estimate fair prices.

using regression  we can find a formula to predict the price 
price = -0.18 * Mileages + 29800

for a car with 60000 km 

price = -0.18* 60000 + 29800 = 19000



## How did we find this formula 





1. Regression  predicts continues numbers 
      use it  when your out put  is a measurable  value not a  category 
  2. the best fit line captures the trend 
     it  Summarizes  the relationship  between  input and output variables 
  3.  the equation y = mx + c   powers predictions 
     once we know m (slop) and c (intercept) . we can predict y for any value of  x
  4. Visualization helps understanding  
     scatter plots and regression  lines make patterns visible and intuitive
