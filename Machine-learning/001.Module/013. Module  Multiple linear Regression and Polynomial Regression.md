
**Introduction to Multiple Linear Regression**

**১. Multiple Linear Regression (MLR) কি?**

Multiple Linear Regression হল একটি পরিসংখ্যানিক মডেল যা **একটি নির্দিষ্ট আউটকাম (যেমন: বাড়ির দাম) একসাথে একাধিক ইনপুট ফ্যাক্টর (যেমন: বাড়ির আয়তন, শোবার ঘরের সংখ্যা, অবস্থান) ব্যবহার করে প্রেডিক্ট করে**। এটি সাধারণ Linear Regression একটি update version, যেখানে শুধুমাত্র একটি ভেরিয়েবল ব্যবহার না করে একাধিক ভেরিয়েবলের প্রভাব বিশ্লেষণ করা হয়।

**কীভাবে কাজ করে?**

*   মডেলটি প্রতিটি ফ্যাক্টরের জন্য একটি **ওয়েট বা গুরুত্ব নির্ধারণ করে**।
*   এই ওয়েটগুলি নির্ধারণ করা হয় যাতে প্রেডিকশন যতটা সম্ভব সঠিক হয়।
*   উদাহরণ: বাড়ির দাম = ২০ + ০.০৫(আয়তন) + ৫(শোবার ঘর)

**২. কেন একাধিক ফিচার প্রয়োজন?**

বাস্তব বিশ্বের আউটকামগুলো জটিল। যেমন: বাড়ির দাম নির্ভর করে:

*   **অর্থনৈতিক অবস্থা**: এলাকার আয়ের স্তর
*   **বাড়ির বয়স**: নতুন বাড়ির দাম বেশি
*   **আকার ও ঘর**: বড় বাড়ি ও বেশি শোবার ঘর হলে বেশি দাম
*   **পাড়ার মান**: স্কুল, হাসপাতাল, শপিং মলের সুবিধা

**একটি মাত্র ফিচার (যেমন: শুধু আয়তন) ব্যবহার করলে প্রেডিকশন কম সঠিক হয়।** একাধিক ফিচার ব্যবহার করলে প্রেডিকশন অনেক বেশি নির্ভরযোগ্য হয়।

**৫. হাইপারপ্লেন: MLR-এর জ্যামিতিক ব্যাখ্যা**

*   সাধারণ Linear Regression এ আমরা একটি straight line ফিট করি ( যেইখানে শুধু একটি ফিচার থাকে )।
*   MLR-এ একাধিক ফিচার থাকায় আমরা একটি **হাইপারপ্লেন** ফিট করি (একটি বহুমাত্রিক সমতল)।

**হাইপারপ্লেন কি?**

*   এটি একটি **সমতল পৃষ্ঠ** যা বহুমাত্রিক স্পেসে ডেটা পয়েন্টগুলোর সবচেয়ে কাছাকাছি অবস্থান করে।
*   উদাহরণ: যদি দুটি ফিচার থাকে (আয়তন ও শোবার ঘর), তাহলে হাইপারপ্লেন হবে একটি **৩ডি সমতল**।

**হাইপারপ্লেনের সমীকরণ:**

দাম = w0 + w1*(আয়তন) + w2*(শোবার ঘর)

*   **w0**: ইন্টারসেপ্ট (ভিত্তি দাম)
*   **w1**: আয়তনের ওয়েট (প্রতি sqft-এ দাম কত বাড়ে)
*   **w2**: শোবার ঘরের ওয়েট (প্রতি ঘরে দাম কত বাড়ে)

**গণনার উদাহরণ:**

**মডেল**: দাম = 20 + 0.05*(আয়তন) + 5*(শোবার ঘর)

বাড়ি A:
*   আয়তন = 1000 sqft
*   শোবার ঘর = 2
*   **দাম** = 20 + 0.05*1000 + 5*2 = 20 + 50 + 10 = ৮০ লক্ষ টাকা

বাড়ি B:
*   আয়তন = 1500 sqft
*   শোবার ঘর = 3
*   **দাম** = 20 + 0.05*1500 + 5*3 = 20 + 75 + 15 = ১১০ লক্ষ টাকা

**৬. হাইপারপ্লেন ভিজ্যুয়ালাইজেশন**
![[131-4.png]]


*   **নীল বিন্দু**: প্রতিটি বাস্তব বাড়ির তথ্য (আয়তন, ঘর, দাম)
*   **নীল সমতল**: MLR মডেলের হাইপারপ্লেন
*   **মডেলের লক্ষ্য**: সমতলটিকে এমনভাবে স্থাপন করা যেন এটি সবগুলো বিন্দুর যতটা সম্ভব কাছাকাছি থাকে।

**৭. MLR-এর সুবিধা ও সীমাবদ্ধতা**

**সুবিধা:**

1.  সহজে বুঝা যায় কোন ফিচারের কী প্রভাব।
2.  কম্পিউটেশন দ্রুত হয় ।
3.  একাধিক ফিচার একসাথে বিশ্লেষণ করা যায়।

**সীমাবদ্ধতা:**

1.  **লিনিয়ারিটি ধারণা**: MLR ধরে নেয় ফিচার ও টার্গেটের সম্পর্ক Linear। বাস্তবে তা নাও হতে পারে।
2.  **মাল্টিকোলিনিয়ারিটি**: দুটি ফিচার খুব সম্পর্কিত হলে মডেলের কার্যকারিতা কমে।
3.  **আউটলায়ার সংবেদনশীলতা**: অস্বাভাবিক ডেটা পয়েন্ট মডেলকে বিগড়ে দিতে পারে।

## **১. Basic Concept**

**মাল্টিপল লিনিয়ার রিগ্রেশন (MLR)** হলো একটি **সহজ কিন্তু শক্তিশালী** টুল যা:

*   **একাধিক ইনপুট** ($x_1, x_2, x_3, \dots$) থেকে
*   **একটি আউটপুট** ($y$) প্রেডিক্ট করতে ব্যবহৃত হয়

**উদাহরণ:**

```text
বাড়ির দাম = w₁ × আয় + w₂ × বেডরুম + w₃ × ফ্লোর + বেস প্রাইস
```

<br>

## **২. Core Formula**

### **সাধারণ রূপ:**
( গানিতিক সমীকরণ )
$$y = w_0 + w_1x_1 + w_2x_2 + \dots + w_nx_n$$

### **সহজ ভাষায়:**

```text
আউটপুট = (ওজন₁ × ইনপুট₁) + (ওজন₂ × ইনপুট₂) + (ওজন₃ × ইনপুট₃) + … + বায়াস
```

### **বাস্তব উদাহরণ:**

ধরা যাক:
*   **$x_1$** = বাসার আকার (বর্গফুট) → **$w_1$** = 2 (প্রতি বর্গফুট দাম)
*   **$x_2$** = বেডরুম সংখ্যা → **$w_2$** = 1.5 (প্রতি বেডরুম মূল্য)
*   **$x_3$** = ফ্লোর নম্বর → **$w_3$** = 0.2 (প্রতি ফ্লোর মূল্য)
*   **$b$** = 5 (বেস প্রাইস)

যদি:
```text
x₁ = 8 (হাজার বর্গফুট)
x₂ = 3 (৩টি বেডরুম)
x₃ = 6 (৬ষ্ঠ ফ্লোর)
```
তাহলে আমরা উপরের সমীকরণ ব্যবহার করে বাড়ির দাম বের করতে পারি।

## **৫. Gradient Descent– ভুল থেকে শেখা**

### **ধারণা:**
**মেশিন লার্নিং এ মডেল নিজে নিজে শেখে** কীভাবে:
১. শুরুতে র‍্যান্ডম ওজন দেয়
২. ভুল ক্যালকুলেট করে
৩. ভুল থেকে শিখে ওজন আপডেট করে

### **সূত্র:**
![[133-7.png]]


```text
নতুন ওজন = পুরোনো ওজন – (লার্নিং রেট × ভুলের দিক)
```

### **উদাহরণ:**
ধরা যাক:
*   **$W_{old}$** = 2
*   **গ্রেডিয়েন্ট** = –0.6 (ভুলের পরিমাণ ও দিক)
*   **$\alpha$ (লার্নিং রেট)** = 0.1

তাহলে:
$W_{new} = 2 - (0.1 \times -0.6)$
$W_{new} = 2 + 0.06 = 2.06$

### **লার্নিং রেটের গুরুত্ব:**
*   **$\alpha$ খুব বড় (0.1):** দ্রুত শেখে, কিন্তু ওভারশুট করতে পারে
*   **$\alpha$ খুব ছোট (0.0001):** ধীরে শেখে, স্টেবল
*   **$\alpha$ মাঝারি (0.01):** ভালো ব্যালেন্স


## **৬. গুরুত্বপূর্ণ টার্মস**

### **১. ওজন (Weights – w)**
*   প্রতিটি ফিচারের গুরুত্ব
*   বড় w = বেশি গুরুত্বপূর্ণ ফিচার
*   ছোট w = কম গুরুত্বপূর্ণ ফিচার

### **২. বায়াস (Bias – b)**

### **৪. লার্নিং রেট ($\alpha$)**
*   “পদক্ষেপের সাইজ”

**Polynomial Regression Extending Linear Models**

**১. এটি কী সমস্যার সমাধান করে??**

*   Linear Regression ধরে নেয় যে ডেটার ফিচার ও টার্গেটের মধ্যে সম্পর্ক সরাসরি লিনিয়ার।
*   বাস্তব জীবনের ডেটা প্রায়শই **Non-linear** বা বক্র ধরনের আচরণ করে।
*   যখন সম্পর্ক nonlinear হয়, একটি সরলরেখা প্রকৃত প্যাটার্ন ধরতে পারে না।
*   Polynomial Regression linear মডেলকে সম্প্রসারণ করে, যাতে এটি বক্র সম্পর্কও ধরতে পারে

**মূল ভাবনা:** Linear Regression + Feature Transformation = Non-linear pattern ধরার ক্ষমতা।

<br>

**৪. মূল ধারণা: Feature Transformation**

1.  **আসল ফিচার:** ইনপুট variable (x)
2.  **রূপান্তর:** বহুপদী ফিচার তৈরি — (x, x^2, x^3, …)
3.  **Linear মডেল:** এই নতুন বৈশিষ্ট্যের উপর Linear Regression প্রয়োগ

Model parameters **Linear** থাকে, কিন্তু আমরা **non-linear relationships** ধরতে পারি।


**৫. ঝুঁকি: Overfitting / Underfitting**

*   **Too low degree (Underfit):** সরল মডেল, প্রকৃত প্যাটার্ন ধরতে পারে না।
*   **Optimum degree:** ব্যালেন্সড, প্যাটার্ন ধরেছে, নয়েজ ধরেনি।
*   **Too high degree (Overfit):** প্রতিটি ডেটা পয়েন্টের মধ্য দিয়ে ঘুরে বেড়ায়।
*   নয়েজও শেখে → সাধারণীকরণ দুর্বল।

## **Step 4: Polynomial Regression (Degrees 1,2,3,5)**

```python
degrees = [1,2,3,5]
results = []

for deg in degrees:
  model = Pipeline([
      ('poly', PolynomialFeatures(degree=deg, include_bias=False)),
      ('lin_reg', LinearRegression())
  ])

  model.fit(X_single_train, y_single_train)

  y_train_pred_deg = model.predict(X_single_train)
  y_test_pred_deg = model.predict(X_single_test)

  mae_train = mean_absolute_error(y_single_train, y_train_pred_deg)
  rmse_train = np.sqrt(mean_squared_error(y_single_train, y_train_pred_deg))
  r2_train = r2_score(y_single_train, y_train_pred_deg)

  mae_test = mean_absolute_error(y_single_test, y_test_pred_deg)
  rmse_test = np.sqrt(mean_squared_error(y_single_test, y_test_pred_deg))
  r2_test = r2_score(y_single_test, y_test_pred_deg)

  results.append({
      'degree': deg,
      'MAE_train': mae_train,
      'RMSE_train': rmse_train,
      'R2_train': r2_train,
      'MAE_test': mae_test,
      'RMSE_test': rmse_test,
      'R2_test': r2_test,
  })

results_df = pd.DataFrame(results)
results_df
```

*   আমরা বিভিন্ন degree (1,2,3,5) এর Polynomial Regression মডেল বানাচ্ছি।
*   Pipeline ব্যবহার → PolynomialFeatures + LinearRegression একসাথে।
*   প্রতিটি মডেল ট্রেন ও টেস্ট ডেটার পারফরম্যান্স হিসাব করছে (MAE, RMSE, R²)।
*   ফলাফল DataFrame এ দেখানো হচ্ছে, সহজে তুলনা করার জন্য।

**Observation:**
*   Degree 1 = Linear
*   Degree 2–3 = Non-linear relationship ধরতে পারে
*   Degree 5 = ওভারফিটিং হতে পারে, Training score ভালো, Test score কমে যেতে পারে
