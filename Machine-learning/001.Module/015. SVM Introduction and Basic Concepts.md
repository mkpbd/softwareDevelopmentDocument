
**15.2 What is SVM Introduction and Basic Concepts**

**What is SVM: Introduction and Basic Concepts**

**Support Vector Machine কী?**

Support Vector Machine (SVM) হলো একটি **supervised machine learning algorithm**, যা মূলত **classification** এবং **regression** সমস্যার জন্য ব্যবহৃত হয়।

তবে বাস্তবে SVM সবচেয়ে বেশি জনপ্রিয় **classification** এর জন্য।

সহজ ভাষায় বললে,

SVM এমন একটি অ্যালগরিদম যা ডেটার ভেতর থেকে **সবচেয়ে ভালো বিভাজন রেখা (decision boundary)** খুঁজে বের করে।

**SVM এক লাইনে**

SVM এমন একটি boundary খোঁজে,

যেটি দুইটি ক্লাসের মাঝখানে সবচেয়ে **নিরাপদ ও প্রশস্ত দূরত্ব** তৈরি করে।

**মূল ধারণা (The Core Idea)**

ধরা যাক আপনার কাছে দুইটি ক্লাস আছে —

Class A এবং Class B।

এই দুই ক্লাসকে আলাদা করতে অসংখ্য সরলরেখা আঁকা সম্ভব।

কিন্তু SVM প্রশ্ন করে:

সব রেখা সমান ভালো কি?

উত্তর: না।

SVM সেই রেখাটিই বেছে নেয়,

যেটি দুই ক্লাস থেকে সবচেয়ে দূরে অবস্থান করে।

**বাস্তব উদাহরণ**

দুইটি পাড়া কল্পনা করুন।

এই দুই পাড়ার মাঝে আপনি একটি রাস্তা বানাতে চান।

আপনি চাইবেন রাস্তা যেন:

*   দুই পাড়ার ঘর থেকে যতটা সম্ভব দূরে থাকে
*   কোনো ঘরের খুব কাছ দিয়ে না যায়

এই **সবচেয়ে চওড়া রাস্তাটিই** হলো SVM এর decision boundary।

**Many Lines, One Best Line**

একই ডেটার জন্য অসংখ্য separator সম্ভব।

কিন্তু SVM শুধুমাত্র একটি রেখাকেই নির্বাচন করে।

প্রশ্ন:

কোন separator সবচেয়ে নির্ভরযোগ্য?

উত্তর:

যেটি দুই ক্লাস থেকে সবচেয়ে বেশি দূরত্ব বজায় রাখে।

**Margin কী?**

Margin হলো:

decision boundary থেকে

সবচেয়ে কাছের ডেটা পয়েন্ট পর্যন্ত দূরত্ব

দুই পাশে দুটি margin থাকে,

আর SVM এই margin দুটিকে **সর্বোচ্চ করতে চায়**।

**কেন Margin গুরুত্বপূর্ণ?**

বড় margin মানে:

*   মডেল বেশি আত্মবিশ্বাসী
*   নতুন ডেটায় ভুল করার সম্ভাবনা কম
*   ভালো generalization

ছোট margin হলে সামান্য noise এলেই boundary বদলে যেতে পারে।

**Support Vectors কী?**

Support Vectors হলো সেই ডেটা পয়েন্টগুলো:

*   যেগুলো decision boundary এর সবচেয়ে কাছাকাছি
*   যেগুলো margin নির্ধারণ করে

এই পয়েন্টগুলো ছাড়া SVM কাজই করতে পারে না।

**কেন Support Vectors এত গুরুত্বপূর্ণ?**

SVM এর একটি বিশেষ বৈশিষ্ট্য হলো:

decision boundary শুধুমাত্র support vectors এর উপর নির্ভর করে।

অন্য সব পয়েন্ট boundary থেকে অনেক দূরে থাকলে,

তারা মডেলের সিদ্ধান্তে কোনো প্রভাব ফেলে না।

**এর সুবিধা কী?**

প্রথমত, Stable Boundary

Boundary কেবল গুরুত্বপূর্ণ পয়েন্টগুলোর উপর নির্ভর করে,

তাই মডেল বেশি স্থিতিশীল হয়।

দ্বিতীয়ত, Outlier Resistance

দূরের outlier গুলো boundary নষ্ট করতে পারে না।

**Hard Margin বনাম Soft Margin**

**Hard Margin SVM**

*   কোনো পয়েন্ট margin অতিক্রম করতে পারবে না
*   একদম নিখুঁতভাবে আলাদা হতে হবে
*   Noise থাকলে সমস্যা হয়

এই পদ্ধতি কেবল তখনই কাজ করে,

যখন ডেটা সম্পূর্ণভাবে separable।

**Soft Margin SVM**

*   কিছু পয়েন্ট margin অতিক্রম করতে পারে
*   সামান্য ভুল মেনে নেয়
*   বাস্তব জীবনের ডেটার জন্য বেশি উপযোগী

Soft Margin বাস্তব সমস্যায় বেশি ব্যবহার করা হয়।

**বাস্তব জীবনের উদাহরণ**

**Email Classification**

Spam বনাম Not Spam

SVM ইমেইলের বিভিন্ন বৈশিষ্ট্য দেখে একটি boundary তৈরি করে, যেমন:

*   শব্দের frequency
*   sender এর ধরন
*   লিংকের উপস্থিতি

**Medical Diagnosis**

Malignant বনাম Benign

Tumor এর বিভিন্ন বৈশিষ্ট্য ব্যবহার করে

SVM রোগ নির্ণয়ে সাহায্য করে।

**কিন্তু সব ডেটা কি সরলরেখায় আলাদা করা যায়?**

না।

অনেক সময় ডেটা:

*   বাঁকানো
*   জটিল
*   intertwined হয়

এই ক্ষেত্রে সরলরেখা দিয়ে আলাদা করা সম্ভব হয় না।

**15.3 Mathematical Intuition Margins, Support Vectors, and Hinge Loss**

**Mathematical Intuition: Margins, Support Vectors, and Hinge Loss**

এই মডিউলে আমরা SVM-এর ভেতরের গণিতের যুক্তি বুঝবো।

লক্ষ্য হলো সূত্র মুখস্থ করা নয়, বরং **কেন এই সূত্রগুলো এমন**—সেটা পরিষ্কারভাবে বোঝা।

**Decision Boundary কে গাণিতিকভাবে বোঝা**

SVM-এ decision boundary সাধারণত লেখা হয়:

```c
w · x + b = 0
```

এখানে,

*   w হলো weight vector
*   x হলো input feature vector
*   b হলো bias

এই সমীকরণটি একটি রেখা (2D), একটি plane (3D), বা উচ্চমাত্রিক ক্ষেত্রে একটি hyperplane নির্দেশ করে।

**Margin এর গাণিতিক অর্থ**

Margin হলো decision boundary থেকে

সবচেয়ে কাছের data point পর্যন্ত লম্ব দূরত্ব।

SVM-এ দুই পাশে দুটি boundary থাকে:

```c
w · x + b = +1
w · x + b = -1
```

এই দুইটি রেখার মাঝের দূরত্বই হলো margin।

**Margin এর সূত্র**

Margin এর প্রস্থ:

```c
Margin = 2 / ||w||
```

এখানে ||w|| হলো w vector-এর magnitude (Euclidean norm)।

**কেন ||w|| ছোট হলে Margin বড় হয়?**

কারণ:

*   w যত ছোট হবে
*   1 / ||w|| তত বড় হবে
*   ফলে margin বাড়বে

SVM-এর মূল লক্ষ্য হলো:

```c
||w|| মিনিমাইজ করা
```

এর মাধ্যমে margin সর্বোচ্চ হয়।

**Optimization Problem এর ধারণা**

Hard Margin SVM-এ সমস্যা দাঁড়ায়:

```c
Minimize:  1/2 ||w||²
Subject to:  yᵢ (w · xᵢ + b) ≥ 1
```

এখানে,

*   yᵢ ∈ {+1, −1}
*   প্রতিটি point সঠিক পাশে এবং margin-এর বাইরে থাকতে হবে

**Support Vectors গাণিতিকভাবে কারা?**

যেসব point এর জন্য:

```c
yᵢ (w · xᵢ + b) = 1
```

এই point গুলোই support vector।

অর্থাৎ:

*   তারা ঠিক margin এর উপর বসে আছে
*   margin সামান্য বদলালেই boundary বদলে যাবে

এই কারণেই support vector গুলো সবচেয়ে গুরুত্বপূর্ণ।

**কেন অন্য point গুলো গুরুত্বহীন?**

যেসব point এর জন্য:

```c
yᵢ (w · xᵢ + b) > 1
```

তারা margin থেকে অনেক দূরে।

এই point গুলো:

*   boundary নির্ধারণে অংশ নেয় না
*   w বা b পরিবর্তনে কোনো ভূমিকা রাখে না

এই কারণে SVM কে sparse model বলা হয়।

**Hard Margin এর সমস্যা**

বাস্তব ডেটাতে প্রায়ই:

*   noise থাকে
*   ভুল লেবেল থাকে
*   perfect separation সম্ভব হয় না

Hard Margin এ একটিও ভুল চলবে না,

ফলে মডেল ভেঙে যেতে পারে।

**Soft Margin ধারণা**

Soft Margin এ constraint শিথিল করা হয়।

নতুন একটি ভ্যারিয়েবল যোগ হয়:

```c
ξᵢ ≥ 0
```

একে slack variable বলা হয়।

নতুন constraint:

```c
yᵢ (w · xᵢ + b) ≥ 1 − ξᵢ
```

**Objective Function (Soft Margin)**

```c
Minimize:  1/2 ||w||² + C Σ ξᵢ
```

এখানে C একটি গুরুত্বপূর্ণ hyperparameter।

**C কী নিয়ন্ত্রণ করে?**

C মূলত দুইটি বিষয়ের balance করে:

| বিষয় | ব্যাখ্যা |
| :--- | :--- |
| Margin size | বড় margin চাই |
| Classification error | ভুল কম চাই |

**C বড় হলে কী হয়?**

*   ভুলের জন্য বড় শাস্তি
*   margin ছোট হতে পারে
*   overfitting এর ঝুঁকি বাড়ে

**C ছোট হলে কী হয়?**

*   কিছু ভুল মেনে নেয়
*   margin বড় হয়
*   generalization ভালো হয়

**Hinge Loss কী?**

Soft Margin ধারণাকে সহজভাবে প্রকাশ করার জন্য

Hinge Loss ব্যবহার করা হয়।

একটি single point এর জন্য loss:

```c
Loss = max(0, 1 − y (w · x + b))
```

**Hinge Loss কে ধাপে ধাপে বোঝা**

ধরা যাক:

```c
score = y (w · x + b)
```

তাহলে,

*   যদি score ≥ 1 → loss = 0
*   যদি score < 1 → loss = 1 − score

**উদাহরণ**

| score | loss |
| :--- | :--- |
| 2.5 | 0 |
| 1.0 | 0 |
| 0.6 | 0.4 |
| -1.0 | 2.0 |

**Hinge Loss কেন ব্যবহার করা হয়?**

কারণ:

*   margin ভাঙলে শাস্তি দেয়
*   margin এর বাইরে থাকলে পুরস্কার দেয়
*   ভুল classification হলে loss দ্রুত বাড়ে

এটি SVM-কে margin-centric করে তোলে।

**সবকিছু একসাথে ভাবলে**

SVM চায়:

*   বড় margin
*   কম ভুল
*   boundary নির্ধারণ করুক কেবল গুরুত্বপূর্ণ point

এই তিনটি লক্ষ্য একসাথে পূরণ করে

margin maximization + hinge loss।

**এই মডিউলের সারসংক্ষেপ**

*   Margin = 2 / ||w||
*   Support vector হলো margin-এর উপর থাকা point
*   Hard margin বাস্তবে অনুপযোগী
*   Soft margin বাস্তব ডেটার জন্য কার্যকর
*   Hinge loss margin ভাঙার শাস্তি নির্ধারণ করে

**15.4 Understanding Kernels Linear, Polynomial, and RBF**

**Understanding Kernels: Linear, Polynomial, and RBF**

এই মডিউলে আমরা SVM-এর সবচেয়ে শক্তিশালী ধারণা **Kernel** নিয়ে আলোচনা করবো।

Kernel না থাকলে SVM শুধুমাত্র সরলরেখায় ডেটা আলাদা করতে পারতো।

Kernel SVM-কে জটিল, বাঁকানো, nonlinear ডেটার জন্য কার্যকর করে তোলে।

**Kernel কী?**

Kernel হলো একটি গাণিতিক ফাংশন,

যা ডেটাকে এমনভাবে রূপান্তর করে

যাতে আগে যেখানে কোনো পরিষ্কার boundary ছিল না,

সেখানে এখন একটি স্পষ্ট decision boundary পাওয়া যায়।

**কেন Kernel দরকার?**

**বাস্তব সমস্যার চ্যালেঞ্জ**

বাস্তব জীবনের ডেটা প্রায় কখনোই:

*   পুরোপুরি সরলরেখায় আলাদা করা যায় না
*   অনেক সময় বাঁকানো বা জটিল আকৃতির হয়

উদাহরণ:

*   moons dataset
*   concentric circles dataset

এই ডেটাগুলোতে সরলরেখা দিয়ে আলাদা করা অসম্ভব।

**Linear Classifier কেন ব্যর্থ হয়?**

Linear classifier সমস্যায় পড়ে যখন:

*   boundary বাঁকানো
*   ক্লাসগুলো পরস্পর জড়ানো
*   ডেটা উচ্চমাত্রিক ও জটিল

এই জায়গাতেই Kernel অপরিহার্য।

**Kernel Trick কী?**

Kernel Trick-এর মূল ধারণা হলো:

ডেটাকে উচ্চমাত্রিক space-এ প্রজেক্ট করা হচ্ছে বলে ধরে নেওয়া,

কিন্তু বাস্তবে সেই গণনা না করা।

অর্থাৎ:

*   explicit transformation করা হয় না
*   শুধু inner product হিসাব করা হয়

এতে computational cost না বাড়িয়ে

উচ্চমাত্রিক separation-এর সুবিধা পাওয়া যায়।

**Linear Kernel: ভিত্তি স্তর**

**কী করে?**

Linear Kernel একটি সরল decision boundary তৈরি করে।

**গাণিতিক রূপ**

```c
K(x, y) = xᵀy
```

এটি মূলত সাধারণ SVM-এর মতোই,

কোনো transformation ছাড়াই।

**কখন ব্যবহার করবেন?**

| বিষয় | ব্যাখ্যা |
| :--- | :--- |
| ডেটা | Linearly separable |
| Feature space | High-dimensional |
| উদাহরণ | Text classification |

**কেন এখনো Linear Kernel জনপ্রিয়?**

কারণ:

*   Training দ্রুত
*   Prediction দ্রুত
*   High-dimensional sparse data-তে ভালো কাজ করে

**Polynomial Kernel: নিয়ন্ত্রিত জটিলতা**

Polynomial Kernel ডেটার মধ্যে polynomial সম্পর্ক ধরতে পারে।

**গাণিতিক রূপ**

```c
K(x, y) = (xᵀy + c)^d
```

এখানে d হলো degree।

**Degree অনুযায়ী আচরণ**

| Degree | বৈশিষ্ট্য |
| :--- | :--- |
| 2 | হালকা বাঁক, মাঝারি nonlinear |
| 3 | বেশি জটিল pattern |
| >3 | উচ্চ ঝুঁকির overfitting |

**Polynomial Kernel-এর সুবিধা**

| বিষয় | ব্যাখ্যা |
| :--- | :--- |
| Feature interaction | Polynomial সম্পর্ক ধরতে পারে |
| Interpretability | Degree স্পষ্ট |
| Efficiency | Low degree-তে কার্যকর |

**Polynomial Kernel-এর সীমাবদ্ধতা**

| বিষয় | সমস্যা |
| :--- | :--- |
| Degree বেশি হলে | Overfitting |
| Stability | Numerical সমস্যা |
| Scaling | Feature scaling জরুরি |

**Best Practice**

*   Degree 2 বা 3 দিয়ে শুরু করুন
*   Cross-validation ব্যবহার করুন
*   High degree সাধারণত এড়িয়ে চলুন

**RBF Kernel: সবচেয়ে শক্তিশালী অস্ত্র**

RBF (Gaussian) Kernel হলো সবচেয়ে বেশি ব্যবহৃত nonlinear kernel।

**গাণিতিক রূপ**

```c
K(x, y) = exp(-γ ||x - y||²)
```

**RBF Kernel কীভাবে কাজ করে?**

*   Euclidean distance দিয়ে similarity মাপে
*   Support vector কাছের point-গুলোকে বেশি প্রভাবিত করে
*   দূরের point-গুলোর প্রভাব কমে যায়

**RBF Kernel-এর বৈশিষ্ট্য**

| বৈশিষ্ট্য | ব্যাখ্যা |
| :--- | :--- |
| Dimension | Infinite-dimensional mapping |
| Boundary | খুবই flexible |
| Shape | জটিল geometry ধরতে পারে |

**Gamma Parameter কী?**

Gamma নিয়ন্ত্রণ করে

একটি support vector কতদূর পর্যন্ত প্রভাব ফেলবে।

**Low Gamma**

| বিষয় | আচরণ |
| :--- | :--- |
| Influence | দূর পর্যন্ত |
| Boundary | মসৃণ |
| Risk | Underfitting |

**High Gamma**

| বিষয় | আচরণ |
| :--- | :--- |
| Influence | খুব কাছাকাছি |
| Boundary | জটিল |
| Risk | Overfitting |

**সহজ তুলনা**

Low gamma মানে

বড় তুলি দিয়ে আঁকা ছবি।

High gamma মানে

পাতলা কলম দিয়ে আঁকা ছবি।

**Practical Rule**

*   gamma = 1 / n_features দিয়ে শুরু করুন
*   Training এবং validation accuracy দুটোই দেখুন
*   Cross-validation দিয়ে tune করুন

**Kernel কীভাবে নির্বাচন করবেন?**

**ধাপে ধাপে গাইড**

| ধাপ | নির্দেশনা |
| :--- | :--- |
| 1 | আগে ডেটা বিশ্লেষণ করুন |
| 2 | Linear kernel চেষ্টা করুন |
| 3 | Nonlinear হলে RBF ব্যবহার করুন |
| 4 | Domain knowledge থাকলে Polynomial |
| 5 | Cross-validation দিয়ে তুলনা করুন |

**সংক্ষেপে এই মডিউল**

*   Kernel SVM-কে nonlinear সমস্যা সমাধানে সক্ষম করে
*   Linear kernel সহজ ও দ্রুত
*   Polynomial kernel নিয়ন্ত্রিত জটিলতা দেয়
*   RBF kernel সবচেয়ে flexible ও জনপ্রিয়
*   Gamma ও degree সঠিকভাবে tune করা জরুরি

**15.5 Support Vector Classifiers Explained Simply**

**Support Vector Classifiers Explained Simply**

এই মডিউলে আমরা Support Vector Classifier (SVC) কে সহজ ভাষায় বুঝবো।

এটি SVM-এর সেই অংশ, যা **categorical prediction** বা classification সমস্যার জন্য ব্যবহার করা হয়।

**Support Vector Classifier কী?**

Support Vector Classifier হলো এমন একটি classification পদ্ধতি,

যা ডেটার ভেতর থেকে সবচেয়ে ভালো separating boundary খুঁজে বের করে।

এই boundary নির্ধারিত হয় কেবলমাত্র কিছু গুরুত্বপূর্ণ ডেটা পয়েন্ট দ্বারা,

যাদের আমরা **support vector** বলি।

**SVC-এর মূল ধারণা**

SVC আলাদা কারণ:

*   এটি সব ডেটা পয়েন্টকে সমান গুরুত্ব দেয় না
*   boundary-এর সবচেয়ে কাছের পয়েন্টগুলোকেই গুরুত্ব দেয়

এই পয়েন্টগুলোর সাহায্যেই

সবচেয়ে শক্তিশালী এবং নির্ভরযোগ্য boundary তৈরি হয়।

**কেন Margin Maximization গুরুত্বপূর্ণ?**

SVC এমন boundary তৈরি করে,

যেটি দুই ক্লাসের মাঝে সবচেয়ে বড় margin রাখে।

এর ফলে:

*   মডেল বেশি confident হয়
*   নতুন ডেটায় ভুল করার সম্ভাবনা কমে
*   generalization উন্নত হয়

**SVC Workflow: ডেটা থেকে সিদ্ধান্ত পর্যন্ত**

SVC ব্যবহারের সাধারণ ধাপগুলো নিচে দেওয়া হলো।

| ধাপ | কী করা হয় |
| :--- | :--- |
| Scale Data | সব feature কে একই স্কেলে আনা |
| Choose Kernel | Linear, Polynomial, বা RBF নির্বাচন |
| Tune C | Margin কতটা কড়া হবে নিয়ন্ত্রণ |
| Tune Gamma | Boundary কতটা জটিল হবে নিয়ন্ত্রণ |
| Train | Training data দিয়ে মডেল শেখানো |
| Evaluate | Model performance যাচাই |

**কেন Data Scaling জরুরি?**

SVC distance-এর উপর নির্ভর করে কাজ করে।

যদি একটি feature-এর মান অনেক বড় হয়,

সে feature অন্যদের উপর আধিপত্য বিস্তার করবে।

তাই scaling না করলে:

*   ভুল boundary তৈরি হতে পারে
*   model unstable হয়

**C Parameter কী নিয়ন্ত্রণ করে?**

C parameter নির্ধারণ করে:

*   margin কতটা চওড়া হবে
*   training error কতটা মেনে নেওয়া হবে

**High C Value**

High C মানে:

*   training data-তে ভুল প্রায় চলবে না
*   margin সরু হয়
*   model খুব কড়া হয়ে যায়

এর ঝুঁকি হলো overfitting।

**Low C Value**

Low C মানে:

*   কিছু ভুল মেনে নেওয়া হয়
*   margin চওড়া হয়
*   model বেশি general হয়

এতে নতুন ডেটায় performance ভালো হয়।

**C Parameter সংক্ষেপে**

| C মান | আচরণ |
| :--- | :--- |
| বেশি | কড়া boundary, overfitting ঝুঁকি |
| কম | নমনীয় boundary, ভালো generalization |

**RBF Kernel-এ Gamma এর ভূমিকা**

Gamma শুধুমাত্র RBF kernel-এর জন্য গুরুত্বপূর্ণ।

Gamma নির্ধারণ করে

একটি support vector কতদূর পর্যন্ত প্রভাব ফেলবে।

**Small Gamma**

Small gamma হলে:

*   দূরের পয়েন্টও প্রভাব ফেলে
*   boundary মসৃণ হয়
*   overfitting কম হয়

**Large Gamma**

Large gamma হলে:

*   শুধু কাছের পয়েন্ট প্রভাব ফেলে
*   boundary খুব জটিল হয়
*   training data মুখস্থ করে ফেলে

**Gamma সংক্ষেপে**

| Gamma মান | ফলাফল |
| :--- | :--- |
| কম | Smooth boundary, underfitting ঝুঁকি |
| বেশি | Complex boundary, overfitting ঝুঁকি |

**Kernel তুলনা: কোনটা কখন?**

| Kernel | Boundary ধরন | ব্যবহার ক্ষেত্র |
| :--- | :--- | :--- |
| RBF | Flexible, radial | জটিল, অজানা pattern |
| Linear | সরলরেখা | Text, high-dimensional data |
| Polynomial | বাঁকানো | মাঝারি nonlinear সমস্যা |

**কোন Kernel দিয়ে শুরু করবেন?**

সাধারণ নিয়ম:

*   আগে Linear চেষ্টা করুন
*   কাজ না করলে RBF ব্যবহার করুন
*   Polynomial কেবল domain knowledge থাকলে

সব ক্ষেত্রে cross-validation ব্যবহার করে সিদ্ধান্ত নিন।

**এই মডিউলে আপনি যা শিখলেন**

*   SVC হলো SVM-এর classification সংস্করণ
*   Support vector দিয়েই boundary নির্ধারিত হয়
*   C margin এবং error-এর balance করে
*   Gamma boundary-এর জটিলতা নিয়ন্ত্রণ করে
*   সঠিক kernel নির্বাচন অত্যন্ত গুরুত্বপূর্ণ

**15.6 Implementing SVM Classifiers on Toy Data**

**Implementing SVM Classifiers on Toy Data**

এই মডিউলে আমরা SVM-এর তাত্ত্বিক ধারণা থেকে বের হয়ে একটি ছোট **toy dataset** ব্যবহার করে বাস্তবে SVM classifier তৈরি করবো।

লক্ষ্য হলো বোঝা:

*   SVM কীভাবে কাজ করে
*   margin ও decision boundary কেমন দেখায়
*   কোডের প্রতিটি ধাপের ভূমিকা কী

**কেন Toy Dataset ব্যবহার করা হয়?**

Toy dataset হলো:

*   ছোট
*   কৃত্রিমভাবে তৈরি
*   সহজে visualise করা যায়

এগুলো দিয়ে:

*   অ্যালগরিদমের আচরণ বোঝা সহজ হয়
*   জটিল বাস্তব ডেটার আগে foundation তৈরি হয়

**প্রয়োজনীয় লাইব্রেরি ইমপোর্ট**

প্রথমে আমরা প্রয়োজনীয় Python লাইব্রেরিগুলো ইমপোর্ট করি।

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.datasets import make_classification
```

**Step 1: Linearly Separable Toy Dataset তৈরি**

এখন আমরা দুইটি feature এবং দুইটি class নিয়ে একটি linearly separable dataset তৈরি করি।

```python
X_lin, y_lin = make_classification(
    n_samples=200,
```

এখানে মূল বিষয়গুলো:

| Parameter | ভূমিকা |
| :--- | :--- |
| n_samples | মোট ডেটা পয়েন্ট |
| n_features | feature সংখ্যা |
| class_sep | ক্লাসগুলোর দূরত্ব |
| random_state | reproducibility |

**Step 2: Dataset Visualisation**

ডেটা বোঝার সবচেয়ে ভালো উপায় হলো চোখে দেখা।

```python
plt.scatter(X_lin[:, 0], X_lin[:, 1], c=y_lin, cmap='bwr', edgecolors='k', alpha=0.8)
plt.xlabel('Feature 1')

plt.show()
```

এই গ্রাফে আমরা স্পষ্টভাবে দেখতে পাই দুইটি ক্লাস একটি সরলরেখা দিয়ে আলাদা করা সম্ভব।

**Step 3: Train–Test Split**

এখন ডেটাকে training এবং test অংশে ভাগ করি।

```python
X_train, X_test, y_train, y_test = train_test_split(
    X_lin, y_lin, test_size=0.2, random_state=42
)
```

| data | শতাংশ |
| :--- | :--- |
| Training data | 80% |

**Step 4: Feature Scaling কেন দরকার?**

SVM distance-এর উপর কাজ করে। তাই feature-এর স্কেল আলাদা হলে সমস্যা হয়। এই কারণে StandardScaler ব্যবহার করা হয়।

```python
scaler = StandardScaler()
```

**Step 7: Decision Boundary Visualisation**

SVM বোঝার সবচেয়ে গুরুত্বপূর্ণ অংশ হলো decision boundary দেখা।

```python
def plot_decision_boundary(model, X, y, title='Decision boundary'):
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    xx, yy = np.meshgrid(
        np.linspace(x_min, x_max, 300),
        np.linspace(y_min, y_max, 300)
    )
    grid = np.c_[xx.ravel(), yy.ravel()]
    Z = model.predict(grid)
    Z = Z.reshape(xx.shape)

    plt.contourf(xx, yy, Z, alpha=0.2, cmap='bwr')
    plt.scatter(X[:, 0], X[:, 1], c=y, cmap='bwr', edgecolors='k', alpha=0.8)
    plt.title(title)
    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.show()
```

এই ফাংশন:

*   পুরো feature space-এ prediction করে
*   decision region আঁকে
*   আসল data point-এর সাথে boundary দেখায়

**Step 8: Linear SVM Boundary দেখা**

```python
plot_decision_boundary(
    svm_linear,

    y_train,
    title='Linear SVM decision boundary (toy data)'
)
```

এখানে আমরা স্পষ্টভাবে দেখি:

*   মাঝখানে decision boundary

*   support vector দ্বারা boundary নির্ধারিত

**15.7 Kernels Visualisation: Linear, Polynomial, and RBF**

**Kernels Visualisation: Linear, Polynomial, and RBF**

**C এবং Gamma এর প্রভাব বোঝা**

RBF kernel ব্যবহার করলে C এবং gamma সবচেয়ে গুরুত্বপূর্ণ parameter। আমরা বিভিন্ন মান ব্যবহার করে accuracy তুলনা করি।

```python
def evaluate_svm_c_gamma(X_train, X_test, y_train, y_test, C_values, gamma_values):
    results = []
    for C in C_values:
        for gamma in gamma_values:
            model = SVC(kernel='rbf', C=C, gamma=gamma, random_state=42)
            model.fit(X_train, y_train)
            y_pred = model.predict(X_test)
            acc = accuracy_score(y_test, y_pred)
            results.append({'C': C, 'gamma': gamma, 'accuracy': acc})
    return pd.DataFrame(results)
```

**Hyperparameter Grid তৈরি**

```python
C_values = [0.1, 1.0, 10.0]
```
