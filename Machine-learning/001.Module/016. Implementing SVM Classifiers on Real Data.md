**15.8 Implementing SVM Classifiers on Real Data**

**Implementing SVM Classifiers on Real Data**

এতক্ষণ আমরা toy dataset ব্যবহার করে SVM-এর আচরণ বুঝেছি। এই মডিউলে আমরা **বাস্তব (real-world) ডেটা** ব্যবহার করে দেখবো:

*   SVM বাস্তবে কিভাবে কাজ করে
*   model performance কিভাবে মূল্যায়ন করা হয়
*   hyperparameter পরিবর্তনে ফলাফল কিভাবে বদলায়

**কেন Real Dataset জরুরি?**

Toy dataset দিয়ে বোঝা সহজ হলেও:
*   বাস্তব ডেটায় noise থাকে
*   feature সংখ্যা বেশি হয়
*   class imbalance থাকতে পারে

একটি ভালো machine learning model বাস্তব ডেটায় কেমন কাজ করে, সেটাই আসল পরীক্ষা।

**Step 1: Breast Cancer Dataset লোড করা**

আমরা scikit-learn এর breast cancer dataset ব্যবহার করছি।

```python
cancer = load_breast_cancer()
X_bc = cancer.data
y_bc = cancer.target
```

**এই dataset-এর বৈশিষ্ট্য:**

| বিষয় | মান |
| :--- | :--- |
| Samples | 569 |
| Features | 30 |
| Classes | Malignant, Benign |

**Dataset সম্পর্কে প্রাথমিক ধারণা**

```python
print('Feature shape:', X_bc.shape)
print('Classes:', cancer.target_names)
```
এতে বোঝা যায় ডেটা high-dimensional এবং এটি একটি গুরুত্বপূর্ণ classification সমস্যা।

**Step 2: Train–Test Split এবং Stratification**

```python
X_bc_train, X_bc_test, y_bc_train, y_bc_test = train_test_split(
    X_bc, y_bc,
    test_size=0.2,
    random_state=42,
    stratify=y_bc
)
```
**Stratify কেন?**
*   Train ও test উভয় সেটে class ratio একই থাকে।
*   Model evaluation আরও নির্ভরযোগ্য হয়।

**Step 3: Feature Scaling**

SVM distance-এর উপর কাজ করে, তাই scaling বাধ্যতামূলক।

```python
scaler_bc = StandardScaler()
X_bc_train_scaled = scaler_bc.fit_transform(X_bc_train)
X_bc_test_scaled = scaler_bc.transform(X_bc_test)
```

**Step 4: RBF Kernel দিয়ে SVM Train করা**

বাস্তব ডেটার জন্য RBF kernel সাধারণত ভালো কাজ করে।

```python
svc_bc = SVC(
    kernel='rbf',
    C=1.0,
    gamma='scale',
    random_state=42
)
svc_bc.fit(X_bc_train_scaled, y_bc_train)
```

**Step 5: Prediction এবং Accuracy**

```python
y_bc_pred = svc_bc.predict(X_bc_test_scaled)
acc_bc = accuracy_score(y_bc_test, y_bc_pred)
print("Accuracy with RBF: ", acc_bc)
```
Accuracy আমাদের একটি সামগ্রিক ধারণা দেয়, কিন্তু একে একমাত্র মেট্রিক হিসেবে ধরা উচিত নয়।

**Step 6: Classification Report বিশ্লেষণ**

```python
print(classification_report(
    y_bc_test,
    y_bc_pred,
    target_names=cancer.target_names
))
```

**Classification report থেকে যা জানা যায়:**
*   **Precision:** Positive prediction কতটা সঠিক।
*   **Recall:** আসল positive কতটা ধরা পড়েছে (Medical dataset-এ এটি খুব গুরুত্বপূর্ণ)।
*   **F1-score:** Precision ও Recall-এর ভারসাম্য।

**Step 7: Confusion Matrix**

```python
cm = confusion_matrix(y_bc_test, y_bc_pred)
print(cm)
```
এটি দেখায় কোন class বেশি ভুল হচ্ছে এবং false positive/false negative সংখ্যা কত।

**C এবং Gamma এর প্রভাব বোঝা (Hyperparameter Tuning)**

RBF kernel ব্যবহার করলে `C` এবং `gamma` সবচেয়ে গুরুত্বপূর্ণ parameter। আমরা বিভিন্ন মান ব্যবহার করে accuracy তুলনা করি।

```python
def evaluate_svm_c_gamma(X_train, X_test, y_train, y_test, C_values, gamma_values):
    results = []
    for C in C_values:
        for gamma in gamma_values:
            model = SVC(kernel='rbf', C=C, gamma=gamma, random_state=42)
            model.fit(X_train, y_train)
            y_pred = model.predict(X_test)
            acc = accuracy_score(y_test, y_pred)
            results.append({'C': C, 'gamma': gamma, 'accuracy': acc})
    return pd.DataFrame(results)
```

**Hyperparameter Grid তৈরি ও ফলাফল বিশ্লেষণ**

```python
C_values = [0.1, 1.0, 10.0]
gamma_values = ['scale', 0.01, 0.1, 1.0]

df_hyper = evaluate_svm_c_gamma(
    X_bc_train_scaled, X_bc_test_scaled,
    y_bc_train, y_bc_test,
    C_values, gamma_values
)

df_hyper.sort_values('accuracy', ascending=False)
```
এখান থেকে বোঝা যায় যে সব সময় default মান সেরা হয় না; `C` এবং `gamma` ঠিকভাবে tune করলে performance বাড়ে।

**এই মডিউল থেকে শিক্ষণীয়**

*   **Real dataset:** Toy data থেকে অনেক বেশি জটিল।
*   **Scaling:** SVM-এর জন্য অপরিহার্য।
*   **RBF kernel:** বাস্তবে সবচেয়ে কার্যকর।
*   **Evaluation:** Accuracy ছাড়াও report (Precision, Recall) দরকার।
*   **Hyperparameter tuning:** সঠিক টিউনিং Performance উন্নত করে।

**Bayes’ Theorem & Naive Assumption**

**১. বেইজ থিওরেমের সূত্র ও উপাদান**

![Bayes Theorem Formula](https://phi.sgp1.digitaloceanspaces.com/website-prod-images/public/files/1766140688890.png)

*   **Y** = ক্লাস লেবেল (স্পাম/নট স্পাম, রোগ/স্বাস্থ্য)
*   **X** = ফিচার (শব্দ, লক্ষণ, বৈশিষ্ট্য)
*   **P(Y)** = প্রায়র প্রোবাবিলিটি (ক্লাসের সাধারণ সম্ভাবনা)
*   **P(X | Y)** = লাইকলিহুড (ক্লাস সত্য হলে ফিচারের সম্ভাবনা)
*   **P(X)** = ফিচারের সামগ্রিক সম্ভাবনা
*   **P(Y | X)** = পোস্টেরিয়র প্রোবাবিলিটি (ফিচার দেখে ক্লাসের সম্ভাবনা)

**Types of Naive Bayes Models**

## **১. Gaussian Naive Bayes**

**কি কাজ করে:**

*   কন্টিনিউয়াস নিউমেরিক্যাল ডেটা এর জন্য উপযুক্ত
*   ডেটা বেল কার্ভ অথবা সাধারণ বণ্টন মেনে চলে এমন ফিচারগুলোর জন্য

**যেসব ডেটার জন্য ব্যবহারযোগ্য:**

*   উচ্চতা ও ওজন পরিমাপ
*   তাপমাত্রা রিডিং
*   রক্তচাপের মান
*   সেন্সর ডেটা স্ট্রিম
*   ল্যাব টেস্টের ফলাফল

**গাণিতিক ধারণা:**

*   প্রতিটি ক্লাসের জন্য ফিচারের **mean** এবং **standard deviation** হিসাব করে
*   একটি নতুন ডেটা পয়েন্ট দেখলে তা কোন ক্লাসের ডিস্ট্রিবিউশনে বেশি ফিট হয় তা বের করে

**উদাহরণ:**

**মেডিক্যাল ডায়াগনোসিস:** রোগীর হার্ট রেট, বডি টেম্পারেচার, ব্লাড প্রেশার দেখে রোগ শনাক্তকরণ

## **২. Multinomial Naive Bayes**

**কি কাজ করে:**

*   কাউন্ট-ভিত্তিক ডিসক্রিট ফিচার এর জন্য
*   ফিচার কতবার ঘটেছে সেই সংখ্যা গুরুত্বপূর্ণ
*   টেক্সট ডেটার জন্য সবচেয়ে বেশি ব্যবহৃত

**যেসব ডেটার জন্য ব্যবহারযোগ্য:**

*   ডকুমেন্টে শব্দের সংখ্যা
*   ইমেইলে টার্ম ফ্রিকোয়েন্সি
*   ক্যাটেগরিকাল ইভেন্টের ঘটনা সংখ্যা
*   ডকুমেন্ট-টার্ম ম্যাট্রিক্স

**এনএলপিতে চ্যাম্পিয়ন:**

*   স্পাম ডিটেকশন
*   সেন্টিমেন্ট অ্যানালিসিস
*   টপিক ক্যাটাগরাইজেশন
*   ডকুমেন্ট ক্লাসিফিকেশন

**গুরুত্বপূর্ণ বিষয়:**

শব্দ **কতবার** এসেছে সেটা গণনা করে, শুধু আছে কিনা সেটা নয়

## **৩. Bernoulli Naive Bayes**

**কি কাজ করে:**

*   বাইনারি/বুলিয়ান ফিচার এর জন্য
*   ফিচার আছে নাকি নেই শুধু সেটাই গুরুত্বপূর্ণ
*   কাউন্ট নয়, শুধু উপস্থিতি ম্যাটার করে

**যেসব ডেটার জন্য ব্যবহারযোগ্য:**

*   শব্দের উপস্থিতি ডিটেকশন
*   বাইনারি টেক্সট ফিচার
*   হ্যাঁ/না সার্ভে রেসপন্স
*   ফিচার এক্সিসটেন্স প্যাটার্ন

**উদাহরণ:**

সাধারণ স্পাম ফিল্টার যেখানে শুধু নির্দিষ্ট শব্দ আছে কিনা দেখে স্পাম চিহ্নিত করা হয়

## **৪. কোন প্রকার কখন ব্যবহার করবেন?**

**ডিসিশন ফ্রেমওয়ার্ক:**

**১. আপনার ডেটা দেখুন প্রথমে:**

*   ফিচারের টাইপ দেখেই বেছে নিন

**২. বাইনারি প্যাটার্ন? → বার্নোলি**

*   উপস্থিতি/অনুপস্থিতি ফিচার
*   ছোট টেক্সট যেখানে শুধু শব্দ আছে কিনা ম্যাটার করে

**৩. টেক্সট ডেটা? → মাল্টিনোমিয়াল**

*   শব্দ সংখ্যা বা টার্ম ফ্রিকোয়েন্সি থাকলে
*   এনএলপির জন্য ডিফল্ট চয়েজ
*   ফ্রিকোয়েন্সি প্যাটার্ন ক্যাপচার করে

**৪. সংখ্যাভিত্তিক মেজারমেন্ট? → গাউসিয়ান**

*   কন্টিনিউয়াস ফিচার (সেন্সর ডেটা, মেডিক্যাল ভাইটাল)
*   নরমাল ডিস্ট্রিবিউশন অনুসরণ করলে

## **৬. প্র্যাকটিক্যাল উদাহরণ ডেটা:**

**বার্নোলির জন্য (বাইনারি):**

```python
[1, 0, 1]
[0, 1, 1]
[0, 1, 0]
```

(1 = আছে, 0 = নেই)

**মাল্টিনোমিয়ালের জন্য (কাউন্ট):**

```python
[4, 1, 2]
[3, 0, 0]
[0, 2, 3]
```

**Implementing Naive Bayes on a Dataset: GaussianNB**

এই মডিউলটি মূলত **Gaussian Naive Bayes** অ্যালগরিদম ব্যবহার করে একটি **Breast Cancer Classification** প্রজেক্টের সম্পূর্ণ ইমপ্লিমেন্টেশন এবং ব্যাখ্যা। নিচে ধাপে ধাপে পুরো প্রক্রিয়াটি সহজ ভাষায় ব্যাখ্যা করা হলো:

### **১. নেভ বেইজ (Naive Bayes) কী?**
এটি একটি প্রোবাবিলিস্টিক (সম্ভাবনা-ভিত্তিক) অ্যালগরিদম।
*   **Naive (সরল):** এটি ধরে নেয় যে ডেটার প্রতিটি ফিচার একে অপরের থেকে স্বাধীন (Independent)।
*   **Bayes:** এটি বেইজ থিওরেমের ওপর ভিত্তি করে কাজ করে।

**সূত্র:**
$$P(A|B) = \frac{P(B|A) \times P(A)}{P(B)}$$
*সহজ কথায়:* নতুন কোনো ডেটা (B) দেখলে, সেটি কোন ক্লাসে (A) পড়ার সম্ভাবনা কত, তা এটি বের করে।

---

### **২. কেন Gaussian Naive Bayes (GNB)?**
নেভ বেইজের বিভিন্ন প্রকারভেদ আছে। আমরা **Gaussian** ব্যবহার করছি কারণ:
*   আমাদের ডেটাসেটের ফিচারগুলো **Continuous/Numeric** (যেমন: টিউমারের ব্যাসার্ধ, টেক্সচার, এরিয়া ইত্যাদি)।
*   ধরে নেওয়া হয় এই ডেটাগুলো একটি **Normal Distribution** বা Bell Curve মেনে চলে।

---

### **৩. প্রজেক্ট ইমপ্লিমেন্টেশন (ধাপে ধাপে)**

#### **ধাপ ১: ডেটা লোড করা**
আমরা `sklearn` থেকে ব্রেস্ট ক্যানসার ডেটাসেট ব্যবহার করছি।
*   **স্যাম্পল:** ৫৬৯ জন রোগীর তথ্য।
*   **ফিচার:** ৩০টি (সবই সংখ্যাত্মক বা numeric)।
*   **টার্গেট ক্লাস:** ২ধরন -
    1.  Malignant (ক্যানসার/ক্ষতিকর) - 0
    2.  Benign (ক্যানসার নয়/নিরাপদ) - 1

#### **ধাপ ২: ডেটা এক্সপ্লোরেশন**
আমরা দেখেছি ডেটাতে **Benign (৩৫৭টি)** কেস **Malignant (২১২টি)** এর চেয়ে বেশি। অর্থাৎ ডেটা কিছুটা ইমব্যালান্সড, তবে খুব বেশি সমস্যা নয়।

#### **ধাপ ৩: ভিজ্যুয়ালাইজেশন**
'mean radius' ফিচারের হিস্টোগ্রাম দেখে বোঝা যায়:
*   Malignant টিউমারের ব্যাসার্ধ সাধারণত বড় হয়।
*   Benign টিউমারের ব্যাসার্ধ ছোট হয়।
*   তবে মাঝখানে কিছু **Overlap** আছে, যার কারণে মেশিন লার্নিং মডেল প্রয়োজন (শুধু if-else দিয়ে আলাদা করা যাবে না)।

#### **ধাপ ৪: ট্রেন-টেস্ট স্প্লিট (খুব গুরুত্বপূর্ণ)**
আমরা ডেটাকে ৭৫% ট্রেনিং এবং ২৫% টেস্টিং সেটে ভাগ করেছি।
*   `stratify=y` ব্যবহার করা হয়েছে।
    *   এর ফলে ট্রেনিং এবং টেস্টিং উভয় সেটেই ক্যানসার ও নন-ক্যানসার রোগীর অনুপাত সমান থাকে। এটি মডেলের সঠিক লার্নিংয়ের জন্য জরুরি।

#### **ধাপ ৫: মডেল ট্রেনিং**
```python
gnb = GaussianNB()
gnb.fit(X_train, y_train)
```
ট্রেনিংয়ের সময় মডেল আসলে কী শেখে?
*   সে প্রতিটি ক্লাসের জন্য প্রতিটি ফিচারের **Mean (গড়)** এবং **Variance (বিচ্যুতি)** মুখস্থ করে রাখে।

---

### **৪. মডেল ইভালুয়েশন (ফলাফল যাচাই)**

#### **অ্যাকুরেসি (Accuracy)**
মডেলটি **৯৩.৭%** সঠিক উত্তর দিয়েছে। অর্থাৎ ১৪৩ জন রোগীর মধ্যে ১৩৪ জনের রোগ সঠিক শনাক্ত করেছে।

#### **কনফিউশন ম্যাট্রিক্স (Confusion Matrix)**
এটি আমাদের ভুলের ধরন দেখায়:
*   **True Positive (TP):** ৪৬ টি সঠিক Malignant শনাক্ত হয়েছে।
*   **True Negative (TN):** ৮৮ টি সঠিক Benign শনাক্ত হয়েছে।
*   **False Negative (FN):** ৭ টি Malignant কেসকে মডেল ভুল করে Benign বলেছে। **(এটি মেডিক্যাল ক্ষেত্রে খুবই বিপজ্জনক!)**
*   **False Positive (FP):** ২ টি Benign কেসকে Malignant বলেছে।

#### **ক্লাসিফিকেশন রিপোর্ট (Precision & Recall)**
মেডিক্যাল টেস্টে শুধু অ্যাকুরেসি দেখলে চলে না, **Recall** বেশি গুরুত্বপূর্ণ।

*   **Recall (Sensitivity):** ০.৮৭ (৮৭%)
    *   এর মানে হলো, যতজন রোগীর আসলেই ক্যানসার ছিল, তাদের মধ্যে ৮৭% কে মডেল ধরতে পেরেছে। বাকি ১৩% মিস করেছে।
*   **Precision:** ০.৯৬ (৯৬%)
    *   মডেল যাদের ক্যানসার বলেছে, তাদের ৯৬% আসলেই ক্যানসার আক্রান্ত।

### **সারসংক্ষেপ**
Gaussian Naive Bayes এই ডেটাসেটে বেশ ভালো কাজ করেছে (৯৩%+ অ্যাকুরেসি)। এটি দ্রুত এবং সহজ, তবে ক্যানসার ডিটেকশনের জন্য আমরা চাইবো **Recall** যেন আরও বেশি হয় (যাতে কোনো ক্যানসার রোগী বাদ না পড়ে)।
