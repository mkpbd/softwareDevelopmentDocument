**18.2 Introduction to Random Forest**

**Introduction to Random Forest**

Random Forest একটি শক্তিশালী **ensemble learning algorithm**, যা মূলত একাধিক Decision Tree একসাথে ব্যবহার করে একটি চূড়ান্ত সিদ্ধান্ত নেয়। এটি classification এবং regression—দুই ধরনের সমস্যার ক্ষেত্রেই অত্যন্ত কার্যকরভাবে কাজ করে। বাস্তব জীবনের ডেটায় ভালো পারফরম্যান্স এবং overfitting কম হওয়ার কারণে Random Forest বর্তমানে সবচেয়ে বেশি ব্যবহৃত machine learning অ্যালগরিদমগুলোর একটি।

এই সেকশনে আমরা Random Forest-এর মূল ধারণা, কেন এটি একক Decision Tree-এর চেয়ে ভালো কাজ করে এবং “forest” ধারণাটির পেছনের যুক্তি বুঝব।

**Why Random Forest?**

একটি single Decision Tree সাধারণত খুব সহজে training data মুখস্থ করে ফেলে, যাকে আমরা **overfitting** বলি। এর ফলে training accuracy বেশি হলেও নতুন বা unseen data-তে পারফরম্যান্স খারাপ হয়।

Random Forest এই সমস্যার সমাধান করে তিনটি মূল কৌশলের মাধ্যমে:

1.  একাধিক Decision Tree ব্যবহার
2.  প্রতিটি tree আলাদা ডেটায় train করা
3.  প্রতিটি tree আলাদা feature subset ব্যবহার করে সিদ্ধান্ত নেওয়া

এই সম্মিলিত পদ্ধতিই Random Forest-কে একটি robust এবং reliable model হিসেবে গড়ে তোলে।

**Understanding the “Forest” Metaphor**

Random Forest নামটি আসলে একটি রূপক (metaphor)।

*   **Tree** → একটি Decision Tree, যা নিজে নিজে সিদ্ধান্ত নিতে পারে
*   **Forest** → অনেকগুলো Decision Tree-এর সমষ্টি

একটি গাছ ভুল সিদ্ধান্ত নিতে পারে, কিন্তু অনেকগুলো গাছ একসাথে সিদ্ধান্ত নিলে ভুলের সম্ভাবনা অনেক কমে যায়। ঠিক এই ধারণার উপর ভিত্তি করেই Random Forest কাজ করে।

প্রতিটি tree একটি আলাদা দৃষ্টিভঙ্গি থেকে সমস্যাটিকে দেখে এবং শেষে সবাই মিলে একটি যৌথ সিদ্ধান্তে পৌঁছায়।

**Ensemble Learning Concept**

Random Forest হলো **ensemble learning** পদ্ধতির একটি ক্লাসিক উদাহরণ।

Ensemble learning বলতে বোঝায়:

একাধিক দুর্বল বা মাঝারি মানের model একত্রিত করে একটি শক্তিশালী model তৈরি করা।

Random Forest-এ:

*   **Classification problem** হলে প্রতিটি tree একটি class predict করে
*   Final output নির্ধারিত হয় **majority voting** এর মাধ্যমে
*   যে class-টি সবচেয়ে বেশি tree predict করে, সেটিই final prediction

Regression-এর ক্ষেত্রে:

*   প্রতিটি tree একটি numeric value predict করে
*   Final output হয় সব prediction-এর **average**

এই aggregation প্রক্রিয়াই Random Forest-কে স্থিতিশীল করে তোলে।

**Bootstrap Sampling: Creating Diversity**

Random Forest-এর একটি গুরুত্বপূর্ণ ভিত্তি হলো **bootstrap sampling**।

Bootstrap sampling মানে:

*   মূল dataset থেকে replacement সহ randomভাবে sample নেওয়া
*   একই data point একাধিকবার আসতে পারে
*   কিছু data point বাদও পড়তে পারে

প্রতিটি Decision Tree আলাদা bootstrap sample দিয়ে train হয়। এর ফলে প্রতিটি tree আলাদা pattern শেখে এবং সব tree একরকম আচরণ করে না।

এই বৈচিত্র্য (diversity) ensemble-এর শক্তি বাড়ায়।

**Feature Randomness: Reducing Correlation**

শুধু আলাদা ডেটা নয়, Random Forest প্রতিটি split-এ **random subset of features** ব্যবহার করে।

এর ফলাফল:

*   সব tree একই dominant feature-এর উপর নির্ভর করে না
*   Tree-গুলোর মধ্যে correlation কমে যায়
*   Overfitting আরও কম হয়

এই randomness Random Forest-কে single Decision Tree বা bagging-এর তুলনায় আরও উন্নত করে।

**Why Random Forest Works So Well**

Random Forest কার্যকর হওয়ার পেছনে তিনটি প্রধান স্তম্ভ রয়েছে:

1.  **Multiple Decision Trees**
    অনেকগুলো model একসাথে কাজ করে
2.  **Bootstrap Sampling**
    আলাদা training data প্রতিটি tree-কে আলাদা করে তোলে
3.  **Feature Randomness**
    Tree-গুলোর মধ্যে dependency কমায়

এই তিনটি একসাথে Random Forest-কে highly accurate এবং overfitting-resistant model বানায়।

**What You Should Take From This Section**

এই introduction শেষে আপনার পরিষ্কারভাবে বোঝা উচিত:

*   Random Forest কী এবং কেন এটি ব্যবহৃত হয়
*   Ensemble learning ধারণাটি কীভাবে কাজ করে
*   কেন একাধিক Decision Tree একসাথে ব্যবহার করলে ভালো ফল পাওয়া যায়
*   Bootstrap sampling এবং feature randomness-এর ভূমিকা

পরবর্তী সেকশনগুলোতে আমরা দেখব কীভাবে এই ধারণাগুলো বাস্তবে প্রয়োগ করা হয় এবং কীভাবে Random Forest model তৈরি, train এবং evaluate করা হয়।

**18.3 Decision Trees & Ensemble Concept**

**Decision Trees & Ensemble Concept**

Random Forest বুঝতে হলে প্রথমে **Decision Tree** কী এবং কেন একক Decision Tree অনেক সময় নির্ভরযোগ্য হয় না—এটি পরিষ্কারভাবে জানা জরুরি। এই মডিউলে আমরা Decision Tree-এর গঠন, সিদ্ধান্ত নেওয়ার প্রক্রিয়া, সীমাবদ্ধতা এবং কীভাবে Ensemble Learning এই সমস্যাগুলো সমাধান করে তা আলোচনা করব।

**What is a Decision Tree?**

Decision Tree হলো একটি **tree-structured predictive model**, যা ধাপে ধাপে কিছু সিদ্ধান্তের মাধ্যমে চূড়ান্ত পূর্বাভাস দেয়। এটি দেখতে অনেকটা flowchart-এর মতো, যেখানে প্রতিটি ধাপে একটি প্রশ্নের উত্তর দিতে হয়।

Decision Tree-এর প্রধান অংশগুলো হলো:

*   **Root Node:** এখান থেকেই সিদ্ধান্ত নেওয়ার প্রক্রিয়া শুরু হয়
*   **Internal Nodes:** feature-এর উপর ভিত্তি করে ডেটা ভাগ করার পয়েন্ট
*   **Branches:** সিদ্ধান্তের সম্ভাব্য ফলাফল অনুযায়ী পথ
*   **Leaf Nodes:** শেষ ধাপ, যেখানে final prediction পাওয়া যায়

Root node থেকে শুরু করে internal node গুলো দিয়ে এগোতে এগোতে শেষ পর্যন্ত একটি leaf node-এ পৌঁছানো হয়, সেখানেই model-এর চূড়ান্ত সিদ্ধান্ত পাওয়া যায়।

**How Decision Trees Make Decisions**

Decision Tree মূলত **splitting process** এর মাধ্যমে কাজ করে। প্রতিটি node-এ algorithm চেষ্টা করে ডেটাকে সবচেয়ে ভালোভাবে ভাগ করতে।

এই প্রক্রিয়াটি ধাপে ধাপে ঘটে:

1.  **Evaluate All Features**
    ডেটাসেটের প্রতিটি feature এবং সম্ভাব্য split point বিবেচনা করা হয়
2.  **Measure Purity Gain**
    প্রতিটি split কতটা ভালোভাবে class আলাদা করতে পারছে বা variance কমাচ্ছে, তা হিসাব করা হয়
    Classification-এর ক্ষেত্রে সাধারণত Gini impurity বা Information Gain ব্যবহৃত হয়
3.  **Choose Best Split**
    যে split সবচেয়ে বেশি purity বাড়ায়, সেটি নির্বাচন করা হয়
4.  **Repeat Recursively**
    একই প্রক্রিয়া প্রতিটি নতুন branch-এ প্রয়োগ করা হয় যতক্ষণ না stopping condition পূরণ হয়

এই greedy পদ্ধতির কারণে Decision Tree খুব দ্রুত complex pattern শিখতে পারে।

**Limitations of Decision Trees**

যদিও Decision Tree বোঝা সহজ এবং ব্যাখ্যাযোগ্য, তবুও এর কিছু গুরুতর সীমাবদ্ধতা রয়েছে।

*   **Overfitting Risk**
    Tree যদি খুব গভীর হয়, তাহলে এটি training data মুখস্থ করে ফেলে। এতে model নতুন ডেটায় ভালো কাজ করতে পারে না।
*   **Learning Noise**
    Deep tree অনেক সময় ডেটার random noise-কেও pattern ভেবে শিখে নেয়, ফলে decision boundary অপ্রয়োজনীয়ভাবে জটিল হয়ে যায়।
*   **High Variance**
    Training data সামান্য পরিবর্তন হলেই সম্পূর্ণ আলাদা একটি tree তৈরি হতে পারে। এই অস্থিরতা single Decision Tree-কে অনির্ভরযোগ্য করে তোলে।

**Bias and Variance Perspective**

Decision Tree সাধারণত **low bias কিন্তু high variance** বৈশিষ্ট্য প্রদর্শন করে।

*   **Low Bias:** জটিল এবং non-linear pattern ভালোভাবে ধরতে পারে
*   **High Variance:** ডেটা পরিবর্তনের সাথে prediction অনেক বদলে যায়

Low bias মানে model খুব expressive, কিন্তু high variance মানে এটি overfitting-এর দিকে ঝুঁকে থাকে। এই imbalance-ই Decision Tree-এর মূল সমস্যা।

**What Is Ensemble Learning?**

Ensemble Learning হলো এমন একটি পদ্ধতি যেখানে **একাধিক model একসাথে ব্যবহার করে** একটি চূড়ান্ত prediction তৈরি করা হয়।

Ensemble-এর মূল ধারণা হলো:
একটি model ভুল করতে পারে, কিন্তু অনেকগুলো model একসাথে কাজ করলে সেই ভুলগুলো কমে যায়।

Ensemble Learning সাধারণত তিনটি ধাপে কাজ করে:
1.  একাধিক base model train করা
2.  প্রতিটি model থেকে আলাদা prediction নেওয়া
3.  সব prediction একত্রিত করে final output তৈরি করা

**How Ensembles Combine Models**

Ensemble model কীভাবে সিদ্ধান্ত নেয়, তা problem type-এর উপর নির্ভর করে।

**Classification Tasks**
Classification সমস্যায় **majority voting** ব্যবহৃত হয়।
যে class-টি সবচেয়ে বেশি model predict করে, সেটিই final output।

**Regression Tasks**
Regression সমস্যায় সব model-এর prediction-এর **average** নেওয়া হয়।

| Base Models | Individual Predictions | Aggregation | Final Prediction |
| :--- | :--- | :--- | :--- |
| Multiple Models | আলাদা আলাদা output | Voting / Averaging | একক ফলাফল |

**Why Ensembles Are Effective**

Ensemble Learning কার্যকর হওয়ার পেছনে কয়েকটি গুরুত্বপূর্ণ কারণ রয়েছে।

*   **Diverse Perspectives**
    প্রতিটি model ডেটাকে ভিন্নভাবে দেখে এবং ভিন্ন ভুল করে।
*   **Errors Cancel Out**
    একটি model বেশি অনুমান করলে আরেকটি কম অনুমান করতে পারে। একত্রে নিলে ভুল কমে যায়।
*   **Increased Stability**
    Single Decision Tree-এর high variance সমস্যা অনেকটাই কমে যায়। Ensemble model বেশি স্থিতিশীল এবং নির্ভরযোগ্য হয়।

এই কারণেই ensemble পদ্ধতি Decision Tree-এর দুর্বলতাগুলো ঢেকে দেয় এবং Random Forest-এর মতো শক্তিশালী algorithm তৈরি করে।

**Key Takeaway of This Module**

এই মডিউল শেষে আপনার স্পষ্টভাবে বোঝা উচিত:

*   Decision Tree কীভাবে কাজ করে
*   কেন single Decision Tree overfitting ও high variance-এর শিকার হয়
*   Ensemble Learning কী এবং কেন এটি কার্যকর
*   কীভাবে ensemble Decision Tree-এর দুর্বলতা দূর করে

**18.4 Bootstrap Sampling & Feature Randomness**

**Bootstrap Sampling & Feature Randomness**

Random Forest-এর সবচেয়ে গুরুত্বপূর্ণ শক্তি আসে **randomness** থেকে। এই randomness ই একাধিক Decision Tree-কে আলাদা করে তোলে এবং পুরো ensemble-কে শক্তিশালী, স্থিতিশীল ও generalizable করে।

এই মডিউলে আমরা দেখব:

*   Randomness কেন এত গুরুত্বপূর্ণ
*   Random Forest কীভাবে দুই জায়গায় randomness ব্যবহার করে
*   Bootstrap sampling কী এবং কীভাবে এটি কাজ করে
*   Feature randomness কীভাবে tree-গুলোর মধ্যে পার্থক্য তৈরি করে
*   Bagging-এর সাথে Bootstrap sampling-এর সম্পর্ক

**Why Randomness Matters**

যদি সব Decision Tree একরকম হয়, তাহলে তারা একই ভুল করবে। এতে ensemble ব্যবহার করার কোনো বাস্তব সুবিধা পাওয়া যায় না।

Randomness কেন প্রয়োজন, তা নিচের ধারণাগুলো থেকে বোঝা যায়:

| বিষয় | ব্যাখ্যা |
| :--- | :--- |
| Similar Trees, Similar Errors | একরকম tree একই ধরনের ভুল বারবার করে |
| Randomness Creates Diversity | randomness tree-গুলোর মধ্যে ভিন্নতা তৈরি করে |
| Diversity Drives Performance | ভিন্ন ভিন্ন tree একত্রে কাজ করলে ভুল কমে |

Random Forest-এর মূল লক্ষ্য হলো এমন tree তৈরি করা, যেগুলো একে অপরের মতো নয় কিন্তু একসাথে কাজ করতে পারে।

**Two Sources of Randomness in Random Forest**

Random Forest training-এর সময় দুইটি গুরুত্বপূর্ণ জায়গায় randomness যোগ করে:

| Randomness-এর উৎস | কীভাবে কাজ করে |
| :--- | :--- |
| Bootstrap Sampling | প্রতিটি tree আলাদা training dataset পায় |
| Feature Randomness | প্রতিটি split-এ আলাদা feature subset ব্যবহার হয় |

এই দুইটি একসাথে নিশ্চিত করে যে কোনো দুইটি tree কখনোই পুরোপুরি একরকম না হয়।

**Bootstrap Sampling Explained**

Bootstrap sampling হলো এমন একটি পদ্ধতি যেখানে মূল dataset থেকে **replacement সহ random sampling** করা হয়।

এর বৈশিষ্ট্যগুলো হলো:

*   নতুন dataset-এর size মূল dataset-এর সমান
*   কিছু data point একাধিকবার আসতে পারে
*   কিছু data point একেবারেই নাও আসতে পারে
*   প্রতিটি tree আলাদা bootstrap sample দিয়ে train হয়

এই প্রক্রিয়ায় প্রতিটি Decision Tree ডেটার একটি ভিন্ন সংস্করণ দেখে।

**Bootstrap Sampling Example**

ধরা যাক আমাদের মূল dataset হলো:

**Original Dataset**
`[1, 2, 3, 4, 5, 6, 7, 8]`

Bootstrap sampling করার পর একটি সম্ভাব্য sample হতে পারে:

**Bootstrap Sample**
`[2, 8, 2, 1, 5, 2, 7, 8]`

এখানে দেখা যাচ্ছে:

*   2 তিনবার এসেছে
*   8 দুইবার এসেছে
*   3, 4, 6 একবারও আসেনি

এই variation-ই tree-গুলোর মধ্যে পার্থক্য তৈরি করে।

**Out-of-Bag (OOB) Samples**

Bootstrap sampling-এর সময় সব data point নির্বাচিত হয় না। যেগুলো নির্বাচিত হয় না, সেগুলোকে বলা হয় **Out-of-Bag samples**।

| বৈশিষ্ট্য | ব্যাখ্যা |
| :--- | :--- |
| Not Selected | গড়ে প্রায় 37% ডেটা বাদ পড়ে |
| Unique for Each Tree | প্রতিটি tree-এর OOB আলাদা |
| Built-in Validation | আলাদা validation set ছাড়াই performance মাপা যায় |

OOB samples ব্যবহার করে Random Forest নিজেই তার performance estimate করতে পারে।

**Effect of Bootstrap Sampling**

Bootstrap sampling Random Forest-এর উপর যেভাবে প্রভাব ফেলে:

| প্রভাব | ফলাফল |
| :--- | :--- |
| Different Data Exposure | প্রতিটি tree ভিন্ন pattern শেখে |
| Reduced Correlation | tree-গুলোর মধ্যে similarity কমে |
| Lower Variance | ensemble আরও স্থিতিশীল হয় |

এতে Random Forest overfitting থেকে অনেকটাই রক্ষা পায়।

**Feature Randomness at Each Split**

Random Forest শুধু ডেটা নয়, feature নির্বাচনেও randomness ব্যবহার করে।

প্রতিটি node-এ যা ঘটে:

1.  শুরুতে সব feature available থাকে
2.  প্রতিটি split-এ randomভাবে কিছু feature বেছে নেওয়া হয়
3.  শুধু এই subset-এর মধ্য থেকেই best split নির্বাচন করা হয়

Classification-এর ক্ষেত্রে সাধারণত √n সংখ্যক feature নেওয়া হয়, যেখানে n হলো মোট feature সংখ্যা।

**Feature Randomness Example**

ধরা যাক একটি credit risk model-এর feature গুলো হলো:
Age, Income, Debt, Credit History, Employment Status

| Tree | Random Feature Subset | Chosen Split |
| :--- | :--- | :--- |
| Tree A | Income, Debt | Debt > 50,000 |
| Tree B | Age, Credit History | Age < 30 |
| Tree C | Employment Status, Income | Income > 75,000 |

একই data হলেও প্রথম split-এই tree-গুলোর সিদ্ধান্ত একেবারে আলাদা।

**Why Feature Randomness Matters**

Feature randomness একটি বড় সমস্যার সমাধান করে, যাকে বলা হয় **feature dominance**।

| সমস্যা | সমাধান |
| :--- | :--- |
| Dominant Feature | শক্তিশালী feature সব tree-এ বারবার আসে |
| Random Subset | tree-গুলো বিকল্প সিদ্ধান্ত পথ অনুসন্ধান করে |
| Diverse Trees | প্রতিটি tree নতুন insight যোগ করে |

এতে ensemble আরও কার্যকর হয়।

**Combined Effect of Randomness**

Bootstrap sampling এবং feature randomness একসাথে কাজ করলে যে ফল পাওয়া যায়:

| উপাদান | প্রভাব |
| :--- | :--- |
| Data Randomness | প্রতিটি tree আলাদা dataset দেখে |
| Feature Randomness | প্রতিটি tree আলাদা decision path নেয় |
| Diverse Ensemble | tree-গুলো সত্যিকার অর্থে independent হয় |
| Stable Predictions | নতুন ডেটায় ভালো generalization হয় |

এই সম্মিলিত randomness-ই Random Forest-কে এত নির্ভরযোগ্য করে তোলে।

**From Bootstrap to Bagging – The Missing Link**

Bootstrap sampling একা যথেষ্ট নয়। আসল শক্তি আসে যখন:

| ধাপ | কাজ |
| :--- | :--- |
| Bootstrap Samples | একাধিক dataset তৈরি |
| Multiple Models | প্রতিটিতে আলাদা model train |
| Aggregation | prediction একত্রিত করা |

এই পুরো প্রক্রিয়াটিই **Bagging** নামে পরিচিত।

**What Is Bagging?**

Bagging বা Bootstrap Aggregating হলো একটি ensemble technique।

| ধাপ | ব্যাখ্যা |
| :--- | :--- |
| Create Samples | replacement সহ sampling |
| Train Models | একই algorithm, ভিন্ন ডেটা |
| Aggregate Output | voting বা averaging |

Classification-এ majority voting এবং regression-এ averaging ব্যবহার করা হয়।
Bagging-এর মূল লক্ষ্য হলো **variance কমানো এবং model stability বাড়ানো**।

*   Bootstrap sampling কীভাবে tree-গুলো আলাদা করে
*   Out-of-Bag sample কী এবং কেন গুরুত্বপূর্ণ

**How Training Works Internally**

Training-এর সময় Random Forest যা করে:

**Why Hyperparameter Tuning Matters**

Default parameter দিয়ে Random Forest ভালো কাজ করলেও সবসময় optimal হয় না।

Default সেটিং-এর কিছু সমস্যা:

*   Tree অনেক বেশি গভীর হতে পারে
*   Model overfit করতে পারে
*   Training অপ্রয়োজনীয়ভাবে ধীর হতে পারে

Hyperparameter tuning-এর লক্ষ্য হলো **model structure উন্নত করা**, শুধু metric বাড়ানো নয়।

**Key Hyperparameters in Random Forest**

Random Forest-এর কয়েকটি গুরুত্বপূর্ণ hyperparameter নিচে দেওয়া হলো:

| Hyperparameter | কাজ |
| :--- | :--- |
| n_estimators | মোট decision tree সংখ্যা |
| max_depth | প্রতিটি tree কত গভীর হবে |
| min_samples_split | একটি node split করার জন্য minimum sample |
| max_features | প্রতিটি split-এ কত feature বিবেচনা হবে |

এই parameter গুলো model-এর bias–variance balance নিয়ন্ত্রণ করে।

**Defining the Parameter Grid**

GridSearchCV ব্যবহার করার আগে আমরা সম্ভাব্য parameter গুলোর একটি grid তৈরি করি।

```python
param_grid = {
    "n_estimators": [100, 150, 175, 200],
    "max_depth": [None, 5, 10, 15],
    "min_samples_split": [2, 3, 5],
    "max_features": ["sqrt", "log2"]
}
```

এটি model-কে বিভিন্ন configuration পরীক্ষা করার সুযোগ দেয়।

**GridSearchCV for Hyperparameter Tuning**

GridSearchCV প্রতিটি parameter combination দিয়ে model train করে এবং cross-validation ব্যবহার করে সেরা configuration নির্বাচন করে।

```python
grid_rf = GridSearchCV(
    RandomForestClassifier(random_state=42),
    param_grid,
    cv=5,
    scoring="f1",
    n_jobs=-1
)

grid_rf.fit(X_train, y_train)
```

এখানে:

*   cv=5 মানে 5-fold cross-validation
*   scoring="f1" কারণ class imbalance-এর ক্ষেত্রে এটি কার্যকর
*   n_jobs=-1 মানে সব CPU core ব্যবহার করা

**Best Parameters Found**

```python
print("Best parameters found:")
print(grid_rf.best_params_)
```

এই output থেকে বোঝা যায় কোন configuration সবচেয়ে ভালো কাজ করেছে।

**Evaluating the Tuned Model**

এখন আমরা tuned model দিয়ে test data-তে prediction করি।

```python
best_rf = grid_rf.best_estimator_
y_pred_best = best_rf.predict(X_test)

print(classification_report(
    y_test,
    y_pred_best,
    target_names=data.target_names
))
```

এখানে baseline model-এর সাথে tuned model-এর performance তুলনা করা উচিত।
