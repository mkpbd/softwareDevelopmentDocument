### **ধাপ ৬: ডিপ লার্নিং (Deep Learning) এর দুনিয়া**

**ডিপ লার্নিং কী?**
ডিপ লার্নিং হলো মেশিন লার্নিং-এর একটি উপশাখা, যা **কৃত্রিম নিউরাল নেটওয়ার্ক (Artificial Neural Networks - ANN)** এর উপর ভিত্তি করে তৈরি। আর এই নিউরাল নেটওয়ার্কের ধারণাটি এসেছে আমাদের নিজেদের মস্তিষ্কের গঠন থেকে।

**মস্তিষ্ক কীভাবে কাজ করে?**
আমাদের মস্তিষ্কে বিলিয়ন বিলিয়ন নিউরন আছে, যারা একে অপরের সাথে সংযুক্ত থেকে সিগন্যাল আদান-প্রদান করে এবং তথ্য প্রসেস করে। এই নিউরনগুলো স্তরে স্তরে সাজানো থাকে।

**কৃত্রিম নিউরাল নেটওয়ার্ক কী?**
এটি মানুষের মস্তিষ্কের একটি সরলীকৃত গাণিতিক মডেল।
*   এতেও কৃত্রিম নিউরন (যাকে **নোড - Node** বা **ইউনিট - Unit** বলা হয়) থাকে, যা কয়েকটি স্তরে (**লেয়ার - Layer**) সাজানো থাকে।
*   একটি বেসিক নিউরাল নেটওয়ার্কে তিনটি অংশ থাকে:
    1.  **ইনপুট লেয়ার (Input Layer):** এখানে আমরা ডেটা বা ফিচারগুলো দিই (যেমন: ছবির পিক্সেল)।
    2.  **হিডেন লেয়ার (Hidden Layers):** ইনপুট এবং আউটপুটের মাঝের স্তরগুলো। এখানেই আসল "চিন্তাভাবনা" বা প্যাটার্ন খোঁজার কাজটা হয়। একটি সাধারণ নিউরাল নেটওয়ার্কে একটি হিডেন লেয়ার থাকতে পারে। কিন্তু যখন অনেকগুলো (সাধারণত ২টির বেশি) হিডেন লেয়ার থাকে, তখন আমরা সেই নেটওয়ার্ককে "গভীর" বা **"ডিপ" (Deep)** বলি, আর সেই শেখার প্রক্রিয়াকে বলি **ডিপ লার্নিং**।
    3.  **আউটপুট লেয়ার (Output Layer):** এখানে আমরা চূড়ান্ত ফলাফল পাই (যেমন: ছবিতে বিড়াল আছে কি না)।



**কেন ডিপ লার্নিং এত শক্তিশালী?**
সাধারণ মেশিন লার্নিং মডেলে, আমাদের প্রায়ই ফিচার ইঞ্জিনিয়ারিং করে বলে দিতে হতো কোন ফিচারগুলো গুরুত্বপূর্ণ। কিন্তু ডিপ লার্নিং মডেল, বিশেষ করে ডিপ নিউরাল নেটওয়ার্ক, নিজে থেকেই ডেটার মধ্য থেকে গুরুত্বপূর্ণ ফিচারগুলো খুঁজে বের করতে বা শিখতে পারে। যেমন, একটি ছবি চেনার মডেলে, প্রথম দিকের লেয়ারগুলো হয়তো শুধু সরল রেখা বা প্রান্ত (edge) শনাক্ত করতে শেখে, মাঝের লেয়ারগুলো সেই রেখা ব্যবহার করে চোখ বা কানের মতো আকৃতি শনাক্ত করতে শেখে এবং শেষের লেয়ারগুলো সেই চোখ-কান ব্যবহার করে পুরো মুখমণ্ডলটি চিনতে শেখে। এই স্বয়ংক্রিয়ভাবে ফিচার শেখার ক্ষমতাই ডিপ লার্নিং-কে এত শক্তিশালী করেছে।

#### **টেনসরফ্লো (TensorFlow) ও কেরাস (Keras)**

ডিপ লার্নিং মডেল তৈরি করার জন্য আমাদের বিশেষায়িত লাইব্রেরির প্রয়োজন হয়।
*   **টেনসরফ্লো (TensorFlow):** গুগলের তৈরি একটি অত্যন্ত শক্তিশালী এবং জনপ্রিয় ওপেন-সোর্স ডিপ লার্নিং ফ্রেমওয়ার্ক।
*   **কেরাস (Keras):** এটি টেনসরফ্লো-এর উপরে থাকা একটি হাই-লেভেল API, যা দিয়ে খুব সহজে এবং দ্রুত নিউরাল নেটওয়ার্ক মডেল তৈরি করা যায়। এটি অনেকটা ডিপ লার্নিং-এর Lego ব্লকের মতো; আপনি শুধু ব্লকগুলো একটার পর একটা জুড়ে দিয়ে আপনার মডেল তৈরি করতে পারেন।

আমরা কেরাস ব্যবহার করব, কারণ এটি নতুনদের জন্য বোঝা এবং কোড করা অনেক সহজ।

### **প্রজেক্ট: হাতে লেখা সংখ্যা শনাক্তকরণ (Digit Recognition)**

এটি ডিপ লার্নিং-এর ক্লাসিক "Hello, World!" প্রজেক্ট। আমরা **MNIST** ডেটাসেট ব্যবহার করব, যেখানে ০ থেকে ৯ পর্যন্ত হাতে লেখা সংখ্যার হাজার হাজার ছবি (২৮x২৮ পিক্সেলের) এবং তাদের সঠিক লেবেল দেওয়া আছে। আমাদের কাজ হলো একটি নিউরাল নেটওয়ার্ক তৈরি করা, যা একটি নতুন হাতে লেখা সংখ্যার ছবি দেখে বলতে পারবে সেটি কোন সংখ্যা।

এটি একটি **মাল্টি-ক্লাস ক্লাসিফিকেশন** সমস্যা (১০টি ক্লাস: ০ থেকে ৯)।

#### **ধাপ ১: লাইব্রেরি ইম্পোর্ট এবং ডেটাসেট লোড করা**

কেরাসের মধ্যে MNIST ডেটাসেটটি আগে থেকেই দেওয়া থাকে।

```python
import tensorflow as tf
from tensorflow import keras
import numpy as np
import matplotlib.pyplot as plt

# MNIST ডেটাসেট লোড করি
(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()
```

#### **ধাপ ২: ডেটা বোঝা এবং প্রি-প্রসেসিং**

চলুন দেখি ডেটাগুলো কেমন।
```python
# ডেটার আকৃতি দেখি
print("ট্রেনিং ডেটার আকৃতি:", x_train.shape) # (60000, 28, 28) মানে ৬০,০০০ ছবি, প্রতিটির সাইজ ২৮x২৮ পিক্সেল
print("টেস্টিং ডেটার আকৃতি:", x_test.shape)

# যেকোনো একটি ছবি দেখি
plt.imshow(x_train[0], cmap='gray') # প্রথম ছবিটি দেখছি
plt.title(f"এই ছবির লেবেল হলো: {y_train[0]}")
plt.show()
```

এখন ডেটাকে মডেলের জন্য প্রস্তুত করতে হবে।
1.  **স্কেলিং (Scaling):** ছবির পিক্সেলের মান ০ থেকে ২৫৫ এর মধ্যে থাকে। নিউরাল নেটওয়ার্ক ভালো কাজ করে যখন ইনপুট ভ্যালু ছোট থাকে (যেমন ০ থেকে ১ এর মধ্যে)। তাই আমরা পিক্সেল ভ্যালুগুলোকে ২৫৫ দিয়ে ভাগ করব।
2.  **ফ্ল্যাটেনিং (Flattening):** আমাদের নিউরাল নেটওয়ার্কের ইনপুট লেয়ার একটি সরল ভেক্টর (1D array) ইনপুট হিসেবে নেয়। তাই আমরা ২৮x২৮ পিক্সেলের 2D ছবিকে একটি লম্বা ভেক্টরে (২৮ * ২৮ = ৭৮৪) পরিণত করব।

```python
# স্কেলিং
x_train = x_train / 255.0
x_test = x_test / 255.0
```

#### **ধাপ ৩: নিউরাল নেটওয়ার্ক মডেল তৈরি করা**

এখন আমরা কেরাসের `Sequential` API ব্যবহার করে আমাদের মডেলের আর্কিটেকচার তৈরি করব।

```python
model = keras.Sequential([
    # ১. ইনপুট লেয়ার: ২৮x২৮ ছবিকে ৭৮৪ নিউরনের একটি লেয়ারে পরিণত করবে
    keras.layers.Flatten(input_shape=(28, 28)),

    # ২. হিডেন লেয়ার: ১২৮টি নিউরন আছে। 'relu' (Rectified Linear Unit) হলো একটি জনপ্রিয় অ্যাক্টিভেশন ফাংশন
    # যা মডেলকে নন-লিনিয়ার প্যাটার্ন শিখতে সাহায্য করে।
    keras.layers.Dense(128, activation='relu'),

    # ৩. আউটপুট লেয়ার: ১০টি নিউরন আছে (কারণ আমাদের ১০টি ক্লাস, ০-৯)।
    # 'softmax' অ্যাক্টিভেশন ফাংশনটি প্রতিটি ক্লাসের জন্য একটি সম্ভাবনা (probability) আউটপুট দেয়।
    # যে নিউরনের সম্ভাবনা সবচেয়ে বেশি হবে, মডেল সেই ক্লাসটিকেই বেছে নেবে।
    keras.layers.Dense(10, activation='softmax')
])
```
ব্যাস! আমাদের ডিপ লার্নিং মডেলের আর্কিটেকচার তৈরি।

#### **ধাপ ৪: মডেল কম্পাইল করা (Compile the Model)**

ট্রেনিং শুরু করার আগে, মডেলকে বলে দিতে হয় সে কীভাবে শিখবে। এর জন্য তিনটি জিনিস লাগে:
1.  **অপটিমাইজার (Optimizer):** এটি ঠিক করে মডেল কীভাবে তার ভুল থেকে শিখবে এবং নিজেকে আপডেট করবে। `adam` একটি খুবই জনপ্রিয় এবং কার্যকরী অপটিমাইজার।
2.  **লস ফাংশন (Loss Function):** এটি মডেলের ভুলের পরিমাণ (error) গণনা করে। যেহেতু আমাদের আউটপুট ক্যাটেগরিক্যাল, আমরা `sparse_categorical_crossentropy` ব্যবহার করব।
3.  **মেট্রিক্স (Metrics):** ট্রেনিং এবং টেস্টিং এর সময় আমরা মডেলের পারফরম্যান্স কী দিয়ে মাপব। আমরা `accuracy` দিয়ে মাপব।

```python
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])
```

#### **ধাপ ৫: মডেলকে ট্রেনিং করানো**

এখন আমরা আমাদের ট্রেনিং ডেটা (`x_train`, `y_train`) দিয়ে মডেলকে শেখাব।
*   **Epochs:** একটি epoch মানে হলো সম্পূর্ণ ট্রেনিং ডেটাসেটটিকে একবার মডেলের মধ্য দিয়ে চালনা করা। আমরা ৫ বার এই কাজটি করব।

```python
# মডেলকে ট্রেনিং করাই
# এই ধাপটি গুগল কোলাবে GPU ব্যবহার করলে দ্রুত হবে
history = model.fit(x_train, y_train, epochs=5, validation_split=0.1) # ১০% ডেটা ভ্যালিডেশনের জন্য রাখছি
```
আপনি ট্রেনিং চলার সময় দেখতে পাবেন প্রতিটি epoch-এর সাথে সাথে মডেলের `loss` কমছে এবং `accuracy` বাড়ছে।

#### **ধাপ ৬: মডেলের পারফরম্যান্স মূল্যায়ন**

ট্রেনিং শেষ। এবার টেস্টিং ডেটা (যা মডেল আগে কখনো দেখেনি) দিয়ে এর আসল যোগ্যতা পরীক্ষা করার পালা।

```python
# টেস্টিং ডেটার উপর মডেলের পারফরম্যান্স দেখি
test_loss, test_acc = model.evaluate(x_test, y_test, verbose=2)

print(f'\nটেস্টিং সেটে Accuracy: {test_acc*100:.2f}%')
```
আপনি দেখবেন মডেলটি প্রায় ৯৭-৯৮% সঠিক উত্তর দিতে পারছে, যা অসাধারণ!

#### **ধাপ ৭: ভবিষ্যদ্বাণী করা**

চলুন টেস্টিং সেটের প্রথম ছবিটি দিয়ে মডেলকে প্রেডিক্ট করতে বলি।

```python
# মডেলের প্রেডিকশন সবসময় একটি সম্ভাবনা বা probability array হয়
predictions = model.predict(x_test)

# প্রথম ছবির জন্য প্রেডিকশন দেখি
print("\nপ্রথম ছবির জন্য মডেলের প্রেডিকশন (সম্ভাবনা):")
print(predictions[0])

# কোন সংখ্যার সম্ভাবনা সবচেয়ে বেশি?
predicted_label = np.argmax(predictions[0])
print(f"\nমডেলের অনুমান করা সংখ্যা: {predicted_label}")

# আসল সংখ্যাটি কী ছিল?
actual_label = y_test[0]
print(f"আসল সংখ্যা: {actual_label}")

# ছবিটিও দেখে নিই
plt.imshow(x_test[0], cmap='gray')
plt.show()
```

### **আমাদের যাত্রার সারসংক্ষেপ**

আমরা একদম শূন্য থেকে শুরু করে মেশিন লার্নিং-এর এক বিশাল পথ পাড়ি দিয়েছি। আমরা শিখেছি:
1.  **বেসিক প্রস্তুতি:** পাইথন, NumPy, Pandas এবং প্রয়োজনীয় গণিত।
2.  **সুপারভাইজড লার্নিং:** লিনিয়ার রিগ্রেশন, লজিস্টিক রিগ্রেশন, ডিসিশন ট্রি, র‍্যান্ডম ফরেস্ট।
3.  **আনসুপারভাইজড লার্নিং:** কে-মিন্স ক্লাস্টারিং।
4.  **অ্যাডভান্সড টেকনিক:** ফিচার ইঞ্জিনিয়ারিং, ওভারফিটিং মোকাবেলা এবং হাইপারপ্যারামিটার টিউনিং।
5.  **ডিপ লার্নিং:** নিউরাল নেটওয়ার্কের মূল ধারণা এবং টেনসরফ্লো/কেরাস দিয়ে একটি ইমেজ ক্লাসিফিকেশন মডেল তৈরি।

আপনি এখন মেশিন লার্নিং-এর মৌলিক এবং কিছু অ্যাডভান্সড ধারণা সম্পর্কে জানেন এবং পাইথন ব্যবহার করে বিভিন্ন ধরনের মডেল তৈরি করতে সক্ষম।

**এরপর কী?**
এই যাত্রা এখানে শেষ নয়, বরং শুরু। আপনি এখন ডিপ লার্নিং-এর আরও গভীরে যেতে পারেন:
*   **CNN (Convolutional Neural Network):** ছবি এবং ভিডিও নিয়ে কাজ করার জন্য বিশেষভাবে তৈরি।
*   **RNN (Recurrent Neural Network) ও LSTM:** ধারাবাহিক ডেটা (যেমন: টেক্সট, অডিও) নিয়ে কাজ করার জন্য।
*   Kaggle-এর মতো প্ল্যাটফর্মে বিভিন্ন প্রতিযোগিতায় অংশ নেওয়া।
*   নিজের পছন্দের কোনো ডেটাসেট নিয়ে একটি সম্পূর্ণ প্রজেক্ট তৈরি করা।
