
পেশন্ট ম্যানেজমেন্ট – রোগী রেজিস্ট্রেশন, মেডিকেল হিস্ট্রি, ভিজিট লগ।

অ্যাপয়েন্টমেন্ট শিডিউলিং – ডাক্তার ও স্লট, অটো রিমাইন্ডার।

ইলেকট্রনিক মেডিকেল রেকর্ড (ইএমআর) – ডায়াগনোসিস, প্রেসক্রিপশন, টেস্ট রিপোর্ট।

বিলিং ও ফাইন্যান্স – পেশেন্ট বিল, পেমেন্ট, ইনস্যুরেন্স ক্লেইম।

ফার্মেসি ম্যানেজমেন্ট – ঔষধের স্টক, বিক্রয়, এক্সপাইরি অ্যালার্ট।

ল্যাবরেটরি ও রেডিওলজি – টেস্ট অর্ডার, রিপোর্ট আপলোড, নোটিফিকেশন।

অপারেশন থিয়েটার (ওটি) ম্যানেজমেন্ট – সার্জারি শিডিউল, সরঞ্জাম, স্টাফ অ্যাসাইনমেন্ট।

বেড ও ওয়ার্ড ম্যানেজমেন্ট – বেড অ্যালোকেশন, রিয়েল-টাইম ট্র্যাকিং।

ইনভেন্টরি ও সাপ্লাই চেইন – মেডিকেল সরঞ্জাম, রি-অর্ডার পয়েন্ট।

এইচআর ও পেসরোল – স্টাফ অ্যাটেন্ডেন্স, শিফট রোস্টার, বেতন।

ডিসচার্জ সামারি – চিকিৎসা সারাংশ, ফলো-আপ নির্দেশনা।

রিপোর্ট ও ড্যাশবোর্ড – রিয়েল-টাইম কেপিআই, অ্যানালিটিক্স।

ইউজার রোল ও অ্যাক্সেস কন্ট্রোল – সুপারঅ্যাডমিন, ডাক্তার, নার্স, বিলার – আলাদা পারমিশন।

নার্স স্টেশন ম্যানেজমেন্ট – ডিউটি রোস্টার, ভাইটাল সাইন এন্ট্রি, ডাক্তারের অর্ডার টাস্ক।

হসপিটাল বিল্ডিং ম্যানেজমেন্ট – বিল্ডিং, ফ্লোর, রুম, মেইনটেন্যান্স টিকিট।

ক্যান্টিন ম্যানেজমেন্ট – মেনু, অর্ডার, ডায়েট অনুযায়ী খাবার, স্টক।

ডায়েট ম্যানেজমেন্ট – রোগীর ডায়েট চার্ট, ক্যান্টিনে অটো অর্ডার, ডেলিভারি লগ।

ডক্টর ম্যানেজমেন্ট – ডিউটি রোস্টার, ছুটি ব্যবস্থাপনা, পারফরম্যান্স ট্র্যাকিং।

ডায়াগনস্টিক ম্যানেজমেন্ট – টেস্ট ক্যাটালগ, নমুনা সংগ্রহ, রিপোর্ট জেনারেশন ও নোটিফিকেশন।  
অ্যাম্বুলেন্স ম্যানেজমেন্ট – GPS ট্র্যাকিং, ড্রাইভার তথ্য, জ্বালানি খরচ, কল লগ, রোগী পরিবহন বিল।

ব্লাড ব্যাংক ম্যানেজমেন্ট – ব্লাড গ্রুপ অনুযায়ী স্টক, ডোনার রেজিস্ট্রেশন, স্ক্রিনিং রেজাল্ট, এক্সপাইরি ডেট, বিতরণ লগ।

ইনস্যুরেন্স ও ক্লেইম ম্যানেজমেন্ট – পলিসি ভেরিফিকেশন, ক্লেইম সাবমিশন, প্রি-অথরাইজেশন, সেটেলমেন্ট ট্র্যাকিং।

হাউসকিপিং ও লন্ড্রি ম্যানেজমেন্ট – রুম ক্লিনিং শিডিউল, লিনেন বিতরণ ও সংগ্রহ, জীবাণুমুক্তকরণ ট্র্যাকিং।

মেইনটেন্যান্স ও ইকুইপমেন্ট ম্যানেজমেন্ট – মেডিকেল ডিভাইসের সার্ভিস শিডিউল, ক্যালিব্রেশন, ব্রেকডাউন টিকিট।

কমপ্লেইন ও ফিডব্যাক ম্যানেজমেন্ট – রোগী/স্বজনের অভিযোগ লগ, রেজল্যুশন ট্র্যাকিং, সন্তুষ্টি জরিপ।

টেলিমেডিসিন মডিউল – ভিডিও কনসালটেশন লিংক জেনারেট, ই-প্রেসক্রিপশন, ভার্চুয়াল অ্যাপয়েন্টমেন্ট।

কনসেন্ট ফর্ম ও লিগ্যাল ডকুমেন্ট ম্যানেজার – সার্জারি, টেস্ট, ডাটা শেয়ারিং কনসেন্ট ফর্ম সংরক্ষণ।

অডিট লগ ও ডাটা সুরক্ষা মডিউল – প্রতিটি টেবিলের পরিবর্তন লগ, এনক্রিপশন, ব্যাকআপ অটোমেশন।

## Step 1: Roles & Permissions

SQL

```sql
-- ============================================
-- TABLE: system_admin.roles
-- PURPOSE: Define user roles in the system
-- ============================================
CREATE TABLE system_admin.roles (
    role_id        SERIAL PRIMARY KEY,
    role_name      VARCHAR(50) NOT NULL UNIQUE,  -- 'superadmin','doctor','nurse','biller'
    description    TEXT,
    is_active      BOOLEAN DEFAULT TRUE,
    created_at     TIMESTAMPTZ DEFAULT NOW(),
    updated_at     TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================
-- TABLE: system_admin.permissions
-- PURPOSE: Define what actions are possible
-- ============================================
CREATE TABLE system_admin.permissions (
    permission_id   SERIAL PRIMARY KEY,
    module_name     VARCHAR(100) NOT NULL,   -- 'patient','billing','pharmacy'
    action_name     VARCHAR(50) NOT NULL,    -- 'create','read','update','delete'
    description     TEXT,
    UNIQUE(module_name, action_name)
);

-- ============================================
-- TABLE: system_admin.role_permissions
-- PURPOSE: Map which role gets which permission
-- ============================================
CREATE TABLE system_admin.role_permissions (
    role_id         INT NOT NULL REFERENCES system_admin.roles(role_id) ON DELETE CASCADE,
    permission_id   INT NOT NULL REFERENCES system_admin.permissions(permission_id) ON DELETE CASCADE,
    granted_at      TIMESTAMPTZ DEFAULT NOW(),
    PRIMARY KEY (role_id, permission_id)
);

-- ============================================
-- TABLE: system_admin.users
-- PURPOSE: All system users (staff/doctors/admin)
-- ============================================
CREATE TABLE system_admin.users (
    user_id          SERIAL PRIMARY KEY,
    username         VARCHAR(50) NOT NULL UNIQUE,
    email            VARCHAR(150) NOT NULL UNIQUE,
    password_hash    VARCHAR(255) NOT NULL,         -- bcrypt hashed
    full_name        VARCHAR(150) NOT NULL,
    phone            VARCHAR(20),
    role_id          INT NOT NULL REFERENCES system_admin.roles(role_id),
    branch_id        INT,                           -- FK added later
    profile_photo    VARCHAR(500),                  -- file path/URL
    is_active        BOOLEAN DEFAULT TRUE,
    last_login       TIMESTAMPTZ,
    failed_attempts  INT DEFAULT 0,
    locked_until     TIMESTAMPTZ,
    created_at       TIMESTAMPTZ DEFAULT NOW(),
    updated_at       TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================
-- TABLE: system_admin.audit_logs
-- PURPOSE: Track every change in the system
-- ============================================
CREATE TABLE system_admin.audit_logs (
    log_id          BIGSERIAL PRIMARY KEY,
    user_id         INT REFERENCES system_admin.users(user_id),
    action          VARCHAR(20) NOT NULL,       -- INSERT, UPDATE, DELETE
    table_name      VARCHAR(100) NOT NULL,
    record_id       VARCHAR(50),               -- The PK of changed record
    old_data        JSONB,                     -- Previous values
    new_data        JSONB,                     -- New values
    ip_address      INET,
    user_agent      TEXT,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- Index for fast audit searches
CREATE INDEX idx_audit_logs_user ON system_admin.audit_logs(user_id);
CREATE INDEX idx_audit_logs_table ON system_admin.audit_logs(table_name);
CREATE INDEX idx_audit_logs_created ON system_admin.audit_logs(created_at);
```

## Step 2: Multi-Branch / Hospital Setup

SQL

```sql
-- ============================================
-- TABLE: system_admin.organizations
-- PURPOSE: Hospital chain / parent organization
-- ============================================
CREATE TABLE system_admin.organizations (
    org_id          SERIAL PRIMARY KEY,
    org_name        VARCHAR(200) NOT NULL,
    org_logo        VARCHAR(500),
    address         TEXT,
    phone           VARCHAR(20),
    email           VARCHAR(150),
    website         VARCHAR(200),
    tax_number      VARCHAR(50),
    license_number  VARCHAR(100),
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================
-- TABLE: system_admin.branches
-- PURPOSE: Individual hospital branches
-- ============================================
CREATE TABLE system_admin.branches (
    branch_id       SERIAL PRIMARY KEY,
    org_id          INT NOT NULL REFERENCES system_admin.organizations(org_id),
    branch_name     VARCHAR(200) NOT NULL,
    branch_code     VARCHAR(20) NOT NULL UNIQUE,  -- 'DHK-01', 'CTG-01'
    address         TEXT,
    city            VARCHAR(100),
    phone           VARCHAR(20),
    email           VARCHAR(150),
    bed_capacity    INT DEFAULT 0,
    is_active       BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- Now add FK to users table
ALTER TABLE system_admin.users 
    ADD CONSTRAINT fk_user_branch 
    FOREIGN KEY (branch_id) REFERENCES system_admin.branches(branch_id);

-- ============================================
-- TABLE: system_admin.buildings
-- PURPOSE: Physical buildings in a branch
-- ============================================
CREATE TABLE system_admin.buildings (
    building_id     SERIAL PRIMARY KEY,
    branch_id       INT NOT NULL REFERENCES system_admin.branches(branch_id),
    building_name   VARCHAR(100) NOT NULL,   -- 'Block A', 'Main Building'
    building_code   VARCHAR(20),
    total_floors    INT DEFAULT 1,
    description     TEXT,
    is_active       BOOLEAN DEFAULT TRUE
);

-- ============================================
-- TABLE: system_admin.floors
-- PURPOSE: Floors within a building
-- ============================================
CREATE TABLE system_admin.floors (
    floor_id        SERIAL PRIMARY KEY,
    building_id     INT NOT NULL REFERENCES system_admin.buildings(building_id),
    floor_number    INT NOT NULL,            -- 0 = Ground, 1,2,3...
    floor_name      VARCHAR(100),            -- 'Ground Floor', 'ICU Floor'
    description     TEXT,
    UNIQUE(building_id, floor_number)
);

-- ============================================
-- TABLE: system_admin.rooms
-- PURPOSE: Individual rooms on each floor
-- ============================================
CREATE TABLE system_admin.rooms (
    room_id         SERIAL PRIMARY KEY,
    floor_id        INT NOT NULL REFERENCES system_admin.floors(floor_id),
    room_number     VARCHAR(20) NOT NULL,
    room_type       VARCHAR(50),   -- 'general','cabin','ICU','OT','lab','office'
    room_name       VARCHAR(100),
    capacity        INT DEFAULT 1,
    is_active       BOOLEAN DEFAULT TRUE,
    UNIQUE(floor_id, room_number)
);
```

```sql
-- ============================================
-- TABLE: clinical.patients
-- PURPOSE: Core patient demographic data
-- ============================================
CREATE TABLE clinical.patients (
    patient_id          SERIAL PRIMARY KEY,
    branch_id           INT NOT NULL REFERENCES system_admin.branches(branch_id),
    mrn                 VARCHAR(30) NOT NULL UNIQUE,  -- Medical Record Number (auto-generated)
    first_name          VARCHAR(100) NOT NULL,
    last_name           VARCHAR(100) NOT NULL,
    date_of_birth       DATE NOT NULL,
    gender              VARCHAR(10) NOT NULL CHECK (gender IN ('male','female','other')),
    blood_group         VARCHAR(5) CHECK (blood_group IN ('A+','A-','B+','B-','AB+','AB-','O+','O-')),
    national_id         VARCHAR(30),                  -- NID / Birth Cert
    passport_number     VARCHAR(30),                  -- For foreign patients
    phone               VARCHAR(20) NOT NULL,
    email               VARCHAR(150),
    address             TEXT,
    city                VARCHAR(100),
    occupation          VARCHAR(100),
    marital_status      VARCHAR(20) CHECK (marital_status IN ('single','married','divorced','widowed')),
    religion            VARCHAR(50),
    nationality         VARCHAR(50) DEFAULT 'Bangladeshi',
    photo               VARCHAR(500),
    qr_code             VARCHAR(500),                 -- QR code image path
    barcode             VARCHAR(100),                 -- Barcode value
    patient_type        VARCHAR(20) DEFAULT 'regular' 
                        CHECK (patient_type IN ('regular','vip','foreign','corporate')),
    corporate_id        INT,                          -- FK to corporate table
    family_group_id     INT,                          -- FK to family groups
    is_deceased         BOOLEAN DEFAULT FALSE,
    deceased_at         TIMESTAMPTZ,
    death_certificate   VARCHAR(500),
    created_by          INT REFERENCES system_admin.users(user_id),
```

```sql
-- ============================================
-- VIEW: Bed Availability Dashboard

CREATE VIEW clinical.bed_availability_view AS
SELECT 
    b.branch_id,
    w.ward_name,
    w.ward_type,
    COUNT(bd.bed_id) AS total_beds,
    COUNT(bd.bed_id) FILTER (WHERE bd.status = 'available') AS available_beds,
    COUNT(bd.bed_id) FILTER (WHERE bd.status = 'occupied') AS occupied_beds,
    COUNT(bd.bed_id) FILTER (WHERE bd.status = 'cleaning') AS cleaning_beds,
    ROUND(
        COUNT(bd.bed_id) FILTER (WHERE bd.status = 'occupied')::DECIMAL / 
        NULLIF(COUNT(bd.bed_id), 0) * 100, 2
    ) AS occupancy_rate
FROM clinical.wards w
JOIN clinical.beds bd ON bd.ward_id = w.ward_id
JOIN system_admin.branches b ON b.branch_id = w.branch_id
GROUP BY b.branch_id, w.ward_id, w.ward_name, w.ward_type;

-- ============================================
-- VIEW: Today's Appointments Summary
-- ============================================
CREATE VIEW clinical.todays_appointments AS
SELECT 
    a.appointment_id,
    a.appointment_time,
    a.token_number,
    p.first_name || ' ' || p.last_name AS patient_name,
    p.mrn,
    p.phone,
    u.full_name AS doctor_name,
    a.chief_complaint,
    a.appointment_type,
    a.status
FROM clinical.appointments a
JOIN clinical.patients p ON p.patient_id = a.patient_id
JOIN system_admin.users u ON u.user_id = a.doctor_id
WHERE a.appointment_date = CURRENT_DATE
ORDER BY a.appointment_time;

-- ============================================
-- VIEW: Medicine Expiry Alert (within 90 days)
-- ============================================
CREATE VIEW operational.medicine_expiry_alerts AS
SELECT 
    ms.stock_id,
    br.branch_name,
    m.medicine_name,
    m.generic_name,
    ms.batch_number,
    ms.expiry_date,
    ms.quantity,
    (ms.expiry_date - CURRENT_DATE) AS days_remaining,
    CASE 
        WHEN ms.expiry_date < CURRENT_DATE THEN 'EXPIRED'
        WHEN ms.expiry_date <= CURRENT_DATE + 30 THEN 'CRITICAL'
        WHEN ms.expiry_date <= CURRENT_DATE + 60 THEN 'WARNING'
        ELSE 'NOTICE'
    END AS alert_level
FROM operational.medicine_stock ms
JOIN operational.medicines m ON m.medicine_id = ms.medicine_id
JOIN system_admin.branches br ON br.branch_id = ms.branch_id
WHERE ms.expiry_date <= CURRENT_DATE + 90 AND ms.quantity > 0
ORDER BY ms.expiry_date;

-- ============================================
-- VIEW: Blood Stock Summary
-- ============================================
CREATE VIEW operational.blood_stock_summary AS
SELECT 
    branch_id,
    blood_group,
    component_type,
    COUNT(*) AS total_units,
    COUNT(*) FILTER (WHERE status = 'available' AND is_cleared = TRUE) AS available_units,
    MIN(expiry_date) FILTER (WHERE status = 'available') AS earliest_expiry
FROM operational.blood_inventory
GROUP BY branch_id, blood_group, component_type;
```

```sql
-- ============================================
-- TRIGGER: Auto-update bed status on admission
-- ============================================
CREATE OR REPLACE FUNCTION clinical.update_bed_on_admission()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'INSERT' THEN
        UPDATE clinical.beds SET status = 'occupied' WHERE bed_id = NEW.bed_id;
    ELSIF TG_OP = 'UPDATE' AND NEW.status IN ('discharged','transferred','expired') THEN
        UPDATE clinical.beds SET status = 'cleaning' WHERE bed_id = OLD.bed_id;
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_bed_status_on_admission
    AFTER INSERT OR UPDATE ON clinical.admissions
    FOR EACH ROW EXECUTE FUNCTION clinical.update_bed_on_admission();

-- ============================================
-- TRIGGER: Auto-calculate bill totals
-- ============================================
CREATE OR REPLACE FUNCTION financial.calculate_bill_totals()
RETURNS TRIGGER AS $$
BEGIN
    UPDATE financial.bills
    SET 
        subtotal = (SELECT COALESCE(SUM(total_price), 0) FROM financial.bill_items WHERE bill_id = NEW.bill_id),
        updated_at = NOW()
    WHERE bill_id = NEW.bill_id;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_bill_total_update
    AFTER INSERT OR UPDATE OR DELETE ON financial.bill_items
    FOR EACH ROW EXECUTE FUNCTION financial.calculate_bill_totals();

-- ============================================
-- TRIGGER: Auto-generate MRN for new patient
-- ============================================
CREATE OR REPLACE FUNCTION clinical.generate_mrn()
RETURNS TRIGGER AS $$
BEGIN
    NEW.mrn := 'MRN-' || TO_CHAR(NOW(), 'YYYY') || '-' || LPAD(NEW.patient_id::TEXT, 6, '0');
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_generate_mrn
    BEFORE INSERT ON clinical.patients
    FOR EACH ROW EXECUTE FUNCTION clinical.generate_mrn();

-- ============================================
-- TRIGGER: Audit log for patient changes
-- ============================================
CREATE OR REPLACE FUNCTION system_admin.log_patient_changes()
RETURNS TRIGGER AS $$
BEGIN
    INSERT INTO system_admin.audit_logs(table_name, action, record_id, old_data, new_data)
    VALUES (
        'clinical.patients',
        TG_OP,
        COALESCE(NEW.patient_id, OLD.patient_id)::TEXT,
        CASE WHEN TG_OP != 'INSERT' THEN row_to_json(OLD) ELSE NULL END,
        CASE WHEN TG_OP != 'DELETE' THEN row_to_json(NEW) ELSE NULL END
    );
    RETURN COALESCE(NEW, OLD);
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_audit_patients
    AFTER INSERT OR UPDATE OR DELETE ON clinical.patients
    FOR EACH ROW EXECUTE FUNCTION system_admin.log_patient_changes();
```
