
পেশন্ট ম্যানেজমেন্ট – রোগী রেজিস্ট্রেশন, মেডিকেল হিস্ট্রি, ভিজিট লগ।

অ্যাপয়েন্টমেন্ট শিডিউলিং – ডাক্তার ও স্লট, অটো রিমাইন্ডার।

ইলেকট্রনিক মেডিকেল রেকর্ড (ইএমআর) – ডায়াগনোসিস, প্রেসক্রিপশন, টেস্ট রিপোর্ট।

বিলিং ও ফাইন্যান্স – পেশেন্ট বিল, পেমেন্ট, ইনস্যুরেন্স ক্লেইম।

ফার্মেসি ম্যানেজমেন্ট – ঔষধের স্টক, বিক্রয়, এক্সপাইরি অ্যালার্ট।

ল্যাবরেটরি ও রেডিওলজি – টেস্ট অর্ডার, রিপোর্ট আপলোড, নোটিফিকেশন।

অপারেশন থিয়েটার (ওটি) ম্যানেজমেন্ট – সার্জারি শিডিউল, সরঞ্জাম, স্টাফ অ্যাসাইনমেন্ট।

বেড ও ওয়ার্ড ম্যানেজমেন্ট – বেড অ্যালোকেশন, রিয়েল-টাইম ট্র্যাকিং।

ইনভেন্টরি ও সাপ্লাই চেইন – মেডিকেল সরঞ্জাম, রি-অর্ডার পয়েন্ট।

এইচআর ও পেসরোল – স্টাফ অ্যাটেন্ডেন্স, শিফট রোস্টার, বেতন।

ডিসচার্জ সামারি – চিকিৎসা সারাংশ, ফলো-আপ নির্দেশনা।

রিপোর্ট ও ড্যাশবোর্ড – রিয়েল-টাইম কেপিআই, অ্যানালিটিক্স।

ইউজার রোল ও অ্যাক্সেস কন্ট্রোল – সুপারঅ্যাডমিন, ডাক্তার, নার্স, বিলার – আলাদা পারমিশন।

নার্স স্টেশন ম্যানেজমেন্ট – ডিউটি রোস্টার, ভাইটাল সাইন এন্ট্রি, ডাক্তারের অর্ডার টাস্ক।

হসপিটাল বিল্ডিং ম্যানেজমেন্ট – বিল্ডিং, ফ্লোর, রুম, মেইনটেন্যান্স টিকিট।

ক্যান্টিন ম্যানেজমেন্ট – মেনু, অর্ডার, ডায়েট অনুযায়ী খাবার, স্টক।

ডায়েট ম্যানেজমেন্ট – রোগীর ডায়েট চার্ট, ক্যান্টিনে অটো অর্ডার, ডেলিভারি লগ।

ডক্টর ম্যানেজমেন্ট – ডিউটি রোস্টার, ছুটি ব্যবস্থাপনা, পারফরম্যান্স ট্র্যাকিং।

ডায়াগনস্টিক ম্যানেজমেন্ট – টেস্ট ক্যাটালগ, নমুনা সংগ্রহ, রিপোর্ট জেনারেশন ও নোটিফিকেশন।  
অ্যাম্বুলেন্স ম্যানেজমেন্ট – GPS ট্র্যাকিং, ড্রাইভার তথ্য, জ্বালানি খরচ, কল লগ, রোগী পরিবহন বিল।

ব্লাড ব্যাংক ম্যানেজমেন্ট – ব্লাড গ্রুপ অনুযায়ী স্টক, ডোনার রেজিস্ট্রেশন, স্ক্রিনিং রেজাল্ট, এক্সপাইরি ডেট, বিতরণ লগ।

ইনস্যুরেন্স ও ক্লেইম ম্যানেজমেন্ট – পলিসি ভেরিফিকেশন, ক্লেইম সাবমিশন, প্রি-অথরাইজেশন, সেটেলমেন্ট ট্র্যাকিং।

হাউসকিপিং ও লন্ড্রি ম্যানেজমেন্ট – রুম ক্লিনিং শিডিউল, লিনেন বিতরণ ও সংগ্রহ, জীবাণুমুক্তকরণ ট্র্যাকিং।

মেইনটেন্যান্স ও ইকুইপমেন্ট ম্যানেজমেন্ট – মেডিকেল ডিভাইসের সার্ভিস শিডিউল, ক্যালিব্রেশন, ব্রেকডাউন টিকিট।

কমপ্লেইন ও ফিডব্যাক ম্যানেজমেন্ট – রোগী/স্বজনের অভিযোগ লগ, রেজল্যুশন ট্র্যাকিং, সন্তুষ্টি জরিপ।

টেলিমেডিসিন মডিউল – ভিডিও কনসালটেশন লিংক জেনারেট, ই-প্রেসক্রিপশন, ভার্চুয়াল অ্যাপয়েন্টমেন্ট।

কনসেন্ট ফর্ম ও লিগ্যাল ডকুমেন্ট ম্যানেজার – সার্জারি, টেস্ট, ডাটা শেয়ারিং কনসেন্ট ফর্ম সংরক্ষণ।

অডিট লগ ও ডাটা সুরক্ষা মডিউল – প্রতিটি টেবিলের পরিবর্তন লগ, এনক্রিপশন, ব্যাকআপ অটোমেশন।

## Step 1: Roles & Permissions

SQL

```sql
-- ============================================
-- TABLE: system_admin.roles
-- PURPOSE: Define user roles in the system
-- ============================================
CREATE TABLE system_admin.roles (
    role_id        SERIAL PRIMARY KEY,
    role_name      VARCHAR(50) NOT NULL UNIQUE,  -- 'superadmin','doctor','nurse','biller'
    description    TEXT,
    is_active      BOOLEAN DEFAULT TRUE,
    created_at     TIMESTAMPTZ DEFAULT NOW(),
    updated_at     TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================
-- TABLE: system_admin.permissions
-- PURPOSE: Define what actions are possible
-- ============================================
CREATE TABLE system_admin.permissions (
    permission_id   SERIAL PRIMARY KEY,
    module_name     VARCHAR(100) NOT NULL,   -- 'patient','billing','pharmacy'
    action_name     VARCHAR(50) NOT NULL,    -- 'create','read','update','delete'
    description     TEXT,
    UNIQUE(module_name, action_name)
);

-- ============================================
-- TABLE: system_admin.role_permissions
-- PURPOSE: Map which role gets which permission
-- ============================================
CREATE TABLE system_admin.role_permissions (
    role_id         INT NOT NULL REFERENCES system_admin.roles(role_id) ON DELETE CASCADE,
    permission_id   INT NOT NULL REFERENCES system_admin.permissions(permission_id) ON DELETE CASCADE,
    granted_at      TIMESTAMPTZ DEFAULT NOW(),
    PRIMARY KEY (role_id, permission_id)
);

-- ============================================
-- TABLE: system_admin.users
-- PURPOSE: All system users (staff/doctors/admin)
-- ============================================
CREATE TABLE system_admin.users (
    user_id          SERIAL PRIMARY KEY,
    username         VARCHAR(50) NOT NULL UNIQUE,
    email            VARCHAR(150) NOT NULL UNIQUE,
    password_hash    VARCHAR(255) NOT NULL,         -- bcrypt hashed
    full_name        VARCHAR(150) NOT NULL,
    phone            VARCHAR(20),
    role_id          INT NOT NULL REFERENCES system_admin.roles(role_id),
    branch_id        INT,                           -- FK added later
    profile_photo    VARCHAR(500),                  -- file path/URL
    is_active        BOOLEAN DEFAULT TRUE,
    last_login       TIMESTAMPTZ,
    failed_attempts  INT DEFAULT 0,
    locked_until     TIMESTAMPTZ,
    created_at       TIMESTAMPTZ DEFAULT NOW(),
    updated_at       TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================
-- TABLE: system_admin.audit_logs
-- PURPOSE: Track every change in the system
-- ============================================
CREATE TABLE system_admin.audit_logs (
    log_id          BIGSERIAL PRIMARY KEY,
    user_id         INT REFERENCES system_admin.users(user_id),
    action          VARCHAR(20) NOT NULL,       -- INSERT, UPDATE, DELETE
    table_name      VARCHAR(100) NOT NULL,
    record_id       VARCHAR(50),               -- The PK of changed record
    old_data        JSONB,                     -- Previous values
    new_data        JSONB,                     -- New values
    ip_address      INET,
    user_agent      TEXT,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- Index for fast audit searches
CREATE INDEX idx_audit_logs_user ON system_admin.audit_logs(user_id);
CREATE INDEX idx_audit_logs_table ON system_admin.audit_logs(table_name);
CREATE INDEX idx_audit_logs_created ON system_admin.audit_logs(created_at);
```

## Step 2: Multi-Branch / Hospital Setup

SQL

```sql
-- ============================================
-- TABLE: system_admin.organizations
-- PURPOSE: Hospital chain / parent organization
-- ============================================
CREATE TABLE system_admin.organizations (
    org_id          SERIAL PRIMARY KEY,
    org_name        VARCHAR(200) NOT NULL,
    org_logo        VARCHAR(500),
    address         TEXT,
    phone           VARCHAR(20),
    email           VARCHAR(150),
    website         VARCHAR(200),
    tax_number      VARCHAR(50),
    license_number  VARCHAR(100),
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================
-- TABLE: system_admin.branches
-- PURPOSE: Individual hospital branches
-- ============================================
CREATE TABLE system_admin.branches (
    branch_id       SERIAL PRIMARY KEY,
    org_id          INT NOT NULL REFERENCES system_admin.organizations(org_id),
    branch_name     VARCHAR(200) NOT NULL,
    branch_code     VARCHAR(20) NOT NULL UNIQUE,  -- 'DHK-01', 'CTG-01'
    address         TEXT,
    city            VARCHAR(100),
    phone           VARCHAR(20),
    email           VARCHAR(150),
    bed_capacity    INT DEFAULT 0,
    is_active       BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- Now add FK to users table
ALTER TABLE system_admin.users 
    ADD CONSTRAINT fk_user_branch 
    FOREIGN KEY (branch_id) REFERENCES system_admin.branches(branch_id);

-- ============================================
-- TABLE: system_admin.buildings
-- PURPOSE: Physical buildings in a branch
-- ============================================
CREATE TABLE system_admin.buildings (
    building_id     SERIAL PRIMARY KEY,
    branch_id       INT NOT NULL REFERENCES system_admin.branches(branch_id),
    building_name   VARCHAR(100) NOT NULL,   -- 'Block A', 'Main Building'
    building_code   VARCHAR(20),
    total_floors    INT DEFAULT 1,
    description     TEXT,
    is_active       BOOLEAN DEFAULT TRUE
);

-- ============================================
-- TABLE: system_admin.floors
-- PURPOSE: Floors within a building
-- ============================================
CREATE TABLE system_admin.floors (
    floor_id        SERIAL PRIMARY KEY,
    building_id     INT NOT NULL REFERENCES system_admin.buildings(building_id),
    floor_number    INT NOT NULL,            -- 0 = Ground, 1,2,3...
    floor_name      VARCHAR(100),            -- 'Ground Floor', 'ICU Floor'
    description     TEXT,
    UNIQUE(building_id, floor_number)
);

-- ============================================
-- TABLE: system_admin.rooms
-- PURPOSE: Individual rooms on each floor
-- ============================================
CREATE TABLE system_admin.rooms (
    room_id         SERIAL PRIMARY KEY,
    floor_id        INT NOT NULL REFERENCES system_admin.floors(floor_id),
    room_number     VARCHAR(20) NOT NULL,
    room_type       VARCHAR(50),   -- 'general','cabin','ICU','OT','lab','office'
    room_name       VARCHAR(100),
    capacity        INT DEFAULT 1,
    is_active       BOOLEAN DEFAULT TRUE,
    UNIQUE(floor_id, room_number)
);
```

```sql
-- ============================================
-- TABLE: clinical.patients
-- PURPOSE: Core patient demographic data
-- ============================================
CREATE TABLE clinical.patients (
    patient_id          SERIAL PRIMARY KEY,
    branch_id           INT NOT NULL REFERENCES system_admin.branches(branch_id),
    mrn                 VARCHAR(30) NOT NULL UNIQUE,  -- Medical Record Number (auto-generated)
    first_name          VARCHAR(100) NOT NULL,
    last_name           VARCHAR(100) NOT NULL,
    date_of_birth       DATE NOT NULL,
    gender              VARCHAR(10) NOT NULL CHECK (gender IN ('male','female','other')),
    blood_group         VARCHAR(5) CHECK (blood_group IN ('A+','A-','B+','B-','AB+','AB-','O+','O-')),
    national_id         VARCHAR(30),                  -- NID / Birth Cert
    passport_number     VARCHAR(30),                  -- For foreign patients
    phone               VARCHAR(20) NOT NULL,
    email               VARCHAR(150),
    address             TEXT,
    city                VARCHAR(100),
    occupation          VARCHAR(100),
    marital_status      VARCHAR(20) CHECK (marital_status IN ('single','married','divorced','widowed')),
    religion            VARCHAR(50),
    nationality         VARCHAR(50) DEFAULT 'Bangladeshi',
    photo               VARCHAR(500),
    qr_code             VARCHAR(500),                 -- QR code image path
    barcode             VARCHAR(100),                 -- Barcode value
    patient_type        VARCHAR(20) DEFAULT 'regular' 
                        CHECK (patient_type IN ('regular','vip','foreign','corporate')),
    corporate_id        INT,                          -- FK to corporate table
    family_group_id     INT,                          -- FK to family groups
    is_deceased         BOOLEAN DEFAULT FALSE,
    deceased_at         TIMESTAMPTZ,
    death_certificate   VARCHAR(500),
    created_by          INT REFERENCES system_admin.users(user_id),
```

```sql
-- ============================================
-- VIEW: Bed Availability Dashboard
-- ============================================
CREATE VIEW clinical.bed_availability_view AS
SELECT 
    b.branch_id,
    w.ward_name,
    w.ward_type,
    COUNT(bd.bed_id) AS total_beds,
    COUNT(bd.bed_id) FILTER (WHERE bd.status = 'available') AS available_beds,
    COUNT(bd.bed_id) FILTER (WHERE bd.status = 'occupied') AS occupied_beds,
    COUNT(bd.bed_id) FILTER (WHERE bd.status = 'cleaning') AS cleaning_beds,
    ROUND(
        COUNT(bd.bed_id) FILTER (WHERE bd.status = 'occupied')::DECIMAL / 
        NULLIF(COUNT(bd.bed_id), 0) * 100, 2
    ) AS occupancy_rate
FROM clinical.wards w
JOIN clinical.beds bd ON bd.ward_id = w.ward_id
JOIN system_admin.branches b ON b.branch_id = w.branch_id
GROUP BY b.branch_id, w.ward_id, w.ward_name, w.ward_type;

-- ============================================
-- VIEW: Today's Appointments Summary
-- ============================================
CREATE VIEW clinical.todays_appointments AS
SELECT 
    a.appointment_id,
    a.appointment_time,
    a.token_number,
    p.first_name || ' ' || p.last_name AS patient_name,
    p.mrn,
    p.phone,
    u.full_name AS doctor_name,
    a.chief_complaint,
    a.appointment_type,
    a.status
FROM clinical.appointments a
JOIN clinical.patients p ON p.patient_id = a.patient_id
JOIN system_admin.users u ON u.user_id = a.doctor_id
WHERE a.appointment_date = CURRENT_DATE
ORDER BY a.appointment_time;

-- ============================================
-- VIEW: Medicine Expiry Alert (within 90 days)
-- ============================================
CREATE VIEW operational.medicine_expiry_alerts AS
SELECT 
    ms.stock_id,
    br.branch_name,
    m.medicine_name,
    m.generic_name,
    ms.batch_number,
    ms.expiry_date,
    ms.quantity,
    (ms.expiry_date - CURRENT_DATE) AS days_remaining,
    CASE 
        WHEN ms.expiry_date < CURRENT_DATE THEN 'EXPIRED'
        WHEN ms.expiry_date <= CURRENT_DATE + 30 THEN 'CRITICAL'
        WHEN ms.expiry_date <= CURRENT_DATE + 60 THEN 'WARNING'
        ELSE 'NOTICE'
    END AS alert_level
FROM operational.medicine_stock ms
JOIN operational.medicines m ON m.medicine_id = ms.medicine_id
JOIN system_admin.branches br ON br.branch_id = ms.branch_id
WHERE ms.expiry_date <= CURRENT_DATE + 90 AND ms.quantity > 0
ORDER BY ms.expiry_date;

-- ============================================
-- VIEW: Blood Stock Summary
-- ============================================
CREATE VIEW operational.blood_stock_summary AS
SELECT 
    branch_id,
    blood_group,
    component_type,
    COUNT(*) AS total_units,
    COUNT(*) FILTER (WHERE status = 'available' AND is_cleared = TRUE) AS available_units,
    MIN(expiry_date) FILTER (WHERE status = 'available') AS earliest_expiry
FROM operational.blood_inventory
GROUP BY branch_id, blood_group, component_type;
```

```sql
-- ============================================
-- TRIGGER: Auto-update bed status on admission
-- ============================================
CREATE OR REPLACE FUNCTION clinical.update_bed_on_admission()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'INSERT' THEN
        UPDATE clinical.beds SET status = 'occupied' WHERE bed_id = NEW.bed_id;
    ELSIF TG_OP = 'UPDATE' AND NEW.status IN ('discharged','transferred','expired') THEN
        UPDATE clinical.beds SET status = 'cleaning' WHERE bed_id = OLD.bed_id;
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_bed_status_on_admission
    AFTER INSERT OR UPDATE ON clinical.admissions
    FOR EACH ROW EXECUTE FUNCTION clinical.update_bed_on_admission();

-- ============================================
-- TRIGGER: Auto-calculate bill totals
-- ============================================
CREATE OR REPLACE FUNCTION financial.calculate_bill_totals()
RETURNS TRIGGER AS $$
BEGIN
    UPDATE financial.bills
    SET 
        subtotal = (SELECT COALESCE(SUM(total_price), 0) FROM financial.bill_items WHERE bill_id = NEW.bill_id),
        updated_at = NOW()
    WHERE bill_id = NEW.bill_id;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_bill_total_update
    AFTER INSERT OR UPDATE OR DELETE ON financial.bill_items
    FOR EACH ROW EXECUTE FUNCTION financial.calculate_bill_totals();

-- ============================================
-- TRIGGER: Auto-generate MRN for new patient
-- ============================================
CREATE OR REPLACE FUNCTION clinical.generate_mrn()
RETURNS TRIGGER AS $$
BEGIN
    NEW.mrn := 'MRN-' || TO_CHAR(NOW(), 'YYYY') || '-' || LPAD(NEW.patient_id::TEXT, 6, '0');
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_generate_mrn
    BEFORE INSERT ON clinical.patients
    FOR EACH ROW EXECUTE FUNCTION clinical.generate_mrn();

-- ============================================
-- TRIGGER: Audit log for patient changes
-- ============================================
CREATE OR REPLACE FUNCTION system_admin.log_patient_changes()
RETURNS TRIGGER AS $$
BEGIN
    INSERT INTO system_admin.audit_logs(table_name, action, record_id, old_data, new_data)
    VALUES (
        'clinical.patients',
        TG_OP,
        COALESCE(NEW.patient_id, OLD.patient_id)::TEXT,
        CASE WHEN TG_OP != 'INSERT' THEN row_to_json(OLD) ELSE NULL END,
        CASE WHEN TG_OP != 'DELETE' THEN row_to_json(NEW) ELSE NULL END
    );
    RETURN COALESCE(NEW, OLD);
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_audit_patients
    AFTER INSERT OR UPDATE OR DELETE ON clinical.patients
    FOR EACH ROW EXECUTE FUNCTION system_admin.log_patient_changes();
```

```sql
-- VIEW: Reorder Alert
-- PURPOSE: Items below reorder point
-- ============================================
CREATE VIEW tenant_template.scm_reorder_alerts AS
SELECT 
    sc.branch_id,
    i.item_code,
    i.item_name,
    ic.category_name,
    SUM(sc.quantity_available) AS current_stock,
    i.reorder_point,
    i.reorder_quantity,
    i.min_stock_level,
    CASE 
        WHEN SUM(sc.quantity_available) <= 0 THEN 'OUT_OF_STOCK'
        WHEN SUM(sc.quantity_available) <= i.min_stock_level THEN 'CRITICAL'
        WHEN SUM(sc.quantity_available) <= i.reorder_point THEN 'REORDER_NOW'
        ELSE 'OK'
    END AS alert_status
FROM tenant_template.scm_stock_current sc
JOIN tenant_template.scm_items i ON i.item_id = sc.item_id
JOIN tenant_template.scm_item_categories ic ON ic.category_id = i.category_id
WHERE i.is_active = TRUE
GROUP BY sc.branch_id, i.item_id, i.item_code, i.item_name, 
         ic.category_name, i.reorder_point, i.reorder_quantity, i.min_stock_level
HAVING SUM(sc.quantity_available) <= i.reorder_point;
```

```sql
-- VIEW: Reagent Expiry Alerts

CREATE VIEW tenant_template.rgm_expiry_alerts AS
SELECT 
    rs.stock_id,
    rs.branch_id,
    r.reagent_code,
    r.reagent_name,
    rc.category_name,
    rc.lab_department,
    rs.batch_number,
    rs.lot_number,
    rs.expiry_date,
    rs.current_quantity,
    rs.status,
    (rs.expiry_date - CURRENT_DATE) AS days_to_expiry,
    CASE 
        WHEN rs.expiry_date < CURRENT_DATE THEN 'EXPIRED'
        WHEN rs.expiry_date <= CURRENT_DATE + 7  THEN 'CRITICAL'
        WHEN rs.expiry_date <= CURRENT_DATE + 30 THEN 'WARNING'
        WHEN rs.expiry_date <= CURRENT_DATE + 90 THEN 'NOTICE'
        ELSE 'OK'
    END AS alert_level,
    rs.storage_location
FROM tenant_template.rgm_reagent_stock rs
JOIN tenant_template.rgm_reagents r ON r.reagent_id = rs.reagent_id
JOIN tenant_template.rgm_reagent_categories rc ON rc.category_id = r.category_id
WHERE rs.status NOT IN ('discarded','recalled')
  AND rs.current_quantity > 0
ORDER BY rs.expiry_date;

-- VIEW: Reagent Stock Summary
-- ============================================
CREATE VIEW tenant_template.rgm_stock_summary AS
SELECT 
    rs.branch_id,
    r.reagent_id,
    r.reagent_code,
    r.reagent_name,
    rc.lab_department,
    SUM(rs.available_quantity) AS total_available,
    r.reorder_point,
    r.min_stock_units,
    MIN(rs.expiry_date) AS earliest_expiry,
    COUNT(rs.stock_id) AS total_batches,
    SUM(rs.available_quantity * rs.purchase_price) AS stock_value,
    CASE 
        WHEN SUM(rs.available_quantity) <= 0 THEN 'OUT_OF_STOCK'
        WHEN SUM(rs.available_quantity) <= r.min_stock_units THEN 'CRITICAL'
        WHEN SUM(rs.available_quantity) <= r.reorder_point THEN 'REORDER'
        ELSE 'ADEQUATE'
    END AS stock_status
FROM tenant_template.rgm_reagent_stock rs
JOIN tenant_template.rgm_reagents r ON r.reagent_id = rs.reagent_id
JOIN tenant_template.rgm_reagent_categories rc ON rc.category_id = r.category_id
WHERE rs.status IN ('available','in_use')
  AND r.is_active = TRUE
GROUP BY rs.branch_id, r.reagent_id, r.reagent_code, r.reagent_name,
         rc.lab_department, r.reorder_point, r.min_stock_units;
```

```sql
-- ============================================
-- TRIGGER: Auto-deduct reagent stock on usage
-- ============================================
CREATE OR REPLACE FUNCTION tenant_template.deduct_reagent_stock()
RETURNS TRIGGER AS $$
BEGIN
    -- Update stock
    UPDATE tenant_template.rgm_reagent_stock
    SET 
        current_quantity = current_quantity - NEW.used_quantity,
        remaining_tests = COALESCE(remaining_tests, 0) - COALESCE(NEW.tests_performed, 0)
    WHERE stock_id = NEW.stock_id;
    
    -- Check if stock went to zero
    IF (SELECT current_quantity FROM tenant_template.rgm_reagent_stock 
        WHERE stock_id = NEW.stock_id) <= 0 THEN
        UPDATE tenant_template.rgm_reagent_stock
        SET status = 'discarded', current_quantity = 0
        WHERE stock_id = NEW.stock_id;
    END IF;
    
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

    AFTER INSERT ON tenant_template.rgm_reagent_usage_log
    FOR EACH ROW EXECUTE FUNCTION tenant_template.deduct_reagent_stock();

-- TRIGGER: Auto-update stock ledger on GRN post
-- ============================================
CREATE OR REPLACE FUNCTION tenant_template.post_grn_to_stock()
RETURNS TRIGGER AS $$
DECLARE
    v_item RECORD;
BEGIN
    IF NEW.status = 'posted' AND OLD.status != 'posted' THEN
        FOR v_item IN 
            SELECT * FROM tenant_template.scm_grn_items 
            WHERE grn_id = NEW.grn_id AND quantity_accepted > 0
        LOOP
            -- Update current stock
            INSERT INTO tenant_template.scm_stock_current 
                (branch_id, item_id, batch_number, expiry_date, quantity_on_hand, avg_unit_cost, total_value)
            VALUES 
                (NEW.branch_id, v_item.item_id, v_item.batch_number, v_item.expiry_date,
                 v_item.quantity_accepted, v_item.unit_price, v_item.total_price)
            ON CONFLICT (branch_id, item_id, batch_number) DO UPDATE
            SET 
                quantity_on_hand = scm_stock_current.quantity_on_hand + v_item.quantity_accepted,
                total_value = scm_stock_current.total_value + v_item.total_price,
                last_updated = NOW();
            
            -- Write to ledger
            INSERT INTO tenant_template.scm_stock_ledger 
                (branch_id, item_id, transaction_type, reference_type, reference_id,
                 batch_number, expiry_date, quantity_in, balance_quantity, unit_price, total_value)
            VALUES 
                (NEW.branch_id, v_item.item_id, 'grn', 'GRN', NEW.grn_id,
                 v_item.batch_number, v_item.expiry_date, v_item.quantity_accepted,
                 (SELECT quantity_on_hand FROM tenant_template.scm_stock_current 
                  WHERE branch_id = NEW.branch_id AND item_id = v_item.item_id 
                  AND batch_number = v_item.batch_number),
                 v_item.unit_price, v_item.total_price);
        END LOOP;
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

    AFTER UPDATE ON tenant_template.scm_goods_receipt_notes

-- ============================================
-- TRIGGER: Auto-update attendance hours
-- ============================================
CREATE OR REPLACE FUNCTION tenant_template.calculate_attendance_hours()
RETURNS TRIGGER AS $$
DECLARE
    v_schedule RECORD;
    v_total_hours DECIMAL(5,2);
    v_late_minutes INT;
BEGIN
    IF NEW.actual_in IS NOT NULL AND NEW.actual_out IS NOT NULL THEN
        -- Calculate total hours
        v_total_hours := EXTRACT(EPOCH FROM (NEW.actual_out - NEW.actual_in)) / 3600;
        NEW.total_hours := ROUND(v_total_hours::NUMERIC, 2);
        
        -- Calculate late minutes if scheduled time exists
        IF NEW.scheduled_in IS NOT NULL THEN
            v_late_minutes := GREATEST(0, 
                EXTRACT(EPOCH FROM (NEW.actual_in::TIME - NEW.scheduled_in)) / 60
            )::INT;
            NEW.late_minutes := v_late_minutes;
        END IF;
        
        -- Determine status
        IF v_total_hours >= 8 THEN
            NEW.status := 'present';
        ELSIF v_total_hours >= 4 THEN
            NEW.status := 'half_day';
        END IF;
    END IF;
    
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

    BEFORE INSERT OR UPDATE ON tenant_template.hr_attendance
    FOR EACH ROW EXECUTE FUNCTION tenant_template.calculate_attendance_hours();
```

```sql
-- ============================================
-- TRIGGER: Auto bed status on transfer complete
-- ============================================
CREATE OR REPLACE FUNCTION tenant_template.execute_bed_transfer()
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.status = 'completed' AND OLD.status != 'completed' THEN
        -- Free old bed
        UPDATE tenant_template.bct_beds
        SET status = 'cleaning',
            current_admission_id = NULL,
            occupied_since = NULL
        WHERE bed_id = NEW.from_bed_id;
        
        -- Occupy new bed
        UPDATE tenant_template.bct_beds
        SET status = 'occupied',
            current_admission_id = NEW.admission_id,
            occupied_since = NEW.transfer_executed_at
        WHERE bed_id = NEW.to_bed_id;
        
        -- Update admission record
        UPDATE tenant_template.adm_admissions
        SET ward_id = NEW.to_ward_id,
            bed_id = NEW.to_bed_id,
            room_id = NEW.to_room_id,
            updated_at = NOW()
        WHERE admission_id = NEW.admission_id;

        -- Create housekeeping task
        INSERT INTO tenant_template.bct_housekeeping_tasks
            (branch_id, ward_id, bed_id, task_type, 
             priority, triggered_by, trigger_reference_id)
        VALUES
            (NEW.branch_id, NEW.from_ward_id, NEW.from_bed_id,
             'discharge_clean', 'high', 'transfer', NEW.transfer_id);
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_execute_bed_transfer
    AFTER UPDATE ON tenant_template.bct_bed_transfers
    FOR EACH ROW EXECUTE FUNCTION tenant_template.execute_bed_transfer();
```

```sql
    oi.dept_id,

    COUNT(*) AS total_tests,
    AVG(
        EXTRACT(EPOCH FROM (r.finalized_at - oi.collected_at)) / 3600
    ) AS avg_tat_hours,
    PERCENTILE_CONT(0.95) WITHIN GROUP (
        ORDER BY EXTRACT(EPOCH FROM (r.finalized_at - oi.collected_at)) / 3600
    ) AS p95_tat_hours,
    COUNT(*) FILTER (
        WHERE EXTRACT(EPOCH FROM (r.finalized_at - oi.collected_at)) / 3600 <= 
        CASE oi.priority 
            WHEN 'stat' THEN 1 
            WHEN 'urgent' THEN 4 
            ELSE 24 
        END
    ) AS within_tat_count
FROM tenant_template.dgn_order_items oi
JOIN tenant_template.dgn_tests t ON t.test_id = oi.test_id
JOIN tenant_template.dgn_test_results r ON r.order_item_id = oi.item_id
WHERE r.is_finalized = TRUE
  AND oi.collected_at IS NOT NULL
GROUP BY oi.dept_id, t.category, oi.priority;
```

```sql
-- VIEW: Trial Balance
-- ============================================
CREATE VIEW tenant_template.acc_trial_balance AS
SELECT 
    coa.account_code,
    coa.account_name,
    at.type_name AS account_type,
    at.normal_balance,
    COALESCE(SUM(jl.debit_amount), 0) AS total_debit,
    COALESCE(SUM(jl.credit_amount), 0) AS total_credit,
    CASE at.normal_balance
        WHEN 'debit' THEN 
            COALESCE(SUM(jl.debit_amount), 0) - COALESCE(SUM(jl.credit_amount), 0)
        ELSE 
            COALESCE(SUM(jl.credit_amount), 0) - COALESCE(SUM(jl.debit_amount), 0)
    END AS net_balance
FROM tenant_template.acc_chart_of_accounts coa
JOIN tenant_template.acc_account_types at ON at.type_id = coa.type_id
LEFT JOIN tenant_template.acc_journal_lines jl ON jl.account_id = coa.account_id
LEFT JOIN tenant_template.acc_journal_entries je ON je.journal_id = jl.journal_id
    AND je.status = 'posted'
WHERE coa.allows_posting = TRUE
GROUP BY coa.account_id, coa.account_code, coa.account_name, 
         at.type_name, at.normal_balance
ORDER BY coa.account_code;

-- ============================================
-- VIEW: Income Statement (P&L)
-- ============================================
CREATE VIEW tenant_template.acc_income_statement AS
WITH revenue AS (
    SELECT 
        coa.account_code,
        coa.account_name,
        COALESCE(SUM(jl.credit_amount), 0) - 
        COALESCE(SUM(jl.debit_amount), 0) AS amount
    FROM tenant_template.acc_chart_of_accounts coa
    JOIN tenant_template.acc_account_types at ON at.type_id = coa.type_id
    LEFT JOIN tenant_template.acc_journal_lines jl ON jl.account_id = coa.account_id
    LEFT JOIN tenant_template.acc_journal_entries je ON 
        je.journal_id = jl.journal_id AND je.status = 'posted'
    WHERE at.type_code = 'REV' AND coa.allows_posting = TRUE
    GROUP BY coa.account_id, coa.account_code, coa.account_name
),
expenses AS (
    SELECT 
        coa.account_code,
        coa.account_name,
        COALESCE(SUM(jl.debit_amount), 0) - 
        COALESCE(SUM(jl.credit_amount), 0) AS amount
    FROM tenant_template.acc_chart_of_accounts coa
    JOIN tenant_template.acc_account_types at ON at.type_id = coa.type_id
    LEFT JOIN tenant_template.acc_journal_lines jl ON jl.account_id = coa.account_id
    LEFT JOIN tenant_template.acc_journal_entries je ON 
        je.journal_id = jl.journal_id AND je.status = 'posted'
    WHERE at.type_code IN ('EXP','COGS') AND coa.allows_posting = TRUE
    GROUP BY coa.account_id, coa.account_code, coa.account_name
)
SELECT 'Revenue' AS section, account_code, account_name, amount FROM revenue
UNION ALL
SELECT 'Expense', account_code, account_name, amount FROM expenses;
```

```sql
-- ============================================
-- MATERIALIZED VIEW: Hospital KPI Dashboard
-- ============================================
CREATE MATERIALIZED VIEW tenant_template.rpt_hospital_kpi AS
WITH date_range AS (
    SELECT 
        CURRENT_DATE AS today,
        DATE_TRUNC('month', CURRENT_DATE) AS month_start,
        DATE_TRUNC('year', CURRENT_DATE) AS year_start
),
admission_stats AS (
    SELECT
        COUNT(*) FILTER (WHERE status = 'active') AS current_inpatients,
        COUNT(*) FILTER (WHERE DATE(admission_datetime) = CURRENT_DATE) AS admissions_today,
        COUNT(*) FILTER (WHERE DATE(discharge_datetime) = CURRENT_DATE) AS discharges_today,
        COUNT(*) FILTER (WHERE DATE(admission_datetime) >= DATE_TRUNC('month', CURRENT_DATE)) AS admissions_this_month,
        AVG(
            EXTRACT(EPOCH FROM (COALESCE(discharge_datetime, NOW()) - admission_datetime)) / 86400
        ) FILTER (WHERE status = 'discharged' 
            AND DATE(discharge_datetime) >= DATE_TRUNC('month', CURRENT_DATE)) AS avg_los_days
    FROM tenant_template.adm_admissions
),
bed_stats AS (
    SELECT
        COUNT(*) AS total_beds,
        COUNT(*) FILTER (WHERE status = 'available') AS available_beds,
        COUNT(*) FILTER (WHERE status = 'occupied') AS occupied_beds,
        ROUND(
            COUNT(*) FILTER (WHERE status = 'occupied')::DECIMAL / 
            NULLIF(COUNT(*), 0) * 100, 2
        ) AS occupancy_rate
    FROM tenant_template.bct_beds
    WHERE is_active = TRUE
),
revenue_stats AS (
    SELECT
        COALESCE(SUM(total_amount) FILTER (
            WHERE DATE(bill_date) = CURRENT_DATE
        ), 0) AS revenue_today,
        COALESCE(SUM(total_amount) FILTER (
            WHERE bill_date >= DATE_TRUNC('month', CURRENT_DATE)
        ), 0) AS revenue_this_month,
        COALESCE(SUM(balance_amount) FILTER (
            WHERE status NOT IN ('paid','cancelled')
        ), 0) AS outstanding_receivables
    FROM tenant_template.fin_bills
),
lab_stats AS (
    SELECT
        COUNT(*) FILTER (
            WHERE DATE(order_datetime) = CURRENT_DATE
        ) AS lab_orders_today,
        COUNT(*) FILTER (
            WHERE status NOT IN ('completed','cancelled')
            AND order_datetime < NOW() - INTERVAL '4 hours'
        ) AS pending_results_delayed
    FROM tenant_template.dgn_test_orders
)
SELECT
    a.current_inpatients,
    a.admissions_today,
    a.discharges_today,
    a.admissions_this_month,
    ROUND(a.avg_los_days::NUMERIC, 1) AS avg_los_days,
    b.total_beds,
    b.available_beds,
    b.occupied_beds,
    b.occupancy_rate,
    r.revenue_today,
    r.revenue_this_month,
    r.outstanding_receivables,
    l.lab_orders_today,
    l.pending_results_delayed,
    NOW() AS last_refreshed
FROM admission_stats a, bed_stats b, revenue_stats r, lab_stats l;
```
