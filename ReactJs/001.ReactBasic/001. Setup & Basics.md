### **পাঠ ১: রিয়্যাক্ট কী এবং কেন? (React vs HTML)**
*বিষয়:* এইচটিএমএল থাকতে রিয়্যাক্ট কেন লাগবে?

**সহজ ভাষায় বুঝুন:**
ধরো, **HTML** হলো "বিটিভির খবর"। খবর পাল্টালে পুরো টিভি বন্ধ করে আবার চালু করতে হয় (Page Reload)। বড্ড বিরক্তিকর, তাই না?

আর **React** হলো "ফেইসবুকের নিউজফিড"। তুমি লাইক দিচ্ছ, কমেন্ট করছ, নতুন পোস্ট আসছে—কিন্তু পেজ রিলোড হচ্ছে না। সব চোখের পলকে স্মুথলি হচ্ছে! একে বলে **SPA (Single Page Application)**।

**মজার উদাহরণ:**
- **HTML:** রিকশাওলা মামা। আস্তে চলে, থামতে বললে সময় লাগে।
- **React:** উবার বা পাঠাওয়ের বাইক। জাস্ট ট্যাপ করবা, ভোঁ দৌড়! ফাস্ট এবং স্মার্ট।

> **সংক্ষেপে:** রিয়্যাক্ট হলো জাভাস্ক্রিপ্টের একটা লাইব্রেরি (Library), যেটা দিয়ে ইউজার ইন্টারফেস (UI) বানানো হয়। এটা মেটা (ফেইসবুক) এর ইঞ্জিনিয়াররা বানিয়েছে।

### **পাঠ ২: Node.js & NPM ইনস্টলেশন**
*বিষয়:* কোডিং করার অস্ত্রপাতি।

রিয়্যাক্ট রান করতে হলে তোমার পিসিতে **Node.js** থাকতে হবে। কেন?
কারণ ব্রাউজার ছাড়া জাভাস্ক্রিপ্ট রান করতে পারে না। পিসিতে জাভাস্ক্রিপ্ট রান করানোর ইঞ্জিন হলো Node.js।

**রান্নার উদাহরণ:**
বিরিয়ানি রান্না করতে গেলে তোমার দুটো জিনিস লাগবে:
১. **গ্যাসের চুলা** (Node.js) - যাতে রান্না হবে।
২. **কাঁচাবাজার** (NPM - Node Package Manager) - চাল, ডাল, মশলা (অন্যদের লেখা কোড প্যাকেজ) আনার জন্য।

**আপনার কাজ (Action):**
1.  [nodejs.org](https://nodejs.org/) তে যান।
2.  **LTS (Long Term Support)** ভার্সনটা ডাউনলোড করে ইনস্টল করুন (Next > Next > Finish)।
3.  ইন্সটল হয়েছে কিনা দেখতে টার্মিনাল বা CMD ওপেন করে লিখুন:
    ```bash
    node -v
    npm -v
    ```
    যদি ভার্সন নম্বর দেখায়, তাইলে বুঝবেন চুলা রেডি! 🔥

### **পাঠ ৩: Vite দিয়ে প্রোজেক্ট সেটআপ**
*বিষয়:* প্রোজেক্ট তৈরি করা।

আগে সবাই `create-react-app` ব্যবহার করত। ওটা এখন "নকিয়া ১১০০" এর মতো স্লো। আমরা ব্যবহার করব **Vite** (উচ্চারণ: ভিট)। এটা নিনজা বাইকের মতো ফাস্ট! ⚡

**সেটআপ স্টেপস:**
১. আপনার পিসির যেকোনো ফোল্ডারে গিয়ে রাইট ক্লিক করে টার্মিনাল ওপেন করুন (বা VS Code ওপেন করুন)।
২. এই কমান্ডটি লিখুন:
   ```bash
   npm create vite@latest my-react-app
   ```
   *(এখানে `my-react-app` হলো আপনার প্রোজেক্টের নাম। আপনি চাইলে `my-biriyani-app` ও দিতে পারেন)*

৩. এরপর অপশন আসবে, কিবোর্ডের অ্যারো কি (Arrow Key) দিয়ে সিলেক্ট করুন:
   - Select a framework: `React`
   - Select a variant: `JavaScript` (আমরা শুরুতে JS দিয়েই শিখব)

৪. ব্যাস! ফোল্ডার তৈরি। এখন সেই ফোল্ডারে ঢুকতে হবে:
   ```bash
   cd my-react-app
   npm install
   npm run dev
   ```
   এখন ব্রাউজারে একটা লিংক (যেমন: `http://localhost:5173`) দেখাবে। লিংকে ক্লিক করলেই দেখবেন আপনার প্রথম রিয়্যাক্ট অ্যাপ চলছে! অভিনন্দন! 🎉

### **পাঠ ৪: ফোল্ডার স্ট্রাকচার পরিচিতি**
*বিষয়:* কোথায় কী রাখব?

প্রজেক্ট ফোল্ডারটা দেখতে অনেকটা "ব্যাচেলর মেস" এর মতো লাগতে পারে। চলুন গুছিয়ে ফেলি:

- 📁 **node_modules:** এটা হলো "ব্ল্যাক হোল"। এখানে হাজার হাজার লাইব্রেরি জমা থাকে। খবরদার! এটাতে হাত দিবেন না, ডিলিটও করবেন না। (NPM এখান থেকেই সব সাপ্লাই দেয়)।
- 📁 **public:** এখানে লোগো বা ছবি থাকে যেগুলো সরাসরি এক্সেস করা যায়।
- 📁 **src (Source):** এটাই আপনার **"কিচেন"**। আমরা ৯৯% সময় এখানেই কাজ করব।
  - `main.jsx`: এটা হলো মেইন সুইচ বোর্ড। এখান থেকেই অ্যাপ স্টার্ট হয়।
  - `App.jsx`: এটা আপনার অ্যাপের মেইন কম্পোনেন্ট (বসার ঘর)।

> **টিপস:** `src` ফোল্ডারের ভেতর হাবিজাবি ফাইলগুলো (যেমন `App.css`, লোগো) ডিলিট করে ক্লিন করে ফেলাই ভালো। আমরা স্ক্র্যাচ থেকে সব বানাবো।

### **পাঠ ৫: JSX কী? (JSX Introduction)**
*বিষয়:* জাভাস্ক্রিপ্ট আর এইচটিএমএল-এর অবৈধ প্রেম।

আপনি যখন রিয়্যাক্টে কোড লিখবেন, দেখবেন সেটা দেখতে HTML এর মতো, কিন্তু আসলে তা জাভাস্ক্রিপ্ট। এটার নাম **JSX (JavaScript XML)**।

**উদাহরণ:**
সাধারণ HTML:
```html
<h1 class="title">হ্যালো বাংলাদেশ</h1>
```

React JSX:
```jsx
const title = "হ্যালো বাংলাদেশ";
return <h1 className="title">{title}</h1>;
```

**পার্থক্য কোথায়?**
১. **className:** HTML-এ আমরা লিখি `class`, কিন্তু JSX-এ লিখতে হয় `className` (কারণ `class` জাভাস্ক্রিপ্টের একটা রিজার্ভ কিওয়ার্ড)।
২. **ভেরিয়েবল:** `{ }` বা কার্লী ব্রেসিসের ভেতর আমরা জাভাস্ক্রিপ্ট লিখতে পারি। যেমন `{2 + 2}` লিখলে ব্রাউজারে দেখাবে `4`।

**মজার ব্যাপার:**
JSX হলো "দুধ ও আমের জুস"। দেখতে দুধের মতো (HTML), কিন্তু স্বাদ আমের (JavaScript Logic)। আপনি HTML এর পেটের ভেতর জাভাস্ক্রিপ্ট ঢুকাতে পারবেন `{ }` দিয়ে।
