
### **পর্ব ২: কম্পোনেন্ট - লেগো গেম (Components)**
*সবকিছুই কম্পোনেন্ট। ওয়েবসাইট হলো ছোট ছোট টুকরো দিয়ে বানানো বিল্ডিং।*

6.  **প্রথম কম্পোনেন্ট তৈরি (Functional Components)** - *উদাহরণ:* ফাংশন হলো একটা জুস মেকার মেশিন, ফল (Code) দিবা, জুস (UI) বের হবে।
7.  **Export & Import** - *উদাহরণ:* গ্রামের বাড়ি থেকে আম পাঠানো (Export) আর ঢাকায় বসে রিসিভ করা (Import)।
8.  **Props (Properties)** - *উদাহরণ:* দাওয়াত খাওয়ার সময় বাচ্চার হাতে ১০ টাকা ধরিয়ে দেওয়া (Data Passing)।
9.  **Destructuring Props** - *উদাহরণ:* খামের ভেতর থেকে টাকাটা বের করে পকেটে রাখা।
10. **Conditional Rendering** - *উদাহরণ:* পকেটে টাকা থাকলে "কাচ্চি", না থাকলে "টং-এর চা"। (Ternary Operator)।

### **পাঠ ৬: প্রথম কম্পোনেন্ট তৈরি (Functional Components)**
*বিষয়:* কম্পোনেন্ট কী এবং দেখতে কেমন?

**সহজ ভাষায়:**
জাভাস্ক্রিপ্টের একটা **ফাংশন (Function)** যখন HTML রিটার্ন করে, তখন তাকে আমরা বলি **কম্পোনেন্ট**।
মনে আছে জুস মেকারের কথা?
- **মেশিন:** ফাংশন
- **ইনপুট:** কোড
- **আউটপুট:** সুস্বাদু জুস (UI বা ওয়েবসাইট)

**কোড উদাহরণ:**
`src` ফোল্ডারে `MyButton.jsx` নামে একটা ফাইল বানাও।

```jsx
// MyButton.jsx
function MyButton() {
  return (
    <button>আমাকে চাপ দাও!</button>
  );
}
```

**জরুরি নিয়ম (থাবড়া খাওয়ার আগে মনে রাখো):** ⚠️
১. কম্পোনেন্টের নামের **প্রথম অক্ষর অবশ্যই বড় হাতের (Capital Letter)** হতে হবে।
   - ✅ `MyButton` (সঠিক)
   - ❌ `myButton` (ভুল - এটা HTML ট্যাগ ভেবে ভুল করবে)
২. একটা কম্পোনেন্ট থেকে **মাত্র একটা** প্যারেন্ট এলিমেন্ট রিটার্ন করা যায়। একাধিক লাইন থাকলে `<div>...</div>` বা রিয়্যাক্ট ফ্র্যাগমেন্ট `<>...</>` দিয়ে মুড়িয়ে দিতে হবে।

### **পাঠ ৭: Export & Import**
*বিষয়:* এক ফাইলের মাল অন্য ফাইলে নেওয়া।

তুমি `MyButton.jsx` বানিয়েছ, কিন্তু `App.jsx` (মেইন ফাইল) তো সেটা চেনে না। গ্রামের বাড়ি থেকে আম পাঠালে (Export) সেটা ঢাকায় রিসিভ (Import) করতে হয়।

**Export করা (MyButton.jsx ফাইলে):**
```jsx
export default function MyButton() {
  return <button>Click Me</button>;
}
```
*(এখানে `export default` মানে এই ফাইল থেকে এটাই প্রধান জিনিস যা বাইরে যাবে।)*

**Import করা (App.jsx ফাইলে):**
```jsx
import MyButton from './MyButton'; // .jsx না লিখলেও চলে

function App() {
  return (
    <div>
      <h1>আমার অ্যাপ</h1>
      <MyButton />  {/* লেগোর মতো বসিয়ে দিলাম */}
      <MyButton />  {/* যত খুশি ব্যবহার করা যায় */}
    </div>
  );
}
export default App;
```
**মজার ব্যাপার:** একবার বানাও (Code Once), হাজার বার ব্যবহার করো (Use Everywhere)। এটাই রিয়্যাক্টের শক্তি!

### **পাঠ ৮: Props (Properties)**
*বিষয়:* কম্পোনেন্টকে ডাটা পাঠানো।

সব বাটন কি দেখতে একই হবে? না! কোনোটা "Login", কোনোটা "Sign Up"।
বিয়ে বাড়িতে বাচ্চাদের হাতে যেমন ১০/২০ টাকা ধরিয়ে দেয় (সালামি), কম্পোনেন্টকেও তেমনি ডাটা দেওয়া যায়। এর নাম **Props**।

**App.jsx (প্যারেন্ট):**
```jsx
<Student name="Rahim" roll="101" />
<Student name="Karim" roll="102" />
```
*(এখানে `name` আর `roll` হলো Props)*

**Student.jsx (চাইল্ড):**
```jsx
function Student(props) {
  // props একটা অবজেক্ট, এর ভেতর সব ডাটা থাকে
  return (
    <div className="card">
      <h2>নাম: {props.name}</h2>
      <p>রোল: {props.roll}</p>
    </div>
  );
}
```
এখন `Rahim` আর `Karim` এর জন্য আলাদা কার্ড তৈরি হবে। ডায়নামিক ব্যাপার-স্যাপার!

---

### **পাঠ ৯: Destructuring Props**
*বিষয়:* স্মার্টলি ডাটা রিসিভ করা।

আগের লেসনে আমরা বারবার `props.name`, `props.roll` লিখছিলাম। এটা বোরিং। কুরিয়ার সার্ভিসের প্যাকেট (props) হাতে পেয়ে আমরা কি প্যাকেটসুদ্ধ আলমারিতে রাখি? না! প্যাকেট খুলে মালটা বের করে ফেলি। একে বলে **Destructuring**।

**স্মার্ট উপায় (Student.jsx):**
```jsx
// সরাসরি ব্র্যাকেটের ভেতর { } দিয়ে ভেঙে ফেলা
function Student({ name, roll }) {
  return (
    <div className="card">
      <h2>নাম: {name}</h2>  {/* props.name লেখার দরকার নাই */}
      <p>রোল: {roll}</p>
    </div>
  );
}
```
দেখতে ক্লিন এবং সুন্দর! কোড দেখে মনে হবে—"মামা, তুমি তো প্রো!" 😎

### **পাঠ ১০: Conditional Rendering**
*বিষয়:* শর্ত সাপেক্ষে কিছু দেখানো।

পকেটে টাকা থাকলে "কাচ্চি", না থাকলে "টং-এর চা"।
রিয়্যাক্টে আমরা `if-else` সরাসরি JSX এর ভেতর লিখতে পারি না। তাই আমরা ব্যবহার করি **Ternary Operator** (`? :`)।

**সিনট্যাক্স:** `শর্ত ? (সত্য হলে এটা) : (মিথ্যা হলে এটা)`

**উদাহরণ:**
```jsx
function UserStatus({ isLoggedIn }) {
  return (
    <div>
      {isLoggedIn ? (
        <h1>স্বাগতম বস! 👋</h1> // যদি সত্য হয়
      ) : (
        <button>লগইন করুন 🔒</button> // যদি মিথ্যা হয়
      )}
    </div>
  );
}
```

**ব্যবহার (App.jsx):**
```jsx
<UserStatus isLoggedIn={true} />  {/* দেখাবে: স্বাগতম বস! */}
<UserStatus isLoggedIn={false} /> {/* দেখাবে: লগইন করুন */}
```
এটা রিয়্যাক্টে প্রচুর লাগে। কন্ডিশনাল রেন্ডারিং ছাড়া জীবন তেজপাতা! 🍃
