### **পাঠ ১১: Event Handling - সুইচে টিপ দিলে ফ্যান ঘোরে**
*বিষয়:* ইউজার ইন্টারেকশন বা খোঁচাখুঁচি হ্যান্ডেল করা।

জাভাস্ক্রিপ্টে আমরা `onclick` লিখতাম, রিয়্যাক্টে লিখব `onClick` (ক্যামেল কেস)।

**উদাহরণ:**
ধরো একটা বাটন আছে, চাপ দিলেই কনসোলে মেসেজ দেখাবে।

```jsx
export default function Clicker() {
  
  // ইভেন্ট হ্যান্ডলার ফাংশন
  function handleClick() {
    alert("আরে! আমাকে গুঁতা দিলেন কেন? 😡");
  }

  return (
    // ভুল: onClick={handleClick()} -> এটা লোড হওয়ার সাথে সাথেই কল হয়ে যাবে।
    // সঠিক: onClick={handleClick} -> ফাংশনের নামটা জাস্ট ধরিয়ে দেওয়া।
    <button onClick={handleClick}>
      আমাকে চাপ দিন
    </button>
  );
}
```
**টিপস:** ফাংশনের শেষে `()` দিবেন না। দিলেই কেলেঙ্কারি! তখন রিয়্যাক্ট ভাববে, "ওহ, এখনই কল করতে বলছে!" আর ক্লিক করার আগেই অ্যালার্ট চলে আসবে।

### **পাঠ ১২: useState Hook (বেসিক) - মুড সুইং**
*বিষয়:* মেমোরি বা ডাটা মনে রাখা।

সাধারণ ভেরিয়েবল (`let count = 0`) দিয়ে রিয়্যাক্টে কাজ হয় না। কারণ ভেরিয়েবল চেঞ্জ হলে রিয়্যাক্ট সেটা টের পায় না, তাই স্ক্রিনেও আপডেট করে না। রিয়্যাক্টকে খোঁচা দিয়ে বলতে হয়—"মামা, ডাটা চেঞ্জ হইছে, স্ক্রিনটা রিলোড দাও!"

এজন্য লাগে **`useState`**। এটা একটা হুক (Hook)।

**উদাহরণ:** গার্লফ্রেন্ডের মুড।
```jsx
import { useState } from 'react'; // ১. ইম্পোর্ট করতে হবে

export default function MoodChanger() {
  // সিনট্যাক্স: const [বর্তমান অবস্থা, পরিবর্তন করার ফাংশন] = useState(শুরুর অবস্থা);
  const [mood, setMood] = useState("Happy 😊");

  return (
    <div>
      <h1>এখন মুড: {mood}</h1>
      <button onClick={() => setMood("Angry 😡")}>
        ঝগড়া করো
      </button>
      <button onClick={() => setMood("Romantic 🥰")}>
        গিফট দাও
      </button>
    </div>
  );
}
```
এখানে `setMood` কল করলেই রিয়্যাক্ট দৌড়ে গিয়ে স্ক্রিনের লেখা চেঞ্জ করে দিবে। ম্যাজিক! ✨

### **পাঠ ১৩: Counter App প্রজেক্ট - ডিজিটাল তসবিহ**
*বিষয়:* আমাদের প্রথম ছোট অ্যাপ।

চলো একটা ডিজিটাল কাউন্টার বানাই। বাটন চাপলে সংখ্যা বাড়বে।

**কোড (DigitalTasbih.jsx):**
```jsx
import { useState } from 'react';

export default function DigitalTasbih() {
  const [count, setCount] = useState(0); // শুরু হবে ০ থেকে

  return (
    <div style={{ textAlign: 'center', marginTop: '50px' }}>
      <h2>সুবহানাল্লাহ কাউন্টার</h2>
      
      <h1 style={{ fontSize: '50px' }}>{count}</h1>

      <button onClick={() => setCount(count + 1)}>
        Count (+)
      </button>
      
      <button onClick={() => setCount(0)} style={{ marginLeft: '10px' }}>
        Reset
      </button>
    </div>
  );
}
```
**বাড়ির কাজ:** `Decrement (-)` বাটন যোগ করো, যাতে সংখ্যা কমানো যায়। কিন্তু খেয়াল রাখবে যেন ০-এর নিচে না যায় (মাইনাস না হয়)।

### **পাঠ ১৪: useState (অবজেক্ট ও অ্যারে) - শপিং লিস্ট**
*বিষয়:* এক স্টেটের ভেতর অনেক তথ্য।

এতক্ষণ শুধু সংখ্যা বা স্ট্রিং নিয়ে খেললাম। এখন যদি অবজেক্ট হয়?
ধরো, ইউজারের প্রোফাইল।

**সমস্যা:** রিয়্যাক্টে স্টেট সরাসরি এডিট করা পাপ (Mutation)।
❌ `user.name = "Rahim"` (এটা করা যাবে না)
✅ `setUser({ ...user, name: "Rahim" })` (পুরোটা কপি করে নতুন করে সেট করা)

**উদাহরণ:**
```jsx
import { useState } from 'react';

export default function UserProfile() {
  const [user, setUser] = useState({
    name: "Abul",
    age: 25,
    city: "Dhaka"
  });

  const updateName = () => {
    // আগের সব ঠিক থাকবে (...user), শুধু নাম চেঞ্জ হবে
    setUser({ ...user, name: "Babul" });
  };

  return (
    <div>
      <h3>নাম: {user.name}</h3>
      <p>বয়স: {user.age}</p>
      <p>শহর: {user.city}</p>
      <button onClick={updateName}>নাম বদলাও</button>
    </div>
  );
}
```
**স্প্রেড অপারেটর (`...`)** হলো জাদুর কাঠি। এটা আগের সব ডাটা কপি করে নিয়ে আসে, যাতে হারিয়ে না যায়।

### **পাঠ ১৫: React 19 Update: ব্যাচিং সিস্টেম - অটোমেটিক গিয়ার**
*বিষয়:* পারফরমেন্স অপ্টিমাইজেশন।

আগে (React 17 বা তার আগে), তুমি যদি একটা বাটনে ক্লিক করে পরপর ৩ বার `useState` চেঞ্জ করতে, রিয়্যাক্ট বোকার মতো ৩ বার স্ক্রিন রি-রেন্ডার (Update) করত।

**আগের দৃশ্য (React 17):**
1. নাম চেঞ্জ -> রেন্ডার
2. বয়স চেঞ্জ -> রেন্ডার
3. কালার চেঞ্জ -> রেন্ডার
(পিসি স্লো হয়ে যেত)

**React 18/19 এর দৃশ্য (Automatic Batching):**
রিয়্যাক্ট এখন স্মার্ট। সে ওয়েটারের মতো। তুমি যদি বলো—"মামা পানি দাও, ভাত দাও, আর লেবু দাও"—সে তিনবার কিচেনে দৌড়াবে না। সে সব অর্ডার একসাথে নিবে, তারপর **একবার** কিচেনে গিয়ে সব আনবে।

**উদাহরণ:**
```jsx
function handleClick() {
  setCount(c => c + 1); // ১
  setFlag(f => !f);     // ২
  setTheme('dark');     // ৩
  // React 19 এখানে মাত্র ১ বার রেন্ডার করবে! 🚀
}
```
**লাভ:** তোমার অ্যাপ এখন সুপার ফাস্ট! অটোমেটিক গিয়ারের গাড়ির মতো, গিয়ার পরিবর্তনের চিন্তা তোমার করা লাগবে না।
