
### **পর্ব ৪: ফর্মস এবং ইনপুট (Forms in React 19)**

16. **Controlled Components** - *উদাহরণ:* রিমোট কন্ট্রোল গাড়ি, তুমি যা বলবে ইনপুট তাই করবে।
17. **React 19 Actions (Form Actions)** - *উদাহরণ:* `onSubmit` ইভেন্ট হ্যান্ডলারে `async` ফাংশন ব্যবহারের নতুন সুপারপাওয়ার।

19. **useActionState Hook** - *উদাহরণ:* ফর্ম সাবমিট ফেইল করলে ইউজারকে ঝাড়ি দেওয়া (Error Handling)।
20. **Validation (Zod/Yup)** - *উদাহরণ:* ক্লাবে ঢুকার আগে গার্ডের চেকিং।

আজকের টপিক হলো **ফর্মস (Forms)**। একটা ওয়েবসাইটের সাথে ইউজারের কথা বলার একমাত্র মাধ্যম হলো এই ফর্ম। লগিন, রেজিস্ট্রেশন, বা স্ট্যাটাস পোস্ট করা—সবই ফর্মের খেলা।

React 19-এ ফর্ম হ্যান্ডলিংয়ে বিশাল পরিবর্তন এসেছে। আগে যা করতে ১০ লাইন লাগত, এখন তা ২ লাইনে সম্ভব। একে বলা হচ্ছে **Server Actions** বা **Form Actions**।

### **পাঠ ১৬: Controlled Components - রিমোট কন্ট্রোল গাড়ি**
*বিষয়:* ইনপুট ফিল্ডকে নিজের নিয়ন্ত্রণে রাখা।

সাধারণ HTML-এ ইনপুট ফিল্ডে কিছু লিখলে সে নিজেই সেটা মনে রাখে। কিন্তু রিয়্যাক্টে আমরা বলি—"তোমার নিজের কোনো ক্ষমতা নাই, আমি (State) যা বলব, তুমি তাই দেখাবে।"

**উদাহরণ:** রিমোট কন্ট্রোল গাড়ি। রিমোটে (State) স্পিড বাড়ালে গাড়ি জোরে চলবে, রিমোট বন্ধ করলে গাড়িও বন্ধ।

**কোড:**
```jsx
import { useState } from "react";

export default function SimpleForm() {
  const [text, setText] = useState("");

  return (
    <div>
      <input
        type="text"
        value={text} // ১. ভ্যালু আসবে স্টেট থেকে
        onChange={(e) => setText(e.target.value)} // ২. টাইপ করলে স্টেট আপডেট হবে
        placeholder="এখানে লিখুন..."
        style={{ padding: "10px", fontSize: "16px" }}
      />
      <p>আপনি লিখছেন: {text}</p>
    </div>
  );
}
```
**কেন এটা দরকার?** কারণ এখন আপনি চাইলেই ইনপুট ভ্যালু চেক করতে পারেন, বা গালিগালাজ লিখলে সেটা ব্লক করে দিতে পারেন টাইপ করার সময়ই!

### **পাঠ ১৭: React 19 Actions (Form Actions) - নতুন সুপারপাওয়ার**
*বিষয়:* `onSubmit` ইভেন্টের দিন শেষ!

আগে আমরা `e.preventDefault()` লিখতাম যাতে পেজ রিলোড না হয়। React 19 বলছে—"ধুরো মিয়া, এসব বাদ দাও। সরাসরি `<form>` এর `action` প্রপস ব্যবহার করো।" এটা অনেকটা সাধারণ HTML এর মতো, কিন্তু পাওয়ারফুল।

**উদাহরণ:**
```jsx
export default function SignupForm() {
  
  // এটা হলো অ্যাকশন ফাংশন (Server Action বা Client Action হতে পারে)
  const handleSignup = async (formData) => {
    // ইভেন্ট প্রিভেন্ট করা লাগবে না! রিয়্যাক্ট অটো করবে।
    const name = formData.get("username");
    
    // ধরো এখানে ডাটাবেসে ডাটা পাঠালাম (Simulation)
    await new Promise(resolve => setTimeout(resolve, 2000));
    alert(`স্বাগতম, ${name}! একাউন্ট খোলা হয়েছে।`);
  };

  return (
    // লক্ষ্য করুন: onSubmit নাই, আছে action
    <form action={handleSignup}>
      <input name="username" type="text" placeholder="User Name" required />
      <button type="submit">Sign Up</button>
    </form>
  );
}
```
**ম্যাজিক:** এই ফাংশনটি অটোমেটিক `async` কাজ করবে এবং পেজ রিলোড ছাড়াই ডাটা প্রসেস করবে। কোড কত ক্লিন হয়ে গেল, দেখেছ?

### **পাঠ ১৮: useFormStatus Hook - লোডিং স্পিনার**
*বিষয়:* ইউজারকে বুঝানো যে কাজ চলছে।

ফর্ম সাবমিট করলে ২ সেকেন্ড সময় লাগলে ইউজার ভাববে "হ্যাং হয়ে গেছে"। তখন একটা চাকা (Spinner) ঘোরাতে হয়।
React 19-এ `useFormStatus` হুক দিয়ে এটা অটোমেটিক চেক করা যায়।

**শর্ত:** এই হুকটি অবশ্যই `<form>` এর **ভেতরের** কোনো কম্পোনেন্টে ব্যবহার করতে হবে।

**উদাহরণ:**
```jsx
import { useFormStatus } from "react-dom";

// সাবমিট বাটনকে আলাদা কম্পোনেন্ট বানালাম
function SubmitButton() {
  const { pending } = useFormStatus(); // pending সত্য হলে বুঝব লোডিং চলছে

  return (
    <button disabled={pending} type="submit">
      {pending ? "কাউন্ট খোলা হচ্ছে..." : "Sign Up"}
    </button>
  );
}

export default function App() {
  const myAction = async () => {
    await new Promise(res => setTimeout(res, 2000)); // ২ সেকেন্ড দেরি
  };

  return (
    <form action={myAction}>
      <input name="email" placeholder="Email" />
      <SubmitButton /> {/* ফর্মের ভেতরে ব্যবহার করলাম */}
    </form>
  );
}
```
**মজা:** আলাদা করে `setIsLoading(true)` বা `false` করার দিন শেষ! রিয়্যাক্ট নিজেই স্ট্যাটাস ট্র্যাক করে।

### **পাঠ ১৯: useActionState Hook - ভুল করলে ঝাড়ি দেওয়া**
*বিষয়:* ফর্ম সাবমিট ফেইল করলে মেসেজ দেখানো।

ধরো ইউজার পাসওয়ার্ড ভুল দিয়েছে। সার্ভার থেকে একটা এরর মেসেজ আসবে। সেটা দেখাবো কীভাবে?
React 19 এটার জন্য এনেছে `useActionState` (আগে নাম ছিল `useFormState`)।

**উদাহরণ:**
```jsx
import { useActionState } from "react";

// অ্যাকশন ফাংশন
async function updateProfile(prevState, formData) {
  const name = formData.get("name");
  if (name.length < 3) {
    return { message: "❌ নাম অন্তত ৩ অক্ষরের হতে হবে মামা!" };
  }
  return { message: "✅ আপডেট সফল!" };
}

export default function Profile() {
  // [বর্তমান স্টেট, অ্যাকশন ট্রিগার, ইজ পেন্ডিং]
  const [state, formAction, isPending] = useActionState(updateProfile, { message: "" });

  return (
    <form action={formAction}>
      <input name="name" placeholder="আপনার নাম" />
      <button type="submit" disabled={isPending}>আপডেট</button>
      
      {/* অ্যাকশনের রেজাল্ট এখানে দেখাবে */}
      <p style={{ color: state.message.includes("❌") ? "red" : "green" }}>
        {state.message}
      </p>
    </form>
  );
}
```
**বাস্তবতা:** ফর্ম সাবমিট হবে, লজিক চেক হবে, তারপর রেজাল্ট ফেরত এসে `state`-এ আপডেট হয়ে যাবে। সুপার স্মুথ!

### **পাঠ ২০: Validation (Zod/Yup) - গার্ড মামার চেকিং**
*বিষয়:* ডাটা সঠিক কিনা যাচাই করা।

ক্লাবে ঢুকার আগে বাউন্সার যেমন ড্রেস কোড চেক করে, ফর্মে ডাটা পাঠানোর আগে আমাদের চেক করতে হবে ইমেইল ঠিক আছে কিনা, পাসওয়ার্ড স্ট্রং কিনা। এটার জন্য `Zod` লাইব্রেরি এখন খুব জনপ্রিয়।

**Zod কেন?** কারণ ম্যানুয়ালি `if-else` লিখে চেক করা বোরিং।

**উদাহরণ (Zod কনসেপ্ট):**
প্রথমে ইন্সটল: `npm install zod`

```javascript
import { z } from "zod";

// ১. নিয়ম কানুন সেট করা (Schema)
const UserSchema = z.object({
  email: z.string().email("ভাই, এটা কোনো ইমেইল হলো?"),
  password: z.string().min(6, "পাসওয়ার্ড অন্তত ৬ সংখ্যার হতে হবে"),
});

// ২. অ্যাকশনের ভেতর ব্যবহার
const handleSubmit = async (formData) => {
  const data = {
    email: formData.get("email"),
    password: formData.get("password")
  };

  // ৩. চেকিং (Safe Parse)
  const result = UserSchema.safeParse(data);

  if (!result.success) {
    // ভুল থাকলে এরর মেসেজ দেখাও
    console.log(result.error.flatten().fieldErrors);
    return;
  }
  
  console.log("সব ঠিক আছে! স্বাগতম।");
};
```
**টিপস:** বড় প্রজেক্টে `Zod` ছাড়া চলা মানে হেলমেট ছাড়া বাইক চালানো। যেকোনো সময় এরর খেয়ে মাথা ফাটবে!
