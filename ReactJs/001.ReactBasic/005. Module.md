25. **Cleanup Function** - *উদাহরণ:* মেহমান যাওয়ার পর ঘর পরিষ্কার করা।

রিয়্যাক্টে **"Side Effect"** মানে হলো এমন কাজ যা স্ক্রিনে ছবি আঁকা (Rendering) ছাড়া বাইরের দুনিয়ার সাথে যোগাযোগ করে। যেমন: সার্ভার থেকে ডাটা আনা, ঘড়ির টাইমার সেট করা, বা ব্রাউজারের টাইটেল চেঞ্জ করা।

এই পর্বের নাম **"বাইরের জগত ও ডাটা ফেচিং"**। চলুন শুরু করি!

### **পাঠ ২১: useEffect (Introduction) - ওষুধ খাওয়ার নিয়ম**
*বিষয়:* সাইড এফেক্ট কখন চালাবো?

রিয়্যাক্ট কম্পোনেন্ট হলো একটা ফাংশন। এটা যখন রান হয়, তখন UI দেখায়। কিন্তু আমরা যদি চাই—"কম্পোনেন্ট লোড হওয়ার পর একটা অ্যালার্ট দেখাও" বা "ডাটা নিয়ে এসো"—তখন লাগে **`useEffect`**।

**উদাহরণ:**
ভাত খাওয়া (Render) হলো মেইন কাজ। কিন্তু খাওয়ার পর ওষুধ খাওয়া (Effect) হলো সাইড কাজ।

**কোড:**
```jsx
import { useEffect, useState } from 'react';

export default function EffectDemo() {
  const [count, setCount] = useState(0);

  // কম্পোনেন্ট রেন্ডার হওয়ার *পর* এটা রান হবে
  useEffect(() => {
    console.log("মামা, আমি রান হয়েছি! 🏃‍♂️");
    document.title = `Count: ${count}`; // ব্রাউজারের ট্যাবের নাম চেঞ্জ হবে
  });

  return (
    <button onClick={() => setCount(count + 1)}>
      Click {count}
    </button>
  );
}
```
**সমস্যা:** ওপরের কোডে যতবার বাটনে চাপ দিবে (Render হবে), ততবার `useEffect` চলবে। এটা সবসময় ভালো না। ওষুধ কি সারাদিন খায় মানুষ?

### **পাঠ ২২: Dependency Array - এলার্ম ঘড়ি**
*বিষয়:* এফেক্টকে কন্ট্রোল করা।

আমরা `useEffect`-কে বলে দিতে পারি—"মামা, তুমি কখন কখন রান হবা।" এটাকেই বলে **Dependency Array** (ফাংশনের শেষে `[]` ব্র্যাকেট)।

**তিনটি অবস্থা:**

১. **ডিপেন্ডেন্সি নেই:** (পাগলা ঘোড়া)
   ```javascript
   useEffect(() => {
     console.log("আমি বারবার রান হবো!"); 
   }); // রেন্ডার হলেই চলবে
   ```

২. **খালি অ্যারে `[]`:** (একবারই জন্ম)
   ```javascript
   useEffect(() => {
     console.log("আমি শুধু শুরুতে একবারই রান হবো!");
   }, []); // কম্পোনেন্ট মাউন্ট হওয়ার সময় ১ বার চলবে (API Call এর জন্য সেরা)
   ```

৩. **ভেরিয়েবলসহ `[count]`:** (শর্ত সাপেক্ষে)
   ```javascript
   useEffect(() => {
     console.log("Count চেঞ্জ হলেই আমি রান হবো!");
   }, [count]); // এলার্ম: count চেঞ্জ হলে বাজবে
   ```

### **পাঠ ২৩: API Fetching (Old Way) - ওয়েটার ডাকা**
*বিষয়:* সার্ভার থেকে ডাটা আনা (পুরানো স্টাইল)।

React 19 এর আগে (এবং এখনো ছোটখাটো কাজে) আমরা `useEffect` এর ভেতর `fetch` কল করি।

**ধাপ:**
১. লোডিং স্টেট `true` করো।
২. ডাটা আনো (Fetch)।
৩. ডাটা স্টেটে রাখো।
৪. লোডিং `false` করো।

**কোড (UserList.jsx):**
```jsx
import { useState, useEffect } from 'react';

export default function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // API কল
    fetch('https://jsonplaceholder.typicode.com/users')
      .then(res => res.json())
      .then(data => {
        setUsers(data); // ডাটা পেলাম
        setLoading(false); // লোডিং বন্ধ
      });
  }, []); // [] মানে শুধু একবার লোড হবে

  if (loading) return <h2>অপেক্ষা করুন মামা... ⏳</h2>;

  return (
    <ul>
      {users.map(user => <li key={user.id}>{user.name}</li>)}
    </ul>
  );
}
```
এটাকে আমরা বলি **"Fetch-on-render"**। একটু পুরনো পদ্ধতি, কিন্তু বেসিক জানার জন্য জরুরি।

### **পাঠ ২৪: Data Fetching (React 19 Way) - `use()` হুক**
*বিষয়:* মাখনের মতো ডাটা লোড করা।

React 19 বলছে—"এত `useEffect`, `useState`, `loading` হ্যান্ডেল করতে হবে না।"
নতুন হুক **`use()`** সরাসরি প্রমিস (Promise) হ্যান্ডেল করতে পারে।

**সতর্কতা:** এটা সাধারণত `Suspense` এর সাথে ব্যবহার করতে হয়।

**কোড (আধুনিক স্টাইল):**
```jsx
import { use, Suspense } from 'react';

// প্রমিসটা কম্পোনেন্টের বাইরে বানালাম (Caching এর জন্য ভালো)
const usersPromise = fetch('https://jsonplaceholder.typicode.com/users')
  .then(res => res.json());

function Users() {
  // ম্যাজিক: use() হুক ডাটা আসার আগ পর্যন্ত অপেক্ষা করাবে
  const users = use(usersPromise);

  return (
    <ul>
      {users.map(user => <li key={user.id}>{user.name}</li>)}
    </ul>
  );
}

export default function App() {
  return (
    // Suspense হ্যান্ডেল করবে লোডিং স্টেট
    <Suspense fallback={<h2>লোডিং হচ্ছে (React 19)... 🚀</h2>}>
      <Users />
    </Suspense>
  );
}
```
**পার্থক্য:** কোড অর্ধেক হয়ে গেছে! ম্যানুয়ালি `isLoading` চেক করার দরকার নাই। `Suspense` সেটা দেখে নিবে।

### **পাঠ ২৫: Cleanup Function - মেহমান বিদায় করা**
*বিষয়:* মেমোরি লিক বন্ধ করা।

ধরো তুমি `useEffect` দিয়ে একটা টাইমার চালু করলে বা চ্যাট সার্ভারে কানেক্ট হলে। কম্পোনেন্ট ডিলিট হওয়ার পর (অন্য পেজে গেলে) সেটা বন্ধ না করলে ব্যাকগ্রাউন্ডে চলতেই থাকবে। পিসি স্লো হয়ে যাবে।

এটাকে বলে **Cleanup**।

**উদাহরণ:** চ্যাটিং অ্যাপ।
```jsx
useEffect(() => {
  const connection = createConnection();
  connection.connect();
  console.log("✅ কানেক্টেড!");

  // এটা হলো ক্লিনআপ ফাংশন (রিটার্ন করতে হয়)
  return () => {
    connection.disconnect();
    console.log("❌ ডিসকানেক্টেড (মেহমান চলে গেছে)");
  };
}, []);
```
**রিয়েল লাইফ:** মেহমান (Effect) আসলে আপ্যায়ন করো, আর চলে যাওয়ার সময় দরজা লাগিয়ে দাও (Cleanup)। না হলে চোর (Bug) ঢুকবে!
