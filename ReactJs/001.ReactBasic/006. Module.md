
### **পর্ব ৬: স্টাইলিং - মেকআপ বক্স (Styling)**

28. **Tailwind দিয়ে Responsive Design** - *উদাহরণ:* মোবাইল, ল্যাপটপ আর ট্যাবে ওয়েবসাইটকে ঠিকঠাক দেখানো।

### **পাঠ ২৬: CSS Modules - নিজের রুমের ডেকোরেশন**
*বিষয়:* এক ফাইলের স্টাইল যেন অন্য ফাইলে ঝামেলা না করে।

**সমস্যা:** সাধারণ CSS-এ যদি `App.css`-এ `.btn { color: red }` লেখেন, সেটা পুরো অ্যাপের সব বাটনে অ্যাপ্লাই হয়ে যাবে। এটা অনেকটা মেসের কমন রুমের মতো—সবাই ব্যবহার করে।

**সমাধান (CSS Modules):**
এটা হলো আপনার পার্সোনাল বেডরুম। এখানে দেয়াল নীল করলে পাশের রুমের দেয়াল নীল হবে না।

**কিভাবে করবেন?**
১. ফাইলের নাম দিন `Button.module.css` (মাঝখানে `module` থাকতে হবে)।
২. `Button.jsx` ফাইলে ইম্পোর্ট করুন একটা অবজেক্ট হিসেবে।

```css
/* Button.module.css */
.myBtn {
  background-color: purple;
  color: white;
  padding: 10px;
}
```

```jsx
// Button.jsx
import styles from './Button.module.css'; // styles নাম দিলাম

export default function Button() {
  return (
    // সরাসরি স্ট্রিং না লিখে, অবজেক্ট থেকে ক্লাস নিব
    <button className={styles.myBtn}>
      আমাকে চাপ দিন
    </button>
  );
}
```
**লাভ:** ব্রাউজারে ক্লাস নেমটা অটোমেটিক `Button_myBtn_xh52` হয়ে যাবে। তাই নাম এক হলেও কনফ্লিক্ট হবে না।

### **পাঠ ২৭: Tailwind CSS সেটআপ - রেডিমেড স্যুট-কোট**
*বিষয়:* CSS না লিখে ক্লাস দিয়ে ডিজাইন করা।

সাধারণ CSS লেখা মানে দর্জি দিয়ে কাপড় বানানো (সময় লাগে)। আর **Tailwind** হলো রেডিমেড শোরুম। জাস্ট বলবেন "লাল শার্ট, মিডিয়াম সাইজ"—ব্যাস, হয়ে গেল!

**ইনস্টলেশন (Vite প্রজেক্টে):**
টার্মিনালে এই কমান্ডগুলো দিন (ভয় নেই, একবারই দিতে হয়):
```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```
এরপর `tailwind.config.js` ফাইলে `content` এর ভেতর এটা লিখুন:
```javascript
content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"],
```
শেষে `index.css` এর একদম ওপরে ৩ লাইন বসিয়ে দিন:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```
**ব্যাস! খেলা শুরু:**
```jsx
export default function Card() {
  return (
    <div className="bg-blue-500 text-white p-4 rounded-xl shadow-lg">
      আমি এখন টেইলউইন্ড দিয়ে হিরো! 😎
    </div>
  );
}
```
কোনো CSS ফাইল খোলা ছাড়াই ডিজাইন কমপ্লিট!

### **পাঠ ২৮: Tailwind দিয়ে Responsive Design - সব ডিভাইসে ফিট**
*বিষয়:* মোবাইল, ট্যাব আর পিসির জন্য আলাদা ডিজাইন।

**উদাহরণ:** পানি যেমন গ্লাসে রাখলে গ্লাসের আকার নেয়, বোতলে রাখলে বোতলের—ওয়েবসাইটও তেমন হতে হবে।

টেইলউইন্ডে এটা পানির মতো সহজ। আমরা **Mobile First** এপ্রোচ ফলো করব। মানে আগে মোবাইলের জন্য লিখব, তারপর বড় স্ক্রিনের জন্য।

**ব্রেকপয়েন্ট:** `sm` (ট্যাব), `md` (ল্যাপটপ), `lg` (বড় মনিটর)।

```jsx
export default function ResponsiveBox() {
  return (
    <div className="bg-red-500 md:bg-green-500 lg:bg-blue-500 p-10">
      <h1>ম্যাজিক দেখুন!</h1>
      <p>মোবাইলে আমি লাল 🔴</p>
      <p>ল্যাপটপে আমি সবুজ 🟢</p>
      <p>বড় স্ক্রিনে আমি নীল 🔵</p>
    </div>
  );
}
```
ব্রাউজার ছোট-বড় করে দেখুন, কালার অটোমেটিক চেঞ্জ হবে!

### **পাঠ ২৯: Dynamic Styling - ডার্ক ও লাইট মোড**
*বিষয়:* লজিক বা স্টেটের ওপর ভিত্তি করে ডিজাইন পাল্টানো।

ধরুন, ইউজার যদি "Active" থাকে তবে বাটন সবুজ হবে, আর না থাকলে ধূসর।

**উপায় ১: টার্নারি অপারেটর (সবচেয়ে সহজ)**
```jsx
import { useState } from 'react';

export default function ToggleBtn() {
  const [isActive, setIsActive] = useState(false);

  return (
    <button
      onClick={() => setIsActive(!isActive)}
      // ব্যাকটিক (`) ব্যবহার করে ডায়নামিক ক্লাস
      className={`p-3 rounded text-white ${isActive ? "bg-green-500" : "bg-gray-400"}`}
    >
      {isActive ? "Active ✅" : "Inactive 💤"}
    </button>
  );
}
```

**উপায় ২: ইনলাইন স্টাইল (কম ব্যবহার করাই ভালো)**
```jsx
<div style={{ backgroundColor: isActive ? 'black' : 'white' }}>...</div>
```

### **পাঠ ৩০: React Icons & Assets - দেয়াল সাজানো**
*বিষয়:* ছবি এবং আইকন যোগ করা।

একটা ওয়েবসাইট শুধু টেক্সট দিয়ে বানালে সেটা "খবরের কাগজ" মনে হবে। আমাদের আইকন দরকার।

**ছবি যোগ করা (Assets):**
ছবিগুলো `src/assets` ফোল্ডারে রাখুন।
```jsx
import mySelfie from './assets/selfie.jpg';

<img src={mySelfie} alt="আমি" className="w-20 h-20 rounded-full" />
```

**React Icons ব্যবহার করা:**
আইকনের জন্য সেরা লাইব্রেরি `react-icons`।
১. ইনস্টল: `npm install react-icons`
২. ব্যবহার:
```jsx
import { FaFacebook, FaYoutube } from "react-icons/fa"; // FontAwesome

export default function Social() {
  return (
    <div className="flex gap-4 text-3xl text-blue-600">
      <FaFacebook className="cursor-pointer hover:text-blue-800" />
      <FaYoutube className="text-red-600 cursor-pointer" />
    </div>
  );
}
```
এখন আপনার সাইট দেখতে প্রফেশনাল লাগবে!
