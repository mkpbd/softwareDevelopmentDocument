### **পাঠ ৩১: React Router Dom 7 সেটআপ - জিপিএস ইনস্টল**
*বিষয়:* রাস্তায় বের হওয়ার আগে ম্যাপ রেডি করা।

রিয়্যাক্টে এক পেজ থেকে অন্য পেজে যাওয়ার জন্য ডিফল্ট কোনো ব্যবস্থা নেই। আমাদের একটা থার্ড-পার্টি প্যাকেজ লাগে, যার নাম `react-router-dom`। (আমরা লেটেস্ট ভার্সন ব্যবহার করব)।

**ইনস্টলেশন:**
টার্মিনালে লিখুন:
```bash
npm install react-router-dom
```

**সেটআপ (main.jsx):**
পুরো অ্যাপটাকে রাউটারের চাদর দিয়ে মুড়িয়ে দিতে হবে।
```jsx
import { BrowserRouter } from 'react-router-dom';
import { createRoot } from 'react-dom/client';
import App from './App.jsx';

createRoot(document.getElementById('root')).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>
);
```
**App.jsx এ রাস্তা বানানো:**
```jsx
import { Routes, Route } from 'react-router-dom';
import Home from './Home';
import About from './About';

function App() {
  return (
    <Routes>
      {/* ঠিকানা এবং গন্তব্য সেট করা */}
      <Route path="/" element={<Home />} />
      <Route path="/about" element={<About />} />
      <Route path="*" element={<h1>৪০৪ - রাস্তা ভুল করছেন মামা! 😵</h1>} />
    </Routes>
  );
}
```
এখন ব্রাউজারে `/about` লিখলে `About` কম্পোনেন্ট আসবে।

### **পাঠ ৩২: Link & NavLink - রিকশা vs উবার**
*বিষয়:* পেজ রিলোড না করে এক জায়গা থেকে আরেক জায়গায় যাওয়া।

**পুরানো পদ্ধতি (HTML `<a>` tag):**
```html
<a href="/about">About</a>
```
এটা অনেকটা রিকশাওয়ালার মতো। প্রতিবার মোড় ঘুরলে রিকশা থামিয়ে চেইন ঠিক করে (Page Reload)। এতে অ্যাপ স্লো মনে হয়, আর আগের স্টেট (State) হারিয়ে যায়।

**নতুন পদ্ধতি (`<Link>`):**
```jsx
import { Link } from 'react-router-dom';

<Link to="/about">About Page</Link>
```
এটা উবারের মতো। থামবে না, জাস্ট স্মুথলি চলে যাবে। পেজ রিলোড হবে না!

**স্পেশাল ফিচার (`<NavLink>`):**
আপনি এখন কোন পেজে আছেন সেটা ইউজারকে বুঝাতে চাইলে `NavLink` ব্যবহার করুন।
```jsx
import { NavLink } from 'react-router-dom';

<NavLink 
  to="/about" 
  className={({ isActive }) => isActive ? "text-red-500 font-bold" : "text-black"}
>
  About
</NavLink>
```
ম্যাজিক: আপনি যদি About পেজে থাকেন, লেখাটা অটোমেটিক লাল হয়ে যাবে!

### **পাঠ ৩৩: Dynamic Route (useParams) - ফেইসবুক প্রোফাইল**
*বিষয়:* এক টেম্পলেট, হাজার হাজার পেজ।

ফেইসবুকে সবার প্রোফাইল পেজ দেখতে একই রকম (কভার ফটো, ডিপি), কিন্তু ডাটা আলাদা। তারা কি ১০০ কোটি মানুষের জন্য ১০০ কোটি পেজ বানিয়েছে? না! পেজ একটাই, ইউআরএল ডায়নামিক।

**রাস্তা সেট করা (App.jsx):**
```jsx
// :id মানে এখানে যা খুশি বসতে পারে (1, 2, rahim, karim)
<Route path="/profile/:username" element={<Profile />} />
```

**ডাটা ধরা (Profile.jsx):**
```jsx
import { useParams } from 'react-router-dom';

export default function Profile() {
  const { username } = useParams(); // URL থেকে নামটা বের করে আনলাম

  return (
    <div>
      <h1>স্বাগতম, {username} ভাই! 👋</h1>
      <p>এটা আপনার পার্সোনাল প্রোফাইল।</p>
    </div>
  );
}
```
এখন `/profile/rahim` এ গেলে দেখাবে "স্বাগতম, rahim ভাই!"।

### **পাঠ ৩৪: Nested Routes - ফ্ল্যাটের ভেতর রুম**
*বিষয়:* এক পেজের ভেতর আরেক পেজ (সাব-মেনু)।

ধরুন একটা ড্যাশবোর্ড বানাবেন। বাম পাশে সাইডবার ফিক্সড থাকবে, শুধু ডান পাশের কন্টেন্ট বদলাবে। এটাকে বলে নেস্টেড রাউটিং।

**App.jsx:**
```jsx
<Route path="/dashboard" element={<Dashboard />}>
  <Route path="settings" element={<Settings />} />
  <Route path="profile" element={<Profile />} />
</Route>
```

**Dashboard.jsx (প্যারেন্ট):**
```jsx
import { Outlet, Link } from 'react-router-dom';

export default function Dashboard() {
  return (
    <div style={{ display: 'flex' }}>
      <nav>
        <Link to="settings">Settings</Link>
        <Link to="profile">Profile</Link>
      </nav>
      
      <main>
        <h1>ড্যাশবোর্ড মেইন এরিয়া</h1>
        {/* Outlet হলো সেই জানালা যেখানে চাইল্ড পেজগুলো দেখাবে */}
        <Outlet /> 
      </main>
    </div>
  );
}
```
`Outlet` না দিলে বাচ্চার খবর পাওয়া যাবে না!

### **পাঠ ৩৫: Protected Route - টিকিট চেকিং**
*বিষয়:* লগইন ছাড়া গোপন পেজে ঢুকতে না দেওয়া।

সিনেমা হলে টিকিট ছাড়া ঢুকতে গেলে গার্ড যেমন আটকে দেয়, আমাদের অ্যাপেও কিছু প্রাইভেট পেজ (যেমন: প্রোফাইল, ড্যাশবোর্ড) থাকে।

আমরা একটা গার্ড কম্পোনেন্ট বানাবো।

**PrivateRoute.jsx:**
```jsx
import { Navigate } from 'react-router-dom';

// এটা একটা র‍্যাপার কম্পোনেন্ট
export default function PrivateRoute({ children, isLoggedIn }) {
  if (!isLoggedIn) {
    // টিকিট নাই? লগইন পেজে ভাগো!
    return <Navigate to="/login" replace />;
  }
  // টিকিট আছে? ভেতরে যাও মামা
  return children;
}
```

**ব্যবহার (App.jsx):**
```jsx
<Route 
  path="/dashboard" 
  element={
    <PrivateRoute isLoggedIn={userState}>
      <Dashboard />
    </PrivateRoute>
  } 
/>
```
এখন ইউজার লগইন না থাকলে ড্যাশবোর্ডে ক্লিক করলেই তাকে ঘাড় ধরে লগইন পেজে পাঠিয়ে দেবে! 👮‍♂️
