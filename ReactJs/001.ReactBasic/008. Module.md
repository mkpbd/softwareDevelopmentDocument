### **পাঠ ৩৬: Prop Drilling সমস্যা - বালতি টানাটানি**
*বিষয়:* কেন আমাদের গ্লোবাল স্টেট দরকার?

**সমস্যা:**
ধরো, তোমার অ্যাপের স্ট্রাকচার এমন:
`App` -> `GrandFather` -> `Father` -> `Son` -> `GrandSon`

এখন `App` এর কাছে একটা ডাটা আছে `userName = "Hero Alom"`। এটা `GrandSon` এর দরকার।
সাধারণ নিয়মে তোমাকে এই ডাটা `App` থেকে `GrandFather`, তারপর `Father`, তারপর `Son` হয়ে `GrandSon`-এ পাঠাতে হবে। মাঝখানের বাপ-দাদারা এই ডাটা দিয়ে কিছুই করবে না, শুধু ক্যারিয়ার হিসেবে বয়ে বেড়াবে।

এটাকে বলে **Prop Drilling**। কোড দেখতে জঘন্য লাগে এবং মেইনটেইন করা কষ্টের।

**উদাহরণ:** ৫ তলা থেকে ১ তলায় বালতি হাতে হাতে পাস করা। মাঝখানের সবার হাত ব্যথা হয়ে যাবে! 😫

### **পাঠ ৩৭: createContext & useContext - মসজিদের মাইক**
*বিষয়:* এক জায়গা থেকে ব্রডকাস্ট করা।

এই সমস্যা সমাধানে এলো **Context API**।
এটা অনেকটা মসজিদের মাইকের মতো। ইমাম সাহেব (Provider) মাইকে কথা বললে পাড়ার সবাই (Consumers) সেটা শুনতে পায়, মাঝখানের কারো সাহায্য লাগে না।

**স্টেপ ১: কনটেক্সট বানানো (মাইক সেটআপ)**
```jsx
import { createContext } from 'react';

export const UserContext = createContext(); // ১. খালি কনটেক্সট বানালাম
```

**স্টেপ ২: প্রোভাইডার দেওয়া (স্পিকার অন করা)**
```jsx
import { useState } from 'react';
import { UserContext } from './UserContext';

export default function App() {
  const [user, setUser] = useState("Hero Alom");

  return (
    // ২. ভ্যালু দিয়ে অ্যাপ মুড়িয়ে দিলাম
    <UserContext.Provider value={user}>
      <GrandFather />
    </UserContext.Provider>
  );
}
```

**স্টেপ ৩: ডাটা রিসিভ করা (শোনা)**
`GrandSon.jsx` ফাইলে গিয়ে সরাসরি শোনা যাবে:
```jsx
import { useContext } from 'react';
import { UserContext } from './UserContext';

export default function GrandSon() {
  const user = useContext(UserContext); // ৩. ডাইরেক্ট কানেকশন!
  return <h1>হ্যালো, {user}!</h1>;
}
```
মাঝখানের `GrandFather` বা `Father` জানলেও না কী ঘটছে! সব বাইপাস! 🚀

### **পাঠ ৩৮: React 19 `use(Context)` - নতুন আপডেট**
*বিষয়:* কনটেক্সট ব্যবহার করা এখন আরও স্মার্ট।

React 19 এ `useContext` হুক ছাড়াও নতুন **`use`** হুক দিয়ে কনটেক্সট রিড করা যায়।
সবচেয়ে বড় সুবিধা হলো, `useContext` কোনো `if-else` বা লুপের ভেতর লেখা যেত না (Hook Rules), কিন্তু `use` হুক যেখানে খুশি লেখা যায়!

**কোড:**
```jsx
import { use } from 'react'; // নতুন হুক
import { ThemeContext } from './ThemeContext';

export default function Card({ showTheme }) {
  // কন্ডিশনাল ব্যবহার সম্ভব!
  if (showTheme) {
    const theme = use(ThemeContext); // useContext এর বদলে use
    return <div className={theme}>This is {theme} mode</div>;
  }
  return <div>No Theme</div>;
}
```
**মজা:** রিয়্যাক্ট ১৯ জীবনটাকে আসলেই সহজ করে দিচ্ছে!

### **পাঠ ৩৯: State Management Libraries (Zustand) - স্টার্টআপ vs সরকারি অফিস**
*বিষয়:* কনটেক্সট যখন স্লো হয়ে যায়, তখন কী করব?

Context API ছোট বা মাঝারি অ্যাপের জন্য বস। কিন্তু অ্যাপ যখন বিশাল হয় (যেমন ফেইসবুক), তখন কনটেক্সট ব্যবহারে অ্যাপ স্লো হতে পারে। তখন লাগে এক্সটার্নাল লাইব্রেরি।

- **Redux:** এটাকে ভাবো "সরকারি অফিস"। একটা কলম কিনতে হলেও ১০টা ফাইলে সই (Boilerplate Code) লাগে। পাওয়ারফুল, কিন্তু সেটআপ করতে জান বের হয়ে যায়।
- **Zustand:** এটা হলো মডার্ন "স্টার্টআপ"। কোনো ফরমালিটি নাই, জাস্ট কাজ শুরু! সিম্পল এবং ফাস্ট।

**Zustand উদাহরণ (২ মিনিটে সেটআপ):**
১. ইনস্টল: `npm install zustand`
২. স্টোর বানানো:
```javascript
import { create } from 'zustand';

const useStore = create((set) => ({
  bears: 0,
  increasePopulation: () => set((state) => ({ bears: state.bears + 1 })),
  removeAllBears: () => set({ bears: 0 }),
}));

export default useStore;
```
৩. ব্যবহার:
```jsx
const bears = useStore((state) => state.bears);
```
কোনো প্রোভাইডার লাগে না, র‍্যাপার লাগে না। জাস্ট ইম্পোর্ট আর বুম! 💥

### **পাঠ ৪০: Context দিয়ে Theme Switcher প্রজেক্ট**
*বিষয়:* ডার্ক মোড এবং লাইট মোড টগল।

চলো আমরা Context API দিয়ে একটা রিয়েল প্রজেক্ট বানাই। পুরো অ্যাপের কালার চেঞ্জ হবে এক ক্লিকে।

**১. ThemeContext.js:**
```jsx
import { createContext, useState } from "react";

export const ThemeContext = createContext();

export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState("light"); // ডিফল্ট লাইট

  const toggleTheme = () => {
    setTheme((prev) => (prev === "light" ? "dark" : "light"));
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}
```

**২. App.jsx (সেটআপ):**
```jsx
import { ThemeProvider } from "./ThemeContext";
import PageContent from "./PageContent";

export default function App() {
  return (
    <ThemeProvider>
      <PageContent />
    </ThemeProvider>
  );
}
```

**৩. PageContent.jsx (ব্যবহার):**
```jsx
import { use } from "react"; // React 19 style
import { ThemeContext } from "./ThemeContext";

export default function PageContent() {
  const { theme, toggleTheme } = use(ThemeContext);

  return (
    <div style={{ 
      backgroundColor: theme === "light" ? "#fff" : "#333", 
      color: theme === "light" ? "#000" : "#fff",
      height: "100vh", padding: "20px" 
    }}>
      <h1>এখন মোড: {theme.toUpperCase()}</h1>
      <button onClick={toggleTheme}>
        সুইচ চাপুন 💡
      </button>
    </div>
  );
}
```
এখন বাটনে চাপলে পুরো অ্যাপের ব্যাকগ্রাউন্ড কালো/সাদা হবে। এটাই গ্লোবাল স্টেটের পাওয়ার!
