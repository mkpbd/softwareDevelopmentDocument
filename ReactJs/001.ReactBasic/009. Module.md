### **পাঠ ৪১: React Compiler (React 19 Magic) - অটোমেটিক গিয়ার**
*বিষয়:* ম্যানুয়ালি অপ্টিমাইজ করার দিন শেষ।

**আগের দিন (React 18 বা তার আগে):**
আগে আমাদের অ্যাপ ফাস্ট করার জন্য `useMemo`, `useCallback`, আর `memo` দিয়ে কোড ভরে ফেলতে হতো। রিয়্যাক্টকে হাতে-কলমে বলে দিতে হতো—"মামা, এই ফাংশনটা বারবার বানাইও না, এটা সেইভ করে রাখো।" এটা ছিল ম্যানুয়াল গিয়ারের গাড়ির মতো—বারবার গিয়ার চেঞ্জ করার প্যারা।

**React 19 এর জাদুকরী কম্পাইলার:**
React 19 এ এসেছে **React Compiler**। এটা একটা অটোমেটিক গিয়ারের গাড়ি।
আপনি জাস্ট কোড লিখবেন, কম্পাইলার নিজেই বুঝবে কোনটা রি-রেন্ডার করা দরকার আর কোনটা দরকার নাই।

**উদাহরণ:**
```jsx
// আগে আমরা এভাবে লিখতাম (Old Way)
const expensiveCalculation = useMemo(() => {
  return count * 1000;
}, [count]);

// React 19 (New Way)
const expensiveCalculation = count * 1000; 
// রিয়্যাক্ট কম্পাইলার নিজে থেকেই এটাকে মেমোইজ করে নিবে। আপনার টেনশন নাই!
```
**লাভ:** কোড থেকে `useMemo`, `useCallback` এর জঞ্জাল কমে গেল। জীবন এখন অনেক সুন্দর! 😎

### **পাঠ ৪২: Lazy Loading (Suspense) - কিস্তিতে লোড করা**
*বিষয়:* সব একসাথে না এনে প্রয়োজনে লোড করা।

ধরুন আপনার অ্যাপে একটা বিশাল ড্যাশবোর্ড আছে যেটা লোড হতে অনেক সময় নেয়। ইউজার যখন হোমপেজে আছে, তখন কি ড্যাশবোর্ড লোড করার দরকার আছে? না!

এটাকে বলে **Lazy Loading** (অলস লোডিং)। যখন লাগবে, তখন লোড হবে।

**উদাহরণ:** রেস্টুরেন্টে গিয়ে সব খাবার একসাথে অর্ডার না করে, আগে স্টার্টার খাওয়া। মেইন ডিশ (বড় কম্পোনেন্ট) রান্না হতে থাকুক।

**কোড:**
```jsx
import { lazy, Suspense } from 'react';

// ১. অলসভাবে ইম্পোর্ট করা (Lazy Import)
const BigDashboard = lazy(() => import('./BigDashboard'));

export default function App() {
  return (
    <div>
      <h1>আমার অ্যাপ</h1>
      
      {/* ২. লোড হওয়ার আগ পর্যন্ত যা দেখাবে (Suspense) */}
      <Suspense fallback={<h2>ড্যাশবোর্ড আসছে... চাকা ঘুরছে 🌀</h2>}>
        <BigDashboard />
      </Suspense>
    </div>
  );
}
```
এতে অ্যাপ ওপেন হবে চোখের পলকে!

### **পাঠ ৪৩: Custom Hooks - নিজের টুলবক্স**
*বিষয়:* লজিক শেয়ার করা।

ধরুন, আপনার অ্যাপের ৫টা কম্পোনেন্টে "ইন্টারনেট আছে কি না" চেক করতে হয়। আপনি কি ৫ জায়গায় একই কোড লিখবেন? মোটেও না! আমরা একটা **Custom Hook** বানাবো।

**উদাহরণ:** "গরম মশলা মিক্স"। একবার বানিয়ে বয়ামে রেখে দিবেন, যখন মাংস রাঁধবেন (Component), তখন এক চামচ দিয়ে দিবেন।

**ধাপ ১: হুক বানানো (useOnlineStatus.js)**
```jsx
import { useState, useEffect } from 'react';

export function useOnlineStatus() {
  const [isOnline, setIsOnline] = useState(true);

  useEffect(() => {
    window.addEventListener('offline', () => setIsOnline(false));
    window.addEventListener('online', () => setIsOnline(true));
    // ক্লিনআপ করতে ভুলবেন না!
    return () => {
      window.removeEventListener('offline', () => setIsOnline(false));
      window.removeEventListener('online', () => setIsOnline(true));
    };
  }, []);

  return isOnline;
}
```

**ধাপ ২: ব্যবহার করা (যেকোনো ফাইলে)**
```jsx
import { useOnlineStatus } from './useOnlineStatus';

function StatusBar() {
  const online = useOnlineStatus(); // জাস্ট কল করলাম
  return <h1>{online ? "✅ কানেক্টেড" : "❌ ডিসকানেক্টেড"}</h1>;
}
```
আপনি এখন অফিসিয়ালি হুক ইঞ্জিনিয়ার! 🛠️

### **পাঠ ৪৪: useRef Hook - কান ধরে টানা**
*বিষয়:* DOM এলিমেন্ট সরাসরি ধরা।

রিয়্যাক্টে আমরা সাধারণত DOM ধরি না। কিন্তু মাঝে মাঝে ইনপুট ফিল্ডে ফোকাস করতে বা ভিডিও প্লে/পজ করতে সরাসরি এলিমেন্টকে ধরতে হয়। `useRef` হলো সেই হাত, যা দিয়ে DOM-এর কান ধরা যায়।

**আরেকটি কাজ:** `useRef` এর ভ্যালু চেঞ্জ হলে কম্পোনেন্ট রি-রেন্ডার হয় না। এটা "গোপন পকেট" এর মতো।

**উদাহরণ (Focus Input):**
```jsx
import { useRef } from 'react';

export default function Form() {
  const inputRef = useRef(null); // শুরুতে নাল

  const handleClick = () => {
    // সরাসরি ইনপুট ফিল্ডে ফোকাস করা
    inputRef.current.focus(); 
    inputRef.current.style.backgroundColor = "yellow"; // স্টাইলও বদলানো যায়!
  };

  return (
    <div>
      <input ref={inputRef} placeholder="এখানে লিখুন..." />
      <button onClick={handleClick}>ফোকাস করো</button>
    </div>
  );
}
```

### **পাঠ ৪৫: Error Boundaries - বাম্পার বা ফিউজ**
*বিষয়:* পুরো অ্যাপ ক্রাশ খাওয়া থেকে বাঁচানো।

জাভাস্ক্রিপ্টে একটা ছোট এরর হলে পুরো সাদা পেজ (White Screen of Death) চলে আসে। এটা খুব লজ্জাজনক।
**Error Boundary** হলো গাড়ির বাম্পার। বাম্পারে ধাক্কা লাগলে লাইট ভাঙ্গে, কিন্তু ইঞ্জিন ঠিক থাকে।

*নোট:* ফাংশনাল কম্পোনেন্টে এখনো অফিশিয়াল এরর বাউন্ডারি হুক আসেনি, তাই ক্লাস কম্পোনেন্ট বা `react-error-boundary` লাইব্রেরি ব্যবহার করতে হয়। আমরা লাইব্রেরি দিয়েই শিখব (সহজ)।

**ইনস্টল:** `npm install react-error-boundary`

**কোড:**
```jsx
import { ErrorBoundary } from "react-error-boundary";

// ১. এরর হলে যা দেখাবে (Fallback UI)
function ErrorFallback({ error, resetErrorBoundary }) {
  return (
    <div role="alert" className="text-red-500">
      <p>ওহ নো! কিছু একটা ভুল হয়েছে:</p>
      <pre>{error.message}</pre>
      <button onClick={resetErrorBoundary}>আবার চেষ্টা করুন</button>
    </div>
  );
}

// ২. মেইন অ্যাপকে মুড়িয়ে দেওয়া
export default function App() {
  return (
    <ErrorBoundary FallbackComponent={ErrorFallback}>
      <MyBuggyComponent /> {/* এই কম্পোনেন্ট ক্রাশ খেলেও পুরো অ্যাপ ঠিক থাকবে */}
    </ErrorBoundary>
  );
}
```
এখন অ্যাপ ক্রাশ করলেও ইউজার একটা সুন্দর মেসেজ দেখবে, সাদা স্ক্রিন না।
