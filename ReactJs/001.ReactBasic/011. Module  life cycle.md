

হ্যালো রিয়্যাক্ট লাভারস! 👋

আজ আমরা রিয়্যাক্টের **"কম্পোনেন্ট লাইফসাইকেল"** নিয়ে আড্ডা দিব। নাম শুনেই মনে হচ্ছে বায়োলজি ক্লাসের কথা, তাই না? আসলে রিয়্যাক্ট কম্পোনেন্টগুলো অনেকটা মানুষের মতোই।

১. **জন্ম নেয়** (Mounting)
২. **বেড়ে ওঠে/পরিবর্তিত হয়** (Updating)
৩. **মারা যায়/চলে যায়** (Unmounting)

এই পুরো জার্নিটা কন্ট্রোল করার জন্য রিয়্যাক্ট আমাদের কিছু স্পেশাল মেথড দিয়েছে। চলো, মানুষের জীবনের সাথে তুলনা করে একদম পানির মতো সহজ করে বুঝি।

---

### **পর্ব ১: মাউন্টিং (Mounting) - জন্ম বা আগমন**
*একটা কম্পোনেন্ট যখন প্রথমবার ব্রাউজারে (DOM-এ) লোড হয়।*

#### **১. `constructor()` – পেটে থাকা অবস্থা**
কম্পোনেন্ট তৈরির একদম প্রথম ধাপ। এটা অনেকটা মায়ের পেটে বাচ্চার ব্রেইন সেটআপ হওয়ার মতো।
*   **কাজ:** এখানে আমরা কম্পোনেন্টের প্রাথমিক **State** (বৈশিষ্ট্য) সেট করি।
*   **বাস্তব উদাহরণ:** একটা বাচ্চা জন্মাবে, তার চোখের রং কী হবে, সে শান্ত হবে নাকি চঞ্চল হবে—এগুলো আগেই ডিএনএ-তে সেট হয়ে যায়।
*   **কখন কল হয়?:** কম্পোনেন্ট স্ক্রিনে আসার ঠিক আগে।

#### **২. `render()` – পৃথিবীর আলো দেখা**
এটা হলো কম্পোনেন্টের চেহারা দেখানো।
*   **কাজ:** JSX রিটার্ন করা, মানে HTML স্ট্রাকচার তৈরি করা।
*   **বাস্তব উদাহরণ:** ডাক্তার নার্সকে বলল, "বাচ্চা হয়েছে!" এবং সবাই দেখল বাচ্চাটা দেখতে কেমন। এই যে বাচ্চাটা দৃশ্যমান হলো, এটাই রেন্ডার।
*   **সতর্কতা:** এখানে কোনো সাইড এফেক্ট (যেমন ডাটা ফেচ করা) করা যাবে না। এটা শুধু চেহারা দেখানোর জন্য।

#### **৩. `componentDidMount()` – প্রথম কান্না**
বাচ্চা পৃথিবীতে আসার পর প্রথম যে কাজটা করে (যেমন কাঁদা বা দুধ খাওয়া), সেটাই এটা।
*   **কাজ:** API কল করা, টাইমার সেট করা বা বাইরের দুনিয়ার সাথে কানেক্ট করা।
*   **বাস্তব উদাহরণ:** বাচ্চা জন্মানোর পর তাকে টিকা দেওয়া হলো বা নাম রাখা হলো। মানে, স্ট্রাকচার রেডি হওয়ার পর বাইরের কাজগুলো করা।
*   **কখন কল হয়?:** প্রথমবার `render()` শেষ হওয়ার ঠিক পরেই।

---

### **পর্ব ২: আপডেটিং (Updating) - বেড়ে ওঠা ও পরিবর্তন**
*মানুষের মুড বা অবস্থা যেমন চেঞ্জ হয়, কম্পোনেন্টেরও `Props` বা `State` চেঞ্জ হলে সে আপডেট হয়।*

#### **৪. `shouldComponentUpdate()` – রিয়্যাকশন দিবো কি না?**
ধরো কেউ তোমাকে গালি দিল। তুমি কি পাল্টা গালি দিবে (Update), নাকি ইগনোর করবে? এই ডিসিশনটা এখানে নেওয়া হয়।
*   **কাজ:** এটা পারফরমেন্স বাড়ানোর জন্য। যদি `return false` করো, তবে রিয়্যাক্ট আর রেন্ডার করবে না।
*   **বাস্তব উদাহরণ:** তোমার বন্ধু তোমাকে পঁচা জোকস শোনালো। তুমি ভাবলে, "ধুর! এটায় হাসবো না (No Render)"। আবার ভালো জোকস হলে হাসলে (Re-render)।
*   **ডিফল্ট:** রিয়্যাক্ট বাই ডিফল্ট সব চেঞ্জেই `true` রিটার্ন করে।

#### **৫. `render()` – নতুন রূপে আসা**
যদি `shouldComponentUpdate` সবুজ সংকেত দেয়, তবে `render` আবার কল হয়।
*   **বাস্তব উদাহরণ:** মুড খারাপ হলে তোমার মুখের এক্সপ্রেশন যেমন চেঞ্জ হয়ে যায়, স্টেটের ডাটা চেঞ্জ হলে রিয়্যাক্ট আবার নতুন করে চেহারা (UI) আঁকে।

#### **৬. `componentDidUpdate()` – কাজ শেষে হাত ধোয়া**
আপডেট হওয়ার ঠিক পরেই এটা কল হয়।
*   **কাজ:** আগের স্টেটের সাথে বর্তমান স্টেটের তুলনা করা।
*   **বাস্তব উদাহরণ:** তুমি ভাত খেয়েছ (Update হয়েছে)। খাওয়ার পর তুমি হাত ধোবে এবং টিস্যু দিয়ে মুখ মুছবে। অর্থাৎ, পরিবর্তনের পর যদি কোনো কাজ বাকি থাকে, সেটা এখানে করা হয়।
*   **কখন কল হয়?:** রি-রেন্ডার হওয়ার ঠিক পরে।

---

### **পর্ব ৩: আনমাউন্টিং (Unmounting) - বিদায় বা প্রস্থান**
*কম্পোনেন্ট যখন স্ক্রিন থেকে গায়েব হয়ে যায়।*

#### **৭. `componentWillUnmount()` – শেষ ইচ্ছা**
কম্পোনেন্ট ডিলিট বা রিমুভ হওয়ার ঠিক আগ মুহূর্তে এটা কল হয়। এটা হলো ঘর ছেড়ে চলে যাওয়ার আগে ঘর পরিষ্কার করার মতো।
*   **কাজ:** টাইমার বন্ধ করা, ইভেন্ট লিসেনার রিমুভ করা বা কোনো কানেকশন ক্যান্সেল করা।
*   **বাস্তব উদাহরণ:** তুমি ভাড়া বাসা ছেড়ে দিচ্ছ। যাওয়ার আগে কি ফ্যান-লাইটের সুইচ বন্ধ করবে না? নাকি বাড়িওয়ালা গালি দিবে? এই মেথডটা হলো সেই সুইচ বন্ধ করা, যাতে মেমোরি লিক না হয়।

### **একনজরে পুরো জীবনচক্র (Summary Diagram 🧠)**

1.  **Constructor:** ডিএনএ সেটআপ (Initialize State).
2.  **Render:** হ্যালো ওয়ার্ল্ড! (UI Display).
3.  **ComponentDidMount:** ডাটা নিয়ে এসো (API Calls).
    *   *(মাঝখানে জীবন চলছে... স্টেট চেঞ্জ হচ্ছে...)*
4.  **ShouldComponentUpdate:** আপডেট হবো? (Performance Check).
5.  **Render (Again):** নতুন জামাকাপড় পরা (UI Update).
6.  **ComponentDidUpdate:** মেকআপ ঠিক করা (After Update Logic).
    *   *(জীবনের শেষ পর্যায়)*
7.  **ComponentWillUnmount:** টাটা বাই বাই! (Cleanup).

### **গুরুত্বপূর্ণ নোট (Modern React - Hooks):**
মামা, এখন তো আমরা **Functional Component** বেশি ব্যবহার করি। সেখানে কিন্তু `componentDidMount` বা `componentWillUnmount` আলাদা করে নেই। সবকিছুর বস হলো **`useEffect`** হুক!

*   `useEffect(() => {}, [])` = `componentDidMount`
*   `useEffect(() => {}, [state])` = `componentDidUpdate`
*   `useEffect(() => { return () => {} }, [])` = `componentWillUnmount`

আশা করি লাইফসাইকেলের এই গোলকধাঁধা এখন তোমার কাছে পানির মতো পরিষ্কার! হ্যাপি কোডিং! 🚀😎

অবশ্যই মামা! থিওরি তো শুনলাম, এবার চলো কোড দিয়ে হাতে-কলমে দেখি।

আমরা একটা **"ডিজিটাল ঘড়ি (Digital Clock)"** বানাবো। এই ঘড়িটা যখন স্ক্রিনে আসবে (Mount), তখন সময় গোনা শুরু করবে। যখন সময় বাড়বে (Update), তখন কনসোলে জানাবে। আর যখন ঘড়িটা রিমুভ করে দিব (Unmount), তখন সে থমকে যাবে।

প্রথমে **ক্লাস কম্পোনেন্ট** দিয়ে দেখি (যাতে আগের ব্যাখ্যাটা মিলে যায়), তারপর মডার্ন **হুকস** দিয়ে দেখাবো।

### **উদাহরণ ১: ক্লাস কম্পোনেন্ট (Old School Style)**

ধরি, আমাদের কম্পোনেন্টের নাম `TimerComponent`।

```jsx
import React, { Component } from 'react';

class TimerComponent extends Component {
  
  // ১. পেটে থাকা অবস্থা (Initialization)
  constructor(props) {
    super(props);
    this.state = { count: 0 };
    console.log("১. Constructor: বাচ্চার জন্ম হলো (State Set)");
  }

  // ৩. পৃথিবীতে আসার পর (Mounting)
  componentDidMount() {
    console.log("৩. componentDidMount: বাচ্চা কান্না শুরু করল (Timer Start)");
    
    // প্রতি ১ সেকেন্ড পর পর কাউন্ট বাড়াবে
    this.timerID = setInterval(() => {
      this.setState({ count: this.state.count + 1 });
    }, 1000);
  }

  // ৪. আপডেট হওয়া (Updating)
  componentDidUpdate(prevProps, prevState) {
    console.log(`৪. componentDidUpdate: বয়স বাড়লো! বর্তমান কাউন্ট: ${this.state.count}`);
  }

  // ৫. বিদায় নেওয়া (Unmounting)
  componentWillUnmount() {
    console.log("৫. componentWillUnmount: টাটা বাই বাই! (Timer Stop)");
    // মেমোরি লিক ঠেকানোর জন্য টাইমার বন্ধ করছি
    clearInterval(this.timerID);
  }

  // ২. চেহারা দেখানো (Rendering)
  render() {
    console.log("২. Render: মানুষকে চেহারা দেখাচ্ছে");
    return (
      <div style={{ border: '2px solid green', padding: '20px', margin: '10px' }}>
        <h2>টাইমার চলছে: {this.state.count} সেকেন্ড</h2>
      </div>
    );
  }
}

export default TimerComponent;
```

### **এটা টেস্ট করার জন্য প্যারেন্ট কম্পোনেন্ট (App.js)**
একটা বাটন রাখব, যেটা চাপলে ঘড়িটা একবার আসবে, আবার চাপলে গায়েব হয়ে যাবে। তাহলেই `Unmount` বুঝতে পারবে।

```jsx
import React, { useState } from 'react';
import TimerComponent from './TimerComponent';

function App() {
  const [showTimer, setShowTimer] = useState(true);

  return (
    <div style={{ textAlign: 'center', marginTop: '50px' }}>
      <h1>রিয়্যাক্ট লাইফসাইকেল টেস্ট</h1>
      
      {/* বাটন চাপলে কম্পোনেন্ট মাউন্ট/আনমাউন্ট হবে */}
      <button onClick={() => setShowTimer(!showTimer)}>
        {showTimer ? "ঘড়ি বন্ধ করুন (Unmount)" : "ঘড়ি চালু করুন (Mount)"}
      </button>

      {/* কন্ডিশনাল রেন্ডারিং */}
      {showTimer && <TimerComponent />}
    </div>
  );
}

export default App;
```

### **কনসোলে (Console) যা যা দেখতে পাবে:**

১. **পেজ লোড করলে (Mounting):**
   *   `১. Constructor: বাচ্চার জন্ম হলো...`
   *   `২. Render: মানুষকে চেহারা দেখাচ্ছে`
   *   `৩. componentDidMount: বাচ্চা কান্না শুরু করল...`

২. **প্রতি ১ সেকেন্ড পর পর (Updating):**
   *   `২. Render: মানুষকে চেহারা দেখাচ্ছে` (কারণ স্টেট চেঞ্জ হয়েছে)
   *   `৪. componentDidUpdate: বয়স বাড়লো!...`

৩. **"ঘড়ি বন্ধ করুন" বাটনে চাপ দিলে (Unmounting):**
   *   `৫. componentWillUnmount: টাটা বাই বাই!...` (টাইমার থেমে যাবে, কনসোল আর আপডেট হবে না)।

### **উদাহরণ ২: ফাংশনাল কম্পোনেন্ট (Modern React Hooks)**
এখনকার দিনে আমরা ক্লাস ব্যবহার করি না। একই কাজ `useEffect` দিয়ে কত সহজে করা যায় দেখো।

```jsx
import React, { useState, useEffect } from 'react';

function FunctionalTimer() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    // === componentDidMount ===
    console.log("১. মাউন্ট হলো: টাইমার স্টার্ট");
    
    const timer = setInterval(() => {
      setCount((prevCount) => {
        console.log("২. আপডেট হলো: রেন্ডার");
        return prevCount + 1;
      });
    }, 1000);

    // === componentWillUnmount ===
    return () => {
      console.log("৩. আনমাউন্ট হলো: সব পরিষ্কার!");
      clearInterval(timer); // ক্লিনআপ ফাংশন
    };
  }, []); // খালি অ্যারে [] মানে এটা শুধু একবারই রান হবে (Mounting এর সময়)

  return (
    <div style={{ border: '2px solid blue', padding: '20px', margin: '10px' }}>
      <h2>হুক টাইমার: {count}</h2>
    </div>
  );
}

export default FunctionalTimer;
```
