

হ্যালো ফিউচার রিয়্যাক্ট বস! 👋

আজকে আমরা রিয়্যাক্টের **Hooks**-এর অপারেশন থিয়েটারে ঢুকব। ভয় পাওয়ার কিছু নেই, ডাক্তার (আমি) সাথে আছি। হুকসগুলো দেখতে কঠিন মনে হলেও এগুলো আসলে আমাদের দৈনন্দিন জীবনের টুলের মতোই।

### **সংক্ষিপ্ত ভূমিকা — Hooks কী এবং কেন?**
সহজ কথায়, **Hooks** হলো ফাংশনাল কম্পোনেন্টের "সুপারপাওয়ার"। আগে ক্লাস কম্পোনেন্ট ব্যবহার করে আমাদের স্টেট (State) আর লাইফসাইকেল হ্যান্ডেল করতে হতো, যা ছিল অনেকটা পুরোনো আমলের ভারী ম্যানুয়াল গিয়ারের গাড়ি চালানোর মতো। আর Hooks আসার পর? এখন আমরা চালাচ্ছি অটোমেটিক গিয়ারের টেসলা! কোড ছোট, ক্লিন এবং লজিক শেয়ার করা এখন পানির মতো সহজ।

### **পর্ব ১: Hook-বাই-Hook বিস্তারিত (The Big 5)**

#### **১. `useState` — অ্যাপের মেমোরি বা মানিব্যাগ**
*   **উদ্দেশ্য:** কম্পোনেন্টের ভেতরে ডাটা মনে রাখা এবং সেই ডাটা পাল্টালে স্ক্রিন আপডেট (Re-render) করা।
*   **মজার Analogy:** ধরো এটা তোমার **মানিব্যাগ**।
    *   মানিব্যাগে টাকা (State) আছে।
    *   টাকা খরচ করলে বা বাড়লে (setState) তুমি টের পাও এবং তোমার মুড চেঞ্জ হয় (Re-render)।
    *   সাধারণ পকেটে টাকা রাখলে (normal variable) সেটা পড়ে যেতে পারে বা হারালে তুমি টের পাও না (No re-render), কিন্তু `useState` হলো সিকিউর লকার।

*   **কোড উদাহরণ:**
    ```jsx
    const [money, setMoney] = useState(100); // শুরুতে ১০০ টাকা

    function buyChai() {
      setMoney(money - 10); // ১০ টাকা কমলো, স্ক্রিন আপডেট হবে
    }
    ```

*   **কখন ব্যবহার করব:** যখনই কোনো ডাটা চেঞ্জ হলে সেটা স্ক্রিনে দেখাতে হবে (ইনপুট, কাউন্টার, টগল)।
*   **Common Mistake:** `money = 90` এভাবে সরাসরি চেঞ্জ করা। এটা পাপ! সবসময় `setMoney` বা সেটার ফাংশন ব্যবহার করতে হবে।
*   **Performance Tip:** ইনিশিয়াল ভ্যালু যদি খুব ভারী ক্যালকুলেশন হয়, তবে `useState(() => heavyCalc())` এভাবে ফাংশন পাস করো (Lazy Initialization)।

---

#### **২. `useEffect` — সাইড এফেক্ট বা ওষুধের নিয়ম**
*   **উদ্দেশ্য:** রেন্ডারিংয়ের বাইরের কাজ করা (API কল, টাইমার, DOM ম্যানিপুলেশন)।
*   **মজার Analogy:** এটা হলো **ওষুধ খাওয়ার প্রেসক্রিপশন**।
    *   ডিপেন্ডেন্সি অ্যারে `[]` খালি: ডাক্তার বলেছে "এই ওষুধ শুধু জন্মের পর একবার খাবে" (Mount)।
    *   ডিপেন্ডেন্সি অ্যারে `[count]`: ডাক্তার বলেছে "যতবার জ্বর (count) আসবে, ততবার খাবে" (Update)।
    *   ডিপেন্ডেন্সি নাই: "সারাদিন খেতেই থাকো" (Dangerous loop!)।

*   **কোড উদাহরণ:**
    ```jsx
    useEffect(() => {
      console.log("কম্পোনেন্ট লোড হয়েছে (Mount)");

      return () => {
        console.log("কম্পোনেন্ট ডিলিট হচ্ছে (Unmount/Cleanup)");
      };
    }, []); // [] মানে শুধু একবার চলবে
    ```

*   **Cleanup Function:** মেহমান চলে যাওয়ার পর ঘর ঝাড়ু দেওয়া। যেমন টাইমার বন্ধ করা বা সাবস্ক্রিপশন বাতিল করা।
*   **Common Mistake:** ডিপেন্ডেন্সি অ্যারে না দেওয়া। এতে লুপ ইনফিনিটি হয়ে পিসি হ্যাং করতে পারে।

---

#### **৩. `useRef` — গোপন পকেট বা কাঠি দিয়ে খোঁচানো**
*   **উদ্দেশ্য:** ১. DOM এলিমেন্ট সরাসরি ধরা। ২. এমন ভ্যালু রাখা যা চেঞ্জ হলে রেন্ডার হবে না।
*   **মজার Analogy:** এটা হলো ক্লাসের **"ব্যাকবেঞ্চার স্টুডেন্ট"** বা **"গোপন পকেট"**।
    *   পকেটে কিছু রাখলে বা বের করলে কেউ টের পায় না (No Re-render)।
    *   অথবা, এটা দিয়ে সরাসরি কাউকে আঙুল দিয়ে দেখানো যায় (DOM Access), যেমন—"ওই ছেলেটা!"।

*   **কোড উদাহরণ:**
    ```jsx
    const inputRef = useRef(null);
    const secretCount = useRef(0);

    const focusInput = () => {
      inputRef.current.focus(); // সরাসরি ইনপুট বক্সে কার্সর নিয়ে যাওয়া
    };

    const increaseSecret = () => {
      secretCount.current += 1; // মান বাড়বে, কিন্তু স্ক্রিন আপডেট হবে না
    };
    ```

*   **কখন ব্যবহার করব:** ইনপুট ফোকাস করতে, স্ক্রল পজিশন মাপতে, অথবা প্রিভিয়াস ভ্যালু মনে রাখতে।
*   **Common Mistake:** `useRef` এর ভ্যালু JSX-এ দেখানোর চেষ্টা করা। কারণ এটা চেঞ্জ হলে রেন্ডার হয় না, তাই স্ক্রিনে আপডেট দেখাবে না।

---

#### **৪. `useMemo` — ক্যাশ মেমোরি বা নোটশিট**
*   **উদ্দেশ্য:** ভারী ক্যালকুলেশনের রেজাল্ট সেভ করে রাখা, যাতে বারবার হিসাব করতে না হয়।
*   **মজার Analogy:** এটা হলো **"অংকের সল্যুশন গাইড/নোটবুক"**।
    *   তুমি একবার কঠিন অংকটা কষে খাতায় লিখে রেখেছ।
    *   স্যার যতক্ষণ একই অংক দিচ্ছেন, তুমি খাতা দেখে উত্তর বলে দিচ্ছ (Cached)।
    *   স্যার সংখ্যা পাল্টে দিলেই (Dependency Change) কেবল তুমি আবার অংক কষবে।

*   **কোড উদাহরণ:**
    ```jsx
    const heavyResult = useMemo(() => {
      return complexCalculation(number); // অনেক সময় লাগে
    }, [number]); // number পাল্টালেই কেবল আবার হিসাব করবে
    ```

*   **কখন ব্যবহার করব:** যখন কোনো ফাংশন রান হতে অনেক সময় নেয় এবং অ্যাপ স্লো করে দেয়।
*   **Common Mistake:** সব জায়গায় `useMemo` ব্যবহার করা। ছোটখাটো যোগ-বিয়োগে এটা ব্যবহার করলে উল্টো মেমোরি খরচ বাড়ে।

---

#### **৫. `useCallback` — ল্যামিনেট করা আই কার্ড**
*   **উদ্দেশ্য:** ফাংশন যাতে বারবার নতুন করে তৈরি না হয় (Referential Equality)।
*   **মজার Analogy:** এটা হলো তোমার **"ল্যামিনেট করা ভিজিটিং কার্ড"**।
    *   সাধারণত রিয়্যাক্ট প্রতি রেন্ডারে ফাংশনগুলোকে নতুন করে বানায় (নতুন কার্ড ছাপায়)।
    *   `useCallback` ব্যবহার করলে রিয়্যাক্ট পুরোনো কার্ডটাই পকেট থেকে বের করে দেয়, যতক্ষণ না তোমার পদবী (Dependency) পাল্টাচ্ছে।

*   **কোড উদাহরণ:**
    ```jsx
    const handleClick = useCallback(() => {
      console.log("Button Clicked");
    }, []); // এই ফাংশনটি মেমোরিতে একবারই তৈরি হবে
    ```

*   **কখন ব্যবহার করব:** যখন কোনো ফাংশন আমরা `props` হিসেবে চাইল্ড কম্পোনেন্টে পাঠাই (বিশেষ করে `React.memo` করা চাইল্ডে)।
*   **Performance Tip:** শুধু শুধু সব ফাংশনে এটা লাগাবে না, অপটিমাইজেশন দরকার হলেই লাগাবে।

#### **৬. Custom Hooks — বিরিয়ানি মিক্স মশলা**
*   **উদ্দেশ্য:** লজিক শেয়ার করা।
*   **মজার Analogy:** এটা হলো রাঁধুনীর **"রেডিমেড বিরিয়ানি মশলা"**।
    *   তুমি প্রতিবার রান্নার সময় আলাদা করে এলাচ, দারুচিনি, লবঙ্গ না বেটে, একবারে একটা প্যাকেট (Custom Hook) বানিয়ে রাখো।
    *   চিকেন বিরিয়ানি হোক বা মাটন—মশলা একটাই ব্যবহার করো।

*   **কোড উদাহরণ:**
    ```jsx
    // useOnlineStatus.js (মশলার প্যাকেট)
    function useOnlineStatus() {
      const [isOnline, setIsOnline] = useState(true);
      // ... logic to check internet
      return isOnline;
    }

    // ব্যবহার (Use):
    const online = useOnlineStatus();
    ```

### **পর্ব ২: পুরো লাইফসাইকেল টাইমলাইন (Mount → Update → Unmount)**

কম্পোনেন্টের জীবনের গল্পটা এক নজরে দেখা যাক:

#### **১. Mounting Phase (জন্ম)**
1.  **Run Lazy Initializers:** `useState(() => ...)` এর ভেতরের ফাংশন রান হয়।
2.  **Render:** কম্পোনেন্ট ফাংশনটি কল হয় এবং JSX রিটার্ন করে।
3.  **DOM Update:** রিয়্যাক্ট ব্রাউজারে HTML বসায়।
4.  **`useLayoutEffect`:** (যদি থাকে) এটা রান হয় (DOM আপডেট হওয়ার পর কিন্তু ইউজার দেখার আগে)।
5.  **`useEffect`:** ব্রাউজারে পেইন্টিং শেষ হওয়ার পর এটা রান হয় (ডিপেন্ডেন্সি `[]` থাকলে)।

#### **২. Updating Phase (বেড়ে ওঠা - যখন state/props চেঞ্জ হয়)**
1.  **Render:** কম্পোনেন্ট ফাংশন আবার কল হয়।
2.  **`useMemo` / `useCallback`:** ডিপেন্ডেন্সি চেক করে—মিলে গেলে পুরোনোটা রাখে, না মিললে নতুন করে বানায়।
3.  **DOM Update:** শুধু যেইটুকু চেঞ্জ হয়েছে, সেইটুকু আপডেট হয়।
4.  **Cleanup Effects:** আগের `useEffect` এর `return` ফাংশন রান হয় (ঘর ঝাড়ু দেওয়া)।
5.  **Run Effects:** নতুন `useEffect` রান হয়।

#### **৩. Unmounting Phase (মৃত্যু/বিদায়)**
1.  **Cleanup Effects:** `useEffect` এর `return` ফাংশন শেষবারের মতো রান হয় (সব কানেকশন বন্ধ করা)।
2.  **Remove from DOM:** স্ক্রিন থেকে কম্পোনেন্ট গায়েব।

### **পর্ব ৩: Practical Exercise / কুইজ (ব্রেইন টেস্ট 🧠)**

**প্রশ্ন ১:**
নিচের কোডে কনসোলে কী প্রিন্ট হবে এবং কতবার?
```jsx
useEffect(() => {
  console.log("I love React");
}); // কোনো array নাই
```
*(ক) একবার (খ) শুধু মাউন্টের সময় (গ) মাউন্ট এবং প্রতি আপডেটে বারবার (ঘ) এরর দিবে*

**প্রশ্ন ২:**
আমি চাই একটা ইনপুট ফিল্ডে ফোকাস করতে, কিন্তু রেন্ডার করতে চাই না। আমি কোন হুক ব্যবহার করব?
*(ক) useState (খ) useEffect (গ) useRef*

**প্রশ্ন ৩:**
`useMemo` এবং `useCallback` এর মূল পার্থক্য কী? (এক কথায়)

### **সমাধান ও হিন্টস:**
১. **উত্তর (গ):** ডিপেন্ডেন্সি অ্যারে না দিলে এটা পাগল হয়ে যাবে এবং প্রতি রেন্ডারে রান হবে।
২. **উত্তর (গ):** `useRef`। কারণ এটি রেন্ডার ট্রিগার করে না।
৩. **উত্তর:** `useMemo` ভ্যালু (রেজাল্ট) মনে রাখে, আর `useCallback` পুরো ফাংশনটা মনে রাখে।

### **পর্ব ৪: Cheat Sheet (পকেটে রাখার মতো)**

| Hook নাম | কাজ (এক কথায়) | রিটার্ন করে কী? | রেন্ডার করায়? |
| :--- | :--- | :--- | :--- |
| **useState** | ডাটা মনে রাখে (State) | `[value, setter]` | ✅ হ্যাঁ |
| **useEffect** | সাইড এফেক্ট (API, Timer) | কিছুই না (Cleanup func ছাড়া) | ❌ না (নিজে করায় না) |
| **useRef** | DOM ধরা / মিউটেবল ভ্যালু | `{ current: value }` | ❌ না |
| **useMemo** | হিসাবের ফল ক্যাশ করা | ক্যালকুলেটেড ভ্যালু | ❌ না |
| **useCallback** | ফাংশন ক্যাশ করা | মেমোইজড ফাংশন | ❌ না |
| **useContext** | গ্লোবাল ডাটা সাপ্লাই | ভ্যালু (Context Value) | ✅ হ্যাঁ (ভ্যালু পাল্টালে) |
