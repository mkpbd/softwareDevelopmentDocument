
হ্যালো ছোট্ট বন্ধু এবং ফিউচার কোডাররা! 👋

আজ আমরা শিখব **React Router**। নামটা শুনে কঠিন মনে হচ্ছে? একদম না! এটা হলো তোমার ওয়েবসাইটের **"ট্রাফিক পুলিশ"** বা **"ম্যাজিক ম্যাপ"**।

এসো, গল্পের ছলে বুঝে নিই।

---

### **React Router আসলে কী?**
মনে করো, তোমার একটা বিশাল **বাড়ি (Website)** আছে।
- বাড়িটাতে অনেকগুলো **রুম (Page/Component)** আছে (যেমন: ড্রইং রুম, বেডরুম, কিচেন)।
- এখন তুমি যদি এক রুম থেকে আরেক রুমে যেতে চাও, তুমি কি ঘর ভেঙে আবার নতুন করে ঘর বানাবে? না! তুমি জাস্ট দরজা দিয়ে এক রুম থেকে আরেক রুমে যাবে।

সাধারণ ওয়েবসাইটে এক পেজ থেকে অন্য পেজে গেলে পুরো পেজ রিফ্রেশ হয় (যেন ঘর ভেঙে নতুন ঘর বানাচ্ছে)। কিন্তু **React Router** দিয়ে আমরা **"ম্যাজিক"** করি। ঘর ভাঙে না, জাস্ট চোখের পলকে তুমি এক রুম থেকে অন্য রুমে (পেজে) চলে যাও।

---

### **১. BrowserRouter – বাড়ির মেইন বাউন্ডারি**
এটা হলো তোমার বাড়ির **মেইন বাউন্ডারি ওয়াল**। বাউন্ডারির ভেতরে যা থাকবে, সেখানেই শুধু ম্যাজিক কাজ করবে। এর বাইরে ম্যাজিক কাজ করে না। তাই পুরো অ্যাপটাকে এই বাউন্ডারি দিয়ে ঘিরে দিতে হয়।

### **২. Routes এবং Route – দিকনির্দেশনা বোর্ড**
- **Routes:** এটা হলো বাড়ির করিডোরে থাকা একটা **বড় নোটিশ বোর্ড**। এখানে সব রুমের ঠিকানা লেখা থাকে।
- **Route:** এটা হলো একেকটা **রুমের ঠিকানা**।
    - *উদাহরণ:* কেউ যদি বলে "আমি কিচেনে যাব", নোটিশ বোর্ড (Routes) চেক করে দেখবে `/kitchen` লেখা আছে কিনা। থাকলে তাকে কিচেন কম্পোনেন্টে পাঠিয়ে দিবে।

### **৩. Link – টেলিপোর্ট মেশিন (দরজা)**
সাধারণত আমরা `<a>` ট্যাগ ব্যবহার করি, যেটা অনেকটা রিকশার মতো—থেমে থেমে চলে (পেজ রিলোড হয়)।
আর **Link** হলো **টেলিপোর্ট মেশিন**। বোতাম টিপবে, আর ভোঁ করে অন্য পেজে চলে যাবে—পেজ রিফ্রেশ হবে না!

### **খেলার ছলে কোড (Example 1: Basic Routing)**
চলো একটা ছোট কোড দেখি। এখানে আমাদের ৩টা রুম: `Home`, `About`, আর `Contact`।

```jsx
import { BrowserRouter, Routes, Route, Link } from "react-router-dom";

// ১. রুমগুলো (Components) বানালাম
function Home() { return <h1>🏠 এটা আমাদের বাড়ি</h1>; }
function About() { return <h1>🤔 আমি কে?</h1>; }
function Contact() { return <h1>📞 হ্যালো হ্যালো!</h1>; }

function App() {
  return (
    // ২. মেইন বাউন্ডারি (Router)
    <BrowserRouter>
      
      {/* ৩. নভিগেশন মেনু (টেলিপোর্ট বাটন) */}
      <nav>
        <Link to="/">Home</Link> | 
        <Link to="/about">About</Link> | 
        <Link to="/contact">Contact</Link>
      </nav>

      {/* ৪. নোটিশ বোর্ড এবং রুমের ঠিকানা */}
      <Routes>
        <Route path="/" element={<Home />} />        {/* মেইন রুম */}
        <Route path="/about" element={<About />} />  {/* বিস্তারিত রুম */}
        <Route path="/contact" element={<Contact />} /> {/* ফোন করার রুম */}
      </Routes>

    </BrowserRouter>
  );
}

export default App;
```

### **৪. Dynamic Route & useParams – ফেইসবুক প্রোফাইল**
মনে করো ফেইসবুকে কোটি কোটি মানুষ। সবার জন্য কি আলাদা আলাদা পেজ বানানো সম্ভব? না!
ফেইসবুক একটা **"ডাইস"** বা **"ছাঁচ"** ব্যবহার করে। ছাঁচ একটাই, কিন্তু মানুষ (Data) আলাদা।

এটাকে বলে **Dynamic Route**।
ঠিকানা দেখতে এমন হয়: `/user/:id`।
এখানে `:id` হলো একটা খালি জায়গা, যেখানে `rahim`, `karim`, বা `101` বসতে পারে।

**useParams** হলো সেই জাদুকরী হাত, যেটা ইউআরএল থেকে ওই নাম বা আইডিটা ধরে আনে।

### **কোড উদাহরণ (Example 2: Dynamic Routing)**
চলো দেখি ইউজার আইডি দিয়ে কীভাবে পেজ চেনা যায়।

```jsx
import { BrowserRouter, Routes, Route, Link, useParams } from "react-router-dom";

// ইউজার প্রোফাইল রুম (ছাঁচ)
function UserProfile() {
  // useParams দিয়ে ইউআরএল থেকে নামটা বের করে আনলাম
  let { name } = useParams(); 
  return <h1>হ্যালো, {name}! এটা তোমার প্রোফাইল। 😎</h1>;
}

function App() {
  return (
    <BrowserRouter>
      <nav>
        {/* লিংকে আমরা নাম পাঠিয়ে দিচ্ছি */}
        <Link to="/user/Rahim">Rahim এর প্রোফাইল</Link> <br />
        <Link to="/user/Karim">Karim এর প্রোফাইল</Link>
      </nav>

      <Routes>
        {/* :name মানে এখানে যা খুশি বসতে পারে */}
        <Route path="/user/:name" element={<UserProfile />} />
      </Routes>
    </BrowserRouter>
  );
}
export default App;
```
*এখন তুমি `Rahim` এ ক্লিক করলে পেজে দেখাবে "হ্যালো, Rahim!"*

### **৫. useNavigate – অটোমেটিক ড্রাইভার**
মনে করো, তুমি গেম খেলছ। গেম ওভার হওয়ার পর কি তুমি বোতাম টিপে মেইন মেনুতে যাও, নাকি গেম একাই তোমাকে পাঠিয়ে দেয়? একাই দেয়, তাই না?

**useNavigate** হলো সেই **ড্রাইভার**। যখন কোনো কাজ শেষ হওয়ার পর (যেমন: লগইন করা) অটোমেটিক অন্য পেজে ইউজারকে পাঠাতে চাও, তখন এটা লাগে।

```javascript
import { useNavigate } from "react-router-dom";

function Login() {
  const navigate = useNavigate(); // ড্রাইভার ভাড়া করলাম

  function handleLogin() {
    // লগইন সফল হলে...
    alert("লগইন সাকসেস!");
    navigate("/dashboard"); // ড্রাইভারকে বললাম, "ড্যাশবোর্ডে চলো!"
  }

  return <button onClick={handleLogin}>লগইন করুন</button>;
}
```

### **৬. Nested Route – রুমের ভেতর রুম**
এটা হলো আলমারির ড্রয়ারের মতো। তুমি বেডরুমে (Parent Route) ঢুকলে, তার ভেতরে আবার ছোট ছোট ড্রয়ার (Child Route) আছে। মেইন পেজ ঠিক থাকে, শুধু পেজের একটা ছোট অংশ বদলে যায়।

### **⚠️ Common Mistakes (ভুল যেগুলো আমরা করি)**

১. **Router এর বাইরে Link ব্যবহার করা:**
   তুমি বাউন্ডারির বাইরে গিয়ে টেলিপোর্ট মেশিন চালালে কাজ হবে না। `<Link>` অবশ্যই `<BrowserRouter>` এর পেটের ভেতরে থাকতে হবে।

২. **`<a href="">` ব্যবহার করা:**
   রিয়্যাক্টে ভুল করেও `<a>` ট্যাগ ব্যবহার করবে না। এটা করলে পেজ রিফ্রেশ হয়ে যায়, আর রিয়্যাক্টের সব স্পিড নষ্ট হয়ে যায়। সবসময় `<Link to="">` ব্যবহার করবে।

৩. **Route এর path এ `/` না দেওয়া:**
   ঠিকানা লিখতে ভুল করলে গুগল ম্যাপ যেমন হারিয়ে যায়, এখানেও তাই। সঠিক বানান আর স্ল্যাশ `/` দিতে ভুলো না।

### **🚀 React Router Cheat-Sheet (কুইক গাইড)**

| নাম | কাজ (সহজ ভাষায়) | উদাহরণ |
| :--- | :--- | :--- |
| **BrowserRouter** | মেইন বাউন্ডারি / ম্যাপ | পুরো অ্যাপ মুড়িয়ে দিতে হয় |
| **Routes** | সব ঠিকানার তালিকা | `<Routes>...</Routes>` |
| **Route** | নির্দিষ্ট একটি ঠিকানা | `<Route path="/home" element={<Home/>} />` |
| **Link** | ম্যাজিক বাটন (নো রিলোড) | `<Link to="/about">About</Link>` |
| **:id** (Dynamic) | খালি জায়গা / ভেরিয়েবল | `path="/user/:id"` |
| **useParams** | ইউআরএল থেকে ডাটা ধরা | `const { id } = useParams()` |
| **useNavigate** | অটোমেটিক নিয়ে যাওয়া | `navigate("/home")` |
| **Outlet** | ছোট রুম দেখানোর জায়গা | নেস্টেড রাউটে ব্যবহার হয় |

আশা করি বন্ধু, এখন তুমি রিয়্যাক্ট রাউটিং নিয়ে আর ভয় পাবে না! এখন তুমি নিজেই তোমার ওয়েবসাইটের ট্রাফিক পুলিশ! 🚦🚓
