আজকে আমরা কথা বলব **TanStack Query** (যাকে আমরা আদর করে **React Query** ডাকি) নিয়ে।

বসো মামা, আগে বুঝাই এটা কেন লাগে।
মনে করো, তুমি `useEffect` আর `useState` দিয়ে ডাটা ফেচ করো। প্রথমে `loading` ট্রু করো, তারপর `fetch` করো, ডাটা আসলে `state` এ রাখো, এরর আসলে `catch` করো, আবার লোডিং ফলস করো... উফ! কি একটা অবস্থা! 😫

**TanStack Query** হলো তোমার সেই স্মার্ট **ম্যানেজার**, যে বলে—"বস, আপনি চিল করেন। ডাটা আনা, ক্যাশ করা, লোডিং দেখানো, এরর হ্যান্ডেল করা—সব আমি দেখব।"

চলো, চায়ের দোকানের উদাহরণ দিয়ে পুরো ব্যাপারটা পানির মতো বুঝে ফেলি! ☕

### **১. সেটআপ: হেড অফিস (QueryClientProvider)**
ম্যানেজার (React Query) রাখার আগে তাকে বসার জায়গা দিতে হবে তো! পুরো অ্যাপকে একটা `QueryClientProvider` দিয়ে মুড়িয়ে দিতে হবে। এটা হলো "হেড অফিস"।

```jsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';

// ১. ম্যানেজার নিয়োগ দিলাম
const queryClient = new QueryClient();

function App() {
  return (
    // ২. হেড অফিস বসালাম
    <QueryClientProvider client={queryClient}>
      <MyComponent />
    </QueryClientProvider>
  );
}
```

### **২. `useQuery` – ওয়েটার মামাকে অর্ডার দেওয়া**
*ডাটা আনা বা Fetch করা।*

মনে করো, তুমি রেস্টুরেন্টে গিয়ে বিরিয়ানির অর্ডার দিলে।
- যতক্ষণ খাবার আসছে না, তুমি ওয়েট করছ (**Loading**).
- খাবার চলে আসলে, তুমি খুশি (**Data**).
- আর যদি বলে "ভাই বিরিয়ানি শেষ", তখন মেজাজ খারাপ (**Error**).

`useQuery` হুক এই পুরো প্রসেসটা একাই হ্যান্ডেল করে।

```jsx
import { useQuery } from '@tanstack/react-query';
import axios from 'axios';

function BiryaniCounter() {
  // useQuery(চিনিবো কীভাবে, ডাটা আনবো কোত্থেকে)
  const { data, isLoading, isError, error } = useQuery({
    queryKey: ['biryani'], // ১. খাবারের নাম (Label)
    queryFn: () => axios.get('/api/biryani').then(res => res.data), // ২. কিচেনে অর্ডার দেওয়া
  });

  if (isLoading) return <h3>মামা, বিরিয়ানি রান্না হচ্ছে... ⏳</h3>;
  if (isError) return <h3>ধুর! {error.message} 😡</h3>;

  return (
    <div>
      <h1>আজকের মেনু: {data.name}</h1>
      <p>দাম: {data.price} টাকা</p>
    </div>
  );
}
```
**ম্যাজিক:** তোমার আর `useState` বা `useEffect` দিয়ে লোডিং হ্যান্ডেল করা লাগল না!

### **৩. Caching & Stale Time – ফ্রিজের খাবার**
*সবচেয়ে গুরুত্বপূর্ণ এবং মজার কনসেপ্ট।*

**Caching (ফ্রিজে রাখা):**
তুমি একবার বিরিয়ানি আনলে। ১০ মিনিট পর তোমার বন্ধু এসে বলল, "বিরিয়ানি আছে?" তুমি কি আবার রেস্টুরেন্টে দৌড় দিবে? না! তুমি ফ্রিজ (Cache) চেক করবে। যদি থাকে, সাথে সাথে দিয়ে দিবে। React Query ডাটা ক্যাশ করে রাখে, তাই অ্যাপ রকেটের মতো ফাস্ট হয়।

**Stale Time (খাবার কতক্ষণ ফ্রেশ?):**
ফ্রিজের খাবার কি ১ বছর ফ্রেশ থাকে? না। একটা নির্দিষ্ট সময় পর সেটা বাসি (Stale) হয়ে যায়।
- **staleTime: 5000 (5 সেকেন্ড):** ডাটা আনার ৫ সেকেন্ড পর্যন্ত ফ্রেশ। এর মধ্যে কেউ চাইলে ফ্রিজ থেকেই দিব। ৫ সেকেন্ড পার হলে? ব্যাকগ্রাউন্ডে চুপিসারে আবার রেস্টুরেন্ট থেকে নতুন ডাটা আনব (Refetch)।

```jsx
const { data } = useQuery({
  queryKey: ['users'],
  queryFn: fetchUsers,
  staleTime: 1000 * 60, // ১ মিনিট পর্যন্ত ডাটা ফ্রেশ (ফ্রিজ থেকে খাবে)
});
```

### **৪. Query Key – টিফিন বক্সের নাম**
ফ্রিজে অনেক খাবার থাকে। কোনটা বিরিয়ানি আর কোনটা ডাল বুঝবে কীভাবে? টিফিন বক্সের গায়ে নাম লিখে রাখতে হয়। এটাই **Query Key**।

- সব ইউজার: `['users']`
- নির্দিষ্ট ইউজার (আইডি ১): `['users', 1]`
- নির্দিষ্ট ইউজার (আইডি ২): `['users', 2]`

যদি কি (Key) আলাদা হয়, React Query বুঝবে এগুলো আলাদা খাবার, তাই আলাদাভাবে ক্যাশ করবে।

```jsx
// ডাইনামিক কুয়েরি কি
const { data } = useQuery({
  queryKey: ['user', userId], // userId চেঞ্জ হলে নতুন করে ফেচ হবে
  queryFn: () => fetchUser(userId),
});
```

### **৫. Background Refetching – ওয়েটারের নজরদারি**
তুমি খাচ্ছ, গ্লাসের পানি একটু কমেছে। তুমি খেয়ালও করোনি, ওয়েটার এসে চুপিসারে পানি ঢেলে দিয়ে গেল।
React Query-ও তাই করে।
- তুমি যখন অন্য ট্যাবে গিয়ে আবার ফিরে আসো (**Window Focus**), সে অটোমেটিক চেক করে ডাটা নতুন আছে কিনা। যদি সার্ভারে ডাটা চেঞ্জ হয়, সে চুপিসারে আপডেট করে দেয়। ইউজার লোডিং স্পিনারও দেখে না, কিন্তু ডাটা ফ্রেশ পায়! ম্যাজিক! ✨

### **৬. `useMutation` – সার্ভারে ডাটা পাঠানো (Action)**
*ডাটা আনা নয়, ডাটা পরিবর্তন করা।*

এতক্ষণ আমরা শুধু খাবার আনছিলাম (GET)। এখন যদি আমরা নতুন অর্ডার প্লেস করি বা ফেসবুকে স্ট্যাটাস দিই (POST, PUT, DELETE)?
তখন লাগে **`useMutation`**।

```jsx
import { useMutation, useQueryClient } from '@tanstack/react-query';

function AddTodo() {
  const queryClient = useQueryClient(); // হেড অফিস এক্সেস করা

  const mutation = useMutation({
    mutationFn: (newTodo) => axios.post('/todos', newTodo),
    
    // সফল হলে যা করবে
    onSuccess: () => {
      // ক্যাশ আপডেট করো! মানে ওয়েটারকে বলো মেনু লিস্ট আবার রিফ্রেশ করতে
      queryClient.invalidateQueries({ queryKey: ['todos'] });
      alert("কাজ যোগ করা হয়েছে বস! ✅");
    },
  });

  return (
    <button onClick={() => mutation.mutate({ title: "React শিখব" })}>
      {mutation.isPending ? "যোগ হচ্ছে..." : "Todo যোগ করো"}
    </button>
  );
}
```
**পার্থক্য:** `useQuery` অটোমেটিক চলে, আর `useMutation` চলে যখন তুমি `.mutate()` কল করো (যেমন বাটনে চাপ দিলে)।

### **কেন React Query ব্যবহার করব? (জীবন সহজ)**
1.  **লোডশেডিং নাই:** লোডিং স্টেট ম্যানুয়ালি হ্যান্ডেল করতে হয় না।
2.  **ক্যাশ মেমোরি:** একবার ডাটা আনলে সেটা সেভ থাকে, বারবার সার্ভারে রিকোয়েস্ট যায় না।
3.  **অটো রিফ্রেশ:** ব্যাকগ্রাউন্ডে ডাটা আপডেট হয়।
4.  **রিট্রাই (Retry):** নেটওয়ার্ক ফেইল করলে সে নিজে নিজে ৩ বার চেষ্টা করে (নাছোড়বান্দা)।

### **⚠️ Common Mistakes & Best Practices (মামা, এগুলো করবেন না)**

❌ **ভুল:** `useEffect` এর ভেতরে `useQuery` কল করা।
✅ **সঠিক:** `useQuery` নিজেই একটা হুক, এটা টপ লেভেলে কল করুন।

❌ **ভুল:** Query Key তে ইউনিক ভ্যালু না দেওয়া। (সবার টিফিন বক্সে এক নাম দিলে খাবার মিক্স হয়ে যাবে!)
✅ **সঠিক:** প্যারামিটারসহ কি দিন। যেমন: `['product', id]`

❌ **ভুল:** ডাটা লোড হওয়ার আগেই ডাটা দেখানোর চেষ্টা করা।
✅ **সঠিক:** সবসময় `if (isLoading)` চেক করবেন অথবা Optional Chaining `data?.name` ব্যবহার করবেন।

### **🚀 React Query Cheat-Sheet (কুইক গাইড)**

| নাম | কাজ (সহজ ভাষায়) | উদাহরণ |
| :--- | :--- | :--- |
| **QueryClientProvider** | হেড অফিস (সবার বাপ) | অ্যাপ র‍্যাপ করতে হয় |
| **useQuery** | ডাটা আনা (Get Data) | `const { data } = useQuery(...)` |
| **queryKey** | খাবারের লেবেল | `['todos', 1]` |
| **staleTime** | খাবার কতক্ষণ ফ্রেশ | `staleTime: 5000` |
| **isLoading** | খাবার রান্না হচ্ছে... | লোডিং স্পিনার দেখান |
| **useMutation** | ডাটা পাঠানো/বদলে দেওয়া | `mutation.mutate(newData)` |
| **invalidateQueries** | মেনু রিফ্রেশ করা | মিউটেশনের পর নতুন ডাটা আনতে |

মামা, TanStack Query হলো রিয়্যাক্ট ডেভেলপারদের জন্য **সুপারপাওয়ার**। এটা একবার ব্যবহার করলে আর সাধারণ `useEffect` এর দিকে ফিরেও তাকাবে না! হ্যাপি কোডিং! 😎🔥
