
# Sniper Scalp — SMC / ICT Strategy

  

A TradingView **Pine v6 strategy** (backtestable, not a signal-only indicator) built on Smart Money Concepts (SMC) and ICT methodology for intraday Forex scalping.

  

> **Core flow:** a market-structure break (BOS/CHoCH) **arms** a direction → price retraces into a PD-array zone (FVG / Order Block / Breaker / IFVG) inside the Fibonacci Golden/OTE band → an engulfing or liquidity-sweep trigger fires the entry while the arm window is open.

## Install

  

1. Open TradingView → **Pine Editor**.

2. Paste the contents of [`sniper_scalp.pine`](sniper_scalp.pine).

3. **Add to chart** (it loads as a strategy — orders + backtest tab appear).

4. Open the **Strategy Tester** panel to see the equity curve and stats.

5. **Critical for scalp backtests:** Strategy Properties → Recalculate → enable **Bar Magnifier** (TV Premium). Without it, a scalp bar that touches both SL and TP is resolved by TV's default assumption — the raw curve is unreliable.

## Quick start

  

Minimum to get going:

  

1. Set chart to your **entry timeframe** (5M recommended; see warnings on 1M).

2. **Scalp Preset** → pick `5M` (auto-tunes swing/EMA/RSI lengths).

3. Set **Spread + slippage cost (pips)** to your broker's typical spread for the pair/session.

4. Leave defaults otherwise — they are a tuned "sniper" config.

5. Read the [Validation workflow](#validation-workflow-read-before-going-live) before risking money.

## The trade logic, step by step

  

```

1. STRUCTURE BREAK   → close breaks last confirmed swing WITH displacement (range ≥ ATR×mult)

                       → arms LONG or SHORT for `structWindow` bars

2. RETRACE           → price pulls back into a PD-array zone (FVG/OB/Breaker/IFVG)

                       inside the Golden (50–78.6%) / OTE (62–79%) band

3. TRIGGER           → engulfing candle OR liquidity-sweep/fakeout

                       (with trigger displacement); OR a passive limit at OTE fills

4. GATES             → HTF bias agrees · external structure agrees · ADX > min ·

                       in session/killzone · not in news window · confluence ≥ minScore

5. ENTRY             → limit at OTE (default) or market-on-close; SL + TP attached instantly

6. MANAGE            → break-even at +R · partial TP1/TP2 · ATR trail · time-stop

```

  

A direction stays **armed** (green/red background tint) until the trigger fires, the window expires, or an opposite break cancels it. The **NEXT** label projects where the armed setup will fire.

## Scalp presets

  

One switch retunes lengths so structure confirms in step with the timeframe (the 20/50/200 + swing-5 defaults are H1-grade and too slow for fast TFs).

  

| Preset | Swing | EMA stack | RSI |

|---|---|---|---|

| 1M | 3 | 9 / 21 / 50 | 7 |

| 3M | 4 | 13 / 34 / 89 | 9 |

| 5M | 5 | 20 / 50 / 200 | 14 |

| Off (manual) | uses your raw inputs | | |

  

When a preset is active it **overrides** the Market-Structure / EMA / RSI length inputs.

## Confluence scoring

  

Each setup earns a score from independent buckets. Entry requires `score ≥ minScore` (default **5**) **on top of** the hard gates (armed + zone + fib + trigger).

  

| # | Bucket | Points |

|---|---|---|

| 1 | Structure armed | 1 |

| 2 | PD-array zone tapped (quality-graded) | 1, or **2** if multiple arrays stack (FVG+OB, breaker/IFVG/BPR) |

| 3 | Discount/Premium location + RSI agreement | 1 |

| 4 | Real trigger (engulf / fakeout) | 1 |

| 5 | **Orderflow ×2** (sweep / SMT / RSI-div / hidden-div / inducement / Judas) | 2 |

| 6 | HTF bias — scored **only** when HTF is not already a hard gate (no double-count) | 1 |

| 7 | Trend confluence (EMA / TL-break / VWAP) | 1 |

| 8 | MSS (CHoCH breaking a classified protected swing) | 1 |

  

**Max = 9** when "Require HTF trend agreement" is ON (HTF is a gate, not scored), else **10**.

  

> Lower `minScore` for more trades, raise for stricter sniping. After the recent trigger-bucket honesty fix, passive-limit setups score ~1 lower than before — if trades starve, drop `minScore` 5→4.

## Risk management

  

- **Stop loss:** structural (swing wick + buffer + spread), then **bounded** to `minSLatr`–`maxSLatr` × ATR. Blocks both micro-stops (absurd leverage) and far-stops (micro size / distorted curve).

- **Take profit:** fixed R:R (default 1:3), or fib-extension, or nearest **draw-on-liquidity** pool — whichever enabled — **capped** at `maxTPr` R so a far pool can't project a fantasy target.

- **Position size:** `risk % of equity ÷ stop distance`, capped so notional ≤ `equity × maxLev`. Sized on the **actual limit-fill price** so real risk matches `riskPerc`.

- **Spread cost:** modeled into SL/TP geometry and sizing. Asia session widens it (`spreadAsiaMult`). **Single cost model by default** — commission is `0`; if you trade a true ECN/commission account set commission AND lower `spreadPips` to raw so they don't double-count.

- **Management:** break-even at +R, optional ATR trail, partial TP1 (50% @1R default) + optional TP2, BE-after-partial, time-stop after N bars.

- **Guards:** daily-loss stop, max trades/day, and a **total/trailing drawdown lock** that flattens and halts once drawdown from peak equity exceeds the limit (set to your prop firm's max-DD minus a buffer).

## Dashboards

  

**SMC Master Pro** (top-right): current + 3 HTF trends, MTF bias, session, kill-zone status, PD zone, confluence score (▲long ▼short), position, signal state, guards/equity.

  

**Performance** (bottom-left): round-trip trade count, win rate, profit factor, max drawdown, net profit, max consecutive losses, expectancy/trade, Sharpe and Sortino (per-trade R).

  

> Stats use **round-trip** accumulators (one count per real position), so partial closes do **not** inflate win% / PF. Sharpe/Sortino are scale-free per-trade-R, **not annualized** — don't compare directly to industry Sharpe.

## Alerts & automation

  

Two alert conditions fire on the signal bar:

- **Sniper LONG** — "SMC long setup — entry, SL & TP set"

- **Sniper SHORT** — "SMC short setup — entry, SL & TP set"

  

Create alert → Condition = the strategy → pick LONG/SHORT. Alerts fire on `goLong`/`goShort` (signal), while the **BUY/SELL chart marks show actual fills** — in limit mode a signal may cancel unfilled. For full automation, gate orders on actual fills downstream and add your own news-calendar blackout (Pine has none).

## Validation workflow (READ before going live)

  

This strategy has many interacting inputs — a large overfitting surface. Do **not** trust an in-sample curve.

  

1. **Measure sample.** Turn ON **Validation Mode** (loosens contextual gates, keeps core SMC logic). Confirm the engine produces **≥ 100 trades** on your instrument. If starved, the live gates are over-filtering.

2. **Fix the obvious.** Set realistic spread, pick the right preset, single cost model.

3. **Walk-forward.** Enable the **in/out-of-sample marker**. Tune inputs **only** on data left of the line. Lock inputs. Verify the curve still profits **right of** the line. A strategy that only works in-sample is overfit — reject it.

4. **Reduce knobs.** Disable experimental layers you don't forward-test (Fast-break, Power-of-3, SMT). Fewer inputs = less overfit.

5. **Paper-forward ≥ 3 months** on the target pairs/sessions before real capital.

6. **Bar Magnifier ON** for every scalp backtest.

## Known limits & warnings

  

- **Pivot-confirmation lag.** Swing pivots confirm `swingLen` bars late, so BOS/CHoCH arming arrives delayed. On 1M this is severe — the author recommends **5M+**. `useFastBreak` adds an earlier arm but trades more; forward-test first.

- **No live news calendar.** Pine can't read economic events. Only manual blackout windows exist. News is the largest single drawdown source in FX scalping — add external gating.

- **Intrabar SL+TP ambiguity.** A scalp bar engulfing both stop and target is unsolvable in code — **enable Bar Magnifier**.

- **Overfitting.** ~80 inputs. Follow the validation workflow. The visual OOS marker helps but there is no automated walk-forward.

- **Limit-fill optimism.** Backtest assumes the OTE limit fills on a wick touch (half-spread pessimized, but queue position / partial fills / rejection are not modeled). Real fills can be worse.

- **Sharpe/Sortino** shown are per-trade-R, not annualized.

## Glossary

  

| Term | Meaning |

|---|---|

| BOS | Break of Structure — continuation break of the last swing |

| CHoCH | Change of Character — break that flips the trend bias |

| MSS | Market Structure Shift — CHoCH breaking a classified protected swing |

| FVG | Fair Value Gap — 3-candle imbalance |

| IFVG | Inverse FVG — a fully-violated FVG that flips polarity |

| OB | Order Block — last opposite candle before an impulsive break |

| Breaker | A violated OB that flips to the opposite side |

| BPR | Balanced Price Range — overlapping bull + bear FVG |

| OTE | Optimal Trade Entry — 62–79% retracement sweet spot |

| Premium / Discount | Upper / lower half of the dealing range (sell / buy) |

| EQ | Equilibrium — 50% of the dealing range |

| BSL / SSL | Buy-side / Sell-side liquidity (above highs / below lows) |

| Liquidity sweep | Wick takes a level then closes back (stop hunt) |

| Inducement | A minor sweep grabbing liquidity before the real move |

| Judas swing | Killzone raid of the Asia-range extreme (Power-of-3 manipulation) |

| SMT | Smart Money Technique — divergence vs a correlated symbol |

| Kill Zone | High-probability ICT session window (NY time) |

| PDH / PDL | Prior Day High / Low |

| Displacement | An impulsive, institutional-size candle (range ≥ ATR × mult) |

| R / R:R | Risk unit (initial stop distance) / reward-to-risk ratio |
