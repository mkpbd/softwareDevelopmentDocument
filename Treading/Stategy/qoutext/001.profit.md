# Quotex UP/DOWN Sniper PRO v2.0 — User Guide

A multi-confluence Pine Script v5 indicator for TradingView. Generates UP/DOWN signals based on a weighted 100-point scoring system across 7 indicator groups, with a configurable dashboard and simulated performance tracker.

> ⚠️ **Risk disclosure.** Binary options and short-expiry directional trading carry very high risk of total loss and are restricted in many jurisdictions. This indicator is a decision-support tool, not a guarantee. The "win rate" stat in the dashboard is an on-chart simulation using ATR-based SL/TP — not a real backtest. Treat all signals as probabilistic.

---

## 1. Installation

1. Open TradingView → any chart → bottom panel → **Pine Editor**.
2. Press `Ctrl+A` / `Cmd+A` and delete any existing code.
3. Paste the contents of `quotex_sniper_pro_v2.pine`.
4. Click **Save** (give it a name) → **Add to chart**.
5. The indicator appears as EMAs + a dashboard in the top-right corner.

If you see error **CE10243** ("Scripts must contain one declaration statement"), you have two `indicator()` lines — clear the editor fully and paste again.

---

## 2. Quick Start

Default settings are tuned for **5–15 minute charts on liquid forex pairs / major indices**. To get going:

1. Add to chart with defaults.
2. Watch the dashboard's **SIGNAL** row — it shows current bias and strength %.
3. A signal fires (label + background highlight) only when:
   - Strength score ≥ threshold (default 60%)
   - Cooldown elapsed (default 5 bars)
   - Bar is confirmed/closed (no-repaint mode)
4. Right-click any signal label → **Add alert on…** to get notified.

---

## 3. How the Signal Engine Works

Each bar, the indicator computes two independent scores: `scoreUp` and `scoreDn`. Each indicator group contributes points to one side based on its current state. When a filter is disabled, it contributes half its weight to *both* sides (neutral).

### Scoring breakdown (max 100 pts)

| Component | Points | UP awarded when… | DOWN awarded when… |
|---|---|---|---|
| EMA stack | 25 | `fast > mid > slow` | `fast < mid < slow` |
| HTF trend | 15 | Close above HTF EMA | Close below HTF EMA |
| RSI | 10 | RSI in 50–OB zone | RSI in OS–50 zone |
| Stoch RSI | 10 | %K crossing up below 80 | %K crossing down above 20 |
| MACD | 15 | Line > signal AND histogram rising | Line < signal AND histogram falling |
| ADX | 10 | ADX > threshold (trending) | ADX > threshold (trending) |
| Volume | 10 | Volume > MA × multiplier | Volume > MA × multiplier |
| Candle pattern | 5 | Bullish engulfing / pin bar | Bearish engulfing / pin bar |

### Signal fires when

```
scoreUp  (or scoreDn) >= effectiveThreshold
AND   patternOK  AND  timeOK  AND  newsOK
AND   bars_since_last_signal >= cooldownBars
AND   (if noRepaint) barstate.isconfirmed
AND   scoreUp != scoreDn  (winner takes it)
```

`effectiveThreshold = minStrength + modeAdjust`, where mode adjusts by **−10 / 0 / +10**.

### 🎯 General
| Setting | Default | Purpose |
|---|---|---|
| Signal Mode | Balanced | Aggressive lowers threshold by 10, Conservative raises it by 10 |
| Min Signal Strength % | 60 | Base threshold for firing |
| Signal Cooldown | 5 bars | Prevents clustered repeat entries |
| No-Repaint | ON | Waits for bar close before confirming — recommended |
| Color Theme | Dark | Dark / Light / Neon |

### 📈 EMA Trend
Triple-EMA stack (default 9/21/50). Trend is confirmed only when all three are aligned. The ribbon between Fast and Mid is shaded green/red.

### 🔭 HTF Filter
Pulls an EMA from a higher timeframe and filters signals to that direction. Default `15` minutes — change to align with your trading timeframe (rule of thumb: HTF ≈ 4–5× your chart TF).

### 📊 RSI / Stoch RSI
Classic RSI plus Stochastic-of-RSI for faster momentum reads. Stoch RSI tends to fire earlier than plain RSI but can be noisier.

### 📉 MACD
Standard 12/26/9. Bullish requires *both* line > signal *and* histogram rising (not just one).

### 💪 ADX
Filters out chop. Default threshold `20` — raise to 25–30 for stricter trend-only signals.

### 📦 Volume
Requires current volume above its MA × multiplier. Note: on forex spot charts, volume is *tick volume*, not real volume.

### 🕯️ Candle Patterns
Engulfing and pin-bar detection. **Avoid Doji** skips signals on indecision candles.

### 🧱 Support / Resistance
Draws pivot-based S/R lines on the most recent pivots. Visual aid only — does not feed the score.

### 🛡️ ATR Stop Loss & Take Profit
SL distance = `ATR × multiplier`. TP distance = SL × R:R ratio. Drawn as circle plots on signal bars. Use for spot/futures; ignore if you're trading fixed-expiry binaries.

### ⏰ Time Filter
Restrict signals to specific hours (chart timezone). **Avoid First 5 Min** skips news-driven open candles.

### 🎨 Display
Toggle labels, background highlight, dashboard, stats panel, and dashboard position.

## 7. Alerts Setup

Two ways to wire alerts:

**A. Built-in alert conditions** (preferred for granularity)

Right-click chart → **Add Alert** → **Condition** dropdown → pick:
- `🟢 UP Signal`
- `🔴 DOWN Signal`
- `📈 EMA Bull Cross`
- `📉 EMA Bear Cross`

The UP/DOWN conditions ship JSON payloads (`{"signal":"UP","symbol":"…","price":"…"}`) suitable for webhook routing to bots / Telegram / Discord.

**B. Dynamic `alert()` calls**

The script also fires inline alerts with strength % and indicator values whenever a signal triggers. To receive these, create **one** alert with condition set to the indicator itself and the alert action you want — TradingView delivers every `alert()` call from the script.

## 8. Limitations & Caveats

- **Tick volume on forex**: the volume filter uses tick count, not traded volume. It's directional but not a true liquidity measure.
- **HTF lookahead**: HTF EMA is fetched with `lookahead_off` to prevent peeking. Backtest results on lower timeframes are honest, but live HTF values lag until the HTF bar closes.
- **Simulated win rate ≠ backtest**: The stats panel tracks signals against ATR SL/TP using bar highs/lows. It doesn't model spread, slippage, or whichever expiry your platform uses. For real performance numbers, convert to a `strategy()` script and use TradingView's Strategy Tester.
- **Pattern detection is strict**: Engulfing/pin-bar definitions are conservative. You'll often see signals where the pattern bonus (5 pts) didn't contribute — the other 95 points still get you there.
- **Repaint**: with **No-Repaint = OFF**, signals can appear and vanish intra-bar. Always trade off the close, or leave No-Repaint **ON**.

## 9. Troubleshooting

**No signals appearing**
- Lower `Min Signal Strength %` by 5–10.
- Switch mode to **Aggressive**.
- Confirm HTF resolution isn't blocking everything (try disabling HTF filter temporarily).
- Check ADX value in dashboard — if always below threshold, market is choppy; lower ADX threshold or disable.

**Too many signals**
- Raise threshold to 70+ or switch to **Conservative**.
- Increase cooldown to 8–10 bars.
- Enable the time filter to restrict to your active session.

**Signals contradict the trend**
- Make sure HTF filter is enabled and HTF resolution is meaningful (≥ 4× chart TF).

**Dashboard not visible**
- Confirm **Show Dashboard** is on.
- Change **Dashboard Position** — it may be hidden behind another indicator.

**Error CE10243 on save**
- Editor has duplicate `indicator()` declarations. Clear all (`Ctrl+A` → Delete) and re-paste.

## 10. Extending the Script

Easy modifications:

- **Add Bollinger Bands to the score**: BB calculation is already in the script (unused). Add a `useBB ? bbInRange ? 5 : 0 : 2.5` block alongside the other score components and reduce another weight by 5.
- **Convert to a strategy()**: change line 2 from `indicator(...)` to `strategy(...)` and replace label calls with `strategy.entry()` / `strategy.exit()` using the existing `longSL/longTP/shortSL/shortTP` levels.
- **Add divergence detection**: compare `ta.pivotlow(close, 5, 5)` against `ta.pivotlow(rsi, 5, 5)` for bullish divergence (price LL, RSI HL).
- **Add session highlights**: use `time()` with session strings like `"0800-1700"` to shade London/NY sessions.
