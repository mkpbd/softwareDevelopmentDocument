
আসসালামু আলাইকুম কোডার ভাই-ব্রাদাররা! 👋

কেমন আছেন সবাই? আমি আপনাদের সেই সিনিয়র ভাই। আগের ক্লাসে আমরা **Attribute** (স্টিকার) নিয়ে কথা বলেছিলাম। আজ আমরা এমন একটা পাওয়ারফুল জিনিস শিখবো যেটা দিয়ে আপনি কোডের **হাড়-মাংস, নাড়ি-ভুঁড়ি সব বের করে ফেলতে পারবেন**! 🕵️‍♂️

আজকের টপিক: **Reflection**।

অনেকে নাম শুনেই ভয় পায়, ভাবে—"ওরে বাবা, এটা মনে হয় রকেট সায়েন্স!" আরে ধুর! এটা পানির মতো সোজা। চলেন, চায়ের কাপ হাতে নিয়ে গল্প করতে করতে শিখে ফেলি।

### ১. Reflection আসলে কী? (What is Reflection?)

এক লাইনে সহজ বাংলা সংগা:
> **"Reflection হলো এমন এক টেকনিক, যা দিয়ে কোড রান করার সময় (Runtime) নিজেই নিজের ভেতরের খবর (Properties, Methods, Events) দেখতে পারে এবং ব্যবহার করতে পারে।"**

**Compile-time vs Runtime:**
*   **Compile-time:** আপনি কোড লিখছেন, জানেন `Person` ক্লাসে `Name` আছে। সরাসরি `p.Name` কল করলেন। এটা হলো প্ল্যান করে কাজ করা।
*   **Runtime (Reflection):** কোড রান হয়ে গেছে। ইউজারের কাছ থেকে একটা স্ট্রিং আসলো "Name"। এখন এই স্ট্রিং দিয়ে প্রপার্টি খুঁজে বের করা—এটাই রিফ্লেকশন।

### ২. রিয়েল লাইফ উদাহরণ (Real-life Analogy) 🪞

**উদাহরণ ১: আয়না (Mirror)**
"Reflection" শব্দের অর্থই হলো প্রতিফলন। আপনি আয়নার সামনে দাঁড়ালে যেমন নিজের চোখ, নাক, কান, শার্টের রং সব দেখতে পান—ঠিক তেমনি কোড যখন আয়নার (Reflection API) সামনে দাঁড়ায়, সে তার ভেতরের সব মেথড, ভেরিয়েবল দেখতে পায়।

**উদাহরণ ২: ডাক্তার ও এক্স-রে (X-Ray)**
একজন সার্জন (Developer) বাইরে থেকে মানুষের শরীর (Object) দেখে সব বোঝে না। কিন্তু এক্স-রে (Reflection) করলে হাড়, কিডনি সব দেখা যায়। রিফ্লেকশন হলো কোডের **এক্স-রে মেশিন**।

### ৩. রিফ্লেকশনের হাতিয়ার (Basic Reflection Concepts) 🛠️

রিফ্লেকশন নিয়ে খেলতে হলে আমাদের `System.Reflection` নেমস্পেসের কিছু বস (Boss) ক্লাস চিনতে হবে:

1.  **Assembly:** এটা হলো পুরো প্রজেক্ট বা DLL ফাইল (পুরো প্যাকেট)।
2.  **Type:** এটা হলো ব্লু-প্রিন্ট বা Class-এর তথ্য (সবচেয়ে গুরুত্বপূর্ণ)।
3.  **PropertyInfo:** প্রপার্টির নাড়ি-নক্ষত্র।
4.  **MethodInfo:** মেথডের সব তথ্য।
5.  **FieldInfo:** ফিল্ডের তথ্য।

### ৪. টাইপ ইনফরমেশন বের করা (Getting Type Information) ℹ️

রিফ্লেকশন শুরুই হয় **Type** চেনা দিয়ে। দুইভাবে এটা করা যায়:

```csharp
using System;
using System.Reflection;

public class Robot
{
    public string Model { get; set; }
}

// মেইন প্রোগ্রাম
var myRobot = new Robot();

// ১. যদি ক্লাসের নাম জানা থাকে (Compile time)
Type t1 = typeof(Robot);

// ২. যদি শুধু অবজেক্ট থাকে (Runtime)
Type t2 = myRobot.GetType();

Console.WriteLine($"Class Name: {t1.Name}"); // Output: Robot
```

### ৫. ক্লাসের নাড়ি-ভুঁড়ি বের করা (Reading Class Details) 🧐

চলেন, আমরা একটা `SuperHero` ক্লাসের ওপর গোয়েন্দাগিরি করি। দেখব এর ভেতরে কী কী আছে।

```csharp
using System;
using System.Reflection;

public class SuperHero
{
    public string Name { get; set; }     // Property
    public int PowerLevel { get; set; }  // Property

    public void Fly()                    // Method
    {
        Console.WriteLine("Flying high!");
    }

    public void Fight(string enemy)      // Method with parameter
    {
        Console.WriteLine($"Fighting with {enemy}!");
    }
}

class Program
{
    static void Main()
    {
        Type t = typeof(SuperHero);

        Console.WriteLine($"--- Spying on {t.Name} ---");

        // ১. সব প্রপার্টি বের করা
        Console.WriteLine("\nProperties:");
        foreach (PropertyInfo prop in t.GetProperties())
        {
            Console.WriteLine($"- Name: {prop.Name}, Type: {prop.PropertyType.Name}");
        }

        // ২. সব মেথড বের করা
        Console.WriteLine("\nMethods:");
        foreach (MethodInfo method in t.GetMethods())
        {
            // Object ক্লাসের ডিফল্ট মেথডগুলো বাদ দিয়ে দেখাচ্ছি
            if(method.DeclaringType == t) 
            {
                Console.WriteLine($"- Method: {method.Name}");
            }
        }
    }
}
```

**Output:**
```text
Properties:
- Name: Name, Type: String
- Name: PowerLevel, Type: Int32

Methods:
- Method: Fly
- Method: Fight
// getter setter মেথডগুলোও ব্যাকগ্রাউন্ডে থাকে
```

### ৬. ডায়নামিক অবজেক্ট তৈরি (Creating Object Dynamically) 🏗️

ধরুন, আপনার কাছে ক্লাসের নাম আছে একটা স্ট্রিং হিসেবে `"SuperHero"`। আপনি `new SuperHero()` লিখতে পারছেন না। তখন কী করবেন?

**Magic:** `Activator.CreateInstance`

```csharp
Type t = typeof(SuperHero);

// জাদুর মতো অবজেক্ট তৈরি হলো! (new SuperHero() এর বিকল্প)
object heroObj = Activator.CreateInstance(t);

// টাইপ কাস্টিং করে চেক করি
if (heroObj is SuperHero hero)
{
    hero.Name = "Iron Man";
    Console.WriteLine($"Hero Created: {hero.Name}");
}
```

### ৭. ডায়নামিক মেথড কল (Invoking Methods Dynamically) 📞

সবচেয়ে ইন্টারেস্টিং পার্ট! আপনি মেথডের নাম জানেন স্ট্রিং হিসেবে, সেটাকে রান করবেন।

```csharp
// ১. অবজেক্ট বানাই
object heroInstance = Activator.CreateInstance(typeof(SuperHero));

// ২. মেথড ইনফো খুঁজি (নাম দিয়ে)
MethodInfo flyMethod = typeof(SuperHero).GetMethod("Fly");
MethodInfo fightMethod = typeof(SuperHero).GetMethod("Fight");

// ৩. মেথড কল করি (Invoke)
Console.WriteLine("Invoking Fly...");
flyMethod.Invoke(heroInstance, null); // প্যারামিটার নেই, তাই null

Console.WriteLine("Invoking Fight...");
object[] parameters = new object[] { "Thanos" }; // প্যারামিটার পাঠাচ্ছি
fightMethod.Invoke(heroInstance, parameters);
```

**আউটপুট:**
> Flying high!
> Fighting with Thanos!

### ৮. অ্যাট্রিবিউট রিডিং (Reading Attributes with Reflection) 🏷️

আগের ক্লাসে আমরা স্টিকার (Attribute) লাগিয়েছিলাম। রিফ্লেকশন ছাড়া সেই স্টিকারের কোনো দাম নেই।

```csharp
[Obsolete("This class is old")]
public class OldRobot { }

// রিফ্লেকশন দিয়ে চেক
Type t = typeof(OldRobot);
var attributes = t.GetCustomAttributes(false);

foreach (var attr in attributes)
{
    if (attr is ObsoleteAttribute obs)
    {
        Console.WriteLine($"Warning: {obs.Message}");
    }
}
```

### ৯. রিয়েল ওয়ার্ল্ডে কোথায় লাগে? (Use Cases) 🌍

ভাই, শুধু হ্যাকিং করতে এটা লাগে না, সিরিয়াস কাজেও লাগে:

1.  **Dependency Injection (DI):** .NET Core যখন `AddTransient<IService, Service>()` করে, সে রিফ্লেকশন দিয়ে কনস্ট্রাক্টর খুঁজে বের করে এবং অবজেক্ট বানায়।
2.  **Entity Framework (ORM):** আপনার ক্লাস `User` এর সাথে ডাটাবেস টেবিল `Users` এর ম্যাপিং রিফ্লেকশন দিয়েই হয়।
3.  **Serialization (JSON):** `Newtonsoft.Json` বা `System.Text.Json` আপনার ক্লাসের প্রপার্টিগুলোর নাম পড়ে এবং JSON বানায়।
4.  **Testing Tools:** Unit Test ফ্রেমওয়ার্কগুলো (xUnit, NUnit) রিফ্লেকশন ব্যবহার করে আপনার `[Test]` মেথডগুলো খুঁজে বের করে রান করায়।

### ১০. পারফরম্যান্স ও সতর্কতা (Performance & Warning) ⚠️

**রিফ্লেকশন কি স্লো?**
হ্যাঁ, ভাই। নরমাল কোডের চেয়ে এটা ধীরগতি।
*   **কেন?** কারণ রানটাইমে তাকে স্ট্রিং মিলিয়ে মিলিয়ে মেথড বা প্রপার্টি খুঁজতে হয়। এটা অনেকটা ম্যাপ না দেখে রাস্তা খোঁজার মতো।

**কখন ব্যবহার করবেন না?**
*   প্রতিটা ছোটখাটো লজিকে (যেমন লুপের ভেতর)।
*   যেখানে সরাসরি `new Class()` বা `obj.Method()` কল করা সম্ভব।

**Best Practice:** রিফ্লেকশনের রেজাল্ট **Cache** করে রাখুন। বারবার `GetMethod` কল করবেন না।

### ১১. সাধারণ ভুলসমূহ (Common Mistakes) ❌

1.  **Private মেথড এক্সেস করা:** রিফ্লেকশন দিয়ে প্রাইভেট মেথডও কল করা যায় (BindingFlags দিয়ে)। কিন্তু এটা সিকিউরিটি রিস্ক এবং খারাপ প্র্যাকটিস।
2.  **বানান ভুল:** `GetMethod("Fighht")` লিখলে রানটাইমে ক্র্যাশ করবে (Null Reference Exception), কারণ মেথড খুঁজে পাবে না।
3.  **অপ্রয়োজনীয় ব্যবহার:** সোজা কাজ জটিল করা। যা সহজে করা যায়, তার জন্য রিফ্লেকশন আনবেন না।

### ১২. বেস্ট প্র্যাকটিস (Best Practices) ✅

*   লাইব্রেরি বা ফ্রেমওয়ার্ক বানানোর সময় রিফ্লেকশন ব্যবহার করুন (যেমন আপনি নিজে একটা ছোট ORM বানাচ্ছেন)।
*   বিজনেস লজিকে (Service layer) রিফ্লেকশন এড়িয়ে চলুন।
*   এক্সেপশন হ্যান্ডলিং (Null Check) অবশ্যই রাখবেন, কারণ টাইপ বা মেথড নাও থাকতে পারে।

### ১৩. ছোট প্র্যাকটিস টাস্ক (Mini Practice Task) 💻

**টাস্ক:**
১. একটা ক্লাস `Student` বানান (Id, Name, ShowInfo())।
২. ইউজারের কাছ থেকে ইনপুট নিন কোন মেথড কল করতে চায় ("ShowInfo")।
৩. রিফ্লেকশন দিয়ে সেই মেথড কল করুন।

**Solutions Snippet:**
```csharp
Console.Write("Enter Method Name: ");
string methodName = Console.ReadLine(); // User types "ShowInfo"

MethodInfo method = typeof(Student).GetMethod(methodName);
if(method != null)
{
    method.Invoke(new Student(), null);
}
else
{
    Console.WriteLine("Method not found!");
}
```

### কুইক সামারি (Summary) 📝

1.  **Reflection** = আয়নার সামনে কোড। রানটাইমে কোড ইন্সপেক্ট করা।
2.  `typeof(ClassName)` বা `obj.GetType()` দিয়ে শুরু করতে হয়।
3.  `GetProperties()`, `GetMethods()` দিয়ে ভেতরের খবর বের করা যায়।
4.  `Activator.CreateInstance` দিয়ে ডায়নামিক অবজেক্ট বানানো যায়।
5.  `Method.Invoke` দিয়ে মেথড কল করা যায়।
6.  এটা পাওয়ারফুল কিন্তু একটু স্লো, তাই বুঝে শুনে ব্যবহার করতে হবে।

### রিফ্লেকশন চিট-শিট (Cheat Sheet) 📄

| কাজ | কোড |
| :--- | :--- |
| **টাইপ পাওয়া** | `Type t = typeof(MyClass);` |
| **প্রপার্টি লিস্ট** | `t.GetProperties();` |
| **মেথড লিস্ট** | `t.GetMethods();` |
| **মেথড খোঁজা** | `t.GetMethod("MethodName");` |
| **অবজেক্ট তৈরি** | `Activator.CreateInstance(t);` |
| **মেথড রান করা** | `methodInfo.Invoke(obj, params);` |
| **প্রপার্টি ভ্যালু পড়া** | `propInfo.GetValue(obj);` |
| **প্রপার্টি ভ্যালু সেট করা** | `propInfo.SetValue(obj, value);` |
