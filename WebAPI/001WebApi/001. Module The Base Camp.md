#### **Lesson 1.1: API কি এবং .NET কেন সেরা? (The Waiter Analogy)**

**সহজ ভাষায়:**
মনে করো তুমি একটা রেস্টুরেন্টে গিয়েছো। তুমি (Client) টেবিলে বসে আছো, আর কিচেনে (Server/Database) বিরিয়ানি রান্না হচ্ছে। তুমি কি সরাসরি কিচেনে গিয়ে বাবুর্চিকে বলবে "মশলা কম দেন"? না!

তুমি **ওয়েটারকে (API)** ডাকবে। ওয়েটার তোমার অর্ডার (Request) নিবে, কিচেনে দিবে, খাবার রেডি হলে প্লেটটা এনে তোমার টেবিলে (Response) দিবে।

**Web API** ঠিক এই ওয়েটার।
*   **Client (Mobile/Web App):** অর্ডার দেয়।
*   **API (Controller):** রিকোয়েস্ট রিসিভ করে প্রসেস করে।
*   **Server/DB:** ডাটা দেয়।

**কেন .NET?**
১. **Performance:** .NET এখন জাভাস্ক্রিপ্ট বা পাইথনের চেয়ে অনেক ফাস্ট (Benchmarks don't lie!)।
২. **Cross-Platform:** Windows, Mac, Linux—সব জায়গায় চলে।
৩. **Microsoft Backing:** এন্টারপ্রাইজ লেভেলে বস!

**Coding Exercise (Mental):**
চিন্তা করো, যদি ফেসবুকের মোবাইল অ্যাপ (Client) হয়, আর তাদের ডাটা সেন্টার (Database) হয়, তাহলে "Login Button"-এ চাপ দিলে মাঝখানে কে কাজ করে? (উত্তর: API)।

#### **Lesson 1.4: Controllers & Action Methods**

কন্ট্রোলার হলো একটা ক্লাস (Class) যেটা `ControllerBase` থেকে ইনহেরিট করে।

**Example:**
```csharp
[ApiController] // সাইনবোর্ড: আমি একটা API Controller

public class StudentController : ControllerBase
{
    // Action Method
    [HttpGet] // আমি ডাটা আনতে গেছি
```

*   `[Route]`: ব্রাউজারে `.../Student` লিখলে এই ক্লাসে হিট করবে।

#### **Lesson 1.5: HTTP Verbs (CRUD Mantra)**

API-তে আমরা প্রধানত ৪টা কাজ করি (CRUD)। আর এদের জন্য ৪টা বিশেষ HTTP Method আছে:

1.  **GET** (Read): "ভাই মেনুটা দেন।" (ডাটা আনা)
2.  **POST** (Create): "ভাই এক প্লেট কাচ্চি দেন।" (নতুন ডাটা তৈরি করা)
3.  **PUT** (Update): "ভাই কাচ্চিতে ঝাল কমাইয়া দিয়েন।" (ডাটা এডিট করা/পুরোটা চেঞ্জ)
4.  **DELETE** (Delete): "অর্ডার ক্যানসেল!" (ডাটা মুছে ফেলা)

**Real World Example:**
*   ফেসবুকে প্রোফাইল দেখছো = **GET**
*   স্ট্যাটাস পোস্ট করছো = **POST**
*   কমেন্ট এডিট করছো = **PUT**
*   কমেন্ট ডিলেট করছো = **DELETE**

#### **Lesson 1.6: Coding Exercise - My First API Endpoint**

এখন তোমার পালা! চলো একটা ছোট কোড লিখি।

**Task:**
তোমার `SchoolManagement.API` প্রজেক্টে `StudentController.cs` নামে একটা ফাইল বানাও `Controllers` ফোল্ডারে।

```csharp
using Microsoft.AspNetCore.Mvc;
```

#### **Lesson 1.7: Return Types & Status Codes (Feedback Loop)**

**সহজ কথা:**
তুমি কাউকে ফোন দিলে। সে যদি ফোন ধরে "হ্যালো" বলে, তুমি বুঝলে লাইন ঠিক আছে। যদি বলে "রং নাম্বার", তুমি বুঝলে ভুল হয়েছে। আর যদি "নেটওয়ার্ক বিজি" বলে, বুঝবে সমস্যা লাইনে।

API-ও ঠিক এভাবেই ব্রাউজার বা অ্যাপকে "Status Code" দিয়ে ফিডব্যাক দেয়। শুধু `string` রিটার্ন করাটা "গুড প্র্যাকটিস" না। আমাদের `IActionResult` ব্যবহার করতে হবে।

**জনপ্রিয় Status Codes (যেগুলো জানতেই হবে):**
*   **200 OK:** সব ঠিক আছে বস! (Success)
*   **201 Created:** নতুন কিছু তৈরি হয়েছে (যেমন: ছাত্র ভর্তি হয়েছে)।
*   **400 Bad Request:** ক্লায়েন্ট ভুল ভাল ডাটা পাঠিয়েছে (পাসওয়ার্ড দেয় নাই, বা ইমেইল ভুল)।
*   **404 Not Found:** যা খুঁজছো তা নাই (ছাত্র পলাতক)।
*   **500 Internal Server Error:** কোডে বাগ আছে বা সার্ভারে আগুন লেগেছে (ডেভেলপারের দোষ)।

**Code Example:**
```csharp
[HttpGet("{id}")]
public IActionResult GetStudent(int id)
{
    if (id <= 0)
    {
        // 400 Bad Request
        return BadRequest("ভাই ID তো পজিটিভ হতে হবে!"); 
    }

    if (id == 99) 
    {
        // 404 Not Found
        return NotFound("এই আইডির কোনো ছাত্র নাই।"); 
    }

    // 200 OK
    return Ok("ছাত্রের নাম: রহিম"); 
}
```
*দেখলে? এখন API অনেক স্মার্ট রেসপন্স দিচ্ছে!*

#### **Lesson 1.8: Model Binding (Data Catching)**

**সহজ কথা:**
API-তে ডাটা বা "মশলা" বিভিন্ন জায়গা থেকে আসতে পারে। .NET খুব চালাক, সে অটোমেটিক বুঝে নেয় ডাটা কোথা থেকে আসছে। কিন্তু আমাদেরও জানতে হবে।

ডাটা আসার ৩টি প্রধান রাস্তা:
1.  **[FromRoute]:** URL-এর ভেতরেই ডাটা থাকে।
    *   `api/students/5` -> এখানে `5` হলো ডাটা। (সাধারণত ID-র জন্য).
2.  **[FromQuery]:** URL-এর শেষে লেজ লাগিয়ে আসে।
    *   `api/students?class=10&section=A` -> এখানে `class` আর `section` হলো ডাটা। (Search/Filter-এর জন্য)।
3.  **[FromBody]:** খামের ভেতরে চিঠি।
    *   বড় ডাটা (যেমন পুরো ছাত্রের ডিটেইলস) আমরা `JSON` ফরমেটে রিকোয়েস্টের পেটের (Body) ভেতর ঢুকিয়ে পাঠাই। (POST/PUT-এর জন্য)।

**Coding Snippet:**
প্রথমে একটা ক্লাস (Model) বানাই `Student.cs` নামে:
```csharp
public class Student
{
    public int Id { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }
}
```

এবার কন্ট্রোলারে:
```csharp
[HttpPost]
public IActionResult CreateStudent([FromBody] Student student)
{
    // student.Name, student.Age অটোমেটিক ডাটা পেয়ে যাবে!
    return Ok($"{student.Name} ভাই ভর্তি হয়ে গেছে! তার বয়স {student.Age}");
}
```

#### **Lesson 1.9: Postman & Swagger UI (Testing Ground)**

কোড তো লিখলাম, এখন টেস্ট করবো কেমনে? ফ্রন্টএন্ড তো নাই!

**1. Swagger UI:**
তোমার প্রজেক্ট রান করলেই (F5) ব্রাউজারে একটা নীল-সবুজ পেজ আসে না? ওটাই Swagger।

*   এখানে দেখা যায় কি কি Endpoint আছে।
*   `Try it out` বাটনে ক্লিক করে তুমি ডাটা দিয়ে টেস্ট করতে পারো।
*   ডেভেলপমেন্টের সময় এটা বেস্ট ফ্রেন্ড।

**2. Postman:**
এটা একটা আলাদা সফটওয়্যার (ইন্সটল করে নিও)।

*   এখানে তুমি বিভিন্ন রিকোয়েস্ট সেভ করে রাখতে পারো।
*   হেডার, অথেন্টিকেশন টোকেন—সব ইজিলি ম্যানেজ করা যায়।

**কাজ:** আপাতত Swagger দিয়েই চালাও। পরে আমরা Postman-এ শিফট হবো যখন টোকেন নিয়ে কাজ করবো।

#### **Lesson 1.10: Module 1 Final Coding Exercise 🎯**

Module 1 শেষ! এখন একটা ছোট পরীক্ষা। ভয় নাই, ওপেন বুক এক্সাম!

**Scenario:**
তোমাকে একটা **"Teacher"** API বানাতে হবে।

**Requirement:**
1.  `Models` ফোল্ডারে `Teacher.cs` ক্লাস বানাও (Id, Name, Subject)।
2.  `Controllers` ফোল্ডারে `TeacherController` বানাও।
3.  **Endpoint 1 (POST):** একজন নতুন টিচার অ্যাড করার জন্য। (Hint: `[FromBody]`, Return `200 OK` with message).
4.  **Endpoint 2 (GET):** আইডি দিয়ে টিচার খোঁজার জন্য।
    *   যদি আইডি ১ বা ২ হয়, টিচারের নাম রিটার্ন করবে `Ok()`.
    *   অন্য আইডি হলে `NotFound()` রিটার্ন করবে।

### **Solution (চেষ্টা করার পর নিচে দেখবে! 🫣)**

**1. The Model (Teacher.cs)**
```csharp
namespace SchoolManagement.API.Models // namespace ঠিক রেখো
{
    public class Teacher
    {
        public int Id { get; set; }
        public string Name { get; set; }
        public string Subject { get; set; }
    }
}
```

**2. The Controller (TeacherController.cs)**
```csharp
using Microsoft.AspNetCore.Mvc;
using SchoolManagement.API.Models; // Model-কে চিনিয়ে দিতে হবে

namespace SchoolManagement.API.Controllers
{
    [Route("api/[controller]")]
    [ApiController]
    public class TeacherController : ControllerBase
    {
        // 1. Add Teacher
        [HttpPost]
        public IActionResult AddTeacher([FromBody] Teacher teacher)
        {
            if(string.IsNullOrEmpty(teacher.Name))
            {
                return BadRequest("নাম ছাড়া টিচার হয় না ভাই!");
            }
            return Ok($"শিক্ষক {teacher.Name} ({teacher.Subject}) সিস্টেমে অ্যাড হয়েছে।");
        }

        // 2. Get Teacher By ID
        [HttpGet("{id}")]
        public IActionResult GetTeacherById(int id)
        {
            if (id == 1) return Ok(new Teacher { Id = 1, Name = "Kashem Sir", Subject = "Math" });
            if (id == 2) return Ok(new Teacher { Id = 2, Name = "Baten Sir", Subject = "English" });

            return NotFound("এই টিচার আমাদের স্কুলে নাই!");
        }
    }
}
```
