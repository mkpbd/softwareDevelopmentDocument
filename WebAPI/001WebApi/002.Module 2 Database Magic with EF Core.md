#### **Lesson 2.1: ORM & EF Core কি? (Translator between C# & SQL)**

**গল্প:**
মনে করো তুমি বাংলা (C#) পারো, কিন্তু ডাটাবেস ব্যাটা শুধু জাপানিজ (SQL) বোঝে। এখন তুমি কি জাপানিজ শিখবে? না! তুমি একজন দোভাষী বা **Translator** রাখবে।

**EF Core** হলো সেই স্মার্ট Translator।
*   তুমি C# এ বলবে: `context.Students.Add(rahim)`
*   EF Core ডাটাবেসকে বলবে: `INSERT INTO Students VALUES (...)`

একে বলে **ORM (Object-Relational Mapper)**। আমাদের SQL কুয়েরি (`SELECT * FROM...`) মুখস্থ করার প্যারা থেকে মুক্তি!

যুদ্ধের সরঞ্জাম (Packages) রেডি করতে হবে।

**Action Items:**

**DbContext কি?**

#### **Lesson 2.3: Entity Classes (Database Blueprint)**

আমরা **Code-First Approach** ব্যবহার করবো। মানে, আমরা C# ক্লাস লিখবো, আর EF Core সেটা দেখে ডাটাবেসে টেবিল বানিয়ে দিবে।

**Step 1:** `Models` ফোল্ডারে `Student.cs` আপডেট করি (বা নতুন করে বানাই)।

```csharp
namespace SchoolManagement.API.Models
{
    public class Student
    {
        public int Id { get; set; } // এটা হবে Primary Key (PK)
        public string Name { get; set; }
        public string Email { get; set; }
        public int Age { get; set; }
    }
}
```
*EF Core বুঝবে:* `Id` মানেই প্রাইমারি কি, আর `Student` ক্লাসের নাম মানে টেবিলের নাম হবে `Students`।

#### **Lesson 2.4: ConnectionString & Dependency Injection**

এবার ডাটাবেসের ঠিকানা (Address) আর চাবি (Auth) দিতে হবে।

**Step 1: Connection String সেট করা**
`appsettings.json` ফাইলটা ওপেন করো এবং নিচের অংশটুকু যোগ করো (AllowedHosts এর উপরে বা নিচে):

```json
"ConnectionStrings": {
    "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=SchoolDB;Trusted_Connection=True;"
}
```
*(এখানে আমরা LocalDB ব্যবহার করছি যা Visual Studio-র সাথে ফ্রি আসে। রিয়েল লাইফে এখানে আসল সার্ভারের আইপি থাকে।)*

**Step 2: DbContext ক্লাস বানানো**
প্রজেক্টে `Data` নামে একটা ফোল্ডার বানাও। তার ভেতর `AppDbContext.cs` নামে একটা ক্লাস বানাও।

```csharp
using Microsoft.EntityFrameworkCore;
using SchoolManagement.API.Models;

namespace SchoolManagement.API.Data
{
    public class AppDbContext : DbContext
    {
        public AppDbContext(DbContextOptions<AppDbContext> options) : base(options)
        {
        }

        // এই লাইনটা বলে দেয় কোন ক্লাসের জন্য টেবিল হবে
        public DbSet<Student> Students { get; set; } 
    }
}
```

**Step 3: Program.cs এ রেজিস্ট্রেশন (Dependency Injection)**
`Program.cs` এ গিয়ে `builder.Build()` এর **আগে** এই লাইনগুলো যোগ করো:

```csharp
// Import namespaces first
using Microsoft.EntityFrameworkCore;
using SchoolManagement.API.Data;

// Add services to the container.
builder.Services.AddDbContext<AppDbContext>(options =>
    options.UseSqlServer(builder.Configuration.GetConnectionString("DefaultConnection")));
```

#### **Lesson 2.5: Migrations: Code to Database (The Bridge)**

সব রেডি! কিন্তু ডাটাবেস তো এখনো তৈরি হয়নি। এখন আমরা জাদুমন্ত্র (Migration Commands) দিব।

**Action:**
১. Visual Studio তে `View` -> `Other Windows` -> **Package Manager Console (PMC)** ওপেন করো।
২. নিচের কমান্ডটা লিখো এবং Enter দাও:
   `add-migration InitialCreate`
   *(এটা তোমার কোড চেক করে একটা প্ল্যান বা ম্যাপ তৈরি করবে)*
   
৩. যদি সব ঠিক থাকে, দেখবে `Done` লেখা এসেছে। এবার আসল কমান্ড দাও:
   `update-database`
   *(এটা সেই ম্যাপ অনুযায়ী ডাটাবেস এবং টেবিল তৈরি করে ফেলবে)*

**Check:** View -> SQL Server Object Explorer এ গিয়ে দেখবে `SchoolDB` নামে ডাটাবেস তৈরি হয়ে গেছে! 🎉

#### **Lesson 2.6 - 2.9: The CRUD Operations (Real Implementation)**

এখন আমরা `StudentController` কে আপডেট করবো যাতে সে আসল ডাটাবেস ব্যবহার করে।

**Constructor Injection:**
আগে আমরা হার্ডকোডেড লিস্ট ব্যবহার করতাম, এখন `AppDbContext` ব্যবহার করবো।

`Controllers/StudentController.cs`:

```csharp
using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;
using SchoolManagement.API.Data;
using SchoolManagement.API.Models;

namespace SchoolManagement.API.Controllers
{
    [Route("api/[controller]")]
    [ApiController]
    public class StudentController : ControllerBase
    {
        private readonly AppDbContext _context;

        // DbContext কে ইনজেক্ট করা হলো
        public StudentController(AppDbContext context)
        {
            _context = context;
        }

        // Lesson 2.7: Reading Data (SELECT *)
        [HttpGet]
        public async Task<IActionResult> GetAllStudents()
        {
            // await ব্যবহার করছি কারণ ডাটাবেস থেকে আসতে একটু সময় লাগে
            var students = await _context.Students.ToListAsync(); 
            return Ok(students);
        }

        // Reading Data by ID (SELECT WHERE ID = x)
        [HttpGet("{id}")]
        public async Task<IActionResult> GetStudentById(int id)
        {
            var student = await _context.Students.FindAsync(id);
            if (student == null) return NotFound("ছাত্র পাওয়া যায়নি!");
            return Ok(student);
        }

        // Lesson 2.6: Saving Data (INSERT)
        [HttpPost]
        public async Task<IActionResult> CreateStudent(Student student)
        {
            await _context.Students.AddAsync(student); // মেমোরিতে অ্যাড হলো
            await _context.SaveChangesAsync(); // ডাটাবেসে পার্মানেন্টলি সেভ হলো (Commit)
            
            return Ok(student);
        }

        // Lesson 2.8: Updating Data (UPDATE)
        [HttpPut("{id}")]
        public async Task<IActionResult> UpdateStudent(int id, Student updatedStudent)
        {
            var existingStudent = await _context.Students.FindAsync(id);
            if (existingStudent == null) return NotFound();

            // ডাটা চেঞ্জ করা
            existingStudent.Name = updatedStudent.Name;
            existingStudent.Email = updatedStudent.Email;
            existingStudent.Age = updatedStudent.Age;

            await _context.SaveChangesAsync(); // সেভ
            return Ok("আপডেট হয়ে গেছে বস!");
        }

        // Lesson 2.9: Deleting Data (DELETE)
        [HttpDelete("{id}")]
        public async Task<IActionResult> DeleteStudent(int id)
        {
            var student = await _context.Students.FindAsync(id);
            if (student == null) return NotFound();

            _context.Students.Remove(student); // ডিলিট মার্ক করা হলো
            await _context.SaveChangesAsync(); // আসল ডিলিট হলো

            return Ok("ছাত্র ডিলেট করা হয়েছে!");
        }
    }
}
```
