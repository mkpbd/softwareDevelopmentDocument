#### **Lesson 3.1: Fluent API কি? (Attributes vs Fluent Config)**

**গল্প:**
টেবিলের কনফিগারেশন (যেমন: কোনটা প্রাইমারি কি, কোনটার লেন্থ কত হবে) দুইভাবে করা যায়:
১. **Data Annotations:** ক্লাসের প্রপার্টির মাথায় `[Key]`, `[Required]` স্টিকার লাগিয়ে। (আমরা মডিউল ১, ২ তে এটা দেখেছি)।
2. **Fluent API:** `DbContext`-এর ভেতর `OnModelCreating` মেথডে কোড লিখে।

**কেন Fluent API ব্যবহার করবো?**
*   **Clean Code:** তোমার মডেল ক্লাস একদম পরিষ্কার থাকে।
*   **More Power:** এমন অনেক কনফিগারেশন আছে যা স্টিকার (Attributes) দিয়ে করা যায় না, শুধু Fluent API দিয়েই করা যায় (যেমন: Composite Key)।

**Example (`Data/AppDbContext.cs`-এ লিখতে হয়):**
```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    // স্টিকার না লাগিয়ে এখান থেকেই বলে দিচ্ছি
    modelBuilder.Entity<Student>()
        .Property(s => s.Name)
        .IsRequired()
        .HasMaxLength(50);
}
```

#### **Lesson 3.2: Relationships: One-to-One (1:1)**

**Scenario:**
একজন ছাত্রের **একটিই** বিস্তারিত ঠিকানা (Address) থাকবে।

**Implementation:**
১. `StudentAddress` মডেল বানাও (Id, City, Country, StudentId)।
২. `Student` মডেলে একটা প্রপার্টি যোগ করো: `public StudentAddress Address { get; set; }`
৩. `StudentAddress` মডেলে: `public Student Student { get; set; }`

**Fluent API Config:**
```csharp
modelBuilder.Entity<Student>()
    .HasOne(s => s.Address)     // ছাত্রের একটা এড্রেস আছে
    .WithOne(ad => ad.Student)  // এড্রেসেরও একটা ছাত্র আছে
    .HasForeignKey<StudentAddress>(ad => ad.StudentId); // লিংক হবে StudentId দিয়ে
```

#### **Lesson 3.3: Relationships: One-to-Many (The Parent-Child)**

**Scenario:**
এটা সবচেয়ে বেশি ব্যবহৃত হয়।
*   একটা ডিপার্টমেন্টে **অনেক** ছাত্র থাকে। (One Department -> Many Students)
*   একজন ছাত্র **একটা** ডিপার্টমেন্টেই থাকে।

**Implementation:**
১. `Department` মডেল বানাও।
```csharp
public class Department
{
    public int Id { get; set; }
    public string Name { get; set; }
    // এক ডিপার্টমেন্টে অনেক ছাত্র, তাই List
    public ICollection<Student> Students { get; set; } 
}
```

২. `Student` মডেলে ফরেন কি (FK) যোগ করো।
```csharp
public class Student
{
    // ... আগের প্রপার্টি
    public int DepartmentId { get; set; } // FK
    public Department Department { get; set; } // Navigation Property
}
```

**Fluent API Config:**
```csharp
modelBuilder.Entity<Student>()
    .HasOne(s => s.Department)
    .WithMany(d => d.Students)
    .HasForeignKey(s => s.DepartmentId);
```
*(EF Core স্মার্ট, সে নাম দেখে অটোমেটিক বুঝে নেয়, তবুও Fluent API দিয়ে লিখে দেওয়া বেস্ট প্র্যাকটিস)*

#### **Lesson 3.4: Relationships: Many-to-Many (The Social Network)**

**Scenario:**
একজন ছাত্র **অনেক** কোর্স নিতে পারে। আবার একটা কোর্সে **অনেক** ছাত্র থাকতে পারে।
(Student <---> Course)

**Implementation (.NET 5 এর পর থেকে এটা খুব সহজ):**
শুধু দুই ক্লাসেই লিস্ট ধরাইয়া দাও!

`Student.cs`:
`public ICollection<Course> Courses { get; set; }`

`Course.cs`:
`public ICollection<Student> Students { get; set; }`

**EF Core Magic:**
EF Core অটোমেটিক মাঝখানে একটা "Join Table" (`StudentCourses`) বানিয়ে ডাটাবেসে লিংক করে দিবে। তোমার কিচ্ছু করা লাগবে না! 😎

#### **Lesson 3.5: Eager Loading vs Lazy Loading (Include vs Virtual)**

এটা খুবই ইম্পরট্যান্ট ইন্টারভিউ টপিক!

**সমস্যা:**
তুমি `var student = _context.Students.Find(1)` দিলে।
তুমি কি তার `Department` বা `Address` পাবে? **না!** শুধু ছাত্রের নাম ধাম পাবে। রিলেশন ডাটা নাল (Null) থাকবে।

**সমাধান (Eager Loading):**
আমাদের বলতে হবে "ভাই ছাত্র আনার সময় তার ডিপার্টমেন্টটাও সাথে নিয়ে এসো"। এটাকে বলে `Include`।

```csharp
// Controller Code
var studentWithDept = await _context.Students
    .Include(s => s.Department) // Join Query চালাবে
    .Include(s => s.Address)
    .FirstOrDefaultAsync(s => s.Id == 1);
```

*Note: Lazy Loading (virtual keyword) আমরা ব্যবহার করবো না, কারণ এটা অজান্তে হাজার হাজার কুয়েরি চালিয়ে সার্ভার স্লো করে দিতে পারে (N+1 Problem)।*

#### **Lesson 3.6: Seed Data (Initial Data Setup)**

**Scenario:**
প্রজেক্ট রান করার পরেই যেন ডাটাবেস ফাঁকা না থাকে। অন্তত "Science", "Arts" ডিপার্টমেন্ট যেন আগে থেকেই থাকে।

**Implementation (OnModelCreating এর ভেতরে):**
```csharp
modelBuilder.Entity<Department>().HasData(
    new Department { Id = 1, Name = "Science" },
    new Department { Id = 2, Name = "Arts" },
    new Department { Id = 3, Name = "Commerce" }
);
```
*এরপর `add-migration` দিলে এই ডাটাগুলো ইনসার্ট হওয়ার কোড তৈরি হবে।*

#### **Lesson 3.7: Global Query Filters (Soft Delete concept)**

**Scenario:**
আমরা রিয়েল লাইফে ডাটা ডিলিট করি না (অডিট বা হিস্ট্রির জন্য)। আমরা একটা ফ্ল্যাগ রাখি `IsDeleted = true`।
কিন্তু প্রতিবার কুয়েরি করার সময় `.Where(s => !s.IsDeleted)` লেখা বিরক্তিকর।

**Solution:**
`OnModelCreating`-এ একবার রুল সেট করে দাও:

```csharp
modelBuilder.Entity<Student>().HasQueryFilter(s => !s.IsDeleted);
```
এখন তুমি `_context.Students.ToList()` দিলেও ডিলেট হওয়া ছাত্ররা আর আসবে না। যেন তারা গায়েব! 👻

#### **Lesson 3.8: Projections (Select specific columns)**

**কেন দরকার?**
স্টুডেন্ট টেবিলে ৫০টা কলাম থাকতে পারে। কিন্তু ড্রপডাউনে দেখানোর জন্য তোমার শুধু `Id` আর `Name` দরকার। পুরো বস্তা টানার দরকার কি?

**Code:**
```csharp
var studentNames = await _context.Students
    .Select(s => new { s.Id, s.Name }) // শুধু এই দুইটা কলামের জন্য SQL হবে
    .ToListAsync();
```
*এটা API-এর স্পিড ১০০ গুণ বাড়িয়ে দিতে পারে!*

#### **Lesson 3.9: Transactions (All or Nothing)**

**Scenario:**
ধরো, রহিম করিমকে ৫০০ টাকা পাঠালো।
১. রহিমের ব্যালেন্স থেকে ৫০০ মাইনাস হবে।
২. করিমের ব্যালেন্স ৫০০ প্লাস হবে।

যদি ১ নম্বর হওয়ার পর কারেন্ট চলে যায়? সর্বনাশ! টাকা গায়েব।
তাই আমরা **Transaction** ব্যবহার করি। সব হবে, নাহলে কিচ্ছু হবে না।

**Code:**
```csharp
using var transaction = await _context.Database.BeginTransactionAsync();
try
{
    // Step 1: Deduct Logic...
    await _context.SaveChangesAsync();

    // Step 2: Add Logic...
    await _context.SaveChangesAsync();

    // সব ঠিক থাকলে সিলমারা
    await transaction.CommitAsync();
}
catch
{
    // ঝামেলা হলে সব আগের মতো করে দাও
    await transaction.RollbackAsync();
}
```

### **Hints for Exercise (Solution Snippet)**

**Controller Update for GET:**
```csharp
[HttpGet]
public async Task<IActionResult> GetAll()
{
    var students = await _context.Students
        .Include(s => s.Department) // ডিপার্টমেন্ট লোড করো
        .Select(s => new 
        {
            s.Id,
            s.Name,
            DepartmentName = s.Department.Name // সুন্দর ফরম্যাট
        })
        .ToListAsync();

    return Ok(students);
}
```

**Controller Update for POST:**
```csharp
[HttpPost]
public async Task<IActionResult> Create(Student student)
{
    // ফ্রন্টএন্ড থেকে student.DepartmentId আসবে
    _context.Students.Add(student);
    await _context.SaveChangesAsync();
    return Ok(student);
}
```
