#### **Lesson 5.1: Data Annotations (Basic Validation)**

**সহজ উপায়:**
মডেল ক্লাসের মাথার ওপর কিছু স্টিকার (Attributes) লাগিয়ে দেওয়া।

**Code:**
```csharp
public class Student
{
    public int Id { get; set; }

    [Required(ErrorMessage = "ভাই নাম তো দিতেই হবে!")]
    [MaxLength(50)]
    public string Name { get; set; }

    [EmailAddress(ErrorMessage = "এটা কি ইমেইল হলো? ঠিক করে দেন।")]
    public string Email { get; set; }

    [Range(18, 100, ErrorMessage = "১৮ বছরের নিচে কাউকে ভর্তি নিই না।")]
    public int Age { get; set; }
}
```
*এখন যদি কেউ ভুল ডাটা পাঠায়, কন্ট্রোলার অটোমেটিক `400 Bad Request` ছুড়ে মারবে। তোমার কিচ্ছু করা লাগবে না।*

#### **Lesson 5.2: Fluent Validation Intro (The Pro Way)**

**সমস্যা:**
মডেল ক্লাস (Student.cs) হলো ডাটাবেসের ব্লু-প্রিন্ট। সেখানে ভ্যালিডেশন লজিক (IsRequired, MaxLength) ঢুকালে ক্লাসটা নোংরা হয়ে যায়। একে বলে "Polluting the Model"।

**সমাধান:**
ভ্যালিডেশনের জন্য আলাদা একজন "আইনজীবী" নিয়োগ দেওয়া। এটাই **Fluent Validation**।

**Action:**
NuGet Package Manager থেকে `FluentValidation.AspNetCore` ইন্সটল করো।

#### **Lesson 5.3: Creating Complex Validators**

এখন আমরা `Student` ক্লাসের জন্য আলাদা একটা ভ্যালিডেশন ক্লাস বানাবো।

**Code (`Validators/StudentValidator.cs`):**
```csharp
using FluentValidation;
using SchoolManagement.API.Models;

public class StudentValidator : AbstractValidator<Student>
{
    public StudentValidator()
    {
        RuleFor(x => x.Name)
            .NotEmpty().WithMessage("নাম খালি রাখা যাবে না বস!")
            .Length(3, 50).WithMessage("নাম ৩ থেকে ৫০ অক্ষরের মধ্যে হতে হবে।");

        RuleFor(x => x.Email)
            .EmailAddress().WithMessage("ভ্যালিড ইমেইল দেন।");

        RuleFor(x => x.Age)
            .GreaterThanOrEqualTo(18).WithMessage("বাচ্চাদের এলাউড না।");
            
        // Complex Logic
        RuleFor(x => x.Name).Must(name => !name.Contains("Admin"))
            .WithMessage("Admin নামে কেউ রেজিস্টার করতে পারবে না!");
    }
}
```
*দেখলে? লজিক এখন কত পরিষ্কার!*

#### **Lesson 5.4: Dependency Injection with FluentValidation**

আইনজীবী নিয়োগ দিয়েছো, কিন্তু আদালতকে (Program.cs) তো জানাতে হবে।

**Program.cs আপডেট:**
```csharp
using FluentValidation;
using FluentValidation.AspNetCore;

// সার্ভিস কন্টেইনারে যোগ করো
builder.Services.AddFluentValidationAutoValidation();
builder.Services.AddValidatorsFromAssemblyContaining<StudentValidator>();
```
*এখন কন্ট্রোলারে হিট করার আগেই এই ভ্যালিডেশন চেক হবে। ভুল থাকলে গেট থেকেই বিদায়!*

#### **Lesson 5.5: Try-Catch Blocks (Old School)**

ভ্যালিডেশন তো ইনপুট চেক করলো। কিন্তু কোড রান করার সময় যদি ডাটাবেস কানেকশন ফেল করে? বা 0 দিয়ে ভাগ (DivideByZero) হয়ে যায়? তখন অ্যাপ ক্র্যাশ করবে।

**লোকাল হ্যান্ডলিং:**
```csharp
[HttpGet("{id}")]
public IActionResult Get(int id)
{
    try
    {
        // Dangerous code
        var result = _service.GetById(id);
        return Ok(result);
    }
    catch (Exception ex)
    {
        // লগ ফাইলে এরর রাখা উচিত
        return StatusCode(500, "সার্ভারে আগুন লেগেছে! পরে চেষ্টা করুন।");
    }
}
```
*সমস্যা: সব অ্যাকশনে `try-catch` লিখতে গেলে হাত ব্যথা হয়ে যাবে।*

#### **Lesson 5.6: Global Exception Handling Middleware (The Safety Net)**

**আইডিয়া:**
সার্কাসে ট্রাপিজ খেলার নিচে একটা বিশাল জাল (Net) থাকে। খেলা দেখাতে গিয়ে কেউ পড়ে গেলে ওই জালে আটকায়, মাটিতে পড়ে মরে না।
**Global Exception Handler** হলো সেই জাল। অ্যাপের যেকোনো জায়গায় এরর হলে এই মিডলওয়্যার সেটা ধরবে।

**Step 1: Create Middleware Class**
```csharp
public class ExceptionMiddleware
{
    private readonly RequestDelegate _next;
    public ExceptionMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        try
        {
            await _next(context); // রিকোয়েস্ট যেতে দাও
        }
        catch (Exception ex)
        {
            // ওরে বাবা! এরর হয়েছে! ধরো একে!
            await HandleExceptionAsync(context, ex);
        }
    }

    private Task HandleExceptionAsync(HttpContext context, Exception exception)
    {
        context.Response.ContentType = "application/json";
        context.Response.StatusCode = 500;
        
        var response = new 
        { 
            StatusCode = 500, 
            Message = "Internal Server Error. চিন্তা নাই, আমরা ফিক্স করছি!", 
            Details = exception.Message // প্রোডাকশনে এটা লুকানো থাকে
        };
        
        return context.Response.WriteAsJsonAsync(response);
    }
}
```

**Step 2: Register in Program.cs**
`app.UseAuthorization()` এর আগে বসাও:
```csharp
app.UseMiddleware<ExceptionMiddleware>();
```

#### **Lesson 5.7: Custom Exceptions**

সব এরর তো আর `500 Server Error` না। মাঝে মাঝে আমরা ইচ্ছাকৃত এরর থ্রো করি।

**Example:**
```csharp
public class NotFoundException : Exception
{
    public NotFoundException(string message) : base(message) { }
}
```

এখন সার্ভিসের ভেতর থেকে তুমি কল করতে পারো:
`if (student == null) throw new NotFoundException("ছাত্র পাওয়া যায়নি");`

মিডলওয়্যারে চেক করবে: `if (ex is NotFoundException) context.Response.StatusCode = 404;`

#### **Lesson 5.8: Standard API Response Wrapper (Common Format)**

**সমস্যা:**
কখনো তুমি রিটার্ন করো `List<Student>`, কখনো `String`, কখনো `Error Object`। ফ্রন্টএন্ড ডেভেলপার কনফিউজড হয়ে যায়।

**সমাধান (Bento Box):**
সব রেসপন্স একটা নির্দিষ্ট বাক্সে করে পাঠাবো।

**Class:**
```csharp
public class ApiResponse<T>
{
    public bool Success { get; set; }
    public string Message { get; set; }
    public T Data { get; set; }
    public List<string> Errors { get; set; }

    // হ্যাপী রেসপন্স
    public static ApiResponse<T> Ok(T data, string msg = "Success")
    {
        return new ApiResponse<T> { Success = true, Message = msg, Data = data };
    }
    
    // স্যাড রেসপন্স
    public static ApiResponse<T> Fail(string msg, List<string> errors = null)
    {
        return new ApiResponse<T> { Success = false, Message = msg, Errors = errors };
    }
}
```

**Usage in Controller:**
```csharp
return Ok(ApiResponse<Student>.Ok(student, "ছাত্র পাওয়া গেছে!"));
```

#### **Lesson 5.9: Logging with Serilog (Black Box Recorder)**

প্লেন ক্র্যাশ করলে যেমন "ব্ল্যাক বক্স" চেক করা হয়, অ্যাপ ক্র্যাশ করলে **Log** চেক করা হয়। ডিফল্ট লগার ভালো, তবে **Serilog** বস লেভেলের। এটি ফাইলে বা ডাটাবেসে কালারফুল লগ রাখে।

**Setup:**
১. প্যাকেজ: `Serilog.AspNetCore`, `Serilog.Sinks.File`।
২. `Program.cs` এ কনফিগারেশন:

```csharp
using Serilog;

// বিল্ডারের আগে
Log.Logger = new LoggerConfiguration()
    .WriteTo.Console()
    .WriteTo.File("logs/log.txt", rollingInterval: RollingInterval.Day) // প্রতিদিন নতুন ফাইল
    .CreateLogger();

builder.Host.UseSerilog(); 
```

এখন তুমি কোডের যেকোনো জায়গায় `_logger.LogError("সর্বনাশ হয়েছে!")` লিখলে ফাইলে সেভ হয়ে যাবে।
