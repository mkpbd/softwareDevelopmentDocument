.NET এর জগতেও একটা রিকোয়েস্ট (Request) কন্ট্রোলারের কাছে পৌঁছানোর আগে বা রেসপন্স (Response) বের হওয়ার সময় অনেকগুলো গেট পার হয়। এদেরকে আমরা বলি **Middleware** এবং **Filters**। আর ডাটাবেসে সেভ হওয়ার ঠিক আগ মুহূর্তে যে চেক হয়, তাকে বলি **Hooks**।

চলো এই "দারোয়ান মামাদের" কাজ এবং ক্ষমতা সম্পর্কে জানি!

#### **Lesson 6.1: Middleware Pipeline Explained (The Russian Doll)**

**সহজ ভাষায়:**
Middleware হলো একটা পাইপলাইনের মতো। রিকোয়েস্ট একটার পর একটা ধাপ পার হয়।
একে **Russian Doll Model**-ও বলা হয়।
১. রিকোয়েস্ট আসে -> Middleware 1 -> Middleware 2 -> **Controller**।
২. কন্ট্রোলার কাজ করে।
৩. রেসপন্স ব্যাক করে -> Middleware 2 -> Middleware 1 -> Client।

**কেন লাগে?**
লগিং, এরর হ্যান্ডলিং (Module 5 এ দেখেছি), অথেন্টিকেশন, সব রিকোয়েস্টের ওপর নজরদারি করার জন্য।

#### **Lesson 6.2: Building Custom Middleware**

আমরা এখন একটা মিডলওয়্যার বানাবো যেটা চেক করবে ইউজারের সিক্রেট চাবি (API Key) আছে কিনা। না থাকলে গেট থেকেই বিদায়!

**Code:**
`Middlewares/ApiKeyMiddleware.cs`:
```csharp
public class ApiKeyMiddleware
{
    private readonly RequestDelegate _next; // পরের দারোয়ান
    public ApiKeyMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        // ১. রিকোয়েস্ট চেক করা (Going In)
        if (!context.Request.Headers.ContainsKey("X-Secret-Key"))
        {
            context.Response.StatusCode = 401; // Unauthorized
            await context.Response.WriteAsync("চাবি ছাড়া ঢোকা নিষেধ বস!");
            return; // এখানেই খেলা শেষ, সামনে যাবে না
        }

        // ২. সব ঠিক থাকলে পরের জনের কাছে পাঠাও
        await _next(context);

        // ৩. রেসপন্স আসার সময় কিছু করতে চাইলে এখানে লিখতে হয় (Coming Out)
    }
}
```

**Registration (Program.cs):**
```csharp
app.UseMiddleware<ApiKeyMiddleware>();
```

#### **Lesson 6.3: Action Filters (The Personal Bodyguard)**

Middleware হলো গ্লোবাল (সবার জন্য)। কিন্তু **Action Filter** হলো স্পেসিফিক কন্ট্রোলার বা মেথডের জন্য।

ধরো, তুমি চাও শুধু `StudentController`-এ হিট করলে একটা লগ হবে।

**Code:**
`Filters/LogActivityFilter.cs`:
```csharp
using Microsoft.AspNetCore.Mvc.Filters;

public class LogActivityFilter : IActionFilter
{
    private readonly ILogger<LogActivityFilter> _logger;
    public LogActivityFilter(ILogger<LogActivityFilter> logger)
    {
        _logger = logger;
    }

    // অ্যাকশন শুরু হওয়ার আগে
    public void OnActionExecuting(ActionExecutingContext context)
    {
        _logger.LogInformation($"Action শুরু হচ্ছে: {context.ActionDescriptor.DisplayName}");
    }

    // অ্যাকশন শেষ হওয়ার পরে
    public void OnActionExecuted(ActionExecutedContext context)
    {
        _logger.LogInformation("Action শেষ বস!");
    }
}
```

**Usage:**
```csharp
[TypeFilter(typeof(LogActivityFilter))] // মাথার উপর লাগিয়ে দাও
[HttpGet]
public IActionResult Get() { ... }
```

#### **Lesson 6.5: Result Filters**

রেসপন্স ক্লায়েন্টের কাছে যাওয়ার ঠিক আগ মুহূর্তে যদি তুমি রেসপন্স মডিফাই করতে চাও।
যেমন: হ্যাকারদের কনফিউজ করার জন্য রেসপন্স হেডারে `X-Powered-By: PHP` লাগিয়ে দেওয়া (যদিও আমরা .NET চালাচ্ছি! 😜)।

```csharp
public class FakeHeaderFilter : IResultFilter
{
    public void OnResultExecuting(ResultExecutingContext context)
    {
        context.HttpContext.Response.Headers.Add("X-System", "Top Secret NASA Server");
    }
    public void OnResultExecuted(ResultExecutedContext context) { }
}
```

#### **Lesson 6.6: EF Core Interceptors/Hooks (The Spy)**

এটা আমার ফেভারিট! ডাটাবেসে `SaveChanges` কল করার ঠিক আগ মুহূর্তে এটা কাজ করে।

**Scenario:**
প্রতিটা টেবিলে `CreatedDate` আর `UpdatedDate` আছে। প্রতিবার ম্যানুয়ালি কোডে `DateTime.Now` বসানো বিরক্তিকর।

**Solution:**
`Data/AuditInterceptor.cs`:
```csharp
using Microsoft.EntityFrameworkCore.Diagnostics;

public class AuditInterceptor : SaveChangesInterceptor
{
    public override ValueTask<InterceptionResult<int>> SavingChangesAsync(
        DbContextEventData eventData, 
        InterceptionResult<int> result, 
        CancellationToken cancellationToken = default)
    {
        var context = eventData.Context;
        if (context == null) return base.SavingChangesAsync(eventData, result, cancellationToken);

        // যারা অ্যাড বা মডিফাই হচ্ছে তাদের ধরো
        var entries = context.ChangeTracker.Entries<BaseEntity>(); // BaseEntity তে Date প্রপার্টি থাকে

        foreach (var entry in entries)
        {
            if (entry.State == EntityState.Added)
            {
                entry.Entity.CreatedDate = DateTime.UtcNow;
            }
            
            if (entry.State == EntityState.Modified)
            {
                entry.Entity.UpdatedDate = DateTime.UtcNow;
            }
        }

        return base.SavingChangesAsync(eventData, result, cancellationToken);
    }
}
```
*রেজিস্ট্রেশন করতে হয় `AddDbContext` এর সময় `options.AddInterceptors(new AuditInterceptor())` দিয়ে।*

#### **Lesson 6.9: Rate Limiting (Traffic Control)**

কোনো দুষ্টু ইউজার যদি স্ক্রিপ্ট চালিয়ে ১ সেকেন্ডে ১০০০ রিকোয়েস্ট পাঠায়? সার্ভার তো শুয়ে পড়বে!
একে আটকানোর নাম **Rate Limiting**।

**Setup (Program.cs):**
```csharp
using Microsoft.AspNetCore.RateLimiting;

builder.Services.AddRateLimiter(options =>
{
    options.AddFixedWindowLimiter("Fixed", opt =>
    {
        opt.Window = TimeSpan.FromMinutes(1);
        opt.PermitLimit = 5; // ১ মিনিটে ৫টার বেশি রিকোয়েস্ট নয়
    });
});
```

**Usage:**
`app.UseRateLimiter();`
এবং কন্ট্রোলারের মাথায়: `[EnableRateLimiting("Fixed")]`
