#### **Lesson 10.1: Unit Testing Intro (xUnit)**

**আইডিয়া:**
একটা গাড়ি বানানোর পর কি সরাসরি রাস্তায় নামাবে? না! আগে ল্যাবে ইঞ্জিন টেস্ট করবে, ব্রেক টেস্ট করবে।
কোডের ছোট ছোট পার্ট (Unit) টেস্ট করাকে বলে **Unit Testing**।

**Tools:** আমরা **xUnit** ব্যবহার করবো (ইন্ডাস্ট্রি স্ট্যান্ডার্ড)।

**Setup:**
১. সলিউশনে নতুন প্রজেক্ট নাও: `SchoolManagement.Tests` (Type: xUnit Test Project).
২. মেইন প্রজেক্টের রেফারেন্স অ্যাড করো।

**Structure (AAA Pattern):**
*   **Arrange:** স্টেজ সাজানো (Variables, Objects ready করা)।
*   **Act:** মেথডটা কল করা (Action)।
*   **Assert:** রেজাল্ট চেক করা (Result ঠিক আছে তো?)।

**Example:**
```csharp
[Fact] // এটা একটা টেস্ট
public void Add_ShouldReturnSum_WhenInputsAreValid()
{
    // Arrange
    int a = 5, b = 10;
    var calc = new Calculator(); // ধরি তোমার একটা ক্যালকুলেটর ক্লাস আছে

    // Act
    var result = calc.Add(a, b);

    // Assert
    Assert.Equal(15, result); // যদি ১৫ না হয়, টেস্ট ফেইল! লাল বাতি জ্বলবে। 🔴
}
```

#### **Lesson 10.2: Mocking dependencies (Moq)**

**সমস্যা:**
তুমি যখন `StudentService` টেস্ট করবে, সে তো ডাটাবেস খোঁজে (`Repository` কল করে)। টেস্ট রান করার সময় ডাটাবেস কানেক্ট করা ঝামেলা এবং স্লো।

**সমাধান (Mocking):**
সিনেমায় যেমন হিরোর বদলে "স্টান্টম্যান" লাফ দেয়, টেস্টিংয়ে আসল রিপোজিটরির বদলে আমরা **Mock (নকল/ডামি)** অবজেক্ট ব্যবহার করি। এ জন্য **Moq** লাইব্রেরি সেরা।

**Action:** `SchoolManagement.Tests` প্রজেক্টে `Moq` প্যাকেজ ইন্সটল করো।

#### **Lesson 10.3: Testing Controllers**

চলো দেখি `StudentController` ঠিকঠাক কাজ করে কিনা, ডাটাবেস ছাড়াই।

```csharp
public class StudentControllerTests
{
    private readonly Mock<IStudentRepository> _mockRepo;
    private readonly StudentController _controller;

    public StudentControllerTests()
    {
        _mockRepo = new Mock<IStudentRepository>(); // নকল রিপোজিটরি
        _controller = new StudentController(_mockRepo.Object); // কন্ট্রোলারে নকলটা ঢুকালাম
    }

    [Fact]
    public async Task GetStudents_ShouldReturn200OK()
    {
        // Arrange: বলে দিলাম রিপোজিটরি কি ফেরত দিবে
        _mockRepo.Setup(repo => repo.GetAllAsync())
                 .ReturnsAsync(new List<Student> { new Student { Name = "Test" } });

        // Act
        var result = await _controller.Get();

        // Assert
        Assert.IsType<OkObjectResult>(result); // চেক করলাম রেসপন্স 200 OK কিনা
    }
}
```
*এখন `Test Explorer` ওপেন করে `Run` দিলে সবুজ বাতি জ্বলবে! 🟢*

#### **Lesson 10.5: Docker Basics for .NET**

**সমস্যা:**
তোমার পিসিতে কোড চলে, কিন্তু সার্ভারে গিয়ে চলে না। কারণ সার্ভারে হয়তো .NET ভার্সন আলাদা বা কোনো ফাইল মিসিং।

**সমাধান (Container):**
**Docker** হলো টিফিন বক্সের মতো। তুমি ভাত, ডাল, মাছ সব বক্সে ভরে দিলে। এখন এটা পার্কে গিয়ে খাও আর অফিসে গিয়ে খাও—খাবার একই থাকবে।
ডকার তোমার অ্যাপ, ডাটাবেস, লাইব্রেরি সব একটা প্যাকেটে (Image) ভরে ফেলে। যেকোনো পিসিতে ডকার থাকলে ওই প্যাকেট হুবহু চলবে।

#### **Lesson 10.6: Containerizing the API**

তোমার প্রজেক্টের মেইন ফোল্ডারে একটা ফাইল বানাও নাম `Dockerfile` (কোনো এক্সটেনশন নাই)।

**The Recipe (Dockerfile):**
```dockerfile
# Step 1: Build Image (রান্নাঘর)
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY . .
RUN dotnet restore
RUN dotnet publish -c Release -o /app

# Step 2: Runtime Image (খাবার টেবিল)
FROM mcr.microsoft.com/dotnet/aspnet:8.0
WORKDIR /app
COPY --from=build /app .
ENTRYPOINT ["dotnet", "SchoolManagement.API.dll"]
```

**Commands:**
1.  ইমেজ বানাও: `docker build -t school-api .`
2.  চালাও: `docker run -p 8080:8080 school-api`
*ব্যাস! তোমার অ্যাপ এখন ডকার কন্টেইনারে চলছে!* 🐳

#### **Lesson 10.7: CI/CD Concepts (GitHub Actions)**

**CI (Continuous Integration):**
তুমি গিটহাবে কোড পুশ করলেই একটা রোবট (GitHub Actions) অটোমেটিক তোমার কোড ডাউনলোড করবে, বিল্ড করবে এবং টেস্ট রান করবে। যদি কোনো টেস্ট ফেইল করে, সে তোমাকে ইমেইল দিবে।

**CD (Continuous Deployment):**
টেস্ট পাস করলে রোবটটা অটোমেটিক তোমার কোড সার্ভারে (Azure/AWS) আপলোড করে দিবে।

*তোমাকে আর ম্যানুয়ালি সার্ভারে ফাইল কপি-পেস্ট করতে হবে না। পুশ করো আর ঘুমাও!* 😴

#### **Lesson 10.8: Deploy to IIS/Azure (Overview)**

**1. Azure (Cloud):**
Visual Studio তে প্রজেক্টের ওপর রাইট ক্লিক -> **Publish** -> **Azure** -> **App Service** (Create New).
*ব্যাস, নেক্সট নেক্সট ফিনিশ দিলেই তোমার সাইট লাইভ!* (স্টুডেন্টদের জন্য এটা বেস্ট)।

**2. IIS (Windows Server):**
*   Publish to **Folder**.
*   ফাইলগুলো কপি করে সার্ভারের `C:\inetpub\wwwroot\mysite` এ রাখো।
*   IIS Manager ওপেন করে "Add Website" দিয়ে ফোল্ডারটা দেখিয়ে দাও।

#### **Lesson 10.9: Performance Tuning Tips**

অ্যাপ তো লাইভ হলো, এখন স্পিড বাড়াবো কিভাবে?
১. **Async/Await:** সব জায়গায় ব্যবহার করো। কখনও `.Result` বা `.Wait()` লিখবে না।
২. **EF Core NoTracking:** ডাটা শুধু পড়ার সময় `.AsNoTracking()` ব্যবহার করো।
৩. **Caching:** যে ডাটা ঘন ঘন চেঞ্জ হয় না (যেমন: দেশের নাম), তা মেমোরিতে (Redis/MemoryCache) রাখো।
৪. **Compression:** `ResponseCompression` মিডলওয়্যার ব্যবহার করো, ডাটার সাইজ কমে যাবে।
