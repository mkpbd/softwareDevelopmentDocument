### **Module 1: হ্যালো প্রোগ্রামিং জগত (Basics)**

#### **Lesson 1: সেটআপ এবং হ্যালো ওয়ার্ল্ড**
* **Learning Goal:** পিসিতে কোড রান করার ব্যবস্থা করা এবং প্রথম প্রোগ্রাম লেখা।
* **Simple Explanation:** ক্রিকেট খেলার আগে যেমন ব্যাট-প্যাড কিনতে হয়, কোডিংয়ের জন্য `.NET SDK` আর `VS Code` (বা Visual Studio) লাগে। আমরা `Console.WriteLine` দিয়ে কম্পিউটারকে কথা বলাব।
* **Analogy:** নতুন সিম কিনলে যেমন প্রথম কাজ "Hello" বলে চেক করা লাইন ঠিক আছে কিনা, প্রোগ্রামিংয়েও তাই।
* **Code Example:**
```csharp
// Program.cs
Console.WriteLine("Assalamu Alaikum, C# 14!");
Console.WriteLine("Ami code likhte pari!");
```
* **File Structure:**
```
MyFirstApp/
└── Program.cs
```
* **Mini Exercise:** তোমার নাম এবং প্রিয় খাবারের নাম প্রিন্ট করো।
* **Common Mistakes:** সেমিকোলন `;` না দেওয়া। (এটা ভাতের পাতে লবণের মতো, না দিলে এরর খাবে)।
* **Summary:** `Console.WriteLine` দিয়ে লেখা প্রিন্ট করে।

#### **Lesson 2: ভ্যারিয়েবল (Variables) - ডেটার টিফিন বক্স**
* **Learning Goal:** ডেটা মেমোরিতে রাখা।
* **Simple Explanation:** ভ্যারিয়েবল হলো মেমোরির ছোট ছোট বক্স। একেক বক্সে একেক জিনিস রাখা যায়। `int` এ পূর্ণসংখ্যা, `string` এ লেখা, `bool` এ সত্য/মিথ্যা।
* **Analogy:** রান্নাঘরে যেমন চালের বয়ামে ডাল রাখা যায় না, কোডেও `int` এর বয়ামে নাম (string) রাখা যায় না।
* **Code Example:**
```csharp
int age = 25;
string name = "Rahim";
bool isHungry = true;
double teaPrice = 12.5;

Console.WriteLine($"Name: {name}, Age: {age}"); // String Interpolation
```
* **Mini Exercise:** নিজের উচ্চতা (double) এবং তুমি ছাত্র কি না (bool) ভ্যারিয়েবলে রেখে প্রিন্ট করো।
* **Common Mistakes:** `int` এর মধ্যে `12.5` রাখা (দশমিকের জন্য `double` বা `decimal` লাগে)।
* **Summary:** ভ্যারিয়েবল হলো ডেটা স্টোর করার পাত্র।

#### **Lesson 3: স্ট্রিং নিয়ে নাড়াচাড়া (String Operations)**
* **Learning Goal:** টেক্সট বা লেখা ম্যানিপুলেট করা।
* **Simple Explanation:** স্ট্রিং জোড়া লাগানো, ছোট হাতের বা বড় হাতের করা।
* **Analogy:** দরদাম করার সময় যেমন কথা ঘুরিয়ে পেঁচিয়ে বলি, স্ট্রিং মেথড দিয়ে লেখাকে সাইজ করা হয়।
* **Code Example:**
```csharp
string fName = "Abul";
string lName = "Hasan";
string fullName = fName + " " + lName; 
string shout = fullName.ToUpper(); // ABUL HASAN

Console.WriteLine(shout);
```
* **Mini Exercise:** তোমার নাম সব ছোট হাতের (LowerCase) করে প্রিন্ট করো।
* **Summary:** স্ট্রিং ম্যানিপুলেশন দিয়ে টেক্সট ফরম্যাট করা হয়।

#### **Lesson 4: অংক এবং লজিক (Operators)**
* **Learning Goal:** যোগ, বিয়োগ, গুণ, ভাগ এবং লজিক চেক।
* **Simple Explanation:** `+`, `-`, `*`, `/` সাধারণ অংক। আর `==`, `>` (বড়), `<` (ছোট) হলো তুলনা।
* **Analogy:** দোকানদার যেমন হিসাব করে বাকি টাকা ফেরত দেয়, কম্পিউটারও অপারেটর দিয়ে হিসাব করে।
* **Code Example:**
```csharp
int a = 10;
int b = 3;
Console.WriteLine(a + b); // 13
Console.WriteLine(a % b); // 1 (ভাগশেষ)
bool isAdult = a > 18; // false
```
* **Mini Exercise:** ১০০ টাকার নোট দিয়ে ৩৫ টাকার চা খেলে কত থাকে, কোড করে বের করো।
* **Summary:** অপারেটর দিয়ে ক্যালকুলেশন আর তুলনা করা হয়।

#### **Lesson 5: সিদ্ধান্ত নেওয়া (If/Else)**
* **Learning Goal:** শর্ত সাপেক্ষে কোড রান করা।
* **Simple Explanation:** যদি বৃষ্টি হয় তবে ছাতা নিব, নাহলে নিব না। এটাই `if-else`।
* **Analogy:** পকেটে টাকা থাকলে বিরিয়ানি খাব (if), না থাকলে সিঙ্গারা (else)।
* **Code Example:**
```csharp
int pocketMoney = 50;

if (pocketMoney >= 200)
{
    Console.WriteLine("Kacchi Biriyani Khabo!");
}
else if (pocketMoney >= 50)
{
    Console.WriteLine("Chicken Burger Khabo.");
}
else 
{
    Console.WriteLine("Pani khabo.");
}
```
* **Mini Exercise:** একটা নাম্বারের ভ্যারিয়েবল নাও, সেটা পজিটিভ না নেগেটিভ তা চেক করো।
* **Summary:** `if-else` দিয়ে কোডের ফ্লো কন্ট্রোল করা হয়।

**✅ Milestone 1: Solved Exercise (Lessons 1-5)**
**Question:** এমন একটা প্রোগ্রাম লেখো যা তোমার জন্মসাল ইনপুট হিসেবে নেবে (হার্ডকোড করো ভ্যারিয়েবলে), এবং তুমি "Voter" কি না তা জানাবে (বয়স ১৮+ হতে হবে)।
**Solution:**
```csharp
int birthYear = 2005;
int currentYear = 2025;
int age = currentYear - birthYear;

Console.WriteLine($"Age is: {age}");

if (age >= 18)
{
    Console.WriteLine("Apni Vote dite parben.");
}
else
{
    Console.WriteLine("Ekhon basay giye porashona koren.");
}
```

### **Module 2: লুপ এবং কালেকশন (Control Flow & Arrays)**

#### **Lesson 6: একই কাজ বারবার (Loops)**
* **Learning Goal:** কোড রিপিট করা।
* **Simple Explanation:** `for` লুপ দিয়ে নির্দিষ্ট বার কাজ করা, `while` দিয়ে শর্ত পূরণ না হওয়া পর্যন্ত কাজ করা।
* **Analogy:** শিক্ষক যখন শাস্তি দেয় "আমি আর ক্লাসে কথা বলব না" ১০০ বার লিখতে, তখন লুপ লাগে।
* **Code Example:**
```csharp
// For loop
for(int i = 1; i <= 5; i++)
{
    Console.WriteLine($"Rickshaw mama jore chalao: {i}");
}
```
* **Mini Exercise:** ১ থেকে ১০ পর্যন্ত সব জোড় সংখ্যা প্রিন্ট করো।
* **Summary:** লুপ দিয়ে রিপিটেটিভ কাজ অটোমেট করা হয়।

#### **Lesson 7: অ্যারে (Arrays) - ফিক্সড তাক**
* **Learning Goal:** অনেকগুলো ডেটা একসাথে রাখা (সাইজ ফিক্সড)।
* **Simple Explanation:** অ্যারে হলো ট্রেনের সিটের মতো। সিট সংখ্যা ফিক্সড, বাড়ান কমানো যায় না।
* **Analogy:** ডিমের কেস। এক ডজন কিনলে ১২টাই রাখা যাবে, ১৩টা রাখা যাবে না।
* **Code Example:**
```csharp
string[] friends = { "Raju", "Mina", "Mithu" };
Console.WriteLine(friends[0]); // Raju
friends[1] = "Dipjol"; // Mina replaced by Dipjol
```
* **Mini Exercise:** ৫টা ফলের নাম অ্যারেতে রাখো এবং ৩ নাম্বার ফলটা প্রিন্ট করো।
* **Summary:** অ্যারে ফিক্সড সাইজের কালেকশন।

#### **Lesson 8: লিস্ট (`List<T>) - রাবার ব্যান্ড**
* **Learning Goal:** ডাইনামিক কালেকশন (যত খুশি ডেটা রাখা)।
* **Simple Explanation:** লিস্টে ডেটা এড করলে সাইজ বাড়ে, রিমুভ করলে কমে। সবচেয়ে বেশি ব্যবহৃত হয়।
* **Analogy:** বাজারের ব্যাগ। যত বাজার করবে, ব্যাগ তত ফুলবে।
* **Code Example:**
```csharp
List<string> shoppingList = new(); // C# modern syntax
shoppingList.Add("Alu");
shoppingList.Add("Peyaj");
shoppingList.Remove("Alu");

foreach(var item in shoppingList)
{
    Console.WriteLine(item);
}
```
* **Mini Exercise:** ৩ জন বন্ধুর নামের লিস্ট বানাও, পরে আরেকজন বন্ধুকে `.Add()` করো।
* **Summary:** `List<T>` ডাইনামিক এবং ফ্লেক্সিবল।

#### **Lesson 9: ডিকশনারি (Dictionary<K,V>)**
* **Learning Goal:** Key-Value পেয়ারে ডেটা রাখা।
* **Simple Explanation:** রোলের বিপরীতে নাম, বা শব্দের বিপরীতে অর্থ খোঁজা।
* **Analogy:** ফোনবুক। নাম (Key) দিয়ে সার্চ দিলে নাম্বার (Value) পাওয়া যায়।
* **Code Example:**
```csharp
Dictionary<string, int> prices = new();
prices.Add("Burger", 150);
prices.Add("Pizza", 400);

Console.WriteLine(prices["Burger"]); // Prints 150
```
* **Mini Exercise:** তোমার ৩ জন বন্ধুর নাম (Key) এবং তাদের বয়স (Value) ডিকশনারিতে রাখো।
* **Summary:** ডিকশনারি দিয়ে ফাস্ট লুক-আপ (Search) করা যায়।

#### **Lesson 10: মেথড বা ফাংশন (Methods)**
* **Learning Goal:** কোড রি-ইউজ করা।
* **Simple Explanation:** একটা কাজ বারবার না লিখে একটা মেথড বানিয়ে রাখা এবং দরকার হলে কল করা।
* **Analogy:** চা বানানোর রেসিপি। একবার শিখলে বারবার রেসিপি দেখতে হয় না, শুধু "চা বানাও" বললেই হয়।
* **Code Example:**
```csharp
void MakeTea(int sugarSpoon)
{
    Console.WriteLine($"Pani gorom korchi...");
    Console.WriteLine($"Cha pata dilam...");
    Console.WriteLine($"{sugarSpoon} chamoch chini dilam.");
    Console.WriteLine("Cha Ready!");
}

MakeTea(2); // Call method
```
* **Mini Exercise:** দুটি সংখ্যার যোগফল রিটার্ন করে এমন একটি মেথড লেখো।
* **Summary:** মেথড কোডকে ছোট এবং অর্গানাইজড রাখে।

### **Module 3: OOP এর হাতেখড়ি (Object Oriented Programming)**

#### **Lesson 11: ক্লাস এবং অবজেক্ট (Class & Object)**
* **Learning Goal:** ব্লু-প্রিন্ট এবং রিয়েল জিনিস।
* **Simple Explanation:** `Class` হলো নকশা (Design), আর `Object` হলো সেই নকশা দেখে তৈরি জিনিস।
* **Analogy:** আর্কিটেক্টের নকশা হলো ক্লাস, আর তৈরি হওয়া বিল্ডিং হলো অবজেক্ট।
* **Code Example:**
```csharp
class Car 
{
    public string Model;
    public void Horn() => Console.WriteLine("Peep Peep!");
}

// Program.cs
Car myCar = new Car();
myCar.Model = "Toyota";
myCar.Horn();
```
* **Mini Exercise:** `Mobile` নামে ক্লাস বানাও, তার `Brand` ফিল্ড দাও।
* **Summary:** ক্লাস হলো টেমপ্লেট, অবজেক্ট হলো তার বাস্তব রূপ।

#### **Lesson 12: প্রপার্টিজ (Properties)**
* **Learning Goal:** ডেটা সিকিউর করা (Getter/Setter)।
* **Simple Explanation:** ফিল্ডের বদলে প্রপার্টি ব্যবহার করা ভালো, এতে লজিক বসানো যায়।
* **Analogy:** বাড়ির গেটে দারোয়ান। কেউ ঢুকলে চেক করে (Set), কেউ কিছু চাইলে এনে দেয় (Get)।
* **Code Example:**
```csharp
class Student
{
    public string Name { get; set; } // Auto property
    private int _age;
    public int Age 
    {
        get => _age;
        set { if (value > 0) _age = value; } // Validation logic
    }
}
```
* **File Structure:** `Models/Student.cs`
* **Mini Exercise:** এমন প্রপার্টি বানাও যেখানে নেগেটিভ টাকা সেট করা যাবে না।
* **Summary:** প্রপার্টি দিয়ে ডেটা অ্যাক্সেস কন্ট্রোল করা হয়।

#### **Lesson 13: কনস্ট্রাক্টর (Constructors)**
* **Learning Goal:** অবজেক্ট তৈরির সময় ডিফল্ট ডেটা সেট করা।
* **Simple Explanation:** অবজেক্ট `new` করার সাথে সাথে এই মেথড কল হয়।
* **Analogy:** রেস্টুরেন্টে বসলেই যেমন ওয়েটার মেনু আর পানি দিয়ে যায় (অটোমেটিক), কনস্ট্রাক্টরও তাই।
* **Code Example:**
```csharp
class Person
{
    public string Name { get; }
    public Person(string name) // Constructor
    {
        Name = name;
    }
}
// Usage: Person p = new Person("Sakib");
```
* **Summary:** কনস্ট্রাক্টর অবজেক্ট ইনিশিয়ালাইজ করে।

#### **Lesson 14: স্ট্যাটিক (Static) মেম্বার**
* **Learning Goal:** অবজেক্ট ছাড়া মেম্বার অ্যাক্সেস।
* **Simple Explanation:** `static` মানে এটা ক্লাসের সম্পত্তি, কোনো নির্দিষ্ট অবজেক্টের না। সবার জন্য এক।
* **Analogy:** বাসের সিট (অবজেক্টের নিজস্ব), কিন্তু বাসের রুট নাম্বার (সবার জন্য এক/স্ট্যাটিক)।
* **Code Example:**
```csharp
class Calculator
{
    public static int Add(int a, int b) => a + b;
}
// Usage: Calculator.Add(5, 6); // No 'new' needed
```
* **Summary:** `static` মেম্বার ক্লাসের নামের সাথে থাকে, অবজেক্ট লাগে না।

#### **Lesson 15: এনক্যাপসুলেশন (Access Modifiers)**
* **Learning Goal:** ডেটা লুকানো (`public`, `private`)।
* **Simple Explanation:** `private` মানে ঘরের ভেতরের কথা (বাইরে কেউ জানবে না), `public` মানে নোটিশ বোর্ড।
* **Analogy:** তোমার ফেসবুক পাসওয়ার্ড `private`, কিন্তু প্রোফাইল পিকচার `public`।
* **Code Example:**
```csharp
class BankAccount
{
    private double _balance; // Hidden
    public void Deposit(double amount) // Public access
    {
        _balance += amount;
    }
}
```
* **Summary:** এনক্যাপসুলেশন কোডের নিরাপত্তা বাড়ায়।

**✅ Milestone 3: Solved Exercise**
**Question:** একটি `Mobile` ক্লাস বানাও যার `Balance` প্রাইভেট থাকবে। `Recharge(int amount)` এবং `Call(int minutes)` মেথড থাকবে। ১ মিনিট কল করলে ২ টাকা কাটবে। ব্যালেন্স না থাকলে কল যাবে না।
**Solution:**
```csharp
class Mobile
{
    private double _balance;

    public void Recharge(int amount)
    {
        _balance += amount;
        Console.WriteLine($"Recharged: {amount}. New Balance: {_balance}");
    }

    public void Call(int minutes)
    {
        double cost = minutes * 2.0;
        if (_balance >= cost)
        {
            _balance -= cost;
            Console.WriteLine($"Call duration: {minutes} mins. Cost: {cost}. Rem Balance: {_balance}");
        }
        else
        {
            Console.WriteLine("Insufficient Balance! Please Recharge.");
        }
    }
}
```

### **Module 4: OOP এর গভীরে (OOP Deep Dive)**

#### **Lesson 16: ইনহেরিটেন্স (Inheritance) - বাপ কা বেটা**
* **Goal:** কোড কপি না করে প্যারেন্ট ক্লাস থেকে বৈশিষ্ট্য পাওয়া।
* **Analogy:** বাবার সম্পত্তি ছেলে পায়, কোডেও চাইল্ড ক্লাস প্যারেন্টের সব `public` জিনিস পায়।
* **Code:**
```csharp
class Animal { public void Eat() => Console.WriteLine("Eating..."); }
class Dog : Animal { public void Bark() => Console.WriteLine("Ghew!"); }
// Dog can now Eat() and Bark()
```
* **Summary:** `: ParentClass` দিয়ে ইনহেরিট করা হয়।

#### **Lesson 17: পলিমরফিজম (Overriding)**
* **Goal:** একই মেথড, কিন্তু ভিন্ন কাজ।
* **Analogy:** "সালাম দেওয়া"। বসকে একভাবে সালাম দাও, বন্ধুকে আরেকভাবে। কাজ এক (সালাম), কিন্তু ভঙ্গি ভিন্ন।
* **Code:**
```csharp
class Animal { public virtual void Speak() => Console.WriteLine("Sound..."); }
class Cat : Animal { public override void Speak() => Console.WriteLine("Meow"); }
```
* **Summary:** `virtual` এবং `override` দিয়ে মেথডের কাজ চেঞ্জ করা যায়।

#### **Lesson 18: অ্যাবস্ট্রাক্ট ক্লাস (Abstract Class)**
* **Goal:** অসম্পূর্ণ ক্লাস যা অবশ্যই ইনহেরিট করে পূর্ণ করতে হয়।
* **Analogy:** শূন্যস্থান পূরণ করো পরীক্ষার খাতা। টিচার কাঠামো দিয়েছেন, ছাত্রকে পূরণ করতে হবে।
* **Code:**
```csharp
abstract class Shape { public abstract double GetArea(); }
class Circle : Shape 
{ 
    public double Radius { get; set; }
    public override double GetArea() => 3.14 * Radius * Radius; 
}
```
* **Summary:** অ্যাবস্ট্রাক্ট ক্লাসের অবজেক্ট হয় না, একে ইনহেরিট করতেই হয়।

#### **Lesson 19: ইন্টারফেস (Interface) - কন্ট্রাক্ট**
* **Goal:** মাল্টিপল ইনহেরিটেন্সের সুবিধা এবং কড়াকড়ি নিয়ম।
* **Analogy:** মাল্টিপ্লাগ সকেট। যেই ডিভাইসই হোক, পিন সাইজ (রুলস) মিললে চলবে।
* **Code:**
```csharp
interface IPlayer { void Play(); }
class Mp3Player : IPlayer { public void Play() => Console.WriteLine("Playing Song"); }
class VideoPlayer : IPlayer { public void Play() => Console.WriteLine("Playing Video"); }
```
* **Summary:** ইন্টারফেস বলে "কি করতে হবে", ক্লাস ঠিক করে "কিভাবে করবে"।

#### **Lesson 20: Structs এবং Enums**
* **Goal:** লাইটওয়েট ডেটা টাইপ এবং কনস্ট্যান্ট লিস্ট।
* **Analogy:** `Enum` হলো রেস্টুরেন্টের মেনু কার্ডের অপশন (фиксированный), `Struct` হলো ছোট ভ্যারিয়েবলের প্যাকেট।
* **Code:**
```csharp
enum Day { Sat, Sun, Mon };
struct Point { public int X; public int Y; } // Value type
// Usage: Day today = Day.Sat;
```
* **Summary:** ছোট ডেটার জন্য Struct এবং ফিক্সড অপশনের জন্য Enum।

#### **Lesson 22: নাল হ্যান্ডলিং (Nullable Types)**

* **Goal:** স্মার্ট কন্ডিশন চেকিং।
* **Analogy:** সিকিউরিটি গার্ড যেমন আইডি কার্ড, ড্রেস বা চেহারা দেখে চিনতে পারে, প্যাটার্ন ম্যাচিং দিয়ে অবজেক্ট চেনা যায়।

#### **Lesson 24: জেনেরিক্স (Generics)` <T>**

#### **Lesson 25: এক্সেপশন হ্যান্ডলিং (Try-Catch)**
* **Goal:** প্রোগ্রাম ক্র্যাশ ঠেকাতে এরর হ্যান্ডেল করা।
* **Analogy:** রিকশা চালাতে গিয়ে চেইন পড়লে (Exception), সেটা ঠিক করে আবার চালানো (Catch), না হলে যাত্রা শেষ (Crash)।

* **Summary:** `try-catch` অ্যাপ ক্র্যাশ হতে দেয় না।

#### **Lesson 39: মাল্টি-থ্রেডিং এবং লক (Lock)**
* **Goal:** একসাথে অনেক কাজ করা এবং সংঘর্ষ এড়ানো।
* **Analogy:** ৪ লেনের রাস্তায় ৪টি গাড়ি একসাথে চলা। টোল প্লাজায় লাইন ধরা (Lock)।
* **Code:**
```csharp
object _lock = new();
lock(_lock) 
{
    // Critical code (Thread safe)
}
```

#### **Lesson 40: ডিপেন্ডেন্সি ইনজেকশন (DI) কনসেপ্ট**
* **Goal:** ক্লাসগুলোকে লুজলি কাপল্ড রাখা।
* **Analogy:** রিমোটের ব্যাটারি ফিক্সড না করে এমন করা যেন যেকোনো ব্র্যান্ডের ব্যাটারি লাগানো যায়।
* **Code:**
```csharp
class Car 
{
    private IEngine _engine;
    public Car(IEngine engine) { _engine = engine; } // DI via Constructor
}
```
