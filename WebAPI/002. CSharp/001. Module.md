### **Lesson 1: সেটআপ এবং হ্যালো ওয়ার্ল্ড**

*   **Learning Goal:** পিসিতে কোড রান করার ব্যবস্থা করা এবং জীবনের প্রথম প্রোগ্রাম লেখা।
*   **Simple Explanation:** ক্রিকেট খেলার আগে যেমন ব্যাট-প্যাড রেডি করতে হয়, কোডিংয়ের জন্য `.NET SDK` আর `VS Code` (বা Visual Studio) লাগে। আমরা `Console.WriteLine` দিয়ে কম্পিউটারকে কথা বলাব।
*   **Funny Real-life Analogy:**
    নতুন সিম কিনলে যেমন প্রথম কাজ "Hello" বলে চেক করা লাইন ঠিক আছে কিনা, প্রোগ্রামিংয়েও তাই। "Hello World" প্রিন্ট করা মানে সিম অ্যাক্টিভ! 📞
*   **Code Example:**
    (C# 14 এ আমরা Top-level statements ব্যবহার করি, তাই `class Program` বা `void Main` না লিখলেও চলে!)
    ```csharp
    // Program.cs
    Console.WriteLine("Assalamu Alaikum, C# 14!");
    Console.WriteLine("Ami code likhte pari!");
    ```
*   **File / Project Structure:**
    ```
    MyFirstApp/
    ├── MyFirstApp.csproj
    └── Program.cs  <-- আমরা এখানে কোড লিখব
    ```
*   **Mini Exercise:** তোমার নাম এবং প্রিয় খাবারের নাম প্রিন্ট করো।
*   **Common Mistakes:** সেমিকোলন `;` না দেওয়া। (এটা ভাতের পাতে লবণের মতো, না দিলে এরর খাবে)।
*   **One-line Summary:** `Console.WriteLine` কমান্ড দিয়ে স্ক্রিনে লেখা প্রিন্ট করে।

### **Lesson 2: ভ্যারিয়েবল (Variables) - ডেটার টিফিন বক্স**

*   **Learning Goal:** মেমোরিতে ডেটা সেভ করে রাখা।
*   **Simple Explanation:** ভ্যারিয়েবল হলো মেমোরির ছোট ছোট বক্স। একেক বক্সে একেক জিনিস রাখা যায়।
    *   `int` = পূর্ণসংখ্যা (1, 2, 100)
    *   `string` = লেখা ("Rahim", "Dhaka")
    *   `bool` = সত্য/মিথ্যা (true, false)
    *   `double` = দশমিক (12.5, 99.99)
*   **Funny Real-life Analogy:**
    রান্নাঘরে যেমন চালের বয়ামে ডাল রাখা যায় না, কোডেও `int` এর বয়ামে নাম (string) রাখা যায় না। বয়ামের গায়ে লেবেল লাগাতে হয়। 🫙
*   **Code Example:**
    ```csharp
    int age = 25;                  // পূর্ণসংখ্যা
    string name = "Rahim Kudus";   // টেক্সট
    bool isHungry = true;          // হ্যাঁ/না
    double teaPrice = 12.5;        // দশমিক

    // $ চিহ্ন দিয়ে ভ্যারিয়েবল টেক্সটের ভেতর ঢুকানো যায় (String Interpolation)
    Console.WriteLine($"Name: {name}, Age: {age}"); 
    ```
*   **Mini Exercise:** নিজের উচ্চতা (double) এবং তুমি ছাত্র কি না (bool) ভ্যারিয়েবলে রেখে প্রিন্ট করো।
*   **Common Mistakes:** `int` এর মধ্যে `12.5` রাখা (দশমিকের জন্য `double` বা `decimal` লাগে)।
*   **One-line Summary:** ভ্যারিয়েবল হলো ডেটা স্টোর করার নির্দিষ্ট পাত্র।

### **Lesson 3: স্ট্রিং নিয়ে নাড়াচাড়া (String Operations)**

*   **Learning Goal:** টেক্সট বা লেখা জোড়া লাগানো এবং সাইজ করা।
*   **Simple Explanation:** স্ট্রিং যোগ করা (`+`), সব বড় হাতের করা (`ToUpper`), বা ছোট হাতের করা (`ToLower`)।
*   **Funny Real-life Analogy:**
    দরদাম করার সময় যেমন আমরা কথা ঘুরিয়ে পেঁচিয়ে বলি, স্ট্রিং মেথড দিয়ে লেখাকে মডিফাই করা হয়। "আমি" + "ভাত খাই" = "আমি ভাত খাই"।
*   **Code Example:**
    ```csharp
    string fName = "Abul";
    string lName = "Hasan";
    
    // জোড়া লাগানো (Concatenation)
    string fullName = fName + " " + lName; 
    
    // সব বড় হাতের করা (Shouting!)
    string shout = fullName.ToUpper(); 

    Console.WriteLine(shout); // Output: ABUL HASAN
    ```
*   **Mini Exercise:** তোমার নাম সব ছোট হাতের (LowerCase) করে প্রিন্ট করো।
*   **Common Mistakes:** স্ট্রিং যোগ করার সময় মাঝখানের স্পেস `" "` দিতে ভুলে যাওয়া।
*   **One-line Summary:** স্ট্রিং ম্যানিপুলেশন দিয়ে টেক্সট ফরম্যাট ও এডিট করা হয়।

### **Lesson 4: অংক এবং লজিক (Operators)**

*   **Learning Goal:** যোগ, বিয়োগ, গুণ, ভাগ এবং তুলনা করা।
*   **Simple Explanation:**
    *   অংক: `+`, `-`, `*` (গুণ), `/` (ভাগ), `%` (ভাগশেষ)।
    *   তুলনা: `==` (সমান?), `>` (বড়?), `<` (ছোট?)।
*   **Funny Real-life Analogy:**
    দোকানদার যেমন হিসাব করে বাকি টাকা ফেরত দেয় (Math), আর পুলিশ যেমন চেক করে তোমার বয়স ১৮ এর বেশি কি না (Logic)। 🧮
*   **Code Example:**
    ```csharp
    int a = 10;
    int b = 3;

    Console.WriteLine(a + b); // 13
    Console.WriteLine(a * b); // 30
    Console.WriteLine(a % b); // 1 (ভাগশেষ বা Remainder)

    bool isAdult = a > 18; // 10 কি 18 এর চেয়ে বড়? না।
    Console.WriteLine(isAdult); // False
    ```
*   **Mini Exercise:** ১০০ টাকার নোট দিয়ে ৩৫ টাকার চা খেলে কত থাকে, কোড করে বের করো।
*   **One-line Summary:** অপারেটর দিয়ে ক্যালকুলেশন আর তুলনা (Comparison) করা হয়।

### **Lesson 5: সিদ্ধান্ত নেওয়া (If/Else)**

*   **Learning Goal:** শর্ত সাপেক্ষে কোড রান করা।
*   **Simple Explanation:** "যদি" বৃষ্টি হয় তবে ছাতা নিব, "নাহলে" নিব না। এটাই `if-else`। কম্পিউটার নিজে সিদ্ধান্ত নিতে পারে না, আমাদের বলে দিতে হয়।
*   **Funny Real-life Analogy:**
    পকেটে ২০০ টাকা থাকলে কাচ্চি খাব (if), না থাকলে সিঙ্গারা (else)। 🍛 vs 🥟
*   **Code Example:**
    ```csharp
    int pocketMoney = 50;

    if (pocketMoney >= 200)
    {
        Console.WriteLine("Kacchi Biriyani Khabo!");
    }
    else if (pocketMoney >= 50)
    {
        Console.WriteLine("Chicken Burger Khabo.");
    }
    else 
    {
        Console.WriteLine("Pani khabo ar basay jabo.");
    }
    ```
*   **Mini Exercise:** একটা নাম্বারের ভ্যারিয়েবল নাও, সেটা পজিটিভ (Positive) না নেগেটিভ (Negative) তা `if-else` দিয়ে চেক করো।
*   **Common Mistakes:** `if` এর কন্ডিশনের পর সেমিকোলন `;` দিয়ে ফেলা (এটা দেওয়া যাবে না)।
*   **One-line Summary:** `if-else` দিয়ে কোডের ফ্লো বা প্রবাহ কন্ট্রোল করা হয়।

### **✅ Milestone 1: Solved Exercise (Lessons 1-5)**

**Question:**
এমন একটা প্রোগ্রাম লেখো যা:
১. তোমার জন্মসাল (Birth Year) ইনপুট হিসেবে নেবে (ভ্যারিয়েবলে হার্ডকোড করো)।
২. তোমার বর্তমান বয়স বের করবে।
৩. তুমি "Voter" কি না তা জানাবে (বয়স ১৮ বা তার বেশি হতে হবে)।

**Solution:**
```csharp
// Program.cs

// 1. Input Data
int birthYear = 2005;
int currentYear = 2025;

// 2. Logic (Calculation)
int age = currentYear - birthYear;

Console.WriteLine($"Apnar boyos: {age}");

// 3. Decision
if (age >= 18)
{
    Console.WriteLine("Congratulation! Apni Vote dite parben.");
}
else
{
    Console.WriteLine("Sorry! Ekhon basay giye porashona koren.");
}
```
