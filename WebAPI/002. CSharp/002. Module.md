### **Lesson 6: একই কাজ বারবার (Loops)**

*   **Learning Goal:** কোড কপি-পেস্ট না করে রিপিট করা।
*   **Simple Explanation:** লুপ হলো এমন একটা মেশিন, যাকে বলে দিবেন "কাজটা ৫ বার করো", সে ঠিক ৫ বারই করবে।
    *   `for` loop: যখন জানো কতবার করতে হবে (যেমন: ১০ বার)।
    *   `while` loop: যতক্ষণ শর্ত পূরণ না হয় (যেমন: বৃষ্টি না থামা পর্যন্ত)।
*   **Funny Real-life Analogy:**
    ছোটবেলায় টিচার যখন শাস্তি দিত—"আমি আর দুষ্টামি করব না"—বোর্ডে ১০০ বার লেখ! ওটাই লুপ। অথবা রিকশাওয়ালা মামা যতক্ষণ প্যাডেল মারেন (Loop), ততক্ষণ রিকশা চলে। 🚲
*   **Code Example:**
    ```csharp
    // For Loop: i শুরু হবে ১ থেকে, চলবে ৫ পর্যন্ত, প্রতিবার ১ বাড়বে (i++)
    for(int i = 1; i <= 5; i++)
    {
        Console.WriteLine($"Rickshaw mama jore chalao: {i}");
    }

    // While Loop
    int power = 10;
    while(power > 0)
    {
        Console.WriteLine($"Mobile cholche... Charge: {power}%");
        power = power - 2; // চার্জ কমছে
    }
    ```
*   **Mini Exercise:** ১ থেকে ২০ এর মধ্যে যত বিজোড় সংখ্যা (Odd numbers) আছে, সব প্রিন্ট করো।
*   **Common Mistakes:** লুপের শর্ত ভুল দেওয়া, যার ফলে লুপ আর থামে না (Infinite Loop)। পিসি হ্যাং করতে পারে!
*   **One-line Summary:** লুপ দিয়ে রিপিটেটিভ কাজ অটোমেট করা হয়।

### **Lesson 7: অ্যারে (Arrays) - ফিক্সড তাক**

*   **Learning Goal:** অনেকগুলো ডেটা একসাথে রাখা (কিন্তু সাইজ ফিক্সড)।
*   **Simple Explanation:** অ্যারে হলো ট্রেনের বগির মতো। আগেই ঠিক করা থাকে কয়টা সিট আছে। সিট বাড়াতে বা কমাতে পারবে না।
    *   প্রথম ডেটা থাকে `0` নাম্বার পজিশনে (ইনডেক্স)।
*   **Funny Real-life Analogy:**
    ডিমের কেস (Egg Tray)। 🥚 এক ডজন ডিমের কেসে ১২টাই রাখা যাবে। জোর করে ১৩টা রাখতে গেলে ভেঙে যাবে (Error)।
*   **Code Example:**
    ```csharp
    // ৩ জন বন্ধুর নাম রাখব
    string[] friends = new string[3]; 
    friends[0] = "Raju";
    friends[1] = "Mina";
    friends[2] = "Mithu";

    // অথবা ডাইরেক্ট রাখা যায়
    int[] marks = { 80, 95, 33 };

    Console.WriteLine(friends[0]); // Raju
    Console.WriteLine(marks[1]);   // 95
    ```
*   **Mini Exercise:** ৫টা ফলের নাম অ্যারেতে রাখো। তারপর ৩ নাম্বার ফলটা প্রিন্ট করো (মনে রেখো ইনডেক্স ২ হবে)।
*   **One-line Summary:** অ্যারে ফিক্সড সাইজের কালেকশন, মেমোরি ফিক্সড রাখে।

### **Lesson 8: লিস্ট (List`<T>) - রাবার ব্যান্ড**

*   **Learning Goal:** ডাইনামিক কালেকশন (যত খুশি ডেটা রাখা)।
*   **Simple Explanation:** অ্যারের সমস্যা হলো সাইজ ফিক্সড। কিন্তু `List` রাবারের মতো, ডেটা ঢুকালে বড় হয়, বের করলে ছোট হয়। রিয়েল লাইফে আমরা অ্যারের চেয়ে লিস্ট বেশি ব্যবহার করি।
*   **Funny Real-life Analogy:**
    বাজারের ব্যাগ। 🛍️ প্রথমে খালি থাকে। আলু কিনলে ভরে, পেঁয়াজ কিনলে আরও ভরে। যত কিনবে ব্যাগ তত ফুলবে।
*   **Code Example:**
    ```csharp
    // C# 14 style 'new()'
    List<string> shoppingList = new(); 

    shoppingList.Add("Alu");
    shoppingList.Add("Peyaj");
    shoppingList.Add("Morich");
    
    shoppingList.Remove("Alu"); // আলু বাদ

    // লুপ চালিয়ে লিস্ট দেখা (foreach লুপ লিস্টের জন্য সেরা)
    foreach(string item in shoppingList)
    {
        Console.WriteLine($"Kinte hobe: {item}");
    }
    ```
*   **Mini Exercise:** ৩ জন গেস্টের নামের লিস্ট বানাও। পরে আরেকজন গেস্ট `.Add()` করো। শেষে `Count` প্রিন্ট করে দেখো মোট কয়জন হলো।
*   **One-line Summary:** `List<T>` হলো ডাইনামিক অ্যারে, যা ছোট-বড় হতে পারে।

### **Lesson 9: ডিকশনারি (Dictionary<K,V>) - খোঁজার ওস্তাদ**

*   **Learning Goal:** Key-Value পেয়ারে ডেটা রাখা (দ্রুত খোঁজার জন্য)।
*   **Simple Explanation:** লিস্টে ডেটা খুঁজতে হলে শুরু থেকে চেক করতে হয়। কিন্তু ডিকশনারিতে একটা "কী" (Key) দিয়ে সার্চ দিলেই সাথে সাথে ভ্যালু পাওয়া যায়।
*   **Funny Real-life Analogy:**
    হোটেলের মেনু কার্ড। 🍕
    তুমি ওয়েটারকে বলো "বার্গার" (Key), সে বলে দেয় "১৫০ টাকা" (Value)। পুরো মেনু মুখস্থ করা লাগে না।
*   **Code Example:**
    ```csharp
    Dictionary<string, int> prices = new();

    prices.Add("Burger", 150);
    prices.Add("Pizza", 400);
    prices.Add("Cha", 10);

    // দাম জানা দরকার
    Console.WriteLine(prices["Pizza"]); // Output: 400
    ```
*   **Mini Exercise:** `Phonebook` নামে একটা ডিকশনারি বানাও। বন্ধুর নাম (Key) আর মোবাইল নাম্বার (Value) রাখো। এরপর নাম দিয়ে নাম্বার প্রিন্ট করো।
*   **Common Mistakes:** একই Key দুইবার এড করা (যেমন "Burger" দুইবার এড করলে এরর খাবে)।
*   **One-line Summary:** ডিকশনারি দিয়ে ফাস্ট লুক-আপ (Search) করা যায়।

### **Lesson 10: মেথড বা ফাংশন (Methods) - কাজের মেশিন**

*   **Learning Goal:** কোড রি-ইউজ করা (একবার লিখব, বারবার ব্যবহার করব)।
*   **Simple Explanation:** একটা কাজ বারবার না লিখে একটা মেথড বানিয়ে রাখা এবং দরকার হলে নাম ধরে ডাকা।
    *   `void`: কিছু ফেরত দেয় না (শুধু কাজ করে)।
    *   `return`: কাজ শেষে কিছু ফেরত দেয় (যেমন যোগফল)।
*   **Funny Real-life Analogy:**
    জুস ব্লেন্ডার মেশিন। 🍹
    তুমি ফল দাও (Input/Parameter), মেশিন ঘুরছে (Process), আর জুস বের হচ্ছে (Return)। মেশিনটা একবার কিনলে হাজারবার জুস বানানো যায়।
*   **Code Example:**
    ```csharp
    // মেথড বানালাম (Top level statement এ মেথড নিচে থাকে)
    void MakeTea(int cups)
    {
        Console.WriteLine("Pani gorom korchi...");
        Console.WriteLine($"{cups} cup cha ready!");
    }

    int Add(int a, int b)
    {
        return a + b; // যোগফল ফেরত দিচ্ছে
    }

    // মেথড কল করলাম
    MakeTea(2); 
    MakeTea(5); 

    int sum = Add(10, 20);
    Console.WriteLine($"Jogfol: {sum}");
    ```
*   **Mini Exercise:** `GetDiscountPrice` নামে মেথড লেখো যা মূল দাম (int price) নিবে এবং ১০ টাকা কমিয়ে রিটার্ন করবে।
*   **One-line Summary:** মেথড কোডকে ছোট, সুন্দর এবং অর্গানাইজড রাখে।
