### **Lesson 21: রেকর্ডস (Records) - C# এর সুপারহিরো**

*   **Learning Goal:** ডেটা মডেল তৈরির জন্য ক্লাসের চেয়ে ভালো ও মডার্ন উপায় শেখা।
*   **Simple Explanation:** `record` হলো এক বিশেষ ধরণের ক্লাস যা মূলত **ডেটা** রাখার জন্য বানানো। এর বিশেষত্ব হলো এটা **Immutable** (অপরিবর্তনযোগ্য) এবং **Value-based Equality** মেনে চলে।
    *   *Immutable:* একবার বানালে আর চেঞ্জ করা যায় না (বাই ডিফল্ট)।
    *   *Equality:* দুইটা আলাদা ক্লাসের অবজেক্টে একই ডেটা থাকলেও তারা সমান হয় না, কিন্তু রেকর্ডে ডেটা সেম হলে তারা সমান।
*   **Funny Real-life Analogy:**
    *   **Class:** হোয়াইটবোর্ড। লেখা যায়, মোছা যায়, চেঞ্জ করা যায়।
    *   **Record:** ল্যামিনেট করা আইডি কার্ড। একবার প্রিন্ট হয়ে গেলে আর নাম-ধাম চেঞ্জ করা যায় না। যদি চেঞ্জ করতে হয়, নতুন কার্ড প্রিন্ট করতে হয়।
*   **Code Example:**
    ```csharp
    // Positional Record (এক লাইনে ক্লাস ডিক্লেয়ার!)
    public record Person(string Name, int Age);

    // Program.cs
    var p1 = new Person("Rahim", 25);
    var p2 = new Person("Rahim", 25);

    Console.WriteLine(p1 == p2); // True (Class হলে False আসত)

    // 'with' expression - কপি করে নতুন অবজেক্ট বানানো
    var p3 = p1 with { Age = 26 }; // নাম Rahim-ই থাকবে, বয়স ২৬ হবে
    Console.WriteLine(p3); // Output: Person { Name = Rahim, Age = 26 }
    ```
*   **Mini Exercise:** `Student` নামে একটা রেকর্ড বানাও (Name, GPA)। `with` ব্যবহার করে জিপিএ আপডেট করে নতুন স্টুডেন্ট বানাও।
*   **Common Mistakes:** রেকর্ডের প্রপার্টি `set` করার চেষ্টা করা (ইমিউটেবল তাই চেঞ্জ হবে না)।
*   **One-line Summary:** ডেটা ট্রান্সফারের জন্য `class` এর বদলে `record` ব্যবহার করা বেস্ট, কারণ এটা ফাস্ট এবং সেফ।

### **Lesson 22: নাল হ্যান্ডলিং (Nullable Types) - নাই মামার চেয়ে কানা মামা ভালো**

*   **Learning Goal:** `NullReferenceException` নামক প্রোগ্রামারের যমদূত থেকে বাঁচা।
*   **Simple Explanation:** C#-এ বাই ডিফল্ট কোনো অবজেক্টে `null` (কিছুই নাই) থাকলে এবং তুমি সেটা ব্যবহার করতে গেলে অ্যাপ ক্র্যাশ করে। মডার্ন C#-এ আমরা `?` দিয়ে বলে দিই কোনটা নাল হতে পারে।
*   **Funny Real-life Analogy:**
    টিফিন বক্স (Variable)।
    *   বক্স খুললে যদি খাবার না থাকে (Null), আর তুমি খেতে যাও—পেটে ব্যথা হবে (Exception/Crash)।
    *   তাই খাওয়ার আগে চেক করা "বক্সে খাবার আছে কি?"—এটাই নাল চেকিং।
*   **Code Example:**
    ```csharp
    string? name = null; // '?' মানে এতে null থাকতে পারে

    // 1. Safe Navigation (?.)
    // নাম থাকলে Length দিবে, না থাকলে null দিবে (ক্র্যাশ করবে না)
    int? length = name?.Length;

    // 2. Null Coalescing (??)
    // নাম না থাকলে ডিফল্ট ভ্যালু "Guest" ব্যবহার করবে
    string userName = name ?? "Guest"; 

    Console.WriteLine($"User: {userName}"); // Output: User: Guest
    ```
*   **Mini Exercise:** একটি `int? salary` ভ্যারিয়েবল নাও। যদি স্যালারি `null` হয়, তবে `0` প্রিন্ট করো `??` ব্যবহার করে।
*   **Common Mistakes:** `null` চেক না করেই প্রপার্টি বা মেথড কল করা।
*   **One-line Summary:** `?`, `??`, `?.` অপারেটরগুলো অ্যাপ ক্র্যাশ হওয়া থেকে বাঁচায়।

### **Lesson 23: প্যাটার্ন ম্যাচিং (Pattern Matching) - স্মার্ট চেকিং**

*   **Learning Goal:** `if-else` বা `switch` কে আরও স্মার্টলি লেখা।
*   **Simple Explanation:** আগে আমরা শুধু ভ্যালু চেক করতাম। এখন আমরা টাইপ এবং প্রপার্টি একসাথে চেক করতে পারি। `Switch Expression` কোডকে অনেক ছোট করে ফেলে।
*   **Funny Real-life Analogy:**
    সিকিউরিটি গার্ড আগে শুধু জিজ্ঞেস করত "নাম কী?"। এখন স্মার্ট গার্ড চেক করে—"আপনি কি ছাত্র? **এবং** আপনার কি আইডি কার্ড আছে? **এবং** কার্ডের মেয়াদ কি আছে?"—সব এক পলকে।
*   **Code Example:**
    ```csharp
    object obj = "Hello World";

    // Type Pattern Check
    if (obj is string s && s.Length > 5)
    {
        Console.WriteLine($"It's a long string: {s.ToUpper()}");
    }

    // Switch Expression (Modern Switch)
    int marks = 85;
    string result = marks switch
    {
        >= 80 => "A+",
        >= 70 => "A",
        >= 60 => "A-",
        _ => "F" // Default case
    };
    Console.WriteLine($"Result: {result}");
    ```
*   **Mini Exercise:** একটা `double temp` ভ্যারিয়েবল নাও। Switch Expression দিয়ে চেক করো: ৩০+ হলে "Hot", ২০-৩০ হলে "Good", ২০ এর নিচে হলে "Cold"।
*   **Common Mistakes:** Switch Expression এ `;` (সেমিকোলন) দিতে ভুলে যাওয়া।
*   **One-line Summary:** প্যাটার্ন ম্যাচিং এবং সুইচ এক্সপ্রেশন দিয়ে জটিল লজিক এক লাইনে লেখা যায়।

### **Lesson 24: জেনেরিক্স (Generics `<T>) - সব কাজের কাজি**

*   **Learning Goal:** এমন কোড লেখা যা যেকোনো ডেটা টাইপের সাথে কাজ করে।
*   **Simple Explanation:** তুমি যদি `int` এর জন্য একটা মেথড লেখো, পরে `string` এর জন্য আরেকটা—এভাবে কোড ডুপ্লিকেট হয়। জেনেরিক্স `<T>` ব্যবহার করলে এক কোড দিয়েই সব টাইপ হ্যান্ডেল করা যায়। `T` মানে "Type"।
*   **Funny Real-life Analogy:**
    জুসার বা ব্লেন্ডার মেশিন (Generic Class)। তুমি আম দিলে আমের জুস হবে, কমলা দিলে কমলার জুস। মেশিন একটাই, কিন্তু ইনপুট (T) যা দিবে, আউটপুট তাই পাবে।
*   **Code Example:**
    ```csharp
    // Generic Method
    public void PrintInfo<T>(T content)
    {
        Console.WriteLine($"Data: {content}, Type: {typeof(T)}");
    }

    // Generic Class
    public class Box<T>
    {
        public T Content;
        public Box(T content) => Content = content;
    }

    // Usage
    PrintInfo<int>(100);       // T becomes int
    PrintInfo<string>("Hello"); // T becomes string

    var intBox = new Box<int>(50);
    var strBox = new Box<string>("Secret Letter");
    ```
*   **Mini Exercise:** `SuperList<T>` নামে একটা ক্লাস বানাও যা একটা `Item` রাখবে। মেইনে `string` এবং `double` দিয়ে টেস্ট করো।
*   **One-line Summary:** `<T>` ব্যবহার করে টাইপ-সেফ এবং রি-ইউজেবল কোড লেখা হয় (যেমন `List<T>`)।

### **Lesson 25: এক্সেপশন হ্যান্ডলিং (Try-Catch) - দুর্ঘটনা এড়ানো**

*   **Learning Goal:** কোড ক্র্যাশ করলে সেটা সামাল দেওয়া এবং সুন্দর মেসেজ দেখানো।
*   **Simple Explanation:** প্রোগ্রাম চালানোর সময় যদি কোনো এরর হয় (যেমন: ০ দিয়ে ভাগ করা, ফাইল না পাওয়া), প্রোগ্রাম দপ করে বন্ধ হয়ে যায়। `try-catch` ব্লক ব্যবহার করলে প্রোগ্রাম বন্ধ না হয়ে এররটা ধরে ফেলে এবং কাজ চালিয়ে যায়।
*   **Funny Real-life Analogy:**
    রিকশা চালানোর সময় চেইন পড়ে যাওয়া (Exception)। চেইন পড়লে কি রিকশা ফেলে পালাও? না! চেইন ঠিক করে (Catch) আবার চালানো শুরু করো। আর গন্তব্যে পৌঁছে ভাড়া দেওয়া হলো `finally` (এরর হোক বা না হোক, এটা হবেই)।
*   **Code Example:**
    ```csharp
    try
    {
        int[] numbers = { 1, 2, 3 };
        Console.WriteLine(numbers[10]); // এই ইনডেক্স নাই! Error হবে।
    }
    catch (IndexOutOfRangeException ex)
    {
        Console.WriteLine("Mama, list er baire haat diyo na!");
    }
    catch (Exception ex) // যেকোনো এরর ধরবে
    {
        Console.WriteLine($"Opps! Error: {ex.Message}");
    }
    finally
    {
        Console.WriteLine("Code shesh, cholo cha khai."); // সব সময় রান হবে
    }
    ```
*   **Mini Exercise:** ইউজার থেকে ইনপুট নিয়ে সেটাকে নাম্বারে কনভার্ট করো (`int.Parse`). ইউজার যদি "abc" দেয়, তাহলে ক্র্যাশ না করে "Please enter numbers only" প্রিন্ট করো।
*   **Common Mistakes:** `catch` ব্লক খালি রাখা (এরর হলো কিন্তু কেউ জানল না, এটা খুব খারাপ)।
*   **One-line Summary:** `try-catch` তোমার অ্যাপকে আনএক্সপেক্টেড ক্র্যাশ থেকে রক্ষা করে।

### **✅ Milestone Exercise: The Generic Storage Box**

**Question:**
একটি `Storage<T>` ক্লাস বানাও।
1. একটি `_items` অ্যারে বা লিস্ট থাকবে (Generic)।
2. `Add(T item)` মেথড থাকবে।
3. `GetItem(int index)` মেথড থাকবে যা নির্দিষ্ট ইনডেক্সের আইটেম রিটার্ন করবে।
4. যদি ভুল ইনডেক্স দেওয়া হয় (try-catch ব্যবহার করো), তবে কাস্টম মেসেজ দেখাবে এবং ডিফল্ট ভ্যালু (`default`) রিটার্ন করবে।
5. মেইন প্রোগ্রামে `Storage<string>` এবং `Storage<int>` দিয়ে টেস্ট করো।

**Solution:**
```csharp
using System;
using System.Collections.Generic;

public class Storage<T>
{
    private List<T> _items = new();

    public void Add(T item)
    {
        _items.Add(item);
        Console.WriteLine($"Item added: {item}");
    }

    public T GetItem(int index)
    {
        try
        {
            return _items[index];
        }
        catch (ArgumentOutOfRangeException)
        {
            Console.WriteLine("Error: Bhul index diso mama! Default value dilam.");
            return default(T); // int হলে 0, string হলে null
        }
    }
}

class Program
{
    static void Main()
    {
        // String Storage
        Storage<string> nameBox = new Storage<string>();
        nameBox.Add("Rahim");
        nameBox.Add("Karim");
        Console.WriteLine(nameBox.GetItem(5)); // Error খাবে, কিন্তু ক্র্যাশ করবে না

        // Int Storage
        Storage<int> numberBox = new Storage<int>();
        numberBox.Add(100);
        Console.WriteLine($"Number: {numberBox.GetItem(0)}");
    }
}
```
