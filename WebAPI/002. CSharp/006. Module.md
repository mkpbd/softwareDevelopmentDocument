### **Lesson 26: ডেলিগেট (Delegates) - মেথডের বাহক**

*   **Learning Goal:** মেথডকে ভ্যারিয়েবলের মতো পাস করা এবং স্টোর করা।
*   **Simple Explanation:** ভ্যারিয়েবলে যেমন `int` বা `string` রাখা যায়, ডেলিগেটের মধ্যে **মেথড** রাখা যায়। তুমি একটা মেথডকে আরেকটা মেথডের কাছে প্যারামিটার হিসেবে পাঠাতে পারো।
*   **Funny Real-life Analogy:**
    বিয়ের কার্ডে লেখা থাকে "প্রেরক: ওমুক পরিবার", কিন্তু কার্ডটা দিয়ে আসে একজন পিয়ন বা বাহক। এই পিয়নই হলো **Delegate**। সে নিজে দাওয়াত দিচ্ছে না, সে শুধু মালিকের মেসেজটা বহন করছে।
*   **Code Example:**
    ```csharp
    // 1. ডেলিগেট ডিক্লেয়ার (সিগনেচার বা চেহারা কেমন হবে)
    public delegate void Messenger(string msg);

    class Program 
    {
        // 2. আসল মেথড
        static void ShowMessage(string m) 
        {
            Console.WriteLine($"Message received: {m}");
        }

        static void Main() 
        {
            // 3. মেথডকে ডেলিগেটের ভেতর ঢুকানো
            Messenger myMessenger = ShowMessage; 
            
            // 4. ডেলিগেট দিয়ে কল করা
            myMessenger("Hello via Delegate!"); 
        }
    }
    ```
*   **Mini Exercise:** `MathOp` নামে ডেলিগেট বানাও যা দুটি int নিবে এবং int রিটার্ন করবে। এরপর `Add` এবং `Multiply` মেথড এতে এসাইন করে রান করো।
*   **One-line Summary:** ডেলিগেট হলো মেথডের পয়েন্টার বা রেফারেন্স।

### **Lesson 27: ল্যাম্বডা এক্সপ্রেশন (Lambda =>) - শর্টকাট জাদুকর**

*   **Learning Goal:** নাম ছাড়া মেথড (Anonymous Method) এক লাইনে লেখা।
*   **Simple Explanation:** প্রতিবার ছোটখাটো কাজের জন্য আলাদা মেথড বানানো বিরক্তিকর। ল্যাম্বডা (`=>`) দিয়ে আমরা কোডের ভেতরেই চটজলদি ফাংশন লিখে ফেলতে পারি।
    *   `Func<>` হলো এমন ডেলিগেট যা ভ্যালু রিটার্ন করে।
    *   `Action<>` হলো এমন ডেলিগেট যা কিছু রিটার্ন করে না (void)।
*   **Funny Real-life Analogy:**
    চিঠি লেখা (Method) বনাম চিরকুট লেখা (Lambda)। "ভাত খেয়ে নিস"—এইটুকু বলার জন্য কি খাম-পোস্টকার্ড লাগে? না, একটা ছোট চিরকুটে লিখলেই হয়। ল্যাম্বডা হলো সেই চিরকুট।
*   **Code Example:**
    ```csharp
    // আগে আমরা এভাবে লিখতাম
    // int Square(int x) { return x * x; }

    // এখন এভাবে (Lambda)
    Func<int, int> square = x => x * x; 
    // ইনপুট x, মাঝখানে তীর (=>), আউটপুট x * x

    Console.WriteLine(square(5)); // Output: 25

    Action<string> greet = name => Console.WriteLine("Hi " + name);
    greet("Rahim");
    ```
*   **Mini Exercise:** একটা ল্যাম্বডা লেখো যা দুটি সংখ্যার যোগফল রিটার্ন করবে (`(a, b) => ...`)।
*   **One-line Summary:** `=>` চিহ্ন দিয়ে নাম ছাড়া ইনস্ট্যান্ট মেথড লেখা হয়।

### **Lesson 28: LINQ (Filtering - Where)**

*   **Learning Goal:** কালেকশন থেকে শর্ত সাপেক্ষে ডেটা বের করা।
*   **Simple Explanation:** `Where` মেথড দিয়ে আমরা ছাঁকনি (Filter) বসাই। লুপের বদলে এটা ব্যবহার করা অনেক স্মার্ট।
*   **Funny Real-life Analogy:**
    এক বস্তা চাল থেকে পাথর বাছা। তুমি একটা একটা করে চাল চেক করছ না (Loop), বরং একটা জাদুকরী ছাঁকনি (LINQ Where) দিচ্ছ যা শুধু ভালো চাল নিচে ফেলছে।
*   **Code Example:**
    ```csharp
    using System.Linq; // এটা অবশ্যই লাগবে

    List<int> numbers = new() { 10, 5, 20, 3, 40 };

    // যাদের ভ্যালু ১০ এর বেশি তাদের বের করো
    var bigNumbers = numbers.Where(n => n > 10).ToList();

    Console.WriteLine(string.Join(", ", bigNumbers)); 
    // Output: 20, 40
    ```
*   **Mini Exercise:** `names` নামে একটা স্ট্রিং লিস্ট নাও। যাদের নামের লেন্থ ৪ এর কম, তাদের আলাদা লিস্টে বের করো।
*   **Common Mistakes:** `.ToList()` না দিলে কোড এক্সিকিউট হয় না (এটাকে Deferred Execution বলে)। সাথে সাথে রেজাল্ট চাইলে `ToList` বা `ToArray` দিতে হবে।
*   **One-line Summary:** `Where` দিয়ে কন্ডিশন অনুযায়ী ডেটা ফিল্টার করা হয়।

### **Lesson 29: LINQ (Projection & Ordering)**

*   **Learning Goal:** ডেটা সাজানো (`OrderBy`) এবং রূপ পরিবর্তন করা (`Select`)।
*   **Simple Explanation:**
    *   **OrderBy:** ছোট থেকে বড় বা বড় থেকে ছোট সাজানো।
    *   **Select:** ডেটার আকার পরিবর্তন করা। যেমন পুরো `Student` অবজেক্ট থেকে শুধু `Name` টা নেওয়া।
*   **Funny Real-life Analogy:**
    *   **OrderBy:** স্কুলের এসেম্বলি লাইনে উচ্চতা অনুযায়ী দাঁড়ানো।
    *   **Select:** আম থেকে জুস বানানো। ইনপুট আম, আউটপুট জুস (রূপ চেঞ্জ)।
*   **Code Example:**
    ```csharp
    List<string> fruits = new() { "Banana", "Apple", "Mango", "Cherry" };

    // ১. নাম অনুযায়ী সাজাও (Alphabetical)
    // ২. সব নাম বড় হাতের (UpperCase) করো
    var result = fruits
                 .OrderBy(f => f)          // সাজানো হলো
                 .Select(f => f.ToUpper()) // রূপ চেঞ্জ (Projection)
                 .ToList();

    foreach (var item in result) Console.WriteLine(item);
    // Output: APPLE, BANANA, CHERRY, MANGO
    ```
*   **Mini Exercise:** কিছু নাম্বারের লিস্ট নাও। প্রথমে ছোট থেকে বড় সাজাও, তারপর সব নাম্বারকে দ্বিগুণ (x2) করে প্রিন্ট করো।
*   **One-line Summary:** `OrderBy` সর্ট করে, আর `Select` ডেটা ট্রান্সফর্ম বা ম্যাপ করে।

### **Lesson 30: এক্সটেনশন মেথড (Extension Methods)**

*   **Learning Goal:** অন্যের ক্লাসে নিজের মেথড জোড়া লাগানো।
*   **Simple Explanation:** ধরো `string` বা `int` ক্লাসটা মাইক্রোসফট বানিয়েছে, তুমি এডিট করতে পারবে না। কিন্তু তুমি চাইলে বাইরে থেকে এমন একটা মেথড বানাতে পারো যা দেখে মনে হবে ওটা `string` ক্লাসেরই মেথড!
*   **Funny Real-life Analogy:**
    কেনা গাড়িতে এক্সট্রা বাম্পার বা স্টিকার লাগানো। গাড়ি কোম্পানি এটা দেয়নি, কিন্তু তুমি বাইরে থেকে লাগিয়েছ এবং এটা গাড়ির অংশ হিসেবেই কাজ করছে।
*   **Code Example:**
    ```csharp
    // ১. স্ট্যাটিক ক্লাস হতে হবে
    public static class StringExtensions 
    {
        // ২. প্রথম প্যারামিটারে 'this' থাকতে হবে
        public static int WordCount(this string str)
        {
            return str.Split(' ').Length;
        }
    }

    // Program.cs
    string message = "I love C# Coding";
    // মনে হচ্ছে WordCount স্ট্রিংয়েরই মেথড!
    int count = message.WordCount(); 
    Console.WriteLine(count); // Output: 4
    ```
*   **Mini Exercise:** `int` এর জন্য `IsEven()` নামে একটা এক্সটেনশন মেথড বানাও যা জোড় হলে true দিবে। `10.IsEven()` দিয়ে টেস্ট করো।
*   **One-line Summary:** `this` কিওয়ার্ড দিয়ে এক্সিস্টিন ক্লাসে নতুন মেথড ইনজেক্ট করা যায়।

### **✅ Milestone Exercise: Student Report Card (LINQ Special)**

**Question:**
একটি `Student` রেকর্ড বানাও (Name, Marks)। ৫ জন ছাত্রের লিস্ট নাও।
LINQ ব্যবহার করে নিচের কাজগুলো করো (লুপ ব্যবহার করা যাবে না):
1. যারা পাশ করেছে (Marks >= 33) তাদের বের করো।
2. তাদের মার্কস অনুযায়ী সবচেয়ে বেশি থেকে কম (Descending) সাজাও।
3. তাদের নামের পাশে গ্রেড যোগ করে নতুন স্ট্রিং বানাও (Projection)। (যেমন: "Rahim: Passed")
4. ফাইনাল লিস্ট প্রিন্ট করো।

**Solution:**
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

// Record defined
public record Student(string Name, int Marks);

class Program
{
    static void Main()
    {
        List<Student> students = new()
        {
            new("Abul", 25),
            new("Babul", 80),
            new("Kabul", 45),
            new("Dabul", 95),
            new("Ebul", 30)
        };

        // LINQ Chain Magic 🪄
        var reportCard = students
            .Where(s => s.Marks >= 33)                // 1. Filter Passers
            .OrderByDescending(s => s.Marks)          // 2. Sort Top to Bottom
            .Select(s => $"{s.Name}: Passed ({s.Marks})") // 3. Project to String
            .ToList();

        // Print
        reportCard.ForEach(Console.WriteLine);
    }
}
```
*Output:*
```
Dabul: Passed (95)
Babul: Passed (80)
Kabul: Passed (45)
```
