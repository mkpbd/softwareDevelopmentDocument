### **Lesson 31: Async/Await (থিওরি) - মাল্টিটাস্কিং**

*   **Learning Goal:** অ্যাপ হ্যাং না করে সময়সাপেক্ষ কাজ (যেমন: ফাইল লোড, ইন্টারনেট কল) করা।
*   **Simple Explanation:**
    *   **Synchronous:** লাইনে দাঁড়িয়ে টিকেট কাটা। যতক্ষণ টিকেট না পাচ্ছ, অন্য কাজ করতে পারবে না।
    *   **Asynchronous:** টোকেন নিয়ে বসে থাকা। টোকেন নাম্বার ডাকলে (Await) কাউন্টারে যাবে, এর মধ্যে তুমি মোবাইলে গেম খেলতে পারো (UI Free)।
*   **Funny Real-life Analogy:**
    হোটেলে অর্ডার দেওয়া।
    *   **Sync:** ওয়েটার রান্নাঘরে গিয়ে দাঁড়িয়ে আছে খাবার হওয়া পর্যন্ত। সে অন্য টেবিলে অর্ডার নিতে পারছে না।
    *   **Async:** ওয়েটার অর্ডার কিচেনে দিয়ে অন্য কাজ করছে। খাবার হলে (Await) সে নিয়ে আসবে।
*   **Code Example:**
    ```csharp
    // মেথডের নামের শেষে Async লেখা ভালো প্র্যাকটিস
    async Task MakeTeaAsync() 
    {
        Console.WriteLine("Pani chulalay dilam...");
        
        // ২ সেকেন্ড অপেক্ষা, কিন্তু থ্রেড ব্লক হবে না
        await Task.Delay(2000); 
        
        Console.WriteLine("Cha Ready! ☕");
    }

    // Main Method
    Console.WriteLine("Kaj shuru...");
    await MakeTeaAsync(); // এখানে অপেক্ষা করবে, কিন্তু সিস্টেম ফ্রি থাকবে
    Console.WriteLine("Kaj shesh.");
    ```
*   **Mini Exercise:** একটা মেথড লেখো `DownloadFileAsync` যা প্রিন্ট করবে "Downloading...", ৩ সেকেন্ড ওয়েট করবে (`Task.Delay`), তারপর প্রিন্ট করবে "Download Complete".
*   **Common Mistakes:** `await` ছাড়া Async মেথড কল করা (তাহলে কাজ শেষ হওয়ার আগেই কোড সামনে চলে যাবে)।
*   **One-line Summary:** `async` এবং `await` ব্যবহার করলে ভারি কাজ চলার সময় অ্যাপ ফ্রি থাকে।

### **Lesson 32: Task এবং Task`<T> (রিটার্ন টাইপ)**

*   **Learning Goal:** Async মেথড থেকে ভ্যালু রিটার্ন করা।
*   **Simple Explanation:**
    *   সাধারণ মেথডে `void` থাকে, Async মেথডে `Task` ব্যবহার করতে হয় (যদি কিছু রিটার্ন না করে)।
    *   আর যদি কিছু রিটার্ন করে (যেমন `int`), তবে `Task<int>` লিখতে হয়।
*   **Funny Real-life Analogy:**
    *   **Task:** কাউকে বললাম "বাজার করে আনো"। সে কাজটা করবে, কিন্তু আমাকে হাতে কিছু দিবে না (হয়তো বাজারের ব্যাগে রেখে দিবে)।
    *   **Task`<T>:** কাউকে বললাম "দোকান থেকে ৫ টাকা ফেরত আনো"। সে কাজ শেষে আমাকে `int` (টাকা) ফেরত দিবে।
*   **Code Example:**
    ```csharp
    // কিছু রিটার্ন করবে না (void এর বিকল্প)
    async Task PrintNameAsync() 
    {
        await Task.Delay(500);
        Console.WriteLine("My Name is Bond.");
    }

    // int রিটার্ন করবে
    async Task<int> GetSalaryAsync()
    {
        await Task.Delay(1000); // স্যালারি হিসাব হচ্ছে...
        return 50000; // Task এর মধ্যে মুড়িয়ে int রিটার্ন হবে
    }

    // Usage
    await PrintNameAsync();
    int salary = await GetSalaryAsync(); // await বাক্স খুলে int বের করে দিবে
    Console.WriteLine($"Salary: {salary}");
    ```
*   **Mini Exercise:** `GetTemperatureAsync` নামে একটা মেথড লেখো যা `Task<double>` রিটার্ন করবে (ভ্যালু ৩৫.৫)। মেইন মেথডে সেটা প্রিন্ট করো।
*   **Common Mistakes:** Async মেথডে `void` ব্যবহার করা (ইভেন্ট হ্যান্ডলার ছাড়া এটা করা নিষেধ, কারণ এরর হলে ধরা যায় না)।
*   **One-line Summary:** কিছু রিটার্ন না করলে `Task`, আর করলে `Task<DataType>`।

### **Lesson 33: ফাইল রিড/রাইট (File I/O) - ডিজিটাল ডায়েরি**

*   **Learning Goal:** হার্ডডিস্কে ফাইল তৈরি করা এবং পড়া (অ্যাসিনক্রোনাসলি)।
*   **Simple Explanation:** `System.IO` নেমস্পেস দিয়ে আমরা টেক্সট ফাইল বানাতে বা পড়তে পারি। `...Async` মেথডগুলো ব্যবহার করলে বড় ফাইল রিড করার সময় অ্যাপ হ্যাং হবে না।
*   **Analogy:** পরীক্ষার খাতায় লেখা (Write) এবং পরে রিভিশন দেওয়া (Read)।
*   **Code Example:**
    ```csharp
    string fileName = "secret_note.txt";
    string secretMessage = "Agami kal brihaspatibar!";

    // ফাইল লেখা (আগে থাকলে ওভাররাইট করবে)
    await File.WriteAllTextAsync(fileName, secretMessage);
    Console.WriteLine("Note lekha shesh.");

    // ফাইল পড়া
    if (File.Exists(fileName))
    {
        string content = await File.ReadAllTextAsync(fileName);
        Console.WriteLine($"Secret: {content}");
    }
    ```
*   **File Structure:** কোড রান করলে `bin/Debug/net8.0/` ফোল্ডারে ফাইলটি তৈরি হবে।
*   **Mini Exercise:** তোমার ৩ জন বন্ধুর নাম একটা ফাইলে সেভ করো, তারপর ফাইল থেকে পড়ে কনসোলে দেখাও।
*   **One-line Summary:** `File.WriteAllTextAsync` এবং `File.ReadAllTextAsync` দিয়ে ফাইল হ্যান্ডেল করা সহজ।

### **Lesson 34: JSON সিরিয়ালাইজেশন - ডেটার পার্সেল**

*   **Learning Goal:** C# অবজেক্টকে টেক্সট ফরম্যাটে (JSON) কনভার্ট করা এবং ব্যাক করা।
*   **Simple Explanation:** ইন্টারনেট বা ফাইলে আমরা সরাসরি C# অবজেক্ট (`new Person...`) পাঠাতে পারি না। আমাদের এটাকে স্ট্রিং বানাতে হয়। এই ফরম্যাটকে বলে JSON।
    *   **Serialize:** Object -> JSON String (প্যাকেট করা)
    *   **Deserialize:** JSON String -> Object (প্যাকেট খোলা)
*   **Funny Real-life Analogy:**
    বাসা বদলানোর সময় খাট-আলমারি খুলে বক্সে ভরা (Serialize)। নতুন বাসায় গিয়ে বক্স খুলে আবার খাট ফিটিং করা (Deserialize)।
*   **Code Example:**
    ```csharp
    using System.Text.Json; // এটা লাগবে

    public record User(string Name, string Email);

    // 1. Object
    var user = new User("Rahim", "rahim@gmail.com");

    // 2. Serialize (Object to JSON)
    string jsonString = JsonSerializer.Serialize(user);
    Console.WriteLine($"JSON: {jsonString}"); 
    // Output: {"Name":"Rahim","Email":"rahim@gmail.com"}

    // 3. Deserialize (JSON to Object)
    var user2 = JsonSerializer.Deserialize<User>(jsonString);
    Console.WriteLine($"Name: {user2.Name}");
    ```
*   **Mini Exercise:** `Product` (Name, Price) ক্লাস বানাও। একটা প্রোডাক্ট অবজেক্ট বানিয়ে সেটাকে JSON এ কনভার্ট করে প্রিন্ট করো।
*   **One-line Summary:** JSON হলো ওয়েব এবং অ্যাপের ইউনিভার্সাল ভাষা।

### **Lesson 35: HttpClient (API Call) - ইন্টারনেটের সাথে কথা**

*   **Learning Goal:** অন্য ওয়েবসাইট বা সার্ভার থেকে ডেটা আনা।
*   **Simple Explanation:** `HttpClient` হলো তোমার ব্রাউজারের মতো। এটা দিয়ে আমরা কোডের মাধ্যমে কোনো URL এ রিকোয়েস্ট পাঠাতে পারি এবং ডেটা আনতে পারি।
*   **Funny Real-life Analogy:**
    ফুডপান্ডায় অর্ডার করা। তুমি অ্যাপে রিকোয়েস্ট পাঠালে, সার্ভার প্রসেস করে তোমাকে কনফার্মেশন (Response) পাঠাল।
*   **Code Example:**
    ```csharp
    // ভালো প্র্যাকটিস: HttpClient বারবার new না করে একবার করা (Singleton)
    using HttpClient client = new HttpClient();

    try 
    {
        // একটা ডামি API থেকে ডেটা আনা
        string url = "https://jsonplaceholder.typicode.com/posts/1";
        string response = await client.GetStringAsync(url);
        
        Console.WriteLine("Data esheche!");
        Console.WriteLine(response); // JSON ডেটা দেখাবে
    }
    catch(Exception ex)
    {
        Console.WriteLine("Internet nai naki mama? " + ex.Message);
    }
    ```
*   **Mini Exercise:** উপরের কোডটি রান করো এবং দেখো কনসোলে কী আসে। (ইন্টারনেট কানেকশন লাগবে)।
*   **Common Mistakes:** `HttpClient` ডিসপোজ বা ক্লোজ করার পর আবার ব্যবহার করার চেষ্টা করা।
*   **One-line Summary:** `HttpClient` দিয়ে আমরা রেস্ট এপিআই (REST API) কল করি।

### **✅ Milestone Exercise: Weather Report Simulator**

**Question:**
এমন একটি কনসোল অ্যাপ বানাও যা:
1. একটি ফেক ওয়েদার ডেটা (JSON String হিসেবে) মেমোরিতে রাখবে।
2. ২ সেকেন্ড সময় নিয়ে (Simulate Download) সেই ডেটা "ডাউনলোড" করবে।
3. ডাউনলোড হওয়া JSON কে `WeatherInfo` ক্লাসে কনভার্ট (Deserialize) করবে।
4. কনভার্ট হওয়া ডেটা একটি টেক্সট ফাইলে `weather.txt` নামে সেভ করবে।

**Solution:**
```csharp
using System;
using System.IO;
using System.Threading.Tasks;
using System.Text.Json;

// 1. Model
public record WeatherInfo(string City, double Temp, string Condition);

class Program
{
    static async Task Main()
    {
        Console.WriteLine("Fetching Weather Data...");

        // 2. Simulate API Call & Download
        string jsonData = await FakeDownloadAsync();
        Console.WriteLine($"Downloaded JSON: {jsonData}");

        // 3. Deserialize
        WeatherInfo info = JsonSerializer.Deserialize<WeatherInfo>(jsonData);
        
        string report = $"City: {info.City}\nTemperature: {info.Temp}C\nCondition: {info.Condition}";
        
        // 4. Save to File
        await File.WriteAllTextAsync("weather.txt", report);
        
        Console.WriteLine("Report saved to 'weather.txt' successfully!");
    }

    // ফেক ডাউনলোড মেথড
    static async Task<string> FakeDownloadAsync()
    {
        await Task.Delay(2000); // ২ সেকেন্ড ওয়েট
        // মনে করি সার্ভার এই JSON পাঠিয়েছে
        return "{\"City\": \"Dhaka\", \"Temp\": 32.5, \"Condition\": \"Sunny\"}";
    }
}
```
