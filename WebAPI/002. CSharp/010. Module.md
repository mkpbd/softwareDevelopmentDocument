### **Lesson 46: Todo অ্যাপ রিফ্যাক্টরিং (Layered Style)**

*   **Learning Goal:** আমাদের আগের অগোছালো কোডকে সুন্দর করে লেয়ারে ভাগ করা।
*   **Simple Explanation:** এতদিন আমরা `Program.cs` এ সব কোড লিখতাম। এখন আমরা সেটাকে তিন ভাগে ভাগ করব:
    1.  **Core:** শুধু মডেল (TodoItem)।
    2.  **Data:** ডেটা সেভ/লোডের দায়িত্ব।
    3.  **UI:** ইউজারের সাথে কথা বলা।
*   **Analogy:** একটা রেস্টুরেন্ট ম্যানেজ করা। শেফ (Data) রান্নাঘরে, ম্যানেজার (Service) তদারকিতে, আর ওয়েটার (UI) কাস্টমারের সামনে। সবাই এক রুমে থাকলে জগাখিচুড়ি হবে!
*   **File Structure:**
    ```
    FinalProject/
    ├── Core/
    │   └── TodoItem.cs
    ├── Data/
    │   └── TodoRepository.cs
    └── Program.cs (UI)
    ```
*   **Code Example:**
    ```csharp
    // 1. Core/TodoItem.cs
    public class TodoItem
    {
        public int Id { get; set; }
        public string Title { get; set; }
        public bool IsDone { get; set; }
    }

    // 2. Data/TodoRepository.cs
    public class TodoRepository
    {
        private List<TodoItem> _db = new(); // মেমোরি ডাটাবেস

        public void Add(string title)
        {
            int nextId = _db.Count + 1;
            _db.Add(new TodoItem { Id = nextId, Title = title, IsDone = false });
        }

        public List<TodoItem> GetAll() => _db;
    }

    // 3. Program.cs (UI)
    var repo = new TodoRepository();
    repo.Add("Learn C#");
    repo.Add("Build Project");

    foreach(var item in repo.GetAll())
    {
        Console.WriteLine($"{item.Id}. {item.Title}");
    }
    ```
*   **Summary:** লজিক আলাদা ফাইলে থাকলে কোড ক্লিন থাকে এবং বড় প্রজেক্ট সামলানো সহজ হয়।

### **Lesson 47: ডেটাবেস মকিং এবং Async (Database Mocking)**

*   **Learning Goal:** রিয়েল ডাটাবেস এর মতো আচরণ (দেরি হওয়া) সিমুলেট করা।
*   **Simple Explanation:** ডাটাবেস থেকে ডেটা আসতে একটু সময় লাগে। আমরা `Task.Delay` ব্যবহার করে সেই সময়টা ভান (Mock) করব এবং মেথডগুলোকে `async` বানাব।
*   **Analogy:** ফ্রিজ থেকে খাবার বের করা (Sync - সাথে সাথে) বনাম ফুডপান্ডায় অর্ডার করা (Async - সময় লাগবে)। রিয়েল অ্যাপে ডাটাবেস ফুডপান্ডার মতো।
*   **Code Example:**
    ```csharp
    public class AsyncTodoRepository
    {
        private List<TodoItem> _db = new();

        // ডেটাবেসে সেভ হচ্ছে... একটু সময় লাগবে
        public async Task AddAsync(string title)
        {
            await Task.Delay(500); // 0.5s ডাটাবেস ল্যাটেন্সি
            _db.Add(new TodoItem { Title = title });
            Console.WriteLine("Saved to DB!");
        }

        public async Task<List<TodoItem>> GetAllAsync()
        {
            await Task.Delay(1000); // 1s সময় লাগছে ডেটা আনতে
            return _db;
        }
    }

    // Program.cs
    Console.WriteLine("Loading...");
    var repo = new AsyncTodoRepository();
    await repo.AddAsync("Buy Milk");
    
    var list = await repo.GetAllAsync();
    Console.WriteLine($"Total Items: {list.Count}");
    ```
*   **Mini Exercise:** `CompleteAsync(int id)` মেথড বানাও যা ১ সেকেন্ড দেরি করে কাজ সম্পন্ন হয়েছে দেখাবে।
*   **Summary:** রিয়েল ওয়ার্ল্ডে সব ডাটাবেস কল `async` হওয়া উচিত যাতে UI ফ্রিজ না হয়।

### **Lesson 48: ইন্টারপ (Interop) - অন্য জগতের সাথে কথা**

*   **Learning Goal:** C# থেকে উইন্ডোজের বা C++ এর নেটিভ কোড কল করা।
*   **Simple Explanation:** মাঝে মাঝে C# এর বাইরে গিয়ে অপারেটিং সিস্টেমের ফাংশন কল করতে হয়। এটাকে `P/Invoke` বা Interop বলে।
*   **Funny Analogy:** তুমি বাংলা জানো, কিন্তু জাপানিজ রেস্টুরেন্টে গিয়ে জাপানিজ ভাষায় অর্ডার দেওয়া (ট্রান্সলেটর ব্যবহার করে)।
*   **Code Example:**
    ```csharp
    using System.Runtime.InteropServices;

    class Program
    {
        // উইন্ডোজের user32.dll থেকে MessageBox ফাংশন ধার করছি
        [DllImport("user32.dll")]
        public static extern int MessageBox(IntPtr hWnd, string text, string caption, int type);

        static void Main()
        {
            // কনসোল অ্যাপ থেকেই পপ-আপ মেসেজ বক্স আসবে!
            MessageBox(IntPtr.Zero, "Hello from C# Interop!", "Magic", 0);
        }
    }
    ```
*   **Note:** এটা শুধু উইন্ডোজ মেশিনে কাজ করবে।
*   **Summary:** C# দিয়ে লো-লেভেল সিস্টেমের কাজও করা সম্ভব।

### **Lesson 49: মিনিমাল API (Web API Intro) - ওয়েবের দুনিয়ায়**

*   **Learning Goal:** কনসোল অ্যাপ ছেড়ে ওয়েবে পা রাখা। C# দিয়ে ব্যাকএন্ড সার্ভার বানানো।
*   **Simple Explanation:** কনসোল অ্যাপ শুধু তোমার পিসিতে চলে। কিন্তু API বানালে সারা দুনিয়া ব্রাউজার বা মোবাইল দিয়ে তোমার কোড এক্সেস করতে পারবে। C# 14/NET 8 এ মাত্র ৩-৪ লাইনে সার্ভার বানানো যায়!
*   **Analogy:**
    *   **Console App:** তোমার ডায়েরিতে লেখা নোট (শুধু তুমি দেখো)।
    *   **Web API:** নোটিশ বোর্ডে টাঙানো নোটিশ (সবাই দেখতে পারে)।
*   **Code Example:**
    *(নোট: এটার জন্য `ASP.NET Core Web API` টেমপ্লেট লাগে, তবে কোডটা দেখো কত সহজ)*
    ```csharp
    // Program.cs (পুরো ওয়েব সার্ভার!)
    var builder = WebApplication.CreateBuilder(args);
    var app = builder.Build();

    // ব্রাউজারে /hello হিট করলে এটা দেখাবে
    app.MapGet("/hello", () => "Assalamu Alaikum World!");

    // ডেটা রিটার্ন করা (JSON)
    app.MapGet("/todos", () => new [] { 
        new { Id = 1, Task = "Learn C#" },
        new { Id = 2, Task = "Build API" }
    });

    app.Run(); // সার্ভার স্টার্ট
    ```
*   **Impact:** এই কোড রান করে ব্রাউজারে `http://localhost:5000/todos` এ গেলে তুমি তোমার ডেটা দেখতে পাবে।
*   **Summary:** C# এখন ওয়েবের জন্যও সুপার পাওয়ারফুল।
