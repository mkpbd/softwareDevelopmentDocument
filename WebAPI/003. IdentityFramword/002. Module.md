## ***Phase 2: Registration & Login (Lesson 6-10)** - Sign Up API, Password Hashing, Login API, JWT Token জেনারেশন.


স্বাগতম মামা! 🎉
গত ক্লাসে আমরা সাকসেসফুলি ইউজার রেজিস্টার করেছি এবং পাসওয়ার্ড "শরবত" (Hash) বানিয়ে ডাটাবেসে রেখেছি।

আজকে আমরা সেই ইউজারকে **লগইন (Login)** করাব। তবে মনে রাখবে, API-তে লগইন মানে কিন্তু ব্রাউজারে হোম পেজে ঢুকে যাওয়া না। API-তে লগইন মানে হলো—**"তোমার পরিচয় সঠিক, এই নাও তোমার ডিজিটাল টিকিট (Token)"**।

আজকে আমরা টোকেন বানাব না, আজকে শুধু চেক করব—**"ইমেইল আর পাসওয়ার্ড সঠিক আছে কিনা"**।

### 🎓 Lesson 6: Login API & Credential Validation

লগইন প্রসেসটা আসলে দুইটা স্টেপে কাজ করে:
১. ইউজার যে ইমেইল দিয়েছে, সেটা ডাটাবেসে আছে তো?
২. ইমেইল থাকলে, সে যে পাসওয়ার্ড দিয়েছে, সেটা কি ডাটাবেসের হ্যাশ করা পাসওয়ার্ডের সাথে মেলে?

#### 🇧🇩 সহজ বাংলায় ব্যাখ্যা
আমরা যখন সাধারণ স্ট্রিং তুলনা করি, তখন `if ("abc" == "abc")` লিখি। কিন্তু পাসওয়ার্ডের ক্ষেত্রে এটা খাটে না। কারণ ডাটাবেসে আছে **Hash** (হিজিবিজি), আর ইউজার দিচ্ছে **Plain Text**।

এখানে `UserManager` আমাদের সাহায্য করবে। সে ইউজারের দেওয়া পাসওয়ার্ডকে আবার সেইম স্টাইলে হ্যাশ করবে এবং ডাটাবেসের হ্যাশের সাথে মিলিয়ে দেখবে।

#### 🤣 ফানি অ্যানালজি (তালা-চাবি)

ধরো, ব্যাংকে তোমার একটা **লকার (Account)** আছে।

১. **ইমেইল চেক:** তুমি ব্যাংকে গিয়ে লকার নাম্বার বললে। ম্যানেজার চেক করল—"এই নাম্বারে কি আদৌ কোনো লকার আছে?" (User Exist Check)।
২. **পাসওয়ার্ড চেক:** লকার থাকলে, তুমি তোমার পকেট থেকে **চাবি (Password)** বের করে দিলে। ম্যানেজার চাবিটা লকারের তালায় ঘুরিয়ে দেখল—তালা খোলে কিনা।
তুমি যদি ভুল চাবি দাও, ম্যানেজার কিন্তু বলবে না "চাবি ভুল"। সে বলবে—**"আপনার লকার নাম্বার অথবা চাবি ভুল"** (সিকিউরিটির খাতিরে আমরা স্পেসিফিক করে বলি না কোনটা ভুল)।

#### 💻 Coding Example

আজকেও আমরা দুইটা স্টেপে কাজ করব। প্রথমে `DTO` তারপর `Controller`।

**Step 1: LoginDto বানানো**
`DTOs` ফোল্ডারে `LoginDto.cs` নামে ফাইল বানাও। লগইন করতে শুধু ইমেইল আর পাসওয়ার্ড লাগে।

```csharp
using System.ComponentModel.DataAnnotations;

namespace AuthMasterClass.DTOs
{
    public class LoginDto
    {
        [Required]
        [EmailAddress]
        public string Email { get; set; }

        [Required]
        public string Password { get; set; }
    }
}
```

**Step 2: AccountController এ Login মেথড বানানো**
`AccountController.cs` ফাইলে `Register` মেথডের নিচে এই কোডটুকু লিখো।

```csharp
// Controllers/AccountController.cs

[HttpPost("login")]
public async Task<IActionResult> Login([FromBody] LoginDto loginDto)
{
    // ১. প্রথমেই চেক করি লকার (User) আছে কিনা
    var user = await _userManager.FindByEmailAsync(loginDto.Email);

    // যদি ইউজার না থাকে, তাহলে সাথে সাথে ভাগাও (Unauthorized)
    if (user == null)
    {
        // সিকিউরিটির জন্য আমরা বলব না "ইমেইল ভুল"। আমরা বলব "ইউজারনেম বা পাসওয়ার্ড ভুল"।
        // এতে হ্যাকার কনফিউজড থাকবে।
        return Unauthorized("Invalid Email or Password");
    }

    // ২. এবার চাবি (Password) মিলিয়ে দেখি
    // CheckPasswordAsync মেথড অটোমেটিক হ্যাশ চেক করে রেজাল্ট দিবে (True/False)
    var isPasswordValid = await _userManager.CheckPasswordAsync(user, loginDto.Password);

    if (!isPasswordValid)
    {
        return Unauthorized("Invalid Email or Password");
    }

    // ৩. সব ঠিক থাকলে
    // পরের ক্লাসে আমরা এখানে JWT Token জেনারেট করব।
    // আপাতত আমরা জাস্ট সাকসেস মেসেজ দিচ্ছি।
    
    return Ok(new 
    { 
        message = "লগইন সাকসেসফুল বস! কিন্তু টোকেন পাবেন পরের ক্লাসে।",
        email = user.Email,
        id = user.Id
    });
}
```

---

#### 🧠 লজিক ব্রেকডাউন
*   `_userManager.FindByEmailAsync(...)`: এটা ডাটাবেস খুঁজে ইউজার অবজেক্ট নিয়ে আসে।
*   `_userManager.CheckPasswordAsync(...)`: এটা দুইটা প্যারামিটার নেয়—(১) ডাটাবেস থেকে পাওয়া ইউজার, (২) ইনপুট দেওয়া পাসওয়ার্ড। সে নিজেই সল্ট ও হ্যাশ মিলিয়ে দেখে `bool` রিটার্ন করে।
*   `Unauthorized(...)`: এটা `401` স্ট্যাটাস কোড রিটার্ন করে। মানে—"তোমার ঢোকার অনুমতি নাই"।

### 🎓 Lesson 7: JWT (JSON Web Token) - ডিজিটাল টিকিট

JWT হলো এমন একটা লম্বা স্ট্রিং (String), যার ভেতরে এনক্রিপ্ট করা অবস্থায় লেখা থাকে—ইউজার কে, তার রোল কি, এবং এই টিকিটের মেয়াদ কতক্ষণ।

#### 🇧🇩 সহজ বাংলায় ব্যাখ্যা
সাধারণ ওয়েবসাইটে সেশন (Session) ব্যবহার করা হয়, কিন্তু API-তে সেশন চলে না। API-তে আমরা **Token** ব্যবহার করি।
সার্ভার ইউজারকে একটা টোকেন বানিয়ে দেয়। এরপর ইউজার যেখানেই যায়, ওই টোকেন পকেটে নিয়ে যায়। সার্ভার শুধু টোকেন চেক করে, পাসওয়ার্ড না।

#### 🤣 ফানি অ্যানালজি (কনসার্টের হাতের ব্যান্ড)

ধরো, তুমি **"Artcell"** এর কনসার্টে গেছ।

১. **লগইন:** তুমি গেটের কাউন্টারে টিকেট দেখালে।
২. **Token Issue:** কাউন্টার থেকে তোমার হাতে একটা **নিল রঙের প্লাস্টিকের ব্যান্ড** পরিয়ে দিল।
৩. **Authorization:** এখন তুমি ভেতরে গিয়ে ফুচকা খাবে বা ওয়াশরুমে যাবে। দারোয়ান কি বারবার তোমার টিকেট চেক করবে?
না! সে শুধু তোমার **হাতের ব্যান্ড (Token)** দেখবে। ব্যান্ড থাকলে সব ফ্রি, না থাকলে ঘাড় ধাক্কা।
৪. **Security:** তুমি যদি বাজার থেকে নীল স্কচটেপ কিনে হাতে পেঁচিয়ে আসো, দারোয়ান ধরে ফেলবে। কারণ আসল ব্যান্ডে একটা **সিল (Signature)** মারা আছে, যেটা নকল করা যায় না।

👉 আমাদের **JWT** হলো ওই হাতের ব্যান্ড। আর **Secret Key** হলো ওই সিক্রেট সিল।

#### 💻 Coding Example (Setup & Configuration)

আজকে আমরা টোকেন বানাব না, টোকেন বানানোর **মেশিন** রেডি করব।

**Step 1: প্যাকেজ ইন্সটল করা**
JWT নিয়ে কাজ করার জন্য মাইক্রোসফটের একটা স্পেশাল প্যাকেজ লাগে। টার্মিনালে এই কমান্ড দাও:

```bash
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer
```

**Step 2: Secret Key এবং সেটিংস ঠিক করা**
টোকেন যে আমরাই বানিয়েছি, সেটা প্রমাণ করার জন্য একটা গোপন চাবি বা **Secret Key** লাগে। এটা হ্যাকাররা জানলে সর্বনাশ!
তোমার `appsettings.json` ফাইল ওপেন করো এবং `AllowedHosts` এর নিচে এই অংশটুকু যোগ করো:

```json
{
  "Logging": { ... },
  "AllowedHosts": "*",
  "ConnectionStrings": { ... },

  // এই অংশটুকু যোগ করো
  "JwtSettings": {
    "securityKey": "ThisIsA_Very_Long_Secret_Key_For_Security_Purpose_MAMA_12345!",
    "issuer": "AuthMasterApp",
    "audience": "AuthMasterClient",
    "expireSeconds": "3600"
  }
}
```

**⚠️ সাবধান:** `securityKey` অবশ্যই অনেক লম্বা হতে হবে (মিনিমাম ১৬-৩২ ক্যারেক্টার)। ছোট হলে .NET এরর দিবে।

**Step 3: Program.cs এ কনফিগারেশন (মেশিন বসানো)**
এখন আমাদের অ্যাপকে বলতে হবে যে আমরা JWT ব্যবহার করব।
`Program.cs` ফাইলে `builder.Services.AddIdentity...` এর নিচে এবং `var app = ...` এর আগে এই কোডটুকু বসাও:

```csharp
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.IdentityModel.Tokens;
using System.Text;

// ... আগের কোড (AddIdentity)

// JWT Authentication কনফিগারেশন
builder.Services.AddAuthentication(options => {
    options.DefaultAuthenticateScheme = JwtBearerDefaults.AuthenticationScheme;
    options.DefaultChallengeScheme = JwtBearerDefaults.AuthenticationScheme;
    options.DefaultScheme = JwtBearerDefaults.AuthenticationScheme;
})
.AddJwtBearer(options => {
    options.SaveToken = true;
    options.RequireHttpsMetadata = false; // ডেভেলপমেন্টের জন্য false, প্রোডাকশনে true হবে
    options.TokenValidationParameters = new TokenValidationParameters
    {
        ValidateIssuer = true,
        ValidateAudience = true,
        ValidateLifetime = true,
        ValidateIssuerSigningKey = true,
        
        // appsettings.json থেকে ডাটাগুলো আনছি
        ValidIssuer = builder.Configuration["JwtSettings:issuer"],
        ValidAudience = builder.Configuration["JwtSettings:audience"],
        IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(builder.Configuration["JwtSettings:securityKey"]))
    };
});

// ...
var app = builder.Build();
```

---

#### 🧠 কোড ব্রেকডাউন
*   **Issuer:** কে টোকেন দিচ্ছে? (আমরা, মানে সার্ভার)।
*   **Audience:** কার জন্য দিচ্ছে? (ক্লায়েন্ট বা ফ্রন্টএন্ড)।
*   **SymmetricSecurityKey:** এটাই সেই সিলমোহর। `appsettings.json` এর চাবি দিয়ে এটা এনক্রিপ্ট হবে। সার্ভার যখন পরে টোকেন চেক করবে, সে এই চাবি দিয়েই মিলিয়ে দেখবে।

#### 📝 আজকের হোমওয়ার্ক (Homework)

আজকে কোড রান করে কিছু দেখবে না, কিন্তু সেটআপ ঠিক থাকা জরুরি।

১. প্যাকেজটা ইন্সটল করো।
২. `appsettings.json` এ কনফিগারেশন বসাও। `securityKey` তে তোমার নিজের মতো একটা লম্বা লাইন লিখো (স্পেস বা স্পেশাল ক্যারেক্টার দিতে পারো)।
৩. `Program.cs` এ কোডটুকু বসাও।
৪. প্রজেক্টটা `dotnet build` দিয়ে চেক করো কোনো লাল দাগ (Error) আছে কিনা।

গত ক্লাসে আমরা **"টোকেন বানানোর মেশিন"** (Configuration) ফিট করেছিলাম। কিন্তু মেশিনের সুইচ এখনো অন করা হয়নি।

আজকে আমরা সেই সুইচ টিপব এবং **Login** করার সাথে সাথে ইউজারকে একটা গরম গরম **JWT Token** হাতে ধরিয়ে দিব। এই টোকেনটাই হবে তার অ্যাপে ঘোরাঘুরির চাবি।

### 🎓 Lesson 8: Generating JWT Token - আসল জাদুর চাবি

টোকেন জেনারেট করা মানে হলো একটা লম্বা স্ট্রিং তৈরি করা, যার ভেতরে এনক্রিপ্ট করা অবস্থায় ইউজারের কিছু তথ্য (Claims) এবং একটা ডিজিটাল সিগনেচার থাকে।

#### 🇧🇩 সহজ বাংলায় ব্যাখ্যা (Claims কি?)
টোকেনের ভেতরে আমরা যে ছোট ছোট তথ্যগুলো ভরে দিই (যেমন: ইউজারের নাম, ইমেইল, আইডি), এগুলোকে বলা হয় **Claims**।
মনে রাখবে, টোকেনের ভেতরে সেনসিটিভ কিছু (যেমন পাসওয়ার্ড) রাখা যাবে না। কারণ টোকেন ডিকোড করা যায়, শুধু এডিট করা যায় না।

#### 🤣 ফানি অ্যানালজি (চেক বই সই করা)

ধরো, তুমি ব্যাংকের ম্যানেজার।

১. **Claims:** তুমি চেকের পাতায় লিখলে—"মিস্টার কুদ্দুসকে (User), ৫০০ টাকা (Role/Permission) দেওয়া হোক"। এই লেখাগুলোই হলো **Claims**।
২. **Secret Key (Signature):** এখন এই চেকটা ব্যাংকের ক্যাশ কাউন্টারে নিলে কি টাকা দিবে? দিবে না। যতক্ষণ না তুমি নিচে তোমার **সিগনেচার** দিচ্ছ।
তোমার সিগনেচারটাই হলো **Secret Key**। এটা ছাড়া চেকের পাতার কোনো দাম নাই।
৩. **Token:** সিগনেচার সহ চেকটাই হলো আমাদের **Token**।

#### 💻 Coding Example (AccountController Update)

আজকে আমরা `AccountController` এ বেশ কিছু চেঞ্জ করব। কারণ `appsettings.json` থেকে সিক্রেট কি (Key) পড়ার জন্য আমাদের `IConfiguration` লাগবে।

**Step 1: IConfiguration ইনজেক্ট করা**
কন্ট্রোলারের কনস্ট্রাকটর আপডেট করো:

```csharp
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Text;
using Microsoft.IdentityModel.Tokens;

// ... namespace and class definition

public class AccountController : ControllerBase
{
    private readonly UserManager<AppUser> _userManager;
    private readonly IConfiguration _configuration; // নতুন অতিথি

    // কনস্ট্রাক্টরে IConfiguration যোগ করা হলো
    public AccountController(UserManager<AppUser> userManager, IConfiguration configuration)
    {
        _userManager = userManager;
        _configuration = configuration;
    }
    
    // ... Register method (No Change)
    
    // ... Login method (Change হবে, নিচে দেখ)
```

**Step 2: টোকেন জেনারেট করার প্রাইভেট মেথড**
কন্ট্রোলারের একদম নিচে একটা প্রাইভেট মেথড বানাও। এটা আমাদের হেল্পার হিসেবে কাজ করবে।

```csharp
    // এই মেথডটা শুধু টোকেন বানিয়ে রিটার্ন করবে
    private string GenerateToken(AppUser user)
    {
        // ১. টোকেনের ভেতরে কি কি তথ্য থাকবে (Claims)
        var claims = new List<Claim>
        {
            new Claim(JwtRegisteredClaimNames.Sub, user.Id), // ইউজারের ইউনিক আইডি
            new Claim(JwtRegisteredClaimNames.Email, user.Email), // ইউজারের ইমেইল
            new Claim(JwtRegisteredClaimNames.Jti, Guid.NewGuid().ToString()), // টোকেনের একটা ইউনিক আইডি
            new Claim("FullName", user.FullName ?? "") // আমাদের কাস্টম প্রপার্টি
        };

        // ২. সিক্রেট কি (Key) রেডি করা (নকল চেক ঠেকাতে)
        var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_configuration["JwtSettings:securityKey"]));
        var creds = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);

        // ৩. টোকেন বানানো (Expiry, Issuer, Audience সব সেট করা)
        var token = new JwtSecurityToken(
            issuer: _configuration["JwtSettings:issuer"],
            audience: _configuration["JwtSettings:audience"],
            claims: claims,
            expires: DateTime.Now.AddSeconds(Convert.ToDouble(_configuration["JwtSettings:expireSeconds"])), // ১ ঘণ্টা মেয়াদ
            signingCredentials: creds
        );

        // ৪. স্ট্রিং আকারে রিটার্ন করা
        return new JwtSecurityTokenHandler().WriteToken(token);
    }
}
```

**Step 3: Login মেথড আপডেট করা**
এখন আমাদের `Login` মেথড থেকে এই `GenerateToken` কল করতে হবে।

```csharp
    [HttpPost("login")]
    public async Task<IActionResult> Login([FromBody] LoginDto loginDto)
    {
        var user = await _userManager.FindByEmailAsync(loginDto.Email);
        
        if (user == null || !await _userManager.CheckPasswordAsync(user, loginDto.Password))
        {
            return Unauthorized("Invalid Email or Password");
        }

        // সব ঠিক থাকলে টোকেন বানাও
        var tokenString = GenerateToken(user);

        return Ok(new 
        { 
            message = "Login Successful",
            token = tokenString // এই সেই সোনার হরিণ!
        });
    }
```

### 🎓 Lesson 9: The `[Authorize]` Attribute - দারোয়ান সেট করা

আজকে আমরা আমাদের কোডের কিছু বিশেষ দরজায় **তালা** ঝুলাব। এই তালা খোলার চাবি হলো তোমার ওই টোকেন।

#### 🇧🇩 সহজ বাংলায় ব্যাখ্যা
.NET-এ কোনো API বা মেথডকে সিকিউর করতে চাইলে তার মাথায় `[Authorize]` সিল মেরে দিতে হয়।
যখনই কেউ ওই API কল করবে, সিস্টেম চেক করবে:
১. রিকোয়েস্টের সাথে কোনো টোকেন আছে কিনা?
২. টোকেনটা কি ভ্যালিড (মেয়াদ আছে তো? সিগনেচার ঠিক আছে তো?)?

যদি সব ঠিক থাকে, তবেই সে ভেতরে ঢুকতে দিবে। না হলে সোজা **401 Unauthorized** (ভাগ এখান থেকে!)।

#### 🤣 ফানি অ্যানালজি (VIP লাউঞ্জ)

ধরো, বিমানবন্দরে একটা **VIP Lounge** আছে।

১. **Public Area:** বিমানবন্দরের বাইরে যে কেউ ঘুরতে পারে। (যেমন আমাদের `Login` বা `Register` API)। এখানে কোনো বাধা নেই।
২. **VIP Lounge:** এখানে গেটে লেখা আছে **`[Authorize]`**।
তুমি যদি হুট করে ঢুকতে যাও, দারোয়ান বলবে—*"স্যার, আপনার বোর্ডিং পাস (Token) দেখান।"*
যদি পাস না থাকে বা পাসের মেয়াদ শেষ হয়ে যায়, দারোয়ান তোমাকে ঢুকতে দিবে না। লাউঞ্জের ভেতরের এসি বাতাস খেতে হলে ভ্যালিড পাস লাগবেই।

#### 💻 Coding Example

আজকে আমরা দুইটা কাজ করব। প্রথমে `Program.cs` এর পাইপলাইন চেক করব (এটা ভুল হলে কাজ করবে না), তারপর একটা সিকিউর API বানাব।

**Step 1: Program.cs এ Middleware চেক করা (খুবই গুরুত্বপূর্ণ)**
`Program.cs` ফাইলে যাও। একদম নিচের দিকে `app.MapControllers();` এর আগে নিচের দুইটা লাইন **অবশ্যই** থাকতে হবে এবং **সঠিক অর্ডারে** থাকতে হবে।

```csharp
var app = builder.Build();

// ... অন্যান্য মিডলওয়্যার (Swagger, HttpsRedirection ইত্যাদি)

// ⚠️ সাবধান মামা! এই অর্ডার ভুল হলে কাজ হবে না।
// আগে Authentication (পরিচয় যাচাই), তারপর Authorization (ক্ষমতা যাচাই)।

app.UseAuthentication(); // ১. আগে চেক করো সে কে? (Token Valid?)
app.UseAuthorization();  // ২. তারপর দেখো তার পারমিশন আছে কিনা।

app.MapControllers();
app.Run();
```

**Step 2: একটা সিকিউরড API বানানো**
এখন আমরা `AccountController` এ একটা নতুন মেথড বানাব, যেটা শুধু লগইন করা ইউজাররাই দেখতে পাবে।

`AccountController.cs` এ যাও এবং নিচের মেথডটা এড করো:

```csharp

// ... ক্লাসের ভেতরে

    [Authorize] // ⛔ এই সেই দারোয়ান! টোকেন ছাড়া ঢুকতে দিবে না।
    [HttpGet("profile")]
    public IActionResult GetProfile()
    {
        // টোকেন ভ্যালিড হলে কোড এখানে আসবে।
        // টোকেন থেকে আমরা ইউজারের নাম বা আইডি বের করতে পারি।
        
        var username = User.Identity?.Name; // এটা অটোমেটিক টোকেন থেকে নাম বের করবে (যদি Claim এ থাকে)
        var userId = User.FindFirst("Id")?.Value; // আমাদের কাস্টম Claim
```

#### 🧪 টেস্টিং (Postman দিয়ে তালা খোলা)

আজকের হোমওয়ার্কটা একটু ট্রিকি, মন দিয়ে দেখো।

১. **Token ছাড়া চেষ্টা করা:**
   * Postman-এ নতুন ট্যাব নাও।
   * GET রিকোয়েস্ট সেট করো: `.../api/account/profile`
   * **Send** বাটনে চাপ দাও।
   * **রেজাল্ট:** `401 Unauthorized`। (দারোয়ান ঢুকতে দেয় নাই, কারণ টোকেন দাও নাই)।

২. **Token সহ চেষ্টা করা:**
   * প্রথমে `Login` API কল করে নতুন একটা ফ্রেশ **Token** কপি করো।
   * এবার আবার `Profile` ট্যাবে আসো।
   * **Headers** অপশনে যাওয়ার দরকার নাই, সোজা **Auth** (Authorization) ট্যাবে ক্লিক করো।
   * Type সিলেক্ট করো: **Bearer Token**।
   * ডানপাশের বক্সে তোমার কপি করা টোকেনটা পেস্ট করো।
   * এবার **Send** চাপ দাও।

৩. **ম্যাজিক:**
   * যদি সব ঠিক থাকে, তুমি `200 OK` দেখবে এবং "স্বাগতম ভিআইপি লাউঞ্জে..." মেসেজটা পাবে। 🎉

### 🎓 Lesson 10: Enable JWT in Swagger UI (Swagger-এ তালা লাগানো)

Swagger-কে যদি না বলে দাও যে "ভাই, আমার এই API-তে সিকিউরিটি আছে", সে বুঝবে না। আমাদের কনফিগার করে দিতে হবে যাতে সে **Header**-এ টোকেন পাঠাতে পারে।

#### 🇧🇩 সহজ বাংলায় ব্যাখ্যা
Swagger হলো তোমার প্রজেক্টের **ম্যানুয়াল বই**। বাই ডিফল্ট সে জানে না যে তোমার অ্যাপে ঢোকার জন্য **পাস (Token)** লাগে।
আমরা এখন Swagger-এর সেটিংসে গিয়ে বলব—
১. "শোনো, আমার অ্যাপে **Bearer Token** সিস্টেম আছে।"
২. "তুমি ইউজার ইন্টারফেসে একটা **বক্স** দাও, যেখানে ইউজার টোকেন পেস্ট করতে পারবে।"
৩. "API কল করার সময় তুমি সেই টোকেনটা অটোমেটিক **Header**-এ জুড়ে দিবে।"

#### 🤣 ফানি অ্যানালজি (আইডি কার্ডের ফিতা)

ধরো, তুমি একটা হাই-সিকিউরিটি অফিসে চাকরি করো।

১. **Postman:** এটা হলো ম্যানুয়ালি পকেট থেকে আইডি কার্ড বের করে দারোয়ানকে দেখানো। কাজ করে, কিন্তু বারবার পকেট হাতড়াতে হয়। বিরক্তিকর!
২. **Swagger without Config:** তোমার আইডি কার্ড আছে, কিন্তু শার্টে কোনো পকেট নাই, হাতেও নেওয়া যাবে না। দারোয়ান তোমাকে গেটেই আটকে দিচ্ছে।
৩. **Swagger with Config:** কোম্পানি তোমাকে একটা **গলায় ঝোলানোর ফিতা (Lanyard)** দিল। তুমি কার্ডটা ফিতায় ঝুলিয়ে রাখলে। এখন গেটে গেলেই দারোয়ান অটোমেটিক কার্ড দেখে স্যালুট দিচ্ছে।

👉 আজকের কোড দিয়ে আমরা Swagger-কে সেই **"গলায় ঝোলানোর ফিতা"** পরিয়ে দিব।

#### 💻 Coding Example (Program.cs Update)

`Program.cs` ফাইলে যাও। যেখানে `builder.Services.AddSwaggerGen();` লেখা আছে, সেটা খুঁজে বের করো। ওটাকে ডিলিট করে বা মডিফাই করে নিচের কোডটুকু বসাও।

*(অবশ্যই `using Microsoft.OpenApi.Models;` উপরে থাকতে হবে)*

```csharp
using Microsoft.OpenApi.Models; // এটা মিস করবা না মামা!

// ...

builder.Services.AddSwaggerGen(option =>
{
    option.SwaggerDoc("v1", new OpenApiInfo { Title = "Auth API", Version = "v1" });

    // ১. সোজা কথায়: Swagger-কে বলা হচ্ছে, "ভাই আমার অথেনটিকেশন সিস্টেমটা এরকম..."
    option.AddSecurityDefinition("Bearer", new OpenApiSecurityScheme
    {
        In = ParameterLocation.Header, // টোকেন কোথায় থাকবে? হেডারে।
        Description = "Please enter a valid token",
        Name = "Authorization", // হেডারের নাম কি? Authorization
        Type = SecuritySchemeType.Http,
        BearerFormat = "JWT",
        Scheme = "Bearer"
    });

    // ২. সোজা কথায়: "সব API-তে এই সিকিউরিটি রুল অ্যাপ্লাই করো"
    option.AddSecurityRequirement(new OpenApiSecurityRequirement
    {
        {
            new OpenApiSecurityScheme
            {
                Reference = new OpenApiReference
                {
                    Type=ReferenceType.SecurityScheme,
                    Id="Bearer"
                }
            },
            new string[]{}
        }
    });
});

// ... বাকি কোড যেমন ছিল
```

#### 🛠️ কিভাবে টেস্ট করবে? (খুবই ইন্টারেস্টিং)

১. কোড সেভ করে প্রজেক্ট রান করো (`dotnet run`)।
২. ব্রাউজারে Swagger UI তে যাও (`https://localhost:xxxx/swagger`).
৩. খেয়াল করে দেখো, ডানদিকে উপরে একটা নতুন বাটন এসেছে: **Authorize 🔓** (তালা খোলা আইকন)।

**এখন ধাপে ধাপে আগাও:**
1.  **Login:** প্রথমে `/api/Account/login` এ গিয়ে লগইন করো। রেসপন্স থেকে `token` টা কপি করো।
2.  **Lock Button:** এবার উপরে গিয়ে **Authorize** বাটনে ক্লিক করো।
3.  **Paste:** একটা বক্স আসবে। সেখানে তোমার কপি করা টোকেনটা পেস্ট করো। (শুধু টোকেন দিলেই হবে, `Bearer` শব্দটা লেখার দরকার নাই, কারণ আমরা কোডে `Scheme="Bearer"` বলে দিয়েছি)।
4.  **Close:** `Authorize` বাটনে চাপ দাও, তারপর `Close` করো। দেখবে তালাটা এখন বন্ধ হয়ে গেছে 🔒।
5.  **Test:** এবার `/api/Account/profile` এ যাও এবং **Execute** করো।
6.  **Success:** কোনো এরর ছাড়া ডাটা দেখতে পাবে! 🎉
