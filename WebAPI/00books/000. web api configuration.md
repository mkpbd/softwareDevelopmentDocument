
### ১. নতুন প্রোজেক্ট তৈরি (Creating a New Project)
- **Visual Studio 2022** ব্যবহার করে একটি নতুন **ASP.NET Core Web API** প্রোজেক্ট তৈরি করা হয়েছে।
- ফ্রেমওয়ার্ক হিসেবে **.NET 8** নির্বাচন করা হয়েছে।
- **Top-level statements** ব্যবহার করা হয়েছে, যার ফলে `Program.cs` ফাইলে `Main` মেথড বা `class` ডিফাইন করার দরকার হয় না, সরাসরি কোড লেখা যায়।

### ২. launchSettings.json কনফিগারেশন
- এই ফাইলটি শুধুমাত্র লোকাল পিসিতে ডেভেলপমেন্টের সময় কাজ করে।
- বইটিতে `launchBrowser: false` করে দেওয়া হয়েছে, যাতে প্রোজেক্ট রান করলে অটোমেটিক ব্রাউজার ওপেন না হয় (কারণ API টেস্ট করার জন্য আমরা সাধারণত Postman ব্যবহার করি)।
- অপ্রয়োজনীয় `http` প্রোফাইল সরিয়ে শুধুমাত্র `https` রাখা হয়েছে।

### ৩. Program.cs ক্লাস এবং ক্লিন কোড (Clean Code)
- `Program.cs` হলো অ্যাপ্লিকেশনের এন্ট্রি পয়েন্ট। এখানে মূলত দুটি কাজ হয়:
  1. **Services Registration:** `builder.Services` ব্যবহার করে বিভিন্ন সার্ভিস (যেমন CORS, SQL Connection, Swagger) যুক্ত করা।
  2. **Middleware Pipeline:** `app.Use...` মেথডগুলো ব্যবহার করে রিকোয়েস্ট পাইপলাইন সাজানো।
- **Extension Methods:** `Program.cs` যাতে অনেক বড় এবং জটিল না হয়ে যায়, তাই কনফিগারেশন কোডগুলোকে আলাদা ফাইলে (`Extensions` ফোল্ডারে `ServiceExtensions.cs` নামে) সরিয়ে নেওয়া হয়েছে। একেই বলা হচ্ছে Extension Method ব্যবহার করা।

### ৪. CORS এবং IIS কনফিগারেশন
- **CORS (Cross-Origin Resource Sharing):** অন্য কোনো ডোমেইন (যেমন একটি React বা Angular অ্যাপ) থেকে যাতে আপনার API কল করা যায়, সেজন্য CORS পলিসি সেটআপ করা হয়েছে। শুরুতে সব ডোমেইনকে অনুমতি দেওয়া হয়েছে (`AllowAnyOrigin`)।
- **IIS Integration:** ভবিষ্যতে অ্যাপটি যাতে IIS (Internet Information Services) সার্ভারে হোস্ট বা ডিপ্লয় করা যায়, তার জন্য একটি কনফিগারেশন যুক্ত করা হয়েছে।

### ৫. পরিবেশ অনুযায়ী সেটিংস (Environment-Based Settings)
- ডেভেলপমেন্ট এবং প্রোডাকশনের (লাইভ সার্ভার) জন্য আলাদা আলাদা কনফিগারেশন বা ডাটাবেস কানেকশন থাকতে পারে।
- এটি নিয়ন্ত্রণ করা হয় `appsettings.json` এবং `appsettings.Development.json` ফাইলের মাধ্যমে।
- কোন ফাইলটি লোড হবে তা নির্ভর করে `ASPNETCORE_ENVIRONMENT` ভেরিয়েবলের ওপর।

### ৬. মিডলওয়্যার (Middleware)
এটি এই চ্যাপ্টারের অন্যতম গুরুত্বপূর্ণ অংশ। মিডলওয়্যার হলো এমন কিছু কোড ব্লক যা প্রতিটি রিকোয়েস্ট ও রেসপন্স হ্যান্ডেল করে।
- **Order Matters:** মিডলওয়্যারগুলো যেই সিরিয়ালে `Program.cs`-এ লেখা হয়, সেই সিরিয়ালেই এক্সিকিউট হয়। ভুল অর্ডারে লিখলে এরর হতে পারে।
- **Run, Use, Map:**
  - `Run`: এটি পাইপলাইন শেষ করে দেয় (Terminal Middleware)।
  - `Use`: এটি কাজ করে পরবর্তী মিডলওয়্যারে রিকোয়েস্ট পাঠিয়ে দেয় (`next()` এর মাধ্যমে)।
  - `Map`: নির্দিষ্ট URL এর ওপর ভিত্তি করে পাইপলাইনকে আলাদা রাস্তায় (Branching) নিয়ে যায়।

**সংক্ষেপে:** এই চ্যাপ্টার শেষে আপনার কাছে একটি ক্লিন এবং গোছানো প্রোজেক্ট থাকবে, যেখানে CORS সেটআপ করা আছে, কোডগুলো আলাদা ফাইলে অর্গানাইজড এবং আপনি জানেন মিডলওয়্যার কীভাবে কাজ করে।

### ২. কোড (Extension Methods)

`Program.cs` ফাইল পরিষ্কার রাখার জন্য আমরা কনফিগারেশন লজিকগুলো আলাদা ফাইলে রাখব।

**ধাপ ১: ফোল্ডার তৈরি**
প্রজেক্টে `Extensions` নামে একটি ফোল্ডার তৈরি করুন।

**ধাপ ২: ক্লাস তৈরি**
ওই ফোল্ডারে `ServiceExtensions.cs` নামে একটি ক্লাস তৈরি করুন এবং নিচের কোড লিখুন।

**ফাইল:** `Extensions/ServiceExtensions.cs`

```csharp
using Microsoft.AspNetCore.Builder;
using Microsoft.Extensions.DependencyInjection;

namespace CompanyEmployees.Extensions
{
    public static class ServiceExtensions
    {
        // 1. CORS কনফিগারেশন (যাতে অন্য ডোমেইন থেকে রিকোয়েস্ট আসতে পারে)
        public static void ConfigureCors(this IServiceCollection services) =>
            services.AddCors(options =>
            {
                options.AddPolicy("CorsPolicy", builder =>
                    builder.AllowAnyOrigin()   // যে কোনো সোর্স এলাউ
                           .AllowAnyMethod()   // GET, POST, PUT সব এলাউ
                           .AllowAnyHeader()); // সব হেডার এলাউ
            });

        // 2. IIS কনফিগারেশন (উইন্ডোজ সার্ভারে হোস্ট করার জন্য)
        public static void ConfigureIISIntegration(this IServiceCollection services) =>
            services.Configure<IISOptions>(options => 
            {
                // ডিফল্ট সেটিংস রাখা হলো
            });
    }
}
```

### ৩. মেইন কনফিগারেশন (Program.cs)

এখন `Program.cs` ফাইলে সবকিছু একসাথে জোড়া লাগাব।

**ফাইল:** `Program.cs`

```csharp
using CompanyEmployees.Extensions; // আমাদের এক্সটেনশন ব্যবহার করার জন্য
using Microsoft.AspNetCore.HttpOverrides;

var builder = WebApplication.CreateBuilder(args);

// --- ১. সার্ভিস রেজিস্ট্রেশন (Services) ---

// আমাদের তৈরি করা এক্সটেনশন মেথড কল করা
builder.Services.ConfigureCors();
builder.Services.ConfigureIISIntegration();

// ডিফল্ট কন্ট্রোলার সার্ভিস
builder.Services.AddControllers();

var app = builder.Build();

// --- ২. মিডলওয়্যার পাইপলাইন (Pipeline) ---

if (app.Environment.IsDevelopment())
{
    app.UseDeveloperExceptionPage();
}
else
{
    app.UseHsts();
}

app.UseHttpsRedirection();

// লিনাক্স বা প্রক্সি সার্ভারের জন্য হেডার ফরওয়ার্ডিং
app.UseForwardedHeaders(new ForwardedHeadersOptions
{
    ForwardedHeaders = ForwardedHeaders.All
});

// স্ট্যাটিক ফাইল (যেমন ছবি, html) সাপোর্ট করার জন্য
app.UseStaticFiles();

// আমাদের CORS পলিসি অ্যাপ্লাই করা
app.UseCors("CorsPolicy");

app.UseAuthorization();

// কন্ট্রোলার রুট ম্যাপ করা
app.MapControllers();

// অ্যাপ রান করা
app.Run();
```
