
**Chapter 5**-এর নাম হলো **"Handling POST Requests"** বা রিসোর্স তৈরি করা। আগের চ্যাপ্টারগুলোতে আমরা শুধু ডাটাবেস থেকে ডাটা এনেছি (GET), কিন্তু এই চ্যাপ্টারে আমরা শিখব কীভাবে ক্লায়েন্ট থেকে ডাটা নিয়ে ডাটাবেসে সেভ করতে হয় (POST)।

এখানে ডাটা ভ্যালিডেশন, DTO ব্যবহার এবং HTTP স্ট্যাটাস কোডের সঠিক ব্যবহার নিয়ে আলোচনা করা হয়েছে। নিচে টপিকগুলো বিস্তারিত বোঝানো হলো:

---

### ১. ইনপুট বা ক্রিয়েশন DTO (Input/Creation DTOs)
আমরা যখন ডাটাবেস থেকে ডাটা দেখাই তখন `CompanyDto` ব্যবহার করি (যেখানে `Id` থাকে)। কিন্তু যখন নতুন কোম্পানি তৈরি করব, তখন ইউজার তো `Id` দেবে না (কারণ `Id` ডাটাবেস জেনারেট করে)। তাই ইনপুটের জন্য আলাদা DTO দরকার।

*   **টপিক:** `CompanyForCreationDto`
*   **কাজ:** ইউজার থেকে শুধু প্রয়োজনীয় তথ্য (যেমন: Name, Address) নেওয়া।
*   **উদাহরণ:**
    ```csharp
    // ইনপুট DTO (Id নেই)
    public record CompanyForCreationDto(string Name, string Address, string Country);
    ```

---

### ২. মডেল ভ্যালিডেশন (Model Validation)
ডাটাবেসে ভুল ভাল ডাটা (যেমন: নাম ছাড়া কোম্পানি) সেভ করা যাবে না। তাই ইনপুট ডাটা ঠিক আছে কি না তা যাচাই করতে হয়। একে **Validation** বলে।

*   **টপিক:** Data Annotations (`[Required]`, `[MaxLength]`)
*   **কাজ:** DTO এর প্রপার্টির ওপর শর্ত জুড়ে দেওয়া।
*   **উদাহরণ:**
    ```csharp
    public record CompanyForCreationDto
    {
        [Required(ErrorMessage = "Company name is a required field.")]
        [MaxLength(60, ErrorMessage = "Maximum length for the Name is 60 characters.")]
        public string Name { get; init; }
        
        // অন্যান্য প্রপার্টি...
    }
    ```
    *   **কিভাবে কাজ করে:** যদি ইউজার `Name` না পাঠায়, তবে কন্ট্রোলারে ঢোকার আগেই বা `ModelState` চেক করার সময় .NET অটোমেটিক **400 Bad Request** রিটার্ন করবে এবং মেসেজ দেখাবে "Company name is a required field."

---

### ৩. POST রিকোয়েস্ট হ্যান্ডলিং (Handling POST)
ডাটা সেভ করার ফ্লো-টা একটু ভিন্ন। এখানে `From Body` থেকে ডাটা আসে।

*   **ফ্লো (Flow):**
    1.  **Controller:** ইউজারের পাঠানো JSON রিসিভ করে (`[FromBody]`)।
    2.  **Service:** ইনপুট DTO কে `AutoMapper` দিয়ে মেইন এনটিটিতে (Entity) কনভার্ট করে।
    3.  **Repository:** এনটিটিকে `Add` করে এবং `Save` করে।
    4.  **Return:** সেভ হওয়ার পর আবার এনটিটিটাকে আউটপুট DTO তে কনভার্ট করে ইউজারকে ফেরত দেওয়া হয়।

---

### ৪. HTTP 201 Created এবং Location Header
REST API-এর নিয়ম অনুযায়ী, সফলভাবে ডাটা তৈরি হলে **200 OK** না পাঠিয়ে **201 Created** পাঠাতে হয়। এবং নতুন তৈরি হওয়া ডাটাটি কোন URL-এ পাওয়া যাবে, তা রেসপন্স হেডার (Header)-এ বলে দিতে হয়।

*   **টপিক:** `CreatedAtRoute` মেথড।
*   **কাজ:** এটি রেসপন্সে `Location` হেডার সেট করে।
*   **উদাহরণ:**
    ধরি, নতুন কোম্পানির ID হলো `10`।
    রেসপন্স হেডার হবে: `Location: https://localhost:5001/api/companies/10`
    
    কোড লজিক:
    ```csharp
    return CreatedAtRoute("CompanyById", new { id = companyDto.Id }, companyDto);
    ```
    *   এখানে `"CompanyById"` হলো `GetCompany` মেথডের নাম (Route Name)। API অটোমেটিক নতুন ID বসিয়ে URL তৈরি করে দেয়।

### ৫. চাইল্ড রিসোর্স তৈরি (Creating Child Resources)
কোম্পানি ছাড়া যেমন এমপ্লয়ির অস্তিত্ব নেই, তাই এমপ্লয়ি তৈরি করতে হলে অবশ্যই বলে দিতে হবে সে কোন কোম্পানির আন্ডারে।

*   **রাউট:** `POST api/companies/{companyId}/employees`
*   **কাজ:**
    1.  ইউআরএল থেকে `companyId` নেওয়া হয়।
    2.  বডি থেকে এমপ্লয়ির তথ্য (`EmployeeForCreationDto`) নেওয়া হয়।
    3.  **সার্ভিস লেয়ার চেক করে:** ওই কোম্পানি ডাটাবেসে আছে কি না? না থাকলে `CompanyNotFoundException` (404 Error)।
    4.  কোম্পানি থাকলে, ওই আইডির আন্ডারে নতুন এমপ্লয়ি সেভ করা হয়।

### ৬. একসাথে অনেকগুলো ডাটা তৈরি (Creating Collection)
ইউজার যদি চায় একসাথে ১০০টি কোম্পানি তৈরি করবে, তাহলে ১০০ বার API কল করা খারাপ প্র্যাকটিস। তাই **Collection Creation** সাপোর্ট দেওয়া হয়।

*   **ইনপুট:** `IEnumerable<CompanyForCreationDto>` (একটি লিস্ট বা অ্যারে)।
*   **উদাহরণ:**
    ```json
    [
        { "name": "Company A", "address": "Dhaka" },
        { "name": "Company B", "address": "Ctg" }
    ]
    ```
*   **কাজ:** লুপ না চালিয়ে, একবারে লিস্টটি রিসিভ করে `AddRange` মেথড ব্যবহার করে ডাটাবেসে সেভ করা হয়।

### ৭. Model Binding
ইউজার পাঠায় JSON ফরম্যাটে টেক্সট, কিন্তু আমাদের কোডে দরকার C# অবজেক্ট। এই কনভার্শন প্রক্রিয়াকে **Model Binding** বা Deserialization বলে।

*   **টপিক:** `[FromBody]` অ্যাট্রিবিউট।
*   **কাজ:** এটি রিকোয়েস্টের বডি চেক করে এবং JSON কি-ভ্যালু (Key-Value) পেয়ারের সাথে DTO-র প্রপার্টি মিলিয়ে অবজেক্ট তৈরি করে।

### ১. ইনপুট DTO এবং ভ্যালিডেশন (Shared Project)
নতুন কোম্পানি বা এমপ্লয়ি তৈরি করার সময় আমরা এই DTO ব্যবহার করব। এখানে `[Required]` এবং `[MaxLength]` ব্যবহার করে ভ্যালিডেশন দেওয়া হয়েছে।

**ফাইল:** `Shared/DataTransferObjects/CompanyForCreationDto.cs`
```csharp
using System.ComponentModel.DataAnnotations;

public record CompanyForCreationDto
{
    [Required(ErrorMessage = "Company name is a required field.")]
    [MaxLength(60, ErrorMessage = "Maximum length for the Name is 60 characters.")]
    public string Name { get; init; }

    [Required(ErrorMessage = "Company address is a required field.")]
    [MaxLength(60, ErrorMessage = "Maximum length for the Address is 60 characters.")]
    public string Address { get; init; }

    [Required(ErrorMessage = "Company country is a required field.")]
    public string Country { get; init; }

    // চাইলে একসাথেই কোম্পানির এমপ্লয়ি তৈরি করা যায় (Optional Feature)
    public IEnumerable<EmployeeForCreationDto> Employees { get; init; } 
}
```

**ফাইল:** `Shared/DataTransferObjects/EmployeeForCreationDto.cs`
```csharp
using System.ComponentModel.DataAnnotations;

public record EmployeeForCreationDto
{
    [Required(ErrorMessage = "Employee name is a required field.")]
    [MaxLength(30, ErrorMessage = "Maximum length for the Name is 30 characters.")]
    public string Name { get; init; }

    [Required(ErrorMessage = "Age is a required field.")]
    [Range(18, int.MaxValue, ErrorMessage = "Age is required and it can't be lower than 18")]
    public int Age { get; init; }

    [Required(ErrorMessage = "Position is a required field.")]
    [MaxLength(20, ErrorMessage = "Maximum length for the Position is 20 characters.")]
    public string Position { get; init; }
}
```

### ৪. সার্ভিস লেয়ার (লজিক এবং সেভ)
এখানে আসল ম্যাজিক হয়। আমরা DTO নিই, এনটিটিতে কনভার্ট করি, সেভ করি এবং শেষে আউটপুট DTO রিটার্ন করি।

**কোম্পানি তৈরি (Parent Resource):**
**ফাইল:** `Service/CompanyService.cs`
```csharp
public CompanyDto CreateCompany(CompanyForCreationDto company)
{
    // ১. DTO -> Entity কনভার্শন
    var companyEntity = _mapper.Map<Company>(company);

    // ২. রিপোজিটরিতে এড করা
    _repository.Company.CreateCompany(companyEntity);
    
    // ৩. ডাটাবেসে পার্মানেন্টলি সেভ করা (Commit)
    _repository.Save();

    // ৪. Entity -> Output DTO কনভার্শন (ইউজারকে দেখানোর জন্য)
    var companyToReturn = _mapper.Map<CompanyDto>(companyEntity);

    return companyToReturn;
}
```

**এমপ্লয়ি তৈরি (Child Resource):**
**ফাইল:** `Service/EmployeeService.cs`
```csharp
public EmployeeDto CreateEmployeeForCompany(Guid companyId, EmployeeForCreationDto employeeForCreation, bool trackChanges)
{
    // ১. আগে চেক করি কোম্পানি আছে কিনা
    var company = _repository.Company.GetCompany(companyId, trackChanges);
    if (company is null)
        throw new CompanyNotFoundException(companyId);

    // ২. DTO -> Entity
    var employeeEntity = _mapper.Map<Employee>(employeeForCreation);

    // ৩. রিপোজিটরিতে এড করা (CompanyId সহ)
    _repository.Employee.CreateEmployeeForCompany(companyId, employeeEntity);
    
    // ৪. সেভ করা
    _repository.Save();

    // ৫. রিটার্ন করার জন্য কনভার্ট
    var employeeToReturn = _mapper.Map<EmployeeDto>(employeeEntity);

    return employeeToReturn;
}
```

### ৫. কন্ট্রোলার (API Endpoint)
এখানে আমরা `CreatedAtRoute` ব্যবহার করব যাতে **201 Created** রেসপন্স যায়।

**ফাইল:** `Presentation/Controllers/CompaniesController.cs`
```csharp
[HttpPost]
public IActionResult CreateCompany([FromBody] CompanyForCreationDto company)
{
    // ModelState.IsValid চেক করার দরকার নেই, কারণ [ApiController] এট্রিবিউট অটোমেটিক চেক করে 400 রিটার্ন করে দেবে।
    if (company is null)
        return BadRequest("CompanyForCreationDto object is null");

    var createdCompany = _service.CompanyService.CreateCompany(company);

    // "CompanyById" হলো GetCompany মেথডের নাম (যা আগের চ্যাপ্টারে বানিয়েছি)
    return CreatedAtRoute("CompanyById", new { id = createdCompany.Id }, createdCompany);
}
```
*নোট: `GetCompany` মেথডের ওপর `[HttpGet("{id:guid}", Name = "CompanyById")]` নাম থাকতে হবে।*

**ফাইল:** `Presentation/Controllers/EmployeesController.cs`
```csharp
[HttpPost]
public IActionResult CreateEmployeeForCompany(Guid companyId, [FromBody] EmployeeForCreationDto employee)
{
    if (employee is null)
        return BadRequest("EmployeeForCreationDto object is null");

    // এখানে trackChanges: false দিচ্ছি কারণ আমরা শুধু চেক করছি কোম্পানি আছে কিনা, কোম্পানির ডাটা বদলাচ্ছি না
    var createdEmployee = _service.EmployeeService.CreateEmployeeForCompany(companyId, employee, trackChanges: false);

    // চাইল্ডের ক্ষেত্রেও CreatedAtRoute ব্যবহার করা হয়
    return CreatedAtRoute("GetEmployeeForCompany", 
        new { companyId, id = createdEmployee.Id }, 
        createdEmployee);
}
```
*নোট: `GetEmployee` মেথডের ওপর `[HttpGet("{id:guid}", Name = "GetEmployeeForCompany")]` নাম থাকতে হবে।*

### ৬. উদাহরণ (Testing with Postman)

**রিকোয়েস্ট ১: নতুন কোম্পানি তৈরি (Success)**
*   **Method:** `POST`
*   **URL:** `https://localhost:5001/api/companies`
*   **Body (JSON):**
    ```json
    {
        "name": "IT Solution Ltd",
        "address": "Banani, Dhaka",
        "country": "Bangladesh"
    }
    ```
*   **Response:** `201 Created`
*   **Header:** `Location: https://localhost:5001/api/companies/gu-id-gu-id`
*   **Body:** `{ "id": "...", "name": "IT Solution Ltd", "fullAddress": "Banani, Dhaka Bangladesh" }`

**রিকোয়েস্ট ২: ভুল ডাটা (Validation Error)**
*   **Body:** `{ "address": "Dhaka" }` (Name মিসিং)
*   **Response:** `400 Bad Request`
*   **Body:**
    ```json
    {
        "Name": [ "Company name is a required field." ],
        "Country": [ "Company country is a required field." ]
    }
    ```

**রিকোয়েস্ট ৩: এমপ্লয়ি তৈরি (Child Resource)**
*   **URL:** `https://localhost:5001/api/companies/{companyId}/employees`
*   **Body:**
    ```json
    {
        "name": "Rahim",
        "age": 25,
        "position": "Software Engineer"
    }
    ```
*   **Response:** `201 Created`
