
**Chapter 6**-এর নাম হলো **"Handling DELETE and PUT Requests"**।

Chapter 5-এ আমরা ডাটা তৈরি (POST) করা শিখেছি। এই চ্যাপ্টারে আমরা শিখব ডাটাবেস থেকে অপ্রয়োজনীয় ডাটা **মুছে ফেলা (DELETE)** এবং বিদ্যমান ডাটা **পুরোপুরি পরিবর্তন বা আপডেট করা (PUT)**।

নিচে এই চ্যাপ্টারের মূল টপিকগুলো এবং তাদের কাজ উদাহরণসহ আলোচনা করা হলো:

---

### ১. ডাটা ডিলিট করা (DELETE Requests)
এপিআই ব্যবহার করে ডাটাবেস থেকে কোনো রিসোর্স মুছে ফেলার প্রক্রিয়া।

*   **কীভাবে কাজ করে:**
    ১. ক্লায়েন্ট `DELETE api/companies/{id}` রিকোয়েস্ট পাঠায়।
    ২. সার্ভিস লেয়ার চেক করে ওই আইডির কোম্পানি ডাটাবেসে আছে কি না।
    ৩. না থাকলে `NotFoundException` (404) দেওয়া হয়।
    ৪. থাকলে রিপোজিটরি লেয়ারের `Delete()` মেথড কল করা হয় এবং `Save()` করা হয়।
*   **রেসপন্স:** ডিলিট অপারেশন সফল হলে সাধারণত কোনো ডাটা রিটার্ন করা হয় না। তাই **204 No Content** স্ট্যাটাস কোড পাঠানো হয়।
*   **Cascade Delete:** EF Core এর ডিফল্ট বিহেভিয়ার অনুযায়ী, আপনি যদি "Parent" (Company) ডিলিট করেন, তবে তার আন্ডারে থাকা সব "Child" (Employee) অটোমেটিক ডিলিট হয়ে যাবে।

---

### ২. ডাটা আপডেট করা (PUT Requests)
REST API তে `PUT` ব্যবহার করা হয় **Full Update** এর জন্য। অর্থাৎ, একটি রিসোর্সের সব তথ্য নতুন করে সেট করা হয়।

*   **আপডেট DTO:** আপডেটের জন্য আমরা `CompanyForUpdateDto` ব্যবহার করি। এটি দেখতে `CreationDto` এর মতোই, কারণ আপডেট করার সময়ও আমাদের ভ্যালিডেশন (Required, MaxLength) দরকার হয়।
*   **TrackChanges এর গুরুত্ব:** ডাটা আপডেট করার সময় ডাটাবেস থেকে ডাটা আনার সময় `trackChanges: true` দিতে হয়।
    *   *কেন?* কারণ EF Core যখন দেখে `trackChanges: true`, তখন সে ওই ডাটাটার ওপর নজর রাখে। যখনই আমরা ডাটার কোনো ভ্যালু চেঞ্জ করি, EF Core সেটা ধরে ফেলে এবং `SaveChanges()` কল করলে অটোমেটিক আপডেট কুয়েরি চালায়।
*   **AutoMapper এর ম্যাজিক:** আপডেট করার জন্য ম্যানুয়ালি `entity.Name = dto.Name` লেখার দরকার নেই।
    *   `_mapper.Map(source, destination)` ব্যবহার করলে অটোমেটিক DTO এর ডাটা এনটিটির ভেতরে ঢুকে যায়।

---

### ৩. PUT অপারেশনের ফ্লো (The Flow of Update)
একটি আপডেট রিকোয়েস্ট কীভাবে কাজ করে তা ধাপে ধাপে দেখুন:

1.  **Check:** ইউজার যে আইডি দিয়েছে, সেই আইডির ডাটা ডাটাবেসে আছে কি না? (না থাকলে 404)।
2.  **Map:** ইউজার যে নতুন ডাটা (DTO) পাঠিয়েছে, সেটা ডাটাবেসের অবজেক্টে (Entity) ম্যাপ বা কপি করা।
3.  **Save:** `SaveChanges` কল করা। যেহেতু ডাটাটি ট্র্যাক করা হচ্ছিল, তাই EF Core বুঝবে ডাটা চেঞ্জ হয়েছে এবং ডাটাবেসে আপডেট করে দেবে।
4.  **Response:** আপডেটের পরও সাধারণত কোনো বডি রিটার্ন করা হয় না, তাই **204 No Content** রিটার্ন করা হয়।

---

### ৪. ইনপুট ভ্যালিডেশন (Update Validation)
তৈরি করার সময়ের মতো আপডেটের সময়ও ভ্যালিডেশন জরুরি।
*   যদি ইউজার আপডেট করার সময় নাম খালি রাখে, তবে `[Required]` অ্যানোটেশন তাকে আটকাবে এবং **400 Bad Request** দেবে।

---

### ৫. Mass Assignment বা Reference Update
`PUT` রিকোয়েস্টে AutoMapper ব্যবহারের সময় একটি ইন্টারেস্টিং বিষয় ঘটে।
আমরা যখন লিখি `_mapper.Map(updateDto, companyEntity)`, তখন:
*   `companyEntity` হলো একটি **Reference Type** যা মেমোরিতে EF Core ট্র্যাক করছে।
*   AutoMapper যখন `updateDto` থেকে ভ্যালু নিয়ে `companyEntity` তে বসায়, তখন মেমোরিতে থাকা অরিজিনাল অবজেক্টটিই মডিফাই হয়ে যায়।
*   ফলে আলাদা করে `_repository.Update()` কল না করলেও `Save()` করলেই কাজ হয়ে যায় (যদি `trackChanges: true` থাকে)। তবুও কোড রিডেবিলিটির জন্য আমরা রিপোজিটরিতে `Update` মেথড রাখি।

### ১. আপডেট DTO তৈরি (Shared Project)
ডাটা আপডেট করার জন্যও আমাদের DTO লাগবে। এটি `CreationDto` এর মতোই। তাই কোড ডুপ্লিকেশন এড়াতে আমরা একটি অ্যাবস্ট্রাক্ট ক্লাস বানাতে পারি। (বইটিতে সরাসরি আলাদা রেকর্ড বানানো হয়েছে, তবে ইনহেরিটেন্সও ব্যবহার করা যায়)।

**ফাইল:** `Shared/DataTransferObjects/CompanyForUpdateDto.cs`
```csharp
using System.ComponentModel.DataAnnotations;

public record CompanyForUpdateDto
{
    [Required(ErrorMessage = "Company name is a required field.")]
    [MaxLength(60, ErrorMessage = "Maximum length for the Name is 60 characters.")]
    public string Name { get; init; }

    [Required(ErrorMessage = "Company address is a required field.")]
    [MaxLength(60, ErrorMessage = "Maximum length for the Address is 60 characters.")]
    public string Address { get; init; }

    [Required(ErrorMessage = "Company country is a required field.")]
    public string Country { get; init; }

    // আপডেটের সময়ও চাইল্ড (Employee) তৈরি বা আপডেট করা যেতে পারে
    public IEnumerable<EmployeeForCreationDto> Employees { get; init; }
}
```

**ফাইল:** `Shared/DataTransferObjects/EmployeeForUpdateDto.cs`
```csharp
using System.ComponentModel.DataAnnotations;

public record EmployeeForUpdateDto
{
    [Required(ErrorMessage = "Employee name is a required field.")]
    [MaxLength(30, ErrorMessage = "Maximum length for the Name is 30 characters.")]
    public string Name { get; init; }

    [Required(ErrorMessage = "Age is a required field.")]
    [Range(18, int.MaxValue, ErrorMessage = "Age is required and it can't be lower than 18")]
    public int Age { get; init; }

    [Required(ErrorMessage = "Position is a required field.")]
    [MaxLength(20, ErrorMessage = "Maximum length for the Position is 20 characters.")]
    public string Position { get; init; }
}
```

### ৪. সার্ভিস লেয়ার (Logic Implementation) - *মূল কাজ*

**DELETE (মুছে ফেলা):**
**ফাইল:** `Service/CompanyService.cs`
```csharp
public void DeleteCompany(Guid companyId, bool trackChanges)
{
    // ১. চেক করি কোম্পানি আছে কিনা
    var company = _repository.Company.GetCompany(companyId, trackChanges);
    if (company is null)
        throw new CompanyNotFoundException(companyId);

    // ২. ডিলিট মেথড কল করা
    _repository.Company.DeleteCompany(company);
    
    // ৩. সেভ করা
    _repository.Save();
}
```

**PUT (আপডেট করা):**
**ফাইল:** `Service/CompanyService.cs`
```csharp
public void UpdateCompany(Guid companyId, CompanyForUpdateDto companyForUpdate, bool trackChanges)
{
    // ১. ডাটাবেস থেকে ডাটা আনা (trackChanges MUST be true here)
    var companyEntity = _repository.Company.GetCompany(companyId, trackChanges);
    if (companyEntity is null)
        throw new CompanyNotFoundException(companyId);

    // ২. AutoMapper ব্যবহার করে DTO থেকে Entity তে ডাটা কপি করা
    // এখানে companyEntity অবজেক্টটি মেমোরিতে মডিফাই হয়ে যাচ্ছে
    _mapper.Map(companyForUpdate, companyEntity);

    // ৩. সেভ করা (EF Core ট্র্যাক করছে তাই অটোমেটিক আপডেট কুয়েরি চলবে)
    _repository.Save();
}
```

**Child Resource (Employee) Update Logic:**
**ফাইল:** `Service/EmployeeService.cs`
```csharp
public void UpdateEmployeeForCompany(Guid companyId, Guid id, EmployeeForUpdateDto employeeForUpdate, bool compTrackChanges, bool empTrackChanges)
{
    // ১. কোম্পানি চেক
    var company = _repository.Company.GetCompany(companyId, compTrackChanges);
    if (company is null)
        throw new CompanyNotFoundException(companyId);

    // ২. এমপ্লয়ি চেক
    var employeeEntity = _repository.Employee.GetEmployee(companyId, id, empTrackChanges);
    if (employeeEntity is null)
        throw new EmployeeNotFoundException(id);

    // ৩. ম্যাপ এবং আপডেট
    _mapper.Map(employeeForUpdate, employeeEntity);
    
    // ৪. সেভ
    _repository.Save();
}
```

### ৫. কন্ট্রোলার (API Endpoints)
এখন আমরা রাউটগুলো তৈরি করব।

**ফাইল:** `Presentation/Controllers/CompaniesController.cs`
```csharp
[HttpDelete("{id:guid}")]
public IActionResult DeleteCompany(Guid id)
{
    _service.CompanyService.DeleteCompany(id, trackChanges: false);
    
    // ডিলিট সফল হলে কিছু রিটার্ন করার দরকার নেই
    return NoContent(); // Status Code 204
}

[HttpPut("{id:guid}")]
public IActionResult UpdateCompany(Guid id, [FromBody] CompanyForUpdateDto company)
{
    if (company is null)
        return BadRequest("CompanyForUpdateDto object is null");

    // এখানে trackChanges: true দেওয়া জরুরি কারণ আমরা আপডেট করতে চাই
    _service.CompanyService.UpdateCompany(id, company, trackChanges: true);

    return NoContent(); // Status Code 204
}
```

**ফাইল:** `Presentation/Controllers/EmployeesController.cs`
```csharp
[HttpDelete("{id:guid}")]
public IActionResult DeleteEmployeeForCompany(Guid companyId, Guid id)
{
    _service.EmployeeService.DeleteEmployeeForCompany(companyId, id, trackChanges: false);
    return NoContent();
}

[HttpPut("{id:guid}")]
public IActionResult UpdateEmployeeForCompany(Guid companyId, Guid id, [FromBody] EmployeeForUpdateDto employee)
{
    if (employee is null)
        return BadRequest("EmployeeForUpdateDto object is null");

    _service.EmployeeService.UpdateEmployeeForCompany(companyId, id, employee, compTrackChanges: false, empTrackChanges: true);

    return NoContent();
}
```
