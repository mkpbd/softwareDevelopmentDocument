এটি একটি এপিআই-এর জন্য অত্যন্ত গুরুত্বপূর্ণ চ্যাপ্টার। ধরুন আপনার ডাটাবেসে **১০ লাখ** এমপ্লয়ি আছে। আপনি যদি `GetAllEmployees` কল করেন এবং এপিআই সব ডাটা একসাথে নিয়ে আসে, তবে আপনার সার্ভার ক্র্যাশ করবে এবং অ্যাপ হ্যাং হয়ে যাবে।

এই সমস্যা সমাধানের জন্যই এই চ্যাপ্টারের টেকনিকগুলো ব্যবহার করা হয়। নিচে প্রতিটি টপিক বিস্তারিত আলোচনা করা হলো:

### ১. পেজিং (Paging / Pagination)

**কি কাজ করে:**
ডাটাবেসের সব ডাটা একসাথে না এনে, ছোট ছোট ভাগে (Chunck) ভাগ করে আনা। যেমন: প্রতি পেজে ১০টি করে ডাটা দেখানো।

**কেন দরকার (সুবিধা):**
1.  **পারফরম্যান্স:** সার্ভার ফাস্ট থাকে কারণ একসাথে লক্ষ লক্ষ ডাটা লোড করতে হয় না।
2.  **ব্যান্ডউইথ সেভ:** মোবাইলে ডাটা কম খরচ হয়।
3.  **ইউজার এক্সপেরিয়েন্স:** ইউজাররা ১ লাখ ডাটার লিস্ট দেখে ভয় পাবে না, ১০টা ১০টা করে দেখবে।

**লজিক (How it works):**
এটিতে দুটি প্যারামিটার লাগে: `PageNumber` (কত নম্বর পেজ) এবং `PageSize` (প্রতি পেজে কয়টা ডাটা)।
লিনক (LINQ) এর `Skip()` এবং `Take()` মেথড ব্যবহার করা হয়।
*   ফর্মুলা: `.Skip((PageNumber - 1) * PageSize).Take(PageSize)`

**উদাহরণ:**
*   **Request:** `GET /api/employees?pageNumber=2&pageSize=10`
*   **Action:** প্রথম ১০টি ডাটা বাদ দিয়ে (Skip) পরের ১০টি ডাটা দেখাবে।

### ২. ফিল্টারিং (Filtering)

**কি কাজ করে:**
সব ডাটা না এনে নির্দিষ্ট শর্তের ওপর ভিত্তি করে ডাটা আনা। যেমন: যাদের বয়স ২০ থেকে ৩০ এর মধ্যে।

**কেন দরকার (সুবিধা):**
1.  ইউজার তার প্রয়োজনীয় ডাটা দ্রুত খুঁজে পায়।
2.  অপ্রয়োজনীয় ডাটা প্রসেস করতে হয় না।

**লজিক (How it works):**
আমরা `MinAge` এবং `MaxAge` নামে প্যারামিটার রিসিভ করি। তারপর LINQ এর `Where` ক্লজ ব্যবহার করি।
*   কোড: `.Where(e => e.Age >= minAge && e.Age <= maxAge)`

**উদাহরণ:**
*   **Request:** `GET /api/employees?minAge=25&maxAge=30`
*   **Result:** শুধু ২৫ থেকে ৩০ বছর বয়সী এমপ্লয়িদের লিস্ট আসবে।

---

### ৩. সার্চিং (Searching)

**কি কাজ করে:**
কোনো একটি টেক্সট দিয়ে ডাটা খোঁজা। ফিল্টারিং হলো নির্দিষ্ট রেঞ্জ বা ভ্যালু দিয়ে খোঁজা, আর সার্চিং হলো "টেক্সট ম্যাচিং"। যেমন: নামের মধ্যে "Rahim" আছে কিনা।

**কেন দরকার (সুবিধা):**
1.  গুগল সার্চের মতো সুবিধা পাওয়া যায়।
2.  ইউজার আংশিক নাম লিখলেও কাঙ্ক্ষিত রেজাল্ট পায়।

**লজিক (How it works):**
`searchTerm` প্যারামিটার নেওয়া হয়। তারপর `Contains` মেথড ব্যবহার করা হয়।
*   কোড: `.Where(e => e.Name.ToLower().Contains(searchTerm.Trim().ToLower()))`

**উদাহরণ:**
*   **Request:** `GET /api/employees?searchTerm=jo`
*   **Result:** "John", "Jonathan", "Banjo" — যাদের নামের সাথে "jo" আছে সবাই আসবে।

---

### ৪. সর্টিং (Sorting)

**কি কাজ করে:**
ডাটাকে নির্দিষ্ট অর্ডারে সাজানো। যেমন: নাম অনুযায়ী (A-Z) বা বয়স অনুযায়ী (Low to High)।

**কেন দরকার (সুবিধা):**
1.  ডাটা দেখতে এবং বিশ্লেষণ করতে সুবিধা হয়।
2.  রিপোর্টিংয়ের কাজে লাগে।

**লজিক (How it works):**
সাধারনত আমরা লিনক-এ `OrderBy(x => x.Name)` লিখি। কিন্তু এপিআই-তে ইউজার স্ট্রিং হিসেবে পাঠায় `"name desc"`, বা `"age asc"`।
বইটিতে **Dynamic LINQ** বা **System.Linq.Dynamic.Core** ব্যবহার করে দেখানো হয়েছে কীভাবে স্ট্রিং থেকে কুয়েরি তৈরি করতে হয়।

**উদাহরণ:**
*   **Request:** `GET /api/employees?orderBy=name desc`
*   **Result:** নামের উল্টো অর্ডারে (Z-A) ডাটা আসবে।
*   **Multi-sort:** `orderBy=name, age desc` (প্রথমে নাম দিয়ে, নাম এক হলে বয়স দিয়ে সর্ট হবে)।

### ৫. মেটাডাটা (MetaData / Paging Header)

**কি কাজ করে:**
পেজিং করার সময় ইউজারকে ডাটার পাশাপাশি কিছু অতিরিক্ত তথ্য দিতে হয়। যেমন:
*   TotalPages: মোট কতটি পেজ আছে?
*   TotalCount: মোট কতটি ডাটা আছে?
*   HasNext: পরের পেজ কি আছে?

এই তথ্যগুলো রেসপন্স বডিতে না দিয়ে **Response Header**-এ `X-Pagination` নামে পাঠানো হয়।

**কেন দরকার:**
ফ্রন্টএন্ড ডেভেলপার (React/Angular) এই তথ্য ব্যবহার করে পেজিশন বার (1, 2, 3, Next...) তৈরি করতে পারে।

### ২. প্যারামিটার ক্লাস (Request Parameters)
সবগুলো ফিচার কন্ট্রোল করার জন্য আমরা একটা ক্লাস বানাব যা ইউজারের পাঠানো কুয়েরি স্ট্রিংগুলো ধরবে।

**বেস ক্লাস (Shared/RequestFeatures):**
প্রথমে পেজিং এর কমন লজিকগুলোর জন্য একটা বেস ক্লাস বানাই।

**ফাইল:** `Shared/RequestFeatures/RequestParameters.cs`
```csharp
public abstract class RequestParameters
{
    const int maxPageSize = 50; // ইউজার চাইলেও ৫০ এর বেশি ডাটা একবারে নিতে পারবে না
    public int PageNumber { get; set; } = 1; // ডিফল্ট ১ নম্বর পেজ

    private int _pageSize = 10; // ডিফল্ট ১০টি ডাটা
    public int PageSize
    {
        get { return _pageSize; }
        set { _pageSize = (value > maxPageSize) ? maxPageSize : value; }
    }

    public string? OrderBy { get; set; } // সর্টিং এর জন্য
}
```

**এমপ্লয়ি প্যারামিটার ক্লাস:**
এখানে ফিল্টারিং এবং সার্চিং এর প্রপার্টি থাকবে।

**ফাইল:** `Shared/RequestFeatures/EmployeeParameters.cs`
```csharp
public class EmployeeParameters : RequestParameters
{
    // Filtering: বয়সের রেঞ্জ দিয়ে ফিল্টার
    public uint MinAge { get; set; }
    public uint MaxAge { get; set; } = int.MaxValue;
    
    // ভ্যালিডেশন: মিন এইজ যেন ম্যাক্স এইজের চেয়ে বড় না হয়
    public bool ValidAgeRange => MaxAge > MinAge;

    // Searching: নাম দিয়ে খোঁজা
    public string? SearchTerm { get; set; }
}
```

### ৩. পেজড লিস্ট (PagedList Helper)
ডাটার সাথে মেটাডাটা (TotalCount, TotalPages) রাখার জন্য একটি কাস্টম লিস্ট ক্লাস।

**ফাইল:** `Shared/RequestFeatures/PagedList.cs`
```csharp
public class PagedList<T> : List<T>
{
    public MetaData MetaData { get; set; }

    public PagedList(List<T> items, int count, int pageNumber, int pageSize)
    {
        MetaData = new MetaData
        {
            TotalCount = count,
            PageSize = pageSize,
            CurrentPage = pageNumber,
            TotalPages = (int)Math.Ceiling(count / (double)pageSize)
        };

        AddRange(items);
    }

    public static PagedList<T> ToPagedList(IEnumerable<T> source, int pageNumber, int pageSize)
    {
        var count = source.Count();
        // Skip এবং Take ব্যবহার করে পেজিং করা হচ্ছে
        var items = source
            .Skip((pageNumber - 1) * pageSize)
            .Take(pageSize)
            .ToList();

        return new PagedList<T>(items, count, pageNumber, pageSize);
    }
}
```
*(MetaData ক্লাসটি সাধারণ একটি ক্লাস যাতে TotalCount, TotalPages প্রপার্টি আছে)*

### ৪. রিপোজিটরি এক্সটেনশন (Repository Extensions)
কোড ক্লিন রাখার জন্য ফিল্টারিং এবং সর্টিং লজিকগুলো আমরা `Extension Method` এ লিখব।

**ফাইল:** `Repository/Extensions/RepositoryEmployeeExtensions.cs`
```csharp
using System.Linq.Dynamic.Core; // ডায়নামিক সর্টিং এর জন্য
using Entities.Models;

namespace Repository.Extensions
{
    public static class RepositoryEmployeeExtensions
    {
        // ১. ফিল্টারিং (Filtering)
        public static IQueryable<Employee> FilterEmployees(this IQueryable<Employee> employees, uint minAge, uint maxAge) =>
            employees.Where(e => e.Age >= minAge && e.Age <= maxAge);

        // ২. সার্চিং (Searching)
        public static IQueryable<Employee> Search(this IQueryable<Employee> employees, string searchTerm)
        {
            if (string.IsNullOrWhiteSpace(searchTerm))
                return employees;

            var lowerCaseTerm = searchTerm.Trim().ToLower();
            return employees.Where(e => e.Name.ToLower().Contains(lowerCaseTerm));
        }

        // ৩. সর্টিং (Sorting)
        public static IQueryable<Employee> Sort(this IQueryable<Employee> employees, string orderByQueryString)
        {
            if (string.IsNullOrWhiteSpace(orderByQueryString))
                return employees.OrderBy(e => e.Name); // ডিফল্ট সর্টিং

            // System.Linq.Dynamic.Core এর জাদুকরী মেথড। এটি স্ট্রিং (যেমন: "age desc") কে LINQ কুয়েরিতে রূপান্তর করে।
            return employees.OrderBy(orderByQueryString); 
        }
    }
}
```

### ৫. রিপোজিটরি ইমপ্লিমেন্টেশন
এখন এক্সটেনশন মেথডগুলো ব্যবহার করে ডাটা আনার মেথড আপডেট করব।

**ফাইল:** `Repository/EmployeeRepository.cs`
```csharp
public PagedList<Employee> GetEmployees(Guid companyId, EmployeeParameters employeeParameters, bool trackChanges)
{
    var employees = FindByCondition(e => e.CompanyId.Equals(companyId), trackChanges)
        .FilterEmployees(employeeParameters.MinAge, employeeParameters.MaxAge) // ফিল্টার
        .Search(employeeParameters.SearchTerm) // সার্চ
        .Sort(employeeParameters.OrderBy)      // সর্ট
        .ToList(); // এখানে ডাটাবেস থেকে সব ফিল্টার করা ডাটা আসবে

    // পেজিং শেষে অ্যাপ্লাই করা হয়
    return PagedList<Employee>.ToPagedList(employees, employeeParameters.PageNumber, employeeParameters.PageSize);
}
```

### ৬. কন্ট্রোলার (Controller)
হেডারে মেটাডাটা পাঠানো এবং প্যারামিটার রিসিভ করা।

**ফাইল:** `Presentation/Controllers/EmployeesController.cs`
```csharp
[HttpGet]
public IActionResult GetEmployeesForCompany(Guid companyId, [FromQuery] EmployeeParameters employeeParameters)
{
    // ১. ভ্যালিডেশন চেক (MinAge > MaxAge কিনা)
    if (!employeeParameters.ValidAgeRange)
        return BadRequest("Max age can't be less than min age.");

    // ২. সার্ভিস থেকে পেজড ডাটা আনা
    var pagedResult = _service.EmployeeService.GetEmployees(companyId, employeeParameters, trackChanges: false);

    // ৩. রেসপন্স হেডার এ মেটাডাটা পাঠানো
    Response.Headers.Add("X-Pagination", JsonSerializer.Serialize(pagedResult.MetaData));

    return Ok(pagedResult.Employees);
}
```
