
**Chapter 9**-এর নাম হলো **"Data Shaping and HATEOAS"**।

এটি একটি অ্যাডভান্সড চ্যাপ্টার। এর আগের চ্যাপ্টারগুলোতে আমরা ডাটা ফিল্টার বা সর্ট করেছি, কিন্তু পুরো অবজেক্টটাই রিটার্ন করেছি। এই চ্যাপ্টারে আমরা শিখব ইউজারকে **ঠিক যতটুকু দরকার, ততটুকু ডাটা** দেওয়া (Data Shaping) এবং ডাটার সাথে **অ্যাকশন লিংক** পাঠিয়ে দেওয়া (HATEOAS)।

নিচে বিস্তারিত আলোচনা করা হলো:

---

### ১. ডাটা শেপিং (Data Shaping)

**কি কাজ করে:**
সাধারণত এপিআই থেকে আমরা পুরো অবজেক্ট রিটার্ন করি। যেমন: `Employee` চাইলে তার `Id`, `Name`, `Age`, `Position`, `Salary` সব চলে আসে।
ডাটা শেপিং-এর মাধ্যমে ক্লায়েন্ট বলে দিতে পারে, "আমার শুধু `Name` আর `Age` দরকার, বাকিগুলো দিও না।"

**কেন দরকার (Why & Benefits):**
১. **ব্যান্ডউইথ কমায়:** মোবাইলে ইন্টারনেট স্লো থাকলে বড় ডাটা লোড হতে সময় নেয়। ডাটা শেপিং করলে রেসপন্স সাইজ অনেক ছোট হয়ে যায়।
২. **ফ্লেক্সিবিলিটি:** একই এপিআই ওয়েব এবং মোবাইল অ্যাপে ভিন্ন ভিন্ন ডাটা দেখাতে পারে। ওয়েবে হয়তো সব ডিটেইলস লাগবে, কিন্তু মোবাইলের লিস্ট ভিউতে শুধু নাম লাগবে।

**কিভাবে কাজ করে (Mechanism):**
আমরা `fields` নামে একটি কুয়েরি স্ট্রিং রিসিভ করি। তারপর **C# Reflection** ব্যবহার করে রানটাইমে ওই অবজেক্টের প্রপার্টিগুলো চেক করি। যেগুলো মিলে যায়, সেগুলোকে একটি ডায়নামিক অবজেক্টে (`ExpandoObject`) ঢুকিয়ে রিটার্ন করি।

**উদাহরণ:**
*   **সাধারণ রিকোয়েস্ট:** `GET /api/employees`
    *   **রেসপন্স:** `[ { "id": 1, "name": "A", "age": 20, "address": "Dhaka" } ]`
*   **Data Shaping রিকোয়েস্ট:** `GET /api/employees?fields=name,age`
    *   **রেসপন্স:** `[ { "name": "A", "age": 20 } ]`
    *(লক্ষ্য করুন: id এবং address গায়েব হয়ে গেছে)*

### ২. HATEOAS (Hypermedia as the Engine of Application State)

**কি কাজ করে:**
এটি REST API-এর সর্বোচ্চ লেভেল (Level 3 Maturity Model)।
সাধারণত এপিআই শুধু ডাটা দেয়। কিন্তু HATEOAS ডাটার সাথে **লিংক (Links)** দেয়। মানে, এই ডাটা দিয়ে ইউজার আর কী কী করতে পারবে, তার URL গুলো ডাটার সাথেই পাঠিয়ে দেওয়া হয়।

**কেন দরকার (Why & Benefits):**
১. **সেলফ-ডিসকভারেবল (Self-Discoverable):** ডেভেলপারকে ডকুমেন্টেশন মুখস্থ করতে হয় না। রেসপন্স দেখেই বোঝা যায় আপডেট বা ডিলিট করার লিংক কী।
২. **লুজলি কাপলড (Loosely Coupled):** সার্ভারে যদি কখনো URL পরিবর্তন হয় (যেমন: `delete` এর লিংক পাল্টে গেল), ক্লায়েন্ট কোড ভাঙবে না, কারণ ক্লায়েন্ট হার্ডকোড করা URL ব্যবহার না করে লিংকের `rel` (relation) নাম ব্যবহার করে।

**উদাহরণ:**
ধরি আপনি একজন এমপ্লয়ির তথ্য চাইলেন। HATEOAS সহ রেসপন্সটি দেখতে এমন হবে:

```json
{
    "name": "Rahim",
    "age": 25,
    "links": [
        {
            "href": "https://localhost:5001/api/employees/1",
            "rel": "self",
            "method": "GET"
        },
        {
            "href": "https://localhost:5001/api/employees/1",
            "rel": "delete_employee",
            "method": "DELETE"
        },
        {
            "href": "https://localhost:5001/api/employees/1",
            "rel": "update_employee",
            "method": "PUT"
        }
    ]
}
```
*   এখানে `links` অ্যারে দেখে ক্লায়েন্ট বুঝতে পারছে সে এই এমপ্লয়িকে **Delete** বা **Update** করতে পারবে এবং তার জন্য কোন মেথড ব্যবহার করতে হবে।

### ১. ডাটা শেপিং (Data Shaping) সেটআপ

ডাটা শেপিংয়ের জন্য আমাদের একটি জেনেরিক ক্লাস দরকার যা রানটাইমে অবজেক্টের প্রপার্টিগুলো বেছে নিয়ে একটি ডায়নামিক অবজেক্ট তৈরি করবে।

**ধাপ ১: IDataShaper ইন্টারফেস**
**ফাইল:** `Contracts/IDataShaper.cs`
```csharp
using System.Dynamic;

public interface IDataShaper<T>
{
    // একটি অবজেক্টের জন্য
    ExpandoObject ShapeData(T entity, string fieldsString);
    
    // লিস্ট বা কালেকশনের জন্য
    IEnumerable<ExpandoObject> ShapeData(IEnumerable<T> entities, string fieldsString);
}
```

**ধাপ ২: DataShaper ইমপ্লিমেন্টেশন**
এখানে রিফ্লেকশন ব্যবহার করে প্রপার্টি ফিল্টার করা হয়।

**ফাইল:** `Service/DataShaping/DataShaper.cs`
```csharp
using System.Dynamic;
using System.Reflection;

public class DataShaper<T> : IDataShaper<T> where T : class
{
    // সব প্রপার্টি (যেমন: Name, Age, Id) ক্যাশ করে রাখা হয়
    public PropertyInfo[] Properties { get; set; }

    public DataShaper()
    {
        Properties = typeof(T).GetProperties(BindingFlags.Public | BindingFlags.Instance);
    }

    public ExpandoObject ShapeData(T entity, string fieldsString)
    {
        var requiredProperties = GetRequiredProperties(fieldsString);
        return FetchDataForEntity(entity, requiredProperties);
    }
    
    // ... ShapeData for IEnumerable একই লজিক ব্যবহার করবে ...

    // এই মেথডটি স্ট্রিং (যেমন: "name, age") থেকে প্রপার্টি ইনফো খুঁজে বের করে
    private IEnumerable<PropertyInfo> GetRequiredProperties(string fieldsString)
    {
        var requiredProperties = new List<PropertyInfo>();

        if (!string.IsNullOrWhiteSpace(fieldsString))
        {
            var fields = fieldsString.Split(',', StringSplitOptions.RemoveEmptyEntries);
            foreach (var field in fields)
            {
                var property = Properties.FirstOrDefault(pi => pi.Name.Equals(field.Trim(), StringComparison.InvariantCultureIgnoreCase));
                if (property != null) requiredProperties.Add(property);
            }
        }
        else
        {
            requiredProperties = Properties.ToList(); // কিছু না বললে সব প্রপার্টি দাও
        }
        return requiredProperties;
    }

    // এই মেথডটি ডায়নামিক অবজেক্ট তৈরি করে ভ্যালু অ্যাসাইন করে
    private ExpandoObject FetchDataForEntity(T entity, IEnumerable<PropertyInfo> requiredProperties)
    {
        var shapedObject = new ExpandoObject();
        foreach (var property in requiredProperties)
        {
            var objectPropertyValue = property.GetValue(entity);
            // ExpandoObject মূলত একটি ডিকশনারির মতো কাজ করে
            shapedObject.TryAdd(property.Name, objectPropertyValue);
        }
        return shapedObject;
    }
}
```

**ধাপ ৩: সার্ভিস রেজিস্ট্রেশন**
`Program.cs` এ এটি রেজিস্টার করতে হবে।

### ২. HATEOAS সেটআপ

HATEOAS এর জন্য আমাদের লিংক জেনারেট করতে হবে এবং রেসপন্সের সাথে যুক্ত করতে হবে।

**ধাপ ১: Link মডেল**
লিংকগুলো কেমন দেখতে হবে তার একটি মডেল।

**ফাইল:** `Entities/LinkModels/Link.cs`
```csharp
public class Link
{
    public string? Href { get; set; } // URL
    public string? Rel { get; set; }  // Relation (e.g., "self", "update")
    public string? Method { get; set; } // GET, POST, PUT

    public Link(string href, string rel, string method)
    {
        Href = href;
        Rel = rel;
        Method = method;
    }
}
```

**ধাপ ২: কাস্টম মিডিয়া টাইপ সেটআপ**
HATEOAS সাধারণত ডিফল্ট JSON এ না পাঠিয়ে কাস্টম হেডারে পাঠানো হয় (বইয়ের রিকমেন্ডেশন)।
`Program.cs` এ মিডিয়া টাইপ অ্যাড করতে হবে:
```csharp
builder.Services.AddControllers(config =>
{
    config.RespectBrowserAcceptHeader = true;
    config.ReturnHttpNotAcceptable = true;
})
.AddXmlDataContractSerializerFormatters()
.AddMvcOptions(options =>
{
    // কাস্টম মিডিয়া টাইপ সাপোর্ট যোগ করা
    //vnd = vendor, hateoas = feature, json = format
    var formatter = options.OutputFormatters.OfType<SystemTextJsonOutputFormatter>().FirstOrDefault();
    formatter?.SupportedMediaTypes.Add("application/vnd.codemaze.hateoas+json");
});
```

### ৩. লিংকিং এবং শেপিং একসাথে ব্যবহার (Controller & Utility)

বইটিতে `EmployeeLinks` নামে একটি ইউটিলিটি ক্লাস বানানো হয়েছে যা লিংকিং লজিক হ্যান্ডেল করে।

**ফাইল:** `Utility/EmployeeLinks.cs`
```csharp
public class EmployeeLinks : IEmployeeLinks
{
    private readonly LinkGenerator _linkGenerator; // .NET এর বিল্ট-ইন লিংক জেনারেটর
    private readonly IDataShaper<EmployeeDto> _dataShaper;

    public EmployeeLinks(LinkGenerator linkGenerator, IDataShaper<EmployeeDto> dataShaper)
    {
        _linkGenerator = linkGenerator;
        _dataShaper = dataShaper;
    }

    public LinkResponse ReturnLinkedEmployees(IEnumerable<EmployeeDto> employeesDto, string fields, Guid companyId, HttpContext httpContext, bool shapedOnly)
    {
        var shapedEmployees = _dataShaper.ShapeData(employeesDto, fields);

        if (shapedOnly) // যদি ক্লায়েন্ট HATEOAS না চায়
            return new LinkResponse { ShapedEntities = shapedEmployees };

        // লিংক তৈরি করা
        var employeeCollection = new List<Entity>();
        foreach(var emp in shapedEmployees) 
        {
            var empDict = emp as IDictionary<string, object>;
            var id = (Guid)empDict["Id"]; // ডাটা শেপিং থেকে আইডি বের করা
            
            // লিংক জেনারেট করা
            var links = CreateLinksForEmployee(httpContext, companyId, id, fields);
            
            // লিংকের সাথে ডাটা মার্জ করা
            empDict.Add("Links", links);
            employeeCollection.Add(empDict); // সমস্যা সমাধানের জন্য বইতে কাস্টম Entity র‍্যাপার ব্যবহার করা হয়েছে
        }
        
        return new LinkResponse { HasLinks = true, LinkedEntities = employeeCollection };
    }

    private List<Link> CreateLinksForEmployee(HttpContext httpContext, Guid companyId, Guid id, string fields = "")
    {
        var links = new List<Link>
        {
            new Link(_linkGenerator.GetUriByAction(httpContext, "GetEmployeeForCompany", values: new { companyId, id, fields }), "self", "GET"),
            new Link(_linkGenerator.GetUriByAction(httpContext, "DeleteEmployeeForCompany", values: new { companyId, id }), "delete_employee", "DELETE"),
            new Link(_linkGenerator.GetUriByAction(httpContext, "UpdateEmployeeForCompany", values: new { companyId, id }), "update_employee", "PUT")
        };
        return links;
    }
}
```

### ৪. কন্ট্রোলার আপডেট (Controller Implementation)

এখন কন্ট্রোলারে চেক করব ইউজার কি সাধারণ JSON চেয়েছে নাকি HATEOAS চেয়েছে।

**ফাইল:** `Presentation/Controllers/EmployeesController.cs`
```csharp
[HttpGet]
[ServiceFilter(typeof(ValidateMediaTypeAttribute))] // মিডিয়া টাইপ ভ্যালিডেশনের জন্য ফিল্টার
public IActionResult GetEmployeesForCompany(Guid companyId, [FromQuery] EmployeeParameters employeeParameters)
{
    // ১. ডাটা আনা
    var pagedResult = _service.EmployeeService.GetEmployees(companyId, employeeParameters, trackChanges: false);
    
    // ২. HATEOAS এবং Data Shaping লজিক (Utility ক্লাস ব্যবহার করে)
    var linkParams = new LinkParameters(employeeParameters, HttpContext);
    var result = _employeeLinks.ReturnLinkedEmployees(pagedResult.Employees, employeeParameters.Fields, companyId, HttpContext, pagedResult.MetaData);

    // ৩. রেসপন্স
    return result.HasLinks ? Ok(result.LinkedEntities) : Ok(result.ShapedEntities);
}
```

### ৫. উদাহরণ (Example Scenarios)

**Scenario 1: Data Shaping Only**
*   **Request:** `GET .../employees?fields=name,age`
*   **Header:** `Accept: application/json`
*   **Response:**
    ```json
    [
        { "Name": "Rahim", "Age": 30 },
        { "Name": "Karim", "Age": 25 }
    ]
    ```

**Scenario 2: HATEOAS + Data Shaping**
*   **Request:** `GET .../employees?fields=name,age`
*   **Header:** `Accept: application/vnd.codemaze.hateoas+json`
*   **Response:**
    ```json
    [
        {
            "Name": "Rahim",
            "Age": 30,
            "Links": [
                {
                    "href": "https://.../api/companies/.../employees/...",
                    "rel": "self",
                    "method": "GET"
                },
                {
                    "href": "https://.../api/companies/.../employees/...",
                    "rel": "delete_employee",
                    "method": "DELETE"
                }
            ]
        }
    ]
    ```

এভাবেই ডাটা শেপিং এবং HATEOAS ইমপ্লিমেন্ট করে আপনার API এখন অনেক বেশি ডায়নামিক এবং স্মার্ট হলো।
