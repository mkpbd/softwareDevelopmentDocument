
**Chapter 14**-এর নাম হলো **"JWT Authentication"**।

এতক্ষণ আমাদের এপিআই খোলা ছিল, যে কেউ ডাটা দেখতে পারত বা ডিলিট করতে পারত। এখন আমরা এপিআইকে তালা-চাবি দিয়ে বন্ধ করব। অর্থাৎ, শুধু রেজিস্টার্ড ইউজাররাই এপিআই ব্যবহার করতে পারবে।

এর জন্য আমরা **ASP.NET Core Identity** এবং **JWT (JSON Web Token)** ব্যবহার করব।

---

### ১. আইডেন্টিটি (ASP.NET Core Identity)

**কি কাজ করে:**
এটি .NET এর একটি বিল্ট-ইন মেম্বারশিপ সিস্টেম। এটি ইউজার তৈরি, পাসওয়ার্ড হ্যাশ করা, লগইন ভ্যালিডেট করা এবং রোল (Role) ম্যানেজ করার কাজ করে।

**কেন দরকার:**
নিজের হাতে ইউজার টেবিল বা লগইন সিস্টেম বানানো খুব কঠিন এবং সিকিউর করা কষ্টসাধ্য। আইডেন্টিটি লাইব্রেরি এগুলো সব রেডিমেড দেয় এবং এটি ইন্ডাস্ট্রিয়াল স্ট্যান্ডার্ড সিকিউরিটি মেইনটেইন করে।

**উদাহরণ:**
*   `UserManager`: ইউজার তৈরি বা খোঁজার জন্য।
*   `RoleManager`: অ্যাডমিন বা ইউজার রোল তৈরির জন্য।

---

### ২. জেডব্লিউটি (JWT - JSON Web Token)

**কি কাজ করে:**
এটি একটি ডিজিটাল পাস বা টিকিটের মতো।
১. ইউজার যখন ইউজারনেম-পাসওয়ার্ড দিয়ে লগইন করে, সার্ভার তাকে একটি বড় এনক্রিপ্টেড স্ট্রিং (Token) দেয়।
২. এর পর থেকে ইউজার যতবার এপিআই কল করবে, তাকে হেডারে এই টোকেনটি পাঠাতে হবে।
৩. সার্ভার টোকেন চেক করে দেখবে এটি আসল কি না। আসল হলে ডাটা দেবে, নকল হলে `401 Unauthorized` দেবে।

**কেন দরকার (Why JWT?):**
*   **Stateless:** সার্ভারে সেশন বা কুকি রাখার দরকার হয় না। সার্ভার টোকেন দেখেই ইউজারকে চিনে ফেলে।
*   **Mobile Friendly:** মোবাইল অ্যাপে কুকি ম্যানেজ করা ঝামেলার, টোকেন পাঠানো সহজ।

**টোকেনের ভেতরে কী থাকে?**
টোকেনটি ডিকোড করলে তিনটি অংশ দেখা যায়:
১. **Header:** অ্যালগরিদম কী (যেমন: HS256)।
২. **Payload (Claims):** ইউজারের তথ্য (যেমন: নাম, রোল, এক্সপায়ার ডেট)।
    *   `sub`: User ID
    *   `exp`: Expiration Time
    *   `role`: Admin/Manager
３. **Signature:** সিক্রেট কি (Secret Key) দিয়ে সাইন করা অংশ। কেউ টোকেন এডিট করলে সিগনেচার মিলবে না।

---

### ৩. রিফ্রেশ টোকেন (Refresh Token)

**সমস্যা:**
সিকিউরিটির জন্য অ্যাক্সেস টোকেনের মেয়াদ কম রাখা হয় (যেমন: ৫ মিনিট)। ৫ মিনিট পর ইউজারকে আবার লগইন করতে বলাটা বিরক্তিকর।

**সমাধান (Refresh Token):**
লগইন করার সময় সার্ভার দুটি টোকেন দেয়:
১. **Access Token:** (মেয়াদ ৫ মিনিট) এপিআই কল করার জন্য।
২. **Refresh Token:** (মেয়াদ ৭ দিন) এটি দিয়ে নতুন অ্যাক্সেস টোকেন পাওয়া যায়।

যখন অ্যাক্সেস টোকেন এক্সপায়ার হয়ে যায়, অ্যাপ ব্যাকগ্রাউন্ডে রিফ্রেশ টোকেন পাঠিয়ে সার্ভার থেকে নতুন অ্যাক্সেস টোকেন নিয়ে আসে। ইউজার টেরই পায় না।

### ৪. অথেনটিকেশন বনাম অথোরাইজেশন

*   **Authentication:** "তুমি কে?" (লগইন করা)।
*   **Authorization:** "তোমার কি পারমিশন আছে?" (যেমন: শুধু অ্যাডমিনরা কোম্পানি ডিলিট করতে পারবে)।

**কোডে ব্যবহার:**
*   `[Authorize]`: লগইন করা যে কেউ এক্সেস পাবে।
*   `[Authorize(Roles = "Administrator")]`: শুধু অ্যাডমিনরা এক্সেস পাবে।

### সারসংক্ষেপ

| টপিক | কাজ | কেন শিখব? |
| :--- | :--- | :--- |
| **Identity** | ইউজার ম্যানেজমেন্ট (রেজিস্ট্রেশন/লগইন)। | সিকিউর ইউজার ডাটাবেস তৈরির জন্য। |
| **JWT** | ডিজিটাল চাবি বা এক্সেস কার্ড। | এপিআইকে স্টেটলেস এবং সিকিউর রাখার জন্য। |
| **Refresh Token** | টোকেন রিনিউ করার মেকানিজম। | ইউজারকে বারবার লগইন করা থেকে মুক্তি দিতে। |

**সহজ উদাহরণ:**
আপনি অফিসে ঢোকার সময় আইডি কার্ড (JWT) পাঞ্চ করলেন। দারোয়ান (Middleware) চেক করল কার্ডটি এই অফিসের কি না। কার্ড ঠিক থাকলে ভেতরে যেতে দিল। কার্ডের মেয়াদ শেষ হলে এইচআর এর কাছ থেকে রিনিউ (Refresh) করে নিলেন।

### ১. মডেল এবং কনটেক্সট সেটআপ (Identity Setup)

প্রথমে আমাদের `User` এনটিটি লাগবে। .NET Identity এর ডিফল্ট `IdentityUser` ব্যবহার করা যায়, আমরা সেটাকেই এক্সটেন্ড করব।

**ধাপ ১: ইউজার মডেল (Entities Project)**
**ফাইল:** `Entities/Models/User.cs`
```csharp
using Microsoft.AspNetCore.Identity;

public class User : IdentityUser
{
    public string FirstName { get; set; }
    public string LastName { get; set; }
}
```

**ধাপ ২: ডাটাবেস কনটেক্সট আপডেট (Repository Project)**
`RepositoryContext` কে এখন `IdentityDbContext` থেকে ইনহেরিট করতে হবে।

**ফাইল:** `Repository/RepositoryContext.cs`
```csharp
using Microsoft.AspNetCore.Identity.EntityFrameworkCore; // এটা জরুরি

public class RepositoryContext : IdentityDbContext<User>
{
    public RepositoryContext(DbContextOptions options) : base(options)
    {
    }
    
    // ... Company, Employee DbSet ...

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        base.OnModelCreating(modelBuilder); // এটি আইডেন্টিটি টেবিলগুলো কনফিগার করে
        
        // কিছু ডিফল্ট রোল (Role) ডাটাবেসে সিড করা
        modelBuilder.ApplyConfiguration(new RoleConfiguration());
    }
}
```
*(নোট: এরপর `Add-Migration` এবং `Update-Database` কমান্ড চালাতে হবে)*

### ২. আইডেন্টিটি এবং JWT কনফিগারেশন (Configuration)

`ServiceExtensions.cs` এ আমরা আইডেন্টিটি রুলস এবং JWT সেটিংস কনফিগার করব।

**ফাইল:** `Extensions/ServiceExtensions.cs`
```csharp
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.IdentityModel.Tokens;
using System.Text;

// ১. আইডেন্টিটি কনফিগারেশন (পাসওয়ার্ড রুলস ইত্যাদি)
public static void ConfigureIdentity(this IServiceCollection services)
{
    var builder = services.AddIdentity<User, IdentityRole>(o =>
    {
        o.Password.RequireDigit = true;
        o.Password.RequireLowercase = false;
        o.Password.RequireUppercase = false;
        o.Password.RequireNonAlphanumeric = false;
        o.Password.RequiredLength = 10;
        o.User.RequireUniqueEmail = true;
    })
    .AddEntityFrameworkStores<RepositoryContext>()
    .AddDefaultTokenProviders();
}

// ২. JWT কনফিগারেশন (টোকেন ভ্যালিডেশন লজিক)
public static void ConfigureJWT(this IServiceCollection services, IConfiguration configuration)
{
    var jwtSettings = configuration.GetSection("JwtSettings");
    var secretKey = Environment.GetEnvironmentVariable("SECRET"); // সিক্রেট কি পরিবেশ ভেরিয়েবল থেকে নেওয়া

    services.AddAuthentication(opt =>
    {
        opt.DefaultAuthenticateScheme = JwtBearerDefaults.AuthenticationScheme;
        opt.DefaultChallengeScheme = JwtBearerDefaults.AuthenticationScheme;
    })
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            
            ValidIssuer = jwtSettings["validIssuer"],
            ValidAudience = jwtSettings["validAudience"],
            IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(secretKey))
        };
    });
}
```

**appsettings.json এ সেটিংস:**
```json
"JwtSettings": {
    "validIssuer": "CodeMazeAPI",
    "validAudience": "https://localhost:5001",
    "expires": 5
}
```
*(সিক্রেট কি `SECRET` এনভায়রনমেন্ট ভেরিয়েবলে সেট করতে হবে, যেমন: `CodeMazeSecretKey12345`)*

### ৩. অথেনটিকেশন সার্ভিস (Authentication Manager)

আমরা কন্ট্রোলারে সরাসরি সব লজিক না লিখে একটি `AuthenticationManager` বা সার্ভিস বানাব।

**DTOs:**
`UserForRegistrationDto` (FirstName, LastName, UserName, Password, Email)
`UserForAuthenticationDto` (UserName, Password)

**সার্ভিস লজিক:**
**ফাইল:** `Service/AuthenticationService.cs`
```csharp
public async Task<IdentityResult> RegisterUser(UserForRegistrationDto userForRegistration)
{
    var user = _mapper.Map<User>(userForRegistration);
    return await _userManager.CreateAsync(user, userForRegistration.Password);
}

public async Task<bool> ValidateUser(UserForAuthenticationDto userForAuth)
{
    var user = await _userManager.FindByNameAsync(userForAuth.UserName);
    // পাসওয়ার্ড চেক করা
    return (user != null && await _userManager.CheckPasswordAsync(user, userForAuth.Password));
}

public async Task<string> CreateToken()
{
    var user = await _userManager.FindByNameAsync(_user.UserName);
    
    // ক্লেইমস (Claims) তৈরি করা
    var claims = new List<Claim>
    {
        new Claim(ClaimTypes.Name, user.UserName),
        new Claim(ClaimTypes.NameIdentifier, user.Id)
        // রোল থাকলে রোলও অ্যাড করতে হবে
    };

    // টোকেন জেনারেট করা
    var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_configuration.GetSection("JwtSettings:Secret").Value)); // অথবা env variable
    var creds = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);
    
    var tokenOptions = new JwtSecurityToken(
        issuer: _jwtSettings["validIssuer"],
        audience: _jwtSettings["validAudience"],
        claims: claims,
        expires: DateTime.Now.AddMinutes(5), // ৫ মিনিট মেয়াদ
        signingCredentials: creds
    );

    return new JwtSecurityTokenHandler().WriteToken(tokenOptions);
}
```

### ৪. অথ কন্ট্রোলার (Auth Controller)

**ফাইল:** `Presentation/Controllers/AuthenticationController.cs`
```csharp
[Route("api/authentication")]
[ApiController]
public class AuthenticationController : ControllerBase
{
    private readonly IServiceManager _service;

    public AuthenticationController(IServiceManager service) => _service = service;

    [HttpPost]
    [ServiceFilter(typeof(ValidationFilterAttribute))]
    public async Task<IActionResult> RegisterUser([FromBody] UserForRegistrationDto userForRegistration)
    {
        var result = await _service.AuthenticationService.RegisterUser(userForRegistration);
        
        if (!result.Succeeded)
        {
            foreach (var error in result.Errors)
            {
                ModelState.TryAddModelError(error.Code, error.Description);
            }
            return BadRequest(ModelState);
        }

        return StatusCode(201);
    }

    [HttpPost("login")]
    [ServiceFilter(typeof(ValidationFilterAttribute))]
    public async Task<IActionResult> Authenticate([FromBody] UserForAuthenticationDto user)
    {
        // ইউজার ভ্যালিড কি না চেক করা
        if (!await _service.AuthenticationService.ValidateUser(user))
            return Unauthorized(); // 401

        // টোকেন তৈরি করা
        var tokenDto = await _service.AuthenticationService.CreateToken(populateExp: true);
        
        return Ok(tokenDto); // { "accessToken": "eyJ...", "expiresIn": ... }
    }
}
```

### ৬. উদাহরণ (Testing Flow)

**Step 1: Register**
*   **POST** `/api/authentication`
*   **Body:** `{ "firstName": "John", "lastName": "Doe", "userName": "john123", "password": "Password123!", "email": "john@mail.com" }`
*   **Response:** `201 Created`

**Step 2: Login**
*   **POST** `/api/authentication/login`
*   **Body:** `{ "userName": "john123", "password": "Password123!" }`
*   **Response:**
    ```json
    {
        "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "expiresIn": 300
    }
    ```

**Step 3: Access Protected API**
*   **GET** `/api/companies`
*   **Header:** `Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI...` (টোকেনটি এখানে পেস্ট করতে হবে)
*   **Response:** `200 OK` (ডাটা দেখা যাবে)

**Step 4: Without Token**
*   **GET** `/api/companies` (No Header)
*   **Response:** `401 Unauthorized`

এভাবেই আমরা আমাদের এপিআইকে আইডেন্টিটি এবং জেডব্লিউটি দিয়ে সম্পূর্ণ সিকিউর করলাম।
