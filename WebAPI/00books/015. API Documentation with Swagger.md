
**Chapter 15**-এর নাম হলো **"API Documentation with Swagger"**।

আমরা এতক্ষণ ধরে অনেকগুলো এপিআই বানালাম (GET, POST, PUT, DELETE, PATCH)। কিন্তু অন্য একজন ডেভেলপার (ধরুন ফ্রন্টএন্ড ডেভেলপার) কীভাবে বুঝবে কোন ইউআরএল-এ কী পাঠাতে হবে? বডি-তে কী জেসন (JSON) দিতে হবে?

এই সমস্যা সমাধানের জন্য এপিআই-এর একটি ম্যানুয়াল বা গাইডবুক দরকার। **Swagger (OpenAPI)** হলো সেই অটোমেটিক গাইডবুক।

---

### ১. সোয়্যাগার কী? (What is Swagger?)

**কি কাজ করে:**
এটি আপনার কোড স্ক্যান করে অটোমেটিক একটি সুন্দর ওয়েব পেজ তৈরি করে। সেখানে আপনার সব এপিআই-এর লিস্ট, ইনপুট ফরম্যাট, আউটপুট ফরম্যাট সব দেখা যায়। শুধু তাই নয়, ওই পেজ থেকেই সরাসরি এপিআই টেস্ট করা যায় (পোস্টম্যানের মতো)।

**কেন দরকার (Why):**
১. **ডকুমেন্টেশন:** ডেভেলপারদের জন্য ম্যানুয়ালি ডকুমেন্ট লেখার দরকার হয় না।
২. **ইন্টারঅ্যাক্টিভিটি:** "Try it out" বাটনে ক্লিক করে এপিআই টেস্ট করা যায়।
৩. **স্ট্যান্ডার্ড:** এটি OpenAPI স্পেসিফিকেশন মেনে চলে, যা সারা বিশ্বে স্বীকৃত।

---

### ২. কনফিগারেশন এবং কাস্টমাইজেশন

সাধারণত প্রোজেক্ট তৈরি করার সময়ই `Enable OpenAPI support` টিক দিলে বেসিক সোয়্যাগার চলে আসে। কিন্তু প্রোডাকশন লেভেলে আমাদের আরও কিছু কনফিগারেশন লাগে।

**ক. ইনফরমেশন কাস্টমাইজেশন:**
সোয়্যাগারের টাইটেল, ভার্সন, ডেসক্রিপশন, লাইসেন্স এবং কন্টাক্ট ইনফো পরিবর্তন করা যায়।
*   **উদাহরণ:** "Ultimate API v1", "Developed by Code Maze".

**খ. XML কমেন্টস (XML Comments):**
কোডের ওপর আমরা যে কমেন্ট লিখি (`/// <summary> Gets all companies </summary>`), সোয়্যাগার সেটা পড়তে পারে এবং ডকুমেন্টে দেখাতে পারে।
*   **সুবিধা:** এপিআই-এর প্রতিটি প্যারামিটারের ব্যাখ্যা সেখানে দেখা যায়।

**গ. অথেনটিকেশন সাপোর্ট (Security Definition):**
আমাদের এপিআই যেহেতু লক করা (JWT), সোয়্যাগার থেকে টেস্ট করতে গেলে সেখানেও টোকেন বসানোর জায়গা থাকতে হবে।
*   **কাজ:** কনফিগারেশনে `AddSecurityDefinition` যোগ করলে সোয়্যাগারের ডান কোণায় একটি **"Authorize"** বাটন আসে। সেখানে টোকেন পেস্ট করলে সোয়্যাগার অটোমেটিক হেডারে টোকেন পাঠিয়ে দেয়।

### ৩. সোয়্যাগার ইউআই (Swagger UI)

এটি হলো সেই ওয়েব পেজ (`/swagger/index.html`) যেখানে সব সুন্দর করে সাজানো থাকে।
আমরা চাইলে এই পেজের সিএসএস (CSS) পরিবর্তন করে এর লুক-এন্ড-ফিল বদলাতে পারি।

### ৪. ভার্সনিং সাপোর্ট

আমাদের এপিআই-এর দুটি ভার্সন আছে (v1, v2)। সোয়্যাগারকেও সেটা বোঝাতে হবে।
কনফিগার করলে সোয়্যাগার পেজের ওপরের ডান কোণায় একটি ড্রপডাউন মেনু আসে, যেখান থেকে `v1` বা `v2` সিলেক্ট করা যায়।

### সারসংক্ষেপ

| টপিক | কাজ | কেন শিখব? |
| :--- | :--- | :--- |
| **OpenAPI** | এপিআই-এর স্ট্যান্ডার্ড ব্লুপ্রিন্ট। | অন্য সিস্টেমের সাথে ইন্টিগ্রেশনের জন্য। |
| **Swagger UI** | ভিজ্যুয়াল ডকুমেন্টেশন পেজ। | ডেভেলপারদের জীবন সহজ করার জন্য। |
| **XML Comments** | কোডের কমেন্ট ডকুমেন্টে দেখানো। | এপিআই-এর বিস্তারিত ব্যাখ্যা দেওয়ার জন্য। |
| **Security** | সোয়্যাগারে লগইন বাটন যোগ করা। | সিকিউর এপিআই ব্রাউজার থেকে টেস্ট করার জন্য। |

**সহজ উদাহরণ:**
আপনি একটি রেস্টুরেন্টে (API) গেলেন।
*   **Swagger ছাড়া:** আপনি জানেন না কী কী খাবার আছে, ওয়েটারকে বারবার জিজ্ঞেস করতে হচ্ছে।
*   **Swagger সহ:** আপনার হাতে একটি সচিত্র মেনু কার্ড (Documentation) ধরিয়ে দেওয়া হলো। আপনি ছবি দেখে, দাম দেখে এবং ইনগ্রেডিয়েন্টস (Parameters) দেখে অর্ডার করতে পারছেন।

আমরা এখানে ৩টি কাজ করব:
১. বেসিক ইনফো সেটআপ।
২. অথেনটিকেশন (লক বাটন) যোগ করা।
৩. XML কমেন্ট এনাবল করা।

### ১. সেটআপ (Setup)

**ধাপ ১: প্যাকেজ চেক করা**
`Swashbuckle.AspNetCore` প্যাকেজটি ইন্সটল করা আছে কি না দেখে নিন। না থাকলে:
```powershell
Install-Package Swashbuckle.AspNetCore
```

**ধাপ ২: সার্ভিস এক্সটেনশন তৈরি (Service Configuration)**
আমরা `Extensions/ServiceExtensions.cs` ফাইলে সোয়্যাগার কনফিগার করব।

**ফাইল:** `Extensions/ServiceExtensions.cs`
```csharp
using Microsoft.OpenApi.Models;

public static void ConfigureSwagger(this IServiceCollection services)
{
    services.AddSwaggerGen(s =>
    {
        // ১. এপিআই ইনফরমেশন (টাইটেল, ভার্সন, কন্টাক্ট)
        s.SwaggerDoc("v1", new OpenApiInfo
        {
            Title = "Code Maze API",
            Version = "v1",
            Description = "CompanyEmployees API by CodeMaze",
            TermsOfService = new Uri("https://example.com/terms"),
            Contact = new OpenApiContact
            {
                Name = "John Doe",
                Email = "John.Doe@gmail.com",
                Url = new Uri("https://twitter.com/johndoe"),
            },
            License = new OpenApiLicense
            {
                Name = "CompanyEmployees API LICX",
                Url = new Uri("https://example.com/license"),
            }
        });
        
        // ভার্সন ২ থাকলে
        s.SwaggerDoc("v2", new OpenApiInfo { Title = "Code Maze API", Version = "v2" });

        // ২. XML কমেন্টস পাথ সেটআপ (যাতে কমেন্ট শো করে)
        var xmlFile = $"{typeof(Presentation.AssemblyReference).Assembly.GetName().Name}.xml";
        var xmlPath = Path.Combine(AppContext.BaseDirectory, xmlFile);
        s.IncludeXmlComments(xmlPath);

        // ৩. অথেনটিকেশন বাটন (JWT Support) যোগ করা
        s.AddSecurityDefinition("Bearer", new OpenApiSecurityScheme
        {
            In = ParameterLocation.Header,
            Description = "Place to add JWT with Bearer",
            Name = "Authorization",
            Type = SecuritySchemeType.ApiKey,
            Scheme = "Bearer"
        });

        s.AddSecurityRequirement(new OpenApiSecurityRequirement()
        {
            {
                new OpenApiSecurityScheme
                {
                    Reference = new OpenApiReference
                    {
                        Type = ReferenceType.SecurityScheme,
                        Id = "Bearer"
                    },
                    Name = "Bearer",
                },
                new List<string>()
            }
        });
    });
}
```

**ধাপ ৩: মিডলওয়্যার কনফিগারেশন**
`Program.cs` ফাইলে সোয়্যাগার মিডলওয়্যারটি প্রোডাকশনেও যেন চলে (যদি চান) বা শুধু ডেভেলপমেন্টে চলে তা সেট করা।

**ফাইল:** `Program.cs`
```csharp
// সার্ভিস কনফিগারেশন
builder.Services.ConfigureSwagger();

var app = builder.Build();

// মিডলওয়্যার পাইপলাইন
if (app.Environment.IsDevelopment()) // অথবা প্রোডাকশনে চাইলে if সরায়ে দিন
{
    app.UseSwagger();
    app.UseSwaggerUI(s =>
    {
        s.SwaggerEndpoint("/swagger/v1/swagger.json", "Code Maze API v1");
        s.SwaggerEndpoint("/swagger/v2/swagger.json", "Code Maze API v2");
    });
}
// ...
```

### ২. XML ডকুমেন্টেশন এনাবল করা

সোয়্যাগার যাতে আমাদের কোডের কমেন্ট পড়তে পারে, তার জন্য প্রোজেক্ট ফাইলে একটি সেটিং অন করতে হবে।

**ধাপ ১: csproj ফাইল এডিট**
`CompanyEmployees.Presentation` (যেখানে কন্ট্রোলার আছে) প্রোজেক্টের প্রোপার্টিজে যান অথবা `.csproj` ফাইলে নিচের লাইনটি যোগ করুন:

```xml
<PropertyGroup>
    <GenerateDocumentationFile>true</GenerateDocumentationFile>
    <NoWarn>$(NoWarn);1591</NoWarn> <!-- ওয়ার্নিং ইগনোর করার জন্য -->
</PropertyGroup>
```

**ধাপ ২: কন্ট্রোলারে কমেন্ট লেখা**
এখন আমরা কন্ট্রোলারের মেথডের ওপর `///` দিয়ে কমেন্ট লিখব।

**ফাইল:** `Presentation/Controllers/CompaniesController.cs`
```csharp
/// <summary>
/// Gets the list of all companies
/// </summary>
/// <returns>The list of companies</returns>
/// <response code="200">Returns all the companies from the database</response>
[HttpGet]
[ProducesResponseType(200)] 
public IActionResult GetCompanies()
{ ... }
```
*এই লেখাগুলো এখন সোয়্যাগার ইউআই-তে দেখা যাবে।*

### ৩. উদাহরণ (Testing Swagger)

১. **প্রোজেক্ট রান করুন:** `F5` চাপুন।
২. **ব্রাউজারে যান:** `https://localhost:5001/swagger/index.html`

**কী দেখবেন?**
*   **Header:** "Code Maze API" টাইটেল এবং কন্টাক্ট ইনফো।
*   **Version:** ডান দিকে ড্রপডাউনে `v1` এবং `v2` সিলেক্ট করার অপশন।
*   **Endpoints:** `Companies`, `Employees`, `Authentication` সব কন্ট্রোলারের লিস্ট।
*   **Authorize Button:** ডান দিকে একটি সবুজ/কালো তালা বাটন।

**কিভাবে টেস্ট করবেন?**
১. **লগইন:** প্রথমে `/api/authentication/login` এ গিয়ে `Try it out` এ ক্লিক করে ইউজারনেম-পাসওয়ার্ড দিয়ে লগইন করুন।
২. **টোকেন কপি:** রেসপন্স থেকে `accessToken` টি কপি করুন।
৩. **অথোরাইজ:** পেজের ওপরের **Authorize** বাটনে ক্লিক করুন। বক্সে লিখুন: `Bearer eyJhbGci...` (Bearer এর পর স্পেস দিয়ে টোকেন)। `Authorize` এ ক্লিক করুন।
৪. **সিকিউর এপিআই কল:** এখন `/api/companies` এ গিয়ে `Execute` করুন। দেখবেন ডাটা চলে এসেছে (401 Error আর আসবে না)।

এভাবেই আপনি একটি পূর্ণাঙ্গ এবং ইন্টারঅ্যাক্টিভ এপিআই ডকুমেন্টেশন তৈরি করলেন।

### ২. সার্ভিস কনফিগারেশন (Swagger Configuration)

আমরা `Extensions/ServiceExtensions.cs` ফাইলে একটি মেথড লিখব যা সোয়্যাগারের টাইটেল, ভার্সন, এবং সিকিউরিটি (JWT লক বাটন) কনফিগার করবে।

**ফাইল:** `Extensions/ServiceExtensions.cs`
```csharp
using Microsoft.Extensions.DependencyInjection;
using Microsoft.OpenApi.Models;

public static void ConfigureSwagger(this IServiceCollection services)
{
    services.AddSwaggerGen(s =>
    {

            {

                Url = new Uri("https://example.com/license"),
            }
        });

        // যদি v2 থাকে
        s.SwaggerDoc("v2", new OpenApiInfo { Title = "Code Maze API", Version = "v2" });

        // ২. XML কমেন্টস ফাইল লোড করা
        // Presentation অ্যাসেম্বলি থেকে XML ফাইলের নাম নেওয়া হচ্ছে
        var xmlFile = $"{typeof(Presentation.AssemblyReference).Assembly.GetName().Name}.xml";
        var xmlPath = Path.Combine(AppContext.BaseDirectory, xmlFile);
        
        // ফাইলটি লোড করা (যদি থাকে)
        s.IncludeXmlComments(xmlPath);

        // ৩. JWT অথেনটিকেশন বাটন (Authorize Button) যোগ করা
        s.AddSecurityDefinition("Bearer", new OpenApiSecurityScheme
        {
            In = ParameterLocation.Header,
            Description = "Please enter token",
            Name = "Authorization",
            Type = SecuritySchemeType.Http,
            BearerFormat = "JWT",
            Scheme = "bearer"
        });

        s.AddSecurityRequirement(new OpenApiSecurityRequirement
        {
            {
                new OpenApiSecurityScheme
                {
                    Reference = new OpenApiReference
                    {
                        Type = ReferenceType.SecurityScheme,
                        Id = "Bearer"
                    }
                },
                new string[] { }
            }
        });
    });
```

### ৫. উদাহরণ (Testing Example)

**ধাপ ১: ব্রাউজারে দেখা**
প্রোজেক্ট রান করে `https://localhost:5001/swagger` এ যান।
*   দেখবেন টাইটেল "Code Maze API"।
*   `GET /api/companies` এর পাশে লেখা থাকবে "Gets the list of all companies"।

**ধাপ ২: সিকিউর টেস্ট (Authorize Button)**
১. প্রথমে `/api/authentication/login` এ গিয়ে `Try it out` এ ক্লিক করুন।
   *   Body: `{ "userName": "test", "password": "Password123!" }`
   *   Execute করুন। রেসপন্স থেকে `accessToken` কপি করুন।
২. পেজের ওপরে ডান দিকে **Authorize** (তালা আইকন) বাটনে ক্লিক করুন।
   *   Value বক্সে শুধু টোকেন পেস্ট করুন (Bearer শব্দটা অটোমেটিক অ্যাড হবে যদি `Scheme = "bearer"` দেওয়া থাকে, অথবা ম্যানুয়ালি `Bearer <token>` লিখুন কনফিগারেশন অনুযায়ী)।
   *   `Authorize` চাপুন এবং `Close` করুন।
৩. এখন `/api/companies` এ গিয়ে `Execute` করুন।
   *   দেখবেন `200 OK` রেসপন্স আসছে। আগে টোকেন ছাড়া `401` আসত।
