বইটির স্ট্যান্ডার্ড ভার্সনে সাধারণত ১৯টি চ্যাপ্টারেই মূল কন্টেন্ট শেষ হয়। তবে কিছু এক্সটেন্ডেড ভার্সন বা লেখক Marinko-এর পরবর্তী গাইডলাইনে **"Microservices"** অথবা **"Advanced Architecture"** নিয়ে আলোচনা থাকতে পারে।

কিন্তু যেহেতু আপনি চ্যাপ্টার ২০ সম্পর্কে জানতে চেয়েছেন এবং এই সিরিজের লজিক্যাল নেক্সট স্টেপ হলো **Microservices** বা **Bonus Topics (Background Tasks, SignalR, etc.)**, আমি ধরে নিচ্ছি এটি একটি বোনাস বা অ্যাডভান্সড চ্যাপ্টার।

আসুন ধরে নিই এটি **"Background Tasks using Hosted Services"** বা **"SignalR"** নিয়ে (যা প্রায়ই ২০তম চ্যাপ্টার হিসেবে থাকে)। এখানে আমি **Background Tasks (IHostedService)** নিয়ে আলোচনা করছি, কারণ এপিআই ডেভেলপমেন্টে এটি খুবই কমন।

---

### ১. ব্যাকগ্রাউন্ড টাস্ক কী? (What is Background Task?)

**কি কাজ করে:**
আপনার এপিআই সাধারণত রিকোয়েস্ট আসার সাথে সাথে রেসপন্স দেয়। কিন্তু কিছু কাজ আছে যা করতে অনেক সময় লাগে (যেমন: ১০০০ জনকে ইমেইল পাঠানো, রোজ রাতে রিপোর্ট জেনারেট করা)।
এই কাজগুলো মেইন রিকোয়েস্টে না করে ব্যাকগ্রাউন্ডে (পর্দার আড়ালে) করা হয়।

**কেন দরকার (Why):**
ইউজারকে ৩ মিনিট অপেক্ষা করিয়ে রাখা খারাপ প্র্যাকটিস। ইউজারকে সাথে সাথে বলে দেওয়া হয় "কাজ শুরু হয়েছে", আর ব্যাকগ্রাউন্ডে আসল কাজ চলতে থাকে।

---

### ২. IHostedService এবং BackgroundService

.NET Core-এ ব্যাকগ্রাউন্ড টাস্ক রান করার জন্য বিল্ট-ইন ইন্টারফেস আছে।

**ক. IHostedService:**
এটিতে দুটি মেথড থাকে: `StartAsync` (অ্যাপ শুরুর সময় রান হয়) এবং `StopAsync` (অ্যাপ বন্ধের সময় রান হয়)।

**খ. BackgroundService:**
এটি `IHostedService` এর একটি অ্যাবস্ট্রাক্ট ক্লাস। আমরা সাধারণত এটিকেই ইনহেরিট করি এবং `ExecuteAsync` মেথডে আমাদের লজিক লিখি।

---

### ৩. টাইমার ও শিডিউলিং (Timer & Scheduling)

**কি কাজ করে:**
আপনি যদি চান প্রতি ১ ঘণ্টা পর পর ডাটাবেস ক্লিনআপ হবে, তবে টাইমার ব্যবহার করা হয়।

**উদাহরণ:**
```csharp
protected override async Task ExecuteAsync(CancellationToken stoppingToken)
{
    while (!stoppingToken.IsCancellationRequested)
    {
        // কাজ করো (যেমন: লগ ক্লিন করা)
        DoWork();
        
        // ১ ঘণ্টা অপেক্ষা করো
        await Task.Delay(TimeSpan.FromHours(1), stoppingToken);
    }
}
```

### ৪. কিউড ব্যাকগ্রাউন্ড টাস্ক (Queued Background Tasks)

**কি কাজ করে:**
ধরুন ইউজার রেজিস্ট্রেশন করল। আপনি সাথে সাথে তাকে ওয়েলকাম ইমেইল পাঠাতে চান, কিন্তু মেইন থ্রেড ব্লক না করে।
আপনি একটি **Background Queue**-তে "ইমেইল পাঠাও" মেসেজটি ফেলে দেন। ব্যাকগ্রাউন্ড সার্ভিস সেই কিউ থেকে মেসেজ নিয়ে ইমেইল পাঠায়।

**সুবিধা:**
এপিআই সুপার ফাস্ট থাকে, কারণ ভারী কাজগুলো ব্যাকগ্রাউন্ড ওয়ার্কার করে।

---

### ৫. সারসংক্ষেপ

| টপিক | কাজ | কেন শিখব? |
| :--- | :--- | :--- |
| **Hosted Service** | অ্যাপের লাইফসাইকেলের সাথে চলা সার্ভিস। | অ্যাপ স্টার্ট বা স্টপ হওয়ার সময় কিছু করার জন্য। |
| **Background Service** | দীর্ঘমেয়াদী কাজ চালানো। | শিডিউল টাস্ক বা ক্রন জব (Cron Job) এর মতো কাজ করার জন্য। |
| **Task Queue** | কাজের তালিকা। | ভারী কাজগুলো পরে করার জন্য জমিয়ে রাখা। |

**সহজ উদাহরণ:**
*   **API (Waiter):** কাস্টমারের অর্ডার নিল এবং কিচেনে স্লিপ দিয়ে দিল।
*   **Background Service (Chef):** কিচেনে ধীরে সুস্থে রান্না করছে।
*   **Queue:** অর্ডারের স্লিপের লাইন।
ওয়েটার (API) দাঁড়িয়ে না থেকে অন্য কাস্টমারের অর্ডার নিতে চলে গেল। শেফ (Background Service) তার মতো রান্না করে খাবার রেডি হলে বেল বাজিয়ে দিল।

==============================================================

যদি আমরা ধরে নিই **Chapter 20**-এ **Background Tasks (IHostedService)** নিয়ে কাজ করা হয়েছে, তবে আমরা একটি সিম্পল ব্যাকগ্রাউন্ড সার্ভিস বানাব যা প্রতি ১ মিনিট পর পর কনসোলে একটি মেসেজ প্রিন্ট করবে (বা লগ করবে)। এটি হতে পারে একটি "Health Monitor" বা "Data Cleaner" এর সিমুলেশন।

নিচে সেটআপ, কোড এবং উদাহরণ দেওয়া হলো।

### ১. সেটআপ (Setup)

ব্যাকগ্রাউন্ড সার্ভিসের জন্য আলাদা কোনো প্যাকেজ লাগে না, এটি .NET Core এর `Microsoft.Extensions.Hosting` লাইব্রেরির অংশ।

তবে আমরা আমাদের লজিকগুলো আলাদা রাখার জন্য একটি ফোল্ডার বানাতে পারি, নাম `BackgroundServices`।

---

### ২. ব্যাকগ্রাউন্ড সার্ভিস তৈরি (Creating Service)

আমরা `BackgroundService` ক্লাসকে ইনহেরিট করে একটি ক্লাস বানাব।

**ফাইল:** `BackgroundServices/DataMonitorService.cs`
```csharp
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;

namespace CompanyEmployees.BackgroundServices
{
    public class DataMonitorService : BackgroundService
    {
        private readonly ILogger<DataMonitorService> _logger;
        
        // টাইমার সেট করার জন্য
        private readonly TimeSpan _period = TimeSpan.FromSeconds(10); // প্রতি ১০ সেকেন্ডে রান হবে

        public DataMonitorService(ILogger<DataMonitorService> logger)
        {
            _logger = logger;
        }

        protected override async Task ExecuteAsync(CancellationToken stoppingToken)
        {
            // অ্যাপ যতক্ষণ বন্ধ না হচ্ছে, ততক্ষণ এই লুপ চলবে
            while (!stoppingToken.IsCancellationRequested)
            {
                _logger.LogInformation($"Background Service is running at: {DateTime.Now}");

                // এখানে আপনার আসল কাজ (Database Cleanup, Email Sending) হতে পারে
                await DoWorkAsync();

                // ১০ সেকেন্ড বিরতি
                await Task.Delay(_period, stoppingToken);
            }
        }

        private async Task DoWorkAsync()
        {
            // সিমুলেশন: ধরুন এখানে ভারী কোনো কাজ হচ্ছে
            await Task.Delay(100); 
            _logger.LogInformation("Data monitoring check completed.");
        }
    }
}
```

### ৩. সার্ভিস রেজিস্টার করা (Registration)

এই সার্ভিসটি কিন্তু কন্ট্রোলারের মতো অটোমেটিক কাজ করবে না। `Program.cs` এ একে `HostedService` হিসেবে রেজিস্টার করতে হবে।

**ফাইল:** `Program.cs` (বা `ServiceExtensions.cs`)

```csharp
using CompanyEmployees.BackgroundServices;

var builder = WebApplication.CreateBuilder(args);

// ... অন্যান্য সার্ভিস ...

// Hosted Service রেজিস্টার করা
builder.Services.AddHostedService<DataMonitorService>();

var app = builder.Build();
// ...
app.Run();
```

### ৫. অ্যাডভান্সড: স্কোপড সার্ভিস ব্যবহার করা (Scoped Service Issue)

একটি গুরুত্বপূর্ণ বিষয় হলো, `BackgroundService` হলো **Singleton** (অ্যাপ লাইফটাইমে একটাই থাকে)। কিন্তু আমাদের `RepositoryManager` হলো **Scoped** (প্রতি রিকোয়েস্টে নতুন তৈরি হয়)।
Singleton এর ভেতর Scoped সার্ভিস সরাসরি ইনজেক্ট করা যায় না। করলে এরর খাবেন।

**সমাধান:**
`IServiceScopeFactory` ব্যবহার করতে হবে।

**উদাহরণ (Database Access in Background):**
```csharp
public class DbCleanerService : BackgroundService
{
    private readonly IServiceScopeFactory _scopeFactory;

    public DbCleanerService(IServiceScopeFactory scopeFactory)
    {
        _scopeFactory = scopeFactory;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            // ম্যানুয়ালি স্কোপ তৈরি করা
            using (var scope = _scopeFactory.CreateScope())
            {
                // স্কোপ থেকে রিপোজিটরি বের করা
                var repository = scope.ServiceProvider.GetRequiredService<IRepositoryManager>();
                
                // এখন রিপোজিটরি ব্যবহার করা যাবে
                // await repository.Company.DeleteOldCompanies();
                // await repository.SaveAsync();
            }

            await Task.Delay(TimeSpan.FromHours(1), stoppingToken);
        }
    }
}
```

এভাবেই আপনি আপনার এপিআই-এর পেছনে দরকারি কাজগুলো (হাউজকিপিং) চালিয়ে যেতে পারেন।
