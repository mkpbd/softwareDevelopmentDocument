
সাধারণত "Ultimate ASP.NET Core Web API" বইয়ের শেষের দিকে বা বোনাস চ্যাপ্টার হিসেবে **Chapter 21**-এ **"Real-Time Communication with SignalR"** নিয়ে আলোচনা করা হয়।

এতক্ষণ আমরা যা শিখেছি তা ছিল **HTTP Request-Response** মডেল (ক্লায়েন্ট চাইলে সার্ভার দেয়)। কিন্তু **SignalR** এর মাধ্যমে সার্ভার নিজেই ক্লায়েন্টকে ধাক্কা দিয়ে (Push) ডাটা পাঠাতে পারে।

নিচে **SignalR** নিয়ে বিস্তারিত আলোচনা করা হলো:

---

### ১. সিগন্যাল-আর কী? (What is SignalR?)

**কি কাজ করে:**
এটি একটি ওপেন সোর্স লাইব্রেরি যা অ্যাপ্লিকেশনে **Real-Time Web Functionality** যোগ করতে সাহায্য করে।
সহজ কথায়, সার্ভারে কোনো ঘটনা ঘটার সাথে সাথে (Instantly) কানেক্টেড সব ইউজারকে সেই তথ্য পাঠিয়ে দেওয়া।

**কেন দরকার (Why):**
সাধারণ HTTP মডেলে, সার্ভারে নতুন ডাটা এসেছে কি না জানার জন্য ক্লায়েন্টকে বারবার রিফ্রেশ দিতে হয় বা পোলিং (Polling) করতে হয়।
SignalR ব্যবহার করলে রিফ্রেশ করার দরকার নেই। যেমন: ফেইসবুকের নোটিফিকেশন বা মেসেঞ্জারের চ্যাট। মেসেজ আসার সাথে সাথেই টং করে আওয়াজ হয়, পেজ রিফ্রেশ করতে হয় না।

---

### ২. এটি কীভাবে কাজ করে? (How it works)

SignalR মূলত **Hub (হাব)** কনসেপ্ট ব্যবহার করে।

১. **The Hub:** এটি সার্ভারের একটি সেন্ট্রাল পয়েন্ট বা টাওয়ার।
২. **Connection:** ক্লায়েন্ট (ব্রাউজার বা মোবাইল) এবং সার্ভারের মধ্যে একটি স্থায়ী পাইপলাইন (Persistent Connection) তৈরি হয়।
৩. **Push Mechanism:**
    *   সার্ভার যখন `SendMessage` মেথড কল করে, তখন হাবের সাথে যুক্ত সব ক্লায়েন্টের কাছে সেই মেসেজ চলে যায়।
    *   এটি **WebSockets** টেকনোলজি ব্যবহার করে (যা সবচেয়ে ফাস্ট)। যদি ব্রাউজার ওয়েব-সকেট সাপোর্ট না করে, তবে এটি অটোমেটিক অন্য পদ্ধতি (Server-Sent Events বা Long Polling) ব্যবহার করে।

---

### ৩. সুবিধা (Benefits)

*   **Real-time Update:** চ্যাট অ্যাপ, লাইভ স্কোরবোর্ড, স্টক মার্কেট গ্রাফ, গেমিং অ্যাপের জন্য আদর্শ।
*   **Reduced Traffic:** ক্লায়েন্টকে বারবার সার্ভারে রিকোয়েস্ট পাঠাতে হয় না ("ভাই নতুন মেসেজ আছে?"), তাই সার্ভারের ওপর চাপ কমে।
*   **Broadcast:** এক জায়গা থেকে হাজার হাজার ইউজারকে একসাথে মেসেজ পাঠানো যায়।

### ৪. উদাহরণ (Real-world Example)

ধরুন আপনি একটি **Company** তৈরি করলেন (POST Request)। আপনি চান সাথে সাথে সব অ্যাডমিনের ড্যাশবোর্ডে একটি পপ-আপ আসুক: *"New Company Created!"*।

*   **REST API:** অ্যাডমিনকে পেজ রিফ্রেশ করতে হবে নতুন কোম্পানি দেখার জন্য।
*   **SignalR:** অ্যাডমিন বসে থাকবে, সার্ভার অটোমেটিক তার স্ক্রিনে ডাটা পাঠিয়ে দেবে।

### সারসংক্ষেপ

| টপিক | কাজ | কেন শিখব? |
| :--- | :--- | :--- |
| **Hub** | সিগন্যাল-আর এর কমিউনিকেশন সেন্টার। | ক্লায়েন্ট এবং সার্ভারের মধ্যে যোগাযোগ রক্ষার জন্য। |
| **WebSockets** | দুই-মুখী যোগাযোগের প্রটোকল। | সুপার ফাস্ট ডাটা ট্রান্সফারের জন্য। |
| **IHubContext** | কন্ট্রোলার থেকে সিগন্যাল পাঠানোর টুল। | REST API এবং Real-time ফিচার একসাথে ব্যবহারের জন্য। |

**সহজ উদাহরণ:**
*   **REST API (ইমেইল):** আপনাকে ইনবক্স খুলে রিফ্রেশ করে দেখতে হয় নতুন মেইল এসেছে কি না।
*   **SignalR (ফোন কল):** কেউ কল করলে আপনার ফোন সাথে সাথে বেজে ওঠে। আপনাকে বারবার চেক করতে হয় না কেউ কল করছে কি না।

### কোড ইমপ্লিমেন্টেশন এবং উদাহরণ

আমরা একটি ছোট ফিচার বানাব: যখনই নতুন কোম্পানি তৈরি হবে, সব ইউজারকে নোটিফিকেশন পাঠানো হবে।

#### ১. সেটআপ (Setup)
SignalR এখন .NET Core এর সাথেই থাকে, আলাদা প্যাকেজ লাগে না (সার্ভারের জন্য)।

#### ২. হাব ক্লাস তৈরি (Hub Class)
এটি আমাদের কমিউনিকেশন টাওয়ার।

**ফাইল:** `HubConfig/BroadcastHub.cs`
```csharp
using Microsoft.AspNetCore.SignalR;

namespace CompanyEmployees.HubConfig
{
    // Hub ক্লাস থেকে ইনহেরিট করতে হবে
    public class BroadcastHub : Hub
    {
        // ক্লায়েন্টরা সরাসরি এই মেথড কল করে মেসেজ পাঠাতে পারে
        public async Task SendMessage(string message)
        {
            // "ReceiveMessage" ইভেন্টে যারা লিসেন করছে তাদের সবাইকে মেসেজ পাঠাও
            await Clients.All.SendAsync("ReceiveMessage", message);
        }
    }
}
```

#### ৩. প্রোগ্রাম ফাইলে কনফিগারেশন (Configuration)

**ফাইল:** `Program.cs` (বা `ServiceExtensions.cs`)
```csharp
// ১. সার্ভিস রেজিস্টার করা
builder.Services.AddSignalR();

var app = builder.Build();

// ২. মিডলওয়্যার এবং রাউট সেট করা
app.UseCors("CorsPolicy"); // SignalR এর জন্য CORS খুব গুরুত্বপূর্ণ

// ক্লায়েন্ট এই ইউআরএল এ কানেক্ট করবে (https://localhost:5001/notify)
app.MapHub<BroadcastHub>("/notify"); 

app.MapControllers();
app.Run();
```

*CORS কনফিগারেশনে `AllowCredentials()` অবশ্যই থাকতে হবে SignalR এর জন্য।*

#### ৪. কন্ট্রোলার থেকে মেসেজ পাঠানো (Send from Controller)

আমরা চাই যখন `CreateCompany` সফল হবে, তখন নোটিফিকেশন যাবে। এর জন্য `IHubContext` ব্যবহার করতে হবে।

**ফাইল:** `Presentation/Controllers/CompaniesController.cs`
```csharp
using Microsoft.AspNetCore.SignalR;
using CompanyEmployees.HubConfig;

public class CompaniesController : ControllerBase
{
    private readonly IServiceManager _service;
    private readonly IHubContext<BroadcastHub> _hubContext; // হাব ইনজেক্ট করা

    public CompaniesController(IServiceManager service, IHubContext<BroadcastHub> hubContext)
    {
        _service = service;
        _hubContext = hubContext;
    }

    [HttpPost]
    public async Task<IActionResult> CreateCompany([FromBody] CompanyForCreationDto company)
    {
        var createdCompany = _service.CompanyService.CreateCompany(company);

        // --- SignalR Magic ---
        // কোম্পানি তৈরির পর সবাইকে ব্রডকাস্ট করা হচ্ছে
        await _hubContext.Clients.All.SendAsync("ReceiveMessage", $"New company created: {createdCompany.Name}");

        return CreatedAtRoute("CompanyById", new { id = createdCompany.Id }, createdCompany);
    }
}
```

#### ৫. ক্লায়েন্ট সাইড (Client Side Testing)

এটি টেস্ট করার জন্য সাধারণত জাভাস্ক্রিপ্ট ক্লায়েন্ট লাগে। তবে কনসেপ্টটি এমন:

```javascript
// ১. কানেকশন তৈরি
const connection = new signalR.HubConnectionBuilder()
    .withUrl("/notify")
    .build();

// ২. ইভেন্ট লিসেন করা (সার্ভার যখন "ReceiveMessage" পাঠাবে)
connection.on("ReceiveMessage", (message) => {
    console.log("Notification: " + message);
    alert(message);
});

// ৩. স্টার্ট
connection.start();
```

**Testing Workflow:**
1. আপনি ব্রাউজারে অ্যাপটি ওপেন করে রাখলেন (যেখানে JS কোডটি রান করছে)।
2. পোস্টম্যান (Postman) দিয়ে একটি `POST` রিকোয়েস্ট পাঠালেন নতুন কোম্পানি তৈরির জন্য।
3. সাথে সাথে আপনার ব্রাউজারে একটি অ্যালার্ট বা কনসোল লগ দেখতে পাবেন: *"Notification: New company created: Google"*।

এভাবেই **SignalR** আপনার স্ট্যাটিক এপিআইকে জীবন্ত (Real-time) করে তোলে।

### ১. সেটআপ এবং কনফিগারেশন

SignalR এর জন্য সার্ভার সাইডে আলাদা প্যাকেজ লাগে না (.NET Core এর সাথেই থাকে)। তবে CORS (Cross-Origin Resource Sharing) কনফিগারেশনটা একটু স্পেশাল হতে হয়।

**ধাপ ১: CORS কনফিগারেশন আপডেট**
`Extensions/ServiceExtensions.cs` ফাইলে CORS পলিসি আপডেট করতে হবে। SignalR এর জন্য `AllowCredentials()` আবশ্যক এবং `AllowAnyOrigin()` এর বদলে নির্দিষ্ট অরিজিন (`WithOrigins`) দিতে হয়।

**ফাইল:** `Extensions/ServiceExtensions.cs`
```csharp
public static void ConfigureCors(this IServiceCollection services) =>
    services.AddCors(options =>
    {
        options.AddPolicy("CorsPolicy", builder =>
            builder.WithOrigins("http://localhost:3000") // ক্লায়েন্টের ইউআরএল (যেমন: React/Angular অ্যাপ)
                   .AllowAnyMethod()
                   .AllowAnyHeader()
                   .AllowCredentials()); // SignalR এর জন্য জরুরি
    });
```

**ধাপ ২: SignalR সার্ভিস রেজিস্টার**
ওই একই ফাইলে বা `Program.cs` এ SignalR সার্ভিস অ্যাড করুন।

```csharp
public static void ConfigureSignalR(this IServiceCollection services) =>
    services.AddSignalR();
```

### ৪. কন্ট্রোলার থেকে ব্রডকাস্ট করা (Broadcasting from Controller)

আমরা চাই যখন `CreateCompany` অ্যাকশন সফল হবে, তখন সব ইউজারকে জানানো হবে। এর জন্য কন্ট্রোলারে `IHubContext` ইনজেক্ট করতে হবে।

**ফাইল:** `Presentation/Controllers/CompaniesController.cs`

```csharp
using Microsoft.AspNetCore.SignalR;
using CompanyEmployees.HubConfig;

public class CompaniesController : ControllerBase
{
    private readonly IServiceManager _service;
    private readonly IHubContext<BroadcastHub> _hubContext; // হাব কনটেক্সট

    public CompaniesController(IServiceManager service, IHubContext<BroadcastHub> hubContext)
    {
        _service = service;
        _hubContext = hubContext;
    }

    [HttpPost]
    [ServiceFilter(typeof(ValidationFilterAttribute))]
    public async Task<IActionResult> CreateCompany([FromBody] CompanyForCreationDto company)
    {
        // কোম্পানি তৈরি করা
        var createdCompany = await _service.CompanyService.CreateCompanyAsync(company);

        // --- SignalR নোটিফিকেশন পাঠানো ---
        // "ReceiveMessage" ইভেন্ট লিসেনারদের কাছে ডাটা পাঠানো হচ্ছে
        await _hubContext.Clients.All.SendAsync("ReceiveMessage", "New company created: " + createdCompany.Name);

        return CreatedAtRoute("CompanyById", new { id = createdCompany.Id }, createdCompany);
    }
}
```

        // ১. কানেকশন তৈরি (URL অবশ্যই সার্ভারের Hub URL হতে হবে)
        const connection = new signalR.HubConnectionBuilder()
            .withUrl("https://localhost:5001/broadcast")
            .build();

        // ২. ইভেন্ট রিসিভ করা (সার্ভার যখন "ReceiveMessage" পাঠাবে)
        connection.on("ReceiveMessage", (message) => {
            const div = document.createElement("div");
            div.textContent = message + " at " + new Date().toLocaleTimeString();
            document.getElementById("messagesList").appendChild(div);
            console.log("Notification received: " + message);
        });

        // ৩. কানেকশন শুরু করা
        connection.start()
            .then(() => console.log("Connected to SignalR Hub"))
            .catch(err => console.error(err));
    </script>
