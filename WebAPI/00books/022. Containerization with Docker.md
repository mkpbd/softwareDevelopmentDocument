### ১. ডকার এবং কন্টেইনার (Docker & Container)

**কি কাজ করে:**
আমরা যখন কোড রান করি, তখন আমাদের পিসিতে .NET SDK, SQL Server ইত্যাদি ইন্সটল থাকতে হয়। কিন্তু অন্য পিসিতে এগুলো নাও থাকতে পারে।
ডকার আপনার অ্যাপ এবং অ্যাপ চালানোর জন্য যা যা দরকার (Dependencies, Runtime), সব কিছু একটি বাক্সে (Container) ভরে ফেলে।

**কেন দরকার (Why):**
*   **"It works on my machine" সমস্যা সমাধান:** অনেক সময় ডেভেলপার বলে "আমার পিসিতে তো কোড চলছে, সার্ভারে কেন এরর দিচ্ছে?" ডকার ব্যবহার করলে এই সমস্যা হয় না, কারণ এনভায়রনমেন্ট সব জায়গায় সেম থাকে।
*   **Isolation:** এক সার্ভারে অনেকগুলো অ্যাপ চালালে একটার সাথে আরেকটার কনফ্লিল্কট হয় না।

---

### ২. ইমেজ এবং কন্টেইনার (Image vs Container)

*   **Docker Image:** এটি হলো সিডি (CD) বা ব্লুপ্রিন্ট। এটি রিড-অনলি ফাইল।
*   **Docker Container:** ইমেজটিকে যখন রান করা হয়, তখন সেটি কন্টেইনার হয়ে যায়। এটি হলো আসল রানিং অ্যাপ।

**সহজ উদাহরণ:**
*   **Class (OOP):** Docker Image.
*   **Object (OOP):** Docker Container.

### ৩. ডকারফাইল (Dockerfile)

**কি কাজ করে:**
এটি একটি টেক্সট ফাইল যেখানে ইনস্ট্রাকশন লেখা থাকে কীভাবে ইমেজ তৈরি করতে হবে।
যেমন:
১. .NET রানটাইম ডাউনলোড করো।
২. কোডগুলো কপি করো।
৩. `dotnet publish` কমান্ড চালাও।
৪. অ্যাপটি রান করো।

### ৪. ডকার কম্পোজ (Docker Compose)

**কি কাজ করে:**
আমাদের অ্যাপের সাথে ডাটাবেস (SQL Server) দরকার। ডকার কম্পোজ ব্যবহার করে আমরা বলতে পারি: "আমার অ্যাপ এবং একটি SQL Server কন্টেইনার একসাথে চালু করো এবং তাদের মধ্যে কানেকশন তৈরি করো।"

### চ্যাপ্টার ২২: সেটআপ এবং কোড (Docker Setup)

আমরা আমাদের `CompanyEmployees` প্রজেক্টটিকে ডকারাইজ করব।

#### ১. পূর্বশর্ত (Prerequisites)
আপনার পিসিতে **Docker Desktop** ইন্সটল এবং রানিং থাকতে হবে।

#### ২. Dockerfile তৈরি করা

মেইন প্রজেক্ট ফোল্ডারে (যেখানে `.csproj` বা `.sln` আছে, রুট ফোল্ডারে রাখা ভালো) একটি ফাইল খুলুন নাম দিন `Dockerfile` (কোনো এক্সটেনশন নেই)।

**ফাইল:** `Dockerfile`
```dockerfile
# ১. বিল্ড স্টেজ (SDK ইমেজ ব্যবহার করে কোড বিল্ড করা)
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /app

# ২. প্রোজেক্ট ফাইল কপি এবং রিস্টোর করা
COPY *.sln .
COPY CompanyEmployees/*.csproj ./CompanyEmployees/
COPY CompanyEmployees.Presentation/*.csproj ./CompanyEmployees.Presentation/
COPY Service/*.csproj ./Service/
COPY Service.Contracts/*.csproj ./Service.Contracts/
COPY Contracts/*.csproj ./Contracts/
COPY Entities/*.csproj ./Entities/
COPY Repository/*.csproj ./Repository/
COPY Shared/*.csproj ./Shared/
COPY LoggerService/*.csproj ./LoggerService/

RUN dotnet restore

# ৩. বাকি সব কোড কপি এবং পাবলিশ করা
COPY . .
WORKDIR /app/CompanyEmployees
RUN dotnet publish -c Release -o /app/publish

# ৪. রানটাইম স্টেজ (শুধু রান করার জন্য হালকা ইমেজ)
FROM mcr.microsoft.com/dotnet/aspnet:8.0 AS runtime
WORKDIR /app
COPY --from=build /app/publish .
ENTRYPOINT ["dotnet", "CompanyEmployees.dll"]
```

#### ৩. Dockerignore ফাইল

আমরা চাই না `bin`, `obj` ফোল্ডারগুলো ইমেজে কপি হোক।

**ফাইল:** `.dockerignore`
```text
**/bin/
**/obj/
```

#### ৪. ইমেজ বিল্ড এবং রান করা (Commands)

টার্মিনাল বা কমান্ড প্রম্পটে প্রজেক্টের রুট ফোল্ডারে যান।

**ইমেজ তৈরি:**
```bash
docker build -t companyemployees-image .
```

**কন্টেইনার রান:**
```bash
docker run -d -p 5000:8080 --name my-api companyemployees-image
```
*   `-d`: ডিটাচ মোড (ব্যাকগ্রাউন্ডে চলবে)।
*   `-p 5000:8080`: আমাদের পিসির ৫০০0 পোর্টে রিকোয়েস্ট দিলে কন্টেইনারের ৮০৮০ পোর্টে যাবে।

এখন ব্রাউজারে `http://localhost:5000/api/companies` দিলে অ্যাপ চলবে।

#### ৫. Docker Compose (API + SQL Server)

আমরা চাই অ্যাপ রান করার সাথে সাথে একটি SQL Server ও রান হোক।

**ফাইল:** `docker-compose.yml` (রুট ফোল্ডারে)

```yaml
version: '3.4'

services:
  db:
    image: mcr.microsoft.com/mssql/server:2022-latest
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=Password123! # স্ট্রং পাসওয়ার্ড দিন
    ports:
      - "1433:1433"

  api:
    image: companyemployees-image
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "5000:8080"
    depends_on:
      - db
    environment:
      - ConnectionStrings__sqlConnection=server=db;database=CompanyEmployeeDB;User Id=sa;Password=Password123!;TrustServerCertificate=True;
```
*(নোট: কানেকশন স্ট্রিংয়ে `server=db` দেওয়া হয়েছে কারণ ডকার কম্পোজে সার্ভিস নেম দিয়েই কানেক্ট করা যায়)*

**রান করার কমান্ড:**
```bash
docker-compose up -d
```

এখন এক কমান্ডেই আপনার অ্যাপ এবং ডাটাবেস দুটোই চালু হয়ে যাবে!

### ২. ডকারফাইল তৈরি (Dockerfile)

প্রজেক্টের একদম রুট ফোল্ডারে (যেখানে `.sln` ফাইল আছে) একটি ফাইল তৈরি করুন যার নাম হবে `Dockerfile` (কোনো এক্সটেনশন যেমন .txt দেওয়া যাবে না)।

এই ফাইলে আমরা বলে দেব কীভাবে আমাদের কোড বিল্ড হবে এবং রান হবে।

**ফাইল:** `Dockerfile`

```dockerfile
# ১. বিল্ড স্টেজ: মাইক্রোসফটের SDK ইমেজ ব্যবহার করছি কোড কম্পাইল করার জন্য
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /app

# ২. প্রজেক্ট ফাইলগুলো কপি করা (লেয়ার ক্যাশিং এর সুবিধার জন্য আগে শুধু csproj কপি করছি)
COPY *.sln .
COPY CompanyEmployees/*.csproj ./CompanyEmployees/
COPY CompanyEmployees.Presentation/*.csproj ./CompanyEmployees.Presentation/
COPY Service/*.csproj ./Service/
COPY Service.Contracts/*.csproj ./Service.Contracts/
COPY Contracts/*.csproj ./Contracts/
COPY Entities/*.csproj ./Entities/
COPY Repository/*.csproj ./Repository/
COPY Shared/*.csproj ./Shared/
COPY LoggerService/*.csproj ./LoggerService/

# ৩. ডিপেন্ডেন্সি রিস্টোর করা (NuGet Packages ডাউনলোড)
RUN dotnet restore

# ৪. বাকি সব সোর্স কোড কপি করা
COPY . .

# ৫. পাবলিশ করা (রিলিজ মোডে)
WORKDIR /app/CompanyEmployees
RUN dotnet publish -c Release -o /app/publish

# ৬. রানটাইম স্টেজ: অ্যাপ চালানোর জন্য হালকা ASP.NET রানটাইম ইমেজ ব্যবহার
FROM mcr.microsoft.com/dotnet/aspnet:8.0 AS runtime
WORKDIR /app

# ৭. বিল্ড স্টেজ থেকে তৈরি হওয়া ফাইলগুলো এখানে কপি করা
COPY --from=build /app/publish .

# ৮. অ্যাপ চালানো
ENTRYPOINT ["dotnet", "CompanyEmployees.dll"]
```

### ৪. ইমেজ তৈরি এবং রান করা (Single Container)

এখন টার্মিনাল বা পাওয়ারশেল ওপেন করে প্রজেক্ট ফোল্ডারে যান এবং নিচের কমান্ডগুলো দিন।

**ধাপ ১: ইমেজ বিল্ড করা**
```bash
docker build -t companyemployees-image .
```
*(এখানে `-t` মানে ট্যাগ বা নাম দেওয়া হচ্ছে)*

**ধাপ ২: কন্টেইনার রান করা**
```bash
docker run -d -p 5000:8080 --name my-api companyemployees-image
```
*   `-d`: ডিটাচ মোড (ব্যাকগ্রাউন্ডে চলবে)।
*   `-p 5000:8080`: আমাদের পিসির **5000** পোর্টে হিট করলে কন্টেইনারের **8080** পোর্টে যাবে (.NET 8 এ ডিফল্ট পোর্ট 8080)।

**টেস্ট:** ব্রাউজারে `http://localhost:5000/api/companies` দিলে অ্যাপ চলবে।

### ৫. ডকার কম্পোজ (Docker Compose - App + DB)

বাস্তবে এপিআই একা চলে না, তার সাথে ডাটাবেস লাগে। আমরা `docker-compose.yml` দিয়ে এপিআই এবং SQL Server একসাথে চালাব।

**ফাইল:** `docker-compose.yml` (রুট ফোল্ডারে)

```yaml
version: '3.8'

services:
  # ১. ডাটাবেস সার্ভিস
  db:
    image: mcr.microsoft.com/mssql/server:2022-latest
    container_name: sql_server_container
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=Password123! # শক্তিশালী পাসওয়ার্ড দিন
    ports:
      - "1433:1433"
    volumes:
      - db_data:/var/opt/mssql # ডাটাবেস পারসিস্টেন্ট রাখার জন্য

  # ২. এপিআই সার্ভিস
  api:
    image: companyemployees-image
    container_name: api_container
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "5000:8080"
    depends_on:
      - db # ডাটাবেস চালু হওয়ার পর এপিআই চালু হবে
    environment:
      # কানেকশন স্ট্রিং ওভাররাইড করা হচ্ছে
      # 'Server=db' -> এখানে 'db' হলো ওপরের সার্ভিস নেম
      - ConnectionStrings__sqlConnection=Server=db;Database=CompanyEmployeeDB;User Id=sa;Password=Password123!;TrustServerCertificate=True;

volumes:
  db_data:
```

```bash
docker-compose up -d
```
*(বন্ধ করার জন্য: `docker-compose down`)*

### ৭. মাইগ্রেশন অ্যাপ্লাই করা (Handling Migrations)

ডকারে ডাটাবেস তো চালু হলো, কিন্তু টেবিলগুলো তো তৈরি হয়নি।
এর জন্য দুটি উপায় আছে:
১. এপিআই কোডে `Program.cs` এ অটো-মাইগ্রেশন কোড লেখা।
২. অথবা কন্টেইনারের ভেতর ঢুকে ম্যানুয়ালি আপডেট করা।

**সহজ উপায় (Program.cs এ কোড যোগ করা):**
```csharp
// অ্যাপ চালুর সময় মাইগ্রেশন চালানো
using (var scope = app.Services.CreateScope())
{
    var dbContext = scope.ServiceProvider.GetRequiredService<RepositoryContext>();
    dbContext.Database.Migrate(); // অটোমেটিক মাইগ্রেশন অ্যাপ্লাই হবে
}
```

এখন `docker-compose up --build` কমান্ড দিলে অ্যাপ চালু হবে, ডাটাবেস তৈরি হবে এবং টেবিলগুলোও তৈরি হয়ে যাবে।

এভাবেই আপনি আপনার সম্পূর্ণ অ্যাপ্লিকেশনটি ডকারাইজ করলেন! 🐳
