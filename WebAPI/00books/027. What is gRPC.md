### ১. জিআরপিসি কী? (What is gRPC?)

**কি কাজ করে:**
এটি REST API এর একটি বিকল্প। এটি গুগলের তৈরি একটি হাই-পারফরম্যান্স ফ্রেমওয়ার্ক।
REST API ডাটা পাঠায় **JSON** ফরম্যাটে (টেক্সট), যা মানুষ পড়তে পারে কিন্তু কম্পিউটারের জন্য প্রসেস করা ধীরগতির।
gRPC ডাটা পাঠায় **Protobuf (Protocol Buffers)** ফরম্যাটে (বাইনারি), যা মানুষ পড়তে পারে না কিন্তু কম্পিউটার চোখের পলকে প্রসেস করতে পারে।

**কেন দরকার (Why):**
যখন দুটি সার্ভার (Microservices) একে অপরের সাথে কথা বলে, তখন স্পিড খুব জরুরি। JSON এর টেক্সট প্রসেসিং ওভারহেড কমানোর জন্য gRPC ব্যবহার করা হয়।

---

### ২. প্রোটোফাইল (.proto File)

**কি কাজ করে:**
REST API তে আমরা Swagger বা C# Class দিয়ে মডেল বানাই। gRPC তে আমরা `.proto` ফাইলে মডেল এবং সার্ভিস ডিফাইন করি।

**উদাহরণ:**
```protobuf
service CompanyService {
  rpc GetCompany (CompanyRequest) returns (CompanyResponse);
}

message CompanyRequest {
  int32 id = 1;
}

message CompanyResponse {
  int32 id = 1;
  string name = 2;
}
```

### ৩. HTTP/2

**কি কাজ করে:**
REST API সাধারণত HTTP/1.1 ব্যবহার করে। gRPC বাধ্যতামূলকভাবে **HTTP/2** ব্যবহার করে।
*   **Multiplexing:** একই কানেকশন দিয়ে একসাথে অনেক রিকোয়েস্ট পাঠানো যায়।
*   **Streaming:** সার্ভার থেকে ক্লায়েন্টে বা ক্লায়েন্ট থেকে সার্ভারে লাইভ ডাটা স্ট্রিম করা যায় (যেমন: ভিডিও কল বা লাইভ চ্যাট)।

### ৪. gRPC বনাম REST

| বৈশিষ্ট্য | REST API | gRPC |
| :--- | :--- | :--- |
| **ফরম্যাট** | JSON (Text) | Protobuf (Binary) |
| **প্রটোকল** | HTTP/1.1 | HTTP/2 |
| **স্পিড** | স্লো (বড় ডাটার জন্য) | সুপার ফাস্ট |
| **ব্রাউজার সাপোর্ট**| ১০০% সাপোর্ট | সরাসরি সাপোর্ট নেই (gRPC-Web লাগে) |
| **ব্যবহার** | পাবলিক এপিআই (ওয়েব/মোবাইল) | ইন্টারনাল মাইক্রোসার্ভিস কমিউনিকেশন |

### সারসংক্ষেপ

| টপিক | কাজ | কেন শিখব? |
| :--- | :--- | :--- |
| **Protobuf** | বাইনারি ডাটা ফরম্যাট। | জেসন এর চেয়ে ছোট এবং ফাস্ট হওয়ার জন্য। |
| **Streaming** | লাইভ ডাটা পাঠানো। | রিয়েল-টাইম অ্যাপের জন্য। |
| **Contract First** | আগে রুলস সেট করা। | দুই টিমের (Frontend/Backend) কাজ সহজ করার জন্য। |

**সহজ উদাহরণ:**
*   **REST (JSON):** আপনি বন্ধুকে চিঠি লিখে পাঠালেন "আমি ভালো আছি"। বন্ধু সেটা পড়ে বুঝল।
*   **gRPC (Protobuf):** আপনি বন্ধুকে একটি কোড পাঠালেন `010101`। আপনার বন্ধুর কাছে মেশিন আছে যা সাথে সাথে বুঝল এর মানে "আমি ভালো আছি"। চিঠি পড়ার সময় নষ্ট হলো না।

### ২. প্রোটো ফাইল তৈরি (Defining the Contract)

gRPC তে প্রথমে `.proto` ফাইল লিখতে হয়। `Protos` ফোল্ডারে `company.proto` নামে ফাইল তৈরি করুন।

**ফাইল:** `Protos/company.proto`

```protobuf
syntax = "proto3";

option csharp_namespace = "CompanyEmployees.Grpc.Protos";

package company;

// ১. সার্ভিস ডেফিনিশন (মেথড)
service CompanyProtoService {
  rpc GetCompanyInfo (CompanyRequest) returns (CompanyResponse);
}

// ২. ইনপুট মেসেজ (প্যারামিটার)
message CompanyRequest {
  string id = 1; // GUID স্ট্রিং হিসেবে যাবে
}

// ৩. আউটপুট মেসেজ (রিটার্ন টাইপ)
message CompanyResponse {
  string id = 1;
  string name = 2;
  string address = 3;
  string country = 4;
}
```

### ৩. সার্ভিস ইমপ্লিমেন্টেশন (Service Logic)

প্রোটো ফাইল সেভ করার পর একবার `Build` দিন। ভিজ্যুয়াল স্টুডিও অটোমেটিক একটি বেস ক্লাস (`CompanyProtoService.CompanyProtoServiceBase`) তৈরি করে দেবে। আমরা সেটাকে ইনহেরিট করব।

**ফাইল:** `Services/CompanyService.cs` (gRPC প্রজেক্টের ভেতরে)

```csharp
using Grpc.Core;
using CompanyEmployees.Grpc.Protos; // অটো জেনারেটেড নেমস্পেস
using Contracts; // IRepositoryManager

namespace CompanyEmployees.Grpc.Services
{
    // অটোমেটিক তৈরি হওয়া বেস ক্লাস ইনহেরিট করা
    public class CompanyService : CompanyProtoService.CompanyProtoServiceBase
    {
        private readonly IRepositoryManager _repository;
        private readonly ILogger<CompanyService> _logger;

        public CompanyService(IRepositoryManager repository, ILogger<CompanyService> logger)
        {
            _repository = repository;
            _logger = logger;
        }

        public override async Task<CompanyResponse> GetCompanyInfo(CompanyRequest request, ServerCallContext context)
        {
            // ১. GUID পার্স করা
            if (!Guid.TryParse(request.Id, out var companyId))
            {
                throw new RpcException(new Status(StatusCode.InvalidArgument, "Invalid Company Id format"));
            }

            // ২. রিপোজিটরি কল করা (আমাদের পুরনো কোড ব্যবহার করছি)
            var company = await _repository.Company.GetCompanyAsync(companyId, trackChanges: false);

            if (company is null)
            {
                throw new RpcException(new Status(StatusCode.NotFound, $"Company with id {request.Id} not found"));
            }

            // ৩. রেসপন্স রিটার্ন করা
            return new CompanyResponse
            {
                Id = company.Id.ToString(),
                Name = company.Name,
                Address = company.Address,
                Country = company.Country
            };
        }
    }
}
```

### ৪. কনফিগারেশন (Program.cs)

gRPC সার্ভিসটি রান করার জন্য `Program.cs` এ রেজিস্ট্রেশন করতে হবে।

**ফাইল:** `Program.cs` (gRPC প্রজেক্টের)

```csharp
using CompanyEmployees.Grpc.Services;
using CompanyEmployees.Extensions; // আমাদের এক্সটেনশন মেথড (DB connection)

var builder = WebApplication.CreateBuilder(args);

// gRPC সার্ভিস অ্যাড করা
builder.Services.AddGrpc();

// আমাদের ডাটাবেস এবং রিপোজিটরি কনফিগারেশন (ServiceExtensions থেকে)
builder.Services.ConfigureSqlContext(builder.Configuration);
builder.Services.ConfigureRepositoryManager();

var app = builder.Build();

// gRPC সার্ভিস ম্যাপ করা
app.MapGrpcService<CompanyService>();

app.MapGet("/", () => "Communication with gRPC endpoints must be made through a gRPC client.");

app.Run();
```

*(নোট: `appsettings.json` ফাইলে কানেকশন স্ট্রিং থাকতে হবে)*

### ৫. টেস্ট করা (Testing gRPC)

gRPC ব্রাউজার দিয়ে টেস্ট করা যায় না। এর জন্য **Postman** (নতুন ভার্সন gRPC সাপোর্ট করে) অথবা **gRPCurl** টুল লাগে।

**Postman দিয়ে টেস্ট:**
১. Postman ওপেন করুন।
২. `New` -> `gRPC Request` সিলেক্ট করুন।
৩. URL বক্সে লিখুন: `https://localhost:5001` (আপনার gRPC প্রজেক্টের পোর্ট)।
৪. **Service Definition:** `.proto` ফাইলটি ইমপোর্ট করুন।
    *   Postman অটোমেটিক `GetCompanyInfo` মেথড লোড করবে।
৫. **Message Body:**
    ```json
    {
        "id": "c9d4c053-49b6-410c-bc78-2d54a9991870"
    }
    ```
    *(আপনার ডাটাবেসের একটি ভ্যালিড আইডি দিন)*
৬. **Invoke** বাটনে ক্লিক করুন।

**ফলাফল:**
আপনি সাথে সাথে ডাটা পেয়ে যাবেন:
```json
{
    "id": "c9d4c053-49b6-410c-bc78-2d54a9991870",
    "name": "IT Solution Ltd",
    "address": "Dhaka",
    "country": "Bangladesh"
}
```

এভাবেই আপনি আপনার এপিআই সল্যুশনে হাই-পারফরম্যান্স **gRPC** যুক্ত করলেন।
