
**Chapter 29**-এর নাম সাধারণত **"Code Analysis and Quality"** বা **"Static Code Analysis using SonarQube"** হয়ে থাকে।

আমরা কোড লিখি, টেস্ট করি, ডিপ্লয় করি। কিন্তু আমাদের কোডের মান (Quality) কেমন? কোডে কি কোনো হিডেন বাগ (Hidden Bug) আছে? কোনো সিকিউরিটি হোল (Security Hole) আছে? ভেরিয়েবলের নাম কি ঠিকমতো দেওয়া হয়েছে?

মানুষের পক্ষে হাজার হাজার লাইন কোড পড়ে এগুলো বের করা কঠিন। এই কাজটিই করে **Static Code Analysis** টুলস। বইটিতে সাধারণত **SonarQube** বা **StyleCop** ব্যবহার করে এটি দেখানো হয়।

---

### ১. স্ট্যাটিক কোড অ্যানালাইসিস কী? (What is Static Code Analysis?)

**কি কাজ করে:**
কোড রান না করেই (Static অবস্থায়) কোড রিড করে ভুল ধরা।
এটি কোডের ব্যাকরণ (Syntax), লজিক এবং স্টাইল চেক করে।

**কেন দরকার (Why):**
১. **Bugs:** "Null Reference Exception" হওয়ার সম্ভাবনা থাকলে আগেই বলে দেয়।
২. **Vulnerabilities:** পাসওয়ার্ড হার্ডকোড করা থাকলে বা SQL Injection এর সুযোগ থাকলে ওয়ার্নিং দেয়।
৩. **Code Smell:** কোড কাজ করছে ঠিকই, কিন্তু লেখা হয়েছে বাজেভাবে (যেমন: বিশাল বড় মেথড, ডুপ্লিকেট কোড)। এগুলো ক্লিন করতে সাহায্য করে।

---

### ২. সোনারকিউব (SonarQube)

**কি কাজ করে:**
এটি বিশ্বের সবচেয়ে জনপ্রিয় কোড কোয়ালিটি টুল। এটি একটি সার্ভার যা আপনার প্রজেক্ট স্ক্যান করে এবং একটি ড্যাশবোর্ডে রিপোর্ট দেখায়।
এটি বলে দেয়: "তোমার কোডে ৫টি বাগ, ৩টি সিকিউরিটি ইস্যু এবং ১০% ডুপ্লিকেট কোড আছে। তোমার টেকনিক্যাল ডেট (Technical Debt) ২ ঘণ্টা।"

**Technical Debt:** এর মানে হলো, এই খারাপ কোডগুলো ঠিক করতে ভবিষ্যতে আপনার কত সময় নষ্ট হবে।

---

### ৩. স্টাইলকপ (StyleCop Analyzers)

**কি কাজ করে:**
এটি ভিজ্যুয়াল স্টুডিওর একটি এক্সটেনশন বা ন্যুগেট প্যাকেজ। এটি কোডিং স্টাইল চেক করে।
যেমন:
*   ভেরিয়েবল নাম ছোট হাতের অক্ষরে শুরু হতে হবে (`camelCase`)।
*   মেথডের নাম বড় হাতের অক্ষরে শুরু হতে হবে (`PascalCase`)।
*   `if` এর পর ব্রাকেট `{ }` দিতেই হবে।

**সুবিধা:**
টিমের সবাই একই স্টাইলে কোড লেখে। কোড দেখতে সুন্দর এবং গোছানো হয়।

---

### ৪. সাইক্লোম্যাটিক কমপ্লেক্সিটি (Cyclomatic Complexity)

**কি কাজ করে:**
এটি একটি মেট্রিক যা বলে আপনার কোড কতটা জটিল।
একটি মেথডে যত বেশি `if`, `else`, `for`, `while` থাকবে, তার কমপ্লেক্সিটি তত বেশি হবে।

**কেন দরকার:**
কমপ্লেক্সিটি বেশি হলে (যেমন ১০ এর বেশি) সেই কোড টেস্ট করা এবং মেইনটেইন করা কঠিন। সোনারকিউব বা এনালিস্ট টুলস আপনাকে বলে দেবে কোন মেথডটি ভেঙে ছোট করতে হবে।

### সারসংক্ষেপ

| টপিক | কাজ | কেন শিখব? |
| :--- | :--- | :--- |
| **Static Analysis** | কোড না চালিয়েই ভুল ধরা। | বাগ এবং এরর কমানোর জন্য। |
| **SonarQube** | কোডের স্বাস্থ্য পরীক্ষা করা। | সিকিউরিটি এবং কোয়ালিটি নিশ্চিত করার জন্য। |
| **Code Smell** | বাজে কোড ডিজাইন। | কোড রিফ্যাক্টর (Refactor) বা ক্লিন করার জন্য। |
| **Complexity** | কোডের জটিলতা মাপা। | কোড সহজ এবং রিডেবল রাখার জন্য। |

**সহজ উদাহরণ:**
*   **Compiler:** আপনার লেখার বানান ভুল ধরলে লাল দাগ দেয় (Syntax Error)।
*   **Static Analysis (SonarQube):** আপনি হয়তো ব্যাকরণ মেনে ঠিকই লিখেছেন "আমি ভাত খাই"। কিন্তু অ্যানালাইজার বলবে: "ভাই, ভাত তো হাত দিয়ে খায়, তুমি চামচ দিয়ে কেন খাচ্ছ? এটা ইনফিশিয়েন্ট (Code Smell)।" অথবা "তোমার হাতে ময়লা আছে, হাত ধুয়ে নাও (Security Vulnerability)।"

### ১. সোনারকিউব সেটআপ (Docker Setup)

সোনারকিউব সার্ভার রান করার সবচেয়ে সহজ উপায় হলো ডকার।

**ধাপ ১: ডকার কন্টেইনার রান করা**
টার্মিনালে নিচের কমান্ডটি দিন:
```bash
docker run -d --name sonarqube -p 9000:9000 sonarqube:lts-community
```
*(এটি ইমেজ ডাউনলোড করে সার্ভার চালু করবে। ৯০০০ পোর্টে এটি চলবে।)*

**ধাপ ২: লগইন করা**
১. ব্রাউজারে যান: `http://localhost:9000`
২. লগইন পেজ আসবে। ডিফল্ট ইউজারনেম: `admin`, পাসওয়ার্ড: `admin`।
৩. লগইন করার পর পাসওয়ার্ড পরিবর্তন করতে বলবে। নতুন একটি পাসওয়ার্ড দিন।

### ২. প্রজেক্ট তৈরি এবং টোকেন জেনারেশন

সোনারকিউব ড্যাশবোর্ডে আমাদের প্রজেক্টটি রেজিস্টার করতে হবে।

**ধাপ ১: প্রজেক্ট তৈরি**
১. ড্যাশবোর্ডে **Create Project** -> **Manually** সিলেক্ট করুন।
২. **Project Key:** `CompanyEmployees_API` (যেকোনো ইউনিক নাম)।
৩. **Display Name:** `Company Employees API`.
৪. **Set Up** এ ক্লিক করুন।

**ধাপ ২: টোকেন তৈরি**
১. **Locally** সিলেক্ট করুন।
২. টোকেন জেনারেশন সেকশনে একটি নাম দিন (যেমন `MyToken`) এবং **Generate** করুন।
৩. টোকেনটি কপি করে নোটপ্যাডে রাখুন (এটি আর দেখা যাবে না)।

**ধাপ ৩: ডটনেট স্ক্যানার সেটআপ**
১. **Run analysis on your project** সেকশনে **.NET** সিলেক্ট করুন।
২. নিচে তিনটি কমান্ড দেখাবে। এগুলো আমাদের প্রোজেক্ট ফোল্ডারে চালাতে হবে।

### ৩. স্ক্যানার টুল ইন্সটল (Global Tool)

আমাদের পিসিতে .NET SonarScanner টুলটি ইন্সটল থাকতে হবে।
টার্মিনালে কমান্ড দিন:
```bash
dotnet tool install --global dotnet-sonarscanner
```

### ৪. প্রজেক্ট স্ক্যান করা (Running Analysis)

এখন আমরা আমাদের `CompanyEmployees` সল্যুশন ফোল্ডারে যাব এবং স্ক্যান চালাব।

টার্মিনাল ওপেন করুন (রুট ফোল্ডারে) এবং নিচের তিনটি কমান্ড একটার পর একটা দিন:

**১. স্ক্যান শুরু করা (Begin):**
```bash
dotnet sonarscanner begin /k:"CompanyEmployees_API" /d:sonar.host.url="http://localhost:9000"  /d:sonar.login="YOUR_COPIED_TOKEN"
```
*(এখানে `YOUR_COPIED_TOKEN` এর জায়গায় আপনার টোকেনটি বসান)*

**২. প্রজেক্ট বিল্ড করা (Build):**
```bash
dotnet build
```
*(এই সময়েই স্ক্যানার আপনার কোডগুলো পড়ছে)*

**৩. স্ক্যান শেষ করা এবং রিপোর্ট পাঠানো (End):**
```bash
dotnet sonarscanner end /d:sonar.login="YOUR_COPIED_TOKEN"
```

### ৫. ফলাফল দেখা (The Report)

কমান্ড শেষ হলে ব্রাউজারে `http://localhost:9000` এ যান এবং আপনার প্রজেক্টে ক্লিক করুন।

**আপনি যা দেখতে পাবেন:**
*   **Bugs:** কোডে কোনো বাগ থাকলে।
*   **Vulnerabilities:** সিকিউরিটি সমস্যা।
*   **Code Smells:** বাজে কোড (যেমন: আনইউজড ভেরিয়েবল, খালি ক্যাচ ব্লক)।
*   **Duplications:** কত শতাংশ কোড ডুপ্লিকেট হয়েছে।

**উদাহরণ (Code Smell):**
যদি আপনার কোডে এমন থাকে:
```csharp
try {
    // some code
} catch (Exception ex) {
    // empty
}
```
সোনারকিউব বলবে: *"Empty Catch Block detected. Either log the error or handle it."*

সোনারকিউব ছাড়াও ভিজ্যুয়াল স্টুডিওর ভেতরেই লাইভ চেক করার জন্য আমরা প্যাকেজ ব্যবহার করতে পারি।

**প্যাকেজ ইন্সটল:**
`CompanyEmployees` প্রজেক্টে রাইট ক্লিক করে `Manage NuGet Packages` এ যান এবং ইন্সটল করুন:
*   `Microsoft.CodeAnalysis.NetAnalyzers`
*   `StyleCop.Analyzers`

**ফলাফল:**
এখন কোড লেখার সময়ই ভিজ্যুয়াল স্টুডিও আপনাকে ওয়ার্নিং দেবে।
যেমন: প্রাইভেট ভেরিয়েবলের নাম `_camelCase` না হলে নিচে সবুজ দাগ দেখাবে।
