### ১. ইভেন্ট-ড্রিভেন আর্কিটেকচার কী? (What is Event-Driven Architecture?)

**কি কাজ করে:**
এতক্ষণ আমরা **HTTP (REST)** ব্যবহার করছিলাম। মানে সার্ভিস A সার্ভিস B-কে কল করে এবং উত্তরের জন্য অপেক্ষা করে (Synchronous)।
ইভেন্ট-ড্রিভেন সিস্টেমে, সার্ভিস A কাউকে কল করে না। সে শুধু একটা **ইভেন্ট (Event)** বা মেসেজ ছুড়ে দেয় "একটি অর্ডার তৈরি হয়েছে"। সার্ভিস B, C, D যারা যারা আগ্রহী, তারা সেই মেসেজটি রিসিভ করে নিজের কাজ শুরু করে (Asynchronous)।

**কেন দরকার (Why):**
১. **Decoupling:** সার্ভিস A-এর জানার দরকার নেই সার্ভিস B বেঁচে আছে না মরে গেছে। সে তার কাজ করে মেসেজ পাঠিয়ে দেয়।
২. **Performance:** রেসপন্সের জন্য অপেক্ষা করতে হয় না, তাই ইউজার সাথে সাথে ফিডব্যাক পায়।
৩. **Reliability:** যদি সার্ভিস B ডাউন থাকে, মেসেজটি কিউতে (Queue) জমা থাকে। সার্ভিস ঠিক হলে মেসেজটি প্রসেস হয়। কোনো ডাটা হারায় না।

### ২. র‍্যাবিট-এমকিউ (RabbitMQ) কী?

**কি কাজ করে:**
এটি একটি **Message Broker**। সহজ কথায় এটি একটি **ডিজিটাল পোস্ট অফিস**।
*   **Producer:** যে চিঠি লেখে (যেমন: Order Service)।
*   **Queue:** মেইলবক্স, যেখানে চিঠি জমা থাকে।
*   **Consumer:** যে চিঠি পড়ে (যেমন: Email Service)।
*   **RabbitMQ:** মাঝখানের পিওন বা পোস্ট অফিস, যে চিঠি এক জায়গা থেকে অন্য জায়গায় পৌঁছে দেয়।

### ৩. ম্যাসট্রানজিট (MassTransit)

**কি কাজ করে:**
সরাসরি RabbitMQ এর কোড লেখা অনেক জটিল। .NET-এ **MassTransit** নামে একটি লাইব্রেরি আছে যা RabbitMQ ব্যবহার করা একদম পানির মতো সহজ করে দেয়। (যেমন SQL এর জন্য EF Core, তেমনি RabbitMQ এর জন্য MassTransit)।

### ৪. উদাহরণ (Real-world Scenario)

ধরুন ইউজার একটি অর্ডার প্লেস করল।
*   **Order Service:** অর্ডারটি ডাটাবেসে সেভ করল এবং RabbitMQ-তে একটি মেসেজ পাঠাল: `OrderCreated`.
*   **Inventory Service:** মেসেজটি পেল এবং স্টকের পরিমাণ কমাল।
*   **Notification Service:** মেসেজটি পেল এবং ইউজারকে ইমেইল পাঠাল।

সব কাজ ব্যাকগ্রাউন্ডে আলাদা আলাদা ভাবে হলো।

```csharp
using MassTransit;

public class CompaniesController : ControllerBase
{
    private readonly IPublishEndpoint _publishEndpoint; // MassTransit Service

    public CompaniesController(IPublishEndpoint publishEndpoint)
    {
        _publishEndpoint = publishEndpoint;
    }

    [HttpPost]
    public async Task<IActionResult> CreateCompany([FromBody] CompanyForCreationDto company)
    {
        // ... কোম্পানি ডাটাবেসে সেভ করার কোড ...

        // ইভেন্ট পাবলিশ করা
        await _publishEndpoint.Publish<ICompanyCreatedEvent>(new

            Id = createdCompany.Id,
            Name = createdCompany.Name,
            CreatedAt = DateTime.UtcNow
        });

        return CreatedAtRoute(...);
    }
}
```

#### ৫. কনজিউমার (Worker - Receiving Message)

এখন একটি কনসোল অ্যাপ বানাব যা এই মেসেজ রিসিভ করবে।

**ফাইল:** `CompanyCreatedConsumer.cs`
```csharp
using MassTransit;
using Shared.Messages;

public class CompanyCreatedConsumer : IConsumer<ICompanyCreatedEvent>
{
    public async Task Consume(ConsumeContext<ICompanyCreatedEvent> context)
    {
        var message = context.Message;
        Console.WriteLine($"New Company Received: {message.Name} (ID: {message.Id})");
        
        // এখানে ইমেইল পাঠানোর লজিক থাকতে পারে
    }
}
```

**ফাইল:** `Program.cs` (Worker Project)
```csharp
using MassTransit;

var busControl = Bus.Factory.CreateUsingRabbitMq(cfg =>
{
    cfg.Host("localhost");

    cfg.ReceiveEndpoint("company-created-queue", e =>
    {
        // কনজিউমার রেজিস্টার করা
        e.Consumer<CompanyCreatedConsumer>();
    });
});

await busControl.StartAsync();
Console.WriteLine("Listening for messages...");
Console.ReadLine();
await busControl.StopAsync();
```

### ৪. মেসেজ পাঠানো (Publishing Message)

এখন আমরা `CreateCompany` অ্যাকশন থেকে মেসেজ পাবলিশ করব।

**ফাইল:** `Presentation/Controllers/CompaniesController.cs`

```csharp
using MassTransit;
using Shared.Messages;

public class CompaniesController : ControllerBase
{
    private readonly IServiceManager _service;
    private readonly IPublishEndpoint _publishEndpoint; // MassTransit এর পাবলিশার

    public CompaniesController(IServiceManager service, IPublishEndpoint publishEndpoint)
    {
        _service = service;
        _publishEndpoint = publishEndpoint;
    }

    [HttpPost]
    public async Task<IActionResult> CreateCompany([FromBody] CompanyForCreationDto company)
    {
        // ১. ডাটাবেসে কোম্পানি সেভ করা
        var createdCompany = await _service.CompanyService.CreateCompanyAsync(company);

        // ২. ইভেন্ট পাবলিশ করা (RabbitMQ তে মেসেজ চলে যাবে)
        // আমরা এখানে Anonymous Object ব্যবহার করছি যা ইন্টারফেসের সাথে মিলে যায়
        await _publishEndpoint.Publish<ICompanyCreatedEvent>(new
        {
            Id = createdCompany.Id,
            Name = createdCompany.Name,
            CreatedAt = DateTime.UtcNow
        });

        return CreatedAtRoute("CompanyById", new { id = createdCompany.Id }, createdCompany);
    }
}
```

### ৫. কনজিউমার তৈরি (Worker Project)

এখন আমরা `Worker` প্রজেক্টে কনজিউমার বানাব যা মেসেজটি ধরবে।

```csharp
using MassTransit;
using Shared.Messages;

namespace CompanyEmployees.Worker
{
    public class CompanyCreatedConsumer : IConsumer<ICompanyCreatedEvent>
    {
        public async Task Consume(ConsumeContext<ICompanyCreatedEvent> context)
        {
            var message = context.Message;
            
            Console.WriteLine($"[Event Received] Company Created: {message.Name} (ID: {message.Id}) at {message.CreatedAt}");
            
            // এখানে আপনি চাইলে ইমেইল পাঠাতে পারেন বা অন্য কোনো ভারী কাজ করতে পারেন
            await Task.CompletedTask;
        }
    }
}
```

```csharp
Console.WriteLine("Worker Started. Waiting for messages...");
```
