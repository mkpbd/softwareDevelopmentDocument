
স্বাগতম ভাতিজা! আমি তোমার **Raju Mama** (Senior .NET Dev)। আজ থেকে আমরা একটা নতুন জার্নি শুরু করব। নাম **ADO.NET Zero to Hero**।

তুমি হয়তো ভাবছ, "মামা, এখন তো Entity Framework (EF Core) এর যুগ, ADO.NET শিখে কী লাভ?"
শোনো ভাতিজা, বিরিয়ানি রান্না করতে গেলে যেমন চাল আর মাংসের হিসাব বুঝতে হয়, তেমনি .NET এর ডাটাবেস কমিউনিকেশনের একদম 'র' (Raw) পাওয়ার বুঝতে হলে ADO.NET জানতেই হবে। EF Core নিজেও তলে তলে এই ADO.NET ই ব্যবহার করে। যখন হাই পারফর্মেন্স দরকার হবে বা কমপ্লেক্স রিপোর্ট বানাতে হবে, তখন এই ADO.NET ই তোমার জীবন বাঁচাবে।

### 🚀 ADO.NET 30-Day Course Roadmap

**Phase 1: ইঞ্জিন স্টার্ট (The Basics)**
1. **Lesson 1:** ADO.NET কী এবং কেন? (The Waiter Analogy)
2. **Lesson 2:** SQL Server সেটআপ ও ডাটাবেস তৈরি (The Kitchen)
3. **Lesson 3:** SqlConnection - ডাটাবেসের সাথে হ্যান্ডশেক (The Bridge)
4. **Lesson 4:** Connection String - সিক্রেট চাবি (Security)
5. **Lesson 5:** Error Handling & Try-Catch (হেলমেট পরে বাইক চালানো)

**Phase 2: অর্ডার দেওয়া (Executing Commands)**
6. **Lesson 6:** SqlCommand - হুকুম দেওয়া (The Order)
7. **Lesson 7:** ExecuteNonQuery - ডাটা ঢুকানো ও পাল্টানো (Insert/Update/Delete)
8. **Lesson 8:** ExecuteScalar - মাত্র একটা ভ্যালু আনা (One Shot)
9. **Lesson 9:** SQL Injection - হ্যাকারদের যম (The Shield)
10. **Lesson 10:** Parameterized Queries - স্যানিটাইজ করা (Hygiene)

**Phase 3: ডাটা নিয়ে খেলা (Reading Data)**
11. **Lesson 11:** SqlDataReader - সুপারফাস্ট রিডিং (The Firehose)
12. **Lesson 12:** Multiple Row Reading - লুপ চালিয়ে ডাটা আনা
13. **Lesson 13:** SqlDataAdapter - স্মার্ট ম্যানেজার (Offline Data)
14. **Lesson 14:** DataSet & DataTable - মেমোরিতে ডাটাবেস
15. **Lesson 15:** DataReader vs DataAdapter - কার শক্তি বেশি?

**Phase 4: লেভেল আপ (Advanced Concepts)**
16. **Lesson 16:** Stored Procedures - প্রি-কুকড বিরিয়ানি (Efficiency)
17. **Lesson 17:** Stored Procedure with Parameters
18. **Lesson 18:** Transactions - সব হবে, নয়তো কিছুই না (All or Nothing)
19. **Lesson 19:** Bulk Operations - একসাথে হাজার ডাটা (The Truck)
20. **Lesson 20:** Connection Pooling - ট্রাফিক জ্যাম কমানো

**Phase 5: আর্কিটেকচার ও প্যাটার্ন (Professional Coding)**
21. **Lesson 21:** Async/Await - অ্যাপ হ্যাং করবে না (Non-blocking)
22. **Lesson 22:** Helper Class - কোড রিপিট না করা (DRY Principle)
23. **Lesson 23:** Layered Architecture (DAL, BLL, UI) - সাজানো গোছানো সংসার
24. **Lesson 24:** Model/Entity Class - ডাটা ম্যাপ করা
25. **Lesson 25:** Repository Pattern - গোডাউন ম্যানেজমেন্ট

**Phase 6: রিয়েল লাইফ প্রজেক্ট (Shop Management System)**
26. **Lesson 26:** Project Setup & DB Design
27. **Lesson 27:** Login System (Authentication)
28. **Lesson 28:** Product CRUD Operation
29. **Lesson 29:** Order Processing with Transaction
30. **Lesson 30:** Final Optimization & Certificate Summary
