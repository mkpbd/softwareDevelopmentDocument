### 🎓 Lesson 11: SqlDataReader - সুপারফাস্ট রিডিং (The Firehose)

**সহজ বাংলায়:**
`SqlDataReader` হলো **সরাসরি লাইভ স্ট্রিমিং** দেখার মতো। টিভিতে যেমন লাইভ খেলা দেখলে তুমি পজ (Pause) করতে পারো না, বা রিওয়াইন্ড করতে পারো না, খেলা চলতেই থাকে—`SqlDataReader` ঠিক তাই।
এটা ডাটাবেস থেকে ডাটা স্ট্রিম করে আনে। একে বলা হয় **Connected Architecture**। মানে যতক্ষণ ডাটা পড়বে, ততক্ষণ কানেকশন অন থাকতে হবে।

**Real-life Analogy:**
এটা হলো **পানির ট্যাপ বা পাইপ (Firehose)**। ট্যাপ ছাড়লে পানি পরবে, তুমি মগ দিয়ে ধরবে। ট্যাপ বন্ধ করলে পানি আসা বন্ধ। তুমি চাইলেই পানি আবার ট্যাপের ভেতরে ঢোকাতে পারবে না (Read Only)।

**Real C# Code:**
```csharp
using System;
using System.Data.SqlClient;

class Program
{
    static void Main()
    {
        string cs = "Server=.\\SQLEXPRESS;Database=TechShopDB;Trusted_Connection=True;";

        using (SqlConnection con = new SqlConnection(cs))
        {
            // আমরা শুধু নাম আর দাম দেখতে চাই
            string query = "SELECT ProductName, Price FROM Products";
            SqlCommand cmd = new SqlCommand(query, con);

            con.Open();

            // Firehose চালু করলাম
            // ExecuteReader কল করলে সে ডাটাবেসের দরজায় দাঁড়িয়ে যায়
            using (SqlDataReader reader = cmd.ExecuteReader())
            {
                // HasRows চেক করে দেখব আদৌ কোনো ডাটা আছে কিনা
                if (reader.HasRows)
                {
                    Console.WriteLine("Maa, Pani... mane Data astese! 🌊");
                    
                    // প্রথম রো (First Row) পড়ার জন্য Read() কল করতে হয়
                    reader.Read(); 
                    
                    // ডাটা প্রিন্ট (শুধু প্রথম প্রোডাক্ট)
                    Console.WriteLine($"First Product: {reader["ProductName"]}");
                }
                else
                {
                    Console.WriteLine("Mama, Stock khali!");
                }
            } // এখানে Reader ক্লোজ হবে
        } // এখানে Connection ক্লোজ হবে
    }
}
```

**Why Important?**
এটা মেমোরি খুব কম খায়। কোটি কোটি ডাটা থাকলেও তোমার র‍্যাম (RAM) ফুল হবে না, কারণ সে একটার পর একটা লাইন পড়ে।

### 🎓 Lesson 12: Multiple Row Reading - লুপ চালিয়ে ডাটা আনা

**সমস্যা:**
আগের লেসনে আমরা `reader.Read()` একবার কল করেছিলাম, তাই শুধু প্রথম প্রোডাক্ট দেখেছি। কিন্তু দোকানে তো ১০০টা প্রোডাক্ট থাকতে পারে।

**সমাধান:**
`reader.Read()` মেথডটা একটা `bool` রিটার্ন করে। যতক্ষণ ডাটা থাকে, সে `true` দেয়, ডাটা শেষ হলে `false` দেয়। তাই আমরা এটাকে `while` লুপের মধ্যে ফেলে দিব।

**Real C# Code:**
```csharp
using (SqlDataReader reader = cmd.ExecuteReader())
{
    Console.WriteLine("------------------------------------------------");
    Console.WriteLine("{0,-20} | {1,10}", "Product Name", "Price (Tk)");
    Console.WriteLine("------------------------------------------------");

    // যতক্ষণ ডাটা আছে, লুপ চলবে
    while (reader.Read())
    {
        string name = reader["ProductName"].ToString();
        
        // সাবধান! ডাটাবেসে Price যদি NULL থাকে, তাহলে ক্র্যাশ করবে।
        // তাই চেক করে নেওয়া ভালো
        decimal price = 0;
        if (reader["Price"] != DBNull.Value) // DBNull.Value হলো ডাটাবেসের NULL
        {
            price = Convert.ToDecimal(reader["Price"]);
        }

        Console.WriteLine("{0,-20} | {1,10}", name, price);
    }
}
```

**Common Mistake:**
লুপের ভেতরে ভারী কাজ (যেমন ফাইল রাইট করা বা অন্য এপিআই কল করা) করা যাবে না। কারণ যতক্ষণ লুপ চলছে, ততক্ষণ ডাটাবেস কানেকশন বিজি (Busy)। অন্য ইউজাররা ওয়েট করবে।

### 🎓 Lesson 13: SqlDataAdapter - স্মার্ট ম্যানেজার (Offline Data)

**সহজ বাংলায়:**
`SqlDataAdapter` হলো রেস্টুরেন্টের সেই ওয়েটার যে তোমার পুরো খাবার একসাথে টেবিলে দিয়ে চলে যায়। ওয়েটার চলে যাওয়ার পর তুমি আস্তে ধীরে খাও, বা খাবার প্যাকেট করে বাসায় নিয়ে যাও—ওয়েটারের আর কোনো কাজ নেই।

একে বলা হয় **Disconnected Architecture**। সে ডাটাবেসে কানেক্ট করে, সব ডাটা নিয়ে আসে, তারপর কানেকশন সাথে সাথে কেটে দেয়। এরপর তুমি সেই ডাটা নিয়ে মেমোরিতে যা খুশি তাই করতে পারো।

**Real-life Analogy:**
এটা হলো **YouTube Video Download** করে দেখার মতো। একবার ডাউনলোড (Fill) হয়ে গেলে ইন্টারনেট (Connection) বন্ধ করলেও ভিডিও চলবে। আর `SqlDataReader` হলো **Live Streaming** (নেট গেলেই ভিডিও অফ)।

**Real C# Code:**
```csharp
using System;
using System.Data; // এটা লাগবে DataSet/DataTable এর জন্য
using System.Data.SqlClient;

class Program
{
    static void Main()
    {
        string cs = "Server=.\\SQLEXPRESS;Database=TechShopDB;Trusted_Connection=True;";

        using (SqlConnection con = new SqlConnection(cs))
        {
            string query = "SELECT * FROM Products";
            
            // Adapter এর জন্য কমান্ড অবজেক্ট আলাদা করে না বানালেও চলে
            // ডাইরেক্ট কুয়েরি আর কানেকশন দিয়ে দেওয়া যায়
            SqlDataAdapter da = new SqlDataAdapter(query, con);
            
            // ডাটা রাখার পাত্র (বালতি)
            DataTable dt = new DataTable();

            // জাদুর মেথড Fill()
            // ১. সে কানেকশন ওপেন করে
            // ২. ডাটা রিড করে
            // ৩. DataTable এ ডাটা ভরে
            // ৪. কানেকশন অটোমেটিক ক্লোজ করে দেয়! (মাজিক!)
            da.Fill(dt);

            Console.WriteLine("Mama, Download Complete! Ekhon net off korleo somossa nai.");
            
            // এখন কানেকশন কিন্তু ক্লোজড। আমরা মেমোরি (RAM) থেকে ডাটা দেখাব।
            foreach (DataRow row in dt.Rows)
            {
                Console.WriteLine($"{row["ProductName"]} - {row["Price"]} Tk");
            }
        }
    }
}
```

### 🎓 Lesson 14: DataSet & DataTable - মেমোরিতে ডাটাবেস

**Concept:**
- **DataTable:** এটা হলো মেমোরির মধ্যে একটা এক্সেল শিট (Excel Sheet)। এতে Row আছে, Column আছে। ঠিক ডাটাবেসের টেবিলের কপি।
- **DataSet:** এটা হলো পুরো একটা এক্সেল ফাইল (Workbook)। একটা `DataSet` এর ভেতরে অনেকগুলো `DataTable` থাকতে পারে। এমনকি টেবিলগুলোর মধ্যে রিলেশনও (Relation) থাকতে পারে।

**Structure:**
`DataSet` ➡️ `DataTable` (Collection) ➡️ `DataRow` & `DataColumn`

**কখন কোনটা?**
- যদি শুধু একটা টেবিলের ডাটা আনো ➡️ `DataTable`
- যদি মাল্টিপল টেবিল (যেমন Products + Orders) আনো ➡️ `DataSet`

**Real C# Code (DataSet Example):**
```csharp
using (SqlConnection con = new SqlConnection(cs))
{
    // দুইটা কুয়েরি একসাথে
    string query = "SELECT * FROM Products; SELECT * FROM Orders;"; 
    SqlDataAdapter da = new SqlDataAdapter(query, con);
    
    DataSet ds = new DataSet();
    
    // Fill করার সময় ডাটাবেস থেকে দুইটা টেবিলই আসবে
    da.Fill(ds);

    // প্রথম টেবিল (Products)
    Console.WriteLine("--- Products List ---");
    foreach (DataRow row in ds.Tables[0].Rows)
    {
        Console.WriteLine(row["ProductName"]);
    }

    // দ্বিতীয় টেবিল (Orders) - যদি Orders টেবিল থাকে
    Console.WriteLine("\n--- Orders List ---");
    if (ds.Tables.Count > 1) 
    {
       // Orders টেবিল লুপ করা হবে
    }
}
```

**Mistake to Avoid:**
`DataSet` মেমোরি (RAM) অনেক বেশি খায়। ধরো তোমার ডাটাবেসে ১০ লাখ ডাটা আছে। তুমি যদি `da.Fill(dt)` দাও, পুরো ১০ লাখ ডাটা র‍্যামে লোড হবে। সার্ভার ক্র্যাশ খেতে পারে (Out of Memory Exception)। তাই সাবধানে!

### 🎓 Lesson 15: DataReader vs DataAdapter - কার শক্তি বেশি?

ভাতিজা, এটা ইন্টারভিউ বোর্ডের হট কেক প্রশ্ন। ভালো করে চার্টটা মাথায় গেঁথে নাও।

| বৈশিষ্ট্য | SqlDataReader | SqlDataAdapter (with DataSet/DataTable) |
| :--- | :--- | :--- |
| **আর্কিটেকচার** | Connected (ফোন কানে থাকা লাগে) | Disconnected (মেসেজ দিয়ে ফোন রাখা যায়) |
| **স্পিড** | সুপার ফাস্ট (F1 Race Car) | একটু স্লো (Heavy Truck) |
| **মেমোরি (RAM)** | খুব কম খায় (এক লাইন করে পড়ে) | বেশি খায় (সব ডাটা লোড করে) |
| **নেভিগেশন** | শুধু সামনে যায় (Forward Only) | সামনে, পেছনে, যেকোনো রো-তে যাওয়া যায় |
| **ব্যবহার** | শুধু ডাটা দেখানোর জন্য (List, Dropdown) | ডাটা নিয়ে কাজ করার জন্য, রিপোর্ট বানানোর জন্য |
| **Analogy** | লাইভ টিভি | রেকর্ডেড ভিডিও |

**Raju Mama's Verdict (মামার রায়):**
- যদি তোমার অ্যাপে শুধু ডাটা লিস্ট আকারে দেখাতে হয় এবং হাজার হাজার ডাটা থাকে ➡️ **চোখ বন্ধ করে `SqlDataReader`**।
- যদি ডাটা এনে সেটা প্রসেস করতে হয়, ফিল্টার করতে হয়, বা ইউজারের কাছে অফলাইনে রাখতে হয় ➡️ **`SqlDataAdapter`**।

---

**সামারি:**
ভাতিজা, আজ আমরা ডাটা রিডিং এর বস হয়ে গেলাম।
- লাইভ দেখার জন্য **Reader**।
- ডাউনলোড করে দেখার জন্য **Adapter**।
- আর মেমোরিতে ডাটা সাজানোর জন্য **DataTable/DataSet**।
