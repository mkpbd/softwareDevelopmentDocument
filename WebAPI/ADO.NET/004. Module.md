### 🎓 Lesson 21: Async/Await - অ্যাপ হ্যাং করবে না (Non-blocking)

**সমস্যা:**
ধরো তুমি একটা বাটনে ক্লিক করলে "Load Data"। ডাটাবেস থেকে ডাটা আসতে ৫ সেকেন্ড লাগল। এই ৫ সেকেন্ড তোমার সফটওয়্যার হ্যাং হয়ে থাকবে (Not Responding)। ইউজার বিরক্ত হয়ে অ্যাপ বন্ধ করে দিবে।

**সমাধান:**
**Async/Await**।
**মামা-ভাগ্নে এনালজি:**
ধরো তুমি চুলায় ভাত বসিয়েছ (Database Call)। ভাত হতে ২০ মিনিট লাগবে। তুমি কি ২০ মিনিট চুলার দিকে তাকিয়ে মূর্তির মতো দাঁড়িয়ে থাকবে? না! তুমি এই ফাঁকে পেঁয়াজ কাটবে, গান শুনবে (UI Responsive)। যখন ভাত হবে (Await), তখন তুমি আবার ভাতের হাড়ি ধরবে।

**Real C# Code:**
সব মেথড নামের শেষে `Async` যোগ হবে।

```csharp
using System.Threading.Tasks; // এটা মাস্ট লাগবে

public async Task LoadDataAsync()
{
    Console.WriteLine("Fetching data... (UI is still active)");

    using (SqlConnection con = new SqlConnection(cs))
    {
        string query = "SELECT COUNT(*) FROM Products";
        SqlCommand cmd = new SqlCommand(query, con);

        await con.OpenAsync(); // কানেকশন খুলতে সময় লাগলে অ্যাপ হ্যাং হবে না

        // ExecuteScalarAsync ব্যবহার করলাম
        var count = await cmd.ExecuteScalarAsync(); 
        
        Console.WriteLine($"Total Products: {count}");
    }
}

// কল করার নিয়ম:
// await LoadDataAsync();
```

**Common Mistake:**
`Async` মেথডকে জোর করে `Wait()` বা `.Result` দিয়ে কল করা। এটা করলে ডেডলক (Deadlock) লেগে অ্যাপ ক্র্যাশ করবে। সবসময় `await` ব্যবহার করবে।

### 🎓 Lesson 22: Helper Class - কোড রিপিট না করা (DRY Principle)

**DRY Principle:** **D**on't **R**epeat **Y**ourself.
আমরা প্রতিবার `SqlConnection`, `SqlCommand` বারবার লিখছি। এটা বোকামি। আমরা একটা **Helper Class** বানাবো, যে আমাদের হয়ে এই রিপিটেড কাজগুলো করে দিবে।

**Analogy:**
ইলেকট্রিশিয়ান মামা কি প্রতিটা ফ্যান ঠিক করার জন্য নতুন স্ক্রু-ড্রাইভার কিনে? না! তার একটা টুলবক্স (Helper Class) থাকে। যেখানে সব টুলস রেডি থাকে।

**Real Project Structure:**
```text
MyProject/
├── Helpers/
│   └── SqlHelper.cs
├── Program.cs
```

**File: SqlHelper.cs**
```csharp
using System;
using System.Configuration;
using System.Data;
using System.Data.SqlClient;

public class SqlHelper
{
    // কানেকশন স্ট্রিং এক জায়গা থেকেই আসবে
    private static string _cs = ConfigurationManager.ConnectionStrings["MyCon"].ToString();

    // ডাটা রিড করার জন্য কমন মেথড
    public static DataTable ExecuteQuery(string query)
    {
        using (SqlConnection con = new SqlConnection(_cs))
        {
            SqlDataAdapter da = new SqlDataAdapter(query, con);
            DataTable dt = new DataTable();
            da.Fill(dt);
            return dt;
        }
    }

    // ইনসার্ট/আপডেট/ডিলিট এর জন্য কমন মেথড
    public static int ExecuteUpdate(string query)
    {
        using (SqlConnection con = new SqlConnection(_cs))
        {
            SqlCommand cmd = new SqlCommand(query, con);
            con.Open();
            return cmd.ExecuteNonQuery();
        }
    }
}
```

**ব্যবহার (Program.cs):**
```csharp
// কত ক্লিন কোড দেখো!
DataTable dt = SqlHelper.ExecuteQuery("SELECT * FROM Products");
int result = SqlHelper.ExecuteUpdate("DELETE FROM Products WHERE ID=5");
```

### 🎓 Lesson 23: Layered Architecture (DAL, BLL, UI) - সাজানো গোছানো সংসার

**বিষয়:**
কোডকে ৩ তালায় ভাগ করা। একে **N-Tier Architecture** বলে।

1.  **UI (User Interface / Presentation Layer):** যা ইউজার দেখে (Console/Web/Mobile)। এখানে কোনো লজিক থাকবে না, ডাটাবেস কোডও থাকবে না।
2.  **BLL (Business Logic Layer):** ব্রেইন। ডিসকাউন্ট ক্যালকুলেশন, ভ্যালিডেশন (নাম কি খালি?), নিয়ম-কানুন এখানে থাকবে।
3.  **DAL (Data Access Layer):** স্টোররুম ম্যানেজার। এর কাজ শুধু ডাটাবেস থেকে মাল আনা আর রাখা। সে কোনো লজিক বোঝে না।

**Real Life Analogy:**
**রেস্টুরেন্ট:**
- **Customer (UI):** টেবিলে বসে অর্ডার দেয়।
- **Waiter (BLL):** অর্ডার নেয়, চেক করে আইটেম এভেইলেবল কিনা, কিচেনে জানায়।
- **Chef/Storekeeper (DAL):** রান্না করে বা ফ্রিজ থেকে জিনিস বের করে দেয়।

**Project Folder Structure:**
```text
TechShopSolution/
├── TechShop.UI (Console App)
├── TechShop.BLL (Class Library)
└── TechShop.DAL (Class Library)
```

**Why Important?**
ভবিষ্যতে যদি তুমি SQL Server বাদ দিয়ে Oracle বা MySQL ব্যবহার করো, শুধু **DAL** চেঞ্জ করলেই হবে। UI বা BLL এ হাত দেওয়া লাগবে না।

### 🎓 Lesson 24: Model/Entity Class - ডাটা ম্যাপ করা

**সমস্যা:**
আমরা `DataTable` বা `SqlDataReader` থেকে ডাটা আনলে `reader["Price"]` এভাবে লিখি। কলামের নাম ভুল হলে রানটাইমে এরর দেয়। তাছাড়া `DataTable` পাস করা ভারী কাজ।

**সমাধান:**
আমরা ডাটাবেসের টেবিলের হুবহু একটা ক্লাস বানাব C# এ। এটাকে বলে **Model** বা **Entity**।

**Analogy (টিফিন ক্যারিয়ার):**
তুমি কি ডাল পকেটে করে আর ভাত হাতে করে নাও? না! টিফিন বক্সে (Object) করে নাও। এই টিফিন বক্সটাই হলো মডেল ক্লাস।

**File: Product.cs**
```csharp
public class Product
{
    public int ProductID { get; set; }
    public string ProductName { get; set; }
    public decimal Price { get; set; }
    public int Stock { get; set; }
}
```

এখন আমরা ডাটাবেস থেকে ডাটা এনে এই `Product` অবজেক্টের মধ্যে ঢুকাব। তারপর পুরো অ্যাপে এই অবজেক্ট নিয়ে খেলব।

### 🎓 Lesson 25: Repository Pattern - গোডাউন ম্যানেজমেন্ট

**বিষয়:**
এটা DAL এর একটা উন্নত রূপ। আমরা সরাসরি DAL ক্লাসে কোড না লিখে, একটা ইন্টারফেস (Interface) বানাই।
Repository প্যাটার্ন বলে: "তোমার ডাটা কোথায় আছে (SQL/XML/API) আমি জানি না, আমি শুধু জানি `GetAllProducts()` কল করলে প্রোডাক্ট পাওয়া যাবে।"

**Structure:**
1.  **IProductRepository (Interface):** এখানে শুধু মেথডগুলোর নাম থাকবে (চুক্তিপত্র)।
2.  **ProductRepository (Class):** এখানে আসল ADO.NET কোড থাকবে।

**Step 1: Interface (Contract)**
```csharp
public interface IProductRepository
{
    List<Product> GetAll();
    void Add(Product p);
}
```

**Step 2: Implementation (Real Code)**
```csharp
public class ProductRepository : IProductRepository
{
    string cs = "Server=...;...";

    public List<Product> GetAll()
    {
        List<Product> list = new List<Product>();

        using (SqlConnection con = new SqlConnection(cs))
        {
            SqlCommand cmd = new SqlCommand("SELECT * FROM Products", con);
            con.Open();
            SqlDataReader rdr = cmd.ExecuteReader();

            while (rdr.Read())
            {
                // ডাটাবেস থেকে এনে মডেলে ভরছি (Mapping)
                Product p = new Product();
                p.ProductID = Convert.ToInt32(rdr["ProductID"]);
                p.ProductName = rdr["ProductName"].ToString();
                p.Price = Convert.ToDecimal(rdr["Price"]);
                
                list.Add(p); // লিস্টে যোগ করছি
            }
        }
        return list; // রিটার্ন দিচ্ছি সুন্দর লিস্ট, কোনো বিদঘুটে DataReader না
    }

    public void Add(Product p)
    {
        // ADO.NET insert code here using p.ProductName, p.Price...
    }
}
```

**Step 3: Usage in BLL/UI**
```csharp
// এখন কোড কত সুন্দর দেখো!
IProductRepository repo = new ProductRepository();
List<Product> allProducts = repo.GetAll();

foreach(var item in allProducts)
{
    Console.WriteLine(item.ProductName); // IntelliSense কাজ করবে! বানান ভুল হবে না।
}
```

**Why Hero Level?**
এই প্যাটার্ন ব্যবহার করলে কোড টেস্ট করা সহজ হয় (Unit Testing)। এবং ভবিষ্যতে ডাটাবেস চেঞ্জ করা পানির মতো সহজ হয়ে যায়।
