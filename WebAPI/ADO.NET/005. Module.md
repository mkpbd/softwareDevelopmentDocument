### 🎓 Lesson 26: Project Setup & DB Design

**ভিত্তিপ্রস্তর স্থাপন:**
বিল্ডিং বানানোর আগে যেমন নকশা করতে হয়, কোড করার আগে ডাটাবেস ডিজাইন আর ফোল্ডার স্ট্রাকচার রেডি করতে হয়।

**১. Database Script (SQL Server):**
SSMS ওপেন করে এই স্ক্রিপ্ট রান করো। আমরা ৩টা টেবিল বানাবো: `Users` (লগইন), `Products` (মালপত্র), `Orders` (বেচাকেনা)।

```sql
CREATE DATABASE ShopDB;
GO
USE ShopDB;
GO

-- 1. Users Table (লগিন এর জন্য)
CREATE TABLE Users (
    UserID INT IDENTITY(1,1) PRIMARY KEY,
    Username NVARCHAR(50) UNIQUE,
    Password NVARCHAR(50), -- রিয়েল লাইফে হ্যাশ করে রাখতে হয়
    Role NVARCHAR(20) -- Admin / Manager
);

-- ডিফল্ট ইউজার (Admin)
INSERT INTO Users VALUES ('admin', '1234', 'Admin');

-- 2. Products Table
CREATE TABLE Products (
    ProductID INT IDENTITY(1,1) PRIMARY KEY,
    ProductName NVARCHAR(100),
    Price DECIMAL(18, 2),
    Stock INT
);

-- 3. Orders Table (Header)
CREATE TABLE Orders (
    OrderID INT IDENTITY(1,1) PRIMARY KEY,
    OrderDate DATETIME DEFAULT GETDATE(),
    TotalAmount DECIMAL(18, 2)
);

-- 4. OrderDetails Table (কোন অর্ডারে কী কী আইটেম আছে)
CREATE TABLE OrderDetails (
    DetailID INT IDENTITY(1,1) PRIMARY KEY,
    OrderID INT FOREIGN KEY REFERENCES Orders(OrderID),
    ProductID INT FOREIGN KEY REFERENCES Products(ProductID),
    Quantity INT,
    UnitPrice DECIMAL(18, 2)
);
```

### 🎓 Lesson 27: Login System (Authentication)

**সিকিউরিটি গার্ড:**
দোকানের শাটার খোলার চাবি (Login) সবার কাছে থাকবে না। শুধু যার নাম লিস্টে আছে, সেই ঢুকবে।

**Model (Models/User.cs):**
```csharp
public class User
{
    public string Username { get; set; }
    public string Password { get; set; }
    public string Role { get; set; }
}
```

**DAL (DAL/AuthRepository.cs):**
```csharp
using System.Data.SqlClient;
// namespaces...

public class AuthRepository
{
    string cs = System.Configuration.ConfigurationManager.ConnectionStrings["MyCon"].ConnectionString;

    public bool Login(string uName, string pass)
    {
        using (SqlConnection con = new SqlConnection(cs))
        {
            // SQL Injection আটকাতে প্যারামিটার মাস্ট!
            string query = "SELECT COUNT(*) FROM Users WHERE Username=@u AND Password=@p";
            SqlCommand cmd = new SqlCommand(query, con);
            cmd.Parameters.AddWithValue("@u", uName);
            cmd.Parameters.AddWithValue("@p", pass);

            con.Open();
            int count = (int)cmd.ExecuteScalar();
            
            return count > 0; // ১ হলে ট্রু (লগিন সাকসেস), ০ হলে ফলস
        }
    }
}
```

### 🎓 Lesson 28: Product CRUD Operation

**দোকান সাজানো:**
এখন আমরা প্রোডাক্ট উঠাবো, দাম চেঞ্জ করবো। এখানে আমরা **Layered Architecture** এর পিওর ব্যবহার দেখব।

**Model (Models/Product.cs):**
```csharp
public class Product
{
    public int ProductID { get; set; }
    public string ProductName { get; set; }
    public decimal Price { get; set; }
    public int Stock { get; set; }
}
```

**DAL (DAL/ProductRepository.cs):**
```csharp
public class ProductRepository
{
    // কানেকশন স্ট্রিং... (সংক্ষেপে)
    
    // সব প্রোডাক্ট দেখার মেথড
    public List<Product> GetAllProducts()
    {
        List<Product> list = new List<Product>();
        using (SqlConnection con = new SqlConnection(cs))
        {
            SqlCommand cmd = new SqlCommand("SELECT * FROM Products", con);
            con.Open();
            SqlDataReader rdr = cmd.ExecuteReader();
            while (rdr.Read())
            {
                list.Add(new Product 
                {
                    ProductID = (int)rdr["ProductID"],
                    ProductName = rdr["ProductName"].ToString(),
                    Price = (decimal)rdr["Price"],
                    Stock = (int)rdr["Stock"]
                });
            }
        }
        return list;
    }

    // প্রোডাক্ট অ্যাড করার মেথড
    public void AddProduct(Product p)
    {
        using (SqlConnection con = new SqlConnection(cs))
        {
            string query = "INSERT INTO Products VALUES (@n, @p, @s)";
            SqlCommand cmd = new SqlCommand(query, con);
            cmd.Parameters.AddWithValue("@n", p.ProductName);
            cmd.Parameters.AddWithValue("@p", p.Price);
            cmd.Parameters.AddWithValue("@s", p.Stock);
            
            con.Open();
            cmd.ExecuteNonQuery();
        }
    }
}
```

### 🎓 Lesson 29: Order Processing with Transaction

**দ্য ফাইনাল বস ফাইট (Transaction):**
ধরো কাস্টমার ২টা আইটেম কিনল: ১টা মাউস, ১টা কিবোর্ড।
এখানে কাজ হবে ৩ ধাপে:
১. `Orders` টেবিলে একটা এন্ট্রি হবে (Header)।
২. `OrderDetails` টেবিলে ২টা এন্ট্রি হবে (Items)।
৩. `Products` টেবিল থেকে স্টক কমাতে হবে (Update Stock)।

যদি ৩ নম্বর ধাপে গিয়ে কারেন্ট চলে যায় বা এরর হয়, তাহলে ১ আর ২ নম্বর ধাপও বাতিল হতে হবে। একেই বলে **Transaction**।

**Code (DAL/OrderRepository.cs):**
```csharp
public void PlaceOrder(List<Product> cartItems, decimal totalAmount)
{
    using (SqlConnection con = new SqlConnection(cs))
    {
        con.Open();
        SqlTransaction tran = con.BeginTransaction(); // ১. ট্রানজ্যাকশন শুরু

        try
        {
            // ২. মেইন অর্ডারে এন্ট্রি
            string orderQuery = "INSERT INTO Orders (TotalAmount) VALUES (@amt); SELECT SCOPE_IDENTITY();";
            SqlCommand cmdOrder = new SqlCommand(orderQuery, con, tran); // ট্রানজ্যাকশন লিংক করলাম
            cmdOrder.Parameters.AddWithValue("@amt", totalAmount);
            
            // নতুন অর্ডার আইডি পেলাম
            int newOrderID = Convert.ToInt32(cmdOrder.ExecuteScalar());

            // ৩. লুপ চালিয়ে আইটেম ডিটেইলস এবং স্টক আপডেট
            foreach (var item in cartItems)
            {
                // A. ডিটেইলস টেবিলে ইনসার্ট
                string detailQuery = "INSERT INTO OrderDetails VALUES (@oid, @pid, 1, @price)";
                SqlCommand cmdDetail = new SqlCommand(detailQuery, con, tran);
                cmdDetail.Parameters.AddWithValue("@oid", newOrderID);
                cmdDetail.Parameters.AddWithValue("@pid", item.ProductID);
                cmdDetail.Parameters.AddWithValue("@price", item.Price);
                cmdDetail.ExecuteNonQuery();

                // B. স্টক কমানো
                string stockQuery = "UPDATE Products SET Stock = Stock - 1 WHERE ProductID = @pid";
                SqlCommand cmdStock = new SqlCommand(stockQuery, con, tran);
                cmdStock.Parameters.AddWithValue("@pid", item.ProductID);
                cmdStock.ExecuteNonQuery();
            }

            // ৪. সব ঠিক থাকলে কমিট
            tran.Commit();
            Console.WriteLine("Order Successful Mama! Cash box e taka dhukse.");
        }
        catch (Exception ex)
        {
            // ৫. ঘাপলা হলে রোলব্যাক
            tran.Rollback();
            Console.WriteLine("Transaction Failed! Rolling back... " + ex.Message);
        }
    }
}
```

### 🎓 Lesson 30: Final Optimization & Certificate Summary

**ফিনিশিং টাচ:**
প্রজেক্ট তো হলো। এখন কিছু টিপস যা তোমাকে "Senior Developer" বানাবে:

1.  **Always Close Connections:** `using` ব্লক ব্যবহার করা বাদ দিবে না।
2.  **Use Stored Procedures:** প্রোডাকশনে র-কুয়েরির বদলে SP ব্যবহার করবে (Lesson 16)।
3.  **Exception Handling:** ইউজারকে কখনো লাল-নীল এরর দেখাবে না। `Try-Catch` দিয়ে সুন্দর মেসেজ দিবে।
4.  **Async:** UI যাতে ফ্রিজ না হয়, তাই `ExecuteReaderAsync` ব্যবহার করবে (Lesson 21)।
5.  **Sensitive Data:** পাসওয়ার্ড প্লেইন টেক্সটে রাখবে না (Hashing ব্যবহার করবে)।
