### **Phase 1: Dapper এর সাথে পরিচিতি (Introduction & Setup)**

#### **Lesson 1: Dapper কি এবং কেন? (The Speedboat)**
*   **সহজ কথা:** Dapper হলো একটি **Micro-ORM**। এটি তোমার C# কোড এবং SQL Database এর মধ্যে ঘটকালি (Matchmaker) করে।
*   **Real-life Analogy:** মনে করো তুমি বিরিয়ানি খাবে।
    *   **EF Core:** তুমি ওয়েটারকে বললে, ওয়েটার শেফকে বলল, শেফ রান্না করে ওয়েটারকে দিল, ওয়েটার তোমাকে দিল। (দেরি হবে, প্রসেস বেশি)।
    *   **Dapper:** তুমি সোজা পাতিলের সামনে গিয়ে বাবুর্চিকে বললে "এক প্লেট দেন", আর সাথে সাথে পেয়ে গেলে। (সুপার ফাস্ট)।
*   **কেন শিখব:** যখন পারফরম্যান্স খুব জরুরি এবং তুমি নিজের SQL নিজে লিখতে পছন্দ করো।

#### **Lesson 2: প্রজেক্ট সেটআপ (The Toolkit)**
*   **কাজ:** Visual Studio তে একটা Console App বা Web API খুলো।
*   **Analogy:** বাইক চালানোর আগে হেলমেট আর চাবি তো লাগবেই!
*   **Action:** NuGet Package Manager এ গিয়ে সার্চ দাও `Dapper` এবং `System.Data.SqlClient` (বা `Microsoft.Data.SqlClient`)। Install বাটনে চাপ দাও।

#### **Lesson 3: Connection String (The House Key)**
*   **সহজ কথা:** ডেটাবেসে ঢোকার চাবি।
*   **Code:**
    ```csharp
    string connectionString = "Server=myServer;Database=myDB;User Id=myUser;Password=myPassword;";
    ```
*   **Analogy:** এটা হলো তোমার গার্লফ্রেন্ডের বাপার বাড়ির মেইন গেটের চাবি। এটা ভুল হলে বাড়ির ভেতরে (ডেটাবেসে) ঢুকতেই পারবে না।

#### **Lesson 4: IDbConnection ইন্টারফেস (The Gatekeeper)**
*   **সহজ কথা:** Dapper কাজ করে `IDbConnection` এর উপর।
*   **Code:**
    ```csharp
    using System.Data.SqlClient;
    using Dapper;

    using (var connection = new SqlConnection(connectionString))
    {
        connection.Open();
        // Dapper magic here
    }
    ```
*   **Analogy:** `connection.Open()` হলো গেট খুলে ভেতরে ঢুকা। কাজ শেষ হলে `using` ব্লক অটোমেটিক গেট বন্ধ করে দেবে।

#### **Lesson 5: তোমার প্রথম Model (The Blueprint)**
*   **কাজ:** C# এ একটা Class বানাও যেটা ডেটাবেস টেবিলের মতো দেখতে।
*   **Code:**
    ```csharp
    public class Product
    {
        public int Id { get; set; }
        public string Name { get; set; }
        public decimal Price { get; set; }
    }
    ```
*   **Analogy:** এটা হলো বিস্কুটের ছাঁচ। ডেটাবেস থেকে ডেটা (ময়দা) এসে এই ছাঁচে পড়ে প্রোডাক্ট অবজেক্ট তৈরি হবে।

### **Phase 2: ডেটা পড়া (Data Retrieval Strategies)**

#### **Lesson 6: `Query<T>` - সব নিয়ে আসো (The Wholesale Buyer)**
*   **কাজ:** যখন অনেকগুলো ডেটা (List) দরকার।
*   **Scenario:** দোকানের সব প্রোডাক্ট দেখাও।
*   **Code:**
    ```csharp
    string sql = "SELECT * FROM Products";
    var products = connection.Query<Product>(sql).ToList();
    ```
*   **Analogy:** মামা, ঝুড়িতে যত আম আছে সব দিয়ে দেন!

#### **Lesson 7: Parameters - হ্যাকার থেকে বাঁচো (The Security Guard)**
*   **সমস্যা:** `sql = "SELECT * FROM Users WHERE Name = '" + userInput + "'"` (এটা মহাপাপ! SQL Injection হবে)।
*   **সমাধান:** Dapper Parameters.
*   **Code:**
    ```csharp
    string sql = "SELECT * FROM Products WHERE Id = @Id";
    var product = connection.Query(sql, new { Id = 1 });
    ```
*   **Analogy:** ছাঁকনি দিয়ে পানি খাওয়া। যাতে ময়লা (Hacker) পেটে না যায়।

#### **Lesson 8: `QueryFirst` - প্রথমটা দাও (The Impatient)**
*   **কাজ:** লিস্টের প্রথম আইটেমটা দরকার। না পেলে `Exception` খাবে।
*   **Code:**
    ```csharp
    var p = connection.QueryFirst<Product>("SELECT * FROM Products WHERE Id = 1");
    ```
*   **Analogy:** বাসের সিটে যেই আগে বসবে, তাকেই নিব। কেউ না থাকলে চিল্লাচিল্লি করব (Error)।

#### **Lesson 9: `QueryFirstOrDefault` - না পেলে সমস্যা নাই (The Cool Guy)**
*   **কাজ:** প্রথমটা দাও, না পেলে `null` দাও। ক্রাশ না খেয়ে হ্যান্ডেল করা।
*   **Code:**
    ```csharp
    var p = connection.QueryFirstOrDefault<Product>("SELECT * FROM Products WHERE Id = 999");
    // p will be null, no error.
    ```
*   **Analogy:** মামা চা আছে? থাকলে দেন, না থাকলে নাই। নো টেনশন। (Best Practice: সিঙ্গেল আইটেম খুঁজতে এটা ব্যবহার করো)।

#### **Lesson 10: `QuerySingle` - একটাই চাই (The One & Only)**
*   **কাজ:** আশা করছি **একটাই** রেকর্ড আছে। যদি ০ টা বা ২ টা পায়, তাহলে Error দিবে।
*   **Code:**
    ```csharp
    var p = connection.QuerySingle<Product>("SELECT * FROM Products WHERE Id = 1");
    ```
*   **Analogy:** বিয়ে একটাই করব। বউ ২টা হলেও সমস্যা (Error), না থাকলেও সমস্যা (Error)।

### **Phase 3: ডেটা ম্যানিপুলেশন (CRUD Operations)**

#### **Lesson 11: `Execute` - অর্ডার দেওয়া (The Commander)**
*   **কাজ:** Insert, Update, Delete করার জন্য। এটা কোনো ডেটা রিটার্ন করে না, শুধু বলে কয়টা row এফেক্টেড হলো।
*   **Code:**
    ```csharp
    string sql = "INSERT INTO Products (Name, Price) VALUES (@Name, @Price)";
    int rowsAffected = connection.Execute(sql, new { Name = "Laptop", Price = 50000 });
    ```
*   **Analogy:** রিকশাওয়ালাকে টাকা দিয়ে বললাম "যাও"। সে চলে গেল। সে আমাকে কিছু ফেরত দিল না (শুধু সার্ভিস ছাড়া)।

#### **Lesson 12: Insert Operation (নতুন মাল তোলাম)**
*   **Scenario:** দোকানে নতুন চিপস এসেছে, এন্ট্রি দাও।
*   **Code:** (Lesson 11 এর কোডটাই Insert)।
*   **Tips:** `Execute` মেথড ব্যবহার করবে।

#### **Lesson 13: Update Operation (ভুল সংশোধন)**
*   **Scenario:** ল্যাপটপের দাম বেড়েছে।
*   **Code:**
    ```csharp
    string sql = "UPDATE Products SET Price = @Price WHERE Id = @Id";
    connection.Execute(sql, new { Price = 55000, Id = 1 });
    ```
*   **Analogy:** পরীক্ষার খাতায় ভুল উত্তর কেটে ঠিক করা।

#### **Lesson 14: Delete Operation (সব শেষ!)**
*   **Scenario:** এই প্রোডাক্ট আর বেচব না।
*   **Code:**
    ```csharp
    string sql = "DELETE FROM Products WHERE Id = @Id";
    connection.Execute(sql, new { Id = 1 });
    ```
*   **Analogy:** এক্স-গার্লফ্রেন্ডের নাম্বার ফোন থেকে ডিলিট করা। সাবধানে! `WHERE` ক্লজ না দিলে সব ডিলিট হয়ে যাবে (সব কন্টাক্ট ডিলিট হওয়ার মতো বিপদ)।

#### **Lesson 15: Insert করে ID ফেরত আনা (Return Value)**
*   **কাজ:** ডেটা ঢোকানোর পর সেই ডেটার `Id` টা দরকার।
*   **Code:**
    ```csharp
    string sql = "INSERT INTO Products (Name) VALUES (@Name); SELECT CAST(SCOPE_IDENTITY() as int)";
    int newId = connection.QuerySingle<int>(sql, new { Name = "Mouse" });
    ```
*   **Analogy:** ব্যাংকে টাকা জমা দিয়ে রিসিপ্ট কপি (ID) নিয়ে আসা।

### **Phase 4: মাসল পাওয়ার (Advanced Features)**

#### **Lesson 16: Stored Procedure (The Prepared Dish)**
*   **কি:** ডেটাবেসে আগে থেকেই লেখা কোড বা লজিক।
*   **Code:**
    ```csharp
    var products = connection.Query<Product>(
        "GetAllProducts", 
        commandType: CommandType.StoredProcedure
    );
    ```
*   **Analogy:** রেস্টুরেন্টের মেনু। তোমাকে রেসিপি বলতে হয় না, শুধু নাম (SP Name) বললেই খাবার চলে আসে।

#### **Lesson 17: `IN` Clause (The Group Party)**
*   **কাজ:** অনেকগুলো ID এর ডেটা একসাথে আনা।
*   **Code:**
    ```csharp
    var ids = new[] { 1, 2, 3 };
    string sql = "SELECT * FROM Products WHERE Id IN @Ids";
    var products = connection.Query<Product>(sql, new { Ids = ids });
    ```
*   **Analogy:** বন্ধুদের ট্রিট দেওয়া। "মামা, ১, ২ আর ৩ নম্বর টেবিলের বিল আমি দিব।"

#### **Lesson 18: Multiple Result Sets (The Combo Meal)**
*   **কাজ:** এক কুয়েরিতে একাধিক টেবিলের ডেটা আনা।
*   **Code:**
    ```csharp
    string sql = "SELECT * FROM Products; SELECT * FROM Categories;";
    using (var multi = connection.QueryMultiple(sql))
    {
        var products = multi.Read<Product>().ToList();
        var categories = multi.Read<Category>().ToList();
    }
    ```
*   **Analogy:** বার্গার সেট অর্ডার করা। এক ট্রে-তে বার্গারও (Products) থাকে, কোকও (Categories) থাকে।

#### **Lesson 19: Dynamic Parameters (The Joker Card)**
*   **কাজ:** যখন জানো না কয়টা প্যারামিটার লাগবে। রান টাইমে ঠিক হবে।
*   **Code:**
    ```csharp
    var p = new DynamicParameters();
    p.Add("@Id", 1);
    p.Add("@Name", "Phone");
    connection.Execute("MyProc", p, commandType: CommandType.StoredProcedure);
    ```
*   **Analogy:** বিয়েবাড়ির খাম। ভেতরে ১০০ টাকাও থাকতে পারে, ১০০০ টাকাও থাকতে পারে। খোলার আগে ফিক্সড না।

#### **Lesson 20: Async/Await (The Multitasker)**
*   **কাজ:** ডেটাবেস কলের সময় অ্যাপ যেন হ্যাং (Freeze) না হয়।
*   **Code:**
    ```csharp
    var products = await connection.QueryAsync<Product>("SELECT * FROM Products");
    ```
*   **Analogy:** হোটেলে অর্ডার দিয়ে বসে না থেকে ফেসবুকে স্ক্রল করা। খাবার আসলে খাওয়া শুরু করবে। সময় নষ্ট কম।

### **Phase 5: ম্যাপিং মাস্টারি (Relationships)**

#### **Lesson 21: Multi-Mapping (1-to-1) (The Couple)**
*   **Scenario:** Product এর সাথে Category লোড করা (যেমন: Laptop belongs to Electronics)।
*   **Code:**
    ```csharp
    string sql = "SELECT p.*, c.* FROM Products p JOIN Categories c ON p.CategoryId = c.Id";
    var list = connection.Query<Product, Category, Product>(
        sql,
        (product, category) => {
            product.Category = category;
            return product;
        },
        splitOn: "Id"
    ).ToList();
    ```
*   **Analogy:** রিকশায় হুড তুলে কপোত-কপোতী যাচ্ছে। তারা আলাদা মানুষ, কিন্তু এখন এক রিকশায় (Object) বসে আছে।

#### **Lesson 22: `splitOn` এর কাজ কি? (The Divider)**
*   **ব্যাখ্যা:** Dapper কে বলে দেওয়া কোথা থেকে দ্বিতীয় অবজেক্ট শুরু হয়েছে। ডিফল্টভাবে এটা "Id"।
*   **Analogy:** ট্রেনের দুই বগির মাঝখানের জয়েন্ট। এটা দেখলেই Dapper বোঝে "আচ্ছা, এখান থেকে পরের বগি শুরু"।

#### **Lesson 23: Multi-Mapping (1-to-Many) (The Parent & Kids)**
*   **Scenario:** ১টা ক্যাটাগরিতে অনেকগুলো প্রোডাক্ট থাকে।
*   **কাজ:** `Dictionary` ব্যবহার করে গ্রুপিং করতে হয়।
*   **Analogy:** হাঁস আর তার পেছনের একগাদা ছানা। সব ছানাকে হাঁসের আন্ডারে আনতে হবে।

#### **Lesson 24: Custom Type Handlers (The Translator)**
*   **Scenario:** ডেটাবেসে আছে `JSON` স্ট্রিং, কিন্তু C# এ চাই `List<string>`।
*   **কাজ:** কাস্টম হ্যান্ডলার বানিয়ে কনভার্ট করা।
*   **Analogy:** চাইনিজ ডেলিগেট এসেছে, তুমি দোভাষী (Translator) রেখেছ যে চাইনিজ শুনে বাংলায় বুঝিয়ে দেয়।

#### **Lesson 25: Anonymous Objects (No Name Hero)**
*   **কাজ:** যখন হুবহু ক্লাসের দরকার নেই, শুধু কিছু ডেটা দরকার।
*   **Code:**
    ```csharp
    var result = connection.Query("SELECT Name, Price FROM Products").Select(x => new { x.Name, x.Price });
    ```
*   **Analogy:** রাস্তায় অপরিচিত কারোর কাছে সময় জিজ্ঞেস করা। তার নাম-ধাম জানার দরকার নেই, শুধু সময় জানলেই হলো।

### **Phase 6: হিরো লেভেল (Pro Practices)**

#### **Lesson 26: Transactions (The All or Nothing)**
*   **কাজ:** হয় সব কাজ হবে, নাহলে কিছুই হবে না।
*   **Scenario:** টাকা পাঠানো: এক অ্যাকাউন্ট থেকে কমবে, অন্যটায় বাড়বে। মাঝপথে কারেন্ট গেলে সর্বনাশ!
*   **Code:**
    ```csharp
    using (var transaction = connection.BeginTransaction())
    {
        try {
            connection.Execute(sql1, transaction: transaction);
            connection.Execute(sql2, transaction: transaction);
            transaction.Commit(); // সব ঠিক থাকলে সেভ।
        } catch {
            transaction.Rollback(); // ভুল হলে আগের অবস্থায়।
        }
    }
    ```
*   **Analogy:** জমি কেনা। টাকা দেওয়া + দলিল রেজিস্ট্রি। দুইটা না হলে ডিল ক্যান্সেল।

#### **Lesson 27: Repository Pattern with Dapper (The Organized Home)**
*   **কাজ:** সব ডেটাবেস কোড আলাদা ফাইলে রাখা। কন্ট্রোলারে সরাসরি কুয়েরি না লেখা।
*   **Analogy:** মোজা ড্রয়ারে, জামা আলমারিতে। সব কিছু অগোছালোভাবে ফ্লোরে না রাখা।

#### **Lesson 28: Bulk Insert (The Cargo Ship)**
*   **কাজ:** ১০০০ টা প্রোডাক্ট লুপ চালিয়ে Insert না করে `Dapper.Plus` বা `BulkCopy` ব্যবহার করা।
*   **Analogy:** একটা একটা করে ইট না এনে, ট্রাক ভরে ইট আনা।

#### **Lesson 29: Dapper Performance Tips (Nitro Boost)**
*   **Tips:**
    1. সবসময় `Async` ব্যবহার করবে।
    2. দরকার না হলে `ToList()` সাথে সাথে মারবে না (Buffered vs Unbuffered)।
    3. `QueryFirst` ব্যবহার করবে `Query` এর বদলে যদি একটাই লাগে।
*   **Analogy:** বাইক সার্ভিসিং। ভালো মবিল দিলে বাইক মাখনের মতো চলে।

#### **Lesson 30: Common Mistakes & Fixes (The Final Exam)**
*   **ভুল ১:** `Parameter` না ব্যবহার করে String যোগ করা (SQL Injection)।
*   **ভুল ২:** Transaction `Commit` করতে ভুলে যাওয়া।
*   **ভুল ৩:** Connection `Open` বা `Dispose` ঠিকমতো না করা।
*   **উপদেশ:** সবসময় `using` ব্লক ব্যবহার করবে।
