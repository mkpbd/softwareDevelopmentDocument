### Lesson 6: ডাটা পড়া বা রিড করা (Read/Select)

**👨‍🏫 কোড রান টিপ:** `Program.cs` ফাইলে আগের কোড মুছে এই লেসনের কোড লিখুন। ডাটাবেজে কিছু ডামি ডাটা থাকা প্রয়োজন (আগের লেসন থেকে)।

**🎉 ভূমিকা:**
ডাটাবেজে ডাটা তো রাখলেন, এখন সেটা দেখবেন কীভাবে? এটা অনেকটা গুগলে সার্চ করার মতো। আপনি EF Core-কে বলবেন "আমাকে সব প্রোডাক্ট দেখাও" অথবা "যাদের আইডি ১ তাকে দেখাও"। EF Core আপনার হয়ে SQL `SELECT` কুয়েরি চালিয়ে ডাটা নিয়ে আসবে।

**🎯 শেখার লক্ষ্য:**
১. `ToList()` ব্যবহার করে সব ডাটা আনা।
২. `Find()` বা `FirstOrDefault()` দিয়ে নির্দিষ্ট একটি ডাটা আনা।
৩. ডাটা নেই এমন পরিস্থিতির (Null) হ্যান্ডলিং।

**📖 প্রধান বিষয়বস্তু:**
EF Core এ ডাটা পড়ার জন্য আমরা **LINQ (Language Integrated Query)** ব্যবহার করি।
- **`context.Products.ToList()`**: এটি `SELECT * FROM Products` চালায় এবং সব ডাটা মেমোরিতে নিয়ে আসে।
- **`context.Products.Find(1)`**: এটি প্রাইমারি কি (PK) দিয়ে সরাসরি ডাটা খোঁজে।
- **`context.Products.FirstOrDefault(p => p.Name == "Mouse")`**: এটি শর্ত দিয়ে প্রথম ডাটাটি খোঁজে।

**💻 কোড উদাহরণ:**

**ফাইল:** `src/Program.cs`
```csharp
using System;
using System.Linq; // LINQ ব্যবহারের জন্য এটি জরুরি
using Lesson01_Intro.Data;
using Lesson01_Intro.Models;

namespace Lesson01_Intro
{
    class Program
    {
        static void Main(string[] args)
        {
            using (var context = new AppDbContext())
            {
                // ডাটা না থাকলে কিছু ডামি ডাটা যোগ করে নিচ্ছি
                if (!context.Products.Any())
                {
                    context.Products.AddRange(
                        new Product { Name = "Laptop", Price = 85000 },
                        new Product { Name = "Mouse", Price = 500 },
                        new Product { Name = "Keyboard", Price = 1200 }
                    );
                    context.SaveChanges();
                }

                Console.WriteLine("--- 1. সব ডাটা রিড করা (Select All) ---");
                // ডাটাবেজ থেকে সব প্রোডাক্ট নিয়ে একটি List<Product> ফেরত দেয়
                var allProducts = context.Products.ToList();

                foreach (var p in allProducts)
                {
                    Console.WriteLine($"ID: {p.Id}, Name: {p.Name}, Price: {p.Price}");
                }

                Console.WriteLine("\n--- 2. নির্দিষ্ট আইডি দিয়ে খোঁজা (Find by ID) ---");
                int searchId = 1;
                var product = context.Products.Find(searchId);

                if (product != null)
                {
                    Console.WriteLine($"Found: {product.Name}");
                }
                else
                {
                    Console.WriteLine($"ID {searchId} দিয়ে কোনো প্রোডাক্ট পাওয়া যায়নি।");
                }

                Console.WriteLine("\n--- 3. শর্ত দিয়ে প্রথমটি খোঁজা (First matching item) ---");
                // নাম 'Mouse' এমন প্রথম প্রোডাক্টটি আনবে
                var mouse = context.Products.FirstOrDefault(p => p.Name == "Mouse");
                Console.WriteLine($"Mouse Price: {mouse?.Price}"); // '?' মানে null না হলে প্রিন্ট করবে
            }
        }
    }
}
```

**🏋️‍♂️ প্র্যাকটিস এক্সারসাইজ:**
১. `FirstOrDefault` ব্যবহার করে এমন একটি প্রোডাক্ট খুঁজুন যার নাম "Monitor"। যদি না থাকে তবে কনসোলে "Not Found" প্রিন্ট করুন।
২. `Find` মেথড ব্যবহার করে ID 999 খোঁজার চেষ্টা করুন এবং দেখুন কী রিটার্ন করে (Null চেক করুন)।

**🧠 কুইজ:**
১. `ToList()` মেথডটি কখন SQL কুয়েরি ডাটাবেজে পাঠায়?
   A. অ্যাপ চালু হওয়ার সাথে সাথে
   B. মেথডটি কল করার ঠিক মুহূর্তেই (Immediate Execution) (উত্তর: B)
   C. লুপ চালানোর সময়

২. যদি `FirstOrDefault` কোনো ডাটা খুঁজে না পায়, তবে এটি কী রিটার্ন করে?
   A. Error / Exception
   B. null (উত্তর: B)
   C. একটি খালি অবজেক্ট

৩. প্রাইমারি কি (Primary Key) দিয়ে খোঁজার সবচেয়ে এফিশিয়েন্ট মেথড কোনটি?
   A. Where
   B. Find (উত্তর: B)
   C. ToList

**⚠️ খুব জরুরি নোট:** `ToList()` সবসময় সবার শেষে কল করবেন। যদি `ToList()` এর আগে ফিল্টার না করেন, তবে পুরো ডাটাবেজ মেমোরিতে চলে আসবে যা অ্যাপ স্লো করে দেবে!

### Lesson 7: ডাটা ফিল্টারিং ও সর্টিং (Filtering & Sorting)

**👨‍🏫 কোড রান টিপ:** আগের কোড মুছে ফেলুন বা কমেন্ট করুন।

**🎉 ভূমিকা:**
আপনার দোকানে ১০০০টি পণ্য আছে। কাস্টমার এসে বলল, "ভাই, ৫০০০ টাকার নিচে কী কী আছে দেখান, তবে দাম অনুযায়ী সাজিয়ে দেবেন।"—এটাই হলো ফিল্টারিং (Filtering) এবং সর্টিং (Sorting)। EF Core-এ আমরা C# এর লজিক লিখব, আর EF Core সেটাকে SQL `WHERE` এবং `ORDER BY` ক্লজ-এ রূপান্তর করবে।

**🎯 শেখার লক্ষ্য:**
১. `Where()` মেথড দিয়ে ডাটা ফিল্টার করা।
২. `OrderBy()` এবং `OrderByDescending()` দিয়ে ডাটা সাজানো।
৩. মেথড চেইনিং (Method Chaining) বোঝা।

**📖 প্রধান বিষয়বস্তু:**
- **Filtering:** `Where(p => p.Price > 1000)`। এটি SQL-এ `WHERE Price > 1000` এ পরিণত হয়।
- **Sorting:** `OrderBy(p => p.Price)` (ছোট থেকে বড়) বা `OrderByDescending` (বড় থেকে ছোট)।
- **Chaining:** আমরা এক লাইনে একাধিক লজিক জুড়তে পারি: `context.Products.Where(...).OrderBy(...)`।

**💻 কোড উদাহরণ:**

**ফাইল:** `src/Program.cs`
```csharp
using System;
using System.Linq;
using Lesson01_Intro.Data;
using Lesson01_Intro.Models;

namespace Lesson01_Intro
{
    class Program
    {
        static void Main(string[] args)
        {
            using (var context = new AppDbContext())
            {
                // কিছু স্যাম্পল ডাটা নিশ্চিত করা
                if (!context.Products.Any())
                {
                    context.Products.AddRange(
                        new Product { Name = "Apple", Price = 200 },
                        new Product { Name = "Mango", Price = 150 },
                        new Product { Name = "Orange", Price = 180 },
                        new Product { Name = "Grape", Price = 400 }
                    );
                    context.SaveChanges();
                }

                Console.WriteLine("--- 1. ফিল্টারিং (দাম ২০০ বা তার বেশি) ---");
                // SQL: SELECT * FROM Products WHERE Price >= 200
                var expensiveProducts = context.Products
                                               .Where(p => p.Price >= 200)
                                               .ToList();

                foreach (var p in expensiveProducts)
                {
                    Console.WriteLine($"{p.Name} - {p.Price} tk");
                }

                Console.WriteLine("\n--- 2. সর্টিং (নাম অনুযায়ী A-Z) ---");
                // SQL: SELECT * FROM Products ORDER BY Name
                var sortedByName = context.Products
                                          .OrderBy(p => p.Name)
                                          .ToList();

                foreach (var p in sortedByName)
                {
                    Console.WriteLine($"{p.Name}");
                }

                Console.WriteLine("\n--- 3. চেইনিং (ফিল্টার + সর্টিং) ---");
                // দাম ২০০ এর কম এবং দাম অনুযায়ী বড় থেকে ছোট সাজানো
                var cheapSorted = context.Products
                                         .Where(p => p.Price < 200)
                                         .OrderByDescending(p => p.Price)
                                         .ToList();

                foreach (var p in cheapSorted)
                {
                    Console.WriteLine($"{p.Name} : {p.Price}");
                }
            }
        }
    }
}
```

**🏋️‍♂️ প্র্যাকটিস এক্সারসাইজ:**
১. এমন সব প্রোডাক্ট বের করুন যাদের নামের মধ্যে "o" অক্ষরটি আছে (`Contains` মেথড ব্যবহার করুন)।
২. প্রোডাক্টগুলো প্রথমে দাম অনুযায়ী (কম থেকে বেশি) এবং তারপর নাম অনুযায়ী সাজান (`ThenBy` ব্যবহার করে)।

**🧠 কুইজ:**
১. SQL-এর `WHERE` ক্লজ জেনারেট করতে EF Core-এ কোন মেথড ব্যবহার হয়?
   A. Select
   B. Where (উত্তর: B)
   C. OrderBy

২. বড় থেকে ছোট (Descending) অর্ডারে সাজাতে কোন মেথড লাগে?
   A. OrderBy
   B. OrderByDescending (উত্তর: B)
   C. Reverse

৩. ফিল্টারিং লজিক কি `ToList()` এর আগে লেখা উচিত নাকি পরে?
   A. পরে
   B. আগে (উত্তর: B)
   C. যেকোনো এক জায়গায়

**⚠️ খুব জরুরি নোট:** কখনোই `ToList()` এর পরে `Where` ব্যবহার করবেন না।
- ✅ `context.Products.Where(...).ToList()` -> ডাটাবেজ ফিল্টার করে অল্প ডাটা আনবে (Fast)।
- ❌ `context.Products.ToList().Where(...)` -> সব ডাটা RAM-এ এনে তারপর ফিল্টার করবে (Slow & Dangerous)।

### Lesson 8: ডাটা আপডেট করা (Update Operation)

**👨‍🏫 কোড রান টিপ:** `Program.cs` ফাইলে কোড লিখুন।

**🎉 ভূমিকা:**
ধরুন, দোকানে একটি পণ্যের দাম বেড়েছে। ডাটাবেজে সেটা কীভাবে ঠিক করবেন? SQL-এ `UPDATE` কুয়েরি লেখা বেশ ঝামেলার। কিন্তু EF Core-এ এটা পানির মতো সহজ! আপনি শুধু C# অবজেক্টের প্রপার্টি ভ্যালু চেঞ্জ করবেন, বাকিটা EF Core বুঝে নেবে।

**🎯 শেখার লক্ষ্য:**
১. ডাটা ফেচ (Fetch) করে মডিফাই করা।
২. EF Core-এর **Change Tracking** মেকানিজম বোঝা।
৩. `SaveChanges()` এর মাধ্যমে আপডেট নিশ্চিত করা।

**📖 প্রধান বিষয়বস্তু:**
EF Core এ ডাটা আপডেটের সাধারণ ফ্লো হলো: **Retrieve → Modify → Save**।
1. **Retrieve:** প্রথমে যেই ডাটা আপডেট করতে চান, সেটা ডাটাবেজ থেকে `Find` বা `First` দিয়ে তুলে আনুন।
2. **Modify:** সাধারণ C# ক্লাসের মতোই প্রপার্টি ভ্যালু পরিবর্তন করুন (যেমন: `p.Price = 500;`)।
3. **Save:** `SaveChanges()` কল করুন।

*মজার বিষয়:* আপনাকে আলাদা করে `context.Update(product)` মেথড কল করতে হবে না! কারণ ডাটাটি যখন তুলে এনেছেন, EF Core সেটাকে "Track" করছে। ভ্যালু চেঞ্জ করলেই সে বুঝতে পারে এবং অটোমেটিক `UPDATE` কুয়েরি জেনারেট করে।

**💻 কোড উদাহরণ:**

**ফাইল:** `src/Program.cs`
```csharp
using System;
using System.Linq;
using Lesson01_Intro.Data;
using Lesson01_Intro.Models;

namespace Lesson01_Intro
{
    class Program
    {
        static void Main(string[] args)
        {
            using (var context = new AppDbContext())
            {
                // ১. টেস্ট করার জন্য একটি প্রোডাক্ট নিশ্চিত করি
                var testProduct = context.Products.FirstOrDefault(p => p.Name == "Old Phone");
                if (testProduct == null)
                {
                    testProduct = new Product { Name = "Old Phone", Price = 10000 };
                    context.Products.Add(testProduct);
                    context.SaveChanges();
                    Console.WriteLine("টেস্ট ডাটা তৈরি করা হলো।");
                }

                Console.WriteLine($"আপডেটের আগে: {testProduct.Name} - {testProduct.Price} tk");

                // ২. ডাটা মডিফাই করা (Modify)
                // আমরা অবজেক্টের ভ্যালু চেঞ্জ করছি, কিন্তু এখনো ডাটাবেজে যাইনি
                testProduct.Price = 12000; // দাম বাড়ালাম
                testProduct.Name = "New Smart Phone"; // নাম পাল্টালাম

                // ৩. পরিবর্তন সেভ করা (Save)
                // EF Core ডিটেক্ট করবে কোন ফিল্ড চেঞ্জ হয়েছে এবং শুধু সেগুলোর জন্য UPDATE SQL চালাবে
                context.SaveChanges();

                Console.WriteLine($"আপডেটের পরে: {testProduct.Name} - {testProduct.Price} tk");
                
                // টিপ: এটি চেক করতে পারেন
                Console.WriteLine($"Entity State: {context.Entry(testProduct).State}");
            }
        }
    }
}
```

**🏋️‍♂️ প্র্যাকটিস এক্সারসাইজ:**
১. একটি প্রোডাক্ট খুঁজে বের করুন এবং তার নামের শেষে " (Updated)" স্ট্রিংটি যুক্ত করে সেভ করুন।
২. `Find` দিয়ে এমন একটি আইডি খুঁজুন যা নেই, তারপর সেটার প্রপার্টি চেঞ্জ করার চেষ্টা করুন (Null Reference Exception হ্যান্ডল করুন)।

**🧠 কুইজ:**
১. ট্র্যাক করা এন্টিটি আপডেট করার জন্য `context.Products.Update(p)` কল করা কি বাধ্যতামূলক?
   A. হ্যাঁ, সবসময়।
   B. না, প্রপার্টি ভ্যালু চেঞ্জ করে `SaveChanges()` কল করলেই হয়। (উত্তর: B)
   C. আপডেট করাই যায় না।

২. EF Core আপডেটের সময় কোন কলামগুলো আপডেট করে?
   A. টেবিলের সব কলাম।
   B. শুধু যে কলামগুলোর ভ্যালু পরিবর্তন হয়েছে। (উত্তর: B)
   C. শুধু প্রাইমারি কি।

৩. `SaveChanges()` কল না করলে মেমোরিতে চেঞ্জ করা ভ্যালুর কী হবে?
   A. ডাটাবেজে অটোমেটিক সেভ হয়ে যাবে।
   B. অ্যাপ বন্ধ হলে হারিয়ে যাবে, ডাটাবেজে প্রভাব ফেলবে না। (উত্তর: B)
   C. এরর থ্রো করবে।

**⚠️ খুব জরুরি নোট:** ওয়েব অ্যাপ্লিকেশনে (API) ক্লায়েন্ট থেকে আসা অবজেক্ট আপডেট করতে `context.Update(obj)` বা `Attach` ব্যবহার করতে হয়, কারণ সেখানে অবজেক্টটি আগে থেকে ট্র্যাক করা থাকে না (Disconnected Scenario)। কিন্তু সাধারণ ফ্লো-তে রিট্রিভ করে আপডেট করাই বেস্ট প্র্যাকটিস।

### Lesson 9: ডাটা ডিলিট করা (Delete Operation)

**👨‍🏫 কোড রান টিপ:** সাবধান! এই কোড চালালে ডাটা চিরতরে মুছে যাবে।

**🎉 ভূমিকা:**
পুরানো বা অপ্রয়োজনীয় ডাটা মুছে ফেলার নামই ডিলিট অপারেশন। EF Core-এ ডিলিট করা মানে হলো—প্রথমে ডাটাটিকে "ডিলিট করার জন্য মার্ক করা" (`Remove`) এবং তারপর "ট্র্যাশ ক্যান খালি করা" (`SaveChanges`)।

**🎯 শেখার লক্ষ্য:**
১. একটি নির্দিষ্ট রেকর্ড ডিলিট করা (`Remove`)।
২. একাধিক রেকর্ড একসাথে ডিলিট করা (`RemoveRange`)।
৩. ডিলিট করার আগে ডাটা চেক করার গুরুত্ব।

**📖 প্রধান বিষয়বস্তু:**
ডিলিট করার জন্যও আমাদের সাধারণত আগে ডাটাটি খুঁজে বের করতে হয় (যাতে ভুল কিছু ডিলিট না হয়)।
- **Single Delete:** `context.Products.Remove(productObject);`
- **Multiple Delete:** `context.Products.RemoveRange(listOfProducts);`
- **Commit:** `SaveChanges();` চালালে ডাটাবেজে `DELETE` SQL কমান্ড যায়।

**💻 কোড উদাহরণ:**

**ফাইল:** `src/Program.cs`
```csharp
using System;
using System.Linq;
using Lesson01_Intro.Data;
using Lesson01_Intro.Models;

namespace Lesson01_Intro
{
    class Program
    {
        static void Main(string[] args)
        {
            using (var context = new AppDbContext())
            {
                // ১. ডিলিট করার জন্য একটি ডাটা খুঁজি
                var productToDelete = context.Products
                                             .FirstOrDefault(p => p.Name == "New Smart Phone");

                if (productToDelete != null)
                {
                    Console.WriteLine($"মুছে ফেলা হচ্ছে: {productToDelete.Name}");

                    // ২. রিমুভ মেথড কল করা (Marked as Deleted)
                    context.Products.Remove(productToDelete);

                    // ৩. ডাটাবেজে কার্যকর করা
                    context.SaveChanges();

                    Console.WriteLine("সফলভাবে ডিলিট হয়েছে!");
                }
                else
                {
                    Console.WriteLine("ডিলিট করার মতো কোনো প্রোডাক্ট পাওয়া যায়নি।");
                }

                // বোনাস: একসাথে একাধিক ডিলিট (Batch Delete)
                // যাদের দাম ৫০০ এর কম তাদের সব ডিলিট করো
                var cheapProducts = context.Products.Where(p => p.Price < 500).ToList();
                if (cheapProducts.Any())
                {
                    context.Products.RemoveRange(cheapProducts);
                    context.SaveChanges();
                    Console.WriteLine($"{cheapProducts.Count} টি সস্তা প্রোডাক্ট ডিলিট করা হয়েছে।");
                }
            }
        }
    }
}
```

**🏋️‍♂️ প্র্যাকটিস এক্সারসাইজ:**
১. আইডি (ID) ব্যবহার করে একটি প্রোডাক্ট খুঁজুন এবং সেটি ডিলিট করুন।
২. ডাটাবেজে নতুন ৫টি প্রোডাক্ট অ্যাড করুন, তারপর `RemoveRange` ব্যবহার করে সব প্রোডাক্ট ডিলিট করে টেবিল খালি করুন।

**🧠 কুইজ:**
১. `Remove()` মেথড কল করার সাথে সাথেই কি ডাটাবেজ থেকে ডাটা মুছে যায়?
   A. হ্যাঁ।
   B. না, `SaveChanges()` কল করার পর মুছে। (উত্তর: B)
   C. কিছুক্ষণ পর অটোমেটিক মুছে।

২. একাধিক রো (Row) একসাথে মুছতে কোন মেথড ব্যবহার করা হয়?
   A. DeleteAll
   B. RemoveList
   C. RemoveRange (উত্তর: C)

৩. আপনি যদি এমন একটি অবজেক্ট `Remove` করতে চান যা ডাটাবেজে নেই, তাহলে কী হবে?
   A. কিছুই হবে না।
   B. EF Core এরর (Exception) দেবে। (উত্তর: B - যদি অবজেক্টটি কনটেক্সটে ট্র্যাক করা না থাকে)
   C. নতুন ডাটা তৈরি হবে।

**⚠️ খুব জরুরি নোট:** EF Core 7+ এ `ExecuteDelete()` নামে একটি ফিচার এসেছে যা ডাটা মেমোরিতে না এনেই সরাসরি SQL দিয়ে ডিলিট করতে পারে (অনেকটা `TRUNCATE` বা `DELETE WHERE...` এর মতো)। এটা আমরা অ্যাডভান্স সেকশনে (Lesson 34) শিখব। আপাতত `Retrieve -> Remove -> SaveChanges` প্যাটার্ন অনুসরণ করুন।

### Lesson 10: সিঙ্ক্রোনাস বনাম অ্যাসিনক্রোনাস (Async/Await) অপারেশন

**👨‍🏫 কোড রান টিপ:** এই লেসনের কোড রান করতে হলে `Program.cs` এর `Main` মেথডকে `async Task` এ পরিবর্তন করতে হবে।

**🎉 ভূমিকা:**
ভাবুন তো, আপনি রেস্টুরেন্টে খাবার অর্ডার দিলেন।
- **Synchronous (Sync):** আপনি কাউন্টারের সামনে ঠায় দাঁড়িয়ে থাকলেন যতক্ষণ না খাবার তৈরি হচ্ছে। আপনি সরছেন না, তাই পেছনে লাইন বড় হচ্ছে। (বোরিং এবং স্লো!)
- **Asynchronous (Async):** আপনি অর্ডার দিয়ে টোকেন নিয়ে টেবিলে বসে মোবাইল টিপছেন। খাবার হলে ওয়েটার আপনাকে ডাকল। কাউন্টার ফাঁকা, তাই অন্যরাও অর্ডার দিতে পারছে। (স্মার্ট এবং ফাস্ট!)

EF Core-এ ডাটাবেজ অপারেশনগুলো সময়সাপেক্ষ (I/O Bound)। তাই আমরা Async ব্যবহার করি যাতে অ্যাপ আটকে (Freeze) না থাকে।

**🎯 শেখার লক্ষ্য:**
১. `async` এবং `await` কি-ওয়ার্ডের কাজ বোঝা।
২. EF Core-এর Async মেথডগুলো (যেমন `ToListAsync`, `SaveChangesAsync`) চেনা।
৩. কনসোল অ্যাপে `async Task Main` সেটআপ করা।

**📖 প্রধান বিষয়বস্তু:**
এতদিন আমরা যেসব মেথড ব্যবহার করেছি (Sync), সেগুলোর সবারই একটি করে "Async" যমজ ভাই আছে। আধুনিক অ্যাপ্লিকেশনে আমরা সবসময় Async ব্যবহার করার চেষ্টা করব।

| Synchronous (এড়িয়ে চলুন) | Asynchronous (ব্যবহার করুন) | কাজ |
| :--- | :--- | :--- |
| `ToList()` | `ToListAsync()` | কুয়েরি করে লিস্ট আনা |
| `FirstOrDefault()` | `FirstOrDefaultAsync()` | প্রথম ডাটা খোঁজা |
| `Find()` | `FindAsync()` | প্রাইমারি কি দিয়ে খোঁজা |
| `SaveChanges()` | `SaveChangesAsync()` | ডাটা সেভ করা |

**নিয়ম:**
১. মেথডের নামের শেষে `Async` থাকে।
২. কল করার আগে `await` লিখতে হয়।
৩. `Microsoft.EntityFrameworkCore` নেমস্পেস `using` করতে হয়।

**💻 কোড উদাহরণ:**

**ফাইল:** `src/Program.cs`
*(লক্ষ্য করুন `Main` মেথডের সিগনেচার পরিবর্তন হয়েছে)*

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks; // Task এর জন্য জরুরি
using Microsoft.EntityFrameworkCore; // Async মেথডগুলোর জন্য জরুরি
using Lesson01_Intro.Data;
using Lesson01_Intro.Models;

namespace Lesson01_Intro
{
    class Program
    {
        // ⚡ পরিবর্তন: void Main এর বদলে async Task Main
        static async Task Main(string[] args)
        {
            Console.WriteLine("--- Async/Await অপারেশন শুরু ---");

            using (var context = new AppDbContext())
            {
                // ১. Async পদ্ধতিতে ডাটা অ্যাড করা
                // (Add মেথডটি মূলত মেমোরিতে কাজ করে, তাই AddAsync খুব কম লাগে। 
                // কিন্তু SaveChangesAsync অবশ্যই লাগবে)
                var newProduct = new Product { Name = "Super Tablet", Price = 25000 };
                context.Products.Add(newProduct);

                Console.WriteLine("ডাটা সেভ হচ্ছে... (অপেক্ষা করুন)");
                
                // ⚡ await ব্যবহার করছি, যাতে এই কাজ শেষ না হওয়া পর্যন্ত কোড সামনে না বাড়ে,
                // কিন্তু থ্রেডটি ব্লক না থাকে।
                await context.SaveChangesAsync();
                
                Console.WriteLine("সেভ সম্পন্ন!");

                // ২. Async পদ্ধতিতে ডাটা পড়া (Read)
                Console.WriteLine("\nসব প্রোডাক্ট লোড হচ্ছে...");
                
                // ToList() এর বদলে ToListAsync()
                var products = await context.Products.ToListAsync();

                foreach (var p in products)
                {
                    Console.WriteLine($"- {p.Name} ({p.Price} tk)");
                }

                // ৩. শর্ত দিয়ে খোঁজা (Filter)
                Console.WriteLine("\n'Super Tablet' খোঁজা হচ্ছে...");
                
                // FirstOrDefault() এর বদলে FirstOrDefaultAsync()
                var tablet = await context.Products
                                          .FirstOrDefaultAsync(p => p.Name == "Super Tablet");

                if (tablet != null)
                {
                    Console.WriteLine($"পাওয়া গেছে: {tablet.Name}");
                }
            }
        }
    }
}
```

**🏋️‍♂️ প্র্যাকটিস এক্সারসাইজ:**
১. `FindAsync` ব্যবহার করে আইডি ১ এর প্রোডাক্টটি খুঁজে বের করুন এবং কনসোলে প্রিন্ট করুন।
২. একটি বিশাল ডাটা ইনসার্ট করার সিমুলেশন করুন (লুপে ১০০০ ডাটা অ্যাড), তারপর `SaveChangesAsync` কল করুন এবং দেখুন কোড ক্র্যাশ করে কি না (করবে না, কিন্তু একটু সময় নেবে)।

**🧠 কুইজ:**
১. EF Core-এ Async মেথড ব্যবহার করার জন্য কোন নেমস্পেসটি অবশ্যই ইম্পোর্ট করতে হবে?
   A. System.Data
   B. Microsoft.EntityFrameworkCore (উত্তর: B)
   C. System.Linq.Async

২. `async` মেথড কল করার সময় কোন কি-ওয়ার্ডটি ব্যবহার করতে হয় যাতে কোড রেজাল্টের জন্য অপেক্ষা করে?
   A. wait
   B. stop
   C. await (উত্তর: C)

৩. ওয়েব অ্যাপ্লিকেশনে (যেমন ASP.NET Core) কেন Async ব্যবহার করা জরুরি?
   A. কোড ছোট করার জন্য
   B. একই সময়ে অনেক রিকোয়েস্ট হ্যান্ডেল করার জন্য (Scalability) (উত্তর: B)
   C. ডাটাবেজ ফাস্ট করার জন্য

**⚠️ খুব জরুরি নোট:** কখনোই Async মেথডকে জোর করে Sync বানাবেন না (যেমন: `ToListAsync().Result` বা `.Wait()`)। এটি **Deadlock** তৈরি করতে পারে এবং আপনার অ্যাপ্লিকেশন হ্যাং হয়ে যেতে পারে। সবসময় `async-await` চেইন বজায় রাখুন।
