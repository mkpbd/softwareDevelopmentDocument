
অবশ্যই! চলুন, আমরা উইন্ডোজ WPF (Windows Presentation Foundation) অ্যাপ্লিকেশন ডেভেলপার হিসেবে আপনার যাত্রা ধাপে ধাপে, একেবারে বেসিক থেকে শুরু করে অ্যাডভান্সড পর্যন্ত সম্পন্ন করি। আমি এখানে একজন অভিজ্ঞ ডেভেলপারের মতো করে আপনাকে গাইড করব।

---

### **ভূমিকা: WPF কী এবং কেন?**

WPF বা Windows Presentation Foundation হলো Microsoft-এর একটি UI (User Interface) ফ্রেমওয়ার্ক যা দিয়ে আপনি সুন্দর এবং আকর্ষণীয় ডেস্কটপ অ্যাপ্লিকেশন তৈরি করতে পারবেন। পুরনো Windows Forms-এর তুলনায় এটি অনেক বেশি শক্তিশালী এবং আধুনিক।

**WPF-এর মূল সুবিধা:**
*   **XAML:** UI ডিজাইন করার জন্য XML-ভিত্তিক একটি ভাষা ব্যবহার করা হয়, যা ডিজাইনার এবং ডেভেলপারের কাজকে আলাদা করে দেয়।
*   **Data Binding:** কোড এবং UI-কে খুব সহজে একসাথে যুক্ত করা যায়। ডেটা পরিবর্তন হলে UI নিজে থেকেই আপডেট হয়ে যায়।
*   **Vector Graphics:** অ্যাপ্লিকেশনটি যেকোনো স্ক্রিন রেজোলিউশনে ঝকঝকে দেখায়, কারণ এটি পিক্সেলের উপর নির্ভরশীল নয়।
*   **Styles and Templates:** অ্যাপ্লিকেশনের চেহারা (look and feel) খুব সহজে পরিবর্তন ও কাস্টমাইজ করা যায়।

### **ধাপ ১: পরিবেশ তৈরি এবং প্রথম প্রজেক্ট (Environment Setup & First Project)**

**আপনার যা যা লাগবে:**

2.  **Workload:** ইনস্টল করার সময় **".NET desktop development"** এই ওয়ার্কলোডটি অবশ্যই সিলেক্ট করবেন। এর মধ্যেই WPF-এর জন্য প্রয়োজনীয় সবকিছু রয়েছে।

**চলুন প্রথম অ্যাপ্লিকেশন তৈরি করি:**

**প্রজেক্ট স্ট্রাকচার পরিচিতি:**

*   `MainWindow.xaml`: এটা আপনার অ্যাপ্লিকেশনের প্রধান উইন্ডো। এখানেই আপনি UI ডিজাইন করবেন।
*   `MainWindow.xaml.cs`: এটা `MainWindow.xaml`-এর কোড-বিহাইন্ড ফাইল। এখানে আপনি C# কোড লিখবেন যা আপনার UI-কে নিয়ন্ত্রণ করবে।
*   `App.xaml` এবং `App.xaml.cs`: এটা আপনার পুরো অ্যাপ্লিকেশনের স্টার্টিং পয়েন্ট এবং গ্লোবাল রিসোর্স রাখার জায়গা।

### **ধাপ ২: XAML এবং বেসিক কন্ট্রোল (XAML and Basic Controls)**

XAML (eXtensible Application Markup Language) হলো WPF-এর প্রাণ। HTML-এর মতো ট্যাগ ব্যবহার করে এখানে UI ডিজাইন করা হয়।

`MainWindow.xaml` ফাইলটি খুলুন। আপনি দুটি অংশ দেখবেন: উপরের অংশে ডিজাইনার এবং নিচের অংশে XAML কোড।

ডিফল্ট কোডটি এরকম দেখতে:
```xml
<Window x:Class="MyFirstWpfApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="MainWindow" Height="450" Width="800">
    <Grid>
        <!-- আমরা এখানে কন্ট্রোল যোগ করব -->
    </Grid>
</Window>
```

**সাধারণ কন্ট্রোল:**
*   **`TextBlock`**: টেক্সট দেখানোর জন্য।
*   **`TextBox`**: ব্যবহারকারীর কাছ থেকে ইনপুট নেওয়ার জন্য।
*   **`Button`**: ক্লিক করার জন্য বাটন।
*   **`Label`**: অন্য কন্ট্রোলের লেবেল হিসেবে ব্যবহৃত হয়।
*   **`CheckBox`**, **`RadioButton`**: অপশন সিলেক্ট করার জন্য।
*   **`ListBox`**, **`ComboBox`**: আইটেমের তালিকা দেখানোর জন্য।
*   **`Image`**: ছবি দেখানোর জন্য।

**উদাহরণ: একটি সাধারণ ফর্ম**
`Grid`-এর ভেতরে নিচের কোডটুকু যোগ করুন:

```xml
<Grid Margin="10">
    <StackPanel>
        <TextBlock Text="Hello, WPF World!" FontSize="24" HorizontalAlignment="Center" Margin="0,0,0,20"/>
        
        <Label Content="আপনার নাম লিখুন:"/>
        <TextBox x:Name="nameTextBox" Margin="0,0,0,10"/>
        
        <Button x:Name="submitButton" Content="ক্লিক করুন" Click="SubmitButton_Click"/>
        
        <TextBlock x:Name="resultTextBlock" Margin="0,20,0,0" FontSize="16"/>
    </StackPanel>
</Grid>
```
এখানে:
*   `StackPanel` কন্ট্রোলগুলোকে একটির পর একটি (উল্লম্বভাবে) সাজিয়ে রাখে।
*   `x:Name` দিয়ে আমরা কন্ট্রোলগুলোর একটি নাম দিয়েছি, যাতে C# কোড থেকে সেগুলোকে ব্যবহার করতে পারি।
*   `Click="SubmitButton_Click"` দিয়ে আমরা বাটনের একটি ইভেন্ট তৈরি করেছি।

**এবার কোড-বিহাইন্ড (`MainWindow.xaml.cs`) ফাইলে যাই:**
`SubmitButton_Click` ইভেন্টটি তৈরি করতে, XAML ফাইলে `SubmitButton_Click`-এর উপর রাইট-ক্লিক করে "Go to Definition" দিন অথবা `MainWindow.xaml.cs` ফাইলে নিজে থেকে নিচের মেথডটি লিখুন:

```csharp
private void SubmitButton_Click(object sender, RoutedEventArgs e)
{
    string name = nameTextBox.Text;
    if (!string.IsNullOrEmpty(name))
    {
        resultTextBlock.Text = $"স্বাগতম, {name}!";
    }
    else
    {
        resultTextBlock.Text = "অনুগ্রহ করে আপনার নাম লিখুন।";
    }
}
```
এখন `F5` চেপে অ্যাপ্লিকেশনটি রান করুন। নাম লিখে বাটনে ক্লিক করলে নিচের TextBlock-এ লেখা পরিবর্তন হবে।

### **ধাপ ৩: লেআউট প্যানেল (Layout Panels)**

WPF-এ কন্ট্রোলগুলোকে সুন্দরভাবে সাজানোর জন্য বিভিন্ন লেআউট প্যানেল আছে।
*   **`Grid`**: সারি (Row) এবং কলাম (Column) তৈরি করে টেবিলের মতো করে কন্ট্রোল সাজানো যায়। এটি সবচেয়ে শক্তিশালী এবং বহুল ব্যবহৃত।
*   **`StackPanel`**: কন্ট্রোলগুলোকে একটির নিচে একটি (Vertical) বা পাশাপাশি (Horizontal) সাজায়।
*   **`DockPanel`**: কন্ট্রোলগুলোকে প্যানেলের চারদিকে (Top, Bottom, Left, Right) ডক করে দেয়।
*   **`WrapPanel`**: জায়গা শেষ হয়ে গেলে কন্ট্রোলগুলোকে পরের লাইনে নিয়ে যায়।
*   **`Canvas`**: নির্দিষ্ট পজিশনে (x, y coordinate) কন্ট্রোল বসানোর জন্য ব্যবহৃত হয়।

**Grid-এর উদাহরণ:**
```xml
<Grid>
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto"/> <!-- কন্টেন্টের মাপে সারি -->
        <RowDefinition Height="Auto"/>
        <RowDefinition Height="*"/>    <!-- বাকি পুরো জায়গা জুড়ে -->
    </Grid.RowDefinitions>
    <Grid.ColumnDefinitions>
        <ColumnDefinition Width="Auto"/> <!-- কন্টেন্টের মাপে কলাম -->
        <ColumnDefinition Width="*"/>    <!-- বাকি পুরো জায়গা জুড়ে -->
    </Grid.ColumnDefinitions>
    
    <Label Content="নাম:" Grid.Row="0" Grid.Column="0" VerticalAlignment="Center"/>
    <TextBox Grid.Row="0" Grid.Column="1" Margin="5"/>
    
    <Label Content="ইমেইল:" Grid.Row="1" Grid.Column="0" VerticalAlignment="Center"/>
    <TextBox Grid.Row="1" Grid.Column="1" Margin="5"/>
</Grid>
```

### **ধাপ ৪: ডেটা বাইন্ডিং (Data Binding) - মধ্যম পর্যায়**

ডেটা বাইন্ডিং WPF-এর সবচেয়ে শক্তিশালী ফিচার। এর মাধ্যমে UI এবং ডেটা সোর্সের মধ্যে একটি সংযোগ তৈরি করা হয়। যখন ডেটা পরিবর্তন হয়, UI অটোমেটিক আপডেট হয় এবং যখন UI-তে কিছু পরিবর্তন করা হয়, ডেটাও আপডেট হয়ে যায়।

**`INotifyPropertyChanged` ইন্টারফেস:**
ডেটা পরিবর্তন হলে UI-কে জানানোর জন্য আমাদের ক্লাসকে `INotifyPropertyChanged` ইন্টারফেস ইমপ্লিমেন্ট করতে হয়।

**উদাহরণ:**
১. একটি ক্লাস তৈরি করুন, যেমন `Person.cs`:
```csharp
using System.ComponentModel;
using System.Runtime.CompilerServices;

public class Person : INotifyPropertyChanged
{
    private string _name;
    public string Name
    {
        get { return _name; }
        set
        {
            _name = value;
            OnPropertyChanged();
        }
    }

    public event PropertyChangedEventHandler PropertyChanged;

    protected void OnPropertyChanged([CallerMemberName] string name = null)
    {
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(name));
    }
}
```

২. `MainWindow.xaml.cs`-এ এই ক্লাসের একটি অবজেক্ট তৈরি করুন এবং উইন্ডোর `DataContext` হিসেবে সেট করুন:
```csharp
public partial class MainWindow : Window
{
    public Person CurrentPerson { get; set; }

    public MainWindow()
    {
        InitializeComponent();
        CurrentPerson = new Person { Name = "প্রাথমিক নাম" };
        this.DataContext = CurrentPerson; // এই লাইনটি খুব গুরুত্বপূর্ণ
    }
}
```

৩. अब `MainWindow.xaml`-এ `TextBox`-এর `Text` প্রপার্টিকে `Name`-এর সাথে বাইন্ড করুন:
```xml
<StackPanel Margin="20">
    <TextBox Text="{Binding Name, UpdateSourceTrigger=PropertyChanged}" FontSize="20"/>
    <TextBlock Text="{Binding Name}" FontSize="20" Margin="0,10,0,0"/>
</StackPanel>
```
*   `{Binding Name}`: এটি `DataContext`-এর `Name` প্রপার্টির সাথে বাইন্ড করে।
*   `UpdateSourceTrigger=PropertyChanged`: এর মানে হলো `TextBox`-এ প্রতিটি অক্ষর টাইপ করার সাথে সাথেই ডেটা আপডেট হবে।

এখন অ্যাপটি রান করলে দেখবেন, `TextBox`-এ যা লিখবেন, নিচের `TextBlock`-এও তাই দেখা যাবে। এখানে কোনো ইভেন্ট হ্যান্ডলার লেখার প্রয়োজন হয়নি! এটাই ডেটা বাইন্ডিং-এর জাদু।

### **ধাপ ৫: MVVM প্যাটার্ন (Model-View-ViewModel) - অ্যাডভান্সড পর্যায়**

বড় অ্যাপ্লিকেশন তৈরির জন্য MVVM একটি অপরিহার্য আর্কিটেকচারাল প্যাটার্ন। এটি কোডকে পরিষ্কার, টেস্টিং-এর উপযোগী এবং সহজে রক্ষণাবেক্ষণযোগ্য করে তোলে।

**MVVM-এর তিনটি অংশ:**
1.  **Model:** ডেটা এবং বিজনেস লজিক ধারণ করে (যেমন: `Person` ক্লাস)।
2.  **View:** ইউজার ইন্টারফেস (XAML ফাইল, যেমন: `MainWindow.xaml`)। View সরাসরি Model-এর সাথে কথা বলে না।
3.  **ViewModel:** View এবং Model-এর মধ্যে মধ্যস্থতাকারী হিসেবে কাজ করে। এটি View-এর জন্য ডেটা এবং কমান্ড (যেমন বাটন ক্লিক) সরবরাহ করে। ViewModel-কে View সম্পর্কে কোনো ধারণা রাখতে হয় না।

**MVVM প্রয়োগ:**
১. **Model:** আমাদের `Person.cs` ক্লাসটিই মডেল।
২. **View:** `MainWindow.xaml` হলো View।
৩. **ViewModel:** একটি নতুন ক্লাস তৈরি করুন, যেমন `MainViewModel.cs`:
```csharp
public class MainViewModel : INotifyPropertyChanged
{
    private Person _person;
    public Person Person
    {
        get { return _person; }
        set
        {
            _person = value;
            OnPropertyChanged();
        }
    }

    public ICommand ClearNameCommand { get; private set; }

    public MainViewModel()
    {
        Person = new Person { Name = "এখানে নাম লিখুন" };
        ClearNameCommand = new RelayCommand(ClearName, CanClearName);
    }

    private void ClearName(object parameter)
    {
        Person.Name = string.Empty;
    }

    private bool CanClearName(object parameter)
    {
        return !string.IsNullOrEmpty(Person.Name);
    }
    
    // INotifyPropertyChanged implementation এখানে থাকবে...
}
```
*   `ICommand`: বাটন ক্লিকের মতো অ্যাকশনগুলো ViewModel-এ `ICommand`-এর মাধ্যমে হ্যান্ডেল করা হয়। এর জন্য আপনাকে একটি `RelayCommand` বা `DelegateCommand` ক্লাস তৈরি করতে হবে (এটি WPF-এ বিল্ট-ইন নেই, কিন্তু অনলাইনে অনেক উদাহরণ পাওয়া যায়)।

৪. `MainWindow.xaml.cs`-কে প্রায় খালি করে ফেলুন এবং `DataContext` সেট করুন:
```csharp
public partial class MainWindow : Window
{
    public MainWindow()
    {
        InitializeComponent();
        this.DataContext = new MainViewModel();
    }
}
```

৫. `MainWindow.xaml`-কে ViewModel-এর সাথে বাইন্ড করুন:
```xml
<StackPanel Margin="20">
    <TextBox Text="{Binding Person.Name, UpdateSourceTrigger=PropertyChanged}" FontSize="20"/>
    <TextBlock Text="{Binding Person.Name}" FontSize="20" Margin="0,10,0,0"/>
    <Button Content="নাম মুছুন" Command="{Binding ClearNameCommand}" Margin="0,10,0,0"/>
</StackPanel>
```
দেখুন, `Button`-এ `Click` ইভেন্টের বদলে `Command` ব্যবহার করা হয়েছে। এখন কোড-বিহাইন্ড (`.cs` ফাইল) প্রায় পুরোটাই পরিষ্কার, এবং সমস্ত লজিক ViewModel-এ রয়েছে।

### **ধাপ ৬: স্টাইল, টেমপ্লেট এবং রিসোর্স (Styles, Templates & Resources)**

অ্যাপ্লিকেশনের সব বাটনের চেহারা একই রকম করতে চাইলে আপনি `Style` ব্যবহার করতে পারেন।
```xml
<Window.Resources>
    <Style TargetType="Button">
        <Setter Property="Background" Value="CornflowerBlue"/>
        <Setter Property="Foreground" Value="White"/>
        <Setter Property="FontSize" Value="14"/>
        <Setter Property="Padding" Value="10,5"/>
        <Setter Property="Margin" Value="5"/>
    </Style>
</Window.Resources>
```
এই কোডটুকু `Window` ট্যাগের ভেতরে রাখলে এই উইন্ডোর সব বাটন এই স্টাইলটি পেয়ে যাবে। `App.xaml`-এ রাখলে পুরো অ্যাপ্লিকেশনের সব বাটন এই স্টাইল পাবে।

**কন্ট্রোল টেমপ্লেট (ControlTemplate):** একটি কন্ট্রোলের সম্পূর্ণ ভিজ্যুয়াল গঠন পরিবর্তন করতে ব্যবহৃত হয়। যেমন, আপনি একটি বাটনকে বৃত্তাকার বা ছবির মতো করে ফেলতে পারেন।
