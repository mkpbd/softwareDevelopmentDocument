### **Module 1: The Absolute Basics - "Hello, WPF!"**

**Goal:** Create your first WPF application, understand its basic structure, and make the UI interactive using XAML and C# code-behind.

#### **Step 1: Create Your First WPF Project**

1.  Open **Visual Studio 2022**.
2.  Click **"Create a new project"**.
3.  In the search bar, type `WPF`.
4.  Select the **"WPF Application"** template with the C# tag. (Ensure you don't pick "WPF Application (.NET Framework)" unless you have a specific reason. The modern one is just "WPF Application").
5.  Click **Next**.
6.  Give your project a name, like `HelloWpfApp`.
7.  Click **Next**.
8.  Choose your framework (e.g., .NET 8.0).
9.  Click **Create**.

Visual Studio will generate a new project and open the `MainWindow.xaml` file, showing you a design view and the corresponding XAML code.

#### **Step 2: Explore the Project Structure**

In the Solution Explorer on the right, you'll see a few key files. Let's understand their roles:

*   `App.xaml` & `App.xaml.cs`:
    *   **What it is:** The entry point for your entire application. Think of it as the `Program.cs` file in a console app.
    *   **What it does:** It defines application-level resources (like styles that apply everywhere) and specifies which window to open first (`StartupUri="MainWindow.xaml"`).

*   `MainWindow.xaml`:
    *   **What it is:** The visual blueprint of your main window, written in XAML.
    *   **What it does:** You define your layout, buttons, text boxes, and all other UI elements here.

*   `MainWindow.xaml.cs` (the "Code-Behind"):
    *   **What it is:** A C# file directly linked to `MainWindow.xaml`.
    *   **What it does:** This is where you write the logic that makes your UI *do* things. For example, what happens when a user clicks a button.

#### **Step 3: Add Your First Controls in XAML**

Let's replace the default `<Grid>` with something simple. Go to `MainWindow.xaml` and replace the code inside the `<Window>` tags with this:

```xaml
<Grid>
    <!-- We'll define two rows to space things out a bit. -->
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto" /> <!-- A row just big enough for its content -->
        <RowDefinition Height="Auto" /> <!-- Another auto-sized row -->
    </Grid.RowDefinitions>

    <!-- Place the TextBlock in the first row (row 0) -->
    <TextBlock Grid.Row="0"
               x:Name="GreetingText"
               Text="Hello, World!"
               FontSize="24"
               HorizontalAlignment="Center"
               Margin="20" />

    <!-- Place the Button in the second row (row 1) -->
    <Button Grid.Row="1"
            x:Name="MyButton"
            Content="Click Me!"
            Width="120"
            Height="40"
            HorizontalAlignment="Center" />

</Grid>
```

**What did we just do?**
*   **`<Grid>`:** We used a `Grid` panel to organize our controls. We told it to create two rows.
*   **`<TextBlock>`:** This is a control for displaying read-only text.
    *   `Grid.Row="0"`: This is an "attached property." It tells the parent `Grid` to place this `TextBlock` in the first row (rows are zero-indexed).
    *   `x:Name="GreetingText"`: **This is very important.** It gives the control a unique name so we can access it from our C# code.
    *   `FontSize`, `HorizontalAlignment`, `Margin`: These are all standard properties to style and position the text.
*   **`<Button>`:** A standard clickable button.
    *   `Content="Click Me!"`: This sets the text displayed on the button.

**Run your application now (press F5 or the green "Start" arrow).** You should see a window with your text and a button. The button doesn't do anything yet.

#### **Step 4: Make It Interactive with Code-Behind**

Now, let's wire up the button.

1.  In your `MainWindow.xaml` file, find the `<Button>` element.
2.  Add a `Click` event handler to it. As you start typing `Click=`, Visual Studio will offer to create a new event handler for you. Press `Tab` to accept.

Your button XAML should now look like this:

```xaml
<Button Grid.Row="1"
        x:Name="MyButton"
        Content="Click Me!"
        Width="120"
        Height="40"
        HorizontalAlignment="Center"
        Click="MyButton_Click" />
```

3.  **Right-click** on `MyButton_Click` and select **"Go To Definition"** (or press F12). This will jump you to the `MainWindow.xaml.cs` file, where Visual Studio has created an empty method for you:

```csharp
private void MyButton_Click(object sender, RoutedEventArgs e)
{
    // We will add logic here
}
```

4.  Now, let's add the logic. Inside this method, we can access the `TextBlock` by its `x:Name` (`GreetingText`) and change its `Text` property.

```csharp
private void MyButton_Click(object sender, RoutedEventArgs e)
{
    GreetingText.Text = "Welcome to your first WPF App!";
}
```

**Run the application again (F5).**

Now, when you click the button, the text will change!
