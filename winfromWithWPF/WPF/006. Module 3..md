Of course. We've set up the "brain" (ViewModel) and the "nervous system" (Data Binding). Now it's time to build the "skeleton"—the layout that holds everything together.

### **Module 3: Layout and Controls**

**Goal:** Learn how to use WPF's powerful layout panels to arrange controls and build a responsive, organized user interface that adapts to different window sizes.

In WPF, you almost never set the exact pixel position of a control. Instead, you place controls inside **layout panels**, and the panel manages their size and position for you. Mastering these panels is the key to creating professional-looking applications.

Let's explore the most important ones.

#### **1. `StackPanel` - The Simple Stacker**

*   **What it does:** Arranges child elements in a single line, either vertically or horizontally. It's simple, fast, and very common.
*   **Key Property:** `Orientation` (can be `Vertical` (default) or `Horizontal`).

**Example:**
```xaml
<StackPanel Margin="10">
    <Label Content="Name:"/>
    <TextBox />
    <Label Content="Email:"/>
    <TextBox />
    <Button Content="Submit" Margin="0,10,0,0"/>
</StackPanel>
```
This will stack each control on top of the previous one. It's great for simple forms or toolbars.

#### **2. `Grid` - The Ultimate Organizer**

*   **What it does:** The most powerful and flexible layout panel. It arranges elements in a grid of rows and columns, much like an HTML table or a spreadsheet.
*   **Key Concepts:**
    *   **`RowDefinitions` & `ColumnDefinitions`:** This is where you define the number and size of your rows and columns.
    *   **Sizing:**
        *   **`Auto`**: The row/column is just big enough to fit its content.
        *   **`*` (Star Sizing)**: Takes up a proportional share of the remaining space. `2*` would take up twice as much space as `*`. This is the key to creating responsive UIs.
        *   **Fixed**: A specific size in pixels (e.g., `Height="50"`).
    *   **`Grid.Row` & `Grid.Column`:** Attached properties you set on the *child* elements to tell the `Grid` where to place them.

**Example:**
```xaml
<Grid Margin="10">
    <Grid.ColumnDefinitions>
        <ColumnDefinition Width="Auto" />   <!-- Column 0 for labels -->
        <ColumnDefinition Width="*" />      <!-- Column 1 for textboxes, fills remaining space -->
    </Grid.ColumnDefinitions>
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto" />      <!-- Row 0 for name -->
        <RowDefinition Height="Auto" />      <!-- Row 1 for email -->
        <RowDefinition Height="Auto" />      <!-- Row 2 for the button -->
    </Grid.RowDefinitions>

    <!-- Place controls in the grid cells -->
    <Label Grid.Row="0" Grid.Column="0" Content="Name:" />
    <TextBox Grid.Row="0" Grid.Column="1" Margin="5" />

    <Label Grid.Row="1" Grid.Column="0" Content="Email:" />
    <TextBox Grid.Row="1" Grid.Column="1" Margin="5" />

    <Button Grid.Row="2" Grid.Column="1" Content="Submit" HorizontalAlignment="Right" Margin="5" Width="100"/>
</Grid>
```
Notice how perfectly aligned this form is, and if you resize the window, the text boxes will grow while the labels stay the same size.

#### **3. `DockPanel` - For Docking to Edges**

*   **What it does:** Docks child elements to the top, bottom, left, or right edges of the panel. The last element added (by default) fills the remaining space in the center.
*   **Key Property:** `DockPanel.Dock` (an attached property set on the children: `Top`, `Bottom`, `Left`, `Right`).
*   **Common Use:** Classic application layouts with a top menu, a bottom status bar, and a main content area.

**Example:**
```xaml
<DockPanel>
    <Menu DockPanel.Dock="Top">
        <!-- Menu Items Here -->
    </Menu>
    <StatusBar DockPanel.Dock="Bottom">
        <StatusBarItem Content="Ready"/>
    </StatusBar>
    <Grid>
        <!-- The rest of your content goes here and fills the center -->
        <TextBlock Text="Main Content Area" HorizontalAlignment="Center" VerticalAlignment="Center"/>
    </Grid>
</DockPanel>
```

### **Let's Build a Practical Layout**

Time to apply this. We'll build a simple login form using a `Grid`, as it's the best tool for the job.

1.  Open your `MainWindow.xaml` file.
2.  **Delete all the code** inside your main `<Grid>` from the previous module. We're starting the layout from scratch.
3.  Set up your `Grid` with the necessary rows and columns. We need:
    *   3 rows: one for the username, one for the password, one for the button.
    *   2 columns: one for the labels, one for the input boxes.

    Add this inside your `<Grid>`:

    ```xaml
    <Grid.ColumnDefinitions>
        <ColumnDefinition Width="Auto" /> <!-- "Auto" makes the column just wide enough for "Password:" -->
        <ColumnDefinition Width="*" />    <!-- "*" makes this column take all remaining space -->
    </Grid.ColumnDefinitions>
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto" /> <!-- "Auto" makes the row just tall enough for the content -->
        <RowDefinition Height="Auto" />
        <RowDefinition Height="Auto" />
    </Grid.RowDefinitions>
    ```

4.  Now, add the controls and place them in the correct cells using `Grid.Row` and `Grid.Column`. Add some `Margin` and alignment properties to make it look clean.

    Add this code *after* the `RowDefinitions`.

    ```xaml
    <!-- Row 0: Username -->
    <Label Grid.Row="0" Grid.Column="0" 
           Content="Username:" 
           Margin="5" 
           VerticalAlignment="Center"/>
    
    <TextBox Grid.Row="0" Grid.Column="1" 
             Margin="5" 
             VerticalAlignment="Center"/>

    <!-- Row 1: Password -->
    <Label Grid.Row="1" Grid.Column="0" 
           Content="Password:" 
           Margin="5" 
           VerticalAlignment="Center"/>

    <!-- Use a PasswordBox for secure password entry -->
    <PasswordBox Grid.Row="1" Grid.Column="1" 
                 Margin="5" 
                 VerticalAlignment="Center"/>

    <!-- Row 2: Login Button -->
    <!-- Grid.ColumnSpan="2" makes the button stretch across both columns -->
    <Button Grid.Row="2" Grid.Column="0" Grid.ColumnSpan="2" 
            Content="Login" 
            Margin="10" 
            Width="100" 
            HorizontalAlignment="Center"/>
    ```

5.  **Run your application (F5).**

You should see a clean, well-aligned login form. Try resizing the window—notice how the text boxes stretch, but the labels stay put. This is the power of a `Grid` with star sizing.

### **Summary of Other Panels**

*   **`WrapPanel`:** Arranges items in a line and "wraps" to the next line when it runs out of space. Perfect for a photo gallery or a tag cloud.
*   **`Canvas`:** The "old school" panel. Lets you position children using explicit coordinates (e.g., `Canvas.Left="50"`). This is **not responsive** and should be used sparingly, mostly for custom drawing or diagrams where absolute positioning is required.

You've now learned the fundamental building blocks for creating any UI layout in WPF. The `Grid` and `StackPanel` will be your tools of choice for 95% of your work.
