Excellent. So far, our application is functional, but it looks like a standard, plain Windows app. One of WPF's greatest strengths is its powerful styling and templating engine, which allows you to completely customize the look and feel of your application.

### **Module 4: Making It Look Good - Styling & Templating**

**Goal:** Learn how to use resources, styles, and templates to create a consistent, reusable, and custom visual design for your application.

#### **1. Resources - The Reusable Building Blocks**

Imagine you want all your buttons to have the same blue background. You could write `Background="Blue"` on every single button, but what happens when you decide to change that color to green? You'd have to find and replace it everywhere.

**Resources** solve this problem. They are a way to define an object (like a color, a brush, a font size, or even a style) in one place and reuse it throughout your application.

**Example: Defining a Reusable Color**

1.  Open `App.xaml`. This is the perfect place for resources you want to be available to your entire application.
2.  Inside the `<Application>` tags, add a resource dictionary:

    ```xaml
    <Application.Resources>
        <ResourceDictionary>
            <!-- Define a solid color brush with a unique key -->
            <SolidColorBrush x:Key="PrimaryBrandColor" Color="#007ACC" />

            <!-- Define a numeric value -->
            <sys:Double x:Key="DefaultFontSize">14</sys:Double>
        </ResourceDictionary>
    </Application.Resources>
    ```
    *   *Note:* To use `sys:Double`, you need to add the `System` namespace at the top of your file: `xmlns:sys="clr-namespace:System;assembly=mscorlib"`

3.  Now, go to your `MainWindow.xaml` and use this resource to set a property. The syntax is `{StaticResource ResourceKey}`.

    ```xaml
    <!-- In MainWindow.xaml -->
    <Button Content="Login" 
            Background="{StaticResource PrimaryBrandColor}"
            Foreground="White"
            FontSize="{StaticResource DefaultFontSize}"
            ... />
    ```

**`StaticResource` vs. `DynamicResource`**
*   **`StaticResource`:** The value is looked up *once* when the XAML is loaded. It's fast and is what you'll use 99% of the time.
*   **`DynamicResource`:** The resource can be changed at runtime, and the UI will automatically update. This is more advanced and used for things like application theming (e.g., switching from a light to a dark theme).

#### **2. Styles - CSS for WPF**

A **Style** is a collection of property settings that can be applied to a control. It's the most powerful way to ensure a consistent look and feel.

**Example: Creating a Style for All Buttons**

Instead of setting the `Background`, `Foreground`, and `FontSize` on every single button, let's create a single style that does it all.

1.  Go back to `App.xaml` and add a `Style` to your `ResourceDictionary`.

    ```xaml
    <Application.Resources>
        <ResourceDictionary>
            <SolidColorBrush x:Key="PrimaryBrandColor" Color="#007ACC" />

            <!-- This is an IMPLICIT style. It will apply to ALL buttons in the app. -->
            <Style TargetType="Button">
                <Setter Property="Background" Value="{StaticResource PrimaryBrandColor}" />
                <Setter Property="Foreground" Value="White" />
                <Setter Property="FontSize" Value="14" />
                <Setter Property="Padding" Value="10,5" />
                <Setter Property="Margin" Value="5" />
            </Style>

            <!-- We can create another style for our TextBoxes -->
            <Style TargetType="TextBox">
                <Setter Property="Padding" Value="5" />
                <Setter Property="Margin" Value="5" />
                <Setter Property="VerticalContentAlignment" Value="Center" />
            </Style>
             <!-- And one for PasswordBox too -->
            <Style TargetType="PasswordBox">
                <Setter Property="Padding" Value="5" />
                <Setter Property="Margin" Value="5" />
                <Setter Property="VerticalContentAlignment" Value="Center" />
            </Style>
        </ResourceDictionary>
    </Application.Resources>
    ```

2.  Now, go to `MainWindow.xaml` and **remove all the properties we just defined in the style** from your button and text boxes. They will automatically pick up the style because the `TargetType` matches the control type.

    Your `Button` XAML might now look as simple as this:
    ```xaml
    <Button Grid.Row="2" Grid.ColumnSpan="2" 
            Content="Login"
            Width="100" 
            HorizontalAlignment="Center"/>
    ```
    ...and yet it will have the blue background, white text, and padding we defined. This makes your XAML incredibly clean and your design incredibly easy to change.

#### **3. Control Templates - Redefining Visual Structure**

This is where WPF truly shines. A Style lets you change properties of a control, but a **Control Template** lets you **completely replace its visual structure.**

Want a button that is a circle with an icon inside instead of a grey rectangle with text? You need a Control Template.

**Example: Creating a Round Button**

This is a more advanced concept, but it's essential to understand. Let's create a new style for a special kind of button.

1.  In `App.xaml`, add a new style. This time, we'll give it an `x:Key` so it's not applied automatically. This is an **explicit** style.

    ```xaml
    <!-- Add this to your ResourceDictionary in App.xaml -->
    <Style x:Key="RoundButtonStyle" TargetType="Button">
        <!-- Set the template for the button -->
        <Setter Property="Template">
            <Setter.Value>
                <ControlTemplate TargetType="Button">
                    <!-- The new visual structure starts here -->
                    <Grid>
                        <!-- We use an Ellipse for the shape -->
                        <Ellipse x:Name="OuterCircle" Fill="{TemplateBinding Background}"/>
                        
                        <!-- This ContentPresenter is a placeholder that says: -->
                        <!-- "Put the button's Content property right here." -->
                        <ContentPresenter HorizontalAlignment="Center" VerticalAlignment="Center" />
                    </Grid>
                    <!-- End of the new visual structure -->

                    <!-- Triggers are used for interactivity, like changing color on mouse over -->
                    <ControlTemplate.Triggers>
                        <Trigger Property="IsMouseOver" Value="True">
                            <Setter TargetName="OuterCircle" Property="Fill" Value="DarkBlue"/>
                        </Trigger>
                    </ControlTemplate.Triggers>

                </ControlTemplate>
            </Setter.Value>
        </Setter>
    </Style>
    ```
    *   **`<ControlTemplate>`**: This block defines the *new look*.
    *   **`<Ellipse ... />`**: Instead of a rectangle, our button's shape is now an ellipse.
    *   **`{TemplateBinding Background}`**: This is special. It binds the `Fill` of our ellipse to the `Background` property of the `Button` itself. This means we can still set `Background="Red"` on our button, and the template will respect it.
    *   **`<ContentPresenter />`**: This is a crucial placeholder. It displays whatever you put in the button's `Content` property (e.g., `<Button>Click Me</Button>`).
    *   **`<Trigger>`**: This lets us react to property changes. Here, when `IsMouseOver` becomes `True`, we change the `Fill` color of our ellipse.

2.  Now, in `MainWindow.xaml`, let's add a new button and apply this explicit style to it.

    ```xaml
    <!-- Add this button inside your Grid, maybe in a new row -->
    <Button Grid.Row="3" Grid.ColumnSpan="2"
            Content="?" 
            Style="{StaticResource RoundButtonStyle}"
            Background="Orange"
            Foreground="White"
            FontWeight="Bold"
            Width="40" Height="40"
            HorizontalAlignment="Left"/>
    ```

3.  **Run the application (F5).**

You will now see your standard rectangular "Login" button and a new, perfectly round orange button. Hover over the round button, and it will turn dark blue! You've completely redefined what a "Button" looks like.

*   **Styles:** Group property setters to create a consistent look. Use `TargetType` for implicit (automatic) styles and `x:Key` for explicit (opt-in) styles.
*   **Templates:** Completely replace the visual tree of a control for ultimate customization.
